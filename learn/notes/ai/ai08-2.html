Viterbi로 전체 상태열의 최빈값 찾기

각 날 가장 그럴듯한 상태를 줄지어 적어도, 가장 그럴듯한 사흘짜리 경로가 된다는 보장은 없습니다. 상태 사이 전이확률이 경로 전체의 점수에 들어가기 때문입니다.

이 장을 읽고 나면

  • 전체 상태열과 시점별 최빈값의 손실 기준을 비교한다.
  • 가장 큰 이전 경로를 택하는 점화식 및 포인터를 유도한다.
  • 경로 열거와 동적 계획으로 분수 결과를 비교한다.

경로 질량은 상태마다 조건을 이어 곱한다

앞 장과 같은 모형에서 관측은 1,0,1입니다. 숨은 경로가 (1,1,1)인 경우 관측까지의 결합확률은 (1/2)·(3/4)·(3/4)·(1/4)·(3/4)·(3/4)=81/2048입니다. 관측은 고정되므로 어떤 경로의 사후확률을 구할 때도 모두 같은 관측열 가능도 13/128로 나눕니다. 따라서 조건부확률이 가장 큰 경로는 결합확률이 가장 큰 경로입니다. 이를 최대 사후 확률(MAP) 경로라고 합니다.

상태 두 개에 길이 n이면 후보가 2ⁿ개입니다. 같은 끝 상태를 공유하는 두 경로의 뒤에 동일한 나머지 상태를 붙인다고 가정합시다. 마르코프 조건에 따라 미래 부분은 끝 상태만 보므로 붙이는 조건부 확률은 같습니다. 그래서 같은 끝 상태 뒤에서는 더 큰 질량을 가진 접두만 보존해도 최댓값을 잃지 않습니다.

끝 상태별 최고를 저장하고 거꾸로 찾는다

δₜ(j)는 시점 t까지 j로 끝나는 경로 가운데 가장 큰 관측 포함 질량입니다. 초기값은 전방 계산과 같습니다. 다음 상태 j로 올 수 있는 각 이전 상태 i를 비교하고, 가장 큰 위치를 backₜ(j)에 적습니다.

δₜ(j)= bⱼ(yₜ) · maxᵢ[δₜ₋₁(i) Tᵢⱼ]

관측 가능도가 0인 상태의 경로는 질량을 0으로 둡니다. 양의 관측열 가능도가 전제된 실습에서는 마지막에 양의 최댓값이 있습니다. 최댓값을 만드는 여러 이전 상태가 동점일 때 이 코드는 작은 상태 번호를 먼저 골라 결과를 고정합니다. 상태가 K개이면 조밀한 전이의 경우 시점마다 K개의 끝점에 K개의 이전 상태를 비교해 전체 O(nK²)번 계산합니다.

둘째 상태의 사후확률은 0이 27/52, 1이 25/52입니다. 따라서 날짜마다 하나씩 채점하면 둘째에 0이 유리합니다. 전체 경로에 대해 한 자리만 달라도 틀렸다고 하면 사후 질량이 가장 큰 1,1,1이 유리합니다. 상태열에 허용되지 않은 전이가 있다면 시점별 최빈을 각각 이은 결과가 실제 가능한 경로인지도 확인합니다.

모든 경로를 별도로 열거해 확인하기

from fractions import Fraction as F
from itertools import product
from math import prod

states = (0, 1)
y = (1, 0, 1)
T = ((F(3,4), F(1,4)), (F(1,4), F(3,4)))
B = ((F(3,4), F(1,4)), (F(1,4), F(3,4)))
scores = [F(1,2)*B[j][y[0]] for j in states]
back = []
for obs in y[1:]:
    incoming = [[scores[i]*T[i][j] for i in states] for j in states]
    pointers = [max(states, key=row.__getitem__) for row in incoming]
    scores = [incoming[j][pointers[j]]*B[j][obs] for j in states]
    back.append(pointers)
j = max(states, key=scores.__getitem__)
path = [j]
for pointers in reversed(back):
    path.append(pointers[path[-1]])
path = tuple(reversed(path))

def mass(z):
    return F(1,2)*B[z[0]][y[0]]*prod(
        T[z[t-1]][z[t]]*B[z[t]][y[t]] for t in range(1,len(y)))

pairs = [(mass(z), z) for z in product(states, repeat=len(y))]
assert mass(path) == scores[j] == max(p for p,z in pairs)
total = sum(p for p,z in pairs)
second_zero = sum(p for p,z in pairs if z[1]==0)
print(path, scores[j], scores[j]/total)
print(total, second_zero/total)
