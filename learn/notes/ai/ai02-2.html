A*는 이미 쓴 비용과 남은 비용의 추정값을 합친다

목적지에 당장 가까워 보이는 길만 고르면 이미 비싼 길로 돌아왔을 수도 있습니다. 실제로 지불한 비용과 아직 남은 거리의 추정을 합칩니다.

이 장을 읽고 나면

  • g·h·f를 구분해 A*의 다음 후보를 계산한다.
  • 허용적 휴리스틱과 일관적 휴리스틱을 구별한다.
  • 과대 추정에서 최적성 보장이 깨질 수 있음을 예로 계산한다.

추정값은 후보의 순서를 정하는 데 쓰인다

앞 장의 지도에서 S→A는 3, A→G는 1입니다. S→B→C→G는 각 간선 비용이 1입니다. 휴리스틱 h(n)은 현재 상태 n에서 목표까지 남은 최소 비용의 추정입니다. g(n)은 지금 후보가 출발점부터 실제 지불한 누적 비용입니다. A*는 f(n)=g(n)+h(n)이 작은 후보를 먼저 처리합니다. h가 언제나 0이면 UCS와 같은 우선순위입니다.

흔한 실수 · h만 보고 고르기

f(n)=h(n), 곧 남은 비용의 추정만으로 후보를 고르는 방법을 탐욕적 최우선 탐색(greedy best-first search)이라 합니다. 위 표의 h로 해 보면, S를 확장한 뒤 A(h=1)와 B(h=2) 가운데 h가 작은 A를 꺼내고, A에서 G(h=0)를 만들어 그것을 꺼내므로 S→A→G(비용 4)를 반환합니다. A까지 이미 3을 쓴 사실(g)을 보지 않았기 때문입니다. 같은 h를 쓰는 A*는 g를 더해 B(f=3)를 A(f=4)보다 먼저 꺼내고 비용 3의 경로를 찾습니다. 탐욕적 최우선 탐색은 목표 쪽으로 빨리 파고들 때가 많지만 최적성을 보장하지 않습니다.

남은 비용을 과대평가하는지와 이웃 간의 약속을 구분한다

허용적 휴리스틱은 참 최소 남은 비용보다 큰 값을 주지 않습니다. 여기서는 목표에서 h=0이고 모든 h가 0 이상인 경우를 다룹니다. 예의 B에서 C→G까지 두 번 각각 1을 지불하므로 h(B)=2는 허용적입니다. 일관적 휴리스틱은 매 간선 n→m에 h(n) ≤ 비용(n,m)+h(m)을 만족합니다. 이미 지불한 비용을 더해 보면 경로를 따라 f가 내려가지 않는 조건입니다. h(G)=0이면 각 간선의 부등식을 목표까지 이어 붙여 허용성도 얻습니다.

허용적이지만 일관적이지 않은 값을 만들 수 있습니다. 이 지도의 진짜 남은 비용을 앞의 표 그대로 두되 B의 h만 0으로 낮춥니다. 여전히 어디서도 과대평가하지 않습니다. 그러나 S→B의 부등식은 3≤1+0이라 성립하지 않습니다. 일관적일 때는 최소 f로 처리된 상태의 g를 다시 고칠 필요 없이 확정할 수 있습니다. 허용적이어도 일관성이 없다면 이미 처리한 상태로 더 싼 경로를 발견할 때 다시 후보로 올리는 방식이 필요할 수 있습니다.

낙관적 추정이 목표를 일찍 확정하는 데 왜 필요한가

유한한 그래프, 비음수 간선 비용, 목표 h=0, 그리고 더 낮은 g를 발견하면 상태를 다시 후보로 올리는 예제를 생각합니다. 아직 최적 목표가 반환되지 않았다면, 최적 경로 위에는 그 경로를 따라 해당 상태까지의 최소 비용 g로 도달한 후보가 남습니다. 허용적인 h를 더한 그 후보의 f는 최적 비용을 넘지 않습니다. 더 비싼 목표 후보는 h=0이라 자신의 더 큰 비용이 곧 f입니다. 더 비싼 후보가 먼저 꺼내질 수 없다는 것이 최적성의 요지입니다. 유한 그래프에서 비용이 엄격히 개선될 때만 상태를 다시 넣으면 갱신은 유한 번이고 도달 가능한 목표도 찾아냅니다.

같은 그래프에 추정값 두 종류를 넣는다

from heapq import heappop, heappush

graph = {"S": [("A", 3), ("B", 1)], "A": [("G", 1)],
         "B": [("C", 1)], "C": [("G", 1)], "G": []}

def astar(h):
    heap = [(h["S"], 0, "S", ("S",))]
    best = {"S": 0}
    popped = []
    while heap:
        _f, g, state, route = heappop(heap)
        if g != best[state]:
            continue
        popped.append(state)
        if state == "G":
            return " ".join(popped), route, g
        for nxt, step in graph[state]:
            next_g = g + step
            if next_g < best.get(nxt, float("inf")):
                best[nxt] = next_g
                heappush(heap, (next_g + h[nxt], next_g, nxt, route + (nxt,)))

normal = {"S": 3, "A": 1, "B": 2, "C": 1, "G": 0}
for estimate in (normal, dict(normal, B=9)):
    order, route, cost = astar(estimate)
    print(order, "::", " -> ".join(route), cost)
S B C G :: S -> B -> C -> G 3
S A G :: S -> A -> G 4

이 예는 과대 추정에서 어떤 후보를 먼저 꺼내는지 보여 줍니다. 더 큰 그래프의 정확한 비용을 모를 때에는 원래 문제의 제약 일부를 없앤 완화 문제(relaxed problem)의 최소 비용을 h로 씁니다. 예를 들어 상하좌우로 한 칸씩 비용 1로 움직이는 격자 지도에서 벽을 무시하면 남은 최소 비용은 가로·세로 칸 수의 합(맨해튼 거리)입니다. 제약을 없애면 선택이 늘기만 하므로 완화 문제의 최소 비용은 원래 문제의 최소 비용보다 커지지 않아 허용적입니다. 또 그것은 완화 문제에서의 정확한 최소 비용이라 간선마다 h(n) ≤ 비용(n,m)+h(m)도 지키므로 일관적이기도 합니다.
