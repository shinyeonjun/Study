규칙과 학습을 구분하고 AI 계열 연결하기

식물의 수분을 보고 물 주기가 필요한지 분류하는 작은 프로그램을 만듭니다. 사람이 기준을 정할 수도 있고, 과거 기록에 기준을 맞출 수도 있습니다. 출력이 같아 보여도 그 기준을 어떻게 얻었는지에 따라 다른 질문이 생깁니다.

이 장을 읽고 나면

  • 직접 지정한 결정 규칙과 자료에 맞춘 모형을 구별한다.
  • 학습한 기준값을 새 입력에 적용한다.
  • AI, 머신러닝, 딥러닝, 강화학습의 관계와 교집합을 설명한다.

같은 분류 문제를 두 가지 방식으로 풀어 본다

화분을 돌보는 사람이 흙의 수분을 재고 물이 필요한지 기록했다고 합시다. 입력은 화분 흙의 수분 측정값 하나입니다. 출력은 물 주기 판단을 돕는 두 범주, ‘물 필요’와 ‘물 불필요’입니다. 사람이 기록한 판단으로 연습한 뒤 새로운 측정값에서 예측을 만들어 봅니다.

사람이 ‘35% 이하에서 물 필요’라고 정해 프로그램에 적었다면, 기준 35는 직접 지정한 규칙입니다. 과거 기록 여러 개에서 평균적인 오류를 줄이도록 기준값을 고르게 하면 그 기준은 자료에서 학습된 값입니다. 출력 규칙의 꼴은 두 경우 모두 수분 ≤ 기준입니다.

연습 기록 네 건의 측정값이 20, 32, 40, 52%이고 앞의 두 건은 사람이 ‘물 필요’로 분류했습니다. 이 판단이 현재 문제에서 맞추고 싶은 정답입니다. 서로 이웃한 수분 값의 중점인 26, 36, 46을 후보로 잡습니다. 예측값과 정답이 다른 개수를 하나씩 세면 다음 표가 나옵니다.

학습한 기준을 새 입력에 적용한다

이 예제의 학습은 후보마다 오류를 계산하고 그중 최소인 기준값을 고르는 일입니다. 앞으로는 그 기준을 실제 예측에서 적용합니다. 새로운 수분 값 36%에서 직접 정한 35 규칙은 ‘물 불필요’, 학습한 36 규칙은 ‘물 필요’를 냅니다. 이것만으로 어느 쪽이 실제로 맞았는지는 알 수 없습니다. 이 화분의 정답을 나중에 확인해야 비교할 수 있습니다.

records = [(20, True), (32, True), (40, False), (52, False)]
cuts = [26, 36, 46]

def mistakes(cut):
    return sum((value <= cut) != label for value, label in records)

learned = min(cuts, key=mistakes)
print([mistakes(cut) for cut in cuts])
print(learned)
for value in (33, 36, 43):
    print(value, value <= 35, value <= learned)

마지막 두 열은 차례로 사람이 정한 규칙과 학습한 기준의 예측입니다. 규칙이나 모형이 과거 기록에 얼마나 잘 맞는지와 새 화분에서 얼마나 잘 작동하는지는 별개의 비교입니다. 새 기록은 학습에 쓴 네 건과 구별해 평가합니다.

네 이름은 과제와 방법을 서로 다른 기준으로 분류한다

이름이름을 붙이는 기준이 교재에서 이어지는 내용
인공지능(AI)판단·계획·예측·생성·행동 같은 문제의 연구 분야학습하는 시스템과 주어진 모형으로 탐색하는 시스템
머신러닝(ML)자료나 경험을 써서 과제에서 사용할 모형이나 결정을 학습수분 값으로 사람의 분류 판단을 예측하는 학습
딥러닝(DL)여러 층의 신경망을 학습해 모형을 만드는 계열영상에서 잎 상태를 분류하는 신경망, 생성 모형
강화학습(RL)행동이 보상과 이후 경험에 영향을 주는 문제의 행동 규칙을 학습여러 번 움직여 목표에 도달하도록 경험에서 학습

머신러닝은 인공지능의 여러 접근 중 하나입니다. 자주 인용되는 정의(Mitchell, 1997)로는, 프로그램이 과제 T에서 성능 척도 P로 잰 성적이 경험 E를 쌓을수록 나아지면 E로부터 학습한다고 말합니다. 앞의 예에서 T는 물 필요 분류, P는 잘못 분류한 건수, E는 네 건의 기록입니다. 딥러닝은 머신러닝 안의 모형 계열(여러 층의 신경망)이고, 강화학습은 머신러닝의 세 갈래(지도학습·비지도학습·강화학습) 가운데 하나로, 보상이 주어지는 상호작용에서 행동을 배우는 문제의 계열입니다. 그래서 딥러닝과 강화학습은 포함 관계가 아니라 일부가 겹치는 관계입니다.

강화학습과 딥러닝의 관계를 예로 보면 다음과 같습니다. 사진 분류용 신경망은 지도학습에 딥러닝을 쓸 수 있습니다. 작은 지도에서 위치와 행동별 점수를 표에 저장하는 강화학습은 신경망 없이 실행할 수 있습니다. 상황이 복잡해 표 대신 신경망으로 행동을 평가하면 딥러닝을 사용하는 강화학습이 됩니다.

영문 inference도 문맥에 따라 다릅니다. 지난 장에서는 사실에서 결론을 얻는 추론을 뜻했습니다. 머신러닝 코드에서 ‘학습 뒤 추론’은 학습한 모형을 새 입력에 적용해 결과를 얻는 단계입니다. 다음에 머신러닝의 문제 정의와 행동으로 배우기를 이어 읽을 수 있습니다.

한 줄 정리

규칙과 학습은 기준을 얻는 방법이 다르고, 머신러닝 안에서 딥러닝(모형)과 강화학습(문제)은 서로 다른 축이다.
