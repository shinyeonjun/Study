확률표를 다 만들지 않고 숨은 변수를 제거하기

관측된 센서 둘로 보이지 않는 상태의 확률을 구합니다. 모든 경우를 한꺼번에 적는 풀이에서 출발해, 계산의 어느 부분을 독립적으로 먼저 더해도 되는지 식으로 증명합니다.

이 장을 읽고 나면

  • 관측값을 인자에 고정하고 남은 변수의 범위를 적을 수 있다.
  • 변수 제거가 결합분포의 열거와 같은 값을 내는 이유를 보일 수 있다.
  • 작은 확률 그래프에서 인자의 곱과 합을 손으로 계산하고 검산할 수 있다.

센서 두 개를 보고 원래 상태를 추정한다

가상의 관측 장치에서 네 변수가 모두 0 또는 1의 값을 가집니다. A는 알고 싶은 원래 상태, M은 직접 보지 못하는 중간 상태입니다. 센서 X는 A에, 센서 Y는 M에 의존합니다. 방향 그래프의 화살표는 이 장의 확률 모형을 만드는 규칙입니다. 실제 실험에서 A를 바꾸면 어떤 결과가 생기는지까지 주장하려면 별도의 가정이 필요합니다.

베이즈망의 조건부 확률표를 곱하면 P(A,M,X,Y)=P(A)P(M|A)P(X|A)P(Y|M)입니다. 각 표는 일부 변수의 값만 받습니다. 이번 장에서는 확률 계산 중간에 만들어지는, 지정된 변수들의 조합에 숫자를 대응하는 표도 다루므로 이를 통틀어 인자(factor)라 부릅니다. 중간 인자 각각의 값은 합이 1일 필요가 없습니다.

값을 정하는 대상조건 상태 0에서 1의 확률조건 상태 1에서 1의 확률
중간 상태 MP(M=1|A=0)=1/5P(M=1|A=1)=4/5
센서 XP(X=1|A=0)=1/4P(X=1|A=1)=3/4
센서 YP(Y=1|M=0)=1/10P(Y=1|M=1)=9/10

나머지 이진 결과의 확률은 1에서 빼면 됩니다. 사전 확률 P(A=1)=1/4입니다. 이번에는 두 센서 모두 1을 보고했습니다.

관측은 표를 자르고 숨은 상태는 표를 더한다

관측 X=1을 P(X|A)에 대입하면 인자 fX(A)=P(X=1|A)를 얻습니다. 이제 X는 합치거나 바꿀 변수가 아닙니다. Y=1도 고정해 fY(M)=P(Y=1|M)로 만듭니다. A=a의 비정규화 값 g(a)는 관측 사건과 A=a가 함께 일어날 확률입니다.

g(a) = Σm∈{0,1} P(a)P(m|a)fX(a)fY(m)

합을 내는 변수는 m입니다. P(a)와 fX(a)는 m에 따라 변하지 않아서 합의 밖으로 꺼낼 수 있습니다.

g(a) = P(a)fX(a) · Σm∈{0,1} P(m|a)fY(m)

이 식의 마지막 합이 숨은 상태 M을 변수 제거(variable elimination)한 결과입니다. M이 나타나는 인자만 곱하고, 그 곱에서 M을 합칩니다. M을 갖지 않은 인자는 나중에 곱합니다. 유한합의 분배법칙이므로 두 인자 묶음이 모두 m과 관계있는 것처럼 곱해 다시 적을 필요가 없습니다.

표의 두 행을 손으로 계산한다

A=0이면 M=0에서 (4/5)(1/10), M=1에서 (1/5)(9/10)입니다. 둘을 더하면 4/50+9/50=13/50입니다. A=1이면 (1/5)(1/10)+(4/5)(9/10)=37/50입니다. 이는 센서 Y만 놓고 본 P(Y=1|A)입니다. 센서 X의 관측과 사전 확률은 아직 반영하지 않았습니다.

AP(A)·P(X=1|A)M 제거 후 인자두 관측의 결합 g(A)
0(3/4)(1/4)=3/1613/5039/800
1(1/4)(3/4)=3/1637/50111/800

두 행을 합치면 관측 사건의 확률 150/800=3/16입니다. 관측이 있었다는 조건에서 상태 1은 (111/800)/(150/800)=37/50입니다. 마지막 나눗셈이 정규화입니다. 관측 확률이 0인 경우 이 방법으로 조건부확률을 정의할 수 없습니다. 0으로 나누는 대신, 불가능한 관측을 모형과 입력에서 먼저 조사합니다.

열거와 제거를 각각 코드로 만들기

from fractions import Fraction as F
from itertools import product

prior = (F(3, 4), F(1, 4))
m_one = (F(1, 5), F(4, 5))
x_seen = (F(1, 4), F(3, 4))
y_seen = (F(1, 10), F(9, 10))

def transition(a, m):
    return m_one[a] if m else 1 - m_one[a]

weights = [F(0), F(0)]
for a, m in product(range(2), repeat=2):
    weights[a] += prior[a] * transition(a, m) * x_seen[a] * y_seen[m]

removed = [sum(transition(a, m) * y_seen[m] for m in range(2)) for a in range(2)]
factored = [prior[a] * x_seen[a] * removed[a] for a in range(2)]
assert factored == weights
print("제거한 인자:", *removed)
print("두 상태의 결합:", *factored)
print("관측 사건:", sum(factored))
print("상태 1의 사후:", factored[1] / sum(factored))

실행 결과

제거한 인자: 13/50 37/50
두 상태의 결합: 39/800 111/800
관측 사건: 3/16
상태 1의 사후: 37/50

두 실행에서 같은 사후확률을 얻지만 중간 작업이 다릅니다. 이 작은 그래프에서는 절약이 작습니다. 숨은 변수가 늘어나면 어느 변수부터 합치는지에 따라 중간 인자의 변수 수가 달라집니다. 다음 장에서는 같은 질문으로 제거 순서를 바꿔 실제 표 크기를 비교합니다.
