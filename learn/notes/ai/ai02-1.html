AI02·1

상태와 목표가 같아도 가장 좋은 경로의 기준은 다르다

가상의 자료 상자를 도착점으로 옮깁니다. 몇 번에 도착하는지와 얼마가 드는지에 따라 같은 지도에서도 다른 길을 선택합니다.

이 장을 읽고 나면

  • 탐색에서 초기 상태·행동·전이·목표·비용을 명시한다.
  • BFS와 균일비용 탐색의 후보 선택 규칙을 비교한다.
  • 목표에 도달할 수 있는 조건과 최소 비용을 보장하는 조건을 구별한다.

무엇을 알아야 다음 행동을 정할 수 있는가

시작점 S에서 도착점 G까지 자료 상자를 옮깁니다. 각 길은 지금 위치만 알면 이용 가능하며, 길의 비용도 고정입니다. 이때 상태는 현재 위치 하나로 충분합니다. 배터리 1개가 있어야 여는 문이 추가되면 같은 위치에서도 할 수 있는 행동이 다릅니다. 그때는 위치와 남은 배터리를 함께 상태로 적습니다.

탐색 문제에는 초기 상태, 상태에서 가능한 행동, 행동 뒤의 상태, 목표 판정, 비용을 둡니다. 여기서 초기 상태는 S, 행동은 화살표 하나를 따라가기, 목표 판정은 현재 상태가 G인지입니다. 모든 가능한 상태와 이동을 합쳐 상태공간이라 합니다. 같은 위치에 들어오는 경로가 여럿이어도 위치 상태는 하나입니다. 후보 기록에는 누적 비용과 경로처럼 어느 길로 왔는지도 따로 저장할 수 있습니다.

간선 수와 비용을 서로 다른 순서로 비교한다

BFS(너비 우선 탐색)는 먼저 들어온 후보를 먼저 꺼냅니다. 새로 발견한 상태를 큐에 넣을 때 기록하면 같은 상태를 반복해서 넣지 않습니다. 시작 S에서 이웃 A, B를 순서대로 넣으면 두 번 이동해 A를 거친 G를 먼저 만납니다. 길이는 2지만 비용은 3+1=4입니다. BFS는 이동 횟수에 대해 최적이며, 모든 간선 비용이 같은 양수라면 비용도 최소입니다.

균일비용 탐색(UCS)은 누적 비용 g가 가장 작은 후보부터 꺼냅니다. 다익스트라와 같은 완화 원리로, 상태까지 더 싼 후보를 찾으면 비용과 경로를 바꿉니다. 이 예에서는 B(1), C(2)를 거치고 G에 비용 3으로 도착합니다. 목표를 처음 생성할 때 바로 반환하면 더 싼 목표 경로를 놓칠 수 있습니다. 예를 들어 S의 이웃 목록에 비용 5의 직행 S→G가 있었다면, S를 확장하는 단계에서 경로 비용 5로 끝내게 됩니다. UCS에서는 저장된 최저 비용과 일치하는 목표 후보를 최소 힙에서 꺼낼 때 멈춥니다.

완전성은 해가 있으면 찾아내는 성질입니다. 최적성은 찾아낸 해가 목표 기준에서 최소 비용이라는 성질입니다. 유한 그래프에서 상태를 적절히 기록하는 BFS는 목표가 도달 가능하면 찾습니다. 유한 그래프에서 가중치가 0 이상이고 더 저렴할 때만 고치는 UCS도 완전하며 비용 최적입니다. 무한 상태공간에서는 별도 조건이 필요합니다. 이웃 수가 유한하고 모든 행동 비용에 양의 공통 하한이 있으면, 유한한 비용의 목표보다 싼 후보를 무한히 펼치는 문제를 피할 수 있습니다.

같은 지도에서 두 기준의 결과를 확인한다

from collections import deque
from heapq import heappop, heappush

graph = {"S": [("A", 3), ("B", 1)], "A": [("G", 1)],
         "B": [("C", 1)], "C": [("G", 1)], "G": []}

def hops():
    queue = deque([("S", ("S",), 0)])
    seen = {"S"}
    while queue:
        node, path, charge = queue.popleft()
        if node == "G":
            return path, charge
        for nxt, cost in graph[node]:
            if nxt not in seen:
                seen.add(nxt)
                queue.append((nxt, path + (nxt,), charge + cost))

def cheapest():
    heap = [(0, "S", ("S",))]
    best = {"S": 0}
    while heap:
        charge, node, path = heappop(heap)
        if charge != best[node]:
            continue
        if node == "G":
            return path, charge
        for nxt, cost in graph[node]:
            total = charge + cost
            if total < best.get(nxt, float("inf")):
                best[nxt] = total
                heappush(heap, (total, nxt, path + (nxt,)))

for name, search in (("BFS", hops), ("UCS", cheapest)):
    path, charge = search()
    print(name, " -> ".join(path), len(path) - 1, charge)
BFS S -> A -> G 2 4
UCS S -> B -> C -> G 3 3

이 출력의 마지막 두 수는 이동 횟수와 비용입니다. 실습에서 목표는 G 하나지만 목표 판정을 함수로 두면 조건을 만족하는 여러 상태 중 하나를 찾을 수 있습니다.
