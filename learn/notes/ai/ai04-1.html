상대도 고르는 게임에서 minimax와 α–β 가지치기

내 차례와 상대 차례가 번갈아 오면 한 수의 가치는 상대가 그 뒤에 어떤 수를 고를지에 따라 달라진다. 작은 게임 트리에서 끝 점수를 거꾸로 전달한다.

이 장을 읽고 나면

  • MAX 관점으로 기록한 잎 점수를 각 차례에 맞게 올린다.
  • α와 β의 뜻을 설명하고 생략 가능한 잎을 찾는다.
  • 가지치기의 결과와 탐색 순서에 달라지는 검사 횟수를 구분한다.

모든 잎 점수의 관점을 맞춘다

두 사람이 번갈아 움직이는 유한한 게임을 생각한다. 둘은 현재 상태를 모두 볼 수 있고, 같은 상태와 행동에서 다음 상태는 정해져 있다. 끝 점수 하나를 MAX의 관점으로 적는다. 상대 MIN은 MAX 점수가 낮을수록 좋다. 예를 들어 MAX가 3을 받는 잎에서 MIN을 −3으로 해석하는 제로섬 게임이다. 각자 최적으로 고른다는 전제를 둔다.

MAX의 첫 수는 왼쪽 L 또는 오른쪽 R이다. L을 고른 뒤 MIN은 3과 5 중 하나, R을 고른 뒤에는 2와 9 중 하나를 결정한다. L의 값은 min(3, 5)=3, R의 값은 min(2, 9)=2다. 첫 차례 MAX는 max(3, 2)=3을 받을 수 있는 L을 고른다. minimax는 잎에서 위로 올라가며 MAX 노드에는 자식 최대, MIN 노드에는 자식 최소를 전달한다.

앞에서 찾은 대안으로 남은 수를 줄인다

L을 먼저 모두 검사하면 시작점 MAX는 최소한 3을 확보할 수 있다. 이때 α는 경로상 MAX가 이미 확보할 수 있는 하한이다. R의 MIN에서 첫 잎 2를 읽으면, MIN이 자기 차례에 최적으로 고를 때 R의 값은 최대 2다. β는 경로상 MIN이 이미 제한할 수 있는 상한을 나타낸다. R의 값은 2 이하이고 L은 이미 3이다. 아직 읽지 않은 9가 어떤 값이어도 R이 L보다 좋아질 수 없다. 이렇게 α ≥ β이면 남은 자식을 생략할 수 있다.

경계는 MAX와 MIN을 내려가며 함께 전달한다. α는 지금까지 얻은 더 큰 하한으로만 갱신하고, β는 더 작은 상한으로만 갱신한다. 좋은 대안을 먼저 보면 가지를 잘라낼 여지가 커진다. 같은 게임 트리의 잎을 다른 순서로 보아도 최적 값은 같다. 같은 값으로 묶이는 최적 행동이 여럿이고 그 목록이 필요하면 동점 여부를 확인할 탐색이 더 필요할 수 있다.

완전 탐색과 방문한 잎을 비교한다

아래 트리는 정수 잎 또는 자식의 튜플로 적는다. use_bounds가 참일 때만 중단 조건을 적용한다. 시작점은 첫 MAX 차례이므로 처음 α와 β에 각각 음의 무한대와 양의 무한대를 준다.

tree = ((3, 5), (2, 9))


def run(use_bounds, root=tree):
    visited = []

    def search(node, maximize, alpha, beta):
        if isinstance(node, int):
            visited.append(node)
            return node

        value = float("-inf") if maximize else float("inf")
        for child in node:
            result = search(child, not maximize, alpha, beta)
            if maximize:
                value = max(value, result)
                alpha = max(alpha, value)
            else:
                value = min(value, result)
                beta = min(beta, value)
            if use_bounds and alpha >= beta:
                break
        return value

    value = search(root, True, float("-inf"), float("inf"))
    return value, visited


print("full:", run(False))
print("alpha-beta:", run(True))
print("reordered:", run(True, ((3, 5), (9, 2))))
full: (3, [3, 5, 2, 9])
alpha-beta: (3, [3, 5, 2])
reordered: (3, [3, 5, 9, 2])

판이 커서 제한 깊이까지만 볼 수 있으면 끝 점수 자리에 현재 상태를 평가하는 함수를 둘 수 있다. 이 경우 계산한 값은 선택한 깊이와 평가 함수에 따른 근사다. 우연 사건이 게임에 포함되면 여러 결과에 최솟값을 줄지, 확률을 가중할지 먼저 구분한다.

한눈에 정리

핵심어기억할 기준
MAX와 MIN한 관점의 점수를 키우는 차례와 줄이는 차례
minimax자식의 최대와 최소를 번갈아 적용
α–β 가지치기경계가 만나 현재 행동의 남은 검사가 결과 값을 개선할 수 없을 때 생략

한 줄 정리

잎 점수의 기준을 MAX로 맞추고, MAX는 최대를, MIN은 최소를 위로 보낸다.
