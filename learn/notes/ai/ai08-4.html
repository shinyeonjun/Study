입자 필터의 가중치와 재표집을 계산하기

상태가 많아 표의 모든 칸에 확률을 저장하기 어렵다면, 표본을 여러 개 움직여 분포를 근사할 수 있습니다. 표본 수가 여덟인 작은 모형으로 예측, 관측 가중치, 다시 뽑기를 분리합니다.

이 장을 읽고 나면

  • 표본 전파와 가능도 가중치의 역할을 구별한다.
  • 정규화된 가중치에서 유효 표본 크기를 손으로 계산한다.
  • 재표집과 표본 손실의 경계를 정확한 필터 값과 비교한다.

분포를 상태 표본 여러 개로 저장한다

한 시점에서 각 입자는 숨은 상태의 후보입니다. 가중치가 같으면 상태별 입자 비율로 확률을 근사합니다. 가중치가 다르면 각 상태에 있는 입자의 가중치 합을 사용합니다. 부트스트랩 입자 필터는 먼저 입자 각각을 다음 상태로 전이시킵니다. 이어 실제 관측을 그 상태에서 볼 가능도를 곱합니다. 바로 앞에서 모든 입자를 같은 무게로 재표집했다면, 이번 원시 가중치는 가능도에 비례합니다.

앞 상태 0과 1의 비율이 정확히 절반이고, 유지 확률이 3/4라면 다음 상태 1의 정확한 예측 확률은 (1/2)(1/4)+(1/2)(3/4)=1/2입니다. 연습에서는 각 타입에서 4개 중 3개가 실제로 유지된 한 번의 전이 결과를 사용합니다. 실제 모의실험에서 매번 유지되는 개수가 3개라고 강제하지 않습니다.

정규화와 가중치가 치우친 정도

예측 상태입자 수관측 1의 가능도입자 하나 정규화 가중치
041/41/16
143/43/16

여덟 입자의 원시 가중치 합은 4·(1/4)+4·(3/4)=4입니다. 따라서 상태 1의 가중 질량은 4·(3/16)=3/4입니다. 이 작은 모형에서는 정확한 Bayes 갱신과 우연히 일치합니다. 보통 입력 표본의 무작위 변동은 정규화한 추정에 남습니다.

정규화한 가중치 wᵢ를 사용해 유효 표본 크기의 흔한 지표 ESS=1/∑ᵢwᵢ²를 구합니다. 가중치가 전부 같으면 N, 하나에만 몰리면 1입니다. 이는 가중치 쏠림을 보여 주는 지표입니다. 상태의 중복이나 시간에 따른 의존성까지 측정하는 실제 독립 표본 수로 해석하면 안 됩니다. 여기서는 ESS=1/[4·(1/16)²+4·(3/16)²]=32/5입니다.

누적 구간에서 뽑아 같은 무게로 바꾼다

계통 재표집은 그릴 표본이 N개일 때 [0,1/N)에서 시작 위치 하나를 뽑고, 그 뒤로 1/N 간격으로 늘어놓습니다. 0에서 1까지의 누적 가중치 구간에서 각 위치가 가리키는 입자를 고릅니다. 연습은 시작 위치 1/32를 고정해 어느 칸을 고르는지 재현합니다. 실제 알고리즘에서는 시작 위치를 균등하게 뽑습니다.

설령 전파 후 입자가 모두 0이라면 같은 상태에서 가능도만 곱하는 연산과 재표집으로 상태 1을 다시 만들 수 없습니다. 이 경우 정규화된 가중치가 고르게 보여 ESS가 높더라도 상태 1의 확률을 놓칩니다. 전파 단계의 제안 분포와 표본 수를 함께 확인해야 합니다. 모든 입자의 가능도가 0이면 재표집할 분포도 정의되지 않습니다. 실제 관측이 모형에서 불가능한지, 표본이 지지집합을 놓쳤는지 구분해야 합니다.

재표집을 하지 않고 시점마다 가능도를 계속 곱하면, 몇 단계 뒤에는 거의 모든 무게가 소수의 입자에 몰려 ESS가 1 근처로 떨어집니다. 이를 가중치 퇴화라 합니다. 재표집은 무게를 다시 고르게 만들지만, 무게가 큰 입자를 복제하고 작은 입자를 버리므로 서로 다른 상태의 수가 줄어듭니다(표본 빈곤화). 그래서 매 시점 재표집하는 대신 ESS가 N/2 같은 기준 아래로 떨어질 때만 재표집하기도 합니다. 기준값은 관례이며 문제에 따라 정합니다.

from bisect import bisect_right
from fractions import Fraction as F
from itertools import accumulate

# 가능한 전이 결과 하나를 고정한다.
predicted = [0,0,0,1,0,1,1,1]
predicted.sort()
raw = [F(1,4) if s == 0 else F(3,4) for s in predicted]
total = sum(raw)
weight = [w/total for w in raw]
ess = 1/sum(w*w for w in weight)
cumulative = list(accumulate(weight))
positions = [F(1,32) + F(k,8) for k in range(8)]
drawn = [predicted[bisect_right(cumulative, u)] for u in positions]
p = sum(w for s,w in zip(predicted,weight) if s == 1)
print(weight[0], weight[-1], ess)
print(p, drawn.count(0), drawn.count(1))
assert p == F(drawn.count(1),8) == F(3,4)

항목핵심
전파각 입자를 전이분포에서 다음 상태로 옮긴다.
가중치관측 가능도에 비례. 정규화한 합으로 상태 확률을 근사.
ESS1/∑wᵢ². 가중치 쏠림의 지표이며 독립 표본 수가 아니다.
재표집과 퇴화재표집 없이는 가중치가 소수 입자에 몰리고, 재표집은 복제로 다양성을 줄인다. 없어진 상태는 재표집으로 되살릴 수 없다.
