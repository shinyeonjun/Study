AI03·1

제약을 만족하는 배치와 백트래킹

세 작업을 세 시간에 넣으면서 순서와 자원 규칙을 모두 지킨다. 가능한 배치만 찾아도 되는 문제에서 변수와 제약을 나누어 적고, 부분 배치를 조금씩 검사한다.

이 장을 읽고 나면

  • 변수, 도메인, 제약, 해를 구분한다.
  • 부분 배치의 제약 위반을 찾고 마지막 선택으로 되돌아간다.
  • 해 한 개를 찾는 문제와 해를 모두 세는 문제를 구분한다.

무엇을 정해야 하는지 먼저 적는다

실습실에서 한 번에 한 작업을 처리한다. A, B, C를 시간 1, 2, 3에 하나씩 배정한다. A는 B보다 먼저 끝나야 하고 C는 시간 3에 할 수 없다. 변수 A, B, C의 값은 각각 작업을 시작하는 시간 칸이고, 모든 작업은 한 칸 동안 진행된다. 각 작업이 일단 고려할 수 있는 값의 집합을 도메인이라고 한다. 이 예에서 각 도메인은 {1, 2, 3}이다. 규칙을 C의 도메인에 미리 반영하면 {1, 2}로 좁힐 수 있다.

변수 간에 지켜야 하는 관계가 제약이다. 여기서는 시간 충돌을 막는 ‘모두 다름’, 순서를 정하는 A < B, C 하나에 적용하는 C ≠ 3이 있다. 모든 변수에 값을 정하고 모든 제약을 만족하면 해다. 현재까지 값을 정한 변수가 일부라면 부분 배치다. 예를 들어 A=1, B=2는 C를 정하기 전이므로 부분 배치다. 아직 판단할 수 없는 제약을 통과했다고 처리하지 말고, 위반이 확정되는 제약부터 찾아낸다.

변수 또는 제약정의
변수A, B, C
처음 도메인각각 {1, 2, 3}
제약 1 (범위: A, B, C)A, B, C는 모두 다른 값
제약 2 (범위: A, B)A < B
제약 3 (범위: C)C ≠ 3

정의 · 제약 충족 문제(CSP)

제약 충족 문제(constraint satisfaction problem)는 세 가지로 정합니다. 변수의 집합 X, 변수마다의 도메인 D, 제약의 집합 C. 제약 하나는 범위(그 제약이 걸리는 변수들)와 그 변수들이 함께 가질 수 있는 값 조합의 규칙으로 이루어집니다. 범위가 변수 하나면 단항 제약(C ≠ 3), 둘이면 이항 제약(A < B), 셋 이상이면 전역 제약(모두 다름)이라 부릅니다. 모든 변수에 값을 정하고(완전 배정) 모든 제약을 만족하는 배정이 해입니다.

부분 배치를 지우고 이전 선택으로 돌아간다

A=1을 고른 다음 B=2를 고르면, C에 남는 값은 3뿐이라 그 가지에는 해가 없다. 마지막으로 시도한 B=2를 거두고 같은 A=1 아래에서 B=3을 시도한다. 이제 C=2가 가능하다. 이 절차를 백트래킹이라고 한다. 제약 위반이 확인된 부분 배치에서 더 깊이 들어가지 않고 아직 시도하지 않은 값을 찾는다. 어떤 변수의 모든 값을 시도했으면 바로 앞 변수를 바꾼다.

A=2이면 A < B로 인해 B=3만 남고 C=1이 된다. A=3이면 B가 더 큰 시간을 가질 수 없다. 해는 총 두 개다. 하나만 필요하면 첫 해에서 반환해도 된다. 전부 찾거나 해가 없음을 증명하려면 가능성이 남은 모든 가지를 검사한다. 각 단계에서 후보가 많고 제약으로 줄이는 가지가 적으면 검사량은 빠르게 커진다.

값을 정하기 전에 후보 줄이기: 전방 검사와 MRV

값 하나를 정할 때마다, 아직 정하지 않은 변수의 도메인에서 그 값과 충돌하는 값을 미리 지울 수 있습니다. 이를 전방 검사(forward checking)라 합니다. C의 도메인을 {1, 2}로 줄여 둔 상태에서 A=1을 정하면, 모두 다름과 A < B 때문에 B는 {2, 3}, C는 {2}가 됩니다. 이어서 B=2를 정하면 C의 도메인 {2}에서 2가 지워져 비므로, C의 값을 하나씩 시도해 보기 전에 바로 되돌아갑니다.

다음에 정할 변수로 남은 값이 가장 적은 변수를 고르는 규칙이 MRV(minimum remaining values, 최소 잔여값)입니다. A=1 뒤에는 C의 값이 2 하나뿐이므로 C=2를 먼저 정합니다. 전방 검사로 B는 {3}이 되고 B=3으로 끝납니다. 고정 순서 A, B, C에서 겪은 B=2의 실패 없이 해 (1, 3, 2)에 도착합니다. 실패할 변수를 먼저 건드려 막다른 가지를 일찍 잘라 내는 것이 MRV의 생각입니다. 더 강하게, 이항 제약으로 이어진 모든 변수 쌍에서 짝이 없는 값을 반복해 지우는 방법을 호 일관성(arc consistency) 검사라 하고, 대표 알고리즘이 AC-3입니다.

배정한 값만으로 검사한다

코드는 변수 순서를 A, B, C로 고정한다. 집합 변환으로 충돌을 확인하고, 규칙에 필요한 값이 배정되었을 때 순서와 C의 시간 조건을 검사한다. 새 딕셔너리를 만들어 재귀 호출에 전달하므로 가지를 나갈 때 다른 가지에 할당값이 섞이지 않는다.

def allowed(a):
    if len(set(a.values())) != len(a):
        return False
    if "A" in a and "B" in a and a["A"] >= a["B"]:
        return False
    return a.get("C") != 3


def solve(a):
    keys = "ABC"
    if len(a) == len(keys):
        yield tuple(a[key] for key in keys)
        return
    key = keys[len(a)]
    for slot in (1, 2, 3):
        child = {**a, key: slot}
        if allowed(child):
            yield from solve(child)


answers = list(solve({}))
print(answers)
print("count:", len(answers))
[(1, 3, 2), (2, 3, 1)]
count: 2

경로 탐색 관점에서 보면 각 노드는 부분 배치다. 여기서 목표는 완성한 배치의 제약 만족 여부이고, 같은 배치에 도착하는 경로 비용을 최소화하는 조건은 문제에 없다. 지연이나 비용 최적화까지 목표로 삼을 경우 어떤 값을 최소화할지 별도로 정의해야 한다. AI02의 경로 탐색에서 상태와 목표 검사를 정의하는 방법을 그대로 쓸 수 있다.
