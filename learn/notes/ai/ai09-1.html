행동의 전제와 효과에서 계획을 탐색하고 검증하기

작은 창고에서 물건 한 개를 A에서 B로 옮깁니다. 말로는 간단해도 빈손이어야 물건을 들 수 있고, 장소를 바꾸면 이전 장소는 지워야 합니다. 계획의 각 행동이 실제로 가능하다는 사실을 상태 전이로 확인합니다.

이 장을 읽고 나면

  • 명제를 사용해 상태와 목표를 적는다.
  • 행동의 전제, 추가, 삭제를 구별한다.
  • 그래프 탐색과 길이 제한 검사를 비교하고 완전성 조건을 증명한다.

참인 명제의 집합으로 창고를 기록한다

로봇이 구역 A에 있고 물건도 A에 있으며 손이 비었다고 합시다. s₀={atA, itemA, empty}로 적습니다. 상태에서 이름을 빠뜨린 사실은 거짓으로 읽습니다. carrying은 그때 참이 아닙니다. 목표는 {itemB}가 상태에 포함되는 것입니다. 로봇이 그 뒤에 어디 있어야 하는지는 목표에 쓰지 않았습니다.

행동을 (pre,add,del)로 기록합니다. pre가 현재 상태의 부분집합이어야 적용할 수 있습니다. 성공하면 s′=(s∖del)∪add를 얻습니다. 삭제하거나 추가하지 않은 명제는 그대로 남습니다. 이 작은 예에서는 전제가 양의 명제이고 행동의 효과는 결정적입니다.

행동전제추가삭제
A에서 들기atA, itemA, emptycarryingitemA, empty
A에서 B로atAatBatA
B에서 A로atBatAatB
B에서 내려놓기atB, carryingitemB, emptycarrying

이동 행동에서 atA를 지우지 않으면 수식은 금지하지 않은 두 위치의 동시 참을 허용합니다. 초기 상태와 올바른 네 행동을 사용하면 ‘atA와 atB 가운데 정확히 하나가 참’이라는 성질은 매번 유지됩니다. 행동이 어떤 불변식을 지키는지 확인하면 현실과 표현이 어긋나는 오류를 잡을 수 있습니다.

단계가 같은 간선이라면 BFS로 최소 행동 수를 찾는다

상태를 정점, 적용 가능한 행동을 간선으로 둡니다. 너비 우선 탐색(BFS)은 행동 수 0, 1, 2 순으로 상태를 꺼냅니다. 발견한 상태를 다시 큐에 넣지 않아도 이후의 적용 가능성과 결과는 같으므로, 같은 상태로 더 길게 돌아오는 경로는 더 짧은 답을 만들 수 없습니다. 동시에 미래 의사결정에 필요한 자원을 누락해 두 상태를 잘못 동일시하면 이 주장을 적용할 수 없습니다.

건전성은 반환한 계획의 행동이 전제에 맞고 마지막에 목적을 달성한다는 뜻입니다. 큐에 넣는 간선을 전제가 맞을 때만 만들므로 시작 상태부터 귀납적으로 이 성질이 성립합니다. 완전성은 가능한 계획이 있다면 하나를 찾는다는 뜻입니다. 상태와 적용할 행동이 유한하고 큐를 모두 처리한다고 합시다. 해를 구성하는 상태들을 처음부터 따라가면 각 상태는 이미 방문했거나 전 단계에서 추가됩니다. 따라서 목표에 도달할 경로가 있으면 목표가 결국 발견됩니다. 비용이 모두 1이면 처음 꺼낸 목표가 최소 행동 수입니다.

일정한 길이를 가정하면 제약 문제로도 풀 수 있다

길이 h를 정해 슬롯 A₀,…,Aₕ₋₁에 각각 행동을 넣습니다. S₀는 초기 상태, 각 Sₜ에서 Aₜ의 전제가 성립하고 다음 Sₜ₊₁이 효과 식에 맞아야 하며, Sₕ는 목표를 만족해야 합니다. 가능한 값이 하나라도 있으면 정확히 h단계 계획이 있다는 뜻입니다. 길이를 늘려 제약을 풀거나, 작은 예처럼 행동열을 전수 대조할 수 있습니다. 한 단계 비용이 행동마다 다르면 BFS의 최소 비용 보장은 없어집니다.

이 작은 문제에서 A*로 바꾼다면 목표 완료에 남은 필수 행동을 세어 하한을 만들 수 있습니다. 물건이 A에 놓여 있으면 들기·이동·내려놓기 세 번이, 든 채 A에 있으면 이동·내려놓기 두 번이, 든 채 B에 있으면 내려놓기 한 번이 필요합니다. 물건이 놓여 있는데 로봇이 B에 있으면 이 하한 밖에 되돌아가기 한 번이 추가됩니다. 한 행동으로 이 하한을 1보다 크게 줄일 수 없으므로, 비용이 1인 각 간선에서 h(s)≤1+h(s′)도 성립합니다. 이런 하한을 일관적인 휴리스틱이라고 부르며, 정의와 탐색에서의 쓰임은 탐색 단원에서 다룹니다.

최소 계획을 두 계산으로 검산한다

from collections import deque
from itertools import product

initial = frozenset(("atA", "itemA", "empty"))
goal = {"itemB"}
actions = {
    "pick": ({"atA","itemA","empty"},{"carrying"},{"itemA","empty"}),
    "move_ab": ({"atA"},{"atB"},{"atA"}),
    "move_ba": ({"atB"},{"atA"},{"atB"}),
    "drop": ({"atB","carrying"},{"itemB","empty"},{"carrying"}),
}

def advance(s, action):
    pre, add, delete = actions[action]
    return (s - delete) | add if pre <= s else None

queue = deque([(initial, ())])
seen = {initial}
while queue:
    state, plan = queue.popleft()
    if goal <= state:
        break
    for action in actions:
        nxt = advance(state, action)
        if nxt is not None and nxt not in seen:
            seen.add(nxt)
            queue.append((nxt, plan + (action,)))
else:
    raise ValueError("달성할 수 없는 목표")

def valid_plan(sequence):
    s = initial
    for action in sequence:
        s = advance(s, action)
        if s is None:
            return False
    return goal <= s

print(plan)
print([sum(valid_plan(seq) for seq in product(actions, repeat=h))
       for h in range(4)])
assert all(len(s & {"atA","atB"}) == 1 for s in seen)
