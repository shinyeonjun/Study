U05·1

Python 설치와 인터프리터

메모장을 열고 2 + 3이라고 적은 뒤 저장해도 컴퓨터는 5를 내놓지 않습니다. 그 글자를 읽고 실제로 계산해 주는 프로그램이 따로 있어야 합니다. 이 장에서는 그 프로그램인 Python 인터프리터가 무엇인지, Windows에 어떻게 설치하고 확인하는지, 그리고 한 줄씩 바로 실행해 보는 대화형 실행(>>>)을 다룹니다.

이 장을 읽고 나면

  • "Python을 설치한다"는 것이 무엇을 내 컴퓨터에 넣는 일인지 설명할 수 있다.
  • Windows 설치 화면에서 "Add python.exe to PATH"를 왜 체크하는지 설명할 수 있다.
  • python --version과 py --version으로 설치를 확인하고, 버전 번호를 읽을 수 있다.
  • 대화형 실행을 열어 계산해 보고, 닫을 수 있다.
  • 화면의 프롬프트(PS C:\…>와 >>>)를 보고 지금 어디에 명령을 치고 있는지 가려낼 수 있다.

코드는 혼자 실행되지 않는다

메모장에 다음 한 줄을 적고 hello.py라는 이름으로 저장했다고 해 봅시다.

print(2 + 3)

이 파일을 아무리 오래 열어 두어도 화면에 5는 나오지 않습니다. 컴퓨터 입장에서 이 파일은 p, r, i, n, t, ( … 같은 글자가 늘어선 글자 묶음일 뿐입니다. 메모장은 글자를 보여 주고 고치는 프로그램이지, 글자가 뜻하는 일을 해 주는 프로그램이 아닙니다.

이 글자를 "괄호 안을 계산해서 그 결과를 화면에 보여 줘"라는 명령으로 알아듣고 그대로 해 주는 프로그램이 필요합니다. 그 프로그램이 Python 인터프리터입니다.

정의 외우기

프로그래밍 언어: 사람이 컴퓨터에게 할 일을 적기 위해 정해 둔 글쓰기 규칙. Python은 그런 언어 가운데 하나입니다.
인터프리터(interpreter): 코드를 읽고 그 자리에서 실행해 주는 프로그램. Windows에서는 python.exe라는 파일이 Python 인터프리터입니다.

interpreter(통역사)라는 이름대로, Python 인터프리터는 코드를 읽어 곧바로 실행합니다. 그래서 코드를 고친 뒤 별도의 빌드 단계 없이 바로 다시 실행할 수 있습니다. C처럼 소스 전체를 실행 파일로 미리 번역해 두는 컴파일러 방식과 대비되는 점입니다(자세한 구분은 SY03).

더 알아보기 · 비유가 틀어지는 곳

"한 줄씩 듣고 바로 옮긴다"는 통역사 비유는 대화형 실행(뒤에서 배울 >>>)에는 잘 맞지만, 파일을 실행할 때는 조금 다릅니다. Python은 파일을 실행하기 전에 파일 전체를 먼저 한 번 읽어 문법이 맞는지 보고, 컴퓨터가 다루기 쉬운 중간 형태(바이트코드)로 바꾼 다음 실행합니다. 그래서 파일 셋째 줄에 괄호를 빠뜨리면, 첫째 줄조차 실행되지 않고 바로 오류가 납니다(U05·3에서 실제로 봅니다).

흔한 실수

"Python"이라는 낱말은 두 가지를 가리킵니다. 하나는 글쓰기 규칙인 언어이고, 다른 하나는 그 규칙대로 쓴 코드를 실행하는 프로그램(인터프리터)입니다. "Python을 배운다"는 앞의 뜻이고, "Python을 설치한다"는 뒤의 뜻입니다. 설치하는 것은 언어가 아니라 python.exe라는 실행 프로그램과 그에 딸린 파일들입니다.

Windows에 Python 설치하기

인터프리터는 Windows에 처음부터 들어 있지 않으므로 직접 설치해야 합니다. 이 교재의 모든 코드는 Python 3.14.6에서 실행해 확인했습니다.

어디서 받나

Python을 만들고 관리하는 단체의 공식 사이트 python.org에서 받습니다. 첫 화면의 Downloads 메뉴에 Windows용 내려받기가 있습니다. 검색 결과 위쪽에 뜨는 광고 사이트나 "무료 다운로드" 모음 사이트에서 받지 않습니다. 이름만 같은 다른 파일이 들어 있을 수 있습니다.

현재 권장 설치 방법

먼저 PowerShell에서 python --version을 실행하세요. 쓸 수 있는 Python 3의 버전이 나오면 이미 설치되어 있습니다. 새로 설치한다면 Python 공식 Windows 안내의 Python install manager를 따르세요. 설치가 끝나면 새 PowerShell 창에서 버전을 확인합니다. 아래의 PATH 확인 그림은 기존 방식의 .exe 설치 프로그램을 사용할 때 해당합니다. 공식 문서(3.14판)는 이 기존 설치 프로그램을 3.14부터 사용 중단 예정(deprecated)으로 표시하고 3.16부터는 만들지 않는다고 적고 있으며, 뒤에서 볼 예전 실행 도우미 py.exe도 install manager의 py 명령으로 대체되었다고 적고 있습니다.

첫 화면의 체크 상자 외우기

예전 방식 설치 프로그램(python-3.14.6-amd64.exe 같은 이름)을 실행하면 아래와 같은 첫 화면이 나옵니다. 여기서 단추를 누르기 전에 맨 아래 체크 상자부터 봅니다.

  1. "Add python.exe to PATH"에 체크합니다. 이것이 이 화면에서 가장 중요한 한 가지입니다. 이유는 바로 다음 절에서 설명합니다.
  2. 첫째 상자는 처음 보인 상태 그대로 둡니다. 3.13 무렵까지의 설치 프로그램에서는 "Use admin privileges when installing py.exe"로, 뒤에서 볼 실행 도우미 py.exe를 모든 사용자용으로 설치할지 정하는 상자였습니다. 3.14 설치 프로그램에서는 이 자리의 선택이 install manager 설치와 관련된 것으로 바뀌었으므로(공식 문서 기준) 문구가 그림과 다를 수 있습니다.
  3. Install Now를 누릅니다. 회사 컴퓨터처럼 관리자 허락을 묻는 창이 뜨면 "예"를 누르거나 관리자에게 부탁합니다.
  4. "Setup was successful"이 보이면 끝입니다. 그 화면에 "Disable path length limit"라는 단추가 보일 수 있는데, Windows의 경로 길이 260자 제한을 푸는 설정으로, 지금은 누르지 않아도 됩니다.

"Customize installation"은 설치할 위치나 부품을 직접 고르는 길입니다. 처음에는 쓰지 않습니다. Install Now를 누르면 그림의 경로(C:\Users\사용자이름\AppData\Local\Programs\Python\Python314)에 설치됩니다.

PATH는 무엇인가 이해하기

다음 장에서 터미널이라는 창을 엽니다. 키보드로 명령을 쳐서 프로그램을 실행하는 창입니다. 거기에 python이라고 치면, 터미널은 컴퓨터 안의 수십만 개 파일 가운데 어느 것을 실행해야 할지 알아야 합니다. 디스크 전체를 뒤지면 너무 오래 걸리므로, 터미널은 미리 정해 둔 폴더 몇 곳만 차례로 들여다봅니다. 그 폴더 목록이 PATH입니다.

용어 환경 변수는 컴퓨터 전체 또는 사용자에게 붙어 있는 설정값입니다. PATH는 그런 환경 변수 가운데 하나로, 값이 "폴더 경로 여러 개를 이어 붙인 목록"입니다.

정의

PATH: 터미널이 명령 이름에 해당하는 프로그램을 찾으러 들여다보는 폴더 목록. 위에서부터 차례로 찾다가 처음 찾은 것을 실행합니다.

"Add python.exe to PATH"에 체크하면 설치 프로그램이 Python이 설치된 폴더를 이 목록에 넣어 줍니다. 체크하지 않으면 Python은 분명히 설치되었는데도 터미널이 python이라는 이름의 프로그램을 찾지 못합니다. 그때 PowerShell은 이런 오류를 냅니다. 아래는 일부러 python을 pyhton으로 잘못 쳐서 "목록 어디에도 없는 이름"을 만든 실제 결과입니다. PATH에 Python 폴더가 없을 때 python을 치면, 앞의 낱말만 다르고 같은 모양의 문장이 나옵니다.

PowerShell 화면 (PowerShell 7 기준. 버전에 따라 아래에 줄이 몇 개 더 붙기도 한다)

PS C:\Users\me> pyhton --version
pyhton: 'pyhton' 용어는 cmdlet, 함수, 스크립트 파일 또는 실행 프로그램의 이름으로 인식되지 않습니다.
이름의 철자를 확인하거나 경로가 포함되어 있으면 경로가 올바른지 확인하고 다시 시도합니다.

이 문장의 뜻은 "PATH 목록의 폴더를 다 뒤졌는데 그런 이름의 프로그램이 없다"입니다. 원인은 두 가지 중 하나입니다. 이름을 잘못 쳤거나, 그 프로그램의 폴더가 PATH에 없거나. 체크를 빠뜨렸다면 설치 프로그램을 다시 실행해 "Modify"로 들어가 PATH 추가를 고르거나, Python을 지우고 체크한 채 다시 설치하면 됩니다. 설치를 고친 뒤에는 터미널 창을 닫고 새로 열어야 바뀐 PATH가 반영됩니다.

흔한 실수

설치하지 않았는데 python을 치면 Microsoft Store가 열린다. Windows 10·11에는 python이라는 이름을 가로채서 Store의 Python 안내 화면을 여는 장치(앱 실행 별칭)가 들어 있는 경우가 있습니다. Python이 이미 설치된 것처럼 보이지만 아닙니다. python.org에서 설치한 뒤 새 터미널에서 다시 확인하세요. 설치 후에도 계속 Store가 열리면 Windows 설정의 "앱 실행 별칭"에서 python 항목을 끄는 방법이 있습니다.

설치 확인하기: 버전 묻기

설치가 끝나면 Python에게 "너 몇 버전이니?"라고 물어서 확인합니다. 시작 단추를 누르고 PowerShell을 검색해 엽니다(터미널은 다음 장에서 자세히 다룹니다). 까만 또는 파란 창에 PS C:\Users\사용자이름> 같은 글자가 보이고 그 뒤에서 커서가 깜박입니다. 거기에 다음을 치고 Enter를 누릅니다.

PowerShell 화면 (첫 줄의 python --version만 내가 친 것)

PS C:\Users\me> python --version
Python 3.14.6
용어 명령 뒤에 붙여 동작을 바꾸는 말을 옵션(option)이라고 합니다. --version처럼 하이픈 두 개로 시작하는 긴 이름과, -V처럼 하이픈 하나에 글자 하나인 짧은 이름이 있습니다.

python은 "python이라는 프로그램을 실행하라", --version은 "코드를 실행하지 말고 버전만 알려 주고 끝내라"라는 옵션입니다. 두 낱말 사이에 빈칸이 꼭 있어야 합니다. 이 책의 예시에서 C:\Users\me의 me는 여러분 컴퓨터의 사용자 이름 자리입니다.

py: Windows용 실행 도우미

python.org 설치 프로그램은 python.exe와 함께 py라는 작은 프로그램(Python launcher, 실행 도우미)도 설치합니다. py는 컴퓨터에 설치된 Python을 찾아 대신 실행해 줍니다. 그래서 PATH 체크를 빠뜨렸어도 py는 동작하는 경우가 많습니다. 이 책이 실행한 실제 결과는 다음과 같습니다.

PowerShell 화면

PS C:\Users\me> py --version
Python 3.14.6
PS C:\Users\me> py -0
 -V:3.14 *        Python 3.14 (64-bit)

py -0은 "설치된 Python 목록을 보여 줘"라는 옵션입니다(숫자 0입니다). 별표(*)는 py만 쳤을 때 고르는 기본 버전입니다. Python을 여러 버전 설치했다면 py -3.14처럼 버전을 골라 실행할 수 있습니다. 위 결과는 예전 설치 프로그램이 넣은 실행 도우미의 것이고, install manager로 설치했다면 py -0은 남아 있지만 목록 모양이 다를 수 있습니다.

명령하는 일이 책에서 나온 결과
python --versionPATH에서 찾은 python의 버전을 보여 준다Python 3.14.6
py --version실행 도우미가 고른 Python의 버전을 보여 준다Python 3.14.6
py -0설치된 Python 목록-V:3.14 * Python 3.14 (64-bit)

macOS·Linux에서는 py가 없고, 명령 이름이 보통 python3입니다(python3 --version). 터미널은 "터미널" 앱을 씁니다. 이 책은 그쪽 화면을 직접 확인하지는 않았습니다.

버전 번호 읽기 이해하기

3.14.6은 소수가 아니라 점으로 나눈 세 개의 정수입니다. 앞에서부터 큰 판(메이저), 중간 판(마이너), 고친 판(마이크로) 번호입니다.

풀이 예제

강의 자료에 "Python 3.9 이상이 필요합니다"라고 적혀 있습니다. 내 컴퓨터는 3.14.6입니다. 조건을 만족할까요?

① 점으로 나눈다: 3.9 → (3, 9), 3.14.6 → (3, 14, 6)
② 첫 칸 비교: 3 = 3, 같으므로 다음 칸으로
③ 둘째 칸 비교: 14와 9는 정수로 비교한다. 14 > 9
④ 따라서 3.14.6이 3.9보다 새 판이다. 만족한다.

소수로 착각해서 "3.14는 3.9보다 작다(0.14 < 0.9)"라고 읽으면 틀립니다. 실제 출시 순서는 3.9 → 3.10 → … → 3.14입니다.

대화형 실행: >>> 에서 한 줄씩

이번에는 옵션 없이 python만 치고 Enter를 누릅니다. 화면이 이렇게 바뀝니다(실제 결과).

PowerShell 화면

PS C:\Users\me> python
Python 3.14.6 (tags/v3.14.6:c63aec6, Jun 10 2026, 10:26:10) [MSC v.1944 64 bit (AMD64)] on win32
Type "help", "copyright", "credits" or "license" for more information.
>>>
  • 첫 줄: 버전(3.14.6)과, 이 프로그램을 언제 어떤 도구로 만들었는지, 64비트 Windows(win32는 Windows를 뜻하는 옛 이름)에서 돈다는 정보입니다. 지금은 버전만 보면 됩니다.
  • 둘째 줄: 도움말을 보려면 help 등을 치라는 안내입니다.
  • 셋째 줄 >>>: 이제 Python이 코드를 기다린다는 표시입니다.
용어 프롬프트(prompt)는 프로그램이 "이제 입력하세요"라고 보여 주는 표시입니다. PowerShell의 프롬프트는 PS C:\…>, Python 대화형 실행의 프롬프트는 >>>입니다.

이 상태를 대화형 실행(interactive mode) 또는 영어 머리글자로 REPL이라고 합니다. 한 줄 치면 Python이 곧바로 답하고, 다시 다음 줄을 기다리는 것이 대화와 같아서 붙은 이름입니다. 실제로 쳐 본 결과입니다.

대화형 실행 (>>> 뒤가 내가 친 것, 그 아랫줄이 Python의 답)

>>> 2 + 3
5
>>> 1200 * 3
3600
>>> 10 / 4
2.5
>>> print("안녕하세요")
안녕하세요

*는 곱하기, /는 나누기입니다(계산 기호는 PY01·3에서 자세히). print("안녕하세요")는 괄호 안의 글자를 화면에 보여 주라는 명령입니다(PY01·1에서 자세히). REPL이라는 이름은 이 한 바퀴를 네 단계로 나눈 영어 머리글자입니다.

왜 그럴까?

위 예에서 2 + 3에는 print가 없는데도 5가 화면에 나왔습니다. 왜일까요?

모범 답 보기

대화형 실행은 한 줄을 계산한 다음 그 값을 자동으로 보여 주는 단계(Print)를 거치기 때문입니다. 계산 결과가 있는 줄이면 print를 쓰지 않아도 값이 나옵니다. 다음 장에서 볼 것처럼 파일로 실행할 때는 이 자동 보여 주기가 없어서, print를 쓰지 않은 값은 화면에 나오지 않습니다.

대화형 실행 닫기

다 썼으면 exit()를 치고 Enter를 누릅니다. 프롬프트가 다시 PS C:\…>로 돌아오면 Python이 끝나고 PowerShell로 돌아온 것입니다. Windows에서는 Ctrl+Z를 누른 뒤 Enter로도 닫을 수 있습니다(macOS·Linux는 Ctrl+D). Python 3.13부터는 괄호 없이 exit만 쳐도 닫힙니다.

PowerShell 화면

>>> exit()
PS C:\Users\me>

지금 어디에 치고 있나: 두 프롬프트 이해하기

같은 창 안에서 PowerShell에게 말하는 상태와 Python에게 말하는 상태가 바뀌는데, 둘을 구분하는 것은 맨 앞의 프롬프트뿐입니다.

(나)에서 python --version을 치면 Python은 이것을 Python 코드로 읽으려 합니다. Python 코드 안에서 python은 아무 뜻도 정해지지 않은 낱말이라 "python이라는 이름은 정해진 적이 없다(not defined)"는 오류를 냅니다. 고치는 법은 간단합니다. exit()로 Python을 닫고 PowerShell 프롬프트로 돌아와서 다시 칩니다.

흔한 실수

>>>까지 따라 치기. 책이나 웹에서 >>> 2 + 3을 보고 >>>까지 그대로 치면 오류가 납니다. >>>는 Python이 보여 주는 표시이지 내가 칠 글자가 아닙니다. 마찬가지로 PS C:\Users\me>도 PowerShell이 보여 주는 표시입니다. 프롬프트 뒤의 글자만 칩니다.

한 줄 정리

Python 코드는 인터프리터가 있어야 실행되고, Windows에서는 python.org 설치 때 PATH에 넣어야 터미널이 python을 찾으며, >>>에서는 한 줄씩 바로 실행해 볼 수 있다.
