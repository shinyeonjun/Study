터미널에서 .py 파일 실행하기

대화형 실행(>>>)에서 친 코드는 창을 닫으면 사라집니다. 내일 다시 쓰려면 코드를 파일로 남겨 두고, 필요할 때마다 그 파일을 실행해야 합니다. 이 장에서는 터미널에서 폴더를 옮겨 다니는 법(cd), .py 파일을 만들어 python hello.py로 실행하는 법, 그리고 "파일을 찾을 수 없다"는 오류를 고치는 법을 다룹니다.

이 장을 읽고 나면

  • PowerShell 프롬프트를 보고 지금 어느 폴더에 있는지 읽을 수 있다.
  • cd 폴더이름, cd .., ls로 폴더를 옮기고 안에 든 파일을 볼 수 있다.
  • .py 파일을 만들어 python 파일이름.py로 실행할 수 있다.
  • 대화형 실행과 파일 실행에서 결과가 다르게 나오는 이유를 설명할 수 있다.
  • can't open file … No such file or directory 오류의 원인을 찾아 고칠 수 있다.

터미널: 글자로 컴퓨터에 시키기

평소에는 마우스로 폴더 아이콘을 두 번 눌러 안으로 들어가고, 파일을 두 번 눌러 엽니다. 같은 일을 글자 명령으로 할 수도 있습니다. "문서 폴더로 들어가라", "이 파일을 Python으로 실행하라"를 키보드로 쳐서 시키는 창이 터미널입니다.

정의

터미널(terminal): 명령을 글자로 치고, 결과를 글자로 받는 창.
셸(shell): 터미널 안에서 내가 친 명령을 알아듣고 실행해 주는 프로그램. Windows의 기본 셸은 PowerShell입니다.

터미널과 셸을 엄밀히 나누면 "창"과 "창 안에서 말을 알아듣는 프로그램"이지만, 일상에서는 둘 다 그냥 "터미널"이라고 부르는 일이 많습니다. 이 책도 PowerShell 창을 터미널이라고 부릅니다. 비슷한 말로 명령줄(command line), CLI(command-line interface)가 있습니다. 마우스로 누르는 화면은 GUI(graphical user interface)라고 합니다.

PowerShell 여는 세 가지 방법

  1. 시작 단추를 누르고 "PowerShell"을 검색해 엽니다. 처음 위치는 보통 내 사용자 폴더(C:\Users\사용자이름)입니다.
  2. Windows 11에서는 파일 탐색기에서 폴더 빈 곳을 마우스 오른쪽 단추로 누르고 "터미널에서 열기"를 고르면, 그 폴더에서 터미널이 열립니다.
  3. 파일 탐색기 위쪽 주소창에 powershell이라고 치고 Enter를 눌러도 그 폴더에서 열립니다.

프롬프트 읽기 이해하기

PowerShell을 열면 맨 앞에 프롬프트가 보입니다. 프롬프트는 단순한 장식이 아니라 지금 내가 어느 폴더에 있는지를 알려 줍니다.

정의 외우기

현재 위치(current directory, 작업 폴더): 터미널이 지금 "들어가 있는" 폴더. 명령에 파일 이름만 쓰면 터미널과 프로그램은 이 폴더 안에서 그 파일을 찾습니다.

U02에서 본 것처럼 폴더는 나무 모양으로 이어져 있고, C:\Users\me\Documents는 "C 드라이브 → Users → me → Documents"로 내려간 길(경로)입니다. 파일 탐색기에서 "문서"라고 보이는 폴더의 실제 경로 이름이 Documents입니다.

현재 위치 옮기기: cd

폴더를 옮기는 명령이 cd입니다. change directory(폴더 바꾸기)의 머리글자입니다. 함께 쓰는 명령 몇 개를 표로 봅니다.

명령뜻예
cd 폴더이름현재 위치 안의 폴더로 한 칸 들어간다cd Documents
cd ..한 칸 바깥(부모 폴더)으로 나간다. 점 두 개가 "부모"라는 뜻cd ..
cd 전체경로어디에 있든 그 경로로 바로 간다cd C:\Users\me\Documents
ls 또는 dir현재 위치에 든 파일·폴더 목록을 보여 준다ls
pwd현재 위치를 글자로 보여 준다pwd
mkdir 폴더이름현재 위치 안에 새 폴더를 만든다mkdir python-study

폴더 이름에 빈칸이 있으면 따옴표로 감쌉니다(cd "my folder"). 이름을 몇 글자 치다가 Tab 키를 누르면 나머지를 채워 줘서, 철자 실수를 줄일 수 있습니다.

풀이 예제

PowerShell을 막 열었더니 프롬프트가 PS C:\Users\me>입니다. 문서 폴더 안에 python-study라는 공부용 폴더를 만들고 그 안으로 들어가 봅시다.

① 지금 위치: C:\Users\me (프롬프트에서 읽는다)
② cd Documents → 프롬프트가 PS C:\Users\me\Documents>로 바뀐다
③ mkdir python-study → Documents 안에 새 폴더가 생긴다
④ cd python-study → 프롬프트가 PS C:\Users\me\Documents\python-study>
⑤ ls → 방금 만든 빈 폴더라 아무것도 나오지 않는다

명령마다 프롬프트의 경로가 의도대로 바뀌었는지 확인하면, 엉뚱한 폴더에서 실행하는 실수를 대부분 막을 수 있습니다.

나중에 이 폴더에 hello.py를 넣고 ls를 치면 이렇게 나옵니다(실제 결과, 경로만 줄임). Mode 칸의 -a---는 파일, d----는 폴더라는 표시이고, Length는 파일 크기(바이트)입니다.

PowerShell 화면

PS C:\Users\me\Documents\python-study> ls

    디렉터리: C:\Users\me\Documents\python-study

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a---        2026-11-18  오전 3:02             40 hello.py

흔한 실수

cd..처럼 붙여 쓰기, cd ...처럼 점 세 개. 명령과 경로 사이에는 빈칸을 둡니다. "부모 폴더"를 뜻하는 것은 점 두 개입니다(점 하나 .는 "지금 폴더" 자신을 뜻합니다). 셸에 따라 붙여 써도 받아 주는 경우가 있지만, 빈칸을 두는 쪽이 어디서나 통합니다.

.py 파일 만들기

Python 코드를 담은 파일은 이름 끝에 .py를 붙입니다. 이렇게 파일로 저장해 두고 통째로 실행하는 코드를 스크립트(script)라고 합니다. 연극 대본(script)처럼 할 일이 처음부터 끝까지 적혀 있다는 뜻입니다.

용어 확장자는 파일 이름 맨 끝의 점 뒤 글자입니다(.txt, .py). 컴퓨터는 확장자를 보고 파일 종류를 짐작합니다. 확장자 자체는 이름의 일부일 뿐, 안의 내용을 바꾸지는 않습니다.

도구는 아무 텍스트 편집기나 됩니다. 여기서는 Windows에 기본으로 있는 메모장을 씁니다. 메모장을 열어 아래 두 줄을 그대로 적고, "다른 이름으로 저장"에서 위치를 python-study 폴더로, 파일 이름을 hello.py로 저장합니다.

코드 (hello.py)

print("안녕하세요")
print(2 + 3)

흔한 실수

hello.py.txt로 저장되는 경우. 메모장의 파일 형식이 "텍스트 문서(*.txt)"로 되어 있으면 설정에 따라 이름 뒤에 .txt가 덧붙을 수 있습니다. Windows는 기본으로 확장자를 숨겨서, 탐색기에는 hello.py로 보여도 실제 이름은 hello.py.txt일 수 있습니다. 파일 형식을 "모든 파일(*.*)"로 바꿔 저장하고, 탐색기의 "보기"에서 "파일 확장명"을 켜 두세요. 터미널의 ls는 확장자를 숨기지 않으므로 가장 확실한 확인 방법입니다.

메모장 말고 코드 편집기(예: VS Code)를 쓰면 줄 번호와 색이 붙어 읽기 편합니다. 편집기는 나중에 필요해지면 설치해도 충분합니다. 이 장의 내용은 메모장만으로 모두 따라 할 수 있습니다.

python 파일이름.py 로 실행하기

터미널의 현재 위치가 hello.py가 든 폴더인지 프롬프트로 확인한 뒤, 다음을 칩니다.

PowerShell 화면 (실제 결과)

PS C:\Users\me\Documents\python-study> python hello.py
안녕하세요
5
PS C:\Users\me\Documents\python-study>

명령의 뜻은 "python 프로그램을 실행하되, hello.py라는 파일에 적힌 코드를 실행하라"입니다. U05·1에서는 python 뒤에 옵션(--version)을 붙였고, 이번에는 파일 이름을 붙였습니다. py hello.py로 쳐도 같은 결과가 나옵니다.

세 가지를 눈여겨봅니다.

  • 위에서 아래로 한 줄씩 실행합니다. 그래서 "안녕하세요"가 5보다 먼저 나옵니다. 두 줄의 순서를 바꿔 저장하고 다시 실행하면 5가 먼저 나옵니다.
  • 마지막 줄까지 실행하면 Python이 저절로 끝나고 PowerShell 프롬프트로 돌아옵니다. 대화형 실행처럼 >>>가 남지 않습니다.
  • 파일은 남아 있으므로 같은 명령을 몇 번이고 다시 칠 수 있습니다. 위 화살표 키(↑)를 누르면 방금 친 명령이 다시 나옵니다.

대화형 실행과 파일 실행은 무엇이 다른가 이해하기

같은 코드를 두 방식으로 실행해 보면 차이가 분명해집니다. 아래 세 줄을 noprint.py로 저장해 실행하고, 똑같은 세 줄을 대화형 실행에도 쳐 봤습니다.

(나)에서도 Python은 2 + 3을 계산했고, x에 10을 넣었고, x의 값도 꺼냈습니다. 다만 파일 실행에는 U05·1에서 본 "값을 자동으로 보여 주는 단계"가 없어서 화면에 아무것도 나오지 않은 것입니다. 파일 실행에서 무엇인가를 보고 싶으면 반드시 print(…)로 감싸야 합니다.

대화형 실행 (>>>)파일 실행 (python 파일.py)
시작python만 친다python hello.py처럼 파일 이름을 붙인다
코드를 넣는 법한 줄씩 쳐서 Enter파일에 미리 적어 저장
값 보여 주기계산한 값을 자동으로 보여 준다print로 내보낸 것만 보인다
끝나면exit()를 칠 때까지 계속 기다린다마지막 줄 다음에 저절로 끝난다
코드가 남는가창을 닫으면 사라진다파일로 남아 몇 번이고 다시 실행
어디에 좋은가한두 줄 시험, 계산기처럼 쓰기여러 줄짜리 프로그램, 다시 쓸 코드

왜 그럴까?

파일 실행에서도 계산한 값을 전부 자동으로 보여 주면 편할 것 같은데, 왜 그렇게 하지 않을까요? 1,000줄짜리 프로그램을 떠올리며 생각해 보세요.

모범 답 보기

프로그램 안에는 중간 계산이 아주 많습니다. 그 값이 전부 화면에 쏟아지면 정작 보고 싶은 결과를 찾을 수 없습니다. 그래서 파일 실행에서는 프로그램을 쓴 사람이 보여 줄 것만 골라 print로 내보내도록 되어 있습니다. 대화형 실행은 한 줄씩 시험하는 자리라서, 그 한 줄의 값을 바로 보여 주는 편이 쓸모 있습니다.

파일을 찾을 수 없을 때

가장 흔한 첫 오류는 이것입니다. hello.py가 든 폴더의 한 칸 바깥(Documents)에서 실행해 본 실제 결과입니다(경로 앞부분만 줄임).

PowerShell 화면

PS C:\Users\me\Documents> python hello.py
C:\Users\...\Python314\python.exe: can't open file 'C:\\Users\\me\\Documents\\hello.py': [Errno 2] No such file or directory

한 부분씩 읽어 봅니다.

  • C:\Users\...\Python314\python.exe: — 이 말을 한 것은 Python 프로그램입니다. PATH 문제였다면 PowerShell이 "인식되지 않습니다"라고 했을 것입니다. 그러니 Python은 잘 실행되었습니다.
  • can't open file 'C:\\Users\\me\\Documents\\hello.py' — 이 경로의 파일을 열 수 없었다는 뜻입니다. 현재 위치(Documents) 뒤에 파일 이름을 붙인 경로입니다. 역슬래시가 두 번씩 찍힌 것은 Python이 경로를 보여 주는 방식일 뿐이니 하나로 읽으면 됩니다.
  • [Errno 2] No such file or directory — "그런 파일이나 폴더가 없다". Errno 2는 운영체제가 정한 오류 번호입니다.

원인은 대개 셋 중 하나이고, 확인하는 순서도 이대로 하면 됩니다.

  1. 현재 위치가 다르다 — 프롬프트를 보고, 맞는 폴더로 cd 한 뒤 다시 실행합니다.
  2. 파일 이름을 잘못 쳤다 — ls로 실제 이름을 보고 똑같이 칩니다(helo.py, Hello.py).
  3. 실제 이름이 hello.py.txt다 — ls에 그렇게 보이면 이름을 고칩니다.

폴더를 옮기기 싫으면 전체 경로를 써도 됩니다: python C:\Users\me\Documents\python-study\hello.py.

Python 안에서 python 파일.py 를 친 경우

U05·1에서 본 프롬프트 혼동이 파일 실행에서도 일어납니다. >>>가 떠 있는 상태에서 python hello.py를 치면 Python은 이것을 Python 코드로 읽으려다 실패합니다. 실제 결과의 마지막 세 줄입니다(그 위에 위치를 알려 주는 줄이 하나 더 있습니다).

대화형 실행 화면

>>> python hello.py
    python hello.py
           ^^^^^
SyntaxError: invalid syntax

SyntaxError는 "문법 오류", 곧 Python 글쓰기 규칙에 맞지 않는 줄이라는 뜻입니다. ^^^^^는 Python이 이상하다고 느낀 자리를 가리킵니다. 고치는 법: exit()로 나간 뒤 PowerShell 프롬프트에서 다시 칩니다. 오류 메시지를 읽는 법은 U05·3에서 자세히 다룹니다.

외우는 법

"누가 말했나"를 먼저 본다. PowerShell이 말하면 "인식되지 않습니다"(명령을 못 찾음, PATH·철자 문제). Python이 말하면 python.exe: can't open file(파일을 못 찾음, 위치·이름 문제) 또는 SyntaxError(Python에게 PowerShell 명령을 침).
