RA02·1

ε–δ 연속과 균등 연속을 증명하기

입력 오차를 얼마나 줄이면 원하는 출력 오차가 나올까요? 기준점마다 다른 범위를 써도 되는 연속과 영역 전체에 같은 범위가 필요한 균등 연속을 구분합니다.

이 장을 읽고 나면

  • 정의역에 상대적인 연속의 ε–δ 정의와 수열 판정을 증명한다.
  • x²의 한 점 연속 및 유계 구간의 균등 연속을 직접 보인다.
  • 영역 전체에서 δ 하나를 고르는 조건이 실패하는 반례를 구성한다.

출력 허용 폭을 먼저 정한다

값이 손잡이를 조금 움직였을 때 얼마나 바뀌는지 알고 싶다고 합시다. 입력 x가 기준 c에 가까우면 출력 f(x)도 f(c)에 가깝다는 것이 연속의 출발점입니다. 거리에는 절댓값을 쓰고, 출력의 허용 거리 ε를 먼저 정해 입력에서 쓸 거리 δ를 고릅니다.

정의 · 한 점에서의 연속

정의역 D⊆ℝ, c∈D에서 f:D→ℝ가 연속이라는 것은 ∀ε>0 ∃δ>0 ∀x∈D, |x−c|<δ ⇒ |f(x)−f(c)|<ε입니다.

x는 D 안에서만 움직입니다. [0,1]의 끝점 0에서는 오른쪽에서만 접근합니다. D 안에서 c가 주변의 유일한 점이면 충분히 작은 δ에서 x=c만 확인하므로 자동으로 연속입니다. 이 정의는 실제 함수값 f(c)를 사용하므로 주변의 극한이 존재해도 그 값이 f(c)와 다르면 불연속입니다.

예로 g(x)=0 (x≠0), g(0)=1이면 0에서 불연속입니다. ε=1/2를 고정하세요. 어떤 δ>0에서도 x=δ/2는 0과 δ보다 가깝지만 |g(x)-g(0)|=1입니다.

부등식을 거꾸로 풀어 δ를 만든다

f(x)=x²가 c=2에서 연속임을 보이겠습니다. 목표는 |x²-4|=|x-2||x+2|<ε입니다. 둘째 인수가 무한히 커질 수 있으므로 우선 |x-2|<1을 요구합니다. 그러면 1<x<3이고 |x+2|<5입니다. 남은 |x-2|를 ε/5 아래로 묶으면 됩니다. 두 요구를 동시에 만족하는 δ=min(1,ε/5)를 고르면

|x²−4| < 5δ ≤ ε

입니다. x=2에서는 차가 0이어서 바로 만족합니다. 이 δ는 가능한 선택 중 하나입니다. ε=.5이면 δ=.1이고, x가 1.9와 2.1 사이일 때 출력은 4에서 .5 미만으로 떨어져 있습니다.

다른 기준점 c에서도 |x-c|<1이면 |x+c|≤|x-c|+2|c|<1+2|c|입니다. δ=min(1,ε/(1+2|c|))가 그 점에는 통합니다. 기준점이 움직일 때 이 식에서 고른 δ도 달라집니다.

수열로 검사하는 정의는 같은 결론을 준다

f가 c에서 연속이라면 D 안의 임의 수열 xₙ→c에 대해 f(xₙ)→f(c)입니다. 출력 ε에 대해 연속 정의의 δ를 고릅니다. xₙ→c이므로 어느 N부터 |xₙ-c|<δ입니다. 그 이후 출력은 ε보다 가까워져 수렴합니다.

반대로 연속이 아니면 어떤 ε₀>0에서 δ>0를 어떻게 정해도 |x-c|<δ이면서 |f(x)-f(c)|≥ε₀인 x∈D를 찾을 수 있습니다. δ=1/n으로 각각 정해 그 점을 xₙ이라 부르면 xₙ→c입니다. 하지만 출력은 항상 ε₀ 이상 멀어 f(c)로 수렴하지 않습니다. 따라서 모든 입력 수열이 출력을 보존한다는 조건과 연속은 동치입니다.

이 방법은 불연속을 보이는 데 편리합니다. 예로 g(0)=1, 나머지 점에서 g=0인 위의 함수에서는 xₙ=1/n→0인데 g(xₙ)=0이므로 1로 가지 않습니다.

모든 위치에 δ 하나를 고른다

균등 연속은 다음 순서를 요구합니다.

∀ε>0 ∃δ>0 ∀x,y∈D, |x−y|<δ ⇒ |f(x)−f(y)|<ε.

여기서는 한 δ를 정한 뒤에 두 위치를 고릅니다. [-3,3]에서 f(x)=x²라면 |x+y|≤6이고 |x²-y²|≤6|x-y|입니다. 그러므로 전체 구간에서 δ=ε/6 하나면 됩니다.

반례. 실수 전체에서 xₙ=n, yₙ=n+1/n을 택하면 |xₙ-yₙ|=1/n→0입니다. 그러나 제곱의 차는 yₙ²-xₙ²=2+1/n²입니다. ε=1에 대해 어떤 δ를 내더라도, n>1/δ를 고르면 입력 거리는 δ 안이고 출력 거리는 1 이상입니다. 모든 점에서 연속인 같은 함수라도 실수 전체에서는 균등 연속에 실패합니다.

유계가 아닌 정의역에서도 균등 연속인 예가 있습니다. f(x)=√x에서 x≥y≥0이면 (√x-√y)²=x+y-2√xy≤x-y입니다. √xy≥y이기 때문입니다. 따라서 양쪽 순서를 모두 포함해 |√x-√y|≤√|x-y|입니다. δ=ε²가 [0,∞) 전체에 통합니다.

손계산을 Python으로 검산한다

from fractions import Fraction as F

epsilon = F(1, 2)
delta = min(F(1), epsilon/5)
for x in [F(19, 10), F(2), F(21, 10)]:
    print(x, x*x, "output error:", abs(x*x-4))
print("worked delta:", delta)

for n in [2, 4, 10]:
    x = F(n)
    y = x + F(1, n)
    print(n, "input gap:", y-x, "output gap:", y*y-x*x)
19/10 361/100 output error: 39/100
2 4 output error: 0
21/10 441/100 output error: 41/100
worked delta: 1/10
2 input gap: 1/2 output gap: 9/4
4 input gap: 1/4 output gap: 33/16
10 input gap: 1/10 output gap: 201/100

Python 3.14.6으로 계산했습니다. 첫 출력은 설명한 입력 구간의 양 끝과 가운데를 비교합니다. 정의는 열린 허용 범위를 쓰며 모든 내부 점에 대한 증명은 본문의 부등식입니다.
