점별·균등수렴과 연속·적분의 극한 교환

각 점에서 함수값이 작아져도 그래프 전체의 면적은 작아지지 않을 수 있습니다. 어느 수렴 조건에서 연속과 적분을 보존하는지 증명하고, 폭이 좁아지는 삼각형으로 반례를 계산합니다.

이 장을 읽고 나면

  • 함수열의 점별수렴과 균등수렴을 정확한 양화사로 쓴다.
  • 균등 극한이 연속성과 리만 적분의 교환을 보존함을 증명한다.
  • 점별수렴만 만족하는 좁은 봉우리에서 교환 실패를 직접 계산한다.

점마다 차례로 좁히는가, 영역 전체를 좁히는가

공통 정의역 D의 함수 f₁,f₂,…를 놓으면, x 하나를 고정할 때 실수 수열 (fₙ(x))를 얻습니다. 모든 x∈D에서 이 수열이 f(x)로 수렴하면 점별수렴입니다. 정확히는 ∀x∈D ∀ε>0 ∃N ∀n≥N, |fₙ(x)-f(x)|<ε입니다. 가까워질 때까지 기다리는 번호 N은 x에 따라 다를 수 있습니다.

균등수렴에서는 ∀ε>0 ∃N ∀n≥N ∀x∈D, |fₙ(x)-f(x)|<ε입니다. 같은 ε에서 N을 하나 정하고 나면, 각 n≥N마다 정의역 전체에서 오차가 작아야 합니다.

최대 오차의 상한 Mₙ=supx∈D|fₙ(x)-f(x)|이 0으로 수렴하면 균등수렴이고, 균등이면 이 상한도 0으로 갑니다. 뒤의 방향에서는 ε/2로 균등수렴을 써서 Mₙ≤ε/2<ε로 잡습니다. 모든 개별 오차가 ε보다 작다는 사실에서 상한 자체의 엄격한 부등식을 바로 단정하지 않습니다.

예. gₙ(x)=x²+x/(n+x), x∈[0,1]에서 0≤gₙ(x)-x²≤1/n입니다. 모든 x에 공통으로 n>1/ε를 선택하면 균등수렴합니다. x=1에서는 오차가 1/(n+1)이고, 이 오차항은 x에 대해 증가하므로 이것이 정확한 최대 오차입니다.

연속을 보존하려면 함수 하나를 고정한다

fₙ이 모두 D에서 연속이고 fₙ→f가 균등이라고 합시다. c∈D에서 f의 연속을 증명하기 위해 ε를 세 조각으로 나눕니다. 균등수렴으로 |f(x)-fN(x)|<ε/3이 모든 x에 성립하는 N을 먼저 고릅니다. 이미 선택된 fN 한 함수가 c에서 연속이므로 δ 하나를 골라 |fN(x)-fN(c)|<ε/3으로 만듭니다. 그러면

|f(x)-f(c)|≤|f(x)-fN(x)|+|fN(x)-fN(c)|+|fN(c)-f(c)|<ε.

점별수렴만 있다면 x와 c에 각각 다른 번호가 필요할 수 있어, 먼저 fN을 하나 고정하는 이 논증이 통하지 않습니다. 예로 fₙ(x)=xⁿ은 [0,1]에서 모두 연속인데 점별 극한은 x<1에서 0, x=1에서 1이라 1에서 불연속입니다. 실제로 xₙ=2−1/n<1을 대입하면 fₙ(xₙ)=1/2, f(xₙ)=0이라 전역 오차가 작아지지 않습니다.

리만 적분의 존재와 값의 수렴을 나누어 증명한다

a<b인 닫힌 구간 [a,b]에서 각각 리만 적분 가능한 fₙ이 균등하게 f로 간다고 합시다. 충분히 뒤의 적분 가능한 한 함수에서 전체 오차를 1 이하로 묶을 수 있으므로 f는 유계입니다. 임의의 δ>0에서 |f-fN|≤δ인 N을 정하면 칸마다 f의 상한은 fN의 상한보다 최대 δ만큼 더 크고, 하한은 최대 δ만큼 더 작습니다.

U(P,f)-L(P,f)≤U(P,fN)-L(P,fN)+2δ(b-a).

원하는 ε에서 δ=ε/[4(b-a)]를 고르고, 적분 가능한 fN에 대해 상합−하합이 ε/2보다 작은 분할을 고르면 f의 간격도 ε 미만입니다. 따라서 f도 리만 적분 가능합니다. 같은 비교를 하합끼리 하면 모든 분할에서 |L(P,f)-L(P,fN)|≤δ(b-a)입니다. 양쪽의 상한을 취하면 |∫ f-∫ fN|≤δ(b-a)입니다. N 이후의 모든 함수에 같은 δ를 쓰므로

limn→∞∫ab fₙ = ∫ab f.

균등수렴하지 않아도 우연히 적분 극한은 맞을 수 있습니다. 바로 위의 xⁿ은 ∫01xⁿ=1/(n+1)→0이고, 점별 극한도 1에서만 1이어서 한 점에서만 값이 있는 적분과 같이 0입니다. 오른쪽 끝을 포함하는 마지막 칸의 폭을 임의로 줄이면 상합도 줄어듭니다. 균등수렴은 충분조건이며 모든 적분 교환 사례에 꼭 필요한 것은 아닙니다.

폭이 줄어드는 봉우리는 면적을 유지한다

n≥2, x∈[0,1]에서 fₙ(x)=n max(0,1-n|x-1/n|)라 둡니다. 그래프는 0에서 2/n까지 밑변, (1/n,n)이 꼭짓점인 삼각형이고 밖에서는 0입니다. fₙ은 연속입니다.

x=0에서 fₙ(0)=0입니다. 어떤 x>0을 고정해도 n>2/x이면 2/n<x라 fₙ(x)=0입니다. 그러므로 점별 극한은 영함수입니다. 하지만 봉우리 높이가 n이라 최대 오차는 n이며, 모든 n에서 ∫01fₙ=(1/2)(2/n)n=1입니다. lim ∫fₙ=1이고 ∫lim fₙ=0입니다. 적분의 값은 고정된 한 점에서의 비교가 아니라 전체의 면적을 읽기 때문에 점별수렴만으로는 충분하지 않습니다.

다음 단원에서는 한 점이나 가산 개수의 점을 길이 0으로 다루고, 균등수렴 대신 어떤 지배 조건에서 적분의 극한을 바꿀 수 있는지 다룹니다.

손계산을 Python으로 검산한다

from fractions import Fraction as F

def spike(n, x):
    return n * max(F(0), 1 - n*abs(x - F(1, n)))

for n in [2, 4, 8, 16]:
    width = F(2, n)
    peak = spike(n, F(1, n))
    print(n, "width:", width, "peak:", peak,
          "area:", width*peak/2, "value at 1/8:", spike(n, F(1, 8)))

for n in [5, 20]:
    print(n, "uniform maximum gap:", F(1, n+1))
2 width: 1 peak: 2 area: 1 value at 1/8: 1/2
4 width: 1/2 peak: 4 area: 1 value at 1/8: 2
8 width: 1/4 peak: 8 area: 1 value at 1/8: 8
16 width: 1/8 peak: 16 area: 1 value at 1/8: 0
5 uniform maximum gap: 1/6
20 uniform maximum gap: 1/21

Python 3.14.6으로 실행했습니다. 고정한 x=1/8에서 함수값이 중간에 올라가도, 충분히 큰 n에서는 0이 됩니다. 반면 각 n의 꼭짓점으로 입력을 함께 옮기면 높이가 커집니다.
