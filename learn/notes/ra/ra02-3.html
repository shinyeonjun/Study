최대·최소에서 Rolle과 평균값 정리 유도하기

두 시점의 평균 변화율과 순간 변화율을 비교합니다. 닫힌 구간의 최대·최소 정리로 평균값 정리를 증명하고, 가정이 하나씩 빠질 때 왜 결론이 깨지는지 계산합니다.

이 장을 읽고 나면

  • 안쪽 극값에서 도함수가 0이 되는 이유를 차분 몫으로 증명한다.
  • Rolle 정리와 평균값 정리를 이전 정리에서 순서대로 유도한다.
  • 가정이 하나씩 빠질 때 반례를 계산하고 도함수로 함수 변화의 상계를 구한다.

극값을 얻는 점에서 양쪽 기울기를 비교한다

점 c가 열린 구간 안에 있고, 그 주변의 점들에 대해 f(x)≤f(c)이면 국소 최댓점입니다. 충분히 작은 h>0에서 [f(c+h)-f(c)]/h≤0입니다. h<0이면 분모의 부호가 반대라 같은 차분 몫이 ≥0입니다. f′(c)가 존재하면 두 방향의 극한이 같아야 하므로 둘 다 가능한 수는 0뿐입니다. 국소 최솟점에는 부등호를 반대로 읽으면 같습니다. 이를 Fermat의 정지점 조건이라고 합니다.

이 논증은 양쪽에서 접근하는 내부점과 미분 가능성을 사용합니다. 예로 f(x)=x의 [0,1] 위 최대는 끝점 1이지만 안쪽의 도함수는 항상 1입니다. 또 f(x)=|x|는 0에서 최소이나 좌미분과 우미분이 달라 f′(0)이 존재하지 않습니다. 반대로 도함수가 0이라도 f(x)=x³의 0처럼 값이 양쪽으로 계속 증가해 극값이 아닐 수 있습니다.

두 끝의 높이가 같으면 안쪽에 수평 접선이 있다

Rolle 정리. a<b이고 f가 [a,b]에서 연속, (a,b)에서 미분 가능하며 f(a)=f(b)이면, 어떤 c∈(a,b)에서 f′(c)=0입니다.

앞 장의 최대·최소 정리로 f는 닫힌 구간에서 양쪽 극값을 얻습니다. 상수함수이면 모든 내부점의 도함수가 0입니다. 상수가 아니면 끝값과 다른 값을 갖는 점이 있어, 최댓값이 공통 끝값보다 높거나 최솟값이 그보다 낮습니다. 해당 극값은 끝점에서 얻을 수 없으므로 안쪽에서 달성됩니다. 그 점에 Fermat 조건을 쓰면 도함수 0입니다. 적어도 한 극값이 내부에 있다는 사실을 끝값의 같음에서 얻었습니다.

끝 높이가 다르면 먼저 두 끝을 잇는 직선을 뺀다

평균값 정리

f가 [a,b]에서 연속이고 (a,b)에서 미분 가능하며 a<b이면, 어떤 내부점 c에서 f′(c)=[f(b)-f(a)]/(b-a)입니다.

두 끝점의 기울기를 m=[f(b)-f(a)]/(b-a)라 놓고, 두 끝을 잇는 직선 ℓ(x)=f(a)+m(x-a)를 뺍니다. g=f-ℓ는 같은 연속성과 미분 가능성을 가지며 g(a)=g(b)=0입니다. Rolle 정리로 g′(c)=0이고 g′=f′-m이므로 결론을 얻습니다. 연속인 도함수까지 요구하는 정리는 아닙니다. 필요한 것은 열려 있는 내부에서 실제 미분이 존재한다는 점입니다.

손계산. f(x)=x², [a,b]=[1,3]에서 두 끝의 기울기는 (9-1)/(3-1)=4입니다. 1과 3을 잇는 직선은 ℓ(x)=4x-3이고, g=x²-4x+3은 x=2에서 최소 −1입니다. 이 점에서 f′(2)=4이며 접선은 y=4x-4입니다.

가정을 빼서 생긴 실패, 가정을 만족해서 얻는 부등식

끝에서 연속하지 않으면 f(x)=x (0≤x<1), f(1)=2를 보세요. 이 함수의 [0,1] 할선 기울기는 2, 내부 도함수는 1뿐입니다. 안쪽에서 미분하지 못하면 f(x)=|x|, [-1,1]을 보세요. 할선은 평평하지만, 미분이 가능한 내부점의 도함수는 −1 또는 1이고 0에서는 도함수가 없습니다.

도함수로 차이를 묶는다. 같은 연속성과 미분 가능성을 갖는 구간에서 |f′(t)|≤M이라면, 구간 안의 서로 다른 x,y에 평균값 정리를 써서 |f(x)-f(y)|≤M|x-y|를 얻습니다. 예로 f(x)=√(1+x)는 x≥0에서 도함수 1/[2√(1+x)]≤1/2이므로 두 입력 사이의 변화는 거리의 절반 이하입니다. 정의역의 넓이에 상관없이 이 상계가 통하므로 균등 연속입니다.

도함수가 내부에서 항상 0이면 위 부등식의 M=0을 써 모든 두 점의 함수값이 같습니다. 도함수가 양수면 x<y에서 f(y)-f(x)=f′(c)(y-x)>0이라 증가합니다. 두 점을 잇는 구간이 정의역에 들어 있어야 평균값 정리를 쓸 수 있습니다. 예로 (-2,-1)∪(1,2)에서 두 구간에 서로 다른 상수를 준 함수는 두 조각 모두 도함수 0이어도 전체에서 일정하지 않습니다.

손계산을 Python으로 검산한다

from fractions import Fraction as F

def f(x):
    return x*x

a, b = F(1), F(3)
slope = (f(b) - f(a))/(b-a)
c = slope/2
print("secant:", slope, "c:", c, "derivative at c:", 2*c)
for x in [a, c, b]:
    line = f(a) + slope*(x-a)
    print("x:", x, "difference:", f(x)-line)

print("endpoint-failure slope:", (F(2)-F(0))/(1-0), "inside:", 1)
print("corner-failure slope:", (abs(F(1))-abs(F(-1)))/2, "derivatives:", [-1, 1])
secant: 4 c: 2 derivative at c: 4
x: 1 difference: 0
x: 2 difference: -1
x: 3 difference: 0
endpoint-failure slope: 2 inside: 1
corner-failure slope: 0 derivatives: [-1, 1]

Python 3.14.6으로 실행했습니다. g=f-ℓ의 값과 가정별 반례의 할선 기울기는 분수로 정확히 계산합니다.
