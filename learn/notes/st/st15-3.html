통계 · ST15 인과효과의 추정과 민감도

ST15·3

미측정 교란을 남겨 두고 표준화와 민감도를 검증하기

관측된 준비도 비중을 두 집단에서 같게 만들어도, 적지 않은 요인이 남아 있을 수 있습니다. 생성 규칙의 참 효과를 알고 숨은 변수를 일부러 제외해, 표준화와 역확률 가중의 가정을 따로 검증합니다.

이 장을 읽고 나면

  • 측정한 변수의 균형과 미측정 교란의 부재를 구별한다.
  • 가산 효과 모형에서 관측 차이가 γδ만큼 움직이는 이유를 유도한다.
  • 민감도 결과와 실제 모의 참가자 효과를 따로 보고한다.

눈에 보이는 준비도와 보이지 않는 경험을 나눈다

장비 시험에서 새 도구 A, 준비도 L, 성공 Y의 의미는 앞과 같습니다. 이번 합성 모집단에는 평소 점검 경험 U가 있습니다. L,U∈{0,1}이고 모든 조합의 비중이 1/4입니다. 경험이 많으면 도구를 더 쓰고, 도구와 무관하게 성공률도 높습니다. 생성자만 U를 알고, 첫 분석자는 L만 관측한다고 둡니다.

잠재 성공률은 P(Y(a)=1|L,U)=.10+.20L+.30U+.20a입니다. 각 L,U에서 사용자 선택은 잠재 결과를 정하는 난수와 독립입니다. 네 층에서의 도구 사용확률은 아래와 같습니다. 모든 층에서 양성이 성립하고 도구의 참 성공확률차는 항상 .20입니다.

적은 가정만으로는 같은 층이 여전히 다르다

L=0에서 A=1의 U=1 비중은 (3/8)/(1/8+3/8)=3/4입니다. A=0의 U=1 비중은 (5/8)/(7/8+5/8)=5/12입니다. 차이가 1/3입니다. L=1에서도 해당 비중 7/12와 1/4의 차이가 1/3입니다. 관측 표에서 L만 같게 두어도 U의 구성이 다릅니다.

이 예의 잠재 성공률을 α_l+τa+γU로 씁니다. 주어진 L=l에서 사용군과 미사용군의 U 비중 차를 δ_l로 두면 관심 결과의 관측 차이는

E[Y|A=1,L=l]−E[Y|A=0,L=l] = τ+γδl.

일치성과 L,U를 준 교환가능성을 사용해 각 군 안에서 잠재식을 평균한 결과입니다. α_l는 차에서 없어지고, U에 붙은 γ는 두 군에서 평균한 U의 차에 곱해집니다. 이 예는 τ=.20,γ=.30,δ_l=1/3이라 각 L에서 관측 차이는 .30입니다. L만 사용하는 표준화와 IPW는 이 차이에 같은 목표 비중을 적용하므로 둘 다 .30을 냅니다. 두 방법이 서로 같다는 사실만으로 인과 식별을 확인할 수는 없습니다.

얼마나 강한 숨은 차이가 결론을 바꾸는가

실측에는 U와 생성 참값이 없다고 생각해 봅시다. 숨은 변수 효과의 크기 γ와 두 군 사이 비중 차 δ에 타당한 범위를 넣어, .30−γδ를 계산합니다. 단순화를 위해 두 L 층에서 같은 δ를 둔 경우입니다. 이 민감도 분석은 여러 가상의 편향 아래 추정값이 어디로 가는지 기록합니다. γ와 δ를 이 자료가 정해 준다는 뜻은 아닙니다.

마지막 조합은 효과가 0이 되는 조건의 예입니다. 실제 U의 효과나 구성 비중을 발견한 결과가 아닙니다. 큰 γ는 다른 확률들과 함께 놓았을 때 0≤α_l+τa+γU≤1인지도 확인합니다. 같은 γ가 모든 층과 처리에서 유지되지 않거나, U와 결과의 관련성이 다르면 편향의 항을 층별로 다시 정해야 합니다. 보고서에는 목표 효과, 조정에 사용한 자료, 미측정 요인에 대한 시나리오, 겹침과 불확실성을 따로 적습니다.

이어 풀기와 증명

미측정 변수를 포함했을 때만 보이는 참값과, 실측에서 실제로 계산 가능한 값을 나눠 적습니다. 같은 가정이 언제 깨지는지도 질문합니다.

파이썬으로 같은 계산 검산하기

from fractions import Fraction as F
from itertools import product

rows = []
for l,u,h,r in product((0,1), (0,1), range(10), range(8)):
    a = int(r < 1+4*l+2*u)
    y0 = int(h < 1+2*l+3*u)
    y1 = int(h < 3+2*l+3*u)
    rows.append((l,u,a,(y0,y1)[a],y0,y1))

def average(values):
    return F(sum(values), len(values))

crude = average([y for _,_,a,y,_,_ in rows if a]) - average([y for _,_,a,y,_,_ in rows if not a])
standard = [sum(average([y for x,_,b,y,_,_ in rows if x==l and b==a])
                for l in (0,1))/2 for a in (0,1)]
weights = {(l,a): F(4, ((1,3)[l] if a else (3,1)[l])) for l,a in product((0,1), repeat=2)}
ipw = [sum(weights[l,a]*y for l,_,b,y,_,_ in rows if a==b)/len(rows)
       for a in (0,1)]
full = [sum(average([y for x,v,b,y,_,_ in rows if (x,v,b)==(l,u,a)])
            for l,u in product((0,1), repeat=2))/4 for a in (0,1)]
truth = average([y1-y0 for _,_,_,_,y0,y1 in rows])
assert standard == ipw
assert full[1]-full[0] == truth
print("rows and crude:", len(rows), crude)
print("L-adjusted standard/IPW:", standard[1]-standard[0], ipw[1]-ipw[0])
print("L,U-adjusted and truth:", full[1]-full[0], truth)
print("bias under known gamma and delta:", F(3,10)*F(1,3))

실행 결과

rows and crude: 320 3/8
L-adjusted standard/IPW: 3/10 3/10
L,U-adjusted and truth: 1/5 1/5
bias under known gamma and delta: 1/10

조건부 교환가능성이 주어지는 L,U를 함께 쓰면 표준화가 다시 참값을 냅니다. 실제 관측 연구에서는 모든 변수를 편의대로 추가하기보다, 어떤 변수에 조건을 걸어야 하는지를 시간 순서와 인과 가정으로 정해야 합니다.
