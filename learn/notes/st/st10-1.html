ST10·1

시간의 순서, 자기상관과 과거만 쓴 검증

시간을 따라 반복되는 모양을 읽고, 떨어진 값의 상관을 작은 표에서 계산합니다. 운영에서 알 수 있었던 자료만으로 예측을 검증합니다.

이 장을 읽고 나면

  • 시간에 따른 추세와 반복 주기, 약한 정상성의 뜻을 구분한다.
  • 시간 간격이 같은 작은 자료에서 시차별 표본 자기상관을 계산한다.
  • 미래 값을 가리지 않은 적합과 과거만으로 검증하는 예측을 구분한다.

시간 표시를 붙이면 값 외에 순서가 보인다

하루 주문 수가 1일부터 8일까지 10,16,14,20,18,24,22,28입니다. 시간에 맞춰 그리면, 짝수 날에서 홀수 날보다 값이 높게 반복되면서 전체 수준도 올라갑니다. 오래 지속되는 수준의 변화를 추세, 달력이나 일정한 주기와 함께 반복되는 움직임을 계절성이라고 합니다. 여기서는 설명을 위해 2일 주기를 만들어 놓았습니다.

평균과 분산이 시각에 따라 같고, 두 시각 사이의 공분산이 시각 자체가 아니라 간격에만 의존한다면 약한 정상성을 갖습니다. 정상성은 서로 다른 시각의 값이 독립이라는 뜻은 아닙니다. 추세나 반복되는 평균 차가 있다면 원자료를 그대로 두고 정상성을 가정하기 어렵습니다. 한두 그래프가 고르게 보인다는 이유만으로 정상성을 확정할 수도 없습니다.

같은 주기의 값을 빼는 계절 차분은 반복 모양의 영향을 줄일 수 있습니다. 위 자료에서 2일 전을 빼면 5일의 값은 18−14=4이고, 6일의 값은 24−20=4입니다. 3일부터 8일까지 모두 4가 되어 추세와 2일 주기가 함께 사라집니다. 바로 전날을 빼는 1차 차분 yₜ−yₜ₋₁은 직선 추세를 없애는 데 쓰지만, 이 자료에서는 6, −2, 6, −2, 6, −2, 6으로 2일 주기가 그대로 남습니다. 차분은 예측 시점에서 이전에 관측한 값만 사용합니다.

시차를 고정하고 떨어진 값끼리 비교한다

매일 한 번씩 잰 자료에서 시차 1은 바로 전날, 시차 2는 이틀 전과 짝짓는 것입니다. 시각이 일정한 간격으로 있는지 먼저 확인합니다. 하루 기록이 비어 있다면 다음 줄이라고 해서 하루 뒤로 세면 안 됩니다.

자기상관은 같은 변수의 시간적으로 떨어진 값들이 같이 움직이는 정도입니다. 이 장에서는 전체 평균을 빼 얻은 값 d를 놓고, 시차 k에 대해 떨어진 항의 곱 Σdₜdₜ₋ₖ를 전체 제곱합 Σdₜ²로 나누는 표본 자기상관을 씁니다. 시차가 바뀌면 곱하는 쌍 수는 바뀝니다. 전체 제곱합은 그대로입니다.

작은 자료 [2,2,4,4]의 평균은 3이고 d는 [−1,−1,1,1]입니다. 시차 1의 분자는 1−1+1=1, 시차 2는 −1−1=−2입니다. 분모는 4이므로 각각 0.25와 −0.5입니다. 이것은 두 조각의 평균을 따로 구하는 피어슨 상관과 계산이 다릅니다. 모든 값이 같아 분모가 0이면 이 식을 사용할 수 없습니다. 추세나 계절성도 자기상관을 크게 만들 수 있으므로 그 값 하나로 원인을 단정하지 않습니다.

예측 기준 시각을 앞으로 옮겨 검증한다

4일까지 본 상태에서 5일을 예측하고, 5일 주문이 실제로 확인된 뒤에는 6일을 예측합니다. 이 이동 원점 검증에서 평가할 값은 각 적합의 뒤에 있습니다. 자료를 바꾸는 평균·척도도 해당 학습 구간에서 정하고, 나중에 확정된 값을 이전 시점의 입력으로 붙이지 않습니다.

5일의 직전값 기준은 4일의 20이고, 같은 주기의 값은 3일의 14입니다. 실제 5일은 18이므로 절대오차는 2와 4입니다. 5~7일의 검증에서 직전값 기준은 평균 10/3, 같은 주기는 4입니다. 이 결과로 직전값 기준을 고른 뒤, 남겨 둔 8일에는 직전 7일의 값인 22를 예측으로 사용합니다. 8일의 실제값 28과의 절대오차는 6입니다.

하루씩 새 관측을 받아 다시 예측하는 경우와, 기준 시각 한 번에서 앞으로 여러 날을 한꺼번에 예측하는 경우는 정보가 다릅니다. 며칠 뒤의 순서까지 중요하다면 운영에서 필요한 예측 거리와 같도록 검증합니다. 라벨 확인이 늦어지는 문제에서는 예측 시점에 이미 확인된 학습 라벨만 쓸 수 있습니다.

시차 계산과 이동 원점 예측을 실행한다

from statistics import mean

def acf(values, lag):
    center = mean(values)
    deviations = [x - center for x in values]
    numerator = sum(a * b for a, b in zip(deviations[lag:], deviations[:-lag]))
    denominator = sum(d * d for d in deviations)
    return numerator / denominator

small = [2, 2, 4, 4]
print(f"acf: lag 1={acf(small, 1):.2f}, lag 2={acf(small, 2):.2f}")

orders = [10, 16, 14, 20, 18, 24, 22, 28]
last_errors = []
season_errors = []
for end in (4, 5, 6):
    past = orders[:end]
    actual = orders[end]
    last_errors.append(abs(actual - past[-1]))
    season_errors.append(abs(actual - past[-2]))
    print(f"day {end + 1}: latest {past[-1]}, seasonal {past[-2]}, actual {actual}")
print(f"validation MAE: latest {mean(last_errors):.4f}, seasonal {mean(season_errors):.4f}")
print("test day 8 error:", abs(orders[7] - orders[6]))
acf: lag 1=0.25, lag 2=-0.50
day 5: latest 20, seasonal 14, actual 18
day 6: latest 18, seasonal 20, actual 24
day 7: latest 24, seasonal 18, actual 22
validation MAE: latest 3.3333, seasonal 4.0000
test day 8 error: 6

위의 자기상관 함수는 양의 시차가 자료 길이보다 짧고 분모가 양수인 경우에 사용합니다. 예측 오차는 그날의 실제값이 확인된 뒤 기록합니다. 시간순 자료를 다시 뽑는 방법은 다음 장에서 다룹니다.

한 줄 정리

시간 자료는 추세·계절성·자기상관 때문에 관측이 독립이 아니므로, 시차를 실제 시간 간격으로 맞춰 계산하고 검증은 예측 시점에 알 수 있던 과거만 써서 기준 시각을 앞으로 옮기며 합니다.
