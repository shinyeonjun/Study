ST15·2

역확률 가중으로 비교 집단을 만들고 겹침을 점검하기

희귀한 배정이 한 건 관측됐을 때 많은 장비를 대신하도록 가중할 수 있습니다. 가중 평균을 표준화와 대조하고, 큰 가중치를 제한할 때 어떤 대가가 생기는지 계산합니다.

이 장을 읽고 나면

  • 역확률 가중의 식별 항등식과 가중 균형을 유도한다.
  • 가중치와 유효 표본 수를 유한 모집단에서 계산한다.
  • 겹침 부족, 가중치 상한, 목표 집단 제한의 차이를 설명한다.

드문 배정의 기록이 같은 층의 더 많은 단위를 대표한다

장비의 준비도 L와 도구 사용 A=1,0을 관측합니다. 목표는 준비도가 낮은 장비와 높은 장비가 절반씩인 전체의 평균 처리 효과입니다. 준비도가 낮으면 네 대 중 한 대가 도구를 쓰고, 높으면 네 대 중 세 대가 씁니다. 실제 값을 관측한 한 대가 얼마나 많은 장비를 대표하는지 계산합니다.

성향점수 e(l)=P(A=1|L=l)를 사용합니다. 도구 사용자의 가중치는 1/e(l), 미사용자는 1/(1−e(l))입니다. e가 .25인 층의 사용자는 4대의 대표가 됩니다. e가 .75인 층의 사용자는 4/3의 비중을 갖습니다. 가중치의 합으로 늘어난 것은 계산의 비중입니다. 독립적으로 관측한 장비의 수는 동일합니다.

가중 결과의 기대값이 무엇인지 계산한다

ea(L)=P(A=a|L)라고 씁니다. 관측 Y 앞에 1{A=a}를 곱하면 도구 a를 가진 행만 남습니다. 층 L에서 E[1{A=a}Y|L]=ea(L)E[Y|A=a,L]입니다. 양성이 성립해 e가 양수이면 이 안에서 나눌 수 있습니다.

E[1{A=a}Y/ea(L)] = E[E[Y|A=a,L]] = E[Y(a)].

마지막 등식에는 앞 장의 일치성과 조건부 교환가능성도 들어갑니다. 같은 계산에서 Y 대신 1{L=l}를 넣으면 도구 a의 가중된 층별 질량이 P(L=l)가 되어, 목표의 준비도 분포와 맞습니다. 이 균형 등식은 참 성향점수 e를 쓴 모집단의 기대값에 대한 결과입니다. 유한한 표본에서는 표본 변동이나 성향점수 모형의 부적합으로 불균형이 남을 수 있으므로 가중한 뒤 실제 층 비중을 확인합니다.

표본 N개 전체를 분모로 쓰는 평균 Σ 1{A=a}wY/N은 Horvitz–Thompson 형태입니다. 각 도구에서 가중치 합을 분모로 쓰는 Σ 1{A=a}wY/Σ 1{A=a}w은 정규화한 Hájek 형태입니다. 두 식은 유한 표본에서 분모가 달라질 수 있습니다. 준비도와 도구의 배정을 정확히 균형 있게 만든 이 80대의 합성 표에서는 두 도구의 가중치 합이 모두 N=80이라 두 방법이 같습니다.

상한을 두면 분산의 신호와 목표 비중이 함께 달라진다

참 확률에서 0 또는 1에 가까운 e가 있으면 한 도구의 표본이 거의 없을 수 있습니다. 이것이 겹침 부족입니다. 정확히 0 또는 1이면 양성이 깨지고 그 층의 비교를 같은 목표로 바로 추정할 수 없습니다. 양쪽 행이 있어도 가중치가 크면 평균이 소수 행에 매우 민감합니다. 비음수 가중치의 집중을 살피는 계산으로 ESS=(Σw)²/Σw²를 도구별로 볼 수 있습니다. 이는 가중 집중을 요약한 수이며, 훈련 반복이나 유한표본 추론의 모든 불확실성을 나타내는 통계량은 아닙니다.

같은 자료에서 도구 사용자의 가중치는 10개가 4, 30개가 4/3입니다. 가중 합이 80이라 ESS는 80²/[10·16+30·(16/9)]=30입니다. w≤2라는 임의의 상한으로 큰 값을 잘라 내고 각 처리군 내부에서 다시 정규화하면, 가중 집중은 작아지지만 층 비중이 더는 목표와 같지 않습니다.

상한을 건 사용군 성공률은 (.30·20+.90·40)/60=.70, 미사용군 성공률은 (.20·40+.60·20)/60=1/3입니다. 차이는 11/30입니다. 가중치 상한 기록에는 상한 적용 전후의 겹침·균형·효과를 함께 적습니다. 양쪽 도구를 비교할 수 있는 L 범위로 대상을 제한하는 접근은 그 제한된 목표 집단의 효과를 정의합니다. 가중치만 제한한 결과를 자동으로 그 집단의 효과라고 볼 수는 없습니다.

이어 풀기와 증명

가중하기 전의 관측 수와 가중치 합, ESS를 따로 적습니다. 어느 층을 비교하는지와 각 군의 가중 층 비중이 같은지도 확인합니다.

파이썬으로 같은 계산 검산하기

from fractions import Fraction as F
from itertools import product

rows = []
for l,u,r in product((0,1), range(10), range(4)):
    e = F((1,3)[l],4)
    a = int(r < (1,3)[l])
    y = int(u < ((2,3),(6,9))[l][a])
    rows.append((l,a,y,1/(e if a else 1-e)))

for max_weight in (None,F(2)):
    means, high_props = [], []
    for a in (0,1):
        group = [(l,y,w if max_weight is None else min(w,max_weight))
                 for l,b,y,w in rows if b==a]
        total = sum(w for _,_,w in group)
        means.append(sum(w*y for _,y,w in group)/total)
        high_props.append(sum(w for l,_,w in group if l==1)/total)
        ess = total**2/sum(w*w for _,_,w in group)
    print("cap:", max_weight, "means:", *means, "high:", *high_props)
    print("effect:", means[1]-means[0], "ESS in treated:", ess)

실행 결과

cap: None means: 2/5 3/5 high: 1/2 1/2
effect: 1/5 ESS in treated: 30
cap: 2 means: 1/3 7/10 high: 1/3 2/3
effect: 11/30 ESS in treated: 270/7

두 군의 ESS는 상한을 쓰는 방식마다 서로 같습니다. 표에서는 같은 수의 장비를 관측했지만 어느 군에 드문 준비도인지가 반대로 나타납니다. 추정값이 참값과 다른 이유를 균형 수치로 확인할 수 있습니다.
