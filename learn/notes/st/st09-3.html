마르코프 연쇄와 수락·거절

사후분포의 모양과 비례하는 값만 계산할 수 있어도, 그 분포를 방문 비율로 근사하는 방법이 있습니다. 상태가 세 개뿐인 예제로 제안, 수락, 거절이 어떻게 목표 비율을 만드는지 확인합니다.

이 장을 읽고 나면

  • 마르코프 연쇄의 한 단계와 그 연쇄가 겨냥하는 분포를 구분한다.
  • 세 상태 예시에서 Metropolis–Hastings 수락률과 전이 확률을 손으로 구한다.
  • 연쇄 표본의 자기상관과 다중 연쇄 진단의 역할을 말한다.

정규화 상수를 모르는 상황

베이즈 모형에서 사후확률의 분자는 각 상태의 사전확률과 우도를 곱한 값입니다. 상태가 많거나 연속이면 분모인 증거를 계산하기 어려울 수 있습니다. 분포의 모양을 결정하는 양의 값 w(x)를 알 때 목표 확률 또는 밀도를 π(x) ∝ w(x)로 씁니다.

마르코프 연쇄는 현재 상태를 바탕으로 난수를 써서 다음 상태를 정합니다. 이 장의 전이 규칙은 직전 상태만 필요하고 시간에 따라 고정됩니다. MCMC는 이렇게 얻은 연쇄의 상태들로 목표 분포의 확률이나 기대값을 계산합니다. 목표 분포에서 독립적으로 한 점씩 뽑는 경우와 달리, 연쇄의 이웃한 기록은 서로 영향을 받습니다.

손계산에 쓰는 상태는 A, B, C입니다. 정규화 전 값이 1, 3, 2이므로 목표 확률은 1/6, 1/2, 1/3입니다. 합이 6인 것을 아는 예시이므로 연쇄가 이 비율을 향하는지도 검사할 수 있습니다.

Metropolis–Hastings 한 단계

현재 상태를 x, 후보를 y, 후보를 내는 제안 확률을 q(y|x)라 합니다. 후보가 나오면 수락 확률 a(x,y)를 구합니다. 균등 난수 u가 a보다 작으면 후보로 이동하고, 그 밖에는 현재 상태를 유지합니다. 양방향 제안 확률이 양수인 후보 쌍에서 수락 확률은 다음과 같습니다.

a(x,y) = min(1, w(y)q(x|y) / [w(x)q(y|x)])

정규화 상수는 같은 분포에서 구한 두 값의 비율에서 소거됩니다. A, B, C의 예는 나머지 두 상태를 각각 1/2의 확률로 제안하므로 어느 쪽으로 움직일 때나 제안 확률이 같습니다. 따라서 a(x,y)=min(1,w(y)/w(x))입니다. B에서 C를 제안했을 때 수락 확률은 2/3이고, B에서 한 번 갱신한 결과가 C일 확률은 (1/2)(2/3)=1/3입니다.

행렬의 P(x,y)는 최종 이동 확률입니다. A와 B 사이의 두 방향을 비교하면 π(A)P(A,B)=(1/6)(1/2)=1/12이고 π(B)P(B,A)=(1/2)(1/6)=1/12입니다. 각 상태 쌍의 이런 균형을 상세 균형이라 부릅니다. 모든 쌍에서 성립하므로 처음에 목표 분포를 따르면 한 번 갱신한 뒤에도 같은 분포입니다. 이 예에서는 모든 상태로 건너갈 수 있고 제자리 전이도 있어서, A에서 시작한 뒤 여러 번 갱신한 분포도 목표 확률에 가까워집니다.

상태를 남기는 규칙

B에서 C를 제안했을 때 u=0.8이면 0.8 > 2/3이므로 갱신 뒤의 상태는 B입니다. 기록을 건너뛰면 거절된 시간 동안 머물렀던 상태의 방문 빈도가 사라집니다. 이 예에서 B는 가중치가 가장 크고, B에서 밖으로 나가는 제안은 종종 거절됩니다. 따라서 머문 시간도 목표 확률에 기여합니다.

다음 코드는 A에서 시작하고, 처음 500회의 상태를 빈도에서 뺀 뒤 20,000회를 기록합니다. 첫 500회라는 선택은 이 예의 설정입니다. 상태의 빈도를 세는 위치가 수락 여부를 판단하는 if 바깥에 있습니다.

실행 예제

from random import Random

rng = Random(37)
weights = [1, 3, 2]
current = 0
frequency = [0, 0, 0]
warmup = 500
kept = 20_000

for t in range(warmup + kept):
    choices = [j for j in range(3) if j != current]
    candidate = rng.choice(choices)
    acceptance = min(1.0, weights[candidate] / weights[current])
    if rng.random() < acceptance:
        current = candidate
    if t >= warmup:
        frequency[current] += 1

print("state count estimate target")
for state, count, weight in zip("ABC", frequency, weights):
    print(f"{state} {count} {count / kept:.3f} {weight / sum(weights):.3f}")

실행 결과

state count estimate target
A 3279 0.164 0.167
B 10064 0.503 0.500
C 6657 0.333 0.333

모형, 수렴, 계산 오차는 서로 다른 질문

실제 사후분포는 정답 비율을 모르므로 도해처럼 직접 비교할 방법이 없을 때가 많습니다. 시도할 때는 서로 떨어진 시작점에서 연쇄를 여러 개 돌린 뒤 궤적의 한쪽 고착과 연쇄별 요약이 일치하는지를 확인합니다. R̂는 한 연쇄 안에서의 변동과 여러 연쇄 사이의 변동을 함께 쓰는 진단입니다. 예를 들어 모든 연쇄가 같은 영역만 방문하면 다른 영역에 큰 확률이 있어도 놓칠 수 있습니다.

하나의 사후 평균을 구할 때는 해당 수치의 자기상관을 반영하는 유효표본크기도 봅니다. 비슷한 값이 길게 이어지면 기록 2,000개가 주는 정보는 독립 기록 2,000개보다 적을 수 있습니다. 원소 수만 넣어 독립 표본 공식으로 계산한 표준오차가 실제 계산 오차를 과소평가할 수 있습니다. 첫 부분을 버리거나 수락 횟수만 세는 것으로는 좋은 탐색을 확인하기 어렵습니다. 연쇄가 목표 분포를 잘 계산했더라도 사전과 우도의 가정이 자료에 맞는지는 별도로 점검합니다.

왜 그럴까?

모든 후보를 거절해서 A에만 남는 연쇄에도 목표 분포의 상세 균형이 성립할까?

모범 답 보기

성립합니다. 다른 상태로 가는 양방향 확률이 모두 0이라 쌍마다 양쪽이 같고, 처음 상태가 목표 확률에 따라 선택됐다면 전체 분포는 유지됩니다. 다만 A 하나에서 시작한 연쇄는 다른 상태를 방문할 수 없으므로 목표 확률을 표본 빈도로 복구하지 못합니다.
