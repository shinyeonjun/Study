통계 · ST08 실험의 설계

ST08·1

표집과 배정을 구별하고 블록 안에서 비교하기

누가 실험에 들어오는지와 누가 새 안내를 받는지를 따로 정합니다. 지점과 시간대의 차이를 고려해 비교할 대상을 배치합니다.

이 장을 읽고 나면

  • 무작위 표집과 무작위 배정이 답하는 질문을 구별한다.
  • 실험 단위와 대조 조건을 고르고 지점 안에서 블록 배정을 한다.
  • 비슷한 두 단위를 짝지은 실험에서 비교할 차이를 계산한다.

표본에 들어오는 과정과 실험 처리의 배정을 나눈다

접수 화면을 새로 바꿨을 때 손님이 기다리는 시간이 얼마나 달라지는지 알고 싶습니다. 목표 모집단은 결과를 적용하려는 전체 대상이고, 표본은 실제 관측한 일부입니다. 무작위 표집은 모집단에서 들어올 대상을 확률 규칙으로 고릅니다. 조사 대상의 범위와 응답 여부가 맞으면 모집단에 관해 말할 근거가 됩니다.

무작위 배정은 실험에 들어온 사람 중 누가 새 안내를 받을지 확률로 정하는 일입니다. 자원한 두 지점의 방문만 포함했어도 그 안에서 무작위 배정할 수 있습니다. 이 비교는 참여한 대상 안에서 원인과 결과를 살피는 근거가 되며, 다른 지점에 결과를 그대로 적용할 수 있는지는 표집과 운영 조건을 별도로 봅니다.

배정을 결정하는 가장 작은 단위를 실험 단위라 합니다. 손님마다 화면을 바꿀 수 있다면 방문이 될 수 있습니다. 한 접수대에 있는 모든 방문이 같은 버전을 써야 한다면 접수대나 접수 기간을 단위로 배정하고, 분석에서도 같은 단위 안의 의존성을 고려합니다.

지점 안에서 무작위 배정하고 지점끼리 비교를 합친다

기존 안내를 대조군, 새 안내를 처리군이라고 합시다. 화면의 효과를 보려면 두 군의 대기시간 측정 방식과 운영 조건을 맞춥니다. 지점별 기본 대기시간이 다르다면 지점으로 먼저 나누고, 각 지점 안에서 새 안내와 기존 안내를 배정합니다. 같은 조건으로 묶은 집단을 블록이라 합니다. 이 예는 각 지점에서 방문 네 건 중 두 건을 새 안내로 뽑습니다.

느린 지점의 차이는 8−11=−3분이고 빠른 지점은 5−6=−1분입니다. 두 지점에 같은 비중을 주면 평균 차이는 −2분입니다. 이 장의 전체 평균도 배정 수가 양쪽에서 같아 같은 결과가 나옵니다. 지점의 규모가 다르면 어떤 지점 비중을 원하는지 먼저 정합니다. 두 지점에 같은 비중을 주는 평균과 전체 방문에 같은 비중을 주는 평균은 서로 다를 수 있습니다.

시간대와 방문 유형 등을 정하는 일은 처리 전에 합니다. 안내를 받은 뒤 달라진 행동으로 블록을 뒤늦게 만들면, 화면의 영향을 받은 변수를 기준으로 비교하게 됩니다.

짝 두 개의 평균을 따로 내기 전에 짝별 차이를 본다

짝짓기는 비슷한 실험 단위 둘만 하나의 작은 블록처럼 다루는 방법입니다. 예로 같은 지점과 비슷한 시간대인 방문 둘을 짝지어 그 안에서 처리 하나를 무작위로 고릅니다. 짝 1에서 기존 10분과 새 9분, 짝 2에서 기존 12분과 새 9분이었다면 차이는 −1분, −3분이고 평균은 −2분입니다.

같은 사람을 두 조건에서 반복 측정하는 비교도 짝지을 수 있습니다. 이 경우에는 어느 조건을 먼저 받았는지, 앞 조건의 영향이 다음까지 남는지, 측정 시점 사이에 무엇이 바뀌는지 살펴야 합니다. 짝짓기만으로 배정의 편향이나 시간에 따른 변화가 없어지는 것은 아닙니다.

합성 배정과 지점별 평균차를 실행한다

교육용으로 시드 7을 사용하고, 그 배정으로 관측됐다고 가정한 대기시간을 입력했습니다. 코드의 sample은 지점마다 번호 넷 중 두 개를 중복 없이 새 안내로 배정합니다. 시험 자료가 이미 있다면 실제 배정 기록으로 분석합니다.

from random import Random
from statistics import mean

rng = Random(7)
sites = {
    "slow": {1: 7, 2: 10, 3: 9, 4: 12},
    "fast": {1: 5, 2: 7, 3: 6, 4: 4},
}

differences = []
for site, outcomes in sites.items():
    assigned_new = set(rng.sample(sorted(outcomes), 2))
    old = [y for i, y in outcomes.items() if i not in assigned_new]
    new = [y for i, y in outcomes.items() if i in assigned_new]
    difference = mean(new) - mean(old)
    differences.append(difference)
    print(site, sorted(assigned_new), mean(old), mean(new), difference)

print("equal-site difference:", mean(differences))
slow [1, 3] 11 8 -3
fast [3, 4] 6 5 -1
equal-site difference: -2

출력은 지점, 새 안내로 배정한 방문 번호, 기존과 새 안내의 평균, 평균차입니다. 시드는 이 예의 배정을 다시 만드는 데 쓰입니다. 실제 실험에서는 배정 순서와 측정 결과를 함께 기록합니다.

한 줄 정리

무작위 표집은 결과를 누구에게 일반화할지를, 무작위 배정은 참여 대상 안에서 처리 효과를 비교할 수 있는지를 정하며, 블록·짝은 처리 전에 알려진 차이를 같은 조건 안의 비교로 줄입니다.
