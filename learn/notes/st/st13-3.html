ST13·3

쌍과 군집을 통째로 다시 뽑아 의존을 보존하기

한 장치에서 두 번 잰 값에는 같은 장치의 특성이 들어 있습니다. 같은 장소에서 모은 여러 기록도 서로 닮을 수 있습니다. 무엇을 독립적으로 다시 뽑을지 정한 뒤 표준오차를 비교합니다.

이 장을 읽고 나면

  • 짝을 함께 재표집하고 공분산을 사용해 표준오차 차이를 설명한다.
  • 독립 단위가 군집인 자료에서 행과 군집 재표집을 구별한다.
  • 크기가 다른 군집에서 질문에 맞는 평균을 고른다.

같은 장치의 전·후 값을 한 단위로 남긴다

독립적으로 뽑은 장치 세 대의 합성 기록에서 설정 전·후 소비전력을 읽습니다. 두 측정에 장치 고유의 크기나 특성이 공통으로 들어갈 수 있습니다. 질문이 ‘장치 하나에서 평균적으로 얼마나 바뀌었나’라면 관심 통계량은 Di=Bi−Ai의 평균입니다. A는 전, B는 후이고 같은 i를 붙인 두 값은 같은 장치입니다.

한 부트스트랩 표에서는 장치 ID 세 개를 복원 추출하고, 각 ID의 두 값을 유지해 차이의 평균을 다시 계산합니다. 평균차라는 목표에서는 (1,2,1)이라는 차이 목록을 그대로 뽑아도 같습니다. 장치마다 한 쌍을 얻고 쌍끼리는 독립이며 같은 모집단에서 왔다는 전제를 둡니다. 날짜마다 새 장치가 아니라 같은 장치가 더 반복되었다면, 날짜의 쌍을 독립 단위로 추가할 수 없습니다.

전과 후를 다른 표에서 독립으로 뽑으면, 원 자료에 없던 1과 8이 같은 장치 쌍처럼 처리될 수 있습니다. Var(B−A)=Var(B)+Var(A)−2Cov(A,B)에서 공분산 부분을 잃습니다. 이 자료의 경험분포에서 Var*(A)=6, Var*(B)=56/9, Cov*(A,B)=6입니다. 성분 분산은 각각 6,56/9인데 공분산을 반영한 차이의 분산은 2/9입니다.

짝 부트스트랩의 평균차 분산 = (2/9)/3 = 2/27. 두 열을 독립 재표집한 분산 = (6+56/9)/3 = 110/27.

같은 장치에서 큰 전 값이 큰 후 값과 연결되어 있으므로 실제 짝을 쓰면 두 값의 공통 변동이 차이에서 대부분 지워집니다. 쌍을 무시할 때 분산이 커지는 방향은 이 예의 양의 공분산을 반영합니다. 다른 의존 구조에서는 오차의 방향이 달라질 수 있습니다.

군집 안에서 보인 반복은 관측 설계의 일부다

이번에는 독립적으로 뽑은 세 장소 A,B,C에서 각각 센서 두 개를 읽습니다. 합성 모형에서 각 장소의 두 값은 같은 장소 특성만 반영해 (0,0), (4,4), (8,8)입니다. 관측 행은 여섯 개지만 독립적으로 표집된 장소는 세 곳입니다. 장소별 평균을 구한 뒤 장소 평균의 평균을 추정한다고 합시다.

군집 부트스트랩에서는 세 장소 ID를 복원으로 뽑습니다. 예를 들어 B,B,C라면 B에 속한 두 측정이 두 번, C의 두 측정이 한 번 들어갑니다. 두 센서가 함께 움직이는 구조를 유지합니다. 이 예는 군집 크기가 모두 2여서 장소 평균의 평균과 모든 센서값의 평균이 같습니다. 독립이 아닌 센서를 여섯 개의 독립 관측처럼 복원 추출하면 부트스트랩 안에서 장소의 두 센서가 떨어집니다.

장소 평균 0,4,8의 경험분포 분산은 (16+0+16)/3=32/3입니다. 장소 세 곳을 뽑으면 이 값을 3으로 나눕니다. 센서별 값도 0,4,8이 각각 두 번이라 값 한 개의 경험분포 분산은 같습니다. 그러나 행을 독립이라고 놓았을 때에는 6으로 나눠 분산 추정이 작아집니다. 같은 군집의 측정이 양의 상관을 갖는 자료에서 흔히 보이는 방향입니다. 독립 단위는 가정과 표집 계획으로 정합니다.

크기가 다른 군집에서는 질문을 다시 읽는다

이번에는 A가 두 행 (0,0), B가 네 행 (4,4,4,4), C가 한 행 (8)이라고 합시다. 각 장소에 같은 비중을 주는 추정은 (0+4+8)/3=4입니다. 관측된 모든 행에 같은 비중을 주면 (0+16+8)/7=24/7입니다. ‘평균 장소가 어땠나’와 ‘관측된 센서 한 건의 평균이 얼마인가’에 따라 결과가 달라집니다. 후자를 관심 통계량으로 정했다면, 군집을 다시 뽑은 뒤 건수와 값의 합을 함께 다시 계산해 나눕니다. 모집단의 관측 행에까지 일반화하려면 군집 표집 확률과 군집 크기 관계도 고려합니다.

어떤 방법도 새로운 독립 장소를 만들어 주지 못합니다. 장소 세 곳의 분포는 지역 전체를 대표하기에 부족할 수 있습니다. 여러 장소가 같은 날 같은 조건의 영향을 받거나, 장치를 시계열로 여러 번 읽어 시점 사이에도 의존성이 있으면 그 구조에 맞는 설계와 재표집을 따로 검토합니다. 부트스트랩으로 계산한 표준오차에 앞서 독립 단위가 무엇인지 보고에 적습니다.

이어 풀기와 증명

대상 모집단에서 서로 독립적으로 들어온 단위가 무엇인지 먼저 적습니다. 분산을 비교하기 전에 두 추정량이 같은 질문에 답하는지도 확인합니다.

파이썬으로 같은 계산 검산하기

from fractions import Fraction as F
from itertools import product
from math import sqrt

def boot_means(values):
    n = len(values)
    return [F(sum(draw), n) for draw in product(values, repeat=n)]

def variance(values):
    mean = sum(values) / len(values)
    return sum((v-mean)**2 for v in values) / len(values)

before, after = [1, 4, 7], [2, 6, 8]
paired = boot_means([b-a for a, b in zip(before, after)])
unpaired = [b-a for a, b in product(boot_means(before), boot_means(after))]
for label, estimates in (("pairs", paired), ("independent columns", unpaired)):
    v = variance(estimates)
    print(label, v, f"SE={sqrt(v):.6f}")

clusters = [(0, 0), (4, 4), (8, 8)]
nested = boot_means([F(sum(c), len(c)) for c in clusters])
rows = boot_means([y for c in clusters for y in c])
print("cluster and row variances:", variance(nested), variance(rows))

unequal = [(0, 0), (4, 4, 4, 4), (8,)]
site_mean = sum(F(sum(c), len(c)) for c in unequal) / len(unequal)
row_mean = F(sum(sum(c) for c in unequal), sum(len(c) for c in unequal))
print("site and row means:", site_mean, row_mean)

실행 결과

pairs 2/27 SE=0.272166
independent columns 110/27 SE=2.018434
cluster and row variances: 32/9 16/9
site and row means: 4 24/7

첫 두 줄은 각 경우 가능한 표를 전부 열거해 얻은 조건부 분산입니다. 장소 평균도 분수로 보존해 끝까지 계산합니다. 세 번째 줄을 비교할 때는 모든 장소의 센서 수가 같아서, 장소 평균과 행 평균이 같은 목표량을 계산한다는 조건을 사용했습니다.
