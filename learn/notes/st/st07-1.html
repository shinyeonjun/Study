단순 선형회귀: 직선 계수와 잔차부터 계산하기

직전 구간의 요청 건수로 다음 대기시간을 표현해 봅니다. 직선은 모든 점을 지나지 않아도, 어떤 기준으로 적합했는지와 예측이 각 관측에서 얼마나 빗나갔는지 확인할 수 있습니다.

이 장을 읽고 나면

  • 기울기·절편을 측정 단위와 질문으로 해석한다.
  • 예측값과 잔차, 잔차 제곱합과 R²를 계산한다.
  • 적합도와 새 자료의 성능 및 인과 의미를 구분한다.

직선 하나로 조건에 따른 평균을 표현한다

직전 10분의 대기 요청 수 x(건)와 다음 구간의 평균 대기시간 y(분)을 다섯 번 관측했다고 합시다. 자료는 손으로 계산할 수 있게 만든 예입니다. 단순 선형회귀는 x 하나를 써서 조건부 평균의 형태를 E[Y|X=x]=β₀+β₁x로 표현합니다. 표본에서 계산한 직선은 ŷ=b₀+b₁x입니다. 조건부 평균과 실제 관측에는 차이가 생길 수 있습니다.

최소제곱은 다섯 점의 실제 값과 직선 값의 세로 차이를 제곱해 합한 값을 가장 작게 하는 직선을 고르는 방법입니다. x 평균은 2, y 평균은 5이고, 중심화한 x 편차의 제곱합 Sxx=10, x·y의 편차 곱합 Sxy=16입니다. 직선을 적합하는 공식은 b₁=S_xy/S_xx=1.6, b₀=ȳ−b₁x̄=1.8입니다. 절편을 포함한 적합선이 평균 점 (2,5)을 지나므로 마지막 식을 확인할 수 있습니다.

기울기 1.6의 단위는 분/건입니다. 이 적합선에서 요청이 한 건 더 많으면 평균 대기가 1.6분 더 깁니다. 절편 1.8분은 x=0의 예측입니다. 예제에는 x=0이 있지만 일반 자료에서 0이 관측 범위 밖이면 절편의 업무 해석이 어려울 수 있습니다. 기울기는 관측된 관계이고 요청 건수를 강제로 바꾸면 1.6분이 달라진다는 결론은 설계 없이 얻을 수 없습니다.

절편을 포함한 최소제곱에서는 표본 잔차의 합이 0입니다. 양·음 방향의 결과가 지워질 수 있어 잔차 합을 오차의 크기로 보지 않습니다. 각 잔차를 제곱해 더한 SSE=2.4분²를 사용합니다. 제곱을 쓰므로 같은 단위라면 큰 잔차 하나가 적합에 크게 영향을 미칠 수 있습니다.

전체 자료의 변동 가운데 직선이 맞춘 몫

y의 전체 평균 5만 항상 예측하면 제곱오차 합은 SST=Σ(y−ȳ)²=28입니다. 절편을 포함한 이 적합에서 결정계수 R²는 1−SSE/SST=1−2.4/28≈0.9143입니다. SST가 양수인 경우의 정의입니다. 이는 이 표본에서 평균만 쓸 때보다 제곱오차를 약 91.4% 줄였다는 의미입니다. 새 주간에 같은 성능을 보장하지는 않습니다. 같은 표본의 최소제곱 모형에 기존 변수를 유지한 채 설명변수를 더하면 훈련 R²는 감소하지 않습니다. 예측 품질을 비교할 때는 써 보지 않은 자료의 오차도 봅니다.

import numpy as np
from scipy.stats import linregress

x = np.array([0, 1, 2, 3, 4], dtype=float)
y = np.array([2, 4, 4, 6, 9], dtype=float)
fit = linregress(x, y)
fitted = fit.intercept + fit.slope * x
residuals = y - fitted
sse = residuals @ residuals
sst = (y - y.mean()) @ (y - y.mean())
r2 = 1 - sse / sst
assert np.isclose(residuals.sum(), 0) and np.isclose(fit.rvalue**2, r2)
print(f"절편={fit.intercept:.1f}, 기울기={fit.slope:.1f}")
print("적합값:", np.round(fitted, 1).tolist())
print("잔차:", np.round(residuals, 1).tolist())
print(f"SSE={sse:.1f}, SST={sst:.1f}, R²={r2:.4f}")

적합값: [1.8, 3.4, 5.0, 6.6, 8.2]
잔차: [0.2, 0.6, -1.0, -0.6, 0.8]
SSE=2.4, SST=28.0, R²=0.9143
