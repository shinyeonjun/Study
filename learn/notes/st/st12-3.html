ST12·3

Fisher scoring을 가중 최소제곱으로 구현하고 잔차를 진단하기

GLM에서 평균에 따른 변동이 바뀌면 모든 행을 같은 비중으로 업데이트할 수 없습니다. 점수와 정보행렬을 유도하고, 작은 포아송 회귀의 가중치·계수·진단을 검산합니다.

이 장을 읽고 나면

  • 조건부 평균의 미분에서 점수와 정보행렬을 얻는다.
  • Fisher scoring 한 번이 IRLS 한 번과 같은 이유를 증명한다.
  • Poisson 회귀의 적합과 잔차를 계산하고 추론이 실패할 조건을 판단한다.

같은 단위를 먼저 맞춘 뒤 한 걸음을 고른다

각 행의 선형예측자를 ηi=xi⊤β+oi로 둡니다. oi는 알려진 오프셋으로, 없으면 0입니다. μi=g−1(ηi), di=dμi/dηi, Vi=Var(Yi|xi)라고 두겠습니다. 반복 한 걸음 동안 이 기호들은 모두 현재 β에서 평가합니다. 내부의 정칙 모형에서 응답은 조건부 독립이며 적합점에서 Vi>0, di≠0이라 합시다.

지수족에서 한 행의 자연모수 점수는 (yi−μi)/a입니다. dμ/dθ=b″=V/a이므로 연쇄법칙으로 η의 점수는 (yi−μi)di/Vi입니다. 설계행렬 X의 i번째 행이 xi⊤라면 계수의 점수 벡터는 S=X⊤u, ui=(yi−μi)di/Vi입니다. 평균 0이고 독립인 행 기여의 공분산을 더하면 정보행렬은 I=X⊤WX, W=diag(di²/Vi)입니다.

뉴턴법은 점수의 실제 미분을 쓰고, Fisher scoring은 그 음의 기댓값인 정보행렬을 씁니다. 이는 현재 점수 S에서 새 점수를 S−IΔ로 근사해 0에 맞추는 계산입니다. IΔ=S를 풀고 β+Δ로 갱신합니다. 정준 연결인 Poisson 로그 연결과 Bernoulli 로짓에서는 로그우도의 β에 대한 이계 미분이 y의 값과 무관해서 이 두 방식이 같습니다.

가중치가 들어간 새 표를 적는다

현재 η에 응답 잔차를 기울기로 나눈 값을 보태 작업 반응 zi=ηi+(yi−μi)/di를 만듭니다. 이 값은 응답을 η 단위로 옮긴 일차 근사입니다. wi=di²/Vi이므로 wi(zi−ηi)=ui입니다. 그 결과 IΔ=X⊤W(z−η)이고 η=Xβ+o를 넣어 정리하면

X⊤WX(β+Δ)=X⊤W(z−o).

이는 z−o를 X로 적합하는 가중 최소제곱의 정규방정식입니다. 계산할 때는 각 행에 √wi를 곱한 배열을 직접 최소제곱으로 풉니다. 새 β에서 μ·z·w를 다시 구하므로 반복 재가중 최소제곱(IRLS)입니다. 같은 가중치를 끝까지 쓰는 한 번의 선형회귀와 구분합니다. 가중치가 양수라도 X의 열이 종속이면 정보행렬은 특이합니다. 중복된 열이나 다른 디자인 문제는 먼저 확인합니다.

Poisson 로그 연결에서 di=μi=Vi라 wi=μi입니다. Bernoulli 로짓의 한 개인 응답에서는 di=pi(1−pi)=Vi라 wi=pi(1−pi)입니다. 같은 p가 있는 n명의 비율을 한 행으로 쓰면 비율의 분산을 쓰므로 가중치에 n을 곱합니다.

작은 관측에서 첫 반복을 두 방식으로 구한다

같은 길이의 독립 인쇄 관측 여섯 구간의 합성 자료입니다. x=(−1,−1,0,0,1,1), y=(0,2,1,3,2,4)입니다. 시작점 β=(log 2,0)이면 모든 η=log 2, μ=2, w=2입니다.

Σx=0, Σx²=4라 I=diag(12,8)입니다. Poisson의 점수는 S=X⊤(y−μ)=(0,4)입니다. 따라서 Δ=(0,.5)이고 다음 β는 (log 2,.5)입니다. IRLS에서도 z−o=z를 가중치 2로 적합하면 같은 결과를 얻습니다. 이후 반복에서 평균과 가중치가 달라집니다.

계수와 표준오차를 계산한 뒤 진단한다

최종 기울기는 약 .522442입니다. 1 증가할 때 발생률비는 e.522442≈1.686141입니다. 참 모형에서 독립이고 계수가 내부에서 잘 추정되며 표본이 충분하다면 정보행렬의 역이 MLE 공분산의 근사입니다. 대각 성분을 제곱근으로 읽은 SE(β̂₁)≈.377769는 이 예의 계산값입니다. 관측 여섯 개에서는 정규근사나 검정에 곧바로 높은 신뢰를 부여하기 어렵습니다.

Poisson에서 Pearson 잔차는 (y−μ̂)/√μ̂입니다. 여섯 잔차 제곱합을 잔차 자유도 6−2=4로 나누면 약 .908542입니다. 포아송의 분산 가정이 맞는지 검토할 때 이 비가 크게 올라갈 때뿐 아니라 조건별 잔차 패턴, 구간의 반복 의존, 누락 변수, 노출 단위, 몇 개의 영향 큰 점을 함께 봅니다. 값이 1에 가깝다는 사실만으로 가정이 입증되지는 않습니다.

이탈도(deviance)는 각 행의 평균을 따로 적합하는 포화모형과 현재 모형의 로그우도 차에 2를 곱한 값입니다. Poisson에서는 2Σ[y log(y/μ̂)−(y−μ̂)]이며 y=0의 y log(y/μ̂)는 극한값 0을 씁니다. 이 예는 약 4.547909입니다. Pearson 통계량과 다른 양입니다. 같은 자료에 맞춘 두 중첩 모형 등에서 이탈도 차를 추론에 쓰려면 내포 관계와 정칙·표본 조건을 함께 확인합니다.

반복값이 크기만 커지는 경우에는 유한 MLE가 있는지 다시 봅니다. 예를 들어 x=0에서 응답이 모두 0이고 x=1에서 모두 1인 이진 로지스틱 자료에서는 절편을 −t, 기울기를 2t로 보내면 두 조건을 점점 완전히 분리합니다. 로그우도는 상한에 가까워지지만 유한한 계수는 그 상한에 닿지 않습니다. 작은 점수나 한 번의 종료만으로 적합이 끝났다고 판단하기 어려운 이유입니다.

이어 풀기와 증명

한 행의 가중치와 작업 반응을 직접 계산한 뒤 정규방정식에서 나온 갱신과 비교합니다. 마지막 문항에서는 진단 수치가 클 때 무엇을 다시 확인할지 구체화합니다.

파이썬으로 같은 계산 검산하기

from math import exp, lgamma, log
import numpy as np

x = np.repeat([-1.0, 0.0, 1.0], 2)
y = np.array([0, 2, 1, 3, 2, 4], dtype=float)
X = np.column_stack((np.ones(len(x)), x))
beta = np.array([log(y.mean()), 0.0])

def loglik(b):
    eta = X @ b
    return float(y @ eta - np.exp(eta).sum()
                 - sum(lgamma(value + 1) for value in y))

for i in range(20):
    eta = X @ beta
    mu = np.exp(eta)
    z = eta + (y - mu) / mu
    sqrt_w = np.sqrt(mu)
    next_beta = np.linalg.lstsq(sqrt_w[:, None] * X, sqrt_w * z,
                                rcond=None)[0]
    assert loglik(next_beta) >= loglik(beta) - 1e-10
    if i == 0:
        print("first:", [round(float(v), 6) for v in next_beta])
    if np.max(np.abs(next_beta - beta)) < 1e-10:
        beta = next_beta
        break
    beta = next_beta
else:
    raise RuntimeError("the example did not converge")

mu = np.exp(X @ beta)
score = X.T @ (y - mu)
assert np.max(np.abs(score)) < 1e-8
info = X.T @ (mu[:, None] * X)
covariance = np.linalg.solve(info, np.eye(2))
slope_se = np.sqrt(covariance[1, 1])
pearson = float(((y - mu)**2 / mu).sum())
deviance = 2 * sum((value * log(value / m) if value > 0 else 0)
                   - (value - m) for value, m in zip(y, mu))
print("estimated:", [round(float(v), 6) for v in beta])
print("fitted means:", [round(float(m), 6) for m in mu[::2]])
print(f"rate ratio: {exp(beta[1]):.6f}, slope SE: {slope_se:.6f}")
print(f"Pearson/df: {pearson/(len(y)-2):.6f}, deviance: {deviance:.6f}")

실행 결과

first: [0.693147, 0.5]
estimated: [0.604157, 0.522442]
fitted means: [1.085146, 1.829708, 3.085146]
rate ratio: 1.686141, slope SE: 0.377769
Pearson/df: 0.908542, deviance: 4.547909

이 예제의 업데이트는 로그우도가 낮아지지 않는지와 최종 점수의 크기를 따로 검사합니다. 다른 자료에서는 한 번에 큰 폭으로 갱신할 때 로그우도가 감소할 수 있습니다. 그때는 단계 크기를 줄이거나 적합 방식과 모형의 조건을 다시 봅니다.
