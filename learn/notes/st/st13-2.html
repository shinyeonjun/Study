ST13·2

경험분포를 다시 뽑아 표준오차와 구간 얻기

관측이 세 개면 길이 3의 복원 표본을 모두 열거할 수 있습니다. 실제로 받은 표를 고정하고 추정량의 다시 뽑은 분포가 무엇을 근사하는지 봅니다.

이 장을 읽고 나면

  • 원 표본 추출과 조건부 부트스트랩 반복을 구별한다.
  • 비모수 부트스트랩에서 표준오차, 백분위수·기본 구간을 계산한다.
  • 표본 최대값에서 백분위수 구간이 실패하는 이유를 증명한다.

관측값 자체를 확률분포로 바꾼다

각 관측 건의 대기시간이 같은 모집단에서 독립적으로 나온다고 가정합니다. 그 모형을 설명하는 합성 자료로 x=(1,1,4)분을 사용합니다. 관심 모수는 모집단의 평균입니다. 자료의 평균 T(x)=2분은 추정값 한 개입니다. 새 원자료를 계속 얻을 수 없으므로, 비모수 부트스트랩은 현재 표에 있는 세 행 각각에 확률 1/3을 주는 경험분포를 모집단의 대용으로 둡니다. 두 행의 값이 1이라 새 한 번에서 1일 확률은 2/3입니다.

그 경험분포에서 복원으로 세 번 뽑아 한 새 표 x*를 만들고 같은 추정법 T*를 적용합니다. 필요한 횟수만큼 표 단위로 반복합니다. 표 안에서 뽑는 수 n과 표를 다시 만드는 수 B를 구별합니다. B를 늘리면 이미 받은 세 행에서 계산한 부트스트랩 분포의 수치 오차가 줄어듭니다. 실제 관측 정보를 늘리려면 원자료를 추가해야 합니다.

크기 3의 표를 전부 만들어 분산을 확인한다

행 번호를 뽑는 순서는 3³=27개로 모두 같은 확률입니다. 값 4가 k번 선택되면 T*=[(3−k)·1+k·4]/3=1+k입니다. k는 조건부로 Binomial(3,1/3)입니다. k=0이면 두 개의 1인 행 중에서 세 번 고를 수 있어 2³=8개입니다. k=1이면 4가 들어갈 자리 3개와 두 1일 자리를 각각 고르는 4가지가 있어 12개입니다.

별표가 붙은 기대값과 분산 E*, Var*는 원자료를 고정한 상태에서 복원 표만 바꿔 평균한 값입니다. E*[T*]=2, Var*(T*)=Var*(k)=3(1/3)(2/3)=2/3입니다. 따라서 평균의 부트스트랩 표준오차는 √(2/3)≈.816497분입니다. 일반적인 독립 표본 평균에서 Var*(X*)=Σ(xi−x̄)²/n이며 Var*(X̄*)=Var*(X*)/n입니다. 기존 불편 표본분산으로 구하는 추정 표준오차와 유한 n에서 차이가 나는 것은 n과 n−1 중 어떤 분모로 경험분포의 분산을 계산하는지에 달려 있습니다.

꼬리 경계에서 두 방식의 구간을 만든다

관측 표의 추정값을 T, 부트스트랩 추정 분포의 q분위수를 Q(q)라 합시다. 이 장의 이산 분위수는 ‘누적확률이 q 이상이 되는 가장 작은 값’입니다. 백분위수 구간은 [Q(α/2), Q(1−α/2)]입니다. 기본 구간은 T*−T의 꼬리값의 범위를 T−θ가 따르는 오차 범위로 근사한 뒤 θ를 풉니다. 따라서 양 끝을 [2T−Q(1−α/2), 2T−Q(α/2)]로 뒤집습니다.

여기서 95%는 두 구간을 구성할 때 입력한 수준입니다. 원자료를 독립적으로 여러 번 다시 얻으면 그때마다 다른 구간이 생깁니다. 그 구간들이 참값을 덮는 비율이 실제 포괄률이며, 근사법마다 가정에 따라 달라집니다. 세 개 관측으로 만든 구간이 모집단 평균을 95% 포함한다고 확정할 수 없습니다. 결측, 독립성, 모집단 꼬리, 추정량의 민감도도 별도로 검토합니다.

극단적인 실패 예는 Uniform(0,θ)의 끝점 θ를 표본 최대값 M으로 추정할 때입니다. 복원 표본에서 뽑을 수 있는 값은 원래 표 안에만 있으므로 모든 M*≤M입니다. 백분위수 구간의 상단도 M 이하입니다. 연속 모형의 어느 유한 표본에서도 확률 1로 M<θ이므로 여기서 이 구간의 포괄률은 0입니다. B를 아무리 늘려도 모집단의 끝점 정보가 경험분포에 생기지 않습니다. 끝점 모형에서는 모형의 파생 분포로 추론하는 등 질문에 맞는 다른 방법이 필요합니다.

이어 풀기와 증명

같은 자료가 반복된 횟수를 그대로 두고 분위수를 구합니다. 이어서 구간의 산술과 그 구간이 실제로 포괄하는 빈도를 구분합니다.

파이썬으로 같은 계산 검산하기

from collections import Counter
from fractions import Fraction as F
from itertools import product
from math import sqrt

sample = (1, 1, 4)
n = len(sample)
estimate = F(sum(sample), n)
means = [F(sum(draw), n) for draw in product(sample, repeat=n)]
histogram = Counter(means)
variance = sum((t-estimate)**2 for t in means) / len(means)

def quantile(q):
    cumulative = 0
    for value in sorted(histogram):
        cumulative += histogram[value]
        if F(cumulative, len(means)) >= q:
            return value
    raise ValueError("q must be between 0 and 1")

low, high = quantile(F(1, 40)), quantile(F(39, 40))
assert variance == F(2, 3)
print("mean frequencies:", [(int(v), histogram[v]) for v in sorted(histogram)])
print("bootstrap variance, SE:", variance, f"{sqrt(variance):.6f}")
print("percentile:", low, high)
print("basic:", 2*estimate-high, 2*estimate-low)

실행 결과

mean frequencies: [(1, 8), (2, 12), (3, 6), (4, 1)]
bootstrap variance, SE: 2/3 0.816497
percentile: 1 4
basic: 0 3

product는 값이 중복된 경우에도 각 입력 위치를 선택지로 둡니다. 따라서 세 행을 복원으로 선택하는 전부를 셉니다. 큰 n에서는 이 열거 대신 난수로 행 인덱스를 뽑습니다. 쌍과 군집에서는 한 행씩 뽑는 규칙부터 바꿉니다.
