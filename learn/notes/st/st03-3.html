ST03·3

부트스트랩: 가지고 있는 표본에서 다시 뽑기

새 기계에서 수집한 표본 하나가 있습니다. 모집단에서 같은 표본을 몇만 번 새로 얻기는 어렵습니다. 부트스트랩은 원표본을 이용해 통계량을 여러 번 다시 계산하고 그 변동으로 불확실성을 어림합니다.

이 장을 읽고 나면

  • 경험분포와 크기 n의 복원 재표집이 무엇인지 설명한다.
  • 재표집 평균과 백분위수 구간을 코드로 계산한다.
  • 표본 크기 n과 반복 횟수 B를 구별하고 적용 한계를 확인한다.

모집단 대신 표본에 들어 있는 값을 사용한다

표준오차를 정확히 알 수 있다면, 새로 표집할 때 통계량이 얼마나 흔들릴지 말할 수 있습니다. 실제 모집단의 분포는 보통 모릅니다. 부트스트랩은 관측한 자료를 바탕으로 표집분포를 근사합니다. 이 장에서는 서로 독립이고 동일한 분포를 따르는 관측의 비모수 부트스트랩을 다룹니다.

원표본 [4, 6, 8]에서 한 행을 확률 1/3씩 뽑는 분포를 생각합니다. 관측된 행의 상대도수를 확률로 쓴 이 분포가 경험분포입니다. 원표본이 [4, 8, 8]이면 값 8에 해당하는 행이 둘이라 8이 나올 확률은 2/3입니다. 숫자의 종류가 아니라 관측한 행을 뽑습니다.

뽑은 행을 후보에 돌려놓는 복원 재표집으로 길이 3의 새 목록을 만듭니다. 목록 하나의 평균을 구합니다. 이제 처음부터 후보 세 행을 다시 놓고 새 목록을 뽑습니다. 이 두 작업을 B번 하면 평균 B개를 얻습니다. 원래 평균 6을 추정값으로 기록하고 평균 B개의 산포로 그 추정의 표준오차를 근사합니다.

작은 표본으로 재표집분포를 전부 확인한다

[4, 6, 8]에서 복원 재표집한 길이 3의 목록은 순서를 구별하면 3³ = 27개입니다. 목록 하나의 평균이 8이려면 [8,8,8] 한 가지여야 해 확률은 1/27입니다. 평균이 6이려면 모두 6이거나 4·6·8을 하나씩 뽑아야 합니다. 순서가 1 + 3×2×1 = 7개이므로 확률은 7/27입니다.

모든 재표집의 평균은 원표본 평균 6을 중심으로 퍼져 있습니다. 이 결과는 주어진 원표본에 조건을 건 분포입니다. 실제 모집단에서 새 원표본을 뽑으면 경험분포도 바뀌고 그 표본의 부트스트랩 분포도 바뀝니다. 원표본이 달라질 때의 표집분포를 실험실에서 직접 안다는 뜻은 아닙니다.

실행 예제

from itertools import product
from collections import Counter

sample = (4, 6, 8)
sums = Counter(sum(draw) for draw in product(sample, repeat=len(sample)))
for total, count in sorted(sums.items()):
    print(f"{total / len(sample):.2f}: {count}")

실행 결과

4.00: 1
4.67: 3
5.33: 6
6.00: 7
6.67: 6
7.33: 3
8.00: 1

분포의 가운데로 백분위수 구간을 만든다

재표집 통계량의 표준편차는 부트스트랩 표준오차입니다. 또 한 방법은 재표집 통계량을 정렬한 뒤 양쪽 2.5% 지점에 해당하는 2.5번째와 97.5번째 백분위수를 구간 양끝으로 삼는 것입니다. 이를 양측 95% 백분위수 부트스트랩 구간이라 합니다. 유한한 반복에서 분위수 사이의 값을 구하는 방법은 여러 가지이며, 아래 코드는 NumPy의 기본 선형 보간을 씁니다.

이번 자료는 독립적으로 측정한 실행 8건의 지연 시간입니다. 재표집한 자료 한 행의 길이는 8이고, 그런 행을 20,000개 만듭니다. axis=1로 각 재표집 행을 평균 내면 길이 20,000인 배열을 얻습니다.

실행 예제

import numpy as np

sample = np.array([4, 6, 7, 9, 10, 12, 13, 15])
rng = np.random.default_rng(41)
resamples = rng.choice(sample, size=(20_000, sample.size), replace=True)
boot_means = resamples.mean(axis=1)
low, high = np.quantile(boot_means, [0.025, 0.975])

print(f"mean={sample.mean():.3f} ms")
print(f"bootstrap SE={boot_means.std(ddof=1):.3f} ms")
print(f"percentile interval=[{low:.3f}, {high:.3f}] ms")

실행 결과

mean=9.500 ms
bootstrap SE=1.230 ms
percentile interval=[7.125, 11.875] ms

default_rng(41)은 같은 실행을 확인하기 위해 난수 생성기의 시작 상태를 고정합니다. n은 실제 관측 수, B는 원표본을 두고 컴퓨터가 재표집한 횟수입니다. B를 늘리면 같은 경험분포에서 계산한 표준오차와 분위수의 난수 오차를 줄일 수 있습니다. 원표본에 들어 있는 정보는 그대로입니다.

어떤 단위에서 무엇을 다시 뽑을지 확인한다

적용을 좌우하는 세 가지

  • 대표성이 중요합니다. 활동 사용자만 관측했다면 재표집 값도 그 사용자에게서 나옵니다. 조사에서 빠진 집단의 특성은 독립된 자료 수집 등 다른 근거가 필요합니다.
  • 의존성에 맞추어 단위를 정합니다. 같은 사용자의 전후 측정 차이를 연구하면 한 사람의 두 값을 묶어 재표집하는 방법을 고려합니다. 시계열의 연속 기록이라면 인접 관계를 살리는 블록처럼 모형과 수집 설계에 맞는 재표집이 필요합니다.
  • 작은 표본과 극단값을 봅니다. 예를 들어 모든 원자료가 8이면 재표집에서도 8밖에 나오지 않고 표준오차가 0으로 계산됩니다. 이 결과가 실제 모집단의 변동을 잘 반영하는지는 별도로 살펴야 합니다.

모든 문제에서 백분위수 구간의 실제 포괄률이 정확히 95%인 것은 아닙니다. 표본의 크기와 분포, 선택한 통계량, 재표집 단위가 중요합니다. 같은 부트스트랩 분포를 쓴 구간에도 백분위수법, 기본법(basic), 편향과 비대칭을 보정하는 BCa 등의 방식이 있습니다. 어떤 방법으로 구간을 계산했는지 이름을 함께 남겨야 결과를 다시 만들 수 있습니다.

왜 그럴까?

행 8개가 있는 자료의 재표집 횟수를 두 배로 늘려도, 새로운 관측값을 8개 더 모았을 때와 무엇이 다른가요?

모범 답 보기

재표집을 늘리면 같은 8행을 바탕으로 계산한 분포가 덜 흔들립니다. 새 독립 관측값은 경험분포를 구성하는 근거를 늘립니다. 전자는 계산의 오차, 후자는 표집에서 오는 불확실성과 관련됩니다.
