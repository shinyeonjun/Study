ST05·3

일원 분산분석: 여러 평균을 한 번에 검정하기

세 방식의 평균 처리시간을 한꺼번에 비교합니다. 평균끼리 떨어진 정도를 각 방식 안의 흔들림과 나란히 두면, 왜 분산을 계산해서 평균을 검정하는지 보입니다.

이 장을 읽고 나면

  • 일원 ANOVA의 귀무가설과 독립·정규성·등분산 가정을 설명한다.
  • 집단 간·집단 내 제곱합, 자유도와 F통계량을 계산한다.
  • 전체 평균 검정과 특정 쌍 비교, 두 분산 검정을 구분한다.

요인 하나가 세 수준을 갖는다

세 가지 업무 방식 A, B, C를 비교합니다. 각 그룹에 서로 독립인 작업 세 건을 두고 처리시간(분)을 쟀습니다. 여기서 설명 요인은 ‘업무 방식’ 하나입니다. 세 수준이 있는 하나의 요인이므로 일원 분산분석(one-way ANOVA)이라고 합니다. 고전적인 검정의 H₀는 세 모집단 평균이 모두 같다는 것입니다. 대립가설은 평균이 다른 쌍이 적어도 하나 있다는 뜻입니다.

흔한 실수 · 두 표본 t검정을 쌍마다 반복하기

세 집단이면 쌍은 A–B, A–C, B–C 세 개입니다. 각각 α=0.05로 검정하면 '적어도 하나를 잘못 기각할' 확률이 0.05보다 커집니다. 세 검정이 독립이라고 단순화하면 1 − 0.95³ ≈ 0.143입니다. 실제 쌍별 비교는 같은 자료를 공유해 독립이 아니므로 값은 다르지만, 0.05를 넘는다는 점은 같습니다. 그래서 먼저 하나의 전체 F검정으로 '모두 같은가'를 묻고, 필요한 쌍 비교는 보정해서 따로 합니다.

흩어짐을 그룹 사이와 그룹 안으로 나눈다

전체 관측 평균은 5분입니다. 그룹 A의 평균 3은 전체 평균에서 −2, B는 0, C의 평균 7은 +2만큼 떨어져 있습니다. 각 평균이 대표하는 관측은 3건이므로 집단 간 제곱합은 3×(3−5)²+3×(5−5)²+3×(7−5)²=24입니다. 표본 수가 서로 다르면 각 그룹의 관측 수를 따로 곱합니다.

각 값에서 자기 그룹의 평균을 빼면 모든 그룹에서 −1,0,+1이 남습니다. 집단 내 제곱합은 2+2+2=6입니다. 각 값에서 전체 평균을 빼 구한 전체 제곱합 30은 앞의 24+6과 같습니다. 제곱합의 단위는 원래 시간 단위를 제곱한 분²입니다.

그룹 수 k=3, 전체 관측 수 N=9입니다. 집단 간 자유도는 k−1=2, 집단 내 자유도는 N−k=6입니다. 제곱합을 각각 자유도로 나눈 평균제곱은 12와 1입니다. 분자에 집단 간 평균제곱, 분모에 집단 내 평균제곱을 놓아 F통계량 12를 얻습니다. 귀무가설 아래에서 F분포의 오른쪽 꼬리를 보면 p=0.008입니다.

F를 이렇게 만드는 이유는 두 평균제곱이 각각 무엇을 추정하는지에 있습니다. 가정이 맞으면 집단 내 평균제곱은 H₀가 참이든 아니든 공통 오차 분산 σ²를 추정합니다. 집단 간 평균제곱은 H₀가 참일 때도 σ²를 추정하지만, 모집단 평균이 서로 다르면 그 차이만큼 커집니다. 그래서 H₀ 아래에서 F는 1 근처에 오고, 평균 차이가 클수록 오른쪽으로 커집니다. 기각역이 오른쪽 꼬리 하나뿐인 이유입니다. F분포는 분자 자유도와 분모 자유도 두 개로 정해지며, 여기서는 F(2, 6)입니다.

F가 크면 어떤 차이가 있다는 근거가 생긴다

이 예에서 0.05 기준으로 기각하면 세 모집단 평균이 모두 같다는 설명과 자료가 잘 맞지 않는다고 판단합니다. 어느 쌍이 다른지, 차이가 몇 분인지까지 전체 F검정 하나로 정할 수는 없습니다. 계획한 대비 또는 보정한 쌍별 비교가 추가로 필요합니다. 비교를 여럿 할 때의 오류는 다중비교에서 이어집니다.

자료의 흩어짐 중 집단 평균과 연결되는 몫을 나타내는 표본 효과크기로 η²=집단 간 제곱합/전체 제곱합을 쓸 수 있습니다. 이 표에서는 24/30=0.8입니다. 여기서 계산한 표본 설명 비율이며 같은 값이 새 자료에서 보장되거나 원인으로 설명된다는 뜻은 아닙니다. 평균 자체와 단위도 같이 적습니다. 예를 들어 관측 C−A 차이는 7−3=4분입니다.

고전적 F검정이 쓰는 조건을 본다

고전적 일원 ANOVA는 관측 사이의 독립, 각 집단의 정규 오차, 집단 사이의 같은 오차 분산을 가정합니다. 작은 그룹에서 이상치나 비대칭이 크면 주의합니다. 분산이 다른 독립 그룹에는 Welch ANOVA를 검토할 수 있습니다. 같은 사람이 여러 방식을 사용한 자료는 반복측정 설계를 다루는 방법이 필요합니다. 등분산성 여부를 같은 자료에서 한 번 검정하고 그 결과만으로 분석 절차를 자동 변경하면 최종 검정의 성질도 달라질 수 있습니다.

이름이 같은 분산 동등성의 F검정은 서로 독립인 두 정규 모집단에서 분산이 같은지를 묻습니다. 통계량은 두 표본분산 s₁²/s₂²입니다. 예로 9와 4라면 2.25입니다. 평균 동등성을 묻는 일원 ANOVA는 집단 간·내의 평균제곱을 사용합니다. 두 검정 다 F분포를 쓰지만 가설과 계산을 구분합니다.

from scipy import stats

groups = [[2, 3, 4], [4, 5, 6], [6, 7, 8]]
means = [sum(g) / len(g) for g in groups]
all_values = [value for g in groups for value in g]
grand = sum(all_values) / len(all_values)
between = sum(len(g) * (mean - grand) ** 2 for g, mean in zip(groups, means))
within = sum((value - mean) ** 2 for g, mean in zip(groups, means) for value in g)
df_between = len(groups) - 1
df_within = len(all_values) - len(groups)
result = stats.f_oneway(*groups)
assert abs((between / df_between) / (within / df_within) - result.statistic) < 1e-12
print("그룹 평균:", means, "전체 평균:", grand)
print(f"제곱합 간/내: {between:g}, {within:g} | 자유도 {df_between}, {df_within}")
print(f"F={result.statistic:.1f}, p={result.pvalue:.3f}, eta²={between / (between + within):.2f}")
그룹 평균: [3.0, 5.0, 7.0] 전체 평균: 5.0
제곱합 간/내: 24, 6 | 자유도 2, 6
F=12.0, p=0.008, eta²=0.80

한 줄 정리

일원 ANOVA는 집단 간 평균제곱을 집단 내 평균제곱으로 나눈 F로 '모든 평균이 같다'를 한 번에 검정하며, 기각 뒤에는 보정한 쌍 비교와 평균차·η²를 함께 본다.
