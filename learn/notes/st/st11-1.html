ST11·1

우도에서 자료의 순서와 충분통계량을 분리하기

성공 세 번이 관측되었을 때 두 기록의 순서가 다릅니다. 어떤 모형에서는 같은 우도가 나오고, 정규모형에서는 추정하려는 모수에 따라 보관해야 할 요약값이 달라집니다.

이 장을 읽고 나면

  • 결합확률과 로그우도를 베르누이와 정규 표본에서 직접 유도한다.
  • 충분성의 조건부분포와 인수분해를 연결한다.
  • 정규분산을 함께 추정할 때 평균 외의 정보가 필요한 이유를 계산한다.

관측을 고정하면 하나의 함수가 남는다

독립인 센서 점검 다섯 번에서 성공을 1, 실패를 0으로 기록합니다. Xi는 모두 같은 베르누이 모수 p를 가집니다. X 한 개가 정확히 x일 확률은 px(1−p)1−x입니다. 독립이면 다섯 확률을 곱할 수 있습니다. 아래에서 s=Σxi는 성공 수입니다.

L(p;x)=ps(1−p)n−s, ℓ(p;x)=s log p+(n−s) log(1−p) (0<p<1)

관측 순서가 10101이면 p=.6에서 우도는 .6³·.4²=.03456입니다. 11100도 같습니다. 순서 있는 기록 하나의 확률과 성공이 셋이라는 사건의 확률은 다릅니다. 후자는 같은 성공 수인 10개 기록의 확률을 더한 .3456입니다. 비교할 p에 공통인 10을 곱해도 우도의 최댓점은 바뀌지 않습니다. 우도는 관측을 고정하고 p에 따라 비교하는 함수이므로 p에 대한 확률분포로 해석하지 않습니다.

로그에서 기울기를 구하면 ℓ′=s/p−(n−s)/(1−p)입니다. 두 항을 합치면 분자가 s−np라서 0<s<n일 때 기울기는 p=s/n 전에는 양수, 뒤에는 음수입니다. 이 예에서는 p̂=3/5입니다. 성공 수가 0 또는 n이면 모수 공간의 경계를 따로 봅니다.

왜 성공 수만 남겨도 모수 정보가 보존될까

통계량 T가 충분하다는 것은, T를 알고 난 후 자료 X의 조건부분포에 모수가 남지 않는다는 뜻입니다. 위 모형에서 0<p<1라면 성공이 s번이라는 조건 아래 가능한 순서 각각의 조건부확률은 1/C(n,s)입니다. 따라서 순서를 버려도 p를 구별할 정보는 더 잃지 않습니다. 시점마다 p가 바뀌거나 실패 후 성공 가능성이 달라지는 모형을 쓰면 순서가 다른 정보를 줄 수 있습니다.

Neyman–Fisher 인수분해는 공통 기준인 계수측도 또는 길이측도에 대해 자료의 확률질량이나 밀도를 fθ(x)=gθ(T(x))h(x) 꼴로 쓸 수 있으면 T가 충분하다는 기준을 줍니다. h는 모수와 무관하고, 모수에 의존하는 부분은 T를 통해서만 자료를 읽습니다. 예를 들어 이산 모형에서 T=t인 자료만 모아 분모의 확률을 계산하면 gθ(t)Σ h(x)입니다. 이 사건의 확률이 양수라면 분자와 분모의 gθ(t)가 상쇄됩니다. 연속 자료에서도 대응하는 밀도와 조건부분포를 사용합니다. 모든 자료에 대해 같은 두 함수 꼴이 성립하는지 확인해야 합니다. 역방향도 성립합니다. T가 충분하면 이런 분해가 반드시 존재하므로, 인수분해는 충분성의 필요충분조건입니다.

정규 우도에서는 중심과 제곱합이 남는다

기기가 일정한 길이를 반복 측정한다고 합시다. 관측 단위는 한 번의 측정이며, 모형은 독립 N(μ,σ²), σ²>0입니다. 한 관측의 밀도 (2πσ²)−1/2 exp(−(x−μ)²/(2σ²))를 n번 곱하고 로그를 취합니다. 연속 자료는 밀도를 곱한 우도를 쓰며 관측한 점 자체의 확률은 0입니다.

ℓ(μ,σ²;x)=−(n/2) log(2πσ²)−[Σxi²−2μΣxi+nμ²]/(2σ²)

모수가 모두 미지라면 자료는 (Σxi,Σxi²)를 통해서만 식에 나타납니다. 같은 내용을 (x̄,Q), Q=Σ(xi−x̄)²로 둘 수 있습니다. σ²를 알고 μ만 모르면 제곱합 항을 모수에 무관한 부분에 넣을 수 있어 Σxi만으로 충분합니다.

각 표본에서 Σ(xi−μ)²=Q+n(x̄−μ)²입니다. 이 항이 최소인 μ̂=x̄를 먼저 넣습니다. v=σ²에 대한 기울기는 −n/(2v)+Q/(2v²)=(Q−nv)/(2v²)이므로 Q>0이면 최대우도 분산은 v̂=Q/n입니다. A에선 8/3 cm², B에선 2/3 cm²입니다. 두 표본에 공통인 μ를 어느 값으로 정해도 평균이 같아서 n(x̄−μ)²는 우도 비에서 상쇄됩니다. LA/LB=exp(−3/σ²)이므로 두 자료의 우도를 구별하려면 σ²에 관한 정보가 남아 있어야 합니다.

이어 풀기와 증명

하나의 요약에서 지워지는 정보를 직접 찾아봅니다. 증명에서는 어떤 양이 θ에 무관한지 표시하고, 새 자료의 최대우도는 로그 기울기로 해를 확인합니다.

파이썬으로 같은 계산 검산하기

from fractions import Fraction
from math import exp, log, pi

p = Fraction(3, 5)
for sample in [(1, 0, 1, 0, 1), (1, 1, 1, 0, 0)]:
    s = sum(sample)
    likelihood = p**s * (1 - p)**(len(sample) - s)
    print("Bernoulli:", s, likelihood, f"{float(likelihood):.5f}")

def normal_loglik(data, mean, variance):
    residual_ss = sum((x - mean)**2 for x in data)
    return -len(data) * log(2 * pi * variance) / 2 - residual_ss / (2 * variance)

a, b = (2, 4, 6), (3, 4, 5)
for data in [a, b]:
    n = len(data)
    mean = Fraction(sum(data), n)
    q = sum((x - mean)**2 for x in data)
    print("Normal:", mean, q, q / n)
for variance in [1, 3]:
    ratio = exp(normal_loglik(a, 4, variance) - normal_loglik(b, 4, variance))
    print("same mean, ratio:", variance, f"{ratio:.6f}")

실행 결과

Bernoulli: 3 108/3125 0.03456
Bernoulli: 3 108/3125 0.03456
Normal: 4 8 8/3
Normal: 4 2 2/3
same mean, ratio: 1 0.049787
same mean, ratio: 3 0.367879

A와 B의 비가 분산 1에서 약 .049787, 분산 3에서 약 .367879로 달라집니다. 실행값에서 우도를 옮겨 비교할 때는 같은 자료와 같은 모형의 모수를 비교합니다. 이 예의 자료는 요약의 차이를 드러내기 위해 만든 값입니다.

한 줄 정리

우도는 자료가 모수에 주는 비교 정보이고, 충분통계량은 그 정보를 잃지 않는 요약이다.
