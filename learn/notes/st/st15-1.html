ST15·1

표준화로 목표 모집단의 평균 인과효과를 구하기

새 검사 도구가 성공률을 높이는지 묻습니다. 두 도구를 쓰는 집단의 준비도가 다르면 성공률의 차이만으로는 효과를 읽을 수 없습니다. 참값을 아는 합성 모집단을 만든 뒤 표준화 결과와 대조합니다.

이 장을 읽고 나면

  • 목표 모집단·처리·결과·효과 척도를 먼저 정의한다.
  • 일치성·조건부 교환가능성·양성 조건에서 표준화 식을 유도한다.
  • 관측된 차이, 평균 처리 효과, 처리자 평균 효과를 따로 계산한다.

어떤 장비에 어떤 비교를 할지 먼저 정한다

모의 과제 성공을 기록하는 장비 하나를 관측 단위로 둡니다. 새 점검 도구 사용 여부를 A=1,0, 같은 시험에서의 성공 여부를 Y=1,0으로 기록합니다. 도구를 쓰기 전에 준비도 L=0,1을 정해 두었습니다. 장비 i에서 각 도구를 썼을 때 나올 잠재 결과는 Yi(1),Yi(0)입니다. 도구를 같은 방식으로 적용하고 한 장비의 도구가 다른 장비의 결과에 영향을 주지 않는 설정입니다.

대상 모집단은 준비도 낮음과 높음이 절반씩인 80대의 합성 모집단입니다. 평균 처리 효과(ATE)는 E[Y(1)]−E[Y(0)]입니다. 이 경우 성공확률의 차이를 써서 퍼센트포인트로 해석합니다. 실제 도구 사용자만 목표라면 E[Y(1)−Y(0)|A=1]인 처리자 평균 효과(ATT)가 됩니다. 결과를 본 뒤 유리한 목표를 골라 바꾸면 무엇을 확증한 것인지 모호해집니다.

합성 모집단은 준비도마다 독립으로 배정 번호 r=0~3과 잠재 점수 u=0~9의 모든 조합을 한 번씩 넣어 구성합니다. A=1은 준비도 낮음에서 r<1, 높음에서 r<3입니다. Y(0),Y(1)은 아래 확률이 나오도록 u의 경계로 정합니다. r과 u의 조합이 완전히 균형이어서 L이 주어지면 도구 배정과 두 잠재 결과가 독립입니다. 실측에서는 이 두 잠재 결과를 한 장비에서 함께 관측하지 못합니다.

관측량으로 목표를 표현하려면 무슨 가정이 필요한가

모집단에 대해 E[Y(a)]=ΣlP(L=l)E[Y(a)|L=l]라는 전기댓값 식을 씁니다. 그러나 오른쪽의 잠재 결과도 바로 관측하지 않습니다. 다음 조건에서 그 항을 관측한 평균으로 대체할 수 있습니다.

  • 일치성. 실제로 받은 도구가 a이면 관측 Y는 Y(a)입니다. 처리의 정의가 일관되어야 합니다.
  • 조건부 교환가능성. L이 같을 때 Y(a)의 분포가 A에 따라 다르지 않습니다. 그래서 E[Y(a)|L=l]=E[Y(a)|A=a,L=l]로 옮길 수 있습니다.
  • 양성. 목표 집단에서 비중이 있는 모든 L 층에 대해 P(A=a|L=l)>0가 필요합니다. 그래야 그 층에서 도구 a를 받은 결과를 비교에 사용할 수 있습니다.
E[Y(a)] = ΣlP(L=l) E[Y|A=a,L=l].

우변은 L이 낮은 그룹의 관측 평균과 높은 그룹의 관측 평균을 같은 목표 비중으로 평균합니다. 이것이 직접 표준화입니다. 위 식을 쓸 수 있게 만드는 가정을 식별이라고 부르고, 자료로 각 확률과 기대값을 계산하는 것이 추정입니다. 보통 식별에 필요한 미측정 교란 부재를 결과와 노출 표만으로 증명할 수는 없습니다.

우연히 앞서 있던 집단의 비중을 고쳐 계산한다

관측 평균을 그대로 비교하면 .75−.30=.45입니다. 표준화는 두 조건에 준비도 비중 (.5,.5)를 곱해서 사용 성공률 (.30+.90)/2=.60, 미사용 성공률 (.20+.60)/2=.40을 얻습니다. 두 값의 차이는 .20입니다. 실제 잠재 결과를 열거한 ATE와 일치합니다. 이 예에서는 유한 모집단을 모두 생성해 참값을 아는 것이며, 실제 소표본에선 이 계산도 표집 변동을 갖습니다.

사용자에게만 적용되는 ATT는 사용자 준비도 분포 (.25,.75)를 목표로 사용합니다. 두 층의 효과를 이 비중으로 평균하면 .25·.10+.75·.30=.25입니다. ATE와 다른 것은 오류가 아니라 적용하려는 모집단과 층별 효과가 다르기 때문입니다.

이어 풀기와 증명

잠재 결과를 고정한 합성 예제에서 참값을 아는 상황과 실제 자료에서 식별을 가정하는 상황을 구별합니다.

파이썬으로 같은 계산 검산하기

from fractions import Fraction as F
from itertools import product

rows = []
for l, u, r in product((0, 1), range(10), range(4)):
    a = int(r < (1, 3)[l])
    y0, y1 = int(u < (2, 6)[l]), int(u < (3, 9)[l])
    rows.append((l, a, (y0, y1)[a], y0, y1))

def mean(values):
    return F(sum(values), len(values))

truth = mean([y1-y0 for _,_,_,y0,y1 in rows])
means = {(l,a): mean([y for ll,aa,y,_,_ in rows if (ll,aa)==(l,a)])
         for l,a in product((0,1), repeat=2)}
crude = mean([y for _,a,y,_,_ in rows if a==1]) - mean([y for _,a,y,_,_ in rows if a==0])
standard = [sum(means[l,a] for l in (0,1))/2 for a in (0,1)]
treated_levels = [F(sum(l==ll and a==1 for l,a,_,_,_ in rows), 40) for ll in (0,1)]
att = sum(treated_levels[l]*(means[l,1]-means[l,0]) for l in (0,1))
assert truth == standard[1] - standard[0]
assert att == mean([y1-y0 for _,a,_,y0,y1 in rows if a==1])
print("rows:", len(rows))
print("crude:", crude)
print("standardized means:", *standard)
print("true and standardized ATE:", truth, standard[1]-standard[0])
print("ATT:", att)

실행 결과

rows: 80
crude: 9/20
standardized means: 2/5 3/5
true and standardized ATE: 1/5 1/5
ATT: 1/4

코드는 한 장비의 잠재 결과를 둘 다 생성하지만, 표준화에는 그중 실제 선택된 Y만 넣습니다. 둘 다 필요한 열은 모의 참값을 구해 추정 절차를 검산하는 데에만 사용합니다.
