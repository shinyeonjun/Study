다중회귀와 상호작용: 같은 조건에서 무엇이 달라지나

같은 요청 수에도 도서관 지점마다 대기시간이 다를 수 있습니다. 지점 차이가 일정한지, 요청 수가 많아질수록 더 벌어지는지 두 모형을 계산해 비교합니다.

이 장을 읽고 나면

  • 다중회귀에서 다른 설명변수를 고정한 계수의 의미를 읽는다.
  • 범주를 지시변수로 표현하고 상호작용이 만드는 기울기 차이를 구한다.
  • 설명변수의 중복과 관측 자료의 인과 해석 한계를 설명한다.

설명변수를 함께 넣되 각각 어떤 변화를 뜻하는지 적는다

한 구간의 관측에 요청 수 x(건), 지점 A 또는 B, 대기시간 y(분)가 있습니다. 작은 합성 자료를 사용합니다. 다중 선형회귀는 설명변수를 둘 이상 사용합니다. B를 1, 기준이 되는 A를 0으로 표시한 지시변수 g를 만들겠습니다.

먼저 상호작용 없이 ŷ=b₀+b₁x+b₂g를 맞춥니다. A는 b₀+b₁x, B는 (b₀+b₂)+b₁x가 됩니다. 지점이 같을 때 x가 한 건 늘면 b₁분씩 달라지고, x를 같은 값으로 둘 때 지점을 A에서 B로 바꾸어 비교하면 적합값 차이는 b₂입니다. 이 구조에서는 두 기울기가 같습니다.

한 변수의 효과가 다른 변수에 따라 달라진다

요청이 한 건 늘 때 나타나는 적합값 차이가 지점마다 다를 수 있게 ŷ=b₀+b₁x+b₂g+b₃(xg)를 사용합니다. 설명변수 두 개의 곱을 더하는 상호작용입니다. 식은 계수 b에 대해서는 여전히 선형이어서 같은 최소제곱 방법을 씁니다. A에서는 g=0이므로 x의 기울기가 b₁, B에서는 g=1이므로 b₁+b₃입니다.

이 예제는 상호작용 모형에서 (b₀,b₁,b₂,b₃)=(2,2,1,1)을 얻습니다. x가 한 건 늘 때 적합값은 A에서 2분, B에서 3분 늘어납니다. 같은 x에서 B−A는 b₂+b₃x=1+x분입니다. b₂는 x=0에서만 지점 간 차이입니다. 예를 들어 x를 x−2로 중심화하고 같은 모형을 적으면 새 지점 계수는 요청 수 2에서의 차이 3분이 되지만 두 적합선은 그대로입니다.

행렬의 한 행에 같은 관측의 항목을 둔다

각 관측을 [1, x, g, x*g]로 적습니다. 첫 1은 절편을 위한 항이고 나머지는 같은 구간의 값입니다. 이 설계행렬에 계수 벡터를 곱하면 적합값들을 한 번에 계산합니다. 지점 A의 열과 B의 열을 둘 다 만들고 절편도 넣으면 두 지시변수 합이 절편 열과 같아집니다. 이런 정확한 선형 중복이 있으면 계수가 하나로 정해지지 않을 수 있습니다. 이 예는 A를 기준으로 두고 B만 한 열에 넣었습니다. 열이 거의 중복되는 경우도 계수의 불확실성이 커질 수 있습니다.

두 모형을 같은 자료에 맞춰 본다

import numpy as np

x = np.tile([0, 1, 2, 3], 2)
g = np.repeat([0, 1], 4)
y = np.array([3, 3, 5, 9, 4, 5, 8, 13], dtype=float)
without = np.column_stack([np.ones(x.size), x, g])
with_interaction = np.column_stack([without, x * g])

for label, design in [("공통 기울기", without), ("상호작용", with_interaction)]:
    coefficient, _, rank, _ = np.linalg.lstsq(design, y, rcond=None)
    residual = y - design @ coefficient
    print(f"{label}: {[round(float(b), 2) for b in coefficient]}")
    print(f"랭크={rank}, SSE={residual @ residual:.2f}")

coef = np.linalg.lstsq(with_interaction, y, rcond=None)[0]
predictions = np.array([[1, 2, 0, 0], [1, 2, 1, 2]]) @ coef
print("요청 2건에서 A, B:", [round(float(v), 1) for v in predictions])
공통 기울기: [1.25, 2.5, 2.5]
랭크=3, SSE=10.50
상호작용: [2.0, 2.0, 1.0, 1.0]
랭크=4, SSE=8.00
요청 2건에서 A, B: [6.0, 9.0]

상호작용을 추가한 모형은 공통 기울기 모형을 특수한 경우로 포함하므로, 같은 자료에서 최소제곱 오차가 늘지는 않습니다. 이것만으로 실제 업무에서 그 항이 필요한지 판단할 수 없습니다. 두 지점에서 요청 수가 비슷한 범위에 걸쳐 관측되었는지 보고, 차이의 불확실성과 새 자료 성능도 확인합니다. ‘다른 설명변수를 고정한다’는 말은 비교에 사용한 모형의 조건을 뜻합니다. 관측되지 않은 직원 수 같은 교란을 통제하거나 지점 변경의 인과 효과를 보장하지는 않습니다.

한 줄 정리

다중회귀 계수는 모형에 넣은 다른 변수를 고정한 비교이고, 상호작용이 있으면 한 변수의 효과가 다른 변수 값에 따라 달라지므로 주효과 계수만 따로 읽지 않습니다.
