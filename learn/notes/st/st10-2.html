ST10·2

반복 측정의 단위를 정하고 묶음으로 재표집하기

같은 장비의 기록이 여러 줄이어도 어떤 단위에 같은 비중을 줄지가 남습니다. 장비 전체를 다시 뽑는 방법과 시간 구간을 이어 붙이는 방법을 비교합니다.

이 장을 읽고 나면

  • 같은 개체에서 얻은 여러 측정을 어떤 단위로 비교할지 정한다.
  • 개체에 같은 비중을 주는 평균과 측정별 평균을 계산한다.
  • 개체를 통째로 다시 뽑는 방법과 연속 시간 블록을 다시 뽑는 방법을 구별한다.

시간이 다른 두 기록이 같은 장비에서 나올 수 있다

업데이트 전후의 같은 시간대에서 장비의 처리 지연을 여러 번 잽니다. 한 장비에서 나온 값은 다른 장비의 값과 같은 구조를 갖지 않을 수 있습니다. 같은 장비의 기본 처리 속도나 가까운 시간대의 부하가 여러 기록에 함께 반영됩니다. 이를 반복 측정이라 합니다.

변화량은 각 짝의 업데이트 이후 지연에서 업데이트 이전 지연을 뺍니다. A의 짝별 변화가 [−2,−2]분, B는 [−1,−1,−1,−1]분, C는 [−3,−3]분이라고 합시다. 장비마다 변화의 평균을 만들면 −2, −1, −3분입니다. 흔히 한 행을 개체 한 개로 세는 분석부터 시작할 수 있지만, 먼저 보고 싶은 효과가 장비당 비교인지 작업당 비교인지 정합니다.

같은 수를 써도 묻는 평균이 다르면 비중이 달라진다

세 장비에 같은 비중이면 평균 변화는 (−2−1−3)/3=−2분입니다. 짝별 측정 여덟 개에 각각 같은 비중이면 (2×(−2)+4×(−1)+2×(−3))/8=−7/4=−1.75분입니다. B가 더 자주 측정됐기 때문에 둘째 결과에서 더 큰 비중을 얻습니다.

개체의 평균이 대상이라면 많은 관측을 가진 개체가 결과를 지배하지 않게 계산합니다. 그렇다고 장비마다 시간을 나눠 잰 횟수를 지울 필요는 없습니다. 서로 다른 시점의 추세가 중요하다면 개체와 시간 정보를 함께 표시합니다. 단순한 전후 관찰의 변화가 업데이트의 인과효과인지는 시간대, 부하 등 다른 변화도 살펴야 합니다.

같은 장비의 여러 기록을 서로 독립인 새 장비들처럼 세면, 효과의 불확실성을 실제보다 작게 추정할 수 있습니다. 장비를 동일한 모집단에서 같은 방식으로 서로 독립되게 표집했고 목표가 장비 평균이라면, 개체 단위 부트스트랩으로 장비 번호를 복원추출해 그 장비의 모든 기록을 함께 가져옵니다. 각 재표본에서 같은 평균을 다시 계산합니다. 한 장비가 두 번 뽑히면 그 장비의 전체 묶음도 두 번 들어갑니다.

하나의 시간열에서는 이웃한 값의 묶음을 다시 뽑는다

여러 독립 장비 대신 한 장비의 시간열 [2,3,3,5,4,6]만 있다고 합시다. 관측을 한 줄씩 복원추출하면 실제 이웃 관계가 흩어집니다. 같은 간격으로 관측된 시계열에서 이동 블록 부트스트랩은 연속한 길이 L의 구간을 후보로 만들고, 그 구간들을 복원추출해 이어 붙입니다. 길이 6에서 L=3이면 시작 위치는 1,2,3,4입니다.

그림처럼 시작 3의 [3,5,4]와 시작 1의 [2,3,3]을 뽑으면 재표본은 [3,5,4,2,3,3]입니다. 원하는 길이를 넘으면 끝을 잘라 맞출 수 있습니다. 짧은 블록은 먼 시차의 연결을 덜 보존합니다. 너무 긴 블록은 뽑을 서로 다른 후보와 이어지는 묶음 수가 작아집니다. 이 계산은 원래 시계열이나 모형의 잔차가 해당 방법의 정상성·의존 조건에 맞을 때 사용합니다. 원자료에 강한 추세가 있으면 추세를 함께 다루는 방법을 검토합니다.

실험의 블록은 배정 전에 비교를 맞추는 방법입니다. 시간의 블록 재표집은 이미 있는 관측에서 의존성을 일부 보존하며 불확실성을 계산하는 방법입니다. 미래 예측의 적합·검증 구간을 만드는 작업은 앞 장의 시간순 절차를 사용합니다.

두 평균과 두 종류의 재표집 단위를 비교한다

from fractions import Fraction
from itertools import product
from statistics import mean

changes = [[-2, -2], [-1, -1, -1, -1], [-3, -3]]
device_means = [mean(values) for values in changes]
all_changes = [value for values in changes for value in values]
print("device means:", device_means)
print("equal devices:", mean(device_means))
print("equal measurements:", Fraction(sum(all_changes), len(all_changes)))

resampled = list(product(device_means, repeat=len(device_means)))
means = [mean(draw) for draw in resampled]
print("device resamples:", len(means), "range:", min(means), max(means))

series = [2, 3, 3, 5, 4, 6]
length = 3
possible = [series[i : i + length] for i in range(len(series) - length + 1)]
drawn = possible[2] + possible[0]
print("moving blocks:", len(possible), "example:", drawn)
device means: [-2, -1, -3]
equal devices: -2
equal measurements: -7/4
device resamples: 27 range: -3 -1
moving blocks: 4 example: [3, 5, 4, 2, 3, 3]

세 장비에서 세 장비를 복원추출하는 순서 있는 경우를 전부 세면 27가지입니다. 마지막의 장비 평균 범위는 이 작은 예의 가능한 결과값을 본 것입니다. 실제 모집단에 대한 신뢰구간을 보고하기에는 이 예의 독립 장비 수가 적습니다.

한눈에 정리

자료 구조재표집이나 평균에 필요한 단위
독립 개체와 개체 내 반복개체를 다시 뽑고 그 개체의 자료를 함께 움직인다.
한 개의 시간 과정목적과 정상성 등을 확인하고 연속하는 구간 단위로 다시 뽑을 수 있다.
개체별 또는 활동별 평균어느 대상에 같은 비중을 주었는지 기록한다.

한 줄 정리

개체 안의 반복 측정이나 한 시간열의 이웃 값은 독립이 아니므로, 어느 단위에 같은 비중을 줄지 먼저 정하고 재표집도 개체 묶음이나 연속 블록 단위로 합니다.
