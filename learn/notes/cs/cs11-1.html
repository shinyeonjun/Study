CS11·1

다익스트라가 확정한 거리를 되돌리지 않아도 되는 이유

거리표의 숫자는 이미 찾은 경로의 비용입니다. 언제 그 값이 모든 경로 중에서도 가장 작은지, 확정 집합의 경계에서 증명합니다.

이 장을 읽고 나면

  • 후보 거리와 실제 최단거리의 관계를 정의한다.
  • 확정 집합의 첫 경계로 다익스트라를 귀납 증명한다.
  • 음수 간선 하나가 확정 규칙을 깨는 유한 반례를 계산한다.

찾은 경로의 비용은 참 최소 비용의 상계입니다

CS07의 다익스트라에서 현재 가장 작은 후보를 골랐습니다. 여기서는 그 즉시 확정하는 것이 왜 가능한지 봅니다. 방향 그래프에서 시작점 S에서 v까지의 최단 거리를 δ(v), 지금까지 찾은 가장 작은 경로 비용을 d(v)라 씁니다. 찾은 모든 값은 실제 경로에서 나왔으므로 d(v)≥δ(v)입니다. 경로를 찾지 못했다면 d(v)=∞로 표시합니다. 확정 집합은 더 짧은 값이 나올 수 없다고 증명한 정점들을 담습니다.

처음 S에서 비용 2인 정점 U와 비용 5인 V를 찾습니다. U를 꺼내면 V는 2+1=3으로 낮아지고 T에는 2+6=8을 기록합니다. V를 꺼내면 T는 3+2=5가 되어 마지막으로 확정합니다. 간선 완화는 d(v)가 실제 경로 비용이라는 성질을 보존합니다.

아직 값이 맞지 않는 경로는 경계를 먼저 지난다는 점을 씁니다

S의 0이 맞다고 놓고, 지금까지 확정한 모든 정점의 거리가 맞다고 가정합니다. 가장 작은 미확정 후보 u의 유한한 값 d(u)보다 짧은 S→u 경로가 있다고 합시다. 그 경로에서 확정 집합을 처음 떠나는 간선 a→v를 잡습니다. a는 이미 처리됐으므로 완화 시 d(v)≤d(a)+w(a,v)였습니다. d(a)는 참 최단 비용이어서 이 가상 경로의 a까지 비용 이하입니다. 따라서 d(v)는 적어도 그 경로의 v까지 비용보다 크지 않습니다.

남은 간선 비용은 모두 0 이상입니다. 가상 경로의 v까지 비용은 전체 비용 이하이므로 d(v)<d(u)가 됩니다. v도 아직 미확정인데 u가 최소 후보였으므로 모순입니다. v가 u 자신이어도 d(u)<d(u)가 되어 마찬가지로 모순입니다. 이로써 새 u의 거리도 맞아 귀납이 이어집니다. 0인 간선이 있어도 이 부등식에 문제가 없습니다. 미확정 후보가 전부 ∞라면 경계를 건널 유한 경로를 발견하지 못하는 상태이고, 더 확정할 도달 정점은 없습니다.

순환 없이도 음수 간선 하나가 반례를 만듭니다

아래 그래프에서 U까지 처음 비용은 2, V는 5입니다. U를 확정하고 T에 값을 4로 둔 뒤, V의 5보다 작아 T도 먼저 확정합니다. 그러나 V에서 U로 비용 −6인 간선이 있어 S→V→U→T의 참 비용은 5−6+2=1입니다. 첫 경계 V에 도달한 비용 5가 전체 1보다 큽니다. 위 증명에서 접두 비용이 전체 이하라는 단계가 바로 여기서 깨집니다.

후보 순서와 별도의 경로 열거를 대조합니다

from math import inf

regular = [("S","U",2),("S","V",5),("U","V",1),("U","T",6),("V","T",2)]
negative = [("S","U",2),("S","V",5),("V","U",-6),("U","T",2)]

def finalized(edges):
    d = dict.fromkeys("SUVT", inf)
    d["S"] = 0
    remaining = set(d)
    history = []
    while remaining:
        u = min(remaining,key=lambda v:(d[v],v))
        if d[u] == inf:
            break
        remaining.remove(u)
        history.append((u,d[u]))
        for a,b,w in edges:
            if a == u and b in remaining:
                d[b] = min(d[b], d[a]+w)
    return history, d["T"]

def simple_paths(edges, path="S", cost=0):
    if path[-1] == "T":
        yield cost,path
    else:
        for a,b,w in edges:
            if a == path[-1] and b not in path:
                yield from simple_paths(edges,path+b,cost+w)

for name,edges in [("regular",regular),("violated assumption",negative)]:
    print(name, finalized(edges), "all paths:", min(simple_paths(edges)))
regular ([('S', 0), ('U', 2), ('V', 3), ('T', 5)], 5) all paths: (5, 'SUVT')
violated assumption ([('S', 0), ('U', 2), ('T', 4), ('V', 5)], 4) all paths: (1, 'SVUT')

두 번째 실행은 전제를 어긴 규칙의 결과를 보여 주기 위해 의도적으로 한 것입니다. 예제의 그래프 두 개에는 음수 순환이 없으므로 첫째와 둘째 모두 단순 경로 열거를 검산에 쓸 수 있습니다. 일반적인 음수 간선을 다루려면 다음 장처럼 여러 차례 완화하거나 위상 순서를 이용합니다.
