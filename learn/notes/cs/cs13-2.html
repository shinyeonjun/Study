3-SAT을 독립집합과 정점 덮개로 바꾸기

논리식의 절마다 참이 되도록 고를 후보를 그래프 정점으로 만듭니다. YES가 YES로, NO가 NO로 옮겨지는 이유를 양방향으로 증명한 뒤 작은 논리식의 가능한 답을 직접 열거합니다.

이 장을 읽고 나면

  • 다항시간 다대일 환원의 정의와 합성 방향을 설명합니다.
  • 3-CNF의 절끼리 충돌하는 경우를 독립집합 간선으로 만듭니다.
  • 독립집합과 정점 덮개의 여집합 관계로 임계값을 변환합니다.

1. 원래 문제를 풀기 위해 대상 문제를 실행합니다

결정 문제 A를 B로 다항시간에 환원한다는 말 A ≤p B는 다항시간에 계산할 수 있는 함수 f가 있어서 모든 입력 x에 대해 x∈A ⇔ f(x)∈B라는 뜻입니다. B를 푸는 알고리즘을 가지고 x를 처리하려면 먼저 f(x)를 만들고 B의 답을 받습니다. f가 다항시간이라 출력 길이 역시 입력 길이의 다항식으로 제한됩니다. B의 결정기도 다항시간이라면 두 계산의 합성으로 A를 다항시간에 풉니다. 이미 NP-hard로 알려진 A를 B에 보내는 것이 B의 난이도를 전달하는 방향입니다.

변환이 YES의 경우만 보존하면, 모든 입력을 무조건 B의 같은 YES 입력으로 보내도 그 조건을 통과해 버립니다. 판정 결과가 일치하려면 NO의 경우에도 답이 보존되어야 합니다. 이를 증명할 때 YES 증명서를 두 방향으로 어떻게 옮기는지 보면 누락을 찾기 쉽습니다.

2. 절에서 하나씩 고르고 모순된 선택을 막습니다

불 변수 x와 그 부정 ¬x를 리터럴이라고 합니다. 절은 리터럴들의 OR입니다. 3-CNF는 여기에서 정확히 세 발생 위치를 갖는 절들의 AND이며, 같은 리터럴의 반복을 허용합니다. 3-SAT은 모든 절을 동시에 참으로 만드는 변수 배정이 존재하는지 묻습니다. 지금 계산할 입력은 다음과 같습니다.

(x ∨ y ∨ z) ∧ (¬x ∨ y ∨ ¬z) ∧ (x ∨ ¬y ∨ w)

무방향 그래프의 독립집합은 안에 든 두 정점 사이에 간선이 하나도 없는 정점 집합입니다. 절 개수를 m이라고 합시다. 리터럴 이름이 같아도 서로 다른 발생 위치는 정점을 따로 만들며 정점 수는 3m입니다. 같은 절의 세 정점은 세 간선으로 모두 연결합니다. 서로 다른 절에서는 같은 변수의 부호가 반대인 두 정점만 연결합니다. 질문은 이 그래프에 크기 적어도 m인 독립집합이 있느냐입니다.

논리식이 만족 가능하면 각 절에서 참인 리터럴을 하나씩 고를 수 있습니다. 서로 다른 절에서 하나씩만 고르므로 절 안 간선의 양 끝을 모두 고를 수 없습니다. 같은 참값 배정 아래 x와 ¬x가 동시에 참이 될 수 없으므로 절 사이 간선의 양 끝도 고르지 않습니다. 따라서 크기 m인 독립집합을 얻습니다.

반대로 크기 적어도 m의 독립집합을 받으면 절마다 최대 하나만 고를 수 있어 정확히 하나씩 고른 상태입니다. 어느 변수에서 x와 ¬x를 동시에 고르면 절 내 또는 모순 간선이 있으므로 그런 변수는 없습니다. 선택한 리터럴들이 참이 되도록 변수를 배정하고 나머지 변수는 아무 값으로 둡니다. 각 절은 자신이 고른 참 리터럴을 갖습니다. 예에서 그림 1대로 고르면 x와 y가 참이면 되고 z와 w는 어느 쪽이어도 됩니다. 정점 쌍 검사를 최대 (3m)²회 하고 각 리터럴 이름 비교는 원래 입력 길이 이하이므로 변환의 입력 시간과 출력 크기가 다항 범위입니다.

3. 독립집합의 여집합을 정점 덮개로 읽습니다

어떤 정점 집합 I가 독립집합이면 두 끝이 모두 I에 들어 있는 간선이 없습니다. 따라서 모든 간선에는 V∖I의 끝점이 하나 이상 있어 V∖I가 정점 덮개입니다. 같은 논증을 역으로 사용해, 정점 덮개의 여집합은 독립집합임을 확인할 수 있습니다. 그래서 크기 적어도 k의 독립집합 질문은 같은 그래프에서 크기 최대 |V|−k의 정점 덮개 질문으로 보낼 수 있습니다. 입력에서 k가 |V|보다 크다면 즉시 정해진 NO 입력을 내보내는 것으로 음의 한도를 피할 수 있습니다. 예제에서는 k=m=3이라 크기 상한이 9−3=6입니다.

3-SAT의 알려진 NP-완전성과 위의 변환을 합치면 독립집합과 정점 덮개에 NP-hard가 전달됩니다. 두 문제에 다항 검증기가 있습니다. 독립집합은 크기 조건과 간선의 양 끝이 모두 선택되는지, 정점 덮개는 크기 조건과 각 간선의 적어도 한 끝이 선택되는지 봅니다. 두 문제는 NP-complete입니다. 변환 코드는 논리식의 참값 배정이나 최적 덮개를 먼저 구하지 않습니다.

from itertools import combinations, product

def reduce_to_graph(clauses):
    vertices = [(i, lit) for i, row in enumerate(clauses) for lit in row]
    edges = []
    for a, b in combinations(range(len(vertices)), 2):
        i, lit = vertices[a]
        j, other = vertices[b]
        if i == j or lit == "!" + other or other == "!" + lit:
            edges.append((a, b))
    return vertices, edges

def verify_example(clauses):
    variables = sorted({lit.lstrip("!") for row in clauses for lit in row})
    assignments = [dict(zip(variables, bits))
                   for bits in product((False, True), repeat=len(variables))]
    def true(lit, values):
        return values[lit.lstrip("!")] != lit.startswith("!")
    sat = any(all(any(true(lit, val) for lit in row) for row in clauses)
              for val in assignments)

    vertices, edges = reduce_to_graph(clauses)
    positions = range(len(vertices))
    target = len(clauses)
    independent = [set(choice) for choice in combinations(positions, target)
                   if all(a not in choice or b not in choice for a, b in edges)]
    bound = len(vertices) - target
    cover = any(all(a in choice or b in choice for a, b in edges)
                for choice in combinations(positions, bound))
    assert sat == bool(independent) == cover
    print("vertices", len(vertices), "edges", len(edges),
          "SAT", sat, "IS", bool(independent), "VC", cover)
    if independent:
        chosen = sorted(independent[0])
        print("choice", [vertices[i] for i in chosen])

verify_example([("x","y","z"), ("!x","y","!z"), ("x","!y","w")])
verify_example([("x","x","x"), ("!x","!x","!x")])
vertices 9 edges 14 SAT True IS True VC True
choice [(0, 'x'), (1, 'y'), (2, 'x')]
vertices 6 edges 15 SAT False IS False VC False

예제의 `!`는 부정을 뜻합니다. 그래프 정점 번호는 정수 인덱스이고, 코드는 각 절 번호를 0부터 셉니다. 대조 검산에서는 변수 배정과 정점 집합을 따로 열거했습니다. 독립집합은 부분집합으로 줄일 수 있고 정점 덮개는 더 큰 정점 집합으로 늘릴 수 있어서 각각 경계 크기만 검사해도 됩니다. 반복 리터럴 예제의 두 절은 각각 x와 ¬x를 강제합니다. 그래프도 6개 정점이 서로 모두 인접하므로 독립집합 크기 2를 만들 수 없습니다.

한눈에 정리

핵심어기억할 기준
환원의 방향A ≤p B라면 B의 알고리즘을 이용해 A를 풀 수 있습니다.
절과 충돌한 절에서는 최대 한 리터럴을 고를 수 있고 절 사이의 반대 리터럴은 함께 고를 수 없습니다.
여집합크기 k 독립집합의 여집합은 크기 |V|−k인 정점 덮개입니다.

한 줄 정리

환원은 답을 계산하지 않고도 다른 표현으로 같은 YES·NO 질문을 만들 수 있습니다.
