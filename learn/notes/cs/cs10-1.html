정렬된 맵을 회전해 높이를 제한하기

검색 방향은 키의 순서로 정하고, 경로의 길이는 트리의 높이로 정합니다. 회전은 순서를 보존하면서 높이를 고치는 국소 연산입니다.

이 장을 읽고 나면

  • 이진 검색 트리의 전역 순서 불변식을 검사한다.
  • 단일·이중 회전 뒤에 중위 순회가 보존되는 이유를 설명한다.
  • AVL의 높이 상계와 무작위 입력 검산을 연결한다.

검색 순서와 높이 균형은 별도 조건입니다

이진 탐색 트리의 정렬된 맵에서는 노드에 키와 값을 둡니다. 한 노드의 왼쪽 서브트리 전부의 키는 현재보다 작고, 오른쪽 전부는 큽니다. 키가 같으면 새 노드를 만들지 않고 값을 교체한다고 하겠습니다. 왼쪽·노드·오른쪽 순으로 읽는 중위 순회에서 키가 증가해, 정렬된 순서와 검색이 같은 구조에 들어갑니다.

일반 탐색 트리는 10,20,30처럼 증가하는 키를 넣으면 한쪽에만 붙을 수 있습니다. AVL 트리는 여기에 각 노드의 왼쪽과 오른쪽 높이 차이가 절댓값 1 이하라는 조건을 둡니다. 빈 트리 높이는 0, 리프는 1입니다. 높이를 저장한 경우 서브트리가 바뀌면 부모 높이를 1+max(왼쪽,오른쪽)으로 고칩니다.

회전에서 바뀌는 연결만 따라가 봅니다

30의 왼쪽에 20이 있고 그쪽이 너무 높다고 합시다. 오른쪽 회전은 20을 올리고 30을 그 오른쪽으로 보냅니다. T₁은 20보다 작고, T₂는 20보다 크면서 30보다 작고, T₃는 30보다 큽니다. 회전 후 T₂를 30의 왼쪽에 붙여야 그 범위가 유지됩니다. 중위 순회 T₁,20,T₂,30,T₃가 그대로이므로 다른 조상에 대한 키 범위도 보존합니다.

30,20,10은 왼쪽 서브트리의 왼쪽이 높은 경우라 30을 오른쪽으로 한 번 회전합니다. 30,10,20은 왼쪽 자식 10의 오른쪽이 높은 경우입니다. 10을 먼저 왼쪽 회전한 뒤 30을 오른쪽 회전하면 20을 가운데로 올릴 수 있습니다. 오른쪽에서의 두 경우는 방향을 바꿔 대칭으로 고칩니다. 회전 뒤에는 상위 노드의 높이를 계산하기 전에 내려간 노드의 높이를 먼저 고칩니다.

그림에서 T₁,T₂,T₃ 높이가 각각 h+1,h,h인 경우를 수로 확인해 봅시다. 회전 전 20의 높이는 h+2이고 30의 두 자식 높이 차는 2입니다. 회전 후 30의 두 자식 T₂,T₃ 높이가 같아 30 높이는 h+1입니다. 새 루트 20의 두 자식 T₁과 30도 높이 h+1로 같아 두 위치의 균형이 회복됩니다.

높이 h를 유지하려면 노드가 얼마나 필요한지 봅니다

높이 h인 AVL 트리의 최소 노드 수를 N(h)라 합시다. h≥2라면 높이가 더 큰 쪽은 h−1이고 작은 쪽도 적어도 h−2입니다. 그래서 N(h)=1+N(h−1)+N(h−2)입니다. 최소를 달성하려면 두 자식에서 각각 해당 높이의 최소 트리를 선택합니다. N(0)=0, N(1)=1입니다. N이 높이에 따라 증가하므로 N(h)≥1+2N(h−2)입니다. 높이가 두 층씩 늘 때 최소한 두 배 규모의 노드가 필요해 높이는 O(log n)입니다. 한 키의 검색은 이 높이만큼 내려갑니다.

정렬된 목록과 저장 상태를 따로 검증합니다

from dataclasses import dataclass
from random import Random

@dataclass
class Node:
    key: int
    value: int
    left: "Node | None" = None
    right: "Node | None" = None
    h: int = 1

def height(node):
    return 0 if node is None else node.h

def refresh(node):
    node.h = 1 + max(height(node.left), height(node.right))

def balance(node):
    return height(node.left)-height(node.right)

def turn_right(node):
    child = node.left
    node.left, child.right = child.right, node
    refresh(node)
    refresh(child)
    return child

def turn_left(node):
    child = node.right
    node.right, child.left = child.left, node
    refresh(node)
    refresh(child)
    return child

def put(node, key, value):
    if node is None:
        return Node(key, value)
    if key == node.key:
        node.value = value
        return node
    if key < node.key:
        node.left = put(node.left, key, value)
    else:
        node.right = put(node.right, key, value)
    refresh(node)
    if balance(node) > 1:
        if balance(node.left) < 0:
            node.left = turn_left(node.left)
        return turn_right(node)
    if balance(node) < -1:
        if balance(node.right) > 0:
            node.right = turn_right(node.right)
        return turn_left(node)
    return node

def checked(node):
    if node is None:
        return [], 0
    left, a = checked(node.left)
    right, b = checked(node.right)
    assert all(k < node.key for k, _ in left)
    assert all(k > node.key for k, _ in right)
    assert abs(a-b) <= 1 and node.h == 1+max(a,b)
    return left + [(node.key,node.value)] + right, node.h

for keys in [(30,20,10), (10,20,30), (30,10,20), (10,30,20)]:
    root = None
    for k in keys:
        root = put(root,k,k)
    items, h = checked(root)
    print(keys, "root:", root.key, "inorder:", [k for k,_ in items])

keys = list(range(32))
Random(91).shuffle(keys)
root = None
baseline = {}
for k in keys + [7]:
    value = -1 if k in baseline else k*k
    root = put(root,k,value)
    baseline[k] = value
    assert checked(root)[0] == sorted(baseline.items())
print("random map:", len(baseline), "new value at 7:", baseline[7])

(10, 20, 30) root: 20 inorder: [10, 20, 30]
(30, 10, 20) root: 20 inorder: [10, 20, 30]
(10, 30, 20) root: 20 inorder: [10, 20, 30]
random map: 32 new value at 7: -1

작은 입력 네 개는 네 종류의 삽입 상황을 거칩니다. 무작위 순서를 쓰는 검산은 고정 시드로 항상 같은 사례를 만들고, 삽입마다 전체 정렬 순서와 각 높이·균형을 다시 계산합니다. 확률적 입력에 의존하지 않는 불변식의 증명과, 여러 입력을 실제로 확인하는 검산은 각각의 역할이 있습니다.
