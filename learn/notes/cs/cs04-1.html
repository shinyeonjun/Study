CS04·1

해시로 후보 위치를 찾고 충돌 처리하기

키에서 찾아볼 번호를 계산합니다. 번호가 같은 다른 키를 구별하고, 바구니에 값이 고르게 들어가는지에 따라 필요한 비교 수를 계산합니다.

이 장을 읽고 나면

  • 해시로 먼저 확인할 바구니를 정하고 나머지 예를 계산한다.
  • 서로 다른 두 키가 같은 곳에 들어갈 때 원래 키를 대조한다.
  • 고르게 분산된 모형의 평균 비용과 한 곳에 모인 최악 비용을 구분한다.

정렬 대신 키에서 확인할 위치를 계산한다

서랍 다섯 개에 숫자 꼬리표가 있는 기록을 둡니다. 키가 정수라면 먼저 key % 5를 계산해 0~4의 번호를 고를 수 있습니다. 이 장에서는 이 번호를 내는 규칙을 해시 함수, 각 저장 자리를 바구니라고 부르겠습니다. 실제 해시 테이블에서는 원래 키를 더 큰 해시값으로 바꾼 다음 저장소의 범위에 맞추어 위치를 정할 수도 있습니다.

12,7,17을 각각 5로 나눈 나머지는 모두 2입니다. 9의 나머지는 4입니다. 서로 다른 키가 같은 곳을 가리키는 일이 충돌입니다. 번호를 같게 얻어도 원래 키가 같은 것은 아닙니다.

한 바구니에 여러 후보를 두면 마지막에 동등성을 확인한다

이 예의 충돌 처리에는 분리 연결을 씁니다. 바구니마다 작은 목록을 두고 (원래 키, 값)을 저장합니다. 키 17을 찾을 때에는 먼저 바구니 2를 고르고, 저장된 12와 7을 건너 17을 확인합니다. 17에 연결한 값은 C이고, 동등성 비교는 세 번입니다.

키 22도 바구니 2에 갑니다. 저장된 세 후보와 모두 다르기 때문에 세 번 비교한 뒤 찾지 못합니다. 6은 빈 바구니 1을 고르면 키 비교 없이 끝납니다. 다른 충돌 처리에는 같은 자리에서 시작해 정해진 규칙으로 다른 자리를 확인하는 방식도 있습니다.

평균과 최악이 다른 이유를 바구니의 개수로 읽는다

키가 n개, 바구니가 m개일 때 평균 바구니 길이 n/m를 적재율이라고 합니다. 이 예는 n=4, m=5라 평균 길이는 0.8이지만 몇 바구니는 비고 바구니 2에는 3개가 있습니다.

각 키가 여러 바구니에 고르게 분포한다고 가정하고 해시 계산과 키 비교를 일정한 비용으로 보면, 분리 연결의 한 검색은 평균적으로 대략 1+n/m 크기의 비용을 기대할 수 있습니다. 첫 1은 위치를 계산해 확인하는 기본 동작을 포함합니다. n이 늘 때 바구니 수도 늘려 적재율을 상수 수준으로 유지한다면 평균 시간은 O(1)입니다.

고르다는 가정이 어긋나 한 바구니에 키가 몰리면 최악에는 n개를 다 볼 수 있어 O(n)입니다. 간단한 key % 5에 모두 5의 배수를 넣으면 실제로 이 현상이 생깁니다. 길이가 긴 문자열 등에서 키 자체의 해시와 비교 비용이 커질 수 있다는 점도 고려합니다.

바구니와 찾기에 든 비교 횟수를 출력한다

buckets = [[] for _ in range(5)]
for key, value in [(12, "A"), (7, "B"), (17, "C"), (9, "D")]:
    buckets[key % len(buckets)].append((key, value))

def lookup(key):
    chain = buckets[key % len(buckets)]
    comparisons = 0
    for stored, value in chain:
        comparisons += 1
        if stored == key:
            return value, comparisons
    return None, comparisons

print("bucket keys:", [[key for key, _ in chain] for chain in buckets])
for key in (17, 22, 9, 6):
    print(key, lookup(key))
bucket keys: [[], [], [12, 7, 17], [], [9]]
17 ('C', 3)
22 (None, 3)
9 ('D', 1)
6 (None, 0)

코드는 충돌을 설명하기 위해 만든 분리 연결 예입니다. Python의 딕셔너리에서 키가 실제로 같은 표 번호에 저장된다고 간주하지 않습니다. 해시 계산을 제외한 키 비교 횟수만 따로 출력합니다.
