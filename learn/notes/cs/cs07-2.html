CS07·2

가중치가 다르면 다익스트라로 먼저 확정할 거리를 고른다

가중치가 모두 0 이상인 길에서 지금 가장 가까운 정점을 하나씩 확정합니다. 먼저 발견한 길이 나중에 더 짧아질 수 있음을 확인합니다.

이 장을 읽고 나면

  • 경로 비용을 간선 가중치의 합으로 계산한다.
  • 후보 거리를 완화하면서 최단경로를 복원한다.
  • 비음수 조건과 우선순위 큐의 역할을 설명한다.

경로에서 몇 번 움직였는지와 비용의 합을 구분한다

화살표마다 이동 비용이 붙은 그래프에서 경로의 길이는 비용의 합입니다. A→B 직행은 간선 하나지만 5가 듭니다. A→C→B는 간선 두 개에 1+2=3만 듭니다. 모든 링크의 비용이 같을 때처럼 간선 수만 세면 더 싼 경로를 고르지 못할 수 있습니다.

이 장에서 다익스트라 알고리즘이 받는 가중치는 유한한 0 이상 수입니다. 거리의 시작값은 A에는 0, 다른 정점에는 아직 경로가 없음을 나타내는 ∞로 둡니다. 실습에서는 정수 비용을 사용하고 시작점에서 도달하지 못하는 F도 포함합니다.

지금 가장 작은 후보를 확정하고 그 이웃을 갱신한다

A를 선택하면 B까지 5, C까지 1이라는 후보를 얻습니다. 다음에 가장 가까운 C(1)를 고릅니다. C를 통해 B로 가면 1+2=3으로 기존 5보다 적습니다. D는 6, E는 9를 얻습니다. 이렇게 거리[u]+비용(u,v)가 현재 거리[v]보다 작을 때 갱신하는 것을 완화라고 합니다.

다음에 B(3)가 D를 4로 줄이고, D(4)가 E를 6으로 줄입니다. 아직 확정되지 않은 정점 중 후보가 가장 작은 정점은 이보다 싸게 갈 수 없습니다. 더 싼 경로가 있다면 이미 확정한 쪽에서 벗어나는 첫 간선 뒤의 정점에 그만큼 작은 후보가 기록됐어야 합니다. 남은 간선 비용은 0 이상이어서 그 경로의 뒷부분에서 이미 지불한 비용을 줄일 수도 없습니다.

우선순위 큐에서 오래된 후보를 넘긴다

최소 힙에는 (후보 거리, 정점)을 넣습니다. B의 새 거리 3을 넣어도 예전 후보 5가 힙에 남습니다. 5가 나중에 꺼내지면 표의 3과 달라서 건너뜁니다. 더 좋은 후보를 발견할 때 바로 이전 정점도 기록하면 마지막 E에서 A까지 거꾸로 경로를 얻습니다.

from heapq import heappush, heappop
from math import inf

graph = {"A": [("B", 5), ("C", 1)], "B": [("D", 1)],
         "C": [("B", 2), ("D", 5), ("E", 8)], "D": [("E", 2)],
         "E": [], "F": []}

def dijkstra(edges, start):
    if any(weight < 0 for row in edges.values() for _, weight in row):
        raise ValueError("edge weights must be nonnegative")
    best = dict.fromkeys(edges, inf)
    best[start] = 0
    parent = {start: None}
    heap = [(0, start)]
    while heap:
        cost, node = heappop(heap)
        if cost != best[node]:
            continue
        for nxt, weight in edges[node]:
            alt = cost + weight
            if alt < best[nxt]:
                best[nxt] = alt
                parent[nxt] = node
                heappush(heap, (alt, nxt))
    return best, parent

best, parent = dijkstra(graph, "A")
route = []
current = "E"
while current is not None:
    route.append(current)
    current = parent[current]
print("distances:", [best[node] for node in graph])
print("path to E:", " -> ".join(reversed(route)))
print("F reachable:", best["F"] < inf)
distances: [0, 3, 1, 4, 6, inf]
path to E: A -> C -> B -> D -> E
F reachable: False

부호 조건은 필수입니다. 예로 A→B의 비용 2, A→C의 비용 4, C→B의 비용 −3이면 B를 비용 2로 먼저 확정할 수 없습니다. C를 거쳐 1에 가는 길이 뒤에 있습니다. 음수 간선이 있는 문제에서는 그 조건을 지원하는 다른 알고리즘을 사용합니다. 실습의 경로 복원은 E가 도달 가능하다는 것을 알고 실행합니다. 임의 목적지라면 먼저 거리나 부모 표에서 도달 여부를 확인합니다.

V개 정점을 거리 표에 두고, E개 간선의 완화 시도마다 힙에 후보를 최대 한 번 넣습니다. 이 구현은 옛 후보도 넣어 두어서 힙에 O(E+1)개까지 들어갈 수 있습니다. 간선이 하나 이상일 때 전체 시간은 O(V+E log(E+1)), 입력 외 공간은 O(V+E)입니다.
