CS06·1

어떤 키로 정렬하고 동점 순서는 어떻게 남길까

한 기록에 이름과 우선순위가 함께 있습니다. 우선순위가 같을 때 이름이 원래 나타난 차례를 지키는 정렬을 구현해 봅니다.

이 장을 읽고 나면

  • 비교에 쓸 키와 줄 전체를 구분한다.
  • 같은 키의 순서로 안정 정렬을 확인한다.
  • 두 정렬된 목록을 합치는 규칙과 비용을 설명한다.

비교에는 키를 쓰고 이동할 때는 기록 전체를 옮긴다

작업 기록이 (이름, 우선순위)이고 입력 순서가 A·2, B·1, C·2, D·1이라고 합시다. 우선순위가 작은 것부터 보려면 2나 1만 비교하되 원래 이름도 함께 옮깁니다. 비교에 꺼내 쓰는 값이 정렬 키입니다. 이름 순서를 기준으로 쓰면 같은 입력에서도 다른 결과가 나옵니다.

동점에서 들어온 순서도 중요하다면 원래 B가 D보다 먼저, A가 C보다 먼저라는 사실을 유지해야 합니다. 같은 키의 기록끼리 입력의 상대 순서를 보존하는 정렬이 안정 정렬입니다. B,D,A,C와 D,B,C,A 모두 키는 1,1,2,2로 정렬돼 있지만, 이 입력에서 동점 순서를 지키는 결과는 B,D,A,C입니다.

두 정렬된 부분에서 앞의 기록끼리만 비교한다

병합 정렬은 작은 부분을 먼저 정렬하고 합치는 분할 정복입니다. 왼쪽 A·2,B·1을 정렬해 B·1,A·2가 되고, 오른쪽 C·2,D·1은 D·1,C·2가 됩니다. 두 부분의 맨 앞인 B와 D는 키가 같으므로 왼쪽의 B를 먼저 쓰겠습니다. 왼쪽은 입력에서 앞선 구간이기 때문입니다. 이어 A(키 2)와 D(키 1)를 비교해 D, A와 C가 동점이면 A, 마지막에 C를 씁니다.

부분 안에서 이미 정해 둔 순서는 앞에서부터 읽으면 유지됩니다. 부분을 가로지르는 동점도 왼쪽부터 고르면 먼저 나온 쪽이 앞으로 옵니다. 길이 0 또는 1인 부분은 이미 안정적으로 정렬됐으므로, 이 규칙을 모든 병합에 적용하면 전체도 안정적입니다.

비교 키와 동점 처리 규칙을 코드에서 확인한다

아래 함수는 두 인덱스를 앞에서부터 전진시킵니다. <=의 등호가 동점에서 왼쪽을 고르게 만듭니다. 한 부분을 다 소모하면 상대쪽 나머지를 그대로 붙일 수 있습니다. 균형 있게 나눌 경우 층마다 합치는 기록 수가 전체 n개이며, 층 수가 로그 규모여서 시간은 Θ(n log n)입니다. 이 구현은 결과를 새로 만드는 배열과 부분 목록을 함께 사용해 추가 저장이 필요합니다.

def by_priority(row):
    return row[1]

def stable_merge_sort(rows):
    if len(rows) < 2:
        return rows[:]
    mid = len(rows) // 2
    left = stable_merge_sort(rows[:mid])
    right = stable_merge_sort(rows[mid:])
    merged = []
    i = j = 0
    while i < len(left) and j < len(right):
        if by_priority(left[i]) <= by_priority(right[j]):
            merged.append(left[i])
            i += 1
        else:
            merged.append(right[j])
            j += 1
    merged.extend(left[i:])
    merged.extend(right[j:])
    return merged

rows = [("A", 2), ("B", 1), ("C", 2), ("D", 1)]
result = stable_merge_sort(rows)
print("keys:", [key for _, key in result])
print("records:", [name for name, _ in result])
assert result == sorted(rows, key=by_priority)
keys: [1, 1, 2, 2]
records: ['B', 'D', 'A', 'C']

Python의 sorted와 list.sort는 둘 다 안정 정렬을 보장합니다. 정렬한 복사본이 필요하면 sorted, 원래 목록을 바꿔도 되면 list.sort를 선택합니다. 이 예의 함수는 병합 원리를 보여 주기 위한 구현입니다. 실제 두 내장 기능이 여기와 똑같은 방식으로 동작한다고 가정할 필요는 없습니다.
