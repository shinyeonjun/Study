CS02·2

평균 비용, 미리 계산한 합과 실제 병목

보통 몇 번 비교하는지는 입력이 어떻게 들어오는지에 달려 있습니다. 계산을 미리 저장하는 방법을 써 보고, 연산 수와 실행 시간의 의미도 구분합니다.

이 장을 읽고 나면

  • 입력 발생 가정을 세우고 비교 횟수의 평균을 계산한다.
  • 구간 합을 반복 계산할 때 앞서 저장한 값이 얼마나 시간을 줄이는지 구한다.
  • 연산 횟수, 실제 측정 시간, 병목을 구분한다.

평균을 말하려면 어떤 입력이 자주 나오는지 적는다

길이 n인 목록에서 찾을 값을 미리 정하고, 앞에서부터 비교한다고 합시다. 일치하는 칸이 반드시 하나이며 그 위치가 0부터 n−1까지 똑같이 가능하다고 가정합니다. 각 위치에서 처음 일치까지 비교할 횟수는 1,2,…,n입니다. 그 평균은 (n+1)/2입니다. 항상 맨 앞에 나타나는 입력이면 평균이 1인 별도의 모형입니다.

n=8이고 찾는 값이 없는 경우가 1/4이면, 그때는 언제나 8회 비교합니다. 있는 3/4에서는 같은 위치 분포를 가정해 평균 4.5회입니다. 평균 비용을 계산할 때는 두 경우에 각각 확률을 곱해 더합니다.

이 예에서 최악은 8회입니다. n이 커져도 같은 확률 규칙을 두면, 평균 역시 n에 비례해 커집니다. 평균과 최악은 모두 어떤 연산을 세는지와 어떤 입력 범위에서 말하는지 적어야 합니다.

구간 합을 자주 묻는다면 계산한 값을 남겨 둔다

목록 A=[2,5,1,4]에서 위치 left부터 right 직전까지의 합을 구합니다. 한 번만 묻는다면 해당 값을 그 자리에서 하나씩 더할 수 있습니다. 같은 목록에서 여러 구간을 반복해 묻는다면, 앞에서부터의 합을 미리 보관해도 됩니다.

P[0]=0이고 P[i]는 처음 i개를 더한 합이라고 정합니다. 이 누적합은 [0,2,7,8,12]입니다. A[1:4]에서 두 번째 값부터 끝까지는 5+1+4=10입니다. P[4]=12에서 앞에 끼어 있는 첫 값의 합 P[1]=2를 빼도 10입니다.

고정된 목록의 P를 만드는 데 n회 더하기와 n+1개의 저장 자리가 필요합니다. 이후 0≤left≤right≤n인 한 쿼리는 두 값을 읽어 차를 구합니다. 정수의 비교·덧셈과 위치 읽기를 상수 비용으로 볼 때, 준비 단계가 Θ(n), 한 쿼리가 Θ(1), 보조 저장 공간은 Θ(n)입니다. left=right이면 빼는 값이 같아 빈 구간의 합 0입니다.

한 번 묻고 마치거나, 원본이 바뀌어 P를 자주 다시 만들어야 하면 같은 준비가 오히려 더 큰 비용일 수 있습니다.

실제 시간에서 가장 오래 걸리는 부분을 먼저 찾는다

비교 횟수는 기기와 무관한 모형에서 세지만, 실제 시간은 언어 구현, 데이터 배치, 메모리 접근, 입출력, 하드웨어 등에 영향을 받습니다. 수가 아주 커지면 덧셈 한 번에도 더 많은 자리가 필요합니다. 같은 입력 크기에서 같은 연산 수라는 사실만으로 같은 실행 시간을 약속할 수 없습니다.

예로 한 작업에서 파일 읽기 200ms와 비교 20ms가 차례로 들었다고 합시다. 다른 비용이 그대로이고 비교만 10배 빨라지면 전체가 220ms에서 202ms로 줄어듭니다. 이 과정의 병목을 찾으려면 어떤 단계가 전체 시간의 많은 부분을 차지하는지 먼저 잽니다.

원할 때 Python의 perf_counter() 등으로 일정 구간의 경과 시간을 측정할 수 있습니다. 입력 크기와 분포, 장치·버전, 포함한 구간을 고정하고 반복합니다. 입력을 다시 만드는 시간이나 파일을 읽는 시간을 어디에 넣었는지도 적습니다. 아래 계산은 성능 측정 대신 비교 모형의 평균과 누적합을 확인합니다.

평균과 누적합 쿼리를 순수한 연산으로 검산한다

from fractions import Fraction

n = 8
absent = Fraction(1, 4)
if_present = Fraction(sum(range(1, n + 1)), n)
overall = absent * n + (1 - absent) * if_present
print("mean comparisons:", if_present, overall)

a = [2, 5, 1, 4]
prefix = [0]
for value in a:
    prefix.append(prefix[-1] + value)
print("prefix:", prefix)
for left, right in [(0, 2), (1, 4), (2, 2)]:
    total = prefix[right] - prefix[left]
    assert total == sum(a[left:right])
    print(left, right, total)
mean comparisons: 9/2 43/8
prefix: [0, 2, 7, 8, 12]
0 2 7
1 4 10
2 2 0

첫 출력의 9/2는 대상이 있을 때의 평균, 43/8은 없을 수도 있을 때의 평균입니다. 뒤의 출력은 각 범위의 시작과 끝, 그리고 합입니다.
