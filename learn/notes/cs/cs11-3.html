가장 싼 신장 트리를 컷과 교환으로 검증하기

모든 기기를 연결하는 데 드는 전체 설치비를 최소화합니다. 한 출발점에서 각 기기까지 이동하는 비용을 최소화하는 문제와 먼저 목적함수를 구분합니다. 작은 그래프에서 컷에서 안전한 간선을 고르고 이미 만들어진 신장 트리가 최적인지 확인합니다.

이 장을 읽고 나면

  • 연결 그래프, 신장 트리, 컷의 정의와 비용을 설명합니다.
  • 컷에서 가장 가벼운 간선의 안전성을 교환으로 증명합니다.
  • 트리 밖의 간선을 넣어 생기는 경로로 최소성의 필요충분조건을 확인합니다.

1. 정점은 다 쓰고 간선 비용은 한 번씩 셉니다

연결된 무방향 그래프에서 신장 트리는 모든 정점을 포함하고, 연결되어 있으며, 사이클이 없는 부분 그래프입니다. 정점이 V개라면 신장 트리의 간선은 V−1개입니다. 한 모서리의 비용은 한 번씩 들어가므로 설치비는 트리 간선들의 가중치 합입니다. 이 합을 최소로 만드는 트리가 최소 신장 트리(MST)입니다.

가령 S–A와 S–B가 각각 4, A–B가 1입니다. S에서 각 정점까지 최단거리만 생각하면 S–A와 S–B를 쓰면 두 거리가 4입니다. 설치비는 8입니다. 설치비를 5로 줄이려면 S–A와 A–B를 고를 수 있습니다. 그때 S에서 B까지는 5입니다. 어떤 결과가 맞는지는 문제에서 거리를 각 목적지별로 비교하는지, 설치비를 전체에 대해 한 번 합하는지에 달려 있습니다.

2. 컷을 건너는 간선과 교환 증명

컷은 전체 정점 집합을 서로 겹치지 않는 두 비어 있지 않은 부분 S와 그 여집합으로 나눈 것입니다. 양 끝점이 서로 다른 부분에 있을 때 간선이 컷을 건넌다고 합니다. 연결 그래프의 신장 트리는 어떤 컷이든 한 번 이상 건너야 합니다. 예제에서 S={A}로 두면 그 컷을 건너는 후보는 AB(1)와 AC(4)입니다.

어떤 컷에서 가장 가벼운 간선 e와 최소 신장 트리 T를 고릅니다. e가 T에 없으면 T 안에서 e의 양 끝점을 잇는 유일한 경로가 있습니다. 그 경로는 두 편을 오가므로 컷을 건너는 간선 f를 적어도 하나 포함합니다. T에 e를 넣으면 그 경로와 e로 이루어진 유일한 사이클이 생깁니다. 그 사이클의 f를 빼면 여전히 연결되고, 사이클도 사라집니다. e가 컷에서 가장 가벼워서 w(e)≤w(f)이므로 새 트리는 최소 신장 트리입니다. e가 유일한 최솟값이면 언제나 w(e)<w(f)이고, e를 빼고 있던 최소 트리의 비용을 줄일 수 있다는 모순이 생깁니다. 이 경우에는 모든 MST가 e를 포함합니다.

Prim은 현재 트리의 정점 집합이 만드는 컷에서 가장 가벼운 간선을 고릅니다. Kruskal은 전체 간선을 비용순으로 보면서 서로 다른 연결 성분을 잇는 간선을 추가합니다. Kruskal에서 현재 한 성분의 정점들을 컷 한편으로 두면, 이미 건너뛴 간선 가운데 그 컷을 건너는 것은 없습니다. 한 번 같은 성분 안에 든 정점들은 이후에도 같은 성분에 남으며, 앞서 선택한 간선도 그 컷을 건넜다면 이미 두 끝점이 같은 성분이었을 것입니다. 이 컷에는 앞서 선택한 간선이 걸려 있지 않으므로 교환은 지금까지 고른 간선들을 보존할 수 있습니다. 동률이 생기면 두 방법 모두 일정한 순서를 두어 결과를 재현할 수 있습니다.

3. 후보 트리 하나만으로 검증하기

트리 T에 없는 간선 e=(u,v)에 대해 T 안의 u에서 v까지 경로에서 가장 큰 가중치를 MT(u,v)로 둡니다. 다음 부등식이 모든 트리 밖 간선에 대해 성립하면, 그리고 그럴 때만 T는 최소 신장 트리입니다.

w(e) ≥ MT(u,v)   (모든 e∉T)

부등식이 깨지면 e를 넣고 경로 위 최댓값 간선을 빼서 비용을 줄입니다. 반대로 부등식이 모두 성립한다고 두고 임의의 최소 트리 M을 하나 잡습니다. 후보 T에만 있는 간선 f를 제거했을 때 T가 갈라지는 두 부분을 봅니다. M에서 f의 양 끝점을 잇는 경로도 그 컷을 건너므로 교차 간선 e를 고를 수 있습니다. T 중에서 이 컷을 건넘직한 간선은 f뿐입니다. f∉M이므로 e∉T입니다. T에서 e의 양 끝점을 잇는 경로에는 f가 들어 있어 w(e)≥w(f)입니다. 따라서 M에서 e를 빼고 f를 넣어도 최소 비용을 유지합니다. T와 공통 간선이 하나 늘어났으므로 이 교환을 반복하면 최소 비용인 상태로 T에 도달합니다.

트리 밖 간선후보 AB·BC·CD 안의 경로경로 최댓값판정
AC, 비용 4A–B–C2통과
BD, 비용 5B–C–D3통과

아래에서는 모든 간선 3개 조합을 확인하는 방법과 트리 밖 경로의 최댓값을 대조하는 방법을 따로 실행합니다. 경로 최댓값을 시작값 0으로 두면 음수만 있는 경로에서 잘못 계산할 수 있습니다. 코드는 빈 경로에서만 음의 무한대를 사용합니다.

from itertools import combinations

vertices = set("ABCD")
edges = [("A","B",1), ("A","C",4), ("B","C",2),
         ("B","D",5), ("C","D",3)]
candidate = [edges[i] for i in (0, 2, 4)]
expensive = [edges[i] for i in (0, 1, 4)]

def neighbors(tree):
    adj = {u: [] for u in vertices}
    for u, v, w in tree:
        adj[u].append((v, w))
        adj[v].append((u, w))
    return adj

def connected(tree):
    adj = neighbors(tree)
    seen, stack = {"A"}, ["A"]
    while stack:
        for v, _ in adj[stack.pop()]:
            if v not in seen:
                seen.add(v)
                stack.append(v)
    return seen == vertices

def cycle_checks(tree):
    adj = neighbors(tree)
    for u, v, w in edges:
        if (u, v, w) in tree:
            continue
        stack = [(u, None, float("-inf"))]
        while stack:
            pos, prev, biggest = stack.pop()
            if pos == v:
                yield u + v, w, biggest
                break
            for nxt, weight in adj[pos]:
                if nxt != prev:
                    stack.append((nxt, pos, max(biggest, weight)))

cost = lambda tree: sum(w for _, _, w in tree)
best = min(cost(tree) for tree in combinations(edges, 3) if connected(tree))
for tree in (candidate, expensive):
    tested = list(cycle_checks(tree))
    fails = [key for key, w, biggest in tested if w < biggest]
    print(cost(tree), tested, "fails", fails)
print("enumerated minimum", best)
6 [('AC', 4, 2), ('BD', 5, 3)] fails []
8 [('BC', 2, 4), ('BD', 5, 4)] fails ['BC']
enumerated minimum 6

검산 코드는 신장 트리임을 앞에서 확인한 후보만 경로 검사에 넘깁니다. 일반 입력을 받는 검사기라면 먼저 정점 포함, 연결, 간선 수 V−1을 확인해야 합니다. 후보를 빠르게 만드는 일과 비용이 최소인지 증명하는 일을 이렇게 분리할 수 있습니다.
