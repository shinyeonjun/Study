CS01·1

입력·출력 계약과 처음 찾는 절차

목록에서 처음 기준 이상이 되는 위치를 찾습니다. 값을 반환할지 위치를 반환할지부터 정하고, 그 약속을 의사코드와 함수로 옮깁니다.

이 장을 읽고 나면

  • 문제의 입력 조건과 반환값을 계약으로 적는다.
  • 처리 순서와 분기를 의사코드로 표현한다.
  • 작은 입력에서 반환 위치를 확인하고, 찾지 못한 경우를 처리한다.

코드를 쓰기 전에 무엇을 만들지 약속한다

센서가 보낸 숫자 기록에서 처음으로 기준에 도달한 위치를 찾습니다. 기준이 7이고 목록이 [3,1,7,7,2]라면 답의 값은 7이고, 위치는 2입니다. 값과 위치 중 어떤 것을 돌려줄지 먼저 정해야 호출하는 코드가 결과를 사용할 수 있습니다.

계약의 입력 조건은 비교할 정수의 유한한 목록과 정수 기준값입니다. 빈 목록도 허용합니다. 출력 조건은 기준 이상인 값이 있으면 그중 가장 작은 0부터 센 위치, 없으면 −1입니다. 목록의 앞뒤 순서는 입력으로 주어집니다. 정렬된 목록만 받는다는 조건은 두지 않습니다. 실행에서 목록도 바꾸지 않기로 합니다.

이렇게 필요한 입력을 적은 것을 전제조건, 올바른 출력과 입력 보존 등 실행 후 약속을 후조건이라고 부를 수 있습니다. 이 예의 코드가 전제에 맞지 않는 모든 문자열이나 결측값을 어떻게 다루는지까지 약속한 것은 아닙니다.

의사코드로 비교하는 순서를 드러낸다

알고리즘은 입력을 받아 결과를 얻는 정해진 절차입니다. 각 단계가 모호하지 않고, 허용된 모든 입력에서 유한한 단계 뒤에 끝나야 합니다.

정의 · 알고리즘의 정확성

알고리즘이 계약에 대해 정확하다는 것은, 전제조건을 만족하는 모든 입력에서 (1) 실행이 유한한 단계 뒤에 끝나고 (2) 그때의 출력이 후조건을 만족한다는 뜻입니다. 예 몇 개를 실행해 맞는 것은 오류를 찾는 데 쓰는 근거이지, 정확성의 증명은 아닙니다. 증명하는 방법(불변식)은 다음 장에서 봅니다.

언어의 구체 문법보다 조건과 반복의 순서를 보여 주려고 적는 글이 의사코드입니다. 다음 줄에서 들여쓰기는 바깥 절차 안에서 언제 실행하는지를 드러냅니다.

목록의 각 위치 i를 0부터 왼쪽에서 오른쪽으로 확인한다.
    목록[i]가 기준 이상이면 i를 반환하고 끝낸다.
모든 확인을 마쳤는데 반환하지 않았으면 −1을 반환한다.

앞에서부터 비교하므로 2에서 반환하는 순간에는 더 이른 두 칸이 이미 조건을 만족하지 않았습니다. 빈 목록이면 반복문을 한 번도 실행하지 않고 −1을 얻습니다. 마지막에 조건이 맞는 경우엔 마지막 칸에서도 정상적으로 위치를 반환해야 합니다.

반환값을 다음 절차에서 다시 확인한다

결과가 −1이라고 해서 곧바로 values[-1]이라고 쓰면 안 됩니다. Python에서는 음수 인덱스 −1이 마지막 원소를 읽는 표현이기 때문입니다. 호출하는 곳에서는 결과가 −1인지 먼저 검사해야, 찾지 못한 일을 마지막 원소를 찾은 것과 구분할 수 있습니다. 이처럼 특별한 값은 사용처까지 포함해 의미를 문서로 정합니다.

조건을 >로 쓰면 기준값과 같은 7을 지나갑니다. 맨 앞, 찾지 못함, 빈 목록, 기준과 같은 값이 반복됨을 각각 검사하면 예시에만 우연히 맞는 실수를 줄입니다.

의사코드를 함수에 옮겨 네 경우를 확인한다

def first_at_least(values, threshold):
    for index, value in enumerate(values):
        if value >= threshold:
            return index
    return -1

cases = [
    ([3, 1, 7, 7, 2], 7, 2),
    ([9, 1], 7, 0),
    ([1, 2], 7, -1),
    ([], 7, -1),
]
for values, threshold, expected in cases:
    result = first_at_least(values, threshold)
    assert result == expected
    print(values, "->", result)
[3, 1, 7, 7, 2] -> 2
[9, 1] -> 0
[1, 2] -> -1
[] -> -1

enumerate는 위치 번호와 값을 함께 줍니다. return은 함수를 끝내고 호출한 쪽에 값을 주며, 출력 명령은 그 값을 이 예에서 확인하는 용도입니다.
