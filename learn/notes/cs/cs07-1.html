공부 교재

자료구조·알고리즘 · CS07 그래프 알고리즘

CS07·1

BFS는 가까운 층부터, DFS는 한 가지 끝까지

같은 그래프라도 다음 정점을 어떻게 고르느냐에 따라 탐색 순서와 처음 얻는 경로가 달라집니다.

이 장을 읽고 나면

  • 너비 우선 탐색과 깊이 우선 탐색의 순서를 추적한다.
  • 방문 기록으로 사이클에서 제자리를 도는 일을 막는다.
  • 간선 수가 가장 적은 경로를 BFS로 얻는다.

경로가 되돌아올 수 있는 자료에 방문 기록을 더한다

처리 상태를 A부터 F까지의 정점으로 둡니다. 각 화살표는 현재 상태에서 다음에 갈 수 있는 곳입니다. 트리와 달리 B→D→E→B처럼 원래 정점으로 돌아올 수 있습니다. 한 정점을 이미 발견했다는 표시가 없으면 경로를 계속 돌아 반복할 수 있습니다. 탐색에서 정점 이름을 set이나 거리 사전에 기록하면 이미 발견한 정점을 구분할 수 있습니다.

A부터 탐색한다고 해서 F도 읽는 것은 아닙니다. 그래프 전체를 방문하려면 한 시작점의 탐색이 끝난 뒤 아직 방문하지 않은 정점에서 별도로 다시 시작합니다. 이 장에서는 A에서 화살표 방향을 따라 도달하는 부분만 탐색하며, 목록에 적힌 순서로 이웃을 확인합니다.

큐는 덜 걸리는 층을 먼저 비우고, 스택은 깊게 들어간다

너비 우선 탐색(BFS)은 FIFO 큐를 사용합니다. 처음 A를 넣습니다. A를 꺼내 B,C를 발견해 큐 뒤에 이 순서로 넣고, B를 꺼낼 때 D를 넣습니다. C를 꺼낼 때 E를 넣습니다. D를 처리할 때는 E를 이미 발견했으므로 큐에 다시 넣지 않습니다. 처음 발견한 순간에 표시해야 같은 정점이 큐에 또 들어오지 않습니다.

깊이 우선 탐색(DFS)은 한 이웃 아래로 재귀 호출하거나 스택으로 들어갑니다. A→B→D→E 뒤에는 E의 이웃 B가 이미 표시돼 있습니다. E와 D, B에서 돌아온 뒤 A의 다음 이웃 C를 방문합니다. BFS는 A,B,C,D,E, 이 재귀 DFS는 A,B,D,E,C 순서입니다.

BFS의 거리와 부모를 함께 기록한다

모든 간선의 비용을 1로 세면 BFS는 거리 d에 먼저 도달한 정점부터 꺼냅니다. 그 정점에서 새로 발견한 이웃에는 d+1을 기록합니다. 한 간선씩 더 이동해야 하고 더 작은 거리의 층을 먼저 검사했으므로, 새 이웃에 더 짧은 경로가 있었다면 이미 발견됐을 것입니다. 처음 발견시킨 정점을 부모로 남기면 E→C→A로 거슬러 올라갈 수 있습니다.

from collections import deque

graph = {"A": ["B", "C"], "B": ["D"], "C": ["E"],
         "D": ["E"], "E": ["B"], "F": []}
dist = {"A": 0}
parent = {"A": None}
queue = deque(["A"])

while queue:
    node = queue.popleft()
    for nxt in graph[node]:
        if nxt not in dist:
            dist[nxt] = dist[node] + 1
            parent[nxt] = node
            queue.append(nxt)

seen = set()
dfs_order = []

def dfs(node):
    seen.add(node)
    dfs_order.append(node)
    for nxt in graph[node]:
        if nxt not in seen:
            dfs(nxt)

dfs("A")
print("BFS:", " ".join(dist))
print("DFS:", " ".join(dfs_order))
print("E:", dist["E"], "parent:", parent["E"])
print("F:", "reachable" if "F" in dist else "unreachable")
BFS: A B C D E
DFS: A B D E C
E: 2 parent: C
F: unreachable

인접 리스트에서 방문 가능한 정점마다 그 이웃을 한 번 확인하며, 전체 정점과 간선 수를 V,E라고 하면 시간은 O(V+E)입니다. 큐, 방문 표와 재귀 스택에 최대 O(V)의 추가 위치가 필요합니다. 간선마다 비용이 다를 때는 먼저 발견한 경로보다 나중에 찾은 경로가 저렴할 수 있습니다. 다음 장에서는 비용을 기준으로 탐색합니다.
