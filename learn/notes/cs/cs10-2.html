CS10·2

힙의 아래부터 구성하고 선형 시간 상계 세우기

원소마다 꼭대기까지 이동한다고 계산하면 힙 구성 비용을 크게 잡게 됩니다. 각 노드가 실제로 내려갈 수 있는 높이를 더합니다.

이 장을 읽고 나면

  • 낮은 서브트리부터 힙 조건을 보존하는 이유를 설명한다.
  • 완전 이진 트리의 층 수를 합해 O(n)을 유도한다.
  • 최소로 뽑는 순서와 배열 구조를 서로 다른 검산 과정으로 확인한다.

이미 힙인 두 자식 아래에만 작업이 남습니다

최소 힙의 배열에서 인덱스 i의 자식은 2i+1, 2i+2입니다. 모든 부모가 자기 자식보다 작거나 같으면 루트가 최솟값입니다. 배열의 끝에서 루트 방향으로 처리하면, 부모를 읽을 때 각 자식 아래는 이미 힙입니다. 부모가 더 작거나 같다면 현재 서브트리도 힙입니다. 아니면 두 자식 중 작은 것과 교환하고 내려간 자리에서 다시 확인합니다. 작은 자식을 위로 보내야 반대 자식과의 순서도 바로 맞습니다.

배열 [9,6,8,1,5,7,2]의 리프는 인덱스 3~6입니다. 내부 인덱스 2의 8을 2와 교환하고, 1의 6을 1과 교환합니다. 이제 루트 9를 작은 자식 1과 바꾸고 9가 내려간 자리에서 그보다 작은 자식 5와 다시 교환합니다. 다른 가지에는 이미 작은 부모가 있으므로 함께 움직일 필요가 없습니다.

인덱스 하나를 처리하고 나면 그 아래 모든 부모 관계가 맞습니다. 내리는 동안 새로 틀릴 수 있는 관계는 내려간 항목과 그 아래 자식뿐입니다. 바닥에 이르거나 그 자리가 이미 맞으면 현재 서브트리의 힙 조건을 복구합니다. 이 국소 성질을 끝에서 루트까지 반복합니다.

모든 노드가 꼭대기까지 움직인다는 가정을 버립니다

0부터 센 인덱스 i에서 왼쪽 자식만 h번 가면 2ʰ(i+1)−1입니다. 이 값이 n−1 이하라면 적어도 h번 아래로 갈 수 있습니다. 완전 이진 트리에서는 같은 깊이의 가장 왼쪽 자리부터 채워지므로 이보다 깊이 h의 더 오른쪽 자리만 존재하는 경우는 없습니다. 조건을 정리하면 i+1≤n/2ʰ이고, 그런 인덱스 수는 ⌊n/2ʰ⌋입니다.

노드별 이동 최대를 모두 더하는 대신, 한 단계 이상 움직일 수 있는 노드 수, 두 단계 이상 움직일 수 있는 노드 수, …를 겹쳐 셉니다. 각각의 한 단계에 상수번 비교·교환이 필요합니다. 기하급수 합 ⌊n/2⌋+⌊n/4⌋+⋯는 n보다 작습니다. 리프를 빼고 각 내부 인덱스에서 처리를 시작하는 비용도 O(n)이라 아래부터 힙을 만드는 전체 비용은 O(n)입니다. 개별 삽입으로 하나씩 구성하면 일반적으로 O(n log n) 상계를 얻습니다.

실제 힙과 정렬 기준의 결과를 대조합니다

from random import Random

def down(a, i):
    swaps = 0
    while 2*i+1 < len(a):
        j = 2*i+1
        if j+1 < len(a) and a[j+1] < a[j]:
            j += 1
        if a[i] <= a[j]:
            break
        a[i], a[j] = a[j], a[i]
        i = j
        swaps += 1
    return swaps

def build(values):
    a = list(values)
    swaps = sum(down(a,i) for i in reversed(range(len(a)//2)))
    return a, swaps

def pop_min(a):
    least = a[0]
    last = a.pop()
    if a:
        a[0] = last
        down(a,0)
    return least

def valid(a):
    return all(a[(i-1)//2] <= a[i] for i in range(1,len(a)))

a, swaps = build([9,6,8,1,5,7,2])
print("example:", a, "swaps:", swaps)
print("pop order:", [pop_min(a) for _ in range(len(a))])

rng = Random(96)
cases = [[], [4], [2,-1,2]]
cases.extend([rng.randrange(-8,9) for _ in range(rng.randrange(30))]
             for _ in range(20))
for values in cases:
    a, _ = build(values)
    assert valid(a)
    popped = []
    while a:
        popped.append(pop_min(a))
        assert valid(a)
    assert popped == sorted(values)
print("checked cases:", len(cases))
example: [1, 5, 2, 6, 9, 7, 8] swaps: 4
pop order: [1, 2, 5, 6, 7, 8, 9]
checked cases: 23

힙 배열은 전체가 정렬된 순서일 필요가 없습니다. 반복해서 최솟값을 뽑은 결과가 정렬된 기준 배열과 같아야 합니다. 검산은 빈 목록, 원소 하나, 중복값과 음수가 있는 목록을 직접 넣고 고정 시드에서 생성한 20개 목록도 검사합니다. 전체 정렬보다 적은 작업으로 구성해 첫 우선순위만 제공할 수 있다는 점이 힙의 용도입니다.
