CS12·1

되돌릴 수 있는 유량에서 최적성 증명으로

한 출발점에서 한 도착점으로 얼마나 많이 보낼 수 있을까요? 네 정점 예제로 유량 보존을 직접 확인하고, 이미 보낸 양을 일부 취소할 수 있어야 탐욕적인 첫 선택을 고칠 수 있는 이유를 증명합니다.

이 장을 읽고 나면

  • 용량과 실제 유량, 정점에서의 유량 보존을 구분합니다.
  • 잔여 간선으로 증가 경로를 찾고 정방향과 역방향을 갱신합니다.
  • 컷과 유량의 값이 같다는 사실로 최대 유량을 검증합니다.

간선에는 한도, 중간 정점에는 보존 조건

방향 그래프에 출발점 s와 도착점 t가 있고, 각 간선 e의 용량 c(e)≥0가 주어졌습니다. 간선에 할당한 유량 f(e)는 0≤f(e)≤c(e)를 만족해야 합니다. s와 t를 제외한 모든 정점에서는 들어온 유량의 합이 나가는 유량의 합과 같아야 합니다. 정점에 물량을 쌓아 두지 않는 모형입니다. 유량의 값 |f|는 s에서 나간 양에서 s에 들어온 양을 뺀 값입니다. 용량이 분당 단위라면 |f|도 분당 단위입니다.

예를 들어 a에 s로부터 3이 들어오고 a→b로 2, a→t로 1이 나가면 a에서 보존이 성립합니다. 개별 간선 값만 쓰고 중간 정점의 일치까지 보아야 후보가 실현 가능합니다.

잔여 용량은 다음 변경량의 한도입니다

원래 간선 u→v에 유량 f가 흐르면 정방향 잔여 용량은 c−f, 역방향 v→u의 잔여 용량은 f입니다. 정방향으로 Δ를 보내면 원래 유량을 Δ만큼 늘립니다. 역방향으로 보내면 원래 유량을 그만큼 줄입니다. 역방향에는 취소하는 양의 상한인 f가 붙습니다. 용량이 양수인 잔여 간선으로 s에서 t에 가는 단순 경로를 증가 경로라고 합니다. 그 경로의 최소 잔여 용량만큼 함께 갱신하면 모든 원래 간선의 용량 제한이 유지됩니다. 경로 내부 정점에는 잔여 경로가 한 번 들어오고 한 번 나가므로 원래 유량의 순변화가 0입니다. 전체 유량 |f|는 Δ만큼 증가합니다.

단계잔여 증가 경로Δ(sa, sb, ab, at, bt)
0시작0(0, 0, 0, 0, 0)
1s–a–b–t2(2, 0, 2, 0, 2)
2s–a–t1(3, 0, 2, 1, 2)
3s–b–t1(3, 1, 2, 1, 3)
4s–b–a–t1(3, 2, 1, 2, 3)

세 번째 단계 뒤에는 a를 향하는 s의 정방향 잔여가 0이고 b에서 t로 가는 잔여도 0입니다. b에서 a로 방향을 바꿀 수 있어 s→b의 남은 1과 a→t의 남은 1을 연결합니다. 최종 상태에서 a는 3을 받아 1+2를 보내고, b는 2+1을 받아 3을 보냅니다.

남은 경로를 찾지 못했다는 말의 수학적 의미

s를 포함하고 t를 제외한 정점 집합 U를 잡습니다. U 내부의 유량 보존식을 합하면 내부 간선은 양쪽에서 한 번씩 나와 상쇄됩니다. 따라서 |f|는 컷 바깥으로 나간 유량에서 컷 안으로 들어온 유량을 뺀 값입니다. 들어온 양은 음수가 아니고, 나간 양은 해당 간선 용량 이하입니다. 그래서 어떤 실현 가능한 유량도 컷의 정방향 용량 총합을 넘을 수 없습니다.

증가 경로가 없는 상태에서 양의 잔여 간선으로 s에서 도달 가능한 모든 정점의 집합을 U라고 합시다. t는 U에 없습니다. U 밖으로 나가는 원래 간선 중 여유가 있는 간선이 있다면 그 끝점도 도달 가능합니다. 따라서 이 간선들은 모두 용량을 채웠습니다. U 안으로 들어오는 원래 간선에 양의 유량이 있다면 잔여 역방향으로 U 밖의 시작점에 도달할 수 있습니다. 따라서 들어오는 간선의 유량은 모두 0입니다. 이 컷의 용량과 현재 유량의 값이 같습니다. 모든 컷이 유량의 상한을 주므로 이 유량은 최대, 이 컷은 최소입니다.

최대 유량–최소 컷 정리

유량 f에 대해 다음 셋은 서로 같은 말입니다. (1) f는 최대 유량이다. (2) 잔여 그래프에 증가 경로가 없다. (3) 용량이 |f|와 같은 s–t 컷이 있다. 따라서 최대 유량의 값은 최소 컷의 용량과 같습니다. (1)⇒(2)는 증가 경로가 있으면 Δ만큼 늘릴 수 있다는 앞 절에서, (2)⇒(3)은 바로 위 도달 집합 U에서, (3)⇒(1)은 모든 컷이 상한이라는 첫 문단에서 나옵니다.

정수 용량에서 0으로 시작하면 매 갱신의 Δ는 양의 정수입니다. |f|가 매번 적어도 1 증가하고 s의 출구 용량이 유한하므로 종료합니다. 그러므로 정수 용량에서는 정수값을 갖는 최대 유량을 하나 얻을 수 있습니다. 이 반복 횟수 상한은 용량의 수치에 의존합니다. 가령 B비트로 2B−1에 달하는 용량을 적을 수 있어, 단위 증가 횟수만의 상한으로는 비트 길이에 대한 다항 실행 시간을 얻을 수 없습니다. 잔여에서 늘 간선 수가 가장 짧은 증가 경로(BFS)를 고르는 Edmonds–Karp는 용량 값과 무관하게 증가 횟수가 O(|V|·|E|)라 전체 O(|V|·|E|²)의 다항시간 보장을 갖습니다. 용량이 무리수이면 경로를 고르는 방식에 따라 Ford–Fulkerson이 끝나지 않거나 최대가 아닌 값으로 수렴하는 예도 알려져 있으므로, 종료 논증에는 정수(또는 유리수) 용량 가정이 필요합니다.

capacity = {("s","a"):3, ("s","b"):2, ("a","b"):2,
            ("a","t"):2, ("b","t"):3}
flow = dict.fromkeys(capacity, 0)

def residual():
    for (u, v), cap in capacity.items():
        value = flow[u, v]
        if cap > value:
            yield (u, v), ((u, v), 1, cap - value)
        if value > 0:
            yield (v, u), ((u, v), -1, value)

def balance(u):
    return sum(value * ((u == a) - (u == b))
               for (a, b), value in flow.items())

paths = ["sabt", "sat", "sbt", "sbat"]
for path in paths:
    available = dict(residual())
    moves = [available[step] for step in zip(path, path[1:])]
    delta = min(room for _, _, room in moves)
    for edge, sign, _ in moves:
        flow[edge] += sign * delta
    assert all(0 <= f <= capacity[e] for e, f in flow.items())
    assert balance("a") == balance("b") == 0
    assert balance("s") == -balance("t")
    print(path, delta, tuple(flow.values()))

seen, stack = {"s"}, ["s"]
remaining = dict(residual())
while stack:
    x = stack.pop()
    for u, v in remaining:
        if x == u and v not in seen:
            seen.add(v)
            stack.append(v)
cut_value = sum(c for (u, v), c in capacity.items()
                if u in seen and v not in seen)
assert "t" not in seen and cut_value == balance("s")
print("reachable", sorted(seen), "flow = cut", cut_value)

sat 1 (3, 0, 2, 1, 2)
sbt 1 (3, 1, 2, 1, 3)
sbat 1 (3, 2, 1, 2, 3)
reachable ['s'] flow = cut 5

코드에서 원래 간선은 정점 쌍당 방향 하나만 두었습니다. 평행 간선이 있거나 원래 간선이 두 방향으로 모두 있다면 같은 방향의 잔여 움직임이 여러 원래 간선에서 나올 수 있으므로 원래 간선의 고유 번호까지 기록해야 합니다.
