CS05·1

재귀 호출과 이진 트리의 세 순회

호출이 끝나기까지 기다리는 정보를 스택에 두고, 같은 트리를 전위·중위·후위로 읽어 봅니다.

이 장을 읽고 나면

  • 재귀 호출에서 기저 조건과 줄어드는 입력을 찾는다.
  • 호출 스택에 남는 순서를 추적한다.
  • 전위·중위·후위 순회를 손으로 계산한다.

호출이 끝날 때 돌아올 위치를 남겨 둔다

함수 visit(A)가 아직 일을 마치지 않고 visit(B)를 부르면, A의 호출은 B가 끝난 뒤 어디서 이어 갈지 기억합니다. B가 D를 부르면 A와 B가 모두 대기합니다. 이렇게 가장 나중에 만든 호출부터 끝내는 저장 구조가 호출 스택입니다. 호출 단위에는 현재 매개변수, 지역 변수, 이어 할 위치 같은 정보가 있습니다.

앞서 본 기저 조건은 더 작게 부르지 않고 끝내는 경우입니다. 여기서는 빈 자식 None을 받으면 바로 반환합니다. 유한한 트리에서 매번 자식 방향으로만 내려가면 언젠가 빈 자식에 닿습니다. 이 조건을 빼거나 같은 노드를 다시 그대로 부르면 호출을 끝낼 수 없습니다.

부모를 언제 기록하는지에 따라 결과가 달라진다

루트 A의 왼쪽은 B, 오른쪽은 C입니다. B에는 왼쪽 D와 오른쪽 E, C에는 오른쪽 F만 있습니다. 이처럼 왼쪽·오른쪽 자리를 구분하며 각 노드가 자식을 최대 두 개 갖는 트리를 이진 트리라고 합니다. 한쪽만 있다면 어느 쪽 자식인지도 기록해야 합니다.

두 자식은 항상 왼쪽, 오른쪽 순서로 살펴봅니다. 전위 순회는 둘보다 먼저 부모를 기록해 A B D E C F가 됩니다. 중위 순회에서는 왼쪽 뒤와 오른쪽 앞에 부모를 넣어 D B E A C F가 됩니다. 후위 순회는 두 자식을 모두 처리한 뒤 부모를 넣어 D E B F C A가 됩니다. C에 왼쪽 자식이 없어서 중위에서는 C가 F보다 먼저 나오지만, 후위에서는 F가 앞섭니다.

한 번 방문하면서 세 시점에 각각 기록한다

각 노드를 (이름, 왼쪽, 오른쪽) 튜플로 적습니다. 빈 트리라면 세 결과가 모두 빈 목록입니다. 노드마다 상수 번의 일을 하므로 n개에는 Θ(n) 시간이 듭니다. 결과를 뺀 호출 저장 공간은 가장 긴 뿌리-잎 경로의 노드 수에 비례합니다. 한쪽으로 길게 치우치면 n에 비례하고, 균형 있게 퍼지면 로그 규모까지 줄어듭니다.

tree = ("A", ("B", ("D", None, None), ("E", None, None)),
            ("C", None, ("F", None, None)))
pre, mid, post = [], [], []

def visit(node):
    if node is None:
        return
    name, left, right = node
    pre.append(name)
    visit(left)
    mid.append(name)
    visit(right)
    post.append(name)

visit(tree)
print("preorder:", " ".join(pre))
print("inorder:", " ".join(mid))
print("postorder:", " ".join(post))
preorder: A B D E C F
inorder: D B E A C F
postorder: D E B F C A

실제 Python의 호출 깊이에는 한도가 있습니다. 길게 이어진 트리도 처리해야 한다면 직접 만든 스택으로 바꾸는 방식을 검토합니다. 이후 그래프 순회에서는 경로가 한 노드로 다시 이어질 수 있어 방문 기록도 추가합니다.
