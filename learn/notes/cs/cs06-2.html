CS06·2

이진 탐색으로 동점의 첫 위치 찾기

정렬된 목록에서 기준 이상인 첫 위치를 찾습니다. 같은 값이 여러 개거나 목표가 목록에 없을 때까지 확인합니다.

이 장을 읽고 나면

  • 정렬돼 있다는 조건으로 한쪽 구간을 버린다.
  • 같은 값이 여러 개일 때 첫 위치를 찾는다.
  • 삽입 위치와 일치 결과를 구분한다.

정렬된 데이터를 같은 기준으로 검색한다

오름차순 목록 [1,3,3,3,6,8]의 3을 찾습니다. 앞에서부터 볼 수도 있지만 이진 탐색은 가운데 한 값을 보고 절반 가까이를 버립니다. 가운데가 x보다 작으면 그 값까지는 전부 x보다 작습니다. 정렬하지 않았다면 가운데의 왼쪽에 더 큰 값이 있을 수 있어서 그 결론을 쓸 수 없습니다.

이 예에서 먼저 찾는 것은 x 이상인 첫 위치, 즉 왼쪽 삽입 위치입니다. 같은 값이 여러 개면 가장 앞 칸이고, 찾는 값이 실제로 없으면 끼울 위치를 반환합니다. 원래 입력이 다른 기준으로 정렬돼 있거나 입력을 정렬하는 과정에서 순서가 바뀌었다면, 반환 위치는 그 정렬 결과의 위치임을 구별합니다.

범위의 두 경계가 뜻하는 조건을 끝까지 지킨다

시작은 lo=0과 hi=길이입니다. lo보다 작은 위치에는 x 미만이라고 확인된 값만 두고, hi부터 끝에는 x 이상인 값만 둡니다. 아직 어느 쪽인지 모르는 범위는 [lo,hi)입니다. x=3에서 먼저 mid=3을 보면 그 값 3이 x 이상이라 hi를 3으로 옮깁니다. mid도 알고 있는 오른쪽에 포함합니다. 다음 mid=1도 3이라 hi가 1입니다. 마지막 mid=0은 1이라 lo를 mid+1인 1로 올립니다.

lo=hi가 되면 왼쪽은 모두 x 미만, 오른쪽은 모두 x 이상이라 이 위치가 경계입니다. 가운데 값이 x와 같다고 곧바로 반환하면 예의 첫 비교에서 위치 3을 반환할 수 있어 처음 위치를 구하지 못합니다.

삽입 위치를 찾은 뒤 실제 일치를 확인한다

x=5의 자리는 4지만 위치 4의 값은 6입니다. x=9이면 모든 값이 더 작아서 삽입 위치가 6, 즉 목록 끝입니다. 목록을 읽기 전에 위치가 범위 안인지 확인하고, 그 뒤 같은 값인지 비교해야 합니다. 빈 목록도 삽입 위치는 0이고 일치하는 값은 없습니다.

from bisect import bisect_left

def lower_bound(values, target):
    lo, hi = 0, len(values)
    while lo < hi:
        mid = (lo + hi) // 2
        if values[mid] < target:
            lo = mid + 1
        else:
            hi = mid
    return lo

values = [1, 3, 3, 3, 6, 8]
for target in (3, 5, 9):
    index = lower_bound(values, target)
    found = index < len(values) and values[index] == target
    print(target, index, found)
    assert index == bisect_left(values, target)
assert lower_bound([], 9) == 0
3 1 True
5 4 False
9 6 False

한 번에 미확정 범위를 최대 절반으로 줄이므로 목록 위치 접근과 키 비교가 일정한 비용일 때 한 조회의 비교 수는 O(log n)입니다(n≥2). 정렬하지 않은 목록에서 검색이 한 번이면, 정렬에 드는 시간까지 포함해 선형 검색과 비교합니다. 같은 기준으로 계속 조회한다면 한 번 정렬한 목록을 재사용할 수 있습니다. 삽입 위치를 찾는 비용과 실제로 그 위치의 뒤 항목을 옮겨 삽입하는 비용도 따로 셉니다.
