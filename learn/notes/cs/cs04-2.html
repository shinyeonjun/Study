CS04·2

딕셔너리로 세고 집합으로 첫 등장을 고르기

작업 기록을 읽으며 유형별 횟수를 세고 처음 등장한 유형만 원래 순서대로 남깁니다. 키로 쓸 수 있는 값과 조회 비용의 가정을 짚습니다.

이 장을 읽고 나면

  • 키에 횟수를 연결할 때 딕셔너리를 사용한다.
  • 본 적 있는 값인지 검사할 때 집합을 사용하고, 처음 나타난 순서를 유지한다.
  • 딕셔너리와 집합의 키 조건과 연산 비용을 설명한다.

딕셔너리는 키에 값을 연결한다

짧은 작업 기록을 읽는다고 합시다. 기록은 ["A", "B", "A", "C", "B"]입니다. 유형별로 몇 번 등장했는지 알아보려면 유형을 키, 횟수를 값으로 하는 딕셔너리가 알맞습니다. 키는 서로 구별되면 한 번씩 저장되고 값은 여러 키에서 같을 수 있습니다. A와 B가 둘 다 2를 가리켜도 괜찮습니다.

각 기록 code에 대해 counts.get(code, 0) + 1을 계산합니다. get은 키가 있으면 현재 횟수를 읽고 키가 없으면 지정한 기본값 0을 반환합니다. 이어서 counts[code] = ...로 증가한 횟수를 저장합니다. get으로 기본값을 읽는 동작만으로 키가 추가되지는 않습니다. 없는 키를 counts[code]로 바로 읽으면 기본 dict에서는 KeyError가 발생합니다.

Python 3.7부터 딕셔너리는 키를 삽입한 순서대로 순회합니다. 이미 있는 키의 값을 바꾸면 그 키의 위치는 유지됩니다. key in counts는 그 키가 있는지 확인합니다. 실제 값으로 None을 저장할 수 있으므로 값이 None인지와 키가 있는지는 다른 질문입니다.

집합은 이미 본 값인지 판단한다

횟수 대신 지금까지 무엇이 나왔는지만 알고 싶다면 집합set을 사용합니다. 빈 집합은 set()으로 만듭니다. {}는 빈 딕셔너리입니다. seen.add(code)를 여러 번 해도 같은 값은 원소 하나로 남고, code in seen으로 포함 여부를 읽습니다.

결과를 첫 등장 순서대로 보여주려면 원본을 왼쪽부터 읽습니다. 아직 집합에 없는 값을 만나면 집합에 추가하고 같은 값을 결과 리스트 뒤에도 붙입니다. 집합은 판단에, 리스트는 출력 순서를 기록하는 데 사용합니다. 이 사례에서 선택한 원래 인덱스는 0, 1, 3입니다. Python 집합의 순회에는 삽입 순서 보장이 없습니다.

키의 해시와 동등성을 확인한다

딕셔너리 키와 집합 원소는 해시 가능해야 합니다. 해시값을 계산할 수 있고 객체의 수명 동안 그 값이 유지되어야 합니다. 두 키가 동등하면 해시값도 같아야 합니다. 같은 해시값을 얻은 두 키는 동등성 비교로 구별합니다. 정수와 문자열은 사용할 수 있고, 튜플은 그 안의 모든 요소가 해시 가능할 때 사용할 수 있습니다. Python의 리스트는 해시 가능하지 않으므로 리스트 전체를 한 키로 쓰고 싶다면 의미가 같은 해시 가능한 형태가 있는지 확인합니다.

앞 장의 바구니는 해시의 원리를 보여주었습니다. Python의 기반 구현인 CPython도 해시를 사용합니다. 검색이나 멤버십 한 번은 키의 해시 계산·동등성 비교가 일정한 비용이고 테이블의 후보가 고르게 분산될 때 기대 O(1), 검사할 후보가 몰리는 최악의 경우에는 저장 키 수에 대해 O(k)입니다. 균등한 분포로 테이블을 유지하고 증설 비용을 여러 삽입에 나누어 보면, 이 예에서 N개 기록을 읽는 전체 시간은 기대 Θ(N)입니다. 서로 다른 기록이 k종이고 고정된 크기의 키를 쓰면 새로 저장할 횟수, 포함 여부, 결과 리스트는 각각 Θ(k) 규모입니다.

횟수, 포함 여부, 순서를 한 번에 확인한다

codes = ["A", "B", "A", "C", "B"]
counts = {}
seen = set()
first = []

for code in codes:
    counts[code] = counts.get(code, 0) + 1
    if code not in seen:
        seen.add(code)
        first.append(code)

print("counts:", counts)
print("missing D:", counts.get("D", 0))
print("first:", first)
print("membership B and Z:", "B" in seen, "Z" in seen)
counts: {'A': 2, 'B': 2, 'C': 1}
missing D: 0
first: ['A', 'B', 'C']
membership B and Z: True False

get("D", 0)은 기본값을 돌려줍니다. B는 두 번 읽었지만 seen의 원소로는 한 번 있으며, 처음 나타났을 때만 first에 들어갔습니다. 마지막 줄에서는 집합 순회에 의존하지 않고 두 원소의 포함 여부를 직접 묻습니다.
