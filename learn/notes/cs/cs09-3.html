배열 확장의 최악·평균·상각 비용을 구분하기

일부 삽입은 배열 전체를 복사하지만 그 일이 매번 일어나지는 않습니다. 여러 연산의 누적 비용을 구한 뒤, 확률에 대한 평균과 차이를 따집니다.

이 장을 읽고 나면

  • 용량을 두 배로 늘리는 배열에서 한 삽입의 비용을 구한다.
  • 복사 수열과 잠재 함수 두 방법으로 상각 상수를 증명한다.
  • 최악·평균·상각의 결론이 무엇을 보장하는지 구분한다.

용량과 들어 있는 개수는 다릅니다

연속된 칸에 값을 담는 동적 배열을 둡니다. 실제 사용 개수 m과 예약된 용량 C를 구별합니다. 처음에는 m=0, C=1입니다. 뒤에 하나를 넣을 빈칸이 있으면 쓰기 한 번입니다. 꽉 차면 용량을 2C로 늘리고 기존 C개를 복사한 뒤 새 항목을 씁니다. 이 장은 새 배열을 구현하는 부수적인 메모리 비용을 쓰기 개수로 설명하며 시간과 상수는 구현에 따라 달라질 수 있습니다.

여덟 번째까지 넣으면 비용은 [1,2,3,1,5,1,1,1]입니다. 아홉 번째는 꽉 찬 여덟 개를 모두 복사하므로 실제 비용 9입니다. 최악 한 번의 비용은 배열에 이미 든 원소 수 규모인 Θ(m)까지 올라갑니다.

어떤 입력 값이든 삽입열 전체를 합산합니다

n번 삽입에서 새로운 항목을 쓰는 데 n번, 각 용량을 확장하면서 1,2,4,… 크기의 복사가 듭니다. 마지막 복사가 2ᵏ라면 2ᵏ<n입니다. 1+2+⋯+2ᵏ=2ᵏ⁺¹−1<2n이어서 합이 3n 미만입니다. n=9에서는 복사 합 15와 새 쓰기 9를 더해 24입니다. 따라서 임의의 값들을 이 규칙에 따라 순차적으로 삽입할 때 상각 비용, 즉 전체 비용을 연산에 나눈 부담의 상계는 O(1)입니다. 삭제나 다른 용량 정책을 적용하면 기존 증명을 그대로 가져올 수 있는지 다시 봅니다.

같은 보장을 잠재 함수 Φ로도 계산합니다. 자료구조 상태에 Φ=2m−C+1을 붙이고, 상각 비용을 실제 비용+(새 Φ−이전 Φ)로 정의합니다. 처음 Φ는 0입니다. 삽입만 한다면 확장 직후의 m은 용량의 절반보다 크고 용량은 다음 확장까지 유지되므로 Φ는 항상 음이 아닙니다.

확장 없는 삽입에서 실제 비용 1과 잠재량 증가 2가 합쳐져 3입니다. 확장에서는 기존 m=C, 새 m=C+1, 새 용량 2C입니다. Φ는 C+1에서 3으로 바뀌고 실제 비용은 C+1이므로, 합은 (C+1)+(3−(C+1))=3입니다. 연산열에서 Φ 변화들을 합하면 중간 값들이 지워져 새 Φ−초기 Φ만 남습니다. 새 Φ가 음이 아니므로 실제 전체 비용은 상각 비용 합 3n 이하입니다.

평균을 낼 때의 확률 전제와 비교합니다

길이 4의 목록에서 네 위치 중 하나를 같은 확률로 찾는 순차 탐색이라면 비교 횟수의 평균은 (1+2+3+4)/4=2.5입니다. 위치 선택 분포를 바꾸면 평균이 바뀝니다. 배열 삽입의 상각 상계는 ‘운이 좋아 대부분 싸다’는 확률 전제가 필요 없습니다. 최악 한 연산은 반응 시간의 큰 지연을 설명하고, 평균은 명시한 입력 분포에서의 기대 비용이며, 상각은 정한 연산열의 누적 보장입니다.

cells = [None]
size = 0
actual_total = 0
charges = []
def potential(m, c):
    return 2*m-c+1

for value in range(1, 10):
    old = potential(size, len(cells))
    actual = 1
    if size == len(cells):
        larger = [None] * (2*len(cells))
        for i in range(size):
            larger[i] = cells[i]
        actual += size
        cells = larger
    cells[size] = value
    size += 1
    actual_total += actual
    charge = actual + potential(size,len(cells)) - old
    charges.append(charge)
    print(size, len(cells), actual, charge)
assert cells[:size] == list(range(1, 10))
print("actual / charged:", actual_total, sum(charges))

표의 네 열은 삽입 번호, 용량, 실제 쓰기, 상각 비용입니다. 계산용 리스트는 이 글의 쓰기 비용 모형을 구현한 것이며 Python 리스트 자체가 항상 같은 용량 규칙을 쓴다고 가정하지 않습니다.
