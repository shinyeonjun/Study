선행 작업이 있는 순서와 막히는 사이클

먼저 끝나야 할 작업이 모두 끝났을 때 다음 작업을 꺼냅니다. 서로 기다리는 작업 때문에 순서를 만들 수 없는 경우도 판별합니다.

이 장을 읽고 나면

  • 간선 방향과 진입 차수로 실행 가능한 작업을 찾는다.
  • 유효한 위상 순서가 둘 이상일 수 있음을 확인한다.
  • 방향 사이클 때문에 남은 작업을 처리할 수 없는 경우를 검출한다.

화살표의 출발 작업을 먼저 끝내야 한다

분석 작업 D를 시작하려면 입력을 만드는 B와 C가 먼저 끝나야 합니다. 원본 받기 A는 B와 C보다 앞에, 결과 제출 E는 D보다 뒤에 둡니다. 이 장에서 화살표 u→v는 u가 먼저여야 한다는 뜻입니다. 별도 점검 F는 이 그래프에서 들어오는 간선도 나가는 간선도 없습니다.

모든 간선의 출발 정점이 도착 정점보다 앞에 오도록 전체 정점을 나열한 결과를 위상 순서라 합니다. 예를 들어 A,F,B,C,D,E가 한 순서입니다. A 뒤에서 C와 B의 순서를 바꾸고 F를 맨 뒤에 놓은 A,C,B,D,E,F도 조건을 모두 지킵니다.

들어오는 선행 의존성이 0개인 작업을 꺼낸다

정점으로 들어오는 화살표 수가 진입 차수입니다. 처음 A,F는 0, B,C,E는 1, D는 2입니다. A와 F를 처리 가능한 큐에 넣습니다. A를 처리해 A의 화살표를 제거하면 B와 C가 각각 0이 되어 큐 뒤로 들어갑니다. B를 처리하면 D는 1이어서 아직 기다립니다. C도 처리하면 D는 0, D를 처리하면 E도 0이 됩니다.

이 방법은 새로 0이 된 정점만 큐에 넣습니다. 같은 단계에서 넣을 것이 여러 개라면 그중 어떤 것을 먼저 고르느냐에 따라 유효한 결과가 바뀔 수 있습니다. 예제에서는 그래프에 적힌 순서와 FIFO 큐를 사용합니다.

큐가 비었는데 남은 정점이 있으면 막힌 이유가 있다

처리되지 않은 정점들 중 진입 차수가 0인 것이 없으면, 각 정점에 아직 남은 선행 정점이 있습니다. 그 선행 정점을 계속 거슬러 가면 유한한 그래프에서는 어느 정점을 다시 만나 방향 사이클이 생깁니다. E→B를 더하면 B→D→E→B가 함께 서로를 기다립니다. A,F,C는 처리할 수 있지만 나머지를 포함하는 위상 순서는 없습니다.

from collections import deque

graph = {"A": ["B", "C"], "B": ["D"], "C": ["D"],
         "D": ["E"], "E": [], "F": []}

def topological_order(edges):
    indegree = dict.fromkeys(edges, 0)
    for row in edges.values():
        for nxt in row:
            indegree[nxt] += 1

    ready = deque(node for node in edges if indegree[node] == 0)
    order = []
    while ready:
        node = ready.popleft()
        order.append(node)
        for nxt in edges[node]:
            indegree[nxt] -= 1
            if indegree[nxt] == 0:
                ready.append(nxt)
    return order if len(order) == len(edges) else None

order = topological_order(graph)
rank = {name: i for i, name in enumerate(order)}
assert all(rank[u] < rank[v] for u, row in graph.items() for v in row)
with_cycle = {**graph, "E": ["B"]}
print("order:", " ".join(order))
print("cycle detected:", topological_order(with_cycle) is None)
order: A F B C D E
cycle detected: True

유한한 방향 그래프에서 방향 사이클이 없을 때, 그리고 그때에만 위상 순서가 존재합니다. 빈 그래프에서는 빈 순서가 하나의 정상 결과입니다. 진입 차수를 처음 계산하고 처리에서 각 간선을 한 번 더 보면 전체 시간은 O(V+E), 입력 외 진입 차수 표와 큐 등은 O(V) 공간입니다.
