호스트가 어떻게 역할을 나눠 통신하는가

휴대폰에서 책 목록을 열면 목록을 계산하는 프로그램은 다른 컴퓨터에 있을 수 있습니다. 두 기기를 그냥 ‘인터넷에 연결된 기계’라고 부르는 데서 한 걸음 더 나아가, 연결에서 무엇을 주고받으며 누가 시작하는지부터 읽습니다.

이 장을 읽고 나면

  • 호스트와 클라이언트·서버 역할을 구별한다.
  • 한 요청과 한 응답이 각각 어떤 일을 하는지 설명한다.
  • 통신 규칙이 필요한 이유를 간단한 요청 형식으로 확인한다.

서로 다른 기기의 프로그램이 데이터를 주고받는다

내 휴대폰에서 노트북에 저장된 사진 목록을 보고 싶다고 합시다. 사진 전체가 아니라 파일 이름을 먼저 보여 주기로 했습니다. 휴대폰의 프로그램은 ‘사진 폴더의 목록을 알려 달라’는 데이터를 보내고, 노트북의 프로그램은 약속한 형식으로 목록을 돌려줍니다. 연결을 통해 두 기기의 프로그램이 정보를 전달하는 것이 통신입니다.

통신의 출발점이나 목적지가 될 수 있는 컴퓨터나 기기를 호스트라 합니다. 휴대폰, 노트북, 서버 컴퓨터, 네트워크로 문서를 받아 인쇄하는 프린터도 통신의 목적지가 될 수 있습니다. 네트워크를 구성하는 장치에는 호스트 외에 메시지가 지나가는 길을 연결하는 장치도 있습니다.

이 요청에서 먼저 사진 목록을 달라고 한 쪽은 클라이언트, 그 요청을 받아 파일 목록을 주는 쪽은 서버입니다. 이름은 우선 프로그램이 그 통신에서 맡은 역할입니다. 같은 노트북에서 다른 사이트로 웹 요청을 보내면, 방금 응답을 주던 그 노트북이 이번에는 웹 클라이언트가 됩니다.

서로 알아듣기 위해 정해 놓은 약속

휴대폰은 어떤 폴더를 원하는지 보내야 합니다. 노트북은 잘 받았는지, 폴더가 있는지, 목록이 무엇인지 구분해서 응답해야 합니다. 글자로 쓸지, 글자 사이 칸을 무엇으로 구분할지, 실패하면 어떤 표시를 보내야 할지도 정해 두어야 합니다. 통신의 형식과 보내고 받는 순서를 정한 약속을 프로토콜이라 합니다.

사진 목록용 약속 만들기

이 예에서는 요청을 LIST 사진처럼 적습니다. 첫 낱말 LIST는 원하는 동작이고 둘째 낱말은 폴더입니다. 폴더가 있으면 서버가 OK와 목록을, 없으면 없음을 돌려주기로 합니다. 실제 HTTP를 배우기 전, 약속이 메시지 뜻을 어떻게 정하는지 알아보는 모형입니다.

folders = {"사진": ["a.jpg", "b.jpg"], "문서": ["계획.txt"]}

def serve(request):
    verb, separator, folder = request.partition(" ")
    if verb != "LIST" or not separator or not folder:
        return "잘못된 요청"
    if folder not in folders:
        return "없음"
    return "OK " + ", ".join(folders[folder])

for request in ("LIST 사진", "LIST 음악", "OPEN 사진"):
    print(request, "→", serve(request))

실행 결과

LIST 사진 → OK a.jpg, b.jpg
LIST 음악 → 없음
OPEN 사진 → 잘못된 요청

코드 안에서는 Python 함수 호출로 요청과 응답을 흉내 냈습니다. 서로 다른 컴퓨터에서 같은 모양의 메시지를 보내려면 글자를 바이트로 바꾸고, 수신할 프로그램까지 전달하는 네트워크가 더 필요합니다. 실제 예의 웹 요청은 다음 단원에서 이어 봅니다.

요청이 답을 받는 방식은 통신 목적에 달려 있다

사진 다운로드 외에도 프린터에 문서를 보내거나, 채팅 메시지를 받거나, 센서 값을 주기적으로 전달할 수 있습니다. 웹에서 요청과 응답으로 역할을 읽는 방법은 유용합니다. 상대 둘이 번갈아 새로운 요청을 시작하거나 한쪽이 알림을 계속 보내는 설계도 있습니다. 통신마다 어떤 메시지가 언제 생기는지 먼저 확인합니다.

한눈에 정리

  • 호스트는 통신의 끝점이 될 수 있는 기기나 컴퓨터다.
  • 요청을 시작하고 서비스 결과를 받는 쪽이 클라이언트, 요청을 처리하는 쪽이 서버다.
  • 프로토콜은 통신 당사자가 메시지를 주고받으며 의미를 해석하도록 정한 약속이다.
