NW04·1

DNS 이름을 주소로 찾고 캐시하기

도메인 이름의 주소를 누가 알고 있는지 추적합니다. 이미 받은 주소를 언제까지 재사용할 수 있는지도 초 단위로 계산합니다.

이 장을 읽고 나면

  • 사람이 쓰는 도메인 이름과 IP 주소, 서비스의 포트를 구분한다.
  • 스텁, 재귀 해석기, 권한 서버가 DNS 조회에서 하는 일을 설명한다.
  • TTL을 보고 캐시를 언제까지 재사용할 수 있는지 계산한다.

이름을 주소로 해석한다

주소창에 https://book.study.example/을 넣었다고 합시다. book.study.example은 사람과 프로그램이 쓰는 이름입니다. 인터넷 계층의 IP 패킷에는 도착지 IP 주소가 필요합니다. DNS는 이름에 해당하는 레코드를 찾는 분산 시스템입니다. A 레코드에는 IPv4 주소, AAAA 레코드에는 IPv6 주소가 들어갑니다. 하나의 이름이 주소 여러 개를 가리키거나, CNAME 레코드가 별칭에서 다른 이름을 가리킬 수 있습니다.

이름에 대응하는 IP를 얻은 뒤 애플리케이션이 연결에 사용할 전송 프로토콜과 포트를 정합니다. 가령 여기서 HTTPS를 TCP로 접속한다면, 포트를 따로 적지 않은 경우 보통 목적지 포트 443을 씁니다. A나 AAAA 주소 레코드에 그 포트가 들어 있다고 생각하면 안 됩니다. 이 장의 이름과 주소는 문서용이며, 실제 외부에 조회하지 않는 가상 예입니다.

재귀 해석기가 필요한 서버에 질문한다

앱이 운영체제의 이름 조회를 호출하면, 단말의 스텁 해석기가 일반적으로 재귀 해석기에 조회를 의뢰합니다. 재귀 해석기는 요청자가 여러 DNS 서버를 직접 찾아다니지 않도록 답이나 실패 결과를 반환합니다. 답이 캐시에 없다면 이미 아는 위임 정보에서 시작하거나, 필요한 경우 루트부터 내려갑니다.

도메인 이름에서 오른쪽의 점부터 위계를 읽습니다. book.study.example.의 마지막 점은 루트입니다. 그림은 루트에 .example 서버가 있다고 가정한 가상 계층입니다. 실제 공개 DNS에서 문서용 .example을 이 그림처럼 조회하라는 뜻은 아닙니다. 루트나 상위 서버는 관리 책임을 아래 영역에 위임할 수 있습니다. 권한 서버는 맡은 영역의 레코드에 대해 권한 있는 답을 제공합니다. 재귀 해석기는 원본의 관리 주체가 아니어도 다른 서버에서 얻은 답을 돌려줄 수 있습니다.

TTL이 지나면 일반 캐시 답을 다시 확인한다

재귀 해석기가 t=0에 자료를 받았고, 레코드의 TTL이 120초라고 합시다. 이 예에서는 캐시 만료 시각이 120초입니다. 30초에는 90초, 90초에는 30초가 남습니다. 같은 종류의 질문이 다시 들어와도 캐시에 들른 시각부터 120초를 새로 세지는 않습니다.

일반적인 캐시 동작을 보여 주는 예제입니다. 일부 재귀 해석기는 갱신할 권한 서버에 닿지 못할 때, 설정과 조건에 따라 만료된 자료를 잠시 제공할 수 있습니다. RFC 8767에서 이 예외를 다룹니다.

권한 서버가 60초에 새 주소로 변경해도 이미 남아 있는 캐시는 TTL 동안 예전 답을 제공할 수 있습니다. 120초에 만료된 후 다시 조회하면 예제에서는 새 주소가 옵니다. 실제 해석기의 미리 갱신, 캐시 정책과 실패 처리에 따라 관측 결과는 달라질 수 있습니다. 이름과 레코드 종류는 따로 기록하기 때문에 A 답을 AAAA 요청의 답으로 재사용하지 않습니다.

같은 조회를 여러 시각에 모형으로 실행한다

cache = {}
question = ("book.study.example.", "A")

def resolve(now_seconds):
    if question in cache:
        address, deadline = cache[question]
        if now_seconds < deadline:
            return "cache", address, deadline - now_seconds

    # A fictional authoritative answer, with a change at t=60.
    address = "192.0.2.20" if now_seconds < 60 else "192.0.2.21"
    ttl = 120
    cache[question] = (address, now_seconds + ttl)
    return "new", address, ttl

for seconds in (0, 30, 90, 120):
    kind, address, remaining = resolve(seconds)
    print(seconds, kind, address, remaining)
0 new 192.0.2.20 120
30 cache 192.0.2.20 90
90 cache 192.0.2.20 30
120 new 192.0.2.21 120

각 줄은 시각(초), 새 응답 또는 캐시, 주소, 남은 TTL(초)입니다. new는 이 프로그램이 만든 합성 응답입니다. 실제 DNS 요청은 보내지 않습니다.
