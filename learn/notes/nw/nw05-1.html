IPv4·IPv6 주소와 접두사 범위

슬래시가 붙은 주소에서 어떤 비트가 같고 어떤 비트가 달라질 수 있는지 봅니다. 블록을 직접 계산하고 그 모든 주소를 호스트에 배정할 수 있는지도 따로 확인합니다.

이 장을 읽고 나면

  • IPv4와 IPv6 주소의 길이·표기를 읽는다.
  • CIDR 접두사로 주소 블록의 시작·끝과 크기를 계산한다.
  • 일반 IPv4 서브넷과 점대점 /31, 단일 주소 /32를 구분한다.

주소의 앞부분을 몇 비트 고정할지 정한다

IPv4 주소는 32비트입니다. 8비트씩 네 묶음으로 나눠 192.0.2.77처럼 각 값을 0부터 255 사이의 십진수로 적습니다. CIDR 접두사에서 슬래시 뒤의 수는 앞에서부터 고정하는 비트 개수입니다. /26이면 26비트를 공유하는 주소들의 블록이고 나머지 6비트가 달라질 수 있습니다. 이런 주소 블록을 서브넷으로 쓸 수 있습니다.

192.0.2.77의 마지막 묶음 77을 8비트로 쓰면 01001101입니다. 처음 세 묶음에서 이미 24비트를 썼으므로 이 마지막 묶음에서는 앞의 01 두 비트를 고정합니다. 나머지를 전부 0으로 두면 01000000 = 64, 전부 1로 두면 01111111 = 127입니다. 따라서 주소 블록은 192.0.2.64/26이고 끝은 192.0.2.127입니다.

서브넷 마스크는 고정 부분을 1, 나머지를 0으로 채운 값입니다. /26에서 첫 세 묶음은 255, 마지막은 11000000 = 192여서 255.255.255.192입니다. 주소와 마스크의 각 자리에서 두 비트가 모두 1인 자리만 남기면(비트 AND) 블록의 시작 주소를 얻습니다. 77 AND 192 = 01001101 AND 11000000 = 01000000 = 64입니다.

예전에는 첫 비트들로 주소의 등급(클래스)을 정해 A는 /8, B는 /16, C는 /24로 네트워크 크기가 고정됐습니다. 이 방식은 주소를 크게 낭비해서, 1993년부터 경계를 아무 비트에나 둘 수 있는 CIDR(Classless Inter-Domain Routing, 지금 기준은 RFC 4632)로 바뀌었습니다. 오늘날 라우팅에서는 클래스를 보지 않고 접두사 길이만 봅니다.

블록의 전체 주소와 할당 가능한 주소를 구별한다

일반적인 IPv4 다중접속 서브넷인 위 예에서는 첫 주소 .64가 네트워크를 가리키고 마지막 .127이 서브넷 브로드캐스트 주소입니다. 따라서 이 둘을 호스트 인터페이스에 배정하지 않는 기준이면 .65부터 .126까지 62개가 남습니다. 64는 블록 크기이고 62는 이 관례의 호스트 범위 크기입니다. 실제 망에서 그중에 라우터에 이미 배정한 값 등은 더 빼고 세어야 합니다.

/31은 2개 주소를 담습니다. RFC 3021의 점대점 링크에서는 두 끝점에 이 두 주소를 모두 쓸 수 있습니다. 예로 192.0.2.8/31의 .8과 .9입니다. 두 주소에서 기계적으로 네트워크와 브로드캐스트를 빼면 이 조건을 놓칩니다. /32는 정확히 한 IPv4 주소만 지정하는 접두사로, 한 호스트를 가리키는 경로에 쓸 수 있습니다.

IPv6는 128비트를 16진수로 나누어 쓴다

IPv6 주소는 128비트이고, 최대 4자리인 16진수 그룹 여덟 개를 콜론으로 나눕니다. 앞쪽 0은 그룹마다 생략할 수 있고, 연속한 0 그룹은 주소 안에서 한 번만 ::로 줄여 쓸 수 있습니다. 2001:db8:1234:56::abcd를 여덟 그룹으로 펼치면 그림과 같습니다.

이 IPv6 주소의 /64 블록은 2001:db8:1234:56::/64, 전체 주소 수는 2⁶⁴입니다. 이 수는 주소 공간의 크기입니다. IPv6의 주소 종류와 설정을 살펴야 실제로 지정할 수 있는 범위를 말할 수 있습니다. IPv6에는 IPv4의 브로드캐스트 주소가 없고, 여러 대상에게 보내는 역할은 필요한 경우 멀티캐스트가 맡습니다.

도구로 계산하고 손계산과 비교한다

from ipaddress import ip_interface, ip_network

interface = ip_interface("192.0.2.77/26")
net = interface.network
print(net, net.netmask)
print("total:", net.num_addresses)
print("ordinary hosts:", net.network_address + 1, net.broadcast_address - 1)
print("broadcast:", net.broadcast_address)

point_to_point = ip_network("192.0.2.8/31")
print("/31:", " ".join(map(str, point_to_point.hosts())))

v6 = ip_interface("2001:db8:1234:56::abcd/64")
print(v6.ip.exploded)
print(v6.network, v6.network.num_addresses)

실행 결과

192.0.2.64/26 255.255.255.192
total: 64
ordinary hosts: 192.0.2.65 192.0.2.126
broadcast: 192.0.2.127
/31: 192.0.2.8 192.0.2.9
2001:0db8:1234:0056:0000:0000:0000:abcd
2001:db8:1234:56::/64 18446744073709551616

코드는 Python 표준 라이브러리로 주소를 계산할 뿐 네트워크에 연결하지 않습니다. 교재의 IPv4 192.0.2.0/24와 IPv6 2001:db8::/32는 문서용 주소입니다.
