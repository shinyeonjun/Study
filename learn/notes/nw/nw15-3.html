IPv6 이웃 탐색의 멀티캐스트와 캐시 상태

라우팅에서 다음 홉을 골랐어도 그 링크의 프레임을 만들 주소가 필요합니다. IPv6의 이웃에게 묻는 주소와 캐시의 진행을 계산합니다.

이 장을 읽고 나면

  • IPv6의 최종 목적지와 현재 링크에서 찾는 이웃을 구분한다.
  • solicited-node IPv6 그룹과 해당 Ethernet 멀티캐스트 주소를 계산한다.
  • 이웃의 주소가 캐시에 있는 상태와 최근 도달이 확인된 상태를 구분한다.

IP에서 정한 다음 홉을 링크 계층 주소로 대응합니다

한 링크에서 직접 전달할 IPv6 주소는 목적지 자체일 수도, 다른 링크로 넘길 라우터일 수도 있습니다. 이웃 탐색(Neighbor Discovery, ND)은 IPv6가 ICMPv6 메시지로 라우터와 이웃에 대한 정보를 얻는 기능입니다. 주소 해석을 할 때는 앞 장에서 고른 다음 홉과 출구 링크가 먼저 필요합니다. 멀리 있는 주소를 보낼 때 그 먼 상대의 MAC을 같은 링크에 묻는 절차는 아닙니다. 링크 로컬 주소로 next hop을 쓰면 어느 출구 인터페이스의 주소인지 구분합니다.

예를 들어 가상 Ethernet 링크의 다음 홉은 fe80::2a3b:4c5d입니다. 출발 주소가 정해진 일반 주소 해석에서 Neighbor Solicitation(NS)에는 이 주소 전체가 질의 대상 필드로 들어갑니다. 초기 질의의 IPv6 목적지는 대상의 solicited-node 멀티캐스트 그룹입니다. ff02::1:ff00:0/104에 대상의 하위 24비트 3b:4c:5d를 붙여 ff02::1:ff3b:4c5d를 얻습니다.

IPv6 멀티캐스트를 Ethernet에 옮길 때는 33:33 뒤에 IPv6 멀티캐스트 주소의 하위 32비트를 붙입니다. 이번 그룹의 하위 32비트가 ff:3b:4c:5d라서 요청 프레임의 MAC은 33:33:ff:3b:4c:5d입니다. 이 값은 요청을 듣는 그룹의 주소입니다. 응답의 내용에서 실제 이웃의 링크 계층 주소를 확인합니다. 서로 다른 IPv6 주소가 하위 24비트를 공유할 수 있으므로 그룹에 속했다고 모두 같은 이웃인 것은 아닙니다.

지금 주소를 아는 것과 최근 도달을 확인한 것을 나눕니다

대상 주소의 MAC을 아직 찾지 못해 해석 중인 캐시는 INCOMPLETE입니다. 대상에서 온 유효한 응답 Neighbor Advertisement(NA)로 주소 정보와 요청에 대한 도달성이 확인되면 REACHABLE로 바뀔 수 있습니다. 시간이 흘러 최근성 기준을 넘으면 주소를 저장한 채 STALE이 됩니다. STALE 항목을 보낼 때는 그 주소를 사용하면서 DELAY 상태에서 상위 계층 등의 확인을 잠시 기다릴 수 있습니다. 더 최근의 확인이 없으면 PROBE 상태에서 알고 있는 이웃에게 직접 도달을 다시 검사합니다.

이 예에서는 t=0에 도달을 확인하고 유지 기준 20초 뒤부터 STALE로 봅니다. t=22에 사용하면 DELAY를 시작하고 5초가 지나도록 별도 확인이 없을 때 t=27에 PROBE로 넘어갑니다. 실제 ND에서 사용되는 시간, 응답 조건과 갱신은 여러 사건에 따릅니다. IPv6의 로컬 링크 판단은 주소 모양만으로 일반화하지 않고, 라우터 광고에서 얻은 on-link 정보나 별도 경로를 확인합니다.

주소 비트와 캐시 시각을 각각 계산합니다

from ipaddress import IPv6Address

target = IPv6Address("fe80::2a3b:4c5d")
low24 = int(target) & ((1 << 24) - 1)
base = int(IPv6Address("ff02::1:ff00:0"))
group = IPv6Address(base | low24)
low32 = int(group) & ((1 << 32) - 1)
mac = bytes.fromhex("3333") + low32.to_bytes(4, "big")
print("low 24:", f"{low24:06x}")
print("solicited node:", group)
print("Ethernet multicast:", mac.hex(":"))

confirmed = 0
fresh_seconds = 20
used = 22
wait = 5
print("at 21:", "STALE" if 21-confirmed >= fresh_seconds else "REACHABLE")
print("DELAY starts:", used, "PROBE starts:", used + wait)
low 24: 3b4c5d
solicited node: ff02::1:ff3b:4c5d
Ethernet multicast: 33:33:ff:3b:4c:5d
at 21: STALE
DELAY starts: 22 PROBE starts: 27

이 코드는 문자열에서 비트를 계산합니다. VLAN별 링크 영역은 앞 장의 브리지 범위에서 정한 뒤, 그 출구에서만 이웃을 찾습니다.
