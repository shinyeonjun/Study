NW04·2

전송의 종점을 구별하고 주소를 임대받기

하나의 서버 포트에 여러 연결이 들어가는 과정부터 봅니다. 이어서 새 단말이 자기 주소를 얻고, 그 주소를 얼마나 오래 사용할 수 있는지 계산합니다.

이 장을 읽고 나면

  • IP 주소와 전송 포트가 각각 어느 범위에서 쓰이는지 설명한다.
  • TCP 연결이 같은 서버 포트에 여러 개 존재할 수 있는 이유를 말한다.
  • DHCPv4 주소 제안과 임대, 갱신과 만료를 시각 계산으로 확인한다.

IP 주소에 전송 프로토콜과 포트를 더한다

DNS에서 주소를 찾았다면 이제 그 주소의 호스트에서 어느 전송 서비스와 통신할지 정합니다. IP 주소는 네트워크 계층의 전달에, 포트는 TCP나 UDP에서 이쪽과 저쪽의 종점을 구별하는 데 씁니다. 포트 번호는 16비트이고, TCP와 UDP는 같은 숫자를 각자의 포트 공간에서 쓸 수 있습니다. 번호의 의미는 서비스와 장치 설정에 따라 확인합니다.

예시의 클라이언트는 IPv4 주소 192.0.2.23에서 서버 198.51.100.20의 TCP 443에 연결합니다. 운영체제가 첫 연결에 임시 반환 포트 53000, 두 번째 연결에 53001을 고를 수 있습니다. 그림과 실습은 문서용 주소를 쓰는 모형입니다.

TCP 연결은 두 종점으로 구분합니다. 한 방향으로 기록할 때 출발 IP·출발 포트·도착 IP·도착 포트와 전송 프로토콜을 함께 쓰면 어느 흐름을 말하는지 분명해집니다. 포트 443과 IP 주소만 적으면 기다리는 서버 종점은 가리킬 수 있지만, 그 서버에 붙은 클라이언트 연결 중 하나를 선택할 수는 없습니다. 같은 서버에 연결 여러 개가 붙어도 응답이 도착할 반대편 종점을 연결마다 기억합니다.

DHCPv4로 사용할 주소와 설정을 빌린다

새 장치가 네트워크에 들어왔을 때 사용할 IP 주소와 설정을 자동으로 받는 방법이 DHCP입니다. 여기서는 IPv4를 다룹니다. 아직 자기 주소를 쓰기 전인 클라이언트는 보통 로컬 링크에 브로드캐스트로 DHCP 서버를 찾습니다. 네트워크에 따라 중계 장치가 다른 망의 서버에 요청을 전달할 수 있습니다. DHCPv4는 일반적으로 UDP 서버 포트 67, 클라이언트 포트 68을 씁니다.

서버가 하나 이상 응답하면 클라이언트는 제안 하나를 고를 수 있습니다. 주소 외에 서브넷 마스크, 기본 라우터, DNS 서버 주소도 설정으로 받을 수 있습니다. DHCP가 알려 준 DNS 서버는 이름을 조회할 상대입니다. DHCP 주소 할당은 도메인 이름에 대한 DNS 응답과 별개의 절차입니다.

임대 갱신에 실패하면 만료 뒤 그 주소를 쓰지 않는다

임대는 정해진 시간 동안 주소를 사용하도록 한 약속입니다. 0분에 80분 임대를 받았고 서버의 별도 설정을 적용하지 않는 단순 예를 봅시다. 기본 계산에서 T1은 80×1/2=40분, T2는 80×7/8=70분입니다. T1에 기존 서버에 갱신을 요청하고, T2까지 성공하지 않으면 다른 서버에도 갱신을 요청할 수 있는 단계로 넘어갑니다. 실제 메시지 전송 시각과 재시도는 프로토콜에 정의된 타이머와 옵션을 따릅니다.

성공적으로 갱신하면 새 임대에 맞춰 시각을 다시 계산합니다. 80분까지 유효한 갱신을 얻지 못했다면 만료된 주소를 계속 사용하지 않습니다. DNS의 TTL은 답을 캐시해 둘 시간이고, DHCP 임대 시간은 현재 단말이 주소를 사용해도 되는 기간입니다.

연결 식별자와 임대 시각을 비교한다

connections = [
    ("TCP", "192.0.2.23", 53000, "198.51.100.20", 443),
    ("TCP", "192.0.2.23", 53001, "198.51.100.20", 443),
]
print("server ports:", {connection[-1] for connection in connections})
print("distinct connections:", len(set(connections)))

lease_minutes = 80
start_minute = 0
t1 = start_minute + lease_minutes / 2
t2 = start_minute + lease_minutes * 7 / 8
expires = start_minute + lease_minutes
print(f"T1 {t1:.0f} min, T2 {t2:.0f} min, expires {expires:.0f} min")
server ports: {443}
distinct connections: 2
T1 40 min, T2 70 min, expires 80 min

서버 포트의 집합에는 443 하나만 있지만, 두 연결을 기록한 튜플은 서로 다릅니다. 두 번째 계산은 기본 T1과 T2만 구합니다. 실제 DHCP 메시지는 주고받지 않습니다.
