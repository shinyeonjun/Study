공부 교재

네트워크

NW01·2

집의 LAN에서 여러 네트워크로 건너가기

집에서 같은 프린터에 문서를 보내는 일과 인터넷에 있는 교재를 여는 일은 둘 다 통신입니다. 목적지가 같은 로컬 네트워크에 있는지에 따라 통신이 지나갈 범위가 달라집니다.

이 장을 읽고 나면

  • LAN과 서로 연결된 네트워크들의 관계를 그린다.
  • 가정용 공유기의 로컬 연결과 라우팅 역할을 구별한다.
  • 집 안 목적지와 외부 서버의 모형 경로를 비교한다.

한 공간의 기기를 서로 통신할 수 있게 묶는다

집 안에 휴대폰, 노트북, 프린터가 있습니다. 세 기기가 같은 집의 로컬 네트워크에 연결됐다면, 설정이 허용하는 경우 휴대폰에서 프린터로 인쇄를 보낼 수 있습니다. 이때 메시지는 집 외부의 인터넷 서버를 꼭 거쳐야 하는 것은 아닙니다.

이렇게 비교적 제한된 범위에서 기기를 연결한 망을 LAN(Local Area Network)이라 부릅니다. 유선과 무선은 기기를 그 망에 연결하는 방식입니다. 같은 이름의 Wi-Fi가 잡힌다는 사실만으로 서로 통신할 수 있다고 단정할 수는 없습니다. 예를 들어 손님용 망을 집안 장치와 분리해 운영하는 설정이 있습니다.

서로 다른 망 사이에서 다음 연결을 고른다

라우터는 여러 네트워크를 잇고, 목적지 쪽으로 어느 연결에 데이터를 내보낼지 결정하는 장치입니다. 가정용 공유기는 라우터 역할과 함께 무선 기기를 LAN에 연결하는 액세스 포인트, 여러 유선 기기를 잇는 스위치 기능을 한 기기에 넣은 제품이 많습니다. 이때 휴대폰에서 같은 LAN의 프린터로 보내는 데이터는 공유기 기기를 지나더라도 집 밖으로 나가는 라우팅을 할 필요는 없습니다.

외부 웹 서버에 요청이 가면 집 LAN에서는 그 목적지의 호스트로 곧바로 보낼 수 없습니다. 집의 라우터에 넘기고, 이후 통신사의 네트워크와 연결된 여러 장치가 목적지 쪽으로 전달합니다. 인터넷은 공통된 통신을 할 수 있도록 서로 연결된 여러 네트워크의 집합입니다. 웹은 그 위에서 이용하는 서비스의 하나입니다.

목적지에 따라 두 모델 경로를 비교한다

작은 예제의 조건

이 집에서는 프린터와 노트북이 같은 LAN에 있고, 교재 서버는 다른 망에 있습니다. 내부 프린터는 연결 설정이 허용합니다. 인터넷 교재 서버로 나가는 출구는 집의 라우터 한 곳으로 정했습니다. 각 통신이 어디에서 끝나는지 아래 코드로 표시합니다.

destinations = {"프린터": "집 LAN", "교재 서버": "외부 네트워크"}

def initial_route(name):
    if destinations[name] == "집 LAN":
        return "노트북 → 집 LAN 안의 프린터"
    return "노트북 → 집 라우터 → 외부 네트워크 → 교재 서버"

for name in destinations:
    print(name + ":", initial_route(name))

실행 결과

프린터: 노트북 → 집 LAN 안의 프린터
교재 서버: 노트북 → 집 라우터 → 외부 네트워크 → 교재 서버

코드는 두 경우를 구별하는 개념도입니다. 같은 LAN에 있는지 계산하려면 주소와 네트워크 범위가 필요하고, 여러 목적지 중 다음 연결을 찾는 방법도 알아야 합니다. 이 내용은 이름과 주소 단원 및 IP 단원에서 이어집니다.

중간의 어디에서 일이 멈췄는지 생각한다

인터넷이 끊겼는데 집 프린터는 여전히 동작한다면 집 LAN의 연결은 적어도 그 두 기기 사이에서 작동하고 있습니다. 반대로 인터넷 접속이 된다고 해서 모든 로컬 장치에 접근할 수 있는 것은 아닙니다. 프린터가 다른 네트워크에 연결돼 있거나 인쇄 서비스가 멈췄을 수 있습니다. 이처럼 한 통신이 지나가는 범위와 그 안에서 요청을 처리하는 프로그램을 각각 생각합니다.

한눈에 정리

  • LAN은 가까운 범위에서 기기를 연결하는 네트워크다.
  • 라우터는 네트워크 사이를 잇고 목적지 쪽으로 전달한다. 가정용 공유기에는 다른 연결 기능도 들어갈 수 있다.
  • 외부로 나가는 요청과 집 안에서 끝나는 요청은 지나가는 구간이 다르다.
