NW14·1

수신 조각의 경계와 독립적인 유한 프레임 파서

한 번 읽었을 때 길이의 절반만 오거나, 한 기록의 끝과 다음 기록의 시작을 같이 받을 수 있습니다. 파서가 기억해야 할 상태를 명세합니다.

이 장을 읽고 나면

  • 수신 조각이 달라도 동일한 프레임이 나오는 규칙을 적는다.
  • 길이 헤더를 검사한 뒤 상한을 넘는 본체를 기다리지 않는다.
  • 상태 불변식과 EOF 조건으로 파서를 검산한다.

스트림 규약의 바이트 순서와 길이 상한을 정합니다

NW09의 길이 접두어는 TCP 한 방향의 바이트열에서 앱 메시지의 끝을 찾는 방법입니다. 이제 송신과 똑같은 단위로 읽히기를 기대하지 않는 증분 파서를 정의합니다. 합성 규약은 길이 헤더 2바이트를 큰 자리 먼저 읽고, 이어서 헤더가 지정한 수의 본체를 읽습니다. 길이는 본체의 바이트 수입니다. 이 규약의 허용 범위는 1~5 B입니다. 정수 0과 6 이상은 잘못된 길이입니다. 본체의 바이트는 임의여서 내부의 0도 일반 데이터입니다.

모형의 두 본체는 ASCII ‘OK’와 ‘xyz’입니다. 전체 바이트열은 00 02 4F 4B 00 03 78 79 7A로 9바이트입니다. 이를 한 덩어리로 받든 네 조각 [00], [02 4F], [4B 00 03 78], [79 7A]로 받든 기록열은 똑같습니다. TCP는 읽기의 호출 크기나 수신 이벤트마다 프레임을 완성해 준다는 규약이 없습니다.

헤더·본체 중 기다리는 상태를 보존합니다

파서에 다음 두 상태를 둡니다. 헤더 상태에서는 아직 본체 길이를 모르므로 길이 바이트 두 개가 모일 때만 판정합니다. 범위에 맞으면 길이를 저장해 본체 상태로 넘어갑니다. 범위를 벗어나면 헤더를 읽은 즉시 오류로 보고합니다. 본체 상태에서는 지금까지 모은 크기를 확인하고, 지정된 수에 정확히 도달하면 기록을 하나 전달한 뒤 다음 헤더 상태로 돌아갑니다. 한 조각에 뒤 프레임의 시작이 섞일 수 있어 남은 바이트에도 같은 동작을 반복합니다.

조각이 끝나도 이전 조각의 미완성 상태를 버리지 않습니다. 증분 처리의 불변식은 ‘지금까지 다 읽은 프레임은 입력 접두부에서 정확히 한 번씩 이어지고, 남은 상태는 다음 미완성 프레임 하나만 나타낸다’입니다. 한 바이트마다 헤더 또는 본체 중 한쪽에만 추가하고, 완료할 때마다 상태를 지우므로 다음 조각에서도 불변식이 유지됩니다. 예제에서 파서가 따로 담아 두는 미완성 자료는 2바이트 헤더 또는 길이 상한 이하의 본체입니다. 호출자가 제공한 입력 조각의 메모리와 이미 반환한 기록은 별도입니다.

수신 스트림이 끝나면 새 헤더를 읽기 직전처럼 비어 있는 상태에서만 정상 종료입니다. 헤더 한 바이트나 본체 일부가 남아 있으면 맞지 않는 길이의 기록이 아니라 잘린 프레임입니다. 오류 전에 이미 전달한 프레임들의 효과가 되돌아가는 규약은 이 예에 두지 않습니다.

모든 바이트를 한 번씩 파서에 공급합니다

def decode(chunks):
    header = bytearray()
    payload = bytearray()
    size = None
    for chunk in chunks:
        for value in chunk:
            if size is None:
                header.append(value)
                if len(header) == 2:
                    size = int.from_bytes(header, "big")
                    if not 1 <= size <= 5:
                        raise ValueError("invalid frame length")
                    header.clear()
            else:
                payload.append(value)
                if len(payload) == size:
                    record = bytes(payload)
                    payload.clear()
                    size = None
                    yield record
    if header or size is not None:
        raise ValueError("truncated frame")

wire = bytes.fromhex("00 02 4f 4b 00 03 78 79 7a")
chunks = [wire[:1], wire[1:3], wire[3:7], wire[7:]]
for data in ([wire], chunks, [wire[i:i+1] for i in range(len(wire))]):
    print(list(decode(data)))

for bad in (bytes.fromhex("00 06"), wire[:-1]):
    try:
        list(decode([bad]))
    except ValueError as error:
        print(error)

위 예제의 유효 범위는 이 교재 규약에서 정한 값입니다. 다른 규약에서는 바이트 순서·0 길이 처리·최대 길이를 각자의 명세로 맞춰야 합니다. 다음 장에서는 스트림이 아직 살아 있는 동안의 타임아웃과 방향별 종료를 다룹니다.
