INNER JOIN, LEFT JOIN과 비어 있는 짝

고객 표의 이름 옆에 주문 번호를 붙입니다. 주문이 두 건인 고객은 두 줄로 나타나고, 주문이 없는 고객이 남는지는 결합의 종류에 달려 있습니다.

이 장을 읽고 나면

  • INNER JOIN과 LEFT JOIN의 결과 행을 손으로 적는다.
  • 일대다 결합에서 결과가 왜 늘어나는지 설명한다.
  • LEFT JOIN에 붙이는 ON 조건과 WHERE 조건의 차이를 구별한다.

같은 키를 가진 행의 짝 만들기

customers AS c JOIN orders AS o ON c.customer_id = o.customer_id는 고객 번호가 일치하는 고객 행과 주문 행의 짝을 만듭니다. AS c와 AS o는 각각 표의 별칭입니다. 두 표에 customer_id라는 열이 있으므로 어떤 표의 열인지 c.customer_id처럼 명시합니다.

INNER JOIN에서는 ON의 조건이 참인 짝만 결과에 나타납니다. 고객 1에게 주문 101, 102가 있고 고객 2에 주문 103, 104가 있습니다. 고객 3은 주문과 짝이 없으므로 이 결합에는 나오지 않습니다. 결과에서 한 행의 입도는 고객 한 명에서 고객과 주문의 짝으로 바뀝니다.

왼쪽의 모든 고객을 보존하기

LEFT JOIN은 조건을 만족하는 짝을 모두 돌려주며, 짝이 없는 왼쪽 행에 한해 오른쪽 열이 모두 NULL로 채워진 결과 행을 한 줄 돌려줍니다. 정상 주문 원본에서 주문 번호는 NULL이 아니지만, 결과의 주문 번호는 손님 3에게 주문 짝이 없어서 NULL입니다. 예제 자료에서 주문에 연결됐지만 쿠폰액만 NULL인 경우도 있습니다. 이 두 경우를 구별하려면 오른쪽 주문의 기본 키가 NULL인지 확인합니다.

LEFT JOIN으로 고객별 주문 건수를 세면 주문 없는 고객 3의 결과에도 한 행이 있습니다. 따라서 COUNT(*)는 1이고 COUNT(o.order_id)는 0입니다. 오른쪽 표의 존재할 때 필수인 열을 세면 주문 건수가 됩니다.

먼저 짝의 기준을 좁힐까, 결과 행을 걸러낼까?

LEFT JOIN orders AS o ON c.customer_id=o.customer_id AND o.status='paid'는 결제 완료 주문만 연결할 후보로 봅니다. 짝이 없는 고객 3의 NULL 행은 유지됩니다. 반대로 고객 번호만으로 연결한 뒤 WHERE o.status='paid'를 적용하면 고객 3에 대해 NULL = 'paid'가 참이 아니므로 행이 빠집니다. 결제한 주문을 가진 고객만 나와야 하는 비교라면 그 조건을 사용해도 됩니다.

왜 그럴까?

어떤 고객에게 미결제 주문만 한 건 있다면, 결제 완료 조건을 ON에 둔 LEFT JOIN에서는 어떻게 보일까?

모범 답 보기

결제 완료 주문과 짝을 만들 수 없으므로 고객 행은 남고 오른쪽 주문 열은 모두 NULL입니다. 해당 고객의 모든 주문이 없다는 뜻은 아닙니다.

행 수와 주문 건수 같이 확인하기

실행 예제

import sqlite3

with sqlite3.connect(":memory:") as db:
    db.execute("PRAGMA foreign_keys = ON")
    db.executescript("""
    CREATE TABLE customers (
        customer_id INTEGER PRIMARY KEY,
        name TEXT NOT NULL
    );
    CREATE TABLE orders (
        order_id INTEGER PRIMARY KEY,
        customer_id INTEGER NOT NULL REFERENCES customers(customer_id),
        order_date TEXT NOT NULL,
        status TEXT NOT NULL CHECK (status IN ('paid', 'pending')),
        total_won INTEGER NOT NULL CHECK (total_won >= 0),
        coupon_won INTEGER CHECK (coupon_won >= 0)
    );
    """)
    db.executemany("INSERT INTO customers VALUES (?, ?)", [
        (1, 'Mina'),
        (2, 'Jun'),
        (3, 'Sol'),
    ])
    db.executemany("INSERT INTO orders VALUES (?, ?, ?, ?, ?, ?)", [
        (101, 1, '2025-01-02', 'paid', 10000, None),
        (102, 1, '2025-01-03', 'paid', 15000, 1000),
        (103, 2, '2025-01-04', 'pending', 12000, None),
        (104, 2, '2025-01-05', 'paid', 15000, 0),
    ])

    for join in ("INNER JOIN", "LEFT JOIN"):
        # 두 SQL 구문은 프로그램에서 고정한 두 값입니다.
        rows = db.execute(f"""
            SELECT c.customer_id, o.order_id
            FROM customers AS c {join} orders AS o
              ON c.customer_id = o.customer_id
            ORDER BY c.customer_id, o.order_id
        """).fetchall()
        print(join, rows)

    counts = db.execute("""
        SELECT c.customer_id, COUNT(*) AS rows_kept, COUNT(o.order_id) AS orders_found
        FROM customers AS c LEFT JOIN orders AS o
          ON c.customer_id = o.customer_id
        GROUP BY c.customer_id
        ORDER BY c.customer_id
    """).fetchall()
    print("counts:", counts)

    paid_in_on = db.execute("""
        SELECT c.customer_id, o.order_id
        FROM customers AS c LEFT JOIN orders AS o
          ON c.customer_id = o.customer_id AND o.status = ?
        ORDER BY c.customer_id, o.order_id
    """, ("paid",)).fetchall()
    paid_in_where = db.execute("""
        SELECT c.customer_id, o.order_id
        FROM customers AS c LEFT JOIN orders AS o
          ON c.customer_id = o.customer_id
        WHERE o.status = ?
        ORDER BY c.customer_id, o.order_id
    """, ("paid",)).fetchall()
    print("ON paid:", paid_in_on)
    print("WHERE paid:", paid_in_where)
db.close()

실행 결과

INNER JOIN [(1, 101), (1, 102), (2, 103), (2, 104)]
LEFT JOIN [(1, 101), (1, 102), (2, 103), (2, 104), (3, None)]
counts: [(1, 2, 2), (2, 2, 2), (3, 1, 0)]
ON paid: [(1, 101), (1, 102), (2, 104), (3, None)]
WHERE paid: [(1, 101), (1, 102), (2, 104)]

예제의 결합 방식 두 문자열은 프로그램 안에서 정한 SQL 구문입니다. 질의에 비교할 사용자 입력값을 보내는 경우에는 앞 장처럼 자리표시자를 사용합니다.

한눈에 정리

개념확인할 것
결합의 입도행 하나가 매칭된 짝 하나를 나타낼 수 있다.
LEFT JOIN오른쪽과 짝이 없어도 왼쪽 행을 결과에 유지한다.
ON과 WHERE결합 짝을 만드는 조건과 결합 결과에 적용하는 조건을 구분한다.
