DB06·2

페이지를 따라 수집하고 권한·출처 남기기

한 번에 주문을 두 건씩 보내는 자료를 다룹니다. 다음 페이지 신호로 네 건을 모두 모으고, 자료를 다시 확인할 수 있는 기록을 남깁니다.

이 장을 읽고 나면

  • 페이지 번호와 제공자가 정한 커서 방식의 차이를 설명한다.
  • 정상적으로 부여받은 권한을 사용하며 응답 상태별로 처리한다.
  • 출처와 이용 조건을 남기면서 인증 정보를 보호한다.

한 응답에 일부 행만 올 수 있다

API는 결과를 한꺼번에 보내는 대신 페이지로 나눌 수 있습니다. 제공자는 페이지 번호, 시작 위치와 개수, 다음 링크, 불투명한 커서 등 여러 방식을 사용합니다. 커서는 서버가 정한 다음 요청의 값입니다. 첫 페이지는 주문 101, 102와 다음 커서 p2를 줍니다. 두 번째 페이지는 주문 103, 104를 주고 다음 커서는 null입니다.

예제의 종료 기준은 다음 커서가 null인 경우입니다. 페이지당 최대 두 건인데 한 건만 왔다고 끝을 임의로 판단하지 않습니다. 수집 중 원자료가 바뀌면 페이지 사이에 중복과 누락이 생길 수 있어 제공자가 스냅샷이나 일정 기준 시점을 지원하는지 확인합니다.

권한과 응답 상태를 읽는다

인증은 요청자의 신원을 확인하는 과정이고 권한 부여는 그 신원이 어느 자료에 어떤 동작을 할 수 있는지 정하는 과정입니다. 제공자가 발급하고 사용이 허용된 자격만 사용합니다. 실행 환경에 보관한 인증 정보는 소스와 실행 로그, 공유 예제에 복사하지 않습니다. 응답에 개인정보가 있다면 자료를 저장·공유하는 목적과 허용 범위를 확인합니다.

HTTP 401은 유효한 인증 정보가 없는 요청에 사용될 수 있고 403은 요청을 이해했지만 허용하지 않은 경우를 나타냅니다. 이런 때는 공식 안내와 권한을 확인합니다. 429는 요청이 너무 많다는 상태이며 Retry-After를 줄 수 있습니다. 제공자가 정한 간격과 재시도 한도를 따르고 실패한 응답을 성공으로 기록하지 않습니다.

자료를 사용할 수 있는 범위까지 기록하기

자료 위치와 제공자, 이름·버전, 수집 시각·대상 범위·필터, 수집한 페이지와 행, 이용 조건과 표시할 출처를 기록합니다. 웹 화면에 보이거나 요청에 성공했다는 사실만으로 재배포 권리를 결정할 수 없습니다. 개인 연구, 팀 안에서의 공유, 공개 재배포에 각각 어떤 이용 제한이 있는지 확인합니다.

인터넷에 접속하지 않는 두 페이지 예제

아래 함수는 메모리에 준비한 JSON 문자열을 돌려줍니다. 상태와 필수 구조를 검사하며, 반복되는 커서면 모의 실행을 멈춥니다. 받은 시각은 고정된 예시입니다.

실행 예제

import json

fixtures = {
    None: '{"orders":[{"order_id":101},{"order_id":102}],"next_cursor":"p2"}',
    "p2": '{"orders":[{"order_id":103},{"order_id":104}],"next_cursor":null}',
}

def get_mock_page(cursor):
    if cursor not in fixtures:
        return 404, "{}"
    return 200, fixtures[cursor]

cursor = None
seen = set()
orders = []
while True:
    if cursor in seen:
        raise ValueError("repeated cursor")
    seen.add(cursor)
    status, body = get_mock_page(cursor)
    if status != 200:
        raise ValueError(f"page failed: {status}")
    page = json.loads(body)
    if not isinstance(page, dict) or not isinstance(page.get("orders"), list):
        raise ValueError("invalid orders list")
    if "next_cursor" not in page:
        raise ValueError("missing next cursor")
    page_orders = page["orders"]
    if any(not isinstance(row, dict) or type(row.get("order_id")) is not int
           or row["order_id"] <= 0 for row in page_orders):
        raise ValueError("invalid order row")
    orders.extend(page_orders)
    cursor = page["next_cursor"]
    if cursor is None:
        break
    if not isinstance(cursor, str) or not cursor:
        raise ValueError("invalid cursor")

print("order ids:", [row["order_id"] for row in orders])
print("source:", "training-order-fixture/v1")
print("retrieved:", "2025-01-08T00:00:00Z", "pages:", len(seen), "rows:", len(orders))

실행 결과

order ids: [101, 102, 103, 104]
source: training-order-fixture/v1
retrieved: 2025-01-08T00:00:00Z pages: 2 rows: 4
