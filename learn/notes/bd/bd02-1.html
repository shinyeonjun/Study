데이터 탐색 실습에서 대기시간의 단위를 맞추고 요약하기

단위가 다른 대기시간을 그대로 더하면 그럴듯한 숫자가 나와도 다른 뜻을 가집니다. 같은 기록을 찾아낸 뒤 단위를 맞추고, 지점별 분모와 평균을 직접 보고합니다.

이 장을 읽고 나면

  • 데이터 항목과 키, 허용 단위, 값이 없는 경우의 처리를 정한다.
  • 재전송을 통합한 뒤 공통 단위로 요약한다.
  • 전체 평균과 지점별 평균의 분모를 구분한다.

계산할 열을 먼저 계약처럼 읽는다

아래는 시험 연습에 쓸 합성 로그입니다. 한 행의 ID는 방문 건입니다. 대기값과 단위가 다른 열에 기록되어 있습니다. 공식 집계의 입력 단위로 sec와 min만 허용한다고 정합니다. 값을 읽어 공통 단위인 분으로 바꿀 계획을 적습니다. 빈 문자열은 실제 0분이 확인된 값과 구별합니다. 숫자로 읽히는 유한한 0 이상의 값만 계산에 씁니다.

D102는 원천에서 같은 방문의 정확한 재전송이라고 확인했습니다. 일반적인 경우에는 동일 ID에 다른 값이 올 수 있어 충돌을 확인합니다. D106은 이 실습의 허용 단위가 아니므로 나중에 검토할 목록에 둡니다. 이 자료 계약이 허용하는 단위가 더 많아지면 검증 규칙도 바뀔 수 있습니다.

열마다 변수의 종류도 확인합니다. ID는 행을 구별하는 식별자라 평균을 내지 않습니다. 지점은 범주형 변수로 집계의 묶음 기준이 됩니다. 대기시간은 수치형(연속형) 변수지만 원문이 문자열이고 단위가 다른 열에 있으므로, 숫자로 바꾸고 단위를 맞춘 뒤에야 계산할 수 있습니다.

단위를 맞춘 뒤 계산한다

동쪽: 120초는 2분, 4분은 그대로입니다. 서쪽: 600초를 10분으로 바꾸고 5분은 그대로입니다. 지점마다 두 값을 더해 2로 나누면 동쪽 평균 (2+4)/2=3분, 서쪽 평균 (10+5)/2=7.5분입니다. 모두 합친 유효 관측의 평균은 (2+4+10+5)/4=5.25분입니다.

from collections import defaultdict
from math import isfinite
from statistics import mean

raw = [
    ("D101", "동쪽", "120", "sec"),
    ("D102", "동쪽", "4", "min"), ("D102", "동쪽", "4", "min"),
    ("D103", "동쪽", "", "min"), ("D104", "서쪽", "600", "sec"),
    ("D105", "서쪽", "5", "min"), ("D106", "서쪽", "4", "hour"),
]
unique = {}
for visit, site, value, unit in raw:
    fields = site, value, unit
    if visit in unique and unique[visit] != fields:
        raise ValueError(f"ambiguous visit: {visit}")
    unique[visit] = fields

minutes_per_unit = {"sec": 1 / 60, "min": 1}
by_site = defaultdict(list)
hold = []
for visit, (site, value, unit) in unique.items():
    try:
        minutes = float(value) * minutes_per_unit[unit]
    except (ValueError, KeyError):
        hold.append(visit)
        continue
    if not isfinite(minutes) or minutes < 0:
        hold.append(visit)
        continue
    by_site[site].append(minutes)

print("source", len(raw), "unique", len(unique), "hold", hold)
for site, minutes in by_site.items():
    print(site, len(minutes), mean(minutes))
print("all usable", mean([m for vs in by_site.values() for m in vs]))

기준에 따라 숫자의 뜻을 확인한다

이 예에서는 두 지점의 유효 관측 수가 각각 2개라 두 평균의 단순 평균도 5.25분입니다. 건수가 다른 상황에서 전체 방문의 평균을 구하려면 각 지점의 평균에 관측 건수를 곱해 합친 뒤 전체 건수로 나눕니다. 여기서 제외한 두 방문의 대기시간은 확정하지 않았으므로, 모든 고유 방문의 평균을 보고하려면 값을 어떻게 처리했는지 별도로 밝힙니다.

평균 하나는 분포의 위치만 알려 줍니다. 서쪽 평균 7.5분은 5분과 10분처럼 5분이나 벌어진 두 값에서 나왔고, 동쪽 3분은 2분과 4분에서 나왔습니다. 관측이 이렇게 적으면 평균과 함께 건수와 최솟값·최댓값(또는 값 전체)을 적어야 읽는 사람이 흩어짐을 판단할 수 있습니다.
