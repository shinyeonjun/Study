주문 지연을 예측할 때 모형을 고르는 순서

운영팀은 오늘 출고할 주문 중 내일까지 지연될 건을 먼저 볼 수 있는 도구를 원합니다. 관측 단위와 기준선을 정하고, 작은 수로 이전 규칙을 교체할 수 있는지 판단합니다.

이 장을 읽고 나면

  • 연속 예측, 분류, 군집화를 업무 질문에 연결한다.
  • 최종 판정 전에 쓸 수 있는 입력을 정한다.
  • 놓친 건과 잘못 알린 건을 다른 비용으로 평가한다.

무엇을 예측하고 누구에게 전달할까

출고 시작 시점의 주문마다 어제부터 밀린 상품 수와 주소 검토 신호를 가지고 있다고 합시다. ‘다음 날까지 출고되지 않음’을 양성으로 정의합니다. 시작 시점의 입력으로 양성 알림을 만들고, 다음 날이 지나 실제 라벨을 붙입니다. 최종 출고 시각은 라벨을 만들 때 사용하지만 예측 시점의 입력으로 가져오면 미래 정보가 새어 들어옵니다.

여섯 주문의 알림을 비교한다

학습 기간을 지나 별도 검증 기간의 여섯 주문에 모형 A와 B를 적용했습니다. 양성을 놓치면 재배송으로 비용 5, 음성을 잘못 알리면 사람이 검토하므로 비용 1이 든다고 정했습니다. 올바른 판정의 비용은 이 연습에서 0입니다. 기준선은 모든 주문을 음성으로 둡니다.

주문실제 지연모형 A모형 B
1111
2010
3010
4110
5000
6000

A는 두 지연 건을 모두 찾지만 주문 2·3을 잘못 알립니다. 비용은 2입니다. B는 하나만 놓쳐 비용이 5입니다. B의 정답 개수는 5개로 A의 4개보다 많습니다. 이 비용에서는 A가 더 낫습니다. 기준선은 지연 두 건을 모두 놓쳐 비용 10입니다.

actual = [1, 0, 0, 1, 0, 0]
candidates = {
    "항상 음성": [0] * len(actual),
    "A": [1, 1, 1, 1, 0, 0],
    "B": [1, 0, 0, 0, 0, 0],
}
for name, predictions in candidates.items():
    fn = sum(y == 1 and p == 0 for y, p in zip(actual, predictions))
    fp = sum(y == 0 and p == 1 for y, p in zip(actual, predictions))
    print(name, "FN:", fn, "FP:", fp, "비용:", 5*fn + fp)

실행 결과

항상 음성 FN: 2 FP: 0 비용: 10
A FN: 0 FP: 2 비용: 2
B FN: 1 FP: 0 비용: 5

후보 알고리즘은 성질로 먼저 좁힌다

모형 A와 B는 실제로 어떤 알고리즘으로든 만들 수 있습니다. 후보를 고를 때는 성능 숫자만이 아니라 자료의 모양과 설명 요구에 맞는지를 함께 봅니다. 아래는 빅분기에 자주 나오는 알고리즘의 일반적인 성질입니다. 어느 쪽이 더 정확한지는 자료마다 다르므로, 결국 같은 검증 자료에서 비교합니다.

알고리즘쓰는 곳장점주의할 점
선형 회귀 · 로지스틱 회귀회귀 · 분류계수로 변수의 방향과 크기를 설명하기 쉽다관계가 선형(로지스틱은 로그 오즈가 선형)이라고 가정한다
결정나무회귀 · 분류‘밀린 상품 ≥ 3이면’ 같은 규칙으로 읽힌다. 척도 변환이 필요 없다깊게 키우면 과적합되기 쉽다
랜덤 포레스트 · 부스팅회귀 · 분류나무 여러 개를 합쳐 대체로 단일 나무보다 정확하다개별 판단의 이유를 설명하기 어렵다
k-최근접 이웃회귀 · 분류학습 단계가 거의 없다거리 계산이라 변수 척도를 맞춰야 하고 예측할 때 계산이 많다
k-평균군집화라벨 없이 비슷한 행을 묶는다군집 수 k를 미리 정하고, 둥근 모양의 군집을 가정한다

입력 변수(특성)를 만드는 일도 모형 선택만큼 중요합니다. ‘어제부터 밀린 상품 수’처럼 예측 시점에 이미 아는 값으로 만든 특성만 후보가 됩니다.

채택 전에 한 번 더 분할한다

검증 자료에서 후보 A를 골랐으므로 같은 자료에서 낸 비용 2는 후보 선택에도 사용한 결과입니다. 검증보다 나중 기간을 시험 자료로 남겨 비용과 알림 건수를 한 번 더 보고합니다. 주문을 합칠 때 같은 주문의 여러 상품 행을 따로 분할하지 않도록 먼저 주문 단위로 집계합니다. 이 연습에서는 출고 가능 시간이나 알림 담당 인원의 처리량에 따라 비용과 알림 규칙을 다시 정할 수 있습니다.

한 줄 정리

질문과 라벨을 정한 뒤 기준선과 후보를 같은 검증 건에서 비교하고, 채택한 후보는 별도 기간에서 확인합니다.
