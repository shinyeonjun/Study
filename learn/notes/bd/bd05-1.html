실측 CSV에서 조건에 맞는 값을 계산해 제출하기

제1유형 형식으로 마우나로아 CO₂ 표를 푸는 연습입니다. ‘2005~2014년의 전년 대비 증가량 중 큰 두 값의 평균’을 구하면서 연산 순서와 최종 출력의 차이를 확인합니다.

이 장을 읽고 나면

  • 정렬·차분·행 선택의 순서가 결과에 미치는 영향을 설명한다.
  • 실수 조건을 원자료의 소수 자릿수에 맞춰 계산한다.
  • 중간 검산 결과와 제출 답의 형식을 구분한다.

문장에서 범위, 단위, 순서를 찾는다

마우나로아 연평균 CSV를 코드와 같은 폴더에 둡니다. 연습 과제는 “2005~2014년 각 해의 CO₂ 연평균에서 직전 해의 연평균을 뺀다. 차이가 큰 두 해의 차이 평균을 소수 둘째 자리까지 출력한다”입니다. 이 기간에 전년보다 2.00ppm 이상 늘어난 해의 수도 중간에 확인합니다. 한 행은 한 연도이고 단위는 ppm입니다.

2005년의 증가량에는 2004년 값이 필요합니다. 먼저 전체를 연도순으로 정렬해 차이를 만들고, 그 다음에 2005~2014년을 고릅니다. 원본 파일에서 첫 행만 차이를 계산할 이웃이 없습니다. 이 실습의 대상 기간에는 그 행이 들어가지 않습니다.

두 자리 소수는 정수 눈금으로 비교한다

농도는 소수 둘째 자리까지 기록됐습니다. 0.01ppm을 1단위로 세면 2.00ppm 이상이라는 조건을 정수 200 이상으로 비교할 수 있습니다. 텍스트를 읽을 때 dtype으로 농도 열을 문자열로 받은 뒤 Decimal로 읽어 100배 합니다. 기대한 자릿수와 값의 형식이 맞는지 검산합니다.

from decimal import Decimal
import pandas as pd

data = pd.read_csv("annual_co2.csv", dtype={"mean_ppm": str}).sort_values("year")
assert data["year"].tolist() == list(range(1990, 2020))

def hundredths(text):
    scaled = Decimal(text) * 100
    assert scaled.is_finite() and scaled == scaled.to_integral_value()
    return int(scaled)

data["change"] = data["mean_ppm"].map(hundredths).astype("Int64").diff()
window = data.loc[data["year"].between(2005, 2014)]
assert len(window) == 10 and window["change"].notna().all()
top = window.sort_values(["change", "year"], ascending=[False, True]).head(2)
answer = Decimal(int(top["change"].sum())) / (100 * len(top))
print("2005년 차이:", int(window["change"].iloc[0]))
print("2.00ppm 이상:", int(window["change"].ge(200).sum()))
print("상위 두 해:", *top["year"])
print(f"{answer:.2f}")

중간 출력으로 검산하고 제출 칸에는 필요한 값만 적는다

상위 차이는 2.68ppm과 2.46ppm입니다. 평균은 2.57ppm입니다. 지정된 답안이 숫자 하나라면 최종 칸에는 2.57만 넣습니다. 문제에서 동점 해의 순서를 요구할 때는 그 규칙을 적용합니다. 여기서는 차이가 같으면 연도가 먼저인 자료를 앞에 뒀습니다. 순서나 자릿수의 기준은 실제 문제 지시를 따릅니다.
