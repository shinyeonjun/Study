실제 CO₂ 자료로 기준선과 선형 예측 비교하기

NumPy와 pandas로 다뤘던 마우나로아 연평균 CO₂ 자료를 다시 엽니다. 앞의 연도로만 추세선을 만들고, 남겨 둔 다섯 연도에서 예측 오차를 비교합니다.

이 장을 읽고 나면

  • pandas로 연도에 따라 학습·시험 표를 나눈다.
  • NumPy로 학습 자료의 선형 추세와 직전값 기준선을 만든다.
  • 숨겨 둔 연도의 오차와 외삽의 범위를 설명한다.

측정값을 분석용 표로 읽는다

마우나로아 관측소의 1990~2019년 CO₂ 연평균 자료를 사용합니다. 연평균 농도는 ppm 단위입니다. 연평균 CSV를 받아 코드와 같은 폴더에 저장합니다. 데이터 출처, 열 설명과 자료 가공 범위는 실습 자료 출처에 있습니다. 얇은 표의 한 행은 관측소 한 곳의 한 해입니다. 연도만 쓰는 이 실습은 그 관측소의 해당 기간 예측 문제입니다.

2014년 연평균까지 사용할 수 있는 시점에서 2015~2019년의 연평균을 한꺼번에 예측하는 상황을 가정합니다. 1990~2014년 25개로 적합하고 2015~2019년 5개는 끝까지 보류합니다. 현재 공개된 자료를 연도순으로 나눈 사후 평가입니다. 당시 그 시점에 공개된 자료를 재현하려면 당시 저장본이 따로 필요합니다.

두 예측 규칙을 같은 다섯 해에 적용한다

직전값 기준선은 2014년의 398.81 ppm을 다섯 번 복사합니다. 선형 추세는 학습 구간에서 산출한 절편과 기울기를 사용합니다. NumPy의 polyfit(x, y, 1)은 잔차 제곱합을 최소화하는 1차식의 기울기와 절편 순서로 반환합니다. 입력 연도에서 1990을 빼면 절편을 1990년 예측값으로 읽을 수 있습니다.

import numpy as np
import pandas as pd

annual = pd.read_csv("annual_co2.csv").sort_values("year")
assert annual["year"].tolist() == list(range(1990, 2020))
assert np.isfinite(annual["mean_ppm"]).all()
train = annual.loc[annual["year"].le(2014)]
test = annual.loc[annual["year"].gt(2014)]
x_train = train["year"].to_numpy() - 1990
y_train = train["mean_ppm"].to_numpy()
slope, intercept = np.polyfit(x_train, y_train, 1)
x_test = test["year"].to_numpy() - 1990
y_test = test["mean_ppm"].to_numpy()
last = np.full(len(test), y_train[-1])
trend = intercept + slope * x_test

print("훈련/평가:", len(train), len(test))
print("선형 추세:", f"{intercept:.3f}", "+", f"{slope:.3f}", "× (연도 - 1990)")
print("연도 실제 직전값 선형추세")
for year, actual, baseline, prediction in zip(test["year"], y_test, last, trend):
    print(year, f"{actual:.2f}", f"{baseline:.2f}", f"{prediction:.2f}")
print("MAE:", f"{np.abs(y_test - last).mean():.3f}", f"{np.abs(y_test - trend).mean():.3f}")

어디에서 얼마나 잘 맞았는가

2015~2019년에서 직전값 기준선의 평균절대오차는 7.700 ppm이고, 선형 추세는 3.501 ppm입니다. 추세선도 이 구간의 실제값을 매번 낮게 예측했습니다. 평균절대오차의 단위는 ppm이고 부호가 없으므로, 일정하게 낮았는지는 각 연도의 실제값과 예측값을 차례로 비교해야 알 수 있습니다.

여기서 선형식을 적용한 다섯 해는 학습 구간 밖입니다. 더 뒤로 외삽하면 같은 선형 추세가 이어진다는 가정에 더 많이 의존합니다. 여러 후보를 시도한다면 2014년 이전에서 기준 시점을 여러 번 옮겨 비교하고, 최종 후보를 고른 후 남겨 둔 시험 구간을 엽니다.

한 줄 정리

측정 단위와 시간 순서를 고정하고 두 예측을 같은 미래 값들과 비교했습니다. 오차의 크기와 방향을 함께 읽습니다.
