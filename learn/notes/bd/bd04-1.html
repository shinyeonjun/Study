평균 점수 뒤에 가려진 집단별 오류 찾기

두 처리 경로의 지연 알림을 따로 평가합니다. 전체 재현율이 그대로인데 작은 경로의 결과는 나빠질 수 있는 이유를 계산하고, 보고할 지표를 정합니다.

이 장을 읽고 나면

  • 경로별 재현율을 실제 양성 수와 함께 계산한다.
  • 양성 수에 가중한 전체 지표와 집단 평균을 비교한다.
  • 오류를 줄이기 위한 검증 자료를 정의한다.

전체 재현율이 같으면 모두 같아졌을까

출고 주문을 직접 접수와 연동 접수로 나눕니다. 별도 시험 기간의 실제 지연 주문은 직접 접수 40건과 연동 접수 10건입니다. 같은 시험 표본에서 현재 모형과 후보를 비교하고 각 모형이 찾아낸 지연 주문을 셉니다.

접수 경로실제 지연현재 모형이 찾음후보가 찾음
직접 접수403236
연동 접수1084
전체504040

직접 접수의 재현율은 현재 0.8, 후보 0.9입니다. 연동 접수에서는 현재 0.8, 후보 0.4입니다. 전체 재현율은 둘 다 40/50=0.8이지만 후보의 연동 접수 미탐은 2건에서 6건으로 늘었습니다.

합쳐서 셀 때와 각 집단을 똑같이 볼 때

전체의 0.8은 예측 결과를 모두 합쳐 50건을 분모로 계산했습니다. 같은 값을 후보의 경로별 재현율에 40/50과 10/50을 곱해 더해도 얻습니다. 각 경로에 같은 비중을 주는 집단 평균은 (0.9+0.4)/2=0.65입니다. 집계 방식은 무엇을 같은 비중으로 볼지 결정합니다.

from fractions import Fraction as F
from statistics import mean

totals = [40, 10]
for model, found in (("현재", [32, 8]), ("후보", [36, 4])):
    recalls = [F(tp, total) for tp, total in zip(found, totals)]
    micro = F(sum(found), sum(totals))
    macro = mean(recalls)
    print(model, "경로별", *(f"{float(v):.2f}" for v in recalls))
    print("전체", f"{float(micro):.2f}", "경로 평균", f"{float(macro):.2f}")

실행 결과

현재 경로별 0.80 0.80
전체 0.80 경로 평균 0.80
후보 경로별 0.90 0.40
전체 0.80 경로 평균 0.65

다음 평가에서 무엇을 수집할까

연동 접수는 실제 지연이 10건뿐이므로 재현율의 변동이 클 수 있습니다. 후보를 채택하기 전에 이후 기간을 추가로 확인하고, 연동 접수의 누락 신호와 늦게 들어오는 정보가 있는지 살핍니다. 각 경로의 정상 주문에서도 불필요 경보를 세어 업무 부담을 비교합니다. 이 표에는 실제 정상의 수와 모형의 오탐 수가 없어 정밀도까지 계산할 수 없습니다.

한 줄 정리

모형 결과를 전체 값으로만 보지 말고 집단의 수, 평가 지표, 오류 방향을 함께 기록합니다.
