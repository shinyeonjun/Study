시험 행 순서를 보존하며 예측 CSV 만들기

간단한 회귀 기준선을 적합하고, 처음 보는 범주까지 포함된 시험 표에 적용합니다. 시간 제한 연습에서는 점수 개선 전에 제출 파일을 읽어 검산하는 습관을 들입니다.

이 장을 읽고 나면

  • 그룹 평균 예측과 미등록 그룹의 대체값을 계산한다.
  • 시험 표의 원래 행 순서와 요구 열을 보존한다.
  • CSV를 다시 읽어 구조와 유한한 값을 검사한다.

먼저 항상 실행되는 기준선을 만든다

훈련 자료에서 서부의 처리 시간이 5, 9분이고 동부가 2, 4분이라고 합시다. 회귀의 예측값으로 각 구역의 훈련 평균을 씁니다. 서부는 7, 동부는 3입니다. 처음 보는 구역은 훈련의 전체 평균 5를 씁니다. 기준선은 이 계획을 그대로 실행한 뒤 검증 결과를 측정할 수 있는 시작점입니다.

이 연습의 제출 규칙은 시험 원래 순서대로 pred라는 예측 열 하나와 헤더를 기록하는 것입니다. 시험 표에서 주문 ID를 정렬하면 105가 먼저 나오지만, 제출에는 그 순서를 쓰지 않습니다. ID는 예측이 어느 행에 속하는지 검증할 때만 사용합니다. 실제 문제에서 ID 열을 제출하라고 요청한다면 그 문제의 열 이름과 순서를 따릅니다.

from pathlib import Path
from tempfile import TemporaryDirectory
import numpy as np
import pandas as pd

train = pd.DataFrame({"region": ["서부", "서부", "동부", "동부"],
                      "minutes": [5, 9, 2, 4]})
test = pd.DataFrame({"order_id": [301, 105, 220],
                     "region": ["서부", "동부", "중부"]})
regional = train.groupby("region")["minutes"].mean()
predictions = test["region"].map(regional).fillna(train["minutes"].mean())
result = pd.DataFrame({"pred": predictions})

with TemporaryDirectory() as folder:
    path = Path(folder) / "result.csv"
    result.to_csv(path, index=False)
    saved = pd.read_csv(path)
    assert saved.columns.tolist() == ["pred"]
    assert len(saved) == len(test)
    assert np.isfinite(saved["pred"]).all()
    assert np.array_equal(saved["pred"], predictions)
    assert list(zip(test["order_id"], saved["pred"])) == [(301, 7), (105, 3), (220, 5)]
    print(path.read_text(encoding="utf-8"), end="")

시간을 재고 모형과 파일을 둘 다 확인한다

빅분기 실기 작업형은 데이터 가공·집계(제1유형, BD05-1), 모형 예측과 CSV 제출(제2유형, 이 장), 통계 검정(제3유형)으로 나뉩니다. 제3유형의 손계산과 해석은 BD02-2의 대응표본 t검정과 빅분기 실기의 독립표본 t검정에서 연습합니다. 유형별 문항 수와 배점은 회차마다 바뀔 수 있으니 공식 공지를 확인합니다.

연습을 시작할 때 모형을 개선하는 시간과 마지막 제출을 점검하는 시간을 나눕니다. 시험에서는 문제에 명시한 위치에 파일을 씁니다. 이 교재 코드는 연습 중 기존 파일을 덮어쓰지 않도록 임시 폴더에 저장합니다. 새 특성을 쓰거나 모형을 교체할 때는 검증용 행에서 원래의 기준선과 같은 지표로 비교하고, 제출 직전에 전체 훈련 자료로 다시 적합할지 절차를 정리합니다. 시험 행은 예측 순서와 파일 구조를 검증하는 데 쓸 수 있지만 정답을 사용해 설정을 고르는 자료는 아닙니다.
