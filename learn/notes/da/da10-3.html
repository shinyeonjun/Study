DA10·3

보정 구간의 오차 폭을 평가하고 재실행 보고서를 남기기

평균 오차가 작아도 실제 값이 예측에서 크게 벗어나는 해가 있습니다. 선택에 쓰지 않은 앞 구간에서 폭을 하나 정하고, 그 범위가 보류 기간에 얼마나 맞았는지 기록합니다.

이 장을 읽고 나면

  • 별도 조정 오차의 경험분위수로 폭을 설정한다.
  • 보류 구간의 폭과 포괄률을 계산하고 보장 범위를 구분한다.
  • 재실행 명령·실패 사례·자료 버전 및 결론 범위를 보고한다.

모형을 잠근 뒤에 예측 폭을 따로 만든다

선택 시기의 MAE에서 정한 최근 3년 규칙을 유지합니다. 그 뒤인 2007–2011년을 구간 조정에만 사용합니다. 다섯 해의 |y−ŷ|를 정렬하고, 누적비율이 .9 이상이 되는 가장 작은 값을 반폭 r로 씁니다. 이 프로젝트에서는 매우 간단한 경험 오차 범위입니다. 따로 검증한 확률모형이 필요하지 않은 대신, 그 폭의 미래 포괄 확률을 보장하는 절차도 아닙니다.

r의 순위 = ⌈.9×5⌉ = 5, 예측 범위 = [ŷ−r, ŷ+r].

정렬한 절대오차는 약 .1067, .1400, .2767, .2967, .6100ppm입니다. 다섯째가 .6100이므로 반폭 .61ppm, 전체 폭은 2×.61=1.22ppm입니다. 소수점으로 나온 오차를 보기 좋게 반올림해 표에 적더라도, 순위를 정할 때는 가능한 한 반올림 전 값으로 계산합니다.

새 여덟 해에서 구간이 놓친 값을 찾는다

반폭 .61을 유지한 채 보류 2012–2019년에는 |y−ŷ|≤.61이면 포함으로 기록합니다. 아래 숫자는 반올림했습니다. 각 행에서 오차를 정한 방식과 같은 조건으로 포함된 횟수를 셉니다.

2016년 예측 403.3267ppm의 범위는 402.7167~403.9367ppm이고 실제 404.4100ppm은 위쪽을 벗어납니다. 2018년 예측 409.4100ppm의 범위는 408.8000~410.0200ppm이며 실제 408.7200ppm은 아래쪽을 벗어납니다. 양쪽 실패를 표시해야 폭 부족과 예측의 치우침을 구분할 수 있습니다.

어떤 불확실성인지 이름을 붙인다

.9를 입력했지만 이 연습에는 미래 90% 보장이 없습니다. 조정 표본이 다섯 개뿐이고, 한 관측소에서 인접한 연도의 차분은 같은 관측값을 공유하는 등 오차가 의존할 수 있습니다. 보류 기간과 조정 기간에서 성장과 변동의 구조가 같다는 근거도 별도로 필요합니다. 실습의 75%는 정해 둔 범위가 실제로 보류 여덟 해를 덮은 비율입니다.

가정에 대한 민감도를 보려고, 같은 조정 오차의 .8 경험분위수로 반폭을 정하는 별도 계산도 적습니다. 순위는 ⌈.8×5⌉=4라 반폭은 약 .2967ppm이며 보류에서는 4/8입니다. 좁은 구간을 만들면 맞아야 할 범위도 줄어든다는 교환을 확인합니다. 이것은 예제의 민감도 비교이며, 보류에서 결과가 좋아 보이는 폭을 골라 다시 성능을 주장하는 절차는 아닙니다.

원자료에 함께 제공되는 uncertainty_ppm은 NOAA와 Scripps의 연평균 추정 차이에서 계산한 측정 자료의 요약입니다. 여기의 r은 과거에 그 규칙을 썼을 때의 예측오차에서 얻었습니다. 같은 단위라도 양이 달라 .12ppm을 예측 범위의 폭이나 모형 성능으로 대체하지 않습니다.

자료와 판단을 함께 다시 실행할 수 있게 적는다

결과 보고서. 대상은 마우나로아의 1990–2019년 연평균 수록 CSV입니다. 파일의 출처와 2026-10-09 원자료 생성본을 적고, 첫 장의 SHA-256을 입력 기록으로 둡니다. CSV를 저장한 작업 폴더에서 이 단원의 코드 세 개를 차례로 실행하면 입력 검사, 선택과 보류 평가, 폭 조정과 실패 표를 다시 얻습니다. Python 표준 라이브러리만 사용합니다.

같은 8개 예측에서 기준선 MAE 2.4750ppm, 3년 규칙 MAE .4183ppm입니다. 폭 1.22ppm으로 6개 연도를 포함했고 2016·2018년에서 실패했습니다. 이 결과는 단일 관측소의 개정본에서 수행한 한 해 앞 후향 비교입니다. 실제로 과거에 최초 발표된 자료로도 같은지와 다른 관측소에서의 유지 여부는 확인되지 않았습니다. 다른 자료로 다음 비교를 한다면 공개 시점 이력과 사용 가능한 관측 범위를 먼저 기록합니다.

이어 풀기와 증명

계산이 정확해도 적용 범위는 별도입니다. 틀린 연도와 새 비교에서 확인할 가정을 함께 보고합니다.

파이썬으로 같은 계산 검산하기

연평균 관측 CSV를 저장하고 아래 코드를 그 파일과 같은 작업 폴더에서 실행합니다.

from csv import DictReader
from fractions import Fraction as F
from math import ceil
from pathlib import Path

with Path("annual_co2.csv").open(encoding="utf8", newline="") as source:
    y = {int(r["year"]): F(r["mean_ppm"]) for r in DictReader(source)}

def forecast(t):
    last = y[t-1]
    return last + (last-y[t-4])/3

calibration = sorted(abs(y[t]-forecast(t)) for t in range(2007, 2012))
print("calibration absolute errors:", [f"{float(e):.4f}" for e in calibration])
for q in (F(9,10), F(4,5)):
    rank = ceil(q*len(calibration))
    radius = calibration[rank-1]
    results = [(t, forecast(t), abs(y[t]-forecast(t)) <= radius)
               for t in range(2012, 2020)]
    covered = sum(ok for _,_,ok in results)
    print(f"q={float(q):.1f}: radius={float(radius):.4f}",
          f"width={float(2*radius):.4f} coverage={covered}/{len(results)}")
    if q == F(9,10):
        for t, guess, ok in results:
            if not ok:
                print(f"{t}: {float(guess-radius):.4f} to {float(guess+radius):.4f}",
                      f"actual={float(y[t]):.4f}")
