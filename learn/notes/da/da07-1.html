실전 분석 1: 마우나로아 관측 CSV 읽고 검사하기

하와이 마우나로아에서 관측한 공기 속 이산화탄소의 연평균 값은 1990년부터 2019년까지 어떻게 달라졌을까요? 원자료 출처를 먼저 확인하고 pandas로 표를 읽어, 그 질문에 답할 만한 자료인지 확인합니다.

이 장을 읽고 나면

  • 측정값의 단위·기간·한 행의 의미를 기록한다.
  • 정렬하고 결측·중복·비연속 연도를 검사한다.
  • 원본과 분석용 계산을 구별해 첫 변화량을 구한다.

이 표로 답할 질문 정하기

이번 질문은 마우나로아에서 1990–2019년 사이 연평균 CO₂ 몰분율이 얼마나, 어떤 흐름으로 변했나?입니다. 한 해의 관측을 모아 보고한 평균 한 건을 한 행으로 봅니다. 연도마다 한 줄이라는 뜻이지, 한 줄에 관측 하나를 직접 측정했다는 뜻은 아닙니다.

자료 출처는 NOAA Global Monitoring Laboratory의 Xin Lan과 Scripps Institution of Oceanography의 Ralph Keeling입니다. 2026년 10월 9일 생성본에서 1990~2019년의 세 열을 옮겨 실습 CSV를 만들었습니다. 열 이름과 구분자만 바꿨습니다. 나중에 공개 원자료와 끝자리가 달라지면 보정과 품질 검사에 따른 자료 개정 여부를 살핍니다.

열 이름한 칸의 뜻단위와 주의점
year연평균이 속한 연도정수이며 이 파일에서는 행 식별자
mean_ppm건조 공기 중 CO₂ 몰분율의 연평균ppm = μmol/mol. 354.45 ppm이면 건조 공기 1몰당 CO₂ 354.45 μmol
uncertainty_ppm보고된 연평균 불확실성ppm. NOAA 설명에서 두 기관의 연평균 추정값 차이의 표준편차

관측 위치를 확인하세요

이 관측소의 연평균으로 이 파일의 기간을 기술할 수 있습니다. 전 지구 평균, 월별 계절 변화, 특정 배출원의 효과를 답하려면 이 질문과 다른 자료가 필요합니다.

연습 파일 준비와 첫 읽기

연평균 관측 CSV를 연습 작업 폴더에 저장합니다. 가상환경에서 pandas를 쓰세요. 아래 코드를 같은 연습 폴더에 inspect_co2.py로 저장하고 그 폴더에서 실행하면 됩니다. 경로를 적는 방식은 PY07·1에서 배운 현재 작업 폴더 기준입니다.

import pandas as pd

df = pd.read_csv("annual_co2.csv", dtype={"year": "Int64"})
print(df.shape)
print(df.columns.tolist())
print(df.loc[0, "year"], df.loc[0, "mean_ppm"], df.loc[0, "uncertainty_ppm"])
print(df.isna().sum().tolist())

실행 결과

(30, 3)
['year', 'mean_ppm', 'uncertainty_ppm']
1990 354.45 0.12
[0, 0, 0]

shape에서 앞은 행의 개수, 뒤는 열의 개수입니다. Int64는 연도를 정수로 읽으면서 결측 표시를 허용하는 pandas 자료형입니다. 마지막 줄의 isna().sum()은 열마다 True를 더해 비어 있는 칸의 수를 셉니다. 이번 데이터에서 세 열 모두 0개입니다.

연도가 연속이어야 차이의 뜻이 맞다

다음에 쓸 diff()는 바로 위 행의 숫자를 뺍니다. 위 행이 전년인지 함수가 확인해 주지 않습니다. 따라서 먼저 순서를 맞추고, 연도 하나가 두 줄로 들어왔는지와 중간 연도가 빠졌는지를 확인합니다.

import pandas as pd

df = pd.read_csv("annual_co2.csv", dtype={"year": "Int64"})
if df.isna().any().any():
    raise ValueError("비어 있는 값이 있습니다.")
if df["year"].duplicated().any():
    raise ValueError("중복 연도가 있습니다.")
df = df.sort_values("year", ignore_index=True)
if df["year"].tolist() != list(range(1990, 2020)):
    raise ValueError("1990–2019년에 매년 한 행이 필요합니다.")

change = df["mean_ppm"].diff()
print(pd.isna(change.iloc[0]))
for i in (1, 2, 3):
    print(f"{df.loc[i, 'year']}: {change.iloc[i]:.2f}")

실행 결과

True
1991: 1.25
1992: 0.84
1993: 0.67

1991년은 355.70 − 354.45 = 1.25 ppm입니다. 첫 행인 1990년은 표 안에 앞 행이 없어서 차이를 계산할 수 없습니다. 여기서 결측은 변화를 계산하는 과정에서 새로 생긴 첫 빈칸입니다. 원자료에 농도가 0이라고 적혀 있었던 것이 아닙니다. 따라서 첫 차이를 0으로 채우지 않습니다.

그림으로 먼저 보기

이 기간의 선은 전체적으로 올라갑니다. 그렇다고 모든 해의 상승량이 같은 것은 아닙니다. 다음 장에서는 연평균 수준의 변화와 해마다의 변화량을 따로 계산하고, 수치와 한계를 함께 적습니다.

작업 기록에 남길 것

이 장에서는 원자료에서 30개 행과 세 열을 골라 CSV로 옮겼고, 값의 결측·중복·연도 간격을 검사했습니다. 누락을 채우거나 이상한 값을 임의로 지우지 않았습니다. 다른 기간을 분석할 때는 끊긴 연도가 없는지 다시 확인하고, 실제로 걸러 낸 행과 이유를 기록합니다.
