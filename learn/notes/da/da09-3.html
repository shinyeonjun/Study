DA09·3

자료 계약으로 형식과 기대 키를 먼저 검사하기

CSV가 읽힌다는 사실만으로 분석에 맞는 자료가 되는 것은 아닙니다. 연도·단위·키를 계약으로 적고, 어떤 입력에서 어느 검사가 먼저 실패하는지 실행합니다.

이 장을 읽고 나면

  • 자료 계약을 열 구조·키·범위·완전성의 검사로 바꾼다.
  • 분석이 멈추는 오류와 따로 조사할 신호를 설명한다.
  • 고정 수록 파일과 메모리 오류 사례를 같은 함수로 검증한다.

분석 함수가 기대하는 입력을 먼저 약속한다

자료 계약은 주어진 분석이 읽을 수 있는 자료의 구조와 의미를 적은 약속입니다. 이 실습은 마우나로아 관측소 하나의 1990–2019년 연평균 수록본을 대상으로 합니다. 열의 종류, 키, 단위 및 기대 연도를 정해야 ‘CSV 파일이 열렸다’는 것과 ‘원하는 자료가 들어 왔다’는 것을 나눌 수 있습니다.

같은 키에 같은 값이 두 번 있어도 중복입니다. 행 하나를 버리기 전에 그 기록이 단순한 재복제인지, 집계 방식이 달라진 개정본인지 확인합니다. 값이 열에 들어 있어도 단위가 틀릴 수 있습니다. 예를 들어 354.45ppm은 0.00035445mol/mol과 같은 값입니다. 두 번째 표현을 ppm이라고 표시하면 소수 형식은 맞지만 의미가 틀립니다. 300~500 범위는 그런 문제를 이 수록본에서 찾는 교육용 신호입니다. 모든 관측소와 모든 시기의 물리 법칙은 아닙니다.

같은 검사를 원본과 모의 입력에 적용한다

먼저 열 이름과 행마다 들어 있는 필드 수를 확인합니다. 연도, 소수 값을 읽고 유한하다는 조건을 확인합니다. Python에 NaN과 Infinity라는 특수한 소수 값이 있으므로 단순히 소수 변환이 끝났다는 사실을 통과 조건으로 두지 않습니다. 이후 키 중복, 연도의 집합, 약속된 수치 범위를 확인합니다.

실습에서는 이 값들을 실패로 처리해 잘못된 표로 계산을 이어 가지 않도록 합니다. 실제 데이터에 적용할 때는 범위를 벗어난 행을 무조건 삭제하기보다 원본 식별자와 실패 조건을 보고, 단위·버전·측정 상황을 확인합니다. 무엇을 누락으로 볼지와 언제 분석을 막을지도 질문에 따라 달라집니다. 값이 규칙을 통과해도 표본 대표성이나 예측 성능이 확보되는 것은 아닙니다.

새 버전이 들어올 때 자료의 뜻도 함께 확인한다

같은 관측소에 2020년 값을 추가하려면 계약의 기대 기간이 달라집니다. 원본이 개정되면 같은 기간이라도 수치가 바뀔 수 있습니다. 기존 계산을 다시 확인할 때는 같은 수록본을 사용하고, 새 판으로 비교할 때는 해시 또는 버전과 변경된 행을 명시합니다. 구조가 알맞고 기간이 같아도 원자료의 품질 관리는 계속될 수 있습니다.

이어 풀기

필드 수, 데이터 형태, 범위, 키와 시간은 서로 다른 검산 항목입니다. 계약을 늘리기 전에 어떤 질문이 그 항목을 필요로 하는지 설명합니다.

파이썬으로 같은 계산 검산하기

연평균 관측 CSV를 저장하고 아래 코드를 그 파일과 같은 작업 폴더에서 실행합니다.

from csv import DictReader
from decimal import Decimal as D, InvalidOperation
from io import StringIO
from pathlib import Path

def validate(text):
    reader = DictReader(StringIO(text))
    if reader.fieldnames != ["year", "mean_ppm", "uncertainty_ppm"]:
        raise ValueError("schema")
    years = set()
    for row in reader:
        if None in row or any(value is None for value in row.values()):
            raise ValueError("row width")
        try:
            year = int(row["year"])
            mean = D(row["mean_ppm"])
            uncertainty = D(row["uncertainty_ppm"])
        except (ValueError, InvalidOperation) as error:
            raise ValueError("number format") from error
        if not mean.is_finite() or not uncertainty.is_finite():
            raise ValueError("non-finite value")
        if not (300 <= mean <= 500 and uncertainty >= 0):
            raise ValueError("unit/range")
        if year in years:
            raise ValueError("duplicate year")
        years.add(year)
    if years != set(range(1990, 2020)):
        raise ValueError("year coverage")
    return len(years)

path = Path("annual_co2.csv")
original = path.read_text(encoding="utf8")
lines = original.splitlines()
print("valid rows:", validate(original))
bad_examples = [
    ("duplicate", original + "\n" + lines[1]),
    ("missing", "\n".join([lines[0], *lines[2:]])),
    ("schema", original.replace("mean_ppm", "mean_frac")),
    ("unit/range", original.replace("354.45", "0.00035445", 1)),
    ("non-finite", original.replace("354.45", "NaN", 1)),
]
for name, bad in bad_examples:
    try:
        validate(bad)
    except ValueError as error:
        print(name + ":", error)
    else:
        raise AssertionError(f"{name} should fail")

CSV를 저장한 같은 작업 폴더에서 실행합니다. 실패한 복사본에는 아무 분석 수치도 출력하지 않습니다. 검사에 쓴 300~500 범위는 이 장의 수록 파일과 질문에 맞춰 정한 값입니다.
