데이터 분석 · DA10 공개 데이터 분석 프로젝트

DA10·1

재사용할 데이터와 예측 질문을 고정하고 시험 시기를 보류하기

마우나로아 연평균 30개로 다음 해를 한 해씩 예측합니다. 프로젝트의 데이터, 알려진 시점, 검증 구간과 지표를 먼저 고정하면 결과가 나온 뒤 판단을 바꾸는 일을 줄일 수 있습니다.

이 장을 읽고 나면

  • 공개 자료의 버전과 관측 단위, 출처의 이용 안내를 확인한다.
  • 시계열 예측의 원점과 대상 시점을 적고 적용 한계를 설명한다.
  • 탐색·선택·구간 조정·보류 평가를 시간상으로 분리한다.

지표로 답할 수 있는 질문을 먼저 적는다

이 프로젝트의 질문은 마우나로아에서 작년까지의 연평균이 알려졌을 때, 마지막 값을 반복하는 기준보다 최근 변화량을 보탠 예측이 다음 해의 절대오차를 줄이는가입니다. 목적은 관측된 두 규칙의 예측 비교입니다. 자료의 한 행은 관측소 한 곳의 연평균이고, 오차 단위는 ppm입니다. 다른 관측소 및 전 지구 농도, CO₂ 변화의 원인은 별개의 질문입니다.

NOAA Global Monitoring Laboratory의 Xin Lan 및 Scripps Institution of Oceanography의 Ralph Keeling 자료 가운데 2026-10-09 생성본의 1990–2019년을 사용합니다. 수록 자료 설명에 선택한 열과 변환을 기록했습니다. 실제 수치를 반올림하거나 보간하지 않았습니다. NOAA GML은 이 자료를 공개하며 연구 발표에 관련 출처를 적도록 안내합니다. 수록 CSV는 분석에 필요한 열과 기간만 옮긴 실습본입니다. NOAA GML 자료 이용 정책 · 이용 조건과 출처 표기 안내

그림에서 전체 시계열을 이미 공개하고 있으므로 이 프로젝트는 새로운 비공개 시험이 아니라 고정 계획을 재실행하는 교육용 후향 분석입니다. 실제 연구라면 탐색에 보는 연도와 가려 둘 연도를 먼저 나누고 선택 단계에서는 보류값을 열지 않습니다. 다음 장에서도 보류 점수를 모델 선택 계산에 사용하지 않습니다.

다음 해를 예측할 때 어떤 해를 입력할 수 있는가

대상 연도를 t라 하면 예측의 원점은 t−1의 값까지 알려진 시점입니다. 예로 2002년을 예측할 때 2001년까지의 값을 사용합니다. 2002년의 실제 값은 예측을 기록한 뒤 점수를 계산하는 데 사용합니다. 이후 2003년 예측 때는 2002년의 관측을 추가할 수 있습니다. 매년 목표를 하나씩 앞으로 옮기는 이동 원점 평가입니다. 2001년에 한 번에 2002–2019년 전체를 내다보는 장기 예측과는 정보 사용 방식이 다릅니다.

현재 파일은 개정된 수록본 하나입니다. 연구 조건에서 ‘이전 연도가 관측되어 이용 가능하다’라고 두지만, 과거의 실제 최초 발표일 및 개정 전 숫자를 갖고 있지는 않습니다. 뒤 해의 행이 들어가는 누출은 막을 수 있지만, 실제 각 시점에 알려진 과거 수치와 같은지까지 검증한 실시간 평가는 아닙니다.

어떤 구간에서 어떤 선택을 하는지 고정한다

기준선은 ŷt=yt−1입니다. 후보는 최근 k년의 평균 연간 변화량을 마지막 값에 더하며 k=3 또는 k=6만 비교합니다. 선택 기준은 2002–2006년에 얻은 평균 절대오차(MAE)이고 동점이면 기간이 짧은 후보를 고릅니다. 보류 평가에는 MAE와 큰 오류를 더 크게 반영하는 제곱평균제곱근오차(RMSE)를 적습니다. 구간 폭을 설정하는 기준과 범위를 다음 장에서도 바꾸지 않습니다.

이어 풀기와 증명

자료 검사와 모형 평가를 두 단계로 기록합니다. 다음 해의 값을 안다는 가정을 무엇으로 검증할 수 있는지도 적습니다.

파이썬으로 같은 계산 검산하기

연평균 관측 CSV를 저장하고 아래 코드를 그 파일과 같은 작업 폴더에서 실행합니다.

from csv import DictReader
from decimal import Decimal as D
from hashlib import sha256
from io import StringIO
from pathlib import Path

path = Path("annual_co2.csv")
text = path.read_text(encoding="utf8")
reader = DictReader(StringIO(text))
assert reader.fieldnames == ["year", "mean_ppm", "uncertainty_ppm"]
rows = [(int(r["year"]), D(r["mean_ppm"]), D(r["uncertainty_ppm"])) for r in reader]
years = [year for year, _, _ in rows]
assert years == list(range(1990, 2020))
assert all(m.is_finite() and u.is_finite() and 300 <= m <= 500 and u >= 0
           for _, m, u in rows)
print("first and last:", rows[0][0], rows[0][1], rows[-1][0], rows[-1][1])
print("observed rows:", len(rows))
print("normalized text SHA-256:", sha256(text.encode("utf8")).hexdigest())
for label, start, stop in (
    ("development", 1990, 2001), ("selection", 2002, 2006),
    ("calibration", 2007, 2011), ("holdout", 2012, 2019),
):
    ids = [year for year in years if start <= year <= stop]
    print(label, len(ids), ids[0], ids[-1])

저장소 최상위에서 실행합니다. 해시는 UTF-8로 읽고 줄바꿈을 표준으로 통일한 텍스트에 적용합니다. 이 실습의 현재 입력을 식별하며, 해시가 같아도 당시 공개일이나 자료의 대표성까지 보장하지는 않습니다.
