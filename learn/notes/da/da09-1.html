DA09·1

관측 단위와 결합 입도, 실제로 알 수 있었던 시각을 구분하기

연평균 표의 한 행과 그 해에 적은 점검 기록은 서로 다른 단위입니다. 둘을 결합할 때 실제 수치가 한 번씩 쓰이는지, 예측 시점에 볼 수 있는 값인지 확인합니다.

이 장을 읽고 나면

  • 공개 표의 관측 단위, 식별 키와 독립 단위를 적는다.
  • 1대다 결합으로 연평균의 비중이 바뀌는 과정을 손으로 계산한다.
  • 관측이 속한 시간과 분석에서 알 수 있었던 시간을 분리한다.

한 행은 무엇을 관측하고 무엇을 합쳤나

저장소의 annual_co2.csv에는 마우나로아 관측소의 1990–2019년 연평균 30개가 있습니다. mean_ppm은 건조 공기 중 CO₂ 몰분율 연평균이고, ppm은 공기 몰수 백만 단위당 CO₂ 몰수입니다. uncertainty_ppm은 NOAA와 Scripps가 각각 추정한 연평균 차이의 표준편차로 원자료에 설명된 양입니다. 오늘 볼 한 행은 관측소 한 곳의 1년입니다. 공기 표본 하나, 매월 평균, 전 세계 평균은 각각 다른 단위입니다.

입도(grain)는 표의 한 행이 뜻하는 관측 수준입니다. 파일에는 관측소 하나만 들어 있으므로 연도만으로 행을 식별할 수 있습니다. 같은 열 구조로 다른 관측소를 붙이면 키는 (station,year)가 됩니다. 원래 관측이 어떻게 모였는지, 몇 번 재고 어떤 규칙으로 집계했는지는 데이터의 생성 과정을 이해하는 질문입니다. 연도 30개가 있다고 해서 서로 독립인 관측소 30곳 또는 독립인 30번 표집이 생기지는 않습니다.

반복 측정

반복 측정(repeated measures)은 같은 단위(사람·기기·관측소)를 여러 번, 보통 시간을 두고 잰 자료입니다. 이 파일의 30행은 관측소 한 곳을 해마다 다시 잰 반복 측정입니다. 같은 단위에서 나온 값들은 공통된 장소·장비·추세를 공유하므로 서로 상관되기 쉽고, 행 수 30은 독립인 정보 30개가 아닙니다. 그래서 측정이 기록된 수준(관측소·연도)과 결론을 일반화할 수준(관측소, 또는 여러 관측소)을 따로 적습니다. 독립 단위가 관측소라면 이 자료의 독립 단위는 1개입니다.

하나의 연평균이 검사 횟수만큼 반복될 수 있다

이 결합 오류를 보이기 위해 1990년과 1991년의 실제 연평균만 꺼냅니다. 두 해에 각각 1건과 2건의 품질 점검 메모가 있었다고 가정한 별도 합성 기록을 만듭니다. 이 메모는 NOAA의 실제 품질 기록이 아닙니다. 연평균의 한 행은 (관측소,연도), 메모의 한 행은 (관측소,연도,메모 ID)입니다. 이것을 연도로 결합하면 점검 메모마다 같은 연평균 값이 복제됩니다.

두 해를 똑같이 평균하는 목표에서는 (354.45+355.70)/2=355.075ppm입니다. 결합한 뒤 모든 행을 평균하면 (354.45+2·355.70)/3≈355.2833ppm입니다. 두 번째 값은 메모에 같은 가중치를 둔 평균입니다. 이 결합을 그대로 사용하려면 질문도 ‘메모 한 건에 대응하는 연평균의 평균’이어야 합니다. 해마다 같은 비중을 주려면 오른쪽 메모를 먼저 (관측소,연도)로 집계하고, 결합 뒤에도 행 수 및 왼쪽 기본 키가 유지되는지 확인합니다.

시점이 맞아도 발표된 결과만 쓸 수 있다

관측연도와 파일에서 실제로 쓸 수 있게 된 날짜를 구별합니다. 예를 들어 1992-01-01을 분석 기준 시각으로 두고, 1991년 관측의 요약이 1992-02-01에 공개됐다고 가정하면 아직 사용할 수 없습니다. 아래 날짜는 시간 조건을 설명하는 모의 발표 일정입니다. 기존 CSV는 현재 생성본이므로 이 자료만으로 당시 발표 날짜나 이후 수정 내용을 확인할 수 없습니다.

공개 이력이 있다면 같은 관측소·연도에 개정본이 둘 이상 있을 수 있으므로, 기준 시각 이하로 제한한 뒤 각 키의 가장 최근 버전을 고릅니다. 반대로 최신 버전 하나만 가진 과거 분석에서는 과거 연도만 사용하는 구조를 검증할 수 있어도, 그 수치가 역사적으로 정확히 그때 알려졌는지는 확인할 수 없습니다. 이후 프로젝트에서는 이 한계를 밝히고 고정된 수록 파일에서 시간순 모형을 비교합니다.

이어 풀기

키가 만드는 행 수와 시간 조건을 따로 검사합니다. 마지막 문제는 서로 다른 두 관측 수준을 한 표로 합치기 전에 무엇을 정의할지 묻습니다.

파이썬으로 같은 계산 검산하기

연평균 관측 CSV를 저장하고 아래 코드를 그 파일과 같은 작업 폴더에서 실행합니다.

from collections import Counter
from csv import DictReader
from datetime import date
from decimal import Decimal as D
from pathlib import Path

path = Path("annual_co2.csv")
with path.open(encoding="utf8", newline="") as source:
    rows = list(DictReader(source))
annual = {("MLO", int(r["year"])): D(r["mean_ppm"]) for r in rows}
assert len(rows) == len(annual) == 30
keys = [("MLO", 1990), ("MLO", 1991)]
notes = [(keys[0], "synthetic-1"), (keys[1], "synthetic-2"), (keys[1], "synthetic-3")]
raw_join = [annual[key] for key, _ in notes]
counts = Counter(key for key, _ in notes)
annual_join = [(annual[key], counts[key]) for key in keys]
print("full station-year rows:", len(annual))
print("note join / summarized join rows:", len(raw_join), len(annual_join))
print(f"note-weighted / year-weighted: {sum(raw_join)/len(raw_join):.4f}",
      f"{sum(value for value, _ in annual_join)/len(annual_join):.4f}")

released = {keys[0]: date(1991, 2, 1), keys[1]: date(1992, 2, 1)}
origin = date(1992, 1, 1)
available = [k for k in keys if released[k] <= origin]
print("synthetic release dates, available years:", [year for _, year in available])

실행 결과

full station-year rows: 30
note join / summarized join rows: 3 2
note-weighted / year-weighted: 355.2833 355.0750
synthetic release dates, available years: [1990]

CSV를 저장한 같은 작업 폴더에서 실행합니다. 코드의 소수 비교는 CSV 문자열을 Decimal로 읽어 원래 소수 자릿수를 보존합니다. NOAA의 실제 연평균은 수정하지 않고 메모와 날짜만 합성했습니다.
