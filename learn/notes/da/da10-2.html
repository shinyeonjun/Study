데이터 분석 · DA10 공개 데이터 분석 프로젝트

DA10·2

다음 해의 기준선과 최근 변화량을 시간순으로 비교하기

기준선과 두 후보는 같은 원점에서 동일한 대상 연도를 예측합니다. 창 길이는 선택 구간에서만 고르고, 그 길이를 잠근 뒤에 보류 구간의 실제 오차를 계산합니다.

이 장을 읽고 나면

  • 최근 변화량 평균과 예측식을 한 해에 손으로 적용한다.
  • 같은 연도를 비교하고 동점 규칙에 맞춰 후보를 고른다.
  • 보류 MAE·RMSE와 부호 있는 오차를 단위와 함께 해석한다.

최근 k번의 차분은 k+1개의 연도 값을 사용한다

t를 목표 연도라고 할 때 원점은 t−1입니다. 기준선은 yt−1를 그대로 내놓습니다. 후보는 그때까지의 최근 k개 연간 증가량을 평균해 마지막 값에 더합니다. 예를 들어 k=3이면 세 차분 yt−1−yt−2, yt−2−yt−3, yt−3−yt−4를 평균합니다. 가운데 항이 합에서 지워집니다.

ŷt(k)=yt−1+[yt−1−yt−1−k]/k.

2002년 예측에서 y2001=371.32ppm, y1998=366.84ppm입니다. k=3의 평균 연간 증가량은 (371.32−366.84)/3≈1.4933ppm이며 예측은 약 372.8133ppm입니다. 관측 373.45ppm을 나중에 보고 오차를 구하면 약 +.6367ppm입니다. 오차의 부호는 이 장 전체에서 e=y−ŷ입니다. 양수는 낮게 예측했다는 뜻입니다.

정해 둔 다섯 해에서 후보를 선택한다

2002–2006년의 다섯 목표를 한 해씩 내다봅니다. 각 해에는 같은 원점의 배열로 기준과 후보를 비교합니다. MAE는 Σ|e|/n입니다. k=3의 MAE와 k=6의 MAE는 두 경우 모두 .4240ppm으로 정확히 동점이어서 작은 k를 선택합니다. 표에서 출력한 값이 반올림으로만 우연히 같은 경우와 구분하기 위해 코드는 수를 분수로 유지합니다. 선택 기준은 처음에 고정한 규칙을 그대로 적용합니다.

선택한 규칙의 성능을 여덟 새 원점에서 집계한다

2012–2019년은 보류 구간입니다. 선택 과정이 끝난 뒤에만 같은 여덟 해의 점 예측을 다시 대조합니다. 기준의 MAE는 2.4750ppm, 선택한 3년 규칙의 MAE는 0.4183ppm입니다. 큰 오류에 더 민감한 RMSE √(Σe²/n)는 각각 2.5174ppm, 0.5232ppm입니다. 이 기록에서 두 지표의 순서는 같습니다. 오차가 한쪽으로 치우치는지 보려면 부호 있는 평균 오차도 따로 적습니다. 3년 규칙의 평균 오차는 0.1283ppm입니다.

2016년에는 약 +1.0833ppm, 2018년에는 −0.6900ppm의 오차가 남았습니다. 평균이 작은 규칙에도 오차가 특히 큰 연도가 있습니다. 8개 연도의 시점 오차는 인접해 생겼고, 같은 장소와 관측 과정에서 얻었습니다. 모형 간 평균 오차를 모았다는 사실만으로 다른 관측소나 다음 수십 년의 성능 차이를 추정하지는 않습니다.

이어 풀기와 증명

모형을 고를 때의 지표와 보류에서 보고할 지표를 따로 적고, 동일한 계산을 다른 한 해에 적용해 봅니다.

파이썬으로 같은 계산 검산하기

연평균 관측 CSV를 저장하고 아래 코드를 그 파일과 같은 작업 폴더에서 실행합니다.

from csv import DictReader
from fractions import Fraction as F
from math import sqrt
from pathlib import Path

with Path("annual_co2.csv").open(encoding="utf8", newline="") as source:
    y = {int(r["year"]): F(r["mean_ppm"]) for r in DictReader(source)}

def forecast(t, k):
    origin = t - 1
    return y[origin] if k == 0 else y[origin] + (y[origin]-y[origin-k])/k

def residuals(start, end, k):
    return [y[t]-forecast(t, k) for t in range(start, end+1)]

def mae(errors):
    return sum(map(abs, errors))/len(errors)

validation = {k: mae(residuals(2002, 2006, k)) for k in (0, 3, 6)}
selected = min((3, 6), key=lambda k: (validation[k], k))
for k, score in validation.items():
    print(f"selection k={k}: MAE={float(score):.4f}")
print("selected:", selected)
for k in (0, selected):
    err = residuals(2012, 2019, k)
    rmse = sqrt(sum(e**2 for e in err)/len(err))
    print(f"holdout k={k}: MAE={float(mae(err)):.4f}",
          f"RMSE={rmse:.4f} mean error={float(sum(err)/len(err)):.4f}")
for t in (2002, 2016, 2018):
    guess = forecast(t, selected)
    print(f"{t}: forecast={float(guess):.4f} actual={float(y[t]):.4f}",
          f"error={float(y[t]-guess):+.4f}")
