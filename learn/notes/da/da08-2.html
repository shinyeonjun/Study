표본을 반복해서 뽑아 보면: 정확한 계산과 시뮬레이션

표본평균은 표본을 어떻게 뽑았느냐에 따라 바뀝니다. 값 네 개에서 두 개를 뽑는 경우를 모두 세고, NumPy로 같은 추출을 반복해 그 분포를 확인합니다.

이 장을 읽고 나면

  • 모집단 분포와 표본평균의 분포를 구별한다.
  • 비복원 표본의 가능한 조합을 모두 세어 정확한 확률을 구한다.
  • 난수 생성기로 같은 표집 규칙을 반복하고 결과의 한계를 설명한다.

한 번 뽑으면 평균 하나가 나온다

네 칸 A, B, C, D에 각각 0, 0, 10, 10이 있습니다. 모집단 평균은 (0 + 0 + 10 + 10) ÷ 4 = 5입니다. 서로 다른 칸 두 개를 같은 가능성으로 뽑아 평균을 내면, A와 B는 평균 0, C와 D는 평균 10, 나머지 조합은 평균 5입니다.

이 방법을 비복원 추출이라고 합니다. 한 번의 표본 안에서 같은 칸을 다시 뽑지 않습니다. A와 B는 값이 둘 다 0이지만 다른 칸이며, 두 칸을 동시에 뽑을 수 있습니다. 다음 표본을 만들 때는 다시 원래의 네 칸에서 시작합니다.

두 칸 조합값표본평균
A와 B0, 00
A와 C / A와 D / B와 C / B와 D0, 105
C와 D10, 1010

표본평균이 가질 수 있는 값의 분포

정해진 표집 절차를 반복했을 때 표본평균이 가질 수 있는 값과 그 확률을 표본평균의 표집분포라고 합니다. 모든 조합이 같은 가능성을 가지므로 평균이 0이거나 10일 확률은 2/6 = 1/3입니다. 평균이 5인 조합이 4개이므로, 뽑기 한 번의 표본평균이 모집단 평균과 같을 확률은 4/6입니다.

from collections import Counter
from itertools import combinations

values = [0, 0, 10, 10]
means = [(values[i] + values[j]) / 2 for i, j in combinations(range(4), 2)]
print(dict(sorted(Counter(means).items())))
print(sum(means) / len(means))

실행 결과

{0.0: 1, 5.0: 4, 10.0: 1}
5.0

combinations는 서로 다른 위치를 순서와 상관없이 짝짓습니다. Counter는 같은 평균이 몇 번 나왔는지 셉니다. 가능한 경우가 여섯 개뿐이므로 이 결과는 근삿값을 만들기 위한 시뮬레이션과 달리 전수 계산입니다.

둘째 줄의 5.0은 가능한 여섯 표본평균을 같은 가중치로 평균한 값, 곧 표본평균의 기댓값입니다. (0 + 5 × 4 + 10) ÷ 6 = 5로 모집단 평균과 같습니다. 개별 표본평균은 0이나 10처럼 빗나갈 수 있지만, 모든 칸이 같은 가능성으로 뽑히는 규칙에서는 표본평균이 평균적으로 모집단 평균을 맞힙니다. 이런 성질을 불편성(unbiasedness)이라고 하며, 한 번의 표본이 정확하다는 뜻은 아닙니다.

시뮬레이션으로 추출을 반복하기

import numpy as np

values = [0, 0, 10, 10]
rng = np.random.default_rng(42)
means = np.array([
    rng.choice(values, size=2, replace=False).mean()
    for _ in range(10_000)
])
print(np.unique(means, return_counts=True)[1].tolist())
print(f"{means.mean():.3f}")
print(f"{((means == 0) | (means == 10)).mean():.4f}")

실행 결과

[1667, 6689, 1644]
4.989
0.3311

예제의 반복마다 평균 0과 10인 경우를 함께 세면 1,667 + 1,644 = 3,311회입니다. 관측된 비율 0.3311은 정확한 확률 1/3에 가깝습니다. 시드를 바꾸면 빈도는 달라질 수 있습니다. 출력은 Python 3.14.6, NumPy 2.5.5에서 확인했습니다.

반복 횟수와 표본 크기를 구별하기

시뮬레이션에서 10,000은 표본을 다시 뽑은 횟수이고 2는 한 표본의 크기입니다. 반복을 많이 하면 이 표집 규칙의 결과 분포를 더 잘 관찰할 수 있습니다. 표본 크기를 4로 바꾸고 비복원으로 뽑으면 매번 네 값이 전부 들어가므로 평균은 늘 5입니다.

처음부터 10인 칸만 고르는 편향된 규칙이라면 같은 실험을 수천 번 반복해도 결과는 10입니다. 실제 분석에서는 모집단 전체의 값이 보이지 않는 경우가 많습니다. 이 예의 의의는 표집 규칙을 바꿨을 때 추정치가 어떻게 달라지는지 작은 데이터에서 직접 확인하는 데 있습니다.

혼자 바꾸어 볼 조건

네 칸에서 한 칸만 뽑으면 평균 0과 10이 각각 절반입니다. 이번에는 복원 추출을 시험하세요. 첫 칸을 뽑은 다음 되돌려 놓고, 다시 네 칸 중 하나를 같은 가능성으로 뽑습니다. 두 번의 선택은 독립입니다. 평균이 0 또는 10일 확률을 손으로 먼저 구하고 replace=True로 바꿔 실행합니다.

이 추출을 집합과 확률로 표현하고 싶다면 집합과 연산에서 시작해 표본공간과 사건으로 이어집니다. 관측 데이터를 본 뒤 어떤 대상을 추정할지 더 살펴보려면 통계의 목표량과 관측 단위를 읽습니다.
