AL04·1

함수: 정의역·치역, 합성, 역함수

머신러닝 모델은 특징 벡터를 받아 예측값 하나를 내놓는 함수이고, 신경망은 그런 함수 여러 개를 이어 붙인 합성함수이며, 데이터를 표준화했다가 원래 단위로 되돌리는 일은 역함수를 쓰는 일입니다. 이 장은 고등학교 함수 단원을 뒤에서 쓰이는 형태로 압축해 복습합니다: 정의와 정의역·공역·치역, 함숫값과 표현의 전환, 합성의 순서와 정의역 조건, 역함수의 존재 조건과 그래프.

이 장을 읽고 나면

  • 함수 f: X → Y의 정의를 쓰고, 화살표 그림·표·그래프에서 함수 여부를 판정할 수 있다.
  • 정의역·공역·치역을 구별하고, 식의 자연스러운 정의역(분모 ≠ 0 등)과 치역을 구할 수 있다.
  • 같은 함수를 말·표·그래프·식으로 옮기고 각 표현이 놓치는 정보를 말할 수 있다.
  • g∘f의 계산 순서와 정의역 조건을 알고, 순서를 바꾸면 결과가 달라지는 예를 들 수 있다.
  • 역함수가 존재할 조건(일대일대응)을 말하고, 역함수의 식과 그래프(y = x 대칭)를 구할 수 있다.

정의

정의 외우기

두 집합 X, Y에 대해, X의 각 원소 x에 Y의 원소를 정확히 하나 대응시키는 규칙 f를 X에서 Y로의 함수라 하고 f: X → Y로 적습니다. x에 대응하는 원소를 함숫값 f(x)라 합니다.
정의역(domain) = X, 공역(codomain) = Y, 치역(range, image) = {f(x) | x ∈ X} ⊆ Y.

{f(x) | x ∈ X}는 "x가 X 전체를 움직일 때 나오는 f(x)들의 집합"이라고 읽습니다. 정의의 핵심 조건은 두 가지입니다. (1) 모든 x ∈ X에 대응값이 있어야 하고, (2) 그 값이 하나여야 합니다. 반대로 정의가 요구하지 않는 것도 분명히 해 둡니다. 서로 다른 x가 같은 값으로 가도 되고(f(1) = f(2)), 공역에 아무 x도 대응하지 않는 원소가 남아도 됩니다. 판정은 언제나 정의역 쪽에서 나가는 화살표 수로 합니다.

그래프 G = {(x, f(x)) | x ∈ X}에서 조건 (2)는 세로선 판정이 됩니다. 어떤 세로선 x = c도 그래프와 두 번 이상 만나지 않아야 합니다. 두 번 만나면 입력 c에 출력이 둘입니다. 가로선이 여러 번 만나는 것은 함수 여부와 무관하고, 뒤에서 볼 일대일 여부와 관련됩니다.

흔한 실수

"출력이 겹치면 함수가 아니다". 그림 1 (라)처럼 f(1) = f(2) = 10이어도 함수입니다. 금지되는 것은 한 입력에 출력이 둘인 경우뿐입니다. 데이터에서도 "학생 → 학과"는 함수(여러 학생이 같은 학과)지만 "학과 → 학생"은 함수가 아닙니다.

f(3)을 f × 3으로 읽기. f는 수가 아니라 규칙의 이름입니다. 또 f(x) = 2x + 1이면 f(3) + 1 = 8, f(3 + 1) = f(4) = 9로 서로 다릅니다.

정의역과 치역 구하기

정의역을 따로 밝히지 않은 식은 식이 실수값으로 계산되는 모든 실수를 정의역으로 봅니다(자연스러운 정의역). 이 장 이후 자주 만나는 제외 조건은 다음과 같습니다.

식의 꼴조건예
분수 p(x) / q(x)q(x) ≠ 01/(x − 3): x ≠ 3
제곱근 √uu ≥ 0 (실수 범위)√(x + 1): x ≥ −1
로그 log uu > 0log x: x > 0 (지수와 로그 단원)
실제 상황뜻이 있는 값만인원수: 0, 1, 2, …

치역은 정의역 전체를 넣어 나오는 값을 모읍니다. 정의역이 유한하면 하나씩 넣고, 같은 값은 한 번만 적습니다.

풀이 예제

① f(x) = 2x + 1, 정의역 {0, 1, 2, 3}: f(0)=1, f(1)=3, f(2)=5, f(3)=7 → 치역 {1, 3, 5, 7}. 공역을 {1, …, 7}로 잡았다면 2, 4, 6은 공역에는 있고 치역에는 없다.
② g(x) = |x|, 정의역 {−2, −1, 0, 1, 2}: 값 2, 1, 0, 1, 2 → 치역 {0, 1, 2}. 원소 다섯 개가 세 값으로 모인다.
③ h(x) = 1/(x − 3): 정의역 = {x | x ≠ 3}. 1/(x − 3) = 0이 되는 x는 없으므로 치역 = {y | y ≠ 0}.

③의 치역은 "y가 되는 x가 있는가"를 거꾸로 풀어 구했습니다. y = 1/(x − 3)을 x에 대해 풀면 x = 3 + 1/y이고, 이 식은 y ≠ 0이면 언제나 계산됩니다. 치역을 구하는 이 방법은 아래의 역함수 구하기와 같은 계산입니다.

네 가지 표현

섭씨온도 c를 화씨온도로 바꾸는 함수 f(c) = 1.8c + 32를 네 가지로 적으면 다음과 같습니다.

표현얻는 것잃는 것
말규칙의 뜻계산 가능성, 정밀함
표몇몇 입력의 정확한 값. 데이터가 처음 생기는 모양표에 없는 입력의 값, 전체 모양
그래프증가·감소·곧음·꺾임 같은 전체 모양정확한 값(눈금 사이는 어림)
식임의의 입력에 대한 정확한 값모양이 한눈에 안 보임

전환 방향마다 하는 일이 다릅니다. 식 → 표는 대입, 표 → 그래프는 순서쌍 (x, f(x))를 점으로 찍기, 그래프 → 값은 읽기(어림)입니다. 선으로 이을지는 정의역이 정합니다. 온도처럼 정의역이 구간이면 선, 인원수처럼 띄엄띄엄이면 점만 찍습니다. 가장 어려운 방향은 표 → 식입니다. 위 표에서는 c가 10 늘 때마다 f(c)가 18씩 늘고 f(0) = 32이므로 1.8c + 32를 찾을 수 있지만, 일반적으로 유한한 표를 지나는 식은 무수히 많습니다. 표에서 식을 "고르는" 문제가 곧 회귀와 머신러닝의 학습 문제입니다(다음 단원에서 직선부터 다룹니다).

합성

정의 외우기

f: X → Y, g: Y → Z일 때 (g∘f)(x) = g(f(x))로 정한 함수 g∘f: X → Z를 f와 g의 합성함수라 합니다. 계산은 안쪽부터, 곧 f 먼저, g 나중입니다.

정의에서 f의 공역이 g의 정의역과 맞물려 있다는 점이 중요합니다. 일반적으로 g(f(x))가 정의되려면 f(x)가 g의 정의역 안에 있어야 합니다. 예를 들어 f(x) = x − 2, g(x) = 1/x이면 g(f(x)) = 1/(x − 2)이고, f(2) = 0이 g의 정의역 밖이므로 g∘f의 정의역에서 2가 빠집니다.

합성은 일반적으로 교환법칙이 성립하지 않습니다(g∘f ≠ f∘g). 10% 할인 f(x) = 0.9x와 3,000원 쿠폰 g(x) = x − 3000으로 확인합니다.

g(f(x)) = 0.9x − 3000
f(g(x)) = 0.9(x − 3000) = 0.9x − 2700
f(g(x)) − g(f(x)) = 300 (모든 x에서)

합성의 결합법칙 h∘(g∘f) = (h∘g)∘f는 성립합니다. 둘 다 "f, g, h 순서로 적용"이기 때문입니다. 그래서 여러 단계를 괄호 없이 h∘g∘f로 적습니다. 신경망의 층 L₁, L₂, L₃을 차례로 통과시키는 계산이 정확히 L₃∘L₂∘L₁이고, 미분 단원의 연쇄법칙은 이 합성의 변화율을 다룹니다.

역함수

정의 외우기

f: X → Y에 대해 g: Y → X가 g(f(x)) = x (모든 x ∈ X)이고 f(g(y)) = y (모든 y ∈ Y)이면 g를 f의 역함수라 하고 f⁻¹로 적습니다. 곧 f(a) = b ⇔ f⁻¹(b) = a.

역함수가 있으려면 f가 일대일대응이어야 합니다. 즉 (1) 일대일: x₁ ≠ x₂이면 f(x₁) ≠ f(x₂), (2) 치역 = 공역: Y의 모든 원소가 어떤 x의 값. (1)이 깨지면 출력 하나에서 입력을 하나로 되찾을 수 없고, (2)가 깨지면 되돌릴 입력이 없는 y가 생깁니다. 그래프로는 가로선 판정입니다. 어떤 가로선도 두 번 이상 만나지 않으면 일대일입니다.

일대일이 아닌 함수는 정의역을 제한하면 역함수를 만들 수 있습니다. |x|를 x ≥ 0으로 제한하면 항등함수가 되고, x²을 x ≥ 0으로 제한하면 역함수가 √x입니다. 공역을 치역으로 줄이면 (2)는 언제나 맞출 수 있으므로, 실제로 따지는 것은 대부분 (1)입니다.

풀이 예제: 역함수 구하기

f(c) = 1.8c + 32 (모든 실수 → 모든 실수)의 역함수.

① y = 1.8c + 32로 놓는다.
② c에 대해 푼다: y − 32 = 1.8c → c = (y − 32)/1.8
③ f⁻¹(y) = (y − 32)/1.8. 변수 이름을 x로 바꾸면 f⁻¹(x) = (x − 32)/1.8
④ 검산: f⁻¹(212) = 180/1.8 = 100, f(100) = 180 + 32 = 212 ✓

②는 f가 한 일(×1.8 다음 +32)을 역순·반대 연산(−32 다음 ÷1.8)으로 되돌린 것입니다. 일반적으로 (g∘f)⁻¹ = f⁻¹∘g⁻¹입니다(양말·신발 순서).

f 위의 점 (a, b)는 f⁻¹ 위의 점 (b, a)이므로, 두 그래프는 직선 y = x에 대해 대칭입니다(가로·세로 눈금이 같을 때 그림에서도 대칭으로 보입니다).

시험 함정

f⁻¹(x) ≠ 1/f(x). f(x) = 2x + 1이면 f⁻¹(3) = 1이지만 1/f(3) = 1/7입니다. 함수 이름에 붙은 ⁻¹은 합성에 대한 역원이라는 표시이고, 거듭제곱 x⁻¹ = 1/x와는 다른 기호입니다.

왜 그럴까?

표준화 z = (x − μ)/σ (μ: 평균, σ: 표준편차 > 0)로 데이터를 바꿔 모델을 학습한 뒤, 예측한 z를 원래 단위로 되돌리려 합니다. 되돌리는 식은 무엇이고, σ > 0이라는 조건은 왜 필요할까요?

모범 답 보기

z = (x − μ)/σ는 "μ를 빼고 σ로 나누기"이므로 역순·반대 연산으로 x = σz + μ입니다. σ = 0이면 처음 식이 정의되지 않고(분모 0), σ ≠ 0이면 일차함수라서 일대일대응이므로 역함수가 존재합니다. 표준편차는 0 이상이고 모든 값이 같을 때만 0이므로, 값이 전부 같은 특징은 표준화할 수 없다는 실무 규칙이 여기서 나옵니다.

한 줄 정리

함수는 정의역의 각 원소에 값 하나를 주는 규칙이고, 합성은 안쪽부터 이어 붙이는 것, 역함수는 일대일대응일 때만 있는 되돌리기다.
