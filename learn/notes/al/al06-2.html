이차함수의 뿌리, 꼭짓점과 최솟값

같은 이차함수를 전개해도, 곱으로 써도, 제곱 하나와 상수로 써도 그래프는 그대로입니다. 곱은 함수값이 0인 곳을 보여 주고, 제곱은 값이 가장 작거나 큰 곳을 보여 줍니다.

이 장을 읽고 나면

  • 이차함수의 세 가지 형태에서 읽을 수 있는 정보를 구별한다.
  • 완전제곱식으로 꼭짓점과 최댓값·최솟값을 구한다.
  • 이차방정식의 실근 수를 판별식으로 해석한다.
  • 입력에 제한이 있는 최솟값 문제를 구별한다.

함수값이 0인 입력을 고르기

실수 x에 대해 f(x) = x² − 6x + 5를 정의합니다. 이차함수는 일반적으로 ax² + bx + c이며 a가 0이 아닙니다. 이 함수의 근은 f(x) = 0을 만족하는 x입니다. 그래프에서 x축과 만나는 점의 x좌표와 같습니다.

풀이 예제

x² − 6x + 5 = (x − 1)(x − 5)입니다. 두 실수를 곱한 결과가 0이라면 적어도 하나가 0입니다. 따라서 x − 1 = 0 또는 x − 5 = 0에서 근은 1, 5입니다. 근은 입력값이고, y절편은 x=0의 출력인 5입니다.

인수분해된 식에서 a가 빠지면 같은 근을 가져도 다른 함수가 될 수 있습니다. 예를 들어 2(x − 1)(x − 5)은 근이 같지만 y절편은 10입니다.

완전제곱으로 꼭짓점 읽기

x² − 6x를 (x − 3)²로 만들려면 9를 더해야 합니다. 식 전체의 값이 바뀌지 않도록 같은 9를 빼면 x² − 6x + 5 = (x² − 6x + 9) − 9 + 5 = (x − 3)² − 4입니다. 이를 완전제곱으로 정리한다고 합니다.

(x − 3)²은 0 이상이며 x=3에서만 0입니다. 따라서 모든 실수에서 가장 작은 함수값은 −4이고, 그때의 입력은 3입니다. 좌표 (3, −4)가 꼭짓점입니다. 입력 3, 출력 −4, 점 (3, −4)는 질문에 따라 구분해 답합니다. x=3에서 같은 거리만큼 떨어진 두 점은 제곱이 같아 그래프가 좌우 대칭입니다.

일반형에서 읽기

ax² + bx + c = a(x + b/(2a))² + c − b²/(4a)입니다. 대칭축은 x = −b/(2a)입니다. 앞 계수 a가 양수이면 꼭짓점이 최솟값, 음수이면 최댓값을 줍니다. 이 말은 정의역을 모든 실수로 두었을 때의 결론입니다.

예를 들어 g(x) = −2(x − 1)² + 8이라면, 제곱항을 빼는 구조이므로 x=1에서 최댓값 8이 됩니다. f의 정의역을 [4, 6]으로 줄인다면 3을 고를 수 없습니다. 이때는 x=4가 3에 가장 가까워 f(4) = −3이 최소입니다.

실행 예제

def f(x):
    return x*x - 6*x + 5

for x in (0, 1, 3, 4, 5, 6):
    assert f(x) == (x - 1)*(x - 5) == (x - 3)**2 - 4
    print(x, f(x))

1 0
3 -4
4 -3
5 0
6 5

흔한 실수

위 코드가 본 입력 몇 개의 값을 비교한다고 해서 모든 실수에서의 최솟값이 증명되는 것은 아닙니다. 제곱항이 항상 0 이상이라는 사실과 0을 만드는 입력이 정의역에 있다는 사실이 증명의 근거입니다.

근이 몇 개인지 먼저 판별하기

ax² + bx + c = 0을 완전제곱으로 정리하고 양변을 a로 나누면 (x + b/(2a))² = (b² − 4ac)/(4a²)입니다. 분모가 양수이므로 오른쪽의 부호는 판별식 D = b² − 4ac의 부호로 결정됩니다.

D의 부호제곱해야 하는 수서로 다른 실근 수
D > 0양수이므로 양·음 제곱근2
D = 00만 가능1 (중근)
D < 0실수의 제곱은 음수가 될 수 없음0

D≥0인 경우에 식을 정리하면 x = (−b ± √D)/(2a)입니다. f에는 a=1, b=−6, c=5이므로 D = 36 − 20 = 16, x = (6 ± 4)/2여서 다시 1과 5입니다. (x − 3)²은 x=3에서만 x축에 닿고, (x − 3)² + 1은 모든 x에서 양수라 x축에 닿지 않습니다.
