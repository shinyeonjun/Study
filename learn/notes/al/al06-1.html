AL06·1

다항식을 펼치고, 약분 뒤에도 정의역 남기기

같은 넓이를 한 덩어리로 곱할 수도 있고 작은 넓이로 나눠 더할 수도 있습니다. 전개와 인수분해는 그 두 표현을 오가는 일입니다. 분수식에서는 같은 값을 주는 표현을 찾은 뒤에도 처음부터 뺀 입력을 기억해야 합니다.

이 장을 읽고 나면

  • 항의 차수를 읽고 분배법칙으로 다항식을 전개한다.
  • 공통인수·합차·이차식의 인수분해를 검산한다.
  • 유리식에서 약분할 인수와 처음 정의되지 않는 입력을 구별한다.

다항식의 구조와 전개

변수 x가 들어간 식 x² + 5x + 6은 세 항의 합입니다. 다항식은 a·xᵏ 꼴의 항을 유한 개 더한 식입니다. k는 0 이상의 정수이고 a는 계수입니다. 항을 모아 정리했을 때 계수가 0이 아닌 항의 최고 지수를 다항식의 차수라고 합니다. 예를 들어 x³ − x³ + 2x는 정리하면 1차이고, 0이 아닌 상수만 남으면 0차입니다. 1/x는 x의 지수가 −1이어서 다항식이 아닙니다.

가로가 x + 2, 세로가 x + 3인 직사각형을 생각합니다. x가 양수일 때 실제 길이로 그릴 수 있습니다. 두 변을 각각 x와 나머지 길이로 나누면 넓이는 x·x + 3x + 2x + 2·3입니다. 분배법칙은 양의 길이를 벗어난 입력에도 쓸 수 있는 대수 규칙입니다.

풀이 예제

(x + 2)(x + 3) = x(x + 3) + 2(x + 3) = x² + 3x + 2x + 6 = x² + 5x + 6입니다. 모든 항의 쌍을 한 번씩 곱한 뒤 지수가 같은 항끼리 모읍니다.

(x − 3)²도 (x − 3)(x − 3)이므로 x² − 6x + 9입니다. 첫 항의 제곱과 마지막 항의 제곱만 쓰면 두 교차항 −3x를 빠뜨립니다.

인수분해는 곱의 구조를 되찾는 일

인수는 곱을 이루는 한 덩어리입니다. 6x² + 9x = 3x(2x + 3)에서 두 항에 공통으로 곱해진 3x를 밖으로 꺼냈습니다. x² − 9 = (x − 3)(x + 3)은 합과 차를 곱하면 교차항이 지워지는 성질입니다. x² + 5x + 6에서는 합이 5, 곱이 6인 2와 3을 찾아 (x + 2)(x + 3)로 씁니다.

먼저 공통인수를 찾고, 남은 부분의 구조를 봅니다. 인수분해가 맞는지 확인할 때는 다시 전개합니다. 서로 다른 두 식이 특정 x 하나에서 같은 값이라는 계산만으로는 항등식을 검증하지 못합니다. 예를 들어 x=1에서는 x와 x²가 모두 1이지만 대부분의 입력에서는 다릅니다.

분모를 먼저 살피고 약분한다

유리식은 다항식을 다항식으로 나눈 식입니다. 함수로 읽을 때 분모를 0으로 만드는 입력은 정의역에서 뺍니다. 예를 들어 f(x) = (x² − 9)/(x − 3)에는 x=3을 넣을 수 없습니다.

풀이 예제

① 원래 분모를 보고 x ≠ 3을 적습니다.
② 분자를 인수분해해 (x − 3)(x + 3)/(x − 3)을 얻습니다.
③ x − 3 ≠ 0인 곳에서 약분합니다.
결과는 x + 3, 단 x ≠ 3입니다.

약분한 식을 모든 실수에서 정의한 g(x) = x + 3은 f의 그래프에서 빈 점을 채운 새 함수입니다. f(3)은 정의되지 않고 g(3)은 6입니다. 계산값이 같다는 말은 원래 정의역 안에서만 적용합니다.

실행 예제

from fractions import Fraction as F

for x in (F(2), F(29, 10), F(3), F(31, 10), F(4)):
    if x == 3:
        print(x, "정의되지 않음")
    else:
        original = (x*x - 9) / (x - 3)
        assert original == x + 3
        print(x, original)

29/10 59/10

더 복잡한 예로 (x² − 4)/[(x − 2)(x + 1)]은 원래 x=2와 x=−1에서 정의되지 않습니다. (x + 2)/(x + 1)로 줄인 뒤에도 두 값은 계속 제외합니다. 반면 (x + 3)/x는 분자의 두 항 가운데 x가 하나 있다고 해서 약분할 수 없습니다. x는 분자 전체에 공통으로 곱해진 인수가 아닙니다. x≠0에서는 1 + 3/x로 나눠 쓰면 두 항이 모두 남습니다.
