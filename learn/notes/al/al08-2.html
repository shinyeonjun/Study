사인 그래프의 진폭·주기·위상 읽기

원을 일정한 속도로 돌 때의 세로 좌표를 시간순으로 그립니다. 파동의 중심과 높이, 반복 시간, 시작점의 차이를 한 함수에서 찾아봅니다.

이 장을 읽고 나면

  • 진폭·중심선·주기·주파수를 수식과 데이터에서 계산한다.
  • 위상 변화가 시간 그래프를 어떻게 이동시키는지 설명한다.
  • 한 주기 뒤 값이 반복되는지 확인한다.

시간을 각으로, 각을 좌표로 바꾼다

모형 h(t)=2+3 sin(πt/2)를 생각합니다. t는 초이고 h는 어떤 센서의 출력입니다. 먼저 t에 π/2를 곱해 각을 얻고, 사인값을 읽은 뒤 3을 곱하고 2를 더합니다. 진폭은 3, 중심선은 h=2입니다. 사인값이 −1과 1 사이이므로 최솟값은 −1, 최댓값은 5입니다.

주기와 1초에 몇 번 반복하는지를 구분한다

각이 초당 π/2라디안씩 증가하므로 각이 한 바퀴 2π 증가하는 데 2π/(π/2)=4초가 걸립니다. 이것이 주기입니다. 주파수는 1초당 주기의 수라서 1/4=0.25Hz입니다. 일반식 b+A sin(ωt+φ)에서 ω>0, A≠0이면 진폭 |A|, 중심 b, 주기 2π/ω입니다. 상수 b만 바꾸면 위아래로 이동하고, ω를 두 배로 키우면 주기가 절반이 됩니다.

센서의 시작점이 다를 때

g(t)=2+3 sin(πt/2+π/2)라 하면 h(t+1)과 같습니다. 시각 t에서 h의 1초 뒤 값을 보여 주므로 g의 그래프는 h보다 왼쪽으로 1초 이동합니다. h는 t=1에서 첫 꼭대기이며 g는 t=0부터 꼭대기에 있습니다. 괄호 안에 더한 위상은 라디안이고 그래프를 옮기는 시간은 초입니다.

from math import isclose, pi, sin

def h(t):
    return 2 + 3 * sin(pi*t/2)

def g(t):
    return 2 + 3 * sin(pi*t/2 + pi/2)

values = [h(t) for t in range(5)]
print("h:", *(f"{v:.1f}" for v in values))
print("g(0):", f"{g(0):.1f}")
periodic = all(isclose(h(t), h(t+4), abs_tol=1e-12) for t in (0, 0.5, 1.25))
shifted = all(isclose(g(t), h(t+1), abs_tol=1e-12) for t in (0, 0.5, 1.25))
assert periodic and shifted
print("주기와 이동 확인:", periodic, shifted)

데이터가 일정한 간격으로 측정되지 않았거나 간격이 너무 길면 꼭대기를 놓칠 수 있습니다. 표본들의 최댓값과 최솟값만으로 실제 파형의 진폭을 항상 찾을 수는 없습니다. 각을 시간에 연결한 모델이나 더 촘촘한 측정이 도움이 됩니다.

한 줄 정리

사인의 중심·진폭·주기는 각각 높이와 변화 폭, 한 바퀴 도는 시간에서 계산합니다.
