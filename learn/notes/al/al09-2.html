유한합과 유한곱, 조건을 세는 지시함수

일주일마다 기록한 수를 전부 더하거나, 기간별 비율을 이어서 곱해야 할 때가 있습니다. Σ와 Π는 어느 범위에 무슨 연산을 반복할지 적는 기호입니다. 더할 값 자리에 조건의 참·거짓을 1과 0으로 놓으면 원하는 건수를 셀 수 있습니다.

이 장을 읽고 나면

  • Σ와 Π에서 첨자, 시작·끝 번호, 각 항을 읽는다.
  • 유한한 등차합과 등비합을 손으로 유도한다.
  • 조건의 지시함수를 합해 건수를 세고, 반복 곱으로 누적 변화를 구한다.

시작과 끝을 함께 읽는다

시그마 Σ는 정해진 범위의 값을 더하라는 기호입니다. 예를 들어 Σi=25 (i+1)은 i에 2, 3, 4, 5를 넣고 차례로 3, 4, 5, 6을 더하므로 18입니다. i는 임시로 이름 붙인 반복 번호입니다. 모두 같은 범위를 취한다면 i를 k로 바꾸어도 합은 같습니다.

첨자의 범위가 m부터 n까지 이어지고 m≤n이면 항은 n−m+1개입니다. 여기서는 5−2+1=4개입니다. 수식의 위끝은 포함하지만 Python의 range(2, 6)에서는 6이 포함되지 않습니다. 전체 합을 구하는 sum에 각 i의 식을 넘기면 같은 계산이 됩니다.

실행 예제

numbers = [i + 1 for i in range(2, 6)]
print(numbers)
print(sum(numbers))
[3, 4, 5, 6]
18

등차수열의 합에서 끝끼리 짝짓기

5, 8, 11, 14, 17의 합 S를 직접 더해도 됩니다. 앞에서 순서대로 적은 S와 뒤에서부터 적은 S를 나란히 놓으면, 5+17과 8+14뿐 아니라 가운데 11+11까지 모두 22입니다.

5개의 열에서 각각 22가 나왔으므로 2S = 5×22이고 S=55입니다. 일반적인 등차수열에서는 서로 짝이 되는 두 항의 합이 a₁ + aₙ입니다. 왼쪽에서 한 칸 갈 때 +d, 오른쪽에서 한 칸 되돌아올 때 −d가 상쇄되기 때문입니다. 그래서 Sₙ = n(a₁ + aₙ)/2입니다.

등비수열의 합에서 겹치는 항 지우기

공비가 r인 등비수열의 첫 n개를 더한 값은 Sₙ = a₁ + a₁r + … + a₁rⁿ⁻¹입니다. r을 곱한 rSₙ = a₁r + … + a₁rⁿ을 빼면 가운데 항이 같은 값끼리 사라집니다. 따라서 (1−r)Sₙ = a₁ − a₁rⁿ입니다.

공식과 조건

r ≠ 1이면 Sₙ = a₁(1−rⁿ)/(1−r)입니다. r=1이면 한 항이 계속 a₁이므로 Sₙ=n·a₁입니다. 유한한 합이므로 r이 1보다 큰 경우에도 쓸 수 있습니다.

예를 들어 8 + 4 + 2 + 1은 첫 항 8, 공비 1/2, 항 네 개입니다. 식에 넣으면 8×(1−(1/2)⁴)/(1−1/2) = 15입니다. 5번째 항 1/2는 이 문제의 합에 포함하지 않습니다.

곱의 기호와 조건의 지시함수

파이 Π는 항을 모두 곱하라는 뜻입니다. 시작값 x가 기간마다 비율 rᵢ만큼 변하면 기간이 끝날 때마다 1+rᵢ를 곱합니다. 먼저 10% 늘고 다음에 20% 줄면 ∏i=12 (1+rᵢ) = 1.10×0.80 = 0.88입니다. 따라서 원래 10,000원은 8,800원이 됩니다. 두 비율을 단순히 더해 −10%라고 하면 서로 다른 기준값을 무시합니다.

지시함수 1{조건}은 조건이 참이면 1, 거짓이면 0입니다. 다섯 값 65, 70, 90, 68, 75에서 70 이상인 수를 세려면 Σi=15 1{xᵢ ≥ 70}을 씁니다. 합에 들어간 다섯 값은 0, 1, 1, 0, 1이므로 결과는 3입니다. 전체 개수 5로 나누면 이 표의 상대도수인 3/5입니다.

실행 예제

from fractions import Fraction as F
from math import prod

factor = prod((F(11, 10), F(4, 5)))
scores = [65, 70, 90, 68, 75]
indicators = [int(score >= 70) for score in scores]
print(factor, 10000 * factor)
print(indicators)
print(sum(indicators), F(sum(indicators), len(scores)))
22/25 8800
[0, 1, 1, 0, 1]
3 3/5

예제에서 int(score >= 70)은 참·거짓을 정수 1·0으로 바꿉니다. 덧셈 전체를 0에서 시작하는 것과 마찬가지로 곱셈 전체는 1에서 시작합니다. 계산할 항이 없다면 합은 0, 곱은 1로 두어 중간 결과를 이어 붙일 때 값이 달라지지 않게 합니다.
