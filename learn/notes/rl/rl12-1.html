RL12·1

학습과 평가를 분리하고 상호작용을 센다

두 정책의 평균 점수가 달랐습니다. 점수를 해석하기 전에 처음에 어떤 조건에서 출발했고, 모델이 바뀌던 동안 무엇을 몇 번 관측했는지부터 확인합니다.

이 장을 읽고 나면

  • 훈련·선택·최종 평가를 나누고 필요한 실험 설정을 기록한다.
  • 환경을 움직인 횟수와 에피소드 수, 학습 갱신 수를 구별한다.
  • 정책 난수와 환경 난수를 분리해 고정한 정책의 평가를 재실행한다.

학습하는 동안 본 점수와 동결한 정책의 점수를 구별한다

훈련 중의 탐험 행동은 데이터를 모으기 위한 것입니다. 학습할 때 쓴 에피소드 점수에는 탐험, 변하는 가중치, 우연히 쉬웠던 시작점이 함께 들어갑니다. 완성한 정책의 실력을 보려면 특정 시점의 가중치를 저장하고, 별도 에피소드에서 가중치가 바뀌지 않게 실행합니다. 평가 시 정규화 통계나 순환 정책의 상태도 관리합니다. 학습 통계를 얼려 두고, 새 에피소드에서는 이전 에피소드의 기억이 이어지지 않게 초기화합니다.

평가에서 무작위로 행동할지, 가장 높은 행동 확률만 고를지는 묻는 질문에 달려 있습니다. 확률 정책 자체를 평가한다면 정책대로 표본을 뽑습니다. 배포에서 결정적 선택을 사용할 예정이면 그 규칙을 따로 명시한 점수를 비교합니다. 환경 변화와 정책의 무작위성이 무엇인지 구분합니다.

변경 사항의 효과를 보고 싶다면 비교할 알고리즘에서 공통 조건을 먼저 고정합니다. 환경 이름과 버전, 관측·행동 변환, 종료·중단, 보상 함수, 시작점 분포, 할인 여부, 평가 에피소드 수, 평가가 이루어지는 학습 시점을 기록합니다. 여러 설정이나 체크포인트를 비교해 고른 성능은 선택용 결과입니다. 최종 시험용 시드나 초기 조건은 선택에 반복해서 활용하지 않습니다.

한 에피소드가 언제나 같은 경험량을 뜻하지는 않는다

확인대에서 직행하면 한 전이 뒤 끝나고, 확인을 거치면 두 전이 이상 필요할 수도 있습니다. 예를 들어 네 에피소드에서 전이가 2,1,2,1개라면 실제로 환경을 6번 움직였습니다. 이 교재에서는 환경 한 단계에서 전이 하나를 얻는다고 세겠습니다. 여러 환경을 병렬로 돌리면 한 번의 벡터 호출에서도 각 환경이 만든 유효한 전이를 합산할 수 있습니다.

상호작용 예산은 환경에서 새로 얻을 수 있는 전이 수를 비교하는 기준입니다. DQN의 버퍼에 있는 전이를 다시 꺼내 다섯 차례 업데이트하면 추가 환경 전이는 0입니다. 반면 시간이나 비용을 비교한다면 학습 갱신 수, 사용한 계산 장치와 걸린 시간도 같이 저장할 수 있습니다. 학습에 쓴 상호작용과 별도 평가를 위해 얻은 상호작용은 구분해 보고합니다.

실험 과제에 외부 시간 제한이 있으면 제한을 넘긴 비율과 점수를 어떻게 집계하는지 먼저 정합니다. 유효한 과제 완료와 시간에 따른 중단을 하나의 성공으로 묶으면 돌아오는 정책의 행동을 다르게 읽을 수 있습니다.

시드와 난수의 사용처를 따로 기록한다

시드는 같은 난수열을 재현할 때 쓰는 초기 입력입니다. 어떤 알고리즘은 환경뿐 아니라 정책의 행동 선택, 초기 가중치, 미니배치 선택과 탐험에도 난수를 씁니다. 한 난수 생성기를 학습과 평가에 함께 사용하면 평가 횟수를 바꾸는 것만으로 뒤의 학습 난수도 달라질 수 있습니다. 환경 난수와 정책 난수를 분리하고, 학습과 평가에서도 별도 생성기를 사용합니다. 실제 실험에서는 라이브러리·장치의 버전과 결정성 설정을 기록합니다. 시드 숫자 하나로 다른 플랫폼의 동일 실행까지 보장할 수는 없습니다.

한 시드로 평가 에피소드를 늘리면 그 정책의 평균 점수를 더 잘 추정할 수 있습니다. 그러나 이는 초기 가중치와 학습 경험을 다시 뽑아 처음부터 훈련한 횟수와 다릅니다. 동일 설정에서 독립적으로 학습한 정책 여러 개를 평가해야 학습 자체의 변동을 확인할 수 있습니다.

고정한 정책의 평가만 실행해 비용을 기록한다

예제에서는 평가 실습을 위해 확인대의 규칙을 줄였습니다. 직행은 한 단계 뒤 보상 2로 끝납니다. 확인은 보상 0으로 C에 가고, 이어진 한 단계가 보상 2 또는 6으로 같은 확률로 끝납니다. 할인율은 0.5라서 확인한 경로의 점수는 1 또는 3입니다. 아래 코드는 학습을 수행하지 않고, 확인 확률을 0.75로 얼려 평가합니다.

from random import Random
from statistics import mean

def evaluate(policy_seed, environment_seed, episodes, confirm_probability):
    policy_rng = Random(policy_seed)
    environment_rng = Random(environment_seed)
    returns = []
    transitions = 0
    for _ in range(episodes):
        transitions += 1
        if policy_rng.random() < confirm_probability:
            transitions += 1
            reward = 6 if environment_rng.random() < 0.5 else 2
            returns.append(0.5 * reward)
        else:
            returns.append(2.0)
    return returns, transitions

scores, steps = evaluate(21, 110, 8, 0.75)
print("returns:", [int(score) for score in scores])
print(f"mean={mean(scores):.2f}, episodes={len(scores)}, transitions={steps}")
print("same protocol:", evaluate(21, 110, 8, 0.75) == (scores, steps))
returns: [1, 3, 1, 3, 3, 2, 2, 3]
mean=2.25, episodes=8, transitions=14
same protocol: True

평가 가중치가 고정돼 있고 두 난수의 초기값도 같으므로 같은 설정의 실행을 반복하면 동일 기록을 얻을 수 있습니다. 여기에서 8은 평가 에피소드이고, 14는 평가 환경 전이입니다. 이 실행 한 번은 학습을 독립적으로 여덟 번 수행한 결과와 다릅니다.
