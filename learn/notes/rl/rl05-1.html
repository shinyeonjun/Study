정책 평가와 개선: 행동 규칙을 한 번씩 바꾸기

전이 확률과 보상 규칙을 알고 있다고 가정합니다. 지금 정책에서 상태마다 기대 반환을 계산하고, 그 값을 바탕으로 한 단계 더 나은 선택을 고르는 과정을 반복합니다.

이 장을 읽고 나면

  • 알려진 모형에서 고정 정책의 가치를 반복 갱신한다.
  • 평가와 개선을 교대로 적용해 두 상태의 정책을 바꾼다.
  • 동률에서 행동을 유지하는 이유와 종료 조건을 설명한다.

환경을 다시 실행하지 않고 가능한 결과를 모두 평균한다

앞 단원의 자료 처리 모형과 할인율 γ=1/2를 사용합니다. 확률과 보상을 모두 알고 있으므로 실제로 한 번 움직여 볼 필요 없이 각 분기를 계산에 포함할 수 있습니다. 이처럼 환경의 완전한 모형(MDP)이 주어졌을 때 Bellman 식을 갱신 규칙으로 바꿔 가치와 최적 정책을 계산하는 알고리즘들을 동적 계획법(DP, dynamic programming)이라고 합니다. 한 상태의 값을 다음 상태들의 값으로 나누어 표현하고, 그 작은 값들을 표에 저장해 재사용한다는 점에서 일반 알고리즘의 동적 계획법과 같은 생각입니다. 이어질 몬테카를로 방법은 모형의 분기를 모두 알 수 없을 때 관측한 경험으로 값을 추정합니다.

아무 행동의 가치를 새로 비교하기 전에, 먼저 S에서도 C에서도 확인만 하는 정책을 고정합니다. 정책 평가에서는 지금 정책에 해당하는 확률로만 계산합니다. v0(S)=v0(C)=0에서 시작하면, 다음 번 값은 vₖ₊₁(C)=1+0.25vₖ(C), vₖ₊₁(S)=0.5vₖ(C)입니다. 완료 T의 값은 항상 0입니다. 일반식은 Bellman 기대식의 좌변과 우변에 서로 다른 반복 번호를 붙인 것입니다.

vk+1(s) = Σₐ π(a|s) Σₛ′,ᵣ p(s′,r|s,a)[r + γ vk(s′)] (모든 비종료 상태 s에 대해)

이 장의 정책은 각 상태에서 확인을 확률 1로 고르므로 Σₐ가 항 하나로 줄어 위의 두 식이 됩니다. 예를 들어 C에서는 0.5×(3+0.5×0)+0.5×(−1+0.5vₖ(C)) = 1+0.25vₖ(C)입니다.

한 묶음에서 전 상태를 계산하고 나서 표를 바꾸는 방식을 동시 갱신이라고 합니다. 묶음 안에서 앞 상태의 새 값을 바로 쓰는 방식도 있지만 중간 표는 달라질 수 있습니다. 이 예에서 C의 남은 오차는 매 묶음 1/4로 줄어듭니다. 일반적인 유한 MDP에서는 γ<1이거나, γ=1이라도 그 정책을 따르면 어느 상태에서 출발하든 결국 종료에 이른다는 조건이 있으면 vπ가 하나로 정해지고 반복 평가가 그 값으로 수렴합니다(Sutton·Barto §4.1). γ<1일 때의 이유는 이렇습니다. 두 가치 표 u, w에 같은 갱신을 한 번 적용하면 상태별 차이의 최댓값이 γ배 이하로 줄어듭니다: maxₛ|u′(s)−w′(s)| ≤ γ·maxₛ|u(s)−w(s)|. 이런 성질을 축약(contraction)이라고 하며, w로 참값 vπ를 넣으면 반복값과 참값의 최대 오차가 매번 γ배 이하로 줄어듭니다.

평가한 값으로 지금의 행동을 바꿔 본다

정책이 정해지면 이번 한 행동만 다른 것으로 바꾼 뒤 기존 정책을 따른 경우의 qπ(s,a)를 비교할 수 있습니다. S에서는 직행 2, 확인 2/3이라 직행으로 바꿉니다. C에서는 직행 6, 확인 4/3이라 역시 직행으로 바꿉니다. 이렇게 각 상태에서 qπ가 가장 큰 행동을 고르는 일은 정책 개선입니다.

이 선택을 실행할 때는 이후에도 바뀐 정책을 따르게 됩니다. 한 번 바꿔 비교한 값보다 손해 보지 않는다는 논리는 다음과 같습니다. 새 정책으로 첫 행동을 정하고 다음 상태의 옛 가치를 더한 평균은 옛 가치 이상입니다. 새 정책을 두 단계, 세 단계로 늘려도 같은 비교가 되풀이됩니다. 유한 할인 문제에서 이를 끝까지 이어 가면 새 정책의 가치는 모든 상태에서 옛 가치 이상입니다.

처음 개선한 정책은 S·C 모두 직행이므로 다시 평가하면 (2,6)입니다. 새 C 값 6을 쓰면 S에서 확인할 때 3을 얻을 수 있어, 두 번째 개선에서는 S만 확인으로 바뀝니다. S 확인, C 직행을 평가하면 (3,6)이고 더 개선할 상태가 없습니다. 이렇게 평가와 개선을 반복하는 것이 정책 반복입니다.

동률은 가치와 정책의 변화를 따로 본다

할인율을 1/3으로만 바꾸면 C의 최적 가치는 여전히 6이고 S에서 직행 2와 확인 2가 동률입니다. 이때 두 행동 모두 최적이며, 어느 하나만 정답인 것은 아닙니다. 정책이 안정적인지 확인하려면 현재 행동이 최대 후보에 포함된 경우 그대로 유지할 수 있습니다. 값이 같은 선택지를 매번 임의로 바꾸면 가치는 그대로인데 정책이 계속 바뀐 것처럼 보일 수 있습니다.

아래 프로그램은 동시 갱신을 세 번 출력하고, 정책을 개선할 때에는 작은 모형의 정확한 값을 계산합니다. C 밖으로 도착하면 끝나므로 C의 방정식은 v(C)=평균 보상+γ·P(C로 복귀)·v(C)입니다. C를 풀고 나면 S에서는 C 또는 T로 갈 뿐이라 S 값도 바로 구할 수 있습니다.

from fractions import Fraction as F

transitions = {
    ("S", "직행"): [(F(1), "T", 2)],
    ("S", "확인"): [(F(1), "C", 0)],
    ("C", "직행"): [(F(1), "T", 6)],
    ("C", "확인"): [(F(1, 2), "T", 3), (F(1, 2), "C", -1)],
}
gamma = F(1, 2)
states = ("S", "C")
actions = ("직행", "확인")

def q(state, action, value):
    return sum(p * (r + gamma * value[dest]) for p, dest, r in transitions[(state, action)])

value = {state: F(0) for state in (*states, "T")}
for k in range(1, 4):
    value = {state: q(state, "확인", value) for state in states} | {"T": F(0)}
    print(f"평가 {k}:", value["S"], value["C"])

def evaluate(policy):
    outcomes = transitions[("C", policy["C"])]
    immediate = sum(p * r for p, _, r in outcomes)
    stay = sum(p for p, dest, _ in outcomes if dest == "C")
    value = {"C": immediate / (1 - gamma * stay), "T": F(0)}
    value["S"] = q("S", policy["S"], value)
    return value

policy = {state: "확인" for state in states}
while True:
    value = evaluate(policy)
    print("정책:", *(policy[state] for state in states), "| 가치:", value["S"], value["C"])
    improved = {}
    for state in states:
        scores = {action: q(state, action, value) for action in actions}
        if scores[policy[state]] == max(scores.values()):
            improved[state] = policy[state]
        else:
            improved[state] = max(scores, key=scores.get)
    if improved == policy:
        break
    policy = improved

평가 2: 1/2 5/4
평가 3: 5/8 21/16

정책: 직행 직행 | 가치: 2 6
정책: 확인 직행 | 가치: 3 6

정확한 평가값에서 더 나은 행동이 하나도 없다는 것은 현재 가치가 Bellman 최적식도 만족한다는 뜻입니다. 유한 할인 모형에서 그 식을 만족하는 값은 하나입니다. 동률일 때 현재 행동을 유지하면, 정책이 바뀌는 묶음마다 적어도 한 상태의 값이 엄격히 개선됩니다. 가능한 결정적 정책이 유한하므로 이전 정책으로 돌아갈 수 없고, 결국 개선을 멈춥니다. 다음 장에서는 각 묶음에서 바로 최대값을 써서 가치를 갱신합니다.
