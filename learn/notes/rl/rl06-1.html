RL06·1

몬테카를로 예측: 에피소드의 끝에서 가치 추정하기

환경의 확률표를 모른다고 합시다. 한 에피소드에서 본 보상을 끝까지 모으면, 방문한 상태마다 그 뒤에 실제로 얻은 반환을 계산할 수 있습니다. 첫 방문만 쓸 때와 모든 방문을 쓸 때 평균이 어떻게 달라지는지 비교합니다.

이 장을 읽고 나면

  • 에피소드 끝에서부터 각 상태의 관측 반환을 계산한다.
  • 첫 방문과 모든 방문의 표본 선택을 구별하고 상태별 평균을 구한다.
  • 표본 수, 반환의 분산, 외부 중단의 영향을 설명한다.

분기 확률 없이도 관측한 반환을 계산할 수 있다

앞에서 다룬 자료 처리 환경의 에이전트에게는 전이 확률을 주지 않습니다. 정책은 여전히 S와 C에서 항상 확인하기입니다. 이 정책으로 시작 S에서 완료 T까지 세 번 실행해 아래 기록을 얻었다고 합시다. 각각의 기록은 한 번의 완료된 에피소드입니다. 상태 가치는 그 상태에 도착한 뒤 같은 정책을 따를 때의 반환 기댓값입니다. 완주한 뒤 받은 반환을 여러 번 평균해 기댓값을 추정하는 방식을 몬테카를로 예측이라고 합니다.

실행방문한 상태 순서행동 뒤 받은 보상
AS → C → T0, 3
BS → C → C → T0, −1, 3
CS → C → C → C → T0, −1, −1, 3

할인율은 γ=1/2입니다. 실행 C에서는 완료 T 바로 전의 C가 3점을 얻습니다. 그 앞 C는 −1+(1/2)×3=1/2를 얻습니다. 가장 먼저 방문한 C는 −1+(1/2)×(1/2)=−3/4입니다. 표에서 실행을 가리키는 이름 C와 상태 C는 서로 다른 역할입니다.

처음 왔던 순간만 고르거나 방문을 모두 센다

첫 방문(first-visit) 예측은 상태 하나에 대해 에피소드마다 처음 방문한 시점의 반환만 사용합니다. 실행 A의 첫 C는 3점, B는 1/2, C는 −3/4입니다. 평균은 (3+1/2−3/4)/3=11/12입니다. 처음 방문하는 순간을 찾을 때는 기록을 시작 쪽에서 읽습니다. 반환을 뒤에서 계산했다면 시작 쪽 순서로 다시 정렬해 선택합니다.

모든 방문(every-visit) 예측은 한 에피소드에서 같은 상태에 여러 번 왔을 때 각 시점의 반환을 사용합니다. 위의 첫 방문 세 값과 함께 B와 C에서 생긴 추가 값 3, 1/2, 3을 넣습니다. 분모가 6으로 바뀌고 평균은 (3+1/2+3−3/4+1/2+3)/6=37/24입니다.

모형을 작성한 사람은 앞 단원의 식을 풀어 실제 vπ(C)=4/3을 알고 있습니다. 이 값은 검산용입니다. 몬테카를로 예측은 이 값을 입력받지 않고 상태별 반환의 합과 개수만으로 추정합니다. 같은 정책에서 한 상태를 충분히 여러 번 방문하고 완주 에피소드가 누적되는 표준 조건에서는 두 방식 모두 방문 수가 무한히 늘수록 vπ(s)로 수렴합니다. 첫 방문 방식에서는 에피소드마다 표본이 하나씩 독립으로 나오므로 각 표본이 vπ(s)의 불편추정량이고, 큰수의 법칙이 그대로 적용됩니다.

반환을 모두 저장할 필요는 없습니다. RL02의 증분 평균을 그대로 써서 상태마다 방문 수 N(s)와 추정값 V(s)만 두고, 새 반환 G가 나올 때마다 N(s) ← N(s)+1, V(s) ← V(s) + (G − V(s))/N(s)로 갱신하면 위 평균과 같은 값이 나옵니다. 1/N(s) 대신 상수 α를 쓰면 최근 에피소드를 더 무겁게 보는 상수-α 몬테카를로가 됩니다.

방문 수가 많아져도 서로 독립인 표본 수와 같지 않다

서로 독립으로 시작한 에피소드에서 C에 처음 도착해 얻는 반환은 이 모형에서 각각 독립입니다. 반환의 분산이 σ²이고 첫 방문 표본 n개가 독립이면, 그 표본평균의 분산은 σ²/n입니다. 한 에피소드의 첫 C와 둘째 C는 같은 미래 보상을 일부 공유합니다. 모든 방문 여섯 개를 독립인 에피소드 여섯 개로 계산해 불확실성을 정하면 이 관계를 잃습니다. 기록마다 결과가 달라지므로 이번 표에서 어느 쪽이 정확한 값에 더 가깝다고 항상 그 방식이 우월하다고 할 수 없습니다.

확장 · 이 모형에서 반환의 분산을 직접 읽기

C에서 마지막 성공 전 실패 횟수를 N이라고 하면, 실패마다 −1을 받고 끝에 3을 받아 G=−2+5(1/2)ᴺ입니다. 성공 확률 1/2인 기하 시행이라 N은 0,1,2,… 각각에 (1/2)ⁿ⁺¹의 확률을 줍니다. 등비합으로 E[(1/2)ᴺ]=2/3, E[(1/4)ᴺ]=4/7이므로 Var(G)=25(4/7−4/9)=200/63입니다. 이 값은 첫 방문 표본평균이 한 번의 실행보다 왜 덜 흔들리는지 설명하지만, 데이터만으로 가치를 계산할 때 꼭 알아야 하는 값은 아닙니다.

외부에서 끊긴 기록은 아직 완주 반환이 아니다

과제의 종료 T 뒤에는 보상이 없으므로 반환 계산을 0으로 시작합니다. 외부 제한으로 C에서 잘렸다면 C의 뒤 보상을 알 수 없습니다. 거기서 0으로 계산하면 완주 반환이 아니라 관측한 부분의 반환입니다. 이후 보상을 추정하여 이어 붙이면 부트스트래핑을 섞은 목표값을 사용하는 방법이고, 순수하게 완주 표본만 쓰는 계산과 다릅니다. 무조건 중단 로그를 빼면 오래 걸린 에피소드가 더 자주 제외될 수 있으므로, 자료가 어떤 규칙으로 끊겼는지도 확인합니다.

반환을 뒤에서 계산하고 표본은 앞에서 고른다

from fractions import Fraction as F
from random import Random

episodes = [
    [("S", 0), ("C", 3)],
    [("S", 0), ("C", -1), ("C", 3)],
    [("S", 0), ("C", -1), ("C", -1), ("C", 3)],
]
first = []
every = []

for episode in episodes:
    after = F(0)
    returns = []
    for state, reward in reversed(episode):
        after = reward + F(1, 2) * after
        returns.append((state, after))
    c_returns = [value for state, value in reversed(returns) if state == "C"]
    first.append(c_returns[0])
    every.extend(c_returns)
    print("C 방문:", *c_returns)

print("첫 방문 평균:", sum(first) / len(first))
print("모든 방문 평균:", sum(every) / len(every))

rng = Random(12)
simulated = []
for _ in range(100):
    failures = 0
    while rng.random() >= 0.5:
        failures += 1
    simulated.append(-2 + 5 * (0.5 ** failures))
print(f"100회 모의실험 첫 C 평균: {sum(simulated) / len(simulated):.4f}")
C 방문: 3
C 방문: 1/2 3
C 방문: -3/4 1/2 3
첫 방문 평균: 11/12
모든 방문 평균: 37/24
100회 모의실험 첫 C 평균: 1.5215

위쪽 계산은 주어진 세 에피소드로 반환 표본을 만드는 에이전트의 계산입니다. 아래쪽은 모형 작성자가 성공확률을 알고 되풀이한 실험입니다. 반환식으로 표본을 얻어 첫 방문 평균이 실행에 따라 변한다는 사실을 확인합니다. 같은 시드의 100개는 그 값 하나를 재현하고, 참 기댓값으로의 수렴을 증명하지는 않습니다.
