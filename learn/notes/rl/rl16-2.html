RL16·2

두 단계 기록에서 시점별 가중치와 이중 강건 합을 대조하기

첫 번째 보상을 평가할 때 다음 행동의 비율까지 곱해야 할까요? 시점별로 필요한 곳까지 비율을 곱하고, 연속 상태에서 보상 계산과 가치 보정이 서로 상쇄되는 과정을 유도합니다.

이 장을 읽고 나면

  • 전체 궤적 비율과 보상까지의 접두 비율을 구분한다.
  • 시차 잔차 보정식이 정책의 가치를 돌려주는 이유를 보인다.
  • 독립 에피소드로 오차를 확인하고 지지집합 제한을 설명한다.

보상 이전의 비율만으로도 그 시점의 평균을 바꿀 수 있다

시작 분포와 전이·보상 법칙은 기록 정책 μ와 목표 π에서 같다고 둡니다. 목표 정책이 도달하는 이력의 행동은 기록에서도 가능해야 합니다. ρ₀:ₜ=∏ⱼ₌₀ᵗ π(aⱼ|sⱼ)/μ(aⱼ|sⱼ)로 두면, 시점 t까지 확률을 곱한 분포에서 μ의 행동 선택 확률이 약분됩니다. 따라서 t번째 보상이 π에서 가질 기대값은 Eμ[ρ₀:ₜrₜ]입니다.

길이 H의 전체 궤적 중요도표본은 전체 할인 반환값에 ρ₀:ₕ₋₁을 한꺼번에 곱합니다. 시점별 중요도표본(PDIS)은 각 γᵗrₜ에 그 보상까지의 비율만 곱합니다. 두 방법은 지지와 정확한 확률 가정 아래 무편향입니다. 뒤쪽 비율을 제거한다고 언제나 더 작은 분산이 따라오는 것은 아닙니다. 여러 보상 항을 더할 때 공분산도 달라집니다. 예를 들어 γ=1, 첫 보상은 항상 1이고 첫 비율도 1이라고 합시다. 둘째 행동을 기록에서 (.5,.5), 목표에서 (.25,.75)로 고르고, 그 두 보상이 2와 0이면 둘째 비율은 .5와 1.5입니다. 전체 추정은 어느 경우나 1.5이며 PDIS는 2 또는 1입니다. 평균은 같고 이 경우에는 PDIS의 분산이 1/4로 더 큽니다.

다음 상태 전망을 넣고 현재 전망을 뺀다

시간 t의 가치 모형 Q̂ₜ에서 V̂ₜ(s)=∑ₐπ(a|s)Q̂ₜ(s,a)를 만들고 V̂H=0으로 둡니다. 시점별 이중 강건 보정은 시작 기준 V̂₀(s₀)에 가중한 TD 형태 잔차를 더합니다.

DR = V̂₀(s₀) + ∑ₜ γᵗρ₀:ₜ[rₜ+γV̂ₜ₊₁(sₜ₊₁)−Q̂ₜ(sₜ,aₜ)]

정확한 비율을 사용하면 각 잔차의 가중 기대값이 π에서의 기대값으로 바뀝니다. π에서 E[Q̂ₜ(sₜ,aₜ)|sₜ]=V̂ₜ(sₜ)이므로, 합의 바로 앞 항이 더한 다음 상태의 전망과 뒷 항이 뺀 현재 전망이 서로 지워집니다. 맨 처음 기준값도 t=0 항에서 지워지고 끝 전망은 0이어서 결과는 목표 반환값입니다. 모형이 참 Q라면 잔차는 현재 상태와 행동을 조건으로 평균 0입니다. 환경의 조건부 법칙이 두 정책에서 같고 가치 모형이 참이면, 평가 자료와 별도로 정한 유한한 가중치가 현재 행동까지의 이력에만 의존할 때에도 잔차가 평균 0입니다. 현재 보상과 이후 정보로 가중치를 바꾸면 이 논증을 적용할 수 없습니다.

두 번의 행동을 실제로 전부 열거한다

어느 행동이든 첫 상태에서 둘째 상태로 가고, 두 번째 행동 뒤 끝납니다. 각 단계에서 μ(L,R)=(3/4,1/4), π(L,R)=(1/2,1/2), γ=1/2입니다. 첫 보상은 (1,3), 둘째는 (2,6)이므로 참 값은 2+(1/2)·4=4입니다. 보상 모형이 (1,2)와 (1,4)라고 가정하면 둘째 V̂=5/2, 첫 Q̂=(9/4,13/4), 첫 V̂=11/4입니다.

세 추정량의 평균은 모두 4입니다. 분산은 280/9, 172/9, 343/144입니다. 개별 기록을 비교하면 같은 실제 보상에서도 비율이 뒤쪽까지 커지며 흔들림이 커질 수 있다는 점을 볼 수 있습니다. 이 예처럼 값이 많이 다른 가지가 드물면 그 가지의 기록 비중과 비율을 특히 확인합니다.

from fractions import Fraction as F
from itertools import product

mu = (F(3,4),F(1,4))
rho = (F(2,3),F(2))
reward0,reward1 = (1,3),(2,6)
gamma = F(1,2)
v0,v1 = F(11,4),F(5,2)
q0,q1 = (F(9,4),F(13,4)),(1,4)
data = []
for a,b in product(range(2),repeat=2):
    w0,w1 = rho[a],rho[a]*rho[b]
    first,second = reward0[a],reward1[b]
    ordinary = w1*(first+gamma*second)
    pdis = w0*first+gamma*w1*second
    dr = v0+w0*(first+gamma*v1-q0[a])+gamma*w1*(second-q1[b])
    data.append((mu[a]*mu[b],ordinary,pdis,dr))
    print(*data[-1])

for column in (1,2,3):
    mean = sum(row[0]*row[column] for row in data)
    var = sum(row[0]*(row[column]-mean)**2 for row in data)
    print(mean,var)
    assert mean == 4
