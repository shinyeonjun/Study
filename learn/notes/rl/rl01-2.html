RL01·2

정책을 따라 경험 한 줄씩 기록하기

같은 정책을 실제로 따라가 보며 로봇의 한 번의 운행을 재현합니다. 보상을 어느 행동에 붙여야 하는지와, 결정 규칙을 실행하는 것과 학습하는 것의 차이를 확인합니다.

이 장을 읽고 나면

  • 현재 관측, 행동, 다음 보상·관측을 시간순으로 기록한다.
  • 관측을 보고 고르는 고정 정책으로 작은 환경의 롤아웃을 만든다.
  • 한 번의 실행 성과와 정책의 학습을 구별한다.

경험의 첫 줄에는 무엇이 있어야 하나

시작 시각을 t=0으로 놓습니다. 에이전트는 먼저 초기 관측 O₀를 받고, 그것을 사용해 행동 A₀를 고릅니다. 환경은 행동을 실행해 보상 R₁과 새 관측 O₁을 돌려줍니다. 이 교재에서는 보상이 도착한 시각을 보상의 번호로 씁니다. 문헌에 따라 같은 보상을 r₀로 적기도 하므로 숫자부터 비교하기보다 어느 행동 뒤에 받았는지 확인합니다.

관측 O₁을 받은 다음에야 A₁을 고를 수 있습니다. A₁ 뒤의 보상은 R₂입니다. 이렇게 한 번의 행동과 그 효과를 순서대로 묶는 기록을 전이 기록이라고 부릅니다. 상태 전체가 노출된 완전관측 예에서는 O 대신 S를 적어 (Sₜ, Aₜ, Rₜ₊₁, Sₜ₊₁) 형태로 기록할 수도 있습니다.

정해 둔 규칙을 세 번 적용한다

앞 장과 같은 보관소와 선반을 씁니다. 이번에는 에이전트에게 위치와 짐 여부가 모두 주어집니다. ‘짐을 집기’는 보관소에 빈손일 때, ‘오른쪽으로 이동’은 짐을 든 채 보관소에 있을 때, ‘놓기’는 선반에 짐을 들고 도착했을 때 허용합니다. 보상을 각각 0, −1, +5점으로 정하고, 짐을 성공적으로 놓는 순간 이 과제는 끝납니다.

시각 t행동 앞 관측 Oₜ행동 Aₜ결과 Rₜ₊₁, Oₜ₊₁
0(보관소, 빈손)집기0, (보관소, 짐 있음)
1(보관소, 짐 있음)오른쪽−1, (선반, 짐 있음)
2(선반, 짐 있음)놓기+5, (완료, 빈손)

‘완료’는 새 물리적 위치가 아니라 이 작은 프로그램에서 끝을 나타내는 표식입니다. 위 표의 관측은 네 개지만 행동과 보상은 각각 세 개입니다. 이 정책으로 초기 상태에서 끝까지 실행하여 모은 경험의 열을 롤아웃이라고 부릅니다. 정해진 길이만큼 실행한 일부분도 롤아웃이라고 부를 수 있습니다.

실행과 학습을 역할별로 나눈다

아래 프로그램은 정책을 사전으로 적습니다. 관측 ("보관소", False)를 넣으면 "집기"가 나옵니다. 환경 함수 step은 선택한 행동과 현재 상태를 받아 다음 상태·보상·종료 신호를 돌려줍니다. 이 장의 함수는 표준 라이브러리만 쓰는 간단한 모형입니다. Gymnasium의 실제 API는 이후 장에서 별도로 읽습니다.

policy = {
    ("보관소", False): "집기",
    ("보관소", True): "오른쪽",
    ("선반", True): "놓기",
}

def step(state, action):
    if state == ("보관소", False) and action == "집기":
        return ("보관소", True), 0, False
    if state == ("보관소", True) and action == "오른쪽":
        return ("선반", True), -1, False
    if state == ("선반", True) and action == "놓기":
        return ("완료", False), 5, True
    raise ValueError("이 장에서 정의하지 않은 상태와 행동 조합")

state = ("보관소", False)
total = 0
t = 0
while True:
    observation = state
    action = policy[observation]
    next_state, reward, terminated = step(state, action)
    print(f"{t}: {action} → 보상 {reward:+d}, 관측 {next_state}")
    total += reward
    state = next_state
    t += 1
    if terminated:
        break

assert t == 3 and total == 4
print("행동 수와 보상 합:", t, total)
0: 집기 → 보상 +0, 관측 ('보관소', True)
1: 오른쪽 → 보상 -1, 관측 ('선반', True)
2: 놓기 → 보상 +5, 관측 ('완료', False)
행동 수와 보상 합: 3 4

정책은 이미 정해져 있고 실행 뒤에도 같은 사전을 사용하므로, 이 코드는 정책에 따라 경험을 모으기만 합니다. 강화학습에서는 이러한 경험을 사용해 어떤 행동을 다음에 더 자주 할지, 어떤 상태의 결과를 더 높게 볼지를 바꿀 수 있습니다. 처음부터 완전한 정책을 주는 일과 학습할 정보를 주는 일은 구분합니다.

한 경로의 점수에서 어떤 결론을 얻을 수 있나

이 고정 모형은 규칙이 결정적이라 같은 시작점과 정책을 쓰면 같은 경로가 나옵니다. 예를 들어 자료를 놓는 동작이 확률적으로 실패하는 환경이라면 한 번 받은 4점으로 정책의 평균 성과를 정할 수 없습니다. 시작점과 정책, 환경의 무작위성에 관한 조건을 기록하고, 서로 다른 결과도 여러 번 수집해서 비교합니다. 행동으로 결과를 바꾸더라도, 같은 상태에서 하지 않은 행동의 보상까지 동시에 관측하는 것은 아닙니다.
