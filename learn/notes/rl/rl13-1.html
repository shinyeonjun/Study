RL13·1

벨만 연산의 수축으로 가치반복의 오차를 증명하기

두 초기 가치표가 달라도 정확한 벨만 갱신은 두 표의 차이를 줄입니다. 할인율이 어떤 항에 들어가는지 증명하고, 계산을 멈추기 전에 남은 오차를 추정합니다.

이 장을 읽고 나면

  • 최대노름을 사용해 벨만 최적 연산의 수축을 증명한다.
  • 고정점의 존재와 유일성이 어디서 오는지 설명한다.
  • 반복 차이로 최적 가치와의 거리를 제한한다.

가치표의 가장 큰 칸 차이를 잰다

상태와 각 상태의 행동이 유한하고, 모든 상태에서 고를 행동이 적어도 하나 있으며, 기대 즉시 보상 r(s,a)가 유한하다고 둡니다. 할인율은 0≤γ<1입니다. 최대노름 ‖v‖∞는 가치표의 절댓값 중 최댓값입니다. 두 표 사이 거리 ‖u−v‖∞는 모든 칸 중 가장 큰 오차를 비교합니다.

(Tv)(s) = maxₐ [ r(s,a) + γ∑ₛ′ P(s′|s,a) v(s′) ]

어떤 행동 a를 고정하면 보상항은 두 표의 차이에서 사라집니다. 전이 확률이 음이 아니고 합이 1이므로, 뒤 상태의 가중합 차이는 최대노름 이하입니다. 여기에 γ가 곱해집니다. 정책을 정해 행동을 평균하는 평가 연산에도 같은 계산이 적용됩니다.

두 최댓값을 만드는 행동이 달라도 된다

두 수 목록 Aₐ, Bₐ에서 M=maxₐ|Aₐ−Bₐ|라고 둡니다. 모든 a에서 Aₐ≤Bₐ+M이라 max A≤max B+M입니다. 두 목록을 바꾸어도 같으므로 |max A−max B|≤M입니다. 이렇게 하면 두 표에서 같은 행동이 최적일 거라고 가정할 필요가 없습니다. 상태마다 이 부등식을 적용하고 다시 최대를 취합니다.

‖Tu−Tv‖∞ ≤ γ‖u−v‖∞

차이가 기하급수로 줄면 어디로 가는가

vₖ₊₁=Tvₖ라고 둡니다. 이웃한 두 가치표의 차이는 ‖vₖ₊₁−vₖ‖∞≤γᵏ‖v₁−v₀‖∞입니다. 두 반복 번호 사이의 거리는 그 사이 이웃 차이들의 합 이하이고, 기하급수 꼬리는 0으로 접근합니다. 그래서 각 좌표는 코시 수열입니다. 유한한 개수의 실수 좌표에서 극한 v*를 얻고, T는 수축 부등식 때문에 연속이라 Tv*=v*입니다. 두 고정점이 있다면 그 거리가 자기 자신의 γ배 이하이므로 거리는 0입니다.

v*에서 최댓값을 만드는 행동으로 정책 π를 정하면 정책 평가 연산 Tπ에서도 Tπv*=v*이므로 그 정책의 가치가 v*입니다. 다른 고정 정책 μ의 평가 연산은 Tμv*≤v*이고, 확률이 음이 아니므로 가치표의 성분별 순서를 유지합니다. Tμ를 반복하면 자신의 고정점인 Vμ에 수렴하고 Vμ≤v*입니다. 따라서 v*는 이런 정책들 중 달성할 수 있는 최적 가치입니다. 벨만 방정식에서 보상 할인합으로 가치를 정의한 부분과 이어집니다.

고정점과 직접 비교하면 ‖vₖ−v*‖∞≤γᵏ‖v₀−v*‖∞입니다. v*를 모를 때는 현재 표 v에서 ε=‖Tv−v‖∞를 계산합니다. 삼각부등식과 수축으로 ‖v−v*‖∞≤ε+γ‖v−v*‖∞이므로 아래처럼 제한할 수 있습니다.

‖v−v*‖∞ ≤ ε/(1−γ)

두 상태를 번갈아 방문하는 가치표

상태 A에서 보상 1을 받고 B로, B에서 보상 0을 받고 A로 갑니다. 행동은 하나씩이고 γ=1/2입니다. v*(A)=1+(1/2)v*(B), v*(B)=(1/2)v*(A)라서 해는 (4/3,2/3)입니다. 0으로 시작해 네 번 갱신한 값은 (5/4,5/8)입니다. 실제 최대오차는 1/12이고, 한 번 더 갱신한 차이를 사용한 잔차 상계는 1/8입니다.

from fractions import Fraction as F

def T(v):
    return 1 + v[1]/2, v[0]/2

def distance(a, b):
    return max(abs(x-y) for x,y in zip(a,b))

v = (F(0),F(0))
star = (F(4,3),F(2,3))
for k in range(1,5):
    v = T(v)
    print(k, *v)
true_error = distance(v,star)
residual_bound = 2*distance(T(v),v)
print(true_error, residual_bound)
assert T(star)==star and true_error <= residual_bound

실행 결과

1 1 0
2 1 1/2
3 5/4 1/2
4 5/4 5/8
1/12 1/8
