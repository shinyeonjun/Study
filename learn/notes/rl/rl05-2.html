가치반복: 최대 행동값을 바로 다음 표에 넣기

현재 가치표에서 가장 유리한 행동을 골라 값을 다시 채웁니다. 정책을 따로 저장하지 않아도 이 반복이 언제 믿을 만한지, 중간 표가 얼마나 좋은지는 수치로 점검할 수 있습니다.

이 장을 읽고 나면

  • 가치반복과 고정 정책 평가의 갱신을 구분한다.
  • 할인율이 오차를 줄이는 이유와 멈춤 허용 오차를 이해한다.
  • 전이 수로 한 묶음의 계산량을 세고 최종 가치에서 정책을 고른다.

각 상태의 다음 숫자에 최대 행동값을 넣는다

S에서 직행하면 보상 2로 끝납니다. 확인하면 보상 0으로 C에 갑니다. C에서 직행은 보상 6, 확인은 확률 1/2로 보상 3과 종료, 확률 1/2로 보상 −1과 C 복귀입니다. 할인율 γ=1/2이고 완료 T의 값은 0입니다.

어떤 임시 가치표 V를 두고, 각 행동의 가능한 결과 r+γV(s′)를 확률평균한 다음 그중 가장 큰 행동값을 새 V로 넣습니다. 이렇게 가치를 갱신하는 일을 가치반복이라고 합니다. 한 묶음의 갱신 결과를 𝒯V라고 쓰겠습니다(완료 상태 T와 구별하려고 글꼴을 달리했습니다). 고정 정책 평가가 π의 행동 비율로 평균했던 자리에, 어느 행동이든 고를 수 있을 때의 최대가 들어갑니다. 즉 Bellman 최적식을 갱신 규칙으로 바꾼 것입니다.

vk+1(s) = maxₐ Σₛ′,ᵣ p(s′,r|s,a)[r + γ vk(s′)]

정책 반복이 평가를 수렴할 때까지 돌린 뒤 개선했다면, 가치반복은 평가를 한 번만 하고 곧바로 최대(개선)를 취하는 셈입니다. Sutton·Barto의 의사코드는 새 값을 같은 표에 바로 덮어쓰는(in-place) 방식이고, 변화량의 최댓값 Δ가 작은 문턱값 θ보다 작아지면 멈춥니다. 이 장은 계산을 따라가기 쉽게 이전 표로 모두 계산하는 동시 갱신을 씁니다. 두 방식 모두 같은 최적 가치로 수렴합니다.

이전 표 (V(S),V(C))S의 새 값C의 새 값
(0,0)max(2, 0) = 2max(6, 1) = 6
(2,6)max(2, 3) = 3max(6, 2.5) = 6
(3,6)max(2, 3) = 3max(6, 2.5) = 6

전 상태를 이전 표로 계산하므로 첫 묶음에서 새로 얻은 C의 값 6을 같은 묶음의 S에 바로 쓰지는 않습니다. 마지막 표를 사용해 최대 행동을 다시 읽으면 S에서는 확인, C에서는 직행입니다. 실수 계산이거나 아직 갱신이 덜 된 표에서 두 행동 값이 아주 가까우면, 근삿값으로 동률인지 우열이 있는지 단정하기 어렵습니다.

할인이 줄이는 것은 표 사이의 최대 차이다

두 가치표 V와 W에서 모든 상태의 차이가 d 이하라고 합시다. 같은 행동과 결과를 비교하면 보상 r이 같아서 사라지고, 다음 상태값 차이에 γ만 곱해집니다. 결과를 확률로 평균해도 차이는 γd 이하입니다. 각 행동의 후보값 차이가 모두 γd 이하면 그 후보들의 최대값 차이도 γd 이하입니다. 최대가 되는 행동이 달라져도 이 상한은 유지됩니다.

이 성질은 수축이라고 합니다. 유한 상태·행동, 유한한 보상, 0≤γ<1에서는 어떤 유한한 값에서 시작해도 같은 최적 가치표로 수렴합니다. γ가 1에 가까우면 한 번의 갱신으로 차이를 줄이는 보장이 약해집니다. γ=1에는 이 증명을 그대로 쓸 수 없습니다. 정해진 유한 지평에서는 남은 시간의 끝부터 역순으로 풀 수 있고, 다른 종료 조건의 문제에는 별도의 가정과 분석이 필요합니다.

멈추는 허용 오차를 정한다

연속된 두 표 V와 𝒯V의 최대 차이를 δ라고 합시다. 앞으로 더 바뀔 차이는 묶음마다 할인율만큼 줄어들므로, 지금 표 V에서 최종값까지의 최대 오차는 δ + γδ + γ²δ + … = δ/(1−γ) 이하입니다. 값 자체의 최대 오차를 ε 이하로 제한하려면 δ≤(1−γ)ε를 멈춤 기준으로 쓸 수 있습니다. 아래 코드는 계산 후 새 표를 보관합니다. 이 기준은 갱신 전 표에 대한 상한이므로 새 표에도 보수적으로 적용됩니다.

동률 처리나 근삿값으로 얻은 정책의 품질 판단은 가치표의 오차 자체와 구분합니다. 특히 두 행동값의 차이가 작은 상태는 허용 오차를 낮춰 다시 보거나 허용한 정책 오차를 별도로 확인해야 합니다. 실수 연산에서는 정확히 같은 숫자가 나올 때까지 기다리는 대신 먼저 오차를 정합니다.

한 묶음의 작업량은 읽어야 할 결과의 수에 달려 있다

이 모형은 S의 두 행동에서 각각 한 결과, C의 두 행동에서 한 결과와 두 결과가 있습니다. 한 묶음에서 총 다섯 결과에 대한 p×(r+γV)를 계산합니다. 상태 수가 N개, 각 상태의 행동 후보가 최대 A개, 상태·행동마다 표에 저장한 결과가 최대 L개라면 한 묶음의 작업량은 대략 O(N·A·L)입니다. O는 입력 크기에 따라 얼마나 빠르게 늘어나는지 나타냅니다. 모든 다음 상태가 가능한 조밀한 표에서 같은 다음 상태의 여러 보상을 기대값으로 미리 묶으면 L은 최대 N이 되어 O(N²A)입니다. 가능한 결과가 적으면 0인 분기를 굳이 저장하거나 읽지 않습니다.

from fractions import Fraction as F

transitions = {
    ("S", "직행"): [(F(1), "T", 2)],
    ("S", "확인"): [(F(1), "C", 0)],
    ("C", "직행"): [(F(1), "T", 6)],
    ("C", "확인"): [(F(1, 2), "T", 3), (F(1, 2), "C", -1)],
}
states = ("S", "C")
actions = ("직행", "확인")
gamma = F(1, 2)
tolerance = F(1, 100)

def scores(state, values):
    return {
        action: sum(p * (r + gamma * values[dest])
                    for p, dest, r in transitions[(state, action)])
        for action in actions
    }

values = {state: F(0) for state in (*states, "T")}
for sweep in range(1, 101):
    updated = {state: max(scores(state, values).values()) for state in states}
    updated["T"] = F(0)
    delta = max(abs(updated[state] - values[state]) for state in states)
    values = updated
    print(f"묶음 {sweep}:", values["S"], values["C"], "| 변화", delta)
    if delta <= (1 - gamma) * tolerance:
        break
else:
    raise RuntimeError("정한 반복 횟수 안에 허용 오차 미도달")

for state in states:
    current = scores(state, values)
    best = [a for a in actions if current[a] == max(current.values())]
    print(state, "최대 후보:", ", ".join(best))
묶음 1: 2 6 | 변화 6
묶음 2: 3 6 | 변화 1
묶음 3: 3 6 | 변화 0
S 최대 후보: 확인
C 최대 후보: 직행

처음부터 모든 전이 확률을 아는 계산입니다. 다음 장에서는 그 확률을 모르고 실제로 겪은 보상열만 관찰할 때 같은 가치를 어떻게 추정하는지 봅니다.
