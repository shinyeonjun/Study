RL10·1

확률 정책의 손잡이를 미분한다

확인 버튼을 얼마만큼 자주 눌러야 점수가 높아질까요? 정책에 값을 하나 붙여, 그 값을 조금 움직이면 행동 확률과 기대 반환이 얼마나 달라지는지 계산합니다.

이 장을 읽고 나면

  • 정책의 로짓, 행동 확률, 환경의 전이 확률을 구분한다.
  • 두 행동의 로그확률 기울기를 계산한다.
  • 기대 반환의 미분과 표본 정책경사의 관계를 설명한다.

확률은 정책에서 나오고 결과는 환경에서 나온다

기존 확인대에서 시작 S의 직행은 보상 2로 끝납니다. 확인은 보상 0으로 C에 갑니다. 계산할 동안 C에서는 항상 직행해 6을 받고 끝난다고 고정합니다. 할인율이 0.5라면 S에서 확인을 골랐을 때 반환은 0+0.5×6=3입니다. S의 행에서만 확인 확률 p를 바꾸면 시작 기대 반환은 J=3p+2(1−p)=2+p입니다. C의 규칙이나 보상을 바꾸지 않아도 어떤 반환을 얼마나 자주 얻는지 바뀝니다.

확률 정책은 상태에서 행동별 확률을 내놓습니다. S에서 확인의 확률이 3/4면 직행은 1/4입니다. 이 숫자는 확인을 골랐을 때 환경이 C에 도착하게 할 확률과 다른 것입니다. 여기에서는 확인 다음에 C로 갈 확률을 1로 두었습니다.

매개변수를 바꿔도 확률의 범위를 지킨다

확률 p를 직접 더하거나 빼면 범위를 벗어날 수 있습니다. 로짓 θ는 실수 전체를 움직일 수 있는 값입니다. 두 행동 중 하나를 기준 점수 0으로 놓으면 확인 확률을 p=exp(θ)/(1+exp(θ))로 만들 수 있습니다. 이것은 시그모이드입니다. θ=0이면 두 확률이 1/2이고 θ=ln 3이면 exp(θ)=3이어서 확인 확률이 3/4입니다. 세 행동 이상에서는 각 행동 점수의 exp를 더해 그 합으로 나누는 소프트맥스를 쓸 수 있습니다.

미분으로 θ를 아주 조금 바꿀 때 확률의 반응을 구할 수 있습니다. 몫을 미분하면 dp/dθ = exp(θ)/(1+exp(θ))² = p(1−p)입니다. 확인의 로그확률 ln p를 미분하면 (1/p)·dp/dθ=1−p가 됩니다. 직행의 로그확률 ln(1−p)는 같은 방식으로 −p가 됩니다. 해당 행동을 고른 다음에는 그 행동의 로그확률 기울기를 사용합니다.

한 번 선택한 행동의 계산을 반복하면 기대 기울기가 된다

이 예에서 dJ/dθ=dp/dθ=3/16입니다. 환경의 반환 3과 2를 이미 알기에 계산할 수 있었습니다. 실제로는 한 행동을 골라 그 반환만 받습니다. 이 경우에도 dπ/dθ = π·d ln π/dθ를 이용할 수 있습니다. 각 행동 반환에 그 행동 로그확률의 기울기를 곱하고 정책 확률로 평균하면 기대 반환의 미분과 같습니다.

확인을 골랐다면 표본 방향은 3×(1/4)=3/4입니다. 직행을 골랐다면 2×(−3/4)=−3/2입니다. 두 가지를 확률로 평균하면 (3/4)(3/4)+(1/4)(−3/2)=3/16입니다. 표본 하나는 참 기울기와 크기가 다르며 부호가 반대일 수도 있습니다. 반복 표본을 모을 때 어떤 정책으로 뽑았는지가 이 식의 조건입니다.

직접 미분과 중앙 차분을 비교한다

from math import exp, log

def probability(theta):
    return 1 / (1 + exp(-theta))

def objective(theta):
    return 2 + probability(theta)

theta = log(3)
p = probability(theta)
scale = 1e-5
finite_difference = (objective(theta + scale) - objective(theta - scale)) / (2 * scale)
picked_then_weighted = p * 3 * (1 - p) + (1 - p) * 2 * (-p)
print(f"p={p:.4f}, J={objective(theta):.4f}")
print(f"direct={p * (1 - p):.4f}, score={picked_then_weighted:.4f}")
print(f"finite difference={finite_difference:.4f}")
p=0.7500, J=2.7500
direct=0.1875, score=0.1875
finite difference=0.1875

코드는 현재 정책에서 두 행동값을 모두 아는 작은 예를 검산합니다. 실제로 반환을 표본으로 얻는 정책경사에서는 기댓값을 그대로 출력하는 대신 그때 얻은 선택과 점수를 사용합니다.

한 줄 정리

정책의 확률을 조금 바꾸는 방법은 모델이 맡고, 그 방향이 얼마나 나을지는 관측한 반환으로 추정한다.
