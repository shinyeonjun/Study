RL15·1

세 상태 Actor–Critic을 학습하고 기준 정책과 재현하기

오른쪽으로 두 번 가면 목적지에 닿는 환경에서 정책과 가치 함수를 함께 학습합니다. 손으로 푼 기준값과 비교하고, 실행 예산과 시드, 중간에 잘린 기록도 보고합니다.

이 장을 읽고 나면

  • 작은 환경에서 정책, 가치, 보상의 연결을 구현한다.
  • 실제 종료와 시간제한에서 TD 목표를 각각 확인한다.
  • 훈련 시드별 결과와 기준 정책의 표본 변동을 보고한다.

환경과 평가 조건을 학습 전에 고정한다

상태는 0,1,2이고 모든 에피소드는 0에서 시작합니다. 행동 R=1은 오른쪽으로 한 칸, L=0은 왼쪽으로 한 칸 옮깁니다. 0에서 왼쪽을 고르면 그대로입니다. 2에 들어갈 때 보상 1을 받고 실제 종료하며 다른 보상은 0입니다. 기본 작업은 제한 없이 이어지지만 실행 기록은 행동 여섯 개를 넘기지 않아, 아직 2에 도달하지 못했으면 시간제한에 잘렸다고 표시합니다. 평가의 반환값은 기록된 보상에 0.9를 시점별로 할인해 더합니다.

정책당 평가 예산은 시드마다 에피소드 200개, 같은 시간제한 6입니다. 기준은 매번 공평하게 L/R을 고르는 정책입니다. 새 정책은 각 상태의 logit으로 R의 확률을 계산해 훈련하며, 학습을 끝낸 뒤에는 확률이 높은 행동을 고르는 정책으로 고정합니다. 비교 대상은 이 고정 정책입니다.

정책과 가치를 한 전이마다 갱신한다

상태 0과 1마다 정책 logit 하나와 가치 V 하나를 둡니다. 현재 정책으로 행동을 뽑은 뒤 critic은 한 단계 예측의 TD 오차 δ를 계산합니다. actor는 정책 경사의 점수 함수 a−p에 그 δ를 곱하고 출발 할인인 γᵗ를 반영합니다. 이 δ는 학습 도중 가치가 정확할 때 정책 이점의 조건부 평균을 주며, 근사 가치와 고정 학습률을 쓰는 이 구현은 수렴 보장을 따로 증명해야 합니다.

진짜 종료는 목표가 보상 1 자체입니다. 시간제한에서 작업이 이어질 수 있는 상태에는 마지막 후속 상태의 가치로 부트스트랩한 다음 다음 기록을 새로 시작합니다. 예를 들어 잘린 행의 보상이 0이고 다음 가치가 0.9라고 하면 목표는 0.9·0.9=0.81입니다. 기준 정책의 평가 반환값은 시간제한 안에서 실제 받은 보상만 셉니다. 학습의 이어지는 가치 목표를 평가 때 더해 주지 않습니다.

비교가 재실행되도록 시드와 실패를 남긴다

훈련 시드 11,23,37,41,59에서 각각 160개 에피소드를 사용합니다. 평가 난수는 별도 생성기를 초기화합니다. 이 설정에서 학습된 다섯 greedy 정책은 모두 (R,R)이라 여섯 번이 되기 전에 모든 평가 에피소드에서 성공했습니다. 각 기준 정책은 성공과 잘림을 별도로 보고합니다. 실패가 0인 학습 시드들을 셌다고 해서 같은 방법이 더 큰 환경이나 다른 학습 예산에서도 같다는 뜻은 아닙니다.

작은 환경을 실제로 실행한다

각 줄은 훈련 시드, 고정 행동쌍, 성공 수·잘린 수·평균 반환값, 무작위 기준의 성공 수·잘린 수·평균 반환값입니다. 마지막 두 줄은 기준 평균과 구간, 종료·잘림 목표값 예입니다.

from math import exp
from random import Random
from statistics import mean, stdev

GAMMA = .9
LIMIT = 6
TRAIN_EPISODES = 160
EVAL_EPISODES = 200
SEEDS = (11, 23, 37, 41, 59)

def step(state, action):
    new = min(2, state+1) if action else max(0, state-1)
    return new, int(new==2), new==2

def train(seed):
    rng = Random(seed)
    logit = [0.,0.]
    value = [0.,0.]
    for _ in range(TRAIN_EPISODES):
        state = 0
        for t in range(LIMIT):
            p = 1/(1+exp(-logit[state]))
            action = int(rng.random() < p)
            new, reward, done = step(state,action)
            target = reward if done else reward + GAMMA*value[new]
            delta = target-value[state]
            value[state] += .16*delta
            logit[state] += .14*(GAMMA**t)*(action-p)*delta
            state = new
            if done:
                break
    return tuple(int(x>=0) for x in logit)

def evaluate(policy, seed):
    rng = Random(seed+1000)
    successes = 0
    returns = []
    for _ in range(EVAL_EPISODES):
        state = 0
        total = 0.
        for t in range(LIMIT):
            action = int(rng.random()<.5) if policy is None else policy[state]
            state, reward, done = step(state,action)
            total += (GAMMA**t)*reward
            successes += int(done)
            if done:
                break
        returns.append(total)
    return successes, EVAL_EPISODES-successes, returns

baseline_returns = []
for seed in SEEDS:
    policy = train(seed)
    s,t,r = evaluate(policy,seed)
    b,c,d = evaluate(None,seed)
    print(f"{seed} {policy} {s} {t} {mean(r):.4f} {b} {c} {mean(d):.4f}")
    baseline_returns.extend(d)
baseline_mean = mean(baseline_returns)
margin = 1.96*stdev(baseline_returns)/len(baseline_returns)**.5
print(f"{baseline_mean:.4f} {baseline_mean-margin:.4f} {baseline_mean+margin:.4f}")
print(f"{1.0:.2f} {GAMMA*.9:.2f}")
assert step(0,1)==(1,0,False) and step(1,1)==(2,1,True)
