궤적 확률을 미분해 정책 경사와 기준값을 얻기

어떤 행동이 높은 보상을 냈다고 해서, 그 행동의 확률을 보상만큼 모두 올리는 것은 아닙니다. 행동 확률이 매개변수에 얼마나 민감한지 곱합니다. 같은 평균을 유지하면서 경사 추정의 흔들림을 바꾸는 방법도 계산합니다.

이 장을 읽고 나면

  • 정책 경사의 로그 미분을 궤적 확률에서 유도한다.
  • 시점별 반환값과 시작 시점 할인율을 구별한다.
  • 행동에 의존하지 않는 기준값의 무편향성을 보인다.

궤적을 뽑는 확률 안에서 정책만 미분한다

시점이 0부터 H−1까지인 유한 문제를 둡니다. 시작 분포와 환경의 전이·보상 법칙은 정책의 매개변수 θ와 별도로 정해져 있습니다. 정책 πθ(a|s)는 매끄럽고 가능한 행동에서는 양수라 합과 미분을 바꿀 수 있는 유한 경우를 다룹니다. 궤적 τ의 확률은 시작 분포와 매 시점의 정책 확률 및 환경 확률을 곱한 것입니다.

목적은 J(θ)=E[∑ₖγᵏrₖ]입니다. 긍정적 확률을 갖는 궤적에서 ∇pθ(τ)=pθ(τ)∇log pθ(τ)이므로, 궤적의 확률을 미분하는 일이 로그 확률의 변화율을 곱하는 기댓값으로 바뀝니다. 환경 법칙은 θ의 함수가 아니므로 로그 궤적 확률의 경사는 각 행동의 점수 함수 ∇log πθ(aₜ|sₜ)의 합입니다.

현재 행동의 신호에서 이미 받은 보상을 지운다

시점 t 직전까지 받은 보상은 지금 행동을 뽑기 전에 정해져 있습니다. 그때까지의 이력을 고정하면 ∑ₐπθ(a|sₜ)∇log πθ(a|sₜ)=∇∑ₐπθ(a|sₜ)=0입니다. 따라서 이전 보상과 현재 점수 함수의 곱은 기댓값 0이라 경사 신호에서 뺄 수 있습니다.

시점 t 기준 상대 할인 반환값을 Gₜ=∑ₖ≥ₜ γᵏ⁻ᵗrₖ라고 두면, 출발 시점 0의 목적에서 그 전체를 γᵗ만큼 할인합니다.

∇J=E[∑ₜ γᵗ ∇log πθ(aₜ|sₜ) Gₜ]

같은 정규화에서 시점과 상태에만 의존하는 기준값 bₜ(sₜ)도 뺄 수 있습니다. 이 값은 그때 행동을 뽑기 전 조건에서 상수이며, 위의 정책 점수 합이 0인 계산을 그대로 적용합니다. 기준값을 현재 행동마다 다르게 만들면 같은 논증이 성립하지 않습니다. 예를 들어 한 단계에서 실제 보상을 그대로 기준값에 주면 경사 표본이 전부 0이 됩니다.

한 단계 정책에서 분산을 직접 비교한다

행동 a∈{0,1}에 대해 a=1 확률을 p=1/(1+e−θ)라 둡니다. 로그 확률을 미분하면 점수는 a−p입니다. p=1/4이고 두 보상이 r₀=1, r₁=4라면 J=1+3p이고 ∂J/∂θ=3p(1−p)=9/16입니다.

위 두 열은 평균이 9/16으로 같습니다. 분산은 각각 507/256과 27/64입니다. 이번 기준값은 값 함수 E[r]인 7/4로 잡았습니다. 이 기준값이 언제나 분산을 가장 작게 만드는 것은 아닙니다. 분산에는 경사 크기의 제곱도 들어가므로 정책과 데이터에 따라 줄거나 늘 수 있습니다.

행동 두 개를 열거해 확인한다

from fractions import Fraction as F

p = F(1,4)
prob = [1-p,p]
reward = [1,4]
baseline = sum(q*r for q,r in zip(prob,reward))
def moments(b):
    values = [(a-p)*(reward[a]-b) for a in (0,1)]
    mean = sum(q*v for q,v in zip(prob,values))
    variance = sum(q*(v-mean)**2 for q,v in zip(prob,values))
    return mean,variance

print(baseline, *moments(0))
print(*moments(baseline))
assert moments(0)[0] == 3*p*(1-p) == moments(baseline)[0]
