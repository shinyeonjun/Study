RL02·1

밴딧의 행동 가치를 보상 평균으로 추정하기

두 선택지 가운데 하나를 누르면 그 선택지의 보상 하나만 받습니다. 행동마다 보상을 따로 모으고, 새 보상 하나가 들어올 때 이전 평균에서 얼마나 움직여야 할지 계산합니다.

이 장을 읽고 나면

  • 밴딧의 행동별 참 기댓값과 실제 보상 및 추정값을 구분한다.
  • 같은 행동의 보상만 사용하여 표본평균을 계산한다.
  • 새 보상과 누적 횟수만으로 표본평균을 갱신한다.

고른 행동의 보상만 보이는 작은 문제

기계에 버튼 A와 B가 있습니다. 누를 때마다 보상은 0 또는 1점이며, 고른 버튼의 결과만 볼 수 있습니다. 이번 모형은 버튼을 누르기 전과 후에 다음번 선택지나 보상 규칙이 바뀌지 않는다고 가정합니다. 맥락도 주어지지 않습니다. 이런 식으로 고정된 선택지 중 하나를 반복해 고르는 문제를 다중 선택지 밴딧이라고 합니다. 각 버튼 하나가 영어로 arm입니다.

설명에서는 A의 보상 1 확률이 1/2, B는 3/4라고 정합니다. 각 선택 이후, 과거 경험을 알고 있어도 다음 보상은 선택한 버튼의 고정 분포에서 새로 정해집니다. 실제 에이전트에게 이 확률은 알려 주지 않습니다. 행동 a의 참 행동 가치 q(a)는 버튼 a를 고를 때 받을 보상의 기댓값입니다. 이 예에서는 q(A)=0.5, q(B)=0.75입니다. A에서도 1이 나오고 B에서도 0이 나올 수 있습니다. 한 번 받은 보상과 참 평균은 다릅니다.

다른 버튼의 보상과 섞지 않는다

실제 기록에서 A의 보상이 1, 0, 1, 0이고 B의 보상이 0, 1, 1이라고 합시다. 그 행동으로 받은 보상의 평균을 행동 가치 추정값 Q(a)로 씁니다. 아직 누른 적이 없는 버튼은 받은 것이 없어 표본평균이 정의되지 않습니다. 프로그램에서 Q=0을 처음 넣더라도 그 값은 관측 결과가 아니라 초기값입니다.

A의 추정값은 (1+0+1+0)/4=1/2, B는 (0+1+1)/3=2/3입니다. 전체 일곱 보상을 더하고 7로 나누면 선택했던 전체 과정의 평균을 계산할 수 있지만, 버튼 하나의 평균 보상을 묻는 질문에는 답하지 않습니다. 한 버튼을 충분히 관측하면 고정 분포 아래에서 그 버튼의 표본평균은 참 기댓값을 추정합니다. 누르지 않는 버튼에는 새 근거가 쌓이지 않습니다.

새 값과 차이를 이용해 평균을 한 번만 갱신한다

어떤 버튼에서 보상 n−1개를 받아 평균이 Qold입니다. n번째 보상 r을 받은 뒤 그 버튼의 평균은 [(n−1)Q_old + r]/n입니다. 이 식을 정리하면 Q_new = Q_old + (r−Q_old)/n입니다. n은 새 보상까지 포함한 해당 버튼의 횟수입니다. 게임의 전체 시간이나 모든 버튼을 누른 합계가 아닙니다.

A 버튼의 세 번째 관측

첫 두 보상 1, 0의 평균은 1/2입니다. 새 보상 1을 받으면 평균과의 차이는 +1/2입니다. n=3이므로 기존 평균에 (1/2)/3=1/6을 더합니다. 새 평균은 2/3입니다. 새 값이 평균보다 작으면 차이는 음수여서 추정값이 내려갑니다.

처음 한 번은 n=1이므로 유한한 초기값이 무엇이었든 첫 관측 r이 그대로 새 Q가 됩니다. 이전 결과를 모두 보관할 필요 없이 버튼마다 Q와 횟수를 저장하면 됩니다. 고정 확률 가정이 깨져 성능이 시간에 따라 바뀐다면 오래된 기록을 똑같이 가중하는 평균이 지금의 값을 잘 따라가지 못할 수 있습니다. 코드로 계산한 평균과 실제 시스템에서 추정할 값을 구분합니다.

매번 전체를 더한 답과 대조한다

from fractions import Fraction as F

records = [("A", 1), ("B", 0), ("A", 0), ("A", 1),
           ("B", 1), ("B", 1), ("A", 0)]
count = {"A": 0, "B": 0}
estimate = {"A": F(0), "B": F(0)}
observed = {"A": [], "B": []}

for arm, reward in records:
    count[arm] += 1
    estimate[arm] += (reward - estimate[arm]) / count[arm]
    observed[arm].append(reward)
    assert estimate[arm] == F(sum(observed[arm]), count[arm])

for arm in ("A", "B"):
    print(arm, "횟수", count[arm], "평균", estimate[arm])
A 횟수 4 평균 1/2
B 횟수 3 평균 2/3

코드의 observed는 갱신 공식을 매 단계 검산하려고 넣었습니다. 실제로 평균만 갱신할 때는 누적 횟수와 추정값을 저장하면 됩니다. 다음 장에서는 이 평균이 아직 불완전할 때 어떤 버튼을 눌러 볼지 결정합니다.
