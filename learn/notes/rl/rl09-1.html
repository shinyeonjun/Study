RL09·1

가치 표의 칸을 공통 함수로 바꾼다

확인대가 두 곳이면 상태마다 값을 적어 둘 수 있습니다. 확인대마다 남은 거리와 대기 인원까지 기록한다면, 본 적 없는 조합에도 값을 계산하는 방법이 필요합니다.

이 장을 읽고 나면

  • 가치표와 특징을 쓰는 선형 가치근사를 구별한다.
  • 선형 추정값과 TD 반경사 갱신을 손으로 구한다.
  • 공통 가중치가 다른 상태의 추정값도 바꾸는 이유를 설명한다.

기록된 상태마다 한 칸을 남길 수 있을까

확인대까지 남은 거리가 2m였던 경우와 2.01m였던 경우는 서로 다른 수입니다. 값의 가능한 조합이 많다면 모든 상태에 한 칸씩 정해 두기 어렵습니다. 관측에서 필요한 정보를 골라 수치 묶음으로 바꿉니다. 이 수치들을 특징이라고 합니다. 같은 함수에 서로 다른 특징을 입력해 가치의 근삿값을 계산하는 방식을 함수근사라고 합니다.

먼저 추정값이 서로 어떻게 연결되는지 보기 위해 작은 확인대만 사용합니다. S와 C의 특징은 각각 x(S)=[1,0], x(C)=[1,1]입니다. 첫 성분은 어느 상태에서나 1인 공통 항입니다. 둘째는 확인대 C에 도착하면 1입니다. 가중치 w=[0,2]를 맞는 자리에 곱해 더하면 선형 가치근사 V̂(s;w)=wᵀx(s)를 얻습니다. V̂(S)=0, V̂(C)=2입니다. 여기서는 이 숫자들이 현재 정책의 정확한 가치라고 가정하지 않습니다.

반대로 x(S)=[1,0], x(C)=[0,1]로 각 상태에만 1인 원-핫 특징을 쓰면 가중치를 서로 공유하지 않습니다. V̂(S)=w₀, V̂(C)=w₁이므로 표와 같은 방식으로 계산합니다. 공통 특징을 주면 한 번도 본 적 없는 조합으로 숫자를 이어갈 수 있지만, 비슷한 특징을 가진 상태끼리 잘못 묶일 수도 있습니다.

TD 오차를 현재 특징만큼 나눠 가중치를 고친다

정책이 S에서 확인을 골라 보상 0을 받고 C에 도착했다고 합시다. 할인율 γ=0.5이면 이전 가중치로 만든 목표 Y=0+0.5×2=1이고 오차는 δ=Y−V̂(S)=1입니다. 지금 목표를 임시로 고정하고 오차 제곱을 줄이려면, S의 예측이 w₀의 변화에 얼마나 반응하는지를 먼저 봅니다. 이 반응이 바로 x(S)의 해당 성분입니다. α=0.5일 때 w ← w+αδx(S)=[0.5,2]입니다.

목표에 있는 V̂(C)도 같은 w로 계산했습니다. 하지만 이 기본 TD는 이번 갱신에서 목표를 고정하고 예측 쪽만 미분합니다. 그래서 반경사(semi-gradient)입니다. 실제 과제 종료에서는 목표에 가치 항이 없으므로 해당 항의 미분 문제도 사라집니다. 이 설명은 정책을 고정한 TD 가치 예측의 예입니다.

특징을 늘리거나 신경망으로 표현한다

상태 가치 V는 그 상태에서 정해진 정책을 따른 결과를 말합니다. 행동을 고르는 데 쓰려면 처음 행동까지 넣은 Q(s,a)를 사용할 수 있습니다. 선형 방식은 예를 들어 (상태, 행동) 특징을 만들고 그 성분의 가중합을 계산합니다. 신경망은 입력을 여러 층에서 바꾸어, 단순한 직선으로 표현하기 어려운 관계도 학습할 수 있게 합니다. 같은 비선형 층을 공유하고 출력에는 가능한 행동마다 Q 숫자 하나를 둡니다. 이 숫자들은 반환(할인 누적 보상)의 예측값이라 음수가 나올 수 있으며 합이 1이라는 제약도 없습니다.

값을 넓게 공유하면 관측하지 않은 상태로 예측을 확장할 수 있습니다. 반대로 중요한 특징이 입력에 빠졌다면 모델이 두 상태를 구분하기 어렵습니다. 가령 남은 작업이 같아도 실패 비용이 다르면 이후 보상이 달라질 수 있습니다. 모형에 어떤 정보를 넣었는지 확인하고, 학습하지 않았던 상태에서도 예측이 얼마나 맞는지 따로 관측합니다.

NumPy로 공통 가중치를 한 번만 갱신한다

import numpy as np

features = np.array([[1.0, 0.0], [1.0, 1.0]])
weights = np.array([0.0, 2.0])
before = features @ weights
target = 0 + 0.5 * before[1]
delta = target - before[0]
weights = weights + 0.5 * delta * features[0]
after = features @ weights

print("before:", before.tolist())
print("target and error:", target, delta)
print("weights:", weights.tolist())
print("after:", after.tolist())
before: [0.0, 2.0]
target and error: 1.0 1.0
weights: [0.5, 2.0]
after: [0.5, 2.5]

각 행이 상태 하나의 특징입니다. 행렬과 가중치 벡터의 곱으로 상태 두 개의 예측을 한꺼번에 계산합니다. 실제 학습에서는 다음 전이의 목표가 업데이트한 가치에 따라 다시 계산될 수 있습니다.
