RL08·1

n-step 목표로 여러 전이의 보상을 잇는다

확인대에서 시작한 결정의 결과를 그다음 한 걸음만 보고 판단할 수도, 마지막까지 기다려 판단할 수도 있습니다. 몇 걸음까지 직접 확인할지 숫자로 정해 봅니다.

이 장을 읽고 나면

  • n-step 목표에서 관측 보상과 부트스트랩 부분을 구별한다.
  • 같은 기록의 한 단계·두 단계·완주 목표를 계산한다.
  • 수집이 끊긴 경계와 과제 자체의 종료를 따로 다룬다.

같은 시작을 세 가지 길이로 읽는다

앞 장의 TD는 바로 다음에 받은 보상 한 개를 씁니다. 확인대 모형에서 정책은 S와 C 모두 확인 행동을 고릅니다. S에서는 0을 받으며 C로 갑니다. C에서는 절반씩 −1을 받으며 그대로 C에 남거나, 3을 받으며 완료 상태 T로 갑니다. 할인율 γ는 0.5입니다. 이 장에서는 길이의 효과만 비교하기 위해 가치 추정표를 고정해서 V(S)=0, V(C)=1로 놓습니다.

한 에피소드에서 S₀=S → S₁=C → S₂=C → S₃=T를 보았습니다. 보상은 R₁=0, R₂=−1, R₃=3입니다. 여기서 아래첨자는 관측 시점을 가리킵니다. R₁은 첫 행동을 고른 뒤 받습니다. 시작 S₀의 목표를 만들 때 n-step은 앞으로 관측한 보상을 최대 n개까지 쓰고, 아직 끝나지 않았으면 n번째로 도달한 상태의 추정값을 덧붙입니다.

Gₜ⁽ⁿ⁾ = Rₜ₊₁ + γRₜ₊₂ + … + γⁿ⁻¹Rₜ₊ₙ + γⁿV(Sₜ₊ₙ).

이 줄은 n번째 전이까지 과제가 계속될 때의 식입니다. 쉽게 확인하려면 할인율의 거듭제곱을 시간표에 먼저 적습니다. 첫 보상은 지금 선택의 바로 다음에 받으므로 할인하지 않습니다. 두 번째 보상에는 γ가 있고, 두 보상 뒤의 가치에는 γ²가 있습니다. 갱신은 TD와 같은 V(Sₜ) ← V(Sₜ)+α(Gₜ⁽ⁿ⁾−V(Sₜ))입니다.

길이시작점 S의 목표 계산목표
10 + 0.5×10.5
20 + 0.5×(−1) + 0.25×1−0.25
30 + 0.5×(−1) + 0.25×30.25

언제 모으고, 언제 기다릴까

한 단계라면 첫 전이만으로 시작 S의 값을 고칠 수 있습니다. 두 단계는 한 시점 더 기다립니다. 온라인 구현은 최근 전이 n개를 순서대로 보관해 충분히 모였을 때 가장 앞 상태를 고칠 수 있습니다. 중간부터 시작한 상태도 같은 방법을 씁니다. 세 전이보다 보상을 더 기다리기로 했어도 이 과제는 T에서 이미 끝났습니다. 마지막까지 관측할 수 있던 보상을 모두 반영해, 아직 목표를 만들지 못한 최근의 시작점을 각각 처리합니다.

길이가 길어지면 멀리 있는 관측 보상이 더 일찍 이전 상태의 학습에 직접 들어갑니다. 대가도 있습니다. 실제 보상을 여러 개 포함하면 궤적의 우연한 차이 때문에 목표값이 달라질 수 있습니다. 짧으면 지금의 가치 오차가 목표로 넘어옵니다. 정책과 추정표 고정이라는 조건에서, n번째 상태의 가치 오차가 목표에 들어가는 크기는 그 오차에 γⁿ을 곱한 값입니다. 참 가치가 이미 정확하면 이 부트스트랩 때문에 생기는 편향은 없습니다. n이 커질 때 분산이 얼마나 달라지는지는 실제 보상과 상태 사이의 의존 구조에 달려 있습니다.

종료와 잘림을 구분해 남은 목표를 계산한다

과제 자체의 종료에서 부트스트랩 항은 0입니다. 환경 수집기가 처음 두 전이만 보여 주고 비종료 C에서 외부 시간 제한으로 잘랐다면, 이 기록으로는 세 번째 보상 3을 모릅니다. 원래 과제의 가치를 추정한다면 지금 본 두 보상에 마지막 C의 가치 1을 붙여 −0.25로 계산할 수 있습니다. 완주를 기록한 경우와 잘린 경우가 서로 다른 목표를 내는 이유입니다.

시작 시점과 기록 경계를 코드에 넣는다

from fractions import Fraction as F

gamma = F(1, 2)
value = {"S": F(0), "C": F(1)}

def target(start, n, states, rewards, terminated):
    stop = min(start + n, len(rewards))
    observed = sum(
        (gamma**(j - start) * rewards[j] for j in range(start, stop)),
        F(0),
    )
    if terminated and stop == len(rewards):
        return observed
    return observed + gamma**(stop - start) * value[states[stop]]

states = ["S", "C", "C", "T"]
rewards = [0, -1, 3]
for n in (1, 2, 3, 5):
    print(n, target(0, n, states, rewards, True))
print("later:", target(1, 2, states, rewards, True))
print("truncated:", target(0, 3, states[:3], rewards[:2], False))
1 1/2
2 -1/4
3 1/4
5 1/4
later: 1/2
truncated: -1/4

상태 배열에는 시작 상태와 보상 하나마다 도달한 상태가 들어갑니다. 마지막 전이로 과제 종료를 관측해도 앞에서 끝나는 목표는 해당 중간 상태를 참고합니다. 뒤에서 시작한 C의 두 단계 목표는 −1+0.5×3=0.5입니다.
