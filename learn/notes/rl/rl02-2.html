RL02·2

ε-greedy: 평균을 쓰면서 새 선택지도 확인하기

첫 결과만 보고 가장 좋아 보이는 버튼을 계속 누르면 다른 버튼을 알아볼 기회가 줄어듭니다. 어느 정도를 이미 아는 선택에 쓰고, 어느 정도를 탐험에 쓰는지 나누어 봅니다.

이 장을 읽고 나면

  • ε-greedy에서 활용과 탐험을 구분하고 실제 선택 확률을 계산한다.
  • 미관측 행동의 초기화와 최대값 동률을 처리한다.
  • 확장으로 UCB의 탐험 항과 누적 후회의 계산 기준을 읽는다.

지금 좋아 보이는 행동과 더 알아볼 행동

실제 참 평균 q(a)는 몰라서 앞 장의 Q(a)를 씁니다. 활용은 지금 Q가 가장 큰 행동을 고르는 것입니다. 탐험은 지금까지 덜 좋아 보인 행동도 시도하여 새 정보를 얻는 것입니다. 예를 들어 참 평균이 더 높은 버튼의 첫 보상이 우연히 0이면, 활용만 하는 규칙은 당장 1을 받은 다른 버튼으로 굳어질 수 있습니다.

ε-greedy의 ε(엡실론)은 0부터 1까지 정합니다. 확률 ε로 모든 행동에서 균등하게 고르고, 확률 1−ε로 최대 Q 행동만 모아서 그중 균등하게 고르겠습니다. 다른 구현은 탐험에서 최댓값 행동을 제외하기도 합니다. 이 장에서 계산하는 확률과 코드는 탐험 시에도 모든 행동을 후보로 둔다는 규약입니다.

세 행동에서 A가 유일한 최대이고 ε=0.2라면 A를 고를 확률은 (1−0.2)+0.2/3=13/15입니다. B와 C는 탐험으로만 고르므로 각각 1/15입니다. 최대 Q가 두 개로 동률이면 활용 확률 1−ε을 두 행동이 절반씩 나눕니다. ε=0이면 지금 추정값에만 의존하고, ε=1이면 항상 전체 행동에서 균등하게 뽑습니다.

초기값과 동률은 실험의 일부다

아무 버튼도 누르지 않았으면 Q는 평균으로 계산할 수 없습니다. 작은 실험에서는 버튼마다 한 번씩 먼저 누르기를 초기화로 두면 모든 행동에 관측값 하나가 생깁니다. Q를 임의의 같은 값으로 시작하는 방법도 있지만, 그 값과 동률 규칙이 첫 행동을 좌우합니다. 코드는 번호가 작은 행동을 무조건 먼저 고르는 대신, 최대값 후보를 모아서 균등하게 나눕니다. 난수 시드를 기록해 선택 과정을 재현할 수 있습니다.

확장 · 한 번 본 행동에 얼마나 탐험 점수를 줄까

UCB(upper confidence bound)는 지금 평균에 덜 알아본 행동의 탐험 점수를 더합니다. 이 장은 Sutton·Barto의 형태인 Q(a)+c√[ln(t)/N(a)]를 씁니다. t는 지금 고를 시행 번호(1부터 시작), N(a)는 그 이전에 해당 행동을 고른 횟수, c는 탐험 크기를 조절하는 음이 아닌 수입니다. ln은 자연로그입니다. N(a)=0이면 식으로 나눌 수 없으므로 먼저 한 번씩 시도합니다. 이 간단한 형태의 점수를 그대로 통계적 신뢰구간이라고 해석하려면 보상 범위 등 추가 조건이 필요합니다.

지금까지 A를 12번, B를 3번 눌렀으므로 이제 t=16입니다. Q(A)=0.75, Q(B)=2/3, c=1이면 A의 점수는 약 1.2307, B는 약 1.6280입니다. 보상이 0·1점뿐이더라도 선택에 쓰는 UCB 점수는 1보다 클 수 있습니다. 시도가 늘면 같은 t에서 점수가 더해지는 크기는 작아집니다.

확장 · 가장 좋은 참 평균과 얼마나 차이 났나

각 버튼의 참 평균이 q(A)=0.75, q(B)=0.50인 환경을 평가한다고 합시다. 최선의 참 평균 q*=0.75는 우리가 만든 모형에서는 알고 있지만, 실제 에이전트에게는 보통 알려 주지 않습니다. 특정 실행에서 고른 행동 Aₜ마다 평균 차이 q*−q(Aₜ)를 쌓으면 그 실행의 누적 평균 격차를 얻습니다. A,B,B,A를 골랐다면 B의 격차가 0.25점씩 두 번 발생해 합은 0.5점입니다.

실행을 여러 번 되풀이할 때 이 합의 기댓값을 누적 기대 의사후회(expected pseudo-regret)라고 부르겠습니다. 분포가 고정되고, 각 시점의 보상은 행동을 고른 뒤 그 행동 분포에서 새로 나온다는 가정 아래 Tq*−E[받은 보상의 합]과 같습니다. 각 실행의 실제 보상 합은 운에 영향을 받습니다. 예를 들어 위 실행에서 1점을 네 번 받았다면 최선 정책의 기대 기준 4×0.75에서 실제 합 4를 뺀 값은 −1입니다. 평균 차이의 합 0.5가 음수로 바뀐 것이 아닙니다.

선택 규칙과 계산 예제를 코드로 대조한다

from fractions import Fraction as F
from math import log, sqrt
from random import Random

def epsilon_greedy(values, epsilon, rng):
    actions = list(range(len(values)))
    if rng.random() < epsilon:
        return rng.choice(actions)
    best_value = max(values)
    tied = [a for a in actions if values[a] == best_value]
    return rng.choice(tied)

rng = Random(7)
fixed_estimates = [0.6, 0.2, 0.3]
choices = [epsilon_greedy(fixed_estimates, 0.2, rng) for _ in range(6)]
scores = [q + sqrt(log(16) / n) for q, n in [(0.75, 12), (2 / 3, 3)]]
means = {"A": F(3, 4), "B": F(1, 2)}
best = max(means.values())
path = "ABBA"
gap = sum(best - means[arm] for arm in path)
observed_loss = len(path) * best - sum([1, 1, 1, 1])

print("ε-greedy 선택:", choices)
print("UCB 점수:", *(f"{score:.4f}" for score in scores))
print("누적 평균 격차:", gap)
print("기대 기준과 관측 합계의 차:", observed_loss)

selector, environment = Random(7), Random(4)
probabilities = [0.5, 0.75]
counts, estimates = [0, 0], [F(0), F(0)]
for step in range(10):
    if step < len(probabilities):
        arm = step
    else:
        arm = epsilon_greedy(estimates, 0.2, selector)
    reward = int(environment.random() < probabilities[arm])
    counts[arm] += 1
    estimates[arm] += (reward - estimates[arm]) / counts[arm]

print("모의실험 선택 횟수:", counts)
print("모의실험 보상 평균:", *estimates)
ε-greedy 선택: [0, 0, 2, 2, 2, 0]
UCB 점수: 1.2307 1.6280
누적 평균 격차: 1/2
기대 기준과 관측 합계의 차: -1
모의실험 선택 횟수: [7, 3]
모의실험 보상 평균: 5/7 2/3

코드의 첫 선택 여섯 번은 Q를 고정해 행동 선택 규칙만 점검합니다. 그 뒤 별도 모의실험에서는 앞 장의 두 버튼을 각각 한 번씩 누른 뒤부터 ε-greedy를 적용합니다. 환경이 보상을 하나 뽑고, 에이전트는 선택한 행동의 Q와 횟수만 갱신합니다. 이 실행에서는 실제 평균이 0.5인 A의 추정값 5/7이 B의 추정값 2/3보다 큽니다. 열 번의 실행으로 참 평균의 순위를 확정할 수는 없습니다.
