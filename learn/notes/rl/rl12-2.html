독립 반복의 불확실성과 보상 실패를 함께 본다

평균 점수가 높은 정책을 골랐는데 실제 작업은 더 자주 실패할 수 있습니다. 학습을 다시 실행했을 때의 변동과 점수가 목표를 얼마나 잘 대변하는지 두 가지를 따로 확인합니다.

이 장을 읽고 나면

  • 에피소드와 독립 훈련 실행의 집계 단위를 구별한다.
  • 대응한 실행의 평균 차이와 신뢰구간을 계산한다.
  • 보상과 실제 성공이 어긋날 때 남길 지표와 사례를 정한다.

에피소드가 아니라 처음부터 학습한 실행을 다시 뽑는다

새 알고리즘 B와 기준 A를 같은 상호작용 예산에서 비교합니다. 각 알고리즘을 초기화부터 학습하는 일을 네 번 수행했습니다. 사전에 정한 네 가지 서로 독립인 시드 묶음에서 A와 B를 짝지었습니다. 예를 들어 각 묶음은 그 한 쌍의 학습과 평가에서 공통의 시작 조건을 제공하고, 다른 묶음과는 별도로 뽑습니다. 각 정책은 해당 묶음에서 같은 평가 조건으로 여러 에피소드를 한 뒤 한 줄의 평균 점수를 냅니다. 아래는 이 비교 구조를 설명하려고 만든 합성 성적입니다.

이번 비교의 독립 표본은 짝마다의 차이 네 개입니다. 같은 시작 조건에서의 두 점수를 빼면 공통 난도에 의한 흔들림을 줄일 수 있습니다. 난수와 시작 조건을 공유할 때에는 무엇을 짝짓는지 먼저 정하고, 서로 다른 쌍의 독립성을 유지합니다. 짝지을 조건이 없는데 성적 순으로 행을 맞추면 그 계산의 의미가 바뀝니다. 단일 학습 정책의 평가 에피소드 50개를 50번 독립 훈련의 성적으로 쓰는 것 역시 잘못된 단위입니다.

차이의 크기에 불확실성을 더한다

각 차이의 평균은 0.5점입니다. 네 차이의 표본분산은 [(-1−0.5)²+(0−0.5)²+(1−0.5)²+(2−0.5)²]/3=5/3입니다. 평균 차이의 추정 표준오차는 √(5/3)/√4≈0.6455점입니다. 차이들이 같은 정규모집단에서 독립으로 왔다고 가정하면, 자유도 3에서 95% 양측 t 임계값 약 3.182를 씁니다. 평균 차이의 구간은 0.5±3.182×0.6455, 약 [−1.554,2.554]점입니다. 실제 데이터에서 실행이 네 번뿐이라면 분포 모양을 충분히 점검하기 어렵습니다. 이 수치는 정규 가정을 둔 계산 예입니다.

점추정은 B가 0.5점 높지만 구간에는 0과 음수도 있습니다. 이 자료에서 B의 평균 개선을 단정하기 어렵습니다. 두 정책이 정확히 같다고 입증한 것도 아닙니다. 평균과 구간, 실행별 점수, 총 학습 예산을 함께 적습니다. 작은 반복 수에서는 신뢰구간을 계산하더라도 자동으로 신뢰할 만한 결론이 생기지 않습니다. 반복을 재표집하는 부트스트랩을 검토할 때도 독립 표본의 단위를 지키고 실험마다 분포가 얼마나 다른지 확인합니다.

높은 보상이 실제 성공을 뜻하는지 확인한다

별도의 가상 확인 장치에서 업무 목표가 “서로 다른 항목 세 개를 올바르게 처리”라고 합시다. 보상 함수가 ‘확인 버튼을 누를 때마다 1’을 주면, 알맞은 정책은 세 항목을 한 번씩 눌러 총 3점을 받습니다. 반복 정책은 효과가 없는 같은 버튼을 10번 눌러 10점을 받으면서도 올바르게 완료한 항목이 하나도 없을 수 있습니다. 성공 판정 규칙을 버튼 누름 수와 별개로 두었을 때 이런 모순을 찾을 수 있습니다.

학습자가 명시된 보상을 더 받았지만 원래 의도를 따르지 않은 이런 행동을 흔히 보상 우회(reward hacking)라고 부릅니다. 무엇을 실제 완료로 셀지 정의하고 검증 가능한 별도 지표를 둡니다. 성공률, 중단율, 완료 시 걸린 전이 수, 반복 실패 사례 등을 미리 정해 로그에 남깁니다. 성공률의 분모가 모든 평가 에피소드인지 조건에 맞는 일부인지 표시합니다. 성공하지 못한 종료나 특별한 시간 제한을 전체에서 뺀다면 보고한 성능이 크게 바뀔 수 있습니다. 평균이 높아도 반복적으로 실패한 두세 기록을 직접 읽으면 어떤 조건을 무시했는지 알 수 있습니다.

합성 실행을 짝지어 평균 차이와 구간을 계산한다

from math import sqrt
from statistics import mean, stdev
from scipy.stats import t

baseline = [2, 4, 6, 8]
candidate = [1, 4, 7, 10]
differences = [b - a for a, b in zip(baseline, candidate, strict=True)]
n = len(differences)
estimate = mean(differences)
se = stdev(differences) / sqrt(n)
width = t.ppf(0.975, df=n - 1) * se
print("differences:", differences)
print(f"mean={estimate:.3f}, se={se:.4f}")
print(f"95% interval=[{estimate - width:.3f}, {estimate + width:.3f}]")
differences: [-1, 0, 1, 2]
mean=0.500, se=0.6455
95% interval=[-1.554, 2.554]

이 구간은 신뢰구간의 절차를 학습 실행 쌍의 차이에 적용한 것입니다. 여러 과제의 결과를 합칠 때에는 과제마다 점수 척도와 반복 수가 다를 수 있습니다. 어떤 과제를 어떻게 평균했는지, 과제와 실행 중 무엇을 고정했는지 명시합니다.
