RL01·1

에이전트와 환경: 무엇을 보고 무엇을 바꾸나

정리 로봇이 자료를 선반에 전달합니다. 로봇이 받은 숫자와 표시가 무엇이고, 로봇 스스로 고른 결정이 무엇인지 나누면 강화학습에서 쓰이는 용어가 서로 연결됩니다.

이 장을 읽고 나면

  • 에이전트·환경·상태·관측·행동의 역할을 작은 사례에 붙인다.
  • 관측이 상태를 완전히 드러내지 않는 경우를 찾는다.
  • 보상, 목표, 정책이 각각 어디에 쓰이는지 설명한다.

누가 결정을 내리고 누가 결과를 돌려주나

정리 로봇이 보관소에서 자료를 집어 선반에 놓는 연습을 한다고 합시다. 에이전트는 로봇의 몸 전체를 뜻하기보다, 받은 정보를 보고 다음 결정을 내리는 쪽입니다. 환경은 그 결정을 입력으로 받아 위치나 짐의 상태를 바꾸고 결과를 돌려주는 쪽입니다. 이 예에서 로봇의 위치가 어떻게 바뀌고 짐이 언제 전달되는지는 환경의 규칙입니다.

에이전트가 고를 수 있는 선택을 행동이라고 합니다. 예를 들어 ‘집기’, ‘오른쪽으로 이동’, ‘놓기’가 행동입니다. 환경은 잘못된 위치에서 ‘놓기’를 실행하더라도 자료를 전달하지 않을 수 있습니다. 에이전트는 행동을 선택하고, 무엇이 성공인지와 그 다음 결과는 환경의 규칙이 정합니다.

환경 안에 있는 정보와 에이전트에게 보이는 정보

작은 모형에서 현재 상태는 ‘위치’와 ‘짐을 들고 있는지’라는 두 값으로 표현할 수 있습니다. 환경이 현재 상태와 행동으로 다음 결과를 계산할 수 있게 필요한 정보를 담았습니다. 관측은 그중 에이전트가 입력으로 받은 값입니다. 위치와 짐 여부가 모두 전달되면 이 모형에서는 상태가 드러납니다. 위치만 전달되면 짐 여부가 가려집니다.

선반에서 ‘놓기’를 고른다고 합시다. 짐을 들고 있으면 배달이 성공해 5점을 얻습니다. 빈손이면 선반에 놓을 것이 없어 보상은 0입니다. 관측이 선반이라는 사실만으로 어떤 보상이 돌아올지 확정할 수 없습니다. 이처럼 상태의 일부가 관측되지 않는 상황을 부분관측이라고 합니다. 상태가 더 복잡하면 위치뿐 아니라 시간·센서의 잡음·이전 행동이 관측에 미치는 영향도 따로 볼 수 있습니다.

기억이 도움이 되는 조건

매회 같은 보관소에서 빈손으로 시작하고 집기의 성공 여부가 확실하며 도중에 잃어버릴 가능성이 없다면, ‘집기를 성공했다’는 기록으로 짐 여부를 추론할 수 있습니다. 집기의 성공 자체가 보이지 않거나 짐이 떨어질 수 있다면 이 기록만으로는 현재 상태를 확정할 수 없습니다.

보상은 한 번의 숫자, 정책은 행동 선택의 규칙

보상은 행동 뒤에 환경에서 받은 숫자입니다. 여기서는 점수이며, 보상 5는 배달 성공 신호입니다. 목표는 여러 행동에 걸쳐 얻는 보상을 쌓아 잘 받는 것입니다. 다음 장에서 이동에 비용 −1이 있더라도 마지막에 5점을 얻는 경로를 비교합니다. 어떤 행동이 당장 보상이 크다고 그 뒤의 점수까지 크다고 말할 수는 없습니다.

문제의 목표를 보상으로 표현할 때는 높은 점수가 실제로 원하는 결과를 가리키는지 확인합니다. 예를 들어 이동할 때마다 1점, 배달에는 0점을 주고 양방향 이동을 허용하면, 자료를 배달하는 대신 두 곳을 오가며 점수를 모을 수 있습니다. 무엇에 점수를 줄지 정하면 정책이 잘해야 할 일이 함께 정해집니다.

정책은 받은 정보로 어떤 행동을 고를지 정한 규칙입니다. 예를 들어 ‘보관소에서 빈손이면 집는다’는 한 조건에서 하나의 행동을 확정하는 결정적 규칙입니다. ‘같은 조건에서 80%로 집고 20%로 다른 행동을 고른다’는 확률적 규칙입니다. 정책이 정해졌더라도 환경의 결과가 확률적이면 매번 같은 보상을 받는 것은 아닙니다. 부분관측에서 정책은 최근 관측과 행동을 기억한 기록을 입력으로 삼을 수도 있습니다.

두 상태를 같은 관측 함수로 바꿔 본다

observe는 환경 안의 상태에서 에이전트에게 보낼 정보만 꺼냅니다. 상태를 나타내는 튜플의 0번은 위치이고 1번은 짐을 들고 있는지의 참·거짓입니다.

def observe(state):
    position, carrying = state
    return position

def drop_reward(state):
    position, carrying = state
    return 5 if position == "선반" and carrying else 0

empty = ("선반", False)
loaded = ("선반", True)
assert observe(empty) == observe(loaded)
assert drop_reward(empty) != drop_reward(loaded)
print("빈손 관측, 보상:", observe(empty), drop_reward(empty))
print("짐 든 관측, 보상:", observe(loaded), drop_reward(loaded))
빈손 관측, 보상: 선반 0
짐 든 관측, 보상: 선반 5

이 코드는 같은 관측이 다른 결과를 숨길 수 있다는 예입니다. 아직 이 두 경험에서 정책을 바꾸는 계산을 하지는 않았습니다. 다음 장에서 선택 규칙을 실행해 경험에 어떤 값이 남는지 살펴봅니다.
