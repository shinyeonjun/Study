RL07·3

Q-learning은 최댓값을 목표로 배운다

데이터를 모으는 행동과 목표에서 비교하는 행동이 다를 수 있습니다. 같은 전이를 SARSA와 Q-learning에 각각 넣어 값이 달라지는 이유를 계산합니다.

이 장을 읽고 나면

  • Q-learning의 목표에 다음 상태의 최댓값을 넣고 새 Q를 계산한다.
  • 행동 정책과 목표 정책을 구분해 온폴리시와 오프폴리시를 설명한다.
  • 과제 종료에서 미래 항을 빼고 표 기반 수렴의 가정을 확인한다.

다음 상태의 행동들을 비교해서 가장 큰 값을 넣는다

S에서 확인하고 보상 0으로 C에 도착했습니다. 현재 표는 Q(S,확인)=1, Q(C,직행)=4, Q(C,확인)=0입니다. 할인율과 학습률을 모두 1/2로 둡니다. SARSA가 고른 다음 행동의 Q를 쓰는 데 비해, Q-learning은 다음 상태에서 가능한 행동들의 현재 Q 중 가장 큰 값을 목표에 사용합니다.

Y = r + γ maxb Q(s′,b).
Q(s,a) ← Q(s,a) + α[Y−Q(s,a)].

Q-learning의 이번 목표는 0+½×4=2입니다. Q(S,확인)을 1에서 1+(1/2)(2−1)=3/2로 고칩니다. 행동 정책이 탐험으로 C 확인을 골라도 이 목표에는 그 값 0 대신 최댓값 4를 씁니다. 최대화할 행동은 C에서 가능해야 합니다. T에서 실제로 종료한 경우에는 최대화할 항을 만들지 않고 목표를 관측 보상으로 둡니다.

다음에 실행할 행동과 값을 배울 때 쓰는 기준

경험을 수집하는 규칙이 행동 정책, 목표값에서 앞으로 따른다고 보는 규칙이 목표 정책입니다. Q-learning에서는 행동 정책으로 ε-탐욕을 사용해 여러 행동을 경험할 수 있고, 후속 값을 정의하는 목표에는 탐욕 규칙의 최댓값을 씁니다. 이렇게 두 역할을 분리할 수 있는 방식을 오프폴리시라고 합니다.

SARSA는 s′에서 미리 뽑은 다음 행동을 목표에도 넣으므로 그 행동이 필요합니다. Q-learning 갱신은 s′에서 적용할 최댓값만 알면 됩니다. 이어지는 실제 행동은 자료 수집 규칙대로 고릅니다. 둘 다 경험에 들어 있는 r과 s′는 바꾸지 않습니다.

외부 시간 제한으로 C에서 수집이 멈추었었다면, 원래 과제에 여전히 가능한 행동이 있으므로 C의 최댓값을 미래 항에 씁니다. 리셋에서 돌아온 S의 최댓값은 이전 전이에 이어 붙이지 않습니다. 반대로 과제 자체가 끝난 T에서는 보상만 씁니다.

이상적인 표와 실제 학습 과정을 나눈다

앞에서 모형을 알고 가치 반복했을 때 최적 상태 가치는 V*(S)=3, V*(C)=6이었습니다. 그 값이 맞는지 행동까지 써 봅니다. S 직행은 즉시 2로 끝나고, S 확인은 C의 최적 가치 6에 할인율을 곱해 3입니다. C 직행은 6입니다. C 확인은 절반이 보상 3으로 종료하고 절반이 보상 −1과 C로 돌아오므로 최적 후속 값을 쓸 때 (3/2)+(−1+½×6)/2=5/2입니다.

유한한 상태·행동을 모두 표로 쓰고 보상이 유계이며 할인율이 1보다 작은 경우를 생각합시다. 표 기반 Q-learning의 대표적인 수렴 조건에는 각 관련 상태·행동을 무한히 자주 갱신하는 탐험과, 각 항목의 학습률이 점점 신중해지는 조건이 포함됩니다. 예로 그 항목의 k번째 방문에 αk=1/k를 쓰면 학습률 합은 무한하지만 학습률 제곱합은 유한합니다. 수집 정책이 놓치는 행동이 있다면 그 값을 경험으로 배우지 못합니다.

SARSA로 최적 정책을 학습하는 표 기반 정리에서는 각 관련 상태·행동을 무한히 자주 방문하면서, 극한에는 탐욕 행동을 고르는 GLIE 조건과 학습률 조건을 확인합니다. ε을 낮춘다는 사실만으로 모든 쌍을 충분히 경험했다고 볼 수는 없습니다. 고정 α로 짧게 실행하거나 신경망으로 Q를 근사하는 경우에는 별도의 수렴 근거가 필요합니다.

같은 초기표에서 두 알고리즘과 경계 조건을 실행한다

from fractions import Fraction as F

alpha = gamma = F(1, 2)
initial = {("S", "check"): F(1), ("C", "direct"): F(4), ("C", "check"): F(0)}
actions = {"S": ("direct", "check"), "C": ("direct", "check")}

def update(q, state, action, reward, next_state, terminated, sampled=None):
    if terminated:
        future = F(0)
    elif sampled is not None:
        future = q[next_state, sampled]
    else:
        future = max(q[next_state, a] for a in actions[next_state])
    target = F(reward) + gamma * future
    q[state, action] += alpha * (target - q[state, action])
    return target, q[state, action]

print("SARSA:", *update(initial.copy(), "S", "check", 0, "C", False, sampled="check"))
print("Q-learning:", *update(initial.copy(), "S", "check", 0, "C", False))
print("terminal:", *update(initial.copy(), "C", "direct", 6, "T", True))
print("external cutoff:", *update(initial.copy(), "S", "check", 0, "C", False))
SARSA: 0 1/2
Q-learning: 2 3/2
terminal: 6 5
external cutoff: 2 3/2

sampled가 있으면 SARSA의 실제 다음 행동, 비종료에서 그 인수가 없으면 Q-learning의 최댓값을 사용합니다. 종료에서는 T의 Q가 없어도 계산됩니다. 잘림 줄에서는 전이가 도착한 C에 대한 최댓값을 사용합니다. 출력 숫자는 (목표, 새 값) 순서입니다.

한눈에 정리

항목계산
SARSA 목표보상 + γ × 실제로 고른 다음 행동의 Q.
Q-learning 목표보상 + γ × 다음 상태에서 가능한 Q의 최댓값.
실제 종료두 알고리즘 모두 미래 항을 0으로 둔다.
장기 수렴 조건탐험의 방문 범위, 학습률, 표 기반 표현과 문제 가정을 확인한다.
