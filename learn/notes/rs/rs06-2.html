RS06·2

실패까지 읽히는 그림과 캡션 쓰기

평균이 나아진 경우에도 각 실행에서 같은 일이 있었는지 확인합니다. 그림에 단위와 분모를 붙이고, 다른 사람이 수치를 다시 계산할 수 있게 기록을 남깁니다.

이 장을 읽고 나면

  • 평균 그림에 가려진 실행별 결과와 실패 사례를 확인한다.
  • 축, 단위, 분모, 분석 단위를 그림과 캡션에 담는다.
  • 그림의 숫자와 실험을 다시 만들 수 있도록 최소한의 기록을 남긴다.

같은 예산의 평균 아래에 무엇이 있었나

두 정책 A와 B가 동일한 합성 큐 환경에서 각각 1,000번 상호작용하며 학습했다고 합시다. 설정을 고정한 뒤 정책을 바꾸지 않고 실행당 평가 작업 10개를 수행합니다. 네 개의 시작 조건을 사용하고, 각 번호의 A와 B는 같은 평가 작업에 답합니다. 예시의 수는 직접 만든 합성 기록입니다.

A의 성공 완료 건수는 6,6,6,6, B는 9,9,9,1입니다. 평균 완료율은 A 60%, B 70%이므로 평균 차이는 10%p입니다. 시드 번호를 같은 평가 조건의 표시로 사용했습니다. 여기서 두 정책을 비교하는 단위는 같은 번호의 실행 쌍 네 개입니다. 한 실행 안에서 시도한 작업 10개를 독립으로 학습한 실행 10개로 세지 않습니다.

실패는 사전에 10개 중 2개 이하 완료로 정의했다고 합시다. A는 네 실행 모두 기준을 넘고 B는 시드 13에서 1건만 완료해 네 실행 중 하나가 실패했습니다. 기록만으로 실패 원인을 단정할 수는 없습니다. 해당 실행의 입력 조건, 실패 단계와 종료 원인을 확인할 수 있도록 남깁니다. 실제 보고에서는 실패를 제외한 평균만 제시하는 대신, 실패 수와 어떤 이유로 빠진 결과가 있는지도 함께 씁니다.

막대와 점의 의미가 유지되는 축을 고른다

비율 막대에서 길이로 크기를 읽으면 0을 기준으로 합니다. 완료율 60%와 70%의 막대를 55%에서 시작하면 그려진 길이는 각각 5와 15가 되어, 원래 비율의 크기를 비교한 길이와 다릅니다. 작은 차이의 범위를 보고 싶으면 축을 명시한 점과 구간으로 확대하고, 선택한 범위를 적습니다.

시간의 순서를 잇는 선은 중간 위치에서 새 관측을 만들어내지 않습니다. 단위가 다른 수치를 한 축에 넣거나, 분모가 다른 비율을 같은 빈도처럼 읽기 쉽다면 축 제목과 분모를 직접 적습니다. 10%p 차이를 %로 잘못 읽지 않도록 축에도 단위를 넣습니다. 두 조건을 색만으로 가르기보다 이름, 모양 또는 선종을 같이 사용합니다.

캡션만 읽어도 분모와 비교 기준을 알 수 있게 한다

보고용 캡션 예

합성 큐 환경의 완료 결과. 두 정책은 1,000회의 동일한 학습 상호작용 예산을 사용했고, 정책을 고정한 뒤 각 실행에서 동일한 10개 평가 작업을 수행했다. 점은 실행 하나의 완료 수다. 네 실행 쌍의 시드 번호는 10~13이다. 완료 수 ≤2를 실패로 정했을 때 A는 0/4, B는 1/4다. 막대는 실행별 완료율의 평균을 표시한다.

그림에 구간이 들어간다면 계산 방법과 반복 단위도 추가합니다. 예로 “독립 실행 쌍을 단위로 한 평균 차이의 95% 부트스트랩 구간”처럼 씁니다. 이 예에서는 실행 결과 네 쌍을 그대로 제시합니다. 시험을 하며 설정을 고른 경우에는 그 자료를 최종 평가와 구분합니다.

다시 확인할 수 있게 어떤 원자료·입력 필터에서 수치가 나왔는지, 코드와 환경 버전, 설정과 시드를 기록합니다. 관측 단위, 제외·탈락 건수, 그림을 만든 집계식도 함께 보관합니다. 그림만 남기는 것보다 같은 입력으로 다시 계산할 수 있는 작은 표나 실행 명령을 같이 두는 편이 확인하기 쉽습니다.

공통 조건의 평균차와 실패 집계를 확인한다

from statistics import mean

seed_ids = (10, 11, 12, 13)
completed_a = (6, 6, 6, 6)
completed_b = (9, 9, 9, 1)
cases_per_run = 10
failure_limit = 2

paired = [b - a for _, a, b in zip(seed_ids, completed_a, completed_b, strict=True)]
print(f"mean completion: A={mean(completed_a) / cases_per_run:.0%}, B={mean(completed_b) / cases_per_run:.0%}")
print("paired differences (count):", paired)
print("effect (percentage points):", 100 * mean(paired) / cases_per_run)
for label, completed in (("A", completed_a), ("B", completed_b)):
    failing = [s for s, n in zip(seed_ids, completed, strict=True) if n <= failure_limit]
    print(f"{label} failed: {len(failing)}/{len(seed_ids)}, seeds={failing}")
mean completion: A=60%, B=70%
paired differences (count): [3, 3, 3, -5]
effect (percentage points): 10.0
A failed: 0/4, seeds=[]
B failed: 1/4, seeds=[13]

차이는 단위별로 B−A입니다. 마지막 두 줄은 사전에 정의한 기준을 충족하지 못한 실행이 몇 개였는지와 그 번호입니다.
