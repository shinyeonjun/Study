RS03·2

논문의 표·그림에서 근거와 한계 읽기

같은 PPO 구현에서 활성화 함수 두 가지를 비교한 실제 값을 읽습니다. 평균의 방향, 표준오차의 기준과 어디까지 주장할 수 있는지를 따로 적습니다.

이 장을 읽고 나면

  • 원문 표의 행, 열, 캡션과 평가 조건을 맞춘다.
  • 평균차를 정확히 계산하고 별도 불확실성과 구분한다.
  • 표에서 확인한 주장과 추가로 필요한 근거를 적는다.

표의 좌표를 정확히 고르기

Henderson 외 arXiv v3의 Network Architecture 절에서 Table 1을 엽니다. 이 표는 각 구현에서 정책망 설정을 바꾸었을 때 평가 수익을 비교합니다. PPO의 Hopper-v1과 HalfCheetah-v1 행에서 tanh와 ReLU 열을 읽습니다. 같은 논문에 가치함수 설정을 바꾼 Table 2도 있으므로 어떤 모듈을 바꾼 수치인지 확인합니다.

Figure 2의 캡션은 왼쪽, 가운데, 오른쪽 그림에 어느 알고리즘이 있는지 알려 줍니다. 그림을 읽을 때 축에 적힌 양과 함께 패널의 알고리즘·환경·설정을 대조합니다. 여기서 계산할 값은 최종 평가의 Table 1 수치입니다.

환경별로 평균차를 계산

Hopper-v1에서 ReLU−tanh는 2,695−2,790=−95입니다. HalfCheetah-v1에서는 2,971−2,201=+770입니다. 같은 두 활성화 함수에서 평균 차이의 방향이 뒤집히므로 “이 표에서는 두 환경에서 같은 방향의 평균 차이가 나오지 않았다”고 적을 수 있습니다. 환경마다 보상 체계가 다를 수 있어 770과 95의 크기를 동일한 실질 효과로 비교하지 않습니다.

±와 차이의 불확실성을 잇기

각 ±는 다섯 시드 실행에 걸친 표준오차입니다. 두 숫자의 차이를 빼는 것만으로 차이의 표준오차나 통계적 근거가 생기지 않습니다. 같은 시드 결과를 짝으로 비교하려면 시드별 값이나 차이의 정보가 필요합니다. 시드별 결과를 모르는 상태에서 두 표준오차가 겹치는지만으로 검정 결과를 결정하지 않습니다.

실행 예제

table_one = [
    ("Hopper-v1", 2790, 62, 2695, 86),
    ("HalfCheetah-v1", 2201, 323, 2971, 364),
]
for env, tanh, tanh_se, relu, relu_se in table_one:
    print(f"{env} | ReLU - tanh: {relu - tanh:+d} | SEs: {tanh_se}, {relu_se}")

실행 결과

Hopper-v1 | ReLU - tanh: -95 | SEs: 62, 86
HalfCheetah-v1 | ReLU - tanh: +770 | SEs: 323, 364

원 논문의 셀을 옮겨 산술을 대조했습니다. 이 출력은 독립적인 강화학습 재실험이나 유의성 검정이 아니라 표를 읽어 계산한 결과입니다.

결론에 답하지 못한 질문을 남기기

평균 차이의 방향으로 이 두 환경의 조건 의존성을 말할 수 있습니다. 새 환경에서 어느 활성화 함수가 더 좋은지 정하려면 해당 환경에서도 구현·예산·시드 조건을 맞춰 확인해야 합니다. 성능 차이를 안정적으로 판단하려면 평균뿐 아니라 시드 런의 변동과 적절한 비교 방법을 기록합니다.
