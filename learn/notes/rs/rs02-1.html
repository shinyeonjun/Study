RS02·1

검색어를 만들고 연구 원문까지 찾기

검색 결과에서 제목을 찾은 뒤, 적합한 근거가 있는 논문과 자료를 따라갑니다.

이 장을 읽고 나면

  • 대상·조건·결과로 나눠 검색어를 만든다.
  • 출판 기록과 원문, 관련 연구를 연결한다.
  • 읽은 원문의 위치와 인용한 사실의 범위를 남긴다.

질문에서 검색어 골라내기

“강화학습 논문의 결과가 왜 달라지는가?”는 넓은 질문입니다. 심층 강화학습을 대상으로, 난수 시드와 알고리즘 구현을 조건으로, 평가 변동과 재현성을 결과로 잡습니다. 영어로 deep reinforcement learning, random seeds, reproducibility를 묶어 검색할 수 있습니다. 결과가 많으면 환경이나 알고리즘을 지정합니다. 너무 적으면 동의어를 쓰거나 조건을 덜어 냅니다.

실제 비교 조건이 필요하면 원 논문의 방법과 실험을 찾습니다. 용어 정의는 공식 기술 문서나 교과서에 있는 정의를 찾습니다. 리뷰나 강의의 참고 문헌은 원문을 찾는 단서입니다.

검색 목록에서 본문으로

사례는 Henderson 외의 Deep Reinforcement Learning that Matters입니다. 저자와 제목이 맞는지 확인하고, AAAI 출판 기록과 arXiv v3의 원문을 각각 엽니다. 결과가 나온 절이나 표 번호도 메모합니다.

방법 절에서 이전 구현의 인용을 찾아 원래 논문이나 공식 자료에 도달할 수 있습니다. 반대로 후속 논문이 이 연구를 어떻게 인용했는지도 살펴봅니다. 이름이 같은 알고리즘이라도 다시 쓴 환경과 평가 규칙이 다르면 결과를 직접 비교하기 어렵습니다.

주장에 근거의 주소를 붙이기

“시드가 중요하다”는 요약 옆에 실제 어느 판본에서 어떤 통계량을 확인했는지 적습니다. 제목, 저자, 발표처와 식별자, 판본, 절·표·그림 번호를 남기면 주장에 쓰인 수치를 다시 확인하기 쉽습니다. 원문의 직접 인용은 표시하고, 자기 설명은 그 문장과 구분합니다.

실행 예제

study = {
    "short_name": "Henderson et al.",
    "used_version": "1709.06560v3",
    "evidence": ["Methodology", "Table 1"],
}
print("source:", study["short_name"], study["used_version"])
print("evidence:", " / ".join(study["evidence"]))
print("version URL:", "https://arxiv.org/abs/" + study["used_version"])

실행 결과

source: Henderson et al. 1709.06560v3
evidence: Methodology / Table 1
version URL: https://arxiv.org/abs/1709.06560v3

코드는 이미 확인한 서지 기록을 출력합니다. 표에서 가져온 근거는 출력의 URL을 열어 해당 판본의 표와 캡션을 대조합니다.
