RS14·1

재실행 조건을 기록하고 입력과 결과를 따로 검사하기

같은 이름의 CSV라도 받은 날짜에 따라 값이 달라질 수 있습니다. 자료, 코드, 실행 순서, 허용 오차를 준비해 다른 날 이어서 해도 어느 지점부터 확인할지 알 수 있게 만듭니다.

이 장을 읽고 나면

  • 실행 명세에 입력·환경·명령·산출물 조건을 기록한다.
  • 바이트 동일성과 수치 결과 일치 검사를 각각 실시한다.
  • 재실행이 실패한 단계와 관측값을 남긴다.

다시 실행하는 사람이 출발할 조건을 남긴다

같은 고정 자료와 분석 단계에서 같은 수치가 나오는지 확인하는 일을 계산 재현이라고 부릅니다. 같은 질문을 새 장비·새 관측으로 조사하는 연구는 새 자료가 주는 증거까지 따로 다룹니다. 이번 장에서는 이미 수록한 마우나로아 실습의 CSV를 가지고, 다른 사람이 입력과 계산 결과를 확인할 수 있는 최소 기록을 씁니다.

자료출처 문서, 1990–2019년 범위, 파일 이름, 기대 SHA-256

무작위 표본을 쓰는 연구라면 난수의 시드와 생성 방법, 그룹 분할 방법도 여기에 적습니다. 새 환경에서 패키지가 필요하면 이름과 검증한 버전, 설치 순서를 남깁니다. 하드웨어가 수치나 속도에 영향을 주는 비교는 해당 조건도 기록해야 의미가 있습니다.

어떤 파일을 읽었는가와 숫자가 같은가

SHA-256은 받은 바이트 내용에서 64개의 16진수 문자로 된 요약값을 만듭니다. 이번 테스트는 같은 스냅샷을 사용해야 하므로 그 값이 기대값과 같은지 확인합니다. 줄바꿈이나 인코딩만 달라져도 요약값이 달라질 수 있습니다. 논문에서 허용한 입력이 ‘숫자 표가 같음’이라면 파일 검사와 별개로, 파싱해 열 이름, 키, 값의 동치성을 비교할 기준을 마련합니다.

정수 행 수, 열 이름, 고정된 파일의 해시처럼 정확히 일치해야 할 것은 직접 비교합니다. 부동소수점으로 얻은 결과는 입력·알고리즘의 정밀도에 따라 허용 오차를 정합니다. Python의 math.isclose(a,b)는 차이가 max(rel_tol·max(|a|,|b|), abs_tol) 이하인지 비교합니다. 0 근처에서는 상대 오차만으로 허용 범위가 거의 없어지므로 절대 오차의 근거를 따로 씁니다.

실패를 발견하는 순서대로 확인한다

파일을 못 찾은 실패와 파일을 열었지만 해시가 다른 실패는 서로 다른 단계입니다. 수치 허용치도 결과를 본 뒤 넓히면 미리 약속했던 검사 의미가 바뀝니다. 그날의 입력 검사 결과, 명령, 실행 환경과 상태를 남긴 뒤, 입력을 확인하지 못했다면 기존 결과를 덮어쓰지 않습니다.

정상 입력과 바이트 한 자리 변경을 검산한다

연평균 관측 CSV를 저장하고 예제를 그 파일의 작업 폴더에서 실행합니다. 파일을 수정하는 대신 메모리의 바이트만 바꿔 검사합니다.

from csv import DictReader
from decimal import Decimal
from hashlib import sha256
from io import StringIO
from math import isclose
from pathlib import Path

expected = "434137320f75320a6dbbd6cdb713fc11e85b8f8d5e257369c3b358bfd27e10f4"
original = Path("annual_co2.csv").read_bytes()
def digest(data):
    return sha256(data).hexdigest()

def verify(data):
    if digest(data) != expected:
        raise ValueError("입력 SHA-256 불일치")
    reader = DictReader(StringIO(data.decode("utf-8")))
    if reader.fieldnames != ["year","mean_ppm","uncertainty_ppm"]:
        raise ValueError("열 이름 불일치")
    rows = list(reader)
    if [int(row["year"]) for row in rows] != list(range(1990,2020)):
        raise ValueError("연도 키 불일치")
    values = [Decimal(row["mean_ppm"]) for row in rows]
    return len(values), values[-1]-values[0], sum(values)/len(values)

print(*verify(original))
try:
    verify(original.replace(b"354.45", b"354.46", 1))
except ValueError as problem:
    print(problem)
print(isclose(0,2e-10,rel_tol=1e-8,abs_tol=1e-9),
      isclose(0,2e-9,rel_tol=1e-8,abs_tol=1e-9))
