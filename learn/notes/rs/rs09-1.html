RS09·1

연구 질문에서 최종 결과까지 보고서 쓰기

무엇을 물었고 무엇을 바꿨는지 적은 뒤, 검증에서 고른 규칙을 따로 둔 2015–2019년 자료에 적용합니다. 같은 시간 범위와 MAE를 비교하고 주장 범위를 씁니다.

이 장을 읽고 나면

  • 질문·방법·결과·해석의 역할을 나눠 적는다.
  • 검증에서 정한 규칙을 최종 구간에 적용해 차이를 계산한다.
  • 수치의 대상과 불확실성의 범위를 보고한다.

질문과 평가 대상을 먼저 붙이기

이 보고서의 질문은 “마우나로아 연평균 CO₂를 직전 값에 기반해 1년 앞 예측할 때 최근 증가율을 더하면 직전 값 기준보다 오차가 작은가?”입니다. 자료는 NOAA/GML과 Scripps의 실습 CSV 1990–2019년입니다. 현재 보관본을 사용한 시간순 평가이고 실제 당시 자료 공개 환경을 재현하지는 않습니다.

방법에는 각 연도 직전까지의 관측만 사용했다고 씁니다. 검증 연도 2010–2014에 변화율 기간 2년과 5년을 비교해 k=5를 선택했습니다. 최종 평가는 그 규칙과 기준을 2015–2019년에 같은 방법으로 적용합니다.

두 지표와 차이를 함께 보고

다섯 최종 연도의 평균 절대오차는 기준에서 2.5680 ppm, 선택한 5년 변화율을 더한 규칙에서 0.5056 ppm입니다. 절대 감소는 2.0624 ppm입니다. 기준 MAE를 분모로 둔 상대 감소는 약 80.3%입니다. 상대 감소만 쓰면 오차의 물리적 단위와 기준을 알기 어려우므로 세 값 중 필요한 것을 함께 표기합니다.

이 차이는 다섯 확인 연도의 관측된 요약입니다. 검증 기간의 지표와 혼용하지 않습니다. 인접 연도에는 시간 의존성이 있을 수 있고 표본이 적으므로 독립 표본의 간단한 신뢰구간을 이 수치에 붙이지 않았습니다.

결과가 다시 나오는 과정

예제는 저장소의 최상위 폴더에서 실행합니다. 실습에 사용하는 30개 연도의 CSV와 출처와 변환 기록을 함께 확인할 수 있습니다.

실행 예제

import csv
from decimal import Decimal
from pathlib import Path

source = Path("learn/labs/mauna-loa/annual_co2.csv")
with source.open(encoding="utf-8", newline="") as stream:
    records = list(csv.DictReader(stream))
series = {int(row["year"]): Decimal(row["mean_ppm"]) for row in records}
assert len(records) == len(series) == 30 and sorted(series) == list(range(1990, 2020))

def forecast(year, k):
    latest = series[year - 1]
    if k == 0:
        return latest
    growth = (latest - series[year - 1 - k]) / k
    return latest + growth

def errors(start, stop, k):
    return [abs(forecast(year, k) - series[year]) for year in range(start, stop)]

def avg(values):
    return sum(values) / len(values)

baseline = avg(errors(2015, 2020, 0))
chosen = avg(errors(2015, 2020, 5))
change = baseline - chosen
print(f"held-out n={len(range(2015, 2020))}")
print(f"baseline={baseline:.4f}, chosen={chosen:.4f} ppm")
print(f"MAE decrease={change:.4f} ppm")
print(f"relative to baseline={100 * change / baseline:.1f}%")

실행 결과

held-out n=5
baseline=2.5680, chosen=0.5056 ppm
MAE decrease=2.0624 ppm
relative to baseline=80.3%

이 예제를 report_mauna_loa.py라는 파일에 복사했다면 저장소 최상위 폴더에서 python report_mauna_loa.py로 실행합니다. 여기서는 표준 라이브러리만 사용했고 난수는 없습니다. 입력의 판본, 실행에 쓴 Python과 기대 결과는 위 코드와 함께 기록합니다.

보고서 한 문단으로 정리

보고 예

NOAA/GML·Scripps 마우나로아 연평균의 고정 사본으로 1년 앞 예측을 평가했다. 2010–2014년 검증에서 5년 변화율 규칙을 고정하고, 2015–2019년의 다섯 해에서 직전값 기준과 비교했다. 기준 MAE 2.5680 ppm과 후보 0.5056 ppm의 차이는 2.0624 ppm이었다. 한 지점의 현재 보관 연평균을 사용한 기술적 비교이며 새로운 기간·다른 지점에 곧바로 적용할 근거는 없다.

결과는 계산해 관찰한 사실이고, 해석은 그 결과가 질문에 어떻게 답하는지 설명하는 일입니다. 다음 장에서 가장 오차가 큰 해와 후속 실험을 구체적으로 정합니다.
