RS04·1

같은 입력과 실행을 찾을 기록 만들기

공개 CSV를 몇 달 뒤에도 같은 조건으로 분석할 수 있도록 원자료의 판본, 변환 내용, 실행 환경과 출력 검산값을 묶습니다.

이 장을 읽고 나면

  • 입력 판본과 저장소의 변환 기록을 구분한다.
  • 자료를 같은지 비교할 해시의 범위를 설명한다.
  • 환경·명령·작업 폴더·출력과 빠른 검산값을 기록한다.

다시 실행하려면 무엇이 같은가?

여기서는 이미 저장소에 포함된 NOAA GML과 Scripps의 마우나로아 연평균 CO₂ 자료를 씁니다. 실습 CSV는 자료 제공자의 2026년 10월 9일 생성본에서 1990–2019년과 세 열을 옮긴 파일입니다. 공개 원자료는 품질 관리로 바뀔 수 있습니다. 현재 공식 파일과 이 실습 입력의 버전은 각각 적습니다.

같은 분석이 가능한 조건에는 실제 사용한 코드, Python 및 의존 패키지 버전, 설정값, 실행 명령과 작업 폴더가 들어갑니다. 코드를 수정한 뒤에는 어떤 버전에서 실행했는지 남깁니다. 난수는 사용하는 경우 시드와 생성 방식을 기록합니다.

같은 입력이라고 판단할 검사

판본과 파일 이름이 같아 보여도 실제 값이 달라질 수 있습니다. 파일 내용의 해시를 남겨 나중에 계산한 해시와 대조할 수 있습니다. 아래 코드는 텍스트를 UTF-8로 읽어 줄바꿈을 LF로 정리한 뒤 SHA-256을 계산합니다. 이 방식에서는 줄바꿈 차이를 무시합니다. 원래 바이트까지 똑같아야 하면 read_bytes()로 해시하고 계산 규칙도 기록합니다.

해시는 값이 과학적으로 타당한지 판정하지 않습니다. 행 수, 열과 단위, 연도 중복·누락, 앞뒤 몇 값을 함께 검사합니다.

입력 요약과 값 확인을 실행

예제는 저장소의 최상위 폴더에서 실행합니다. 실습에 사용하는 30개 연도의 CSV와 출처와 변환 기록을 함께 확인할 수 있습니다.

실행 예제

import csv
from decimal import Decimal
from hashlib import sha256
from pathlib import Path

source = Path("learn/labs/mauna-loa/annual_co2.csv")
text = source.read_text(encoding="utf-8")
reader = csv.DictReader(text.splitlines())
assert reader.fieldnames == ["year", "mean_ppm", "uncertainty_ppm"]
rows = list(reader)
years = [int(row["year"]) for row in rows]
assert years == list(range(1990, 2020))
for row in rows:
    co2 = Decimal(row["mean_ppm"])
    uncertainty = Decimal(row["uncertainty_ppm"])
    assert co2.is_finite() and co2 > 0
    assert uncertainty.is_finite() and uncertainty >= 0
print("rows and range:", len(rows), years[0], years[-1])
print("endpoints ppm:", rows[0]["mean_ppm"], rows[-1]["mean_ppm"])
print("sha256 after newline normalization:", sha256(text.encode("utf-8")).hexdigest())

실행 결과

rows and range: 30 1990 2019
endpoints ppm: 354.45 411.65
sha256 after newline normalization: 434137320f75320a6dbbd6cdb713fc11e85b8f8d5e257369c3b358bfd27e10f4

줄바꿈을 정규화하는 규칙이 포함돼 있습니다. 실행 기록에는 이 규칙, 파일의 위치, 명령의 Python 버전, 행 수와 결과를 둡니다. 이 예제는 파일을 읽고 stdout에 출력합니다. 그림이나 CSV가 생기는 다른 실행은 생성될 출력의 위치까지 적습니다.

실행 기록에서 환경과 자료를 함께 관리

입력 자료의 재배포 조건도 확인합니다. 허용된 사본을 공유할 수 없다면 팀이 접근할 수 있는 위치와 판본을 남깁니다. 환경 버전만 같아도 입력을 모르거나 잘못된 작업 폴더에서 시작하면 재실행이 실패할 수 있습니다. Git과 실행 기록, 가상환경과 패키지의 내용을 연결합니다.
