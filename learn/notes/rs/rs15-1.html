RS15·1

공개 회귀 결과를 재계산하고 한 점에 대한 민감도를 확인하기

기울기와 상관이 거의 같은 네 표가 있습니다. 원자료를 그리면 모양이 서로 다릅니다. 먼저 공개 결과를 숫자로 재계산하고, 어떤 점이 기울기를 결정하는지 계획한 한 가지 변경으로 확인합니다.

이 장을 읽고 나면

  • 재현할 결과와 허용 오차를 사전에 적는다.
  • 중심화 합으로 절편·기울기·상관을 재계산한다.
  • 한 관측 제거에서 식별 불가를 증명하고 결론의 범위를 제한한다.

재현할 주장을 실행 전에 한 줄로 적는다

Anscombe가 제시한 네 자료의 기울기와 Pearson 상관을 재계산합니다. 같은 11행을 사용하는 원표를 정하고 ‘기울기는 소수 둘째 자리까지 .50, 상관은 .82가 되는가’를 먼저 확인합니다. 더 엄격하게 비교하려면 같은 원표에서 아래 여섯 자리 목표와 비교합니다. 프로그램끼리는 반올림하기 전 수치의 차이를 예컨대 5×10⁻⁷ 이하로 두되, 원표의 측정 정밀도와 이 검사 정밀도를 구별합니다.

설명할 민감도 변화는 하나입니다. IV에서 x=19인 한 행만 제외합니다. 예상은 나머지 x가 모두 8이 되어 기울기를 정하지 못한다는 것입니다. 원 논문도 그 점의 역할을 다루므로, 여기서는 계산 재현과 원표에서의 민감도 분석을 구분해 기록합니다.

열의 평균을 뺀 합계로 회귀를 계산한다

Sxx=∑(xᵢ−x̄)², Sxy=∑(xᵢ−x̄)(yᵢ−ȳ), Syy=∑(yᵢ−ȳ)²입니다. 절편이 있는 최소제곱에서 b=Sxy/Sxx, a=ȳ−b·x̄입니다. 두 제곱합이 모두 양수이면 상관 r=Sxy/√(Sxx Syy)를 얻습니다. 분모가 0인 경우에는 계산을 멈추고, 값이 정의될 조건부터 확인합니다.

x가 같으면 기울기를 바꿔도 같은 적합이 가능하다

IV의 (19,12.50)을 제외한 10개의 x는 모두 8이고 y의 평균은 7.001입니다. 원래는 두 x 수준의 평균을 잇는 기울기 (12.50−7.001)/(19−8)=5499/11000을 확인할 수 있습니다. 삭제 뒤 모든 예측값은 a+8b 한 숫자입니다. 이 숫자를 7.001로 만들면 어느 b에서도 같은 오차를 냅니다. 이때 기울기를 0으로 정하는 것은 절편만 있는 다른 모형을 택한 것입니다. 자료만으로 기울기 0을 확인한 결론으로 쓰지 않습니다.

표의 네 계산과 계획한 변경을 실행한다

from math import sqrt
from statistics import mean

x = [10,8,13,9,11,14,6,4,12,7,5]
late = [8,8,8,8,8,8,8,19,8,8,8]
values = [[8.04,6.95,7.58,8.81,8.33,9.96,7.24,4.26,10.84,4.82,5.68],[9.14,8.14,8.74,8.77,9.26,8.1,6.13,3.1,9.13,7.26,4.74],[7.46,6.77,12.74,7.11,7.81,8.84,6.08,5.39,8.15,6.42,5.73],[6.58,5.76,7.71,8.84,8.47,7.04,5.25,12.5,5.56,7.91,6.89]]
def summarize(x,y):
    mx,my = mean(x),mean(y)
    dx,dy = [a-mx for a in x],[b-my for b in y]
    xx,yy = sum(a*a for a in dx),sum(b*b for b in dy)
    xy = sum(a*b for a,b in zip(dx,dy))
    if xx == 0:
        return xx,None,None,None
    slope = xy/xx
    return xx,my-slope*mx,slope,xy/sqrt(xx*yy) if yy else None

for label,predictor,y in zip(("I","II","III","IV"),(x,x,x,late),values):
    xx, intercept, slope, r = summarize(predictor,y)
    print(label, xx, f"{intercept:.6f} {slope:.6f} {r:.6f}")
remaining = [(a,b) for a,b in zip(late,values[3]) if a!=19]
new_x,new_y = map(list,zip(*remaining))
print(len(remaining), mean(new_y), summarize(new_x,new_y)[0])
assert summarize(new_x,new_y)[2] is None
