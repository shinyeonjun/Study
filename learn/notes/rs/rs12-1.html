RS12·1

반복 측정에서 독립 실험 단위와 짝을 정하기

장비 네 대를 세 번씩 재면 기록은 열두 개입니다. 장비마다 일정한 특성이 있어서 세 값이 함께 움직일 수 있습니다. 표준오차에 무엇을 독립으로 세어야 하는지 묻고, 같은 장비를 짝으로 비교합니다.

이 장을 읽고 나면

  • 관측·배정·분석 단위를 각각 적는다.
  • 반복 측정을 장비별 비교로 모아 표준오차를 구한다.
  • ablation 한 건의 비교 조건, 산출 결과, 실패 처리 규칙을 써 본다.

한 행이 하나의 독립 실험이라는 가정부터 점검한다

컴퓨터 네 대에서 기준 방법과 대안 방법의 지연을 재고 싶습니다. 같은 장비에서 같은 과제를 두 방법에 모두 처리하게 합니다. 과제별 ‘기준 지연−대안 지연’을 한 줄에 쓴다면 관측 단위는 장비와 과제의 조합입니다. 장비마다 과제 세 개가 있어 열두 차이가 기록됩니다.

이 실험에서는 장비가 서로 독립적으로 뽑힌다는 가정 아래, 장비를 독립 분석 단위로 둡니다. 방법을 어느 순서로 돌릴지는 장비와 과제 안에서 미리 무작위화하거나 균형을 맞춥니다. 예를 들어 앞 실행이 뒤 실행의 캐시를 데운다면 순서가 효과 추정에 들어옵니다. 그런 영향이 사라지도록 초기화하거나, 제거하기 어렵다는 사실을 기록하고 설계에 반영해야 합니다.

한 장비의 모든 과제에 같은 방법 하나만 무작위 배정하는 다른 설계에서는 장비가 배정 단위입니다. 그때 검정에서 표지를 섞는다면, 한 장비의 일부 과제만 다른 방법으로 옮길 수 없습니다. 배정됐던 장비 단위에 맞춰야 합니다.

조건이 같은 두 실행의 차이부터 만든다

장비세 과제의 지연 차이 (ms)장비별 차이 평균
A2, 3, 43
B−1, 0, 10
C1, 2, 32
D−2, −1, 0−1

장비들의 평균 차이는 (3+0+2−1)/4=1ms입니다. 차이가 양수면 대안이 더 빠릅니다. 장비 평균의 차이들이 독립이고 같은 변동을 가진다고 두면, 표본분산은 [(3−1)²+(0−1)²+(2−1)²+(−1−1)²]/3=10/3입니다. 전체 평균 추정량의 표준오차 추정은 √[(10/3)/4]=√(5/6)≈0.9129ms입니다.

열두 과제 차이를 모두 독립이라고 계산하면 표준오차가 약 0.5365ms로 나옵니다. 이 예에서 장비 간의 차이와 장비 내부 반복을 하나로 섞으면 불확실성이 작게 보입니다. 장비별 행 수까지 다르면 두 계산의 평균이 달라질 수 있습니다. 장비에 같은 비중을 주려는지, 전체 실행 중 무작위 한 번에 해당하는 평균을 구하는지도 먼저 정합니다.

비교에서 바꾸는 부품 하나를 미리 적는다

제거 실험(ablation)이라면 전체 방법과 한 구성만 제거한 방법으로 어떤 주장을 검사할지 먼저 씁니다. 예를 들어 같은 빌드, 입력, 실행 제한 안에서 메모리 캐시를 켠 것과 끈 것의 장비별 평균 지연을 비교합니다. 실패 처리 규칙도 사전에 지정합니다. 한 방법이 어려운 과제에서만 자주 끝나지 않는다면 성공 실행의 평균만으로 전체 방법의 지연을 비교하기 어렵습니다. 완료율과 종료 기준, 사전에 정의한 지연 지표를 모두 기록합니다.

두 계산을 실행해 어떤 표본 수를 썼는지 확인한다

from math import sqrt
from statistics import mean, stdev

devices = [[2,3,4],[-1,0,1],[1,2,3],[-2,-1,0]]
group = [mean(values) for values in devices]
rows = [x for values in devices for x in values]
for values in (group, rows):
    print(len(values), mean(values), f"{stdev(values)/sqrt(len(values)):.6f}")
assert group == [3,0,2,-1]
