RS12·2

짝 비교의 검정력과 자료를 보고 멈추는 규칙

차이가 있어도 장비가 너무 적으면 놓칠 수 있습니다. 반대로 매번 결과를 보고 유의해질 때 끝내면 사실 차이가 없어도 유의하다고 보고할 기회가 늘어납니다. 독립 짝 수와 중단 규칙을 계산에 넣습니다.

이 장을 읽고 나면

  • 유의수준과 검정력을 서로 다른 가정에서 계산한다.
  • 정규 짝 차이에서 양측 검정력을 도출해 계획 표본 수를 구한다.
  • 중간 분석을 추가할 때 귀무 오탐률이 달라지는 구조를 보여 준다.

차이가 있는 세계에서 검정이 발견하는 비율

장비 하나마다 기준과 대안의 차이 D를 한 수로 정리합니다. 독립 장비의 차이가 정규분포 N(δ,σ²)를 따르고 σ를 알고 있다고 가정합니다. δ는 평균 차이입니다. δ=0일 때 검정이 잘못 기각할 확률을 유의수준 α로 정합니다. 우리가 검출하기 원하는 차이 δ≠0일 때 기각할 확률이 검정력입니다. 최소로 중요한 효과를 단위와 함께 정해야 검정력의 목표가 정해집니다.

귀무에서 Z=√n D̄/σ는 표준정규입니다. z=Φ⁻¹(1−α/2)로 두어 |Z|≥z일 때 기각하면 양쪽 꼬리 합이 α입니다. 실제 차이가 δ라면 Z의 평균이 a=√n δ/σ로 이동하고 분산은 1 그대로입니다.

검정력 = 1−Φ(z−a) + Φ(−z−a)

독립인 짝 수를 계획한다

목표 검정력을 0.80, 유의수준을 0.05, 검출할 표준화 차이 δ/σ를 0.5로 가정합니다. 양의 δ에서 오른쪽 꼬리만으로 목표를 달성하려면 n≥[(z+Φ⁻¹(.80))/.5]²≈31.3955가 충분합니다. 실제 두 꼬리를 계산하면 31쌍의 검정력은 약 0.795008, 32쌍은 0.807430입니다. a>0에서 검정력을 a로 미분하면 φ(z−a)−φ(z+a)≥0입니다. |z−a|≤z+a이고 표준정규 밀도는 0에서 멀수록 줄어들기 때문입니다. 따라서 이 설정에서 최소 32쌍입니다. σ도 자료에서 추정하면 이 식이 알려진 분산의 정확 계산이라는 가정이 사라집니다. 대응 t 검정에 맞춰 계획하거나 불확실한 분산과 탈락률에 대한 민감도를 같이 봅니다.

중간 결과를 한 번 더 쓰면 귀무 확률도 다시 계산한다

귀무에서 첫 n쌍과 나중 n쌍의 평균을 각각 표준화해 서로 독립인 표준정규 Z₁, W라고 둡니다. 전체 2n쌍의 통계량은 Z₂=(Z₁+W)/√2입니다. 따라서 두 검정은 자료를 공유하고 같은 현상을 일부 봅니다. 한 번이라도 기각할 확률은 1에서 두 통계량이 모두 (−z,z) 안에 있을 확률을 뺀 값입니다. Z₁=u에 조건을 걸면 다음 통계량이 범위 안에 있을 W의 구간은 (−√2z−u, √2z−u)입니다. 이를 −z에서 z까지 표준정규 밀도로 평균하면 오탐률을 구할 수 있습니다.

아래 적분 근사에서는 한 번 보는 .05 기준을 두 번 그대로 쓰면 전체 오탐률이 약 .083118임을 얻습니다. 연구 계획에 주 지표, 독립 짝 수, 정해진 분석 시점, 그 시점에서 적용할 임계값 또는 자료를 더 모으는 기준을 같이 씁니다. 임의로 계속 살펴본 결과를 고정 n의 해석으로 보고할 수 없습니다.

정규분포의 양측 꼬리와 중간 분석을 수치로 확인한다

from math import sqrt
from statistics import NormalDist

normal = NormalDist()
z = normal.inv_cdf(.975)
def power(n):
    a = .5*sqrt(n)
    return 1-normal.cdf(z-a)+normal.cdf(-z-a)

def both_inside(u):
    edge = sqrt(2)*z
    return normal.pdf(u)*(normal.cdf(edge-u)-normal.cdf(-edge-u))

# [-z,z]에서 중점 수치적분
n_steps = 20000
width = 2*z/n_steps
accept_both = width*sum(both_inside(-z+(i+.5)*width)
                        for i in range(n_steps))
print(f"{power(31):.6f} {power(32):.6f}")
print(f"{1-accept_both:.6f}")
assert power(31) < .8 < power(32)
