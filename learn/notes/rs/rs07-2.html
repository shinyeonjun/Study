연구 기초 · RS07 작은 재현

RS07·2

한 조건을 바꾸고 재현 실패를 분류하기

2010–2014년 검증의 예측 날짜와 평가식을 고정합니다. 최근 증가량을 계산하는 간격만 2년에서 5년으로 바꾼 뒤 예상과 다른 결과를 어디부터 조사할지 정합니다.

이 장을 읽고 나면

  • 하나의 요인만 다르게 설정해 비교한다.
  • 똑같은 검증 구간에서 두 MAE와 차이를 계산한다.
  • 실행·입력·측정 정의·통계 변동 문제를 구분한다.

유지할 조건과 바꿀 조건을 먼저 적기

질문은 “마우나로아 1년 앞 예측에서 최근 추세의 길이 k만 바꾸면 검증에서 오차가 어떻게 달라지는가?”입니다. 예측 연도가 t일 때 최근 k년의 평균 증가율은 (y[t−1]−y[t−1−k])/k입니다. 2010년의 k=5는 2009년과 2004년 값을 써서 (387.64−377.70)/5=1.988 ppm/년입니다.

입력 파일, 예측 지평, 검증 날짜 2010~2014, 오차 MAE는 고정합니다. 후보는 2년과 5년 두 개입니다. 2015~2019 자료는 최종 평가 쪽에 둡니다. 후보를 검증한 뒤 결과를 보고 평가 자료를 바꾸지 않습니다.

검증 오차를 비교하고 후보를 정한다

예제는 저장소의 최상위 폴더에서 실행합니다. 실습에 사용하는 30개 연도의 CSV와 출처와 변환 기록을 함께 확인할 수 있습니다.

실행 예제

import csv
from decimal import Decimal
from pathlib import Path

source = Path("learn/labs/mauna-loa/annual_co2.csv")
with source.open(encoding="utf-8", newline="") as stream:
    records = list(csv.DictReader(stream))
series = {int(row["year"]): Decimal(row["mean_ppm"]) for row in records}
assert len(records) == len(series) == 30 and sorted(series) == list(range(1990, 2020))

def forecast(year, k):
    latest = series[year - 1]
    if k == 0:
        return latest
    growth = (latest - series[year - 1 - k]) / k
    return latest + growth

def errors(start, stop, k):
    return [abs(forecast(year, k) - series[year]) for year in range(start, stop)]

def avg(values):
    return sum(values) / len(values)

choices = {}
for k in (2, 5):
    e = errors(2010, 2015, k)
    choices[k] = avg(e)
    print(f"k={k}: MAE={choices[k]:.4f} ppm")
chosen = min(choices, key=choices.get)
print("chosen on validation:", chosen)
print(f"validation change (5 - 2): {choices[5] - choices[2]:.4f} ppm")

실행 결과

k=2: MAE=0.4430 ppm
k=5: MAE=0.3576 ppm
chosen on validation: 5
validation change (5 - 2): -0.0854 ppm

정해 둔 후보 둘 중 이 검증 구간에서 더 작은 값을 얻은 k=5를 다음 평가에 사용합니다. 두 설정의 차이 0.0854 ppm은 다섯 연도의 검증 결과입니다. 모든 맥락에서 다섯 해 간격이 최선이라는 규칙을 얻은 것은 아닙니다.

불일치에서 먼저 구분할 것

예제가 끝나지 않는 일과 예제가 끝나 다른 수치가 나온 일은 다르게 진단합니다. 입력 참조가 사라진 경우에는 자료 확보를 확인합니다. 숫자가 조금 다르면 열의 단위와 반올림 순서, 허용 오차를 확인합니다. 같은 조건의 무작위 실험에서는 시드의 재현과 반복 간 변동을 구분합니다.

예로 CSV를 바꿔 2013년 행이 빠졌다면 검증 MAE를 네 행으로 비교하기 전에 누락으로 기록합니다. 입력과 규칙이 같은 상태에서도 예측값이 틀리면 2010년의 하나를 손으로 계산해 기호와 인덱스를 확인합니다.

실패와 개선을 함께 기록

실행 로그에는 예상, 실제, 가장 작은 재현 예, 바뀐 조건과 확인한 자료를 적습니다. “안 됨”만 남기면 다음 사람이 다시 어디서 막힐지 모릅니다. 원인을 아직 확인하지 못했으면 가능성을 확정 사실과 구분합니다. 예제의 범위를 더 크게 넓힐 때는 시간과 메모리도 따로 봅니다.
