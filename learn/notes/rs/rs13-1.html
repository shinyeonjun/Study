연구하고 설명하는 방법 · RS13 연구 결과의 불확실성과 증거 합성

RS13·1

역분산으로 연구 결과를 합치고 이질성을 확인하기

세 연구가 같은 처리를 비교했다고 해도 추정값의 정밀도와 결과가 다를 수 있습니다. 공통 효과가 있다는 모형에서 가중평균을 도출하고, 그 모형과 맞지 않는 경우를 확인합니다.

이 장을 읽고 나면

  • 효과 추정치의 표준오차에서 역분산 가중치를 구한다.
  • 반복 연구의 독립성을 이용한 결합 분산을 유도한다.
  • 이질성·겹치는 표본·보고 누락이 해석에 주는 영향을 구분한다.

어떤 효과와 어떤 방향을 평균하는가

세 연구의 결과가 모두 기준과 대안 사이의 평균 지연 차이이고 양수일 때 시간이 줄었다고 합시다. 결과 정의와 단위가 같을 때 연구의 효과 추정치 yᵢ와 표준오차 SEᵢ를 모읍니다. 표준오차는 효과 추정량이 반복해서 흔들릴 정도이며, 한 연구의 원래 관측값을 나열한 표준편차와 다릅니다.

공통 효과 정규모형에서 가중평균을 도출한다

서로 독립인 추정치들이 같은 θ를 평균으로 하며, 각각 정규이고 알려진 분산 vᵢ=SEᵢ²를 가진다고 둡니다. 그때 음의 로그우도에서 θ에 관계있는 항은 ∑ᵢ(yᵢ−θ)²/(2vᵢ)입니다. 미분을 0으로 놓으면 θ̂=∑ᵢwᵢyᵢ/∑ᵢwᵢ이고 wᵢ=1/vᵢ입니다. 연구 B는 분산이 A의 1/4이라 비중이 네 배입니다.

정규화한 가중치를 aᵢ=wᵢ/∑w라고 쓰면 독립 가정에서 Var(θ̂)=∑aᵢ²vᵢ=1/∑wᵢ입니다. 이번 예의 결합 효과는 7/6, 표준오차는 1/√6이고, 정규 95% 구간은 약 [0.3665,1.9668]ms입니다. 개별 연구가 낸 표준오차를 알려진 수처럼 사용할 때, 실제로는 표준오차도 추정됐을 수 있으므로 이 정규 구간은 근사입니다.

공통 효과와 맞지 않는 정도를 계산한다

잔차의 가중제곱합 Q=∑wᵢ(yᵢ−θ̂)²은 합치기 전 결과들이 결합값에서 얼마나 떨어졌는지 잽니다. 독립·알려진 분산의 정규 공통 효과 모형 아래, 각 효과에서 θ를 빼고 표준오차로 나눈 벡터는 표준정규입니다. θ를 맞추는 자유도 하나를 투영으로 제거하고 남은 제곱합이므로 Q는 자유도 k−1의 카이제곱입니다.

이 예에서 Q=29/6입니다. 흔히 쓰는 이질성 지표는 Q>0에서 I²=max(0,(Q−(k−1))/Q)이며 여기서는 17/29입니다. Q와 I²는 자료가 적으면 정밀하지 않습니다. 두 수는 결과 정의가 다른 연구를 합쳐도 될지 판단하는 근거 전부를 대체하지 않습니다. C를 빼면 결합값은 4/5입니다. 한 결과를 사후 제거하면 사실상 질문에 포함된 범위가 바뀌므로, 원래 범위의 결과와 별개로 민감도 계산임을 밝힙니다.

표본이 겹치거나 결과가 공개되지 않았다면

같은 표본을 쓴 두 비교를 별개의 독립 연구처럼 넣으면 오차가 함께 움직입니다. 그때 분산에는 가중치 곱과 공분산 항을 포함해야 합니다. 예를 들어 A의 추정치를 두 번 넣고 각 가중치 1인 줄로 처리하면, 독립으로 가정한 분산은 1/7이지만 A가 완전히 중복인 실제 계산은 9/49입니다. 이 차이를 없애려면 연구 식별자와 겹치는 결과를 먼저 파악해야 합니다. 작은 효과나 실패한 실험이 보고되지 않은 문제는 가중치와 잔차만으로 진단할 수 없으므로, 포함 기준 및 확인한 누락을 따로 기록합니다.

from fractions import Fraction as F
from math import exp, sqrt

values = [0,1,3]
weights = [1,4,1]
total = sum(weights)
theta = F(sum(w*y for w,y in zip(weights,values)),total)
q = sum(w*(y-theta)**2 for w,y in zip(weights,values))
i2 = max(F(0),(q-2)/q)
se = sqrt(1/total)
print(theta, q, i2)
print(f"{se:.6f} {theta-1.959964*se:.6f} {theta+1.959964*se:.6f}")
print(f"{exp(-float(q)/2):.6f}", F(4,5))
print(F(1,7), F(2,7)**2 + F(4,7)**2/4 + F(1,7)**2)

0.089219 4/5

자유도 2에서 카이제곱 꼬리는 exp(−Q/2)이므로 위 코드의 0.089219가 나옵니다. 자유도가 달라지면 같은 지수식을 일반적으로 쓸 수 없습니다.
