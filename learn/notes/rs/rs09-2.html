RS09·2

가장 큰 오차·한계·다음 실험 적기

평균 오차가 낮았어도 모든 해가 비슷하게 정확했던 것은 아닙니다. 가장 크게 빗나간 해를 확인하고, 한계에서 다음 질문을 만드는 방법을 연습합니다.

이 장을 읽고 나면

  • 연도별 오차를 평균과 함께 보여 준다.
  • 관찰한 오차와 원인에 대한 추측을 구분한다.
  • 다음 실험과 검토 반영 기록을 작성한다.

평균을 큰 오류 사례와 함께 읽기

5년 변화율 규칙의 최종 MAE는 0.5056 ppm입니다. 연도별로 보면 2016년의 예측 403.192 ppm이 실제 404.41 ppm보다 1.218 ppm 낮았습니다. 예측−관측의 부호는 음수이고, MAE에 들어가는 절댓값은 양수입니다.

평균 감소를 보고하면서 어느 해에서 아직 크게 빗나갔는지도 적습니다. 2016년의 자료만 다시 적용해 규칙을 새로 고르면 최종 평가를 개발에 쓴 셈입니다. 더 살펴볼 사례로 표시하고 새 연구에서는 별도 확인 범위를 정합니다.

한계에서 다음 실험으로 이어가기

지금 자료는 한 관측소의 연간 요약으로 다섯 해를 평가했습니다. 2016년 오차가 큰 이유가 원자료에 나온 특정 사건 때문인지 결론낼 수 없습니다. 원인을 조사하려면 월별 관측과 측정 조건, 여러 관측소의 변화가 추가로 필요합니다.

후속 질문은 “다른 기간에 같은 규칙을 고정해도 기준보다 MAE가 낮은가?”로 정할 수 있습니다. 이미 본 2015~2019년은 고정 기록으로 두고 새로 지정한 기간을 사용합니다. 관측소·예측 지평·기준·지표·평가 시점에 사용할 수 있는 정보·예산을 먼저 적습니다.

실제 입력으로 연도별 오차를 재실행

예제는 저장소의 최상위 폴더에서 실행합니다. 실습에 사용하는 30개 연도의 CSV와 출처와 변환 기록을 함께 확인할 수 있습니다.

실행 예제

import csv
from decimal import Decimal
from pathlib import Path

source = Path("learn/labs/mauna-loa/annual_co2.csv")
with source.open(encoding="utf-8", newline="") as stream:
    records = list(csv.DictReader(stream))
series = {int(row["year"]): Decimal(row["mean_ppm"]) for row in records}
assert len(records) == len(series) == 30 and sorted(series) == list(range(1990, 2020))

def forecast(year, k):
    latest = series[year - 1]
    if k == 0:
        return latest
    growth = (latest - series[year - 1 - k]) / k
    return latest + growth

def errors(start, stop, k):
    return [abs(forecast(year, k) - series[year]) for year in range(start, stop)]

def avg(values):
    return sum(values) / len(values)

signed = {year: forecast(year, 5) - series[year] for year in range(2015, 2020)}
for year, error in signed.items():
    print(f"{year}: {error:+.3f} ppm")
largest_year = max(signed, key=lambda year: abs(signed[year]))
print(f"largest absolute: {largest_year}, {abs(signed[largest_year]):.3f} ppm")

실행 결과

2015: +0.034 ppm
2016: -1.218 ppm
2017: +0.162 ppm
2018: +0.580 ppm
2019: -0.534 ppm
largest absolute: 2016, 1.218 ppm

같은 코드로 새 범위를 평가할 때는 최종 규칙과 판본을 먼저 고정합니다. 시계열이 연속된 입력인지 확인하고 사용할 수 있는 과거 이력도 기록합니다.

검토를 받은 뒤의 기록

“단위가 무엇인가?”라는 검토는 표의 열과 캡션을 고쳐 답할 수 있습니다. “다른 지점에서도 개선되는가?”는 현재 자료만으로 답하기 어려우므로 적용 한계와 다음 실험으로 남깁니다. 어떤 증거로 문장을 바꿨는지와 아직 미확인인 항목을 기록합니다.

검토하는 사람에게 실행에 필요한 코드·판본·자료 출처·명령·기대 출력 위치를 함께 전달합니다. 직접 사용한 출처는 어떤 수치나 가정에 대응하는지 가리킵니다.
