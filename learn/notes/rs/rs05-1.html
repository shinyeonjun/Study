연구 기초 · RS05 비교의 타당성

RS05·1

같은 검증 조건에서 기준과 후보 비교하기

다음 해 CO₂ 연평균을 예측합니다. 지난 값 그대로 쓰는 기준과 최근 변화율을 한 번 더 더하는 후보를 같은 날짜와 지표에서 비교합니다.

이 장을 읽고 나면

  • 질문과 맞는 baseline을 정한다.
  • 연도순 개발·검증·최종 평가를 분리한다.
  • 같은 예측 날짜와 사용할 수 있는 정보만으로 MAE를 비교한다.

비교 전에 무엇을 예측할지 정하기

이 실습의 질문은 마우나로아 1년 앞 연평균을 예측할 때 최근 증가량을 더하는 규칙이 단순 기준보다 검증 오차가 작은가입니다. 미래에 사용할 수 없는 자료를 미리 보지 않습니다. 현재 CSV에 정리된 직전 연도의 연평균은 다음 해를 예측할 때 사용할 수 있다고 가정합니다. 실제 당시의 공개·정정 시점을 복원하는 실험은 아닙니다.

개발용 이력에서 방법을 작성하고, 2010–2014년의 같은 5개 예측으로 규칙을 검증합니다. 2015–2019년은 선택이 끝날 때까지 최종 평가용으로 둡니다. 한 시점에서 5년을 한번에 맞추는 문제가 아니라 매년 직전 해의 관측을 얻어 다음 1년을 예측하는 절차입니다.

간단한 기준과 공통 지표

baseline은 새 방법이 어떤 기준에서 얼마나 다른지 볼 기준 방법입니다. 이 비교의 기준은 직전 해 값입니다. 후보는 예측할 연도를 t라 하면 (y[t−1]−y[t−3])/2를 직전 해 값에 더합니다. 예로 2010년에는 2009년 387.64와 2007년 384.02를 사용해 2년간의 평균 연간 증가 1.81 ppm을 얻습니다.

두 규칙을 같은 연도에서 평가합니다. MAE는 해마다 예측값에서 실제값을 뺀 절댓값의 평균이며, 값이 작을수록 이 지표에서 오차가 작습니다. 단위는 관측과 같은 ppm입니다.

같은 다섯 연도에서 검증

예제는 저장소의 최상위 폴더에서 실행합니다. 실습에 사용하는 30개 연도의 CSV와 출처와 변환 기록을 함께 확인할 수 있습니다.

실행 예제

import csv
from decimal import Decimal
from pathlib import Path

source = Path("learn/labs/mauna-loa/annual_co2.csv")
with source.open(encoding="utf-8", newline="") as stream:
    records = list(csv.DictReader(stream))
series = {int(row["year"]): Decimal(row["mean_ppm"]) for row in records}
assert len(records) == len(series) == 30 and sorted(series) == list(range(1990, 2020))

def forecast(year, k):
    latest = series[year - 1]
    if k == 0:
        return latest
    growth = (latest - series[year - 1 - k]) / k
    return latest + growth

def errors(start, stop, k):
    return [abs(forecast(year, k) - series[year]) for year in range(start, stop)]

def avg(values):
    return sum(values) / len(values)

for k in (0, 2):
    mistakes = errors(2010, 2015, k)
    print(f"k={k}, n={len(mistakes)}, MAE={avg(mistakes):.4f} ppm")
    print(f"  2010 forecast={forecast(2010, k):.3f}, observed={series[2010]:.2f}")

실행 결과

k=0, n=5, MAE=2.2340 ppm
  2010 forecast=387.640, observed=390.10
k=2, n=5, MAE=0.4430 ppm
  2010 forecast=389.450, observed=390.10

후보의 검증 MAE가 2.2340−0.4430=1.7910 ppm 작습니다. 이 수치는 2010–2014년의 기술적 비교입니다. 같은 후보가 다른 기간이나 다른 관측소에서도 이득을 준다는 근거는 별도로 필요합니다.

기준을 유리하거나 불리하게 만들지 않기

두 방법의 예측 시점, 입력 공개 범위와 지표를 맞춥니다. 각 연도마다 이미 사용할 수 있는 과거 값은 두 방법에 모두 열어 둡니다. 출력에 맞춰 평가 기간을 바꾸면 비교의 의미도 달라집니다. 다음 장에서 정보가 뒤에서 앞으로 새는 경우와 예산 차이를 봅니다.
