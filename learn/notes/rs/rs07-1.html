RS07·1

공개 결과의 계산을 작은 범위에서 재현하기

마우나로아 연평균 CO₂ 공개값을 같은 범위로 읽고, 교재에 제시된 시작과 끝의 차이와 최대 인접 연도 차이를 다른 코드로 대조합니다.

이 장을 읽고 나면

  • 재현할 결과와 입력 버전, 일치 기준을 좁혀 적는다.
  • 실제 공개 CSV에서 29개 인접 차이를 검산한다.
  • 계산의 재현과 관측 자체의 반복, 다른 증가율 정의를 구분한다.

성공의 범위를 정하고 시작

시작 값 354.45 ppm과 끝 값 411.65 ppm의 차이를 구하는 작은 목표를 세웁니다. 자료는 DA07의 공개 자료 분석에 사용한 것과 같은 저장소 CSV입니다. 수집한 1990~2019년 30행, 차이를 구한 29쌍, 끝에서 시작을 뺀 57.20 ppm을 기대합니다.

원본 제공자의 자료 버전과 전처리를 기록합니다. 현재 공개본의 값이 달라지면 먼저 개정 여부를 확인한 뒤, 비교할 입력 범위를 정합니다. “공개 연구의 계산 일부를 확인했다”는 말에는 입력과 결과의 이름을 넣습니다.

인접 차이를 손으로 따라가기

2014년부터 2017년까지 일부분을 먼저 계산합니다. 2015년 401.01에서 2014년 398.81을 빼면 2.20 ppm입니다. 다음 쌍의 차이는 3.40 ppm입니다. 가장 큰 차이가 들어가는 쌍은 차이의 부호, 쌍의 연도 표기, 정렬 순서를 확인할 수 있는 작은 검산입니다.

중간 해가 이어지면 인접 차이의 합에서 내부 값이 한 번 빼고 한 번 더해져 끝−시작만 남습니다. 이 값이 일치해도 연도나 원래 입력을 잘 읽었는지는 따로 검사합니다.

공개 데이터의 일부 계산 실행

예제는 저장소의 최상위 폴더에서 실행합니다. 실습에 사용하는 30개 연도의 CSV와 출처와 변환 기록을 함께 확인할 수 있습니다.

실행 예제

import csv
from decimal import Decimal
from pathlib import Path

source = Path("learn/labs/mauna-loa/annual_co2.csv")
with source.open(encoding="utf-8", newline="") as stream:
    records = list(csv.DictReader(stream))
series = {int(row["year"]): Decimal(row["mean_ppm"]) for row in records}
assert len(records) == len(series) == 30 and sorted(series) == list(range(1990, 2020))

years = sorted(series)
changes = [(year, series[year] - series[year - 1]) for year in years[1:]]
delta = series[years[-1]] - series[years[0]]
assert sum(change for _, change in changes) == delta
largest_year, largest = max(changes, key=lambda row: row[1])
print("years / intervals:", len(years), len(changes))
print(f"end minus start: {delta:.2f} ppm")
print(f"mean adjacent change: {delta / len(changes):.2f} ppm/year")
print(f"largest: {largest_year-1}-{largest_year}, {largest:.2f} ppm")

실행 결과

years / intervals: 30 29
end minus start: 57.20 ppm
mean adjacent change: 1.97 ppm/year
largest: 2015-2016, 3.40 ppm

29년 간격의 평균 차이는 57.20÷29≈1.97입니다. 소수 둘째 자리로 표시한 결과를 교재와 대조합니다. NOAA가 별도로 발표하는 연 증가율은 계절 보정·연말 전후 월평균 등 다른 정의를 사용하므로 여기서 계산한 연평균 간 차이와 구별합니다.

재현 범위를 결과와 함께 기록

이 파일과 분석에 대해서는 독립적으로 작성한 코드의 요약값이 일치했습니다. 관측소 측정 장비를 다시 운영하거나 관측소를 바꿔 같은 결과가 나오는지 검증한 것은 아닙니다. 검증한 항목, 확인하지 않은 절차를 공개 결과에 적습니다.
