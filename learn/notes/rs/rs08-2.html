RS08·2

실험 횟수·장치 시간·비용의 예산 세우기

두 설정을 세 시드로 평가합니다. 설정별 본 실행과 탐색, 실패 재실행까지 계산해 보고 언제 점검하고 멈출지 정합니다.

이 장을 읽고 나면

  • 실행 횟수·경과시간·GPU 시간을 계산한다.
  • 탐색과 실패를 포함한 예산을 비교한다.
  • 실제 비용·저장 공간과 결과를 함께 남긴다.

곱셈에 포함할 실험을 적기

설정 두 개를 세 시드에서 각각 한 번 실행하면 6회입니다. 모두 GPU 한 대에서 20분을 사용하면 120 GPU-분, 즉 2 GPU-시간입니다. 20분 동안 두 대를 쓰면 장치 시간은 40 GPU-분이 됩니다. 장치 시간과 실제 경과 시간은 작업이 여러 대에서 얼마나 겹쳤는지에 따라 다릅니다.

학습에만 시간을 배정하면 평가와 실패 복구의 비용이 숨을 수 있습니다. 후보를 고르는 비용까지 같은 비교에 넣을지, 사전에 쓴 실험과 최종 실행을 구분할지 정합니다.

비용과 저장의 단위를 쓰기

교육용 가정으로 GPU 한 대의 시간당 값이 1,200원이라고 두면 본 실행의 계산 비용은 2,400원입니다. 실제 요금에서는 유휴 시간, 여러 장치, 저장 및 데이터 이동을 포함하는지 확인합니다. 학습 결과를 150 MiB씩 실행 6회마다 하나 보존하면 체크포인트만 900 MiB입니다. 임시 파일과 로그는 별도입니다.

잘 끝난 실행만 계산하면 실제 자원 소비가 작게 보입니다. 한도를 먼저 적고 어떤 비교를 끝낼지, 어떤 고장·초과에 중단할지 정합니다. 계획 단계에서 명시하는 비용과 수행 뒤 측정한 비용을 구분합니다.

계획된 예산을 코드로 검산

실행 예제

settings, seeds = 2, 3
minutes_per_run = 20
runs = settings * seeds
training = runs * minutes_per_run
search, retry = 40, 20
cap = training + search + retry
won_per_gpu_hour = 1200
print("runs:", runs)
print("training GPU-min:", training, "cap:", cap)
print(f"training / cap cost: {training/60*won_per_gpu_hour:.0f} / {cap/60*won_per_gpu_hour:.0f} won")
print("checkpoint MiB:", runs * 150)

실행 결과

runs: 6
training GPU-min: 120 cap: 180
training / cap cost: 2400 / 3600 won
checkpoint MiB: 900

시간과 요금은 계산을 위한 모의 값입니다. 마우나로아의 간단한 실습은 CPU에서 실행할 수 있습니다. 실험을 크게 확대하려면 실제 입력 크기와 장치를 먼저 기록합니다.

공정한 비교의 예산을 공개

시간 제한이 같은 비교와 환경 상호작용 수가 같은 비교는 다른 질문에 답합니다. 목표를 정한 뒤 예산의 단위와 바뀐 조건을 보고합니다. 실험 과정에서 시도를 추가했다면 적용 시점과 이유를 남깁니다. 동일 조건과 보고서의 결과 표가 연결되는 부분입니다.
