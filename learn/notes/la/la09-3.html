LA09·3

핵의 기저를 확장해 계수–영차원 정리 증명하기

입력을 두 번 측정하면 미지수가 몇 개 남을까요? 핵과 상의 기저를 함께 만들어, 자유도가 어디에 남는지 증명하고 해집합을 구합니다.

이 장을 읽고 나면

  • 핵과 상이 부분공간인 이유와 두 차원의 의미를 설명한다.
  • 핵의 기저를 확장해 rank–nullity 정리를 증명한다.
  • 같은 관측값을 갖는 모든 입력을 한 해와 핵으로 표현한다.

영이 되는 입력과 실제로 닿는 출력

T:V→ W를 선형사상이라 하고 V는 n차원, 두 공간의 스칼라체는 같다고 합시다. 영인 출력을 만드는 입력들을 핵(kernel), 가능한 모든 출력들을 상(image)이라고 부릅니다.

ker T={x∈ V:T(x)=0}⊆ V,  imT={T(x):x∈ V}⊆ W.

영벡터는 각 집합에 들어갑니다. u,v∈ker T이면 T(au+bv)=aT(u)+bT(v)=0이므로 선형결합도 핵에 있습니다. y1=T(x1), y2=T(x2)이면 ay1+by2=T(ax1+bx2)이므로 선형결합도 상에 있습니다. 어느 공간의 부분공간인지 구분해야 합니다. 서로 차원이 다른 V,W 사이에서도 이 정의가 적용됩니다.

계수(rank)는 상의 차원, 영차원(nullity)은 핵의 차원입니다. 행렬의 계수는 행을 줄여 얻는 피벗 개수이고, 차원 해석에서는 원래 행렬의 열들이 생성하는 공간의 차원입니다. 사상에서의 정의는 기저를 지정하기 전에 성립합니다.

핵의 기저를 전체 공간의 기저로 키운다

계수–영차원 정리. V가 유한차원이고 T:V→ W가 선형사상이면 dim V=rankT+nullityT입니다. W 전체가 유한차원이라는 가정은 필요 없습니다. 입력의 기저를 보내 얻은 유한 개의 벡터만으로도 상을 생성하기 때문입니다.

핵의 기저를 (u1,…,uk)라 합시다. 현재 목록이 V를 생성하지 않으면 생성 공간 밖의 벡터 v1을 추가합니다. 새 벡터에 0이 아닌 계수를 주어 0을 만든 식이 있다면, 정리해서 새 벡터를 기존 목록으로 표현할 수 있어 선택과 모순됩니다. 새 계수가 0이면 기존 목록의 독립성으로 나머지 계수도 0입니다. 따라서 이 단계를 반복해도 독립성을 지키며, 독립인 목록의 길이가 n을 넘지 않으므로 결국 (u1,…,uk,v1,…,vr)이라는 전체 기저를 얻고 k+r=n입니다.

  1. 상을 생성한다. y∈imT를 잡아 y=T(x)라고 쓰세요. 전체 기저로 x=Σi ai ui+Σj bjvj라고 적으면 y=Σj bjT(vj)입니다. u 항은 모두 0으로 갑니다.
  2. 상의 목록은 독립이다. Σj cjT(vj)=0이라 가정합니다. 그러면 Σj cjvj∈ker T라서 어떤 di에 대해 Σj cjvj=Σi di ui입니다. 두 항을 한쪽으로 모으면 전체 기저 벡터들의 선형관계가 됩니다. 기저가 독립이므로 모든 cj와 di가 0입니다.

따라서 (T(v1),…,T(vr))는 상의 기저라서 dim imT=r입니다. 핵의 기저가 비어 있으면 k=0인 경우이며, 상의 기저가 비어 있으면 r=0으로 상은 영공간입니다. 위 두 논증에서 해당 합을 0으로 읽으면 됩니다.

두 가지 다항식 측정으로 남는 자유도를 찾는다

F:𝒫2→ℝ2를 F(p)=(p(1),p'(0))로 정의합니다. 값과 도함수는 각각 선형이라 그 쌍도 선형입니다. p=a+bx+cx2이면 p(1)=a+b+c이고 p'(0)=b이므로 다음과 같습니다.

F(p)=(a+b+c,b),  [F]=[[1, 1, 1], [0, 1, 0]].

핵은 b=0, a+c=0인 다항식 전부입니다. 즉 ker F=span(x2−1)입니다. u=x2−1에 v1=1, v2=x−1을 추가해 보겠습니다. α u+β v1+γ v2의 표준 계수는 (−α+β−γ,γ,α)입니다. 이 셋이 모두 0이면 α=γ=β=0이라 목록이 독립이고, 차원이 3이므로 기저입니다. 두 출력 F(v1)=(1,0), F(v2)=(0,1) 역시 ℝ2의 기저입니다. 따라서 정의역의 차원 3 중 1이 핵에, 2가 상에 대응합니다.

F(p)=(4,2)의 한 해는 p0=4v1+2v2=2+2x입니다. 선형성 때문에 p0에 핵 벡터를 더해도 값이 같습니다. 반대로 임의의 해 p는 F(p−p0)=(4,2)−(4,2)=0을 만족하므로 p−p0∈ker F입니다. 모든 해는 p=2+2x+c(x2−1) (c∈ℝ)입니다.

해의 존재와 유일성을 따로 판단한다

일반적으로 T(x)=y의 해가 있으면 y∈imT이고 그 역도 성립합니다. 한 해 x0를 잡았을 때 해 전체는 x0+ker T={x0+z:z∈ker T}입니다. 예로 F(p)=(4,2)의 해는 원점을 지나지 않는 다항식 공간의 직선입니다. 해가 존재할 때 유일하려면 ker T={0}이어야 하고, 이것은 T가 단사일 조건입니다. 모든 목표 y에서 존재하려면 imT=W이어야 하고, 이것은 T가 전사일 조건입니다.

비교. G:𝒫2→ℝ2, G(p)=(p(1),2p(1))은 상이 span((1,2))라서 목표 (4,2)를 만들 수 없습니다. p(1)=0 하나만 제약하므로 핵의 차원은 2입니다. dim V가 같은 두 사상이라도 어떤 관측을 정의했는가에 따라 잃는 자유도가 달라집니다.

더 읽기. 차이가 핵에 속하는 입력들을 하나의 동치류 x+ker T로 묶으면 그 동치류가 상의 출력 T(x)에 일대일 대응합니다. 대표자를 바꾸어도 출력이 같고, 두 출력이 같으면 두 입력의 차이가 핵에 있으며, 상에 있는 모든 출력은 어떤 대표자가 만듭니다. 이 동치류들의 벡터공간을 몫공간 V/ker T라고 부릅니다.

손계산을 작은 배열로 다시 검산한다

import numpy as np

measure = np.array([[1, 1, 1], [0, 1, 0]])
basis = np.array([[-1, 1, -1], [0, 0, 1], [1, 0, 0]])
print("basis images:", (measure @ basis).tolist())

representative = np.array([2, 2, 0])
kernel_direction = basis[:, 0]
for c in [-1, 0, 3]:
    coefficients = representative + c * kernel_direction
    print(c, coefficients.tolist(), (measure @ coefficients).tolist())
basis images: [[0, 1, 0], [0, 0, 1]]
-1 [3, 2, -1] [4, 2]
0 [2, 2, 0] [4, 2]
3 [-1, 2, 3] [4, 2]

Python 3.14.6, NumPy 2.5.4로 실행했습니다. 열을 곱해 핵과 상의 후보를 검사했습니다. 상의 기저가 된다는 사실은 두 번째와 세 번째 열이 서로 다른 단위벡터라는 점에서 바로 확인됩니다.
