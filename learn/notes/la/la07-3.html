대칭행렬과 양의 준정부호

수직인 고유방향에서 대칭행렬의 작용을 봅니다. 방향을 어떤 쪽으로 골라도 이차형식이 음이 아닌 조건을 고유값과 연결합니다.

이 장을 읽고 나면

  • 대칭행렬의 고유벡터를 직교정규기저로 골라 대각화한다.
  • xᵀAx와 고유값의 부호로 양의 정부호와 양의 준정부호를 확인한다.
  • MᵀM과 공분산 행렬에 음의 고유값이 없다는 이유를 설명한다.

대칭이면 수직인 고유방향을 고를 수 있다

실수 정사각행렬 A에서 Aᵀ=A이면 대칭행렬입니다. 실대칭행렬은 실수 고유값을 갖고, 길이가 1이며 서로 수직인 고유벡터들로 기저를 고를 수 있습니다. 이를 스펙트럼 정리라고 부릅니다. 고유값이 같은 여러 방향에서도 직교정규기저를 고를 수 있습니다.

서로 다른 고유값 λ, μ의 벡터를 u, v라고 하면 대칭 때문에 (Au)ᵀv=uᵀAv입니다. 이 식은 λ(uᵀv)=μ(uᵀv)가 되므로 uᵀv=0입니다. 고유벡터를 모은 행렬 Q는 열끼리 직교하고 길이가 1이라 QᵀQ=I입니다. 따라서 Q⁻¹=Qᵀ이고 A=QΛQᵀ입니다.

A=[[2,1],[1,2]]는 q₁=(1,1)/√2 방향을 3배, q₂=(1,−1)/√2 방향을 1배로 보냅니다.

벡터가 어떤 방향에 있든 제곱식이 음이 아닌가

xᵀAx는 벡터 하나에 대해 얻는 숫자이며 이차형식이라고 합니다. x=Qz로 적으면 z=Qᵀx는 직교정규 고유기저의 좌표입니다. 따라서 xᵀAx=zᵀΛz=Σi λizi²입니다. 모든 x에서 이 값이 음이 아닌 실대칭행렬을 양의 준정부호(PSD)라고 합니다. 모든 x≠0에서 값이 양수이면 양의 정부호(PD)입니다.

고유값에 음수가 하나라도 있으면 그 단위 고유벡터를 x로 놓아 음수를 얻습니다. 그래서 PSD는 모든 고유값 ≥0, PD는 모든 고유값 >0인 조건과 각각 동치입니다. 예를 들어 B=[[1,1],[1,1]]에서 xᵀBx=(x₁+x₂)²입니다. B는 고유값 2와 0을 가져 PSD이며, x=(1,−1)처럼 0이 아닌 벡터에 대해서도 값이 0입니다.

대칭이더라도 D처럼 음의 고유값이 있을 수 있습니다. B처럼 준정부호일 때 고유값 0이 허용되므로 역행렬이 없을 수도 있습니다.

고유값을 구하지 않고 판정하는 법

  • 2×2 대칭 [[a,b],[b,c]]: PD ⇔ a>0 그리고 ac−b²>0. 두 고유값의 곱이 det=ac−b², 합이 a+c이기 때문입니다. det<0이면 고유값 부호가 서로 달라 부정부호입니다. A=[[2,1],[1,2]]는 2>0, 4−1=3>0이라 PD입니다.
  • n×n 대칭(실베스터 판정법): 왼쪽 위 k×k 부분행렬들의 행렬식(선행 주소행렬식) k=1,…,n이 모두 양수 ⇔ PD.
  • PSD는 선행 주소행렬식이 모두 0 이상인 것만으로는 부족하고, 모든 주소행렬식(같은 번호의 행과 열을 골라 지운 정사각 부분행렬의 행렬식)이 0 이상이어야 합니다. 예: [[0,0],[0,−1]]은 선행 주소행렬식이 0, 0이지만 e₂에서 이차형식이 −1입니다.
  • 계산에서는 숄레스키 분해 A=LLᵀ(L은 대각이 양수인 아래삼각)가 성공하면 PD입니다. NumPy의 np.linalg.cholesky는 PD가 아니면 오류를 냅니다.

길이 제곱으로 쓰이는 행렬은 준정부호다

M이 직사각행렬이어도 MᵀM은 정사각 대칭행렬입니다. xᵀ(MᵀM)x=(Mx)ᵀ(Mx)=∥Mx∥²≥0이므로 PSD입니다. 이 형태를 그람 행렬이라고 합니다. M의 열이 독립이면 x≠0에서 Mx가 0이 아니기 때문에 PD입니다. 서로 종속된 열이 있으면 0 방향도 생깁니다.

중심화한 자료 X의 각 행이 관측 하나이고 각 열이 특성 하나라면, n>1에서 표본 공분산 행렬은 XᵀX/(n−1)입니다. 같은 이유로 PSD입니다. 어떤 단위방향 x로 자료를 사영했을 때 표본분산이 xᵀ[XᵀX/(n−1)]x입니다. 이 성질은 뒤의 주성분 분석으로 이어집니다.

고유값과 그람 행렬의 제곱을 실행해 확인한다

import numpy as np

matrices = {
    "A": np.array([[2, 1], [1, 2]]),
    "B": np.ones((2, 2)),
    "D": np.diag([1, -1]),
}
for name, matrix in matrices.items():
    eig = np.linalg.eigvalsh(matrix)
    print(name, " ".join(f"{value:.1f}" for value in eig))

M = np.array([[1, 1], [2, 2], [0, 0]])
x = np.array([2, -1])
gram_result = x @ (M.T @ M) @ x
length_squared = (M @ x) @ (M @ x)
assert gram_result == length_squared
print("Gram:", gram_result, length_squared)
A 1.0 3.0
B 0.0 2.0
D -1.0 1.0
Gram: 5 5

eigvalsh에는 실대칭행렬을 넣었습니다. 출력의 고유값은 작은 값부터입니다. 마지막 줄은 xᵀ(MᵀM)x와 ∥Mx∥²를 따로 계산한 값입니다.

실대칭 A실수 고유값과 직교정규 고유기저, A=QΛQᵀ.
PSD / PD모든 고유값이 각각 0 이상 / 0보다 큼.
그람 행렬 MᵀM이차형식이 ∥Mx∥²이므로 PSD.
고유값 없이 PD 판정선행 주소행렬식이 모두 양수(실베스터), 2×2는 a>0·ac−b²>0.

한 줄 정리

실대칭행렬은 A=QΛQᵀ로 직교 대각화되고, 이차형식 xᵀAx=Σλᵢzᵢ²이므로 PSD/PD는 모든 고유값이 0 이상/양수인 것과 같습니다.
