LA01·1

벡터와 성분: 한 관측을 숫자 여러 개로 나타내기

지점 하나의 오늘 주문 수와 평균 배송 시간을 한꺼번에 기록합니다. 한 숫자와 숫자 묶음의 차이, 좌표의 순서, 행·열 모양이 데이터 계산에서 무엇을 뜻하는지부터 잡습니다.

이 장을 읽고 나면

  • 스칼라와 벡터, 벡터 성분의 의미를 구별한다.
  • 벡터의 성분 개수와 표의 관측 개수를 따로 셀 수 있다.
  • 열벡터와 행벡터, NumPy의 1차원 배열 모양을 비교한다.

숫자 하나와 숫자 묶음

지점의 주문 수 120은 한 숫자입니다. 이런 값을 스칼라라고 부릅니다. 지점마다 순서를 ‘주문 수, 평균 배송 시간, 반품 수’로 정하면 A점은 (120, 32, 4)처럼 나타낼 수 있습니다. 이 장에서 쓰는 실수 벡터는 순서 있는 실수의 묶음입니다. 각 자리를 성분이라고 합니다.

성분값뜻과 단위
첫째120주문 수(건)
둘째32배송 시간 평균(분)
셋째4반품 수(건)

숫자가 같은 것만으로는 같은 의미가 되지 않습니다. (120, 4, 32)는 둘째와 셋째를 바꾼 벡터입니다. 여러 자료에서 같이 계산하려면 성분 이름과 순서, 단위가 같은지 확인합니다.

두 성분을 좌표로 그리기

화살표로 그리는 벡터는 방향과 변위를 보여 줍니다. (2,1)은 가로 +2, 세로 +1의 변화입니다. 시작점이 (4,2)이면 끝점은 (6,3)입니다. 고정 좌표에서 한 점 (6,3)을 부르는 것과, 시작점에서 끝점까지의 변화량 (2,1)을 부르는 것을 구분합니다.

좌표축의 성분은 공간에서의 거리를 나타낼 수 있습니다. 주문 수와 배송 시간 같은 특징 벡터는 관측을 기록하기 위한 숫자 묶음입니다. 120건과 32분을 그림에 찍을 수는 있어도, 두 축의 크기를 곧바로 물리 거리로 합칠 때는 단위와 척도를 따져야 합니다.

관측 수와 특징 수

열이 3개인 실수 특징 벡터는 ℝ³에 있다고 씁니다. 여기는 성분을 놓을 자리가 세 개인 공간입니다. 데이터에 같은 열을 복사해 붙이면 자리 수는 늘지만 새 정보가 생기지는 않습니다. 이런 선형 관계는 나중에 기저와 공간을 배울 때 다시 봅니다.

수학의 행·열과 코드의 shape

계산할 벡터를 세로로 적으면 3행 1열, 가로로 적으면 1행 3열입니다. 이 책에서는 변환을 계산할 때 기본적으로 열벡터를 씁니다. NumPy에서 array([120,32,4])를 만들면 shape는 (3,)입니다. 축이 하나라서 (3, 1)이나 (1, 3)처럼 방향이 지정된 2차원 배열과 다릅니다.

import numpy as np

x = np.array([120, 32, 4])
col = x.reshape(3, 1)
row = x.reshape(1, 3)
print(x.shape, col.shape, row.shape)
print(row.tolist(), col.tolist())

실행 결과

(3,) (3, 1) (1, 3)
[[120, 32, 4]] [[120], [32], [4]]

함수를 부르기 전에 입력 모양을 읽어 봅니다. x.T는 1차원 배열에서는 모양을 그대로 두지만, row.T는 (1,3)을 (3,1)로 바꿉니다. 전치는 행과 열을 서로 바꾸는 연산이며, 행렬 계산에서 자세히 나옵니다.

혼자 해 보기

기온(°C), 풍속(m/s), 시간대(시)를 세 성분으로 둡니다. 6번 측정한 관측을 차곡차곡 쌓았을 때 모양을 적고, 하나의 관측을 열벡터로 쓰면 행과 열이 각각 몇 개인지 써 보세요.
