LA10·3

조르당 표준형의 증명과 거듭제곱

고유값마다 일반화 고유공간을 분리해 표준형을 증명합니다. 거듭제곱의 다항식 항을 계산하고, 작은 성분 변화가 블록을 어떻게 바꾸는지 확인합니다.

이 장을 읽고 나면

  • 특성다항식이 일차 인수로 분해되는 공간에서 일반화 고유공간의 직합을 증명한다.
  • 조르당 블록의 거듭제곱과 반복의 일시적 증가·장기 거동을 계산한다.
  • 작은 섭동으로 조르당 구조가 변하는 이유를 설명한다.

고유값마다 자기 부분공간을 어떻게 분리할까

앞 장에서는 N=A−λ I가 멱영인 부분공간에서 사슬 기저를 만들었습니다. 이제 복소 행렬 A에 고유값이 여럿 있어도 이 방법을 각각 적용할 수 있음을 보입니다. 증명은 사용 중인 스칼라체에서 특성다항식이 일차 인수로 분해되기만 하면 성립합니다. 따라서 복소수에는 항상 적용되고, 실수에서는 모든 근이 실수일 때 적용됩니다.

특성다항식의 분해를 pA(t)=f1(t)⋯ fs(t), fi(t)=(t−λi)mi로 쓰고 서로 다른 λi를 구분합니다. Gi=ker fi(A)를 해당 고유값의 일반화 고유공간이라 합니다. fi(A)x=0이라면 fi(A)Ax=Afi(A)x=0이므로 Gi는 A에 대해 불변입니다. A−λiI를 이 부분공간으로 제한하면 그 mi제곱이 0이라 멱영입니다.

핵심은 전체 공간이 G1⊕⋯⊕ Gs라는 점입니다. 준비로 pi=pA/fi라고 둡니다. 각 근 λi에서 pi(λi)≠0이므로 모든 pi에 공통인 비상수 인수가 없습니다. 다항식의 유클리드 알고리즘에서는 나머지를 되짚어 최대공약수를 원래 다항식들의 선형결합으로 표현할 수 있습니다. 이를 여러 다항식에 이어 적용한 베주 항등식으로, 어떤 다항식 qi가 있어서 Σi qi(t)pi(t)=1입니다. 한 근만 있는 경우에는 p1=1이라 곧바로 성립합니다.

여기에 A를 대입해 Ei=qi(A)pi(A)를 만듭니다. 다항식의 상수항 c는 대입할 때 cI가 됩니다. 그러므로 Σi Ei=I입니다. 케일리–해밀턴 정리 pA(A)=0에 의해 fi(A)Ei=qi(A)pA(A)=0이고, 따라서 Ei의 출력은 항상 Gi에 속합니다. 또한 j≠ i일 때 pi에 fj 인수가 들어 있으므로 Ei는 Gj에 속한 모든 벡터를 0으로 보냅니다.

  1. 합이 전체 공간을 채운다. 임의의 v에 대해 v=Σi Ei v입니다. 각 항은 하나의 Gi에 속합니다.
  2. 합의 표현은 유일하다. ui∈ Gi이고 Σi ui=0이라 합시다. Ej를 적용하면 j 이외의 항은 전부 사라집니다. uj에서는 다른 Ei가 모두 0이므로 Σi Ei=I에 의해 Ej uj=uj입니다. 따라서 각 uj=0입니다.

이로써 직합이 증명되었습니다. 각 Gi에서 앞 장의 멱영 사슬 기저를 만들고 모두 모으면 전체 기저를 얻습니다. 이 기저에서 A는 Jr(λi)들을 대각에 놓고 블록 바깥에 0을 둔 조르당 표준형입니다. 각 고유값에 해당하는 블록 크기의 합이 그 고유값의 대수적 중복도입니다. 블록별 특성다항식을 곱하면 바로 확인됩니다. 또 (A−λiI)k는 다른 고유값의 블록에서 가역이라, 해당 핵 차원만으로 앞 장의 규칙을 적용해 λi의 블록 크기를 알아낼 수 있습니다. 표준형은 블록 순서를 빼면 유일합니다.

케일리–해밀턴 정리의 짧은 증명. 여인수 행렬을 전치한 수반행렬을 사용하면 (tI−A)adj(tI−A)=pA(t)I입니다. 수반행렬을 행렬 계수를 가진 다항식 Σj tjBj로 펼치세요. 양변을 t의 다항식으로 본 뒤 각 tk의 계수 왼쪽에 Ak를 곱해 더합니다. 왼쪽은 각 j마다 Aj+1Bj−Aj A Bj=0이고 오른쪽은 정의에 의해 pA(A)입니다. 이 증명에서는 Bj와 A의 교환을 가정하지 않습니다.

3×3에서 다른 고유값의 두 블록을 분리한다

M=[[1, 1, 1], [0, 1, 0], [0, 0, 2]]은 위삼각이므로 pM(t)=(t−1)2(t−2)입니다. M−I는 (a,b,c)를 (b+c,0,c)로 보내고, 한 번 더 적용하면 (c,0,c)입니다. 따라서 G1={(a,b,0)}입니다. 이 평면에서 (M−I)e2=e1, (M−I)e1=0이므로 순서 (e1,e2)에 블록 J2(1)이 생깁니다.

고유값 2에 대해서는 (M−2I)(a,b,c)=(−a+b+c,−b,0)입니다. b=0,a=c가 되어 G2는 (1,0,1)이 생성하는 직선입니다. P를 열 (e1,e2,(1,0,1)⊤)로 만들면 P가 가역이고 P−1MP는 J2(1)과 [2]를 차례로 놓은 블록 대각행렬입니다. 대각화는 모든 블록의 크기가 1인 경우입니다. 여기서는 고유값 1의 일반화 고유공간 안에 고유벡터가 하나의 방향만 있으므로 크기 2 블록을 더 나눌 수 없습니다.

블록을 직접 확인하는 순서. 특성다항식을 분해하고 각 (A−λ I)j의 핵을 조사합니다. 핵 차원의 증가량으로 사슬의 길이를 정한 뒤 사슬 끝 후보를 위에서부터 골라 N=A−λ I를 적용합니다. 마지막으로 열을 각 사슬의 고유벡터부터 나열해 AP=PJ인지 확인합니다. 같은 특성다항식을 가진 행렬이 두 개 있을 때도, 고유값별 핵 차원이 다르면 이 계산에서 다른 블록 목록이 나옵니다.

거듭제곱의 지수 항과 다항식 항을 함께 읽는다

조르당 블록 Jr(λ)=λ I+N에서 Nr=0이고 두 항이 교환합니다. 따라서 이항정리에서 Nj를 포함하는 항 중 j<r인 것만 남습니다. C(k, j)는 k개의 곱셈 중 j개 자리에서 N을 고르는 방법의 수입니다.

Jr(λ)k=Σj=0min(k,r−1)C(k, j)λk−jNj (λ≠0, k≥0)

λ=0이면 바로 Jr(0)k=Nk이고 k≥ r에서 영행렬입니다. k=0의 행렬 거듭제곱은 항등행렬입니다. 여러 블록을 가진 A=PJP−1는 인접한 P−1P가 소거되므로 Ak=PJkP−1입니다.

크기 2. J2(1/2)를 e2=(0,1)에 한 번 곱하면 (1,1/2)입니다. k≥1에서는 N2=0이고 Ne2=e1이라 결과는 (k(1/2)k−1,(1/2)k)입니다. 첫 반복의 유클리드 길이는 √(1+1/4)>1이고 원래 길이는 1이므로 처음에는 커집니다. 그러나 k(1/2)k−1과 (1/2)k 모두 0으로 갑니다.

크기 3. LA10-2의 A=[[0, 1, 0], [0, 1, 1], [1, −1, 2]]는 λ=1인 길이 3 사슬 v1=(1,1,0), v2=(0,1,1), v3=(0,0,1)을 갖습니다. Ak v3=v3+kv2+C(k, 2)v1이며 k=0,1에서는 마지막 계수를 0으로 둡니다. 예컨대 k=3에서 v3+3v2+3v1=(3,6,4)입니다. |λ|=1이어도 사슬이 길면 성분이 다항식 크기로 성장할 수 있습니다.

유한차원에서 모든 고유값에 |λ|<1이면 Ak→0입니다. λ≠0인 각 블록의 성분은 차수가 유한한 다항식과 지수 감쇠를 곱한 항들의 합이기 때문입니다. 예컨대 kj rk의 이웃한 두 양의 항의 비는 (1+1/k)jr→ r<1이라 충분히 뒤에서는 1보다 작은 일정한 비율로 감소합니다. 반대로 |λ|≥1인 고유값이 있으면 Akv=λkv인 고유벡터에서 영으로 수렴하지 않습니다. 모든 고유값의 크기가 1 이하이고 크기 1인 고유값의 블록이 모두 길이 1이라면 거듭제곱은 유계입니다. 절댓값이 1인 고유값의 블록 길이가 2 이상이면 사슬 좌표에 kλk−1 성분이 생길 수 있어 거듭제곱이 유계가 아닙니다.

정확한 행렬의 표준형과 수치 계산을 구분한다

Aε=[[1, 1], [ε, 1]]에서 ε=0이면 크기 2 조르당 블록입니다. 그러나 ε>0이면 특성다항식은 (t−1)2−ε이고 고유값 1±√(ε)이 서로 다릅니다. 행렬의 성분이 아주 조금만 달라져도 크기 2 블록 하나에서 크기 1 블록 둘로 바뀝니다.

고유벡터를 (1,√(ε))와 (1,−√(ε))로 고르면 ε이 0에 다가갈수록 두 방향이 가까워집니다. 두 열의 행렬식이 −2√(ε)이라 그 좌표로 바꾸기 위한 역행렬의 성분도 커질 수 있습니다. 측정값으로 얻은 부동소수점 행렬에서 조르당 블록 크기를 곧바로 판정하거나, 고유벡터 기저로 바꾸어 Ak를 계산하면 작은 오차에 민감해질 수 있습니다. 정확히 주어진 작은 정수·유리수 행렬의 구조 증명에는 표준형을 사용하고, 일반 수치 행렬에서 고유값을 분석할 때는 유니터리 기저를 쓰는 슈어 분해가 대표적인 방법입니다. 복소 슈어 분해는 A=QTQ*에서 T가 위삼각, Q*Q=I인 분해이며 Q*는 켤레전치입니다.

손계산을 작은 배열로 다시 검산한다

from math import comb, sqrt
import numpy as np

j2 = np.array([[0.5, 1.0], [0.0, 0.5]])
v = np.array([0.0, 1.0])
for k in range(5):
    print(k, v.tolist())
    v = j2 @ v

a = np.array([[0, 1, 0], [0, 1, 1], [1, -1, 2]])
v1 = np.array([1, 1, 0])
v2 = np.array([0, 1, 1])
v3 = np.array([0, 0, 1])
k = 3
predicted = v3 + k * v2 + comb(k, 2) * v1
print("size 3:", (np.linalg.matrix_power(a, k) @ v3).tolist(), predicted.tolist())

epsilon = 1e-8
perturbed = np.array([[1.0, 1.0], [epsilon, 1.0]])
observed = np.sort(np.linalg.eigvals(perturbed))
expected = [1 - sqrt(epsilon), 1 + sqrt(epsilon)]
assert np.allclose(observed.imag, 0.0, atol=1e-12)
print("split roots:", [round(float(x.real), 4) for x in observed])
print("root formula:", np.allclose(observed, expected))
