내적과 노름: 가중합과 거리 계산

상품 세 개를 몇 개씩 샀고 단가가 얼마인지 알 때, 대응하는 수를 곱하고 합치면 비용 한 숫자가 나옵니다. 내적의 구조를 이해한 뒤, 자기 자신과의 내적이 길이와 거리로 이어지는 과정을 봅니다.

이 장을 읽고 나면

  • 실수 벡터의 내적을 성분별로 구한다.
  • 유클리드 노름과 두 점의 거리를 연결한다.
  • 스케일과 단위가 거리 해석에 미치는 효과를 설명한다.

곱하고 더해서 값 하나 얻기

구매 수량이 (2,3,1)이고 대응하는 단가가 (1200,800,3000)원입니다. 가격 한 숫자는 2×1200 + 3×800 + 1×3000 = 7800원입니다. 어느 가격을 어느 수량에 붙이는지 정해져 있으므로 벡터의 순서를 맞춥니다.

정의

실수 성분을 가진 같은 차원 벡터 x, w의 내적 x·w는 ∑ᵢ xᵢwᵢ입니다. 같은 자리끼리 곱한 결과를 모두 더합니다. 내적의 결과는 스칼라입니다.

가중평균은 가중합에 가중치 합으로 나누는 조건이 붙습니다. 총비용 7800원은 가중합이고, 수량이 총 6개일 때 평균 단가는 7800/6 = 1300원입니다.

자기 자신과의 내적에서 길이 구하기

v = (3,4)의 내적 v·v는 3²+4² = 25입니다. 제곱근이 5이므로 원점부터 v까지 유클리드 길이는 5입니다. 이를 유클리드 노름 ∥v∥₂라 씁니다. x가 (x₁,…,xn)이면 ∥x∥₂ = √(x·x) = √(x₁² + … + xn²)입니다. 영벡터의 길이는 0입니다. 아래 첨자 2는 성분을 제곱해 더한 뒤 제곱근을 취한다는 표시이고, 이 때문에 L2 노름이라고도 부릅니다.

두 점 사이 거리는 차이 벡터의 길이

P=(1,1), Q=(4,5)일 때 Q−P=(3,4)입니다. ∥Q−P∥₂ = 5입니다. P와 Q의 순서를 뒤집으면 차이 벡터의 방향이 바뀌지만 길이는 그대로입니다.

import numpy as np

q = np.array([2, 3, 1])
w = np.array([1200, 800, 3000])
P = np.array([1, 1])
Q = np.array([4, 5])
print(int(q @ w))
print((Q - P).tolist())
print(float(np.linalg.norm(Q - P)))

실행 결과

7800
[3, 4]
5.0

@는 NumPy에서 행렬 곱 문법이고 1차원 배열 두 개에는 해당 벡터의 내적을 계산합니다. q * w는 중간의 성분별 곱 [2400,2400,3000]을 돌려줍니다. 한 숫자가 필요한가, 성분별 곱을 따로 갖고 있어야 하는가에 따라 선택합니다.

노름의 조건과 L1 노름

길이를 재는 방법은 하나가 아닙니다. 벡터에 0 이상의 수 하나를 붙이는 함수 ∥·∥가 다음 세 조건을 만족하면 노름(norm)이라고 부릅니다.

정의: 노름의 세 조건

① ∥x∥ ≥ 0이고, ∥x∥ = 0은 x가 영벡터일 때뿐
② ∥cx∥ = |c|·∥x∥ (스칼라배는 길이를 |c|배)
③ ∥x+y∥ ≤ ∥x∥ + ∥y∥ (삼각부등식: 돌아가는 길이 곧은 길보다 짧지 않다)

성분의 절댓값을 그대로 더하는 L1 노름 ∥x∥₁ = |x₁| + … + |xn|도 세 조건을 만족합니다. 바둑판 같은 길을 가로·세로로만 걷는 거리와 같아서 맨해튼 거리라고도 합니다. 성분의 절댓값 중 가장 큰 값을 쓰는 ∥x∥∞ = max |xᵢ|(L∞ 노름)도 있습니다.

풀이 예제: 같은 벡터, 다른 길이

v = Q − P = (3, 4)
∥v∥₂ = √(3² + 4²) = √25 = 5
∥v∥₁ = |3| + |4| = 7
∥v∥∞ = max(3, 4) = 4

그림의 점선을 따라가면 3 + 4 = 7, 빗변은 5입니다. 일반적으로 ∥x∥∞ ≤ ∥x∥₂ ≤ ∥x∥₁입니다. NumPy에서는 np.linalg.norm(v, 1)이 7.0, np.linalg.norm(v)가 5.0입니다.

L2는 큰 성분 차이를 제곱으로 더 크게 반영하고, L1은 모든 성분 차이를 절댓값 그대로 더합니다. 그래서 이상값 하나의 영향은 L2 쪽이 더 큽니다. 두 노름은 뒤에서 거리 기반 모델(k-NN)과 정규화(L1·L2 벌점, OP06)에서 다시 나옵니다.

특징 척도가 다르면 거리가 달라진다

예를 들어 x축이 키(cm)이고 y축이 체중(kg)이라면, 두 열을 그대로 합쳐 구한 수를 실제 길이 ‘몇 cm’로 해석할 수 없습니다. 키를 m로 적는 것만으로도 수치상 거리가 달라집니다. 기능상 어떤 차이를 중요하게 볼지 결정한 뒤 단위 변환, 가중치, 혹은 표준화(열마다 평균을 빼고 표준편차로 나누기, DA05)를 적용합니다. 표준화를 해도 그 관측들에 어떤 거리가 적합한지는 문제에 따라 다릅니다.

풀이 점검

내적, 크기, 거리의 차이를 식으로 적어 봅시다. 내적은 두 벡터를 넣고, 크기는 하나의 벡터를 자기 자신과 비교하고, 거리는 두 점의 차이 벡터를 만든 뒤 길이를 구합니다. 다음 장에서는 내적이 0이거나, 일부만 특정 방향으로 겹칠 때를 그림으로 해석합니다.

한 줄 정리

내적은 짝지어 곱해 더한 스칼라이고, 노름은 노름의 세 조건을 만족하는 길이이며, 거리는 차이 벡터의 노름입니다.
