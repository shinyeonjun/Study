행렬 곱과 전치: 계산 전에 모양부터 읽기

두 매장의 품목별 수량으로 비용과 포장 무게를 계산합니다. 값 하나는 행과 열의 내적이며, 행렬 곱 전체는 이 계산을 여러 줄과 여러 열에 반복합니다.

이 장을 읽고 나면

  • 행렬–벡터와 행렬–행렬 곱의 모양을 손으로 구한다.
  • 같은 행렬 곱을 행 내적과 열의 선형 결합으로 읽는다.
  • 전치와 NumPy의 @·* 차이를 구분한다.

행과 벡터의 내적

품목이 삼각김밥, 물, 샌드위치 순서입니다. 매장별 수량을 A=[[2,3,1],[1,2,4]]에 넣고 단가 w=(1200,800,3000)원을 열벡터로 생각합니다. Aw는 각 행의 수량을 단가와 내적합니다.

계산

첫 매장: 2×1200 + 3×800 + 1×3000 = 7800원
둘째 매장: 1×1200 + 2×800 + 4×3000 = 14800원

A는 2행 3열, w는 길이 3이므로 결과는 매장마다 하나인 길이 2의 벡터입니다.

열마다 가중치 묶음을 넣는다

포장 무게도 한꺼번에 구해 봅시다. 단가와 무게를 B의 열로 놓습니다. 행은 같은 품목 세 개입니다.

품목B 첫째 열: 원/개B 둘째 열: g/개
삼각김밥1200100
물800500
샌드위치3000200

일반적으로 (m×n)과 (n×p)를 곱하면 (m×p)입니다. (AB)ij는 ∑ₖ AᵢₖBₖⱼ로, A의 i번째 행과 B의 j번째 열을 짝짓습니다. 여기서 (AB)12는 첫 매장의 무게이고 2×100 + 3×500 + 1×200 = 1900 g입니다.

행 하나가 아닌 열 하나로도 읽기

Aw는 A의 열 세 개에 w의 세 계수를 각각 곱해 더한 결과이기도 합니다. A의 첫 열 (2,1)에 1200을, 둘째 열 (3,2)에 800을, 셋째 열 (1,4)에 3000을 곱해 합하면 (7800,14800)으로 같습니다. 행 중심 해석은 출력 한 자리를 계산하는 데 편하고, 열 중심 해석은 각 입력 방향의 기여를 보는 데 편합니다.

import numpy as np

A = np.array([[2, 3, 1], [1, 2, 4]])
B = np.array([[1200, 100], [800, 500], [3000, 200]])
C = A @ B
print(A.shape, B.shape, C.shape)
print(C.tolist())
print((C[:, 0] == A @ B[:, 0]).all())

실행 결과

(2, 3) (3, 2) (2, 2)
[[7800, 1900], [14800, 1900]]
True

이 예에서 둘째 매장 무게도 100 + 1000 + 800 = 1900g입니다. 비슷한 결과가 다른 조합에서도 나올 수 있습니다. 결과 한 숫자만으로 원래 수량을 되찾을 수 있는지는 다른 질문입니다.

전치와 원소별 곱

전치 Aᵀ는 행과 열을 바꾸고, Aij를 Aᵀji에 놓습니다. NumPy의 2차원 배열에서 A.T는 전치이고, A * B는 가능한 경우 원소별로 곱합니다. 곱셈 기호를 똑같이 읽지 않습니다.

단위와 모양으로 검산하기

결과의 첫 열은 원, 둘째 열은 g입니다. 2×3과 2×2를 그대로 곱할 수 없습니다. 연결할 축의 길이와 의미를 먼저 확인하세요. 품목 순서가 어긋나면 모양이 맞더라도 올바른 결과를 얻지 못합니다.
