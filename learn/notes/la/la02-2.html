직교·사영·코사인 유사도: 방향을 따로 읽기

빛을 한 방향으로 비추면 벡터가 선 위에 그림자를 남깁니다. 원래 벡터를 한 방향에 겹치는 부분과 그 방향에 수직인 나머지로 나눌 수 있습니다. 내적이 두 방향의 관계를 어떻게 수치화하는지 확인합니다.

이 장을 읽고 나면

  • 내적이 0인 경우를 직교와 연결한다.
  • u의 v 방향 사영과 수직으로 남는 잔차를 구한다.
  • 크기가 다른 실수 벡터의 방향을 코사인 유사도로 비교한다.

내적 0과 직각

실수 벡터 (1,1)과 (1,−1)의 내적은 1×1 + 1×(−1) = 0입니다. 두 화살표는 평면에서 직각으로 만납니다. 내적이 0이면 두 벡터가 직교한다고 합니다. 영벡터는 모든 벡터와 내적이 0이지만 자체 방향도 각도도 없습니다. 각도를 말할 때는 두 벡터가 모두 0이 아니어야 합니다.

한 방향으로 내려놓기

u=(4,2)를 v=(1,1)에 평행한 직선 위의 한 벡터 p와, 그 직선에 수직인 잔차 u−p의 합으로 나타냅니다. p는 v의 배수이므로 p=cv라고 둡니다. 남는 u−cv가 수직이어야 하므로 (u−cv)·v = 0입니다.

사영 식을 얻기

(u−cv)·v = u·v − c(v·v) = 0
c = (u·v)/(v·v)
p = c v

v가 영벡터가 아니면 v·v는 양수입니다. 예에서 u·v = 6, v·v = 2이므로 c=3, p=(3,3)입니다. 남은 (1,−1)의 내적은 (1,−1)·(1,1)=0입니다.

p를 u의 v 방향 사영(projection)이라고 합니다. 한 식으로 쓰면 proj_v(u) = ((u·v)/(v·v)) v = ((u·v)/∥v∥₂²) v입니다. 사영은 벡터 p 자체이고, c=3은 v를 몇 배 했는지 나타내는 계수입니다. 길이가 1인 벡터를 단위벡터라고 하는데, v가 단위벡터가 아니라면 c와 사영의 부호 있는 길이 (u·v)/∥v∥₂는 값이 다릅니다. 이 예에서 c=3이지만 부호 있는 길이는 6/√2 = 3√2 ≈ 4.243이고, 이는 ∥p∥₂ = ∥(3,3)∥₂와 같습니다. 사영 p가 이 직선 위에서 u에 가장 가까운 점이라는 사실은 직각을 이용해 확인할 수 있습니다. 직선 위의 다른 점 q를 고르면 u−p와 p−q가 직교하므로 피타고라스 정리에 의해 ∥u−q∥² = ∥u−p∥² + ∥p−q∥² > ∥u−p∥²가 됩니다.

크기를 뺀 방향 비교

영벡터가 아닌 u,v의 사이각 θ(0° ≤ θ ≤ 180°)에는 u·v = ∥u∥₂∥v∥₂ cos θ가 성립합니다. 이를 cos θ = (u·v)/(∥u∥₂∥v∥₂)로 정리한 값을 코사인 유사도라고 부릅니다. 값은 −1 이상 1 이하이고 같은 방향이면 1, 직교하면 0, 반대면 −1입니다. 크기가 달라도 방향이 같으면 값이 1입니다.

유도: 코사인법칙에서 내적 공식으로

원점에서 u, v를 그리면 세 변이 ∥u∥, ∥v∥, ∥u−v∥인 삼각형이 생깁니다. 코사인법칙과 내적 전개를 나란히 씁니다.

코사인법칙: ∥u−v∥² = ∥u∥² + ∥v∥² − 2∥u∥∥v∥cos θ
내적 전개: ∥u−v∥² = (u−v)·(u−v) = u·u − 2u·v + v·v = ∥u∥² + ∥v∥² − 2u·v
두 식 비교: u·v = ∥u∥∥v∥cos θ

u=(4,2), v=(1,1)이면 ∥u−v∥² = 3² + 1² = 10이고, ∥u∥² + ∥v∥² − 2u·v = 20 + 2 − 12 = 10으로 같습니다. cos θ = 6/(√20·√2) = 6/√40 ≈ 0.949, θ ≈ 18.4°입니다. |u·v| ≤ ∥u∥∥v∥(코시–슈바르츠 부등식)이 항상 성립하므로 이 값은 −1과 1 사이에 들어갑니다.

import numpy as np

u = np.array([4, 2])
v = np.array([1, 1])
p = ((u @ v) / (v @ v)) * v
r = u - p
cos = (u @ v) / (np.linalg.norm(u) * np.linalg.norm(v))
print(p.tolist(), r.tolist())
print(float(r @ v))
print(f"{cos:.3f}")

실행 결과

[3.0, 3.0] [1.0, -1.0]
0.0
0.949

무엇을 같다고 보는지 정한다

키워드 두 개의 등장 횟수 벡터 (1,2)와 (3,6)는 코사인 유사도가 1입니다. 등장 분량은 다르지만 비중의 방향은 같습니다. 문서 분량 자체가 중요한 질문이면 길이의 정보를 함께 보관합니다. 영벡터와의 코사인은 분모가 0이어서 정의되지 않습니다. 아무 특징도 없다는 별도 상태로 처리할지 먼저 정합니다.

혼자 그려 보기

u=(5,3)을 x축 방향 v=(2,0)에 사영하면, p와 u−p를 어떻게 그릴 수 있나요? p가 x축 위에 있고 남은 벡터가 y축과 평행한지 확인한 뒤 내적을 다시 계산합니다.
