열공간과 영공간으로 선형계의 해 읽기

선형계 Ax=b의 우변마다 해가 있는지 먼저 묻고, 해가 있다면 입력이 얼마나 달라질 수 있는지 봅니다. 행렬의 열공간은 가능한 출력, 영공간은 출력에서 사라지는 입력 방향을 알려줍니다.

이 장을 읽고 나면

  • 열공간에 b가 놓이는지 확인한다.
  • 자유변수로 영공간 기저와 Ax=b의 모든 해를 찾는다.
  • 랭크와 영공간의 차원을 구분한다.

행렬의 열은 출력 방향이다

아래 A를 입력 x=(x₁,x₂,x₃)에 곱합니다. 행별 계산으로 세 출력은 (x₁+x₃, x₂+x₃, x₁+x₂+2x₃)입니다. 열별로 보면 입력의 각 성분이 열벡터 a₁=(1,0,1), a₂=(0,1,1), a₃=(1,1,2)에 붙는 계수입니다.

A = [ 1  0  1 ]
    [ 0  1  1 ]
    [ 1  1  2 ]

모든 입력을 넣어 얻는 출력 집합 span(a₁,a₂,a₃)을 열공간이라고 합니다. 마지막 출력은 앞의 두 출력을 더한 값입니다. 그래서 b=(2,3,5)는 가능한 출력이고 b=(2,3,6)은 불가능합니다. 처음 두 출력을 (2,3)으로 만드는 입력은 어떤 것이든 마지막 출력을 2+3=5로 내기 때문입니다. 정리하면 Ax=b에 해가 있다 ⇔ b가 A의 열공간에 있다입니다.

피벗이 가리키는 원래 열로 기저를 만든다

세 번째 열은 첫째와 둘째의 합입니다. 첫째와 둘째는 첫 두 성분에서 각각 다른 자리만 1이므로 독립입니다. 이 두 열이 열공간의 기저를 이루며 차원은 2입니다. 열공간의 차원을 A의 랭크(rank, 계수)라고 하고, 행 소거에서 나오는 피벗의 개수와 같습니다. 행공간(행들의 생성공간)의 차원도 같은 피벗 수와 같아서, 행 랭크와 열 랭크는 언제나 같습니다. 일반적으로 행 소거를 하면 추린 피벗 열 번호를 알 수 있습니다. A의 열공간 기저를 정할 때에는 이 번호에 해당하는 원래 A의 열을 꺼냅니다. 행 소거는 열 사이의 선형결합 관계를 보존하지만, 각 열이 출력 공간에서 실제로 놓이는 위치를 바꿀 수 있기 때문입니다.

풀이 예제

이 A에서는 셋째 행에서 첫째와 둘째 행을 빼면 0행이 됩니다. 첫 두 행이 이미 첫째와 둘째 열에 각각 피벗을 가지고 있습니다. 그래서 랭크는 2입니다. 예컨대 첫 피벗에 대응하는 원래 열은 (1,0,1)이고, 소거 결과의 첫 열은 (1,0,0)입니다. 후자는 y₃=y₁+y₂를 만족하지 않습니다.

영공간의 벡터를 더해도 출력은 그대로다

Ax=0의 해 집합을 영공간 또는 핵(kernel)이라고 합니다. 앞의 두 방정식에서 x₁=−x₃, x₂=−x₃입니다. x₃=t를 자유롭게 고르면 x=t(−1,−1,1)입니다. 영공간 기저로 (−1,−1,1) 하나를 택할 수 있습니다.

Ax=b, b=(2,3,5)에서는 x₃=0으로 놓아 하나의 해 x₀=(2,3,0)을 얻습니다. 어떤 영공간 벡터 v도 A(x₀+v)=b를 만족합니다. 반대로 임의의 해 x가 있다면 A(x−x₀)=b−b=0이므로 모든 해는 x₀에 영공간의 변위를 더한 꼴입니다.

import numpy as np

A = np.array([[1, 0, 1], [0, 1, 1], [1, 1, 2]])
x0 = np.array([2, 3, 0])
direction = np.array([-1, -1, 1])
print((A @ direction).tolist())
for t in (-1, 0, 1):
    x = x0 + t * direction
    print(x.tolist(), (A @ x).tolist())

실행 결과

[0, 0, 0]
[3, 4, -1] [2, 3, 5]
[2, 3, 0] [2, 3, 5]
[1, 2, 1] [2, 3, 5]

입력 차원을 두 숫자로 설명한다

A가 m행 n열이면 열공간은 ℝᵐ 안에 있고 영공간은 입력 공간 ℝⁿ 안에 있습니다. 피벗 변수 개수 r은 랭크입니다. 동차 방정식 Ax=0의 자유변수는 n−r개이고, 각각을 1, 나머지를 0으로 두어 얻는 해들이 영공간의 기저가 됩니다. 따라서 rank(A) + dim(ker A) = n입니다. 영공간의 차원 dim(ker A)를 퇴화차수(nullity)라고 하며, 이 관계를 차원 정리(랭크–퇴화차수 정리, rank–nullity theorem)라고 합니다.

이 정리로 해의 개수를 정리할 수 있습니다. b가 열공간에 있으면 해가 있고, 그때 영공간이 {0}뿐(rank=n)이면 해가 하나, 영공간 차원이 1 이상이면 해가 무수히 많습니다. 이 장의 A는 rank 2, n=3이라 영공간 차원이 1이고, b=(2,3,5)의 해는 직선 하나만큼 있습니다.

위 그림은 차원 개수의 관계를 보여 줍니다. 영공간과 열공간을 같은 공간의 두 부분으로 쪼갠 그림으로 읽으면 안 됩니다. m과 n이 다르면 두 공간의 벡터는 애초에 성분 개수가 다를 수 있습니다.

한 줄 정리

열공간은 해가 있는지를, 영공간은 해가 얼마나 많은지를 정하고, 둘의 차원은 rank + nullity = n으로 묶입니다.
