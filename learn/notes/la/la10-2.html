LA10·2

일반화 고유벡터와 조르당 사슬 만들기

A에서 고유값을 뺀 N을 반복해 적용합니다. 언제 영이 되는지 추적해 고유벡터만으로 채울 수 없었던 기저를 만들고, 핵의 차원만으로 블록 크기를 알아냅니다.

이 장을 읽고 나면

  • 일반화 고유벡터의 차수와 고유벡터에서 시작하는 사슬을 구분한다.
  • 2×2 및 3×3 행렬에서 직접 사슬을 만들어 조르당 블록을 얻는다.
  • 거듭제곱 핵의 차원으로 블록 크기를 결정하는 이유를 증명한다.

한 번에 0이 되지 않는 방향까지 조사한다

정사각행렬 A와 고유값 λ에 대해 N=A−λ I를 놓습니다. 고유벡터는 Nv=0인 0 아닌 벡터입니다. 이를 넓혀 어떤 양의 정수 j에서 Njv=0이 되는 0 아닌 벡터를 일반화 고유벡터라 부릅니다. 이 조건을 처음으로 만족하는 j를 차수라고 합시다. 고유벡터의 차수는 1입니다.

K0={0}, Kj=ker Nj로 씁니다. 한 번 영이 된 벡터에 N을 더 적용해도 영이므로 K0⊆ K1⊆ K2⊆⋯입니다. Kj∖ Kj−1에 있는 벡터의 차수는 j입니다. N을 몇 번 반복하더라도 모든 벡터가 영이 되는 것은 아닙니다. 이번 장의 행렬들은 특정 고유값에서 N이 공간 전체를 결국 영으로 보냅니다. 다음 장은 고유값이 여러 개면 어느 부분공간에 이 논증을 적용하는지 다룹니다.

차수 s인 vs를 골라 vs−1=Nvs, vs−2=N2vs처럼 내리면 v1=Ns−1vs≠0, Nv1=0입니다. 이렇게 생긴 (v1,…,vs)가 조르당 사슬입니다. Σj=1scjvj=0에 Ns−1을 적용하면 csv1=0만 남습니다. v1≠0이므로 cs=0이고, 남은 식에 Ns−2를 적용해 cs−1=0을 얻습니다. 차례로 해 보면 모든 계수가 0이라 사슬은 독립입니다.

행렬에서 보이는 자리. 이 사슬은 자기 생성 공간을 A가 보존합니다. Av1=λ v1, Avj=λ vj+vj−1 (j≥2)입니다. j번째 열에서 vj 계수는 λ, vj−1 계수는 1이므로, 사슬을 위 순서로 기저에 적으면 대각에 λ, 바로 위 대각선에 1인 조르당 블록 Js(λ)가 됩니다.

2×2에서 독립인 두 번째 방향을 복원한다

A=[[3, 1], [−1, 1]]라 합시다. det (tI−A)=(t−3)(t−1)+1=(t−2)2입니다. N=A−2I=[[1, 1], [−1, −1]]은 N(x,y)=(x+y,−x−y)로 작용합니다. 고유공간 x+y=0의 차원은 1이라 고유벡터만으로 대각화할 수 없습니다.

N≠0이지만 그 모든 출력의 두 좌표를 더하면 0이라 N2=0입니다. N의 핵 바깥에 있는 v2=(1,0)를 고르면 Nv2=(1,−1)=v1, Nv1=0입니다. 두 열의 행렬 P=[[1, 1], [−1, 0]]는 행렬식 1이어서 가역입니다. 아래 등식은 실제로 A가 두 벡터에 어떻게 작용하는지 쓴 것입니다.

Av1=2v1,  Av2=v1+2v2  ⇒   AP=P[[2, 1], [0, 2]].

같은 v1으로 시작해도 Nv2=v1의 해 v2는 유일하지 않습니다. v2+c v1도 같은 식을 만족합니다. 어느 해를 골라도 차수는 2이고, 같은 형태의 블록을 얻습니다.

3×3에서 오른쪽 끝부터 사슬을 만들고 핵을 센다

A=[[0, 1, 0], [0, 1, 1], [1, −1, 2]]에서 λ=1에 해당하는 방향을 찾아봅시다. N=A−I의 마지막 열을 바로 읽을 수 있도록 v3=(0,0,1)을 택했습니다. 이 선택부터 확인하고, 사슬이 완성된 뒤 세 벡터가 기저인지 판단합니다.

N=[[−1, 1, 0], [0, 0, 1], [1, −1, 1]],  Nv3=(0,1,1)=v2,  Nv2=(1,1,0)=v1,  Nv1=(0,0,0).

N2v3=v1≠0이라 가장 긴 사슬의 독립성으로 (v1,v2,v3)는 기저입니다. 이 좌표에서 N(a,b,c)=(b,c,0), N2(a,b,c)=(c,0,0), N3=0입니다. 따라서 K1=span(v1), K2=span(v1,v2), K3=ℝ3입니다. 차원은 순서대로 1,2,3, 계수는 2,1,0입니다. A는 이 기저에서 J3(1)이고, 특성다항식은 (t−1)3입니다.

다른 3차원 행렬에서도 N3=0이고 N≠0인 경우, dim K1이 2면 2와 1의 길이를 가진 별도의 사슬이 필요합니다. K1 차원이 1이면 길이 3 사슬 하나입니다. 다음 증명은 같은 방법이 임의의 유한차원에서 성립하는 이유를 설명합니다.

증명. 가장 높은 핵 층부터 내려오면 사슬 기저를 얻는다

어떤 m≥1에서 Nm=0인 유한차원 선형사상을 멱영(nilpotent)이라고 부릅니다. V=Km입니다. Kj/Kj−1은 Kj의 벡터 중에서 차이가 Kj−1에 속하는 것들을 같은 것으로 본 벡터공간입니다. 이 공간의 차원은 dim Kj−dim Kj−1입니다. Kj−1의 기저를 Kj의 기저로 확장하면 새로 보탠 벡터들의 동치류가 몫공간의 기저가 되기 때문입니다.

  1. 한 층 내리는 작용은 단사다. N은 Kj+1을 Kj로, Kj를 Kj−1로 보냅니다. 따라서 Kj+1/Kj의 대표자를 x에서 x+k (k∈ Kj)로 바꾸어도 Nx의 Kj/Kj−1 동치류는 그대로입니다. 이 대응이 영 동치류를 만들면 Nx∈ Kj−1이고, Nj−1(Nx)=0이라 x∈ Kj입니다. 그러므로 단사입니다.
  2. 높은 층에서 시작해 새 사슬을 보탠다. Km/Km−1에서 기저를 골라 실제 대표자들을 택합니다. 이 벡터들은 길이 m 사슬의 끝입니다. N을 적용해 바로 아래 층으로 가면 1단계의 단사성 때문에 그 동치류들이 여전히 독립입니다. 독립 목록을 Km−1/Km−2의 기저로 확장하고, 새 동치류의 대표자들은 길이 m−1 사슬의 끝으로 삼습니다. 같은 과정을 K1/K0까지 반복합니다.
  3. 각 층의 벡터들을 합치면 전체 기저다. 지금까지 모은 각 층의 벡터는 그 층의 몫공간 기저를 나타냅니다. 어떤 x∈ Kj는 그 기저에 맞춰 같은 층 벡터들의 선형결합을 빼면 Kj−1로 내려갑니다. 이를 반복하면 전체를 생성합니다. 선형관계가 있다면 항이 남은 가장 높은 층에서 몫공간으로 내려서 그 층의 계수가 모두 0임을 얻습니다. 같은 논증을 반복하면 모든 계수가 0이므로 독립입니다.

이제 각 층에 놓인 벡터를 세면, dj=dim Kj−dim Kj−1은 길이가 j 이상인 블록 수입니다. 길이 s인 사슬은 차수 1,2,…,s에 벡터 하나씩을 보태기 때문입니다. 따라서 길이가 정확히 j인 블록 수는 dj−dj+1이고, 길이의 목록은 사슬 벡터 선택과 관계없이 핵 차원으로 결정됩니다.

손계산을 작은 배열로 다시 검산한다

import numpy as np

cases = [
    (2, [[3, 1], [-1, 1]], [1, 0]),
    (1, [[0, 1, 0], [0, 1, 1], [1, -1, 2]], [0, 0, 1]),
]
for eigenvalue, entries, last in cases:
    a = np.array(entries)
    size = len(a)
    identity = np.eye(size, dtype=int)
    n = a - eigenvalue * identity
    tail = [np.array(last)]
    for _ in range(size - 1):
        tail.append(n @ tail[-1])
    p = np.column_stack(tail[::-1])
    j = eigenvalue * identity + np.diag(np.ones(size - 1, dtype=int), k=1)
    nullities = [size - int(np.linalg.matrix_rank(np.linalg.matrix_power(n, k)))
                 for k in range(1, size + 1)]
    print("P:", p.tolist())
    print("AP=PJ:", np.array_equal(a @ p, p @ j), "nullities:", nullities)
P: [[1, 1], [-1, 0]]
AP=PJ: True nullities: [1, 2]
P: [[1, 0, 0], [1, 1, 0], [0, 1, 1]]
AP=PJ: True nullities: [1, 2, 3]

Python 3.14.6, NumPy 2.5.4로 실행했습니다. 앞의 행렬 곱은 작은 정수로 정확하게 비교합니다. matrix_rank는 수치 연산으로 이 예들을 확인합니다. 핵의 차원은 본문처럼 사슬 기저에서 자유 좌표를 세어도 얻을 수 있습니다.
