가우스 소거: 연립식의 해가 한 개·없음·여러 개인 경우

행렬 A를 알고 출력 b도 안다면, 어떤 입력 x가 그 출력을 냈는지 되짚을 수 있을까요? 연립식을 행으로 적은 뒤 한 미지수씩 없애고, 해를 구할 수 없는 경우까지 가려냅니다.

이 장을 읽고 나면

  • Ax=b를 계수와 우변이 있는 연립식으로 해석한다.
  • 가우스 소거 중 행 연산을 오른쪽 항에도 동일하게 적용한다.
  • 모순 행·자유변수·피벗으로 해의 종류를 판정한다.

입력을 되찾는 문제 Ax=b

A=[[2,1],[1,3]], b=(7,11)인 사례를 봅니다. 첫 식은 2x+y=7, 둘째는 x+3y=11입니다. (x,y) 하나를 넣어서 두 수 7과 11을 동시에 만들어야 합니다.

행 하나를 바꿔도 해를 보존하는 방법

계수와 우변을 한 행에 놓은 표 첨가행렬 [A|b]를 씁니다. 식의 순서를 바꾸거나, 행을 0이 아닌 수로 곱하거나, 다른 행의 배수를 더해도 연립식의 해는 그대로입니다. 세 연산은 모두 되돌릴 수 있기 때문입니다. 우변은 같은 식의 일부이므로 같이 바꿉니다.

상태첫 행둘째 행
처음2  1  |  71  3  |  11
두 행 교환1  3  |  112  1  |  7
둘째 행 − 2×첫 행1  3  |  110  −5  |  −15

아래 행이 −5y=−15가 되어 y=3입니다. 첫 행에 넣으면 x=11−3×3=2입니다. 아래쪽에서 알아낸 값을 위 식에 넣는 것을 후진대입이라고 부릅니다.

검산

(2×2 + 3, 2 + 3×3) = (7,11)

처음 받은 식에 해를 넣어 두 우변과 비교합니다.

미지수 세 개에서 소거하기

가우스 소거는 왼쪽 위부터 열마다 한 행을 기준(피벗 행)으로 정하고, 그 아래 행들의 같은 열 값을 0으로 만드는 일을 반복해 계단 모양을 만든 뒤 후진대입으로 푸는 방법입니다. 미지수가 셋이어도 절차는 같습니다.

풀이 예제: 3×3 소거

x + y + z = 6, 2x + y − z = 1, x − y + 2z = 5

처음 [A|b]: [1 1 1 | 6], [2 1 −1 | 1], [1 −1 2 | 5]
① R₂ ← R₂ − 2R₁: [2−2, 1−2, −1−2 | 1−12] = [0 −1 −3 | −11]
② R₃ ← R₃ − R₁: [1−1, −1−1, 2−1 | 5−6] = [0 −2 1 | −1]
③ R₃ ← R₃ − 2R₂: [0, −2+2, 1+6 | −1+22] = [0 0 7 | 21]
계단 모양: [1 1 1 | 6], [0 −1 −3 | −11], [0 0 7 | 21]
후진대입: 7z = 21 → z = 3
−y − 3×3 = −11 → y = 2
x + 2 + 3 = 6 → x = 1

검산: (1+2+3, 2+2−3, 1−2+6) = (6, 1, 5). 피벗은 1, −1, 7의 세 개입니다.

해가 없거나 무한히 많은 경우

첫 식을 2x+y=7로 두고 둘째를 4x+2y=15로 바꾸면 둘째에서 첫째의 두 배를 뺐을 때 0x+0y=1이 남습니다. 모순이므로 해가 없습니다. 둘째가 4x+2y=14라면 같은 계산에서 0=0이 나옵니다. 새 제약이 없어 y를 임의로 정하고 x=(7−y)/2를 선택할 수 있습니다. 이렇게 피벗이 없는 열의 미지수를 자유변수라 하고, 피벗이 있는 열의 미지수(여기서 x)는 자유변수 값에 따라 정해집니다. 해집합은 y=t로 두어 (x, y) = ((7−t)/2, t), t는 임의의 실수로 씁니다. 그림으로는 두 식이 같은 직선이라 그 직선 위의 모든 점이 해입니다.

소거로 만든 계단 모양, 곧 행사다리꼴(row echelon form: 모든 원소가 0인 행은 맨 아래에 있고, 각 행의 첫 0 아닌 원소가 윗행의 것보다 오른쪽에 있는 모양)에서 0이 아닌 각 행의 첫 번째 0이 아닌 원소를 피벗이라고 합니다. 이때 계수 부분의 피벗 개수는 랭크(rank)입니다. 위의 원래 A에서는 2, 두 행이 비례하는 예에서는 1입니다. 모순 행의 우변에 1이 남더라도 그것을 A의 피벗에 넣지 않습니다. 행 연산 순서를 달리해도 피벗 개수는 같으므로 랭크는 행렬 하나에 하나로 정해집니다.

정리: 랭크로 해의 개수 판정 (미지수 n개)

rank(A) < rank([A|b]) → 해 없음 (모순 행 0 = c, c≠0이 생김)
rank(A) = rank([A|b]) = n → 해 하나 (자유변수 없음)
rank(A) = rank([A|b]) < n → 해 무한 (자유변수 n − rank개)

예: [[2,1|7],[4,2|15]]는 rank(A)=1, rank([A|b])=2라 해 없음. [[2,1|7],[4,2|14]]는 둘 다 1이고 n=2라 자유변수 1개. 실수 선형계의 해는 0개, 1개, 무한개 중 하나뿐입니다. 서로 다른 해 x₁, x₂가 있으면 A(x₁ + t(x₂−x₁)) = b + t(b−b) = b라서 그 둘을 잇는 직선 위의 모든 점이 해가 되기 때문입니다.

코드가 식을 만족하는지 확인한다

import numpy as np

A = np.array([[2, 1], [1, 3]])
b = np.array([7, 11])
x = np.linalg.solve(A, b)
redundant = np.array([[2, 1], [4, 2]])
print(x.round(6).tolist())
print(np.allclose(A @ x, b))
print(int(np.linalg.matrix_rank(A)), int(np.linalg.matrix_rank(redundant)))

실행 결과

[2.0, 3.0]
True
2 1

np.linalg.solve는 유일해가 있는 정사각 계수행렬에 사용합니다. 두 행이 비례하는 행렬을 넘기면 해 유형을 알려 주지 않고 LinAlgError: Singular matrix 오류를 냅니다(예: np.linalg.solve([[2,1],[4,2]], [7,15])). 해 없음과 해 무한을 구별하려면 위의 랭크 판정이나 소거 결과를 봅니다. matrix_rank는 수치 계산에서 작은 값을 0으로 볼 허용 오차를 쓰므로, 거의 비례하는 행렬의 결과는 단순한 정수 예와 다를 수 있습니다.

제약과 미지수를 각각 세기

식이 미지수와 똑같이 두 개라도 같은 식을 두 번 적으면 해를 하나로 고르지 못합니다. 식이 여럿이라고 해서 각 식이 모두 새로운 제약을 추가하는 것은 아닙니다. 예를 들어 x=0, y=0, x+y=0은 세 식이 서로 다르지만 마지막 식은 앞의 두 식을 더해 만들 수 있습니다. 랭크는 이렇게 중복되는 제약을 걸러 냈을 때 몇 개의 독립인 제약이 남는지 셉니다. 다음 장에서 어떤 b가 들어오더라도 역으로 풀 수 있게 하는 행렬을 살펴봅니다.
