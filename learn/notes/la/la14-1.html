LA14·1

양의 정부호 선형계를 이차함수의 최소점으로 읽기

매우 큰 행렬에서는 모든 소거 결과를 저장하기 어려울 수 있습니다. 해를 구하는 일을 이차함수를 낮추는 일로 바꾸고, 한 번의 정확한 선 탐색에서 이동 거리와 잔차가 어떻게 나오는지 유도합니다.

이 장을 읽고 나면

  • 실대칭 양의 정부호 선형계의 해가 이차함수의 유일한 최소점임을 보일 수 있다.
  • 한 방향의 정확한 최소 이동량을 구하고 잔차에 대한 직교 조건을 증명할 수 있다.
  • 잔차와 해의 오차가 다를 수 있음을 작은 예에서 확인할 수 있다.

선형계의 해와 그 주변의 높이

행렬 A가 실대칭 양의 정부호이고 b가 주어졌다고 합시다. 해 x*는 Ax*=b를 만족합니다. A가 정부호라면 영이 아닌 x에서 Ax=0일 수 없으므로 A는 가역이고 해는 하나입니다. 다음 이차 목적함수를 정의해 해 근처의 높이를 잽니다.

φ(x) = (1/2)xᵀAx − bᵀx

정부호 조건은 모든 방향의 이차항이 양수임을 뜻합니다. x=x*+e를 넣어 전개하면 선형 교차항 x*ᵀAe−bᵀe가 0입니다. Aᵀ=A이고 Ax*=b이기 때문입니다. 남은 차는 다음과 같습니다.

φ(x)−φ(x*) = (1/2)eᵀAe

e≠0이면 오른쪽은 양수입니다. 따라서 선형계의 해가 전역에서 유일한 최소점입니다. 에너지 노름 ‖e‖A=√(eᵀAe)를 쓰면 목적함수 차는 오차의 에너지 노름 제곱의 절반입니다. 이 노름은 보통의 길이와 방향별 배율이 다릅니다. 예를 들어 A=diag(1,9)이면 표준 길이는 둘 다 1인 e₁,e₂의 에너지 노름이 각각 1,3입니다.

한 방향의 정확한 이동 거리를 구한다

현재 x의 잔차를 r=b−Ax라고 씁니다. φ의 기울기는 Ax−b이므로 r은 기울기의 음수입니다. 임의의 방향 p≠0에서 x를 x+αp로 옮겨 봅니다. α에 따라 바뀌는 높이는

φ(x+αp)−φ(x) = −α pᵀr + (α²/2) pᵀAp

입니다. pᵀAp>0이므로 오른쪽은 위로 열린 포물선입니다. 미분을 0으로 두면 정확한 선 최소점은 α=(pᵀr)/(pᵀAp)입니다. 움직인 뒤 잔차 r′=r−αAp를 구하면 pᵀr′=pᵀr−αpᵀAp=0입니다. 지금 방향으로 조금 더 가도 높이가 줄지 않는다는 조건입니다. 다른 방향에 대한 조건까지 모든 경우에 주는 것은 아닙니다.

가장 가파른 방향에서 두 걸음 계산하기

A=[[4,1],[1,3]], b=(1,2), x₀=(0,0)으로 시작합니다. 이 방법은 매번 p=r을 택하므로 가장 가파른 하강법이라고 부릅니다. 첫 잔차 r₀=(1,2)이고 Ar₀=(6,7)입니다. 분자는 5, 분모는 1×6+2×7=20이므로 α₀=1/4입니다. x₁=(1/4,1/2)이고 r₁=(−1/2,1/4)입니다. r₀ᵀr₁=−1/2+1/2=0으로 방금 움직인 방향과 수직입니다.

다음에는 ‖r₁‖²=5/16, r₁ᵀAr₁=15/16이므로 α₁=1/3입니다. 따라서 x₂=(1/12,7/12)입니다. 정확한 해는 (1/11,7/11)이므로 두 걸음을 해도 아직 도착하지 않았습니다. 매번 새 잔차 방향에서 찾은 해는 앞에서 선택한 방향의 직교 조건을 유지할 필요가 없습니다. 다음 장에서 앞 방향으로 이미 낮춘 결과를 되돌리지 않는 선택을 만듭니다.

가장 가파른 하강법의 속도는 조건수 κ=λmax/λmin에 달려 있습니다. 정확한 선 탐색을 쓰면 한 걸음마다 ‖ek+1‖A ≤ ((κ−1)/(κ+1))‖ek‖A가 성립한다고 알려져 있습니다. 이 예에서 κ≈1.94라 상계 비율은 약 0.319이고, 실제 두 걸음의 비율은 각각 약 0.289입니다. κ가 크면 비율이 1에 가까워 잔차 방향이 지그재그로 오가며 느려집니다.

정확한 분수로 계산한 뒤 오차와 잔차를 구분한다

from fractions import Fraction as F

def dot(x, y):
    return sum(a * b for a, b in zip(x, y))

def apply_a(x):
    return (4 * x[0] + x[1], x[0] + 3 * x[1])

b = (F(1), F(2))
x = (F(0), F(0))
r = b
for step in range(2):
    ar = apply_a(r)
    alpha = dot(r, r) / dot(r, ar)
    x = tuple(a + alpha * z for a, z in zip(x, r))
    new_r = tuple(v - alpha * w for v, w in zip(r, ar))
    assert dot(r, new_r) == 0
    assert new_r == tuple(v - w for v, w in zip(b, apply_a(x)))
    r = new_r
    print(f"{step + 1}단계 α={alpha}, x={x[0]},{x[1]}, r={r[0]},{r[1]}")
assert apply_a((F(1,11), F(7,11))) == b
print("정확한 해: 1/11,7/11")

실행 결과

1단계 α=1/4, x=1/4,1/2, r=-1/2,1/4
2단계 α=1/3, x=1/12,7/12, r=1/12,1/6
정확한 해: 1/11,7/11

잔차는 주어진 식과 얼마나 일치하는지 보는 값 r=b−Ax입니다. 해의 오차 e=x−x*에 대해서는 r=−Ae입니다. A의 작은 고유값 방향으로 틀리면 e가 커도 r은 작을 수 있습니다. 예를 들어 A=diag(1,0.001)에서 e=(0,2)이면 r=(0,−0.002)입니다. 잔차만 작은 경우에도 A의 조건과 허용하는 계수 오차를 알아야 합니다.

한눈에 정리

공부할 기준결론
선형계와 최소화정부호 A에서 φ(x)−φ(x*)=‖x−x*‖²ₐ/2입니다.
정확한 선 탐색α=(pᵀr)/(pᵀAp)이고 새 잔차는 p와 직교합니다.
오차의 단위잔차는 r=−A(x−x*)라 오차와 방향별 크기가 다를 수 있습니다.
