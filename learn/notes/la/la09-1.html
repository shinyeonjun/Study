LA09·1

기저 좌표를 정의하고 서로 다른 좌표계 오가기

한 벡터를 서로 다른 기저로 읽으면 계수만 바뀝니다. 기울어진 평면 기저와 다항식에서 좌표를 구하고 두 좌표계 사이의 행렬을 직접 만듭니다.

이 장을 읽고 나면

  • 순서 있는 기저와 그 좌표열의 존재·유일성을 설명한다.
  • 비직교 기저에서 좌표를 내적 대신 연립식으로 구한다.
  • R²와 다항식 공간의 기저 변환 행렬을 양방향으로 만든다.

벡터와 그 벡터를 적은 숫자열을 구분한다

평면에서 점 하나의 이동을 (3,4)라고 적으면 보통 ‘오른쪽으로 3, 위로 4’라는 두 기준을 이미 정한 상태입니다. 움직임 자체를 바꾸지 않고 비스듬한 두 방향을 기준으로 다시 적을 수 있습니다. 같은 원리로 다항식 2+x+3x²도 어떤 다항식들을 기본 재료로 삼는가에 따라 다른 계수열로 표현할 수 있습니다.

아래에서는 실수 벡터공간 V의 유한하고 0이 아닌 차원을 n으로 둡니다. 순서 있는 목록 B=(b₁,…,bₙ)가 기저라는 조건이 두 가지 있습니다. 첫째, 모든 벡터를 그들의 선형결합으로 만들 수 있습니다(생성). 둘째, 그 결합으로 0을 만들 때는 계수가 전부 0이어야 합니다(선형독립). v=a₁b₁+⋯+aₙbₙ이면 열벡터 (a₁,…,aₙ)ᵀ를 B-좌표 [v]ᵦ라고 씁니다. 순서는 좌표의 각 칸이 가리킬 기저 벡터를 정합니다.

좌표가 정확히 하나 존재하는 이유

생성이 존재를 보장합니다. 두 계수열 a,c가 같은 v를 나타낸다고 하면 두 표현을 빼서 Σ(aᵢ−cᵢ)bᵢ=0을 얻습니다. 선형독립이므로 각 aᵢ−cᵢ=0입니다. 이렇게 정의한 좌표 사상 v↦[v]ᵦ는 덧셈과 스칼라배를 보존합니다. 예를 들어 두 좌표를 더한 뒤 같은 기저 벡터들과 곱해 합치면 두 원래 벡터의 합이 나오고, 유일성으로 그것이 합의 좌표입니다. 반대 사상은 계수열을 입력으로 받아 실제 벡터를 다시 만드는 a↦Σaᵢbᵢ입니다. 둘은 서로의 역입니다.

순서를 바꾸면 좌표의 칸도 바뀐다

기저가 (b₁,b₂)일 때 [v]ᵦ=(1,2)였다면, 같은 벡터의 (b₂,b₁) 좌표는 (2,1)입니다. 독립된 벡터를 덜 모으면 표현할 수 없는 벡터가 생기고, 종속된 목록으로 생성하면 같은 벡터에 여러 계수열이 생길 수 있습니다.

평면의 기울어진 기저에서는 연립식을 푼다

표준 기저를 E라 하고 b₁=(1,0), b₂=(1,2)를 B의 순서 있는 기저로 둡니다. 열에 이 기저를 모은 P=[[1,1],[0,2]]는 B-계수열을 받아 표준 좌표를 만듭니다. x=(3,4)의 B-좌표를 (s,t)라 하면 P(s,t)ᵀ=(3,4)ᵀ입니다. 둘째 식에서 2t=4라서 t=2, 첫째 식에서 s+t=3이라 s=1입니다. 거꾸로 1(1,0)+2(1,2)=(3,4)여서 검산됩니다.

이 기저에서 b₁·x=3, b₂·x=11은 (1,2)가 아닙니다. 직교정규 기저인 경우에만 각 원래 기저 벡터와의 내적으로 직접 계수를 읽을 수 있습니다. 순수하게 직교하지만 길이가 1이 아니면 각 내적을 그 기저 벡터 길이의 제곱으로 나눕니다. 일반 기저에서는 연립식을 풉니다. 이 예에선 식을 거꾸로 정리해 표준 좌표 (u,v)에서 t=v/2, s=u−v/2라는 좌표 변환식을 얻습니다.

새 기저가 바뀌는 방향을 열에서 읽는다

같은 공간에서 두 기저를 B와 C라고 합시다. 기저 변환 행렬 PC←B의 j번째 열을 [bⱼ]꜀로 둡니다. v=Σaⱼbⱼ일 때 C-좌표를 취하면 [v]꜀=Σaⱼ[bⱼ]꜀가 되므로 다음 식이 성립합니다.

[v]꜀ = PC←B[v]ᵦ,   PB←C = PC←B−1.

각 기저의 벡터를 표준 좌표로 적은 행렬이 PE←B와 PE←C이면 먼저 B에서 E로, 그 다음 E에서 C로 가면 됩니다. 따라서 PC←B=PE←C−1PE←B입니다. 차원을 맞추려고 임의로 곱 순서를 외우기보다, 오른쪽 인자가 결과가 필요한 좌표를 받아들이는지부터 확인합니다.

앞의 평면에서 C의 두 벡터를 (0,1),(2,1)로 택합시다. C-좌표 (a,b)가 주는 표준 벡터는 (2b,a+b)입니다. B의 첫 벡터 (1,0)으로 풀면 (−1/2,1/2), 둘째 (1,2)로 풀면 (3/2,1/2)입니다. 두 열을 모아 PC←B=[[−1/2,3/2],[1/2,1/2]]를 얻습니다. 이 행렬을 [x]ᵦ=(1,2)에 곱하면 [x]꜀=(5/2,3/2)입니다. 실제로 (5/2)(0,1)+(3/2)(2,1)=(3,4)입니다.

다항식에서도 같은 계산이 일어난다

𝒫₂는 차수가 2 이하인 실수 다항식과 영다항식의 공간입니다. 표준 단항 기저 E=(1,x,x²)에서 p=2+x+3x²는 (2,1,3)입니다. 새 기저로 B=(1,1+x,x+x²)를 사용합시다. 먼저 이 목록이 실제 기저인지 확인합니다. a·1+b(1+x)+c(x+x²)=(a+b)+(b+c)x+cx²의 계수가 모두 0이면 c=0,b=0,a=0만 나옵니다. 반대로 임의의 세 계수를 정하면 x² 계수부터 거꾸로 계산해 모두 나타낼 수 있습니다.

계수를 높은 차수부터 맞추기

p=2+x+3x²에 적용하면 c=3, b+c=1에서 b=−2, a+b=2에서 a=4입니다. B-좌표는 (4,−2,3)입니다. 각 기저 다항식의 계수열을 열에 한 개씩 쓰면 PE←B=[[1,1,0],[0,1,1],[0,0,1]]임도 확인할 수 있습니다. 추상적인 다항식의 변환에서도 무엇을 열에 넣는지 정하면 계산은 일반 행렬 곱으로 바뀝니다.

왜 그럴까?

기저 하나에서 다른 기저로 변환할 때 행렬의 j번째 열 하나만 구하려면 어떤 벡터를 새 기저로 표현할까요?

풀이 보기

원래 기저의 j번째 벡터를 새 기저로 표현합니다. 원래 기저에서 그 벡터의 좌표는 j번째만 1인 표준 열이므로, 변환 행렬이 그 열에 작용한 결과가 행렬의 j번째 열입니다.

손계산을 작은 배열로 다시 검산한다

import numpy as np

B = np.array([[1, 1], [0, 2]])
C = np.array([[0, 2], [1, 1]])
x = np.array([3, 4])
x_b = np.linalg.solve(B, x)
C_from_B = np.linalg.solve(C, B)
x_c = C_from_B @ x_b
print("B coords:", x_b.tolist())
print("C from B:", C_from_B.tolist())
print("C coords:", x_c.tolist())
assert np.array_equal(B @ x_b, x)
assert np.array_equal(C @ x_c, x)

basis = np.array([[1, 1, 0], [0, 1, 1], [0, 0, 1]])
p = np.array([2, 1, 3])
coords = np.linalg.solve(basis, p)
assert np.array_equal(basis @ coords, p)
print("polynomial coords:", coords.tolist())
B coords: [1.0, 2.0]
C from B: [[-0.5, 1.5], [0.5, 0.5]]
C coords: [2.5, 1.5]
polynomial coords: [4.0, -2.0, 3.0]

코드의 solve(C, B)는 B의 열을 오른쪽 항으로 하나씩 푸는 계산입니다. 예제에서는 정수와 1/2 단위 값이 정확히 표현돼 직접 대조했습니다. 다음 장에선 좌표만 바꾸는 행렬 두 개 사이에 실제 변환을 넣어 보겠습니다.
