LA01·2

벡터 덧셈과 스칼라곱: 방향과 성분으로 계산하기

오른쪽으로 두 칸, 위로 한 칸 움직인 뒤 오른쪽으로 세 칸, 위로 두 칸 이동합니다. 성분별 계산과 그림이 같은 결과 (5,3)을 주는 이유를 확인하고, 실제 자료에서 같은 계산을 쓸 조건을 살펴봅니다.

이 장을 읽고 나면

  • 같은 차원의 벡터를 성분별로 더하고 뺀다.
  • 스칼라를 곱했을 때 그림과 각 성분의 변화를 설명한다.
  • 두 관측의 차이 벡터와 평균 벡터를 구한다.

같은 자리끼리 합친다

u = (2,1), v = (3,2)로 둡니다. u + v에서는 x 성분끼리 더하고 y 성분끼리 더합니다. 두 변위를 이어 붙인 결과는 (2+3,1+2) = (5,3)입니다.

u를 먼저 그린 뒤 그 끝을 v의 시작점으로 옮깁니다. 그림에서는 세 화살표가 있고 계산에는 가로·세로 성분이 따로 있습니다. 같은 차원의 벡터를 더할 때 u+v와 v+u는 같습니다. 각 성분의 덧셈이 순서에 영향을 받지 않기 때문입니다.

스칼라를 각 성분에 곱한다

c·u는 u의 각 성분을 c배 한 벡터입니다. u=(2,1)이라면 2u=(4,2), (1/2)u=(1,0.5), −u=(−2,−1)입니다. 양수 곱은 0이 아닌 화살표의 방향을 유지하고 음수 곱은 방향을 뒤집습니다. 0을 곱하면 영벡터가 됩니다.

뺄셈 u−v는 v를 반대로 뒤집어 더하는 것입니다. 점 P=(2,1), Q=(5,3)에서 P에서 Q로 가는 변위는 끝−시작인 Q−P=(3,2)입니다. P−Q는 반대 방향입니다.

데이터 두 줄에 적용하기

월요일 특징 (120건, 32분), 화요일 (136건, 28분)을 보겠습니다. 화요일−월요일은 (16건, −4분)입니다. 첫 성분이 16 늘고 둘째가 4 줄었습니다. 두 날을 똑같이 한 번씩 세는 평균 벡터는 (128건, 30분)입니다.

이 둘째 평균은 하루의 평균 배송 시간에 같은 무게를 준 결과입니다. 배송 한 건씩 같은 무게로 평균을 내는 문제라면 날마다 배송 건수를 알아야 합니다. 벡터 계산은 각 성분에 같은 규칙을 적용하지만, 보고서에 쓸 분모는 분석 질문이 정합니다.

import numpy as np

previous = np.array([120, 32])
current = np.array([136, 28])
print((current - previous).tolist())
print(((previous + current) / 2).tolist())
print((2 * np.array([2, 1])).tolist())

실행 결과

[16, -4]
[128.0, 30.0]
[4, 2]

모양만 같아서 생기는 실수

(건, 분)과 (명, 시)를 더하면 자리가 두 개라 코드에서는 계산할 수 있습니다. 같은 의미와 단위의 성분끼리 비교하는 식인지 먼저 살펴야 합니다. 모양이 다르면 NumPy가 브로드캐스팅하는 경우도 있습니다. 행이나 열의 모양이 달라졌다면 연산 결과의 shape와 의도를 같이 검사합니다.

검산 기준

같은 종류의 성분끼리 비교했나요? 부호를 반대로 쓰지 않았나요? 편차나 평균을 만들 때 분모가 분석에서 세려는 단위와 맞나요?
