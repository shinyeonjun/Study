LA09·2

같은 선형 사상을 다른 행렬로 쓰는 닮음 변환

미분이라는 한 연산을 두 기저에서 계산합니다. 닮음은 어느 두 행렬이 같은 변환을 다른 좌표로 적은 것인지 알려 줍니다.

이 장을 읽고 나면

  • 정의역과 공역의 기저가 행렬의 열과 모양을 정하는 이유를 설명한다.
  • 닮음식을 좌표의 경로에서 얻고 뒤집힌 곱 순서를 확인한다.
  • 다항식 미분 행렬을 만들고 닮음에서 보존되는 양을 증명한다.

입력 기저와 출력 기저를 지정해야 행렬이 정해진다

선형 사상 T:V→W에서 정의역 V의 기저가 B=(b₁,…,bₙ), 공역 W의 기저가 C=(c₁,…,cₘ)라고 합시다. 선형이라는 조건은 T(au+bv)=aT(u)+bT(v)입니다. 각 bⱼ를 T에 보낸 뒤 출력 T(bⱼ)의 C-좌표를 열에 넣습니다. 이렇게 만든 행렬을 [T]C←B라 쓰면 m개의 출력 좌표와 n개의 입력 좌표를 연결하는 m×n 행렬입니다.

왜 열 규칙만으로 모든 벡터의 결과를 얻을까요? 입력을 v=Σaⱼbⱼ로 쓰면 선형성으로 Tv=ΣaⱼTbⱼ입니다. 출력 좌표도 같은 계수의 선형결합이므로, 행렬 곱에서 j번째 열에 aⱼ를 곱해 더하는 것과 같습니다. 예로 다항식 a+bx+cx²를 (p(0),p′(0))로 보내는 사상에서 단항 기저와 R² 표준 기저를 쓰면 열은 (1,0),(0,1),(0,0)입니다.

하나의 공간에서 입력과 출력 기저를 함께 바꾼다

이제 W=V인 선형 연산자를 생각합니다. Aᴇ=[T]E←E, Aᵦ=[T]B←B이고, P=PE←B입니다. B-좌표를 받고 결과도 B-좌표로 적고 싶습니다. 먼저 P로 E-좌표로 바꾸고, Aᴇ로 실제 사상을 적용한 뒤 P⁻¹로 다시 B-좌표로 옵니다.

Aᵦ = P−1AᴇP.

이 관계를 가진 두 정사각행렬을 닮음(similarity)이라고 합니다. P를 임의의 가역행렬로 주어도, 그 열들을 기존 기저의 좌표로 해석하면 새로운 순서 있는 기저가 됩니다. 단순히 계수표를 바꾸는 과정입니다. 등가식 AᴇP=PAᵦ는 두 행렬 곱에 임의의 B-좌표를 각각 넣어 같은 E-좌표 결과를 얻으면 증명됩니다.

정의역과 공역을 독립적으로 바꾸는 경우

정의역과 공역이 다르거나, 같은 공간에서 입력과 출력에 별개 기저를 사용하는 경우에는 양쪽 변환 행렬이 서로 역이라는 보장이 없습니다. 각 인자를 ‘새 입력 좌표→옛 입력 좌표→옛 출력 좌표→새 출력 좌표’ 순서로 읽습니다. 예컨대 R²의 항등 사상을 표준 입력 기저와 출력 기저 (2e₁,e₂)로 적으면 diag(1/2,1)입니다. I와 이 행렬은 같은 사상을 서로 다르게 적었지만 닮음 관계는 아닙니다. I를 어떤 가역행렬로 닮음 변환해도 I 그대로이기 때문입니다.

다항식의 미분 행렬을 두 번 만든다

예제에서 𝒫₂는 차수 2 이하의 실수 다항식 공간이고, D(p)=p′로 둡니다. D는 결과를 𝒫₂ 안에 내보내는 선형 연산자입니다. 단항 기저 E=(1,x,x²)에서는 D(1)=0, D(x)=1, D(x²)=2x이므로 세 열을 바로 적습니다.

새 기저 B=(1,1+x,x+x²)에서 첫 열은 0, 둘째 열은 D(1+x)=1의 좌표 (1,0,0)입니다. 셋째 열의 함수 D(x+x²)=1+2x는 −1·1+2(1+x)+0(x+x²)라서 좌표 (−1,2,0)입니다. 셋째 열에 표준 좌표 (1,2,0)를 그대로 넣으면 출력의 기저를 섞은 표가 됩니다.

앞 장의 다항식 p=2+x+3x²의 B-좌표는 (4,−2,3)입니다. Aᵦ를 곱하면 (−5,6,0)이 되고, 이것을 B에서 복원하면 −5+6(1+x)=1+6x입니다. 표준 기저에서도 직접 미분하면 같은 결과입니다. 변환 행렬 P=[[1,1,0],[0,1,1],[0,0,1]]로 AᴇP를 구하고 PAᵦ=AᴇP라는 선형계를 풀어도 위의 결과가 나옵니다.

닮음에서 보존되는 양을 식으로 확인한다

임의의 스칼라 λ에서 Aᵦ−λI=P⁻¹(Aᴇ−λI)P입니다. (Aᵦ−λI)u=0이면 (Aᴇ−λI)Pu=0입니다. 반대 방향에서 P⁻¹을 써 되돌릴 수 있으므로, 고유공간의 차원이 같습니다. 특히 u가 0이 아닌 벡터라면 Pu도 0이 아닙니다. P가 가역이기 때문입니다.

행렬식의 곱셈 성질을 적용하면 det(tI−Aᵦ)=det(P⁻¹)det(tI−Aᴇ)det(P)=det(tI−Aᴇ)입니다. 따라서 특성다항식, 그 뿌리인 고유값과 그 중복도가 보존됩니다. Aᵦ의 치역은 Aᴇ의 치역을 P⁻¹로 옮긴 것이므로 랭크도 같습니다. 한편 두 행렬이 특성다항식만 같다고 닮음이라는 결론은 나오지 않습니다. I₂와 [[1,1],[0,1]]는 특성다항식이 모두 (t−1)²이지만 첫 행렬의 1-고유공간은 2차원, 둘째는 1차원입니다. 이 차이를 LA10에서 더 나눠 봅니다.

검산할 자리

표준 행렬 diag(2,3)에 P=[[1,1],[0,1]]로 좌표를 바꾸면 B-행렬은 [[2,−1],[0,3]]입니다. 이 행렬의 3-고유벡터 (−1,1)에 P를 곱하면 (0,1)이 되어 표준 행렬의 고유벡터가 됩니다. 3이라는 배율은 그대로입니다.

손계산을 작은 배열로 다시 검산한다

import numpy as np

A_e = np.array([[0, 1, 0], [0, 0, 2], [0, 0, 0]])
P = np.array([[1, 1, 0], [0, 1, 1], [0, 0, 1]])
A_b = np.linalg.solve(P, A_e @ P).astype(int)
b_coords = np.array([4, -2, 3])
print("B matrix:", A_b.tolist())
print("derivative in B:", (A_b @ b_coords).tolist())
print("derivative in E:", (P @ A_b @ b_coords).tolist())
assert np.array_equal(P @ A_b, A_e @ P)
assert np.array_equal(P @ b_coords, [2, 1, 3])

D = np.diag([2, 3])
S = np.array([[1, 1], [0, 1]])
M = np.linalg.solve(S, D @ S).astype(int)
u = np.array([-1, 1])
assert np.array_equal(M @ u, 3*u)
print("same eigenvector in E:", (S @ u).tolist())
B matrix: [[0, 1, -1], [0, 0, 2], [0, 0, 0]]
derivative in B: [-5, 6, 0]
derivative in E: [1, 6, 0]
same eigenvector in E: [0, 1]

이 예의 정수 변환은 피벗이 1인 삼각행렬을 풀어서 얻습니다. 출력의 astype(int)는 이 예에서 계산값이 정확한 정수라는 사실을 사용한 표현입니다. 일반적인 실수 변환 행렬에 이 변환을 적용하면 나머지 값을 잃습니다.
