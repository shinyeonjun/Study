선형변환의 넓이와 방향을 재는 행렬식

정사각형을 행렬로 보냈을 때 넓이와 방향이 어떻게 달라지는지 봅니다. 그 배율이 0인 경우에 왜 처음 위치를 되찾을 수 없는지도 확인합니다.

이 장을 읽고 나면

  • 2×2 행렬식의 절댓값을 넓이 배율로, 부호를 방향으로 읽는다.
  • 행렬식이 0인 경우 기저 방향이 겹쳐 공간이 납작해지는 이유를 말한다.
  • 행 연산과 삼각행렬의 대각으로 작은 행렬식을 계산한다.

단위 정사각형이 어디로 가는지 본다

행렬 A의 첫째 열은 기본 방향 e₁=(1,0)을 보낸 위치이고, 둘째 열은 e₂=(0,1)을 보낸 위치입니다. 원래의 두 방향으로 만든 단위 정사각형은 두 열벡터를 변으로 하는 평행사변형으로 바뀝니다. 행렬식 det A는 정사각행렬에 대해 구하는 수입니다. 2차원에서는 절댓값이 넓이의 배율이며, 부호는 두 기저 방향의 순서가 뒤집혔는지를 나타냅니다.

A=[[a,b],[c,d]]이면 det A = ad−bc.

예로 열벡터가 (3,1), (1,2)라면 det A = 3×2−1×1 = 5입니다. 한 열에서 다른 열의 배수를 빼는 것은 평행사변형의 밑변이나 높이를 기준으로 옆으로 미는 일이라 넓이를 바꾸지 않습니다. 두 열을 바꾸면 모양은 같고 먼저 읽는 방향이 바뀌어 행렬식이 −5입니다.

넓이가 0이면 역변환에 필요한 정보가 사라진다

B=[[1,2],[2,4]]의 두 열은 각각 (1,2), (2,4)입니다. 둘째 열이 첫째 열의 두 배라 변환한 점이 모두 한 직선 위에 놓입니다. det B=1×4−2×2=0입니다. 예를 들어 서로 다른 입력 (2,0)과 (0,1)은 모두 (2,4)로 갑니다. 출력만 보고 원래 입력을 하나로 고를 방법이 없습니다.

일반적인 n×n 실수 행렬에서 |det A|는 n차원 부피의 배율입니다. det A=0이면 열들이 선형독립이 아니므로 어떤 방향을 잃었고 역행렬이 없습니다. det A≠0이면 모든 방향을 보존하므로 역행렬이 있습니다. 합성에서는 배율과 방향이 이어져 det(AB)=det A·det B가 됩니다.

n×n 행렬식의 정의와 자주 쓰는 성질

3×3 이상에서는 한 행(또는 열)을 따라 펼치는 여인수 전개로 정의할 수 있습니다. 첫 행으로 펼치면 det A = Σⱼ (−1)1+j a1j det A1j이고, A1j는 1행과 j열을 지운 (n−1)×(n−1) 행렬입니다. 계산량이 커서 실제로는 아래 절의 소거를 씁니다.

  • det(Aᵀ)=det A. 그래서 행에 대한 규칙은 열에도 그대로 성립합니다.
  • det(AB)=det A·det B, 가역이면 det(A⁻¹)=1/det A.
  • n×n에서 det(cA)=cⁿ det A. 모든 행에 c가 곱해지기 때문이며, c·det A가 아닙니다.
  • det(A+B)는 일반적으로 det A+det B가 아닙니다.

소거하며 부호와 배율을 기록한다

상삼각행렬의 행렬식은 대각 원소의 곱입니다. 소거로 위쪽 삼각형을 만들 때 행을 맞바꾸면 행렬식의 부호가 바뀝니다. 한 행에 상수 c를 곱하면 행렬식도 c배가 됩니다. 한 행에 다른 행의 배수를 더하는 연산은 행렬식을 바꾸지 않습니다.

예로 M의 세 행이 (0,2,1), (3,1,4), (3,1,5)입니다. 첫 두 행을 바꾼 후 셋째 행에서 새 첫째 행을 빼면 대각 원소 3,2,1의 상삼각행렬 U가 됩니다. det U=6이고 부호가 한 번 바뀌었으므로 det M=−6입니다. 첫 행으로 여인수 전개를 해도 0·(1·5−4·1) − 2·(3·5−4·3) + 1·(3·1−1·3) = 0−6+0 = −6으로 같습니다.

실수 연산에서 계산한 행렬식은 반올림 오차가 있을 수 있습니다. 크기만 보고 역행렬 계산이 얼마나 안정한지 판단하기도 어렵습니다. 예로 단위행렬에 아주 작은 스칼라를 곱하면 행렬식은 매우 작아도 방향 사이의 상대적인 찌그러짐은 없습니다.

넓이 배율과 소거 계산 결과를 대조한다

import numpy as np

A = np.array([[3, 1], [1, 2]])
B = np.array([[1, 2], [2, 4]])
M = np.array([[0, 2, 1], [3, 1, 4], [3, 1, 5]])
U = np.array([[3, 1, 4], [0, 2, 1], [0, 0, 1]])
assert np.isclose(np.linalg.det(M), -np.prod(U.diagonal()))

for name, matrix in [("A", A), ("swapped", A[:, ::-1]), ("B", B), ("M", M)]:
    det = np.linalg.det(matrix)
    printed = 0.0 if abs(det) < 1e-12 else det
    print(f"{name}: {printed:.1f}")
A: 5.0
swapped: -5.0
B: 0.0
M: -6.0

출력은 소수 첫째 자리로 표시했습니다. 작은 값의 표시를 다듬는 코드의 기준을 일반적인 가역성 판정에 쓰지는 않습니다.

한 줄 정리

행렬식은 정사각 선형변환의 부피 배율(절댓값)과 방향(부호)이고, 0이면 열이 종속이라 역행렬이 없습니다.
