피벗이 있는 가우스 소거에서 PA=LU가 성립하는 이유

가우스 소거에서 0이나 매우 작은 수로 나누어야 할 때 행을 바꿉니다. 그때 이미 기록한 소거 배수도 함께 움직여야 하는 이유를 3×3 예와 함께 증명합니다.

이 장을 읽고 나면

  • 부분 피벗 선택의 기준과 소거 배수를 계산할 수 있다.
  • 행 교환을 P와 이전 L에 기록해 PA=LU를 유도할 수 있다.
  • 여러 우변을 두 삼각 풀이로 풀고 분해와 잔차를 검산할 수 있다.

0으로 나누지 않고 소거를 시작한다

A=[[0,2,1],[2,1,0],[4,1,2]]를 소거해 봅시다. 첫 번째 행을 기준으로 첫 열을 지우려면 피벗 0으로 나누어야 합니다. 아래에는 2와 4가 있으므로 첫 행을 바꿀 수 있습니다. 현재 열에서 아직 소거하지 않은 행 중 절댓값이 가장 큰 성분을 피벗으로 선택하는 방법을 부분 피벗이라고 합니다. 이 예에서는 첫째 행과 셋째 행을 바꿔 4를 위로 올립니다.

절댓값 최대 피벗을 쓰면 그 열의 다른 성분을 피벗으로 나눈 배수의 절댓값은 1 이하입니다. 예를 들어 아래 값 2를 지우는 배수는 2/4=1/2입니다. 이 국소적인 조건은 실수 연산 전체에서 오차가 얼마나 쌓일지 자동으로 보장하지는 않습니다. 소거 중 다른 성분이 얼마나 커지는지, 원래 A의 조건수가 어떤지도 실제 오차에 영향을 줍니다.

소거를 거꾸로 읽으면 아래 삼각 인자가 된다

행 i에서 아래의 특정 성분을 없애기 위해 행 k의 ℓik배를 빼면, 반대 연산은 행 k의 같은 배수를 더하는 것입니다. 첫 단계에서 피벗 행 u₁의 ℓi1배를 빼면 이후 행에 첫 열이 0인 남은 부분이 생깁니다. 그 행을 복구할 때는 피벗 행의 배수 ℓi1만큼을 더해야 합니다. 이 수를 첫 열 아래에 저장합니다.

k단계 이후의 행을 일반적으로 읽으면, 이미 정해진 위 삼각행렬 U의 행 u₁,…,uₖ와 저장된 배수 ℓi1,…,ℓik의 선형결합에 아직 남은 미처리 행을 더한 것이 원래 행입니다. 다음 피벗으로 i행과 j행의 자리를 서로 바꾸면 원래 행과 미처리 행의 대응도 바뀝니다. 그래서 이전까지 저장한 배수도 i와 j 사이에서 교환합니다. 이 대응을 유지하며 끝까지 소거하면 미처리 부분이 사라지고, 교환을 반영한 각 원래 행이 U 행들의 결합으로 표현됩니다.

분해의 식

P는 원래 행의 순서를 바꾼 순열행렬, L은 대각이 1이고 아래에 소거 배수를 담은 행렬, U는 소거를 마친 위 삼각행렬입니다. 행 교환과 소거를 일관되게 기록하면 PA=LU입니다. Ax=b를 풀 때는 좌변 행만 바꾸지 말고 우변도 Pb로 바꿉니다.

두 번째 피벗에서 이미 계산한 값도 옮긴다

첫 피벗 뒤 원래 행의 순서는 (3,2,1)입니다. 둘째 행 (2,1,0)에서 피벗 행의 1/2을 빼면 (0,1/2,−1)이고, 셋째 행 (0,2,1)은 배수 0이라 그대로입니다. 둘째 열의 피벗은 2이므로 둘째·셋째 행을 다시 바꿉니다. 이때 첫 열의 배수 1/2와 0도 함께 움직입니다. 그러고 나면 둘째 열에서 아래 값을 없애는 배수는 (1/2)/2=1/4이며 마지막 성분은 −1−(1/4)=−5/4입니다.

최종 행PA의 원래 행 번호L의 행U의 행
13(1,0,0)(4,1,2)
21(0,1,0)(0,2,1)
32(1/2,1/4,1)(0,0,−5/4)

셋째 행을 다시 만들어 봅시다. (1/2)(4,1,2)+(1/4)(0,2,1)+(0,0,−5/4)=(2,1,0)입니다. 만약 두 번째 행 교환에서 첫 소거 배수를 옮기지 않았다면, L의 셋째 행 첫 배수가 0이어서 원래 행의 첫 값 2를 되살리지 못했을 것입니다.

분해를 검산하고 우변을 풀어 본다

b=(7,4,12)이면 Pb=(12,7,4)입니다. Lz=Pb의 첫 값 12와 둘째 값 7을 대입하면 셋째 값은 4−(1/2)×12−(1/4)×7=−15/4입니다. Ux=z에서는 마지막부터 x₃=3, x₂=2, x₁=1을 얻습니다. 아래 구현은 찾은 순열과 배수를 직접 저장한 뒤 분해를 확인합니다. 두 삼각계는 하나씩 대입해 풉니다. np.linalg.solve는 원래 Ax=b를 두 번째 방법으로 풀어 결과를 검산하는 데 사용합니다.

import numpy as np

a = np.array([[0., 2., 1.], [2., 1., 0.], [4., 1., 2.]])
u = a.copy()
n = len(a)
permutation = np.arange(n)
l = np.eye(n)
for k in range(n):
    pivot = k + np.argmax(np.abs(u[k:, k]))
    if u[pivot, k] == 0:
        raise ValueError("zero pivot in this example")
    u[[k, pivot], :] = u[[pivot, k], :]
    permutation[[k, pivot]] = permutation[[pivot, k]]
    l[[k, pivot], :k] = l[[pivot, k], :k]
    for row in range(k + 1, n):
        multiplier = u[row, k] / u[k, k]
        l[row, k] = multiplier
        u[row, k:] -= multiplier * u[k, k:]
        u[row, k] = 0.0

b = np.array([7., 4., 12.])
z = np.empty(n)
for k in range(n):
    z[k] = b[permutation[k]] - l[k, :k] @ z[:k]
x = np.empty(n)
for k in range(n - 1, -1, -1):
    x[k] = (z[k] - u[k, k+1:] @ x[k+1:]) / u[k, k]
assert np.allclose(a[permutation, :], l @ u)
assert np.allclose(a @ x, b)
assert np.allclose(np.linalg.solve(a, b), x)
print("원래 행 번호:", (permutation + 1).tolist())
print("U의 대각:", np.diag(u).tolist())
print("중간 벡터:", z.tolist())
print("해:", x.tolist())

비용과 한계를 같이 기록한다

밀집 행렬에서 각 피벗은 남은 행과 열의 사각 블록을 갱신합니다. 상수배로 보면 단계별 작업은 (n−1)²,(n−2)²,…,1이고 합은 O(n³)입니다. 분해한 뒤 한 우변에 대해 각 삼각형을 한 번씩 훑는 비용은 O(n²)입니다. 같은 A에 우변이 여러 개면 분해를 한 번 쓰고 순열과 삼각 풀이를 반복할 수 있습니다.

이 코드는 정확한 0만 검사하는 작은 예제입니다. 수치적으로 거의 특이한 자료를 판별하려면 스케일과 오차를 고려한 별도 기준을 적용합니다. 배수가 커지는 문제는 피벗으로 줄일 수 있습니다. 예를 들어 A=[[10⁻⁸,1],[1,1]]을 위 행 그대로 풀면 첫 배수는 10⁸이고 행을 바꾸면 10⁻⁸입니다. 그것만으로 참 해에 대한 모든 오차가 사라지는 것은 아닙니다. 계산된 PA와 LU의 차이, Ax와 b의 잔차, 조건수는 각각 다른 정보를 제공합니다.
