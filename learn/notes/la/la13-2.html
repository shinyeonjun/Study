Householder 반사로 QR을 만들고 직교성을 검사하기

벡터를 그대로 투영하고 빼는 대신, 길이를 보존하는 반사로 열의 아래 성분들을 한꺼번에 0으로 만듭니다. 반사가 왜 직교인지 증명하고, 거의 겹치는 열에서 두 QR 계산의 결과를 비교합니다.

이 장을 읽고 나면

  • 반사 행렬 H의 대칭성과 H²=I를 사영에서 유도할 수 있다.
  • 벡터를 좌표축으로 보내는 반사 방향을 계산할 수 있다.
  • QR 검산에서 재구성 오차와 직교성 오차를 별도로 측정할 수 있다.

한 성분만 반대로 돌리는 변환

0이 아닌 벡터 v가 지정한 방향에 대한 사영은 P=vvᵀ/(vᵀv)입니다. P는 x에서 v 방향만 뽑습니다. Px는 v 방향으로 남고, x−Px는 v에 수직입니다. 이 수직 성분을 고정하고 v 방향 성분만 부호를 바꾸면 Hx=(x−Px)−Px=(I−2P)x입니다. 이것을 Householder 반사라고 합니다.

Pᵀ=P이고 P²=P입니다. 따라서 Hᵀ=H이고 HᵀH=H²=(I−2P)²=I−4P+4P²=I입니다. 이 식은 반사를 연달아 두 번 하면 원래 위치, 한 번만 해도 내적과 길이는 보존된다는 뜻입니다. 수치 계산에서는 큰 정방 행렬 H를 만들어 저장하지 않고 x−2v(vᵀx)/(vᵀv)를 적용할 수 있습니다.

한 열의 아래 성분을 동시에 0으로 만들기

현재 열의 남은 부분이 a라고 합시다. a를 첫 좌표축 e₁의 α배로 보내려면 길이를 보존하기 위해 α²=‖a‖²여야 합니다. v=a−αe₁를 놓습니다. v가 0이 아닌 경우, vᵀa=‖a‖²−αa₁이고 vᵀv=‖a‖²−2αa₁+α²=2vᵀa입니다. 반사 식에 대입하면 Ha=a−v=αe₁입니다.

a의 첫 성분과 반대 부호의 α를 고르면 v의 첫 성분을 만들 때 크기가 비슷한 수를 빼지 않습니다. a=(3,4)이면 ‖a‖=5, α=−5, v=(8,4)입니다. vᵀv=80이므로 P의 네 성분을 계산해 H=[[-3/5,−4/5],[−4/5,3/5]]을 얻습니다. H를 a에 곱한 결과는 (−5,0)입니다.

한 열씩 영역을 좁혀 간다

첫 번째 열을 반사해 첫 대각 아래 성분을 0으로 만듭니다. 다음에는 둘째 행 이하만 반사해 둘째 열의 꼬리를 없앱니다. 반사를 이미 소거한 행 위에는 항등변환처럼 확장하면 앞 열의 0은 그대로 남습니다. Hk까지 왼쪽에서 곱해 R=Hk⋯H₂H₁A가 되면, 역순을 적용하는 식으로 A=(H₁H₂⋯Hk)R을 얻습니다. 괄호가 Q입니다. 직교행렬의 곱은 직교행렬입니다.

코드에는 열 두 개짜리 A=[[3,0],[4,0],[0,2]]를 넣습니다. 첫 반사 후 첫 열의 피벗은 −5이고, 둘째 열의 꼬리는 (0,2)로 남습니다. 둘째 반사에서 첫 성분 0의 부호를 양으로 취해 α=−2로 정하면 최종 R은 [[−5,0],[0,−2],[0,0]]입니다. 부호를 달리 고르는 구현은 다른 Q,R을 주지만 각각 알맞게 곱하면 같은 A입니다. 완전한 Q의 앞 두 열과 R의 처음 두 행만 남기면 얇은 QR입니다.

분해가 맞는 것과 기저가 직교하는 것을 따로 검사한다

범위가 작은 예제로 알고리즘을 직접 구현하고, 별도의 거의 종속인 예에서 고전 Gram–Schmidt도 비교합니다. 고전 방식은 원래 열을 앞 기저 각각에 사영한 값을 구한 다음 한꺼번에 뺍니다. 원래 열의 큰 공통 부분을 빼면 작은 성분만 남습니다. 이 계산에서 생긴 오차가 새 벡터의 정규화에 의해 커지면, 이후 벡터가 이전 기저와 수직이라는 성질을 잃을 수 있습니다. 수식이 틀렸다는 뜻보다 부동소수점에서 어떤 형식으로 계산하는지의 문제입니다.

import numpy as np

def householder(a):
    r = a.copy().astype(float)
    q = np.eye(r.shape[0])
    for k in range(r.shape[1]):
        v = r[k:, k].copy()
        length = np.linalg.norm(v)
        if length == 0:
            continue
        v[0] += np.copysign(length, v[0])
        v /= np.linalg.norm(v)
        r[k:, k:] -= 2 * np.outer(v, v @ r[k:, k:])
        q[:, k:] -= 2 * np.outer(q[:, k:] @ v, v)
    return q, r

def classical(a):
    q = np.zeros_like(a)
    for j in range(a.shape[1]):
        previous = q[:, :j]
        column = a[:, j]
        tail = column - previous @ (previous.T @ column)
        q[:, j] = tail / np.linalg.norm(tail)
    return q

simple = np.array([[3., 0.], [4., 0.], [0., 2.]])
q, r = householder(simple)
shown = np.where(np.abs(r) < 1e-12, 0., r)
assert np.allclose(q @ r, simple)
print("삼각형 R:", shown.round(3).tolist())

nearly_parallel = np.vstack((np.ones(3), 1e-8 * np.eye(3)))
cgs = classical(nearly_parallel)
q, r = householder(nearly_parallel)
thin = q[:, :3]
loss = lambda basis: np.max(np.abs(basis.T @ basis - np.eye(basis.shape[1])))
assert np.allclose(q @ r, nearly_parallel, rtol=1e-12, atol=1e-14)
print("고전 방법의 내적 오차 > 0.1:", bool(loss(cgs) > 0.1))
print("반사의 내적 오차 < 1e-12:", bool(loss(thin) < 1e-12))

실행 결과

삼각형 R: [[-5.0, 0.0], [0.0, -2.0], [0.0, 0.0]]
고전 방법의 내적 오차 > 0.1: True
반사의 내적 오차 < 1e-12: True

Householder 구현은 행 수가 열 수보다 크거나 같은 실수 행렬을 받습니다. 비교용 고전 방법은 열이 독립이며 입력을 부동소수 배열로 준다는 조건도 사용합니다. 두 판정의 임계값은 이 예를 비교하기 위한 것입니다. 실제 자료에서는 ‖QR−A‖/‖A‖와 ‖QᵀQ−I‖에 맞는 노름과 허용 오차를 함께 적습니다. 첫 번째만 작으면 A를 잘 재구성했음을, 두 번째까지 작으면 새 좌표축이 거의 정규직교함을 확인합니다.

연산량과 반올림 오차 비교

곱셈과 덧셈을 하나씩 센 부동소수점 연산(flop) 수의 주요 항으로 비교하면, n×n 행렬의 부분 피벗 LU는 약 (2/3)n³, m×n 행렬의 Householder QR은 약 2mn²−(2/3)n³입니다. 정사각 행렬이면 QR이 약 (4/3)n³으로 LU의 두 배 정도입니다. 최소제곱에서 정규방정식은 AᵀA를 만드는 데 약 mn², Cholesky에 약 n³/3이 들어 QR보다 싸지만, 앞 장에서 본 것처럼 조건수가 제곱됩니다. 오차 쪽에서는 Householder QR이 직교 변환만 쓰므로 후방 안정(계산 결과가 A를 아주 조금 바꾼 문제의 정확한 답)이고, 계산된 Q의 ‖QᵀQ−I‖가 단위 반올림 정도로 작습니다. 고전 Gram–Schmidt는 위 실험처럼 직교성을 크게 잃을 수 있고, 수정 Gram–Schmidt도 잃는 정도가 대략 κ(A)에 비례합니다. 정확한 상수와 증명은 Trefethen–Bau, Golub–Van Loan의 해당 장을 봅니다.
