LA08·1

특이값 분해로 입력과 출력의 축을 나누기

정사각형이 아닌 행렬에는 입력과 출력의 크기부터 다를 수 있습니다. 두 공간의 축을 따로 잡아 각 방향이 얼마나 늘어나고 어디로 향하는지 계산합니다.

이 장을 읽고 나면

  • 직사각행렬을 입력 방향·특잇값·출력 방향으로 나눈다.
  • AᵀA의 고유값에서 특잇값을 계산하고 0의 의미를 읽는다.
  • 전체 SVD와 간소 SVD의 배열 모양을 구분한다.

직사각행렬도 방향별 배율로 설명한다

고유벡터 식 Av=λv는 입력과 출력이 같은 차원에서 성분별로 비교될 때 씁니다. 3×2 행렬은 두 수를 받아 세 수를 내놓으므로 입력과 출력의 방향을 따로 준비합니다. 특이값 분해(SVD)는 실수 m×n 행렬 A를 A=UΣVᵀ로 씁니다. V는 입력 공간의 직교정규기저, U는 출력 공간의 직교정규기저이고, Σ는 m×n 직사각형 행렬로, (i,i) 자리에만 음이 아닌 특잇값(singular value) σᵢ가 있고 나머지는 0입니다. 특잇값은 관례상 σ₁ ≥ σ₂ ≥ … ≥ σp ≥ 0 (p=min(m,n)) 순서로 놓습니다. 모든 실수 행렬은 SVD를 가지며, 특잇값은 하나로 정해지지만 U와 V는 부호 등에서 여러 가지로 고를 수 있습니다.

오른쪽부터 Vᵀ가 입력을 고른 축들의 좌표로 바꿉니다. Σ가 축마다 길이를 곱하고 U가 결과를 출력의 축에 기록합니다. 양의 특잇값 σi에 대응하는 오른쪽 특이벡터 vi와 왼쪽 특이벡터 ui는 Avi=σiui입니다. 고유분해와 달리 u와 v는 다른 공간에 속할 수 있습니다.

AᵀA가 입력에서 길이의 제곱을 알려 준다

A의 행이 (0,2), (3,0), (0,0)이라고 합시다. A(1,0)=(0,3,0), A(0,1)=(2,0,0)입니다. 앞의 두 벡터를 각각 단위 방향으로 나누면 그림처럼 입력의 두 축이 출력에서 길이 3과 2인 서로 수직인 축이 됩니다.

AᵀA는 두 열의 내적을 모은 행렬입니다. 두 열의 길이 제곱이 9와 4, 교차 내적이 0이므로 AᵀA=diag(9,4)입니다. 그 고유벡터 v₁=(1,0), v₂=(0,1)에 대해, A를 곱한 벡터의 길이가 각각 √9=3, √4=2입니다.

일반적으로 AᵀA=VΣᵀΣVᵀ입니다. 따라서 AᵀA의 고유값은 특잇값의 제곱과 필요한 0들입니다. 양의 σi에서는 ui=Avi/σi로 계산할 수 있습니다. σ가 0인 방향은 A가 영벡터로 보내니 0으로 나누지 않습니다. 0보다 큰 특잇값의 개수가 A의 랭크입니다.

같은 방식으로 AAᵀ=UΣΣᵀUᵀ입니다. 그래서 V의 열은 AᵀA(n×n)의 고유벡터, U의 열은 AAᵀ(m×m)의 고유벡터이고, 두 행렬의 0이 아닌 고유값은 똑같이 σᵢ²입니다. 이 예에서 AAᵀ=diag(4,9,0)이고 고유값 9, 4의 고유벡터가 u₁=(0,1,0), u₂=(1,0,0)입니다. 특잇값은 대칭이 아닌 행렬의 고유값과 다릅니다. 예를 들어 [[0,1],[0,0]]은 고유값이 0, 0이지만 특잇값은 1, 0입니다.

전체 기저가 필요할 때와 줄여서 저장할 때

기본 전체 분해에서 U는 m×m, Σ는 m×n, Vᵀ는 n×n입니다. p=min(m,n)이라 하면, 간소 SVD는 U의 처음 p개 열, Vᵀ의 처음 p개 행, p×p 대각 행렬 Σr를 씁니다. 행렬 A를 정확히 복원한다는 점은 같습니다. 간소 분해는 필요한 모양을 잘라 보관할 뿐, 양의 특잇값을 버리는 저랭크 근사와 다릅니다. 이 장에서 아래 첨자 r은 "줄인(reduced)"의 뜻입니다. 랭크 r개의 양의 특잇값까지만 남기는 더 작은 분해(compact SVD)도 A를 정확히 복원합니다. 버린 항의 특잇값이 모두 0이기 때문입니다.

위 3×2 예의 간소 모양은 Uᵣ 3×2, Σᵣ 2×2, Vᵣᵀ 2×2입니다. NumPy는 Σᵣ에 넣을 값들을 길이 2인 배열 s로 돌려줍니다. U * s에서 s가 U의 열에 맞춰 곱해집니다. 손계산에서는 AᵀA의 고유값으로 특잇값을 구하지만, 라이브러리의 SVD는 AᵀA를 만들지 않습니다. AᵀA를 만들면 조건수가 제곱되어(LA06·3) 작은 특잇값이 반올림 오차에 묻힐 수 있기 때문입니다.

간소 분해로 원래 행렬을 복원해 본다

import numpy as np

A = np.array([[0, 2], [3, 0], [0, 0]])
U, s, Vt = np.linalg.svd(A, full_matrices=False)
reconstructed = (U * s) @ Vt
x = np.array([1, 2])

assert np.allclose(reconstructed, A)
assert np.allclose(s**2, np.linalg.eigvalsh(A.T @ A)[::-1])
print("shapes:", U.shape, s.shape, Vt.shape)
print("singular values:", s.tolist())
print("Ax:", (A @ x).tolist())
shapes: (3, 2) (2,) (2, 2)
singular values: [3.0, 2.0]
Ax: [4, 3, 0]

부호가 동시에 바뀐 u,v 두 벡터도 같은 곱을 만듭니다. 그래서 구현마다 특이벡터의 부호가 달라도, 특잇값과 복원한 행렬은 같을 수 있습니다.

한눈에 정리

구성역할
Vᵀ입력 공간의 축에서 좌표를 읽는다.
Σ각 축의 값에 특잇값을 곱한다.
U출력 공간의 축에 좌표를 놓는다.
양의 특잇값살아남은 독립 방향의 개수가 랭크다.
특잇값 계산σᵢ = √(AᵀA의 고유값). V는 AᵀA, U는 AAᵀ의 고유벡터.
모양전체: U m×m, Σ m×n, Vᵀ n×n / 간소: m×p, p×p, p×n (p=min(m,n)).

한 줄 정리

SVD A=UΣVᵀ는 모든 실수 행렬을 입력 축 회전(Vᵀ), 축별 늘이기(σ₁≥σ₂≥…≥0), 출력 축 배치(U)로 나누며, 특잇값은 AᵀA 고유값의 제곱근입니다.
