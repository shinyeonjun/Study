행렬의 두 관점: 숫자 표와 선형변환

숫자 표의 행·열은 데이터 저장에도 쓰이고, 입력 벡터를 바꾸는 계산 규칙에도 쓰입니다. 숫자 배열의 모양에서 출발해 선형변환의 각 열이 어떤 방향의 변화를 담는지 확인합니다.

이 장을 읽고 나면

  • 행렬의 행·열·원소 위치를 읽는다.
  • 선형변환의 조건과 변환 행렬의 열을 연결한다.
  • 정사각 행렬과 항등행렬을 구별한다.

행과 열의 순서를 지킨 숫자 표

매장 두 곳의 세 가지 특징이 다음과 같습니다. 행이 매장, 열이 특징입니다.

매장주문 수평균 분반품 수
A120324
B136288

숫자 부분은 2행 3열 행렬입니다. m행 n열 행렬을 m×n 행렬이라 하고, (m, n)을 그 행렬의 모양(shape)이라고 합니다. 이 표는 2×3입니다. aij는 i번째 행, j번째 열의 원소입니다. 수학에서 첫 행과 첫 열을 1로 세면 a23=8입니다. NumPy에서는 0부터 세므로 A[1, 2]가 같은 자리를 찾습니다. 행과 열의 수가 같으면 정사각 행렬입니다. 행과 열이 다르더라도 행렬이 될 수 있습니다.

입력 벡터를 다른 벡터로 바꾸기

이번에는 다른 행렬을 봅니다. 입력 (x,y)를 두고 T(x,y)=(2x+y, y)로 보내는 규칙입니다. 첫째 출력의 x 계수는 2, y 계수는 1입니다. 둘째 출력의 x 계수는 0, y 계수는 1입니다. 이를 행으로 적으면 A = [[2,1],[0,1]]입니다.

입력계산출력
(1,0)(2×1+0, 0)(2,0)
(0,1)(2×0+1, 1)(1,1)
(2,3)(2×2+3, 3)(7,3)

첫 번째 단위벡터 e₁=(1,0)의 출력은 A의 첫 번째 열 (2,0)입니다. 두 번째 e₂=(0,1)의 출력은 둘째 열 (1,1)입니다. 입력 (x,y)는 x·e₁ + y·e₂이므로, 아래에서 정의할 선형성에 의해 출력은 T(x,y) = x·T(e₁) + y·T(e₂), 즉 두 열을 x와 y만큼 곱해 더한 것입니다. (2,3)이면 2×(2,0)+3×(1,1)=(7,3)입니다.

이것이 행렬–벡터 곱 Ax의 정의입니다. 같은 값을 두 방향으로 읽을 수 있습니다. 열로 읽기: Ax = x₁·(A의 1열) + … + xn·(A의 n열). 행으로 읽기: Ax의 i번째 성분 = (A의 i행)·x, 즉 i행과 x의 내적. 예에서 첫 행 (2,1)·(2,3) = 7, 둘째 행 (0,1)·(2,3) = 3으로 같은 (7,3)이 나옵니다. A의 열 수와 x의 성분 수가 같아야 곱이 정의됩니다.

언제 선형변환이라고 할까

두 보존 조건

선형변환 T는 입력 벡터 합의 출력을 각각 출력한 합으로 바꾸어도 같고, 입력을 스칼라 c배 한 결과도 출력의 c배와 같습니다.

T(u+v) = T(u)+T(v),   T(cu) = cT(u)

실수 공간 ℝⁿ에서 ℝᵐ으로 가는 선형변환은 좌표계를 정하면 m×n 행렬로 나타낼 수 있습니다. T(x,y)=(2x+y,y)는 해당하지만, S(x,y)=(2x+y+3,y)는 영벡터를 (3,0)으로 보내므로 해당하지 않습니다. S는 선형변환 뒤에 고정된 위치 이동을 더한 예입니다. 고등학교의 일차함수 f(x)=2x+3은 그래프가 직선이지만 f(0)=3≠0이고 f(1+1)=7≠f(1)+f(1)=10이라서 선형대수의 선형변환이 아닙니다. 이런 '선형변환 + 평행이동'은 아핀(affine) 변환이라고 따로 부릅니다. T(0) = T(0·u) = 0·T(u) = 0이므로, 영벡터를 영벡터로 보내지 않으면 곧바로 선형이 아닙니다(반대로 T(0)=0이라고 해서 선형이 보장되지는 않습니다).

입력을 그대로 보내는 행렬

2차원에서 I=[[1,0],[0,1]]은 (x,y)를 (x,y) 그대로 보냅니다. 대각선이 1, 나머지가 0인 정사각 행렬을 항등행렬이라고 합니다. I가 나타내는 변환은 항등변환입니다.

import numpy as np

A = np.array([[2, 1], [0, 1]])
x = np.array([2, 3])
I = np.eye(2, dtype=int)
print(A.shape)
print((A @ x).tolist())
print((I @ x).tolist())

실행 결과

(2, 2)
[7, 3]
[2, 3]

행렬의 역할을 먼저 읽는다

데이터 표의 열은 기록할 특징이고 관측이 추가되면 행이 늘어납니다. 변환 행렬의 각 행은 출력 성분 하나의 계산식을 담고, 각 열은 입력 단위 방향에서 나오는 출력입니다. 숫자 표의 생김새만 보고 역할을 확정하지 말고 그 행렬이 무엇을 표현하도록 정했는지 읽습니다.
