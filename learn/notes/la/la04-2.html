행렬 곱의 순서와 변환의 합성

평면을 가로로 두 배 키운 뒤 밀어 옮길 때와, 먼저 밀고 두 배 키울 때 결과가 달라집니다. 행렬 곱 AB가 어떤 변환부터 적용하는지 그림과 수로 확인합니다.

이 장을 읽고 나면

  • 열벡터 표기에서 변환 합성의 순서를 읽는다.
  • 곱의 교환이 일반적으로 되지 않는 예를 계산한다.
  • 결합법칙, 전치의 순서 뒤집기와 여러 관측에 한 번에 적용하기를 연결한다.

두 변환을 하나씩 따라가기

가로를 두 배 늘리는 A(x,y)=(2x,y)와 높이 y만큼 오른쪽으로 미는 B(x,y)=(x+y,y)를 생각합니다. B는 모든 점을 같은 거리만큼 옮기는 이동과 달리 높이에 비례해 바꿉니다. 점 (1,1)에 A를 먼저 쓰면 (2,1), 그 뒤 B를 쓰면 (3,1)입니다.

반대로 먼저 B를 써도 이 입력의 중간점은 (2,1)입니다. 여기에서 A를 쓰면 (4,1)입니다. 우연히 중간 위치가 같아도 마지막에 적용하는 변환이 다르기 때문에 끝점이 다릅니다.

어느 행렬이 먼저 작용하나

열벡터 x에 A를 적용한 뒤 B를 적용하면 B(Ax)=(BA)x입니다. x에 가까운 쪽부터 먼저 적용합니다. 이 예에서 A=[[2,0],[0,1]], B=[[1,1],[0,1]]이므로

기록 순서합성 행렬x=(1,1)에 적용
A 뒤 BBA=[[2,1],[0,1]](3,1)
B 뒤 AAB=[[2,2],[0,1]](4,1)

곱을 서로 바꾸는 교환법칙은 일반적으로 성립하지 않습니다. 게다가 AB와 BA 중 한쪽만 모양이 맞을 수도 있습니다. A가 2×3, B가 3×4이면 AB는 2×4이지만 BA에 필요한 가운데 차원 4와 2는 다릅니다.

순서를 두고 괄호를 바꿀 수 있다

A의 열 수가 B의 행 수와 같고, B의 열 수가 C의 행 수와 같으면 (AB)C=A(BC)입니다. 양쪽 모두 C를 먼저, B를 다음, A를 마지막에 적용하는 합성입니다. 이것이 결합법칙입니다. 전치를 취할 때는 (AB)ᵀ = BᵀAᵀ로 순서가 바뀝니다.

왜 순서가 뒤집히나: 성분으로 확인

A가 m×n, B가 n×p라고 합시다. 양변의 j행 i열 성분을 비교합니다.

((AB)ᵀ)ⱼᵢ = (AB)ᵢⱼ = Σₖ AᵢₖBₖⱼ
(BᵀAᵀ)ⱼᵢ = Σₖ (Bᵀ)ⱼₖ(Aᵀ)ₖᵢ = Σₖ BₖⱼAᵢₖ

실수 곱 BₖⱼAᵢₖ = AᵢₖBₖⱼ이므로 모든 성분이 같습니다. 모양으로도 확인됩니다. (AB)ᵀ는 p×m이고 BᵀAᵀ는 (p×n)(n×m) = p×m입니다. 순서를 그대로 둔 AᵀBᵀ는 (n×m)(p×n)이라 p = m이 아니면 곱 자체가 정의되지 않습니다. 예를 들어 A가 2×3, B가 3×2이면 (AB)ᵀ는 2×2인데 AᵀBᵀ는 3×3입니다.

흔한 실수

(AB)ᵀ를 AᵀBᵀ로 쓰는 실수입니다. 양말을 신고 신발을 신었다면 벗을 때는 신발부터 벗는 것처럼, 곱의 전치와 곱의 역행렬((AB)⁻¹ = B⁻¹A⁻¹, 다음 단원)은 모두 순서를 뒤집습니다.

import numpy as np

A = np.array([[2, 0], [0, 1]])
B = np.array([[1, 1], [0, 1]])
x = np.array([1, 1])
print((B @ A @ x).tolist())
print((A @ B @ x).tolist())
print(np.array_equal((A @ B).T, B.T @ A.T))

실행 결과

[3, 1]
[4, 1]
True

관측을 행으로 쌓았다면

지금까지 변환은 입력 열벡터 x를 A에 넣었습니다. 데이터 표의 관측을 행으로 쌓으면 i번째 행은 xᵢᵀ입니다. 각각의 출력 Axᵢ를 행으로 보관하려면 (Axᵢ)ᵀ = xᵢᵀAᵀ를 씁니다. 관측 표 X가 n행 d열, A가 m행 d열이면 X @ A.T는 n행 m열입니다.

import numpy as np

A = np.array([[2, 1], [0, 1]])
X = np.array([[1, 1], [2, 3], [0, 3]])
Y = X @ A.T
print(Y.tolist())
print(Y.shape)

실행 결과

[[3, 1], [7, 3], [3, 3]]
(3, 2)

다음 장에서 풀 질문

입력 x를 알면 Ax를 계산할 수 있습니다. 출력 b를 알 때 원래 입력을 되찾는 문제는 Ax=b입니다. 모든 b에 하나의 입력이 있는지, 전혀 없는 경우와 여러 개인 경우는 어떻게 찾는지 살펴봅니다.

한 줄 정리

행렬 곱은 변환의 합성이라 순서가 중요하고, 괄호는 옮길 수 있지만 순서는 바꿀 수 없으며, 전치하면 순서가 뒤집힙니다.
