SP02·3

영상·문자·소리를 같은 사건의 표현으로 비교하기

같은 사건을 설명한 문장, 사진, 소리 조각을 공통 벡터로 바꿉니다. 어떤 방식에서 맞는 사진을 더 자주 찾는지 작은 자료로 계산합니다.

이 장을 읽고 나면

  • 입력 종류가 달라도 공통 공간의 점수로 비교할 수 있음을 설명한다.
  • 모달리티별 검색 정밀도를 계산한다.
  • 소리의 시간 정렬과 융합 결과를 검증한다.

자료의 종류는 다르고 비교할 목표는 공유한다

사진은 픽셀 배열, 문장은 토큰열, 소리는 시간에 따라 달라지는 압력 변화의 표본입니다. 소리는 파형 그대로 처리하거나 짧은 구간의 주파수 성분을 펼친 스펙트로그램으로 바꿀 수 있습니다. 입력을 처리하는 인코더는 종류별로 달라도, 끝에서 같은 크기의 벡터를 출력하도록 학습하면 서로 내적할 수 있습니다.

표현 정렬의 한 방법은 같은 사건의 사진과 설명, 또는 같은 시간에서 녹음한 소리의 벡터 점수를 높이는 것입니다. 앞 단원의 대조 학습처럼 맞는 쌍과 비교 후보를 정의합니다. 영상의 소리를 쓸 때는 어떤 시간 구간이 장면과 연결됐는지 기록합니다. 장면 밖 소리가 섞였거나 글이 사건의 다른 측면만 말하면 모든 쌍이 같은 개념으로 정렬된다고 단정할 수 없습니다.

정의 · 대조 학습으로 두 모달리티 정렬하기 (CLIP 방식)

짝이 맞는 사진–문장 N쌍을 한 묶음으로 넣고, 두 인코더의 출력을 길이 1로 정규화한 벡터 u_i(사진), v_j(문장)를 얻습니다. 길이 1인 벡터의 내적은 코사인 유사도와 같습니다. 유사도 행렬 s_ij = u_i·v_j / τ (τ는 온도)에서 사진 i의 정답은 문장 i 하나이고 나머지 N−1개는 오답 후보입니다. 각 행에 softmax 교차 엔트로피를 걸면 −log( exp(s_ii) / Σ_j exp(s_ij) )이고, 이 손실(InfoNCE)을 문장→사진 방향으로도 계산해 평균합니다. 학습이 끝나면 맞는 쌍의 유사도는 크고, 틀린 쌍은 작아집니다.

이 장의 사진·문장·소리 벡터는 모두 길이가 1이므로(예: 0.8²+0.6²=1) 아래에서 이들끼리 계산한 내적은 곧 코사인 유사도입니다. 뒤에서 가중합한 질의 벡터 [0.75,0.65]는 길이가 1이 아니므로 그 점수는 내적 그대로 읽습니다.

사진을 찾는 질문에서 모달리티를 따로 평가한다

‘종’ 문장 벡터 [0.8,0.6]을 세 사진과 내적하면 순서대로 0.8,0.6,−0.8이라 종 사진이 1위입니다. 같은 사건의 소리 벡터 [0.6,0.8]로는 0.6,0.8,−0.6이라 발자국 사진이 1위에 옵니다. 각 사건의 문장·소리에 대해 올바른 사진 한 장이 정해져 있으면, 검색 1위가 정답인 질문의 비율을 계산할 수 있습니다. 세 질문에서 문장→사진은 3/3, 소리→사진은 2/3입니다.

여러 자료를 함께 받을 때 결합하는 위치에 따라 두 방식으로 나눕니다. 초기 융합(early fusion)은 모달리티별 특징이나 표현을 먼저 이어 붙이거나 섞어 하나의 모델에 넣고, 후기 융합(late fusion)은 모달리티마다 따로 점수·예측을 낸 뒤 그 점수를 평균·가중합합니다. 이 예의 종 사건에서 문장에 0.75, 소리에 0.25를 주면 질의 벡터가 [0.75,0.65]라 종 사진 점수가 가장 높습니다. 내적은 선형이므로 질의 벡터를 가중합한 뒤 내적한 점수(0.75, 0.65, −0.75)는 문장 점수와 소리 점수를 같은 가중치로 더한 값(0.75×0.8+0.25×0.6=0.75 등)과 같습니다. 즉 이 예에서는 두 방식이 같은 결과를 냅니다. 비선형 신경망 안에서 섞으면 일반적으로 달라집니다. 가중치를 늘렸을 때 언제나 새 자료의 성능이 좋아진다는 뜻은 아닙니다. 가중치를 고르는 자료와 마지막 시험을 분리하고, 입력 종류가 빠졌을 때도 따로 기록합니다.

결합한 자료가 실제로 같은 원본에서 왔는지 살핀다

실제 데이터에서는 같은 연속 영상의 겹치는 소리 조각을 서로 다른 분할에 넣지 않고, 참조할 원본이나 사건을 기준으로 구분합니다. 평가 기준에서 사진 여러 장이 모두 타당하게 대응할 수 있다면 그 정답 집합을 먼저 표시합니다. 이 코드는 타당한 사진을 사건당 하나만 둔 가장 작은 예입니다.

images = [(1, 0), (0, 1), (-1, 0)]
texts = [(0.8, 0.6), (0, 1), (-1, 0)]
sounds = [(0.6, 0.8), (0, 1), (-1, 0)]

def scores(query):
    return [sum(x*y for x,y in zip(query, image)) for image in images]

def best(query):
    return max(enumerate(scores(query)), key=lambda row: row[1])[0]

for channel in (texts, sounds):
    picked = [best(query) for query in channel]
    print("top-1:", picked, "accuracy:", f"{sum(x==i for i,x in enumerate(picked))/len(picked):.6f}")
combined = tuple(0.75*t + 0.25*a for t,a in zip(texts[0], sounds[0]))
print("fused scores:", [round(x, 2) for x in scores(combined)])
top-1: [0, 1, 2] accuracy: 1.000000
top-1: [1, 1, 2] accuracy: 0.666667
fused scores: [0.75, 0.65, -0.75]

사진의 행 번호 0,1,2가 각각 종, 발자국, 비의 정답입니다. 서로 다른 모달리티를 하나에 넣는 모델에서도 자료가 어디서 왔는지, 어느 방향으로 검색하는지와 입력 누락 조건을 명시합니다.
