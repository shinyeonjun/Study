SP08·1

시간 표를 이산 푸리에 변환으로 읽기

네 번 측정한 값에서 어느 속도로 반복하는 성분이 있는지 찾습니다. 복소수 회전으로 점수를 계산하고 같은 변환을 FFT로 검산합니다.

이 장을 읽고 나면

  • DFT의 시간 인덱스와 주파수 인덱스를 구분한다.
  • 간단한 코사인 샘플의 푸리에 계수를 계산한다.
  • FFT와 역변환, 실제 주파수의 관계를 설명한다.

시간의 네 값에서 반복 패턴을 찾는다

1초에 한 번 반복하는 코사인을 1초에 네 번 측정했습니다. 시간은 0, 0.25, 0.5, 0.75초이고 표본값은 [1,0,−1,0]입니다. 각도가 한 바퀴 도는 동안의 가로 좌표를 네 곳에서 읽은 값입니다.

길이 N의 이산 푸리에 변환(DFT)은 각 후보 k에서 x[n]에 복소수 회전 cos(2πkn/N)−i sin(2πkn/N)을 곱해 n=0부터 N−1까지 더합니다. +i와 −i로 회전 방향을 정할 수 있는데, 여기서는 NumPy의 전방 변환 약속에 따라 −i를 사용합니다. |X[k]|가 크면 그 회전 성분이 신호에 많이 들어 있다는 뜻입니다.

DFT와 역변환

X[k] = Σn=0N−1 x[n]·e−2πikn/N, k=0, …, N−1
x[n] = (1/N)·Σk=0N−1 X[k]·e+2πikn/N
오일러 공식 eiθ=cos θ+i sin θ에 따라 e−2πikn/N은 위의 회전 cos(2πkn/N)−i sin(2πkn/N)과 같습니다. 1/N을 어느 쪽에 둘지는 라이브러리마다 다를 수 있고, NumPy 기본값은 역변환 쪽에 둡니다.

무엇과 곱할지 네 점으로 계산한다

후보 k수열에 곱할 네 회전 계수X[k]
0[1, 1, 1, 1]0
1[1, −i, −1, i]2
2[1, −1, 1, −1]0
3[1, i, −1, −i]2

k=0은 단순합 1+0−1+0=0입니다. k=1에서는 첫째 항 1과 셋째 항 (−1)×(−1)이 더해져 2입니다. 이 실수 신호의 k=1과 k=3은 양·음 방향의 한 쌍입니다. k=3은 표본에서 k=−1과 같은 회전을 나타냅니다. 진폭으로 환산할 때는 이 짝을 함께 봅니다. 실수 코사인 A·cos(2πkn/N)(0<k<N/2)는 이 약속에서 |X[k]|=|X[N−k]|=AN/2를 만듭니다. 여기서는 A=1, N=4라 2입니다. 따라서 진폭은 2|X[k]|/N으로 읽습니다. 짝이 없는 k=0 칸과(N이 짝수일 때) k=N/2 칸은 |X[k]|/N입니다. 정규화 약속이 다르면 이 환산도 달라집니다.

FFT로 같은 DFT를 더 빨리 계산한다

위 정의의 직접 구현은 N개 k에 대해 N개 항을 계산합니다. 고속 푸리에 변환(FFT)은 그 합의 중복 구조를 재사용하는 계산법입니다. 같은 DFT 계수를 구하지만, 예를 들어 2의 거듭제곱 길이에서 분할 정복으로 O(N log N) 연산에 구할 수 있습니다. 역변환은 반대 부호의 회전과 N으로 나누는 규칙으로 원래 표본을 복구합니다.

from cmath import exp
from math import pi
import numpy as np

x = np.array([1, 0, -1, 0])
n = len(x)
slow = [sum(int(x[t])*exp(-2j*pi*k*t/n) for t in range(n))
        for k in range(n)]
fast = np.fft.fft(x)
assert np.allclose(slow, fast, atol=1e-12)
restored = np.fft.ifft(fast)
assert np.allclose(restored.real, x, atol=1e-12)
print("계수 실수부:", [round(v.real) for v in fast])
print("주파수 Hz:", [int(f) for f in np.fft.fftfreq(n, d=0.25)])
print("복원:", [round(v.real) for v in restored])

실행 결과

계수 실수부: [0, 2, 0, 2]
주파수 Hz: [0, 1, -2, -1]
복원: [1, 0, -1, 0]

표본 간격 d가 0.25초라 표본 빈도는 4Hz입니다. N=4이면 주파수 칸 사이의 간격은 4/4=1Hz입니다. FFT 결과에 실제 단위를 붙이려면 배열 길이뿐 아니라 표본 간격도 알아야 합니다.
