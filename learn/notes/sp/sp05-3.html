SP05·3

GNN 층이 이웃 메시지를 모으는 방법

노드의 자체 정보와 가까운 이웃의 정보를 한 값에 모읍니다. 작은 그래프에서 한 층을 계산하고, 더 많은 층이나 미래의 연결이 결과에 어떻게 영향을 주는지 살펴봅니다.

이 장을 읽고 나면

  • 메시지·집계·갱신의 역할을 구분한다.
  • 자기 루프를 포함한 이웃 평균과 선형 갱신을 계산한다.
  • 학습에서 볼 수 있는 노드·간선과 예측 시점을 확인한다.

노드 하나의 표현을 갱신

그래프 신경망은 간선으로 연결된 이웃을 통해 노드 표현을 갱신할 수 있습니다. 메시지 전달 단계에서는 이웃의 현재 특징이나 표현에서 보낼 값을 만들고, 받는 노드는 합이나 평균 등의 집계로 이를 모은 뒤 표현을 바꿉니다. 그래프의 이웃에는 정해진 순서가 없으므로, 집계는 합·평균·최댓값처럼 이웃을 어떤 순서로 나열해도 결과가 같은 순서 불변(permutation invariant) 함수를 씁니다.

정의 · 메시지 전달 층

층 l의 노드 v 표현을 h_v⁽ˡ⁾라 하면 한 층은
메시지: m_{u→v} = MSG(h_u⁽ˡ⁾, h_v⁽ˡ⁾) (u는 v의 이웃)
집계: a_v = AGG{ m_{u→v} : u ∈ N(v) } (합·평균·최댓값 등)
갱신: h_v⁽ˡ⁺¹⁾ = UPD(h_v⁽ˡ⁾, a_v)
로 쓸 수 있습니다. 모든 노드가 같은 MSG·AGG·UPD와 같은 가중치를 공유하므로, 노드 수가 다른 그래프에도 같은 층을 적용할 수 있습니다. 대표 예인 GCN 층은 행렬로 H⁽ˡ⁺¹⁾ = σ( D̃^(−1/2) Ã D̃^(−1/2) H⁽ˡ⁾ W⁽ˡ⁾ )입니다. Ã = A + I는 자기 루프를 더한 인접행렬, D̃는 Ã의 차수 대각행렬, W는 학습하는 가중치 행렬, σ는 ReLU 같은 비선형 함수입니다.

이번 한 층은 메시지를 이웃의 특성 그대로 두고 자신의 값도 평균에 넣습니다. C의 경우 (0+1+3+2)/4=3/2입니다. 가중치 2를 곱해 다음 표현을 3으로 만듭니다. 이 계산에서는 비선형 변환을 생략합니다. 자기 루프를 넣은 평균은 행렬로 D̃⁻¹ÃX이고, 이웃이 아니라 양쪽 차수로 나누는 GCN의 대칭 정규화와는 가중치가 조금 다릅니다.

층이 깊어질 때 닿는 범위

한 층에서 직접 이웃의 이전 표현을 씁니다. 그 표현도 다른 이웃에서 얻었으므로 두 층에서 최대 두 간선 떨어진 특성이 들어올 수 있습니다. 각 층을 계산할 때 모든 노드가 같은 이전 층을 사용합니다. 지나치게 반복해 평균을 내면 노드 표현이 서로 비슷해져 구별이 어려워지는데, 이를 과평활(over-smoothing)이라고 합니다. 앞 장의 랜덤 워크가 정상분포로 수렴하는 것과 같은 원리입니다. 노드가 연결 성분 밖에 있다면 이 메시지 규칙만으로는 도달하지 않습니다.

가중치가 벡터와 행렬일 수 있으며, 모형에 따라 수신자의 자신의 특징을 평균과 따로 더하거나 이어 붙입니다. GCN의 대칭 차수 정규화, GraphSAGE의 이웃 샘플링은 다른 집계 설계입니다. 아래 산술은 공통 원리를 보여 주는 스칼라 예입니다.

한 층을 직접 계산

실행 예제

from fractions import Fraction as F

vertices = "ABCDEF"
edges = {"AB", "AC", "BC", "CD", "DE", "DF", "EF"}
x = dict(zip(vertices, [1, 3, 0, 2, 4, 0], strict=True))
def aggregate(node):
    neighborhood = [v for v in vertices if v == node
                    or "".join(sorted(v + node)) in edges]
    return F(sum(x[v] for v in neighborhood), len(neighborhood))

for node in vertices:
    pooled = aggregate(node)
    print(node, "mean", pooled, "next", 2 * pooled)

실행 결과

A mean 4/3 next 8/3
B mean 4/3 next 8/3
C mean 3/2 next 3
D mean 3/2 next 3
E mean 2 next 4
F mean 2 next 4

코드는 이웃 평균에서 새 열을 계산하는 순방향 예제입니다. 레이블을 이용해 가중치를 최적화하지 않습니다.

평가 과제에 맞는 그래프를 사용

노드 분류는 노드당 답을, 링크 예측은 두 노드 사이의 연결 점수를, 그래프 분류는 그래프마다 답을 내는 과제입니다. 같은 시점에 이미 알려진 그래프에서 일부 노드의 레이블만 감추는 설정과 미래 노드·간선을 예측하는 설정을 구분합니다. 앞 설정에서는 레이블 없는 노드의 기존 연결을 사용할 수 있지만, 후자에서는 실제 예측 시점에 모르는 연결이나 특징을 메시지 전달에 쓰면 누출이 됩니다.

노드 분류에서는 숨긴 실제 레이블을 집계 특징으로 넣지 않습니다. 비교 대상의 그래프와 분할, 라벨 범위를 기록하고 이웃 평균 같은 간단한 기준과 비교합니다.
