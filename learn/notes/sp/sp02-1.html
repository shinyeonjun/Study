SP02·1

이미지 분류와 상자 검출의 성공 조건 읽기

한 장에 붙은 이름을 맞히는 일과 물체의 위치까지 찾는 일을 구별합니다. 상자의 겹치는 넓이와 자신도 점수 순서로 검출을 평가합니다.

이 장을 읽고 나면

  • 이미지 분류와 물체 검출의 결과 형태를 구분한다.
  • 상자의 교집합과 합집합으로 IoU를 계산한다.
  • 중복 검출을 FP로 세어 AP를 계산한다.

분류로는 이미지의 이름을, 검출로는 이름과 위치를 얻는다

사진 전체에 ‘부품 있음’이라는 하나의 결과를 내는 것은 이진 분류입니다. 정답 [1,0,1,1], 예측 [1,1,1,0]이면 정답과 예측이 맞는 사진은 2/4입니다. 실제 부품 사진 세 장 중 두 장을 맞혀 재현율은 2/3이고, 있다고 한 세 장 중 두 장이 맞아 정밀도 역시 2/3입니다.

한 사진에서도 부품 여러 개가 있고 어떤 위치에 있는지 필요하다면 검출을 쓸 수 있습니다. 검출 결과 하나는 분류 이름, 위치 상자, 점수를 가집니다. 상자가 얼마나 일치하는지를 보려면 겹친 면적을 전체 합집합으로 나눈 IoU를 계산합니다. 높이 4가 같은 정답 [0,4)×[0,4)와 예측 [1,5)×[0,4)는 교집합 12, 합집합 16+16−12=20이라 IoU=0.6입니다.

같은 물체 두 개를 찾았다고 중복 계산하지 않는다

한 사진, 한 부품 클래스의 정답 상자가 T1=[0,4)×[0,4), T2=[6,10)×[0,4)라고 가정합니다. 예측을 점수 0.9, 0.8, 0.7 순으로 확인합니다. 첫 예측은 앞에서 본 조금 밀린 상자, 두 번째는 T1과 정확히 같은 상자, 세 번째는 T2와 정확히 같은 상자입니다. 같은 사진과 클래스 안에서 아직 짝지어지지 않은 정답 중 IoU가 가장 큰 것과 짝짓고, IoU≥0.5만 인정하겠습니다.

이 규칙에서 첫 예측은 T1의 TP입니다. T1의 정확한 두 번째 상자도 이미 짝이 찼기 때문에 FP입니다. 세 번째는 T2의 TP입니다. 3위까지의 정밀도는 2/3, 재현율은 1입니다. 이런 식으로 보통 점수 순위를 따라 여러 정밀도·재현율을 읽습니다.

정확히 어떤 AP인지를 먼저 쓴다

이 장의 작은 AP는 보간을 하지 않고 재현율이 늘어난 순위의 정밀도에 재현율 증가분을 곱해 더합니다. 재현율은 TP마다 0.5씩 증가하므로 (1×0.5)+(2/3×0.5)=5/6≈0.833333입니다. IoU의 하한을 0.75로 높이면 첫 상자가 실패하고 2,3위가 TP라 AP는 (1/2+2/3)/2≈0.583333입니다.

COCO의 대표 AP는 0.50,0.55,…,0.95의 여러 IoU 기준을 사용하며 정밀도를 101개 재현율 지점에서 보간하는 공식 평가 규칙을 따릅니다. 이 장의 작은 AP와 동일한 숫자라고 보고하지 않습니다. 클래스·정답 매칭 규칙, 평가 범위, IoU 기준과 보간법을 기록합니다.

def iou(a, b):
    overlap = max(0, min(a[2], b[2]) - max(a[0], b[0]))
    overlap *= max(0, min(a[3], b[3]) - max(a[1], b[1]))
    area = lambda x: (x[2] - x[0]) * (x[3] - x[1])
    return overlap / (area(a) + area(b) - overlap)

truth = [(0, 0, 4, 4), (6, 0, 10, 4)]
predictions = [(0.9, (1, 0, 5, 4)), (0.8, truth[0]), (0.7, truth[1])]
print("first IoU:", iou(predictions[0][1], truth[0]))
for threshold in (0.5, 0.75):
    remaining = set(range(len(truth)))
    hits = []
    for _, box in sorted(predictions, reverse=True):
        best = max(remaining, key=lambda i: iou(box, truth[i]), default=None)
        success = best is not None and iou(box, truth[best]) >= threshold
        hits.append(int(success))
        if success:
            remaining.remove(best)
    ap = sum(sum(hits[:j]) / j for j, value in enumerate(hits, 1) if value) / len(truth)
    print("threshold", threshold, "flags", hits, "AP", f"{ap:.6f}")
first IoU: 0.6
threshold 0.5 flags [1, 0, 1] AP 0.833333
threshold 0.75 flags [0, 1, 1] AP 0.583333

예제는 면적이 양수인 상자, 하나 이상 있는 정답, 서로 다른 점수와 고정된 클래스 하나만 가정합니다. 실제 평가에서는 동점·가려진 물체·작은 물체 등의 처리도 평가 규약의 일부입니다.
