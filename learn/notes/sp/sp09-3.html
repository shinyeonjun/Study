SP09·3

섞인 뉴런에서 희소 특징을 읽고 회로 가설 검증하기

같은 뉴런 값에 여러 특징이 섞일 수 있습니다. 둘을 다른 좌표에서 읽고, 출력으로 이어지는 경로 중 무엇을 없앴는지 계산합니다.

이 장을 읽고 나면

  • 한 뉴런의 값과 여러 좌표에 걸친 특징을 구분한다.
  • 간단한 희소 인코딩과 복원을 계산한다.
  • 회로의 경로 가설을 대조 개입으로 평가한다.

한 좌표의 숫자만 보고 어느 특징인지 바로 알 수 없다

두 특징 a,b가 음이 아니고 모의 활성 벡터 h=(a+b,a−b)로 관찰된다고 합시다. a=2,b=0일 때와 a=0,b=2일 때 첫 활성이 모두 2입니다. 전체 벡터는 [2,2]와 [2,−2]로 다릅니다. 첫 좌표에 두 특징이 섞였지만, 전체를 사용하면 a=(h₀+h₁)/2, b=(h₀−h₁)/2로 복원합니다.

이 예의 두 특성은 여러 뉴런 좌표를 함께 써서 표현됩니다. 특징 a의 방향은 [1,1], b의 방향은 [1,−1]입니다. a=2,b=3이면 h=[5,−1]입니다. 실제 네트워크에서는 특징 수가 활성 차원보다 더 많은 모형도 연구되지만, 이 두 좌표 예는 두 방향이 단순히 섞이는 원리를 보여줍니다.

많은 후보 중 적은 특징을 남기도록 학습할 수 있다

희소 오토인코더(SAE)는 관찰한 활성 h를 특징 z로 바꾸고, 그 적은 활성 특징을 조합해 h를 복원합니다. 작은 모형으로 z=ReLU(Wₑh+bₑ), ĥ=Wᵈz+bᵈ를 씁니다. 예를 들어 복원 평균제곱오차 + λΣ|zᵢ|를 최소화하면, 오차와 특징 활성 크기 사이의 절충을 학습할 수 있습니다. 실제 얼마나 적은 특징이 활성화됐는지도 별도로 셉니다.

아래 계산은 앞의 모형을 아는 인코더와 디코더를 지정합니다. [5,−1]을 z=(2,3)으로 읽고 두 방향을 섞으면 정확히 [5,−1]이 됩니다. b를 끄면 재구성은 [2,2]로 바뀌어 원래 [5,−1]과의 평균제곱오차는 (9+9)/2=9입니다. 학습한 특징의 출력 효과를 바꾸는 개입과 원래 표현을 잘 복원하는지도 다른 질문입니다.

회로는 계산에 기여한다는 가설이다

회로 분석은 예를 들어 ‘이 특징이 이 층과 위치를 거쳐 출력에 전달된다’처럼 작은 구성 요소와 경로를 가설로 세웁니다. 이 예는 h에서 z를 읽고 a+2b를 내는 간단한 회로를 코드에 모두 정해 두었습니다. 실제 연구에서는 후보 경로를 찾은 뒤 어떤 부분만 남기는지, 어떤 부분만 제거하는지에 따른 출력 변화도 대조해야 합니다.

def encode(h):
    x, y = h
    return max(0, (x+y)/2), max(0, (x-y)/2)

def decode(z):
    a, b = z
    return a+b, a-b

def score(z):
    a, b = z
    return a+2*b

for h in ((2, 2), (2, -2), (5, -1)):
    z = encode(h)
    assert decode(z) == h
    print("h, z, score:", h, z, score(z))
ablated = (encode((5, -1))[0], 0)
restored = decode(ablated)
mse = sum((a-b)**2 for a,b in zip(restored, (5, -1))) / 2
print("without b:", restored, "score:", score(ablated), "mse:", mse)
h, z, score: (2, 2) (2.0, 0) 2.0
h, z, score: (2, -2) (0, 2.0) 4.0
h, z, score: (5, -1) (2.0, 3.0) 8.0
without b: (2.0, 2.0) score: 2.0 mse: 9.0

실제 SAE에서 특징에 붙인 이름은 활성 사례를 설명하려는 가설입니다. 복원 오차, 다른 의미를 섞어 읽는 사례, 서로 대신할 수 있는 경로, 다른 층과 입력에서의 실패를 함께 봅니다. 한 입력에서의 효과를 모델 전체나 사람의 개념 전체까지 일반화할 수 있는지는 별도 실험이 필요합니다.
