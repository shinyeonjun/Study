표본화에서 서로 다른 주파수가 같은 값이 되는 이유

센서가 일정한 간격에서만 값을 읽으면 두 연속 파형이 같은 표를 만들 수 있습니다. 1Hz와 7Hz를 8Hz로 재며 어떤 정보가 사라지는지 봅니다.

이 장을 읽고 나면

  • 표본 시점과 표본 빈도를 계산한다.
  • 에일리어싱을 손계산과 NumPy로 확인한다.
  • 샘플링 정리의 조건과 양자화의 차이를 설명한다.

두 파형이 같은 시각에 같은 값을 낸다

1Hz 코사인과 7Hz 코사인을 1초에 8번 읽습니다. 시간 t=n/8에서 첫 파형의 각은 2πn/8, 둘째는 2π·7n/8입니다. 둘째 각은 2πn−2πn/8로 같고, 2πn만큼 회전해도 코사인은 그대로입니다. 또한 코사인은 각에 음수를 붙여도 같습니다. 따라서 모든 정수 n에서 두 표본이 같습니다.

이처럼 실제로 다른 주파수가 같은 표본이나 다른 주파수처럼 보이는 현상을 에일리어싱이라 합니다. 주파수가 8 Hz의 정수배만큼 다른 성분이 이 격자에서 같은 복소 회전을 만들고, 실수 코사인에서는 양·음의 방향에 대해서도 같은 값을 냅니다. 일반적으로 표본 빈도 fₛ에서 주파수 f인 코사인은 0~fₛ/2 범위에 드는 |f−m·fₛ|(m은 정수) 주파수와 같은 표본을 냅니다. 7 Hz는 |7−8|=1 Hz로 보입니다.

어떤 신호 범위를 다룬다고 가정하는가

표본 빈도 fₛ의 절반 fₛ/2를 Nyquist 주파수라고 합니다. 샘플링 정리에 따르면 이상적인 대역 제한 신호에서는 최고 주파수의 두 배보다 높은 빈도로 전 시간축에서 균일하게 얻은 정확한 표본으로 원래 신호를 복구할 수 있습니다. 표본 빈도 8 Hz의 경계인 4 Hz에서는 위상에 따라 신호 성분을 잃을 수 있습니다. 예를 들어 4 Hz의 사인을 0에서 시작해 n/8에서 읽으면 sin(πn)=0입니다. 실제 장치에서는 표본화 전에 관심 대역 밖의 신호를 줄이는 필터를 둘 수 있습니다.

from math import pi
import numpy as np

samples = np.arange(8)/8
low = np.cos(2*pi*samples)
high = np.cos(2*pi*7*samples)
equal = np.allclose(low, high, atol=1e-12)
assert equal
rounded = [f"{0 if abs(x) < 1e-12 else x:.4f}" for x in low]
print("기록:", " ".join(rounded))
print("두 표본 동일:", equal)
print("경계 사인 최대:", f"{np.abs(np.sin(2*pi*4*samples)).max():.4f}")

언제 읽는 것과 어떤 눈금에 맞추는 것은 다르다

표본화는 읽을 시간을 고릅니다. 양자화는 읽은 값을 유한한 수치 눈금으로 반올림합니다. 양자화를 더 많은 비트로 표현하면 값 눈금은 촘촘해질 수 있지만, 두 파형의 표본 자체가 같아진 문제를 해결하지는 못합니다. 필요한 시간 간격과 해상도를 따로 정합니다.
