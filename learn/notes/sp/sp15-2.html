SP15·2

분야의 관측 단위가 연구 질문을 바꾸는 이유

마우나로아의 연평균 CO₂를 읽고, 같은 평균 계산을 대기 관측과 합성 신경 신호에서 어떻게 다르게 해석하는지 살펴봅니다. 생물·경제·복잡계 질문에도 단위와 가정을 붙입니다.

이 장을 읽고 나면

  • 분야별 질문에서 관측 단위, 결과 단위, 시간 범위를 적는다.
  • NOAA 연평균의 절대 차이와 기준 대비 상대차를 구분한다.
  • 집계의 분모와 도메인 가정을 확인하고 후속 연구를 정한다.

분야 이름 대신 세 가지를 적는다

연구를 시작할 때 분야 이름만 붙이기보다 무엇을 관찰해 어떤 조건의 대상을 비교할지 정합니다. 과학계산에서 풀 수 있는 식이나 통계 모형이 있어도 그 값의 의미와 해석은 자료의 생성 방식에 달려 있습니다.

예를 들어 한 식물의 같은 잎을 여러 날 측정하면 행 수는 늘지만 독립 식물 수는 유지됩니다. 자료에 속한 대상의 변화를 묻는지, 다른 식물에도 일반화할지 설계를 확인합니다. 과제의 범위는 관찰과 형태 비교입니다.

관측 값에 근거해 말할 수 있는 범위

NOAA GML·Scripps가 공개한 마우나로아 연평균 CO₂는 건조 공기에서의 몰분율입니다. 1 ppm은 건조 공기 1몰당 1 μmol에 해당합니다. 보관 CSV에서 시작과 끝을 빼면 57.20 ppm이며, 1990년 값을 분모로 놓은 상대차는 약 16.14%입니다.

이 수치로 대기 전체의 CO₂ 질량 증가나 원인을 직접 구할 수 없습니다. 관측소를 넘어서는 비교에는 관측 위치, 대기 순환과 공간 대표성, 같은 집계 기간을 검토해야 합니다. 공개 값 계산을 재현한 장에서 자료의 판본을 연결합니다.

어떤 분모를 써야 질문에 답할까?

합성 신경 신호에서 어떤 구간의 사건 수를 12개와 14개로 셌습니다. 관측 길이가 각각 .5초와 2초라면 초당 사건은 24와 7입니다. 구간을 각각 하나의 관측으로 보고 같게 평균하면 15.5/초입니다. 전체 시간에서 세면 26÷2.5=10.4/초입니다. 생물학적 해석을 하기 전에 사건 정의와 측정 시간, 관심 단위를 결정합니다.

경제 자료에서도 가격과 판매량은 수요·공급과 함께 바뀔 수 있습니다. 가격을 낮추면 판매량이 얼마나 변하는가라는 개입 질문은 관측된 상관 외에 설계와 가정이 필요합니다. 복잡계에서는 노드가 무엇이고 어떤 시간 동안 어떤 활동을 연결로 기록했는지가 비교의 일부입니다.

공개 값과 합성 구간의 단위 검산

예제는 저장소의 최상위 폴더에서 실행합니다. 실습에 사용하는 30개 연도의 CSV와 출처와 변환 기록을 함께 확인할 수 있습니다.

실행 예제

import csv
from decimal import Decimal
from pathlib import Path

source = Path("learn/labs/mauna-loa/annual_co2.csv")
with source.open(encoding="utf-8", newline="") as stream:
    records = list(csv.DictReader(stream))
series = {int(row["year"]): Decimal(row["mean_ppm"]) for row in records}
assert len(records) == len(series) == 30 and sorted(series) == list(range(1990, 2020))

first, last = series[1990], series[2019]
change = last - first
print(f"change={change:.2f} ppm, relative={100 * change / first:.2f}%")

counts = [12, 14]
seconds = [0.5, 2.0]
rates = [n / t for n, t in zip(counts, seconds, strict=True)]
print(f"rates: {rates[0]:.1f}, {rates[1]:.1f} per second")
print(f"equal segments: {sum(rates)/len(rates):.1f} per second")
print(f"pooled time: {sum(counts)/sum(seconds):.1f} per second")

실행 결과

change=57.20 ppm, relative=16.14%
rates: 24.0, 7.0 per second
equal segments: 15.5 per second
pooled time: 10.4 per second

다음 연구 질문은 자료와 가정을 붙여 결정합니다. 관측소 비교에서는 같은 기간과 집계법부터 맞춥니다. 시간당 신호 비교에서는 구간의 길이와 사건 판정 규칙을 확인합니다. 공개 보고에는 원자료의 이용 범위와 관측 단위를 함께 밝힙니다.

이어 읽기

결과의 해석은 연구 보고서의 한계와 다음 실험으로, 관측된 관계와 개입을 구분하는 방법은 인과 효과의 식별로 연결합니다.
