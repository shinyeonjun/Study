SP06·3

여러 시간에 걸친 옵션과 여러 에이전트의 공동 행동

하위 정책을 여러 시점 동안 실행하면 상위 정책의 시간 단위가 바뀝니다. 에이전트가 여럿이면 상대가 고른 행동도 결과에 들어갑니다.

이 장을 읽고 나면

  • 옵션의 시작 조건, 내부 정책, 종료 조건을 구분한다.
  • 옵션 길이에 맞춰 보상 합과 다음 가치를 할인한다.
  • 다중 에이전트에서 상대 정책 변화가 행동 가치에 미치는 영향을 계산한다.

기본 행동 여러 개를 한 선택으로 묶습니다

작은 타일 퍼즐에서 첫 두 칸을 진행하는 행동을 상위 단계에서 하나의 선택으로 둘 수 있습니다. 계층 강화학습에서는 위 정책이 중간 목표나 하위 정책을 고르고, 아래 정책이 기본 행동을 선택합니다. 대표 형식인 옵션은 실행할 수 있는 시작 상태들의 집합, 실행 중 쓸 내부 정책, 상태별 종료 조건 또는 확률을 정합니다. 상위 정책의 다음 선택은 현재 옵션이 끝난 뒤에 이루어집니다.

옵션이 두 단계 걸리고 바로 받고 난 보상이 순서대로 1과 2, 할인율 γ=1/2라면 옵션 동안의 할인 보상은 1+γ·2=2입니다. 종료한 상태에서 앞으로 얻을 가치가 4라면, 이미 지난 기본 두 단계만큼 할인한 γ²·4=1을 더해 상위 선택의 표적이 3이 됩니다. 같은 상위 선택 안에서도 걸리는 시간 k가 바뀐다면 다음 값의 계수는 매 경우 γᵏ입니다. 옵션 종료 자체가 환경의 에피소드 종료를 뜻하지 않습니다.

한 번 정한 옵션이 잘 설계되면 긴 계획에서 탐색할 결정을 줄입니다. 시작 조건이나 내부 정책이 상태의 다른 중요한 차이를 무시하면 더 나은 기본 행동을 선택할 기회를 없앨 수 있습니다. 작은 문제에서는 옵션 없이 얻은 결과와 비교해 길이 변화와 제한 효과를 확인합니다.

다른 에이전트의 행동도 결과에 들어갑니다

두 퍼즐 참가자가 같은 방향을 골라야 점수를 얻습니다. 각자는 E(동쪽), W(서쪽) 중 하나를 동시에 선택합니다. 모두 E면 두 사람에게 공통 보상 3, 모두 W면 2, 다르면 0입니다. 마르코프 게임에서는 각자의 선택을 모은 공동 행동이 다음 상태와 각자의 보상을 정합니다. 서로 협력하는 문제에서는 보상을 공유할 수 있고 경쟁하거나 이해가 일부만 일치하는 경우 보상 함수가 다를 수 있습니다.

상대가 E를 확률 1/4로 고른다고 합시다. 내가 E라면 기대 보상은 3/4이고 W라면 2×3/4=3/2입니다. 상대가 E 확률을 3/4로 높이면 내 E의 기대 보상은 9/4, W는 1/2로 바뀝니다. 상대도 학습 중이면 내 관점에서 같은 상태·행동의 결과 분포가 변화할 수 있습니다. 훈련 때는 양쪽 상태와 행동 기록을 함께 쓰고 실행 때는 각자 볼 수 있는 자료만 사용하는 중앙집중 훈련·분산 실행 방식도 있습니다. 실행 시 어떤 정보가 실제로 가능한지부터 정의합니다.

시간 할인과 두 정책의 상호작용을 확인합니다

from fractions import Fraction as F

gamma = F(1, 2)
rewards = [1, 2]
inside = sum(gamma**i * r for i, r in enumerate(rewards))
target = inside + gamma**len(rewards) * 4
print("option return:", inside, "target:", target)
for p in (F(1, 4), F(3, 4)):
    scores = {"E": 3 * p, "W": 2 * (1 - p)}
    print("opponent E:", p, "values:", *scores.values(), "best:", max(scores, key=scores.get))
option return: 2 target: 3
opponent E: 1/4 values: 3/4 3/2 best: W
opponent E: 3/4 values: 9/4 1/2 best: E

이 장의 공동 선택은 보상을 받고 끝나는 한 단계 사례입니다. 여러 시점의 경우 각자 사용하는 정책과 상태 전이를 함께 놓고 미래 보상을 계산합니다. 한 에이전트의 MDP에서 어떤 조건을 바꾼 것인지 추적하면 모형을 세우기 쉽습니다.
