물체 좌표에서 카메라 좌표와 화면 좌표로

물체를 돌리고 움직인 뒤 카메라에서 본 위치를 계산합니다. 같은 옆 위치라도 깊이가 다르면 화면에서 얼마나 떨어지는지 비교합니다.

이 장을 읽고 나면

  • 물체·세계·카메라 좌표가 어떤 기준인지 설명한다.
  • 회전과 이동의 적용 순서에 따른 차이를 계산한다.
  • 원근 투영과 직교 투영의 화면 위치를 구한다.

좌표계가 바뀌면 같은 점의 숫자도 바뀐다

물체의 가운데를 원점으로 잡은 물체 좌표와, 장면 전체가 공유하는 세계 좌표를 둡니다. 물체의 점 [1,0,4]에 XY 평면의 양의 90도 회전 (x,y,z)→(−y,x,z)을 적용한 뒤 세계 축에서 x에 2를 더하면 [2,1,4]가 됩니다. 반대로 먼저 x에 2를 더한 뒤 돌리면 [0,3,4]입니다. 같은 두 변환이어도 적용 순서가 달라지면 결과가 다릅니다.

열벡터를 사용한 동차 좌표 (x,y,z,1)에서는 회전과 이동을 각각 4×4 행렬로 써 순서대로 합칠 수 있습니다. 회전 R 뒤 이동 T라면 (TR)p입니다. 카메라 좌표로 옮길 때는 카메라가 세계 어디에 있고 어느 쪽을 보는지 반영합니다. 카메라 축이 세계 축과 같고 세계 위치만 C만큼 움직였다면, 점의 카메라 좌표는 세계 좌표 p에서 C를 빼면 됩니다.

카메라에서 같은 각도로 보이는 점을 같은 자리로 보내기

이 장의 카메라 좌표에서 X는 오른쪽, Y는 위쪽, Z는 앞쪽입니다. Z>0인 점을 받는 작은 원근 투영에서는 X/Z와 Y/Z가 화면의 중심으로부터의 오프셋을 정합니다. 화면 좌표 u는 오른쪽, v는 아래쪽으로 증가한다고 정해 u=cₓ+fₓX/Z, v=cᵧ−fᵧY/Z로 씁니다. 여기서 화면 중심은 (320,240)픽셀, 초점 길이를 픽셀로 표현한 fₓ=fᵧ=80픽셀입니다.

카메라 좌표 (2,1,4)는 (360,220), (2,1,8)은 (340,230)입니다. 깊이와 상관없이 같은 평면 위치를 찍는 직교 투영에서는 X,Y에 일정 비율을 곱합니다. 1좌표 단위당 20픽셀을 쓰면 두 점 모두 (360,220)입니다.

예제에서 쓰지 않은 좌표도 어디까지 허용되는지 정한다

예제는 회전한 다음 이동한 물체의 세계 좌표를 구하고, 세계 원점에 있는 카메라와 x 방향으로 한 단위 움직인 카메라를 비교합니다. 원근 나눗셈에 쓸 Z는 양수여야 합니다. 실제 그래픽 API는 방향, 원근 나눗셈과 화면 좌표 범위의 규약이 서로 다를 수 있으므로 사용한 축과 변환 행렬의 순서를 함께 적습니다.

def rotate(point):
    x, y, z = point
    return -y, x, z

def translate(point):
    x, y, z = point
    return x+2, y, z

def project(point, camera=(0, 0, 0)):
    x, y, z = (p-c for p,c in zip(point,camera))
    if z <= 0:
        raise ValueError("this pinhole model needs positive depth")
    return 320+80*x/z, 240-80*y/z

def ortho(point):
    x, y, _ = point
    return 320+20*x, 240-20*y

local = (1, 0, 4)
world = translate(rotate(local))
far = (2, 1, 8)
print("R then T / T then R:", world, rotate(translate(local)))
print("perspective near/far:", project(world), project(far))
print("ortho near/far:", ortho(world), ortho(far))
print("camera moved right:", project(world, camera=(1,0,0)))
R then T / T then R: (2, 1, 4) (0, 3, 4)
perspective near/far: (360.0, 220.0) (340.0, 230.0)
ortho near/far: (360, 220) (360, 220)
camera moved right: (340.0, 220.0)

이 예는 화면에서 가려지는 물체나 가까운 평면 바깥의 삼각형을 처리하지 않았습니다. 다음 장에서 어떤 화면 위치에 그림 조각을 남길지 결정합니다.
