합성곱으로 신호를 걸러 내고 FFT로 대조하기

현재 샘플에서 직전 샘플을 빼는 간단한 필터를 적용합니다. 변환 영역에서 곱하면 왜 같은 결과가 나오는지와 길이 때문에 달라지는 부분을 봅니다.

이 장을 읽고 나면

  • 필터 계수로 이산 합성곱을 계산한다.
  • 선형 합성곱과 원형 합성곱의 차이를 설명한다.
  • 0 채움의 길이를 정해 FFT 결과를 직접 계산과 대조한다.

현재와 직전 값을 결합한다

입력 x=[1,2,3]을 번호 0,1,2에서 읽고 그 밖에서는 0으로 둡니다. 필터 h=[1,−1]의 이산 합성곱은 y[n]=Σₖ h[k]x[n−k]입니다. 이 예에는 k=0,1만 있어서 y[n]=x[n]−x[n−1]입니다. 값이 그대로인 구간에서는 출력 0, 값이 변하면 그 차이를 얻습니다.

출력 nx[n]x[n−1]y[n]
0101
1211
2321
303−3

마지막 −3은 주어진 유한 신호 뒤에 0을 붙인 경계에서도 변화가 있기 때문입니다. 관측이 실제로 0으로 바뀌었음을 표시하는 데이터가 아니라, 계산에서 채운 경계의 결과입니다.

변환에서의 곱은 길이가 정한 원형 계산이다

같은 길이로 DFT한 두 배열의 계수를 성분별로 곱한 뒤 역변환하면 원형 합성곱입니다. 길이 3이면 n=0에서 직전 n=−1이 마지막 번호 2로 이어집니다. 따라서 첫 값이 1−3=−2입니다. 반대로 두 배열 끝에 0을 채워 길이 4로 만들면 원래 선형 결과 [1,1,1,−3]의 네 값을 보전합니다. 유한 길이 N과 M의 선형 합성곱 결과는 N+M−1칸이므로, 변환 길이도 N+M−1 이상이어야 합니다.

이 관계를 합성곱 정리라고 합니다. 길이 L의 원형 합성곱을 DFT하면 두 배열의 DFT를 성분별로 곱한 것과 같습니다. 직접 계산은 N×M번의 곱이 필요하지만, FFT를 쓰면 O(L log L) 연산으로 끝나므로 긴 신호와 긴 필터에서 유리합니다.

import numpy as np

signal = np.array([1, 2, 3])
kernel = np.array([1, -1])
linear = np.convolve(signal, kernel)

def via_fft(length):
    fft_result = np.fft.fft(signal, length) * np.fft.fft(kernel, length)
    return np.fft.ifft(fft_result)

long_result = via_fft(4)
short_result = via_fft(3)
assert np.allclose(long_result, linear)
print("직접 선형:", linear.tolist())
print("4칸 FFT:", [round(v.real) for v in long_result])
print("3칸 FFT:", [round(v.real) for v in short_result])

실행 결과

직접 선형: [1, 1, 1, -3]
4칸 FFT: [1, 1, 1, -3]
3칸 FFT: [-2, 1, 1]

같은 ‘합성곱’ 이름을 쓰는 구현도 인덱스를 확인한다

수학의 합성곱에는 x[n−k]와 같은 뒤집힘이 들어갑니다. 흔히 CNN의 층이 구현하는 교차상관에서는 입력의 이동한 창과 필터를 같은 방향으로 곱하는 약속을 쓰기도 합니다. 같은 이름이 붙어도 주어진 커널 하나의 답을 검산할 때는 식, 커널 방향과 패딩을 확인합니다.
