SP03·2

숨은 수준을 추정하고 예측구간 만들기

온도계의 읽음 13이 숨은 수준 자체는 아닙니다. 선형·가우시안 모형에서 예측과 관측을 결합한 뒤 다음 관측값의 예측구간을 계산합니다.

이 장을 읽고 나면

  • 상태 전이와 관측 식, 과정 잡음과 관측 잡음을 구별한다.
  • 칼만 갱신 한 번의 평균과 분산을 계산한다.
  • 숨은 상태 구간과 새 관측값의 예측구간을 구분한다.

실제 상태와 읽은 값이 다르다

합성 센서의 숨은 수준을 zₜ, 읽은 값을 yₜ라 합니다. 상태공간 모형은 두 식을 분리합니다. zₜ=zₜ₋₁+wₜ는 상태가 어떻게 바뀌는지, yₜ=zₜ+vₜ는 상태가 주어졌을 때 무엇을 읽는지 정합니다. 여기서는 wₜ와 vₜ가 서로 독립이고 시간 간 독립이며 평균 0인 정규 잡음이라고 둡니다. 과정 분산은 Q=1, 관측 분산은 R=3입니다.

HMM에서도 전이와 관측을 분리하지만, 여기의 숨은 값은 연속값입니다. 선형·가우시안이라 이전 분포의 평균과 분산으로 계산을 이어갑니다.

칼만 필터의 예측과 관측 갱신

이전 시점의 사후 평균과 분산이 10과 1입니다. 상태 전이에서 평균은 그대로이고 분산은 1+Q=2가 됩니다. 새 관측 13의 예측과 차이는 3입니다. 칼만 이득 K=P⁻/(P⁻+R)=2/5는 이 차이의 얼마를 평균에 반영할지 정합니다.

갱신 평균은 10+(2/5)·3=11.2, 분산은 (1−2/5)·2=1.2입니다. 관측 잡음이 클수록 같은 예측 분산에서 이득이 작아집니다. 이 업데이트는 그 시점까지 본 자료에서 숨은 상태를 구하는 필터링입니다.

새 상태와 새 관측의 폭이 다르다

그다음 시점의 숨은 수준 분산은 1.2+1=2.2입니다. 그 시점의 실제 읽음을 예측하면 관측 잡음 3을 더해 5.2가 됩니다. 모형이 맞고 매개변수를 알려진 값으로 두면 조건부 예측 분포는 평균 11.2, 분산 5.2의 정규분포입니다.

실행 예제

from math import sqrt
from statistics import NormalDist

prior_mean, prior_var = 10.0, 1.0
process_var, observation_var = 1.0, 3.0
prediction_var = prior_var + process_var
gain = prediction_var / (prediction_var + observation_var)
updated_mean = prior_mean + gain * (13 - prior_mean)
updated_var = (1 - gain) * prediction_var
next_observation_var = updated_var + process_var + observation_var
distribution = NormalDist(updated_mean, sqrt(next_observation_var))
print(f"gain={gain:.1f}, state mean={updated_mean:.1f}, state var={updated_var:.1f}")
print(f"next observation var={next_observation_var:.1f}")
print(f"95% interval [{distribution.inv_cdf(.025):.4f}, {distribution.inv_cdf(.975):.4f}]")

실행 결과

gain=0.4, state mean=11.2, state var=1.2
next observation var=5.2
95% interval [6.7306, 15.6694]

구간 폭은 모형이 가정한 잡음의 크기에 따라 다릅니다. 실제 여러 예측에서 약속한 비율로 미래 관측이 구간에 포함되는지 시간순 검증으로 평가합니다. 모형 매개변수의 추정 오차는 이 작은 계산에 넣지 않았습니다.
