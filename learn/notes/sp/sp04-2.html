SP04·2

반사실 효과의 식별과 층별 조정

같은 사람에게 교육을 했을 때와 하지 않았을 때의 결과를 모두 볼 수는 없습니다. 어떤 가정을 두면 관측 자료를 공통 준비도 분포로 조정해 평균 효과를 계산할 수 있는지 봅니다.

이 장을 읽고 나면

  • 교육 제공과 비제공의 잠재 결과, 개입과 관측을 구분한다.
  • 조건부 교환가능성, 양의 확률, 일관성을 명시한다.
  • 같은 대상 구성을 쓴 표준화로 위험차를 계산한다.

보지 못한 결과까지 포함하는 질문

사람 하나의 성공을 0 또는 1로 기록합니다. 교육이 제공된 때의 잠재 결과를 Y(1), 제공되지 않은 때를 Y(0)라고 씁니다. 실제로 선택한 조건의 결과만 봅니다. 적용하지 않은 조건의 결과가 반사실입니다. 목표 모집단의 평균 처리효과 E[Y(1)−Y(0)]는 모두에게 제공했을 경우와 모두에게 제공하지 않았을 경우의 평균 성공률 차이입니다.

P(Y=1|T=1)은 실제로 교육을 받은 사람 중 성공한 비율입니다. P(Y=1|do(T=1))은 대상을 유지한 채 교육 제공을 정한 개입에서의 성공확률입니다. 실제 교육 선택이 준비도에 의존하면 두 값은 달라질 수 있습니다.

관측량만으로 계산할 수 있는 조건

식별은 효과를 어떤 관측 자료의 함수로 나타낼 수 있는지 판단하는 단계입니다. 이 예에서 준비도 W를 같게 하면 비교하는 사람들이 잠재 결과 측면에서 어느 쪽을 선택해도 비교 가능하다고 가정합니다. 이것이 조건부 교환가능성입니다. 준비도마다 두 교육 조건에 속할 가능성이 양수여야 한다는 양의 확률도 필요합니다.

또 관측 결과가 실제 받은 교육의 잠재 결과와 맞아야 하는 일관성이 필요합니다. 교육의 버전을 명확히 하고 한 사람의 교육이 다른 사람의 성공에 영향을 주지 않는 모형을 이 예에서 사용합니다. 가정이 맞으면 준비도별로 조건부 성공률을 구해 목표 모집단의 준비도 비율로 가중할 수 있습니다.

같은 가중치로 각 조건을 평균

목표에서 높은 준비도와 낮은 준비도가 각각 절반이라고 둡니다. 교육 제공은 (.80+.40)/2=.60, 제공 안 함은 (.70+.30)/2=.50입니다. 차이는 +.10, 즉 10퍼센트포인트입니다. 기존 자료로 직접 구한 +.34에는 집단 구성 차이도 반영됐습니다.

실행 예제

from fractions import Fraction as F

# preparation: ((trained successes, total), (untrained successes, total))
table = [((64, 80), (14, 20)), ((8, 20), (24, 80))]
for label, group in (("trained", 0), ("untrained", 1)):
    counts = [row[group] for row in table]
    observed = F(sum(yes for yes, _ in counts), sum(n for _, n in counts))
    standardized = sum(F(1, 2) * F(yes, n) for yes, n in counts)
    print(f"{label}: crude={float(observed):.2f}, adjusted={float(standardized):.2f}")

실행 결과

trained: crude=0.72, adjusted=0.60
untrained: crude=0.38, adjusted=0.50

코드는 관측값으로부터 수치를 계산하는 추정 예입니다. 준비도 외에 중요한 공통 원인이 남았다면 조정한 계산도 효과를 정확히 식별하지 못할 수 있습니다.
