SP07·2

칼만 필터로 센서값과 상태 예측을 합치기

현재 위치가 직접 보이지 않습니다. 모형이 예측한 위치와 잡음이 섞인 센서값을 불확실성에 맞춰 합칩니다.

이 장을 읽고 나면

  • 상태가 어떻게 변하는지와 센서가 무엇을 보는지 따로 적는다.
  • 한 단계의 스칼라 칼만 예측과 갱신을 계산한다.
  • 과정 잡음과 관측 잡음이 신뢰에 미치는 효과를 설명한다.

상태를 하나로 단정하지 않고 평균과 분산으로 기록합니다

가상 표시의 상태 xₜ를 센서 yₜ로 추정합니다. 모형은 xₜ₊₁=xₜ+uₜ+wₜ, 센서는 yₜ₊₁=xₜ₊₁+vₜ₊₁입니다. x, u, y는 같은 위치 단위입니다. w는 상태 변화 중 예상하지 못한 양이고 v는 센서의 오차입니다. 여기서는 두 잡음이 시간에 걸쳐 서로 및 초기 상태와 독립인 평균 0 가우스 잡음이고, 분산 Q=1, R=4라고 둡니다. 초기 상태의 추정 분포도 가우스라고 가정합니다. 분산 단위는 위치 단위의 제곱입니다.

이전 관측까지 반영한 상태 평균 m=2, 분산 P=1입니다. 입력 u=1을 적용합니다. 다음 상태의 예측 평균 m⁻은 2+1=3, 예측 분산 P⁻는 1+Q=2입니다. 독립 잡음이 더해지므로 불확실성도 더해집니다. 아직 새 센서값은 사용하지 않았습니다.

센서가 말한 값과 예측의 차이만큼 보정합니다

새 센서값 y=6이 왔습니다. 예측된 센서값은 이 모형에서 m⁻=3입니다. 실제와 예측의 차이 3을 혁신(innovation) 또는 관측 잔차라고 부릅니다. 칼만 이득 K=P⁻/(P⁻+R)=2/(2+4)=1/3만큼 그 차이를 반영합니다. 새 평균은 3+(1/3)(6−3)=4, 새 분산은 (1−K)P⁻=(2/3)·2=4/3입니다. 여기서는 센서의 관측 행렬 C=1이라 이 단순한 식을 쓸 수 있습니다.

같은 결과는 정밀도(분산의 역수)로 가중한 평균으로도 얻습니다. 새 평균 = (R·m⁻+P⁻·y)/(P⁻+R) = (4×3+2×6)/6 = 4, 새 분산 = 1/(1/P⁻+1/R) = 1/(1/2+1/4) = 4/3입니다. 분산이 작은 쪽, 곧 더 믿을 만한 쪽에 더 큰 가중치가 가고, 합친 뒤의 분산은 두 분산보다 작습니다.

양수인 예측 분산 P⁻를 고정하고 센서 잡음 분산 R을 늘리면 K가 작아져 센서에 덜 반응합니다. 다음 상태의 예측이 불확실해 P⁻가 더 커지면 양수인 R이 고정됐을 때 K가 커집니다. 실제 확률 구조가 다르거나 센서가 지속적으로 한쪽으로 치우치면 위 갱신을 그대로 써도 실제 오차가 작다는 보장은 없습니다. 이 선형 가우스 전제에서는 평균과 분산으로 사후분포를 정확히 나타낼 수 있습니다. 일반 벡터 모형에서는 공분산 P와 관측 행렬 C가 보정 방향도 정합니다.

벡터 칼만 필터 (xₜ₊₁=Axₜ+Buₜ+wₜ, yₜ=Cxₜ+vₜ)

예측: m⁻=Am+Bu, P⁻=APAᵀ+Q
이득: K=P⁻Cᵀ(CP⁻Cᵀ+R)⁻¹
갱신: m=m⁻+K(y−Cm⁻), P=(I−KC)P⁻
A=B=C=1이면 이 장의 스칼라 식과 같습니다. Q와 R은 이제 과정 잡음과 관측 잡음의 공분산 행렬입니다.

예측하고 갱신하는 값을 분수로 출력합니다

from fractions import Fraction as F

mean, variance = F(2), F(1)
command, q, r, sensor = 1, 1, 4, 6
pred_mean, pred_var = mean + command, variance + q
gain = pred_var / (pred_var + r)
innovation = sensor - pred_mean
mean = pred_mean + gain * innovation
variance = (1 - gain) * pred_var
print("prediction:", pred_mean, pred_var)
print("gain and innovation:", gain, innovation)
print("correction:", mean, variance)
print("gain with noisier sensor:", pred_var / (pred_var + 8))
prediction: 3 2
gain and innovation: 1/3 3
correction: 4 4/3
gain with noisier sensor: 1/5

필터는 상태를 추정하는 단계입니다. 이 평균을 제어기에 넘기면 그다음 단계에서 보내는 입력을 고를 수 있습니다. 관측 직후 추정하는 칼만 갱신은 이산 상태 필터링과 같은 예측·갱신 구성을 가집니다.
