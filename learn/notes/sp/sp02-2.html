SP02·2

픽셀 분할을 채점하고 증강에서 정답도 같이 옮기기

정답 영역과 예측 영역을 픽셀 단위로 비교합니다. 사진을 변환할 때 마스크를 어떻게 옮기며, 어느 단위에서 데이터 분할을 나눌지 정합니다.

이 장을 읽고 나면

  • 픽셀 정확도·IoU·Dice의 분모를 구분한다.
  • 영상의 공간 증강을 마스크에 같이 적용한다.
  • 관련 프레임이 평가로 새지 않게 원본 단위로 분할한다.

물체의 모양을 각 칸의 종류로 표현한다

의미 분할은 이미지의 각 픽셀을 배경, 부품 등 한 클래스로 배정합니다. 같은 종류의 개별 물체도 따로 구분하고 싶다면 인스턴스 분할이라는 별도 결과가 필요합니다. 이 장은 부품 1과 배경 0의 두 값만 포함합니다.

정답에서 부품 픽셀은 5, 예측에선 4, 겹치는 것은 3입니다. 따라서 부품 IoU는 3/(5+4−3)=0.5이고, Dice는 2×3/(5+4)=2/3입니다. 배경으로 맞힌 픽셀도 3이라 전체 픽셀 정확도는 (3+3)/9=2/3입니다. 다수의 배경을 잘 맞히는 점수와 부품 영역을 맞히는 점수를 함께 봅니다.

정의 · 한 클래스의 IoU와 Dice

정답 픽셀 집합 G, 예측 픽셀 집합 P에 대해 IoU = |G∩P| / |G∪P|, Dice = 2|G∩P| / (|G|+|P|)입니다. 픽셀마다 양성·음성을 세면 IoU = TP/(TP+FP+FN), Dice = 2TP/(2TP+FP+FN)이므로 Dice는 그 클래스의 F1 점수와 같습니다. 두 값은 Dice = 2·IoU/(1+IoU)로 서로 바뀌어 순위는 같고, 0과 1 사이에서는 Dice가 IoU보다 큽니다. 이 예는 TP 3, FP 1, FN 2라 IoU 3/6, Dice 6/9입니다.

클래스 평균 기준과 증강 규칙을 함께 정한다

각 클래스의 IoU를 따로 구하고 평균을 내면 mIoU입니다. 이 예의 배경 픽셀은 정답 4, 예측 5, 공통 3이라 배경 IoU도 0.5입니다. 양쪽에 전혀 등장하지 않아 합집합이 0인 클래스는 점수가 정의되지 않습니다. 실험에서는 해당 항목을 평균에서 빼는지, 이미지들을 합쳐 클래스별로 세는지 등 집계 단위를 명시합니다.

증강은 입력에 변화를 주면서 작업에 필요한 관계를 보존하는 방법입니다. 예를 들어 영상을 좌우 반전하면 마스크도 같은 방향으로 반전해 물체 위치가 계속 맞아야 합니다. 축을 바꾸지 않는 밝기 증강은 마스크 값을 바꿀 이유가 없습니다. 클래스 ID의 격자는 보통 최근접 방식으로 크기를 바꿉니다. 예를 들어 두 클래스 ID 0과 1을 평균해 0.5라는 새 정답을 만들지 않습니다.

같은 촬영을 한쪽 분할에 모은다

한 연속 촬영에서 나온 프레임이나 한 원본의 여러 자르기를 훈련과 시험에 섞으면 서로 매우 비슷한 모습을 보게 됩니다. 새 촬영에서 잘 되는지 평가하려면 원본 영상 또는 촬영 세션 단위로 분할한 뒤 훈련 부분에 증강을 적용합니다. 좌우가 뜻 자체를 바꾸는 작업에서는 반전이 유효한 증강인지도 따로 살핍니다.

truth = [[1, 1, 1], [1, 0, 0], [1, 0, 0]]
pred = [[1, 1, 0], [1, 1, 0], [0, 0, 0]]
pairs = [(a, b) for x, y in zip(truth, pred) for a, b in zip(x, y)]

def class_iou(label):
    union = sum(a == label or b == label for a, b in pairs)
    return sum(a == b == label for a, b in pairs) / union

foreground_dice = 2 * sum(a == b == 1 for a, b in pairs)
foreground_dice /= sum((a == 1) + (b == 1) for a, b in pairs)
flipped = [row[::-1] for row in truth]
ious = [class_iou(c) for c in (0, 1)]
print("IoU by class and mean:", ious, sum(ious)/len(ious))
print("pixel accuracy and foreground dice:",
      f"{sum(a == b for a, b in pairs)/len(pairs):.6f}", f"{foreground_dice:.6f}")
print("flipped mask:", flipped)
IoU by class and mean: [0.5, 0.5] 0.5
pixel accuracy and foreground dice: 0.666667 0.666667
flipped mask: [[1, 1, 1], [0, 0, 1], [0, 0, 1]]

예제는 두 클래스 모두 합집합이 있는 한 장의 배열입니다. 실험 보고서에서는 원본 그룹을 어떻게 분리했는지와 제외한 픽셀·클래스를 함께 적습니다.

한 줄 정리

분할은 클래스별 IoU·Dice로 채점하고, 증강의 기하 변환은 정답 마스크에도 같이 적용하며, 비슷한 프레임이 훈련과 시험에 나뉘지 않게 원본 단위로 분할한다.
