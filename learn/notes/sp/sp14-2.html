삼각형을 화면 샘플로 바꾸고 가까운 표면 남기기

정점 세 개가 정하는 영역을 화면의 샘플로 바꿉니다. 같은 위치에 여러 표면이 있을 때 무엇을 남길지 깊이와 색으로 계산합니다.

이 장을 읽고 나면

  • 화면 삼각형의 안팎을 샘플 하나에서 판단한다.
  • 보간과 깊이 비교의 결과를 구한다.
  • 빛의 방향과 표면 방향의 관계를 내적으로 계산한다.

투영한 정점으로 화면의 넓이를 찾는다

삼각형으로 만든 표면을 화면으로 보내면 A=(0,0), B=(4,0), C=(0,4) 같은 정점이 생깁니다. 래스터화는 이 기하 도형이 화면의 어느 샘플을 덮는지 판단해 그릴 조각을 만드는 과정입니다. 이번 화면 좌표의 원점과 y 방향은 그림에 표시했습니다. 간단히 (1,1), (3,2)의 샘플 두 곳을 평가합니다. 실제 API에서는 픽셀 내부 샘플 배치와 경계 포함 규칙을 정해 둡니다.

점 P=(1,1)을 A,B,C의 계수로 쓰면 (0.5,0.25,0.25)입니다. 0.5A+0.25B+0.25C=(1,1)이고 합이 1입니다. 이런 값을 무게중심 좌표라고 합니다. 둘째 점 Q=(3,2)는 (−0.25,0.75,0.5)로 첫 계수가 음수라 밖입니다. 만약 A,B,C의 속성이 각각 빨강, 초록, 파랑의 RGB 단위벡터이면, 간단한 화면 선형 보간으로 P의 RGB는 (0.5,0.25,0.25)입니다.

겹치는 두 표면에서는 깊이도 비교한다

같은 샘플 위치에 삼각형 두 개가 겹칠 수 있습니다. 여기서는 불투명하며 카메라 앞의 깊이가 일정한 두 표면을 가정합니다. 첫 표면의 깊이 4가 기록된 뒤 깊이 2인 조각이 오면, 2가 더 가까워 화면 색과 깊이를 새 값으로 저장합니다. 가까운 값이 이미 있으면 이후에 먼 값이 들어와도 덮이지 않습니다.

그림의 깊이는 간단히 크면 멀다고 정했습니다. 실제 깊이 버퍼 값은 투영 뒤의 규약에 따르고, 설정에 따라 비교 방향을 다르게 할 수도 있습니다. 화면 좌표로 색을 선형 보간한 이 예와 달리, 원근 투영 뒤 3차원 속성을 맞추려면 보통 원근 보정이 필요합니다. 반투명 표면이 여러 개라면 한 깊이만 고르는 것 외에 혼합 규칙도 사용합니다.

표면이 어떤 방향으로 빛을 받는지 본다

단위벡터 N을 표면의 법선, L을 표면에서 광원을 향하는 방향으로 둡니다. 단순 확산 조도의 방향 항은 max(0,N·L)입니다. 법선과 빛 방향이 같으면 1, 각도가 60도면 0.5, 정반대면 0입니다. 실제 렌더링은 재질·빛의 거리와 세기, 가려짐, 출력 색의 표현도 계산합니다.

from math import sqrt

def barycentric(x, y):
    b, c = x/4, y/4
    return 1-b-c, b, c

for name, point in [("P", (1,1)), ("Q", (3,2))]:
    weights = barycentric(*point)
    print(name, weights, "inside:", all(w >= 0 for w in weights))
candidates = [("far", 4, (0.3, 0.3, 0.3)), ("near", 2, barycentric(1,1))]
print("closest:", min(candidates, key=lambda item: item[1]))
n = (0, 0, 1)
lights = [(0,0,1), (0,sqrt(3)/2,0.5), (0,0,-1)]
print("diffuse factors:", [max(0, sum(a*b for a,b in zip(n,l))) for l in lights])
P (0.5, 0.25, 0.25) inside: True
Q (-0.25, 0.75, 0.5) inside: False
closest: ('near', 2, (0.5, 0.25, 0.25))
diffuse factors: [1, 0.5, 0]

가까운 면의 색을 결정하는 데는 삼각형의 범위, 깊이, 속성과 조명처럼 다른 계산들이 함께 들어갑니다. 한 픽셀만 계산해 확인하면 어느 단계에서 색이나 위치가 어긋났는지 찾기 쉽습니다.
