SP10·4

도착과 처리의 확률과정에서 평균 대기 구하기

분당 3건이 들어오고 한 작업자가 분당 평균 5건을 처리할 수 있습니다. 처리 능력이 도착보다 커도 대기는 생깁니다. 도착과 처리 시간의 가정을 명시하고 기다리는 시간을 계산합니다.

이 장을 읽고 나면

  • M/M/1의 도착, 서비스 시간, 서버 수 가정을 설명할 수 있다.
  • 정상상태 분포를 구해 시스템 평균 인원과 체류 시간을 계산할 수 있다.
  • Little의 법칙에서 세 수치가 같은 범위를 기준으로 해야 하는 이유를 설명할 수 있다.

평균 속도 두 개와 분포 가정

M/M/1은 켄들 표기입니다. 첫 칸은 도착 과정, 둘째 칸은 처리 시간 분포, 셋째 칸은 서버 수이고, M은 무기억(Markov) 성질, 곧 포아송 도착과 지수분포 처리 시간을 뜻합니다. 인쇄 요청이 일정한 비율 λ=분당 3건으로 도착한다고 합시다. M/M/1에서는 도착 횟수를 포아송 과정으로 두므로 길이 t분인 구간에서 도착한 수는 평균 λt의 포아송 분포입니다. 겹치지 않는 구간의 도착 수는 독립입니다. 도착 사이 시간은 비율 λ의 지수분포입니다. 요청별 처리 시간은 동일한 지수분포를 따릅니다. 서로 및 도착 과정과 독립이며 평균은 1/μ=0.2분입니다. 1은 요청을 한 번에 하나씩 처리하는 서버 수입니다.

묶음 도착과 예약 인쇄처럼 특정 시각에 요청이 모인다면 이 도착 가정을 먼저 확인합니다. 처리 시간이 항상 일정하다면 두 번째 M이 가리키는 서비스 가정도 달라집니다. 이번 장은 대기 공간이 충분하고 요청이 빠져나가지 않는 한 서버 모형을 사용합니다.

장기적으로 몇 건이 쌓이는가

시간 t에 처리 중이거나 대기 중인 요청 수를 N(t)로 둡니다. 도착하면 n에서 n+1로, 한 건을 마치면 n에서 n−1로 이동합니다. 대기열이 비어 있으면 완료할 인쇄가 없습니다. 포아송 도착과 지수 처리의 무기억 성질 덕분에, 현재 요청 수를 알 때 바로 다음 상태로 이동하는 비율을 지정할 수 있습니다.

정상상태란 상태 확률이 시간에 따라 바뀌지 않는 상태입니다. 서로 이웃한 상태의 장기 확률 흐름을 맞추면 πₙλ=πₙ₊₁μ입니다. 따라서 ρ=λ/μ라 할 때 πₙ=π₀ρⁿ입니다. ρ<1이어야 이 기하급수의 합을 1로 만들 수 있습니다. 이 조건에서는 π₀=1−ρ이며, 예제의 ρ=3/5에서 빈 비율은 0.4입니다. π₂=0.4×0.6²=0.144입니다.

평균 시스템 인원은 L=Σ nπₙ=ρ/(1−ρ)입니다. 등비급수에 n이 붙은 합은 Σ nρⁿ=ρ/(1−ρ)²이므로 위 식을 얻습니다. 예제에서 L=1.5건입니다. λ≥μ라면 이 모형에 정규화 가능한 정상 분포가 없어 아래 정상상태 표를 적용할 수 없습니다.

기다리는 시간과 인쇄하는 시간을 나누기

Little의 법칙 L=λW에서 W는 도착부터 완료까지 걸린 평균 시간입니다. 따라서 W=L/λ=1.5/(분당 3건)=0.5분입니다. 평균 처리 시간 0.2분을 빼면 처리 전 대기 Wq=0.3분입니다. 대기 중인 것만 세면 평균 Lq=λWq=0.9건입니다. 두 법칙에서 센 인원과 시간의 범위가 일치해야 합니다. Little의 법칙은 도착 간격이나 처리 시간의 분포를 가정하지 않습니다. 장기 평균들이 존재하는 안정된 시스템이면 M/M/1이 아니어도 성립합니다.

범위평균 요청 수요청 하나의 평균 시간
대기와 처리 전체1.5건0.5분
인쇄를 받기 전 대기만0.9건0.3분
from fractions import Fraction as F

arrival, service = 3, 5
rho = F(arrival, service)
empty = 1 - rho
mean_count = rho / empty
system_time = mean_count / arrival
wait = system_time - F(1, service)

assert system_time == F(1, service - arrival)
assert mean_count == arrival * system_time
print(f"빈 비율: {float(empty):.3f}")
print(f"2건일 확률: {float(empty * rho**2):.3f}")
print(f"시스템: {float(mean_count):.1f}건, {float(system_time):.1f}분")
print(f"대기열: {float(arrival * wait):.1f}건, {float(wait):.1f}분")

실행 결과

빈 비율: 0.400
2건일 확률: 0.144
시스템: 1.5건, 0.5분
대기열: 0.9건, 0.3분

도착을 하나 더 늘리면

처리율을 분당 5건으로 고정하고 도착률을 4건으로 높이면 W=1/(5−4)=1분입니다. 3건에서 4건으로 늘었을 뿐인데 평균 체류는 두 배가 됩니다. 실측 데이터를 분석할 때는 평균 도착률과 처리율만 맞추기보다 시간대별 혼잡, 분포의 적합성과 요청의 처리 순서를 함께 기록합니다.

핵심어기억할 기준
M/M/1포아송 도착 λ, 지수 처리 μ, 서버 1개

정상상태πₙ=(1−ρ)ρⁿ, L=ρ/(1−ρ), W=1/(μ−λ)

한 줄 정리

ρ=λ/μ로 정상 분포를 구하고 Little의 법칙으로 인원을 시간으로 바꾸며, ρ가 1에 가까워질수록 대기는 급격히 늘어납니다.
