SP09·2

내부 활성을 바꾸고 삭제와 복원을 대조하기

같은 모형에서 두 입력의 값을 기록하고, 한 내부 성분만 바꿔 점수가 어떻게 움직이는지 봅니다. 정상 입력에서의 제거와 손상 입력에서의 복원을 구분합니다.

이 장을 읽고 나면

  • 개입할 위치·기준 상태·측정값을 명시한다.
  • ablation과 activation patching을 작은 계산으로 구분한다.
  • 복원율의 분모와 일반화의 한계를 확인한다.

기준 입력과 비교 입력의 점수를 먼저 기록한다

합성 모형의 내부 활성은 두 숫자 (u,v)이고 측정할 최종 점수는 s=2u+v입니다. 정상 조건에서 (3,1)을 관측해 점수 7, 관련 단서를 바꾼 비교 조건에서 (−1,1)을 관측해 점수 −1을 얻었습니다. 비교 입력을 ‘손상’이라고 부르는 것은 분석에서 어떤 단서를 바꿨다는 뜻입니다. 각 상태의 나머지 값과 모델은 동일하게 둡니다.

Ablation은 어떤 요소를 제거하거나 기준값으로 바꾸었을 때의 결과를 보는 실험입니다. 정상 조건의 u를 0으로 바꾸면 s=1이라 원래보다 6만큼 떨어집니다. v만 0으로 바꾸면 s=6이라 원래보다 1 떨어집니다. 0이 아주 드문 값이라면 결과가 달라진 이유가 그 요소의 의미만인지 판단하기 어려울 수 있습니다. 연구에서는 평균처럼 다른 대체값도 같이 비교할 수 있습니다.

다른 실행에서 얻은 활성 하나를 복사해 다시 계산한다

Activation patching은 한 실행에서 기록한 활성의 일부를 다른 실행의 같은 위치에 넣은 뒤 이후 계산을 보는 방법입니다. 비교 상태 (−1,1)에서 u만 정상값 3으로 바꾸면 s=7이 됩니다. 반대로 v만 정상값으로 바꾸면 그 값이 이미 1이라 s=−1입니다.

이 장에서는 복원율을 (개입 점수−비교 점수)/(정상 점수−비교 점수)로 정합니다. 점수 차가 8이라 u의 경우 (7+1)/8=1, v는 0입니다. 정상·비교 점수가 같아 분모가 0이면 계산하지 않습니다. 개입 점수가 정상보다 높거나 비교보다 낮을 때 값은 0~1 밖에도 나올 수 있습니다. 이 수치는 성공 확률이 아니라 점수 차를 비율로 표현한 것입니다.

같은 위치와 조건에서 바꾼 것이 무엇인지 적는다

실제 텐서라면 모델, 입력 쌍의 차이, 층과 토큰 위치, 교체한 성분과 방향, 출력 지표를 적습니다. 서로 다른 위치의 숫자를 바꾸면 같은 정보의 복원이 아닐 수 있습니다. 다른 입력이나 대체값, 무관한 위치에서도 같은 결론이 나오는지 대조합니다. 여기에서는 후속 계산을 함수 한 줄로 적고, 실제로 교체한 두 성분을 인쇄합니다.

def score(state):
    u, v = state
    return 2*u + v

clean = (3, 1)
changed = (-1, 1)
baseline = score(changed)
gap = score(clean) - baseline
print("clean/changed:", score(clean), baseline)
for i in range(2):
    removed = list(clean)
    removed[i] = 0
    patched = list(changed)
    patched[i] = clean[i]
    recovery = (score(patched) - baseline) / gap if gap else None
    print("axis:", i, "ablation:", score(removed),
          "patched:", score(patched), "recovery:", recovery)
clean/changed: 7 -1
axis: 0 ablation: 1 patched: 7 recovery: 1.0
axis: 1 ablation: 6 patched: -1 recovery: 0.0

이 예의 v 교체는 정상과 비교에서 값이 같아 아무 변화도 만들지 않았습니다. 따라서 v가 전혀 쓰이지 않는다고 결론내릴 수 없습니다. 실제로 정상 실행에서 v를 0으로 바꾸면 점수가 1 줄어듭니다. 다른 조건과 측정값에서 결과가 다시 나오는지 보기 전에는 이 입력 쌍과 개입에서 관찰한 효과로 주장 범위를 정합니다.
