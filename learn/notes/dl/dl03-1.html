DataLoader로 배치를 만들고 손실 모으기

입력과 정답을 쌍으로 보관하고 배치로 꺼냅니다. 마지막 배치가 작을 때에도 관측 하나씩 같은 무게로 손실을 집계합니다.

이 장을 읽고 나면

  • Dataset에서 관측 행과 정답 한 쌍을 꺼내고 DataLoader로 배치를 구성한다.
  • 배치 순서 섞기, 한 에포크, 마지막 배치 크기의 의미를 설명한다.
  • 배치 크기가 달라도 관측별 손실의 전체 평균을 올바르게 집계한다.

한 관측을 짝지어 보관하고 여러 관측을 묶는다

입력 한 값과 정답 하나를 가진 교육용 자료를 만듭니다. x가 −2, −1, 0, 1, 2이고 정답은 y=2x+1입니다. TensorDataset(x,y)는 두 텐서의 첫 축에서 같은 인덱스를 꺼내 (입력, 정답)의 쌍을 돌려줍니다. x와 y 각각의 모양을 (5,1)로 두었습니다.

데이터 로더는 자료를 꺼내 작은 배치들을 만듭니다. batch_size=2, shuffle=False를 쓰면 처음 두 쌍, 다음 두 쌍, 마지막 한 쌍 순서입니다. 기본 설정인 drop_last=False에서는 마지막에 배치 크기에 못 미쳐도 사용합니다.

이 예에서는 배치를 다 꺼내 관측 다섯 개를 한 번씩 본 것이 한 에포크입니다. 로더를 다시 반복하면 다음 에포크를 진행할 수 있습니다. 자료를 섞는 학습 예에서는 shuffle=True로 입력·정답 쌍의 순서를 섞을 수 있습니다. 평가 자료는 별도로 두고 반복해서 결과를 확인하기 쉽게 순서를 고정할 수 있습니다.

모양을 맞춰 관측마다 손실 하나를 계산한다

이 장에서는 모든 예측을 0으로 두겠습니다. 예측과 정답은 각 배치에서 둘 다 (B,1)입니다. (prediction−target)**2로 관측별 제곱오차를 구합니다. 모양이 (B,1)인 예측에서 (B,)인 정답을 바로 빼면 브로드캐스팅으로 (B,B)가 될 수 있습니다. 각 정답과 각 예측의 모든 조합이 섞이지 않도록 회귀 모양을 맞춥니다.

첫 배치의 오차 제곱은 9,1이라 평균 5입니다. 둘째 배치는 1,9라 평균 5입니다. 마지막 배치는 25 하나라 평균 25입니다.

전체 합과 전체 관측 수로 평균을 구한다

평균에 포함하는 관측들의 수가 각각 다릅니다. 이 예의 전체 평균은 (2×5+2×5+1×25)/(2+2+1)=45/5=9입니다. 배치 평균들을 같은 무게로 평균하면 (5+5+25)/3=35/3이 됩니다. 전체 관측당 평균이 목표면 손실 합과 건수를 따로 더합니다.

여기서는 관측마다 출력을 하나만 갖기 때문에 관측 수가 오차 원소 수와 같습니다. 여러 출력이나 일부 값만 비교하는 경우에는 원하는 평균의 분모, 예를 들어 실제 평가한 값의 수를 기록합니다. 훈련 중 배치마다 모델이 바뀌는 상황의 평균은 에포크 끝 모델을 전체 자료에 한 번 적용한 결과와도 다를 수 있습니다.

같은 자료로 올바른 전체 평균과 잘못된 전체 평균을 대조한다

import torch
from torch.utils.data import DataLoader, TensorDataset

x = torch.tensor([[-2.], [-1.], [0.], [1.], [2.]], device="cpu")
y = 2 * x + 1
data = TensorDataset(x, y)
loader = DataLoader(data, batch_size=2, shuffle=False, num_workers=0)

total = 0.0
count = 0
batch_means = []
for xb, yb in loader:
    squared = (torch.zeros_like(yb) - yb)**2
    mean_loss = squared.mean().item()
    print(tuple(xb.shape), tuple(yb.shape), yb.flatten().tolist(), mean_loss)
    total += squared.sum().item()
    count += len(xb)
    batch_means.append(mean_loss)

print(f"sample mean: {total / count:.4f}")
print(f"unweighted batch mean: {sum(batch_means) / len(batch_means):.4f}")

(2, 1) (2, 1) [1.0, 3.0] 5.0
(1, 1) (1, 1) [5.0] 25.0
sample mean: 9.0000
unweighted batch mean: 11.6667
