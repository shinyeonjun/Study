확산 모형에서 잡음을 더하고 예측해 걷어내기

한 데이터에 잡음을 더하는 규칙과, 잡음이 섞인 데이터에서 무엇을 학습하는지 나눕니다. 스칼라 한 개로 원본 추정을 검산합니다.

이 장을 읽고 나면

  • 잡음 일정과 누적 신호 크기의 뜻을 설명한다.
  • 고정된 잡음으로 한 단계의 값을 계산한다.
  • 잡음 예측 학습과 여러 번의 역방향 생성을 구분한다.

단계마다 사용할 잡음 크기를 정한다

확산 모형은 여러 단계에 걸쳐 원래 상태 x₀에 잡음을 섞는 전방 과정을 정합니다. 정규 잡음을 쓰는 DDPM의 경우 0과 1 사이의 단계별 신호 계수 α를 누적 곱해서 āₜ를 만듭니다. t에서의 상태를 직접 뽑는 식은 xₜ=√āₜ·x₀+√(1−āₜ)·ε입니다. ε는 평균 0, 분산 1인 정규 난수입니다. 배열 데이터를 쓰면 성분과 모양을 맞는 잡음 배열을 사용합니다.

이 장은 손계산을 위해 x₀=2, āₜ=0.64, ε=−0.5로 정합니다. 원본 계수는 √0.64=0.8이고 잡음 계수는 √0.36=0.6입니다. 따라서 xₜ=0.8×2+0.6×(−0.5)=1.3입니다.

잡음을 예측하면 원래 값도 추정할 수 있다

정확한 ε를 알고 있고 āₜ>0이라면 전방식을 정리해 (xₜ−√(1−āₜ)·ε)/√āₜ로 x₀를 계산합니다. xₜ=1.3에서 예제의 참 잡음 −0.5를 쓰면 (1.3+0.3)/0.8=2입니다. 모형이 ε̂=−0.4를 냈다면 (1.3+0.24)/0.8=1.925입니다. 잡음 오차가 원본 추정에도 영향을 줍니다.

사용한 잡음원래 값 추정원래 2와의 절대 차이
실제 −0.52.0000.000
예측 −0.41.9250.075
from math import sqrt

original, a_bar, actual_noise = 2, 0.64, -0.5
signal_scale = sqrt(a_bar)
noise_scale = sqrt(1-a_bar)
corrupted = signal_scale*original + noise_scale*actual_noise

def estimate_original(noise):
    return (corrupted-noise_scale*noise)/signal_scale

print("잡음 상태:", f"{corrupted:.4f}")
print("참 잡음으로:", f"{estimate_original(actual_noise):.4f}")
print("예측 잡음으로:", f"{estimate_original(-0.4):.4f}")

실행 결과

잡음 상태: 1.3000
참 잡음으로: 2.0000
예측 잡음으로: 1.9250

학습의 목표와 생성 절차를 구분한다

훈련에서는 자료에서 원본을 뽑고, 단계와 잡음도 뽑아 xₜ를 만듭니다. 잡음 예측 방식에서는 모형의 입력으로 xₜ와 t를 주고, 실제 ε와 예측 ε̂ 사이의 제곱오차를 학습에 쓸 수 있습니다. 생성은 끝 쪽 잡음 상태에서 시작해 앞쪽으로 여러 번 이동합니다. 위의 계산은 한 단계의 추정을 이해하기 위한 것입니다. 여러 단계를 되돌리는 실제 샘플러에는 역방향 분포와 단계 규칙도 필요합니다.

한 줄 정리

확산은 어떤 잡음을 넣는지 정하고 그 잡음을 예측하도록 학습합니다. 새 자료는 잡음 상태에서 단계별로 생성합니다.
