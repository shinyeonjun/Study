정규화의 축과 잔차 연결의 경로

같은 작은 배치를 두 방법으로 정규화해 어떤 값이 함께 집계되는지 봅니다. 잔차 연결이 기울기에 더하는 항도 계산합니다.

이 장을 읽고 나면

  • LayerNorm과 BatchNorm이 평균을 내는 축을 정한다.
  • 훈련·평가에서 BatchNorm 상태가 어떻게 쓰이는지 확인한다.
  • 잔차 연결을 지나는 두 기울기 경로를 계산한다.

한 줄 안에서 묶을지, 배치의 같은 열을 묶을지 정한다

[[1,3],[2,6]]은 샘플 두 개와 특성 두 개를 담은 (N,C) 배열입니다. 평균 μ와 분산 σ²를 구하고, 각 x를 (x−μ)/√(σ²+ε)로 바꿉니다. 분모가 0이 되지 않게 작은 양수 ε를 넣습니다. 학습 가능한 스케일과 편향이 있는 설정에서는 여기에 다시 값을 곱하고 더할 수 있습니다.

LayerNorm(2)는 샘플마다 마지막 특성 두 개를 함께 봅니다. 첫 행의 평균은 2, 둘째 행은 4입니다. 행마다 정규화 값은 약 [−1,1]입니다. 이 장의 2차원 BatchNorm1d(2)는 훈련 중 같은 열의 두 샘플을 함께 봅니다. 특성별 평균은 [1.5,4.5]이고 훈련 출력 행은 각각 약 [−1,−1], [1,1]입니다.

같은 층이라도 평가에서 어떤 통계를 쓰는지 확인한다

기본 track_running_stats=True인 BatchNorm은 훈련 중 얻은 평균과 분산의 이동 통계를 버퍼에 남깁니다. 평가에서는 이 축적된 값을 사용합니다. PyTorch의 훈련 순전파 분산은 N으로 나누고, 버퍼에 반영하는 배치 분산은 N−1로 나눕니다. 이 장은 차이를 보이려고 모멘텀을 1로 두어 이번 배치 통계로 바로 바꿉니다. 첫 열 [1,2]의 평균은 1.5이고 분산은 훈련에서 0.25, 버퍼에 0.5가 기록됩니다.

기본 LayerNorm은 훈련과 평가 모두 현재 입력의 지정 축에서 통계를 냅니다. 배치를 섞었을 때 결과가 달라진다면 입력, 상태, 사용하는 축부터 확인합니다. BatchNorm의 이동 통계는 state_dict()에 포함되는 버퍼여서 저장한 가중치를 평가에 불러올 때 함께 복원합니다.

입력을 더하는 길을 하나 추가한다

잔차 연결은 같은 모양의 입력 x를 변환 F(x)에 더해 y=x+F(x)를 만듭니다. 스칼라에서는 dy/dx=1+F′(x)이고, 벡터라면 항등 행렬 I와 F의 야코비안을 더합니다. 변환 쪽의 미분이 작더라도 직접 경로에서 1이 더해질 수 있습니다. 이 경로가 모든 모델의 폭주나 소실을 자동으로 해결하지는 않습니다. 축 크기가 다르면 그대로 더할 수 있는지 확인하고 필요한 경우 별도 변환을 둡니다.

import torch
from torch import nn

torch.set_num_threads(1)
x = torch.tensor([[1.0, 3.0], [2.0, 6.0]])
layer = nn.LayerNorm(2, elementwise_affine=False)
batch = nn.BatchNorm1d(2, affine=False, momentum=1.0)

def rounded(x):
    return [[round(v, 3) for v in row] for row in x.tolist()]

batch.train()
print("layer norm:", rounded(layer(x)))
print("batch train:", rounded(batch(x)))
print("running mean:", batch.running_mean.tolist())
print("running var:", batch.running_var.tolist())
batch.eval()
with torch.no_grad():
    print("batch eval:", rounded(batch(x)))

a = torch.tensor(2.0, requires_grad=True)
out = a + 0.5 * a
out.backward()
print("residual:", out.item(), "grad:", a.grad.item())
layer norm: [[-1.0, 1.0], [-1.0, 1.0]]
batch train: [[-1.0, -1.0], [1.0, 1.0]]
running mean: [1.5, 4.5]
running var: [0.5, 4.5]
batch eval: [[-0.707, -0.707], [0.707, 0.707]]
residual: 3.0 grad: 1.5

실행 환경은 Python 3.14.6과 PyTorch 2.14.1+cu130의 CPU입니다. 입력과 계산에 쓰는 값을 직접 정했습니다.

예제의 LayerNorm·BatchNorm은 스케일과 편향을 빼고 집계 축만 비교합니다. 평가에서는 실행 결과와 함께 batch.training 상태도 확인할 수 있습니다.
