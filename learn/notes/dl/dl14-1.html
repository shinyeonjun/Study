딥러닝 · DL14 표현학습의 평가와 재사용

DL14·1

대조 손실이 보존하는 정보를 동결 평가로 확인하기

두 사진을 같은 물체의 모습으로 묶을 때, 모양과 조명 중 어느 것이 같아야 할까요? 같은 원본을 어떻게 바꾸느냐에 따라 손실이 좋아하는 표현이 달라집니다. 학습한 표현을 다른 조건에서 써 보는 방식까지 계산합니다.

이 장을 읽고 나면

  • 대조 손실의 긍정·비교 후보와 정규화 분모를 계산한다.
  • 붕괴 표현과 원본마다 달라지는 지름길을 구별한다.
  • 동결 선형 평가, 전체 미세조정, 원본 그룹 분할을 비교한다.

각 표현이 자기 짝을 후보 가운데 찾는다

원본 두 개에서 각각 두 변형본을 만들어 네 표현 z를 얻습니다. 앵커 하나에서 같은 원본의 다른 표현 한 개가 positive입니다. 자기 자신만 분모에서 빼고, positive와 다른 원본 표현 두 개를 모두 후보로 둡니다. 단위 벡터로 정규화한 코사인 유사도를 온도 τ>0로 나눠 softmax를 구하고, positive에 준 확률의 음의 로그를 최소로 합니다.

positive의 코사인이 1, 다른 둘이 0, τ=.5이면 positive 확률은 e²/(e²+2)이고 손실은 log(1+2e⁻²)≈.239545입니다. 네 표현이 모두 같은 방향으로 붕괴하면 세 후보가 각각 1/3이라 손실은 log 3≈1.098612입니다. 손실값의 비교로 이 예에서는 붕괴가 낮은 값이 아님을 알 수 있습니다. 경사로 학습할 때 어떤 점에 멈출지는 초기화·표현·최적화 규칙에도 달려 있습니다.

같은 원본에서 무엇을 바꾸는지가 목표를 정한다

두 원본의 의미 좌표 s는 각각 −1과 +1이고, 조명처럼 부차적인 좌표 n과 구분된다고 합시다. 같은 원본의 두 변형에서 n의 부호는 바꾸고 s는 보존합니다. 그때 z=s를 쓰면 positive 코사인은 1이고 다른 두 후보는 −1입니다. 손실은 log(1+2e⁻⁴)≈.035976입니다. z=n에서는 positive가 −1이고 다른 둘은 1과 −1이어서 손실이 약 4.035976입니다.

표현positive와 나머지의 유사도손실
의미 보존1 / −1, −10.035976
변하는 조명만 보존−1 / 1, −14.035976
조명을 원본별로 고정해 복제1 / −1, −10.035976

두 원본의 조명 부호를 −1과 +1로 서로 다르게 고정하고 아무 변화 없이 두 장을 복제하면 조명만으로도 같은 낮은 손실을 얻습니다. 같은 대조 목적값이 원하는 특성을 보장하는지는 증강 규칙을 봐야 합니다. 예를 들어 원본들이 실제로 같은 클래스를 나타내더라도, 다른 원본이라는 이유로 해당 배치에서 비교 후보가 될 수 있습니다.

표현이 실제로 무엇을 넘겨주는지 측정한다

동결 선형 평가는 표현을 움직이지 않고 선형 머리만 학습합니다. 동결된 표현이 가리고 있는 정보는 머리만으로 되찾기 어렵습니다. 전체 미세조정은 같은 시작점에서 표현층도 갱신합니다. 아래에서는 의미 또는 조명 좌표 하나를 읽는 선형 표현과, 그 위에 스칼라 선형 분류기를 둡니다. 새 개체는 같은 부호라도 다른 좌표 절댓값을 가집니다. 훈련에 들어간 개체의 조명 변형이 시험에 섞이지 않도록 먼저 개체를 나눕니다.

보류 개체 4개의 두 변형씩 8행을 평가하면 동결 의미는 정확도 1, 동결 조명은 .5, 조명에서 시작해 표현까지 움직이면 1이 됩니다. 조명만 보면 같은 조명에 두 라벨이 균등하게 들어 있습니다. 데이터의 구조와 대상이 있는 작은 실험이므로, 같은 수치를 다른 자료에 그대로 옮기기보다 어떤 정보를 보존하고 무엇을 평가했는지 확인합니다. 이미지나 문장 모델에서 Dropout 또는 BatchNorm을 사용했다면 동결 평가 시 실행 모드와 상태도 함께 확인합니다.

from math import exp, log1p, log
import torch
from torch.nn import functional as F

torch.manual_seed(1)
torch.set_num_threads(1)
torch.use_deterministic_algorithms(True)
d = torch.float64
torch.set_default_dtype(d)

def ntxent(z, tau=.5):
    z = F.normalize(z,dim=-1)
    sim = z @ z.T / tau
    positive = torch.tensor([1,0,3,2])
    diag = torch.eye(z.shape[0],dtype=torch.bool)
    return F.cross_entropy(sim.masked_fill(diag,-torch.inf),positive)

orth = torch.tensor([[1.,0.],[1.,0.],[0.,1.],[0.,1.]])
collapsed = torch.ones(4,2)
assert abs(ntxent(orth).item()-log1p(2*exp(-2))) < 1e-12
assert abs(ntxent(collapsed).item()-log(3)) < 1e-12
semantic = torch.tensor([[-1.],[-1.],[1.],[1.]])
nuisance = torch.tensor([[-1.],[1.],[-1.],[1.]])
same_view_style = torch.tensor([[-1.],[-1.],[1.],[1.]])
assert abs(ntxent(semantic).item()-log1p(2*exp(-4))) < 1e-12
assert abs(ntxent(nuisance).item()-(4+log1p(2*exp(-4)))) < 1e-12
print("orthogonal/collapse",*(f"{ntxent(z):.6f}" for z in (orth,collapsed)))
print("augmented semantic/nuisance; unaugmented style",
      *(f"{ntxent(z):.6f}" for z in (semantic,nuisance,same_view_style)))

def samples(magnitudes):
    # Each distinct first coordinate corresponds to a separate entity.
    # Its two views n=-1 and n=+1 stay in the same split.
    x = torch.tensor([[sgn*m,n] for m in magnitudes
                      for sgn in (-1,1) for n in (-1,1)])
    return x,x[:,0].gt(0).to(d)

train,y_train = samples((.6,1.1))
test,y_test = samples((.8,1.3))
assert set(train[:,0].tolist()).isdisjoint(test[:,0].tolist())

def adapt(coordinate,frozen):
    w = torch.tensor([1.,0.] if coordinate==0 else [0.,1.],requires_grad=not frozen)
    head = torch.tensor(1.,requires_grad=True)
    params = [head] if frozen else [head,w]
    optimizer = torch.optim.SGD(params,lr=.2)
    for _ in range(100):
        optimizer.zero_grad(set_to_none=True)
        loss = F.binary_cross_entropy_with_logits(head*(train@w),y_train)
        loss.backward()
        optimizer.step()
    with torch.no_grad():
        pred = head*(test@w)
        return F.binary_cross_entropy_with_logits(pred,y_test).item(), pred.gt(0).eq(y_test.bool()).to(d).mean().item()
for coordinate,frozen in ((0,True),(1,True),(1,False)):
    loss,acc = adapt(coordinate,frozen)
    print("transfer",coordinate,frozen,f"{loss:.6f}",f"{acc:.2f}")
