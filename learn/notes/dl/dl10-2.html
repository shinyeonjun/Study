자기지도 대조학습에서 가까워질 표현 정하기

사람이 입력마다 정답 범주를 붙이지 않아도 입력 자체에서 학습 신호를 만들 수 있습니다. 세 이미지 후보 중 같은 원본에서 온 표현을 고르는 손실을 계산합니다.

이 장을 읽고 나면

  • 자기지도 학습 신호와 평가용 라벨을 구분한다.
  • 유사도와 온도를 대조 손실에 적용한다.
  • 양성 쌍의 정의와 배치 내 음성의 한계를 설명한다.

어떤 두 입력을 같은 대상으로 볼 것인가

한 그림에서 서로 다른 두 자르기 결과를 만든다고 합시다. 두 결과는 같은 원본에서 왔으므로 양성 쌍으로 정합니다. 다른 원본에서 만든 결과를 비교에 넣을 수 있습니다. 모델이 답해야 할 쌍의 종류는 원본과 변환으로 생성됐습니다. 분류용 정답처럼 사람이 입력마다 붙여 주지 않아도 학습 신호가 생깁니다. 이런 방식이 자기지도의 한 예입니다.

그림을 자를 때 관심 대상이 완전히 사라지면 두 입력이 같아야 한다는 가정이 약해집니다. 자료에서 무엇을 같게 보고 무엇을 구분할 것인지와 작업 목적을 연결합니다.

내적을 확률의 분자로 바꾼다

정의 · InfoNCE 대조 손실 (SimCLR의 NT-Xent)

기준 표현 z, 양성 z⁺, 음성 z₁⁻, …, zK⁻에 대해
ℓ = −ln [ exp(sim(z, z⁺)/τ) / ( exp(sim(z, z⁺)/τ) + Σk exp(sim(z, zk⁻)/τ) ) ]

sim은 코사인 유사도(길이 1로 정규화한 벡터의 내적), τ>0은 온도입니다. 이것은 "후보 K+1개 가운데 양성을 고르는 분류"의 softmax 교차엔트로피와 같은 식입니다. SimCLR은 이미지 N장에서 증강된 보기 2N개를 만들고, 각 보기마다 짝이 된 보기 하나를 양성, 나머지 2N−2개를 음성으로 씁니다(배치 내 음성). 손실은 인코더 뒤에 붙인 작은 투영 헤드의 출력에서 계산하고, 뒤의 과제에는 투영 헤드 앞의 인코더 표현을 씁니다.

이미 정규화된 길이 1의 벡터를 사용합니다. 기준 표현이 (1,0)이고 후보가 양성 (1,0), 다른 후보 (0,1)과 (−1,0)이면 내적은 각각 1, 0, −1입니다. 온도 τ=0.5로 나누면 소프트맥스 입력은 2, 0, −2입니다. 이 셋에서 양성의 확률은 약 0.866813입니다. 선택할 확률을 높이도록 음의 로그확률 약 0.142932를 줄입니다.

from math import exp, log

scores = [1, 0, -1]
for temperature in (0.5, 1.0):
    logits = [score/temperature for score in scores]
    largest = max(logits)
    weights = [exp(value-largest) for value in logits]
    positive = weights[0]/sum(weights)
    print("온도", temperature, "양성 확률", f"{positive:.6f}",
          "손실", f"{-log(positive):.6f}")

실행 결과

온도 0.5 양성 확률 0.866813 손실 0.142932
온도 1.0 양성 확률 0.665241 손실 0.407606

쌍 규칙이 표현 평가를 대신하지 않는다

온도를 낮추면 같은 순위에서 높은 점수와 낮은 점수의 차이가 커집니다. 양성 쌍이 잘못 정해졌거나 비슷한 의미의 다른 원본이 음성으로 들어가면, 그런 차이를 키우는 것이 목표와 어긋날 수 있습니다. 배치 후보가 무엇인지 확인하고, 학습한 표현이 뒤의 독립 문제에서 필요한 정보를 담았는지 출력층 학습이나 검색 평가로 검토합니다.

한 줄 정리

자기지도 대조학습에서는 쌍의 정의가 훈련 신호입니다. 실제로 필요한 표현이 되었는지는 별도로 평가합니다.
