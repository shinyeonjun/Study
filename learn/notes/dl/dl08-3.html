PyTorch 블록에서 차원과 미래 토큰 차단을 확인하기

앞 장의 마스크를 작은 Transformer 블록에서 직접 씁니다. 마지막 토큰만 바꿔 앞 위치의 출력이 그대로인지 검사합니다.

이 장을 읽고 나면

  • 머리 수와 토큰 표현 차원을 연결한다.
  • attention·잔차·층 정규화·토큰별 변환의 차원을 확인한다.
  • 미래 토큰을 바꿔 인과 마스크를 검증한다.

세 위치가 각각 네 개의 특징을 가진다

배치 하나에서 세 토큰을 처리하고 표현 차원은 4라고 둡니다. 입력 배열은 (배치, 위치, 특징)=(1,3,4)입니다. attention 머리를 두 개로 두면 각 머리의 질의·키·값은 특징 차원 2로 계산됩니다. 이를 다시 합쳐 길이 4의 표현을 만들 수 있으므로 입력과 더하는 잔차의 형태가 맞습니다.

같은 마스크라도 라이브러리의 참·거짓 의미를 확인한다

이 예의 torch.nn.MultiheadAttention에서 불리언 마스크가 True인 쿼리·키 위치는 attend하지 않도록 차단합니다. triu(diagonal=1)로 대각선 위만 True를 만듭니다. 각 머리의 첫 위치는 자기 첫 위치만 볼 수 있으므로, 평가 모드에서는 그 행의 가중치가 [1,0,0]이어야 합니다.

모형 출력과 가중치 배열의 차원을 확인합니다. 배치 모양은 유지되고, 머리별 가중치 모양은 (배치, 머리, 쿼리, 키)=(1,2,3,3)입니다. 각 위치의 피드포워드 모형과 층 정규화는 다른 토큰과 섞지 않습니다.

import torch
from torch import nn

torch.manual_seed(17)

class TinyBlock(nn.Module):
    def __init__(self):
        super().__init__()
        self.attention = nn.MultiheadAttention(4, 2, batch_first=True)
        self.norm1 = nn.LayerNorm(4)
        self.feedforward = nn.Sequential(nn.Linear(4, 8), nn.ReLU(), nn.Linear(8, 4))
        self.norm2 = nn.LayerNorm(4)

    def forward(self, input_values, mask):
        attention, weights = self.attention(
            input_values, input_values, input_values, attn_mask=mask,
            average_attn_weights=False,
        )
        features = self.norm1(input_values + attention)
        return self.norm2(features + self.feedforward(features)), weights

model = TinyBlock().eval()
values = torch.arange(12, dtype=torch.float32).reshape(1, 3, 4)
modified = values.clone()
modified[0, 2] += torch.tensor([4., 0., -3., 2.])
blocked = torch.ones(3, 3, dtype=torch.bool).triu(diagonal=1)
with torch.no_grad():
    before, weights = model(values, blocked)
    after, _ = model(modified, blocked)
    same = torch.allclose(before[:, :2], after[:, :2], atol=1e-6)
    assert same
print("출력:", tuple(before.shape))
print("머리별 가중치:", tuple(weights.shape))
print("첫 위치 가중치:", weights[0, 0, 0].tolist())
print("앞 두 위치 동일:", same)

실행 결과

출력: (1, 3, 4)
머리별 가중치: (1, 2, 3, 3)
첫 위치 가중치: [1.0, 0.0, 0.0]
앞 두 위치 동일: True

그림이 맞아도 실제 축을 검사한다

마지막 벡터만 바꾼 뒤 1, 2번 위치의 출력에 차이가 없다면 이 입력에서 미래 값이 앞쪽에 전달되지 않았음을 확인한 것입니다. 또 패딩이 있는 실제 데이터에서는 가짜로 채운 토큰 위치를 별도로 가려야 합니다. 각 라이브러리 함수에서 마스크 형태와 True의 의미를 확인하고, 아주 작은 모양의 입력으로 먼저 테스트합니다.

한 줄 정리

블록에서 배치·위치·특징 축을 읽고, 미래 입력을 바꾸는 작은 시험으로 마스크가 맞게 적용되는지 봅니다.
