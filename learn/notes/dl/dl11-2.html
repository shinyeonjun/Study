LayerNorm의 세 경로와 활성함수의 스케일 검산

좌표 하나를 바꾸면 그 좌표뿐 아니라 행 전체의 평균과 분산도 바뀝니다. 이 변화가 역전파에 모두 들어가는지 도출하고, 너무 큰 입력이 활성함수 미분을 줄이는 예를 살핍니다.

이 장을 읽고 나면

  • 평균, 중심화, 스케일을 거치는 경로에서 LayerNorm 기울기를 구한다.
  • 해석식과 자동미분에서 같은 입력 경사가 나오는지 검사한다.
  • 입력과 초기 가중치 하나씩을 바꾸어 활성함수의 포화를 확인한다.

정규화에서 각 좌표의 계산이 서로 연결된다

한 행의 좌표 x에서 m=mean(x), z=x−m, s=√(mean(z²)+ε), x̂=z/s라 둡니다. ε>0은 분모가 0으로 떨어지지 않게 합니다. PyTorch nn.LayerNorm의 기본값은 ε=1e−5이고, 아래 예는 손계산이 쉽도록 ε=1/3을 씁니다. 출력은 y=γ⊙x̂+β입니다. 여기서 γ와 β는 좌표별 학습 매개변수입니다. 평균과 분산은 현재 행의 좌표를 함께 사용합니다.

차분을 먼저 계산하고 내적을 묶는다

dm=mean(dx), dz=dx−dm입니다. z의 합이 0이므로 mean(z⊙dz)=mean(z⊙dx)입니다. 따라서 ds=mean(z⊙dx)/s입니다. x̂의 변화는 (dx−dm)/s−z·ds/s²입니다. 출력 경사 g에 γ를 곱한 h=g⊙γ와 이 식을 내적하고, dx의 계수만 모읍니다.

입력 경사 = [h−mean(h)−x̂ · mean(h⊙x̂)]/s

g에서 각 좌표의 γ 경사는 g⊙x̂, β 경사는 g입니다. 여러 행에서 매개변수를 공유하면 각 행의 기여를 더합니다. x=(1,2,3), ε=1/3이면 m=2, 분산 2/3, s=1, x̂=(−1,0,1)입니다. g=(1,2,4), γ=(1,1,1)에서는 mean(h)=7/3, mean(h⊙x̂)=1이라 경사는 (−1/3,−1/3,2/3)입니다. 행 전체에 같은 값을 더하면 z가 그대로라, 이 방향의 손실 미분이 0인 것도 합계로 확인할 수 있습니다.

활성함수에서는 입력과 초깃값을 하나씩 바꿔 본다

tanh 한 뉴런의 출력 tanh(wx)를 w로 미분하면 x·(1−tanh²(wx))입니다. w=1에서 x를 .25,1,4로 올리면 경사는 .2350, .4200, .0054입니다. x가 작을 때는 앞에 곱한 x 때문에 경사가 커지지만, |wx|가 커지면 tanh가 ±1 가까이 가며 안쪽 미분 1−tanh²가 거의 0이 되어 경사도 줄어듭니다. x=2를 고정하고 w만 .1,1,3으로 바꾼 결과도 아래에 있습니다. 반올림한 0.0000은 해석적으로 정확히 0이라는 뜻과 다릅니다.

ReLU는 다른 활성입니다. x=0에서 왼쪽과 오른쪽 기울기가 달라 미분이 정의되지 않습니다. PyTorch 2.14.0의 torch.relu는 이 점에서 기울기 0을 돌려주도록 정해 두었고(직접 확인), 중심차분은 (ε−0)/(2ε)=0.5를 냅니다. 그래서 수치 검사에서는 매끄러운 점을 쓸지 구현의 규칙을 확인할지 먼저 정합니다. 더 깊은 모델에서 초기 가중치 규모를 고를 때는 활성함수, 입력 및 출력 차원과 분산의 전달도 같이 봅니다.

import math
import torch
from torch.nn import functional as F

torch.set_num_threads(1)
d = torch.float64
x = torch.tensor([1.,2.,3.],dtype=d,requires_grad=True)
g = torch.tensor([1.,2.,4.],dtype=d)
gamma = torch.ones(3,dtype=d,requires_grad=True)
beta = torch.zeros(3,dtype=d,requires_grad=True)
y = F.layer_norm(x,(3,),gamma,beta,eps=1/3)
dx,dgamma,dbeta = torch.autograd.grad(y,(x,gamma,beta),grad_outputs=g)
std=(x.var(unbiased=False)+1/3).sqrt()
z=(x-x.mean())/std
h=g*gamma
assert torch.allclose(dx,(h-h.mean()-z*(h*z).mean())/std,atol=1e-12,rtol=0)
assert torch.equal(dgamma,g*z) and torch.equal(dbeta,g)
print("layernorm"," ".join(f"{v:.6f}" for v in dx.tolist()),dgamma.tolist(),dbeta.tolist())

def tanh_weight_gradient(x,w):
    return x*(1-math.tanh(w*x)**2)
print("input scaling"," ".join(f"{tanh_weight_gradient(x,1.):.4f}" for x in (.25,1.,4.)))
print("init scaling"," ".join(f"{tanh_weight_gradient(2.,w):.4f}" for w in (.1,1.,3.)))
