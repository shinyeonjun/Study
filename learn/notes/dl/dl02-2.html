DL02·2

autograd로 기울기를 계산하고 비우기

자동 미분을 실행해 입력과 매개변수의 변화율을 읽습니다. 같은 미분을 두 번 계산했을 때 저장값이 왜 두 배가 되는지도 확인합니다.

이 장을 읽고 나면

  • autograd가 기록하는 연산과 .grad에 저장되는 값을 구분한다.
  • 새 순전파에서 기울기가 누적되는 동작과 초기화 이유를 확인한다.
  • 미분하는 입력과 실제 갱신하는 매개변수를 선택한다.

미분할 값과 실제 움직일 값을 따로 정한다

PyTorch의 자동 미분(autograd)은 순전파에서 행한 텐서 연산의 의존 관계를 기록하고, 역전파에서 필요한 미분을 계산합니다. 실수 텐서를 만들 때 requires_grad=True를 두면, 그 텐서에 대한 미분이 필요한 계산을 기록할 수 있습니다. loss.backward()를 부르면 스칼라 손실에 대한 역전파가 시작됩니다.

w=0, x=2에서 L=(wx−4)²/2를 생각합니다. 예측은 0, 손실은 8입니다. ∂L/∂w=(wx−4)x=−8이고 ∂L/∂x=(wx−4)w=0입니다. 여기서는 입력 x의 미분도 확인하지만 경사하강에서 움직일 항목은 w 하나입니다.

위와 같이 사용자가 먼저 만들어 연산의 시작점으로 둔 텐서를 리프 텐서라고 합니다. 기본적으로 기울기는 미분을 요청한 리프의 .grad에 쌓입니다. 곱 wx나 손실처럼 연산 결과로 만들어진 중간 텐서의 기울기를 저장하고 싶다면 retain_grad() 같은 별도 동작이 필요합니다.

새 계산을 역전파해도 기존 .grad에는 더해진다

새 손실을 계산해 역전파할 때 PyTorch는 그 결과를 기존 .grad에 더합니다. w를 바꾸지 않은 상태로 새 순전파와 역전파를 두 번 하면, 두 번 모두 새 기울기가 −8이어도 저장된 값은 −8에서 −16으로 바뀝니다.

이번 배치의 기울기만 사용하려면 이전 .grad를 비워야 합니다. 예는 w.grad = None을 사용합니다. 학습 루프에서는 최적화 도구에 등록한 파라미터를 optimizer.zero_grad()로 한 번에 초기화합니다(PyTorch 2.x의 기본값 set_to_none=True는 0을 채우는 대신 .grad를 None으로 만듭니다). 보통 역전파가 끝난 그래프에서 계산 중간정보는 해제되므로, 다음 손실은 새 순전파에서 계산합니다.

갱신 자체를 새로 미분할 필요가 없는 경우

학습률을 0.125로 정하면 w는 0−0.125×(−8)=1입니다. x는 2 그대로입니다. 보통의 경사하강에서 이 값 수정 자체를 다음 역전파 그래프에 담지 않으므로, 파라미터를 직접 수정하는 예에서는 torch.no_grad() 범위를 사용합니다. 이 범위를 나오면 다시 기울기를 기록하는 연산을 할 수 있습니다.

같은 입력에서 w가 1이 되었으므로 이제 예측은 2입니다. 손실은 2, 새 기울기는 ∂L/∂w=(2−4)×2=−4, ∂L/∂x=(2−4)×1=−2입니다. requires_grad는 텐서마다 붙는 속성이고, no_grad()는 그 범위 안의 연산을 기록하지 않는 실행 문맥입니다. 아래 코드에서 w는 여전히 requires_grad=True지만, no_grad() 안에서 계산한 test_prediction은 기록되지 않아 requires_grad가 False로 나옵니다.

미분의 누적, 초기화, 갱신을 차례로 실행한다

import torch

w = torch.tensor(0., device="cpu", requires_grad=True)
x = torch.tensor(2., device="cpu", requires_grad=True)

def loss_at_current_values():
    return (w * x - 4)**2 / 2

loss_at_current_values().backward()
print("first (dw, dx):", w.grad.item(), x.grad.item())

loss_at_current_values().backward()
print("accumulated dw:", w.grad.item())

w.grad = None
x.grad = None
loss_at_current_values().backward()
print("after reset, dw:", w.grad.item())

with torch.no_grad():
    w -= 0.125 * w.grad
    test_prediction = w * x
print("w, x:", w.item(), x.item())
print("prediction recorded:", test_prediction.requires_grad)

w.grad = None
x.grad = None
new_loss = loss_at_current_values()
new_loss.backward()
print("new loss, dw, dx:", new_loss.item(), w.grad.item(), x.grad.item())
first (dw, dx): -8.0 -0.0
accumulated dw: -16.0
after reset, dw: -8.0
w, x: 1.0 2.0
prediction recorded: False
new loss, dw, dx: 2.0 -4.0 -2.0

실행 확인 환경 · Python 3.14.6, PyTorch 2.14.0+cu130, CPU. w와 x는 직접 초기화했습니다. 출력의 −0.0은 부동소수점에서 표현되는 0입니다.

한눈에 정리

표현뜻
requires_grad이 텐서에 대한 계산 경로의 기울기가 필요한지 표시.
backward / .grad기록한 순전파를 거슬러 계산하고 리프에 기울기를 더한다.
no_grad그 범위의 연산은 역전파용으로 기록하지 않는다.
