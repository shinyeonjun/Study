딥러닝 · DL08 Transformer

DL08·1

Transformer에 위치 정보와 잔차 연결을 넣는 이유

Attention은 여러 토큰의 표현을 섞습니다. 그 표현에 순서의 단서를 어디에 더하는지, 블록의 계산을 거쳐도 입력을 어떻게 함께 남기는지 봅니다.

이 장을 읽고 나면

  • 위치 정보와 토큰 임베딩을 구분한다.
  • 아주 작은 사인·코사인 위치 벡터를 만든다.
  • attention·잔차·층 정규화·피드포워드의 역할을 연결한다.

같은 단어가 두 곳에서 나올 수 있다

토큰 임베딩은 토큰의 ID로 찾아온 벡터입니다. 같은 토큰이 문장의 두 위치에 있어도 처음의 토큰 벡터만 보면 같습니다. 위치 정보나 위치에 의존하는 마스크가 없는 자기 attention에서는 입력 위치를 섞으면 출력 위치도 같은 방식으로 섞입니다. 위치를 따로 주면 모델이 ‘어떤 토큰인가’와 함께 ‘어디에 있었나’를 사용할 수 있습니다.

원 논문의 한 방법은 위치마다 사인과 코사인의 쌍을 서로 다른 속도로 넣는 것입니다. 표현 차원 4의 예에서는 두 쌍의 각이 p와 p/100입니다. 위치 p=0이면 (0,1,0,1)입니다. p=1에서는 (sin 1, cos 1, sin 0.01, cos 0.01)입니다. 이 벡터를 토큰 벡터와 성분별로 더합니다.

정의 · 사인·코사인 위치 부호화 (Vaswani 외 2017)

PE(p, 2i) = sin(p / 100002i/dmodel),  PE(p, 2i+1) = cos(p / 100002i/dmodel)
p는 0부터 센 위치, i=0, 1, …, dmodel/2−1은 사인·코사인 쌍의 번호입니다. dmodel=4이면 i=0의 분모는 10000⁰=1, i=1의 분모는 100002/4=100이라 위의 각 p와 p/100이 나옵니다. 앞쪽 쌍은 위치에 따라 빨리 돌고 뒤쪽 쌍은 천천히 돌아, 여러 쌍을 함께 보면 위치마다 다른 무늬가 됩니다. 원 논문은 이 벡터를 임베딩과 더하기 전에 임베딩에 √dmodel을 곱했습니다.

학습 가능한 위치 벡터나, attention의 점수에 위치 관계를 반영하는 방식도 있습니다. 이 장의 고정 신호는 위치를 표현하는 여러 방식 중 하나입니다.

토큰 사이를 섞고 토큰 내부도 바꾼다

여러 헤드 어텐션

Transformer의 attention 하위층은 DL07의 스케일드 점곱 어텐션을 헤드 h개로 나눠 병렬로 계산하는 다중 헤드 어텐션(multi-head attention)입니다.

정의 · 다중 헤드 어텐션

headⱼ = Attention(XWjQ, XWjK, XWjV),  j=1, …, h
MultiHead(X) = Concat(head₁, …, headh) WO

X는 (L, dmodel), 각 WjQ, WjK는 (dmodel, dk), WjV는 (dmodel, dv), WO는 (h·dv, dmodel)입니다. 보통 dk=dv=dmodel/h로 둡니다. 원 논문은 dmodel=512, h=8, dk=64였습니다. 헤드 각각의 출력은 (L, 64), 이어 붙이면 (L, 512), WO를 곱해도 (L, 512)라 입력과 모양이 같습니다.

헤드마다 서로 다른 투영을 쓰므로 한 헤드는 바로 앞 토큰, 다른 헤드는 멀리 떨어진 관련 토큰처럼 서로 다른 관계에 높은 가중치를 줄 수 있습니다. 그렇게 나뉜다는 것은 학습 결과로 생길 수 있는 일이지 구조가 보장하는 것은 아닙니다.

잔차 연결

잔차 연결에서는 블록의 입력 x에 블록이 계산한 변화 F(x)를 더해 x+F(x)를 냅니다. 예를 들어 x=[1,3], F(x)=[0.5,−0.5]면 합은 [1.5,2.5]입니다. 더하려면 F(x)의 모양이 x와 같아야 하므로, 위 다중 헤드 어텐션과 피드포워드 층은 모두 dmodel 크기를 내도록 맞춥니다.

잔차를 넣는 이유는 기울기 경로입니다. y=x+F(x)의 미분은 ∂y/∂x = I + ∂F/∂x (I는 항등행렬)입니다. F의 미분이 작아져도 항등 경로 I로 기울기가 그대로 아래층까지 내려가므로, 블록을 수십 개 쌓아도 앞쪽 층이 학습됩니다. 또 F가 0에 가까우면 블록이 입력을 거의 그대로 넘기므로, 각 블록은 "입력을 얼마나 고칠지"만 배우면 됩니다.

층 정규화와 피드포워드 층

정의 · 층 정규화(LayerNorm)

한 토큰의 특징 벡터 z=(z₁,…,zd)에 대해 μ=(1/d)Σzᵢ, σ²=(1/d)Σ(zᵢ−μ)²,
LN(z)ᵢ = γᵢ·(zᵢ−μ)/√(σ²+ε) + βᵢ

평균·분산은 배치가 아니라 한 토큰 안의 특징 축으로 구합니다(배치 정규화와 다른 점). 분산은 n으로 나눈 값이고, ε은 0으로 나누는 것을 막는 작은 수(PyTorch 기본 1e−5), γ와 β는 학습되는 크기·이동 매개변수입니다(처음 값 1과 0).

[1.5,2.5]의 평균은 2, 분산은 ((−0.5)²+0.5²)/2=0.25, 표준편차 0.5이므로 γ=1, β=0에서 LN 결과는 [−1, 1]입니다(ε 때문에 실제로는 ±0.99998).

위치별 피드포워드 층(position-wise feed-forward)은 토큰마다 같은 두 층 신경망 FFN(x)=max(0, xW₁+b₁)W₂+b₂를 따로 적용합니다. 원 논문은 W₁이 512→2048, W₂가 2048→512였습니다. attention이 토큰 사이를 섞는다면, 이 층은 각 토큰 안의 특징을 바꿉니다.

원 논문은 각 하위층의 잔차 합 뒤에 정규화하는 Post-LN 구성 x←LN(x+Sublayer(x))를 썼습니다. 이후 많은 모델은 하위층 입력을 먼저 정규화하는 Pre-LN 구성 x←x+Sublayer(LN(x))를 씁니다. Pre-LN은 잔차 경로에 정규화가 끼지 않아 깊게 쌓아도 학습이 안정적인 편입니다. PyTorch nn.TransformerEncoderLayer는 기본이 Post-LN(norm_first=False)입니다.

from math import cos, sin
import torch
from torch.nn.functional import layer_norm

for position in (0, 1, 2):
    features = (sin(position), cos(position),
                sin(position/100), cos(position/100))
    print("위치", position, *(f"{value:.4f}" for value in features))

x = torch.tensor([1.0, 3.0])
change = torch.tensor([0.5, -0.5])
combined = x + change
normalized = layer_norm(combined, (2,))
print("잔차 합:", combined.tolist())
print("정규화:", *(f"{value:.4f}" for value in normalized.tolist()))

위치 2 0.9093 -0.4161 0.0200 0.9998
잔차 합: [1.5, 2.5]

위치 정보나 잔차 덧셈을 넣을 때는 더하는 두 배열의 차원이 맞는지 확인합니다. 여러 토큰과 여러 문장을 한꺼번에 처리할 때는 어느 축이 위치인지 정규화나 마스크가 어느 축에 적용되는지도 확인합니다.

한 줄 정리

위치가 입력의 순서를 알려 주고, attention과 피드포워드가 표현을 바꾸며, 잔차와 정규화가 그 블록을 연결합니다.
