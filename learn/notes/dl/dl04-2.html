DL04·2

Dropout과 가중치 패널티로 과적합 다루기

일부 활성값을 잠시 가리는 방법과 손실에 가중치의 크기를 더하는 방법을 계산합니다. 훈련과 평가에서 무엇이 바뀌는지 확인합니다.

이 장을 읽고 나면

  • dropout 확률과 유지된 활성값의 배율을 계산한다.
  • 훈련 모드와 평가 모드의 출력 차이를 확인한다.
  • 손실의 패널티와 검증 손실을 분리해 기록한다.

일부 활성값의 통과를 훈련 중에 무작위로 정한다

Dropout은 훈련할 때 활성값의 일부를 확률 p로 0으로 바꿉니다. 이 장의 nn.Dropout은 원소 단위입니다. 0≤p<1이고 활성값이 그대로 지나갈 때는 1/(1−p)배 합니다. 예를 들어 p=0.5, 활성 [1,2,3,4]에 샘플 마스크 [1,0,1,0]가 나왔다면 [2,0,6,0]입니다. 입력이 고정되어 있을 때 두 경우의 확률을 평균하면 각 활성의 기대값은 원래 값과 같습니다.

확률 0.5는 항상 절반이 지워진다는 의미가 아닙니다. 같은 입력으로도 여러 순전파에서 다른 마스크가 나옵니다. 일부 표현에 지나치게 의존하지 않게 하는 정규화(regularization) 방법 가운데 하나입니다. 데이터와 모델에 따라 효과가 다를 수 있어 기준 모델과 검증 결과를 비교합니다.

목적함수에서 가중치가 커질 때 치르는 값을 정한다

다른 방법으로 훈련 목적을 데이터 손실 + λ·Σwᵢ²로 정할 수 있습니다. 이 L2 패널티에서 w=(3,4)라면 제곱합은 25이고 λ=0.1을 곱하면 2.5가 추가됩니다. 이 글은 ½을 넣지 않는 정의를 택했습니다. 따라서 데이터 손실과 별도로 w에 더하는 기울기는 2λw입니다.

훗날 옵티마이저에서 weight_decay 인자를 쓰게 되면 논문의 λ와 같은 수치·규칙인지 확인합니다. 예를 들어 업데이트에서 따로 가중치를 줄이는 AdamW의 규칙은 손실에 L2를 더하는 방법과 일반적으로 다릅니다. 검증에서 비교할 때는 데이터 손실과 패널티를 따로 기록해 어떤 값이 줄었는지 알 수 있게 합니다.

평가할 때 모듈을 평가 상태로 바꾼다

PyTorch에서 model.train()과 model.eval()은 등록된 하위 모듈의 훈련 상태도 바꿉니다. nn.Dropout은 평가에서 입력을 그대로 통과시킵니다. 이 상태 전환과 torch.no_grad()는 역할이 다릅니다. 기울기 계산만 껐다고 dropout의 가림이 멈추지는 않습니다.

import torch
from torch import nn

torch.set_num_threads(1)
torch.manual_seed(29)
x = torch.ones(8)
drop = nn.Dropout(p=0.5)
drop.train()
with torch.no_grad():
    sampled = torch.stack([drop(x) for _ in range(16)])
drop.eval()
with torch.no_grad():
    evaluated = drop(x)
print("training values:", torch.unique(sampled).tolist())
print("eval equals input:", torch.equal(evaluated, x))

w = torch.tensor([3.0, 4.0], requires_grad=True)
penalty = 0.1 * w.square().sum()
penalty.backward()
print("penalty:", f"{penalty.item():.1f}")
print("penalty gradient:", [round(v, 1) for v in w.grad.tolist()])
training values: [0.0, 2.0]
eval equals input: True
penalty: 2.5
penalty gradient: [0.6, 0.8]

실행 환경은 Python 3.14.6과 PyTorch 2.14.1+cu130의 CPU입니다. 난수 시드는 29입니다. 같은 시드를 써도 PyTorch 버전이나 장치가 바뀌면 난수열과 세부 결과가 달라질 수 있습니다.

예제는 평가에 들어가기 전에 eval()을 호출합니다. 평가 후 같은 모형으로 학습을 계속할 때는 train()으로 돌립니다. 함수형 torch.nn.functional.dropout을 직접 쓰면 모듈의 상태에 따라 동작하도록 training=self.training을 명시하는 패턴을 확인합니다.
