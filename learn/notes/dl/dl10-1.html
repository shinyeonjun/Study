사전학습 표현을 고정하고 새 출력층 학습하기

기존 모델이 입력을 읽고 만든 표현을 새 작업에 씁니다. 표현을 고정한 채 출력층만 바꾸는 방법과 전체를 미세조정하는 방법을 구분합니다.

이 장을 읽고 나면

  • 사전학습·출력층 적합·미세조정을 구분한다.
  • 고정한 인코더와 업데이트하는 헤드의 역할을 계산한다.
  • 전이 방식의 공정한 비교 조건을 설명한다.

새 문제에서 가져오는 것은 무엇인가

앞선 문제에서 학습한 인코더가 데이터를 벡터로 바꾼다고 합시다. 새 문제의 목표는 이전과 다를 수 있어서 새 출력층을 연결합니다. 헤드는 인코더의 표현에서 새 목표값을 내는 부분입니다. 인코더를 고정하고 출력층만 학습하거나, 인코더 일부나 전부를 함께 갱신하는 미세조정을 할 수 있습니다.

정해 놓은 인코더에서 수치 검산

이 장에서는 가중치를 정해 인코더를 흉내 냅니다. 실제 사전학습을 돌리지는 않습니다. 입력 [1,0], [0,2]에 첫 특징을 두 배로 하는 인코더를 적용하면 표현은 [2,0], [0,2]입니다. 목표는 각각 1, 2입니다. 두 계수 모두 0인 헤드는 둘 다 0으로 예측하고 MSE는 (1²+2²)/2=2.5입니다.

첫 헤드 기울기는 −2, 둘째는 −4입니다. 학습률 0.1에서 한 번 움직이면 헤드 가중치는 [0.2,0.4]입니다. 새 훈련 예측은 [0.4,0.8]로 바뀌며 MSE는 (0.6²+1.2²)/2=0.9입니다.

import torch
from torch import nn

encoder = nn.Linear(2, 2, bias=False)
head = nn.Linear(2, 1, bias=False)
with torch.no_grad():
    encoder.weight.copy_(torch.diag(torch.tensor([2., 1.])))
    head.weight.zero_()
encoder.requires_grad_(False)
encoder.eval()

inputs = torch.tensor([[1., 0.], [0., 2.]])
target = torch.tensor([[1.], [2.]])
original = encoder.weight.detach().clone()
optimizer = torch.optim.SGD(head.parameters(), lr=0.1)
features = encoder(inputs)
loss = (head(features) - target).square().mean()

optimizer.zero_grad()
loss.backward()
optimizer.step()

with torch.no_grad():
    final_loss = (head(features) - target).square().mean()
print("이전 MSE:", f"{loss.item():.1f}")
print("새 헤드:", *(f"{w:.1f}" for w in head.weight[0].tolist()))
print("이후 MSE:", f"{final_loss.item():.1f}")
print("인코더 동일:", torch.equal(original, encoder.weight))

실행 결과

이전 MSE: 2.5
새 헤드: 0.2 0.4
이후 MSE: 0.9
인코더 동일: True

성능을 비교할 때 자료와 학습 예산을 적는다

표현을 고정했다는 말에는 계수의 기울기와 모델의 실행 모드가 함께 등장할 수 있습니다. 예로 BatchNorm에 누적하는 값이 바뀌지 않게 하려면 인코더의 평가 모드도 확인합니다. 계수를 고정하는 설정과 drop-out이나 누적치에 영향을 주는 모드는 별개입니다.

훈련 손실이 낮아진 한 번의 결과는 새 자료에서의 개선을 말해 주지 않습니다. 사전학습 모델, 새 작업의 분할, 갱신할 계수, 시드와 예산이 어떤 조건인지 적습니다. 인코더를 가져오지 않은 모델도 같은 새 과제에서 기준으로 비교할 수 있습니다.
