작은 자기회귀 언어모델을 학습하고 처음 보는 조합 평가하기

‘we are’ 다음 단어를 맞히려면 지금 이후의 정답을 미리 보지 않아야 합니다. 작은 문장 표, 가림 행렬, 손실의 분모를 한 번씩 확인하고 실제 CPU에서 모델을 학습합니다.

이 장을 읽고 나면

  • 토큰화, 입력과 목표의 한 칸 이동, 패딩을 손으로 적는다.
  • 어텐션의 차원과 미래 토큰 차단을 검증한다.
  • 훈련과 보류의 토큰 손실 및 생성 실패를 보고한다.

단어와 시작·끝 표지를 토큰 번호로 정한다

공백으로 나눈 단어와 시작 <bos>, 끝 <eos>, 겹치는 길이를 맞출 <pad>를 사용합니다. 어휘는 훈련 문장에 실제 나온 단어로만 고릅니다. 검증과 시험 문장에는 배운 단어를 쓰지만, 문장 전체 조합은 서로 다릅니다. 모델에게 처음부터 그 조합을 알려 주지 않았을 때 어떤 오차가 나는지 보려는 합성 실험입니다.

문장입력 다섯 칸다음 정답 다섯 칸
i am redBOS, i, am, red, EOSi, am, red, EOS, PAD
i amBOS, i, am, EOS, PADi, am, EOS, PAD, PAD

현재 칸에서 다음 칸을 예측합니다. 교사 강제 학습에서는 입력에 실제 앞 토큰이 들어갑니다. 스스로 생성할 때는 방금 고른 토큰을 다시 입력에 붙이며 다음을 고릅니다. 이 차이 때문에 한 번 틀린 생성 뒤에는 훈련 때 보지 않은 입력이 올 수 있습니다.

미래 위치와 패딩 key를 별도로 가린다

배치 크기 B, 길이 T, 폭 D일 때 Q,K,V는 [B,T,D]입니다. QKᵀ/√D의 [B,T,T]에서 한 query 행이 key 열들에 가중치를 줍니다. 오른쪽 미래 key가 softmax에 들어가면 현재 정답을 미리 볼 수 있습니다. masked_fill에서 미래 또는 PAD key의 위치를 참으로 만들어 점수를 −∞로 바꾸어 그 확률을 0으로 둡니다. 이 코드에서 BOS가 첫 칸에 있어 모든 key가 가려지는 query는 없습니다.

예제에서는 뒤의 빨강·파랑 토큰만 다른 두 문장을 입력해, 앞 세 query의 모든 후보 점수가 가까운지 직접 검사합니다. PAD query가 만든 결과는 목표가 PAD인 위치를 손실에서 제외해 사용하지 않습니다.

다음 토큰 손실을 실제 정답 수로 나눈다

모델의 logits는 어휘 각 토큰의 정규화 전 점수입니다. 손실은 정답 위치의 −log 확률입니다. 유효 정답 확률이 1/2, 1/4이고 나머지 목표가 PAD라면 평균 NLL은 (log 2+log 4)/2입니다. perplexity는 이 토큰별 NLL의 지수라 √8입니다. 다른 모델과 비교할 때는 어휘와 토큰화, 정답 포함 기준을 맞춰야 합니다.

훈련 단계 수를 고정한 뒤 처음으로 시험 값을 읽는다

훈련 9문장과 검증·시험 각각 3문장을 미리 나눕니다. 시드 7, 폭 16, 한 개의 causal attention과 잔차, AdamW로 120회 고정 전 배치 갱신합니다. 처음에는 훈련과 검증만 재고, 고정 단계가 끝난 뒤 시험을 평가합니다. Python 3.14.6과 PyTorch 2.14.0의 CPU 연산으로 확인한 실행입니다.

시험에서는 수식어 위치의 NLL이 8.0356으로 커서 전체 손실의 대부분을 차지합니다. ‘i am’과 ‘you are’로 시작해 가장 큰 확률의 토큰을 하나씩 고르면 학습 중 본 red, blue가 나오고, ‘we are’에서는 바로 끝을 냅니다. 구체적으로 어떤 새로운 조합에서 틀렸는지 다루는 예입니다. 실제 언어 모델의 일반 성능을 예측하려면 다른 어휘·자료와 독립 평가가 필요합니다.

import torch
from torch import nn
from torch.nn import functional as F

torch.manual_seed(7)
torch.set_num_threads(1)
torch.use_deterministic_algorithms(True)
torch.set_default_device("cpu")

train = ["i am red", "i am warm", "i am", "you are blue", "you are calm", "you are",
         "we are red", "we are calm", "we are"]
valid = ["i am blue", "you are red", "we are warm"]
test = ["i am calm", "you are warm", "we are blue"]
tokens = ["<pad>", "<bos>", "<eos>"] + sorted({w for s in train for w in s.split()})
to_id = {w:i for i,w in enumerate(tokens)}
PAD, BOS, EOS = (to_id[w] for w in ("<pad>", "<bos>", "<eos>"))
CONTEXT, WIDTH = 5, 16

def batch(sentences):
    rows = []
    for sentence in sentences:
        ids = [BOS] + [to_id[w] for w in sentence.split()] + [EOS]
        assert len(ids) <= CONTEXT+1
        rows.append(ids + [PAD]*(CONTEXT+1-len(ids)))
    z = torch.tensor(rows, dtype=torch.long)
    return z[:, :-1], z[:, 1:]

class LanguageModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.embed = nn.Embedding(len(tokens), WIDTH)
        self.pos = nn.Embedding(CONTEXT, WIDTH)
        self.qkv = nn.Linear(WIDTH, 3*WIDTH, bias=False)
        self.head = nn.Linear(WIDTH, len(tokens))

    def forward(self, x):
        _, t = x.shape
        h = self.embed(x) + self.pos(torch.arange(t))
        q,k,v = self.qkv(h).chunk(3, dim=-1)
        scores = (q @ k.transpose(-2,-1)) / WIDTH**.5
        future = torch.ones(t,t,dtype=torch.bool).triu(diagonal=1)
        key_pad = x.eq(PAD).unsqueeze(1)
        attention = scores.masked_fill(future | key_pad, -torch.inf).softmax(dim=-1)
        return self.head(h + attention @ v)

def nll(model, data):
    x,y = batch(data)
    logits = model(x)
    return F.cross_entropy(logits.flatten(0,1),y.reshape(-1),
                           ignore_index=PAD, reduction="sum") / y.ne(PAD).sum()

m = LanguageModel()
opt = torch.optim.AdamW(m.parameters(), lr=.01, weight_decay=.01)
def print_scores(label, include_test=False):
    m.eval()
    with torch.no_grad():
        splits = (train,valid,test) if include_test else (train,valid)
        losses = [nll(m, split).item() for split in splits]
        print(label,*[f"{loss:.4f}" for loss in losses])
        if include_test:
            print("test_ppl", f"{torch.exp(torch.tensor(losses[-1])).item():.3f}")

assert not set(train)&set(valid) and not set(train)&set(test) and not set(valid)&set(test)
print("vocab", tokens)
print("target_tokens", *(batch(split)[1].ne(PAD).sum().item() for split in (train,valid,test)))
print("logit_shape",tuple(m(batch(train)[0]).shape))
print_scores("initial_train_valid")
m.train()
for _ in range(120):          # Fixed without looking at test metrics.
    opt.zero_grad(set_to_none=True)
    loss = nll(m,train)
    loss.backward()
    opt.step()
print_scores("fixed_final", include_test=True)
with torch.no_grad():
    x,y = batch(test)
    losses = F.cross_entropy(m(x).transpose(1,2), y, ignore_index=PAD, reduction="none")
    print("test_by_target_role", *(f"{v:.4f}" for v in losses[:,:4].mean(dim=0)))
    xa = torch.tensor([[BOS,to_id["we"],to_id["are"],to_id["red"],EOS],
                       [BOS,to_id["we"],to_id["are"],to_id["blue"],EOS]])
    a,b = m(xa)
    assert torch.allclose(a[:3],b[:3],atol=1e-6)
    print("identical_prefix",torch.allclose(a[:3],b[:3],atol=1e-6))
    # PAD and BOS are independently disallowed in decoding, not in loss.
    for subject, verb in (("i","am"),("you","are"),("we","are")):
        generated = [BOS,to_id[subject],to_id[verb]]
        while len(generated) < CONTEXT+1:
            logits = m(torch.tensor([generated]))[0,-1].clone()
            logits[[PAD,BOS]] = -torch.inf
            generated.append(logits.argmax().item())
            if generated[-1] == EOS:
                break
        print("generated"," ".join(tokens[i] for i in generated))
