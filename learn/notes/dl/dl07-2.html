딥러닝 · DL07 표현과 attention

DL07·2

Q와 K로 점수를 정하고 V를 가중합하기

질문 두 줄로 키 세 줄을 비교합니다. 같은 값 벡터를 보고도 각 질문이 다른 비율로 가중합하는 것을 계산합니다.

이 장을 읽고 나면

  • Q·K·V가 어떤 행과 특성 축을 갖는지 읽는다.
  • QKᵀ의 행을 softmax로 바꾼다.
  • 각 행의 가중치로 V를 섞어 결과 모양을 계산한다.

질문 한 줄이 각 열의 키와 대응한다

Attention은 입력마다 어떤 정보를 얼마만큼 모을지 가중치로 정하는 계산입니다. 쿼리 Q의 한 행은 찾고 싶은 정보의 표현, 키 K의 한 행은 그 항목을 찾기 위한 표현입니다. 값 V의 같은 행이 실제로 전달할 정보입니다. 쿼리와 키는 내적하기 위해 특성 길이 d가 같아야 합니다. 키 수와 값 행 수가 같아야 하지만, 값의 특성 길이 dᵥ는 d와 다를 수 있습니다.

예제에서 쿼리 두 행은 [√2 ln 2,0]과 [0,√2 ln 2]입니다. K에는 [1,0], [0,1], [0,0]을 둡니다. 첫 쿼리의 키별 내적은 [√2 ln 2,0,0]입니다. 이를 √d=√2로 나누어 [ln 2,0,0]을 얻습니다. 둘째 행은 [0,ln 2,0]입니다. 왜 √d로 나눌까요? q와 k의 성분이 서로 독립이고 각각 평균 0, 분산 1이라고 가정하면 q·k=Σqᵢkᵢ는 분산 1인 항 d개의 합이라 평균 0, 분산 d입니다. d=64면 점수의 표준편차가 8이 되어 softmax가 한 칸에 거의 1을 몰아 주는 포화 상태가 되기 쉽고, 그러면 softmax의 기울기가 0에 가까워져 학습이 느려집니다. √d로 나누면 이 가정에서 분산이 다시 1이 됩니다. 실제 학습 중의 성분이 이 가정을 정확히 따르는 것은 아니므로 "규모를 맞추는 관례"로 이해합니다.

정의 · 스케일드 점곱 어텐션 (Vaswani 외 2017)

Attention(Q, K, V) = softmax(QKᵀ / √dk) V
Q는 (L, dk), K는 (S, dk), V는 (S, dv) 행렬이고 softmax는 각 행(키 축)마다 적용합니다. L은 쿼리 수, S는 키·값 수, dk는 쿼리·키의 특성 길이입니다. 이 장의 d는 dk입니다.

질문 하나마다 키 전체에 걸쳐 합이 1이 되게 한다

행마다 softmax를 적용합니다. 첫 행에서는 exp(ln 2)=2, exp(0)=1, exp(0)=1이라 합이 4입니다. 각 값을 4로 나눠 [0.5,0.25,0.25]입니다. 두 번째 행은 [0.25,0.5,0.25]입니다. 모양을 (질문,키)로 정했다면 마지막 키 축에 softmax를 적용합니다. 여러 질문을 하나의 합으로 정규화하지 않습니다.

첫 질문의 결과는 0.5[2,0]+0.25[0,4]+0.25[2,4]=[1.5,2]입니다. 둘째 결과는 [1,3]입니다. 출력 행 수는 쿼리 수, 각 행의 길이는 값 벡터의 길이입니다. PyTorch 코드에서는 마지막 축을 dim=-1로 적습니다.

행렬 곱마다 무엇이 남는지 확인한다

Q=(L,d), K=(S,d), V=(S,dᵥ)입니다. Q @ Kᵀ의 모양은 (L,S), softmax 결과도 (L,S)입니다. 여기에 V를 곱하면 S가 사라지고 (L,dᵥ)가 됩니다. 자기 어텐션(self-attention)에서는 같은 토큰 표현 X(L×dmodel)에 서로 다른 학습 행렬을 곱해 Q=XWQ, K=XWK, V=XWV를 만듭니다. 같은 X에서 나왔어도 세 행렬이 달라 역할이 나뉩니다. 다른 입력을 참조하는 교차 어텐션에서는 쿼리의 길이와 키·값의 길이가 다를 수 있습니다.

import math
import torch

torch.set_num_threads(1)
dtype = torch.float64
a = math.sqrt(2) * math.log(2)
q = torch.tensor([[a, 0], [0, a]], dtype=dtype)
k = torch.tensor([[1, 0], [0, 1], [0, 0]], dtype=dtype)
v = torch.tensor([[2, 0], [0, 4], [2, 4]], dtype=dtype)
scores = q @ k.T / math.sqrt(q.shape[-1])
weights = scores.softmax(dim=-1)
out = weights @ v

def shown(matrix):
    return [[round(x, 6) for x in row] for row in matrix.tolist()]

print("shapes:", tuple(scores.shape), tuple(out.shape))
print("scores:", shown(scores))
print("weights:", shown(weights))
print("output:", shown(out))
assert torch.allclose(weights.sum(dim=-1), torch.ones(2, dtype=dtype))
shapes: (2, 3) (2, 2)
scores: [[0.693147, 0.0, 0.0], [0.0, 0.693147, 0.0]]
weights: [[0.5, 0.25, 0.25], [0.25, 0.5, 0.25]]
output: [[1.5, 2.0], [1.0, 3.0]]

실행 환경은 Python 3.14.6과 PyTorch 2.14.0+cu130의 CPU입니다. 입력과 계산에 쓰는 값을 직접 정했습니다.

토큰 순서를 따로 넣지 않은 내적만으로는 각 항목이 몇 번째였는지 알 수 없습니다. 시퀀스 모델은 위치를 담는 별도 표현이나 어떤 위치를 볼 수 있는지 제한하는 규칙을 사용합니다. 다음 장에서는 미래와 패딩을 가리는 마스크를 직접 계산합니다.
