GAN에서 생성 분포와 판별기의 목표 분리하기

생성 모형이 두 결과 중 하나를 만들고, 판별기는 그 결과의 출처를 맞힙니다. 두 분포를 알고 있는 아주 작은 예에서 판별기와 생성기의 역할을 계산합니다.

이 장을 읽고 나면

  • 생성기와 판별기가 최적화하는 방향을 구분한다.
  • 두 결과에서 최적 판별기의 값을 계산한다.
  • 일부 결과만 반복하는 모드 붕괴를 해석한다.

같은 두 결과가 서로 다른 비율로 나온다

데이터와 생성기가 A 또는 B를 냅니다. 관측 자료에서 A 비율은 0.75, B 비율은 0.25입니다. 현재 생성기에서는 반대로 A 0.25, B 0.75입니다. 생성기는 난수에서 예를 만들고 판별기 D는 입력이 자료에서 왔을지 점수로 냅니다. D(A)=0.75라면 A의 점수가 자료 쪽으로 높다는 뜻입니다.

두 분포를 고정하고 판별기만 최적화한다

원래 GAN의 목적을 간단히 쓰면 V=자료에서의 평균 ln D + 생성 예에서의 평균 ln(1−D)입니다. 판별기는 V를 크게 하고 생성기는 원래 최소·최대 게임에서 V를 작게 합니다. 이 장에서는 먼저 생성기를 고정합니다.

A에 대해 D(A)=d라고 놓으면 V의 A 항은 0.75 ln d+0.25 ln(1−d)입니다. 미분해 0을 놓으면 0.75/d=0.25/(1−d)여서 d=0.75입니다. 일반적으로 두 확률의 합이 양수인 결과 x에서 최적 값은 D*(x)=p자료(x)/(p자료(x)+p생성(x))입니다. B에서는 0.25입니다.

결과자료의 확률생성기의 확률최적 D
A0.750.250.75
B0.250.750.25
from math import log

real = (0.75, 0.25)
fake = (0.25, 0.75)
optimal = [p/(p+q) for p, q in zip(real, fake)]

def objective(scores):
    return sum(p*log(d) + q*log(1-d)
               for p, q, d in zip(real, fake, scores))

print("판별기:", optimal)
print("D=0.5일 때:", f"{objective([0.5, 0.5]):.6f}")
print("최적 판별기에서:", f"{objective(optimal):.6f}")

실행 결과

판별기: [0.75, 0.25]
D=0.5일 때: -1.386294
최적 판별기에서: -1.124670

좋은 판별기가 나왔다고 생성이 잘된 것은 아니다

상대적으로 뚜렷한 차이가 있으면 판별 점수가 자료와 생성 예를 더 잘 구분합니다. 반대로 두 분포가 같으면 위 계산의 D*는 등장하는 모든 결과에서 0.5입니다. 실제 학습에서는 생성기 업데이트에 다른 형태의 손실을 택하기도 합니다. 원 논문은 초기에 기울기가 약해지는 것을 피하기 위한 손실 변형도 제안합니다.

생성기가 A만 계속 내면 A 자료와 비슷하게 보이는 예를 만들 수도 있지만, B가 전혀 없는 분포는 원래 자료와 다릅니다. 여러 종류가 있어야 할 자료에서 소수 결과만 반복하는 현상을 모드 붕괴라 합니다. 그럴듯한 사례 하나에 더해 전체 생성 예의 다양성도 확인합니다.

한 줄 정리

판별기는 출처를 구분하고 생성기는 그 차이를 줄이는 방향으로 업데이트합니다. 분포 전체가 닮는지를 따로 확인합니다.
