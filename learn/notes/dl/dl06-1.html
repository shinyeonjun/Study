DL06·1

순환 상태로 입력 순서를 읽고 시간을 거슬러 미분하기

같은 숫자라도 순서를 바꾸면 마지막 상태가 달라집니다. 시간 단계로 펼쳐 마지막 값에서 첫 입력까지의 미분을 계산합니다.

이 장을 읽고 나면

  • 현재 입력과 바로 전 상태로 다음 상태를 계산한다.
  • 시간 단계마다 같은 가중치를 사용하는 이유를 설명한다.
  • 시간을 따라 역전파한 입력·공유 가중치의 기울기를 확인한다.

한 번 읽을 때 바로 전의 상태를 입력으로 더 받는다

센서값 2,4,6이 순서대로 들어옵니다. 매 시점에 입력 xₜ와 이전 상태 hₜ₋₁을 받아 새 상태 hₜ를 만드는 모형을 순환 신경망(RNN)이라고 합니다. 가장 작은 그림에서는 h₀=0, hₜ=xₜ+0.5hₜ₋₁로 둡니다. 새 숫자에 앞 요약의 절반을 더합니다. 정해 둔 이 규칙에서는 h₁=2, h₂=5, h₃=8.5입니다. 입력만 [6,4,2]로 바꾸면 6,7,5.5입니다.

일반적인 RNN에는 입력을 곱하는 행렬, 이전 상태를 곱하는 행렬, 편향과 비선형 활성함수가 있습니다. 같은 매개변수를 매 시점에 씁니다.

정의 · 기본 RNN(Elman RNN)

hₜ = φ(Wihxₜ + bih + Whhhₜ₋₁ + bhh), h₀는 보통 0벡터.
xₜ는 길이 F인 입력, hₜ는 길이 H인 숨은 상태(hidden state)입니다. Wih는 H×F, Whh는 H×H 행렬이고, 이 네 매개변수는 모든 시점 t에서 같습니다. φ는 활성함수로, PyTorch nn.RNN의 기본값은 tanh이고 nonlinearity="relu"로 바꿀 수 있습니다.

위의 hₜ=xₜ+0.5hₜ₋₁은 F=H=1, Wih=1, Whh=0.5, 편향 0, φ가 항등함수인 특수한 경우입니다. 이 장의 nn.RNN 예제는 활성함수 ReLU를 선택합니다. 두 양수 입력 순서에서 활성화 앞 수가 모두 양수라 ReLU가 값을 그대로 넘기고 단순 식과 일치합니다.

시간 방향을 따라 계산 그래프를 펼친다

h₃= x₃+0.5x₂+0.25x₁이므로 h₃에 대한 입력별 기울기는 [0.25,0.5,1]입니다. h₃에서 h₂로, 다시 h₁로 돌아갈 때마다 0.5를 곱하는 연쇄법칙과 같습니다. 이렇게 반복 계산을 시간 순서대로 펼쳐 기울기를 뒤로 보내는 것을 시간을 통한 역전파(BPTT)라고 합니다.

공유 가중치 r도 모든 시점의 경로에서 영향을 받습니다. h₀=0일 때 마지막 값을 x₃+r·x₂+r²·x₁로 쓰면, r에 대한 미분은 x₂+2r·x₁=4+2×0.5×2=6입니다. 각 시점에 다른 r을 만들어 따로 미분하는 것과는 다릅니다. 여러 시점에서 손실을 더했다면 각 손실의 기울기 항도 더해집니다.

배치·시간·특성 축을 모양으로 확인한다

모듈에 batch_first=True를 쓰면 한 층 단방향 RNN의 입력은 (B,T,F), 시점별 출력은 (B,T,H)입니다. B는 배치, T는 시간 단계, F는 입력 특성, H는 숨은 상태의 크기입니다. 마지막 상태 h_n은 batch_first와 관계없이 (층 수×방향 수,B,H)입니다. 예제는 (1,3,1) 입력과 모양 (1,1,1)의 마지막 상태 hₙ을 씁니다.

import torch
from torch import nn

torch.set_num_threads(1)
torch.manual_seed(37)
rnn = nn.RNN(1, 1, nonlinearity="relu", batch_first=True, bias=False)
with torch.no_grad():
    rnn.weight_ih_l0.fill_(1)
    rnn.weight_hh_l0.fill_(0.5)

seq = torch.tensor([[[2.0], [4.0], [6.0]]], requires_grad=True)
out, final = rnn(seq)
with torch.no_grad():
    rev, _ = rnn(seq.flip(dims=(1,)))
print("sequence:", out.flatten().tolist())
print("reverse:", rev.flatten().tolist())
print("shapes:", tuple(out.shape), tuple(final.shape))
out[0, -1, 0].backward()
print("input grad:", seq.grad.flatten().tolist())
print("recurrent grad:", rnn.weight_hh_l0.grad.item())
sequence: [2.0, 5.0, 8.5]
reverse: [6.0, 7.0, 5.5]
shapes: (1, 3, 1) (1, 1, 1)
input grad: [0.25, 0.5, 1.0]
recurrent grad: 6.0

실행 환경은 Python 3.14.6과 PyTorch 2.14.0+cu130의 CPU입니다. 난수 시드는 37입니다. 같은 시드를 써도 PyTorch 버전이나 장치가 바뀌면 난수열과 세부 결과가 달라질 수 있습니다.

긴 순서에서는 ∂hₜ/∂hₜ₋₁ 꼴의 미분이 시점 수만큼 곱해집니다. 이 곱의 크기가 1보다 작으면 오래 전 입력의 기울기가 0에 가까워지는 기울기 소실(vanishing gradient), 1보다 크면 커져 터지는 기울기 폭발(exploding gradient)이 생깁니다. 위 예에서 계수 0.5가 T번 곱해지면 0.5ᵀ이 되는 것과 같은 모양입니다. 폭발은 기울기 크기를 잘라 내는 기울기 클리핑으로 흔히 막고, 소실은 다음 장의 LSTM·GRU 같은 구조로 줄입니다. 그래프를 나눠 중간 상태의 기울기 연결을 끊는 절단 BPTT는 비용을 제한합니다. 그 경우 상태 값은 다음 구간에 줄 수 있지만, 잘린 경계를 넘어가는 기울기는 계산하지 않습니다.
