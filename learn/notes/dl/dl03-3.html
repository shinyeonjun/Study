DL03·3

state_dict로 저장하고 같은 예측 되찾기

모델 상태의 텐서를 파일로 저장하고 같은 구조에 다시 채웁니다. 직접 만든 가중치 파일을 읽어 같은 입력과 예측으로 복원 결과를 검증합니다.

이 장을 읽고 나면

  • 모델의 state_dict에 들어가는 텐서와 다시 준비해야 하는 구조를 구분한다.
  • 로컬에서 만든 가중치 파일을 CPU에 안전하게 읽어 같은 구조에서 복원한다.
  • 같은 입력의 예측을 비교하고 추론 복원과 학습 재개의 필요한 정보를 구분한다.

다시 쓰려는 것은 이름과 모양이 있는 값들이다

nn.Sequential(nn.Linear(1,1))에 가중치 2, 편향 1을 넣으면 ŷ=2x+1입니다. state_dict는 모델의 파라미터와 지속적으로 저장하도록 등록한 버퍼를 이름으로 묶습니다. 이 예의 딕셔너리에는 첫 모듈의 0.weight와 0.bias가 있고 모양은 각각 (1,1)과 (1,)입니다.

가중치 파일에는 모듈을 사용한 순서와 입력 특성의 의미가 저절로 들어가지는 않습니다. 같은 예측을 재현하려면 실제 사용한 모델 구조와 사전 처리, 입력 특성의 순서를 같이 보관합니다. 아래 함수는 새 모델을 만들 때도 같은 Sequential(Linear(1,1))을 준비합니다.

직접 만든 가중치 파일을 읽어 복원한다

torch.save(model.state_dict(), path)로 필요한 텐서만 담은 파일을 만듭니다. 아래에서 경로는 코드가 생성한 임시 폴더입니다. 복원할 때 torch.load(path, map_location="cpu", weights_only=True)는 CPU에 읽으며 가중치용 제한된 방식으로 파일을 풉니다. 출처를 신뢰할 수 있는 파일만 선택합니다. weights_only=True는 읽을 수 있는 객체를 제한하지만 파일 전체의 안전을 보장하는 절차로 쓰이지 않습니다.

load_state_dict(..., strict=True)로 모델이 기대하는 키와 맞는지 확인하고, 텐서 모양도 일치해야 복원할 수 있습니다. 같은 키와 모양을 갖더라도 계산 동작이나 입력 처리 방식이 같아야 같은 예측을 기대할 수 있습니다. 복원 후에는 평가 모드를 지정하고, 비교할 예측은 no_grad()에서 만듭니다.

저장 전 출력과 같은 입력의 복원 후 출력을 비교한다

입력이 −1, 0, 2이면 ŷ=2x+1의 출력은 −1, 1, 5입니다. 프로그램에서는 같은 세 입력을 양쪽 모델에 넣어 실제 예측을 비교합니다.

추론용 복원에는 모델 상태와 동일한 계산 구조가 중요합니다. 중단한 학습부터 다시 시작하려면 옵티마이저가 가진 상태, 현재 에포크와 스케줄, 필요에 따라 난수 상태와 데이터 순서도 함께 보관합니다. 모델 상태만 복원한 뒤 이어 학습해도 이전 실행과 같은 학습 궤적을 보장하지는 않습니다.

임시 파일에 저장한 뒤 다시 만든 모델로 읽어 본다

from pathlib import Path
from tempfile import TemporaryDirectory

import torch
from torch import nn

torch.manual_seed(7)

def build_model():
    return nn.Sequential(nn.Linear(1, 1)).to(device="cpu", dtype=torch.float32)

model = build_model()
with torch.no_grad():
    model[0].weight.fill_(2)
    model[0].bias.fill_(1)
model.eval()
x = torch.tensor([[-1.], [0.], [2.]], dtype=torch.float32)
with torch.no_grad():
    before = model(x)

with TemporaryDirectory() as folder:
    path = Path(folder) / "model_weights.pt"
    torch.save(model.state_dict(), path)
    state = torch.load(path, map_location="cpu", weights_only=True)
    restored = build_model()
    restored.load_state_dict(state, strict=True)

restored.eval()
with torch.no_grad():
    after = restored(x)

print("keys and shapes:", [(name, tuple(value.shape)) for name, value in state.items()])
print("before:", before.flatten().tolist())
print("after:", after.flatten().tolist())
print("same:", torch.equal(before, after))
keys and shapes: [('0.weight', (1, 1)), ('0.bias', (1,))]
before: [-1.0, 1.0, 5.0]
after: [-1.0, 1.0, 5.0]
same: True

실행 확인 환경 · Python 3.14.6, PyTorch 2.14.1+cu130, CPU, 시드 7. 가중치와 편향은 2와 1로 직접 지정했고, 실행이 끝나면 임시 폴더가 정리됩니다.
