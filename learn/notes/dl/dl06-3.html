딥러닝 · DL06 순서와 기억

DL06·3

길이가 다른 순서를 한 배치에 넣고 패딩을 제외하기

길이 3과 길이 1을 같은 텐서로 만듭니다. 원래 마지막 시점, 무시할 손실 위치, 순환 계산을 생략하는 방법을 따로 확인합니다.

이 장을 읽고 나면

  • 길이 벡터에서 (B,T) 유효 위치 마스크를 만든다.
  • 패딩 뒤 상태와 원래 마지막 상태를 구분한다.
  • pack_padded_sequence와 손실 마스크의 역할을 나눈다.

배열의 길이와 관측한 길이를 둘 다 기록한다

[2,4,6]과 [5]를 한 배치에 넣기 위해 둘째 줄 뒤에 0 두 개를 붙입니다. 이런 칸이 패딩입니다. 배열의 두 줄은 모두 길이 3이지만 처음 자료의 길이는 [3,1]입니다. 실제 관측값도 0일 수 있으므로 값이 0인지로 패딩을 찾지 않고, 0부터 센 위치 t가 해당 길이보다 작은지 비교합니다.

예제는 오른쪽에 패딩합니다. 시점별 유효 마스크는 첫째 [참,참,참], 둘째 [참,거짓,거짓]입니다. 길이만 전달해서 원래 순서의 끝을 찾을 때는 각 샘플의 length−1 위치를 읽습니다. 이 예는 두 순서 모두 길이가 1 이상입니다.

0을 읽어도 이전 상태 때문에 값은 바뀔 수 있다

앞의 hₜ=xₜ+0.5hₜ₋₁ 규칙에서 둘째 줄의 유효한 끝 상태는 5입니다. 하지만 패딩을 그냥 순환 계산하면 0+0.5×5=2.5, 한 번 더 해 1.25가 됩니다. 배치의 마지막 열을 매번 읽으면 원래 순서 뒤의 불필요한 상태를 결과로 가져옵니다.

한 층 단방향이고 오른쪽 패딩인 예에서는 out[배치 위치, 길이−1]로 유효 출력을 고를 수 있습니다. pack_padded_sequence로 길이를 전달하면 RNN이 패딩 없이 유효 단계만 계산합니다. 양방향 순환이나 여러 층에서 마지막 숨은 상태의 의미를 해석할 때는 방향과 모듈 반환 모양을 따로 확인합니다.

손실에는 참인 위치만 넣는다

시점별 관측을 예측하고 각 오차의 평균을 낼 때, 패딩 칸을 분자와 분모에서 빼야 합니다. 여기서는 모든 참 위치의 목표를 0으로 둔 제곱오차를 예로 씁니다. 네 오차는 2²,5²,8.5²,5²이므로 평균은 126.25/4=31.5625입니다. pack으로 순환 계산을 건너뛰었어도 출력을 다시 일정 길이 배열로 펼치고 손실을 계산한다면 유효 위치 규칙은 필요합니다.

import torch
from torch import nn
from torch.nn.utils.rnn import pack_padded_sequence

torch.set_num_threads(1)
torch.manual_seed(43)
rnn = nn.RNN(1, 1, nonlinearity="relu", batch_first=True, bias=False)
lengths = torch.tensor([3, 1])
x = torch.tensor([[[2.0], [4.0], [6.0]], [[5.0], [0.0], [0.0]]])
with torch.no_grad():
    rnn.weight_ih_l0.fill_(1)
    rnn.weight_hh_l0.fill_(0.5)
    out, _ = rnn(x)
    packed = pack_padded_sequence(x, lengths, batch_first=True, enforce_sorted=False)
    _, packed_last = rnn(packed)

mask = torch.arange(x.shape[1])[None, :] < lengths[:, None]
last_valid = out[torch.arange(x.shape[0]), lengths - 1, 0]
masked_loss = out.squeeze(-1).square()[mask].mean()
assert torch.equal(last_valid, packed_last[0, :, 0])
print("mask:", mask.tolist())
print("last array column:", out[:, -1, 0].tolist())
print("last valid and packed:", last_valid.tolist(), packed_last.flatten().tolist())
print("mean square:", masked_loss.item())
mask: [[True, True, True], [True, False, False]]
last array column: [8.5, 1.25]
last valid and packed: [8.5, 5.0] [8.5, 5.0]
mean square: 31.5625

실행 환경은 Python 3.14.6과 PyTorch 2.14.0+cu130의 CPU입니다. 난수 시드는 43입니다. 같은 시드를 써도 PyTorch 버전이나 장치가 바뀌면 난수열과 세부 결과가 달라질 수 있습니다.

pack_padded_sequence의 길이 텐서는 CPU에 둡니다. 이 함수는 양의 길이를 기대합니다. 길이가 0인 샘플을 허용하는 일에서는 제외할지, 별도의 빈 상태 값을 줄지 먼저 정합니다. 입력을 배치로 묶을 때 순서 내부가 정말 시간순인지와 샘플과 길이의 배치 순서가 일치하는지도 봅니다.
