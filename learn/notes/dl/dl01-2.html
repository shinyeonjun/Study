선형층과 활성함수로 작은 MLP 만들기

가중치를 곱하고 편향을 더한 뒤 활성함수를 적용합니다. 이 과정을 두 번 이어 입력 둘이 서로 다를 때만 1을 내는 네트워크를 직접 계산합니다.

이 장을 읽고 나면

  • 한 선형층의 가중치와 편향을 배치 모양에 맞춰 곱한다.
  • 활성함수로 왜 여러 직선 계산을 합칠 때 생기는 제약을 넘을 수 있는지 설명한다.
  • 고정 가중치를 사용해 XOR의 로짓과 분류 결과를 직접 계산한다.

선형층이 한 행에서 여러 값을 계산한다

관측의 두 특성을 (x₁,x₂)로 놓습니다. 가중치 w₁,w₂와 편향 b로 z=w₁x₁+w₂x₂+b를 계산합니다. 이런 계산을 출력마다 하나씩 가지면 선형층입니다. 편향을 포함하면 수학적으로는 아핀 변환이라고 합니다. PyTorch의 Linear(in_features, out_features)는 편향을 기본으로 둡니다.

가중치 W의 한 행은 출력 하나를 만드는 계수입니다. 입력 특성 F개, 출력 H개, 배치 B개라면 X는 (B,F), W는 (H,F), b는 (H,)입니다. 층의 결과는 Z=XWᵀ+b로, 모양은 (B,H)입니다. 마지막의 b는 각 관측 행에 적용됩니다.

활성함수로 입력 범위에 따라 계산을 달리한다

두 층이 모두 아핀 변환이면 합성도 아핀입니다. 첫 결과 W₁x+b₁에 W₂와 b₂를 적용하면, (W₂W₁)x+(W₂b₁+b₂)로 한 번에 정리할 수 있습니다. 층 사이에 활성함수를 넣으면 이런 단순 합성으로 줄지 않는 함수를 만들 수 있습니다.

ReLU는 max(0,z)입니다. z가 음수면 출력 0이고 양수면 입력이 그대로 나옵니다. z=0에서 두 부분이 만납니다. 예로 ReLU(−2)=0, ReLU(3)=3입니다.

여러 선형층과 활성함수를 합성한 구조를 다층 퍼셉트론(MLP)이라고 합니다. 시그모이드는 실수 로짓을 0과 1 사이로 바꿉니다. 출력이 이진 분류의 점수라면 로짓 0이 시그모이드 0.5에 대응합니다. 은닉층의 활성함수와 최종 출력의 해석은 문제에 맞춰 골라야 합니다.

입력 두 값이 서로 다를 때 1이 되는 네 점

이진 입력에서 두 값이 다르면 1, 같으면 0인 규칙을 XOR이라고 합니다. (0,0)과 (1,1)은 0이고 (0,1),(1,0)은 1입니다. 두 클래스의 점들을 각각 잇는 선분이 가운데에서 만나므로 직선 하나로 두 쌍을 엄격히 분리할 수 없습니다.

이 장의 네트워크는 먼저 s=x₁+x₂를 구합니다. 은닉층의 두 값은 h₁=ReLU(s), h₂=ReLU(s−1)입니다. 마지막 출력 z=h₁−2h₂−0.5를 계산합니다. z≥0이면 클래스 1로 정합니다.

(1,1)에서는 은닉값이 (2,1)이므로 로짓은 2−2×1−0.5=−0.5입니다. (0,1)과 (1,0)에서는 은닉값이 (1,0)으로 같아 둘 다 0.5입니다. 가중치는 이 규칙을 보여 주려고 우리가 직접 정한 값입니다.

가중치를 정한 뒤 네 입력을 한 번에 넣는다

import torch
from torch import nn

torch.manual_seed(7)
model = nn.Sequential(nn.Linear(2, 2), nn.ReLU(), nn.Linear(2, 1))
model = model.to(device="cpu", dtype=torch.float32)
with torch.no_grad():
    model[0].weight.copy_(torch.tensor([[1., 1.], [1., 1.]]))
    model[0].bias.copy_(torch.tensor([0., -1.]))
    model[2].weight.copy_(torch.tensor([[1., -2.]]))
    model[2].bias.fill_(-0.5)

x = torch.tensor([[0., 0.], [0., 1.], [1., 0.], [1., 1.]], dtype=torch.float32)
with torch.no_grad():
    hidden = model[1](model[0](x))
    logits = model(x)
    decision = (logits[:, 0] >= 0).to(torch.int64)
    assert torch.equal(decision, torch.tensor([0, 1, 1, 0]))
    positive_prob = torch.sigmoid(logits[:, 0])

print("hidden:", hidden.tolist())
print("logits:", logits[:, 0].tolist())
print("sigmoid:", " ".join(f"{p:.4f}" for p in positive_prob))
print("classes:", decision.tolist())

실행 확인 환경 · Python 3.14.6, PyTorch 2.14.1+cu130, CPU. 시드 7로 초기화하고 계산에 쓰는 가중치와 편향은 직접 넣었습니다.

Sequential은 적은 순서대로 모듈을 적용합니다. no_grad()로 직접 값을 복사하는 작업과 예측 계산을 미분 기록에서 제외했습니다. 다음 단원에서 이 기록이 실제로 어디에 쓰이는지 살펴봅니다.
