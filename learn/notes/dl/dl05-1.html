DL05·1

필터를 옮겨 합성곱의 출력 칸 계산하기

작은 영상과 2×2 필터를 겹쳐 네 출력을 계산합니다. 보폭과 테두리가 달라지면 어느 위치를 계산하는지도 추적합니다.

이 장을 읽고 나면

  • 영상의 작은 칸과 필터를 곱해서 더한다.
  • stride와 padding으로 출력 크기를 구한다.
  • Conv2d에서 실제로 필터를 적용하는 방향을 확인한다.

한 위치에서 대응하는 값들을 곱해 더한다

한 채널의 3×3 영상에 2×2 가중치 표를 겹칩니다. 영상의 좌상단 [[1,2],[0,1]]에 필터 [[1,0],[0,−1]]을 놓으면 1×1+2×0+0×0+1×(−1)=0입니다. 같은 필터를 한 칸 오른쪽으로 옮기면 2×1+0×0+1×0+3×(−1)=−1입니다. 위치마다 가중치를 새로 만들지 않고 필터 하나를 여러 위치에 공유합니다.

PyTorch의 Conv2d는 아래처럼 필터의 순서를 유지해 계산하는 교차 상관을 사용합니다. 수학에서 필터를 뒤집는 합성곱도 따로 정의합니다. 이 장의 CNN 계산은 PyTorch 규약에 따릅니다. 편향을 넣는 층이면 곱셈을 합한 뒤 같은 출력 채널의 편향을 모든 위치에 더합니다. 식으로 쓰면 K×K 필터 w, 보폭 S일 때 출력 칸 (i,j)는 y[i,j]=ΣmΣn x[S·i+m, S·j+n]·w[m,n]+b (m,n=0,…,K−1)입니다. 필터를 뒤집는 수학의 합성곱이라면 w[m,n] 자리에 w[K−1−m, K−1−n]이 들어갑니다.

영상 가장자리를 둘러싸고 시작 위치를 띄울 수 있다

Stride는 시작점의 이동 간격이고, padding은 바깥에 붙이는 칸입니다. 원래 영상에 0을 한 겹 둘러싸면 5×5가 됩니다. 보폭 2라면 시작 행과 열은 각각 0,2입니다. 다음 시작점 4에서는 2×2 필터가 온전히 들어오지 않습니다. 좌상단 출력은 0−1=−1이며, 네 위치의 출력은 [[−1,0],[−2,1]]입니다.

필터의 칸 사이에 간격을 두지 않는 dilation=1, 높이 H, 필터 높이 K, 양쪽 패딩 P, 보폭 S라면 출력 높이는 ⌊(H+2P−K)/S⌋+1입니다. 출력 너비도 너비 쪽 값으로 같은 계산을 합니다. 필터를 놓을 수 없을 만큼 입력이 작으면 정상 출력 크기가 나오지 않으므로 각 축에서 먼저 유효성을 확인합니다.

실제 Conv2d에서 가중치를 직접 넣어 검산한다

입력 모양은 (N,C,H,W)입니다. N=1은 영상 한 장, C=1은 입력 채널 하나입니다. 이 예는 필터 하나여서 가중치 모양이 (1,1,2,2)입니다. 모듈을 만든 뒤 가중치를 모두 덮어써 손계산과 같은 값을 씁니다. 같은 결과가 함수형 conv2d로도 나오는지 확인합니다.

import torch
from torch import nn
from torch.nn import functional as F

torch.set_num_threads(1)
torch.manual_seed(31)
image = torch.tensor([[[[1.0, 2.0, 0.0], [0.0, 1.0, 3.0], [2.0, 1.0, 0.0]]]])
weight = torch.tensor([[[[1.0, 0.0], [0.0, -1.0]]]])
for stride, padding in ((1, 0), (2, 1)):
    conv = nn.Conv2d(1, 1, 2, stride=stride, padding=padding, bias=False)
    with torch.no_grad():
        conv.weight.copy_(weight)
        out = conv(image)
        assert torch.equal(out, F.conv2d(image, weight, stride=stride, padding=padding))
    print(stride, padding, tuple(out.shape), out[0, 0].to(torch.int64).tolist())
1 0 (1, 1, 2, 2) [[0, -1], [-1, 1]]
2 1 (1, 1, 2, 2) [[-1, 0], [-2, 1]]

실행 환경은 Python 3.14.6과 PyTorch 2.14.0+cu130의 CPU입니다. 난수 시드는 31입니다. 같은 시드를 써도 PyTorch 버전이나 장치가 바뀌면 난수열과 세부 결과가 달라질 수 있습니다.

두 설정의 출력 크기는 같고 각 칸이 참조한 범위는 다릅니다. 층에서 관측한 모양뿐 아니라 어떤 입력 위치가 출력에 들어갔는지 확인합니다.
