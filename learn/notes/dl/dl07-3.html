DL07·3

어텐션의 마스크를 질문 행과 키 열에 맞추기

미래 위치와 패딩 키를 가립니다. 배치와 헤드의 축을 포함해 마스크가 어떻게 퍼지는지 확인하고 패딩 질문의 출력도 따로 처리합니다.

이 장을 읽고 나면

  • 점수의 배치·헤드·쿼리·키 축을 확인한다.
  • 패딩 키와 미래 위치를 가리는 조건을 합친다.
  • PyTorch 함수와 모듈에서 bool 마스크의 뜻을 구분한다.

점수 판에서 행은 질문, 열은 키다

입력은 배치 B=2, 헤드 H=2, 질문과 키의 길이 L=S=3인 자기 어텐션 예입니다. 여러 헤드는 같은 토큰 위치의 여러 표현을 병렬로 비교합니다. Q와 K의 마지막 특성 크기는 d=2, V의 마지막 크기는 dᵥ=1입니다. Q @ K.transpose(-2,-1)의 모양은 (B,H,L,S)입니다. 마지막 두 축은 한 질문이 어느 키를 보는지를 나타냅니다.

현재와 이전 위치를 쓰는 시퀀스 모형에서는 질문의 0부터 센 t에 대해 키 위치 s≤t이면 볼 수 있게 합니다. 미래를 차단하는 인과 마스크입니다. 첫 샘플의 유효 길이는 3, 둘째는 2라 둘째의 마지막 키 s=2는 모든 행에서 제외합니다. 질문과 키가 둘 다 같은 오른쪽 패딩 시퀀스일 때 두 조건을 동시에 쓰면 아래 그림이 됩니다.

1인 축으로 헤드마다 같은 마스크를 적용한다

인과 판의 모양은 (L,S), 키 유효 여부는 (B,S)입니다. 이를 각각 (1,1,L,S)와 (B,1,1,S)로 만들어 논리 AND를 하면 (B,1,L,S)입니다. 크기가 1인 헤드 축은 점수의 각 헤드로 브로드캐스트됩니다. 샘플별 키 유효 길이는 다르므로 이 예의 배치 축은 B를 유지합니다.

수동 계산에서는 제외할 점수를 softmax 전에 −∞로 바꿉니다. 제외한 키 열의 exp(−∞)는 0입니다. 유효 키가 하나 이상 있으면 제외한 열의 가중치는 0입니다. 모든 키가 막힌 행에서 직접 softmax를 계산하면 0으로 나누는 상태가 생길 수 있으므로, 유효한 키가 없는 샘플을 어떻게 다룰지 먼저 정합니다. 이 예는 모든 샘플에 유효한 첫 토큰이 있어 각 행에 적어도 하나의 키가 남습니다.

키를 제외해도 패딩 질문의 출력은 남을 수 있습니다. 둘째 샘플에서 t=2 행은 앞의 키 0과 1을 봅니다. 필요한 결과가 유효 질문만의 값이라면 (B,1,L,1) 마스크로 출력이나 해당 위치의 손실을 별도로 처리합니다.

호출하는 함수가 bool 마스크를 어떻게 해석하는지 확인한다

PyTorch의 함수 scaled_dot_product_attention에서 bool 마스크의 True는 옆 키를 사용한다는 뜻입니다. nn.MultiheadAttention의 bool key_padding_mask는 (B,S)이며 True가 그 키를 무시한다는 뜻입니다. 그 모듈의 bool attn_mask도 True가 금지입니다. 같은 이름의 마스크라도 호출 규약이 달라 그대로 넘기면 결과가 뒤집힐 수 있습니다.

import torch
from torch.nn import functional as F

torch.set_num_threads(1)
B, H, T, D = 2, 2, 3, 2
q = torch.zeros(B, H, T, D, dtype=torch.float64)
k = torch.zeros_like(q)
v = torch.tensor([[[[2.0], [4.0], [8.0]], [[10.0], [20.0], [30.0]]],
                  [[[3.0], [9.0], [99.0]], [[12.0], [18.0], [99.0]]]],
                 dtype=torch.float64)
lengths = torch.tensor([3, 2])
t = torch.arange(T)
valid = t[None, :] < lengths[:, None]
causal = t[:, None] >= t[None, :]
allowed = causal[None, None, :, :] & valid[:, None, None, :]

result = F.scaled_dot_product_attention(q, k, v, attn_mask=allowed, dropout_p=0.0)
reference = ((q @ k.transpose(-2, -1)) / D**0.5).masked_fill(~allowed, float("-inf"))
assert torch.allclose(result, reference.softmax(dim=-1) @ v)
kept = result.masked_fill(~valid[:, None, :, None], 0)
print("mask and output:", tuple(allowed.shape), tuple(result.shape))
print("allow second sample:", allowed[1, 0].int().tolist())
print("first sample, head 0:", [round(x, 6) for x in result[0, 0, :, 0].tolist()])
print("second sample, head 0:", result[1, 0, :, 0].tolist())
print("remove padded queries:", kept[1, 0, :, 0].tolist())
mask and output: (2, 1, 3, 3) (2, 2, 3, 1)
allow second sample: [[1, 0, 0], [1, 1, 0], [1, 1, 0]]
first sample, head 0: [2.0, 3.0, 4.666667]
second sample, head 0: [3.0, 6.0, 6.0]
remove padded queries: [3.0, 6.0, 0.0]

실행 환경은 Python 3.14.6과 PyTorch 2.14.1+cu130의 CPU입니다. 입력과 계산에 쓰는 값을 직접 정했습니다.

함수형 어텐션은 dropout_p로 받은 값에 따라 가림을 적용합니다. 평가에서는 0을 넘깁니다. 이 예에서는 인과 조건까지 직접 마스크에 결합했으므로 is_causal은 따로 켜지 않습니다.
