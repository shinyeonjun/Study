오토인코더에서 잠재값 하나로 두 값을 복원하기

입력을 작은 벡터로 줄였다가 다시 늘려 봅니다. 원래 값을 얼마나 잘 되돌리는지와 새로운 데이터를 어떻게 만들 수 있는지는 다른 질문입니다.

이 장을 읽고 나면

  • 인코더·잠재 공간·디코더를 구분한다.
  • 작은 선형 예제에서 복원과 손실을 계산한다.
  • 같은 잠재값으로 겹친 입력을 왜 되돌릴 수 없는지 설명한다.

기록을 줄이고 나중에 다시 펼친다

센서가 두 개 내놓은 값 (a,b)을 하나의 값으로 줄인다고 합시다. 인코더가 z=(a+b)/2로 줄이고 디코더가 (z,z)로 펼칩니다. z는 압축된 표현을 담은 잠재값입니다. 연습용 매개변수는 미리 정해 두었습니다. 실제 오토인코더는 두 변환의 매개변수를 복원 오차에 맞춰 학습합니다.

입력잠재 z복원특징당 평균제곱오차
(2,4)3(3,3)(1²+1²)/2=1
(3,3)3(3,3)0
(5,1)3(3,3)(2²+2²)/2=4

여러 원본이 같은 좌표에 모일 수 있다

세 기록 모두 잠재값 3이므로 디코더가 어떤 입력을 받았든 복원은 (3,3)입니다. 입력 (2,4)와 (5,1)을 알아보려면 평균 이외의 정보도 보존해야 합니다. 차원을 줄이면 모델이 무엇을 버려도 되는지 복원 손실과 데이터가 알려 줍니다. 잡음 제거처럼 일부 정보를 버리는 것이 목표인 문제도 있습니다.

import numpy as np

values = np.array([[2., 4.], [3., 3.], [5., 1.]])
encoded = values.mean(axis=1, keepdims=True)
restored = np.repeat(encoded, 2, axis=1)
loss_per_record = ((values-restored)**2).mean(axis=1)
assert encoded.shape == (3, 1) and restored.shape == values.shape
print("잠재값:", encoded.ravel().tolist())
print("복원:", restored.tolist())
print("행별 MSE:", loss_per_record.tolist())

실행 결과

잠재값: [3.0, 3.0, 3.0]
복원: [[3.0, 3.0], [3.0, 3.0], [3.0, 3.0]]
행별 MSE: [1.0, 0.0, 4.0]

복원을 넘어 새 값을 만들고 싶을 때

복원 모형에서는 실제 입력을 인코더로 보내 어떤 z를 사용할지 정합니다. 그 z 분포가 어떤 모양인지 따로 정의하지 않았다면 임의로 고른 z에서 나오는 입력의 의미를 예측하기 어렵습니다. 생성에 쓰려면 어떤 잠재값을 뽑을지와 그 값에서 어떤 관측을 내는지에 대한 모형을 추가할 수 있습니다. 다음 장은 잠재분포가 있는 변분 오토인코더를 살핍니다.

한 줄 정리

오토인코더는 잠재값으로 입력을 줄이고 복원합니다. 무엇을 잃었는지는 작은 원본과 복원의 차이에서 압니다.
