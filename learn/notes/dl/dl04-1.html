DL04·1

초기화와 기울기의 크기를 함께 살피기

기울기가 여러 층을 지나는 동안 얼마나 달라지는지 곱셈으로 확인합니다. 시작 가중치의 규모와 옵티마이저의 역할을 구분합니다.

이 장을 읽고 나면

  • 연쇄법칙에서 기울기가 작아지거나 커지는 경우를 계산한다.
  • fan-in과 fan-out으로 초기값의 규모를 정한다.
  • 초기화와 SGD·Adam의 갱신을 구분한다.

여러 층의 기울기를 이어 곱한다

한 층이 숫자 하나를 받아 f(x)=ax를 계산한다고 합시다. 입력에 대한 도함수는 a입니다. 같은 모양의 층을 네 번 통과하면 맨 처음 입력에 대한 마지막 값의 기울기는 a⁴입니다. a=0.5에서는 0.0625, a=2에서는 16입니다. 손실의 기울기가 뒤에서 앞쪽으로 전해지기 때문에, 앞쪽 층에서 학습 신호가 지나치게 작아지거나 커질 수 있습니다.

역전파가 더 앞쪽 층에 이르는 동안 기울기가 작아지는 현상을 기울기 소실, 지나치게 커지는 현상을 기울기 폭주라고 합니다. 실제 층에서는 활성함수의 미분과 가중치가 만든 행렬을 연쇄로 적용하므로 방향마다 증폭 정도가 다를 수 있습니다. 손실과 가중치 값만 보고 단정하기보다 여러 층의 기울기 크기와 NaN 여부를 따로 확인합니다. 폭주를 직접 막는 흔한 방법으로, 역전파 뒤 갱신 전에 전체 기울기 벡터의 노름이 정한 값을 넘으면 비율을 유지한 채 줄이는 기울기 노름 자르기(torch.nn.utils.clip_grad_norm_)가 있습니다.

입력이 몇 개씩 연결되는지 보고 시작 분산을 정한다

Linear(4,2)의 가중치에는 출력 뉴런 2개, 뉴런마다 들어오는 입력 가중치 4개가 있습니다. fan-in은 출력 하나로 들어오는 연결 수 4, fan-out은 입력 하나가 연결된 출력 수 2입니다. 비슷한 분산의 독립 성분을 더한다는 단순한 모형에서는 입력을 더 많이 합칠수록 결과의 분산이 늘 수 있습니다. 구체적으로, 평균 0인 가중치 wᵢ와 입력 xᵢ가 서로 독립이면 출력 z=Σwᵢxᵢ의 분산은 Var(z)=fan-in×Var(w)×Var(x)입니다. 층을 지나도 Var(z)=Var(x)로 유지하려면 Var(w)=1/fan-in이어야 합니다. 이것이 아래 초기화 규칙들이 fan-in(역전파 쪽까지 고려하면 fan-out)으로 나누는 이유입니다.

크기가 너무 큰 임의 초기값은 신호를 증폭할 수 있고 너무 작은 초기값은 줄일 수 있습니다. 같은 층의 여러 뉴런의 가중치와 편향을 전부 똑같이 두면 대칭적인 조건에서 같은 기울기를 받아 같은 특성을 배울 수 있습니다. 여기서는 시드를 고정하고 가중치를 임의로 서로 다르게 뽑습니다. gain=1인 Xavier 정규 초기화의 목표 분산은 2/(fan-in+fan-out)이고, ReLU·fan_in을 사용하는 Kaiming 정규 초기화는 2/fan-in입니다. ReLU는 0을 중심으로 대칭인 입력의 음수 절반을 0으로 만들어 출력의 제곱 평균을 입력 분산의 절반으로 줄이므로, Kaiming은 이를 메우려고 분자를 2로 둡니다. 아래 그림의 값은 뽑힌 8개의 실측 통계가 아니라 분포의 목표 분산입니다. 참고로 PyTorch nn.Linear는 따로 지정하지 않으면 가중치와 편향을 균등분포 U(−1/√fan-in, 1/√fan-in)에서 뽑습니다.

초깃값을 정하는 일과 값을 갱신하는 일을 분리한다

초기화한 뒤에는 실제 학습 데이터의 손실을 계산하고 최적화 규칙을 적용합니다. 단순 SGD는 현재 기울기에 학습률을 곱해 빼고, Adam은 기울기의 이동평균과 제곱의 이동평균으로 좌표별 보폭을 조절합니다. 예제는 모멘텀이 없는 SGD와 기본 Adam에서 매개변수 하나를 같은 기울기 2와 학습률 0.1로 한 번 갱신합니다. SGD는 1−0.1×2=0.8입니다. Adam은 기울기 g로 m←β₁m+(1−β₁)g, v←β₂v+(1−β₂)g²를 갱신하고, t번째 단계에서 편향 보정 m̂=m/(1−β₁ᵗ), v̂=v/(1−β₂ᵗ)를 거쳐 θ←θ−lr×m̂/(√v̂+ε)로 움직입니다. PyTorch 기본값은 β₁=0.9, β₂=0.999, ε=10⁻⁸(기본 학습률은 0.001이지만 예제는 0.1을 지정)입니다. 첫 단계에서 m=0.1×2=0.2, v=0.001×4=0.004이고 보정하면 m̂=0.2/0.1=2, v̂=0.004/0.001=4입니다. 보폭은 0.1×2/(2+10⁻⁸)≈0.1이라 θ≈0.9입니다. 첫 단계의 Adam 보폭은 기울기의 크기와 상관없이 거의 학습률과 같다는 점이 SGD와 다릅니다. 어느 설정이 더 잘 학습하는지는 같은 조건에서 검증해야 합니다.

import math
import torch

torch.set_num_threads(1)
torch.manual_seed(17)
for factor in (0.5, 2.0):
    x = torch.tensor(1.0, requires_grad=True)
    value = x
    for _ in range(4):
        value = factor * value
    value.backward()
    print("gradient:", factor, x.grad.item())

weight = torch.empty(2, 4)
torch.nn.init.kaiming_normal_(weight, mode="fan_in", nonlinearity="relu")
assert weight.shape == (2, 4) and torch.isfinite(weight).all()
print("target std:", f"{math.sqrt(2/6):.3f}", f"{math.sqrt(2/4):.3f}")

for name, cls in (("SGD", torch.optim.SGD), ("Adam", torch.optim.Adam)):
    parameter = torch.nn.Parameter(torch.tensor(1.0))
    optimizer = cls([parameter], lr=0.1)
    optimizer.zero_grad()
    (2 * parameter).backward()
    optimizer.step()
    print(name, f"{parameter.item():.3f}")
gradient: 0.5 0.0625
gradient: 2.0 16.0
target std: 0.577 0.707
SGD 0.800
Adam 0.900

실행 환경은 Python 3.14.6과 PyTorch 2.14.0+cu130의 CPU입니다. 난수 시드는 17입니다. 같은 시드를 써도 PyTorch 버전이나 장치가 바뀌면 난수열과 세부 결과가 달라질 수 있습니다.

훈련을 새로 시작하면 초기값과 옵티마이저 상태가 모두 새로 생깁니다. 중간부터 학습을 이어갈 때는 모델 매개변수뿐 아니라 Adam의 이동평균과 단계 수가 들어 있는 옵티마이저 상태도 복원합니다.

한눈에 정리

개념핵심
기울기 소실·기울기 폭주층마다 곱해지는 도함수가 1보다 작으면 앞쪽 기울기가 줄고, 크면 커진다.
fan-in·fan-out출력 하나로 들어오는 연결 수, 입력 하나가 나가는 연결 수. Linear(4,2)는 4와 2.
Xavier·Kaiming목표 분산 2/(fan-in+fan-out), ReLU용 2/fan-in.
SGD·AdamSGD는 lr×기울기만큼 이동. Adam은 이동평균 m, v와 편향 보정으로 좌표별 보폭을 정한다.
