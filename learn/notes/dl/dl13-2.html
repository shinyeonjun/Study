확산의 전방 정규분포를 유도하고 역방향 시작 분포를 비교하기

정상 신호에 잡음을 두 번 넣는 대신 한 번에 같은 분포를 만들 수 있습니다. 작은 정규 자료로 잡음을 맞히는 학습을 해 보고, 되돌리기를 시작하는 분포가 다르면 결과가 어떻게 달라지는지 비교합니다.

이 장을 읽고 나면

  • 독립 Gaussian 잡음의 전방 평균과 분산을 귀납으로 구한다.
  • 작은 정규 모형의 잡음 예측과 역방향 분포를 대조한다.
  • 같은 역방향 함수에서 시작 분포의 영향만 비교한다.

매번 독립 잡음이 같은 방식으로 더해진다

0<βₜ<1, αₜ=1−βₜ이고 εₜ는 서로 독립인 표준정규이며, 초기 x₀가 확률변수라면 x₀와도 독립이라고 둡니다. 전방 변화는 xₜ=√αₜ xₜ₋₁+√βₜ εₜ입니다. x₀를 고정하고 ᾱₜ=∏ᵢ₌₁ᵗαᵢ라 쓰면 평균은 √ᾱₜ x₀, 분산은 1−ᾱₜ입니다. 평균은 매 스텝 √αₜ를 곱하고, 분산은 독립 잡음이라 αₜ(1−ᾱₜ₋₁)+βₜ=1−ᾱₜ가 됩니다.

(β₁,β₂)=(.25,.2)에서는 ᾱ₂=.75·.8=.6입니다. 따라서 x₀를 고정한 두 번째 값은 바로 √.6 x₀+√.4 ε로 그릴 수 있습니다. 여러 전방 잡음의 선형결합이 다시 정규라는 성질을 사용했습니다. 합쳐 놓은 ε도 초기 x₀와 독립입니다.

모형은 어떤 잡음이 섞였는지 맞힌다

이 생성 학습의 한 방법은 학습 시점 t와 xₜ에서, 한 번에 섞었던 표준 잡음 ε를 예측하고 제곱오차를 줄이는 것입니다. 제곱오차의 최적 함수는 조건부 평균입니다. 이 예에서 x₀가 N(2,1)이면 각 시점의 주변분산이 1, 평균이 mₜ=2√ᾱₜ입니다. Cov(ε,xₜ)=√(1−ᾱₜ)라 공동정규의 조건부 평균은 ε̂=√(1−ᾱₜ)(xₜ−mₜ)입니다.

다음 코드는 독립 중심 잡음의 1·2차 모멘트가 맞는 네 점으로 직선 기울기를 맞춥니다. 그 뒤 표집을 할 때는 실제 정규 난수를 사용합니다. 두 시점의 손실을 같은 비중으로 평균하므로 잡음 일정이 바뀌면 손실의 비교 조건도 바뀝니다.

이 예의 정확한 역방향 평균과 시작 조건

공동정규에서 Cov(xₜ₋₁,xₜ)=√αₜ이고 Var(xₜ)=1입니다. 그래서 xₜ를 주었을 때 이전 값의 평균은 mₜ₋₁+√αₜ(xₜ−mₜ), 분산은 1−αₜ=βₜ입니다. 이는 이 자료 모형에서 구한 역방향 q(xₜ₋₁|xₜ)입니다. 원래 x₀까지 안다는 조건의 q(xₜ₋₁|xₜ,x₀)는 정보가 다르며 일반적으로 분산도 다릅니다. 잡음 예측에서 쓰는 평균식 (xₜ−βₜ ε̂/√(1−ᾱₜ))/√αₜ에 위 ε̂를 넣으면 이 예의 참 역방향 평균이 됩니다.

참 마지막 주변값에서 시작하면 평균 2로 돌아옵니다. 대신 N(0,1)에서 시작하면 마지막 평균의 차이 −2√ᾱT가 역방향에서 각 √α를 거쳐 −2ᾱT가 됩니다. 최종 평균은 2(1−ᾱT)입니다. 실제로 ᾱT=.6이면 .8, ᾱT=.05면 1.9입니다.

from itertools import product
from math import sqrt
from random import Random
from statistics import mean

def fitted_steps(betas, location=2.):
    alpha_bar = 1.
    learned = []
    for beta in betas:
        alpha_bar *= 1-beta
        # Four exact first/second-moment design points for z0, eps.
        points = [(sqrt(alpha_bar)*(location+z0)+sqrt(1-alpha_bar)*eps,eps)
                  for z0,eps in product((-1.,1.),repeat=2)]
        center = mean(x for x,_ in points)
        avg_eps = mean(eps for _,eps in points)
        slope = (sum((x-center)*(eps-avg_eps) for x,eps in points)
                 /sum((x-center)**2 for x,_ in points))
        bias = avg_eps-slope*center
        loss = mean((slope*x+bias-eps)**2 for x,eps in points)
        assert abs(slope-sqrt(1-alpha_bar)) < 1e-12
        assert abs(loss-alpha_bar) < 1e-12
        learned.append((beta,alpha_bar,slope,bias,loss))
    return learned

def generate(learned, matched_prior, generator, size=20_000):
    prior_mean = 2*sqrt(learned[-1][1]) if matched_prior else 0.
    for _ in range(size):
        x = prior_mean + generator.gauss(0,1)
        for beta,abar,slope,bias,_ in reversed(learned):
            eps = slope*x+bias
            reverse_mean = (x-beta*eps/sqrt(1-abar))/sqrt(1-beta)
            x = reverse_mean + sqrt(beta)*generator.gauss(0,1)
        yield x

for betas in ((.25,.2),(.75,.8)):
    learned = fitted_steps(betas)
    terminal_abar = learned[-1][1]
    correct = mean(generate(learned,True,Random(2027)))
    standard = mean(generate(learned,False,Random(2027)))
    # Common random numbers isolate the algebraic shift.
    assert abs((correct-standard)-2*terminal_abar)<1e-12
    print("diffusion",f"abar={terminal_abar:.2f}",
          f"avg epsilon MSE={mean(row[-1] for row in learned):.3f}",
          f"N(mT,1) empirical mean={correct:.4f}",
          f"N(0,1) empirical mean={standard:.4f}",
          f"N(0,1) analytic mean={2*(1-terminal_abar):.3f}")

두 시작 조건에 같은 난수열을 사용해 시작 평균만 바꾼 차이가 드러납니다. 이는 Gaussian 한 차원의 생성 평균 실험입니다. 복잡한 자료에서 낮은 잡음 예측 손실이 표본 품질을 곧바로 뜻하는지는 재구성과 보류 표본으로 별도 평가가 필요합니다.
