DL03·2

학습 루프와 평가 루프 실행하기

입력에서 손실까지 계산하고, 역전파한 기울기로 가중치를 움직입니다. 검증에서는 모델의 동작과 기울기 기록을 각각 설정한 뒤 별도 자료의 오차를 확인합니다.

이 장을 읽고 나면

  • Sequential 모델과 옵티마이저를 만들어 배치별 학습을 실행한다.
  • 순전파, 기울기 초기화·역전파·갱신의 역할을 구분한다.
  • eval()과 no_grad()를 각각 적용하고 별도 검증 자료의 손실을 계산한다.

모델이 계산할 식과 갱신할 항목을 고른다

앞 장의 자료에서 표본 x를 받아 y=2x+1을 예측하도록 합니다. 입력 하나, 출력 하나인 nn.Linear(1,1)를 nn.Sequential로 감싸고, 출력은 wx+b입니다. 앞서 만든 MLP와 같은 호출 방식을 사용합니다. 사용자 정의 모델 클래스를 쓰는 방식은 객체·클래스를 다루는 PY12 뒤에 이어집니다.

회귀의 nn.MSELoss()는 여기서 예측과 정답의 제곱오차 평균입니다. 옵티마이저는 파라미터와 기울기를 받아 업데이트합니다. torch.optim.SGD(model.parameters(), lr=0.1)에는 모델의 파라미터만 등록했습니다. 이번 장에서 여러 관측은 로더로 섞어 배치에 넣고 각각의 평균 기울기로 갱신합니다.

배치에서 기울기를 비우고 한 번 갱신한다

학습률 0.1에서 한 갱신을 먼저 손으로 해 봅시다. w=b=0이고 배치에 (x,y)=(0,1),(1,3)이 들어오면 오차가 −1,−3이라 손실은 5입니다. 평균제곱오차의 w 기울기는 2[−1×0+(−3)×1]/2=−3이고, b 기울기는 2(−1−3)/2=−4입니다. 새 w는 0.3, 새 b는 0.4입니다. 실제 코드에서는 에포크마다 학습 자료를 섞으므로 첫 배치의 선택은 이 손계산과 다를 수 있습니다.

optimizer.zero_grad()로 이전 배치의 기울기를 비우고, loss.backward()로 새 값을 계산합니다. optimizer.step() 뒤의 파라미터로 다음 배치를 예측합니다. 손실 계산에서 예측과 정답 모양이 같은지 확인하도록 코드를 넣었습니다.

모듈의 모드와 미분 기록은 별개로 바꾼다

model.train()은 학습할 때 모듈이 적용할 동작을 고릅니다. 예를 들어 드롭아웃을 가진 모듈은 학습 중 일부 값을 무작위로 제외하고, model.eval()에서는 그 동작을 중지합니다. 이 장의 모델은 선형층만 있어서 두 모드의 순전파 계산 자체는 같습니다.

검증 루프에서는 보통 eval()로 모델을 평가 모드로 둔 뒤 no_grad()에서 순전파합니다. 그러면 필요 없는 역전파 그래프를 남기지 않습니다. 검증 예측을 만들 때 optimizer.step()도 실행하지 않습니다. 다음 에포크에서 모델을 다시 train()으로 두는 과정을 코드에 넣습니다.

별도 자료를 사용해 학습 전후를 비교한다

학습 관측은 x=−2,−1,0,1,2이고 검증에는 별도로 x=−1.5,0.5,1.5를 둡니다. 검증 정답은 −2,2,4이므로 초기 예측이 0이면 검증 MSE는 (4+4+16)/3=8입니다. 관측별 출력 하나를 쓰므로 검증에서는 각 배치 평균에 배치의 관측 수를 곱해 전체 손실을 구합니다.

import torch
from torch import nn
from torch.utils.data import DataLoader, TensorDataset

torch.manual_seed(7)
torch.set_num_threads(1)
generator = torch.Generator(device="cpu").manual_seed(7)

train_x = torch.tensor([[-2.], [-1.], [0.], [1.], [2.]])
valid_x = torch.tensor([[-1.5], [0.5], [1.5]])
train = TensorDataset(train_x, 2 * train_x + 1)
valid = TensorDataset(valid_x, 2 * valid_x + 1)
train_loader = DataLoader(train, batch_size=2, shuffle=True,
                          generator=generator, num_workers=0)
valid_loader = DataLoader(valid, batch_size=2, shuffle=False, num_workers=0)

model = nn.Sequential(nn.Linear(1, 1)).to(device="cpu")
with torch.no_grad():
    model[0].weight.zero_()
    model[0].bias.zero_()

loss_fn = nn.MSELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)

def validation_mse():
    model.eval()
    total = 0.0
    count = 0
    with torch.no_grad():
        for xb, yb in valid_loader:
            loss = loss_fn(model(xb), yb)
            total += loss.item() * len(xb)
            count += len(xb)
    return total / count

print(f"initial validation MSE: {validation_mse():.6f}")
for epoch in range(8):
    model.train()
    for xb, yb in train_loader:
        optimizer.zero_grad()
        prediction = model(xb)
        assert prediction.shape == yb.shape
        loss = loss_fn(prediction, yb)
        loss.backward()
        optimizer.step()

print(f"final validation MSE: {validation_mse():.6f}")
print(f"weight, bias: {model[0].weight.item():.4f}, {model[0].bias.item():.4f}")

probe = valid_x[:1]
print("eval records gradients:", model(probe).requires_grad)
with torch.no_grad():
    print("no_grad records gradients:", model(probe).requires_grad)

final validation MSE: 0.000008
weight, bias: 1.9998, 0.9972
eval records gradients: True
no_grad records gradients: False

실행 확인 환경 · Python 3.14.6, PyTorch 2.14.1+cu130, CPU 1스레드, 모델과 학습 로더 시드 7. 초기 w와 b는 0으로 지정했습니다.

학습 여덟 번 순회에서 얻은 w와 b가 2와 1에 가깝습니다. 초기값과 셔플 순서, 자료와 학습률을 바꾸면 결과도 달라질 수 있습니다. 이 예에서는 검증 자료를 갱신에 쓰지 않고 성능만 잽니다.

과정하는 일
학습train(), 기울기 초기화 → 모델 호출 → 손실 → backward → step.
검증eval(), no_grad()에서 고정된 모델의 손실을 관측별로 집계.
