LSTM과 GRU가 상태를 남기는 비율

오래된 상태를 전부 다시 계산하는 대신 일부를 남기고 새 후보를 보탭니다. 두 셀의 게이트가 어느 항에 곱해지는지 확인합니다.

이 장을 읽고 나면

  • LSTM의 셀 상태와 숨은 출력을 구분한다.
  • GRU의 업데이트와 리셋 게이트를 계산에 대응시킨다.
  • 게이트가 긴 문맥을 돕는 이유와 한계를 설명한다.

LSTM은 저장하는 상태와 밖으로 내는 값을 구분한다

LSTM의 게이트는 현재 입력과 이전 숨은 상태에서 계산한 값입니다. 시그모이드를 사용한 게이트의 성분은 0과 1 사이여서, 각 정보가 얼마나 통과할지 정합니다. 이 예는 각 상태가 숫자 하나이고, 게이트를 계산한 뒤의 값을 줍니다. f는 이전 셀 상태에 곱하는 망각 게이트, i는 후보 g에 곱하는 입력 게이트, o는 외부 출력에 곱하는 출력 게이트입니다.

기억 c의 갱신은 cₜ=f·cₜ₋₁+i·g이고, 숨은 값은 hₜ=o·tanh(cₜ)입니다. cₜ₋₁=0.8, f=0.5, i=0.5, g=0.4라면 예전 기억의 0.4와 새 후보의 0.2를 합쳐 cₜ=0.6입니다. o=0.5이면 hₜ≈0.268525입니다. 여러 성분에서는 같은 규칙을 성분별로 적용합니다.

GRU는 하나의 상태를 두 값의 가중합으로 갱신한다

GRUCell의 PyTorch 식에서 업데이트 게이트 z가 클수록 이전 숨은 상태 h를 더 많이 남깁니다. 새 상태는 (1−z)·n+z·h입니다. 후보 n을 만드는 곳에는 리셋 게이트 r이 들어갑니다. 구체적으로 PyTorch에서는 이전 상태를 반영한 선형 결과 Wₕₙh+bₕₙ에 r을 성분별로 곱한 뒤, 현재 입력에서 온 항을 더하고 tanh로 보냅니다. 원 논문 등에서는 리셋을 행렬곱 전 상태에 적용하는 변형도 있으므로 구현식을 확인합니다.

이 예에서 이전 h=0.8, z=0.75, n=0.2라면 새 후보의 0.05와 이전 상태의 0.6을 합해 h=0.65입니다. GRU는 이 값 하나를 다음 시점 상태로 보냅니다. LSTM의 c,h 쌍을 그대로 넘겨주는 규약과 다릅니다.

게이트의 비율을 실제 셀로 검산한다

편향이 0인 시그모이드는 0.5, 편향이 ln 3이면 0.75입니다. tanh가 0.4를 내게 하려면 입력을 그 역함수 atanh(0.4)로 정할 수 있습니다. 예제는 위 계산을 재현하도록 대부분의 파라미터를 0으로 덮고 일부만 정한 모형입니다. 모델을 훈련해 게이트를 추정하는 과정은 포함하지 않습니다.

import math
import torch
from torch import nn

torch.set_num_threads(1)
torch.manual_seed(41)
lstm = nn.LSTMCell(1, 1, dtype=torch.float64)
gru = nn.GRUCell(1, 1, dtype=torch.float64)
x = torch.zeros(1, 1, dtype=torch.float64)
old = x + 0.8
with torch.no_grad():
    for cell in (lstm, gru):
        for parameter in cell.parameters():
            parameter.zero_()
    lstm.bias_ih[2] = math.atanh(0.4)  # i, f, g, o
    h, c = lstm(x, (old, old))

    gru.bias_ih[1] = math.log(3.0)  # r, z, n
    gru.weight_hh[2, 0] = 1.0
    gru.bias_ih[2] = math.atanh(0.2) - 0.4  # r * old is 0.4
    g = gru(x, old)
print("LSTM cell:", f"{c.item():.6f}", "hidden:", f"{h.item():.6f}")
print("GRU hidden:", f"{g.item():.6f}")
LSTM cell: 0.600000 hidden: 0.268525
GRU hidden: 0.650000

실행 환경은 Python 3.14.6과 PyTorch 2.14.1+cu130의 CPU입니다. 난수 시드는 41입니다. 같은 시드를 써도 PyTorch 버전이나 장치가 바뀌면 난수열과 세부 결과가 달라질 수 있습니다.

LSTM처럼 이전 상태를 게이트로 곱해 더하는 경로는 오래된 정보를 보존하도록 학습하는 데 도움을 줍니다. 예를 들어 다른 경로의 영향은 잠시 고정하고 셀 상태의 직접 경로만 보면 한 단계의 배율은 f입니다. 전체 기울기는 게이트 자신이 입력과 상태에 의존하는 다른 경로도 포함하므로, f 하나만으로 장기 기억이나 안정성을 보장할 수 없습니다.
