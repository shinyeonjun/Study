DL02·1

계산 그래프를 그려 역전파 손으로 하기

작은 신경망을 순전파해 손실을 구하고, 방향을 바꿔 각 매개변수와 입력이 손실에 주는 영향을 계산합니다.

이 장을 읽고 나면

  • 입력부터 예측과 손실을 계산하는 순전파를 그래프로 읽는다.
  • 연쇄법칙을 사용해 손실을 매개변수와 입력으로 각각 미분한다.
  • 같은 변수가 여러 갈래에 쓰일 때 기울기가 합쳐지는 이유를 설명한다.

입력부터 손실까지 계산한 순서를 적는다

입력 x 하나와 정답 y 하나를 사용합니다. 은닉 계산은 z=wx+b, h=ReLU(z)입니다. 출력은 ŷ=vh+c, 손실은 L=(ŷ−y)²/2입니다. w,b,v,c는 바꿀 수 있는 매개변수이고 x,y는 주어진 자료입니다. 각 연산이 어떤 값에 의존하는지 화살표로 이으면 계산 그래프입니다.

x=2, w=3, b=−1, v=2, c=0, y=4를 넣습니다. z=3×2−1=5이고 ReLU(5)=5입니다. ŷ=2×5=10, 오차 ŷ−y=6, 손실 6²/2=18입니다. 입력 쪽에서 결과로 계산해 가는 일을 순전파라고 합니다.

손실에서 한 연결씩 거슬러 미분한다

목표는 w를 조금 바꿨을 때 손실이 얼마나 변하는지 아는 것입니다. 직접 연결된 연산의 미분을 이어 곱하는 연쇄법칙을 씁니다. 출력에 대한 손실의 미분은 ∂L/∂ŷ=ŷ−y=6입니다. h에 대한 ŷ의 미분이 v=2이므로 ∂L/∂h=6×2=12입니다. z=5는 양수이므로 ∂h/∂z=1입니다. 따라서 ∂L/∂z=12입니다.

이제 z의 w에 대한 미분은 x=2, b에 대한 미분은 1, x에 대한 미분은 w=3입니다. 따라서 ∂L/∂w=12×2=24, ∂L/∂b=12, ∂L/∂x=12×3=36입니다. 출력을 만드는 v와 c에 대해서는 ∂L/∂v=6×h=30, ∂L/∂c=6입니다. 이렇게 뒤에서부터 값을 공유하며 미분을 전파하는 일이 역전파입니다.

x의 미분 36은 입력을 바꾸면 이 지점에서 손실이 얼마나 변하는지를 말합니다. 보통 학습에서 실제로 움직이는 값은 w,b,v,c이며 어떤 값을 갱신할지는 따로 정합니다. 입력에 대한 미분도 분석에 필요하다면 계산할 수 있습니다.

갈라진 경로에서는 기여를 합한다

L(x)=x²+3x에서 하나의 x가 제곱과 3배의 양쪽에 들어갑니다. x=2의 변화는 x²를 따라 2x=4만큼, 3x를 따라 3만큼 영향을 줍니다. 최종 손실은 두 갈래를 더하므로 전체 미분은 4+3=7입니다.

ReLU 입력이 음수라면 그 연산의 미분은 0이어서, 해당 경로를 통한 이전 값의 기여가 0이 됩니다. z=0에서는 ReLU의 양쪽 기울기가 달라 미분이 존재하지 않습니다. PyTorch는 이 지점의 역전파 값으로 0을 사용합니다.

손계산 결과를 PyTorch 역전파와 대조한다

import torch

device = "cpu"
x, w, b, v, c = [torch.tensor(n, dtype=torch.float64, device=device,
                              requires_grad=True) for n in (2., 3., -1., 2., 0.)]
y = 4.
z = w * x + b
h = torch.relu(z)
prediction = v * h + c
loss = (prediction - y)**2 / 2
loss.backward()

print("forward:", [u.item() for u in (z, h, prediction, loss)])
print("grad x,w,b,v,c:", [u.grad.item() for u in (x, w, b, v, c)])

shared = torch.tensor(2., dtype=torch.float64, device=device, requires_grad=True)
total = shared**2 + 3 * shared
total.backward()
print("shared gradient:", shared.grad.item())
forward: [5.0, 5.0, 10.0, 18.0]
grad x,w,b,v,c: [36.0, 24.0, 12.0, 30.0, 6.0]
shared gradient: 7.0

실행 확인 환경 · Python 3.14.6, PyTorch 2.14.1+cu130, CPU. 초기값을 직접 정했습니다.

마지막에 backward()를 부르면 PyTorch가 기록한 연산을 따라 각 텐서에 대한 손실의 기울기를 계산합니다. 저장 위치와 누적 규칙은 다음 장에서 다룹니다.
