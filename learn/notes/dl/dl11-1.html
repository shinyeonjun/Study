딥러닝 · DL11 역전파를 유도하고 구현으로 검증하기

DL11·1

벡터 출력의 역전파와 선형층 기울기를 손으로 구하기

한 입력이 여러 출력으로 퍼지면 손실을 바꾸는 길도 여러 개가 됩니다. 위 층에서 내려오는 경사를 받아 각 길의 기여를 더하고, 작은 배열에서 해석식·수치미분·자동미분을 대조합니다.

이 장을 읽고 나면

  • 야코비안의 행과 열을 고정하고 벡터–야코비안 곱을 유도한다.
  • 배치 선형층의 dX, dW, db 모양과 계산식을 직접 쓴다.
  • 중심차분과 자동미분으로 같은 손실의 기울기를 검산한다.

출력의 각 변화를 입력까지 돌려보낸다

f:ℝⁿ→ℝᵐ이고 y=f(x), 최종 손실 L은 스칼라라고 둡니다. 야코비안 J의 (i,j) 성분은 ∂yᵢ/∂xⱼ입니다. 출력 경사 u=∇ᵧL을 알고 있고 작은 입력 변화가 v이면 출력 변화는 Jv입니다. 손실의 일차 변화는 uᵀ(Jv)입니다. 이를 v의 내적으로 쓰면 (Jᵀu)ᵀv이므로 입력 경사는 Jᵀu입니다.

행벡터로 쓰면 같은 계산을 uᵀJ라고 하며 벡터–야코비안 곱(VJP)이라고 부릅니다. 야코비안 전체를 기록하지 않고도, 어떤 출력 경사를 입력 쪽으로 보낼지 계산할 수 있습니다. 반대로 입력 방향 하나 v에서 출력이 어떻게 변하는지 묻는 Jv에서는 곱의 방향이 다릅니다.

배치 선형층에서 세 가지 기울기를 분리한다

X의 모양을 [B,D], W를 [D,M], b를 [M]이라 둡니다. H=XW+1bᵀ의 모양은 [B,M]입니다. G를 H에 대한 경사라 둡니다. H의 작은 변화는 ΔX·W+X·ΔW+1·Δbᵀ입니다. 이를 ΔL=∑ᵢⱼGᵢⱼΔHᵢⱼ에 넣습니다. 예를 들어 ΔWkm의 계수는 배치 전체 ∑ᵢXikGim입니다.

구하려는 경사식모양
∇XLGWᵀ[B,D]
∇WLXᵀG[D,M]
∇bL배치 행마다 G를 더함[M]

같은 b가 모든 행에 쓰였으므로 그 경사는 배치에서 더합니다. 평균 손실을 사용했다면 G를 만들 때 이미 그 평균 배율이 들어갑니다. PyTorch nn.Linear가 저장하는 가중치의 모양은 [M,D]라 위 표의 W와 전치 관계입니다.

수치미분은 같은 손실을 살짝 옮겨 대조한다

f(x)=(x₀²+x₁,x₀x₁), x=(2,3), u=(5,−2)를 사용하면 y=(7,6), J의 두 행은 (4,1), (3,2)입니다. 그래서 Jᵀu=(14,1)입니다. 수치 검산은 u를 고정하고 스칼라 uᵀf(x)를 좌표마다 ±ε만큼 바꿔 두 값의 차이를 2ε로 나눕니다. 입력을 아주 작게 바꾸면 뺄셈 반올림이 커질 수 있으므로, 매끄러운 점과 허용 오차를 잡아 비교합니다.

import torch
from torch.func import jacrev, vjp

torch.set_num_threads(1)
d = torch.float64
x = torch.tensor([2.,3.], dtype=d)
u = torch.tensor([5.,-2.], dtype=d)
def f(x):
    return torch.stack((x[0].square()+x[1], x[0]*x[1]))

y, pullback = vjp(f, x)
(grad,) = pullback(u)
J = jacrev(f)(x)
eps = 1e-5
dirs = torch.eye(2, dtype=d)
numeric = torch.stack([((u @ f(x+eps*e))-(u @ f(x-eps*e)))/(2*eps) for e in dirs])
assert torch.equal(grad, J.T @ u)
assert torch.allclose(grad, numeric, atol=1e-8, rtol=0)
print("y",y.tolist(),"J",J.tolist(),"grad",grad.tolist())

a = torch.tensor([[1.,2.],[3.,4.]], dtype=d, requires_grad=True)
w = torch.tensor([[2.,0.],[-1.,1.]], dtype=d, requires_grad=True)
b = torch.tensor([1.,-1.], dtype=d, requires_grad=True)
g = torch.tensor([[1.,2.],[-1.,3.]], dtype=d)
out = a @ w+b
da,dw,db = torch.autograd.grad(out, (a,w,b), grad_outputs=g)
assert torch.equal(da,g@w.T) and torch.equal(dw,a.T@g) and torch.equal(db,g.sum(0))
print("affine",out.tolist(),da.tolist(),dw.tolist(),db.tolist())

실행 결과

y [7.0, 6.0] J [[4.0, 1.0], [3.0, 2.0]] grad [14.0, 1.0]
affine [[1.0, 1.0], [3.0, 3.0]] [[2.0, 1.0], [-2.0, 4.0]] [[-2.0, 11.0], [-2.0, 16.0]] [0.0, 5.0]

이 예제는 Python 3.14.6과 PyTorch 2.14.0 CPU 연산에서 검증했습니다. 부동소수점으로 읽는 검산은 출력의 모든 숫자를 같은 문자열로 비교하는 대신 식에 대한 절대 허용 오차를 함께 확인합니다.
