시스템 · SY03 프로그램이 실행될 때

SY03·2

같은 프로그램도 실행할 때마다 별도 상태를 가진다

편집기를 두 번 실행하면 같은 파일을 읽지만 두 창에서 다른 작업을 할 수 있습니다. 실행 파일과 프로세스를 구분하고, Python 부모가 자식을 시작해 어떤 값을 주고받는지 확인합니다.

이 장을 읽고 나면

  • 실행 파일의 내용과 프로세스의 상태를 구별한다.
  • 명령 인자, 작업 디렉터리, 환경, 종료 코드를 구분한다.
  • Python에서 로컬 자식 프로세스를 실행하고 출력을 읽는다.

실행 파일 하나가 실행 상태를 하나로 묶지는 않는다

디스크의 실행 파일에는 운영체제가 프로그램을 시작할 때 읽을 코드와 데이터, 형식 정보가 있습니다. 같은 실행 파일을 다시 시작하면 운영체제가 새로운 프로세스를 만들 수 있습니다. 프로세스는 실행 중인 프로그램의 자원과 상태를 관리하는 단위입니다. 실행 중에는 자신에게 보이는 메모리, 시작할 때 받은 명령 인자, 열어 사용하는 파일 등을 가질 수 있습니다.

프로세스 식별자(PID)는 운영체제가 실행 중인 프로세스를 가리키기 위한 번호입니다. 예를 들어 편집기 한 종류를 프로세스 두 개로 실행했다면 서로 다른 PID와 상태를 가집니다. 실제 프로그램이 여러 창을 하나의 프로세스로 관리하기도 하므로, 창 수만 보고 프로세스 수를 판단하지 않습니다. 프로세스가 끝나면 값이 나중에 재사용될 수 있어 오래 보관하는 기록에서 PID만으로 과거 실행을 식별하면 헷갈릴 수 있습니다.

같은 소스도 어디에서 어떻게 실행하는지에 따라 달라진다

Windows에서 흔히 실행하는 Python 프로그램 이름은 python.exe입니다. 이때 .exe의 이름과 운영체제가 이해하는 실행 파일 형식은 Windows에 관한 설명입니다. 프로세스와 명령 인자, 작업 디렉터리의 개념은 다른 운영체제에도 있지만, 실행 파일 이름 형식, 실행 파일에 적힌 명령의 종류, 경로 표기와 기본 설정은 달라질 수 있습니다.

프로그램을 시작할 때 넘기는 인자는 프로그램이 받을 목록입니다. 작업 디렉터리는 단순한 상대 경로를 해석할 때 기준이 되는 폴더입니다. 예를 들어 results.csv라는 이름을 바로 열더라도, 다른 폴더에서 두 번 실행하면 각기 다른 파일을 보게 될 수 있습니다. 스크립트 파일이 있는 폴더와 작업 디렉터리는 같다는 보장이 없습니다. 운영체제의 환경 변수는 선택할 설정과 검색 경로 같은 문자열을 제공할 수 있습니다. 인자나 환경을 받았다고 해서 모든 OS와 설치에서 같은 프로그램이 발견되는 것은 아닙니다.

항목이 예에서 보는 것비슷하지만 다른 것
실행 프로그램현재 Python의 실제 실행 경로인 sys.executable작성한 소스 문자열
명령 인자자식에게 건네는 order-3 한 항목자식의 표준 출력
종료 코드자식이 끝날 때 내놓은 정수 7화면에 적은 텍스트

부모는 자식에게 인자를 보내고 종료 결과를 받는다

한 프로세스에서 새 실행을 시작하면 시작한 쪽을 부모, 새로 만들어진 쪽을 자식이라고 부릅니다. 아래 subprocess.run은 현재 실행한 Python과 같은 실행 프로그램을 찾아 짧은 코드를 자식으로 실행합니다. OS에 셸 문장을 넘기는 방식이 아니라 실행할 프로그램과 각 인자를 목록으로 넘깁니다. capture_output=True로 자식의 표준 출력과 표준 오류를 받을 수 있습니다. 프로세스가 끝난 뒤에는 반환 코드도 확인할 수 있습니다.

관례상 종료 코드 0은 성공이고 0이 아닌 값은 프로그램이 정한 시험 실패나 다른 종료 사유를 알릴 수 있습니다. 구체적인 의미는 프로그램 설명을 확인합니다. 예제에서는 숫자 7을 일부러 반환해 그것이 표준 출력과 별개임을 확인합니다. check=True라면 자식이 0이 아닌 코드로 종료했을 때 예외가 발생합니다.

자기 Python으로 짧은 자식 프로그램을 실행한다

import subprocess
import sys

summary = "parent"
source = "import sys; summary = 'child'; print(summary, sys.argv[1]); sys.exit(7)"
run = subprocess.run(
    [sys.executable, "-c", source, "order-3"],
    capture_output=True, text=True, encoding="utf-8", check=False,
)
print("stdout:", run.stdout.strip())
print("exit status:", run.returncode)
print("parent:", summary)
stdout: child order-3
exit status: 7
parent: parent

자식도 변수 이름 summary를 썼지만 부모의 값은 그대로입니다. 인자, 출력, 종료 코드는 이 실행에서 부모와 자식이 명시적으로 주고받은 값입니다.
