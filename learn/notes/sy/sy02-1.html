SY02·1

CPU는 명령을 실행하고 메모리에서 데이터를 가져온다

파일에 있는 두 수를 더한다고 할 때, CPU 앞에는 언제 어떤 수가 도착할까요? 지금 실행 중인 내용과 나중에 다시 열 내용이 각각 어느 장치에 놓이는지 봅니다.

이 장을 읽고 나면

  • CPU·주기억장치·저장장치의 역할을 구분한다.
  • 작은 명령열에서 레지스터, 메모리, 다음 명령 번호를 추적한다.
  • 데이터 크기와 전송률로 이상적 이동 시간을 구한다.

파일을 보관하는 곳과 계산 재료가 놓인 곳

문서가 저장장치의 파일에 남아 있어도 전원이 꺼진 컴퓨터에서 계산이 이루어지지는 않습니다. SSD 같은 저장장치는 전원이 꺼져도 보통 파일을 유지합니다. 프로그램이 실행되면 운영체제는 CPU가 사용할 코드와 데이터를 주기억장치(메인 메모리)에서 접근할 수 있도록 준비합니다. 파일 전체를 처음에 무조건 한꺼번에 옮기는 것은 아닙니다. 실제 환경에서는 필요할 때 파일 일부를 가져오거나 이미 읽었던 부분을 기억해 둘 수 있습니다.

CPU는 프로그램의 기계 명령을 실행하는 장치입니다. CPU 안에도 아주 작은 저장 공간인 레지스터가 있습니다. 예를 들어 두 레지스터의 수를 더해 다른 레지스터에 적습니다. 메모리에서 읽은 자료를 레지스터에 넣는 동작과 레지스터의 결과를 메모리에 쓰는 동작은 구분할 수 있습니다. 메모리에 쓴 값이 자동으로 새 파일이 되는 것도 아닙니다.

명령이 바뀔 때 어디의 값이 바뀌는지 기록한다

실제 CPU가 이해하는 명령 집합은 CPU 계열마다 다를 수 있습니다. 여기서는 계산에 필요한 동작을 분리하기 위해 가상의 명령 네 개를 씁니다. LOAD는 메모리 값을 레지스터로 읽어 옵니다. ADD는 두 레지스터의 값을 더합니다. STORE는 결과를 레지스터에서 메모리로 옮깁니다. 메모리 칸에는 주소가 있고, 프로그램 카운터(PC)는 이 모형에서 다음에 실행할 명령 번호입니다.

실행한 명령 번호실행한 명령R1R2메모리 2번 칸
0LOAD R1, [0]700
1LOAD R2, [1]750
2ADD R1, R21250
3STORE [2], R112512

표의 수는 각 명령을 실행한 뒤의 상태입니다. 예를 들어 ADD 직후 R1은 12가 되었지만, 메모리 2번 칸은 아직 0입니다. STORE가 실행되어야 12가 적힙니다. 이 순서에서는 명령 번호가 1씩 늘지만, 실제 프로그램에서는 조건이 맞을 때 다른 명령 위치로 분기할 수도 있습니다.

데이터를 어디에서 가져오는지가 실행에 영향을 준다

같은 계산이라도 필요한 값이 CPU 근처에 있는지, 메인 메모리나 파일에서 와야 하는지에 따라 걸리는 시간이 달라질 수 있습니다. 대역폭은 한 초에 옮길 수 있는 데이터 양입니다. 순수하게 1MiB를 100MiB/s로 전송하면 전송률이 일정하다는 가정에서 0.01초입니다. 실제 작업에는 전송을 시작하기까지의 대기, 명령 실행, 경합 등의 시간이 추가될 수 있습니다.

지연 시간은 요청 하나를 시작해 원하는 결과를 받기까지의 시간입니다. 대역폭이 큰 통로도 첫 번째 데이터가 도착하기까지 시간이 걸릴 수 있습니다. 작은 값을 여기저기 요청하는 작업과 큰 덩어리 하나를 전송하는 작업의 차이를 이 두 개념으로 볼 수 있습니다.

가상 CPU의 명령을 재생한다

memory = [7, 5, 0]
registers = {"R1": 0, "R2": 0}
program = [("LOAD", "R1", 0), ("LOAD", "R2", 1),
           ("ADD", "R1", "R2"), ("STORE", "R1", 2)]
for pc, (op, reg, operand) in enumerate(program):
    if op == "LOAD":
        registers[reg] = memory[operand]
    elif op == "ADD":
        registers[reg] += registers[operand]
    else:  # STORE in this example
        memory[operand] = registers[reg]
    print(pc + 1, registers["R1"], registers["R2"], memory[2])

print(f"transfer: {1 / 100:.2f} seconds")
1 7 0 0
2 7 5 0
3 12 5 0
4 12 5 12
transfer: 0.01 seconds

출력 첫 열은 실행을 끝낸 명령 뒤에 다음으로 가리킬 번호입니다. 4에 도착하면 이 작은 프로그램에는 더 실행할 명령이 없습니다. 앞 표의 번호는 실행할 명령을, 코드의 번호는 실행한 뒤 다음 위치를 가리킵니다.
