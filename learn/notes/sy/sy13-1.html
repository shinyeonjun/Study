작은 언어의 타입 보존과 루프의 정답을 증명하기

조건문의 조건에는 참·거짓을, 덧셈에는 숫자를 넣습니다. 계산이 한 단계 진행될 때도 이 약속이 지켜지는지 확인합니다. 그다음 반복문의 각 단계에 대해 결과와 종료를 따로 증명합니다.

이 장을 읽고 나면

  • 귀납적으로 정의한 구문에서 작은 단계 실행을 재현한다.
  • 진행·타입 보존을 규칙의 경우를 나누어 증명한다.
  • 반복문의 불변식과 종료량을 찾아 전체 정확성을 확인한다.

식이 무엇을 포함할 수 있는지 작은 규칙으로 정한다

우리 식의 기본 값은 정수와 참·거짓입니다. 두 식을 더한 식 또는 ‘조건이면 왼쪽, 아니면 오른쪽’인 식도 포함합니다. 이 작은 언어에는 변수가 없으며 모든 식은 여기 적은 기본 값과 두 조립 규칙으로 만들어집니다. 타입은 종이에 나무처럼 아래 조건을 붙여 유도할 수 있습니다.

식타입을 정할 조건결과 타입
정수 n기본값Int
참·거짓기본값Bool
e₁+e₂양쪽이 IntInt
if c then e₁ else e₂c는 Bool, 양쪽은 같은 타입 TT

작은 단계 의미론은 식 하나를 다음 식 하나로 바꾸는 규칙입니다. 덧셈에서는 왼쪽을 먼저 값으로 만들고 오른쪽으로 갑니다. 두 값이 정수이면 그 합으로 바꿉니다. 조건문에서는 조건을 먼저 값을 만들고, 참·거짓이 나오면 해당 가지로 바꿉니다. 선택되지 않은 가지는 실행하지 않습니다. 여기서 값은 정수 상수와 true·false뿐이며, 값에는 적용할 규칙이 없습니다.

값이 아닌데 적용할 규칙도 없는 식을 막힌 식(stuck)이라 합니다. 예를 들어 true+1은 값이 아니고, 덧셈 규칙은 두 정수에만 있으므로 막힙니다. 타입 규칙의 목적은 이런 식을 실행 전에 걸러 내는 것입니다. 타입은 아래처럼 규칙을 위로 쌓은 타입 유도(나무)로 보입니다. 가로줄 위가 전제, 아래가 결론입니다.

                  1 : Int    2 : Int
                  ------------------
true : Bool         1+2 : Int          0 : Int
----------------------------------------------
     if true then 1+2 else 0 : Int

타입 있는 식이 막히지 않고 같은 타입을 유지한다

진행은 타입 있는 식이 이미 값이거나 다음 규칙을 적용할 수 있다는 뜻입니다. 구문에서 작은 식에도 성립한다고 귀납 가정합니다. 덧셈이면 아직 값이 아닌 인자에서 한 단계 진행할 수 있고, 모두 값이면, Int 타입인 값은 정수 상수뿐이라는 사실(표준 형태 보조정리, canonical forms)에 따라 둘 다 정수여서 덧셈 규칙이 있습니다. 조건문이면 조건 자체를 진행시키거나, 이미 값이면 표준 형태에 따라 true나 false이므로 한 가지를 선택합니다.

보존은 실행 한 단계 뒤에도 같은 타입이 남는다는 뜻입니다. 덧셈 인자를 줄일 때 그 인자의 타입이 그대로라는 귀납 가정으로 덧셈 전체를 같은 규칙으로 검사합니다. 값들의 합은 Int입니다. 조건을 줄이면 귀납 가정으로 조건은 여전히 Bool이고, 두 가지는 바뀌지 않았으므로 같은 타입 T를 유지합니다. 조건 값을 읽고 가지로 바꾸면 그 가지가 원래 결과 타입을 갖습니다. 여기서는 닫힌 작은 언어의 경우를 모두 다뤘습니다. 두 정리를 합치면 "타입이 있는 식은 몇 단계를 가든 막히지 않는다"(타입 안전성)가 나옵니다. 보존으로 매 단계 타입이 유지되고, 진행으로 그 식이 값이 아니면 다음 단계가 있기 때문입니다.

반복문에서는 계산 도중의 문장을 고른다

음이 아닌 정수 n까지 합하는 코드에서 i=0, total=0으로 시작해 i<n일 때 i를 1 올리고 total에 i를 더합니다. 반복문의 머리에서 0≤i≤n, total=i(i+1)/2가 불변식입니다. 처음 i=0이므로 맞습니다. 반복 직전 맞았다면 새 값은 이전 i에서 쌓은 합에 i+1을 더한 i(i+1)/2+(i+1)=(i+1)(i+2)/2입니다. 그리고 검사 i<n으로 새 i≤n입니다. 반복이 끝나면 i≥n과 i≤n을 합쳐 i=n이므로 답이 맞습니다.

반복할 때마다 n−i라는 음이 아닌 정수가 1씩 줄어듭니다. 무한히 감소할 수 없으므로 반복이 종료됩니다. 불변식 증명은 ‘종료하면 맞는 결과’를, 이 별도 계산은 ‘실제로 끝남’을 줍니다. 앞의 것을 부분 정확성, 둘을 합친 것을 전체 정확성이라 합니다. Hoare 논리에서는 부분 정확성을 {P} c {Q}(P가 참인 상태에서 c가 끝나면 Q가 참)로 씁니다. 이 예는 {n≥0} 반복문 {total=n(n+1)/2}이고, while 규칙의 핵심이 위의 불변식 I입니다: 시작 때 I, 본문이 I∧(i<n)에서 I를 유지, 끝나면 I∧¬(i<n)에서 결론.

def type_of(e):
    tag,*parts=e
    if tag in ("int","bool"):
        return tag
    if tag=="add" and all(type_of(x)=="int" for x in parts):
        return "int"
    if tag=="if":
        c,left,right=parts
        if type_of(c)=="bool" and type_of(left)==type_of(right):
            return type_of(left)
    raise TypeError("타입 규칙 위반")

def value(e):
    return e[0] in ("int","bool")

def step(e):
    tag,*parts=e
    if tag=="add":
        left,right=parts
        if not value(left):
            return ("add",step(left),right)
        if not value(right):
            return ("add",left,step(right))
        return ("int",left[1]+right[1])
    c,left,right=parts
    return (left if c[1] else right) if value(c) else ("if",step(c),left,right)

e=("if",("bool",True),
   ("add",("add",("int",1),("int",2)),("int",3)),("int",0))
steps=0
while not value(e):
    old=type_of(e)
    e=step(e)
    assert old==type_of(e)
    steps+=1
print(steps, *e)

def triangle(n):
    i=total=0
    while i<n:
        assert total==i*(i+1)//2
        i+=1
        total+=i
    return total
for n in range(101):
    assert triangle(n)==n*(n+1)//2
print([triangle(n) for n in (0,1,5,100)])

문법대로 만든 구문 트리의 타입을 검사한 뒤, 그 검사를 통과한 식에 실행 함수를 적용합니다. 예제마다 값을 대조하는 테스트와, 모든 표현에 대해 귀납하는 증명은 각각 다른 확인 방법입니다.

한눈에 정리

핵심어기억할 기준
작은 단계 의미론식 하나를 다음 식 하나로 바꾸는 규칙. 값에는 규칙이 없고, 값도 아니고 규칙도 없으면 막힌 식입니다.
진행타입 있는 닫힌 식은 값이거나 한 단계 갈 수 있습니다(표준 형태 보조정리 사용).
보존e:T이고 e→e′이면 e′:T. 타입 유도에 대한 귀납으로 증명합니다.
루프 불변식시작 때 참, 한 번 반복해도 유지, 종료 조건과 합쳐 결론. 부분 정확성을 줍니다.
종료량음이 아닌 정수가 매번 줄어들면 끝납니다. 불변식과 합쳐 전체 정확성입니다.

한 줄 정리

진행+보존은 "타입이 맞으면 막히지 않는다"를, 불변식+종료량은 "끝나고 답이 맞다"를 증명합니다.
