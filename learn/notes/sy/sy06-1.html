셸에서 경로를 고르고 권한을 읽는다

터미널에서 파일 목록을 보면 이름 앞에 여러 글자가 붙습니다. 명령이 어느 폴더에서 실행되는지, 파일의 소유자와 다른 사용자가 무엇을 할 수 있는지 먼저 읽습니다.

이 장을 읽고 나면

  • 터미널과 셸, 실행 명령을 구분한다.
  • Linux 절대·상대 경로와 현재 폴더를 확인한다.
  • 소유자·그룹·기타의 권한 숫자를 문자로 풀어 읽는다.

명령을 적는 창과 명령을 해석하는 프로그램

터미널은 문자로 입력하고 실행 결과를 볼 수 있는 환경입니다. 셸은 그 안의 명령줄을 해석하는 프로그램입니다. Bash에서 pwd는 현재 작업 디렉터리를 표시하고, ls -l은 목록을 자세히 보여 줍니다. cd는 실행 중인 셸 자신의 폴더를 바꾸므로 셸이 직접 제공하는 명령입니다. 명령에 따라 셸 안에서 실행되거나 별도의 프로그램이 시작될 수 있습니다.

Linux에서 /study/report.csv처럼 처음이 /인 절대경로는 루트에서 출발합니다. 상대경로는 현재 폴더에서 출발합니다. .는 현재 폴더, ..는 한 단계 위를 가리킵니다. 현재 폴더가 /study라면 data/raw.csv는 /study/data/raw.csv입니다. Bash의 인용되지 않은 ~가 경로의 첫머리에 오면 일반적인 경우 자신의 홈 디렉터리로 확장됩니다.

Windows PowerShell에서도 현재 폴더와 상대경로의 개념을 쓰지만 C:\work처럼 드라이브를 포함한 경로와 Windows의 접근 제어 규칙을 사용합니다. 표시가 비슷해도 PowerShell의 별칭 ls에 Bash에서 쓰던 옵션이 그대로 적용된다고 가정하지 않습니다.

권한을 세 사용자 범주로 읽는다

Linux의 기본 모드 비트에서 읽기 r은 4, 쓰기 w는 2, 실행 x는 1입니다. 소유자, 그룹, 기타 사용자에 대해 각각 세 비트를 정합니다. 일반 파일의 모드가 640이면 소유자 6은 읽기·쓰기, 그룹 4는 읽기, 기타 0은 세 권한이 없습니다. ls -l의 권한 표시 맨 앞 글자는 파일 종류입니다. 일반 파일이면 그 자리에 -가 오고, 뒤에 권한 9글자가 이어집니다.

디렉터리의 x는 '이 폴더를 프로그램으로 실행'한다는 뜻이 아닙니다. 그 아래 이름을 탐색하는 권한입니다. r은 이름 목록을 읽는 데, w는 이름 항목을 만들거나 지우는 일에 관계합니다. 파일 안의 데이터에 쓸 수 있는가와 상위 디렉터리에 새 파일 이름을 만들 수 있는가는 다른 질문입니다. 예제의 640 해석은 정상적인 자기 실습 파일의 권한을 읽는 연습입니다.

사용하는 셸의 약속을 확인한다

명령을 조금씩 실행할 때는 먼저 pwd로 어디인지 확인하고, 파일 이름에 공백이 있으면 "my report.csv"처럼 한 인자로 묶습니다. ls -a는 이름이 점으로 시작하는 항목도 포함할 수 있습니다. 점으로 시작하는 관례와 파일을 읽을 수 있는지는 별개입니다. 아래 코드는 Windows에서도 Linux와 같은 문자열 규칙을 연습할 수 있도록 PurePosixPath를 사용하고, 어느 파일의 실제 권한도 변경하지 않습니다.

from pathlib import PurePosixPath

cwd = PurePosixPath("/study")
print("current:", cwd)
print("from cwd:", cwd / "data" / "raw.csv")
print("parent:", cwd.parent)

def symbolic(digits):
    names = [(4, "r"), (2, "w"), (1, "x")]
    return " ".join(
        "".join(letter if digit & bit else "-" for bit, letter in names)
        for digit in digits
    )

print("640:", symbolic([6, 4, 0]))
print("750:", symbolic([7, 5, 0]))
current: /study
from cwd: /study/data/raw.csv
parent: /
640: rw- r-- ---
750: rwx r-x ---

이 코드는 경로 객체의 문자열과 권한 숫자의 뜻만 확인합니다. 실재하는 경로와 자신의 권한을 조사하는 작업은 사용하는 OS와 셸에서 따로 합니다.
