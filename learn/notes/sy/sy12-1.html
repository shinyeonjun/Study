겹친 읽기·쓰기의 일관성과 과반 교집합을 검산하기

읽기 호출과 쓰기 호출이 겹치면 읽기가 예전 값을 내도 어떤 순서로는 설명할 수 있습니다. 시작과 응답 시각이 강제하는 순서, 과반이 겹치는 이유, 메시지의 앞뒤를 각각 검증합니다.

이 장을 읽고 나면

  • 실시간 제약을 지키는 선형화 순서를 열거한다.
  • 충돌 정족수의 최소 교집합과 로그가 추가로 필요한 이유를 설명한다.
  • Lamport 논리 시각으로 메시지 인과를 따라간다.

겹침은 순서를 고를 수 있고 끝난 호출은 먼저 와야 한다

쓰기 W(v)는 정수 레지스터를 v로 바꾸고, 읽기 R은 그 값을 반환한다고 둡니다. 초기값은 0입니다. 연산의 시작과 응답 사이 어딘가에서 한 번에 일어난 것처럼 순서를 배정하고, 앞 호출이 응답한 뒤 다음 호출이 시작했다면 그 순서를 지켜야 합니다. 그 순서에 따라 읽기 결과가 모두 설명되는 성질이 선형화 가능성입니다. 완료된 연산만 다루는 작은 이력을 열거합니다.

요청시작과 응답결과 또는 쓰는 값
W0, 41 쓰기
R₁1, 20 읽기
R₂5, 61 읽기

R₁는 W와 겹칩니다. R₁→W→R₂를 택하면 두 읽기가 모두 설명됩니다. 만약 W가 0.5에 끝났다면 R₁보다 앞이어야 하므로, 다른 쓰기가 없는 이력에서 R₁의 0은 설명되지 않습니다. 실제 시간을 항상 모두 관측할 수 있는 것은 아니므로, 어떤 클라이언트의 시작·응답 기록을 사용했는지 밝힙니다.

다섯 복제본 중 세 곳이 겹칠 수밖에 없는 이유

이 모형에서 고장은 노드가 정상적으로 동작하다 멈추고 다시 보내지 않는 형태(crash-stop)입니다. 임의의 잘못된 메시지를 보내는 고장은 다른 모형에서 다룹니다. N개의 복제본에서 읽기 집합 크기가 R, 쓰기 집합 크기가 W라면, 합집합 크기가 N 이하이므로 교집합 크기는 최소 R+W−N이며, 이 값이 음수이면 0 이상의 자명한 하계를 사용합니다. N=5, R=W=3이면 최소 1입니다. R=3,W=2라면 두 집합이 완전히 나뉠 수 있습니다.

정족수가 겹친다는 사실만으로 오래된 값이 최신 값을 덮지 못한다는 결론은 나오지 않습니다. 어떤 쓰기가 승인됐는지 구분하고, 읽을 버전과 장애 뒤의 로그를 정하는 규칙이 필요합니다. Raft는 선거의 임기 번호, 투표 전 로그 최신성 검사, 로그 전후 일치 조건 등을 함께 사용합니다. 노드 구성이 고정되어 있고 같은 임기에서 각 노드가 한 후보에게만 투표한다는 조건에 과반의 교집합을 합치면 같은 임기에 두 후보가 과반으로 당선될 수 없습니다. 쓰기 커밋은 리더 선출 외 로그 복제를 다루는 규칙까지 필요합니다.

논리 시각은 인과가 먼저일 때 값을 작게 만든다

프로세스 안에서 이벤트마다 수를 올립니다. 메시지를 받으면 로컬 수와 메시지의 수 중 큰 것보다 1을 크게 적습니다. 같은 프로세스 순서, 보냄→받음, 그 추이로 정의한 인과 순서(happened-before, a→b)가 있으면 앞 이벤트의 수가 작습니다. 곧 a→b이면 C(a)<C(b)입니다. 역은 성립하지 않습니다. 서로 메시지 없이 시작한 두 프로세스에서 한쪽이 1, 다른 쪽이 2를 표시해도 더 작은 이벤트가 인과적으로 먼저라는 뜻은 아닙니다. 인과 관계를 시각만으로 판정하려면 프로세스마다 칸을 둔 벡터 시계를 씁니다. 벡터 시계에서는 a→b와 V(a)<V(b)(모든 칸이 작거나 같고 적어도 한 칸이 작음)가 동치입니다.

from itertools import combinations, permutations

def valid(history):
    names = tuple(history)
    chronological = [(a,b) for a in names for b in names if a!=b
                     and history[a][1]<history[b][0]]
    for order in permutations(names):
        pos = {name:i for i,name in enumerate(order)}
        if any(pos[a]>pos[b] for a,b in chronological):
            continue
        value=0
        for name in order:
            _,_,kind,number=history[name]
            if kind=="write":
                value=number
            elif value!=number:
                break
        else:
            return order
    return None

h={"W":(0,4,"write",1),"R1":(1,2,"read",0),"R2":(5,6,"read",1)}
print(valid(h))
h["W"]=(0,.5,"write",1)
print(valid(h))
nodes=range(5)
for w in (3,2):
    print(min(len(set(r)&set(s)) for r in combinations(nodes,3)
              for s in combinations(nodes,w)))
print(max(1,3)+1)

한눈에 정리

핵심어기억할 기준
선형화 가능성각 연산을 시작과 응답 사이 한 점에 놓아 순차 명세로 설명할 수 있어야 합니다. 끝난 연산은 뒤에 시작한 연산보다 앞입니다.
정족수 교집합|R∩W| ≥ R+W−N. R+W>N이면 반드시 겹칩니다(5개 중 3·3은 1개 이상).
겹침만으로는 부족버전 비교, 임기 번호, 로그 최신성 같은 규칙이 함께 있어야 최신 값을 고릅니다.
Lamport 시계a→b이면 C(a)<C(b). 역은 성립하지 않으며, 역까지 필요하면 벡터 시계를 씁니다.

한 줄 정리

실시간 순서, 정족수의 겹침, 논리적 인과는 서로 다른 성질이므로 각각 따로 검산합니다.
