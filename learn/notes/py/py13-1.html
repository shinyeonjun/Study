정수 범위와 실수 반올림을 계산 전에 확인하기

센서에서 온 정수 250과 20을 더했는데 배열에는 14가 남을 수 있습니다. 같은 수식도 어떤 칸에 저장하느냐에 따라 결과가 달라집니다. 저장 범위와 반올림을 손으로 예측한 뒤 검산합니다.

이 장을 읽고 나면

  • 비트 수에서 정수 범위를 구하고 넘침을 계산한다.
  • 변환을 연산 전후 중 어디에 두어야 하는지 결정한다.
  • 실수를 더하는 순서가 결과를 바꾸는 예를 설명하고 작은 표에서 독립적으로 검산한다.

정수 칸에 놓을 수 있는 256가지

한 자리의 비트에는 0과 1이 들어갑니다. 여덟 자리는 2⁸=256가지입니다. 부호를 쓰지 않는 uint8은 이 조합을 0부터 255까지에 배정합니다. 255까지 찬 계수기에 1을 더하면 8자리 바깥의 올림은 저장할 수 없습니다. 이런 범위 초과를 넘침(overflow)이라고 합니다.

어느 단계에서 자료형을 바꾸는가

a.astype(np.uint16) + b.astype(np.uint16)는 270이 들어가는 칸으로 입력을 옮겨 덧셈을 합니다. (a+b).astype(np.uint16)는 이미 14가 된 값을 옮깁니다. np.sum은 규칙이 다릅니다. 플랫폼 기본 정수보다 좁은 정수(uint8, int8 등)를 합할 때는 누적 자료형을 기본 정수(64비트 환경의 NumPy 2에서 uint64·int64)로 넓히므로 values.sum()은 270을 냅니다. 원소별 연산 a+b에는 이런 넓힘이 없습니다. 집계의 dtype도 명시할 수 있습니다. 넓힌 정수도 범위가 있으므로 최악의 합을 미리 따져야 합니다.

흔한 실수

배열 연산의 정수 넘침은 경고 없이 조용히 일어납니다. 스칼라 np.uint8(250)+np.uint8(20)은 RuntimeWarning: overflow encountered in scalar add를 내고 14를 돌려주지만, 같은 계산을 배열로 하면 아무 메시지도 없습니다. 또 NumPy 2에서는 Python 정수를 섞을 때 배열의 자료형을 유지하므로, np.uint8(250)+300처럼 Python 정수 자체가 범위 밖이면 OverflowError가 납니다. 경고가 없다는 사실을 정상의 증거로 쓰지 않습니다.

실수의 저장 간격과 덧셈 순서

float64는 실수를 유한한 비트로 근사합니다. 저장 간격은 크기에 따라 달라집니다. 1.0에서 바로 다음 큰 수까지는 2⁻⁵²입니다. 10¹⁶은 2⁵³과 2⁵⁴ 사이에 있으며 이 구간에서 이웃한 저장값의 간격은 2입니다. 따라서 10¹⁶+1은 정확히 두 칸의 중간이고, 일반적인 가장 가까운 짝수 쪽 반올림으로 10¹⁶에 저장됩니다. 뒤에서 10¹⁶을 빼면 1을 되찾을 수 없습니다.

계산 순서첫 계산의 저장값최종값
(10¹⁶ + 1) − 10¹⁶10¹⁶0
(10¹⁶ − 10¹⁶) + 101

실수에서 덧셈은 결합법칙이 성립하지만, 반올림을 끼운 부동소수점 계산에서는 괄호 위치가 결과에 영향을 줍니다. math.fsum은 부동소수점 입력의 합을 더 정밀하게 누적합니다. 이 예와 같이 입력을 정확히 표현할 수 있을 때 정확한 수학 결과와 확인하기 좋습니다. 파일을 읽을 때 이미 잃은 정밀도까지 복원하는 기능은 없습니다.

실행으로 확인하기

import math
import numpy as np

a = np.array([250], dtype=np.uint8)
b = np.array([20], dtype=np.uint8)
print(np.iinfo(a.dtype).max)
print((a + b).tolist(), (a + b).astype(np.uint16).tolist())
print((a.astype(np.uint16) + b.astype(np.uint16)).tolist())
values = np.array([250, 20], dtype=np.uint8)
print(int(values.sum(dtype=np.uint16)))

x = np.float64(10**16)
print(np.nextafter(x, np.inf) - x)
print((x + 1) - x, (x - x) + 1)
print(math.fsum([float(x), 1, -float(x)]))
assert int(a[0]) + int(b[0]) == 270

검산할 입력

높은 값과 낮은 값을 섞은 배열, 정수 한계 근처의 배열, 같은 정수 데이터를 Python int로 계산한 결과를 함께 확인합니다. 실수 근삿값을 비교할 때는 문제의 단위와 허용오차를 정한 뒤 검사합니다.
