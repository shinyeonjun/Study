최근 세 행과 최근 사흘을 구별해 시간 집계하기

하루에 한 번 기록할 예정이었어도 며칠 빠지면 최근 세 번의 측정이 최근 사흘에 들어오지 않습니다. 날짜를 정렬하고, 현재 행을 포함할지 결정해서 과거 정보만 보는 평균을 구합니다.

이 장을 읽고 나면

  • 행 개수와 달력 시간으로 정한 창을 구별한다.
  • 닫힌 끝점을 읽고 평균에 들어갈 날짜를 적는다.
  • 누락된 날짜와 현재 행을 보고서에 올바르게 처리한다.

창은 과거를 자르는 규칙이다

센서 하나에서 4월 1일에 10, 2일에 20, 4일에 8, 5일에 16을 관측했습니다. 하루 전 값이라는 질문과 직전 관측값이라는 질문은 다릅니다. 4일에 직전 관측은 2일의 20입니다. 3일에는 관측이 없습니다. 행 번호만 보면 2일과 4일 값이 나란히 붙어 있습니다.

기준일이전 세 행에 있는 날짜직전 사흘의 관측 날짜
4월 4일1일, 2일1일, 2일
4월 5일1일, 2일, 4일2일, 4일

이 예의 직전 사흘은 날짜 t에 대해 [t−3일, t)입니다. 왼쪽 끝은 들어가고 오른쪽 끝은 빠집니다. 5일에는 2일과 4일이 들어가지만, 1일은 너무 멀고 5일은 지금의 값이라 제외합니다. 날짜는 시간대가 없는 날짜형으로 통일하고 각 기록이 해당 날짜 00:00에 놓인 것으로 계산합니다.

정렬, 창의 크기, 현재 행의 위치

rolling("3D", closed="left", min_periods=1)에서 "3D"는 날짜 인덱스에 적용할 3일의 시간 길이입니다. closed="left"는 왼쪽 끝을 포함하고 오른쪽 끝을 제외합니다. min_periods=1이라 창에 유효 관측이 하나도 없으면 평균을 NaN으로 둡니다. 하루에 한 줄이 맞는 실험이라면 날짜 키의 중복을 검사하고, 여러 센서가 들어온 파일은 센서별로 분리해 각자의 시간 순서를 확인합니다.

shift(1).rolling(3, min_periods=1)은 입력값을 관측 위치 하나만큼 옮긴 뒤 세 행 이내에서 평균을 구합니다. 시간의 간격이 불규칙하면 날짜로 계산한 평균과 달라질 수 있습니다. 5일 기준 날짜 창의 평균은 (20+8)/2=14이고, 행 창의 평균은 (10+20+8)/3=38/3입니다.

실행으로 확인하기

import pandas as pd

times = pd.to_datetime(["2020-04-05", "2020-04-01", "2020-04-04", "2020-04-02"])
values = pd.Series([16, 10, 8, 20], index=times).sort_index()
if values.index.hasnans or not values.index.is_unique:
    raise ValueError("관측 날짜가 비었거나 중복되었습니다")

by_day = values.rolling("3D", closed="left", min_periods=1).mean()
by_row = values.shift(1).rolling(3, min_periods=1).mean()
for date, day, row in zip(values.index, by_day, by_row):
    print(f"{date:%m-%d} {day:.4f} {row:.4f}")
t = pd.Timestamp("2020-04-05")
inside = (values.index >= t - pd.Timedelta(days=3)) & (values.index < t)
print(values.index[inside].strftime("%m-%d").tolist())
assert by_day.loc[t] == values.loc[inside].mean()

여기서는 과거 관측이 모두 그때 사용 가능하다고 가정했습니다. 발표가 늦어지거나 개정되는 자료는 관측일과 별도로 공개 시각을 확인합니다. 공개 데이터 프로젝트에서는 분석용 CSV에 적힌 연도만큼 과거를 자르는 것과, 그때 발표된 숫자를 비교하는 것이 어떻게 다른지 다시 확인합니다.
