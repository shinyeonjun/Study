CSV와 JSON 주고받기

선생님이 반 성적을 엑셀에서 CSV 파일로 저장해 보내 주었습니다. 이 파일로 과목 평균을 내려면, 파일 속 글자를 표로 읽고, 숫자로 바꾸고, 빠진 칸을 찾아야 합니다. 이 장에서는 데이터를 주고받는 가장 흔한 두 형식인 CSV와 JSON을 Python으로 읽고 쓰고, 읽은 자료의 모양을 확인하는 법을 배웁니다.

이 장을 읽고 나면

  • CSV 파일의 구조(머리글, 행, 열, 구분자)를 설명할 수 있다.
  • csv 모듈로 CSV를 읽고 쓰며, 읽은 값이 모두 문자열이라는 점을 처리할 수 있다.
  • 읽은 자료의 행 수·열 이름·빈 칸을 확인하는 짧은 코드를 쓸 수 있다.
  • json 모듈로 딕셔너리·리스트를 JSON 파일로 저장하고 다시 읽을 수 있다.
  • CSV와 JSON 중 어느 것을 쓸지 자료의 모양을 보고 고를 수 있다.

CSV: 쉼표로 나눈 표

엑셀 표를 "CSV"로 저장한 뒤 메모장으로 열어 보면 칸 대신 쉼표가 보입니다. 이 장에서 계속 쓸 예제 파일입니다.

예제 파일 data\scores.csv

이름,반,국어,수학
민수,1,80,90
지아,2,95,85
하준,1,70,
서윤,2,88,92

직접 만들기: 실습 폴더(예: study\py07b) 안에 data 폴더를 만들고, 메모장에 위 다섯 줄을 그대로 붙여 넣은 뒤 "다른 이름으로 저장"에서 파일 이름 scores.csv, 인코딩 UTF-8로 저장합니다. 하준의 줄은 일부러 수학 점수를 비워 두었습니다(결석한 상황). 이 장의 코드는 모두 study\py07b에서 실행했고, 결과는 Windows 11, Python 3.14의 실제 출력입니다.

정의

CSV(Comma-Separated Values, 쉼표로 나눈 값)는 표를 글자로 적는 형식입니다. 한 줄이 표의 한 행이고, 줄 안에서 쉼표가 칸을 나눕니다. 칸을 나누는 글자를 구분자(delimiter)라고 합니다. 보통 첫 줄은 각 열의 이름을 적은 머리글(header)입니다.

CSV는 그냥 텍스트 파일이므로 앞 장에서 배운 대로 열고 한 줄씩 읽어서 쉼표로 자를 수 있습니다. 문자열의 split(",")은 쉼표 자리에서 잘라 리스트를 돌려줍니다.

파일 01_split.py

with open("data/scores.csv", encoding="utf-8") as f:
    for line in f:
        print(line.strip().split(","))

실행 결과

['이름', '반', '국어', '수학']
['민수', '1', '80', '90']
['지아', '2', '95', '85']
['하준', '1', '70', '']
['서윤', '2', '88', '92']

이 파일에서는 잘 됩니다. 하준의 빈 수학 칸은 빈 문자열 ''로 나왔습니다. 그런데 칸 안에 쉼표가 들어 있으면 이야기가 달라집니다. 주소 "서울, 중구"처럼요. CSV는 이럴 때 그 칸을 큰따옴표로 감싸 "서울, 중구"라고 적는 규칙이 있습니다. split은 이 규칙을 모릅니다.

파일 07_addr.py

import csv
rows = [["이름", "주소"], ["민수", "서울, 중구"], ["지아", "부산"]]
with open("addr.csv", "w", encoding="utf-8", newline="") as f:
    csv.writer(f).writerows(rows)

with open("addr.csv", encoding="utf-8") as f:
    print(f.read())

with open("addr.csv", encoding="utf-8") as f:
    for line in f:
        print(line.strip().split(","))

with open("addr.csv", encoding="utf-8", newline="") as f:
    for row in csv.reader(f):
        print(row)

민수,"서울, 중구"
지아,부산

['지아', '부산']
['이름', '주소']

파일에는 민수,"서울, 중구"로 적혔습니다(첫 출력). split은 따옴표 안의 쉼표에서도 잘라 칸이 3개가 되었습니다(둘째 출력). 아래에서 배울 csv.reader는 따옴표 규칙을 알아서 칸 2개로 바르게 읽었습니다(셋째 출력). 그래서 CSV는 split이 아니라 csv 모듈로 읽습니다.

csv 모듈로 읽기 이해하기

import csv는 Python에 딸려 오는 CSV 도구 묶음을 불러옵니다. csv.reader(f)는 열린 파일에서 한 행씩 칸 리스트를 꺼내 주고, list(...)로 감싸면 모든 행을 리스트 하나에 모읍니다.

파일 02_reader.py

print(len(rows))
header = rows[0]
body = rows[1:]
print(header)
print(body[0])
print(type(body[0][2]))

DictReader: 열 이름으로 꺼내기

row[2]의 2가 국어라는 것은 머리글을 보고 사람이 세어야 압니다. PY06·1에서 본 "자리 번호의 불편함"이 여기서도 나타납니다. csv.DictReader는 머리글을 키로 삼아 각 행을 딕셔너리로 만들어 줍니다.

파일 04_dictreader.py

import csv
with open("data/scores.csv", encoding="utf-8", newline="") as f:
    rows = list(csv.DictReader(f))
print(rows[0])
total = 0
for row in rows:
    total = total + int(row["국어"])
print(total, total / len(rows))

실행 결과

{'이름': '민수', '반': '1', '국어': '80', '수학': '90'}
333 83.25

풀이 예제

DictReader로 읽은 rows는 딕셔너리 4개의 리스트입니다(머리글은 키로 쓰였으므로 행으로 세지 않습니다). PY06·2 끝의 표에서 "표 전체 = 딕셔너리의 리스트"라고 한 바로 그 모양입니다. 국어 평균을 손으로 따라가 봅니다.

① 민수: int("80") = 80 → total = 0 + 80 = 80
② 지아: int("95") = 95 → total = 80 + 95 = 175
③ 하준: int("70") = 70 → total = 175 + 70 = 245
④ 서윤: int("88") = 88 → total = 245 + 88 = 333
⑤ 평균: 333 ÷ len(rows) = 333 ÷ 4 = 83.25

출력 333 83.25와 같습니다.

읽은 자료의 모양 확인하기

남이 준 파일을 읽으면 바로 계산하지 말고 먼저 모양을 봅니다. 앞 장에서 본 글자 깨짐, 방금 본 빈 칸, 칸 수가 다른 줄 같은 문제를 계산 전에 잡기 위해서입니다.

파일 06_shape.py

import csv
with open("data/scores.csv", encoding="utf-8", newline="") as f:
    rows = list(csv.reader(f))
header = rows[0]
body = rows[1:]
print("열 이름:", header)
print("행 수:", len(body), "열 수:", len(header))
for i in range(len(body)):
    row = body[i]
    line_no = i + 2
    if len(row) != len(header):
        print(line_no, "번째 줄 칸 수가 다름:", row)
    for j in range(len(header)):
        if row[j] == "":
            print(line_no, "번째 줄", header[j], "칸이 비었음")

line_no = i + 2인 까닭: body의 0번 행은 파일의 2번째 줄입니다(1번째 줄은 머리글). 그래서 i에 2를 더해야 메모장에서 보는 줄 번호와 맞습니다. 하준은 body[2], 곧 파일의 4번째 줄입니다.

CSV로 쓰기

계산 결과를 다시 CSV로 저장해 봅니다. 행을 딕셔너리로 가지고 있다면 csv.DictWriter가 편합니다. fieldnames에 열 이름과 순서를 주고, writeheader()로 머리글을, writerows(...)로 행들을 씁니다.

파일 09_dictwriter.py

import csv
result = [{"이름": "민수", "평균": 85.0}, {"이름": "지아", "평균": 90.0}]
with open("avg.csv", "w", encoding="utf-8", newline="") as f:
    w = csv.DictWriter(f, fieldnames=["이름", "평균"])
    w.writeheader()
    w.writerows(result)

with open("avg.csv", encoding="utf-8") as f:
    print(f.read())

실행 결과

이름,평균
민수,85.0
지아,90.0

숫자 85.0은 쓸 때 글자 "85.0"으로 바뀌어 적힙니다. 다시 읽으면 문자열 "85.0"이 됩니다. 리스트로 된 행이면 csv.writer(f).writerows(행들)을 씁니다(07_addr.py가 그 예).

흔한 실수

CSV를 쓸 때 newline=""을 빠뜨리는 것 (Windows). csv 모듈은 줄 끝에 스스로 \r\n을 붙이는데, 텍스트 모드는 앞 장에서 본 대로 \n을 또 \r\n으로 바꿉니다. 그래서 \r\r\n이 되어 버립니다.

JSON: 겹친 자료를 글자로 이해하기

CSV는 칸이 고정된 표에 맞습니다. 그런데 학생 한 명에게 과목별 점수(딕셔너리)와 동아리 목록(리스트)이 함께 있다면 표 한 장에 담기 어렵습니다. 이렇게 겹쳐 담긴 자료를 글자로 적는 형식이 JSON입니다. 빅데이터 노트에서 "반정형 데이터"의 대표로 나온 그 JSON입니다.

정의

JSON(JavaScript Object Notation)은 이름: 값 짝과 목록을 겹쳐 적을 수 있는 글자 형식입니다. 웹에서 프로그램끼리 자료를 주고받을 때 가장 널리 쓰입니다. 생김새는 Python의 딕셔너리·리스트와 거의 같지만 규칙이 더 엄격한 별개의 형식입니다. 문자열은 반드시 큰따옴표, 참·거짓은 true/false, 없음은 null입니다.

파일 10_json_dumps.py

import json
student = {"이름": "민수", "반": 1, "점수": {"국어": 80, "수학": 90},
           "동아리": ["바둑", "합창"], "전학생": False, "메모": None}
text = json.dumps(student, ensure_ascii=False, indent=2)
print(text)
print(type(text))
print(json.dumps({"이름": "민수"}))

파일로 저장하고 다시 읽기

파일에 바로 쓰고 읽을 때는 s가 없는 json.dump(객체, 파일)와 json.load(파일)을 씁니다. JSON 파일은 UTF-8로 쓰는 것이 표준 관례입니다.

파일 11_json_file.py

import json
student = {"이름": "민수", "반": 1, "점수": {"국어": 80, "수학": 90}, "동아리": ["바둑", "합창"]}
with open("student.json", "w", encoding="utf-8") as f:
    json.dump(student, f, ensure_ascii=False, indent=2)

with open("student.json", encoding="utf-8") as f:
    loaded = json.load(f)
print(loaded)
print(type(loaded))
print(loaded["점수"]["수학"])
print(loaded == student)

실행 결과

용어 메모리 속 객체를 파일에 적거나 네트워크로 보낼 수 있는 글자·바이트로 바꾸는 일을 직렬화(serialization), 되돌리는 일을 역직렬화라고 합니다. 줄 세워(직렬) 보낸다는 뜻입니다.

JSON은 겹친 구조와 숫자·참거짓 같은 형이 그대로 살아 돌아옵니다. loaded["점수"]["수학"]이 문자열 "90"이 아니라 숫자 90인 것이 CSV와 다른 점입니다. 단, 표에 적은 두 가지 예외는 실제로 확인해 둡니다.

파일 12_json_types.py

import json
before = {1: "하나", "점": (3, 5)}
after = json.loads(json.dumps(before, ensure_ascii=False))
print(before)
print(after)
print(before == after)
{1: '하나', '점': (3, 5)}
{'1': '하나', '점': [3, 5]}
False

정수 키 1이 문자열 "1"이 되었고, 튜플 (3, 5)가 리스트 [3, 5]가 되었습니다. json.loads는 JSON 문자열을 객체로 되돌리는 함수입니다(load + s). 저장했다 읽은 뒤 d[1]로 찾으면 KeyError가 나니, JSON에 넣을 딕셔너리의 키는 처음부터 문자열로 쓰는 것이 좋습니다.

흔한 실수

print(딕셔너리)의 출력을 JSON 파일로 저장하는 것. print가 보여 주는 {'이름': '민수'}는 Python의 표기라 작은따옴표를 쓰고 True/None을 그대로 씁니다. 이걸 파일에 써 두면 위 오류처럼 JSON으로 읽을 수 없습니다. JSON 파일은 반드시 json.dump로 만듭니다.

JSON의 모양 확인

JSON은 겹쳐 있어서, 받은 파일의 맨 바깥이 딕셔너리인지 리스트인지부터 확인하고 한 층씩 들어갑니다.

파일 15_json_shape.py

import json
with open("student.json", encoding="utf-8") as f:
    data = json.load(f)
print(type(data))
print(list(data.keys()))
for key, value in data.items():
    print(key, type(value))

이름 <class 'str'>
반 <class 'int'>
점수 <class 'dict'>

바깥은 딕셔너리, 키는 4개, "점수"는 다시 딕셔너리, "동아리"는 리스트입니다. 이 지도가 있어야 data["점수"]["국어"]나 data["동아리"][0] 같은 꺼내기를 틀리지 않습니다.

왜 그럴까?

CSV는 숫자를 숫자로 기억하지 못하는데도 왜 이렇게 널리 쓰일까요?

모범 답 보기

가장 단순하기 때문입니다. 메모장으로도 열리고, 엑셀·데이터베이스·통계 프로그램·어떤 프로그래밍 언어든 읽고 쓸 수 있으며, 같은 표를 담을 때 JSON처럼 줄마다 열 이름을 반복하지 않아 파일도 작습니다. 형 정보가 없는 대가로, 읽는 쪽이 "이 열은 정수"라고 정해서 바꿔 주고 빈 칸을 처리해야 합니다. 그래서 CSV를 읽은 뒤의 모양 확인과 형 변환이 데이터 분석의 첫 단계가 됩니다.

PY11에서 pandas로 표를 다룰 때, DA06에서 데이터 품질을 점검할 때, DB06에서 웹 API의 JSON 응답을 받을 때 이 장의 내용이 그대로 바탕이 됩니다.

한눈에 정리

주제핵심
CSV한 줄 = 한 행, 쉼표 = 구분자, 첫 줄 = 머리글. 칸 안의 쉼표는 큰따옴표로 감싼다
CSV 읽기open(..., encoding=..., newline="") + csv.reader(리스트) / csv.DictReader(딕셔너리). split은 따옴표를 모른다
CSV의 값모두 문자열. 계산 전에 int()/float(). 빈 칸 ''은 ValueError
CSV 쓰기csv.writer / DictWriter(fieldnames, writeheader). newline="" 빠뜨리면 Windows에서 빈 줄
모양 확인앞 몇 줄, 행 수, 열 이름, 줄마다 칸 수, 빈 칸, 자료형
JSON겹친 dict·list를 글자로. 큰따옴표, true/false/null. dump/load(파일), dumps/loads(문자열). 한글은 ensure_ascii=False
JSON 주의튜플 → 리스트, 정수 키 → 문자열 키. print 출력은 JSON이 아니다

한 줄 정리

평평한 표는 CSV(값이 모두 문자열이니 바꾸고 빈 칸을 확인), 겹친 자료는 JSON(형이 살아 돌아옴)으로 주고받고, 읽은 뒤에는 계산 전에 모양부터 확인한다.
