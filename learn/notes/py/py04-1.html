PY04·1

리스트와 인덱스·슬라이싱

한 반 학생 세 명의 점수 80, 90, 70을 변수에 담으려면 지금까지 배운 방법으로는 score1, score2, score3처럼 변수 세 개가 필요합니다. 학생이 300명이면 변수 300개를 만들어야 할까요? 이 장에서는 여러 값을 한 줄로 늘어놓아 한 이름으로 부르는 그릇인 리스트와, 그 안의 값을 번호로 꺼내는 법(인덱스), 여러 개를 한꺼번에 잘라 내는 법(슬라이싱)을 배웁니다.

이 장을 읽고 나면

  • 대괄호로 리스트를 만들고, len()으로 길이를 구할 수 있다.
  • 인덱스가 왜 0부터 시작하는지 설명하고, 양수·음수 인덱스로 원하는 값을 꺼낼 수 있다.
  • a[시작:끝] 슬라이싱의 결과를 손으로 미리 적을 수 있다(끝 번호는 포함하지 않는다).
  • IndexError가 왜 나는지 읽고 고칠 수 있다.
  • 문자열도 같은 방법으로 인덱스·슬라이싱이 된다는 것을 확인할 수 있다.

값 여러 개를 한 이름으로

PY01에서 변수는 "값을 가리키는 이름표"라고 했습니다. 점수가 세 개라면 이름표도 세 개 필요합니다.

score1 = 80
score2 = 90
score3 = 70

이 방식은 값이 늘어날 때마다 이름을 새로 지어야 하고, "모든 점수를 더하라" 같은 일을 시키려면 이름을 하나하나 다 적어야 합니다. 그래서 Python은 값을 순서대로 한 줄에 늘어놓은 묶음을 따로 제공합니다.

용어 리스트(list)는 "목록"이라는 뜻입니다. 리스트 안에 든 값 하나하나를 원소(element) 또는 항목이라고 부릅니다.

정의 · 리스트

리스트는 여러 값을 순서를 지켜 담는 Python의 자료형입니다. 대괄호 [ ] 안에 값을 쉼표로 구분해 적어 만듭니다. 리스트에 든 원소의 개수를 길이라고 하고, len(리스트)로 구합니다(len은 length, 길이의 줄임말).

scores = [80, 90, 70]
print(scores)
print(len(scores))

실행 결과

[80, 90, 70]
3

한 줄씩 읽어 봅시다.

  • scores = [80, 90, 70]: 80, 90, 70을 이 순서대로 담은 리스트를 만들고, 그 리스트에 scores라는 이름을 붙입니다. 이름은 하나, 들어 있는 값은 셋입니다.
  • print(scores): 리스트 전체를 출력합니다. 대괄호와 쉼표까지 그대로 보입니다.
  • len(scores): 원소가 몇 개인지 셉니다. 3입니다.

리스트에는 여러 종류의 값을 섞어 넣을 수 있고, 아무것도 없는 빈 리스트도 만들 수 있습니다.

item = ["라면", 1200, True]
print(item)
empty = []
print(empty, len(empty))

실행 결과

['라면', 1200, True]
[] 0

문자열 "라면", 정수 1200, 참·거짓 값 True가 한 리스트에 들어 있습니다. 출력할 때 문자열은 작은따옴표로 감싸 보여 줍니다. 빈 리스트 []의 길이는 0입니다. 실제로는 한 리스트에 같은 종류(예: 점수만)를 담는 경우가 대부분이고, 그래야 다루기도 쉽습니다.

값 바꾸기와 뒤에 붙이기

리스트는 만든 뒤에도 내용을 바꿀 수 있습니다. 두 번째 학생의 점수를 95로 고치고, 네 번째 학생의 점수 60을 맨 뒤에 붙여 봅시다. 대괄호 안의 숫자([1])가 무엇인지는 바로 다음 절에서 설명합니다.

scores = [80, 90, 70]
scores[1] = 95
print(scores)
scores.append(60)
print(scores)
print(len(scores))

실행 결과

[80, 95, 70]
[80, 95, 70, 60]
4
문법 scores.append(60)은 "scores의 append 기능을 60을 넣어 실행하라"로 읽습니다. 가운데 점(.)은 "~의"라는 뜻입니다. append는 영어로 "덧붙이다"입니다. 이렇게 어떤 값에 딸린 기능을 메서드(method)라고 부르는데, 자세한 것은 뒤에서 다룹니다. 지금은 "리스트 맨 뒤에 하나 붙이는 명령"으로만 기억하면 됩니다.

인덱스: 몇 번째 칸인가 외우기

리스트 안의 값 하나를 꺼내려면 위치 번호를 말해야 합니다. PY02·1에서 문자열의 글자를 꺼낼 때 쓴 번호, 곧 인덱스(index)를 리스트에도 똑같이 씁니다. 규칙도 같아서 1이 아니라 0부터 셉니다.

scores = [80, 90, 70]
print(scores[0])
print(scores[1])
print(scores[2])

실행 결과

80
90
70

scores[0]은 "scores의 0번 칸"이라고 읽습니다. 첫 번째 값 80이 0번, 두 번째 값 90이 1번, 세 번째 값 70이 2번입니다.

정의 · 인덱스

인덱스는 리스트의 각 칸에 붙은 위치 번호입니다. 맨 앞 칸이 0이고 오른쪽으로 갈 때마다 1씩 커집니다. 그래서 길이가 n인 리스트의 인덱스는 0부터 n − 1까지입니다. 리스트[i]는 "i번 칸의 값"을 뜻합니다.

왜 0부터 셀까

PY02·1에서 본 것처럼 인덱스는 "몇 번째"가 아니라 맨 앞에서 떨어진 거리(offset)입니다. 80은 맨 앞에서 0칸, 90은 1칸, 70은 2칸 떨어져 있으므로 인덱스가 0, 1, 2입니다. 그래서 길이가 n이면 마지막 인덱스는 n − 1입니다.

흔한 실수

"세 번째 값은 scores[3]"이라고 쓰는 실수. 세 번째 값은 맨 앞에서 2칸 떨어져 있으므로 scores[2]입니다. "k번째 값의 인덱스는 k − 1"이라고 바꿔 생각하세요. 이 하나 차이 실수는 반복문에서도 똑같이 생깁니다(PY04·3에서 다시 봅니다).

음수 인덱스: 뒤에서부터 세기

리스트의 마지막 값을 꺼내고 싶은데 길이를 모르면 어떻게 할까요? 앞의 방법이라면 scores[len(scores) - 1]처럼 길이에서 1을 빼야 합니다. Python은 더 간단한 방법을 줍니다. 음수 인덱스는 뒤에서부터 셉니다. 맨 끝이 -1, 그 앞이 -2입니다.

scores = [80, 90, 70]
print(scores[-1])
print(scores[-2])
print(scores[-3])

실행 결과

70
90
80

음수 인덱스는 0이 아니라 -1부터 시작한다는 점에 주의하세요. 0번은 이미 맨 앞 칸의 번호이기 때문입니다. 길이가 3인 리스트에서 같은 칸을 가리키는 두 번호는 다음과 같이 짝을 이룹니다.

풀이 예제 · 양수 인덱스를 음수로 바꾸기

길이 3인 리스트에서 인덱스 1과 같은 칸을 가리키는 음수 인덱스는?

① 음수 인덱스 = 양수 인덱스 − 길이
② 1 − 3 = −2
③ 확인: scores[1]과 scores[-2] 모두 90

거꾸로, 음수 인덱스에 길이를 더하면 양수 인덱스가 됩니다. −1 + 3 = 2이므로 scores[-1]은 scores[2]와 같은 칸입니다.

없는 칸을 부르면: IndexError

길이가 3인 리스트에 3번 칸은 없습니다(0, 1, 2까지만 있습니다). 없는 칸을 부르면 Python은 실행을 멈추고 오류를 냅니다. 아래는 practice.py라는 파일로 저장해 실행한 실제 결과입니다.

scores = [80, 90, 70]
print(scores[3])

실행 결과

Traceback (most recent call last):
  File "C:\Users\...\practice.py", line 2, in <module>
    print(scores[3])
          ~~~~~~^^^
IndexError: list index out of range

오류 메시지는 아래에서 위로 읽으면 쉽습니다.

  • 맨 아래 IndexError: list index out of range: 오류의 종류는 IndexError(인덱스 오류), 내용은 "리스트 인덱스가 범위를 벗어났다".
  • 그 위 ~~~~~~^^^: 문제가 된 부분을 밑줄로 가리킵니다. scores[3]의 [3] 쪽입니다.
  • line 2: 2번째 줄에서 났습니다.

음수 쪽도 마찬가지입니다. 길이 3인 리스트에서 scores[-4]는 맨 앞보다 더 앞이라 같은 IndexError가 납니다. 쓸 수 있는 인덱스는 -3부터 2까지입니다.

슬라이싱: 여러 칸을 한꺼번에 잘라 내기 이해하기

엿새 동안의 낮 기온을 리스트에 담았다고 합시다. 이 가운데 둘째 날부터 넷째 날까지만 보고 싶습니다. 하나씩 꺼내 다시 묶을 수도 있지만, Python은 연속된 여러 칸을 한 번에 잘라 새 리스트로 만드는 방법을 줍니다. 이것을 슬라이싱(slicing)이라고 합니다. PY02·1에서 잠깐 본 word[1:]가 바로 슬라이싱입니다.

temps = [12, 15, 17, 20, 18, 14]
print(temps[1:4])
print(temps[:3])
print(temps[3:])
print(temps[-2:])
print(temps[:])

실행 결과

[15, 17, 20]
[12, 15, 17]
[20, 18, 14]
[18, 14]
[12, 15, 17, 20, 18, 14]

정의 · 슬라이싱

리스트[시작:끝]은 인덱스 시작부터 끝 바로 앞까지의 원소를 담은 새 리스트입니다. 시작은 포함하고, 끝은 포함하지 않습니다. 0 ≤ 시작 ≤ 끝 ≤ 리스트 길이면 결과의 길이는 끝 − 시작입니다.

시작을 비우면 맨 앞부터, 끝을 비우면 맨 끝까지라는 뜻입니다. 둘 다 비운 [:]은 전체를 복사한 새 리스트입니다.

"끝은 포함하지 않는다"가 처음에는 이상하게 느껴집니다. 그림처럼 인덱스를 칸 자체가 아니라 칸 사이의 경계선에 붙은 번호로 보면 잘 보입니다. 경계선 1과 경계선 4 사이를 자르면 15, 17, 20 세 칸이 나옵니다.

풀이 예제 · temps[1:4]를 손으로 구하기

① 시작 = 1, 끝 = 4. 가져올 인덱스는 1, 2, 3 (4는 빼고)
② temps[1] = 15, temps[2] = 17, temps[3] = 20
③ 결과: [15, 17, 20]
④ 길이 확인: 끝 − 시작 = 4 − 1 = 3개 ✔

(나)와 (다)를 나란히 보세요. temps[:3]과 temps[3:]은 같은 경계 3에서 리스트를 둘로 나눈 앞쪽과 뒤쪽입니다. 둘을 이으면 원래 리스트가 됩니다. "끝을 포함하지 않는다"는 규칙 덕분에 이렇게 겹치지도 빠지지도 않게 나눌 수 있습니다. 앞에서 k개를 가져오려면 [:k], 처음 k개를 빼고 나머지를 가져오려면 [k:]라고 기억하면 편합니다.

temps[-2:]는 "끝에서 둘째 칸부터 끝까지", 곧 마지막 두 개 [18, 14]입니다. 음수 인덱스는 슬라이싱에서도 그대로 쓸 수 있습니다.

범위를 벗어난 슬라이싱과 빈 결과

인덱스 하나를 꺼낼 때와 달리, 슬라이싱은 범위를 벗어나도 오류가 나지 않습니다. 있는 데까지만 잘라 줍니다.

temps = [12, 15, 17, 20, 18, 14]
print(temps[4:10])
print(temps[3:3])
print(temps[4:1])
print(temps[0:6:2])
print(temps)

실행 결과

[18, 14]
[]
[]
[12, 17, 18]
[12, 15, 17, 20, 18, 14]
  • temps[4:10]: 10번 경계는 없지만 오류 없이 4번부터 끝까지 [18, 14]를 돌려줍니다.
  • temps[3:3]: 시작과 끝이 같으면 자를 칸이 없어 빈 리스트 []입니다. 길이 = 3 − 3 = 0과 맞습니다.
  • temps[4:1]: 시작이 끝보다 뒤에 있으면 역시 빈 리스트입니다.
  • temps[0:6:2]: 세 번째 숫자는 건너뛰는 간격입니다. 0부터 2칸씩 건너 0, 2, 4번 칸 → 12, 17, 18. 지금은 이런 것이 있다는 것만 알아 두세요.
  • 마지막 줄: 슬라이싱을 여러 번 했어도 원래 temps는 그대로입니다. 슬라이싱은 새 리스트를 만들 뿐 원래 것을 자르지 않습니다.

흔한 실수

"temps[1:4]는 1번부터 4번까지 네 개"라고 읽는 실수. 끝 번호 4는 포함하지 않으므로 1, 2, 3번 세 개입니다. 끝이 리스트 밖이면 실제 길이까지만 자릅니다. 예를 들어 원소가 6개인 temps[4:10]에는 두 개만 남고, temps[4:1]은 잘라 낼 구간이 없어 빈 리스트입니다. temps[4]는 4번 칸의 값 18 하나를 꺼냅니다.

문자열도 같은 방식으로

문자열도 글자가 순서대로 늘어선 것이라, PY02·1에서 쓴 인덱스뿐 아니라 이 장의 슬라이싱도 리스트와 똑같이 됩니다. 글자 하나하나가 한 칸입니다.

word = "python"
print(word[0], word[-1])
print(word[1:4])
print(len(word))

실행 결과

p n
yth
6

하지만 문자열은 리스트와 한 가지가 다릅니다. PY02·1에서 본 것처럼 한번 만든 문자열의 글자는 바꿀 수 없습니다.

word = "python"
word[0] = "P"

실행 결과

Traceback (most recent call last):
  File "C:\Users\...\practice.py", line 2, in <module>
    word[0] = "P"
    ~~~~^^^
TypeError: 'str' object does not support item assignment

메시지는 "str(문자열) 객체는 항목 대입을 지원하지 않는다"는 뜻입니다. 리스트 scores[1] = 95는 됐지만 문자열은 안 됩니다. 이런 "바꿀 수 있는가, 없는가"의 차이는 PY06 "자료를 담는 방법"에서 자세히 다룹니다.

들어 있는지 확인하기: in

리스트에 어떤 값이 들어 있는지는 in으로 묻습니다. 결과는 PY02에서 본 참·거짓 값입니다.

print(90 in [80, 90, 70])
print(60 in [80, 90, 70])

실행 결과

True
False

왜 그럴까?

인덱스 하나 temps[10]은 오류가 나는데, 슬라이싱 temps[4:10]은 오류 없이 [18, 14]를 돌려줍니다. 왜 이렇게 다르게 만들었을까요?

모범 답 보기

인덱스 하나는 "그 칸의 값 하나"를 달라는 요청이라, 칸이 없으면 돌려줄 값이 아예 없습니다. 아무 값이나 지어 줄 수 없으니 오류를 내는 것이 안전합니다. 슬라이싱은 "이 범위에 있는 것들을 모아 달라"는 요청이라, 범위의 일부만 있으면 있는 것만, 하나도 없으면 빈 리스트를 돌려주면 됩니다. 빈 리스트도 엄연한 리스트이므로 "돌려줄 것이 없다"는 상황이 생기지 않습니다.

이 내용이 다시 나오는 곳

  • 다음 장(PY04·2): 리스트의 값을 하나씩 차례로 꺼내 더하는 for 반복을 배웁니다. 인덱스 0, 1, 2를 차례로 만드는 range도 나옵니다.
  • PY04·3: "끝은 포함하지 않는다"에서 생기는 하나 차이 실수(off-by-one)를 반복문에서 다시 봅니다.
  • PY06·PY10: 튜플, 그리고 표 모양으로 숫자를 담는 NumPy 배열에서도 인덱스 0부터·끝 미포함 슬라이싱 규칙이 그대로 쓰입니다(같은 PY06의 사전은 번호가 아니라 이름(키)으로 꺼내므로 슬라이싱이 없습니다). 데이터 분석에서 "앞 5행만 보기" 같은 일도 슬라이싱으로 할 수 있습니다.

[a, b, c]값을 순서대로 담은 리스트원소 6개
len(x)원소의 개수(길이)6
x[i]i번 칸의 값. 인덱스는 0부터, 마지막은 길이 − 1temps[0] → 12, temps[5] → 14
x[-i]뒤에서 i번째. 맨 끝이 -1temps[-1] → 14
x[시작:끝]슬라이싱. 시작 포함, 끝 미포함. 범위를 벗어나면 있는 칸까지만 담는다.temps[1:4] → [15, 17, 20]
범위 밖 인덱스IndexError (슬라이싱은 오류 없이 있는 데까지)temps[6] → 오류
x.append(v), x[i] = v맨 뒤에 붙이기, i번 칸 바꾸기 (문자열은 바꿀 수 없음)

한 줄 정리

리스트는 값을 순서대로 담는 그릇이고, 칸 번호(인덱스)는 맨 앞에서 떨어진 거리라서 0부터 세며, 슬라이싱 [시작:끝]은 끝 칸을 빼고 잘라 낸다.
