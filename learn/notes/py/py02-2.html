PY02·2

입력과 형 변환

두 수를 키보드로 받아 더하는 프로그램을 만들었는데, 3과 4를 넣었더니 7이 아니라 34가 나왔습니다. 오류도 없이 틀린 답이 나온 것입니다. 이 장에서는 그 까닭인 "input()은 언제나 글자를 돌려준다"는 규칙과, 글자를 숫자로, 숫자를 글자로 바꾸는 형 변환을 실행해 보며 익힙니다.

이 장을 읽고 나면

  • input()이 무엇을 하고 어떤 자료형의 값을 돌려주는지 설명할 수 있다.
  • int(), float(), str()로 값의 자료형을 바꾸고, 그 결과를 미리 적을 수 있다.
  • 숫자로 바꿀 수 없는 글자를 넣었을 때 나는 ValueError를 읽고 원인을 말할 수 있다.
  • 문자열과 정수를 +로 이을 때 나는 TypeError를 세 가지 방법으로 고칠 수 있다.

키보드로 값 받기: input()

PY01의 프로그램은 값이 코드 안에 적혀 있었습니다. price = 1200이면 언제 실행해도 1200입니다. 실행할 때마다 사람이 값을 넣게 하려면 input()을 씁니다. U03에서 본 입력·처리·출력 가운데 "입력"을 코드로 쓰는 방법입니다.

name = input("이름을 입력하세요: ")
print(f"반갑습니다, {name}님")

실행 결과 (민지는 키보드로 친 것)

이름을 입력하세요: 민지
반갑습니다, 민지님

실행하면 이런 일이 차례로 일어납니다.

① 괄호 안의 글 "이름을 입력하세요: "를 화면에 보여 준다. 이 글을 안내문(prompt)이라고 한다. 줄을 바꾸지 않으므로 커서가 그 뒤에서 깜빡인다.
② 프로그램이 멈춰서 기다린다. 사람이 글자를 치고 Enter 키를 누를 때까지 다음 줄로 넘어가지 않는다.
③ Enter를 누르면, 친 글자들(Enter 자체는 빼고)을 문자열로 돌려준다. 여기서는 "민지".
④ 그 값이 =에 의해 변수 name에 담긴다.
⑤ 둘째 줄이 실행되어 f-문자열(PY02·1)로 인사말을 출력한다.

이 장의 실행 결과에서 안내문 뒤의 값은 키보드로 친 것입니다. 터미널이 입력을 화면에 되비춰(echo) 주므로 실제로 이 모양으로 보입니다.

3과 4를 넣었는데 34가 나온다

이제 처음 장면을 실제로 만들어 봅시다.

a = input("첫째 수: ")
b = input("둘째 수: ")
print(a + b)

실행 결과 (3과 4는 키보드로 친 것)

첫째 수: 3
둘째 수: 4
34

오류 없이 34가 나왔습니다. 무엇이 들어 있는지 type()으로 확인해 봅니다.

a = input("첫째 수: ")
print(type(a))
print(type(3))
print(type(3.5))

실행 결과 (3은 키보드로 친 것)

첫째 수: 3
<class 'str'>
<class 'int'>
<class 'float'>

키보드로 친 3은 정수 int가 아니라 문자열 str이었습니다. 그러니 a + b는 "3" + "4", 곧 PY02·1에서 본 문자열 잇기가 되어 "34"가 나온 것입니다.

정의

input()은 사람이 친 내용을 무엇을 쳤든 항상 문자열(str)로 돌려준다. 숫자처럼 보이는 3을 쳐도 결과는 글자 한 개짜리 문자열 "3"이다.

왜 그렇게 만들었을까요? 키보드로 들어오는 것은 원래 글자입니다. 사람이 "3"을 쳤을 때 그것이 개수인지, 우편번호의 일부인지, 전화번호 첫 자리인지 Python은 알 수 없습니다. 그래서 짐작하지 않고 받은 그대로 글자로 넘겨주고, 숫자로 쓸지는 프로그램을 쓰는 사람이 정하게 합니다.

자료형 바꾸기: int(), float(), str() 외우기

값의 자료형을 다른 자료형으로 바꾸는 것을 형 변환(type conversion)이라고 합니다. 자료형 이름과 같은 이름의 함수를 쓰면 됩니다. 34 문제를 고쳐 봅시다.

a = int(input("첫째 수: "))
b = int(input("둘째 수: "))
print(a + b)

실행 결과 (3과 4는 키보드로 친 것)

첫째 수: 3
둘째 수: 4
7

int(input("첫째 수: "))는 안쪽 괄호부터 실행됩니다. input(…)이 먼저 "3"을 돌려주고, 그 자리가 int("3")이 되어 정수 3이 됩니다.

세 함수가 하는 일을 한 번에 실행해 봅니다.

print(int("42"))
print(int("-7"))
print(int(" 42 "))
print(float("3.5"))
print(float("10"))
print(int(3.9))
print(int(-3.9))
print(float(2))
print(str(42) + "개")
print(type(str(42)))

실행 결과

42
-7
42
3.5
10.0
3
-3
2.0
42개
<class 'str'>
함수하는 일예
int(x)정수로 바꾼다. 글자는 정수 모양이어야 하고, 실수는 소수 부분을 버린다int("42") → 42, int(3.9) → 3
float(x)실수(소수점이 있는 수)로 바꾼다float("3.5") → 3.5, float(2) → 2.0
str(x)문자열로 바꾼다. 어떤 값이든 글자로 바꿀 수 있다str(42) → "42"

몇 가지를 더 짚어 둡니다.

  • int(" 42 ")처럼 앞뒤 빈칸은 무시하고 바꿔 줍니다. 사람이 실수로 빈칸을 친 경우를 봐주는 것입니다. 하지만 숫자 사이의 빈칸이나 쉼표는 봐주지 않습니다(다음 절).
  • float("10")은 10.0입니다. 실수는 값이 정수여도 .0을 붙여 보여 줍니다. 그래서 자료형이 실수라는 것을 출력만 보고도 알 수 있습니다.
  • int(3.9)는 4가 아니라 3입니다. int()는 반올림하지 않고 소수 부분을 잘라 버립니다. 음수에서는 int(-3.9)가 -4가 아니라 -3입니다. 둘 다 0 쪽으로 잘린다는 점이 같습니다.

흔한 실수

int()가 반올림한다고 생각하는 것. 3.9를 int()로 바꾸면 4가 아니라 3입니다. 반올림이 필요하면 따로 round()를 씁니다(round(3.9)는 4). 주의할 점: Python의 round()는 정확히 .5인 값을 가장 가까운 짝수 쪽으로 보냅니다(은행가 반올림). 실행하면 round(2.5)는 2, round(3.5)는 4, round(-2.5)는 -2입니다. 학교에서 배운 사사오입과 다릅니다.

바꿀 수 없는 글자: ValueError

나이를 받아 1을 더하는 프로그램이 있습니다.

age = int(input("나이: "))
print(age + 1)

20을 넣으면 21이 나옵니다. 그런데 사람이 늘 정수를 넣어 주지는 않습니다. 세 가지 입력을 넣어 실제로 실행해 봅니다.

실행 결과 ① 3.5를 넣었을 때

나이: 3.5
Traceback (most recent call last):
  File "C:\Users\...\age.py", line 1, in <module>
    age = int(input("나이: "))
          ~~~^^^^^^^^^^^^^^^^^
ValueError: invalid literal for int() with base 10: '3.5'

실행 결과 ② 스물을 넣었을 때 (마지막 줄만)

ValueError: invalid literal for int() with base 10: '스물'

실행 결과 ③ 아무것도 치지 않고 Enter만 눌렀을 때 (마지막 줄만)

ValueError: invalid literal for int() with base 10: ''

오류 메시지는 맨 아래 줄부터 읽습니다. 맨 아래 줄은 "오류의 종류: 설명"의 모양입니다.

  • ValueError: 값 오류. 자료형은 맞는데(int()에 문자열을 넣는 것 자체는 허용됨) 그 값이 쓸 수 없는 것일 때 납니다.
  • invalid literal for int() with base 10: "int()가 10진수로 읽을 수 없는 글자"라는 뜻입니다. base 10은 우리가 쓰는 10진법입니다.
  • '3.5': 문제가 된 값을 작은따옴표로 보여 줍니다. ③에서는 '', 곧 빈 문자열이 들어왔다는 것을 알 수 있습니다.

그 위의 줄들은 어디서 났는지 알려 줍니다. line 1은 파일의 1번째 줄, 그 아래는 그 줄의 코드, ~~~^^^^ 표시는 그 줄에서 문제가 된 부분입니다. 오류 메시지의 각 부분을 읽는 법은 다음 장(PY02·3)에서 그림으로 정리합니다.

float()도 같은 방식으로 실패합니다. float("abc")를 실행하면 마지막 줄이 ValueError: could not convert string to float: 'abc'("문자열을 실수로 바꿀 수 없다")입니다. 반면 float("3.5")는 되므로, 3.5를 받고 싶으면 int() 대신 float()를 쓰면 됩니다. 소수가 섞인 글자를 정수로 만들고 싶다면 int(float("3.5"))처럼 두 번 바꿉니다(결과 3).

흔한 실수

"오류가 났으니 코드가 틀렸다"고만 생각하는 것. 이 절의 코드는 20을 넣으면 잘 돌아갑니다. 같은 코드가 입력에 따라 성공하기도 하고 멈추기도 합니다. 그래서 프로그램을 확인할 때는 정상 입력 하나만 넣어 보지 말고, 소수·글자·빈 입력처럼 사람이 실수로 넣을 만한 값도 넣어 봐야 합니다. 잘못된 입력을 만났을 때 멈추지 않고 "다시 입력하세요"라고 묻게 만드는 방법(try/except, 입력 검증)은 PY08에서 배웁니다.

반대 방향: 숫자를 글 속에 넣기

이번에는 숫자를 문자열에 이으려는 경우입니다.

age = 20
print("나이: " + age)

실행 결과

Traceback (most recent call last):
  File "C:\Users\...\concat.py", line 2, in <module>
    print("나이: " + age)
          ~~~~~~~~~^~~~~
TypeError: can only concatenate str (not "int") to str

TypeError는 자료형 오류입니다. 값이 문제가 아니라 자료형의 조합이 그 연산에 맞지 않을 때 납니다. 설명은 "문자열에는 (int가 아니라) 문자열만 이을 수 있다"는 뜻입니다. ^ 표시가 + 기호 바로 아래에 있어서, 더하기(잇기)가 문제라는 것을 가리킵니다.

Python은 "나이: " + 20을 보고 "20을 글자로 바꿔 이으라는 건가, 아니면 앞의 글을 숫자로 바꿔 더하라는 건가"를 짐작하지 않습니다. 고치는 방법은 세 가지이고 결과는 같습니다.

age = 20
print("나이: " + str(age))
print(f"나이: {age}")
print("나이:", age)

실행 결과

나이: 20
나이: 20
나이: 20
  • 첫째 줄: str()로 직접 글자로 바꾼 뒤 잇습니다.
  • 둘째 줄: f-문자열이 알아서 글자로 바꿔 끼웁니다(PY02·1).
  • 셋째 줄: print에 쉼표로 값을 여러 개 넘기면 각각을 출력하면서 사이에 빈칸 하나를 넣습니다. 그래서 "나이:" 뒤에 빈칸을 쓰지 않았습니다.

시험 함정

* 는 문자열과 정수 사이에서도 오류가 나지 않습니다. "3" * 4는 TypeError가 아니라 3333입니다(문자열 반복, PY02·1). 그래서 다음 코드는 오류 없이 엉뚱한 답을 냅니다.

x = input("수: ")
print(x * 2)

5를 넣으면 10이 아니라 55가 나옵니다. +는 문자열과 정수를 섞으면 오류로 알려 주지만, *는 조용히 반복을 해 버립니다. 입력받은 값으로 계산할 때는 먼저 int()나 float()로 바꿨는지 확인하세요.

왜 그럴까?

"3" * 4는 되는데 "3" + 4는 오류가 납니다. Python이 둘을 다르게 대하는 까닭을 "짐작"이라는 낱말로 설명해 보세요.

모범 답 보기

"3" * 4는 뜻이 하나뿐입니다. 정수와 곱할 수 있는 것은 "문자열을 4번 반복"밖에 없으므로 짐작할 것이 없습니다. "3" + 4는 "잇기(34)"와 "더하기(7)" 두 가지로 읽힐 수 있어서, Python은 어느 쪽인지 짐작하지 않고 오류로 멈춥니다.

입력 → 변환 → 계산 → 출력 이해하기

지금까지 배운 것을 한 프로그램에 모읍니다. 올해 나이를 받아 내년 나이를 알려 줍니다.

age = int(input("올해 나이: "))
next_age = age + 1
print(f"내년에는 {next_age}살입니다.")

실행 결과 (27은 키보드로 친 것)

올해 나이: 27
내년에는 28살입니다.

풀이 예제

가격과 할인율(%)을 받아 낼 돈을 계산합니다. 12000과 15를 넣으면 무엇이 나올지 먼저 손으로 계산해 봅니다.

price = float(input("가격(원): "))
rate = float(input("할인율(%): "))
pay = price * (1 - rate / 100)
print(f"낼 돈: {pay}원")

① price ← float("12000") → 12000.0
② rate ← float("15") → 15.0
③ 괄호 안 나눗셈 먼저: rate / 100 = 15.0 / 100 = 0.15
④ 괄호 안 뺄셈: 1 - 0.15 = 0.85
⑤ 곱하기: 12000.0 × 0.85 = 10200.0
⑥ 출력: 낼 돈: 10200.0원

실행 결과 (12000과 15는 키보드로 친 것)

가격(원): 12000
할인율(%): 15
낼 돈: 10200.0원

float()로 받았으므로 결과도 실수라서 .0이 붙었습니다. 금액답게 보이려면 PY02·1의 모양 지정을 써서 f"{pay:,.0f}원"으로 출력합니다. ,는 세 자리 쉼표, .0f는 소수 0자리라는 뜻이고, 실행하면 10,200원이 나옵니다.

이 내용이 다시 나오는 곳

  • PY02·3: 이 장에서 만난 ValueError, TypeError를 SyntaxError, NameError와 함께 놓고 오류 메시지 읽는 법을 정리합니다.
  • PY03: 받은 점수·금액으로 조건을 따질 때, 형 변환을 빼먹으면 "90" >= 80 같은 비교에서 오류가 납니다.
  • PY07·데이터 분석: CSV 파일에서 읽은 값도 처음에는 모두 문자열입니다. "숫자 열이 글자로 읽혀 평균이 안 구해지는" 문제는 데이터 정리에서 가장 흔한 일 가운데 하나이고, 해결은 이 장의 형 변환입니다.
