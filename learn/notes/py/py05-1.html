PY05·1

함수 만들기: 매개변수와 반환값

지금까지 print(), len(), range()를 써 왔습니다. 괄호 안에 값을 넣으면 무언가를 해 주는 이 도구들을 함수라고 합니다. 이 장에서는 이런 도구를 직접 만드는 법을 배웁니다. 값을 넣는 자리(매개변수), 실제로 넣는 값(인자), 결과를 돌려주는 return, 그리고 자주 헷갈리는 "return과 print의 차이"를 실행 흐름 그림으로 따라갑니다.

이 장을 읽고 나면

  • def로 함수를 정의하고 호출할 수 있으며, 정의만으로는 아무것도 실행되지 않는다는 것을 설명할 수 있다.
  • 매개변수와 인자를 구분하고, 인자가 순서대로 매개변수에 들어가는 것을 그릴 수 있다.
  • 함수 호출이 실행 흐름을 함수 안으로 옮겼다가 반환값을 들고 돌아오는 과정을 따라갈 수 있다.
  • return과 print의 차이를 설명하고, None이 왜 나왔는지 찾아낼 수 있다.

코드 묶음에 이름 붙이기: def

여러 줄의 처리 순서를 한 번 적어 두고 이름을 붙인 뒤, 필요할 때마다 그 이름으로 부르는 것이 함수의 생각입니다.

용어 함수(function)라는 말은 수학에서 왔습니다. 수학의 함수는 "x를 넣으면 정해진 규칙으로 y가 하나 나오는 관계"입니다(AL04 함수에서 자세히). 프로그래밍의 함수는 이보다 넓어서, 값을 돌려주지 않고 화면에 출력만 하는 함수도 있습니다.
def greet():
    print("안녕하세요")

greet()
greet()

실행 결과

안녕하세요
안녕하세요

코드를 두 부분으로 나눠 읽습니다.

  • 1~2번 줄 (정의): def greet():는 "greet라는 이름의 함수를 정의한다(define)"로 읽습니다. def는 define의 줄임말입니다. 이름 뒤에 괄호 (), 줄 끝에 콜론 :, 그리고 들여쓴 몸통이 옵니다(for·if와 같은 규칙).
  • 4~5번 줄 (호출): greet()는 "greet를 실행하라"입니다. 이름 뒤에 괄호를 붙이면 그 함수의 몸통이 실행됩니다. 두 번 불렀으니 두 번 출력됩니다.

정의 · 함수, 정의, 호출

함수는 이름을 붙여 둔 코드 묶음입니다.
정의(definition): def 이름():과 몸통을 적어 함수를 만드는 것. 이때 몸통은 실행되지 않고 기억만 됩니다.
호출(call): 이름()으로 함수를 실행시키는 것. 호출할 때마다 몸통이 처음부터 끝까지 한 번 실행됩니다.

그래서 def만 있고 호출이 없는 코드는 실행해도 아무것도 출력하지 않습니다.

정의가 호출보다 먼저

Python은 위에서 아래로 한 줄씩 실행합니다. 아직 정의하지 않은 함수를 부르면 그런 이름이 없다는 오류가 납니다.

print(cube(2))

def cube(x):
    return x * x * x

실행 결과

    print(cube(2))
          ^^^^

1번 줄을 실행하는 순간에는 3번 줄의 정의를 아직 읽지 않았습니다. 그래서 함수 정의는 보통 파일 위쪽에 모아 두고, 실제로 부르는 코드는 그 아래에 둡니다.

값을 넣는 자리: 매개변수와 인자 외우기

greet()는 언제나 같은 인사만 합니다. 사람 이름을 넣어 인사를 바꾸고 싶다면, 함수에 값을 받을 자리를 만들어야 합니다.

def greet(name):
    print("안녕하세요,", name)

greet("가람")
greet("나래")

실행 결과

안녕하세요, 가람
안녕하세요, 나래

정의 · 매개변수와 인자

매개변수(parameter): 함수를 정의할 때 괄호 안에 적는 이름. 값이 들어올 빈자리입니다. 위에서는 name.
인자(argument): 함수를 호출할 때 괄호 안에 넣는 실제 값. 위에서는 "가람", "나래".
호출하면 인자가 매개변수에 대입된 뒤 몸통이 실행됩니다. greet("가람")은 몸통 앞에 name = "가람"이 있는 것처럼 동작합니다.

"매개(媒介)"는 둘 사이를 이어 준다는 뜻입니다. 매개변수는 바깥에서 들어온 값과 함수 몸통을 이어 주는 변수입니다. 교재에 따라 인자를 "인수", 매개변수를 "파라미터"라고도 씁니다. 말은 달라도 "정의 쪽 이름표 / 호출 쪽 실제 값"이라는 구분은 같습니다.

여러 개면 순서대로

매개변수는 쉼표로 여러 개 둘 수 있습니다. 인자는 적힌 순서대로 매개변수에 하나씩 들어갑니다. 낸 돈과 물건값을 받아 거스름돈을 계산하는 함수로 확인해 봅시다.

def change(paid, cost):
    return paid - cost

print(change(10000, 4900))
print(change(4900, 10000))
print(change(cost=4900, paid=10000))

실행 결과

5100
-5100
5100

(return은 다음 절에서 설명합니다. 지금은 "계산 결과를 내놓는다" 정도로 읽어 두세요.)

(나)처럼 순서를 바꿔 넣으면 Python은 오류 없이 엉뚱한 답 −5100을 냅니다. 순서가 헷갈릴 때는 셋째 줄처럼 cost=4900, paid=10000으로 이름을 붙여 넘길 수 있습니다. 이것을 키워드 인자라고 하며, 이름이 붙어 있으면 순서가 달라도 맞는 자리에 들어갑니다.

개수가 맞지 않으면

매개변수 수와 인자 수가 다르면 Python은 호출하는 순간 오류를 냅니다.

def square(x):
    return x * x

print(square())

"square()에 꼭 필요한 위치 인자 1개 'x'가 빠졌다"는 뜻입니다. 반대로 square(2, 3)처럼 너무 많이 넣으면 이렇게 나옵니다.

실행 결과

  File "C:\Users\...\practice.py", line 4, in <module>
    print(square(2, 3))
          ~~~~~~^^^^^^

"square()는 위치 인자 1개를 받는데 2개가 주어졌다". 두 메시지 모두 함수 이름과 개수를 알려 주므로, 정의(def 줄)의 매개변수 수와 호출의 인자 수를 맞춰 보면 됩니다.

결과를 돌려주기: return 이해하기

len([80, 90, 70])은 화면에 아무것도 찍지 않습니다. 대신 3이라는 값을 내놓아서 n = len(scores)처럼 변수에 담거나 len(scores) - 1처럼 계산에 쓸 수 있게 합니다. 우리가 만든 함수도 이렇게 값을 내놓게 하려면 return을 씁니다.

def square(x):
    return x * x

y = square(4)
print(y)
print(square(3) + square(4))

실행 결과

16
25

정의 · return과 반환값

return 식은 식의 값을 계산해 호출한 자리로 돌려보내고 함수를 끝냅니다. 돌려보낸 값을 반환값(return value)이라고 합니다. 호출식 square(4)는 실행이 끝나면 그 자리가 반환값 16으로 바뀐다고 생각하면 됩니다.

호출하면 실행 흐름이 함수로 건너갔다 돌아온다

함수를 호출하면 Python은 지금 읽던 줄에서 잠시 멈추고 함수 몸통으로 건너가 실행한 뒤, return을 만나면 반환값을 들고 멈췄던 자리로 돌아옵니다. 위 코드를 실행 순서대로 따라가 봅시다.

마지막 줄 print(square(3) + square(4))는 이 왕복을 두 번 합니다. square(3)이 9를 들고 돌아오고, square(4)가 16을 들고 돌아온 뒤, 그 자리에서 9 + 16 = 25를 계산해 출력합니다.

풀이 예제 · 호출식을 반환값으로 바꿔 가며 계산하기

print(square(3) + square(4))

① square(3) 호출: x = 3, return 3 * 3 = 9 → print(9 + square(4))
② square(4) 호출: x = 4, return 4 * 4 = 16 → print(9 + 16)
③ 덧셈: 9 + 16 = 25 → print(25)
④ 출력: 25

return과 print는 다르다 이해하기

화면에 결과가 보이니 return이나 print나 같다고 느끼기 쉽습니다. 둘을 나란히 놓고 실행해 봅시다.

def add_print(a, b):
    print(a + b)

def add_return(a, b):
    return a + b

r1 = add_print(2, 3)
r2 = add_return(2, 3)
print("r1 =", r1)
print("r2 =", r2)

실행 결과

5
r1 = None
r2 = 5

첫 줄의 5는 add_print 안의 print가 화면에 찍은 것입니다. 그런데 r1에는 5가 아니라 None이 들어 있습니다. 반대로 add_return은 화면에 아무것도 찍지 않았지만 r2에는 5가 들어 있습니다.

정의 · None

None은 "값이 없음"을 나타내는 Python의 특별한 값입니다. 함수가 return 없이 끝나거나, 값 없이 return만 쓰면 Python은 None을 돌려줍니다. 화면에 무언가를 찍는 것(print)은 반환이 아니므로, print만 하는 함수의 반환값은 None입니다.

None은 계산에 쓸 수 없습니다. print만 하는 함수의 결과를 계산에 쓰면 이렇게 됩니다.

def add_print(a, b):
    print(a + b)

double = add_print(2, 3) * 2

실행 결과

5
Traceback (most recent call last):
  File "C:\Users\...\practice.py", line 4, in <module>
    double = add_print(2, 3) * 2
             ~~~~~~~~~~~~~~~~^~~
TypeError: unsupported operand type(s) for *: 'NoneType' and 'int'

"*(곱하기)는 NoneType(None의 자료형)과 int(정수) 사이에 쓸 수 없다". 5가 화면에 찍혀 있어서 "5 × 2를 했는데 왜?"라고 생각하기 쉽지만, 곱하기에 실제로 들어간 값은 None이었습니다.

흔한 실수 · return을 빠뜨리기

def square(x):
    x * x

print(square(4))

실행 결과

None

몸통에서 x * x를 계산은 했지만 그 값을 어디에도 보내지 않고 버렸습니다. return이 없으니 반환값은 None입니다. 오류 없이 None만 나온다면 가장 먼저 return이 빠졌는지 보세요.

print(값)return 값
값을 보내는 곳화면 (사람)함수를 호출한 자리 (코드)
변수에 담기·계산에 쓰기안 됨 (반환값은 None)됨
함수가 끝나는가아니오, 다음 줄 계속예, 즉시 끝남
언제 쓰나사람에게 결과를 보여 줄 때결과를 다른 코드가 이어서 쓸 때

일반적으로 계산하는 함수는 return으로 값을 돌려주고, 출력은 그 값을 받은 쪽에서 한 번에 하는 것이 좋습니다. 그래야 같은 함수를 출력에도, 다른 계산에도 쓸 수 있습니다.

return은 함수를 끝낸다

return을 만나면 함수는 그 자리에서 끝납니다. 그 아래에 줄이 남아 있어도 실행되지 않습니다. 이 성질을 이용하면 PY03의 if와 함께 "조건에 따라 다른 값을 돌려주기"를 깔끔하게 쓸 수 있습니다.

def sign(n):
    if n > 0:
        return "양수"
    elif n < 0:
        return "음수"
    return "0"
    print("여기는 실행되지 않는다")

print(sign(5))
print(sign(-2))
print(sign(0))

실행 결과

양수
음수
0

sign(5): 5 > 0 참 → "양수"를 돌려주고 끝 (아래 줄은 보지 않음)
sign(-2): 첫 조건 거짓, -2 < 0 참 → "음수"를 돌려주고 끝
sign(0): 두 조건 모두 거짓 → if 아래의 return "0"에 닿아 "0"을 돌려주고 끝

어떤 경우든 return에서 끝나므로 print("여기는 실행되지 않는다")는 한 번도 실행되지 않습니다. 이렇게 절대 실행될 수 없는 줄은 실수로 남은 것이니 지웁니다.

괄호를 빼먹으면

함수 이름 뒤에 괄호가 없으면 호출이 아닙니다. 함수 자체를 가리킬 뿐입니다.

def square(x):
    return x * x

print(square)
print(square(5))

실행 결과

<function square at 0x000001CA7F8B7320>
25

첫 줄은 "square라는 함수가 메모리의 이 위치에 있다"는 설명입니다. 0x로 시작하는 숫자는 실행할 때마다 다르게 나옵니다. 계산 결과 대신 이런 글자가 보이면 괄호를 빠뜨린 것입니다.

왜 그럴까?

print()도 함수입니다. 그렇다면 x = print("안녕")을 실행한 뒤 x에는 무엇이 들어 있을까요? 이 장의 내용으로 예측해 보세요.

모범 답 보기

None입니다. print 함수는 받은 값을 화면에 찍는 일을 하고, 따로 돌려주는 값이 없기 때문에 반환값이 None입니다. 그래서 화면에는 "안녕"이 찍히고 x에는 None이 들어갑니다. 우리가 만든 add_print와 똑같은 구조입니다. 반면 len()은 길이를 돌려주는 함수라 n = len("안녕")을 하면 n에 2가 들어갑니다.

이 내용이 다시 나오는 곳

  • 다음 장(PY05·2): 매개변수와 함수 안에서 만든 변수가 함수 밖에서는 보이지 않는 이유(지역변수)와, 큰 문제를 작은 함수 셋으로 나누는 법을 봅니다.
  • AL04 함수: 수학의 함수 f(x) = x²은 여기의 square(x)와 같은 모양입니다. square처럼 매개변수만으로 결과를 정하는 함수는 같은 x를 넣으면 늘 같은 값이 나온다는 성질도 같습니다(바깥 값이나 난수를 쓰는 Python 함수는 그렇지 않을 수 있습니다).
  • 데이터 분석(PY10 이후): 내장 함수 sum()이나 NumPy의 mean()처럼 이미 만들어진 함수를 매일 쓰게 됩니다. 인자를 넣고 반환값을 받는 구조는 똑같습니다.
