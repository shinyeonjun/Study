PY01·1

print와 변수

마트에서 라면 2개(개당 1,200원)와 우유 1개(2,500원)를 샀습니다. 계산기라면 숫자를 매번 다시 눌러야 하지만, 프로그램에서는 가격에 ramen, milk 같은 이름을 붙여 두고 몇 번이고 다시 씁니다. 이 장에서는 결과를 화면에 내보내는 print, 값에 이름을 붙이는 변수, 그리고 수학의 등호와 뜻이 다른 대입 기호 =의 뜻을 다룹니다.

이 장을 읽고 나면

  • print로 글자와 계산 결과를 내보내고, 따옴표가 있을 때와 없을 때 결과가 어떻게 다른지 말할 수 있다.
  • 코드와 실행 결과를 구분해서 읽고, 결과를 미리 적어 볼 수 있다.
  • 변수를 "값에 붙인 이름"으로 설명하고, 여러 줄을 지나며 값이 어떻게 바뀌는지 따라갈 수 있다.
  • =(넣기)와 ==(같은지 묻기)를 구분할 수 있다.
  • 쓸 수 있는 변수 이름과 쓸 수 없는 이름을 가려낼 수 있다.

이 장의 코드는 U05·2에서 만든 python-study 폴더에 .py 파일로 저장해 python 파일이름.py로 실행하거나, 대화형 실행(>>>)에 쳐서 따라 할 수 있습니다. 모든 결과는 Python 3.14.6에서 실제로 실행한 것입니다.

첫 줄: print

print는 괄호 안에 넣은 것을 화면에 내보내라는 명령입니다. U03에서 배운 입력·처리·출력 가운데 출력을 맡습니다. 여러 가지를 넣어 실행해 봅시다.

코드 (p1.py)

print("안녕하세요")
print(7)
print(3 + 4)
print("3 + 4")
print("합계:", 3 + 4)
print()
print("가", "나", "다")
print("끝")

실행 결과

안녕하세요
7
7
3 + 4
합계: 7

가 나 다
끝
용어 print(…)처럼 이름 뒤에 괄호를 붙여 일을 시키는 것을 함수 호출이라고 합니다. print는 Python에 처음부터 들어 있는 함수입니다. 함수를 직접 만드는 법은 PY05에서 배웁니다.

한 줄씩 짚어 봅니다.

  • print("안녕하세요"): 큰따옴표로 감싼 글자를 글자 그대로 내보냅니다. 화면에 따옴표는 나오지 않습니다.
  • print(7): 숫자는 따옴표 없이 씁니다.
  • print(3 + 4)와 print("3 + 4"): 따옴표가 없으면 계산한 값 7을, 있으면 글자 3 + 4를 그대로 내보냅니다. 아래 그림에서 다시 봅니다.
  • print("합계:", 3 + 4): 괄호 안에 쉼표(,)로 여러 개를 넣으면, 빈칸 하나를 사이에 두고 한 줄에 이어서 내보냅니다.
  • print(): 괄호 안이 비면 빈 줄 하나를 내보냅니다.
  • print 하나가 끝나면 다음 출력은 새 줄에서 시작합니다. 그래서 결과가 줄마다 나뉘었습니다.

정의 외우기

print: 괄호 안의 값을 화면에 내보내는 함수. 쉼표로 여러 값을 넣으면 빈칸으로 이어 한 줄에 내보낸다.
문자열(string): 따옴표로 감싼 글자들. "안녕하세요", "3 + 4"처럼 씁니다. 큰따옴표 "…"와 작은따옴표 '…' 둘 다 되지만, 여는 것과 닫는 것이 같아야 합니다.

문자열은 다음 장(PY01·2)에서 값의 한 종류로 다시 보고, PY02에서 자세히 다룹니다.

코드와 결과를 구분하기 이해하기

프로그래밍 책을 읽을 때 가장 먼저 익힐 습관은 "이것은 내가 쓰는 코드인가, Python이 보여 준 결과인가"를 늘 가르는 것입니다. 이 책은 두 가지를 항상 따로 적습니다.

  • 코드 칸: 파일에 적거나 >>> 뒤에 치는 글자. 이름표에 파일 이름을 함께 적습니다.
  • 실행 결과 칸: 코드를 실행했을 때 화면에 나온 글자. 이 칸의 글자는 치는 것이 아닙니다.
  • 대화형 실행 칸: >>> 뒤가 코드, >>>이 없는 줄이 결과입니다.

대화형 실행에서는 한 가지가 더 헷갈립니다. 문자열을 print 없이 치면 따옴표가 붙은 채로 보입니다.

대화형 실행 (실제 결과)

>>> "안녕"
'안녕'
>>> print("안녕")
안녕

대화형 실행이 자동으로 보여 주는 것은 "이 값은 문자열이다"를 알 수 있게 코드처럼 적은 모양(작은따옴표 포함)이고, print가 내보내는 것은 사람이 읽을 내용(따옴표 없음)입니다. 그래서 결과에 따옴표가 보이면 "아, 대화형 실행이 값을 그대로 보여 준 것이구나"라고 읽으면 됩니다. 파일로 실행하는 프로그램에서는 print의 모양만 보입니다.

흔한 실수

결과를 코드로 옮겨 치기. 책의 결과 칸에 있는 합계: 7을 파일에 적으면 Python은 그것을 코드로 읽으려다 오류를 냅니다. 반대로, 결과를 미리 예상해 보는 연습은 아주 좋은 공부입니다. 코드 칸만 보고 결과를 종이에 먼저 적은 뒤, 실행해서 맞춰 보세요. 이 책의 확인 문제도 대부분 그런 모양입니다.

변수: 값에 붙이는 이름

라면 2개와 우유 1개 값을 계산하는 프로그램을 써 봅시다.

코드 (receipt.py)

ramen = 1200
milk = 2500
total = ramen * 2 + milk
print("라면 2개, 우유 1개")
print("합계:", total, "원")

실행 결과

라면 2개, 우유 1개
합계: 4900 원

ramen = 1200은 "값 1200에 ramen이라는 이름을 붙여라"라는 뜻입니다. 그다음부터 코드에 ramen이라고 쓰면 Python은 그 자리에 1200을 넣어 계산합니다. 셋째 줄은 1200 * 2 + 2500, 곧 2400 + 2500 = 4900을 계산해 그 값에 total이라는 이름을 붙입니다(*는 곱하기이고, 곱하기를 더하기보다 먼저 합니다. PY01·3에서 자세히).

정의 외우기

변수(variable): 값에 붙인 이름. 이름을 쓰면 그 이름이 가리키는 값이 그 자리에 쓰입니다.
대입(assignment): 이름 = 식 꼴의 문장. 오른쪽을 먼저 계산하고, 그 결과 값에 왼쪽 이름을 붙입니다. 같은 이름에 다시 대입하면 이름이 새 값으로 옮겨 붙습니다.

더 알아보기 · "상자" 비유와 "이름표" 비유

많은 책이 변수를 "값을 담는 상자"에 빗댑니다. 처음에는 그렇게 생각해도 계산 결과는 같습니다. 다만 Python에서 실제로 일어나는 일에 더 가까운 것은 값에 이름표를 붙인다는 그림입니다. 뒤에서 볼 b = a는 값을 복사해 새 상자에 넣는 것이 아니라 같은 값에 이름표를 하나 더 붙이는 것입니다. 숫자나 문자열만 다룰 때는 두 비유의 차이가 드러나지 않지만, 여러 값을 담는 목록을 다룰 때(PY06 "참조와 복사")는 이 차이가 결과를 바꿉니다. 그래서 이 책은 처음부터 이름표 그림을 씁니다.

이름은 계산 결과를 붙잡을 뿐, 따라 바뀌지 않는다

가격이 바뀌면 합계도 저절로 바뀔까요? 엑셀에서는 그렇지만 Python에서는 아닙니다. 실제로 실행해 봅니다.

코드 (p2.py, 왼쪽 숫자는 줄 번호)

1  price = 1200
2  count = 3
3  total = price * count
4  print(total)
5  price = 1500
6  print(total)
7  total = price * count
8  print(total)

실행 결과

3600
3600
4500

풀이 예제

p2.py를 한 줄씩 따라가며 이름이 가리키는 값을 적어 봅니다.

① 1번 줄: price → 1200
② 2번 줄: count → 3
③ 3번 줄: 오른쪽 price * count = 1200 × 3 = 3600 → total → 3600
④ 4번 줄: 3600 출력
⑤ 5번 줄: price → 1500 (price 이름표만 옮겨 붙는다. total은 건드리지 않는다)
⑥ 6번 줄: total은 여전히 3600 → 3600 출력
⑦ 7번 줄: 오른쪽 price * count = 1500 × 3 = 4500 → total → 4500
⑧ 8번 줄: 4500 출력

③에서 total이 붙잡은 것은 "price × count라는 규칙"이 아니라 그 순간 계산한 값 3600입니다. 합계를 새 가격으로 바꾸고 싶으면 ⑦처럼 다시 계산해서 다시 대입해야 합니다.

= 는 "같다"가 아니다

수학에서 x = x + 5는 해가 없는 방정식입니다. 수학의 등호는 양쪽이 같다는 사실을 말하기 때문입니다. Python의 =는 사실을 말하는 기호가 아니라 "오른쪽을 계산해서 왼쪽 이름을 거기에 붙여라"라는 명령입니다.

코드

score = 10
score = score + 5
print(score)

실행 결과

15

이 모양은 아주 자주 씁니다. "점수에 5점 더하기", "포인트 100 쌓기"(U05·3의 points = points + 100), "개수 하나 늘리기"가 모두 이름 = 이름 + 값 꼴입니다. 반복을 배우는 PY04에서 누적값을 구할 때 핵심이 됩니다.

"같은가?"를 묻는 기호는 ==

Python에서 "두 값이 같은가?"를 물을 때는 등호를 두 개 붙인 ==를 씁니다. 답은 참이면 True, 거짓이면 False입니다.

코드

x = 5
print(x == 5)
print(x == 6)
print(x)

실행 결과

True
False
5

x == 6은 x를 6으로 바꾸지 않습니다. 묻기만 하므로, 마지막 줄의 x는 여전히 5입니다. True와 False는 다음 장에서 값의 한 종류로 보고, 비교 기호는 PY02에서 자세히 다룹니다.

기호읽는 법하는 일예결과
="넣어라", "붙여라"오른쪽 값에 왼쪽 이름을 붙인다 (대입)x = 5화면에는 아무것도 안 나옴
=="같은가?"두 값이 같은지 묻는다 (비교)x == 5True 또는 False

두 기호를 바꿔 쓰면 Python이 알려 주기도 합니다. 숫자에 이름을 붙이려고 5 = x라고 거꾸로 쓴 실제 결과입니다.

실행 결과 (파일 첫 줄이 5 = x일 때, 경로 줄임)

  File "C:\Users\me\Documents\python-study\one.py", line 1
    5 = x
    ^
SyntaxError: cannot assign to literal here. Maybe you meant '==' instead of '='?

"여기서는 값(literal, 코드에 직접 적은 값)에 대입할 수 없다. = 대신 == 를 쓰려던 것 아닌가?" 대입의 왼쪽에는 이름이 와야 하고, 5 같은 값은 올 수 없습니다.

이름표 두 개가 같은 값을 가리킬 때

코드

a = 5
b = a
a = 7
print(a, b)

실행 결과

7 5

b = a의 오른쪽 a는 그 순간 5입니다. 그래서 b는 5를 가리킵니다. b가 "a라는 이름 자체"에 묶이는 것이 아닙니다. 앞의 total과 price 예와 같은 원리입니다.

흔한 실수

=를 "같다"로 읽기. total = price * count를 "total은 언제나 price × count와 같다"로 읽으면 p2.py의 6번 줄 결과(3600)를 틀리게 예상합니다. 읽을 때부터 "price × count를 계산해서, 그 값에 total을 붙여라"라고 소리 내어 읽는 습관을 들이세요. "같은가?"는 ==뿐입니다.

왜 그럴까?

엑셀에서는 B1 칸에 =A1*3을 적어 두면 A1을 바꿀 때 B1이 저절로 바뀝니다. Python의 total = price * count는 왜 그렇지 않을까요?

모범 답 보기

엑셀 칸에 적은 것은 "이렇게 계산하라"는 식 자체가 칸에 남아서, 재료가 바뀔 때마다 다시 계산됩니다. Python의 대입은 그 줄을 실행하는 순간 한 번 계산하고, 나온 값에 이름을 붙이고 끝납니다. 식은 남지 않습니다. 그래서 재료가 바뀌면 계산하는 줄을 다시 실행해야 합니다. 프로그램은 위에서 아래로 한 줄씩 실행된다는 U05·2의 규칙과 같은 이야기입니다.

이름 짓는 규칙

변수 이름에는 지켜야 할 규칙(어기면 오류)과 지키면 좋은 습관이 있습니다.

지켜야 할 규칙 외우기

  • 글자, 숫자, 밑줄(_)만 씁니다. 빈칸이나 -, ! 같은 기호는 쓸 수 없습니다.
  • 숫자로 시작할 수 없습니다. price2는 되지만 2price는 안 됩니다.
  • 대문자와 소문자를 다른 글자로 봅니다. price와 Price는 다른 이름입니다.
  • if, for, True 같은 Python의 예약어(문법에 쓰려고 정해 둔 낱말)는 이름으로 쓸 수 없습니다.

어기면 실제로 이런 오류가 납니다.

코드실제 오류의 마지막 줄까닭
2nd = 5SyntaxError: invalid decimal literal숫자로 시작하면 Python은 숫자를 쓰다 만 것으로 읽는다
my price = 1SyntaxError: invalid syntax빈칸 때문에 이름 두 개가 나란히 있는 꼴이 된다
if = 3SyntaxError: invalid syntaxif는 예약어(PY03의 조건문)
price = 1200 다음 줄에 print(Price)NameError: name 'Price' is not defined. Did you mean: 'price'?대문자 P는 다른 이름이다

지키면 좋은 습관

  • 뜻이 드러나는 이름을 씁니다. a, x보다 price, count가 한 달 뒤의 나에게 친절합니다.
  • 낱말 두 개는 밑줄로 잇습니다: total_price, is_member. Python에서 널리 쓰는 방식입니다.
  • Python은 한글 이름(가격 = 1200)도 받아 주지만, 다른 사람과 코드를 나누거나 라이브러리 예제와 섞어 쓰기 좋게 영어 소문자 이름을 권합니다.
  • print처럼 이미 쓰이는 이름을 변수로 쓰지 않습니다. print = 3은 오류 없이 실행되지만, 그 뒤로는 print("안녕")이 TypeError: 'int' object is not callable("숫자는 함수처럼 부를 수 없다")을 냅니다. print라는 이름표를 3에 옮겨 붙여 버렸기 때문입니다.

다음에 이어지는 곳

  • PY01·2: 이름이 가리키는 값에는 종류(정수, 실수, 문자열, 참·거짓)가 있습니다. type()으로 종류를 확인합니다.
  • PY01·3: + - * /와 // % **로 계산합니다.
  • PY02: 문자열, 입력받기, 비교(==, <)를 자세히 다룹니다.
  • PY04: total = total + x 꼴의 대입으로 반복하며 값을 쌓습니다.
