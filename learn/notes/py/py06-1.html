PY06·1

딕셔너리·집합·튜플

가게 가격표에서 "우유는 얼마지?"를 찾을 때, 우리는 "세 번째 줄"을 떠올리지 않고 "우유"라는 이름을 찾습니다. PY04에서 배운 리스트는 자리 번호로 찾는 상자였습니다. 이 장에서는 이름표로 찾는 딕셔너리, 같은 것이 두 번 들어가지 않는 집합, 한번 만들면 바꾸지 않는 튜플을 차례로 배웁니다.

이 장을 읽고 나면

  • 딕셔너리를 만들고, 키로 값을 꺼내고, 값을 더하거나 고칠 수 있다.
  • 딕셔너리로 개수 세기 코드를 한 줄씩 따라가며 결과를 손으로 계산할 수 있다.
  • 집합으로 중복을 없애고, 합집합·교집합·차집합의 결과를 맞힐 수 있다.
  • 튜플을 만들고 풀어 담을 수 있으며, 튜플을 고치려 할 때 나는 오류를 설명할 수 있다.
  • 리스트·튜플·집합·딕셔너리의 차이를 표로 정리할 수 있다.

자리 번호로 찾기의 불편함

PY04의 리스트는 정수 인덱스로만 값을 꺼냅니다. 가격을 리스트로 담으면:

price_list = [1200, 2500, 3000]   # 라면, 우유, 빵 순서라고 "기억"해야 한다
print(price_list[1])              # 우유 가격

"1번 = 우유"라는 대응은 코드에 없고 사람이 기억해야 하며, 항목을 하나 지우면 뒤의 인덱스가 모두 바뀝니다. 필요한 것은 이름(키)에서 값으로 가는 대응, 곧 사상(mapping)을 직접 저장하는 자료구조입니다.

딕셔너리: 이름표로 찾는 상자 이해하기

정의

딕셔너리(dictionary, dict)는 키(key)와 값(value)을 짝지어 담는 상자입니다. 키는 이름표, 값은 그 이름표가 붙은 내용입니다. 키를 주면 그 짝인 값을 돌려줍니다. 한 딕셔너리 안에서 같은 키는 하나만 있을 수 있습니다.

쓰는 법: 중괄호 { } 안에 키: 값을 쉼표로 나눠 적습니다. 꺼낼 때는 딕셔너리[키]처럼 대괄호 안에 키를 넣습니다.

용어 영어 dictionary는 "사전"입니다. 사전에서 낱말(키)을 찾으면 뜻(값)이 나오는 것과 같아서 붙은 이름입니다. 줄여서 dict라고 씁니다.

가격표를 딕셔너리로 만들고 이것저것 해 봅시다. 이 장의 실행 결과는 모두 Windows 11, Python 3.14에서 python 파일이름.py로 실제 실행한 출력입니다.

파일 01_price.py

price = {"라면": 1200, "우유": 2500, "빵": 3000}
print(price)
print(price["우유"])
price["계란"] = 6000
price["라면"] = 1300
print(price)
print(len(price))
print("빵" in price, "김밥" in price)
print(price.get("김밥"))
print(price.get("김밥", 0))

흔한 실수

딕셔너리에 자리 번호를 쓰는 것. 리스트 습관대로 price[0]이라고 쓰면 "첫 번째 상품"이 나오지 않습니다. 딕셔너리는 대괄호 안의 것을 항상 키로 읽기 때문에, 키 0을 찾다가 없어서 오류가 납니다.

모든 짝을 차례로 보기

딕셔너리를 for로 돌 때는 .items()를 붙이면 키와 값을 한 번에 받을 수 있습니다. .keys()는 키만, .values()는 값만 줍니다. 아무것도 붙이지 않고 for k in price:처럼 딕셔너리를 그대로 돌면 키가 하나씩 나옵니다(.keys()를 돈 것과 같음). del은 짝 하나를 지웁니다.

파일 03_items.py

price = {"라면": 1300, "우유": 2500, "빵": 3000}
for name, won in price.items():
    print(name, won)
print(list(price.keys()))
print(list(price.values()))
del price["빵"]
print(price)

실행 결과

우유 2500
빵 3000
['라면', '우유', '빵']
[1300, 2500, 3000]
{'라면': 1300, '우유': 2500}

for name, won in price.items():에서 반복할 때마다 짝 하나가 나오고, 그 짝의 앞쪽(키)이 name에, 뒤쪽(값)이 won에 담깁니다. 이렇게 두 이름에 나눠 담는 방법은 뒤의 튜플 절에서 다시 봅니다. 출력 순서를 보면 넣은 순서대로 나옵니다. Python 3.7부터 딕셔너리는 넣은 순서를 지키도록 정해졌습니다. 그래도 딕셔너리의 본업은 순서가 아니라 키로 찾기입니다.

풀이 예제: 투표 수 세기

딕셔너리가 가장 자주 쓰이는 일 중 하나가 개수 세기입니다. 점심 메뉴 투표 6장을 세어 봅시다. 키는 메뉴 이름, 값은 지금까지 센 표 수입니다.

파일 04_votes.py

votes = ["짜장", "짬뽕", "짜장", "볶음밥", "짜장", "짬뽕"]
count = {}
for menu in votes:
    if menu in count:
        count[menu] = count[menu] + 1
    else:
        count[menu] = 1
    print(menu, count)
print(count)

실행 결과

짜장 {'짜장': 1}
짬뽕 {'짜장': 1, '짬뽕': 1}
짜장 {'짜장': 2, '짬뽕': 1}
볶음밥 {'짜장': 2, '짬뽕': 1, '볶음밥': 1}
짜장 {'짜장': 3, '짬뽕': 1, '볶음밥': 1}
짬뽕 {'짜장': 3, '짬뽕': 2, '볶음밥': 1}
{'짜장': 3, '짬뽕': 2, '볶음밥': 1}

풀이 예제

count = {}는 빈 딕셔너리입니다. 반복 한 번마다 if menu in count로 "이 메뉴를 전에 센 적이 있나?"를 묻습니다.

① "짜장": count에 없음 → else → count["짜장"] = 1 → {짜장 1}
② "짬뽕": 없음 → count["짬뽕"] = 1 → {짜장 1, 짬뽕 1}
③ "짜장": 있음 → count["짜장"] = 1 + 1 = 2 → {짜장 2, 짬뽕 1}
④ "볶음밥": 없음 → count["볶음밥"] = 1 → {짜장 2, 짬뽕 1, 볶음밥 1}
⑤ "짜장": 있음 → 2 + 1 = 3 → {짜장 3, 짬뽕 1, 볶음밥 1}
⑥ "짬뽕": 있음 → 1 + 1 = 2 → {짜장 3, 짬뽕 2, 볶음밥 1}
⑦ 검산: 3 + 2 + 1 = 6 = 투표 수

⑦처럼 값의 합이 원래 개수와 같은지 보는 것이 세기 코드의 기본 검산입니다.

if/else 네 줄을 get으로 한 줄로 줄일 수도 있습니다. count.get(menu, 0)은 "센 적 있으면 지금까지 수, 없으면 0"이므로 거기에 1을 더하면 됩니다.

for menu in votes:
    count[menu] = count.get(menu, 0) + 1

이렇게 바꿔 실행해도 마지막 결과는 {'짜장': 3, '짬뽕': 2, '볶음밥': 1}로 같습니다.

집합: 겹치지 않는 모음 이해하기

도서관 출입 기록에 이름이 "민수, 지아, 민수, 하준, 지아, 민수" 순서로 찍혔습니다. "오늘 온 사람은 몇 명인가?"라고 물으면 답은 6이 아니라 3입니다. 같은 사람을 한 번만 세야 하기 때문입니다. 이렇게 중복 없이 "있다/없다"만 따지는 상자가 집합입니다.

정의

집합(set)은 같은 값을 한 번만 담고, 순서가 없는 모음입니다. 수학의 집합과 같은 뜻입니다. 중괄호 { } 안에 값만(키: 값 짝이 아니라) 쉼표로 적거나, set(리스트)로 리스트를 집합으로 바꿉니다.

파일 05_set.py

visitors = ["민수", "지아", "민수", "하준", "지아", "민수"]
s = set(visitors)
print(s)
print(len(visitors), len(s))
s.add("서윤")
s.add("민수")
print(len(s))
print("하준" in s)

실행 결과

{'지아', '민수', '하준'}
6 3
4
True

리스트에는 6개가 있었지만 집합으로 바꾸니 3개가 남았습니다. add로 "서윤"을 넣자 4개가 되었고, 이미 있는 "민수"를 또 넣어도 그대로 4개입니다. 오류도 나지 않고 그냥 아무 일도 일어나지 않습니다.

집합에는 순서가 없다

위 결과에서 출력 순서가 넣은 순서(민수, 지아, 하준)와 다릅니다. 같은 한 줄짜리 코드를 세 번 실행해 보았습니다.

파일 06_set_order.py (세 번 실행)

print({"민수", "지아", "하준"})
{'지아', '하준', '민수'}
{'민수', '지아', '하준'}
{'민수', '하준', '지아'}

실행할 때마다 순서가 다릅니다. 여러분 컴퓨터에서는 또 다른 순서가 나올 수 있습니다. 집합은 값을 빨리 찾기 위해 내부에서 자기 방식대로 자리를 정하는데, 글자의 경우 그 자리가 실행마다 바뀌도록 되어 있기 때문입니다. 그래서 집합에 "첫 번째 것"은 없습니다.

파일 08_set_index.py

s = {"민수", "지아"}
print(s[0])

TypeError: 'set' object is not subscriptable

not subscriptable은 "대괄호로 꺼낼 수 없다"는 뜻입니다. 순서대로 보고 싶으면 sorted(s)로 정렬된 리스트를 새로 만들어 씁니다. sorted는 값을 작은 것부터(글자는 유니코드 번호순이라 한글은 가나다순) 늘어놓은 새 리스트를 돌려주는 함수입니다.

합집합·교집합·차집합

집합 두 개를 견주는 연산이 있습니다. 월요일 방문자 a와 화요일 방문자 b를 비교해 봅시다.

파일 07_set_ops.py

a = {"민수", "지아", "하준"}
b = {"지아", "하준", "서윤"}
print(sorted(a | b))
print(sorted(a & b))
print(sorted(a - b))
print(sorted(b - a))
print(type({}))
print(type(set()))

실행 결과

['민수', '서윤', '지아', '하준']
['지아', '하준']
['민수']
['서윤']
<class 'dict'>
<class 'set'>
기호이름뜻이 예의 결과
a | b합집합둘 중 어디에든 있는 것민수, 서윤, 지아, 하준 (4명)
a & b교집합둘 다에 있는 것지아, 하준 (2명)
a - b차집합a에는 있고 b에는 없는 것민수 (1명)

합집합 크기 검산: len(a) + len(b) − len(a & b) = 3 + 3 − 2 = 4로 len(a | b)와 같습니다. 겹친 지아·하준을 두 번 세지 않도록 교집합 크기를 한 번 뺍니다(포함·배제 원리).

흔한 실수

빈 집합을 {}로 만드는 것. 중괄호만 쓰면 Python은 빈 딕셔너리로 읽습니다. 위 실행 결과의 마지막 두 줄이 그 증거입니다(type({})은 dict). 빈 집합은 반드시 set()으로 만듭니다. 값이 들어 있는 {"민수", "지아"}는 키: 값 짝이 없으니 집합으로 읽힙니다.

튜플: 바꾸지 않을 묶음

지도 위 한 점의 위치(가로 3, 세로 5)나 서울의 위도·경도처럼, 몇 개의 값이 한 덩어리로 하나의 뜻을 이루고 나중에 바꿀 일이 없는 경우가 있습니다. 이런 묶음에 쓰는 것이 튜플입니다.

정의

튜플(tuple)은 리스트처럼 순서가 있고 자리 번호로 꺼낼 수 있지만, 한번 만들면 안의 값을 바꾸거나 더하거나 뺄 수 없는 묶음입니다. 소괄호 ( ) 안에 쉼표로 적습니다.

파일 09_tuple.py

point = (3, 5)
print(point[0], point[1])
x, y = point
print(x, y)
one = (7,)
not_tuple = (7)
print(type(one), type(not_tuple))
a, b = 1, 2
a, b = b, a
print(a, b)

실행 결과

3 5
3 5
<class 'tuple'> <class 'int'>
2 1

세 가지를 눈여겨봅니다.

  • 풀어 담기(unpacking). x, y = point는 튜플의 첫 값을 x에, 둘째 값을 y에 나눠 담습니다. 왼쪽 이름 개수와 튜플 길이가 같아야 합니다. 앞에서 본 for name, won in price.items()도 같은 원리입니다. .items()가 내놓는 짝 하나하나가 ("라면", 1300) 같은 튜플입니다.
  • 값이 하나인 튜플은 쉼표가 필요합니다. (7)은 그냥 괄호로 감싼 숫자 7입니다. 튜플을 만드는 것은 사실 괄호가 아니라 쉼표입니다(예외: 빈 튜플은 ()).
  • 두 값 맞바꾸기. a, b = b, a는 오른쪽에서 먼저 (2, 1)이라는 튜플을 만들고, 그것을 왼쪽 a, b에 풀어 담습니다.

튜플을 고치려 하면

point = (3, 5)
point[0] = 10
Traceback (most recent call last):

"튜플은 칸에 값을 넣는 일(item assignment)을 지원하지 않는다"는 뜻입니다. 리스트였다면 아무 문제 없이 바뀌었을 줄입니다. 바꿀 수 없다는 것이 불편해 보이지만, 실수로 바뀌면 안 되는 값을 지켜 주는 장점이 됩니다.

튜플은 딕셔너리의 키가 될 수 있다

두 도시 사이의 거리를 저장하고 싶다면 키가 "도시 두 개의 짝"이어야 합니다. 튜플은 키가 될 수 있지만 리스트는 될 수 없습니다.

파일 11_tuple_key.py

dist = {}
dist[("서울", "부산")] = 325
print(dist[("서울", "부산")])
print(dist)
325
{('서울', '부산'): 325}

파일 12_list_key.py

d = {}
d[["서울", "부산"]] = 325

    ~^^^^^^^^^^^^^^^^^^

오류 문장은 "리스트는 딕셔너리 키로 쓸 수 없다"입니다. 괄호 속 unhashable은 "키로 쓸 수 있는 지문(해시)을 만들 수 없다"는 뜻인데, 그 까닭은 리스트가 나중에 바뀔 수 있기 때문입니다. 이름표가 중간에 바뀌면 사전에서 낱말을 찾을 수 없게 되겠지요. 무엇이 바뀔 수 있고 무엇이 바뀔 수 없는지는 다음 장(PY06·2)의 주제입니다. 같은 까닭으로 집합에도 리스트를 넣을 수 없습니다.

상자 안에 상자

실제 자료는 한 가지 상자로 끝나지 않습니다. 학생마다 과목별 점수가 있다면 "학생 이름 → (과목 → 점수)"처럼 딕셔너리 안에 딕셔너리를 넣습니다. 학생 목록을 (이름, 점수) 튜플의 리스트로 담을 수도 있습니다.

파일 13_nested.py

students = [("민수", 80), ("지아", 95), ("하준", 70)]
for name, score in students:
    print(name, score)
book = {"민수": {"국어": 80, "수학": 90}, "지아": {"국어": 95, "수학": 85}}
print(book["민수"]["수학"])

실행 결과

민수 80
지아 95
하준 70
90

book["민수"]["수학"]은 왼쪽부터 두 단계로 읽습니다.

① book["민수"] → {"국어": 80, "수학": 90} (안쪽 딕셔너리)
② 그 딕셔너리["수학"] → 90

PY07에서 배울 JSON 파일은 이렇게 겹쳐 담긴 자료를 그대로 글자로 적어 둔 것입니다.

네 상자 견주기 외우기

지금까지 본 리스트·튜플·집합·딕셔너리처럼 여러 값을 담는 것을 통틀어 컨테이너(container), 우리말로 "담는 그릇"이라고 부릅니다. 같은 재료 "가", "나"를 네 그릇에 담아 나란히 놓아 봅니다.

리스트튜플집합딕셔너리
괄호[ ]( ) (핵심은 쉼표){ } 값만, 빈 것은 set(){ } 키: 값
순서있음있음없음넣은 순서 유지
중복됨됨안 됨키는 안 됨, 값은 됨
만든 뒤 바꾸기됨안 됨됨됨
찾는 법자리 번호자리 번호in으로 있는지키

외우는 법

괄호 모양으로 기억합니다. 대괄호 [ ] = 줄 세운 목록, 소괄호 ( ) = 묶어서 봉한 꾸러미, 중괄호 { } = 순서 없이 찾는 것(집합, 딕셔너리). 중괄호 안에 쌍점(:)이 있으면 딕셔너리, 없으면 집합입니다.

왜 그럴까?

"그냥 리스트 하나로 다 하면 안 되나?" 리스트로도 투표를 셀 수 있고 중복도 뺄 수 있습니다. 그런데도 딕셔너리와 집합을 따로 두는 이유는 무엇일까요?

모범 답 보기

할 수는 있지만 코드가 길어지고 뜻이 흐려집니다. 리스트로 "김밥이 있나?"를 알려면 처음부터 하나씩 비교해야 하고, 중복을 빼려면 매번 "전에 넣었나?"를 직접 확인해야 합니다. 딕셔너리와 집합은 키로 찾기, 중복 막기를 그릇이 스스로 해 주므로 코드가 짧아지고 실수가 줄어듭니다. 또 그릇의 종류만 보고도 "이건 이름으로 찾는 자료구나", "이건 겹치면 안 되는 자료구나" 하고 뜻을 읽을 수 있습니다. 성능도 다릅니다. 리스트의 in은 앞에서부터 비교하므로 원소 수 n에 비례하는 시간(O(n))이 들지만, dict·set은 해시 테이블로 구현되어 평균 O(1)에 찾습니다. 키가 불변이어야 하는 이유도 해시값이 바뀌면 안 되기 때문입니다(PY06·2, CS03).

어떤 상황에서 어느 그릇을 고를지는, "바꿀 수 있음/없음"의 뜻을 제대로 배운 뒤 다음 장 끝에서 표로 정리합니다.

한눈에 정리

그릇한마디꼭 기억할 것
딕셔너리 dict키로 값을 찾는 짝의 모음없는 키를 []로 꺼내면 KeyError. get(키, 기본값)으로 피한다. 같은 키에 넣으면 덮어쓴다.
집합 set중복 없고 순서 없는 모음빈 집합은 set(). 자리 번호 없음. | 합집합, & 교집합, - 차집합.
튜플 tuple순서 있고 바꿀 수 없는 묶음값 하나면 (7,). 풀어 담기 x, y = point. 딕셔너리 키가 될 수 있다.
리스트 list순서 있고 바꿀 수 있는 목록딕셔너리 키나 집합 원소가 될 수 없다.

한 줄 정리

이름으로 찾으려면 딕셔너리, 겹치지 않게 모으려면 집합, 바뀌면 안 되는 묶음이면 튜플을 쓴다.
