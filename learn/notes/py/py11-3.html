Matplotlib로 그래프 그리고 오차 막대 읽기

두 매장의 평균 매출은 같아도 하루하루 움직이는 폭은 다를 수 있습니다. 날짜순 선그래프를 직접 저장한 뒤, 같은 숫자를 평균과 표준편차로 그립니다. 오차 막대가 관측값의 퍼짐을 그렸는지 평균 추정의 불확실성을 그렸는지도 구분합니다.

Matplotlib로 매출 흐름을 저장한다

Figure는 도화지 전체이고, Axes는 실제 축과 데이터가 놓이는 영역입니다. fig, ax = plt.subplots()로 그림 한 장과 그릴 영역 한 개를 받습니다. 각 선에는 어떤 매장인지 이름을 붙이고, legend()로 그 이름과 선 모양을 묶어 보입니다. marker를 써서 실제 측정 날짜도 보이게 합니다.

import matplotlib
matplotlib.use("Agg")  # 창을 띄우지 않고 파일로 저장
import matplotlib.pyplot as plt

days = ["Mon", "Tue", "Wed", "Thu", "Fri"]
east = [14, 16, 18, 20, 22]
west = [8, 13, 18, 23, 28]

fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(days, east, marker="o", label="East")
ax.plot(days, west, marker="s", linestyle="--", label="West")
ax.set_xlabel("Day")
ax.set_ylabel("Daily sales (1000 KRW)")
ax.set_ylim(0, 30)
ax.legend()
fig.tight_layout()
fig.savefig("py11_sales_lines.png", dpi=140)
plt.close(fig)
print("저장: py11_sales_lines.png")

savefig()는 이 예제에서 실행한 폴더에 파일을 저장합니다. 저장한 파일을 열어 표의 수요일 값이 두 선의 교차점인지 확인합니다. 예제를 파일 이름이 겹치지 않는 실습 폴더에서 실행하는 편이 좋습니다. 실제 날짜의 간격이 불규칙하다면 날짜를 날짜 자료형으로 읽고 시간 간격을 그대로 그립니다. 이 예제처럼 날짜를 문자열 범주로 두면 하루 차이와 일주일 차이가 같은 간격으로 그려질 수 있습니다.

set_ylim(0, 30)은 이 표를 읽기 위해 고른 범위입니다. 0을 쓰는지, 두 그림에서 같은 축을 쓰는지는 자료의 종류와 비교 목적에 맞춰 결정합니다. 축을 확대할 때는 범위를 읽을 수 있게 눈금을 남깁니다. 단위와 범례를 따로 확인하고, 같은 종류의 선이 여러 개이면 색만 다르게 하지 않고 점 모양이나 선 종류도 함께 바꿉니다.

오차 막대에는 무엇을 그렸는지 붙인다

이번에는 주어진 자료 다섯 날의 평균과 퍼짐을 비교합니다. East의 평균은 (14 + 16 + 18 + 20 + 22) ÷ 5 = 18천 원이고, West의 평균도 18천 원입니다. 평균에서 얼마나 떨어져 있는지를 비교하면 결과가 달라집니다.

계산 예제

East의 편차는 −4, −2, 0, 2, 4입니다. 제곱을 더하면 16 + 4 + 0 + 4 + 16 = 40입니다. 표본 분산 규칙을 적용해 n − 1 = 4로 나누면 10, 표본 표준편차는 √10 ≈ 3.16천 원입니다. West의 편차 제곱 합은 100 + 25 + 0 + 25 + 100 = 250이므로 표본 표준편차는 √62.5 ≈ 7.91천 원입니다. 제곱을 푸는 마지막 단계에서 단위가 다시 천 원이 됩니다.

아래 코드는 두 평균이 같은 높이에 찍히는지와 오차 막대의 길이를 확인합니다. stdev()는 표본 표준편차를 계산하는 Python 표준 라이브러리 함수입니다. yerr=sd에는 점에서 위아래로 뻗을 거리를 줍니다. 구간 양 끝의 값은 아닙니다. 여러 점에서는 점 순서와 거리 순서가 맞아야 합니다.

import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from statistics import mean, stdev

stores = ["East", "West"]
values = [[14, 16, 18, 20, 22], [8, 13, 18, 23, 28]]
means = [mean(group) for group in values]
sd = [stdev(group) for group in values]

for name, group, avg, s in zip(stores, values, means, sd):
    print(f"{name}: n={len(group)}, mean={avg:.2f}, SD={s:.2f}")

fig, ax = plt.subplots(figsize=(6, 4))
ax.errorbar(stores, means, yerr=sd, fmt="o",
            capsize=6, label="Mean +/- sample SD")
ax.set_ylabel("Daily sales (1000 KRW)")
ax.set_ylim(0, 30)
ax.legend()
fig.tight_layout()
fig.savefig("py11_sales_sd.png", dpi=140)
plt.close(fig)
print("저장: py11_sales_sd.png")

SE (표준오차)같은 방식으로 표본을 뽑아 평균을 다시 구하면 평균이 얼마나 흔들리나?독립적인 동일 분포 표본의 평균이라면 SD ÷ √n로 추정할 수 있다.
CI (신뢰구간)자료와 정해진 계산 절차로 모집단 평균을 어느 범위로 추정하나?95%라면 가정 아래 같은 절차를 반복할 때 만들어진 구간 중 약 95%가 모집단 평균을 포함한다.

읽을 수 있는 비교의 범위

두 오차 막대는 하루 매출을 관측값으로 삼습니다. 여기서는 같은 5일로 한정해서 West의 일별 매출 퍼짐이 더 컸다고 말할 수 있습니다. 이 5일은 연속된 평일이고 두 매장이 날짜를 공유하므로, 독립적인 무작위 표본이라고 가정할 근거가 없습니다. 오차 막대가 겹치는지만 보고 모집단 평균이 같다고 판정하지 않습니다. 관측값이 적다면 원래 점도 함께 그리면 어떤 값이 이 요약을 만들었는지 확인하기 쉽습니다.
