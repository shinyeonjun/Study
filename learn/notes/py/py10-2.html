배열에서 값을 골라 계산하고 집계하기

두 날의 판매 기록에서 화요일 상품 B의 판매량만 보려면 한 칸을 찾으면 됩니다. 상품별 이틀 합계를 구하려면 같은 상품의 값을 더해서 날 축을 없애야 합니다. 두 작업 모두 숫자보다 먼저 어떤 축과 칸을 다루는지 정해야 합니다.

이 장을 읽고 나면

  • 정수 인덱스, 슬라이스, 불리언 마스크로 필요한 값만 고른다.
  • 뷰와 사본을 구별해 원본이 바뀌는 일을 피한다.
  • 원소별 연산과 축을 줄이는 집계의 결과 모양을 예측한다.
  • 작은 표에서 합계와 평균을 먼저 손으로 구해 코드와 대조한다.

칸 하나와 범위 선택하기

두 날에 세 상품을 기록한 (2, 3) 배열을 다시 사용합니다. sales[1, 1]의 첫 숫자는 행, 두 번째 숫자는 열을 정합니다. 인덱스는 0부터 시작하므로 화요일 상품 B의 값 4입니다. -1은 해당 축의 마지막 원소를 가리킵니다.

실행 예제

import numpy as np

sales = np.array([[12, 5, 8], [20, 4, 10]])
print(sales[1, 1], sales[-1, -1])
print(sales[:, 1])
print(sales[1].shape, sales[1:2, :].shape)
print(sales[:, 1:3])
4 10
[5 4]
(3,) (1, 3)
[[ 5  8]
 [ 4 10]]

정수 인덱스로 고른 축은 결과에서 빠집니다. sales[1]과 sales[1, :]는 둘째 행을 골라 (3,) 배열을 만듭니다. 반대로 sales[1:2, :]에서는 행 축에서 구간을 골랐으므로 (1, 3) 배열로 남습니다. : 하나는 그 축의 전 범위를 뜻하고, 1:3처럼 끝을 썼으면 그 끝 인덱스는 포함하지 않습니다. 범위를 벗어난 정수 하나를 고르면 sales[2, 0]처럼 IndexError: index 2 is out of bounds for axis 0 with size 2가 나지만, 슬라이스의 끝은 가능한 범위에 맞춰 잘립니다.

뷰와 사본, 그리고 원본을 바꾸는 대입

한 값이 잘못 기록되어 부분 배열에서 고쳤는데 원본까지 바뀌는 경우가 있습니다. 기본 슬라이싱으로 얻은 뷰(view)는 원래 배열의 데이터 일부를 같은 메모리에서 읽습니다. 바꿀 수 있는 배열이라면 뷰에서 원소를 수정할 때 원본에도 반영됩니다. .copy()로 만든 사본은 독립된 데이터를 써서 수정이 서로 전파되지 않습니다.

실행 예제

import numpy as np

sales = np.array([[12, 5, 8], [20, 4, 10]])
left = sales[:, 0]
picked = sales[[0, 1], 0]
left[0] = 99
picked[1] = 77
print(sales.tolist())
print(picked.tolist())
isolated = sales[:, 0].copy()
isolated[0] = 0
sales[[0, 1], 0] = 6
print(sales[:, 0].tolist(), isolated.tolist())
[[99, 5, 8], [20, 4, 10]]
[12, 77]
[6, 6] [0, 20]

sales[:, 0]은 첫 열의 12와 20을 가리키는 뷰입니다. sales[[0, 1], 0]은 [0, 1]이라는 정수 목록으로 두 행을 고르는 고급 인덱싱(advanced indexing)이라 같은 값을 별도 사본으로 얻습니다. 두 결과의 모양과 값이 처음에 같아도 변경의 영향은 다릅니다. 원본을 쓰기 전에 슬라이스를 독립적으로 고치려면 sales[:, 0].copy()를 쓰세요.

고급 인덱싱을 읽어서 변수에 넣는 것과, 그 위치에 바로 대입하는 것은 결과가 다릅니다. picked = sales[[0, 1], 0] 뒤에 picked[:] = 0을 하면 사본만 바뀝니다. sales[[0, 1], 0] = 0은 원본의 해당 칸에 바로 쓰는 표현입니다. 이 단원에서는 정수 목록 한 개로 한 축을 선택합니다. 행과 열에 정수 목록을 동시에 쓸 때는 같은 위치의 인덱스가 짝지어질 수 있어 모든 조합이 자동 선택된다고 가정할 수 없습니다.

비교 결과로 값 골라내기

판매 기록 전체에서 8개 이상인 값만 골라 보겠습니다. sales >= 8의 결과는 원래 값마다 참·거짓을 가진 같은 모양의 배열입니다. 이런 선택 조건을 담은 배열을 불리언 마스크라고 합니다. 같은 모양의 마스크를 sales[mask]에 넣으면 참인 칸만 행 순서대로 모은 1차원 배열을 얻습니다. 이 조회 결과는 사본입니다.

실행 예제

import numpy as np

sales = np.array([[12, 5, 8], [20, 4, 10]])
mask = sales >= 8
print(mask.tolist())
print(sales[mask].tolist())
print(sales[(sales >= 8) & (sales < 20)].tolist())
print(np.where(mask, sales, 0).tolist())
[[True, False, True], [True, False, True]]
[12, 8, 20, 10]
[12, 8, 10]
[[12, 0, 8], [20, 0, 10]]

원소 단위 조건을 묶을 때는 괄호로 각 비교를 감싸고 &(그리고), |(또는)를 씁니다. 예제에서 sales >= 8의 참은 4개지만 sales < 20 조건까지 넣으면 20이 빠집니다. and는 배열 전체를 참 또는 거짓 하나로 해석하려고 하므로, 원소가 여러 개인 배열에 쓰면 ValueError: The truth value of an array with more than one element is ambiguous. Use a.any() or a.all()이 납니다. 괄호도 필요합니다. &는 >=보다 먼저 계산되므로 sales >= 8 & sales < 20은 뜻이 달라집니다. 원래 표 모양을 유지하며 위치별로 결과를 만들 때는 np.where(mask, 참일 때 값, 거짓일 때 값)을 쓸 수 있습니다.

자리를 지키는 연산과 축을 줄이는 집계

sales * 2에서는 같은 자리마다 2를 곱해 원래와 같은 모양을 유지합니다. 같은 모양의 두 배열 a, b를 a + b로 더하면 같은 위치의 원소끼리 더합니다. 이를 원소별 연산이라고 합니다. 하나의 값이나 더 짧은 모양을 함께 계산하는 규칙은 다음 장에서 배웁니다. a * b는 원소별 곱입니다. 선형대수에서 배우는 행렬 곱은 @를 써서 다른 규칙으로 계산합니다.

집계는 여러 원소를 합계나 평균 등으로 모아 더 적은 개수의 결과를 만드는 작업입니다. axis를 지정하면 그 축을 따라 계산하고, 보통 그 축이 결과에서 빠집니다. sales.sum(axis=0)은 같은 열을 잡고 날을 바꿔가며 더하므로 상품별 결과입니다. sales.sum(axis=1)은 같은 행을 잡고 상품을 바꿔가며 더하므로 날짜별 결과입니다.

실행 예제

import numpy as np

sales = np.array([[12, 5, 8], [20, 4, 10]])
print(sales.sum(axis=0).tolist())
print(sales.sum(axis=1).tolist())
print(sales.mean(axis=0).tolist())
print(sales.sum())
print(sales.sum(axis=1, keepdims=True).shape)
[32, 9, 18]
[25, 34]
[16.0, 4.5, 9.0]
59
(2, 1)

풀이 예제

무엇을 남길지 먼저 정합니다. 상품 A의 이틀 평균은 (12 + 20) ÷ 2 = 16입니다. 상품 B는 4.5, 상품 C는 9입니다. 상품 축(1)을 남기려면 날 축(0)을 줄여야 하므로 sales.mean(axis=0)입니다. 인수를 생략하면 모든 원소를 모아 평균이나 합을 구합니다. 여기서는 전체 합이 59입니다.

keepdims=True는 축을 없애지 않고 길이 1로 남깁니다. 날짜별 합은 보통 (2,)이지만 sales.sum(axis=1, keepdims=True)의 모양은 (2, 1)입니다. 원래 표와 날짜별 값을 다시 계산할 때 유용합니다. 배열에 결측을 뜻하는 np.nan이 있다면 기본 합계·평균에 전파됩니다. 건너뛸지는 np.nanmean 같은 함수를 쓰기 전에 분석 목적에 따라 결정합니다.

한눈에 정리

표현선택하거나 계산하는 대상새 값과 원본
a[1, :]두 번째 행기본 인덱싱에서 얻은 배열은 뷰
a[mask]참인 원소만조회 결과는 사본
a + b같은 위치를 더함원소별 연산
a.sum(axis=0)축 0의 값을 더함기본으로 축 0이 줄어듦

다음 장으로

어느 축을 줄일지 먼저 정합니다. 다음 장에서 길이 1인 축을 이용해 날짜별 합과 판매량 표를 함께 계산합니다.
