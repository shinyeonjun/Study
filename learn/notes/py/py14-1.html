위치와 라벨을 구별하고 없는 값을 추적하기

관측점 A와 B의 기준값이 표의 다른 순서로 적혀 있습니다. 같은 칸 번호끼리 빼면 오류 없이 틀린 결과가 만들어집니다. 관측점 이름을 기준으로 정렬하고, 기준값을 모르는 행을 그대로 드러냅니다.

이 장을 읽고 나면

  • NumPy의 위치 계산과 pandas의 라벨 연산을 비교한다.
  • 중복 키와 참조 표에 없는 키를 검사한다.
  • 유효한 0과 결측을 구별해 분모를 확인한다.

두 표를 서로 다른 순서로 받았을 때

A와 B의 센서값은 각각 12와 18입니다. 기준값 장부에는 C가 10, B가 14, A가 11 순으로 기록됐다고 합시다. 질문은 ‘같은 센서에서 관측값이 기준보다 얼마나 높은가’입니다. 먼저 센서의 이름을 맞춰 A의 차이는 12−11=1, B는 18−14=4로 계산합니다. C는 기준은 있지만 관측이 없습니다.

센서 ID관측기준관측 − 기준
A12111
B18144
C결측10결측

pandas Series는 원소마다 인덱스 라벨을 갖습니다. 라벨이 유일한 두 Series를 기본 산술로 빼면 공통된 이름끼리 정렬하고, 한쪽에만 있는 이름도 결과에 남겨 값은 결측으로 둡니다. NumPy 배열에서는 이런 식별자가 없으므로 같은 위치끼리 계산합니다. 관측의 개수에 맞춰 기준 장부의 앞 두 값을 바로 빼면 A에 C의 10을 잘못 쓰게 됩니다.

어떤 이름을 결과에 남길지 먼저 정한다

관측된 행만 유지하려면 reference.reindex(observed.index)로 관측 순서에 맞춥니다. 기준 표에 같은 이름이 두 번 나오면 어떤 줄을 쓸지 정해야 합니다. 여러 날짜의 기준이라면 (센서, 적용 시각)의 복합 키 또는 분석 시점에 맞는 규칙이 필요합니다. 마지막 줄을 무조건 남겨도 된다는 근거는 없습니다.

정수 값과 결측이 함께 들어가는 열

pandas의 Int64는 결측 pd.NA를 담을 수 있는 정수 자료형입니다. 이 예에서 D의 기준값 대신 0을 쓰면 관측 − 기준이 20으로 바뀌어 평균을 올립니다. .isna()로 결측을 찾고 .count()로 유효한 수를 셉니다. .size는 관측 목록에 붙은 모든 행을 셉니다. 보고할 평균은 유효한 A와 B의 2.5이며, 두 값이 계산 가능했다는 사실도 같이 표시합니다.

실행으로 확인하기

import pandas as pd

observed = pd.Series([12, 18, 20], index=["A", "B", "D"], dtype="Int64")
reference = pd.Series([10, 14, 11], index=["C", "B", "A"], dtype="Int64")
for series in (observed, reference):
    if series.index.hasnans or not series.index.is_unique:
        raise ValueError("센서 키에 빈칸 또는 중복이 있습니다")

print((observed.to_numpy() - reference.to_numpy()).tolist())
delta = observed - reference.reindex(observed.index)
print(delta.to_dict())
print(delta.index[delta.isna()].tolist())
print(delta.count(), delta.size, float(delta.mean()))
assert delta.loc["A"] == 1 and delta.loc["B"] == 4
assert pd.isna(delta.loc["D"])

독립 검산

A와 B가 들어 있는 기준 장부를 작은 Python 딕셔너리로 손에 적고, 관측 행마다 같은 이름으로 찾아 계산해 봅니다. NumPy로 옮길 때는 키가 유일한지 확인하고 정렬한 뒤, 배열에서 빠져 나갈 라벨과 결측 정보를 어떻게 기록할지 먼저 결정합니다.
