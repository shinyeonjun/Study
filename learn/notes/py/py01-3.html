숫자 계산과 연산자

동영상 길이가 125분이라면 몇 시간 몇 분일까요? 사람은 "60분이 두 번 들어가고 5분 남는다"고 셉니다. Python에는 이 "몇 번 들어가나"와 "얼마 남나"를 바로 계산하는 기호 //와 %가 따로 있습니다. 이 장에서는 Python의 산술 연산자 일곱 가지와 그 결과의 자료형, 그리고 여러 기호가 섞였을 때의 계산 순서를 다룹니다.

이 장을 읽고 나면

  • + - * / // % ** 일곱 연산자의 결과를 실행 전에 예상할 수 있다.
  • /와 //의 차이, 그리고 결과가 int인지 float인지 설명할 수 있다.
  • //와 %로 몫과 나머지를 구해 시간·돈 나누기 문제를 풀고, 검산할 수 있다.
  • 여러 연산자가 섞인 식을 Python과 같은 순서로 계산할 수 있다.
  • 0으로 나눌 때와 음수를 //로 나눌 때 무슨 일이 생기는지 말할 수 있다.

일곱 가지 계산 기호 외우기

용어 +, *처럼 계산을 시키는 기호를 연산자(operator)라고 합니다. 7 + 2에서 7과 2처럼 연산자가 다루는 값은 피연산자(operand)라고 합니다. U05·3에서 본 TypeError의 "operand"가 이것입니다.

같은 두 수 7과 2에 일곱 연산자를 모두 써 본 실제 결과입니다.

연산자이름코드결과결과 자료형
+더하기7 + 29int
-빼기7 - 25int
*곱하기7 * 214int
/나누기7 / 23.5항상 float
//몫 (정수 나눗셈)7 // 23int (재료가 int일 때)
%나머지7 % 21int (재료가 int일 때)
**거듭제곱7 ** 249int

%는 여기서 "퍼센트"가 아니라 나머지라는 뜻이고, **는 별표 두 개를 붙여 씁니다(사이에 빈칸이 있으면 안 됩니다). 연산자 앞뒤의 빈칸은 있어도 없어도 결과가 같지만, 7 + 2처럼 한 칸씩 띄우는 것이 읽기 좋습니다.

나누기 세 가지: /, //, %

7 ÷ 2에 대해 "정확한 값"(3.5), "몇 번 들어가나"(3), "얼마 남나"(1)는 서로 다른 질문이고, Python은 질문마다 연산자를 하나씩 둡니다.

정의 외우기

/ (나누기): 소수까지 정확히 나눈 값. 결과는 항상 float.
// (몫, floor division): 나눈 값을 내린 정수 부분. "몇 번 들어가나".
% (나머지, modulo): 몫만큼 빼고 남은 것. "얼마 남나".
세 연산 사이에는 늘 이 관계가 성립합니다: 나뉘는 수 = 나누는 수 × 몫 + 나머지. 7 = 2 × 3 + 1.
정확히 쓰면 a // b = ⌊a / b⌋ (⌊ ⌋는 그 수 이하의 가장 큰 정수, 바닥 함수), a % b = a − b × ⌊a / b⌋ 입니다.

floor는 "바닥"이라는 뜻입니다. 수직선에서 바닥 쪽(왼쪽, 작은 쪽)으로 내린다는 말입니다. 양수에서는 소수 부분을 떼어 버리는 것과 같습니다. 음수에서는 결과가 달라지는데, 이 장 끝의 "음수를 // 로 나눌 때"에서 봅니다.

풀이 예제

125분은 몇 시간 몇 분일까요? Python으로 풀고 검산합니다.

코드 (m.py)

minutes = 125
hours = minutes // 60
rest = minutes % 60
print(hours, "시간", rest, "분")

실행 결과

2 시간 5 분

① 몫: 125 // 60 = ⌊2.08…⌋ = 2 (60 × 2 = 120 ≤ 125 < 180)
② 나머지: 125 % 60 = 125 − 120 = 5
③ 검산: 60 × 2 + 5 = 125 ✓

결과 줄의 "2 시간 5 분"에 빈칸이 끼어 있는 것은 print에 쉼표로 네 값을 넣었기 때문입니다(PY01·1). 빈칸 없이 "2시간 5분"으로 붙이는 법은 PY02의 문자열에서 배웁니다.

몫과 나머지가 쓰이는 곳

  • 짝수·홀수 가리기: 2로 나눈 나머지가 0이면 짝수, 1이면 홀수입니다. 14 % 2 → 0, 15 % 2 → 1.
  • 돈 나누기: 아래 예처럼 1원 단위로 정확히 나눠야 할 때.
  • 단위 바꾸기: 초 → 분·초, 날수 → 주·날(365 // 7 → 52, 365 % 7 → 1, 1년은 52주와 1일).

코드 (split.py): 10,000원을 3명이 나눠 내기

bill = 10000
people = 3
each = bill // people
left = bill % people
print("한 사람:", each)
print("남는 돈:", left)
print("나누기만 하면:", bill / people)

실행 결과

한 사람: 3333
남는 돈: 1
나누기만 하면: 3333.3333333333335

검산: 3,333 × 3 + 1 = 9,999 + 1 = 10,000 ✓. 마지막 줄의 / 결과는 원 단위로 낼 수 없는 값이고, 끝자리 5는 PY01·2에서 본 float의 작은 오차입니다. 돈처럼 낱개로 세는 것에는 //와 %가 맞습니다.

코드실제 결과까닭

/ 의 결과는 언제나 float 이해하기

정수끼리 나눠 딱 떨어져도 /는 소수점을 붙입니다. 실제 결과입니다.

대화형 실행

>>> 6 / 2
3.0
>>> 6 // 2
3
>>> 9 / 3
3.0
>>> 7.0 // 2
3.0
>>> 7.5 % 2
1.5
>>> 3 + 2.0
5.0

규칙은 두 줄로 정리됩니다.

  1. /는 재료가 무엇이든 결과가 float입니다. "나누면 소수가 나올 수 있다"를 늘 전제하기 때문입니다.
  2. 그 밖의 연산자(+ - * // % **)는 재료가 모두 int면 int, 하나라도 float면 float입니다. 그래서 7.0 // 2는 몫이지만 3.0(float)으로 나옵니다.

(**는 지수가 음수일 때 예외입니다. 2 ** -1은 int끼리지만 0.5가 나옵니다. 아래 거듭제곱 절에서 봅니다.)

흔한 실수

개수를 /로 구하기. 학생 30명을 6모둠으로 나눈 모둠 인원을 30 / 6으로 구하면 5.0이 나옵니다. 값은 맞지만 float라서, 나중에 "다섯째 칸"처럼 정수만 받는 자리(PY04의 목록 번호, range)에 넣으면 TypeError가 납니다. 사람 수·개수·번호처럼 낱개로 세는 값에는 //를 씁니다.

다른 언어에서 배운 습관. 예전 Python 2나 C 같은 언어에서는 정수끼리 /하면 몫(3)이 나왔습니다. Python 3에서 7 / 2는 3.5입니다. 인터넷의 오래된 예제를 볼 때 주의하세요.

거듭제곱: **

a ** b는 a를 b번 곱한 값입니다. 2 ** 3은 2 × 2 × 2 = 8입니다. 빅데이터분석기사 노트 1-01에서 계산한 데이터 단위도 바로 확인할 수 있습니다.

대화형 실행

>>> 2 ** 10
1024
>>> 1024 ** 2
1048576
>>> 10 ** 6
1000000
>>> 5 ** 0
1
>>> 2 ** 0.5
1.4142135623730951
>>> 2 ** -1
0.5
  • 2 ** 10 = 1,024는 1KB를 1,024바이트로 셀 때의 그 수이고, 1024 ** 2 = 1,048,576은 그렇게 셀 때 1MB의 바이트 수입니다(1-01은 시험 관례에 따라 1KB = 1,024B로 계산했습니다. 국제 표준에서는 1kB = 1,000B, 1KiB = 1,024B로 구분합니다. U04에서 자세히).
  • 0제곱은 1입니다(5 ** 0 → 1).
  • 지수가 0.5면 제곱근(√2 ≈ 1.414…), 음수면 역수(2−1 = 1/2 = 0.5)가 됩니다. 이런 지수는 AL07 지수와 로그에서 다시 다룹니다.

흔한 실수

^를 거듭제곱으로 쓰기. 엑셀이나 계산기에서는 2^10이 1024지만, Python에서 2 ^ 10은 오류 없이 8이 나옵니다. Python의 ^는 수를 2진법 자리마다 비교하는 전혀 다른 연산자이기 때문입니다. 거듭제곱은 반드시 **입니다.

계산 순서 외우기

여러 연산자가 한 식에 섞이면 Python은 정해진 순서대로 계산합니다. 곱셈·나눗셈이 덧셈·뺄셈보다 먼저인 수학의 규칙에, **와 //, %가 더해진 것입니다.

순서연산자같은 줄끼리는
1 (가장 먼저)( ) 괄호 안안쪽 괄호부터
2**오른쪽부터
3부호 -x
4* / // %왼쪽부터
5 (가장 나중)+ -왼쪽부터

표의 2와 3에는 예외가 하나 있습니다. **는 왼쪽의 부호보다는 먼저지만, 오른쪽(지수 자리)의 부호보다는 나중입니다. 그래서 -2 ** 2는 −(2 ** 2) = −4이고, 2 ** -1은 2 ** (−1) = 0.5입니다(공식 문서: "binds more tightly than unary operators on its left; it binds less tightly than unary operators on its right").

실제로 실행해 확인한 예입니다.

코드계산 순서실제 결과
2 + 3 * 43 * 4 = 12 → 2 + 1214
(2 + 3) * 42 + 3 = 5 → 5 * 420
10 - 4 - 3왼쪽부터: 10 − 4 = 6 → 6 − 33
100 / 10 / 2왼쪽부터: 100 / 10 = 10.0 → 10.0 / 25.0
2 * 3 ** 2** 먼저: 3 ** 2 = 9 → 2 * 918
2 ** 3 ** 2오른쪽부터: 3 ** 2 = 9 → 2 ** 9512
-2 ** 2** 가 부호보다 먼저: 2 ** 2 = 4 → −4-4
(-2) ** 2괄호 먼저: (−2) × (−2)4

풀이 예제

1 + 2 * 3 - 4 / 2를 Python과 같은 순서로 계산해 봅시다.

① 곱하기·나누기를 왼쪽부터: 2 * 3 = 6
② 이어서 4 / 2 = 2.0 (나누기라서 float)
③ 식이 1 + 6 - 2.0 이 된다. 더하기·빼기를 왼쪽부터: 1 + 6 = 7
④ 7 - 2.0 = 5.0 (float가 섞였으므로 결과도 float)

실제로 실행하면 5.0이 나옵니다. 답의 크기(5)뿐 아니라 소수점이 붙는지까지 예상하는 것이 이 장의 목표입니다.

시험·코딩 함정

-2 ** 2는 4가 아니라 −4. 거듭제곱이 부호보다 먼저이므로 −(2²)으로 계산됩니다. 음수를 제곱하려면 (-2) ** 2처럼 괄호를 칩니다. 2 ** 3 ** 2는 64가 아니라 512. 거듭제곱만 오른쪽부터 계산합니다(2(32) = 29). 헷갈릴 때는 언제나 괄호를 쳐서 뜻을 분명히 하는 것이 가장 좋은 습관입니다. 괄호는 결과가 같을 때도 쳐도 됩니다.

음수를 // 로 나눌 때

양수에서 //는 소수 부분을 떼는 것처럼 보이지만, 정확한 뜻은 "수직선에서 왼쪽(더 작은 쪽)의 정수로 내린다"입니다. 음수에서 이 차이가 드러납니다.

대화형 실행

>>> -7 / 2
-3.5
>>> -7 // 2
-4
>>> -7 % 2
1

−3.5에서 왼쪽의 정수는 −4이므로 -7 // 2는 −4입니다. 그러면 나머지는 관계식 "나뉘는 수 = 나누는 수 × 몫 + 나머지"를 맞추도록 정해집니다: −7 = 2 × (−4) + 1. 그래서 -7 % 2는 1입니다. 나누는 수가 양수이면 Python의 나머지는 늘 0 이상이 되어, 음수든 양수든 n % 2로 짝수·홀수를 가릴 수 있습니다. C·Java의 정수 나눗셈은 0 쪽으로 자르므로(−7 / 2 → −3, 나머지 −1) 다른 언어와 결과가 다를 수 있다는 점도 기억해 둡니다.

다음에 이어지는 곳

  • PY02: 입력받은 문자열을 수로 바꿔 계산하고, 결과를 비교(<, ==)합니다.
  • PY04: i % 2 == 0처럼 나머지로 짝수 번째만 고르고, 누적 합을 구합니다.
  • AL07 지수와 로그: 분수 지수와 로그 등 **로 계산한 거듭제곱의 뜻을 자세히 다룹니다.

한눈에 정리

묻는 것답
일곱 연산자+ - * / 와 //(몫) %(나머지) **(거듭제곱)
7 / 2, 7 // 2, 7 % 23.5, 3, 1
관계식나뉘는 수 = 나누는 수 × 몫 + 나머지 (125 = 60 × 2 + 5)
결과 자료형/는 항상 float. 그 밖의 연산자는 int끼리면 int, float가 섞이면 float
0으로 나누기/ // % 모두 ZeroDivisionError
계산 순서괄호 → **(오른쪽부터) → 부호 → * / // % → + - (같은 줄은 왼쪽부터)
함정-2 ** 2 = −4, 2 ** 3 ** 2 = 512, 2 ^ 10 = 8 (거듭제곱 아님)
음수의 //버림이 아니라 내림: -7 // 2 = −4

한 줄 정리

나누기는 / (항상 float), 몫은 //, 나머지는 %, 거듭제곱은 ** 이고, 섞이면 괄호 → ** → 곱셈 무리 → 덧셈 무리 순서로 계산한다.
