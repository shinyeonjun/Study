클래스로 여러 기록의 상태와 동작을 묶기

같은 계산을 여러 시설에서 반복하더라도 기록이 서로 섞이면 안 됩니다. 각 기록에 검증과 평균 계산을 붙이고, 두 객체가 어떤 값을 따로 보관하는지 확인합니다.

이 장을 읽고 나면

  • 클래스와 클래스에서 만든 객체를 구분한다.
  • self와 인스턴스 속성이 무엇을 가리키는지 설명한다.
  • 유효성 검사와 독립 상태를 작은 실행으로 확인한다.

함수와 값 사이의 관계를 정한다

지점마다 대기시간을 모아 평균을 내려고 합니다. 목록 두 개와 함수들을 따로 넘겨도 됩니다. 한 가지 방식은 목록을 어느 지점의 것인지와 함께 보관하고, 기록 추가와 평균을 그 객체의 동작으로 묶는 것입니다. 클래스는 그 규칙을 적은 정의이고 인스턴스는 정의로 만든 구체적인 객체입니다.

WaitLog("동쪽")을 만들 때 __init__에서 이름을 저장하고 빈 목록을 만듭니다. 이때 self는 지금 초기화하는 객체입니다. east.add(3)을 부르면 같은 객체가 add의 self로 전달됩니다. 서쪽 객체로 같은 메서드를 부르면 self가 서쪽을 가리킵니다. 실제로 east.add(3)은 WaitLog.add(east, 3)과 같은 호출입니다. 점 앞의 객체가 첫 인수 self로 자동으로 들어가므로, 메서드를 정의할 때는 self를 첫 매개변수로 적고 부를 때는 적지 않습니다. self라는 이름은 예약어가 아니라 관례입니다.

객체에 들어갈 값을 확인한다

대기시간에는 0 이상의 유한한 수만 기록하도록 정합니다. 이 조건을 add에서 확인하므로, 검사를 통과한 값만 목록에 추가됩니다. 평균은 자료가 없으면 None을 반환합니다. 0분이라는 측정 결과와 아직 측정한 적 없음을 서로 다른 상태로 표현합니다.

from math import isfinite
from statistics import mean

class WaitLog:
    def __init__(self, name: str) -> None:
        self.name = name
        self._minutes: list[float] = []

    def add(self, minutes: float) -> None:
        if not isfinite(minutes) or minutes < 0:
            raise ValueError("대기는 유한한 0 이상이어야 합니다.")
        self._minutes.append(minutes)

    def average(self) -> float | None:
        if not self._minutes:
            return None
        return mean(self._minutes)

east, west = WaitLog("동쪽"), WaitLog("서쪽")
east.add(3.0)
east.add(9.0)
print(east.name, east.average())
print(west.name, west.average())
try:
    east.add(-1.0)
except ValueError:
    print("잘못된 기록은 추가되지 않습니다.")
assert east.average() == 6.0 and west.average() is None

실행 결과

동쪽 6.0
서쪽 None
잘못된 기록은 추가되지 않습니다.

함께 쓸 값과 각자 보관할 값을 구분한다

만약 클래스 몸체에 minutes = []를 두고 모든 객체에서 거기에 값을 추가하면, 각 객체가 같은 목록에 접근하는 상황이 생깁니다. 클래스 몸체의 문장은 class 문이 실행될 때 한 번만 실행되므로 목록도 하나만 만들어지고, 그 목록은 클래스의 속성(클래스 속성)이 됩니다. self.minutes로 읽을 때 객체에 같은 이름의 속성이 없으면 클래스 속성을 찾아 쓰기 때문에 모든 객체가 이 하나를 바꿉니다.

class SharedLog:
    minutes = []              # 클래스 몸체: 모든 객체가 함께 쓰는 하나의 목록

    def add(self, m):
        self.minutes.append(m)

a, b = SharedLog(), SharedLog()
a.add(3)
print(b.minutes)
print(a.minutes is b.minutes)

실행 결과

[3]
True

각 기록이 따로 있어야 하므로 이 예는 __init__ 안에서 self._minutes = []를 실행해 객체마다 새 목록을 만듭니다. 앞에 밑줄을 붙인 이름은 내부 동작에 쓰려는 관례이며, Python이 접근을 물리적으로 차단한다는 뜻은 아닙니다.
