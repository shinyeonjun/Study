긴 표와 넓은 표를 오가며 집계의 분모 지키기

온도와 습도가 한 줄에 있는 표를 변수당 한 줄로 펴면 그래프를 그리기 쉽습니다. 행 수가 달라지고 같은 센서·시점에 반복 측정이 생겼을 때, 어느 평균을 보고하는지가 바뀔 수 있습니다.

이 장을 읽고 나면

  • 관측·변수·값을 식별하고 melt와 pivot을 연결한다.
  • 유일한 키와 반복 측정 키를 구분한다.
  • 행 평균과 센서 평균의 평균이 각각 어떤 질문에 답하는지 계산한다.

값 열 하나에 측정 이름을 따로 적는다

원래 표에서는 한 행이 센서와 시각으로 정해지고, 온도와 습도는 두 열입니다. melt는 센서·시각을 계속 식별 열로 두고 측정 이름과 값을 두 열로 펼칩니다. 한 시각에 센서 두 개가 있고 두 종류를 측정하면 네 행이 생깁니다. 값이 결측인 자리도 펼쳐진 표에 남아 관측 누락을 확인할 수 있습니다.

되돌릴 때 한 칸에 들어갈 값은 하나

pivot에서 index와 columns를 합친 키에 값이 둘 있으면 한 칸에 들어갈 값을 정할 수 없어 오류가 납니다. pivot_table은 여러 값을 지정한 집계 함수로 하나로 줄입니다. 재전송으로 복제된 행인지, 같은 시각에 반복한 별도 측정인지를 먼저 판단합니다. 전자라면 중복 처리 규칙과 근거를 남기고, 후자라면 반복 ID를 보존한 뒤 필요에 따라 평균을 구합니다.

관측당 평균과 센서당 평균

센서온도 관측값센서 내부 평균
A10, 1412
B2020

센서 A를 두 번, B를 한 번 쟀다면 관측을 모두 합친 평균은 (10+14+20)/3=44/3입니다. 센서에 같은 비중을 주려면 각 센서 평균의 평균 (12+20)/2=16입니다. 첫 번째 계산에서는 A의 합산 비중이 2/3이고, 두 번째 계산에서는 1/2입니다. 두 집계에 답하는 질문이 다르므로 그래프와 보고서에 어느 단위의 평균인지 씁니다.

집계 전에 값이 없는 센서가 있었는지 확인합니다. 그룹별 size는 행 수이고 count는 결측이 아닌 값 수입니다. 그룹 키 자체가 결측이면 groupby(..., dropna=False)로 그런 행을 별도 묶음에 보존할 수 있습니다. 장부에 있어야 하는 센서가 아예 나타나지 않았는지도 알아야 하므로 기대하는 센서 목록과 대조합니다.

실행으로 확인하기

import pandas as pd

wide = pd.DataFrame({"station": ["A", "B"], "time": ["09:00", "09:00"],
                     "temp_c": [10, 20], "humidity_pct": [70, 50]})
long = wide.melt(id_vars=["station", "time"], var_name="metric", value_name="reading")
key = ["station", "time", "metric"]
assert not long.duplicated(key).any()
recovered = long.pivot(index=["station", "time"], columns="metric", values="reading")
print(long.shape[0], int(recovered.loc[("A", "09:00"), "humidity_pct"]))

repeat = pd.DataFrame({"station": ["A"], "time": ["09:00"],
                       "metric": ["temp_c"], "reading": [14]})
repeated = pd.concat([long, repeat], ignore_index=True)
print(int(repeated.duplicated(key, keep=False).sum()))
temp = repeated.loc[repeated["metric"].eq("temp_c")]
means = temp.groupby("station")["reading"].mean()
print(means.to_dict())
print(f"{temp['reading'].mean():.4f} {means.mean():.4f}")
assert len(temp) == 3 and means.size == 2

예제는 마지막 줄을 A의 별도 반복 측정으로 가정합니다. 실제 파일이라면 반복을 구분하는 고유 ID가 필요합니다. 그래야 읽는 순서가 달라져도 A의 두 관측을 구별할 수 있습니다. 다음 데이터 입도와 데이터 계약에서는 그 가정을 검사 규칙으로 옮깁니다.
