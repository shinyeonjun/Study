결측을 제외하고 가중평균과 가중분산 계산하기

관측 하나가 빠진 열과 실제로 0을 관측한 열에는 서로 다른 분모가 필요합니다. NumPy 마스크가 어떤 값을 포함하는지 표에서 먼저 표시하고, 합과 나눗셈을 안전하게 구현합니다.

이 장을 읽고 나면

  • 값과 가중치의 모양을 맞추고 열마다 유효 분모를 구한다.
  • 분모가 0인 열의 계산 결과를 명시한다.
  • 가중분산의 제곱 편차를 손으로 계산하고 배열 결과와 대조한다.

평균에 들어오는 값과 가중치

두 관측 10, 20의 가중치를 각각 1, 2로 놓으면 평균은 (1·10+2·20)/(1+2)=50/3입니다. 20을 두 번 센 산술평균과 같습니다. 이 장에서는 유한한 0 이상의 가중치를 직접 주고, 관측값의 결측을 NaN으로 표현합니다. 가중치 0의 행은 결과에 기여하지 않습니다. 무한대인 관측은 입력에서 오류로 처리합니다.

A열에서 채택한 가중치는 1과 2로 합계가 3입니다. B열은 2와 1이 분모에 들어갑니다. B열의 0은 관측이므로 분자에는 0·1을 더하고 분모에는 1을 더합니다. C열의 분모가 0이라는 것은 양의 가중치를 가진 유효 관측이 없다는 뜻입니다. SQL 집계나 pandas에서 이 표를 만들 때도 먼저 관측 단위와 결측이 생기는 과정을 정합니다.

0 * np.nan의 결과는 NaN입니다. 먼저 유효값이 있는 자리를 구하고 np.where로 제외할 값의 자리를 0으로 채워 곱합니다. 이 0은 계산할 항을 제거하는 표식입니다. 같은 자리의 가중치도 0으로 만들어야 결측을 실제 0으로 집계하는 오류를 피합니다.

나눌 수 있는 열에서만 나눈다

값의 모양은 (4, 3)이고, 행별 가중치는 w[:, None]으로 (4, 1)로 바꿔 모든 열에 적용합니다. 행 축을 줄일 때 axis=0을 사용합니다. np.divide에 길이 3인 출력 배열을 NaN으로 채워 전달하면 where=False인 자리에는 미리 갖고 있던 NaN이 남습니다.

같은 가중치로 제곱 편차를 평균한다

각 열 평균을 먼저 구합니다. 그다음 채택한 값에서 열 평균을 빼고 제곱해, 같은 가중치로 평균합니다. 이 식은 주어진 가중치를 가진 분포의 분산입니다. 표본으로 모집단 분산을 추정할 때의 보정에는 표집 방식과 가중치의 뜻에 관한 추가 가정이 필요합니다.

B열의 평균은 80/3입니다. 가중분산은 [2·(40−80/3)²+1·(0−80/3)²]/3 = 3200/9입니다. A열은 200/9입니다. 두 계산 모두 유효값의 가중치로 다시 나눕니다. 분산의 단위는 원래 단위의 제곱입니다.

실행으로 확인하기

import numpy as np

x = np.array([[10, np.nan, np.nan], [20, 40, np.nan],
              [np.nan, 0, np.nan], [100, np.nan, np.nan]], dtype=float)
w = np.array([1, 2, 1, 0], dtype=float)
if w.shape != (x.shape[0],) or not np.isfinite(w).all() or (w < 0).any():
    raise ValueError("가중치는 행당 하나의 유한한 음이 아닌 수")
if np.isinf(x).any():
    raise ValueError("무한대인 관측")
valid = ~np.isnan(x) & (w[:, None] > 0)
weight = np.where(valid, w[:, None], 0)
observed = np.where(valid, x, 0)
total = weight.sum(axis=0)
mean = np.full(x.shape[1], np.nan)
np.divide((observed * weight).sum(axis=0), total, out=mean, where=total > 0)
deviation = np.where(valid, observed - mean, 0)
variance = np.full(x.shape[1], np.nan)
np.divide((weight * deviation**2).sum(axis=0), total,
          out=variance, where=total > 0)

print(valid.sum(axis=0).tolist(), total.tolist())
print(" ".join(f"{v:.4f}" for v in mean))
print(" ".join(f"{v:.4f}" for v in variance))
assert np.allclose(variance[:2], [200/9, 3200/9])
assert np.isnan(mean[2]) and np.isnan(variance[2])

다른 방법으로 손검산

A열에서 실제 더할 값은 10, 20, 20입니다. B열은 40, 40, 0입니다. 목록을 각자 세 칸으로 펼쳐 평균과 제곱 편차를 계산하면 배열의 가중치 처리와 독립적으로 대조할 수 있습니다. 채택한 관측 수와 가중치의 합은 서로 다른 양이므로 두 값을 모두 기록합니다.
