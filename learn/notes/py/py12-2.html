반복자와 생성기로 값이 필요할 때 하나씩 만들기

목록을 한꺼번에 만들지 않고, 다음 값이 필요할 때 계산을 이어 갑니다. 끝까지 쓴 반복자가 왜 두 번째 순회에서 비어 있는지도 직접 확인합니다.

이 장을 읽고 나면

  • 반복할 수 있는 객체와 진행 위치를 가진 반복자를 구별한다.
  • next와 StopIteration이 for와 어떻게 연결되는지 설명한다.
  • yield를 사용해 누적 평균을 하나씩 계산한다.

자료가 있어도 어느 값을 읽었는지는 따로 있다

목록 [2,4,8]은 여러 번 훑을 수 있는 반복 가능 객체입니다. iter로 받은 반복자는 어디까지 진행했는지 기억합니다. 처음 두 번 next로 읽으면 2, 4가 나옵니다. 같은 반복자의 남은 값을 list로 읽으면 [8]만 나옵니다. 처음 목록으로 iter를 다시 호출하면 처음부터 읽는 다른 반복자가 생깁니다.

반복자가 더 주는 값이 없으면 next는 기본적으로 StopIteration을 냅니다. for는 반복자를 요청하고 다음 값을 받다가 이 예외를 만나면 순회를 마칩니다. 마지막 값이 0이나 None인지 보고 끝을 판단하지 않습니다.

다음 평균이 필요할 때까지 기다린다

예로 [2,4,8]의 접두 평균을 순서대로 계산합니다. 첫 값까지 평균 2, 앞 두 값의 평균 3, 세 값의 평균 14/3입니다. 누적 합과 개수만 저장하면 이전 모든 원소를 다시 더하지 않고 다음 결과를 만들 수 있습니다.

yield가 포함된 함수를 호출하면 생성기 객체를 얻습니다. 첫 next로 실행을 시작하고, 첫 yield에서 값을 건넨 뒤 위치와 지역 변수를 보관합니다. 다음 요청에서 멈춘 지점 뒤로 실행을 이어 갑니다.

def running_means(values):
    total = 0
    for count, value in enumerate(values, start=1):
        total += value
        yield total / count

values = [2, 4, 8]
cursor = iter(values)
print("앞 두 값:", next(cursor), next(cursor))
print("남은 값:", list(cursor))
print("처음부터 다시:", list(iter(values)))

means = running_means(values)
print("첫 평균:", f"{next(means):.3f}")
print("이후 평균:", [f"{x:.3f}" for x in means])
print("같은 생성기를 다시 읽기:", list(means))

실행 결과

앞 두 값: 2 4
남은 값: [8]
처음부터 다시: [2, 4, 8]
첫 평균: 2.000
이후 평균: ['3.000', '4.667']
같은 생성기를 다시 읽기: []

작은 입력과 큰 입력에서 저장할 것을 정한다

생성기는 아직 요청하지 않은 출력 목록을 만들지 않습니다. 이 예에서 새 평균을 만드는 데는 누적 합과 개수만 필요합니다. 다만 순회하는 values 자체가 이미 큰 목록이면 그 입력 목록의 메모리는 계속 필요하고, 출력 전체를 list로 바꾸면 출력 메모리도 생깁니다. 파이프라인 전체에서 어느 단계가 목록을 만드는지 봅니다.

한 줄 정리

반복자는 한 번씩 진행하는 위치를 담고, 생성기는 필요한 값에서 멈췄다가 다음 요청을 받을 때 이어서 계산합니다.
