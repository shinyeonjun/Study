브로드캐스팅과 재현할 수 있는 난수 실험

두 날의 판매량 표에서 상품별 가격을 곱하면 칸마다 매출액이 나옵니다. 가격표에는 세 값뿐인데 어떻게 두 날에 적용될까요? 배열의 모양을 맞춰 계산하는 브로드캐스팅으로 이 문제를 풀고, 같은 배열 도구로 주사위 실험을 여러 번 반복합니다.

이 장을 읽고 나면

  • 브로드캐스팅에서 모양을 오른쪽부터 비교한다.
  • 날짜별 값과 상품별 값이 어느 축을 따라 적용되는지 설명한다.
  • 난수 생성기를 만들고 정수 뽑기와 복원 추출을 실행한다.
  • 시드, 호출 순서, 환경을 기록하고 재현성의 범위를 설명한다.

상품 가격표 하나를 두 날에 적용하기

상품 A, B, C의 단가를 각각 100원, 200원, 300원으로 정합니다. 월요일 상품 B의 매출액은 5 × 200 = 1,000원입니다. 화요일 상품 B에도 같은 200원을 곱합니다. NumPy에서는 판매량 표 (2, 3)에 가격 배열 (3,)을 바로 곱할 수 있습니다.

실행 예제

import numpy as np

sales = np.array([[12, 5, 8], [20, 4, 10]])
price = np.array([100, 200, 300])
money = sales * price
print(money.tolist())
print(money.sum(axis=1).tolist())
[[1200, 1000, 2400], [2000, 800, 3000]]
[4600, 5800]

크기가 다른 두 배열에 대해 같은 자리끼리 계산할 수 있도록 축을 맞추는 규칙을 브로드캐스팅(broadcasting)이라고 합니다. 이 예에서는 가격이 날짜마다 반복되는 것처럼 계산되지만, 가격 배열을 2행으로 복사해 둘 필요는 없습니다. 다만 출력 배열 자체는 커질 수 있습니다.

모양은 오른쪽 끝의 축부터 맞추기

길이 1인 축은 해당 칸을 필요한 만큼 다시 읽을 수 있습니다. 빠진 축도 길이 1로 간주합니다. 각 축을 오른쪽 끝부터 비교해 길이가 같거나, 둘 중 하나가 1이면 계산할 수 있습니다. 둘 다 1이 아니면서 서로 다른 길이면 그 자리에서 모양이 맞지 않습니다.

  1. (2, 3)과 (3,)을 맞추면, 오른쪽에서 3과 3이 같습니다. 왼쪽의 빠진 자리는 길이 1로 봅니다. 2와 1도 맞아서 결과는 (2, 3)입니다.
  2. (2, 3)과 (2,)를 맞추면, 오른쪽에서 3과 2가 만납니다. 어느 쪽도 1이 아니므로 실패합니다.
  3. (2, 3)과 (2, 1)을 맞추면 오른쪽 3과 1, 왼쪽 2와 2가 모두 맞아 결과는 (2, 3)입니다.

두 날의 판매량에 날짜별 보정량 1개, 2개를 더한다면 보정값을 (2, 1)로 만들어야 합니다. daily[:, np.newaxis]는 (2,)의 뒤에 길이 1인 축을 새로 둡니다. 이 경우 daily.reshape(2, 1)과 모양이 같습니다.

실행 예제

import numpy as np

sales = np.array([[12, 5, 8], [20, 4, 10]])
daily = np.array([1, 2])
try:
    sales + daily
except ValueError:
    print("오른쪽 축의 길이가 맞지 않습니다.")
print(daily[:, np.newaxis].shape)
print((sales + daily[:, np.newaxis]).tolist())
오른쪽 축의 길이가 맞지 않습니다.
(2, 1)
[[13, 6, 9], [22, 6, 12]]

흔한 실수

판매표가 우연히 (2, 2)라면 (2,) 배열을 더하는 코드가 실행됩니다. 그래도 정렬하는 기준은 마지막 축입니다. 첫 보정값을 첫날 모든 상품에 더할 의도라면, 정사각형 표에서도 날짜별 보정 배열을 (2, 1)로 만듭니다. 모양이 계산 가능한지 확인한 다음 축의 의미도 대조하세요.

각 상품이 그날 총판매량에서 차지하는 비율을 구할 때도 같은 원리입니다. sales.sum(axis=1, keepdims=True)로 날짜별 합계의 모양을 (2, 1)로 남기면, 날짜가 같은 행의 값들을 그 합계로 나눌 수 있습니다. 날짜별 합계에 0이 있다면 나눗셈 전에 별도로 처리 규칙을 정합니다.

실행 예제

import numpy as np

sales = np.array([[12, 5, 8], [20, 4, 10]])
daily_total = sales.sum(axis=1, keepdims=True)
share = sales / daily_total
print(daily_total.tolist())
print(share[0].round(2).tolist())
print(np.allclose(share.sum(axis=1), [1, 1]))
[[25], [34]]
[0.48, 0.2, 0.32]
True

난수 생성기의 상태와 시드

주사위를 여러 번 던지는 과정을 컴퓨터로 흉내 내 보겠습니다. NumPy의 default_rng(seed)는 난수 생성기(Generator)를 만듭니다. 컴퓨터가 내부 상태를 정해진 규칙으로 바꾸면서 무작위처럼 보이는 수를 생성하므로 이 수를 의사난수라고 합니다. 시드(seed)는 시작 상태를 만들 때 쓰는 입력입니다.

rng.integers(1, 7, size=6)은 1 이상 7 미만의 정수 6개를 뽑습니다. 뽑기 한 번에서 각 숫자가 나올 확률은 같습니다. 같은 생성기를 다시 호출하면 바뀐 상태에서 다음 수를 뽑습니다. 처음과 똑같이 맞춰 보려면 같은 시드로 생성기를 새로 만들고, 메서드와 인수, 호출 순서도 같게 실행합니다.

실행 예제

import numpy as np

rng = np.random.default_rng(2026)
first = rng.integers(1, 7, size=6)
second = rng.integers(1, 7, size=6)
repeat = np.random.default_rng(2026).integers(1, 7, size=6)
print(first.tolist())
print(second.tolist())
print(np.array_equal(first, repeat))
[6, 2, 1, 4, 3, 3]
[1, 3, 4, 3, 5, 5]
True

위에 나온 수열은 이 예제를 검증한 NumPy 2.5.3에서 얻었습니다. 마지막 줄은 같은 환경에서 각각 새로 만든 두 생성기의 첫 결과가 같은지 확인합니다. 시드를 같게 적어도 버전, 난수 알고리즘, 호출 순서나 크기를 바꾸면 정확히 같은 수열이 보장되지 않습니다. 보고서에는 시드와 코드, NumPy 버전 등을 함께 기록하고, 분석 결과가 특정 시드 하나에 지나치게 의존하지 않는지도 봅니다.

실험 한 번과 여러 번을 배열로 구별하기

주사위를 네 번 던져 평균을 내는 실험을 세 번 하겠습니다. 결과 배열의 행 하나는 실험 한 번, 열 하나는 그 실험에서의 던지기 한 번입니다. 그러므로 size=(3, 4)로 값을 생성하고 mean(axis=1)을 구하면 실험별로 평균 하나씩 남습니다.

실행 예제

import numpy as np

rng = np.random.default_rng(2026)
rolls = rng.integers(1, 7, size=(3, 4))
print(rolls.tolist())
print(rolls.mean(axis=1).tolist())
[[6, 2, 1, 4], [3, 3, 1, 3], [4, 3, 5, 5]]
[3.25, 2.5, 4.25]

첫 실험 평균은 (6 + 2 + 1 + 4) ÷ 4 = 3.25이고, 다음 두 실험은 다른 값이 나왔습니다. 이 세 결과를 정답처럼 외울 필요는 없습니다. 반복할 때 평균이 얼마나 달라지는지 살펴보기 위한 작은 실험입니다. 실제 모집단에서 몇 개를 뽑을지나 표본 편향은 DA08에서 자세히 다룹니다.

rng.choice([12, 5, 8], size=4, replace=True)를 쓰면 주사위 눈 대신 관측된 값 중에서 네 번 뽑을 수 있습니다. replace=True는 매번 원래 후보 중에서 다시 뽑는 복원 추출입니다. 그래서 서로 다른 후보가 셋뿐이어도 네 번 뽑을 수 있습니다. replace=False는 뽑았던 자리를 다시 고르지 않으므로, 세 자리에서 서로 다른 네 자리를 고르려고 하면 실패합니다. 원래 자료에 값이 같은 두 자리가 있다면 비복원 추출에서도 동일한 값이 나올 수 있습니다.

실행 예제

import numpy as np

rng = np.random.default_rng(2026)
sample = rng.choice([12, 5, 8], size=4, replace=True)
print(sample.tolist())
[8, 12, 12, 5]
