다시 실행할 수 있게 버전과 작업 조건 남기기

분석 코드와 CSV를 보관했는데 한 달 뒤 실행 결과가 달라졌습니다. 패키지 버전뿐 아니라 실행할 명령, 어떤 입력 파일을 사용했는지, 결과가 어느 폴더에 생기는지까지 적어 두어야 원인을 찾을 수 있습니다.

이 장을 읽고 나면

  • 직접 의존성과 함께 설치되는 간접 의존성을 구별한다.
  • 패키지 버전을 조사하고 requirements 파일을 읽는다.
  • 코드, 입력, 실행 명령, 출력 위치를 남기고 다시 실행한다.

나중에도 다시 시작할 수 있게 기록하기

다른 사람이 analyze.py를 받았다고 합시다. 어떤 Python을 써야 하는지, 이름이 같은 CSV 중 어떤 파일이 입력인지 모르면, 파일을 찾아 실행하는 데부터 막힙니다. 연구에서 재현이란 같은 조건을 다시 마련해서 결과를 비교할 수 있는 상태를 뜻합니다.

버전은 어디서 확인하나

Python 버전은 python --version, 패키지 버전과 설치 위치는 그 환경의 python -m pip show pandas에서 확인합니다. 설치된 배포 패키지의 버전은 Python 코드에서 importlib.metadata.version(...)으로도 읽을 수 있습니다. 이 실습은 결과를 만든 환경을 먼저 기록하고, 다른 환경이라면 값이 달라질 수 있음을 명시합니다.

.\.venv\Scripts\python.exe --version
.\.venv\Scripts\python.exe -m pip show numpy pandas matplotlib

문서에 실제 버전 번호를 적을 때는 본인의 터미널에서 확인한 값으로 바꿉니다. 버전 확인을 하는 이유는 서로 다른 환경을 구별하기 위해서입니다. 버전 번호 자체를 외울 필요는 없습니다.

requirements 파일

분석 코드는 NumPy, pandas, Matplotlib를 직접 가져옵니다. 이런 패키지를 직접 의존성이라고 합니다. 예를 들어 시각화 도구가 내부에서 쓰는 별도 패키지는 내 분석 파일에 직접 import가 없어도 함께 설치될 수 있습니다. 그것은 이 분석에서 간접 의존성입니다.

numpy==2.5.5
pandas==3.1.1
matplotlib==3.11.2

위 파일은 이 교재의 실제 분석을 검증한 세 패키지의 버전을 적은 것입니다. ==는 버전 하나를 지정합니다. 다른 운영체제나 Python 버전에서 이 조합을 설치하려면 지원 여부를 별도로 확인합니다. 해당 버전의 설치 파일이 없는 환경이라면 Python 버전부터 확인합니다. 이 세 줄은 직접 의존성만 고정합니다. 간접 의존성은 적혀 있지 않으므로 나중에 설치하면 그때 가능한 다른 버전이 들어올 수 있습니다. 간접 의존성까지 똑같이 맞춰야 할 때는 결과를 만든 환경에서 pip freeze 출력을 함께 보관합니다.

.\.venv\Scripts\python.exe -m pip install -r requirements.txt

흔한 오해

pip freeze는 지금 환경에 설치된 목록을 보고합니다. 내가 직접 사용한 것만 추려 주거나 새 환경에서 동작 여부를 보장하지 않습니다. 이전 실습이 섞인 환경에서 결과를 무조건 복사하면 실제로 필요하지 않은 패키지도 들어갑니다.

경로와 데이터도 버전의 일부

동일한 이름의 CSV를 다시 만들어도 행 내용이 달라지면 같은 분석이 아닙니다. 다운로드 날짜나 파일 생성일과 출처를 적고, 원자료와 정리본을 다른 이름으로 둡니다. Path("annual_co2.csv") 같은 상대 경로는 명령을 실행한 현재 작업 폴더(Path.cwd())를 기준으로 찾습니다. 반면 파일 안에서 Path(__file__).with_name("annual_co2.csv")를 쓰면 그 Python 파일 옆에서 찾습니다. 분석 결과는 어디에 쓸지 코드를 읽어 확인합니다.

from pathlib import PureWindowsPath

script = PureWindowsPath(r"C:\study\co2\analyze.py")
print(script.with_name("annual_co2.csv").name)
print(script.with_name("annual_co2.csv").parent == script.parent)

실행 결과

annual_co2.csv
True

서로 다른 시스템에서 이미지 파일의 바이트까지 같아야 하는 것은 아닙니다. 글꼴 등의 차이가 있더라도 데이터 요약과 그림에서 읽는 수치, 계산 규칙을 확인할 수 있습니다. 난수로 표본을 뽑는 경우에는 초기값(seed)과 생성기의 종류, 버전을 함께 남기는 이유를 PY10·3에서 배웁니다.
