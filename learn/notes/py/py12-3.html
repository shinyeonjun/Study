공부 교재

Python과 프로그래밍 사고 · PY12 코드가 커질 때

PY12·3

계산과 출력 코드를 모듈로 나누고 타입 적기

분석 스크립트를 실행하면 결과가 나와야 하지만, 그 안의 계산 함수를 다른 분석에서 가져올 수도 있습니다. 파일을 두 개로 나눠 두 상황이 어떻게 동작하는지 확인합니다.

이 장을 읽고 나면

  • 모듈을 가져오는 코드와 프로그램으로 실행하는 코드를 구분한다.
  • 입력과 반환 타입을 함수 표기에 남긴다.
  • 계산과 입출력 사이에 검산할 지점을 만든다.

읽는 사람에게 기대하는 입력과 결과를 알려 준다

함수가 대기 시간 목록의 평균에 보정값을 더한다고 합시다. 매개변수 samples: list[float]와 offset: float를 쓰고, 매개변수 괄호 뒤 -> float에 반환할 값의 종류를 적을 수 있습니다. 이런 표기를 타입 힌트(type hint)라고 합니다. 이는 편집기나 mypy 같은 타입 검사 도구가 읽는 표기이며, 호출 시 Python이 자동으로 인수의 형식을 검사하는 기능은 아닙니다. 예를 들어 def double(x: float) -> float: return x * 2에 double("ab")를 넣어도 오류 없이 'abab'가 나옵니다. 자주 쓰는 표기는 list[float](실수 목록), dict[str, int](문자열 키와 정수 값), float | None(실수 또는 None, PY12·1의 average)입니다. 실제 입력이 유효한지는 프로그램에서 확인할 수 있습니다.

평균을 내려면 값이 적어도 하나 있어야 합니다. 이 함수는 빈 목록을 받으면 ValueError로 알려 주기로 정합니다. 유효한 [3.0, 5.0]과 보정 0.5를 넣으면 평균 4.0에 0.5를 더해 4.5를 반환합니다.

import는 정의를 읽되, 보고서 출력은 실행에 둔다

.py 파일로 분리한 모듈에는 함수·클래스·값을 둘 수 있습니다. 한 프로세스에서 모듈을 처음 가져올 때 최상위 코드는 실행됩니다. 그래서 화면 출력이나 파일 갱신을 곧바로 최상위에 두면, 함수를 이용하려고 가져온 경우에도 의도치 않게 그 일이 일어날 수 있습니다.

모듈마다 있는 변수 __name__에는 보통 모듈 이름이 들어갑니다. import report로 가져오면 "report"이고, python report.py처럼 그 파일을 직접 실행하면 "__main__"입니다. 그래서 if __name__ == "__main__":은 해당 파일을 프로그램으로 직접 실행할 때만 진입점을 부르는 관례입니다. 같은 프로세스에서 이미 가져온 모듈을 다시 import하면 저장된 모듈(sys.modules)을 그대로 쓰므로 최상위 코드는 다시 실행되지 않습니다. 아래에서 python report.py는 main을 실행하지만 import report는 main을 정의하고 부르지는 않습니다.

from pathlib import Path
import subprocess
import sys
from tempfile import TemporaryDirectory

calculations = """from statistics import mean

def shifted_mean(samples: list[float], offset: float = 0.0) -> float:
    if not samples:
        raise ValueError("At least one sample required")
    return float(mean(samples) + offset)
"""
report = """from measurements import shifted_mean

def main() -> None:
    print(f"result={shifted_mean([3.0, 5.0], 0.5):.1f}")

if __name__ == "__main__":
    main()
"""

with TemporaryDirectory() as folder:
    work = Path(folder)
    (work / "measurements.py").write_text(calculations, encoding="utf-8")
    (work / "report.py").write_text(report, encoding="utf-8")

    def run(*args):
        return subprocess.run([sys.executable, "-B", *args], cwd=work,
                              check=True, capture_output=True, text=True).stdout.strip()

    direct = run("report.py")
    imported = run("-c", "import report")
    verified = run("-c", "from measurements import shifted_mean; "
                        "assert shifted_mean([10.0, 14.0], -2.0) == 10.0; "
                        "print('ok')")
    print("직접 실행:", direct)
    print("import 시 출력 없음:", imported == "")
    print("계산만 검산:", verified)

실행 결과

직접 실행: result=4.5
import 시 출력 없음: True
계산만 검산: ok

기능을 찾기 쉬운 이름을 두고 따로 검산한다

두 파일은 임시 폴더의 같은 위치에 있습니다. 직접 비슷한 프로젝트를 만들 때는 파일명을 Python 표준 모듈 이름과 충돌하지 않게 고릅니다. 예로 statistics.py라는 파일을 같은 곳에 두면 표준 statistics 앞에 그 파일이 import될 수 있습니다.

이 예의 계산 함수는 인수로 받은 값을 직접 반환합니다. 같은 파일을 읽거나 화면을 준비하지 않아도, 작은 입력에서 결과를 독립적으로 대조할 수 있습니다. 모듈을 나누는 기준은 파일 줄 수보다 어떤 코드가 같은 책임을 지는지입니다.

한 줄 정리

계산은 입력과 반환을 표기한 함수로 가져오고, 사람에게 결과를 내보내는 동작은 필요한 실행 진입점에 둡니다.
