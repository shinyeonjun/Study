PY02·1

문자열 다루기

영수증에는 "라면 2개 2,400원" 같은 글이 찍힙니다. 숫자 2와 2400은 계산해서 나왔지만, "라면", "개", "원"은 계산이 아니라 글자입니다. 이 장에서는 Python이 글자를 담는 값인 문자열을 만들고, 잇고, 세고, 한 글자씩 꺼내고, 숫자를 글 속에 끼워 넣는 방법을 하나씩 실행해 보며 익힙니다.

이 장을 읽고 나면

  • 큰따옴표와 작은따옴표로 문자열을 만들고, 따옴표가 섞인 글에서 오류가 나는 까닭을 설명할 수 있다.
  • \n, \t, \", \\ 같은 이스케이프 문자가 화면에 어떻게 나오는지 예측할 수 있다.
  • +로 문자열을 잇고 *로 되풀이하며, len()으로 글자 수를 셀 수 있다.
  • 번호(인덱스) 0부터 세어 문자열에서 한 글자를 꺼내고, 범위를 벗어나면 어떤 오류가 나는지 말할 수 있다.
  • f-문자열로 변수 값과 계산 결과를 문장 속에 끼워 넣을 수 있다.

글자를 담는 값

PY01에서 print(1200 * 2)처럼 숫자를 계산해 화면에 내보냈습니다. 이번에는 숫자가 아니라 글을 다뤄 봅시다. 다음 네 줄을 str1.py라는 파일로 저장하고 실행합니다. 파일을 만들고 실행하는 방법은 U05와 PY01에서 본 그대로입니다(명령 프롬프트나 PowerShell에서 python str1.py).

print("안녕하세요")
print('안녕하세요')
print("It's me")
print('그는 "좋아"라고 말했다')

실행 결과

안녕하세요
안녕하세요
It's me
그는 "좋아"라고 말했다

따옴표로 둘러싼 글은 화면에 그대로 나왔는데, 둘러싼 따옴표 자체는 나오지 않았습니다. 셋째와 넷째 줄에서는 글 속에 들어 있던 따옴표가 나왔습니다. 이 차이가 이 절의 핵심입니다.

용어 문자열(文字列, string)은 글자(문자)를 한 줄로 늘어놓은 값입니다. 영어 이름을 줄여 str이라고 부르고, PY01에서 본 type()으로 확인하면 <class 'str'>이 나옵니다. "리터럴(literal)"은 코드에 값을 글자 그대로 적어 넣은 것을 말합니다. "안녕하세요"는 문자열 리터럴, 1200은 정수 리터럴입니다.

정의

문자열은 따옴표로 시작과 끝을 표시한 글자들의 값이다. 큰따옴표 "…"와 작은따옴표 '…' 중 어느 것을 써도 같은 문자열이 된다. 단, 여는 따옴표와 닫는 따옴표는 같은 종류여야 한다. 따옴표는 "여기서부터 여기까지가 글"이라는 표지일 뿐 문자열의 내용이 아니다.

따옴표 두 종류를 두는 까닭

영어의 It's처럼 글 속에 작은따옴표가 들어 있을 때가 있습니다. 이것을 작은따옴표로 둘러싸면 Python은 'It'까지를 문자열로 읽고, 남은 s me')를 이해하지 못합니다. 실제로 실행하면 이렇습니다.

print('It's me')

실행 결과

  File "C:\Users\...\quote.py", line 1
    print('It's me')
                  ^
SyntaxError: unterminated string literal (detected at line 1)

마지막 줄의 SyntaxError는 "문법 오류", unterminated string literal은 "끝나지 않은 문자열"이라는 뜻입니다. Python 눈에는 s me 뒤의 작은따옴표가 새 문자열을 여는 따옴표로 보이고, 그 문자열을 닫는 따옴표가 줄 끝까지 없으니 "끝나지 않았다"고 알립니다. 글 속에 작은따옴표가 있으면 바깥을 큰따옴표로, 글 속에 큰따옴표가 있으면 바깥을 작은따옴표로 둘러쌉니다. 앞의 셋째·넷째 줄이 그렇게 한 것입니다. 오류 메시지를 읽는 법은 PY02·3에서 더 자세히 다룹니다.

흔한 실수

따옴표를 빼먹으면 글이 아니라 이름이 됩니다. print(안녕)이라고 쓰면 Python은 "안녕"이라는 변수를 찾습니다. 그런 변수를 만든 적이 없으면 NameError가 납니다(PY02·3). 또 "1200"과 1200은 다른 값입니다. 앞의 것은 글자 네 개짜리 문자열이고, 뒤의 것은 계산할 수 있는 정수입니다. 화면에는 똑같이 1200으로 보여도 type()으로 확인하면 각각 str과 int가 나옵니다.

보이지 않는 글자: 이스케이프 외우기

문자열 안에서 줄을 바꾸고 싶다고 해 봅시다. 따옴표 안에서 키보드의 엔터를 누르면 문자열이 그 줄에서 끝나지 않은 채로 끊겨 위와 같은 오류가 납니다. 그래서 Python은 역슬래시(\) 뒤에 글자 하나를 붙여 특별한 글자를 나타내는 방법을 씁니다.

용어 역슬래시(backslash) \는 한국어 Windows 키보드에서 원화 기호 ₩로 보이는 키입니다. 글꼴에 따라 화면에 ₩로 보여도 컴퓨터 안에서는 같은 글자입니다. 이스케이프(escape)는 "빠져나가다"라는 뜻으로, 역슬래시 뒤의 글자가 보통 뜻에서 빠져나와 특별한 뜻을 갖는다는 말입니다.
print("첫째 줄\n둘째 줄")
print("상품\t가격")
print("라면\t1200")
print("그는 \"좋아\"라고 말했다")
print("C:\\data")

실행 결과

첫째 줄
둘째 줄
상품	가격
라면	1200
그는 "좋아"라고 말했다
C:\data
코드에 쓰는 것뜻화면에 나오는 것
\n줄바꿈 (new line)다음 줄로 넘어간다
\t탭 (tab)다음 칸 위치까지 띄운다. 표처럼 줄을 맞출 때 쓴다

\\역슬래시 글자 자체\ 하나

중요한 점은 \n이 코드에서는 두 글자로 적히지만 문자열 안에서는 한 글자라는 것입니다. 그림으로 보면 이렇습니다.

흔한 실수

Windows 폴더 경로를 문자열에 그대로 적을 때 조심해야 합니다. print("C:\new_folder")를 실행하면 이렇게 나옵니다.

C:

\n이 줄바꿈으로 읽혀 n이 사라지고 줄이 바뀌었습니다. 오류 없이 엉뚱한 결과가 나오므로 더 위험합니다. 역슬래시를 두 번 써서 "C:\\new_folder"로 적으면 C:\new_folder가 그대로 나옵니다. 파일 경로를 다루는 더 편한 방법은 PY07에서 봅니다.

잇기와 되풀이: + 와 *

PY01에서 +는 더하기, *는 곱하기였습니다. 같은 기호를 문자열 사이에 쓰면 뜻이 바뀝니다.

a = "빅"
b = "데이터"
print(a + b)
print(a + " " + b)
print("-" * 10)
print("하" * 3)
print(3 * "ab")

실행 결과

빅데이터
빅 데이터
----------
하하하
ababab

정의

문자열 + 문자열은 두 문자열을 순서대로 이어 붙인 연결(concatenation)이다. 문자열 * 정수(또는 정수 * 문자열)는 그 문자열을 정수만큼 이어 붙인 반복이다.

둘째 줄을 보세요. a + b는 빈칸 없이 "빅데이터"가 됩니다. 연결은 사이에 아무것도 넣어 주지 않습니다. 띄어 쓰고 싶으면 " "(빈칸 한 글자짜리 문자열)을 직접 끼워 넣어야 합니다.

(다)는 PY01·2에서 "7" + "7"이 "77"이 되는 것으로 이미 본 내용이고, 이 장에서 가장 중요한 그림입니다. 실행해 보면 확인할 수 있습니다.

print("1" + "2")
print(1 + 2)
print("ab" + "cd" * 2)

실행 결과

12
3
abcdcd

셋째 줄은 계산 순서를 보여 줍니다. 숫자와 같은 우선순위 규칙이 적용되어 *가 +보다 먼저입니다.

① "cd" * 2 → "cdcd"
② "ab" + "cdcd" → "abcdcd"

그렇다면 문자열과 정수를 +로 이으면 어떻게 될까요? "나이: " + 20은 오류가 납니다. Python은 "잇기"인지 "더하기"인지 정할 수 없을 때 짐작하지 않고 멈춥니다. 이 오류와 해결법은 다음 장(PY02·2)에서 형 변환과 함께 다룹니다.

글자 수 세기: len()

len()은 길이(length)를 알려 주는 함수입니다. 괄호 안에 문자열을 넣으면 글자가 몇 개인지 정수로 돌려줍니다.

print(len("데이터"))
print(len("data"))
print(len("빅 데이터"))
print(len(""))
print(len("a\nb"))

실행 결과

3
4
5
0
3

하나씩 확인해 봅시다.

  • "데이터": len()은 바이트 수가 아니라 글자(유니코드 코드 포인트) 수를 셉니다. UTF-8로 저장하면 한글 한 글자는 3바이트지만 len은 1로 셉니다(인코딩은 SY01). 다만 코드 포인트 수는 사람 눈에 보이는 글자 수와 항상 같지는 않습니다. 예를 들어 e 뒤에 결합용 악센트 부호(U+0301)를 붙인 "é"은 화면에 é 한 글자로 보이지만 len은 2입니다.
  • "빅 데이터": 빅, 빈칸, 데, 이, 터로 5입니다. 빈칸도 한 글자입니다.
  • "": 따옴표 사이에 아무것도 없는 문자열을 빈 문자열이라고 합니다. 길이는 0입니다. 빈칸 한 글자짜리 " "(길이 1)와 다릅니다.
  • "a\nb": a, 줄바꿈, b로 3입니다. 앞 그림의 \n이 한 글자라는 것을 len()으로 확인한 셈입니다.

한 글자씩 꺼내기: 인덱스 이해하기

문자열은 글자를 한 줄로 늘어놓은 것이므로, 글자마다 자리 번호를 매길 수 있습니다. 이 번호를 인덱스(index)라고 하고, 대괄호 [ ] 안에 번호를 넣어 그 자리의 글자를 꺼냅니다.

word = "Python"
print(word[0])
print(word[1])
print(word[5])
print(word[-1])
print(word[-2])

실행 결과

P
y
n
n
o

정의

문자열 s에서 s[i]는 i번 자리의 글자 하나다. 첫 글자의 번호는 0이고, 마지막 글자의 번호는 len(s) - 1이다. 음수 번호 -1은 마지막 글자, -2는 끝에서 둘째 글자를 가리킨다.

번호는 "몇 번째"가 아니라 첫 글자로부터의 거리(offset)입니다. s[i]는 시작에서 i칸 떨어진 글자이므로 첫 글자가 0, 마지막 글자가 len(s) - 1입니다. 음수 번호 s[-k]는 s[len(s) - k]와 같습니다.

길이가 6인 문자열에 6번 칸은 없습니다. 없는 칸을 꺼내려 하면 오류가 납니다.

word = "Python"
print(word[6])

실행 결과

Traceback (most recent call last):
  File "C:\Users\...\index.py", line 2, in <module>
    print(word[6])
          ~~~~^^^
IndexError: string index out of range

IndexError: string index out of range는 "문자열 번호가 범위를 벗어났다"는 뜻입니다. ~~~~^^^ 표시가 word[6] 부분 아래에 붙어 어디가 문제인지 가리킵니다.

풀이 예제

s = "데이터 분석"일 때 s[0], s[4], s[-1], len(s)를 구합니다.

① 칸에 번호를 붙인다: 데(0) 이(1) 터(2) 빈칸(3) 분(4) 석(5)
② s[0] → 데
③ s[4] → 분 (빈칸이 3번 칸을 차지하므로 4번은 '분')
④ s[-1] → 마지막 칸 → 석
⑤ len(s) → 칸이 0~5까지 6개 → 6

print(s[0], s[4], s[-1], len(s))을 실행하면 데 분 석 6이 나옵니다. (print에 쉼표로 여러 값을 넣으면 사이에 빈칸 하나를 넣어 한 줄에 출력합니다.)

흔한 실수

문자열의 한 글자를 바꿀 수는 없습니다. word[0] = "J"로 "Jython"을 만들려고 하면 TypeError: 'str' object does not support item assignment(문자열은 칸에 값을 넣는 것을 지원하지 않는다)가 납니다. 문자열은 한번 만들면 내용이 바뀌지 않는 값입니다. 바꾼 글이 필요하면 "J" + word[1:]처럼 새 문자열을 만듭니다. 여기 나온 [1:](1번부터 끝까지 잘라 내기, 슬라이싱)는 PY04에서 목록과 함께 자세히 배웁니다.

글 속에 값 끼워 넣기: f-문자열

영수증 한 줄 "라면 2개는 2400원입니다."를 변수로 만들어 봅시다. 지금까지 배운 +만으로 하면 이렇게 됩니다.

name = "라면"
price = 1200
count = 2
print(name + " " + str(count) + "개는 " + str(price * count) + "원입니다.")

정수를 문자열에 이으려면 str()로 글자로 바꿔야 하고(다음 장에서 자세히), 따옴표와 +가 줄줄이 붙어 읽기 어렵습니다. 그래서 Python에는 문장의 틀을 먼저 쓰고 빈 자리에 값을 끼우는 방법이 있습니다.

name = "라면"
price = 1200
count = 2
print(f"{name} {count}개는 {price * count}원입니다.")
print(name + " " + str(count) + "개는 " + str(price * count) + "원입니다.")
print("{name} {count}개")

실행 결과

라면 2개는 2400원입니다.
라면 2개는 2400원입니다.
{name} {count}개

정의

여는 따옴표 바로 앞에 f를 붙인 문자열을 f-문자열(f-string, formatted string)이라고 한다. 그 안의 중괄호 { } 속에는 변수 이름이나 계산식을 쓰고, 실행할 때 그 값이 계산되어 글자로 바뀐 뒤 그 자리에 들어간다.

실행 결과의 셋째 줄을 보세요. 앞에 f를 빼먹은 "{name} {count}개"는 중괄호까지 글자 그대로 나왔습니다. 오류도 나지 않으니 결과를 꼭 눈으로 확인해야 합니다.

자릿수와 쉼표 맞추기

중괄호 안에서 값 뒤에 쌍점 :을 찍고 모양을 정할 수 있습니다. 자주 쓰는 두 가지만 봅니다.

avg = 250 / 3
print(avg)
print(f"평균 {avg:.1f}점")
print(f"평균 {avg:.2f}점")
print(f"합계 {4900:,}원")

실행 결과

83.33333333333333
평균 83.3점
평균 83.33점
합계 4,900원
  • :.1f는 "소수점 아래 1자리까지 보여 줘"라는 뜻입니다. .2f는 2자리입니다. 그 아래 자리는 반올림해서 보여 주는데, 값 자체가 바뀌는 것은 아니고 보여 주는 모양만 바뀝니다. avg에는 여전히 83.333…이 들어 있습니다.
  • :,는 세 자리마다 쉼표를 찍습니다. 금액을 출력할 때 씁니다.

더 알아보기 · 여러 줄 문자열

따옴표를 세 개씩 써서 """…"""로 둘러싸면 엔터로 줄을 바꿔 가며 여러 줄 문자열을 쓸 수 있습니다. 긴 안내문이나 함수 설명(PY05)에 씁니다. f-문자열은 Python 3.6부터 생긴 문법이라 아주 오래된 Python에서는 동작하지 않습니다. 이 교재가 쓰는 Python 3.14에서는 문제없습니다.

왜 그럴까?

print(f"{count}개")와 print(str(count) + "개")는 같은 결과를 냅니다. 그런데 f-문자열 쪽에서는 str()을 쓰지 않아도 되는 이유는 무엇일까요?

모범 답 보기

f-문자열은 중괄호 안의 값을 계산한 뒤 스스로 글자로 바꿔서 틀에 끼워 넣기 때문입니다. +는 그런 변환을 해 주지 않으므로 정수를 문자열에 이으려면 우리가 직접 str()로 바꿔야 합니다.

이 내용이 다시 나오는 곳

  • PY02·2: input()으로 받은 값은 항상 문자열입니다. 그래서 "3" + "4"가 "34"가 되는 일이 실제로 벌어집니다.
  • PY04: 인덱스와 0부터 세기, 범위를 잘라 내는 슬라이싱을 목록(list)에서 그대로 다시 씁니다.
  • PY07·데이터 분석: CSV 파일의 한 줄은 문자열로 읽혀 들어옵니다. 쉼표로 나누고, 숫자로 바꾸고, 결과를 f-문자열로 보기 좋게 출력하는 일이 데이터 정리의 기본 동작입니다.

한눈에 정리

할 일쓰는 법예와 결과
문자열 만들기큰따옴표나 작은따옴표로 둘러싼다. 여닫는 따옴표는 같은 종류"It's" → It's
특별한 글자이스케이프 \n 줄바꿈, \t 탭, \\ 역슬래시"a\nb" → 두 줄, 길이 3
잇기·되풀이문자열 + 문자열, 문자열 * 정수"1" + "2" → 12, "-" * 3 → ---
글자 수len(문자열). 빈칸·줄바꿈도 한 글자len("빅 데이터") → 5
한 글자 꺼내기인덱스는 0부터, 마지막은 -1"Python"[0] → P, 범위 밖은 IndexError
값 끼워 넣기f-문자열 f"…{값}…", :.1f, :,f"{4900:,}원" → 4,900원

한 줄 정리

문자열은 따옴표로 시작과 끝을 표시한 글자들의 줄이고, +로 잇고, len으로 세고, 0부터 세는 번호로 꺼내고, f-문자열로 값을 끼워 넣는다.
