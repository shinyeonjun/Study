사전분포의 모양에서 MAP와 계수 벌점 읽기

정규화는 계수의 크기에 주는 비용으로 읽을 수 있습니다. 확률 모형에서는 계수가 어떤 범위에 있을 것으로 생각했는지, 즉 사전분포의 모양을 반영한 해석도 가능합니다.

이 장을 읽고 나면

  • 가우스 오차의 음의 로그우도를 제곱오차로 연결한다.
  • 가우스·라플라스 사전의 MAP와 L2·L1을 연결한다.
  • 사후평균과 사후밀도가 최대인 점을 구분한다.

정규 관측 오차를 손실로 바꾼다

평균 θ를 중심으로 분산 1인 정규분포에서 두 독립 관측 y=2,4를 얻었다고 둡니다. θ에 따라 바뀌는 음의 로그우도는 [(2−θ)²+(4−θ)²]/2입니다. 상수 항을 빼도 최소 위치는 같으므로, θ의 최대우도 추정치는 두 값을 평균한 3입니다.

사후밀도에 로그를 적용하고 부호를 바꾼다

이제 θ의 사전도 평균 0, 분산 1인 정규분포로 둡니다. 관측을 본 뒤의 사후밀도는 우도와 사전밀도의 곱에 비례합니다. 로그에서는 곱이 합이 되고, 음의 로그를 최소화하는 것은 사후밀도를 최대화하는 일과 같습니다. 이 점 추정치를 MAP(최대 사후 추정, maximum a posteriori)라고 합니다. 식으로는 θ̂MAP=argmax p(θ|y)=argmin[−log p(y|θ)−log p(θ)]이고, 증거 p(y)는 θ와 무관해 빠집니다.

θ에 관한 음의 로그사전은 θ²/2입니다. 두 제곱오차에 이 식을 더해 미분하면 (θ−2)+(θ−4)+θ=3θ−6이고 0이 되는 θ=2가 MAP입니다. 이 정규 사후분포는 θ=2에서 대칭이라 평균도 2이고, 정밀도(분산의 역수)는 3이라 분산은 1/3입니다. θ=2를 출력하는 것만으로 그 분산까지 전해지는 것은 아닙니다.

가운데가 뾰족한 사전은 절대값을 만든다

정규 사전 대신 중심 0, 척도 b인 라플라스 사전의 밀도가 exp(−|θ|/b)에 비례한다고 합시다. 음의 로그에는 |θ|/b가 들어갑니다. 따라서 우도에 이 사전을 적용한 MAP는 L1 벌점과 같은 형태입니다. b=1인 예에서 θ>0이면 미분은 (θ−2)+(θ−4)+1=2θ−5입니다. 0이 되는 θ=2.5가 이 볼록 목적함수의 최소입니다.

관측 2, 4의 조건추가 비용선택한 θ
최대우도없음3
정규 사전 MAPθ²/22
라플라스 사전 MAP|θ|2.5
from fractions import Fraction as F

y = [2, 4]
n, total = len(y), sum(y)
mle = F(total, n)
gaussian_map = F(total, n+1)
laplace_map = F(total-1, n)
assert laplace_map > 0

def data_loss(theta):
    return sum((value-theta)**2 for value in y)/2

for name, point, extra in (("MLE", mle, lambda x: 0),
                           ("정규 MAP", gaussian_map, lambda x: x*x/2),
                           ("라플라스 MAP", laplace_map, abs)):
    value = data_loss(point) + extra(point)
    assert all(value <= data_loss(point+d) + extra(point+d)
               for d in (F(-1, 2), F(1, 2)))
    print(name, point)

실행 결과

MLE 3
정규 MAP 2
라플라스 MAP 5/2

벌점의 세기 λ는 오차 분산과 사전 척도의 비로 정해집니다. 관측 오차의 분산을 σ², 정규 사전의 분산을 τ²로 일반화하면 음의 로그사후는 (1/(2σ²))Σ(yᵢ−θ)²+θ²/(2τ²)+상수입니다. 전체에 σ²를 곱해도 최소 위치는 같으므로 ½Σ(yᵢ−θ)²+(λ/2)θ², λ=σ²/τ²인 L2 벌점 문제가 됩니다. 사전 분산 τ²가 작을수록(0 근처를 강하게 믿을수록) λ가 커집니다. 위 예는 σ²=τ²=1이라 λ=1이었습니다. 라플라스 사전이면 같은 방법으로 λ=σ²/b인 L1 벌점이 됩니다. 우도 대신 표본별 손실의 평균을 쓰면(전체를 n으로 나누면) 사전 항도 같은 비율로 조정해야 같은 해를 얻습니다. 높은 사후밀도의 위치는 일반적으로 사후평균과 다를 수 있고, 연속 사후에서 점 하나 자체의 확률을 최대화한다는 뜻도 아닙니다. 예를 들어 라플라스 사전의 MAP는 라쏘처럼 정확한 0이 될 수 있지만, 같은 사후분포의 평균은 0을 사이에 둔 양쪽 질량을 모두 평균하므로 보통 0이 아닙니다. '라쏘 = 라플라스 사전'은 MAP 점 추정에 한한 대응입니다.

MAP는 사후밀도가 가장 높은 점이고, 사후평균과는 사후분포가 정규처럼 좌우 대칭이고 봉우리가 하나일 때 일치하며, 비대칭이면 보통 다릅니다. 점 추정 하나는 사후분포의 퍼짐(사후분산)을 담지 않습니다.

한 줄 정리

MAP에서 제곱·절대값 벌점은 사전밀도에 음의 로그를 취하면서 나타납니다.
