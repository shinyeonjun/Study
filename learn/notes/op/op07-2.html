교차엔트로피와 KL, 실제와 다른 확률의 비용

실제로 A가 자주 나오는데 A와 B가 비슷하게 나온다고 짐작했습니다. 그 모형의 확률로 길이를 고르면 평균 비용이 얼마나 늘어날까요? 실제 사례의 빈도로 평균을 내되 로그 안의 확률은 모형에서 얻습니다.

이 장을 읽고 나면

  • 위치가 같은 두 이산분포에서 교차엔트로피와 KL을 계산한다.
  • 확률이 0일 때 유한한 항과 무한대인 항을 구별한다.
  • 관측 정답 한 건의 로그 손실과 평균 손실을 설명한다.

평균을 내는 확률과 비용을 정하는 확률을 구별한다

실제 출처의 분포를 P=(0.75,0.25), 이를 예측한 모형의 분포를 Q=(0.50,0.50)이라 합니다. 동일한 순서의 두 결과 A,B에 대한 분포입니다. 교차엔트로피는 H(P,Q)=−Σ pᵢ log₂ qᵢ입니다. 실제로 관측하는 빈도에 p를, 모형이 정한 예상 비용에 q를 씁니다. Q가 둘 다 1/2로 보면 비용은 모두 1비트라 평균도 1비트입니다.

P의 엔트로피는 −0.75log₂(0.75)−0.25log₂(0.25)≈0.8113비트입니다. Q를 써서 늘어난 평균 비용 H(P,Q)−H(P)을 KL 발산이라 합니다. 같은 로그 밑에서 D(P‖Q)=Σ pᵢ log₂(pᵢ/qᵢ)이고 이 예에서는 0.1887비트입니다.

KL은 방향과 양의 확률이 있는 범위를 살핀다

KL은 0 이상입니다. 양의 p가 있는 자리에서 −ln(q/p)≥1−q/p 이므로 p를 곱해 더하면 Σ(p−q)≥0입니다. 이때 P의 양의 범위에서 p의 합은 1이고, q의 합은 최대 1입니다. 같은 분포일 때 0입니다. P와 Q를 뒤집으면 가중치가 달라져 이 예에서는 D(Q‖P)≈0.2075비트입니다. 따라서 KL은 일반적인 거리처럼 대칭일 필요가 없습니다.

분포가 확률을 양수로 배정한 결과들의 집합을 지지집합이라 합니다. 어떤 결과에서 p>0인데 q=0이면 그 결과가 현실에서 나올 수 있는데 모형은 불가능하다고 대답한 셈입니다. 이 경우 CE와 D(P‖Q)는 모두 양의 무한대입니다. p=0인 자리의 항은 0으로 다룹니다. 유한한 KL에는 P의 지지집합이 Q에 포함되어야 합니다.

실행 예제

from math import inf, log2

def entropy(p):
    return -sum(v * log2(v) for v in p if v > 0)

def cross_entropy(p, q):
    pairs = list(zip(p, q, strict=True))
    if any(a > 0 and b == 0 for a, b in pairs):
        return inf
    return -sum(a * log2(b) for a, b in pairs if a > 0)

p, q = (0.75, 0.25), (0.5, 0.5)
print(f"H(P)={entropy(p):.4f}, CE(P,Q)={cross_entropy(p,q):.4f}")
print(f"KL(P||Q)={cross_entropy(p,q)-entropy(p):.4f}")
print(f"KL(Q||P)={cross_entropy(q,p)-entropy(q):.4f}")
print(f"q(B)=0 with p(B)>0: {cross_entropy(p,(1,0))}")

실행 결과

H(P)=0.8113, CE(P,Q)=1.0000
KL(P||Q)=0.1887
KL(Q||P)=0.2075
q(B)=0 with p(B)>0: inf

코드는 합이 1이고 음수가 없는 두 분포를 입력으로 가정합니다. 수치 오차로 계산 중 확률이 0처럼 보인 상황과 모형에서 정확히 0을 지정한 상황도 구별합니다.

정답 한 건의 교차엔트로피를 계산한다

정답이 A라면 그 한 건의 정답 분포를 (1,0)으로 놓습니다. 교차엔트로피는 A에 예측한 확률이 q일 때 −log₂(q) 하나만 남습니다. 여러 사례의 값을 평균하면 모형의 확률 예측을 비교하는 로그 손실이 됩니다.

왜 그럴까?

실제 분포 P가 같은 문제에서 KL과 교차엔트로피로 고른 모형의 순서는 왜 같을까요?

모범 답 보기

교차엔트로피는 두 모형에 공통인 H(P)에 각 모형의 KL을 더한 값입니다. 같은 만큼을 더해도 두 값의 순서가 유지됩니다.
