조건수와 잔차로 선형계 풀이의 민감도 읽기

관측한 합이 아주 조금 달라졌는데 연립식의 해가 크게 움직이는 사례를 살핍니다. 입력의 민감도와 계산값이 식을 얼마나 잘 맞추는지를 구분합니다.

이 장을 읽고 나면

  • 조건이 좋지 않은 선형계에서 작은 입력 변화의 영향을 계산한다.
  • 조건수와 잔차가 말해 주는 정보를 구분한다.
  • NumPy의 선형계 풀이로 두 입력을 대조한다.

거의 같은 내용을 담은 두 식

두 미지수 u와 v의 합은 2입니다. 두 번째 식은 u+1.001v=2.001입니다. 두 식을 빼면 0.001v=0.001이라 v=1, u=1입니다. 다른 측정에서 두 번째 우변만 2.002가 되었다고 합시다. 이제 0.001v=0.002여서 v=2, u=0입니다.

행행렬 A와 우변 b바뀐 우변
첫 식u + v = 2u + v = 2
둘째 식u + 1.001v = 2.001u + 1.001v = 2.002
해(1, 1)(0, 2)

두 식이 거의 같은 방향으로 u와 v를 합치기 때문에, 둘의 차이로 각 값을 분리하려면 아주 정확한 조건이 필요합니다. 예처럼 우변의 작은 변동만으로 해가 크게 이동할 수 있습니다. 계산 프로그램의 결과가 달라졌다고 하기 전에 식 자체가 민감한지 확인합니다.

조건수로 잠재적인 증폭을 표시한다

벡터의 무한 노름은 성분 절댓값 중 가장 큰 값입니다. 대응하는 행렬의 무한 노름은 행별로 성분 절댓값을 더한 것 중 가장 큰 값입니다. 가역인 행렬 A의 조건수는 같은 노름을 사용한 κ(A)=‖A‖·‖A⁻¹‖입니다. 이 예에서 ‖A‖∞=2.001이고, 역행렬의 첫 번째 행에서 절댓값을 더한 2001이 ‖A⁻¹‖∞입니다. 따라서 κ∞=2.001×2001=4004.001입니다.

역행렬은 A⁻¹=(1/0.001)·[[1.001, −1], [−1, 1]]=[[1001, −1000], [−1000, 1000]]이고, 행별 절댓값 합은 2001과 2000입니다. 조건수는 항상 1 이상이며(‖I‖=1 ≤ ‖A‖‖A⁻¹‖), 특이 행렬은 κ=∞로 봅니다. 값은 어떤 노름을 쓰는지에 따라 조금 다릅니다. np.linalg.cond(A)의 기본값은 2-노름(가장 큰 특이값 ÷ 가장 작은 특이값)으로, 이 행렬에서는 약 4002.0입니다.

가역인 A에서 처음 우변 b가 영벡터가 아니고 b만 달라진다고 합시다. 모두 같은 무한 노름으로 재면 해의 상대 변화는 조건수와 입력의 상대 변화의 곱 이하입니다. 이 예의 입력 상대 변화는 0.001/2.001≈0.000500이고, 해의 상대 변화는 1/1=1입니다. 상한은 4004.001×(0.001/2.001)=2.001로, 실제 변화보다 큽니다. 민감한 문제라도 작은 변화가 어떤 방향이냐에 따라 매번 상한까지 증폭되지는 않습니다.

‖Δx‖/‖x‖ ≤ κ(A) · ‖Δb‖/‖b‖

컴퓨터에 b를 저장하는 것만으로도 상대오차가 약 10⁻¹⁶ 생기므로, 이 부등식은 경험 규칙 하나를 줍니다. 조건수가 10k 정도이면 안정한 방법으로 풀어도 해에서 십진 k자리 정도를 잃을 수 있습니다. 이 예(κ≈4×10³)에서는 약 3~4자리입니다. A의 성분에 오차가 있을 때도 같은 κ가 증폭의 크기를 나타냅니다.

import numpy as np

matrix = np.array([[1, 1], [1, 1.001]])
for right in (np.array([2, 2.001]), np.array([2, 2.002])):
    solution = np.linalg.solve(matrix, right)
    residual = np.linalg.norm(matrix @ solution - right, ord=np.inf)
    shown = [int(round(float(v))) for v in solution]
    print("해:", shown, "잔차가 기준 이내:", residual < 1e-12)
    assert residual < 1e-12
print("조건수:", f"{np.linalg.cond(matrix, np.inf):.3f}")

실행 결과

해: [1, 1] 잔차가 기준 이내: True
해: [0, 2] 잔차가 기준 이내: True
조건수: 4004.001

식을 잘 만족해도 원래 값과 멀 수 있다

잔차 A·계산해−b가 작으면 그 계산해가 주어진 식에는 가깝게 맞습니다. 입력 b가 실제 측정에서 흔들리거나 민감한 A를 썼다면 원래 기대한 해가 무엇인지는 별도로 확인해야 합니다. 원래 식(우변 2, 2.001)에 다른 측정의 해 (0,2)를 넣어 보면 잔차는 (0, 0.001)로 무한 노름이 0.001에 불과합니다. 그런데 참해 (1,1)과의 거리는 1입니다. 조건이 나쁜 문제에서는 잔차가 작아도 해의 오차는 클 수 있습니다. 계산해를 x̂, 참해를 x, 잔차를 r=Ax̂−b라 하면 ‖x̂−x‖/‖x‖ ≤ κ(A)·‖r‖/‖b‖가 성립합니다(r을 우변의 변화로 보면 위 부등식과 같은 식). 이 예에서는 4004.001×0.001/2.001=2.001 ≥ 1입니다.

역행렬을 곱하지 않고 solve를 쓰는 이유

np.linalg.solve(A,b)는 LAPACK의 LU 분해(부분 피벗팅을 쓰는 가우스 소거)로 Ax=b를 직접 풉니다. n×n에서 약 (2/3)n³번의 곱셈·덧셈이 들고, 얻은 해의 잔차가 반올림 수준으로 작습니다(작은 잔차를 보장하는 성질을 후진 안정성이라고 합니다). 역행렬을 구해 곱하면 약 2n³번으로 세 배쯤 비싸고, 조건이 나쁠수록 잔차와 오차가 보통 더 커집니다. 우변이 여러 개라도 분해를 한 번 하고 재사용하면 되므로, 역행렬 자체가 필요할 때가 아니면 만들지 않습니다.

import numpy as np

n = 8
i, j = np.indices((n, n))
A = 1.0 / (i + j + 1)          # 힐베르트 행렬: 조건이 매우 나쁜 대표 예
x_true = np.ones(n)
b = A @ x_true

by_solve = np.linalg.solve(A, b)
by_inverse = np.linalg.inv(A) @ b
print("조건수:", f"{np.linalg.cond(A):.1e}")
for name, x in (("solve", by_solve), ("inv 곱", by_inverse)):
    residual = np.linalg.norm(A @ x - b, np.inf)
    error = np.linalg.norm(x - x_true, np.inf)
    print(f"{name}: 잔차 {residual:.1e}, 해의 오차 {error:.1e}")

실행 결과 (NumPy·BLAS 환경에 따라 뒷자리는 달라질 수 있습니다)

조건수: 1.5e+10
solve: 잔차 4.4e-16, 해의 오차 1.3e-07
inv 곱: 잔차 5.0e-08, 해의 오차 9.5e-07

solve의 해는 오차가 10⁻⁷ 정도로, κ≈10¹⁰에서 16자리 중 약 10자리를 잃은 것과 맞습니다. 그래도 잔차는 반올림 수준입니다. 방법을 바꿔 계산 오차를 줄여도 주어진 문제의 조건수 자체가 새로 좋아지는 것은 아닙니다.

잔차로 주어진 식의 적합을 확인하고, 조건수와 입력의 정확도로 해가 얼마나 믿을 만한지 판단합니다.
