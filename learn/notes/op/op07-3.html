OP07·3

결합분포가 알려 주는 상호정보량

두 알림 X와 Y는 각각 절반의 확률로 켜집니다. 그런데 X가 켜졌을 때 Y도 켜질 확률이 3/4이라면, X를 읽은 뒤 Y에 대해 더 많이 알게 됩니다. 결합표에서 그 감소량을 비트로 구합니다.

이 장을 읽고 나면

  • 결합표에서 주변확률과 조건부확률을 계산한다.
  • 조건부 엔트로피와 상호정보량의 관계를 사용한다.
  • 상호정보량, 독립성, 상관, 인과를 구별한다.

두 변수의 조합 확률을 주변확률과 비교한다

PR07의 결합·주변·조건부분포를 사용합니다. 합성 자료에서 X와 Y가 각각 0 또는 1입니다. 두 값이 같으면 각 칸의 확률이 3/8, 다르면 각 칸이 1/8입니다. 행의 합과 열의 합인 주변확률은 각각 1/2입니다.

X=0을 조건으로 걸면 Y=0의 확률은 (3/8)/(1/2)=3/4입니다. X=1이면 Y=1이 같은 확률 3/4입니다. 독립이면 조건에 따라 확률이 바뀌지 않아 두 조건 모두 Y의 분포가 (1/2,1/2)였을 것입니다.

어떤 X가 나와도 평균적으로 줄어드는 양을 구한다

조건을 알기 전 Y는 두 결과가 반씩이라 H(Y)=1비트입니다. X=0을 아는 조건의 엔트로피는 −(3/4)log₂(3/4)−(1/4)log₂(1/4)≈0.8113비트입니다. X=1일 때는 두 확률의 순서만 바뀌어 같은 값입니다.

조건부 엔트로피 H(Y|X)는 각 X에서 계산한 엔트로피를 그 X의 확률로 평균 낸 값입니다. 이 예는 0.5×0.8113+0.5×0.8113≈0.8113입니다. 평균적으로 줄어든 양인 상호정보량은 I(X;Y)=H(Y)−H(Y|X)≈0.1887비트입니다.

결합분포 P와, 두 변수가 독립이라고 두어 주변확률을 곱한 분포 Q의 KL을 계산해도 같습니다. Σ p(x,y)log₂[p(x,y)/(p(x)p(y))]입니다. 결합 확률에서 직접 계산하는 점이 X와 Y의 자리를 바꿔도 같은 값이 나오는 이유입니다.

실행 예제

from math import log2

def mi(table):
    px = list(map(sum, table))
    py = list(map(sum, zip(*table)))
    return sum(p * log2(p / (px[i] * py[j]))
               for i, row in enumerate(table)
               for j, p in enumerate(row) if p > 0)

examples = {
    "noisy match": [[3/8,1/8],[1/8,3/8]],
    "independent": [[1/4,1/4],[1/4,1/4]],
    "exact match": [[1/2,0],[0,1/2]],
}
for name, table in examples.items():
    print(f"{name}: I={mi(table):.4f} bits")

실행 결과

noisy match: I=0.1887 bits
independent: I=0.0000 bits
exact match: I=1.0000 bits

같이 움직인다는 뜻을 구체적으로 해석한다

이산분포를 정확히 아는 경우 상호정보량이 0인 것과 두 변수가 독립인 것은 같은 조건입니다. 자료의 일부만 세어 만든 결합표에서는 추정값이 어긋날 수 있습니다. 범주를 어디에서 나누었는지와 관측 건수의 영향도 확인합니다.

선형 상관이 0이어도 상호정보량이 양수일 수 있습니다. X가 −1, 0, 1을 각각 확률 1/3로 가지며 Y=X²라면 양수·음수 방향이 대칭이라 공분산은 0입니다. 그러나 X를 알면 Y를 완전히 알려 줄 수 있습니다. 큰 상호정보량은 두 값의 의존을 설명하지만 어느 쪽이 원인이거나 제3의 원인이 없다고 정해 주지는 않습니다.
