OP11·2

기댓값을 아는 변수를 빼서 표준오차 줄이기

복잡한 수치가 올라갔다 내려갈 때 같이 움직이는 간단한 수치가 있다고 합시다. 그 간단한 수치의 평균을 이미 알면, 평균은 그대로 두면서 무작위 흔들림 일부를 빼낼 수 있습니다.

이 장을 읽고 나면

  • 평균이 알려진 변수를 사용해 무편향 추정량을 만든다.
  • 공분산을 이용해 분산을 최소로 만드는 계수를 유도한다.
  • 별도 표본을 이용한 계수 추정과 비교의 조건을 설명한다.

평균은 0인 교정항을 만든다

같은 표본 X에서 두 값 G=g(X), H=h(X)를 구합니다. E[G]를 모르고 E[H]=m은 정확히 안다고 합시다. 제어 변수(control variate)는 G와 함께 변하는 H를 이용합니다. Z=G−c(H−m)로 놓으면, 고정한 c에 대해 E[Z]=E[G]입니다. H−m의 평균이 0이기 때문입니다. G와 H가 같은 X에서 나와 서로 의존해도 이 기대값 계산은 유지됩니다.

교차항까지 쓰면 최적 계수가 보인다

두 변수의 분산은 유한하다고 두고, Var(H)>0이라 가정합니다. 분산에는 상수 m이 영향을 주지 않습니다.

Var(Z)=Var(G)−2c Cov(G,H)+c² Var(H)

c에 대한 양의 이차식이므로 미분을 0으로 만드는 c*=Cov(G,H)/Var(H)에서 최소입니다. 이를 대입하면 Var(Z*)=Var(G)−Cov(G,H)²/Var(H)입니다. G의 분산도 양수라면 상관계수 ρ를 사용해 Var(G)(1−ρ²)라고 쓸 수 있습니다. 상관이 0이면 이 형태의 선형 교정이 얻는 이득은 0입니다. H가 상수라면 H−m이 0이라 c를 정할 필요가 없습니다.

세 가지 상태에서 손으로 뺄 값을 계산한다

X가 0,1,2에 균등하고 G=X², H=X입니다. E[H]=1, Var(H)=2/3입니다. E[X³]=(0+1+8)/3=3이고 E[X²]=5/3이라 Cov(G,H)=3−5/3=4/3입니다. 따라서 계수는 2입니다.

실험으로 확인하기

from fractions import Fraction as F

def avg(x):
    return sum(x)/len(x)

def variance(x):
    m = avg(x)
    return avg([(v-m)**2 for v in x])

h = [F(x) for x in (0,1,2)]
g = [x*x for x in h]
m = avg(h)
cov = avg([(a-avg(g))*(b-m) for a,b in zip(g,h)])
c = cov/variance(h)
z = [a-c*(b-m) for a,b in zip(g,h)]
print(c, *z)
print(avg(g), avg(z))
print(variance(g), variance(z), variance(g)/variance(z))
assert variance(z) == variance(g)-cov**2/variance(h)

실제로 공분산을 모르면 작은 예비 표본으로 c를 추정한 뒤 새 독립 표본에서 고정해 적용할 수 있습니다. 계수가 유한한 범위에 들도록 제한하고, 예비 자료에서 H의 분산이 0이면 c=0으로 두는 규칙을 사용할 수 있습니다. 예비 자료를 조건으로 두면 c는 상수이고, 독립인 본 표본의 교정항의 기대값은 여전히 0입니다. 최종 추정량의 절댓값 기대가 유한하므로 예비 자료에 대해 다시 평균할 수 있습니다. 같은 자료에서 c까지 추정하면 이 독립성 논증을 그대로 쓸 수 없습니다. 실제 분산이 감소했는지 확인하려면 독립 반복에서 평균 추정량의 산포를 비교합니다.
