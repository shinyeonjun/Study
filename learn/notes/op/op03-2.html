OP03·2

두 매개변수에서 기울기를 계산하고 멈추기

두 점을 예측하는 직선에서 절편과 기울기 계수를 동시에 조정합니다. 잔차가 어떻게 기울기가 되는지 손으로 계산하고, 반복을 어떤 이유로 멈췄는지 코드에 남깁니다.

이 장을 읽고 나면

  • 직선 예측의 잔차, 제곱 손실, 편미분으로 이루어진 기울기를 계산한다.
  • 현재 기울기를 기준으로 두 매개변수를 동시에 한 걸음 갱신한다.
  • 손실의 배율이 학습률과 종료 기준에 영향을 주는 이유를 설명하고, 실패와 종료를 구분한다.

두 자료점의 예측과 잔차를 적는다

관측 자료는 (x,y)=(0,1), (2,5)입니다. 두 매개변수 b와 m으로 직선 ŷ=b+mx를 만듭니다. x는 관측된 입력, y는 관측된 정답, ŷ는 예측입니다. 여기서 바꿀 것은 입력 x가 아니라 절편 b와 기울기 계수 m입니다. 매개변수 묶음을 열벡터 w=(b,m)⊤로 적습니다.

이 장에서는 잔차를 r=예측−관측으로 정합니다. b=0.6, m=1인 직선에서 예측은 0.6과 2.6이므로 잔차는 −0.4와 −2.4입니다. 회귀 모형의 오차를 평가하는 장에서는 관측−예측을 써서 부호가 반대입니다. 제곱한 손실은 어느 쪽이든 같은 값입니다. 미분식과 해설에서는 각 장이 정한 잔차의 부호가 어떤 뜻인지 확인합니다.

잔차가 자료마다 하나씩 있으므로 r0=b−1, r1=b+2m−5입니다. 자료가 n개일 때 여기서 쓸 손실은 제곱 잔차의 평균에 1/2를 곱한 것입니다. 두 관측이므로 J(b,m)=[(b−1)²+(b+2m−5)²]/4입니다.

한 위치에서 두 편미분을 계산해 동시에 갱신한다

b로 미분할 때 m을 고정합니다. 두 잔차의 b에 대한 편미분이 모두 1이므로 ∂J/∂b=(r0+r1)/2입니다. m으로 미분할 때 b를 고정합니다. 첫 입력은 x=0이기 때문에 r0은 m의 영향을 받지 않습니다. 두 번째는 x=2이므로 ∂J/∂m=2r1/2입니다.

두 편미분을 같은 위치 w에서 계산해 기울기 ∇J(w)로 묶습니다. ∇J의 방향은 길이가 같은 작은 이동 중 손실을 가장 빠르게 늘리는 쪽입니다. 반대로 −∇J 쪽으로 충분히 작게 이동하면 기울기가 0이 아닌 매끄러운 점에서 손실이 줄어듭니다. 일차 근사에서 점 하나의 기울기 g와 이동 벡터 Δw를 내적하면 손실 변화가 g⊤Δw에 가깝습니다. Δw=−ηg이면 이 내적은 −η∥g∥²입니다.

손으로 풀기 · 처음 두 걸음

(b,m)=(0,0)에서 잔차는 (−1,−5), 기울기는 (−3,−5)입니다. η=0.2이면 w1=(0,0)−0.2(−3,−5)=(0.6,1)입니다. 손실은 6.5에서 1.48로 줄었습니다.

다음 걸음에서는 w1의 잔차 (−0.4,−2.4)를 다시 구합니다. 기울기는 (−1.4,−2.4)여서 w2=(0.6,1)−0.2(−1.4,−2.4)=(0.88,1.48)입니다. 두 좌표 모두 w1에서 얻은 기울기로 동시에 갱신합니다. J(w2)=0.34입니다.

직선이 두 관측을 모두 지나려면 b=1, b+2m=5여서 m=2입니다. 이때 J=0이고 제곱의 합은 음이 될 수 없으므로 전역 최소입니다. 이 예에서는 정확한 해를 손으로 구할 수 있어 반복의 결과를 비교할 수 있습니다.

행렬로 여러 잔차와 기울기를 한 번에 계산한다

설계행렬 X의 한 행은 관측 하나의 입력입니다. 절편 b 앞에 1을 놓아 X의 두 행을 (1,0), (1,2)로 씁니다. y=(1,5)⊤입니다. r=Xw−y가 잔차 벡터입니다. X⊤에서 첫 행은 (1,1), 둘째 행은 (0,2)라서 r을 곱하면 앞서 계산했던 두 편미분에 필요한 합을 얻습니다.

J(w) = r⊤r/(2n).
∇J(w) = X⊤r/n.
wk+1 = wk − η∇J(wk).

코드의 X.shape는 (2,2)입니다. w와 y는 각각 길이 2인 1차원 배열입니다. X @ w는 행마다 열벡터 w와 내적하는 수학식과 같습니다. X.T @ residual로 얻은 길이 2의 배열 원소 순서는 절편 방향, 기울기 계수 방향입니다.

손실의 배율과 종료 기준을 함께 기록한다

1/2을 곱하기 전의 평균제곱오차를 손실로 쓰면 값과 기울기는 모두 두 배입니다. 이 경우 argmin은 같고, 같은 실제 갱신을 원한다면 학습률을 절반으로 줄입니다. 제곱 오차의 합을 쓰면 여기서의 J에 2n을 곱합니다. 두 코드의 학습률을 비교할 때는 손실의 수식과 평균을 내는 범위를 확인합니다.

이 장의 프로그램은 매 걸음 손실과 기울기가 유한한지 확인하고, ∥∇J∥이 설정한 허용값보다 작거나 같은 때 종료합니다. 기울기 크기 또한 손실의 배율을 따라 바뀌므로 이 허용값을 같은 숫자로 두면 서로 다른 위치에서 멈출 수 있습니다. 학습률이 아주 작거나 수치 정밀도에 막히면 w가 거의 안 움직여도 기울기가 아직 클 수 있습니다. 평평한 점에서 기울기가 작다는 사실만으로 모든 함수의 전역 최적을 증명할 수는 없습니다.

반복 한도에 도달했다면 그 시점의 변수와 종료 이유를 기록합니다. 손실이 계속 커지면 학습률과 미분의 부호를 확인하고, 유한한 값에서 벗어나면 수치 계산과 입력을 점검합니다. 종료했는지와 유용한 해를 얻었는지는 각각 판단합니다.

흔한 종료 기준식주의할 점
기울기 크기∥∇J(wk)∥ ≤ tol손실의 배율에 따라 값이 바뀝니다.
손실 변화|J(wk)−J(wk+1)| ≤ tol (또는 J로 나눈 상대 변화)평평한 구간이나 작은 학습률에서 너무 일찍 멈출 수 있습니다.
이동 거리∥wk+1−wk∥ ≤ tol이동 거리 = η∥∇J∥이라 학습률이 작으면 기울기가 커도 만족합니다.
반복 한도k = max_steps수렴의 근거가 아니라 계산 예산입니다.

더 알아보기 · 두 변수에서 쓸 수 있는 학습률

OP03-1의 한 변수 이차함수에서는 0<η<2/L이었습니다. 이 장의 J도 이차함수라 곡률이 행렬 H=X⊤X/n=[[1,1],[1,2]]로 정해지고, 방향마다 곡률이 다릅니다. 가장 가파른 방향의 곡률(H의 가장 큰 고윳값 (3+√5)/2≈2.618)이 L 역할을 해서 고정 학습률은 η<2/2.618≈0.764여야 수렴합니다. 가장 완만한 방향(고윳값 ≈0.382)은 이동이 느려 반복 수를 늘립니다. 고윳값은 선형대수 단원에서 다룹니다.

초기값과 종료 이유를 재현한다

처음에는 0에서 시작해 손계산과 대조합니다. 이후 시드 7에서 생성한 다른 초기값으로 실행하고, 몇 번 실제로 갱신한 뒤 어떤 기준으로 종료했는지 출력합니다. 이 코드는 매번 두 관측을 모두 쓰는 전체 자료 경사하강입니다. 난수는 시작값에만 사용합니다. 뒤 단원에서 일부 표본으로 방향을 추정하는 방법을 다룹니다.

import numpy as np

X = np.array([[1.0, 0.0], [1.0, 2.0]])
y = np.array([1.0, 5.0])

def loss_and_gradient(w):
    residual = X @ w - y
    return (residual @ residual) / (2 * len(y)), X.T @ residual / len(y)

def train(initial, rate, grad_tol, max_steps):
    w = initial.copy()
    for step in range(max_steps + 1):
        loss, gradient = loss_and_gradient(w)
        if not np.isfinite(loss) or not np.isfinite(gradient).all():
            return w, step, "유한성 검사 실패"
        if np.linalg.norm(gradient) <= grad_tol:
            return w, step, "기울기 기준"
        if step == max_steps:
            return w, step, "반복 한도"
        w = w - rate * gradient

w = np.zeros(2)
for step in range(3):
    loss, gradient = loss_and_gradient(w)
    print(f"k={step}: b={w[0]:.4f}, m={w[1]:.4f}, J={loss:.4f}")
    w = w - 0.2 * gradient

rng = np.random.default_rng(7)
initial = rng.normal(size=2)
result, steps, reason = train(initial, rate=0.2, grad_tol=1e-7, max_steps=500)
assert np.allclose(result, [1, 2], atol=1e-6, rtol=0)
print(f"시드 초기값: {initial[0]:.4f}, {initial[1]:.4f}")
print(f"{steps}회 갱신 후 {reason}: b={result[0]:.5f}, m={result[1]:.5f}")
k=0: b=0.0000, m=0.0000, J=6.5000
k=1: b=0.6000, m=1.0000, J=1.4800
k=2: b=0.8800, m=1.4800, J=0.3400
시드 초기값: 0.0012, 0.2987
152회 갱신 후 기울기 기준: b=1.00000, m=2.00000

마지막 수는 소수 다섯 자리로 출력합니다. 출력된 1과 2는 반올림 결과입니다. 시드, 라이브러리, 반복 한도, 손실 및 허용값을 같이 기록하면 초기값과 종료 과정의 차이를 추적할 수 있습니다.
