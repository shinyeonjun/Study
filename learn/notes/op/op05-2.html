제약의 경계와 KKT 조건에서 최소점 읽기

가장 좋은 실수값이 허용 구간 밖에 있으면 기울기가 0인 점만 찾아서는 부족합니다. 경계에서 목적함수의 방향과 제약의 역할을 함께 계산합니다.

이 장을 읽고 나면

  • 활성 제약과 느슨한 제약을 구분한다.
  • 간단한 부등식에서 라그랑주 승수와 KKT 조건을 계산한다.
  • 제약의 부호와 승수의 조건을 연결한다.

제약을 벗어난 최적값을 확인한다

목적함수 f(w)=(w−3)²를 작게 하고 싶습니다. 허용 범위가 w≤2라면 제한 없는 최솟값 w=3은 사용할 수 없습니다. w≤2에서 3에 가장 가까운 값인 w=2가 답입니다. 여기서 제약 g(w)=w−2≤0은 w=2에서 g=0이 되므로 활성입니다. 범위가 w≤4라면 w=3이 답이고, 그때 g(w)=w−4=−1이므로 제약에 여유가 있습니다.

기울기와 경계의 영향을 한 식에 넣는다

g≤0인 부등식에 대해 라그랑주 함수 L(w,λ)=f(w)+λg(w)를 만듭니다. 여기서는 λ≥0으로 둡니다. 이 형태의 KKT 조건은 다음과 같습니다.

조건이 예의 식쓰임
원래 제약w−2≤0w가 허용 범위에 있음
승수의 부호λ≥0부등식에 맞는 방향
정지 조건2(w−3)+λ=0합친 함수의 w 기울기가 0
상보성λ(w−2)=0제약에 여유가 있으면 λ=0

w=2에서는 f의 기울기가 −2이고 g의 기울기는 1입니다. 정지 조건을 만족하려면 λ=2입니다. w=2는 허용되고 λ가 양수이며 λ·0=0입니다. 가능 범위 안쪽에 답이 있다고 가정하면 g<0이므로 λ=0이고 정지 조건에서 w=3을 얻습니다. 3은 허용 범위를 벗어나므로 이 경우는 성립하지 않습니다.

for bound in (2, 4):
    w = min(3, bound)
    multiplier = max(0, 2*(3-bound))
    objective = (w-3)**2
    g = w-bound
    assert g <= 0 and multiplier >= 0
    assert 2*(w-3) + multiplier == 0
    assert multiplier*g == 0
    print("상한:", bound, "w:", w, "λ:", multiplier, "손실:", objective)

실행 결과

상한: 2 w: 2 λ: 2 손실: 1
상한: 4 w: 3 λ: 0 손실: 0

조건의 범위를 함께 적는다

이 문제는 볼록한 목적함수와 선형 부등식으로 이루어져 있고 제약을 엄격하게 만족하는 w=1도 있습니다. 여기서는 KKT를 만족하는 점이 전역 최적입니다. 모든 비볼록 문제에서 정지 조건을 확인하는 것만으로 전역 최적이라고 말할 수는 없습니다. 등식 제약 h(w)=0을 라그랑주 함수에 더할 때는 h를 양·음 방향에서 함께 제약하므로 승수의 부호를 부등식처럼 λ≥0으로 제한하지 않습니다.

한 줄 정리

제약 가능성, 승수 부호, 정지 조건, 상보성을 함께 확인해 경계에서의 답을 찾습니다.
