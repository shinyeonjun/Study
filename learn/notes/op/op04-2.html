모멘텀과 Adam이 이전 기울기를 사용하는 방식

미니배치마다 기울기가 흔들릴 때, 최근 기울기로 상태를 쌓는 두 방법을 봅니다. 같은 세 값을 넣고 다음 위치가 어떻게 달라지는지 계산합니다.

이 장을 읽고 나면

  • 지수 이동평균으로 모멘텀 상태를 계산한다.
  • Adam의 일차 상태, 제곱 상태와 편향 보정을 구분한다.
  • 학습률과 옵티마이저 상태를 실험 조건에 기록한다.

최근의 기울기를 이어서 사용한다

학습률 0.1 외에 직전 기울기의 영향을 남길 수 있습니다. 이 장에서 설명하는 모멘텀의 한 표기는 vₜ=βvₜ₋₁+(1−β)gₜ입니다. v₀=0에서 시작하고, w의 새 값은 w−ηv이고, 이번 이동량은 −ηv입니다. 예로 기울기 −6, −2, 2가 순서대로 주어졌다고 합시다. 이 세 값은 갱신 공식을 따로 연습하기 위한 입력입니다.

β=0.5일 때 v의 처음 세 값은 −3, −2.5, −0.25입니다. 마지막 기울기는 양수인데도 이전 음의 값들이 남아 이동 방향은 아직 오른쪽입니다. 구현마다 모멘텀 상태에 (1−β)를 넣을지와 초기값을 어떻게 둘지 다르게 표현할 수 있으므로 사용 중인 옵티마이저 정의를 확인합니다.

표기상태 갱신위치 갱신이 예(β=0.5, η=0.1)의 w
이 장(지수 이동평균)v ← βv + (1−β)gw ← w − ηv0.3, 0.55, 0.575
PyTorch SGD(momentum=β) (dampening=0 기본)v ← βv + gw ← w − ηv0.6, 1.1, 1.15
고전적 무거운 공(Polyak)v ← βv − ηgw ← w + vPyTorch 형과 같은 궤적

PyTorch 형은 (1−β)를 곱하지 않으므로 같은 η에서 이동이 1/(1−β)배 큽니다(β=0.5면 2배, 위 표의 값을 PyTorch 2.14에서 확인). 기울기가 계속 g로 일정하면 v는 g/(1−β)로 다가가 실질 학습률이 η/(1−β)가 됩니다. β는 흔히 0.9를 씁니다(PyTorch의 momentum 기본값은 0, 곧 모멘텀 없음). 이 장의 β=0.5는 손계산을 위한 값입니다.

크기의 최근 기록도 함께 쓸 때

Adam은 기울기 g의 지수평균 m과 제곱 g²의 지수평균 s를 각각 계산합니다. 0으로 시작한 영향 때문에 초기에는 m을 (1−β₁ᵗ)로, s를 (1−β₂ᵗ)로 나눠 보정합니다. 한 성분의 갱신은 w ← w − η·m̂/(√ŝ+ε)입니다. ε는 분모가 지나치게 작아지는 것을 막는 작은 양수입니다. 벡터의 각 성분에서 이런 상태를 따로 계산합니다.

Adam의 한 걸음 (Kingma·Ba 2015, PyTorch와 같은 식) 외우기

mt = β₁mt−1 + (1−β₁)gt
st = β₂st−1 + (1−β₂)gt²
m̂t = mt/(1−β₁t),  ŝt = st/(1−β₂t)
wt = wt−1 − η·m̂t/(√ŝt + ε)

기본값: η=0.001, β₁=0.9, β₂=0.999, ε=10⁻⁸(논문과 PyTorch torch.optim.Adam이 같음). 논문은 제곱 상태를 v로 적고, 이 장은 모멘텀의 v와 헷갈리지 않게 s로 적습니다. m₀=s₀=0에서 시작합니다.

편향 보정이 필요한 이유: 0에서 시작한 지수평균은 처음 몇 걸음 동안 0 쪽으로 끌려 있습니다. 기울기가 일정하게 g이면 mt=(1−β₁t)g이므로, (1−β₁t)로 나누면 정확히 g가 됩니다. β₂=0.999이면 첫 걸음의 s₁은 g²의 0.001배밖에 되지 않아 보정 없이는 분모가 작아져 첫 걸음들이 지나치게 커집니다. t가 커지면 βt→0이라 보정은 사라집니다.

예에서 β₁=β₂=0.5이고 첫 g가 −6이면 m=−3, s=18입니다. 각각 0.5로 나누어 m̂=−6, ŝ=36입니다. ε의 작은 효과를 무시하면 정규화한 방향은 −6/6=−1이며 한 걸음 뒤 w≈0.1입니다. 첫 걸음에서는 β 값과 상관없이 m̂₁=g₁, ŝ₁=g₁²이므로 이동이 η·g₁/|g₁|, 곧 크기 η입니다. Adam의 한 걸음 크기는 기울기의 크기보다 학습률 η에 묶여 있고, 성분마다 최근 기울기 크기로 나누어 큰 성분과 작은 성분의 보폭을 비슷하게 맞춥니다.

from math import sqrt

beta, rate, epsilon = 0.5, 0.1, 1e-8
mean_gradient = mean_square = momentum_value = adam_value = 0.0
for step, gradient in enumerate([-6, -2, 2], start=1):
    mean_gradient = beta*mean_gradient + (1-beta)*gradient
    mean_square = beta*mean_square + (1-beta)*gradient**2
    momentum_value -= rate*mean_gradient
    correction = 1-beta**step
    adjusted_gradient = mean_gradient / correction
    adjusted_square = mean_square / correction
    adam_value -= rate*adjusted_gradient / (sqrt(adjusted_square) + epsilon)
    print(step, f"{momentum_value:.6f}", f"{adam_value:.6f}")

기울기, 상태, 위치를 따로 기록한다

같은 학습률 숫자를 두 방법에 넣어도, 보정과 정규화가 달라 실제 이동 거리가 다릅니다. 실제 학습에서 중간부터 이어 갈 때는 모형의 매개변수와 옵티마이저의 상태를 함께 저장하는지 확인합니다. 매개변수 값만 복구해 처음부터 다시 모멘텀이나 Adam을 시작하면 다음 업데이트가 달라질 수 있습니다.

한 줄 정리

모멘텀은 최근 방향을 남기고 Adam은 최근 제곱 크기로도 갱신을 조절합니다. 학습률과 상태 저장 범위를 같이 적습니다.
