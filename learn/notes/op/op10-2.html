강볼록성에서 기울기를 최적값 오차로 바꾸기

기울기가 작다는 말만으로는 얼마만큼 최적값에 다가갔는지 알기 어렵습니다. 함수가 모든 방향에서 일정한 곡률을 가진다는 가정을 더해, 경사하강의 오차가 어느 비율 이하로 줄어드는지 증명합니다.

이 장을 읽고 나면

  • 강볼록 하계에서 함수값 오차와 기울기 노름의 부등식을 유도할 수 있다.
  • 경사하강의 기하급수 수렴률에 L과 μ가 어떻게 들어가는지 설명할 수 있다.
  • 최적화 오차의 이론적 상계와 실제 좌표의 감소율을 구분할 수 있다.

곡률이 가장 작은 방향에도 하한을 둔다

앞 장에서는 기울기가 얼마나 빠르게 바뀔 수 있는지 L로 제한했습니다. 이번에는 반대쪽으로, 접평면보다 적어도 얼마만큼 더 높아지는지도 제한합니다. 미분 가능한 f가 다음 부등식을 모든 x,y에서 만족하면 μ-강볼록이라고 합니다.

f(y) ≥ f(x)+∇f(x)ᵀ(y−x)+(μ/2)‖y−x‖², μ>0

이차함수 f(x)=(1/2)xᵀAx에서 위 식과 앞 장의 상계는 1/2·dᵀAd 항을 양쪽에서 제한합니다. A가 실대칭 양의 정부호라면 최소 고유값을 μ, 최대 고유값을 L로 사용할 수 있습니다. f(x,y)=(x²+100y²)/2에서는 μ=1, L=100입니다. y 방향이 훨씬 가파릅니다.

아래쪽 포물선의 최솟값도 직접 구한다

최적점 x*가 존재한다고 하고 위 부등식에 y=x*를 넣습니다. 오른쪽에서 가능한 변화량 d=y−x에 대한 이차식의 최솟값을 구하면 실제 y를 모르는 상태에서 오른쪽을 아래에서 제한할 수 있습니다. 완전제곱으로 쓰면

gᵀd+(μ/2)‖d‖² = (μ/2)‖d+g/μ‖² − ‖g‖²/(2μ), g=∇f(x)

입니다. 따라서 f(x*)≥f(x)−‖∇f(x)‖²/(2μ)입니다. 이를 옮기면

‖∇f(x)‖² ≥ 2μ[f(x)−f(x*)]

가 됩니다. 식의 방향을 확인하세요. 일정한 최적값 차가 남아 있으면 기울기도 어느 정도 커야 한다는 의미입니다. 기울기가 아주 작은데 비용이 많이 남는 평평한 영역은 이 전제에서는 허용되지 않습니다.

한 걸음의 감소식을 연결한다

L-매끄러운 함수에 α=1/L를 쓰면 앞 장에서 f(x′)≤f(x)−‖∇f(x)‖²/(2L)을 증명했습니다. 이번 부등식을 여기에 대입하면

f(x′)−f(x*) ≤ (1−μ/L)[f(x)−f(x*)]

입니다. 같은 부등식을 k번 쓰면 f(xₖ)−f(x*)≤(1−μ/L)k[f(x₀)−f(x*)]입니다. 이를 기하급수 수렴이라고 합니다. 최적값 차에 대한 상계이며, 매번 정확히 같은 비율로 줄어든다고 말하지 않습니다.

예제에서 느린 좌표와 빠른 좌표를 분리해 본다

(x²+100y²)/2에서 α=0.01을 쓰면 x는 매번 0.99배로 줄고, y는 한 번에 0이 됩니다. 초기값 (1,1)의 첫걸음에서 비용은 50.5에서 0.49005로 줄지만, 이후에는 남은 x가 천천히 줄어듭니다. 처음부터 (1,0)이었다면 빠른 방향이 없어 첫 스텝부터 느립니다. 같은 L,μ여도 처음의 방향이 실제 경로에 영향을 줍니다.

from fractions import Fraction as F

def cost(point):
    x, y = point
    return (x*x + 100*y*y) / 2

x, y = F(1), F(1)
initial = cost((x, y))
for k in range(1, 11):
    old = cost((x, y))
    x, y = F(99,100)*x, F(0)
    current = cost((x, y))
    assert current <= F(99,100)*old
    if k in (1,10):
        print(f"{k}단계: x={float(x):.6f}, y={float(y):.1f}, 비용={float(current):.6f}")
print(f"첫 비용: {float(initial):.1f}")

실행 결과

1단계: x=0.990000, y=0.0, 비용=0.490050
10단계: x=0.904382, y=0.0, 비용=0.408953
첫 비용: 50.5

이 예에 적용한 상계의 비율은 1−1/100=0.99입니다. 하지만 y가 0이 된 후의 실제 함수값 비율은 (0.99)²입니다. 좌표 x가 0.99배이고 손실에 x²이 들어가기 때문입니다. 함수값과 좌표 오차를 혼동하면 같은 숫자라도 의미가 달라집니다.

계산을 쉽게 만드는 좌표가 따로 있다

이 예에서는 y와 x의 곡률 크기가 크게 다릅니다. y를 다른 단위로 표현해 두 방향의 이차항을 비슷한 크기로 만들면 같은 스텝으로 둘 다 빠르게 줄일 수 있습니다. 다변수에서 상호작용까지 있다면 단순히 각 축을 바꾸는 것만으로 해결되지 않을 수 있습니다. 대각 스케일로 조건을 바꾸는 실습에 같은 구조가 등장합니다.

한눈에 정리

전제얻는 것
μ-강볼록기울기 노름 제곱이 2μ×최적값 차 이상.
L-매끄러움α=1/L의 감소량이 기울기 제곱을 2L로 나눈 값 이상.
두 조건을 결합남은 최적값 차가 최대 1−μ/L배.
실제 경로초기 방향과 좌표 스케일에 따라 이론 상계보다 빨라질 수 있다.
