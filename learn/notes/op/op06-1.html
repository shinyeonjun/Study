L1과 L2 벌점이 계수를 줄이는 방식 비교하기

자료만 맞추면 5가 좋지만, 계수가 커지는 데도 값을 매기면 어느 수를 고를까요? 한 변수에서 왜 L1이 정확한 0을 만들 수 있는지 계산합니다.

이 장을 읽고 나면

  • 적합 손실과 계수 벌점을 구분한다.
  • 한 계수의 L2 축소와 L1의 문턱값을 계산한다.
  • 벌점의 세기를 검증 자료로 선택하는 이유를 설명한다.

손실에서 데이터에 맞추는 부분과 벌점을 나눈다

기록에 맞춘 오차를 단순화해 ½(w−5)²로 둡니다. w는 선택하는 계수입니다. 손실만 보면 w=5가 최적입니다. 여기에 큰 계수에 비용을 부과하는 정규화(벌점)를 더합니다. λ≥0은 비용을 얼마나 강하게 적용할지 정하는 설정입니다.

L2 예제에서는 λw²/2를 더합니다. 미분값은 (w−5)+λw이므로 0인 곳은 w=5/(1+λ)입니다. λ=1이면 2.5, λ=4이면 1입니다. λ가 커질수록 0에 가까워지지만 이 한 계수 예에서는 유한한 λ에서 정확한 0은 되지 않습니다.

절대값을 더하면 0에서 경사가 꺾인다

L1 예제에서는 λ|w|를 더합니다. w>0이면 미분값은 w−5+λ, w<0이면 w−5−λ입니다. λ가 5보다 작을 때 양의 해는 5−λ입니다. λ≥5이면 양수 쪽의 경사는 0 또는 양수로 시작하고 음수 쪽은 계속 내려와, 둘 사이인 0에서 최소입니다. 그래서 이 예의 답은 max(5−λ,0)입니다.

w=0에서 |w|는 미분할 수 없으므로 '기울기=0' 대신 다음 조건을 씁니다. 0에서 |w|의 기울기로 가능한 값은 −1부터 1까지의 구간 전체(이 구간을 |w|의 서브그래디언트 집합이라 합니다)로 봅니다. w=0이 최소일 조건은 (0−5)+λs=0을 만드는 s가 [−1,1] 안에 있는 것, 즉 5≤λ입니다. 일반적으로 w=0에서 잰 데이터 손실의 기울기 크기가 λ 이하이면 계수는 정확히 0에 머뭅니다. L2의 벌점 기울기 λw는 0 근처에서 0으로 작아지므로 이런 '문턱'이 생기지 않습니다.

데이터에만 맞춘 계수 z가 음수일 때는 좌우가 바뀝니다. 기본 손실이 ½(w−z)²인 경우 L1 해는 부호를 유지해 |z|에서 λ를 뺀 뒤, 결과가 음수면 0에 둡니다. 이 연산 sign(z)·max(|z|−λ,0)을 연성 임계값(soft thresholding)이라 하고, 같은 경우 L2 해는 z/(1+λ)로 비율만 줄입니다. 예로 z=−2와 λ=1에서는 w=−1입니다. 여러 특징에서 일부 계수가 0이 되는 결과를 희소성이라고 합니다. 그래서 L1 벌점 회귀(라쏘, Lasso)는 특징 선택을 겸하고, L2 벌점 회귀(릿지, Ridge)는 모든 계수를 남긴 채 줄입니다. 특징이 여러 개이고 서로 상관되어 있으면 계수끼리 영향을 주므로 이 한 변수 공식이 그대로 적용되지는 않지만(특징 행렬의 열이 서로 직교하고 길이가 1인 경우, 즉 XᵀX=I이면 각 계수에 그대로 적용됩니다), 0에서 꺾이는 L1과 매끄러운 L2의 차이는 같습니다.

from fractions import Fraction as F

def ridge(z, weight):
    return z / (1 + weight)

def lasso(z, weight):
    size = max(abs(z) - weight, 0)
    return -size if z < 0 else size

for weight in (0, 1, 4, 5):
    print("λ", weight, "L2", ridge(F(5), weight), "L1", lasso(F(5), weight))
print("음의 z에서 L1:", lasso(F(-2), 1))

실행 결과

λ 0 L2 5 L1 5
λ 1 L2 5/2 L1 4
λ 4 L2 1 L1 1
λ 5 L2 5/6 L1 0
음의 z에서 L1: -1

훈련 자료에서 가장 작은 벌점을 고르는 문제가 아니다

새 자료에 더 잘 일반화하도록 λ를 정할 수 있습니다. 높은 λ에서는 계수가 작아지지만 관련 있는 신호까지 줄어들 수 있습니다. 훈련 폴드에서 각 λ의 계수를 적합하고 검증 폴드에서 목적에 맞는 예측 지표로 비교합니다. 훈련 손실에 더한 벌점과 보고하는 시험 예측 오차에는 여전히 다른 역할이 있습니다.

라이브러리마다 손실의 배율이 달라 같은 숫자의 λ가 같은 세기가 아닙니다. 예를 들어 scikit-learn의 Ridge는 ‖y−Xw‖²+α‖w‖²(오차 제곱의 합)를, Lasso는 (1/(2n))‖y−Xw‖²+α‖w‖₁(오차 제곱의 평균에 ½)을 최소화합니다. 이 교재의 λ에 해당하는 값은 구현의 문서에서 목적함수를 확인해 맞춥니다.

한 줄 정리

L2는 제곱으로 계수를 줄이고, L1은 절대값의 꺾임에서 일정 범위의 계수를 0으로 만들 수 있습니다.
