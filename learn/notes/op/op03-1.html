OP03·1

최솟값을 정의하고 한 변수에서 내려가기

어떤 값을 바꿀 수 있고, 무엇을 가장 작게 만들고 싶은지 정합니다. 제곱 손실의 예에서 기울기를 따라 업데이트하고, 보폭이 커질 때 왜 실패하는지 계산합니다.

이 장을 읽고 나면

  • 최적화 문제에서 바꾸는 변수, 작게 만들 목적함수, 허용하는 제약을 정한다.
  • 목적함수의 최솟값과 그 값을 만드는 변수의 위치를 구분한다.
  • 제곱 손실의 경사하강을 손으로 반복하고, 이 예에서 학습률의 안정 범위를 구한다.

고를 값과 평가할 값을 따로 적는다

목표가 3인 장치 출력을 조절한다고 합시다. 우리가 선택하는 출력 w가 변수입니다. 출력과 목표의 차이는 w−3입니다. 작게 만들 값으로 차이의 제곱 J(w)=(w−3)²를 쓰겠습니다. 양쪽으로 벗어나는 차이를 음이 아닌 수로 비교합니다. 이렇게 후보를 평가하는 J가 목적함수이며, 예측이나 출력이 목표에서 어긋난 정도를 나타낼 때는 손실함수라고도 합니다.

장치에서 가능한 출력이 0부터 2까지라면 0 ≤ w ≤ 2는 제약입니다. 그 범위의 후보들만 비교합니다. 기호 J(w)가 같아도 어떤 w를 고를 수 있는지에 따라 문제가 달라집니다.

최솟값과 최소로 만드는 위치

0 ≤ w ≤ 2에서 w가 2에 가까울수록 (w−3)²은 작아집니다. 따라서 최소 손실은 J(2)=1이고 그때의 변수는 w=2입니다. min은 값, argmin은 그 값을 달성하는 변수의 집합을 반환하는 기호로 쓰겠습니다.

minw∈[0,2] J(w) = 1.   argminw∈[0,2] J(w) = {2}.

제약이 없으면 min은 0, argmin은 {3}입니다. 서로 다른 선택이 같은 최솟값을 줄 수도 있습니다. 예를 들어 J(w)=w²을 허용 후보 {−2,2}에서 비교하면 argmin은 {−2,2}입니다. 또 열린 구간 0 < w < 1에서 J(w)=w라면 0에 아무리 가까이 갈 수 있어도 0을 고를 수는 없습니다. 이 경우 최솟값을 달성하는 후보가 없습니다. 이때 후보들의 값이 내려갈 수 있는 한계 0은 하한(infimum, inf)이라 부르고 min과 구분합니다. argmin은 답이 하나뿐이면 집합 대신 그 원소로 w*=argmin J(w)처럼 쓰는 관례도 흔합니다.

기울기가 향하는 쪽의 반대로 작은 한 걸음을 옮긴다

w를 자유롭게 움직일 수 있다고 합시다. 제곱 손실의 도함수 J′(w)=2(w−3)입니다. w=0에서 도함수는 −6이므로 w를 오른쪽으로 조금 움직이면 손실이 줄어듭니다. w=5에서는 도함수가 4이므로 왼쪽으로 조금 움직이면 줄어듭니다. 작은 변화 Δw에 대해 J(w+Δw)−J(w) ≈ J′(w)Δw입니다. 변화량을 도함수와 반대 부호로 정하면 이 근삿값이 음수가 됩니다.

wk+1 = wk − η J′(wk).

이 갱신을 반복하는 방법을 경사하강이라고 합니다. 양수 η는 학습률로, 도함수에 곱해 얼마나 옮길지 정합니다. 실제 이동 거리의 크기는 η|J′(wk)|입니다. 갱신할 때는 도함수를 새 위치에서 다시 계산합니다.

두 번 갱신하기

w0=0, η=1/4로 둡니다. 첫 도함수 −6을 쓰면 w1=0 − (1/4)(−6)=1.5입니다. w1에서 도함수는 −3이므로 w2=1.5 − (1/4)(−3)=2.25입니다. 손실은 차례로 9, 2.25, 0.5625입니다.

제약이 있다면 새 w가 허용 범위 안에 있는지 확인해야 합니다. 예를 들어 [0,2]에서 1.5 다음으로 나온 2.25를 가까운 허용점 2로 보내는 방법이 있습니다. 이 문제의 해 2에서 J′(2)=−2입니다. 제약의 경계에서는 도함수가 0이 아닌 점도 최적일 수 있습니다. 아래 학습률 계산은 자유롭게 w를 움직이는 경우입니다.

이 제곱 함수에서 수렴이 가능한 학습률

정답 w=3에서 얼마나 벗어났는지 ek=wk−3이라 놓습니다. 갱신식의 양쪽에서 3을 빼면 오차는 다음처럼 매번 같은 수가 곱해집니다.

ek+1 = ek − 2ηek = (1 − 2η)ek.

w0가 3이 아니면, |1−2η| < 1일 때 오차가 0으로 수렴합니다. 이 부등식을 풀면 0 < η < 1입니다. 0 < η < 1/2에서는 정답의 같은 편에서 접근합니다. η=1/2에서는 한 번에 3에 닿고, 1/2 < η < 1에서는 양쪽을 오가며 가까워집니다.

η=1이면 오차는 부호만 바뀌고 손실 ek²은 같게 유지됩니다. η > 1이면 처음 오차가 0인 경우를 제외하고 그 크기가 늘어납니다. η=0이면 처음 위치에서 움직이지 않습니다. 이 범위는 J(w)=(w−3)²의 곡률에서 나온 값입니다. 손실에 양의 상수를 곱하면 가장 좋은 w는 그대로여도 도함수와 안정적인 학습률 범위는 바뀝니다. 일반적으로 이차함수 J(w)=(L/2)(w−w*)²이면 J″=L이고 오차 배율이 1−ηL이므로 수렴 조건은 0 < η < 2/L입니다. 이 장의 예는 L=2라서 η<1입니다. 곡률이 큰(가파르게 휜) 함수일수록 쓸 수 있는 학습률이 작아집니다.

같은 시작점에서 학습률만 바꾸어 실행한다

def loss(w):
    return (w - 3)**2

def run(rate, steps):
    w = 0.0
    values = [w]
    for _ in range(steps):
        slope = 2 * (w - 3)
        w = w - rate * slope
        values.append(w)
    positions = " ".join(f"{value:.4f}" for value in values)
    print(f"η={rate:.2f}: {positions} | 마지막 손실={loss(w):.4f}")

for rate in (0.25, 0.75, 1.0, 1.1):
    run(rate, 4)

η=1.10: 0.0000 6.6000 -1.3200 8.1840 -3.2208 | 마지막 손실=38.6984

출력의 마지막 값은 네 번 갱신했을 때의 값입니다. 경사하강을 어디서 끝낼지는 정해 둔 반복 한도나 도함수 크기 같은 기준으로 판단할 수 있습니다. 이 예에서는 |J′(w)|=2|w−3|이므로, 도함수가 작다는 기준을 정답과 가까운 정도로 해석할 수 있습니다. 다음 장에서는 여러 변수에서 기울기와 종료 조건을 다룹니다.
