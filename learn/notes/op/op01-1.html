부동소수점으로 값을 저장할 때 생기는 반올림

0.1과 0.2를 더한 값이 Python에서 0.3과 정확히 같지 않을 수 있습니다. 이진으로 표현할 수 있는 수의 간격부터 확인합니다.

이 장을 읽고 나면

  • 유한한 이진 소수로 쓸 수 있는 분수를 구분한다.
  • 절대오차와 허용 오차의 용도를 설명한다.
  • Decimal과 이진 부동소수점이 각각 언제 적합한지 판단한다.

컴퓨터가 간격을 두고 수를 고른다

이진 소수는 1/2, 1/4, 1/8처럼 2의 거듭제곱의 역수를 더해서 쓸 수 있습니다. 0.125는 1/8이므로 이진에서 0.001입니다. 반면 0.1은 1/10이며 분모에 5가 들어 있습니다. 2의 거듭제곱을 분모로 하는 어떤 유한한 분수와도 정확히 같지 않습니다.

설명용으로 1/8의 배수만 저장하는 작은 모형을 생각합니다. 0.1을 넣으면 가까운 0.125를 선택합니다. 실제 Python float는 훨씬 촘촘하고 넓은 범위를 씁니다. 그래서 0.1에 아주 가까운 이진 값을 쓰지만, 차이가 완전히 없어지지는 않습니다.

표시되는 숫자와 저장된 값

일반적인 Python 환경의 float는 IEEE 754 배정밀도 이진 부동소수점을 사용합니다. 표현 가능한 수들 사이에서 반올림이 일어나고, 연산 결과도 다시 표현 범위에 맞춰 반올림됩니다. 출력의 자릿수를 줄이면 0.3처럼 보이게 만들 수 있지만, 이미 저장한 값 자체는 바뀌지 않습니다. 1 바로 다음 표현 가능 수와 1의 차이는 이 환경에서 약 2.22×10⁻¹⁶입니다. 더 큰 수 주변의 간격은 달라질 수 있습니다.

from decimal import Decimal
from math import inf, isclose, nextafter

value = 0.1 + 0.2
print("17자리:", f"{value:.17f}")
print("정확히 같은 float?", value == 0.3)
print("허용 범위 안?", isclose(value, 0.3, rel_tol=1e-12))
print("1 다음 간격:", f"{nextafter(1.0, inf) - 1.0:.2e}")
print("문자에서 읽은 Decimal:", Decimal("0.1") + Decimal("0.2"))

비교의 허용 오차를 계산 목적에 맞춘다

비교 종류어떤 차이를 보는가예
절대오차|측정값−기준값|0.1mm보다 작은 차이를 허용
상대오차기준이 0이 아닐 때 기준 크기로 나눈 차이큰 값과 작은 값의 상대적인 변동
정확한 정수·십진 계산정의에 맞는 정확 값으로 비교센트 단위 정수나 문자열에서 만든 Decimal

기준이 0이면 상대오차의 분모가 0이 됩니다. math.isclose로 0 근처를 비교할 때는 허용할 절대 차이 abs_tol을 함께 정합니다. math.isclose의 상대 항은 두 입력의 절댓값 중 큰 값에 상대 허용 비율을 곱합니다. 표의 한 기준값에 대한 상대오차와 구분합니다. 원과 센트처럼 정확한 십진값을 다룬다면 0.1을 먼저 float로 만들기보다 문자열에서 직접 Decimal("0.1")을 만드는 편이 의도를 지킵니다. Decimal도 끝나지 않는 나눗셈 등에서는 설정한 정밀도로 반올림합니다.

한 줄 정리

저장 가능한 간격과 원래 의도한 단위를 구분하고, 근사값은 허용할 오차와 함께 비교합니다.
