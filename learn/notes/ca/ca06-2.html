이중적분과 좌표가 바꾸는 넓이

두 개의 변수가 있다면 어느 방향으로 잘라 더하는지, 작은 조각의 넓이가 얼마인지 함께 기록해야 합니다. 삼각형 영역을 두 방향으로 자른 뒤, 좌표를 바꾸면 넓이가 어떻게 변하는지 계산합니다.

이 장을 읽고 나면

  • 이차원 영역에 놓인 양을 두 방향으로 잘라 더하며, 안쪽 적분과 바깥쪽 적분을 읽는다.
  • 삼각형의 영역을 두 적분 순서로 표현하고, 같은 영역과 같은 적분값을 확인한다.
  • 좌표를 바꾸면 적분 함수, 범위, 야코비안 행렬식의 절댓값이 어떻게 바뀌는지 설명한다.

작은 넓이마다 높이를 곱해 더한다

바닥의 위치 (x,y)마다 바닥부터 물표면까지의 높이 f(x,y)가 주어졌다고 합시다. 높이가 m 단위이고 바닥의 작은 직사각형 폭이 Δx m, Δy m라면, 그 위 물의 부피는 대략 f(x,y)ΔxΔy m³입니다. 영역 D의 작은 조각들을 더하고 조각을 잘게 만드는 극한을 이중적분 ∬D f(x,y) dA로 적습니다. dA는 바닥의 아주 작은 넓이를 뜻합니다.

f가 양수인 경우 부피가 됩니다. f가 양수와 음수를 모두 가질 때는 음수인 부분이 합에서 빠지는 부호 있는 누적량입니다. 바닥의 넓이만 구할 때는 f(x,y)=1을 씁니다.

직사각형 0 ≤ x ≤ 2, 0 ≤ y ≤ 1 위에서 f(x,y)=x+y를 적분해 봅시다. 먼저 x를 한 값으로 고정하고 y에 대해 높이를 적분합니다. 단면을 따라 누적한 값을 다시 x 방향으로 더합니다. 두 적분을 차례로 적어서 반복적분이라고 부릅니다.

∫02 [∫01 (x+y) dy] dx = ∫02 (x + 1/2) dx = [x²/2 + x/2]02 = 3.

dy가 가장 안쪽에 있어 y를 먼저 적분합니다. 안쪽에서는 x가 상수입니다. 이 예처럼 닫힌 직사각형에서 연속인 함수는 순서를 바꿔도 값이 같습니다. 일반 영역에서는 순서를 바꿀 때 같은 지점을 빠짐없이 담도록 경계를 다시 정합니다.

삼각형을 세로와 가로로 잘라 본다

이번 영역은 D = {(x,y) | 0 < y < x < 1}입니다. 좌표평면에서 x = 1의 왼쪽, y = 0의 위쪽, y = x의 아래쪽에 놓인 삼각형입니다. 경계선을 포함할지 여부는 여기서 넓이나 연속함수 적분값에 영향을 주지 않습니다. 선은 면적이 0입니다.

세로로 자르면 바깥 변수 x는 0부터 1까지 움직입니다. 각 x에서 y는 0부터 x까지 움직이므로 세로 단면의 길이는 x입니다. 가로로 자르면 바깥 변수 y는 0부터 1까지 움직입니다. 각 y에서 x는 y부터 1까지 움직이므로 가로 단면의 길이는 1 − y입니다.

같은 넓이를 두 순서로 계산

세로 먼저: ∫01 [∫0x 1 dy] dx = ∫01 x dx = 1/2.
가로 먼저: ∫01 [∫y1 1 dx] dy = ∫01 (1 − y) dy = 1/2.

같은 영역 위에 높이 y를 누적한다면 세로부터 계산할 때 안쪽 적분은 [y²/2]0x = x²/2이고, 바깥 적분은 1/6입니다. 가로부터 계산할 때는 y가 고정이므로 안쪽 적분은 y(1 − y), 바깥 적분은 1/2 − 1/3 = 1/6입니다.

이처럼 같은 영역에서 함수를 계속 누적할 수 있습니다. 나중에 결합밀도를 배울 때 이 삼각형 위의 높이 2를 적분하면 2·(1/2)=1이 됩니다. 삼각형 밖은 밀도를 0으로 두고, 관심 영역의 면적에 높이를 곱해 확률을 구합니다.

좌표를 바꾸면 작은 넓이의 비율도 바뀐다

x = 2u, y = 3(1 − v)로 두면 uv 평면의 단위 정사각형이 xy 평면의 2×3 직사각형으로 갑니다. u 간격 Δu는 x 방향으로 2Δu만큼 늘어납니다. v가 Δv만큼 증가하면 y는 3Δv만큼 내려갑니다. 방향은 뒤집히지만 그림 속 직사각형의 세로 길이는 3Δv입니다.

일반적으로 x = x(u,v), y = y(u,v)라면 작은 구간에서 좌표의 변화를 편미분으로 근사할 수 있습니다. 두 좌표를 u와 v로 각각 미분해 모은 2×2 야코비안 행렬 J에서, 열 하나는 u 방향 작은 이동을, 다른 열은 v 방향 작은 이동을 나타냅니다. 원래의 작은 직사각형은 근사적으로 평행사변형이 되며 그 넓이의 배율은 |det J|입니다.

J = [[∂x/∂u, ∂x/∂v], [∂y/∂u, ∂y/∂v]].
det J = (∂x/∂u)(∂y/∂v) − (∂x/∂v)(∂y/∂u).

위 그림에서는 J = [[2, 0], [0, −3]]입니다. 행렬식은 −6입니다. 음수는 방향이 뒤집혔음을 보여 주며, 작은 면적 dA는 6 du dv로 바뀝니다. 매끄럽고 일대일인 변환이 영역 안에서 좌표를 겹치지 않게 바꾸고 det J가 0이 아닌 경우, 다음처럼 적분합니다.

∬D f(x,y) dA = ∬S f(x(u,v), y(u,v)) |det J(u,v)| du dv.

S는 uv에서의 영역이고 D는 S를 변환한 xy 영역입니다. 위 예에서 f(x,y)=x+y라면 f는 2u+3(1−v)로 바뀝니다. 이 함수의 단위 정사각형 위 평균은 1+1.5=2.5이고, 면적 배율 6을 적용한 적분은 15입니다.

배율이 위치에 따라 달라지는 예

단위 정사각형 S에 x=u, y=(1+u)v를 적용하면 D는 0 ≤ x ≤ 1, 0 ≤ y ≤ 1+x인 사다리꼴입니다. J = [[1,0],[v,1+u]]이므로 |det J|=1+u입니다. 왼쪽 u=0에서는 세로 길이가 그대로이고, 오른쪽 u=1에서는 두 배입니다. D의 넓이는 ∫01 [∫01 (1+u) dv] du = 3/2입니다.

양쪽에서 계산한 값이 맞는지 확인한다

삼각형에서 높이 y의 적분은 단면 계산을 손으로 마쳤습니다. 아래에서는 그 결과인 두 단면식만을 중점 합으로 적분해 비교합니다. 각 구간의 가운데에서 높이를 고르므로 이차식 적분은 근삿값입니다. 직사각형 예에서는 각각의 변수에 대해 선형인 단면의 평균을 양 끝 높이의 평균으로 정확히 구할 수 있습니다.

from math import fsum, isclose

def midpoint_on_unit_interval(function, count):
    return fsum(function((index + 0.5) / count) for index in range(count)) / count

vertical = midpoint_on_unit_interval(lambda x: x**2 / 2, 10000)
horizontal = midpoint_on_unit_interval(lambda y: y * (1 - y), 10000)
assert isclose(vertical, horizontal, rel_tol=1e-7)

original = 2 * 3 * (2 + 3) / 2
transformed = abs(2 * (-3)) * (2 / 2 + 3 / 2)
assert original == transformed
print(f"삼각형 위 높이 y의 누적: {vertical:.6f}, {horizontal:.6f}")
print(f"직사각형 위 높이 x+y의 누적: {original:.1f}, {transformed:.1f}")
삼각형 위 높이 y의 누적: 0.166667, 0.166667
직사각형 위 높이 x+y의 누적: 15.0, 15.0
