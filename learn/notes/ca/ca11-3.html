외력이 있는 초기값 문제를 Laplace 변환으로 풀기

장치를 켠 뒤 상태가 어떻게 변하는지 계산합니다. 미분을 대수적 곱으로 옮기는 Laplace 변환에 초기값이 어디에 들어가는지 부분적분으로 유도합니다.

이 장을 읽고 나면

  • 동차해와 외력이 만든 해를 더해 초기값 문제를 해석한다.
  • Laplace 변환의 미분법칙을 부분적분으로 유도한다.
  • 상수 외력과 늦게 켜는 외력의 응답을 계산하고 원래 식에 대입한다.

외력과 초기 상태를 구분한다

이전 장에서 다룬 q″+3q′+2q=0의 오른쪽에 시간 함수 u(t)를 넣으면 q″+3q′+2q=u(t)입니다. u는 장치에 가하는 외부 입력입니다. 예로 입력이 계속 1이면 충분히 시간이 지났을 때 멈춰 있는 상태의 후보는 2q=1에서 q=1/2입니다. 초기 위치와 속도가 모두 0이라면 바로 그 값에 있을 수 없으므로, 그 사이의 움직임을 찾아야 합니다.

같은 외력에서 두 해의 차는 동차식을 만족합니다. 한 특별한 해를 qp라고 하면 모든 해는 qp+qh 꼴이고, qh는 동차해입니다. 예로 상수 입력에서는 qp=1/2, 동차해는 C e−t+D e−2t입니다. 두 초기값으로 C,D를 맞출 수 있습니다. Laplace 변환을 쓰면 이 초기값을 변환 식 안에 함께 처리할 수 있고, 중간 시점에 입력이 켜지는 문제도 같은 방식으로 계산할 수 있습니다.

부분적분이 미분을 s의 곱으로 보낸다

t≥0에서 함수 f의 한쪽 Laplace 변환을 F(s)=ℒ[f](s)=∫0∞e−stf(t)dt로 정의합니다. 이 장에서는 실수 s를 충분히 크게 잡아 이상적분이 수렴하는 경우를 다룹니다. 예로 |f(t)|≤C eat가 충분히 뒤에서 성립하면 s>a에서 지수 가중치와 곱한 함수가 적분 가능합니다. f=1이면 1/s, f=ebt이면 1/(s-b)입니다.

f는 연속이고 조각별로 연속 미분 가능하며 f,f′가 각각 지수만큼 또는 더 느리게 자란다고 가정합시다. 유한 구간에서 e−stf′(t)를 부분적분하면 경계항 [e−stf(t)]0T에 s∫0Te−stf(t)dt를 더한 값입니다. 조각을 나눠도 이음점에서 f가 이어져 경계항이 서로 상쇄됩니다. 충분히 큰 s에서 T→∞이면 위쪽 경계항은 0이고 아래쪽에서 -f(0)가 남습니다.

ℒ[f′]=sF(s)−f(0).

f′에도 같은 연속성과 조각별 미분 가능성이 있고 f″도 지수만큼 또는 더 느리게 자라면 한 번 더 적용해 ℒ[f″]=s²F(s)−s f(0)−f′(0)입니다. 초기값은 미분을 변환할 때 생긴 경계항입니다. f가 중간에서 갑자기 뛰면 부분적분의 중간 항이 남을 수 있습니다. 여기서 다루는 해 q와 그 속도 q′는 연속입니다.

상수 외력을 부분분수로 되돌린다

q″+3q′+2q=1, q(0)=q′(0)=0을 변환합니다. Q=ℒ[q]라고 두면 (s²+3s+2)Q=1/s이고, 분모의 인수를 나눠 Q=1/[s(s+1)(s+2)]입니다.

부분분수를 A/s+B/(s+1)+C/(s+2)로 놓습니다. 양변에 공통 분모를 곱한 뒤, 다항식 등식에 s=0,-1,-2를 차례로 넣으면 A=1/2, B=-1, C=1/2입니다. 여기서 음의 s를 넣은 것은 원래 이상적분에 대입한 것이 아니라 이미 얻은 다항식의 항등식에 대입한 것입니다. 기본 변환들과 맞추어

q(t)=1/2−e−t+(1/2)e−2t = (1−e−t)²/2

를 얻습니다. q′=e−t−e−2t, q″=-e−t+2e−2t로 계산해 q″+3q′+2q=1을 확인합니다. 두 초기값도 0입니다. 예로 t=log 2에서 위치는 1/8입니다. 충분히 뒤에는 두 지수항이 작아져 1/2로 갑니다.

초기값이 0이 아니면 왼쪽 변환에 -s q(0)-q′(0)-3q(0)가 남습니다. 이를 오른쪽으로 옮겨야 시작값이 해에 들어갑니다. 이 항을 빠뜨리면 현재 입력만 반영하고 이전 상태는 반영하지 않습니다.

입력이 한참 뒤에 켜질 때

H(t-a)를 t<a이면 0, t>a이면 1인 계단 함수라 하고 a≥0을 가정합니다. 한 점 t=a에서의 값은 변환 적분에 영향을 주지 않습니다. H(t-a)f(t-a)의 변환은 적분을 a부터 시작해 τ=t-a로 바꾸면 e−asF(s)입니다.

u(t)=H(t-1)이면 오른쪽 변환은 e−s/s입니다. 처음 상태가 0인 계에서는 새 응답도 e−sQ(s)에 대응하는 H(t-1)q(t-1)입니다. 여기서 q는 방금 구한 상수 외력의 응답입니다. 켜기 전에는 미분방정식의 양변이 0이고, 켠 뒤에는 이미 구한 식이 시간을 한 칸 옮겨 만족합니다. 이음점에서도 원래 q(0)=q′(0)=0이라 위치와 속도는 연속입니다. 가속도는 계단이 켜지는 바로 그 시각에서 불연속일 수 있어 구간별로 방정식을 읽습니다.

예컨대 t=1+log 2에서는 켠 뒤의 시간이 log 2이므로 위치는 1/8입니다. 일정한 입력과 달리 시각까지 바뀌었지만, 이 예의 계수행렬은 시간에 따라 바뀌지 않습니다. 같은 입력을 늦추면 같은 모양의 응답이 늦게 시작합니다.

손계산을 Python으로 검산한다

from fractions import Fraction as F

def partial(s):
    return F(1, 2)/s - 1/(s+1) + F(1, 2)/(s+2)

for s in [F(1), F(2), F(3)]:
    transformed = 1/(s*(s+1)*(s+2))
    print("s:", s, "Q(s):", transformed, "partial match:", partial(s) == transformed)

for label, z in [("0", F(1)), ("log 2", F(1, 2)), ("log 4", F(1, 4))]:
    q = (1-z)**2/2
    v = z-z*z
    acceleration = -z+2*z*z
    print(label, "q:", q, "ODE left:", acceleration + 3*v + 2*q)

s: 2 Q(s): 1/24 partial match: True
s: 3 Q(s): 1/60 partial match: True
0 q: 0 ODE left: 1
log 2 q: 1/8 ODE left: 1
log 4 q: 9/32 ODE left: 1

Python 3.14.6의 분수 연산으로 실행했습니다. 시각을 e−t가 분수일 때로 골랐습니다. 부분분수와 미분방정식의 등식은 본문에서 임의의 허용된 시각과 변환 변수에 대해 확인했습니다.
