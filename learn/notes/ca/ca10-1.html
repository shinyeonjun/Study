CA10·1

곡면의 접벡터에서 법선과 유속 구하기

기울어진 면을 바람이 통과할 때 어느 성분을 더해야 할까요? 매개변수 격자의 작은 칸이 곡면에서 어떤 면적과 방향을 갖는지 외적으로 구합니다.

이 장을 읽고 나면

  • 곡면 매개화의 두 접벡터와 외적을 구하고 정칙성을 검사한다.
  • 무방향 면적 요소와 방향 있는 면적벡터를 구분한다.
  • 그래프 곡면과 원기둥 옆면에서 유속을 직접 계산한다.

작은 매개변수 사각형을 곡면 위로 옮긴다

곡선은 변수 하나로 길 위의 점을 찾습니다. 곡면의 작은 조각은 변수 두 개 (u,v)로 점을 찾습니다. 예로 밑면에서 x,y를 움직이며 높이 z=x+2y를 지정하면 r(u,v)=(u,v,u+2v)입니다. 이처럼 평면의 영역 D에서 3차원 공간으로 가는 벡터함수 r:D→ℝ³를 곡면 매개화라고 합니다.

v를 고정하고 u만 바꾸면 하나의 곡선을 얻고, 그 접벡터는 rᵤ=∂r/∂u입니다. 같은 방식으로 rᵥ를 얻습니다. 두 벡터의 외적 N=rᵤ×rᵥ이 0이 아니면 두 접벡터가 독립이라 그 점의 접평면을 펼칩니다. 이 조건을 정칙이라 합니다. 아래에서는 매개화가 연속 미분 가능하고 내부를 한 번 덮는 정칙 조각을 사용합니다. 모서리, 이음선, 극처럼 한 조각으로 다루기 어려운 점은 곡면을 나누거나 다른 좌표를 써서 처리합니다.

매개변수의 한 변이 Δu, 다른 변이 Δv인 칸은 곡면에서 1차 근사로 rᵤΔu, rᵥΔv가 만드는 평행사변형입니다. 두 벡터 a,b의 평행사변형 넓이는 ‖a×b‖=‖a‖‖b‖sin θ이므로, 곡면에서의 작은 면적은 ‖N‖ΔuΔv입니다. 점점 작은 직사각형 근사를 합하면 곡면 면적 요소를 얻습니다.

dS=‖rᵤ×rᵥ‖ du dv.

속도 한 개의 크기가 곡선 길이 요소를 만들고, 두 접벡터 외적의 크기가 곡면 면적 요소를 만듭니다. 예로 r(u,v)=(3u,2v,0)이면 단위 매개변수 정사각형에 대응하는 실제 평면 넓이는 ‖(3,0,0)×(0,2,0)‖=6입니다.

스칼라 면적과 벡터장 유속의 차이를 계산한다

스칼라장 g를 면적에 대해 더하면 ∬Sg dS = ∬Dg(r(u,v))‖N‖du dv입니다. 예컨대 표면 밀도라면 질량입니다. 벡터장 F가 면을 가로지르는 정도를 재려면, 먼저 면의 어느 쪽으로 향하는 것을 양이라고 할지 정해야 합니다. 법선이 연속적으로 한쪽을 향하도록 고른 곡면을 방향이 지정된 곡면이라 합니다.

단위법선을 n이라 하면 F·n은 단위 면적당 법선 성분입니다. n=N/‖N‖을 골랐다면 n dS=N du dv라서 유속은 아래와 같습니다.

∬SF·n dS = ∬DF(r(u,v))·(rᵤ×rᵥ) du dv.

반대 법선을 고르면 부호를 뒤집습니다. 장이 면과 평행하면 내적이 0입니다. 물이 흐르는 속도장이 m/s이고 면적이 m²라면 이 유속은 m³/s입니다. 외적을 사용한 식에서 면적 요소를 다시 곱하면 길이 보정이 두 번 들어갑니다. 단위법선 n에는 dS, 정규화하지 않은 외적 N에는 du dv를 짝지으세요.

곡면이 z=f(x,y)라면 r(x,y)=(x,y,f(x,y)), 접벡터는 (1,0,fₓ)와 (0,1,fᵧ)입니다. 외적은 N=(-fₓ,-fᵧ,1)입니다. z성분이 양수여서 이 부호가 위쪽입니다. 아래는 -N입니다.

기울어진 삼각형에서 면적과 유속을 모두 구한다

S는 D={0≤y≤x≤1} 위의 z=x+2y이고 위쪽을 양으로 정합니다. 여기서 N=(-1,-2,1), ‖N‖=√6입니다. 밑면의 넓이가 1/2이므로 곡면 넓이는 √6/2입니다.

위쪽 유속. F=(x,0,z)를 곡면에 넣으면 F(r)·N=-x+(x+2y)=2y입니다. y=0부터 y=x까지 먼저 적분해 x²을 얻고 이를 x=0부터 1까지 적분하면 1/3입니다. 아래쪽 유속은 -1/3입니다. 같은 경우에 F=(x,y,z)를 쓰면 -x-2y+z=0입니다. 원점을 지나는 이 평면에서 위치벡터 자체는 평면과 나란하기 때문입니다.

원기둥 옆면의 바깥 방향을 선택한다

반지름 R>0, 높이 h>0인 원기둥에서 옆면을 r(θ,z)=(R cos θ,R sin θ,z), 0≤θ≤2π, 0≤z≤h로 적습니다. θ의 양 끝이 같은 이음선이지만 내부의 곡면을 한 번 덮습니다. rθ=(-R sin θ,R cos θ,0), rz=(0,0,1)이므로 외적 N=(R cos θ,R sin θ,0)은 원기둥 축에서 멀어지는 바깥 방향입니다.

벡터장 F(x,y,z)=(x,y,0)에서는 내적이 R²(cos²θ+sin²θ)=R²라 옆면 유속은 2πR²h입니다. 면적은 2πRh이므로 법선 성분의 크기 R에 면적을 곱해도 같습니다. 원기둥의 위·아래 원판을 같이 적분한다면 각각의 법선을 더 지정해야 합니다.

좌표에서 생기는 예외. 평면 원판 r(ρ,θ)=(ρ cos θ,ρ sin θ,0)에서 ρ=0이면 rθ=0이고 외적도 0입니다. 원판 자체가 찢어졌다는 뜻은 아닙니다. 원점에서 모든 θ가 한 점을 나타내기 때문에 극좌표가 그 자리의 접평면을 표현하지 못합니다. 직교좌표 r(u,v)=(u,v,0)는 원점에서도 정칙입니다.

손계산을 Python으로 검산한다

from fractions import Fraction as F
from math import sqrt

def cross(a, b):
    return (
        a[1]*b[2] - a[2]*b[1],
        a[2]*b[0] - a[0]*b[2],
        a[0]*b[1] - a[1]*b[0],
    )

def dot(a, b):
    return sum(x*y for x, y in zip(a, b))

normal = cross((1, 0, 1), (0, 1, 2))
print("normal:", normal)
print("area:", round(sqrt(dot(normal, normal)) / 2, 6))
# 이중적분에서 y 적분을 마친 x^2를 3점 공식으로 적분
flux = (F(0)**2 + 4*F(1, 2)**2 + F(1)**2) / 6
print("up/down flux:", flux, -flux)
radius, height = 2, 3
print("cylinder-side flux / pi:", 2 * radius**2 * height)
normal: (-1, -2, 1)
area: 1.224745
up/down flux: 1/3 -1/3
cylinder-side flux / pi: 24
