CA10·2

Stokes 정리로 공간 경계의 순환을 계산하기

곡면을 한 겹 벗겨 매개변수 평면에 펴면 경계 선적분을 Green 정리로 계산할 수 있습니다. 곡면 위에서 생기는 그 미분이 왜 벡터장의 회전과 법선의 내적이 되는지 증명합니다.

이 장을 읽고 나면

  • 회전의 성분을 구하고 양의 경계 방향을 법선에서 읽는다.
  • 곡면 한 조각의 Stokes 정리를 Green 정리로 증명한다.
  • 같은 기울어진 삼각형에서 선적분·회전의 유속을 각각 계산한다.

순환을 측정하는 세 좌표 방향

평면의 Green 정리에서 Qₓ−Pᵧ는 한 점을 둘러싼 작은 사각형을 반시계로 돌 때의 순환을 사각형의 면적으로 나누고, 사각형을 그 점으로 줄여 얻는 극한입니다. 공간에서는 회전축에 따라 가로지르는 평면이 달라집니다. F=(P,Q,R)에서 yz평면의 대응 성분은 Rᵧ−Q_z, zx평면에서는 P_z−Rₓ, xy평면에서는 Qₓ−Pᵧ입니다. 평면에서 좌표를 순서대로 놓아 오른손 방향을 정합니다. 세 값을 모은 벡터를 회전(curl)이라 부릅니다.

curl F = ∇×F = (Rᵧ−Qz, Pz−Rₓ, Qₓ−Pᵧ).

예로 F=(-y,x²,x)에서 curl F=(0,-1,2x+1)입니다. 첫째는 두 미분이 모두 0, 둘째는 0−1, 셋째는 2x−(-1)입니다. 법선이 축 방향과 일치하지 않을 때는 이 회전벡터와 법선의 내적을 사용합니다.

경계는 곡면이 정해 주는 방향으로 돈다

Stokes 정리

S를 콤팩트한(공간에서 닫히고 유계인) 방향 있는 조각별 매끄러운 곡면으로 둡니다. 여기서 방향을 준다는 것은 매끄러운 각 조각에서 단위법선을 연속적으로 고르고 맞닿은 조각들에서 방향을 일관되게 잇는다는 뜻입니다. 예를 들어 유한 개의 닫히고 유계인 매개변수 영역의 매끄러운 곡면 조각을 이어 얻는 곡면입니다. 경계 ∂S는 조각별로 매끄럽고, F는 S와 경계를 포함하는 열린 집합에서 연속 미분 가능하다고 합시다. 경계와 법선을 호환되게 고르면

∮∂SF·dr = ∬S(curl F)·n dS.

오른손 엄지 방향이 법선이고, 감아 쥔 손가락이 가리키는 쪽이 경계의 양의 방향입니다. 이를 경계 가까이에서 해석하면, 고른 법선 방향으로 머리를 두고 경계를 걸을 때 곡면이 왼쪽에 놓입니다. 예로 수평 원판의 위쪽 법선은 위에서 보아 반시계 경계를 정합니다. 법선 또는 경계 방향을 하나만 뒤집으면 두 적분의 부호가 어긋납니다. 둘을 함께 뒤집으면 등식은 유지됩니다.

위쪽 법선의 xy 평면 조각에서는 오른쪽 적분함수가 정확히 Qₓ−Pᵧ이고, 경계에는 dz=0입니다. 이때는 Green 정리의 순환형이 됩니다. 공간에서 경계는 면이 있어야 정해집니다. 닫힌 공간곡선이라고 해서 어떤 평면 영역의 경계에 자동으로 해당하지는 않습니다.

매개변수 평면에서 Green 정리를 적용한다

한 조각을 충분히 매끄러운 정칙 매개화 r(u,v)로 한 번 덮고 방향을 rᵤ×rᵥ로 잡읍시다. 경계의 미소 변위는 dr=rᵤdu+rᵥdv입니다. 평면 매개변수 영역 D의 양의 경계를 따라가면, 그 이미지는 위 방향과 호환됩니다. 평면 Green 정리에 A(u,v)=F(r(u,v))·rᵤ, B(u,v)=F(r(u,v))·rᵥ를 넣으면 왼쪽은 ∮(A du+B dv)입니다. 이를 평면 안쪽으로 옮기면 ∬(∂ᵤB−∂ᵥA)du dv입니다.

미분을 전개한다. 곱의 미분에서 F(r)·rᵥᵤ와 F(r)·rᵤᵥ는 이계 미분이 연속이므로 상쇄됩니다. 행렬 JF의 (i,j) 성분을 ∂ⱼFᵢ로 쓰면, 합성함수의 미분에서 남은 값은 아래와 같습니다.

∂ᵤB−∂ᵥA = (JF·rᵤ)·rᵥ − (JF·rᵥ)·rᵤ = (curl F)·(rᵤ×rᵥ).

마지막 등식의 한 쌍을 직접 확인하세요. x,y 성분에서 나오는 항들은 Qₓ(rᵤₓrᵥᵧ−rᵥₓrᵤᵧ)+Pᵧ(rᵤᵧrᵥₓ−rᵥᵧrᵤₓ)입니다. 정리하면 (Qₓ−Pᵧ)(rᵤₓrᵥᵧ−rᵤᵧrᵥₓ)로, 회전의 z성분에 외적의 z성분을 곱한 결과입니다. y,z와 z,x 쌍에서도 같은 방식으로 나머지 두 성분을 얻습니다. 이 사실과 n dS=(rᵤ×rᵥ)du dv를 합치면 한 조각에서 정리가 증명됩니다.

처음부터 한 매개화로 곡면을 덮기 어려운 경우에는 방향에 맞춘 조각을 이어 붙입니다. 공통 경계는 양쪽 조각에서 반대 방향을 가져 적분에서 상쇄됩니다. 이 설명은 유한 개의 그런 조각으로 나누는 경우를 대상으로 합니다.

같은 공간 삼각형에서 양쪽을 직접 비교한다

S는 0≤y≤x≤1 위의 z=x+2y이며 위쪽을 고릅니다. F=(-y,x²,x)이고 n dS=(-1,-2,1)dxdy입니다. 회전의 유속 적분함수는 (0,-1,2x+1)·(-1,-2,1)=2x+3입니다. 먼저 y를 적분하면 x(2x+3)이고, 0부터 1까지 적분하면 2/3+3/2=13/6입니다.

경계에서는 F·dr=-y dx+x²dy+x dz입니다. (0,0,0)에서 (1,0,1)로 가는 첫 변에서 y=0,z=x라 ∫01x dx=1/2입니다. 둘째 변은 x=1,z=1+2y이므로 ∫01(1+2)dy=3입니다. 마지막 대각선은 (x,y,z)=(t,t,3t)를 1→0으로 지나서 ∫10(t²+2t)dt=-4/3입니다. 합은 1/2+3-4/3=13/6으로 같습니다.

같은 경계를 가진 다른 곡면을 선택할 수 있다

벡터장 F=(-y/2,x/2,0)에서 curl F=(0,0,1)입니다. z=0의 단위원이 경계인 위쪽 원판에서 이 회전의 유속은 π입니다. 같은 원을 경계로 갖는 단위 상반구를 바깥 방향으로 잡으면, 경계도 위에서 볼 때 반시계가 됩니다. 따라서 Stokes 정리에 의해 이 곡면에서도 회전의 유속이 π입니다.

상반구에서 직접 확인할 수 있습니다. r(φ,θ)=(sin φ cos θ,sin φ sin θ,cos φ), 0≤φ≤π/2, 0≤θ≤2π로 쓰면 rφ×rθ의 z성분은 cos φ sin φ입니다. 이 항을 φ에 대해 적분하면 1/2, θ까지 적분하면 π입니다. 극 한 점과 이음선은 다른 좌표로 덮거나 그 주변의 면적이 작아지는 극한으로 처리할 수 있습니다.

곡면을 교체하려면 경계의 모양과 방향이 같고 장이 각각의 곡면 근방에서 필요한 미분을 가져야 합니다. 예컨대 F=(-y/(x²+y²),x/(x²+y²),0)를 단위원의 원판에 적용할 수는 없습니다. 원판 중심에서 장이 정의되지 않아 회전이 0이라는 정보를 원판 전체에 적분할 수 없기 때문입니다.

손계산을 Python으로 검산한다

from fractions import Fraction as F

def integrate(f):
    return (f(F(0)) + 4*f(F(1, 2)) + f(F(1))) / 6

edges = (
    integrate(lambda x: x),
    integrate(lambda y: F(3)),
    -integrate(lambda t: t*t + 2*t),
)
curl_flux = integrate(lambda x: x * (2*x + 3))
print("boundary edges:", ", ".join(map(str, edges)))
print("boundary and curl flux:", sum(edges), curl_flux)
print("hemisphere curl flux / pi:", 2 * F(1, 2))
boundary edges: 1/2, 3, -4/3
boundary and curl flux: 13/6 13/6
hemisphere curl flux / pi: 1

Python 3.14.6으로 실행했습니다. 마지막 줄은 구면에서 θ 적분이 2π, φ 적분이 1/2라는 손계산을 그대로 곱합니다.
