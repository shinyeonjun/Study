미분방정식을 오일러 한 걸음으로 계산하기

연속적인 변화율만 알 때, 현재 기울기를 짧은 구간의 변화로 바꾸어 다음 상태를 근사합니다. 보폭이 정확도와 안정성에 어떤 영향을 주는지 봅니다.

이 장을 읽고 나면

  • 초기값 문제와 차분 업데이트를 구분한다.
  • 전진 오일러법으로 감쇠 모형의 상태를 계산한다.
  • 참 해의 안정성과 수치 근사의 안정성을 비교한다.

연속 시간에서 상태값과 변화율을 연결한다

시간 t에서 상태 y(t)의 변화율이 y′(t)=−y(t)라고 합시다. 현재 상태가 양수인 경우, 값이 클수록 더 빠르게 줄어듭니다. 이런 식을 상태와 그 도함수를 연결한 미분방정식이라고 합니다. 초기조건 y(0)=1을 함께 준 경우 참 해는 y(t)=exp(−t)입니다. t=0에서 1이고 미분하면 −exp(−t)가 되어 두 조건을 만족합니다.

초기조건이 없으면 y(t) = C·e−t(C는 임의의 상수) 전체가 y′ = −y를 만족합니다. 이를 일반해라고 하고, 초기조건 y(0) = 1이 C = 1을 골라 하나의 해를 정합니다. 미분방정식과 초기조건을 함께 준 문제를 초기값 문제라고 합니다. 같은 식에서 y(0) = 3이면 해는 3e−t입니다.

짧은 구간의 변화를 현재 기울기로 근사한다

시간 간격 h>0를 정합니다. 현재 시간과 상태를 tₖ, yₖ로 적으면, 전진 오일러법은 시간 tₖ₊₁=tₖ+h와 상태 yₖ₊₁=yₖ+h·f(tₖ,yₖ)를 사용합니다. f는 미분방정식의 오른쪽입니다. 이 예에서는 f(t,y)=−y이므로 yₖ₊₁=(1−h)yₖ입니다.

h=0.5일 때 첫 상태 1은 0.5가 되고, 그 상태의 기울기 −0.5를 써 다시 0.25가 됩니다. 두 걸음 뒤 t=1이고, 참값 exp(−1)≈0.367879와 비교하면 절대오차는 약 0.117879입니다.

같은 끝 시각에서 간격을 줄이면 더 많은 기울기를 계산합니다. 이 매끄러운 모형에서는 오차도 작아집니다. 표에서 h를 절반으로 할 때 오차는 0.1179 → 0.0515 → 0.0243으로 대략 절반씩 줄고, h = 0.0625(16걸음)이면 0.0118입니다. 한 걸음의 오차는 h²에 비례하지만 걸음 수가 1/h에 비례해 늘어나므로, 고정된 끝 시각의 전체 오차는 h에 비례합니다. 그래서 전진 오일러법을 1차 방법이라고 합니다. 한 걸음의 근사 오차가 여러 걸음 뒤에 누적되므로, 보폭을 바꾸었을 때 결과가 얼마나 달라지는지도 검산합니다.

from math import exp

def euler_decay(step, count):
    state = 1.0
    for _ in range(count):
        state += step*(-state)
    return state

for step, count in ((0.5, 2), (0.25, 4), (0.125, 8)):
    approximation = euler_decay(step, count)
    print(step, count, f"{approximation:.6f}", f"{abs(exp(-1)-approximation):.6f}")
print("보폭 3, 두 걸음:", euler_decay(3, 2))

감쇠해야 할 값이 프로그램에서는 커질 수 있다

연속 해 exp(−t)는 시간이 늘면 0으로 갑니다. 수치 규칙은 (1−h)를 매번 곱합니다. |1−h|<1, 즉 0<h<2이면 수치 단계도 0으로 접근합니다. h=3이면 1, −2, 4, −8로 부호가 바뀌면서 크기가 커집니다. 참 해는 줄어드는데 수치해만 커지는 것이므로, 모형이 아니라 너무 큰 보폭의 수치 규칙이 만든 결과입니다. 일반적으로 y′ = λy (λ < 0)에 오일러를 쓰면 yₖ₊₁ = (1 + hλ)yₖ이고, 앞 장의 조건 |1 + hλ| < 1에서 0 < h < 2/|λ|가 수치 안정 조건입니다. 감쇠가 빠를수록(|λ|가 클수록) 허용 보폭이 작아집니다. 안정한 h라도 한 번의 예측이 충분히 정확하려면 오차를 별도로 확인합니다.

연속 시간의 평형점과 안정성

y′ = f(y)에서 f(y*) = 0인 값 y*는 변화율이 0이라 머무는 평형점(차분식의 고정점에 해당)입니다. y* 근처의 작은 차이 e = y − y*는 e′ ≈ f′(y*)·e를 따르므로 e(t) ≈ e(0)·ef′(y*)t입니다. 따라서 f′(y*) < 0이면 국소 안정, f′(y*) > 0이면 불안정, f′(y*) = 0이면 이 근사로는 판정할 수 없습니다.

차분식은 곱하는 수의 절댓값이 1보다 작은지를, 미분방정식은 지수의 부호가 음수인지를 봅니다. 예: y′ = −y는 f′ = −1 < 0이라 평형점 0이 안정합니다. y′ = y(1 − y)는 평형점 0(f′(0) = 1, 불안정)과 1(f′(1) = −1, 안정)을 가집니다.

한눈에 정리

대상식과 뜻
초기값 문제y′ = f(t, y)와 y(t₀) = y₀. 초기조건이 일반해의 상수를 정한다.
전진 오일러법yₖ₊₁ = yₖ + h·f(tₖ, yₖ). 전체 오차는 h에 비례(1차).
수치 안정성y′ = λy (λ < 0)이면 |1 + hλ| < 1, 즉 0 < h < 2/|λ|.
평형점 안정성f(y*) = 0에서 f′(y*) < 0이면 국소 안정, > 0이면 불안정.
