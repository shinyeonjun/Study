함수의 극한과 연속: 그 점과 그 주변

식에서 x=3을 넣을 수 없는데도 x가 3에 가까워질수록 출력이 6에 가까워질 수 있습니다. 또 x=3에서 값을 정해 놓고도 왼쪽과 오른쪽에서 보이는 값이 다를 수 있습니다. 함수값, 극한값, 연속을 차례로 구별합니다.

이 장을 읽고 나면

  • 주변의 값에서 좌극한·우극한을 읽고 양쪽 극한을 판단한다.
  • 함수값이 없거나 극한값과 다른 경우를 설명한다.
  • 한 점에서의 연속을 세 조건으로 판정한다.

정확히 그 점에 넣는 질문과 주변에서 다가가는 질문

f(x) = (x² − 9)/(x − 3)에는 3을 넣을 수 없습니다. 하지만 x≠3인 가까운 값에서는 f(x) = x + 3이라는 같은 계산을 합니다. 이때 |f(x) − 6| = |x − 3|입니다. x가 3에 가까워지는 만큼 출력도 6에 가까워지므로 limx→3 f(x) = 6입니다.

함수의 극한 limx→a f(x) = L은 a 바로 주변의 서로 다른 입력으로 다가가면 함수값이 L에 원하는 만큼 가까워진다는 말입니다. x=a를 빼고 그 주변을 봅니다. 여기서는 a 양쪽에 a와 다른 정의역의 점이 얼마든지 가깝게 있다고 가정합니다. 주어진 모든 허용 오차 ε>0마다 양수 δ가 있어서, 정의역의 x가 0 < |x−a| < δ를 만족하면 |f(x)−L| < ε여야 합니다. 이 예에서는 δ=ε이면 됩니다.

이제 x≠3에서는 f와 같은 g(x) = x + 3이고, 3에서만 값을 따로 g(3) = 1로 정한 함수 g를 생각합니다. 아래 그림이 g의 그래프입니다.

g는 주변의 식이 f와 같으므로 역시 극한이 6입니다. 하지만 g(3)=1입니다. 그래프에서 열린 점 (3,6)은 주변 선이 향하는 곳이고, 채운 점 (3,1)은 3에 정확히 넣은 값입니다.

실행 예제

from fractions import Fraction as F

def g(x):
    return (x*x - 9) / (x - 3) if x != 3 else F(1)

for x in (F(29,10), F(299,100), F(3), F(301,100), F(31,10)):
    print(f"{float(x):.2f}  {float(g(x)):.2f}")
2.90  5.90
2.99  5.99
3.00  1.00
3.01  6.01
3.10  6.10

흔한 실수

0/0은 구하려는 값이 0이라는 뜻도, 극한이 없다는 결론도 아닙니다. 원래 식에 직접 대입할 수 없다는 신호입니다. 주변의 식을 다른 형태로 바꾸거나 좌우 접근을 따로 판단합니다.

왼쪽과 오른쪽을 따로 확인한다

limx→a⁻는 a보다 작은 값에서 다가가는 좌극한입니다. limx→a⁺는 a보다 큰 값에서 다가가는 우극한입니다. a 양쪽에서 접근할 수 있는 이 장의 예에서는, 좌극한과 우극한이 둘 다 존재하고 같은 실수 L일 때, 그리고 그때에만 양쪽 극한이 L입니다.

예를 들어 j(x)=1 (x<3), j(x)=4 (x≥3)으로 둡니다. 왼쪽에서는 계속 1, 오른쪽에서는 계속 4입니다. 따라서 좌극한은 1, 우극한은 4이고 둘이 달라 양쪽 극한은 없습니다. j(3)=4가 있어도 판단은 그대로입니다.

양쪽 모두 값이 유한한 수에 가까워져야 한다는 점도 확인합니다. 1/(x−3)²은 x가 3에 가까워질수록 양수 쪽으로 한없이 커집니다. limx→3 1/(x−3)² = +∞라는 표기는 유한한 실수 극한이 있다는 뜻이 아니라 커지는 방향을 기록한 것입니다.

연속이려면 그 점과 주변이 맞아야 한다

양쪽에서 접근할 수 있는 점에서 연속의 세 조건

  1. f(a)가 정의된다.
  2. limx→a f(x)가 유한한 값으로 존재한다.
  3. 둘이 같은 값이다.

앞의 f는 3이 빠져 첫 조건, g는 극한 6과 g(3)=1이 달라 셋째 조건을 만족하지 않습니다. 두 함수 모두 3의 값을 6으로 놓은 새 함수를 만들면 3에서 연속입니다. 이런 경우를 제거 가능한 불연속이라 부릅니다. j는 좌우 극한이 달라 둘째 조건을 만족하지 않습니다. 그 점의 값 하나로 좌우를 맞출 수 없는 점프 불연속입니다.

풀이 예제

u(x) = 2x + 1 (x < 2), u(2) = k, u(x) = x + 3 (x > 2)라면 좌극한은 2×2+1=5이고 우극한은 2+3=5입니다. 두 방향이 같은 값을 주므로 u(2)도 5로 정할 때에만 연속입니다.

다항함수는 실수 전체에서 연속이고, 두 다항식의 몫은 분모가 0이 아닌 곳에서 연속입니다. 함수가 정의된 범위가 [1, 4]처럼 닫힌 구간이라면 끝점에서는 구간 안쪽의 한 방향으로 접근해 연속인지 판단합니다. 예를 들어 왼끝 1에서는 우극한과 함수값을 비교합니다.
