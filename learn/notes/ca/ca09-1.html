CA09·1

곡선의 매개화와 일을 재는 선적분

힘이 위치에 따라 달라질 때 물체를 밀어 움직이는 데 한 일은 얼마일까요? 이동을 짧게 쪼개 시작과 끝, 속력, 이동 방향을 구분해 선적분을 만듭니다.

이 장을 읽고 나면

  • 곡선의 매개화에서 위치·접선·방향을 읽는다.
  • 힘과 작은 변위의 내적 합에서 일의 선적분을 유도한다.
  • 경로와 방향을 바꿔 벡터 선적분과 스칼라 선적분을 비교한다.

점의 모임에 지나가는 순서를 더한다

원점에서 (1,1)까지 걸어간다고 합시다. 먼저 동쪽으로 가다가 (1,0)에서 북쪽으로 꺾을 수도 있고, 대각선이나 포물선을 따라 갈 수도 있습니다. 같은 모양의 길도 어느 쪽으로 걷는지, 몇 번 지나가는지에 따라 일이 달라집니다. 위치에 붙은 화살표 F(x,y)=(P(x,y),Q(x,y))를 벡터장이라 하고, 이동은 시작과 끝의 순서를 지정하는 벡터값 함수로 씁니다.

r(t)=(x(t),y(t)), a≤t≤b

r(a)에서 출발해 r(b)에 도착합니다. r′(t)는 접선 방향과 매개변수 단위당 위치 변화이고, 그 크기 ‖r′(t)‖가 속력입니다. 예로 r(t)=(t,t²)에서 r′(t)=(1,2t)이고 t=1/2에서 위치는 (1/2,1/4), 접선방향은 (1,1)입니다. t는 시간으로 해석할 수 있지만, 곡선을 따라 위치를 지정하는 번호로만 사용할 수도 있습니다.

매끄러운 조각에서는 성분이 연속 미분 가능해서 접선이 부드럽게 이어집니다. 여기서는 각 조각 내부에서 r′(t)≠0인 경로를 사용합니다. 꺾이는 경로도 유한 개의 매끄러운 조각으로 나눠 각 조각의 적분을 더합니다. 예를 들어 (0,0) → (1,0) → (1,1)은 각각 (t,0), (1,t)를 0에서 1까지 움직이는 두 조각입니다.

힘과 작은 변위의 내적을 더한다

힘이 벡터 F이고 변위가 Δr인 짧은 이동의 일은 F·Δr로 근사합니다. 각도 θ가 예각이면 양수, 둔각이면 음수이며, 접선과 힘이 수직이면 0입니다. 길을 짧은 시간 구간 [tᵢ,tᵢ₊₁]로 나누면 Δrᵢ=r′(tᵢ)Δtᵢ+o(Δtᵢ)입니다. 이 식에서 나머지를 Δtᵢ로 나눈 값은 구간이 짧아질수록 0에 가까워집니다. 매끄러운 조각의 닫힌 매개변수 구간에서 r′가 균등하게 연속이므로 그 오차를 모든 조각에 동시에 작게 만들 수 있습니다. F도 연속이면 F(r(t))는 구간에서 유계입니다. 이 때문에 잘게 나눠 일의 근사값을 합치면 다음 리만 적분이 됩니다.

∫C F·dr = ∫ab F(r(t))·r′(t) dt = ∫C P dx+Q dy.

3차원이면 F=(P,Q,R), r=(x,y,z)로 두고 R dz를 추가합니다. 단위 접선 T=r′/‖r′‖, 작은 호길이 ds=‖r′‖dt를 써서 ∫(F·T)ds로도 표현합니다. 장의 접선 성분에 길이를 곱해 더한다는 뜻입니다. 힘의 단위가 N, 길이가 m이면 일의 단위는 N·m입니다.

손계산. F(x,y)=(y,2x)에서 대각선 r(t)=(t,t)를 지나면 F(r(t))·r′(t)=(t,2t)·(1,1)=3t여서 일은 3/2입니다. 포물선 r(t)=(t,t²)에서는 (t²,2t)·(1,2t)=5t²여서 5/3입니다. 끝이 같은 두 경로의 일은 다릅니다. x축과 세로선으로 꺾는 경로에서는 첫 구간이 (0,2t)·(1,0)=0, 둘째가 (t,2)·(0,1)=2라 전체 일은 2입니다.

속도를 바꾸거나 방향을 뒤집으면

같은 경로를 같은 방향으로 더 빠르게 또는 느리게 지나도 일은 같습니다. t=φ(s)가 매끄럽고 증가하는 일대일 재매개화로 원래 구간을 한 번 덮는다고 합시다. 새 경로는 r(φ(s)), 미분은 r′(φ(s))φ′(s)입니다. 새 적분의 φ′(s)ds를 dt로 바꾸면 같은 적분과 끝점을 얻습니다. 예를 들어 대각선을 r(t)=(t²,t²)로 적으면 (t²,2t²)·(2t,2t)=6t³이고 적분은 다시 3/2입니다. 시작점에서의 영속력은 이 적분에 영향을 주지 않습니다.

r−(t)=r(a+b−t)는 출발점과 도착점을 교환합니다. 미분에 −1이 붙으므로 역방향 경로 −C에서 적분은 −∫CF·dr입니다. 같은 닫힌 길을 두 번 돌면 변위 내적도 두 바퀴분을 더합니다. 증가 재매개화 성질은 주어진 이동을 한 번 동일 순서로 밟을 때 적용됩니다.

같은 이름의 다른 적분. g가 스칼라장일 때 ∫Cg ds = ∫ g(r(t))‖r′(t)‖ dt입니다. 예컨대 선밀도 g를 길이에 대해 더하면 전체 질량입니다. 대각선에서 g=x라면 ∫01t√2 dt=√2/2이고, 뒤집어도 속력의 크기는 같아 결과가 같습니다.

손계산을 Python으로 검산한다

from fractions import Fraction as F

# [0,1]에서 3차 이하 다항식의 적분을 정확히 계산
def integrate_cubic(f):
    return (f(F(0)) + 4 * f(F(1, 2)) + f(F(1))) / 6

examples = {
    "diagonal": lambda t: 3*t,
    "parabola": lambda t: 5*t*t,
    "turning path": lambda t: F(0) + F(2),
    "slower start": lambda t: 6*t**3,
    "reversed diagonal": lambda t: -3*(1-t),
}
for name, integrand in examples.items():
    print(name, integrate_cubic(integrand))
diagonal 3/2
parabola 5/3
turning path 2
slower start 3/2
reversed diagonal -3/2

Python 3.14.6의 Fraction으로 계산했습니다. 함수 integrate_cubic은 세 점의 가중합으로 3차 이하 다항식을 적분합니다. 기저인 1, t, t², t³를 하나씩 넣으면 1, 1/2, 1/3, 1/4가 나옵니다. 다른 함수에는 이 식을 그대로 정확한 적분으로 사용할 수 없습니다.
