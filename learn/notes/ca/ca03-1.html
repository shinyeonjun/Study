CA03·1

미분 계산 · 다항식, 곱·몫, 지수·로그

식에서 숫자를 다루는 순서대로 미분 규칙을 고릅니다. 직접 차분몫을 다시 구하지 않고 계산하되, 곱의 두 항과 몫의 빼기가 왜 나오는지도 작은 넓이 계산과 연결합니다.

이 장을 읽고 나면

  • 상수·거듭제곱·합을 미분한다.
  • 곱과 몫의 규칙을 적용하고 정의역을 확인한다.
  • 지수와 로그의 도함수를 구하고 수치 차분으로 검산한다.

한꺼번에 전개하기 전에 식의 구조를 읽는다

미분의 뜻에서 도함수는 차분몫을 극한으로 보낸 값이었습니다. 이제 그 정의를 여러 번 사용해 얻은 계산 규칙을 씁니다. 먼저 가장 바깥 연산이 무엇인지 찾습니다. 두 함수의 합이면 항마다, 곱이면 두 항이 서로 영향을 주는 정도를 합쳐 계산합니다.

원래 함수도함수예
상수 c07의 도함수는 0이다.
양의 정수 거듭제곱 xⁿnxⁿ⁻¹x⁴의 도함수는 4x³이다.
상수 곱 cfcf′3x²의 도함수는 6x이다.
합 f+g 또는 차 f−gf′+g′ 또는 f′−g′x²−4x+3의 도함수는 2x−4이다.

규칙은 차분몫에서 나온다

상수는 f(x+h)와 f(x)가 같아 분자가 0입니다. 합은 차분몫부터 두 함수의 차분몫을 더한 값입니다. 둘 다 미분 가능하면 극한도 각각 얻어 더할 수 있습니다. 양의 정수 n에 대해 (x+h)ⁿ을 전개하면 첫 항은 xⁿ, h가 한 번 들어간 항들은 합이 nxⁿ⁻¹h입니다. 나머지에는 h가 두 번 이상 들어갑니다. 차를 h로 나눈 뒤 h→0을 취하면 nxⁿ⁻¹이 남습니다. x 자체의 도함수는 1입니다.

3x⁴−2x²+5x−7의 도함수는 12x³−4x+5입니다. 계산한 뒤 어느 항에서 나온 기울기인지 한 번 확인하세요. 예를 들어 상수 −7은 함수 전체를 아래로 옮기지만 기울기를 바꾸지 않습니다.

같은 꼴 (xʳ)′ = r·xʳ⁻¹은 지수 r이 음의 정수나 분수 같은 실수일 때도 성립합니다(x>0이면 언제나, 정수 지수면 x≠0인 곳). 증명은 이 단원 뒤쪽의 지수·로그 미분과 다음 장의 연쇄법칙을 쓰면 됩니다. 예: (1/x)′ = (x⁻¹)′ = −x⁻², (√x)′ = (x^(1/2))′ = 1/(2√x)(x>0). 기계학습 식에 자주 나오는 꼴이라 함께 기억합니다.

곱: 가로도 세로도 바뀐다

가로 f(x), 세로 g(x)인 직사각형은 넓이가 f(x)g(x)입니다. x에 작은 변화가 생겼을 때 길이 변화량을 Δf와 Δg로 씁니다. 다음 그림은 두 길이가 늘어나는 한 경우입니다. 실제 식은 변화량이 음수여도 성립합니다.

(f+Δf)(g+Δg)−fg = gΔf + fΔg + ΔfΔg입니다. 입력 간격 h로 나누면 앞의 두 항은 g·(Δf/h)와 f·(Δg/h)입니다. 마지막 항은 (Δf/h)·Δg가 됩니다. 미분 가능한 f에서는 첫 인수가 유한한 값으로 가고, 미분 가능한 g는 연속이어서 둘째 인수가 0으로 갑니다. 따라서 마지막 항의 극한은 0입니다.

곱의 미분

(fg)′ = f′g + fg′. 두 함수가 해당 점에서 미분 가능할 때 씁니다. 하나는 f만 바꾼 항, 다른 하나는 g만 바꾼 항입니다. f′g′는 일반적으로 올바른 답이 아닙니다. 예를 들어 f=x, g=x라면 (x·x)′=2x이지만 두 도함수를 곱하면 1입니다.

몫: 분모의 변화에는 빼기가 들어간다

f와 g가 미분 가능하고 g(x)≠0인 곳에서 (f/g)′ = (f′g − fg′)/g²입니다. 순서가 중요합니다. 분자 변화의 항을 먼저 쓰고 분모 변화의 항을 뺍니다. 실제로 f가 양수인 상수이고 분모가 양수인 상태에서 커지면 몫은 작아지는 방향입니다.

원래 몫의 두 값을 통분하면 차분몫의 분자가 g(x)[f(x+h)−f(x)]−f(x)[g(x+h)−g(x)]가 됩니다. 전체 분모는 h·g(x+h)·g(x)입니다. 각 차를 h로 나누어 극한을 보면 분자에는 gf′−fg′, 남은 분모에는 g²이 남습니다.

풀이 예제

q(x)=(x²+1)/(x+1)에서 x=1의 미분계수를 구합니다. f(1)=2, g(1)=2, f′(1)=2, g′(1)=1입니다. 몫 규칙에 넣으면 (2×2−2×1)/2² = 1/2입니다.

(x²−1)/(x+1)을 x−1로 약분해도 원래 식에는 x≠−1 조건이 남습니다. 약분한 식의 기울기가 1이라도 원래 식이 정의되지 않은 −1에 미분계수를 붙이지 않습니다.

지수와 로그: 무엇이 변하는지 읽는다

x³은 x가 밑에 있는 거듭제곱이고, 3ˣ은 x가 지수에 있는 지수함수입니다. 지수와 로그에서 본 자연상수 e를 밑으로 하는 exp(x)=eˣ는 미분해도 eˣ입니다. 일반 지수함수 aˣ의 도함수는 aˣ ln(a)입니다(a>0). 밑이 1인 상수함수도 ln(1)=0이라 같은 식이 맞습니다.

자연로그 함수 ln x의 도함수는 1/x입니다(x>0). 자연로그는 지수함수의 역함수입니다. y=eˣ에서 x에 대한 y의 기울기가 y이므로, 두 축을 맞바꾼 역함수의 같은 대응점에서는 입력 y당 출력 x의 기울기가 1/y입니다. 밑 a의 로그도 logₐ x=ln x/ln a를 쓰면 도함수가 1/[x ln a]입니다(x>0, a>0, a≠1).

곱과 지수를 한 식에 쓰기

k(x)=x²eˣ에서 k′(x)=2xeˣ+x²eˣ입니다. x=1에서는 k′(1)=3e입니다. 지수 함수의 도함수를 알면서도 곱의 두 항 가운데 하나를 빠뜨리면 이 값을 얻지 못합니다.

from math import exp, log

examples = [
    ("다항식과 로그", lambda x: x**3 - 2*x + log(x), 2.0),
    ("곱", lambda x: x**2 * exp(x), 3 * exp(1)),
    ("몫", lambda x: (x**2 + 1) / (x + 1), 0.5),
]
x = 1.0
h = 1e-5
for name, f, exact in examples:
    approx = (f(x + h) - f(x - h)) / (2*h)
    assert abs(approx - exact) < 1e-7
    print(f"{name}: 공식 {exact:.6f}, 차분 {approx:.6f}")

실행 결과

다항식과 로그: 공식 2.000000, 차분 2.000000
곱: 공식 8.154845, 차분 8.154845
몫: 공식 0.500000, 차분 0.500000

중앙 차분은 x 양쪽 값의 차를 2h로 나누어 도함수에 가까운 값을 구합니다. 유한한 h와 부동소수점 연산을 써서 계산한 근삿값입니다. 식과 단위를 검사하는 대조용으로 사용하고, 모든 x에서 공식이 맞다는 증명으로 사용하지 않습니다.

왜 그럴까?

곱에서 두 함수가 모두 변하는데 ΔfΔg 항의 영향은 왜 도함수에서 사라지나요?

모범 답 보기

입력 간격 h로 나눈 항은 (Δf/h)Δg입니다. 미분 가능하므로 첫 인수는 유한한 값에 가까워지고 둘째 인수는 0에 가까워집니다.

가장 바깥 연산도함수 계산
합각 항의 도함수를 더한다.
곱f′g와 fg′를 더한다.
몫(f′g − fg′)/g², 분모가 0이 아닌 곳
지수·로그(eˣ)′=eˣ, (ln x)′=1/x (x>0)
