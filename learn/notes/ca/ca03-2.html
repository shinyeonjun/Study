CA03·2

합성함수의 연쇄법칙과 작은 계산 그래프

예측이 가중치에 따라 바뀌고, 예측에서 얻은 오차를 다시 제곱하면 손실이 됩니다. 가운데 값이 한 번 바뀌는 효과와 마지막에 제곱하는 효과를 이어 곱해 손실의 변화율을 계산합니다.

이 장을 읽고 나면

  • 합성식에서 안쪽·바깥쪽 함수를 구별한다.
  • 각 단계의 정의역과 도함수를 구해 연쇄법칙으로 잇는다.
  • 가중치 하나를 바꾸는 제곱 손실의 기울기를 직접 검산한다.

안쪽 함수부터 값을 구하고 바깥쪽까지 잇는다

y=ln(1+x²)에는 함수가 두 겹으로 들어 있습니다. 먼저 입력 x를 안쪽 함수 g(x)=1+x²에 넣어 u를 얻습니다. 그 뒤 바깥 함수 f(u)=ln u를 계산합니다. 이렇게 한 함수의 출력을 다음 함수의 입력으로 넣는 것을 합성이라고 합니다. 이 합성은 f(g(x))로 적습니다.

연쇄법칙

g가 x에서 미분 가능하고 f가 u=g(x)에서 미분 가능하면 [f(g(x))]′ = f′(g(x))·g′(x)입니다. dy/dx = (dy/du)(du/dx)로도 씁니다. 두 비율 표현을 정해진 입력에 대입한 뒤 곱한다는 뜻입니다.

x가 아주 조금 변하면 u의 변화량은 대략 g′(x)·Δx입니다. u가 그렇게 변할 때 y는 대략 f′(u)·Δu만큼 변합니다. 두 식을 잇고 입력 변화량으로 나누면 기울기의 곱이 나옵니다. 이 기호를 숫자 분수처럼 아무 곳에서나 약분하는 것이 규칙의 근거는 아닙니다.

더 알아보기 · 안쪽 변화량이 0이어도 된다

Δu/h가 0에 가까워지거나 Δu가 실제로 0일 때에도 연쇄법칙을 쓸 수 있습니다. 바깥 함수의 일차 근사에서 남는 오차를 e(Δu)라고 쓰면, Δu≠0일 때 e(Δu)/h = [e(Δu)/Δu]·[Δu/h]입니다. 첫 인수는 0에, 둘째는 유한한 도함수에 가까워져 오차 항의 극한은 0입니다. Δu=0일 때는 바깥 함수값이 그대로라 오차도 0입니다. 그러므로 안쪽 미분값이 0이어도 규칙이 성립합니다.

겉의 기울기와 속의 기울기를 따로 구한다

풀이 예제

  1. y=ln(1+x²)에서 u=1+x²입니다. 안쪽 기울기는 u′=2x입니다.
  2. ln u의 기울기 1/u는 u가 양수일 때 계산합니다. 1+x²>0은 모든 실수 x에서 참입니다.
  3. 바깥 기울기에 u를 대입하고 안쪽 기울기를 곱하면 y′ = 2x/(1+x²)입니다. x=2에서는 4/5 = 0.8입니다.

마지막 줄처럼 합성 전체의 정의역은 안쪽 식 자체의 정의역과 바깥 식의 입력 조건을 모두 만족해야 합니다. ln(3−x)가 x=3에서 정의되지 않으면, 그 점의 도함수도 없습니다. 도함수 식만 보고 원래 함수가 정의되지 않는 곳까지 범위를 넓히지 않습니다.

from math import exp, log

examples = [
    ("ln(1+x^2)", lambda x: log(1+x**2), 2.0, 0.8),
    ("exp(-2x)", lambda x: exp(-2*x), 0.0, -2.0),
    ("(3x+1)^4", lambda x: (3*x+1)**4, 0.0, 12.0),
]
h = 1e-5
for name, f, x, exact in examples:
    approx = (f(x+h) - f(x-h)) / (2*h)
    assert abs(approx - exact) < 1e-7
    print(f"{name}: 공식 {exact:.6f}, 차분 {approx:.6f}")

실행 결과

ln(1+x^2): 공식 0.800000, 차분 0.800000
exp(-2x): 공식 -2.000000, 차분 -2.000000
(3x+1)^4: 공식 12.000000, 차분 12.000000

양쪽 수치를 비교하는 방법은 검산입니다. 근사에 쓸 양쪽 점이 원래 정의역 안에 있는지부터 확인합니다.

예측값에서 손실까지 기울기를 추적한다

어느 입력에서 예측한 값이 실제값과 얼마나 다른지 제곱으로 재는 간단한 예를 봅니다. 입력 숫자 2와 절편 1, 실제값 5는 고정하고 가중치 w 하나만 바꿉니다. 예측을 ŷ=2w+1, 실제값과의 차이를 r=ŷ−5, 제곱 손실을 L=r²로 둡니다. 여기서 '제곱 손실'은 틀린 정도를 음수 없이 재는 함수입니다. 손실이나 잔차의 정의를 달리 쓰는 자료도 있으므로 어떤 방향으로 차를 정의했는지 적습니다.

기울기를 읽는 순서

  1. 가중치 w=1.5를 넣으면 예측은 4, 차이는 −1, 손실은 1입니다.
  2. 예측은 가중치 1만큼의 변화당 2만큼 변합니다. dŷ/dw=2입니다.
  3. 차이는 예측에서 5를 뺀 값입니다. 상수를 빼도 기울기는 1이라 dr/dŷ=1입니다.
  4. 차이 r를 제곱한 손실의 기울기는 dL/dr=2r입니다. 현재 r=−1이라 −2입니다.
  5. 세 기울기를 곱하면 dL/dw=(−2)×1×2=−4입니다.

가중치를 아주 조금 늘리면 이 점 근처에서 손실이 감소합니다. 예를 들어 w=1.51이면 손실은 (−0.98)²=0.9604입니다. 접선으로 근사한 값은 1+(−4)×0.01=0.96입니다. 이 부호를 보고 아무 크기나 늘려도 손실이 작아진다고 결론 내리지는 않습니다. 멀리 벗어나면 원래 곡선의 기울기가 달라질 수 있습니다.

def loss(w):
    predicted = 2*w + 1
    error = predicted - 5
    return error**2

w, h = 1.5, 0.01
error = (2*w + 1) - 5
slope = 2*error * 1 * 2
tangent = loss(w) + slope*h
print(f"가중치 {w:.2f}: 손실 {loss(w):.4f}, 기울기 {slope:.0f}")
print(f"가중치 {w+h:.2f}: 실제 {loss(w+h):.4f}, 접선 근사 {tangent:.4f}")
assert abs(loss(w+h) - tangent - 4*h**2) < 1e-12

실행 결과

가중치 1.50: 손실 1.0000, 기울기 -4
가중치 1.51: 실제 0.9604, 접선 근사 0.9600

입력에서 출력을 만들어 가는 길을 계산 그래프로 그릴 수 있습니다. 이 예에서는 연결이 한 줄이므로 경로의 기울기를 차례로 곱하면 됩니다. 이후 여러 변수와 경로가 함께 있는 계산에서는 어떤 변수를 바꾸고 무엇을 고정하는지, 한 변수가 여러 경로로 영향을 주는지를 따로 확인합니다.

왜 그럴까?

(3x+1)⁴를 미분할 때 4(3x+1)³만 쓰면 무엇을 빠뜨린 것일까요?

모범 답 보기

이 식은 안쪽 값 u=3x+1이 한 단위 변할 때의 바깥 변화율입니다. x가 한 단위 변할 때 안쪽 값은 3만큼 변하므로 안쪽 기울기 3을 한 번 더 곱합니다.
