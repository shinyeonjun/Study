Euler·중점·Runge–Kutta의 오차 차수 검산하기

정확한 해를 모르더라도 현재 기울기로 한 걸음 움직일 수 있습니다. 기울기를 어디에서 몇 번 재느냐가 한 걸음과 전체 구간의 오차에 어떤 차이를 만드는지 계산합니다.

이 장을 읽고 나면

  • 한걸음 방법의 Euler, 명시적 중점, 고전 RK4 갱신식을 계산한다.
  • 국소 한걸음 오차와 전역 오차의 차수를 가정과 함께 유도한다.
  • 정확한 해에 대해 보폭을 반으로 줄여 관측 차수를 검산한다.

현재 기울기로 움직이는 방법에서 시작한다

초기값 y(0)=y₀와 미분방정식 y′=f(t,y)가 있습니다. 관심 구간 [0,T]를 길이 h=T/N의 보폭 N개로 나눕니다. 정확한 해를 y(t), tₙ=nh에서의 근사값을 Yₙ이라고 쓰겠습니다. 다음 값을 현재 값과 함수 f로 계산하는 규칙을 한걸음 방법이라고 합니다.

시작에서의 기울기 f(tₙ,Yₙ)가 한 보폭 동안 이어진다고 보면, 명시적 Euler 방법은 Yₙ₊₁=Yₙ+h f(tₙ,Yₙ)입니다. 기울기는 실제 해가 어디에 있을지 모르는 상태에서 근사점 Yₙ을 넣어 계산합니다. 해가 충분히 매끄러우면 정확점에서의 Taylor 전개는 y(t+h)=y(t)+h y′(t)+O(h²)입니다. 정확점에서 시작한 Euler는 앞의 두 항을 맞추므로 한걸음 차이는 보통 O(h²)입니다.

y′=y,y(0)=1에서 첫 보폭 h=1/2이면 Y₁=1+(1/2)·1=3/2, 둘째는 Y₂=(3/2)·(3/2)=9/4입니다. 정확한 값 y(1)=e에서 이것을 빼면 약 0.46828입니다. 첫 보폭이 끝났을 때 이미 차이가 생겨 다음 보폭의 기울기에도 그 차이가 들어갑니다.

중점에서 기울기를 한 번 더 재면 2차 항이 생긴다

보폭 중간의 근사 상태를 Yₙ+(h/2)k₁, k₁=f(tₙ,Yₙ)로 예상합니다. 그곳의 기울기 k₂=f(tₙ+h/2,Yₙ+(h/2)k₁)로 한 보폭 전체를 옮기면 Yₙ₊₁=Yₙ+h k₂입니다. 이 규칙은 명시적 중점 방법입니다. 반 보폭 값은 중간 기울기를 읽는 임시 상태이며 최종 갱신은 원래 Yₙ부터 시작합니다.

정확한 y(t)에서 시작해 f(t+h/2,y+(h/2)f)를 두 변수 Taylor 전개하면 f+(h/2)(fₜ+fᵧ f)+O(h²)입니다. 또 y′=f(t,y(t))를 시간에 대해 미분하면 y″=fₜ+fᵧy′=fₜ+fᵧf입니다. 따라서 Y+h k₂의 h²/2 항도 정확해와 같습니다. 해 근방에서 편미분들이 충분히 매끄럽고 관련 도함수가 유계이면 정확점에서 시작한 한걸음 차이는 O(h³)입니다.

y′=y에서는 k₁=Y, k₂=(1+h/2)Y라 한걸음의 배수는 1+h+h²/2입니다. h=1/2를 대입하면 13/8이며 두 보폭 뒤에는 169/64입니다.

고전 RK4는 기울기 네 개를 섞는다

이 장에서는 k를 기울기로 적습니다. 각 기울기에 h를 아직 곱하지 않았다는 뜻입니다. 시각 t와 근사점 Y에서 고전적인 4차 Runge–Kutta(RK4)의 순서는 다음과 같습니다.

  1. k₁=f(t,Y)
  2. k₂=f(t+h/2,Y+h k₁/2)
  3. k₃=f(t+h/2,Y+h k₂/2)
  4. k₄=f(t+h,Y+h k₃)
Y새=Y+(h/6)(k₁+2k₂+2k₃+k₄).

선형 예에서 네 항을 검사한다. y′=y라면 k₁=Y, k₂=(1+h/2)Y, k₃=(1+h/2+h²/4)Y, k₄=(1+h+h²/2+h³/4)Y입니다. 이들을 가중합하면 배수가 1+h+h²/2+h³/6+h⁴/24입니다. 이는 정확한 한걸음 배수 eh의 Taylor 전개에서 4차 항까지입니다. 일반적인 충분히 매끄러운 f에서도 이 가중치와 중간점 계수는 정확한 해의 4차 항까지 맞춥니다. 그 일반 차수 정리의 전개는 참고 자료에 이어지고, 이 장에서는 직접 확인한 선형 예에 적용합니다.

한걸음 손실이 쌓여 전역 차수가 만들어진다

국소 오차 δₙ=y(tₙ₊₁)-Φₕ(tₙ,y(tₙ))는 정확점에서 다시 시작한 한걸음 차이입니다. 여기서는 h로 나누지 않은 정의를 사용합니다. 전역 오차 eₙ=|y(tₙ)-Yₙ|는 처음부터 연속해서 근사값을 사용해 얻은 전체 오차입니다. 갱신 함수 Φₕ가 해와 계산값이 놓인 영역에서 |Φₕ(t,u)-Φₕ(t,v)|≤(1+Lh)|u-v|이고, 국소 오차가 모든 n에서 |δₙ|≤Chp+1라 가정합시다. Euler에서는 f가 상태에 대해 Lipschitz이면 이 한걸음 조건을 바로 얻습니다.

중간에 Φₕ(tₙ,y(tₙ))를 끼워 두 오차를 더하면 eₙ₊₁≤(1+Lh)eₙ+Chp+1입니다. 시작값이 같아 e₀=0이므로, 이 부등식을 반복해 만든 항은 최대 N개입니다. 각각의 증폭인자 (1+Lh)j≤eLj h≤eLT라서 eₙ≤C T eLThp입니다. 즉 고정된 T에서 각 보폭 오차가 p+1차라면 쌓인 전체 오차는 p차 이하입니다. 이 결론에서 보폭이 줄어도 같은 상수와 같은 해의 주변 범위가 사용되어야 합니다.

끝점 오차가 E(h)≈A hp인 범위에서는 반 보폭의 오차가 대략 E(h)/2p입니다. 따라서 p̂=log₂(E(h)/E(h/2))를 계산할 수 있습니다. 여기서는 같은 미분방정식, 같은 끝점과 정확해를 사용합니다. 보폭이 아주 크면 점근적인 비율에 가까워지지 않을 수 있고, 너무 작으면 두 거의 같은 부동소수점 수의 뺄셈에 반올림이 두드러질 수 있습니다.

손계산을 Python으로 검산한다

from math import e, log2

def euler(f, t, y, h):
    return y + h*f(t, y)

def midpoint(f, t, y, h):
    k1 = f(t, y)
    return y + h*f(t + h/2, y + h*k1/2)

def rk4(f, t, y, h):
    k1 = f(t, y)
    k2 = f(t + h/2, y + h*k1/2)
    k3 = f(t + h/2, y + h*k2/2)
    k4 = f(t + h, y + h*k3)
    return y + h*(k1 + 2*k2 + 2*k3 + k4)/6

def error(step, n):
    h, y = 1/n, 1.0
    for i in range(n):
        y = step(lambda t, y: y, i*h, y, h)
    return abs(e - y)

methods = (euler, midpoint, rk4)
for n in [10, 20, 40, 80]:
    print(n, *(f"{error(step, n):.6e}" for step in methods))
print("p-hat:", *(f"{log2(error(step, 40)/error(step, 80)):.3f}" for step in methods))
10 1.245394e-01 4.200982e-03 2.084324e-06
20 6.498412e-02 1.090774e-03 1.358027e-07
40 3.321799e-02 2.778841e-04 8.666190e-09
80 1.679689e-02 7.012736e-05 5.473049e-10
p-hat: 0.984 1.986 3.985

Python 3.14.6으로 실행했습니다. 각 행은 Euler, 중점, RK4 순서의 끝점 오차입니다. 마지막 줄은 h=1/40과 1/80을 비교한 관측 차수입니다.
