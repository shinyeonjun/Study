CA04·1

편미분과 기울기: 어느 쪽으로 움직이면 더 빨리 변할까

바닥의 온도를 앞뒤 위치 x와 좌우 위치 y로 알아낸다고 합시다. 한 방향으로 한 걸음 내딛을 때의 온도 변화는 어느 좌표만 바꾸는지, 두 좌표를 함께 바꾸는지에 따라 달라집니다. 한 변수를 고정하는 계산에서 출발해 임의 방향의 순간 변화율까지 구합니다.

이 장을 읽고 나면

  • 한 점에서 다른 변수를 고정한 편미분을 계산한다.
  • 기울기 벡터와 단위벡터의 내적으로 방향미분을 구한다.
  • 변화율의 단위를 쓰고, 입력 스케일이 달라지면 방향 해석도 점검한다.

입력은 좌표 두 개이고 출력은 온도 한 개다

작은 공간에서 바닥 온도를 T(x, y) = 20 + 0.1(x² + y²)로 근사한다고 합시다. x, y는 원점을 기준으로 각각 m로 잰 위치입니다. 0.1의 단위는 ℃/m²입니다. (3, 4)에서 T = 20 + 0.1(9 + 16) = 22.5℃입니다. 입력은 두 성분을 가진 좌표이고 출력은 수 하나입니다. 이것이 두 변수의 스칼라값 함수의 예입니다.

첫째 좌표가 3m에서 4m가 되는 동안 둘째 좌표를 4m로 두면 온도가 22.5℃에서 23.2℃로 바뀝니다. 이 1m 구간의 평균 변화율은 0.7℃/m입니다. 출발점의 기울기를 얻으려면 움직인 거리 h를 0에 가까이 해야 합니다(CA02).

편미분은 한 좌표만 움직인 단면의 기울기다

편미분의 정의

나머지 입력을 고정하고 한 입력에 대해 구한 순간 변화율을 편미분(partial derivative)이라 합니다. ∂T/∂x는 ‘T를 x로 편미분’이라고 읽습니다.

∂T/∂x = limh→0 [T(x+h, y) − T(x, y)]/h
∂T/∂y = limh→0 [T(x, y+h) − T(x, y)]/h

T를 x로 미분할 때 y²은 상수입니다. 따라서 ∂T/∂x = 0.2x, ∂T/∂y = 0.2y입니다. P = (3, 4)에서 각 값은 0.6과 0.8℃/m입니다. 위에서 계산한 0.7℃/m는 1m를 이동한 평균이라 ∂T/∂x와 같을 필요가 없습니다.

고정한다는 말은 항 전체를 지운다는 뜻이 아닙니다. U(x, y) = xy라면 y는 상수 배율이고 ∂U/∂x = y입니다. y를 4로 고정하면 U(x, 4) = 4x가 되므로 기울기가 4라는 설명과 같습니다.

편미분들을 모아서 기울기 벡터를 만든다

기울기 벡터(gradient)는 입력 순서대로 편미분을 모은 벡터입니다. 여기서는 ∇T = (∂T/∂x, ∂T/∂y)이고, P에서는 (0.6, 0.8)입니다. 아주 조금 δ = (Δx, Δy)만큼 움직이면 온도 변화는 ΔT ≈ ∇T(P) · δ = 0.6Δx + 0.8Δy입니다. ·는 두 벡터의 대응 성분을 곱해 합하는 내적(LA02)입니다.

작은 움직임의 근사

P에서 Δx = 0.03m, Δy = 0.04m만큼 이동합니다. ① x 성분은 0.6 × 0.03 = 0.018℃. ② y 성분은 0.8 × 0.04 = 0.032℃. ③ 합은 0.05℃입니다. 원식에 두 좌표를 넣은 실제 변화량은 0.05025℃입니다. 이 차이는 작은 움직임의 2차 항까지 원식에는 들어 있기 때문입니다.

이런 근사를 선형 근사라고 합니다. 다변수 함수가 한 점에서 미분 가능하다는 말은 그 점 가까이에서 이와 같은 선형식으로 잘 근사된다는 뜻입니다. 편미분 값 두 개를 각각 구할 수 있다는 사실만으로는 항상 다변수 미분 가능성을 보장하지 않습니다. 이 장의 다항함수처럼 근방에서 편미분이 연속인 경우는 미분 가능합니다.

하나의 방향을 골라 1m당 얼마나 바뀌는지 묻는다

두 좌표를 함께 움직일 때는 방향 벡터를 정합니다. 예에서 v = (3, 4)의 길이는 5이므로 단위벡터 u = (3/5, 4/5)를 씁니다. P에서 h·u를 더하면 h가 양수일 때 h m만큼 그 방향으로 움직입니다. u가 단위벡터인 이유는 ‘실제 이동 거리 1m당’ 변화율을 얻기 위해서입니다.

방향미분

DuT(P) = limh→0 [T(P+hu) − T(P)]/h = ∇T(P) · u

내적으로 계산하는 식은 T가 P에서 미분 가능할 때 성립합니다. u = (0.6, 0.8)일 때 0.6² + 0.8² = 1℃/m입니다. 그림의 접선 방향 u = (−0.8, 0.6)에서는 0.6 × (−0.8) + 0.8 × 0.6 = 0입니다. 등온선은 같은 온도를 주는 점들의 모음이므로, 그에 접하는 방향으로 움직일 때 1차 변화가 없습니다.

같은 거리만큼 움직일 때 가장 큰 내적은 기울기와 같은 방향에서 나옵니다. 그 최대 변화율은 기울기의 길이인 1℃/m입니다. 반대 방향에서는 −1℃/m로 가장 빨리 낮아집니다. 기울기가 0이면 모든 방향의 1차 변화율이 0이며 이 정보만으로 최솟값·최댓값인지 알 수 없습니다.

단위와 수치 검산

이 예에서는 x와 y가 둘 다 m이고 같은 거리 눈금을 씁니다. 입력 하나가 거리이고 하나가 시간이라면 편미분 단위도 다릅니다. 예를 들어 ℃/m와 ℃/초를 성분으로 붙인 벡터를 그대로 그려 ‘실제 공간에서 가장 뜨거워지는 방향’이라고 해석할 수는 없습니다. 어떤 입력 변화에 같은 크기를 부여할지, 단위나 스케일을 먼저 정해야 합니다.

def temperature(x, y):
    return 20 + (x*x + y*y) / 10

x, y = 3, 4
h = 0.001
dx = (temperature(x+h, y) - temperature(x-h, y)) / (2*h)
dy = (temperature(x, y+h) - temperature(x, y-h)) / (2*h)
along = (temperature(x+0.6*h, y+0.8*h)
         - temperature(x-0.6*h, y-0.8*h)) / (2*h)
print(f"편미분: {dx:.3f}, {dy:.3f} ℃/m")
print(f"방향미분: {along:.3f} ℃/m")
print(f"작은 이동의 실제 변화: {temperature(3.03, 4.04)-temperature(3, 4):.5f} ℃")
편미분: 0.600, 0.800 ℃/m
방향미분: 1.000 ℃/m
작은 이동의 실제 변화: 0.05025 ℃

앞뒤로 h만큼 움직여 두 함수값의 차이를 2h로 나눈 것은 중앙 차분입니다. 코드의 근삿값을 정확한 미분과 대조했습니다. h를 지나치게 작게 잡으면 두 수가 거의 같아 계산기에서 생기는 반올림 오차가 상대적으로 커질 수 있습니다.
