분리형과 일차 선형 미분방정식 풀기

시간이 주어졌을 때 상태의 변화율을 안다고 합시다. 초기값을 넣어 상태를 복원하고, 방정식이 풀려도 해의 범위와 유일성을 따로 확인해야 하는 이유를 살펴봅니다.

이 장을 읽고 나면

  • 상미분방정식과 초기값 문제, 해가 성립하는 구간을 설명한다.
  • 분리형과 일차 선형의 적분 공식을 미분으로 유도한다.
  • 존재·유일성의 조건과 무한대로 발산하는 해를 구분한다.

초기값과 함께 어느 구간의 함수를 찾는가

물체의 온도나 장치의 잔량처럼 시간 t의 함수 y(t)가 있다고 합시다. 현재 시각과 현재 상태가 바뀌는 속도를 f(t,y)로 주면 y′=f(t,y)입니다. 변수가 시간 하나이므로 상미분방정식(ODE)입니다. 식 안에서 가장 높은 미분이 일차이면 일차 ODE입니다. 이 식을 만족하는 미분 가능한 함수마다 해가 될 수 있습니다. 시각과 상태 y(t₀)=y₀를 함께 주고 그 조건을 만족하는 해를 찾으면 초기값 문제입니다.

풀이를 확인할 때에는 (1) 해가 정의되는 구간이 t₀를 포함하는지, (2) 부드러움과 식이 구간에서 성립하는지, (3) 시작값을 만족하는지를 봅니다. 식의 계수나 해의 분모가 0인 곳은 해가 끊길 수 있습니다. 예를 들어 y′=y², y(0)=1에서 y(t)=1/(1−t)는 t<1에서 성립하지만 t→1에서 왼쪽으로부터 값이 무한히 커집니다. 같은 식을 t>1에도 계산할 수 있어도, 1을 지나도록 하나의 미분 가능한 해로 연장할 수는 없습니다.

미분방정식 속의 y는 수 하나가 아니라 찾고 있는 함수입니다. 실제 값을 손에 넣기 전에는 도함수의 기호와 초기값이 같이 주어져 있어도 시간에 따른 전체 궤적을 알아내야 합니다.

분리할 때 평형해를 먼저 확인한다

y′=g(t)h(y)인 분리형에서는 h(y)=0인 값 y=c가 있으면 상수함수 y(t)=c가 해입니다. 이 값을 먼저 기록하세요. h(y)≠0인 구간에서는 H′(y)=1/h(y)인 원시함수를 쓰면 연쇄법칙에 의해 d[H(y(t))]/dt=g(t)입니다. 변수분리의 기호 dy/h(y)=g(t)dt는 이 연쇄법칙을 적분하는 약식입니다.

손계산. y′=y(1−y), y(0)=1/4를 풉니다. 평형해는 0과 1입니다. 처음에는 0<y<1이므로 1/[y(1−y)]=1/y+1/(1−y)를 적분해 log y−log(1−y)=t+C입니다. t=0의 오즈가 (1/4)/(3/4)=1/3이라 C=log(1/3)입니다. 원래 변수로 바꾸면

y(t)=1/(1+3e−t).

이 식은 모든 실수 t에서 0과 1 사이이고 직접 미분하면 3e−t/(1+3e−t)²=y(1−y)입니다. t→∞이면 1에 가까워지고 t→−∞이면 0에 가까워집니다. 초기값이 0 또는 1인 경우에는 첫 단계에서 따로 얻은 상수해를 씁니다. 0으로 나눠서 그 해를 잃지 않도록 합니다.

일차 선형식은 곱의 미분으로 바꾼다

열린 구간 I에서 p,q가 연속인 y′+p(t)y=q(t)를 생각하세요. 양변에 양의 함수 m(t)를 곱했을 때 왼쪽이 (my)′=my′+m′y가 되려면 m′=pm이어야 합니다. t₀∈I에서 m(t₀)=1이 되도록 다음 함수를 고릅니다.

m(t)=exp(∫t₀tp(s)ds).

이를 적분인자라고 합니다. (my)′=mq를 적분하면

y(t)=[y₀+∫t₀tm(s)q(s)ds]/m(t).

연속 적분과 양의 분모라 I에서 함수가 정의됩니다. 기본정리로 곱을 미분하면 원래 식으로 돌아가고, t=t₀를 넣으면 초기값을 얻으므로 존재합니다. 같은 초기값인 모든 해에 적분인자를 곱하면 이 식을 얻으므로 유일합니다. 또는 두 해의 차 w가 (mw)′=0, w(t₀)=0이라 전체에서 0이라고 볼 수 있습니다.

손계산. y′+2y/(1+t)=t, y(0)=1에서 구간을 (−1,∞)로 잡습니다. m=(1+t)²를 곱하면 [(1+t)²y]′=t(1+t)²=t+2t²+t³입니다. 따라서 y=[1+t²/2+2t³/3+t⁴/4]/(1+t)²입니다. t=1을 넣으면 분자는 29/12, 분모는 4라 y(1)=29/48입니다.

연속 기울기만으로 유일성이 따라오지는 않는다

일반식 y′=f(t,y)에서 초기점의 작은 직사각형 안에 f가 연속이고, 같은 t에서 |f(t,y)-f(t,z)|≤L|y-z|인 상수 L이 있으면, Picard–Lindelöf 정리가 초기시각 근처에서 해의 존재와 유일성을 보장합니다. 이 부등식을 상태변수에 대한 Lipschitz 조건이라고 합니다. 예컨대 ∂f/∂y가 그 직사각형에서 존재하고 유계면 평균값 정리로 이 부등식을 얻습니다. 보장되는 해는 초기시각 근처에서 시작합니다. 앞의 y′=y²처럼 유일해도 먼 시각까지 계속 정의된다는 결론은 따로 확인합니다.

유일성이 생기는 이유는 초기값이 같은 두 해 y,z에 대해 |y(t)-z(t)|≤L∫t₀t|y(s)-z(s)|ds이기 때문입니다. t≥t₀인 길이 h의 구간에서 두 해의 최대 거리 M을 잡으면 M≤LhM입니다. Lh<1이도록 구간을 짧게 택하면 M=0입니다. t≤t₀ 쪽도 같은 방식으로 적분 방향을 바꾸어 보일 수 있습니다.

반례. y′=2√|y|, y(0)=0에서 f는 연속입니다. 하지만 |f(t,y)-f(t,0)|/|y|=2/√y는 양수 y가 0으로 가면 유계가 아닙니다. y≡0도 해이고, 원하는 a≥0에 대해 t≤a에서 0, t>a에서 (t-a)²인 함수도 해입니다. 붙이는 곳에서 양쪽 미분값이 0이고, 이후에는 y′=2(t-a)=2√y입니다. 기다리는 시간이 여러 가지여서 초기값이 같아도 해가 여러 개입니다.

손계산을 Python으로 검산한다

from fractions import Fraction as F
from math import exp

def integrating_solution(t):
    integral = t*t/2 + 2*t**3/3 + t**4/4
    numerator, denominator = 1 + integral, (1 + t)**2
    numerator_prime, denominator_prime = t + 2*t*t + t**3, 2*(1+t)
    derivative = (numerator_prime*denominator - numerator*denominator_prime) / denominator**2
    return numerator / denominator, derivative

for t in [F(0), F(1), F(2)]:
    y, derivative = integrating_solution(t)
    print(t, y, "equation:", derivative + 2*y/(1+t) == t)

for t in [0, 1, 2]:
    value = 1 / (1 + 3*exp(-t))
    print("logistic", t, f"{value:.6f}")

print("two delayed roots at t=3:", *(max(0, 3-a)**2 for a in [1, 2]))
