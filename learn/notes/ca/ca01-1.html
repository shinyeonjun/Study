미적분과 변화 · CA01 극한과 연속

CA01·1

항을 크게 보낼 때와 두 점을 좁힐 때

2에 1/n을 더한 값은 어느 항에서도 정확히 2가 되지 않지만, n을 충분히 크게 하면 원하는 만큼 2에 가까워집니다. 위치의 평균변화율에서도 두 시각 사이를 좁히면 같은 종류의 질문을 할 수 있습니다.

이 장을 읽고 나면

  • 수열의 극한에서 ‘충분히 큰 모든 번호’의 뜻을 설명한다.
  • 항이 한 값의 양쪽을 오가더라도 그 값까지의 거리가 0에 가까워지면 수렴함을 설명한다.
  • 두 점 사이의 평균변화율을 단위와 함께 계산한다.

도달하는지보다 결국 얼마나 가까운지 묻는다

수열 aₙ = 2 + 1/n, n = 1, 2, …의 처음 항은 3, 2.5, 2.333…, 2.25입니다. 어떤 항도 정확히 2는 아니지만 오차 |aₙ − 2| = 1/n를 더 작게 할 수 있습니다. 예를 들어 0.01보다 가까우려면 n ≥ 101이면 됩니다. 그전 일부 항이 멀어도 뒤에서 늘 가까이 있으면 됩니다.

수열의 극한

허용 오차 ε를 아무리 작게 정해도, 그 뒤의 모든 항에 대해 |aₙ − L| < ε가 되는 번호 N을 고를 수 있으면 limn→∞ aₙ = L입니다. 이때 수열이 L로 수렴한다고 합니다.

ε는 ‘엡실론’이라고 읽으며 양수입니다. 위의 수열에서는 N > 1/ε인 정수를 고르면, n ≥ N일 때 1/n ≤ 1/N < ε입니다. 원하는 정밀도가 먼저 주어지면 거기에 맞춰 출발 번호를 찾는다는 뜻입니다. 무한대는 마지막 항의 번호가 아닙니다.

양쪽을 오가도 수렴할 수 있다

bₙ = (−1)ⁿ/n은 음수와 양수가 번갈아 나오지만, 0까지의 거리는 늘 1/n입니다. 어느 쪽에서 접근하는지보다 결국 얼마나 가까운지가 중요하므로 lim bₙ = 0입니다.

cₙ = (−1)ⁿ은 거리가 줄지 않아 −1과 1을 번갈아 오갑니다. 두 값 사이 거리가 2이므로 양쪽 모두 어떤 하나의 수에서 0.5 이내에 있을 수 없습니다. 뒤로 가도 두 값이 계속 나타나므로 유한한 극한이 없습니다. 또 dₙ = n처럼 임의의 큰 기준을 결국 계속 넘어서는 경우는 양의 무한대로 발산한다고 말합니다. 특정 실수가 극한이라는 뜻은 아닙니다.

실행 예제

for n in (1, 2, 10, 101):
    a = 2 + 1/n
    b = (-1)**n/n
    print(n, f"{a:.5f}", f"{b:.5f}")
1 3.00000 -1.00000
2 2.50000 0.50000
10 2.10000 0.10000
101 2.00990 -0.00990

표의 역할

몇 항의 수치만으로 극한을 증명할 수는 없습니다. 표와 그래프는 후보를 보게 해 줍니다. 위 수열의 극한은 오차를 나타내는 1/n이 충분히 뒤의 모든 항에서 작다는 식으로 확인합니다.

평균변화율은 ‘출력 차이 ÷ 입력 차이’

시각 t의 수치를 초, 그 시각의 위치 s(t) = t²의 수치를 미터로 둔 간단한 모형을 생각합니다. 2초에 위치 4m, 3초에 위치 9m입니다. 두 시각 사이의 평균변화율은 (9 − 4)/(3 − 2) = 5 m/s입니다. 그래프에서 두 점을 잇는 직선인 할선의 기울기입니다.

두 번째 시각을 조금만 옮겨 보기

첫 시각을 2에 고정하고 두 번째 시각을 2+h에 둡니다. h≠0이면 차이를 나눌 수 있습니다.

[s(2+h) − s(2)]/h = [(2+h)² − 4]/h = [4h + h²]/h = 4+h

두 시각을 뒤로 좁혀도 같은 식입니다. h=−0.1이면 두 시각은 2초와 1.9초이고, 분자와 분모가 모두 음수여서 평균변화율은 3.9 m/s입니다. 시간 순서대로 두 시각을 써도 분자와 분모를 동시에 뒤집으므로 같은 결과입니다.

실행 예제

from fractions import Fraction as F

def s(t):
    return t*t

for h in (F(-1), F(-1, 10), F(1, 10), F(1)):
    rate = (s(2 + h) - s(2)) / h
    assert rate == 4 + h
    print(h, f"{float(rate):.1f} m/s")
-1 3.0 m/s
-1/10 3.9 m/s
1/10 4.1 m/s
1 5.0 m/s

h를 0으로 정하면 두 점이 같은 점이어서 원래 몫은 0/0이 되어 정의되지 않습니다. h가 0에 접근할 때 몫이 무엇에 가까워지는지 묻는 것은 별개의 질문입니다. 4+h는 h가 0에 가까울수록 4에 가까워집니다. 다음 장의 함수 극한을 거치면 이 아이디어가 미분으로 연결됩니다.
