정적분: 순간 변화율을 합해 순변화를 구하기

물탱크에 물이 들어올 때는 양의 유량, 빠질 때는 음의 유량으로 기록한다고 합시다. 그래프 높이는 분당 몇 L인지 나타냅니다. 구간 하나에 담긴 양을 구하려면 그 높이에 시간을 곱합니다. 시간을 잘게 나누어 양을 합하는 과정에서 정적분이 등장합니다.

이 장을 읽고 나면

  • 유량과 순변화량의 단위를 구별하고 그래프 부호를 해석한다.
  • 구간을 분할해 왼쪽·오른쪽 리만 합을 구한다.
  • 미적분의 기본정리 두 관점을 누적 함수와 실제 계산에 적용한다.

변화율에 시간을 곱하면 변화량이 된다

유량이 2 L/분으로 일정하면 3분에 6 L가 들어옵니다. −2 L/분이면 3분에 순변화가 −6 L입니다. ‘높이 × 폭’이 하는 일입니다. 유량이 계속 달라지는 경우에는 폭을 잘게 나눠 각 안에서 유량이 거의 일정하다고 보고, 구간별 변화량을 더합니다.

여기서는 0분부터 5분까지 순유량의 숫자를 r(t) = t − 2라고 둡니다. t는 분으로 읽고 r은 L/분으로 읽습니다. 처음엔 물이 빠지다가 2분을 지나 유입으로 바뀝니다.

풀이 예제

0~2분의 삼각형은 폭 2분, 높이 2 L/분입니다. 물이 빠지므로 순변화는 −(2 × 2)/2 = −2 L입니다. 2~5분에는 폭 3분, 높이 3 L/분이라 +(3 × 3)/2 = +4.5 L입니다.

순변화량 = −2 + 4.5 = 2.5 L.
순유량의 절댓값을 누적한 양 = 2 + 4.5 = 6.5 L.

부호는 물의 양이 늘었는지 줄었는지를 알려 줍니다. 두 질문에 답하는 값은 다릅니다.

시간을 나누어 직사각형으로 근사한다

0~5분을 폭 Δt = 1분짜리 다섯 구간으로 나눕니다. 각 구간에서 왼쪽 끝 시각의 유량을 그 구간 대표값으로 씁니다. 계산은 (−2)×1 + (−1)×1 + 0×1 + 1×1 + 2×1 = 0L입니다. 오른쪽 끝을 쓰면 (−1 + 0 + 1 + 2 + 3)×1 = 5L입니다. 두 값이 다른 것은 경계 하나의 유량만으로 구간 전체를 근사했기 때문입니다.

리만 합과 정적분

구간마다 대표점 tᵢ*를 골라 높이와 폭을 곱해 더한 값이 리만 합(Riemann sum)입니다. 같은 폭으로 나누면 ∑ r(tᵢ*)·Δt이고, 폭이 제각각이면 각 구간의 Δtᵢ를 곱합니다.

분할의 가장 넓은 구간도 0으로 줄일 때 대표점 선택에 관계없이 같은 극한을 얻으면, 그 값이 정적분 ∫ab r(t) dt입니다. 이 장처럼 닫힌 구간에서 연속인 함수는 적분할 수 있습니다.

∫는 잘게 나누어 합한다는 표기이고, a와 b는 적분 범위입니다. dt는 t에 대해 폭을 잡는다는 표기입니다. 정적분의 결과는 숫자 하나입니다. 구간을 이어 붙이면 순변화량도 더할 수 있습니다. 양 끝을 거꾸로 쓰면 부호를 뒤집는 규약을 사용합니다. a와 b가 같으면 구간 길이가 0이므로 적분도 0입니다.

누적한 함수를 미분하면 순간 변화율이 돌아온다

정적분의 위끝을 바꾸어 A(x) = ∫0x r(t) dt라고 두면, x를 넣었을 때 처음부터 그때까지 얼마나 물이 달라졌는지 주는 함수가 됩니다. x 근처의 작은 구간에서 r이 연속이라면, 그 구간의 면적을 폭 h로 나눈 값은 h가 작은 동안 r(x)에 가까워집니다. 따라서 내부점에서 A′(x) = r(x)입니다.

이를 미적분의 기본정리의 누적 관점으로 읽습니다. A(x)는 순변화량이고 저장량 그 자체는 아닙니다. 초기 저장량이 10L라면 저장량은 10 + A(x)입니다. 2분에 A(2) = −2L여서 저장량은 8L이고, 5분에는 A(5) = 2.5L여서 12.5L입니다.

순간 변화율의 원시함수를 알면 정적분을 계산한다

미분해서 r이 되는 함수 F를 원시함수라고 합니다. r이 [a, b]에서 연속이고 F가 원시함수라면 누적 함수와 F는 같은 도함수를 갖습니다. 초기 누적량을 0으로 맞추면 정적분 ∫ab r(t) dt = F(b) − F(a)입니다. 원시함수에 어떤 상수를 더해도 이 차에서는 상쇄됩니다.

예에서는 F(t) = t²/2 − 2t입니다. F′(t) = t − 2입니다. F(5) − F(0) = 25/2 − 10 − 0 = 2.5L라 그래프 넓이와 맞습니다. 두 기본정리의 관점을 연결하면, ‘적분으로 함수를 만든 뒤 미분’과 ‘미분이 알려진 함수의 끝값 차이’가 같은 구조입니다.

def rate(t):
    return t - 2

for n in (5, 10, 100):
    dt = 5 / n
    left = dt * sum(rate(i * dt) for i in range(n))
    right = dt * sum(rate((i + 1) * dt) for i in range(n))
    print(f"{n:3d}칸: 왼쪽 {left:.3f}, 오른쪽 {right:.3f}")

def F(t):
    return t*t/2 - 2*t

print(f"정적분: {F(5)-F(0):.3f} L")
  5칸: 왼쪽 0.000, 오른쪽 5.000
 10칸: 왼쪽 1.250, 오른쪽 3.750
100칸: 왼쪽 2.375, 오른쪽 2.625
정적분: 2.500 L

이 예에서 함수가 증가하기 때문에 왼쪽 합이 작고 오른쪽 합이 큽니다. 일반적인 함수를 두고 한쪽 합이 항상 낮다고 말할 수는 없습니다. 더 잘게 나눈 결과가 어디로 가는지와 실제 함수의 모양을 함께 봅니다.
