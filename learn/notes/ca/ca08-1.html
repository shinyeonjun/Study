차분식으로 상태의 다음 값과 안정성 읽기

조절 장치를 한 번 적용하면 다음 측정값이 어떻게 달라지는지 적습니다. 시작값이 달라도 같은 상태 가까이 모이는 경우를 숫자로 확인합니다.

이 장을 읽고 나면

  • 초기값에 차분 규칙을 반복해 상태를 계산한다.
  • 변하지 않는 고정점을 찾는다.
  • 고정점에서의 차이가 줄어들거나 커지는 조건을 설명한다.

한 번의 규칙과 시작값이 있어야 다음을 안다

실험 장치의 상태 x를 같은 간격으로 읽습니다. 다음 상태를 xₖ₊₁=0.5xₖ+3으로 바꾼다고 합시다. 처음 측정값 x₀=2를 넣으면 x₁=4, x₂=5, x₃=5.5입니다. 이처럼 시간 단계를 정수 k로 세는 규칙은 차분식 또는 이산시간 모형입니다. 이름은 차분 Δxₖ = xₖ₊₁ − xₖ에서 왔습니다. 같은 규칙을 Δxₖ = −0.5xₖ + 3, 즉 “한 단계의 변화량이 현재 상태로 정해진다”로 쓸 수 있고, 이것이 미분방정식 y′ = f(y)의 이산판입니다. 다음 값을 정하려면 규칙과 함께 초기조건 x₀가 있어야 합니다. 같은 업데이트 규칙도 다른 초기값을 넣으면 처음 궤적이 달라집니다.

업데이트해도 남는 값

어떤 값 x*를 넣고 한 번 갱신했는데 그대로라면 그 값을 고정점이라고 합니다. x*=0.5x*+3을 풀면 x*=6입니다. 실제로 0.5×6+3=6입니다. 처음 값이 2였다면 아래에서, 10이었다면 위에서 6에 접근합니다.

고정점까지 남은 차이를 재서 안정성을 본다

eₖ=xₖ−6이라 두면 eₖ₊₁=xₖ₊₁−6=0.5(xₖ−6)=0.5eₖ입니다. 처음 오차 −4는 −2, −1, −0.5로 줄어듭니다. 계수가 음수라면 부호가 바뀔 수 있습니다. 예로 xₖ₊₁=−0.5xₖ+9도 고정점이 6인데, 2에서 출발하면 8, 5, 6.5로 번갈아 접근합니다.

def trace(start, a, b, steps):
    values = [float(start)]
    for _ in range(steps):
        values.append(a*values[-1] + b)
    return values

for start in (2, 10):
    print(start, trace(start, 0.5, 3, 4))
print("교대:", trace(2, -0.5, 9, 4))
assert trace(6, 0.5, 3, 4) == [6]*5

실행 결과

2 [2.0, 4.0, 5.0, 5.5, 5.75]
10 [10.0, 8.0, 7.0, 6.5, 6.25]
교대: [2.0, 8.0, 5.0, 6.5, 5.75]

어떤 고정점이 존재하고 eₖ₊₁=a·eₖ이면 |a|<1에서 오차 크기가 0으로 갑니다. |a|>1이면 처음 오차가 0이 아닌 경우 크기가 커집니다. a=−1이면 오차가 같은 크기로 부호만 바꿉니다. a=1인 원래 식 xₖ₊₁=xₖ+b에서는 b=0일 때 모든 시작값이 고정점이고 b≠0이면 고정점이 없습니다.

선형 규칙 xₖ₊₁ = a·xₖ + b (a ≠ 1)는 고정점 x* = b/(1 − a)를 가지며, eₖ = aᵏe₀이므로 닫힌 식 xₖ = x* + aᵏ(x₀ − x*)로 쓸 수 있습니다. 위 예에서 x₄ = 6 + 0.5⁴·(2 − 6) = 6 − 0.25 = 5.75로 표와 같습니다.

비선형 규칙의 고정점 안정성 외우기

xₖ₊₁ = g(xₖ)이고 g(x*) = x*, g가 x* 근처에서 미분 가능하면, 작은 오차는 eₖ₊₁ = g(x* + eₖ) − x* ≈ g′(x*)·eₖ로 움직입니다. 따라서 |g′(x*)| < 1이면 국소적으로 안정(근처에서 출발하면 모임), |g′(x*)| > 1이면 불안정, |g′(x*)| = 1이면 이 일차 근사로는 판정할 수 없습니다. 선형 규칙에서는 g′ = a라 위 조건과 같습니다.

예: g(x) = 2.5x(1 − x). 고정점은 x = 2.5x(1 − x)를 풀어 0과 0.6.
g′(x) = 2.5(1 − 2x)이므로 g′(0) = 2.5 (불안정), g′(0.6) = −0.5 (안정, 부호가 바뀌며 접근).
x₀ = 0.5 → 0.625, 0.5859, 0.6065, 0.5966, 0.6017 …: 0.6과의 차이가 약 −0.5배씩 바뀝니다.

한눈에 정리

대상식과 뜻
차분식xₖ₊₁ = g(xₖ). 규칙과 초기조건 x₀가 있어야 궤적이 정해진다.
고정점g(x*) = x*. 선형이면 x* = b/(1 − a) (a ≠ 1).
선형 안정성eₖ = aᵏe₀. |a| < 1 수렴, |a| > 1 발산, a < 0이면 부호가 번갈아 바뀐다.
비선형 안정성|g′(x*)| < 1이면 국소 안정, > 1이면 불안정, = 1이면 판정 불가.

한 줄 정리

상태가 유지되는 고정점을 구하고, 그 점과의 차이가 갱신할 때마다 어떻게 변하는지 봅니다.
