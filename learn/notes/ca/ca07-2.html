헤시안으로 방향마다 휘어지는 정도 비교하기

변수가 두 개면 움직일 방향도 여러 가지입니다. 한 점에서 기울기는 0인데 한 방향은 올라가고 다른 방향은 내려가는 이유를 그림과 수로 확인합니다.

이 장을 읽고 나면

  • 두 변수의 이계편도함수로 헤시안을 구성한다.
  • 방향을 정해 이차항과 방향 곡률을 계산한다.
  • 정지점의 국소 최솟값과 안장점을 구분한다.

기울기 벡터와 헤시안의 역할

f(x,y)=x²+2xy+3y²를 보겠습니다. x만 움직였을 때의 기울기는 2x+2y, y만 움직였을 때는 2x+6y입니다. 두 값을 모은 기울기 벡터는 (2x+2y, 2x+6y)입니다. 원점에서는 둘 다 0이지만, 원점에서 한 걸음 떨어지면 함수가 변합니다.

다시 미분할 값x로 미분y로 미분
x 방향 기울기22
y 방향 기울기26

이 이계편도함수의 2×2 배열이 헤시안 H=[[2,2],[2,6]]입니다. 두 변수의 이계편도함수가 주변에서 연속이면 이 예처럼 섞인 항 두 개가 같습니다.

한 방향으로 자르면 다시 한 변수의 함수가 된다

이동 방향 d=(1,−1)을 고르고 원점에서 (x,y)=(t,−t)로 움직입니다. 이 방향에서 f는 t²−2t²+3t²=2t²입니다. t에 대한 두 번째 미분은 4입니다. 행렬에서는 Hd=(0,−4), dᵀHd=1×0+(−1)×(−4)=4입니다. 길이가 1인 방향으로 비교할 때는 d를 그 길이로 나눠 단위벡터로 맞춥니다. 여기서는 t당 움직인 길이가 √2이므로 단위 방향 u = d/√2의 곡률은 uᵀHu = 4/2 = 2입니다.

작은 이동 벡터 d에 대한 2차 테일러식은 기준 함수값 + 기울기와 d의 내적 + ½ dᵀHd입니다. 이 예에서는 f가 원래 2차식이라 식이 원점 주변뿐 아니라 모든 이동에 정확히 맞습니다. 원점에서 d=(1,−1)로 이동하면 기울기 항이 0이고 ½×4=2입니다.

모든 방향에서 올라가는지 확인한다

이 f의 방향 곡률은 d=(a,b)에 대해 2(a+b)²+4b²입니다. 0이 아닌 방향에서는 양수이므로 원점은 이 이차식에서 유일한 전역 최솟값입니다. 보다 일반적인 매끄러운 함수에서는 기울기가 0이고 모든 방향의 헤시안 곡률이 양수인 점이 엄격한 국소 최솟값입니다. 함수가 멀리서 다시 낮아질 수 있으므로 기울기와 헤시안만 보고 전역 최솟값이라고 단정하지 않습니다.

g(x,y)=x²−y²는 원점에서 기울기가 0입니다. x 방향으로는 값이 올라가고 y 방향으로는 내려가므로 안장점입니다. 반대로 f(x)=x⁴는 원점에서 두 번째 미분이 0이어도 최소이고, −x⁴는 최대입니다. 이차항이 0인 방향이 있으면 더 높은 항이나 직접 비교가 필요할 수 있습니다.

이계도함수 판정법 외우기

한 변수에서 이계도함수 f″(x)는 기울기 f′의 변화율입니다. f″ > 0인 구간에서는 기울기가 커지므로 그래프가 아래로 볼록(convex)하고, f″ < 0이면 위로 볼록(concave)합니다. 그래서 f′(a) = 0인 점(정지점, 임계점)에서 다음이 성립합니다.

한 변수: f′(a) = 0일 때두 변수: ∇f = 0일 때, D = fxxfyy − fxy² (= det H)결론
f″(a) > 0D > 0이고 fxx > 0 (H의 고윳값이 모두 양수)엄격한 국소 최솟값
f″(a) < 0D > 0이고 fxx < 0 (고윳값이 모두 음수)엄격한 국소 최댓값
(해당 없음)D < 0 (고윳값의 부호가 서로 다름)안장점
f″(a) = 0D = 0 (고윳값 중 0이 있음)판정 불가: 더 높은 차수나 직접 비교

앞의 f는 H = [[2,2],[2,6]]이라 D = 2·6 − 2² = 8 > 0, fxx = 2 > 0이므로 원점이 국소 최솟값입니다. H의 고윳값은 4 ± 2√2 ≈ 1.17, 6.83으로 모두 양수이며, 단위 방향 곡률 uᵀHu는 항상 이 두 값 사이에 있습니다. g(x,y) = x² − y²는 H = [[2,0],[0,−2]], D = −4 < 0이라 안장점입니다. 판정 불가의 예로, x⁴, −x⁴, x³은 모두 0에서 f′ = f″ = 0이지만 각각 최소, 최대, 극값 아님입니다.

국소 극값과 전역 극값

국소(local) 최솟값은 그 점 근처에서만 가장 작은 값이고, 전역(global) 최솟값은 정의역 전체에서 가장 작은 값입니다. 닫힌 구간 [a, b]에서 연속인 함수는 최댓값과 최솟값을 반드시 가지며(최대·최소 정리), 그 후보는 구간 안의 임계점과 두 끝점뿐입니다. 예를 들어 f(x) = x³ − 3x를 [−2, 3]에서 보면 f′ = 3x² − 3 = 0에서 x = ±1이고, 후보값은 f(−2) = −2, f(−1) = 2, f(1) = −2, f(3) = 18입니다. x = −1의 국소 최댓값 2는 전역 최댓값이 아니며, 전역 최댓값 18은 기울기가 0이 아닌 끝점 x = 3에 있습니다. 전역 최솟값 −2는 x = 1과 x = −2 두 곳에서 나옵니다.

import numpy as np

hessian = np.array([[2, 2], [2, 6]])
direction = np.array([1, -1])

def f(point):
    x, y = point
    return x*x + 2*x*y + 3*y*y

curvature = direction @ hessian @ direction
step = 0.125
move = step*direction
finite_difference = (f(move) - 2*f(np.zeros(2)) + f(-move)) / step**2
print("Hd:", list(map(int, hessian @ direction)))
print("곡률:", int(curvature), "차분:", f"{finite_difference:.1f}")
assert curvature == finite_difference

실행 결과

Hd: [0, -4]
곡률: 4 차분: 4.0

한눈에 정리

대상식과 뜻
헤시안 H이계편도함수의 행렬. 섞인 편도함수가 연속이면 대칭이다.
방향 곡률dᵀHd = 방향 d로 자른 단면의 두 번째 미분. 단위 방향끼리 비교한다.
2차 근사f(p + d) ≈ f(p) + ∇f(p)·d + ½dᵀHd
정지점 판정H의 고윳값이 모두 양수 → 국소 최소, 모두 음수 → 국소 최대, 부호 섞임 → 안장점, 0 포함 → 판정 불가
전역 극값국소 정보만으로는 알 수 없다. 닫힌 구간이면 임계점과 끝점의 값을 비교한다.
