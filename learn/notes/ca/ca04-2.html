다변수 연쇄법칙과 야코비 행렬

한 입력 t가 중간 값 두 개를 바꾸고, 두 중간 값이 함께 출력을 바꾼다고 합시다. 전체 변화율은 어느 한 갈래만 보면 놓칩니다. 경로마다 변화율을 곱해 모두 더하고, 출력이 여러 개일 때는 같은 계산을 행렬로 정리합니다.

이 장을 읽고 나면

  • 한 입력에서 두 경로를 지나가는 합성함수를 미분한다.
  • 야코비 행렬의 (출력 수, 입력 수) 형태와 한 원소의 뜻을 읽는다.
  • 합성의 두 행렬을 어느 점에서 계산하고 어느 순서로 곱하는지 설명한다.

한 입력이 여러 갈래에서 같은 출력을 바꾼다

중간 값 u = t², v = 1 + t와 결과 z = uv + v²를 둡니다. t = 2일 때 u = 4, v = 3이므로 z = 4 × 3 + 3² = 21입니다. t를 조금 바꾸면 u와 v 모두 바뀝니다. z의 편미분 ∂z/∂u만 계산하면 v의 변화를 빠뜨립니다.

풀이 예제

t = 2에서 z의 전체 변화율을 구합니다.

① u 경로: du/dt = 2t = 4, ∂z/∂u = v = 3. 이 경로의 기여는 3 × 4 = 12.
② v 경로: dv/dt = 1, ∂z/∂v = u + 2v = 4 + 6 = 10. 이 경로의 기여는 10 × 1 = 10.
③ dz/dt = 12 + 10 = 22.

직접 한 변수 식으로 바꾸면 z = t³ + 2t² + 2t + 1입니다. 3t² + 4t + 2에 t = 2를 대입해도 22입니다.

경로마다 곱하고, 같은 출력에 들어오는 항을 더한다

u(t), v(t)와 z = f(u, v)가 해당 점에서 미분 가능하면 다변수 연쇄법칙이 성립합니다.

dz/dt = (∂f/∂u)(du/dt) + (∂f/∂v)(dv/dt)

u의 미분은 t가 주어진 값에서, f의 편미분은 그때의 (u, v)에서 계산합니다. 예를 들어 t의 단위가 초, u와 v는 m, f는 ℃라면, 각 경로 곱의 단위는 (℃/m) × (m/초) = ℃/초라 서로 더할 수 있습니다. 계산 그래프에서 합쳐지는 경로의 항을 더하는 이유는 작은 u 변화와 v 변화에 대한 선형 근사가 합으로 표현되기 때문입니다.

입력과 출력이 여러 개라면 미분을 표로 적는다

입력 n개에서 출력 m개를 계산하는 함수 F를 생각합니다. 야코비 행렬(Jacobian matrix) JF는 행마다 출력 하나, 열마다 입력 하나를 써서 각 편미분을 모은 m × n 표입니다. i행 j열은 다른 입력을 고정했을 때 j번째 입력 변화에 대한 i번째 출력의 순간 변화율입니다.

출력 두 개와 입력 두 개

F(u, v) = (uv, u + v²)의 각 성분을 u와 v로 편미분합니다.

출력u로 미분v로 미분
F₁ = uvvu
F₂ = u + v²12v

(u, v) = (3, 6)에서 JF의 첫 행은 (6, 3), 둘째 행은 (1, 12)입니다. 첫 행 6은 v를 6으로 고정하고 u를 아주 조금 바꿀 때 F₁이 얼마나 바뀌는지 나타냅니다.

입력의 작은 변화 δ를 n × 1 열벡터로 두면, 출력의 변화는 ΔF ≈ JF · δ입니다. 행과 열의 순서를 고정한 이유가 여기에 있습니다. 스칼라 출력은 m = 1이므로 야코비 행렬의 한 행이 기울기 벡터 성분을 모은 것입니다. 기울기를 열벡터로 적는 관례를 따르면 기울기는 이 행의 전치에 해당합니다. 책이나 API에서 행·열 규약이 다를 수 있으니 직접 곱해 차원을 확인합니다.

행렬을 곱하면 두 함수의 연쇄법칙이 된다

세 입력을 받는 G(x, y, z) = (x + y, yz)에 F를 이어 붙입니다. H = F ∘ G입니다. 기준 입력 (1, 2, 3)에서 G(1, 2, 3) = (3, 6)입니다. 앞에서 구한 JF는 이 중간 값에서 사용합니다.

행렬 곱의 각 칸을 확인한다

JG(1, 2, 3) = [[1, 1, 0], [0, 3, 2]]
JF(3, 6) = [[6, 3], [1, 12]]
JH(1, 2, 3) = JF(3, 6) · JG(1, 2, 3)
= [[6, 15, 6], [1, 37, 24]]

예를 들어 첫 출력의 y에 대한 미분은 첫 행 (6, 3)과 둘째 열 (1, 3)의 내적 6 × 1 + 3 × 3 = 15입니다. y를 바꾸면 u를 통한 효과와 v를 통한 효과가 함께 생깁니다.

일반적으로 G가 n → k, F가 k → m으로 보낼 때 JG는 k × n, JF는 m × k입니다. 미분 가능한 함수들을 합성해 JF∘G(x) = JF(G(x)) · JG(x)입니다. 작은 변화부터 생각하면 δ에 JG가 먼저 작용하고 결과에 JF가 곱해집니다. 앞 예에서 순서를 뒤집으면 (2 × 3) · (2 × 2)의 안쪽 길이가 맞지 않습니다. 안쪽 길이가 우연히 같은 경우에도 곱의 순서를 바꿀 이유는 없습니다.

작은 입력 변화로 행렬의 열을 검산한다

행렬 곱(LA04)을 코드로 재현하고, y를 앞뒤로 조금 바꿔 둘째 열의 두 숫자를 점검합니다. 행렬의 한 열은 해당 입력 하나를 바꿨을 때의 출력 변화율 벡터입니다.

def composite(x, y, z):
    u, v = x+y, y*z
    return (u*v, u+v*v)

jf = [[6, 3], [1, 12]]
jg = [[1, 1, 0], [0, 3, 2]]
columns = list(zip(*jg))
jh = [[sum(a*b for a, b in zip(row, col)) for col in columns] for row in jf]
h = 0.001
plus = composite(1, 2+h, 3)
minus = composite(1, 2-h, 3)
approx = [(a-b)/(2*h) for a,b in zip(plus, minus)]
print("야코비 행렬:", jh)
print("y의 편미분:", [round(x, 3) for x in approx])
야코비 행렬: [[6, 15, 6], [1, 37, 24]]
y의 편미분: [15.0, 37.0]

zip(*jg)는 행들의 같은 위치를 묶어 열을 만듭니다. 모든 행과 열 사이에서 대응 성분을 곱해 하나의 칸을 구합니다. 점검용 중앙 차분은 분석 미분을 대신하는 정의가 아니라, 출력값을 몇 번 계산해 비교하는 근사입니다.
