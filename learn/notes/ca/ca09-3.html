CA09·3

Green 정리로 경계의 순환과 평면 내부를 비교하기

삼각형의 세 변을 직접 걸어 적분한 값과 내부의 미분을 모두 더한 값을 맞춰 봅니다. 영역이 구멍을 가지면 왜 안쪽 경계의 방향을 바꿔야 하는지도 증명에서 읽어 냅니다.

이 장을 읽고 나면

  • Green 정리의 순환형을 두 편미분의 적분으로 유도한다.
  • 같은 삼각형에서 경계 적분과 이중적분을 각각 구한다.
  • 구멍 있는 영역의 경계 방향 및 유속형을 판별한다.

계산을 시작하기 전에 닫힌 경계와 방향을 확인한다

평면에서 F=(P,Q)를 따라 한 바퀴 돌아오는 일을 순환이라고 합니다. 이 장에서 D는 유계이고 경계가 유한 개의 서로 겹치지 않는 조각별 매끄러운 단순 폐곡선으로 이루어진 영역입니다. F의 두 성분은 경계를 포함한 영역의 닫힘을 담는 열린 집합에서 연속 미분 가능하다고 가정합니다. ∂D는 영역의 전체 경계입니다. 이를 양의 방향으로 돌면 진행하면서 영역이 왼쪽에 놓입니다. 구멍이 없는 삼각형에서는 반시계 방향입니다.

Green 정리 · 순환형

∮∂D P dx+Q dy = ∬D (Qₓ−Pᵧ) dA.

왼쪽은 경계의 접선방향을 따라 실제로 이동하며 적분합니다. 오른쪽은 내부 점마다 회전 방향을 나타내는 편미분의 차를 면적에 대해 더합니다.

이 등식은 경계를 한 바퀴 반대로 돌면 왼쪽의 부호가 바뀐다는 사실과 같이 사용해야 합니다. 방향과 두 편미분의 순서를 동시에 기억하는 방법은 F=(-y,x)를 넣어 보는 것입니다. 단위원 위 반시계 접선과 항상 같은 방향이라 순환이 양수이고, Qₓ−Pᵧ=1−(-1)=2여서 오른쪽도 양수입니다.

한 쌍의 경계 높이에서 기본정리를 써서 유도한다

먼저 D={(x,y): a≤x≤b, g(x)≤y≤h(x)}처럼 세로줄과 만나는 부분이 한 구간인 경우를 봅시다. 경계 위쪽과 아래쪽 함수는 조각별 매끄러워 이 적분이 가능하다고 합시다. -Pᵧ부터 안쪽 y 적분을 하면 P(x,g(x))−P(x,h(x))입니다. 아래 경계에서는 x=a→b, 위에서는 x=b→a로 이동합니다. 두 수직 옆변의 dx는 0이므로 ∮P dx=−∬ Pᵧ dA입니다.

이번에는 가로줄이 ℓ(y)≤x≤r(y), c≤y≤d를 만나는 경우입니다. Qₓ를 x에 관해 먼저 적분하면 Q(r(y),y)−Q(ℓ(y),y)입니다. 양의 방향에서 오른쪽은 아래에서 위, 왼쪽은 위에서 아래로 움직입니다. 수평 옆변의 dy=0이어서 ∮Q dy=∬ Qₓ dA를 얻습니다. 두 종류의 설명이 모두 가능한 영역에서는 이 둘을 더해 정리를 증명했습니다.

이런 작은 영역들로 분할할 수 있는 경우, 공통 변은 두 조각이 서로 반대 방향으로 지나므로 선적분이 상쇄됩니다. 이중적분은 겹치지 않는 내부 조각에서 합쳐집니다. 따라서 바깥 경계와 실제 구멍 둘레만 남습니다. 예컨대 고리를 상하 반쪽으로 나누면 자른 선분들은 합칠 때 없어집니다. 이 논증은 이런 유한 분할이 가능한 영역에 대한 증명이고, 정리의 더 일반적인 판본은 경계의 정칙성을 이용합니다.

세 변과 내부에서 7/6을 각각 구한다

앞서 다룬 곡선의 매개화에서 이어서, D={0≤y≤x≤1}, F=(-y,x²)라 둡니다. 삼각형의 꼭짓점을 반시계로 (0,0)→(1,0)→(1,1)→(0,0)으로 지납니다.

  1. 밑변은 y=0,dy=0이므로 -y dx +x²dy=0입니다.
  2. 오른쪽 변은 x=1,dx=0, y:0→1이라 ∫011dy=1입니다.
  3. 대각선은 x=y=t, t:1→0입니다. ∫10(−t+t²)dt=1/6이므로 순환의 합은 7/6입니다.

영역에서 Qₓ−Pᵧ=2x+1입니다. 먼저 y를 0부터 x까지 적분하면 x(2x+1), 다음으로 x를 0부터 1까지 적분하면 2/3+1/2=7/6입니다. 이 예에서는 경계를 세 조각으로 계산한 값과 내부를 이중적분한 값이 일치합니다.

법선 방향으로 재는 유속과 구멍의 방향

r′(t)=(x′,y′)가 양의 경계 방향일 때 오른쪽이 바깥입니다. 접선을 오른쪽으로 90° 돌린 (y′,−x′)를 단위벡터로 나누고 ds를 곱하면 n ds=(dy,−dx)입니다. 따라서 평면 유속(flux), 즉 바깥으로 향하는 법선 성분의 적분은 ∮ F·n ds = ∮ P dy−Q dx입니다. 순환형에 (−Q,P)를 넣어 유속형을 얻습니다.

∮∂D F·n ds = ∬D(Pₓ+Qᵧ)dA.

같은 삼각형의 유속. F=(x,2y)이면 내부에서 Pₓ+Qᵧ=3이라 3×(1/2)=3/2입니다. 경계의 밑변에서는 Q=0, 오른쪽 변에서는 P=1이라 유속이 1, 대각선에서는 Pdy−Qdx=(t−2t)dt를 1에서 0까지 적분해 1/2를 더합니다. 유속은 경계를 관통하는 성분, 순환은 경계를 따라 도는 성분입니다.

원점을 뺀 평면의 반례 F=(-y/(x²+y²),x/(x²+y²))를 1≤√(x²+y²)≤2에 적용하면, 장은 고리의 경계와 내부 모두에서 매끄럽습니다. 내부의 Qₓ−Pᵧ=0이고, 바깥 원의 순환 2π와 안쪽 원의 순환 −2π를 더해도 0입니다. 반지름 2의 원판 전체에 곧바로 적용하면 장이 원점에서 정의되지 않아 가정이 깨집니다.

응용. 순환형에 F=(-y/2,x/2)를 넣으면 Qₓ−Pᵧ=1이라 영역의 넓이는 (1/2)∮(x dy−y dx)입니다. 다음 단원에서는 경계를 따르는 순환과 바깥을 가로지르는 흐름을 3차원에서 각각 확장합니다.

손계산을 Python으로 검산한다

from fractions import Fraction as F

def integrate(f):
    return (f(F(0)) + 4*f(F(1, 2)) + f(F(1))) / 6

# 양의 경계 순서: 밑변, 오른쪽, 역방향 대각선
circulation = [F(0), F(1), -integrate(lambda t: -t + t*t)]
inside_circulation = integrate(lambda x: x*(2*x + 1))
flux = [F(0), F(1), -integrate(lambda t: -t)]
inside_flux = integrate(lambda x: 3*x)

print("circulation edges:", ", ".join(map(str, circulation)))
print("circulation totals:", sum(circulation), inside_circulation)
print("flux edges:", ", ".join(map(str, flux)))
print("flux totals:", sum(flux), inside_flux)
circulation edges: 0, 1, 1/6
circulation totals: 7/6 7/6
flux edges: 0, 1, 1/2
flux totals: 3/2 3/2

Python 3.14.6으로 실행했습니다. 대각선의 매개변수는 1에서 0으로 줄어드므로, 코드에서는 0에서 1까지 구한 값 앞에 음의 부호를 붙였습니다.
