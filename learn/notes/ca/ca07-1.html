CA07·1

테일러 근사에서 접선·곡률·오차 읽기

복잡한 함수도 한 점의 가까운 곳에서는 접선이나 포물선으로 계산할 수 있습니다. 지수함수로 몇 자리까지 쓸 만한지 확인합니다.

이 장을 읽고 나면

  • 함숫값과 미분값으로 일차·이차 근사를 만든다.
  • 2차식에서 계수를 왜 2로 나누는지 설명한다.
  • 구간에서 나머지의 절댓값을 제한한다.

출발점의 높이와 기울기를 맞춘다

함수 f(x)를 x=0 근처에서 계산하고 싶습니다. 일차식 P₁(x)=f(0)+f′(0)x는 f와 x=0에서 높이와 기울기가 같습니다. 그 점을 조금 벗어난 x에서는 두 함수가 달라집니다. x에 붙는 항은 접선 방향으로 이동한 양을 나타냅니다.

이차식 P₂(x)=f(0)+f′(0)x+f″(0)x²/2는 두 번째 미분값도 맞춥니다. a·x²를 두 번 미분하면 2a이므로 계수 a를 f″(0)/2로 둡니다. 다른 점 x=a를 중심으로 쓰고 싶을 때는 여기서 x 대신 이동량 x−a, 각 미분값은 a에서 읽습니다.

n차 테일러 다항식과 나머지 외우기

f가 a를 포함한 구간에서 n+1번 미분 가능하면

Pₙ(x) = f(a) + f′(a)(x−a) + f″(a)(x−a)²/2! + … + f⁽ⁿ⁾(a)(x−a)ⁿ/n!
Rₙ(x) = f(x) − Pₙ(x) = f⁽ⁿ⁺¹⁾(c)(x−a)ⁿ⁺¹/(n+1)! (c는 a와 x 사이의 어떤 수, 라그랑주 나머지)

k번째 항의 계수를 k!로 나누는 이유는 (x−a)ᵏ을 k번 미분하면 k!이 되기 때문입니다. 그래서 Pₙ의 k번째 미분값이 a에서 f⁽ᵏ⁾(a)와 같아집니다(k = 0, …, n). c가 정확히 어디인지는 모르지만, a와 x 사이에서 |f⁽ⁿ⁺¹⁾| ≤ M이면 |Rₙ(x)| ≤ M|x−a|ⁿ⁺¹/(n+1)!이라는 상한을 얻습니다. a = 0인 경우를 매클로린(Maclaurin) 다항식이라고 부릅니다.

eˣ에서는 미분값이 모두 1에서 출발한다

f(x)=exp(x)는 미분해도 exp(x)입니다. x=0에서 함수, 일차 미분, 이차 미분이 모두 1이므로 P₁(x)=1+x, P₂(x)=1+x+x²/2입니다. x=0.1이면 P₁=1.1과 P₂=1.105입니다. 실제 f(0.1)은 약 1.10517092입니다.

정확한 값을 몰라도 오차의 한계를 정할 수 있다

세 번 미분 가능한 함수에서 0과 x 사이의 세 번째 미분 절댓값이 M 이하라면, 2차 테일러 근사의 나머지는 |f(x)−P₂(x)|≤M|x|³/6입니다. exp의 경우 x가 0.1이면 구간 [0,0.1]에서 세 번째 미분의 최대가 exp(0.1)입니다. 이 상한을 사용하면 오차는 약 0.00018420 이하입니다. 실제 오차 0.00017092는 이보다 작습니다.

입력일차 근사의 절대오차이차 근사의 절대오차이차 오차 상한
0.10.005170920.000170920.00018420
0.50.148721270.023721270.03434836
from math import exp

for x in (0.1, 0.5):
    exact = exp(x)
    first = 1 + x
    second = first + x*x/2
    first_error = abs(exact - first)
    second_error = abs(exact - second)
    bound = exp(abs(x)) * abs(x)**3 / 6
    assert second_error <= bound
    print(f"x={x:.1f}", *(f"{v:.8f}" for v in (first_error, second_error, bound)))

실행 결과

x=0.1 0.00517092 0.00017092 0.00018420
x=0.5 0.14872127 0.02372127 0.03434836

차수가 높아도 목표 입력이 중심에서 멀어지면 원하는 정확도를 보장하지 못할 수 있습니다. 미분값의 범위를 모를 때는 오차 상한을 그대로 적용할 수 없습니다. 먼저 원하는 입력 구간과 허용 오차를 정하고 중심이나 차수를 선택합니다.
