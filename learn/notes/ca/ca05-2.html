부정적분·치환과 측정값의 수치 적분

식이 주어지면 미분을 거꾸로 하여 원시함수를 찾을 수 있습니다. 반대로 센서가 몇 시각의 값만 주었다면, 측정 사이의 모양을 가정해 적분을 근사해야 합니다. 각각의 계산에서 무엇을 알며 무엇을 가정하는지 구분합니다.

이 장을 읽고 나면

  • 부정적분에 붙는 상수와 정적분의 끝값 차이를 구분한다.
  • 안쪽 함수와 그 미분을 찾아 치환하고, 정적분의 경계를 같은 변수로 맞춘다.
  • 간격이 일정하지 않은 실측 자료에 사다리꼴 합을 적용한다.

미분을 거꾸로 해 원시함수를 찾는다

미분해서 g(x) = 6x²가 되는 함수 하나는 2x³입니다. 끝에 5를 더한 2x³ + 5도 미분하면 같은 결과를 줍니다. 한 연결된 구간에서 같은 도함수를 가지는 원시함수들은 상수만큼 다릅니다. 부정적분은 이렇게 원시함수들의 모음을 적은 것입니다.

∫ 6x² dx = 2x³ + C

거듭제곱 규칙을 거꾸로 쓰면 ∫ xn dx = xn+1/(n+1) + C입니다. xn과 그 원시함수를 미분할 수 있는 구간에서 n ≠ −1일 때 씁니다. n = −1에는 분모가 0이 되므로 이 규칙을 적용하지 않습니다. x = 0을 지나지 않는 구간에서는 ∫ 1/x dx = ln|x| + C입니다.

이전 장의 정적분은 함수 모음이 아니라 두 경계 사이의 수 하나입니다. 예를 들어 ∫01 6x² dx = (2 + C) − (0 + C) = 2로 C가 사라집니다.

합성함수의 안쪽과 그 미분을 찾는다

∫ 2x(1 + x²)³ dx를 직접 전개하지 않고 계산해 봅시다. 괄호 안쪽 1 + x²의 미분은 2x입니다. 미분에서 연쇄법칙을 쓰면 바깥 도함수에 안쪽 미분을 곱하므로, 적분에서는 그 곱을 다시 한 변수로 바꿀 수 있습니다. 이를 치환적분이라고 부릅니다.

부정적분 풀이

① u = 1 + x²로 둔다. 안쪽 미분은 du/dx = 2x.
② 2x dx를 du에 대응시키면 ∫ u³ du가 남는다.
③ u⁴/4 + C를 얻고 u를 1 + x²로 되돌린다.
답은 (1 + x²)⁴/4 + C.

미분하면 바깥의 (1 + x²)³과 안쪽의 2x가 곱해져 원래 식이 나옵니다. du 표기는 이 연쇄법칙을 기억하기 위한 것입니다. ∫에서 x로 남은 부분이 있다면 u로 바뀌었는지 확인합니다.

정적분에서 치환하면 경계도 같은 변수로 바꾼다

위 식을 x = 0부터 x = 1까지 적분한다면, u = 1 + x²에 경계 x = 0을 넣으면 u = 1, x = 1을 넣으면 u = 2입니다.

∫01 2x(1 + x²)³ dx = ∫12 u³ du = (2⁴ − 1⁴)/4 = 15/4.

또는 원시함수 F(x) = (1 + x²)⁴/4에 원래 경계 0, 1을 넣어 같은 값 3.75를 얻습니다. u의 원시함수에 x 경계를 넣는 방식과 x의 원시함수에 u 경계를 넣는 방식은 변수를 섞은 계산입니다.

줄어드는 치환에서도 부호를 따라간다

∫01 2(3 − 2x)³ dx에서는 u = 3 − 2x, du = −2 dx를 씁니다. 경계는 u = 3에서 1로 줄어듭니다. 2 dx = −du이므로 ∫31 −u³ du가 됩니다. 경계를 1에서 3으로 뒤집을 때 부호가 한 번 더 바뀌어 ∫13 u³ du = (81 − 1)/4 = 20입니다.

시간 사이의 폭이 제각각인 표를 적분한다

이번에는 유량 센서가 0, 1, 3, 4분에 2, 4, 4, 0 L/분을 기록했다고 합시다. 좌우 두 관측 사이를 직선으로 잇기로 하면, 한 구간의 평균 높이는 두 끝점 높이의 평균입니다. 이것을 실제 시간 폭에 곱하고 모든 구간을 더하는 계산이 사다리꼴 합입니다.

구간 (분)폭 (분)평균 높이 (L/분)변화량 (L)
0 → 11(2 + 4)/2 = 33
1 → 32(4 + 4)/2 = 48
3 → 41(4 + 0)/2 = 22

세 값을 합해 13L로 근사합니다. 1분과 3분 사이에는 관측이 없어서 그 사이에 생긴 급격한 변화는 알 수 없습니다. 실제 센서 데이터에서 단위, 관측 순서, 중복·누락 시각을 점검합니다(DA06). 같은 시각이 두 번 나오면 어느 값이 유효한지부터 정합니다. 오랫동안 센서가 끊긴 구간을 직선으로 채우는 것이 타당한지도 별도로 판단합니다.

from math import isclose

time = [0, 1, 3, 4]
rate = [2, 4, 4, 0]
assert len(time) == len(rate)
assert all(b > a for a, b in zip(time, time[1:]))

areas = [(b-a)*(left+right)/2
         for a, b, left, right in zip(time, time[1:], rate, rate[1:])]
print("구간별 L:", areas)
print(f"누적량: {sum(areas):.1f} L")

def antiderivative(x):
    return (1+x*x)**4 / 4

exact_original = antiderivative(1) - antiderivative(0)
exact_changed = (2**4-1**4) / 4
assert isclose(exact_original, exact_changed)
print(f"치환 예제 검산: {exact_original:.2f}")
구간별 L: [3.0, 8.0, 2.0]
누적량: 13.0 L
치환 예제 검산: 3.75

사다리꼴 합은 직선 사이의 넓이에는 정확합니다. 곡선의 경우에는 함수와 측정 간격에 따라 오차가 생깁니다. 실제로 더 많은 측정값을 얻으면 구간을 다시 나눠 볼 수 있지만, 같은 데이터에 선으로 추정한 점만 더해도 새 정보는 생기지 않습니다.
