CA06·1

부분적분과 이상적분

곱을 적분할 때는 미분에서 배운 곱의 법칙으로 돌아갑니다. 적분 경계가 무한히 멀거나 함수가 끝없이 커지면, 먼저 계산할 수 있는 구간을 정한 뒤 경계를 움직입니다.

이 장을 읽고 나면

  • 곱의 미분을 정리하여 부분적분 식을 얻고, 새로운 적분이 쉬워지도록 항을 고른다.
  • 무한히 긴 구간이나 함수가 발산하는 끝점에서 유한 구간의 적분으로 극한을 세운다.
  • 특이점 양쪽의 수렴 여부를 따로 판단하고, 지수함수의 무한 누적량을 계산한다.

곱의 미분을 거꾸로 읽는다

시간 x가 늘면서 두 효과가 곱해져 순간 변화량이 x ex가 된다고 합시다. ∫ x ex dx에서 x와 ex는 두 함수의 곱입니다. 두 함수를 따로 적분한 뒤 곱하면 그 결과를 미분할 때 곱의 법칙에 따른 두 항이 생깁니다. 곱의 법칙 자체를 활용하면 원하는 적분을 하나의 더 쉬운 적분으로 바꿀 수 있습니다.

u(x), v(x)가 연속적으로 미분 가능하다고 하면 (uv)′ = u′v + uv′입니다. 아래 그림은 u와 v가 늘어나는 경우에 두 곱의 항이 생기는 이유를 보여 줍니다.

양변을 a부터 b까지 적분하고 ∫ uv′ dx를 한쪽에 남깁니다. 적분의 기본정리로 ∫ (uv)′ dx = (uv)(b) − (uv)(a)입니다. 이렇게 얻은 식을 부분적분이라고 합니다.

∫ab u(x)v′(x) dx = [u(x)v(x)]ab − ∫ab u′(x)v(x) dx.

∫ u dv = uv − ∫ v du도 같은 관계입니다. 부정적분에서 오른쪽의 최종 원시함수에 + C를 붙입니다. 정적분에서는 대괄호에 위 경계를 넣은 값에서 아래 경계를 넣은 값을 뺍니다.

손으로 풀기 · x ex의 누적

u = x는 미분하면 1이 됩니다. v′ = ex는 적분하면 v = ex인 원시함수를 고를 수 있습니다. 따라서 다음과 같습니다.

∫01 x ex dx = [x ex]01 − ∫01 ex dx = e − (e − 1) = 1.

원시함수 (x − 1)ex를 미분하면 ex + (x − 1)ex = x ex로 돌아옵니다. ×1이 생략된 ln x도 ∫ (ln x)·1 dx로 볼 수 있습니다. u = ln x, v′ = 1로 고르면 x > 0에서 남는 적분은 ∫ (1/x)·x dx = ∫ 1 dx입니다.

먼저 미분하면 단순해지는 u를 찾고, 남은 v′의 원시함수를 구할 수 있는지 봅니다. 계산을 시작한 뒤에는 ∫ vu′가 실제로 쉬워졌는지 확인합니다.

무한 구간은 유한한 적분의 극한으로 계산한다

e−x는 x가 커질수록 0에 가까워집니다. 0부터 무한히 멀리까지 쌓인 넓이를 알고 싶다면, 먼저 유한한 b까지 적분하고 b를 점점 키웁니다. 이러한 적분을 이상적분이라고 부릅니다. 극한이 유한한 실수로 존재하면 수렴하고, 그렇지 않으면 발산합니다.

∫0∞ e−x dx = limb→∞ [−e−x]0b = limb→∞(1 − e−b) = 1.

∞는 적분에 값을 대입할 수 있는 수가 아닙니다. 왼쪽 끝이 −∞라면 유한한 왼쪽 경계를 −∞로 보냅니다. 양쪽이 모두 무한한 구간은 중간 기준점 하나에서 나누어 두 적분이 각각 수렴하는지 확인합니다. 또 함수가 0에 가까워진다는 사실만으로 면적의 수렴을 판단할 수 없습니다. x ≥ 1에서 1/x는 0에 가까워지지만 ∫1b (1/x) dx = ln b가 끝없이 커집니다.

수렴 조건 · p-적분 외우기

∫1∞ x−p dx는 p > 1이면 1/(p − 1)로 수렴, p ≤ 1이면 발산.
∫01 x−p dx는 p < 1이면 1/(1 − p)로 수렴, p ≥ 1이면 발산.

p ≠ 1이면 원시함수 x1−p/(1 − p)에서 x1−p가 x → ∞일 때 0으로 가려면 1 − p < 0, x → 0⁺일 때 0으로 가려면 1 − p > 0이어야 하기 때문입니다. p = 1은 두 쪽 모두 ln으로 발산합니다. 무한 꼬리는 충분히 빨리 줄어야 하고(p > 1), 0 근처의 높이는 충분히 느리게 커져야(p < 1) 합니다. 원시함수를 모를 때는 0 ≤ f ≤ g이고 ∫g가 수렴하면 ∫f도 수렴한다는 비교 판정으로 이 기준 함수와 견줍니다.

유한 구간에서도 함수의 크기가 제한을 벗어날 수 있다

0 < x ≤ 1에서 x−1/2는 x가 0으로 다가가면 끝없이 커집니다. 먼저 안전한 경계 ε > 0을 잡아 적분하고, ε를 오른쪽에서 0으로 보냅니다.

∫01 x−1/2 dx = limε→0⁺ [2√x]ε1 = limε→0⁺ 2(1 − √ε) = 2.

같은 구간에서 1/x를 적분하면 [ln x]ε1 = −ln ε가 끝없이 커집니다. 높이가 끝없이 커진다는 공통점이 있어도, 경계를 옮길 때 쌓이는 양은 다를 수 있습니다.

가운데에서 끊기는 구간

∫−11 (1/x) dx는 x = 0에서 두 부분으로 나눠야 합니다. 왼쪽 ∫−1−ε (1/x) dx = ln ε는 −∞, 오른쪽 ∫ε1 (1/x) dx = −ln ε는 +∞로 향합니다. 각각 수렴하지 않으므로 이 이상적분은 발산합니다. 한 ε로 맞춘 두 유한 적분을 먼저 더하면 0이 되지만, 이 대칭 절단 값은 이상적분의 정의와 별개의 계산입니다.

절단값을 실행해서 비교한다

각 유한 적분을 원시함수로 계산해 경계를 바꾸어 봅니다. 몇 개 출력값은 극한을 예상하게 해 줍니다. 수렴과 발산의 판정은 위에서 세운 극한으로 합니다.

from math import exp, log, sqrt

def product_primitive(x):
    return (x - 1) * exp(x)

print(f"x exp(x)의 0~1 적분: {product_primitive(1) - product_primitive(0):.6f}")
for b in (1, 3, 6):
    print(f"b={b}: 넓이 {1 - exp(-b):.6f}, 꼬리 {exp(-b):.6f}")

for epsilon in (0.01, 0.0001, 0.000001):
    root_area = 2 * (1 - sqrt(epsilon))
    reciprocal_area = -log(epsilon)
    print(f"ε={epsilon:.6f}: 역제곱근 {root_area:.6f}, 역수 {reciprocal_area:.6f}")

ε=0.010000: 역제곱근 1.800000, 역수 4.605170

ε=0.000001: 역제곱근 1.998000, 역수 13.815511

ε를 100분의 1로 줄일 때마다 역제곱근의 적분은 2까지 남은 양이 10분의 1로 줄어듭니다. 역수의 적분은 ln 100만큼 계속 늘어납니다. 확률에서 대기 시간의 꼬리 면적을 계산할 때도 지수함수에 적용한 같은 극한을 사용합니다.

한 줄 정리

부분적분은 곱의 미분을 거꾸로 쓴 ∫u dv = uv − ∫v du이고, 이상적분은 유한 구간 적분의 극한이 유한하게 존재할 때만 값을 갖습니다.
