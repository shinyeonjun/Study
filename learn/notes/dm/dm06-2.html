반복문 불변식으로 가장 큰 값의 위치 증명하기

한 번씩 왼쪽부터 읽으며 가장 큰 값을 기억합니다. 지금까지 읽은 데이터에 대해 언제나 참인 문장을 만들면, 코드가 놓치기 쉬운 음수와 동점 조건도 확인할 수 있습니다.

이 장을 읽고 나면

  • 반복 단계마다 유지해야 할 불변식을 말한다.
  • 초기화·유지·종료를 따라 결과가 맞음을 증명한다.
  • 경계 입력과 실제 비교 횟수를 확인한다.

무엇을 반환할지 먼저 정한다

비어 있지 않은 정수 목록의 최댓값 위치를 0부터 세어 반환합니다. 값이 같은 최댓값이 여러 번 나오면 처음 위치를 반환합니다. 예로 [−7, −3, −5, −3]에서는 최댓값 −3이 두 번 나오므로 첫 위치인 인덱스 1을 사용합니다. 원소가 없는 입력은 이 장에서 오류로 처리합니다.

반복문의 불변식은 각 반복 단계의 약속한 지점에서 유지되는 조건입니다. k개를 읽은 직후에 “best는 처음 k개에서 최댓값이 처음 나오는 위치”라는 조건을 둡니다. 처리할 데이터가 새로 들어와 best의 값은 달라질 수 있지만, 그때까지 읽은 범위로 말한 조건은 계속 참입니다.

처음, 한 단계, 마지막을 연결한다

초기화에서는 k=1입니다. 목록에 첫 원소 하나만 보면 인덱스 0이 유일한 최대 위치입니다. 유지에서는 앞 k개에서 불변식이 참인 상태에서 인덱스 k의 새 값을 읽습니다. 새 값이 더 크면 새로운 최대는 새 위치에만 있습니다. 더 작거나 같으면 이전 best가 처음 최대가 나온 위치입니다. 어느 쪽이든 k+1개에 대해 불변식이 유지됩니다.

흔한 오해: 후보값을 0으로 시작하기

최댓값 후보를 첫 원소가 아니라 0으로 두면 초기화 단계에서 불변식이 이미 거짓입니다. 0은 읽은 값이 아니기 때문입니다. [−7, −3, −5, −3]에서는 어떤 원소도 0보다 크지 않아 후보가 한 번도 바뀌지 않고, 목록에 없는 0을 답으로 냅니다. 첫 원소로 시작하면 후보는 언제나 읽은 값 중 하나입니다.

종료에서는 k=n입니다. 반복마다 인덱스가 하나씩 커지고 항목 수가 유한하므로 실제로 끝납니다. 이제 불변식의 처음 n개란 전체 목록이므로 반환값이 계약과 같습니다. 유지 규칙에서 ‘더 크다’를 ‘크거나 같다’로 바꾸면 동점일 때 마지막 위치로 이동하므로 첫 위치 계약이 깨집니다.

def first_max_index(values):
    if not values:
        raise ValueError("한 원소 이상이 필요합니다.")
    best = 0
    for index in range(1, len(values)):
        if values[index] > values[best]:
            best = index
    return best

for row in ([-7, -3, -5, -3], [6], [8, 8, 1], [2, 4, 9]):
    result = first_max_index(row)
    assert result == row.index(max(row))
    print(row, "→", result)

try:
    first_max_index([])
except ValueError:
    print("빈 목록은 정의한 오류를 냅니다.")

빈 목록은 정의한 오류를 냅니다.

반복 과정의 정확성을 먼저 보인 뒤 비용을 센다

첫 원소는 기준으로만 놓고 나머지 n−1개는 매번 현재 최댓값과 한 번 비교합니다. 값의 비교를 한 연산으로 세면 모든 입력에서 정확히 n−1회, 충분히 큰 n에서는 Θ(n)입니다. 이미 있는 목록에 더해 저장하는 것은 인덱스 두 개 등 일정한 수의 값입니다.

한 줄 정리

불변식이 처음 참인지, 한 번 반복한 뒤에도 참인지, 종료할 때 원하는 답을 말해 주는지 확인합니다.
