기저 조건과 점화식에서 재귀 함수 만들기

다음 값의 답이 앞의 작은 답들로 결정되는 경우를 만납니다. 수열의 정의를 구현하고, 호출이 끝나는 이유와 같은 계산을 왜 반복하게 되는지 살핍니다.

이 장을 읽고 나면

  • 기저값과 점화식을 계산 순서로 옮긴다.
  • 더 작은 입력을 사용하는 재귀가 끝나는 이유를 설명한다.
  • 정의가 정한 값을 구하는 여러 구현의 차이를 확인한다.

제일 작은 답을 쓰고 더 큰 답으로 잇는다

수열 F의 첫 두 값을 F(0)=0, F(1)=1로 정합니다. n≥2의 규칙은 F(n)=F(n−1)+F(n−2)입니다. 이처럼 값의 관계를 적은 식을 점화식이라 하고, 더 작은 값에 의존하지 않는 두 항을 기저값이라 부릅니다. 입력은 0 이상인 정수입니다.

n작은 값으로 계산F(n)
0기저값0
1기저값1
2F(1)+F(0)1
3F(2)+F(1)2
4F(3)+F(2)3
5F(4)+F(3)5

F(4)를 정의대로 계산하면 F(3)과 F(2)를 요청합니다. F(3) 역시 F(2)를 요청하므로 같은 식이 여러 갈래에 나타납니다. 재귀 구현에서는 호출이 실제로 그 갈래를 따라갑니다. 그래도 모든 호출의 n이 0이나 1에 가까워지므로 종료합니다. n이 2일 때 F(0)에도 도달하므로 F(1)만 적어 두면 부족합니다.

재귀로 계산하고 반복문으로도 대조한다

다음 코드는 재귀 함수가 계산한 값과 자기 자신을 포함한 총 호출 수를 함께 반환합니다. 반복문에서도 연속한 값 두 개를 기억하면 같은 점화식을 계산할 수 있습니다. 반복문의 각 단계에서는 첫 변수에 F(k), 다음 변수에 F(k+1)이 있습니다. 한 번의 대입으로 이 둘을 F(k+1), F(k)+F(k+1)로 바꿉니다.

def recursive(n):
    if n < 0:
        raise ValueError("0 이상의 정수가 필요합니다.")
    if n < 2:
        return n, 1
    first, count_first = recursive(n - 1)
    second, count_second = recursive(n - 2)
    return first + second, 1 + count_first + count_second

def iterative(n):
    if n < 0:
        raise ValueError("0 이상의 정수가 필요합니다.")
    current, following = 0, 1
    for _ in range(n):
        current, following = following, current + following
    return current

for n in range(7):
    value, count = recursive(n)
    assert value == iterative(n)
    print(n, value, count)

재귀는 값을 정하는 방식이면서 구현 전략이다

코드가 F를 정확히 구함을 보이려면 기저에서 함수가 0, 1을 직접 돌려주는지 확인합니다. 그보다 큰 n에서는 두 작은 결과가 맞다는 가정에서 두 값을 더하면 점화식이 요구하는 F(n)이 나옵니다. 작은 결과 두 개를 모두 쓰므로 강한 귀납으로 표현하기 쉽습니다.

이 재귀 구현은 동일한 입력을 이전에 계산했어도 다시 호출합니다. 계산 결과를 저장했다가 재사용하는 메모이제이션이나, 작은 항부터 한 번씩 계산하는 반복문을 쓰면 중복 작업을 줄일 수 있습니다. 재귀가 끝난다고 해도 큰 입력에서는 언어의 호출 깊이 제한이 있으므로, 실제로 허용할 크기도 확인합니다.
