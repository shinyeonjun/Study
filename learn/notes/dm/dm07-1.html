관계가 만드는 분할과 부분순서의 차이를 증명하기

같은 나머지로 묶으면 한 원소는 블록 하나에만 들어갑니다. 선수 단원이나 집합 포함을 비교할 때는 서로 어느 쪽도 앞이 아닌 쌍이 생깁니다. 두 구조가 각각 어떤 조건에서 만들어지는지 증명합니다.

이 장을 읽고 나면

  • 관계를 순서쌍 집합으로 쓰고 네 성질을 검사한다.
  • 동치관계와 분할이 양쪽 방향으로 대응함을 보인다.
  • 부분순서에서 비교 불가능, 극소와 최소를 구분하고 위상 순서를 센다.

관계는 어떤 순서쌍을 포함하는지 정하는 조건이다

집합 A 위의 관계 R은 A×A의 부분집합입니다. aRb는 (a,b)가 그 안에 있다는 뜻입니다. 다음 네 조건은 서로 다른 검사입니다.

성질검사
반사모든 a에서 aRa
대칭aRb이면 bRa
반대칭aRb와 bRa가 모두 성립하면 a=b
추이aRb와 bRc이면 aRc

등호 관계는 a=b일 때만 관계에 들어갑니다. 이 관계는 대칭과 반대칭을 동시에 만족합니다. 그러므로 반대칭은 ‘대칭이 아니다’와 같은 말이 아닙니다. 반대칭이 금하는 것은 서로 다른 두 원소 사이에 양방향으로 관계가 성립하는 경우뿐입니다. 거꾸로 A={1,2,3} 위의 {(1,2),(2,1),(1,3)}은 (1,3)에 (3,1)이 없어 대칭이 아니고, 1≠2인데 양방향이라 반대칭도 아닙니다.

동치관계에서 분할을 얻고 분할에서 되돌린다

반사·대칭·추이를 갖는 관계를 동치관계라 합니다. 각 a의 동치류 [a]={x:aRx}를 만들면 반사성으로 a가 들어갑니다. 두 동치류 [a], [b]에 공통 원소 z가 있다고 합시다. aRz와 bRz에서 대칭·추이로 aRb를 얻습니다. b류의 임의의 x에서 bRx와 aRb를 이어 aRx이므로 [b]⊆[a]입니다. 같은 방식으로 [a]⊆[b]입니다. 따라서 동치류는 서로 같거나 만나지 않고, 전체를 덮는 분할입니다.

반대로 분할은 비어 있지 않은 블록들이 서로소이며 합집합이 A라는 뜻입니다. ‘같은 블록에 든다’를 관계로 쓰면 모든 원소는 자기 블록에 있고, 순서를 바꿔도 그대로이며, a,b와 b,c의 공통 블록은 b가 한 블록에만 있기에 같아서 추이가 성립합니다. 예를 들어 0~7을 3으로 나눈 나머지에 따라 묶으면 {0,3,6}, {1,4,7}, {2,5}입니다.

부분순서는 모든 쌍을 비교할 필요가 없다

반사·반대칭·추이가 있는 관계는 부분순서입니다. 서로 다른 a와 b에 대해 집합 포함관계에서 {a}와 {b} 어느 쪽도 다른 쪽을 포함하지 않습니다. 다음 그림처럼 작은 원소를 아래에 두고, 자기 자신과의 관계(반사)와 추이로 이미 알 수 있는 관계(∅⊆{a,b})를 생략해 바로 위의 관계만 선으로 그린 그림을 하세 도표라고 합니다.

공집합을 뺀 세 집합에서는 {a}와 {b}가 각각 극소입니다. 각각 자기보다 엄격하게 작은 집합이 없습니다. 최소는 집합의 모든 원소 이하인 원소입니다. {a}와 {b}가 비교 불가능하므로 이 세 집합에는 최소가 없습니다.

정해지지 않은 쌍을 나열 가능한 순서로 펴기

유한한 부분순서에서 서로 다른 원소의 ‘작다’를 간선으로 쓰면 방향 순환이 없습니다. 순환이면 추이로 서로 다른 두 원소가 양방향이 되어 반대칭에 걸립니다. DAG에서 진입차수가 0인 정점이 없다면, 앞 정점만 계속 따라가다 유한 개 안에서 반복되어 순환을 만듭니다. 따라서 진입차수 0 하나를 나열하고 지우기를 반복해 모든 제약을 만족하는 순서를 얻습니다. 이 예에서는 ∅가 먼저, {a,b}가 마지막이고 중간 두 단계의 순서는 두 가지입니다.

from itertools import permutations

numbers = range(8)
classes = [[x for x in numbers if x%3==r] for r in range(3)]
print(classes)
edges = [(0,1),(0,2),(1,3),(2,3)]
orders = []
for order in permutations(range(4)):
    pos = {node:i for i,node in enumerate(order)}
    if all(pos[a]<pos[b] for a,b in edges):
        orders.append(order)
print(orders)
assert set().union(*map(set,classes)) == set(numbers)
