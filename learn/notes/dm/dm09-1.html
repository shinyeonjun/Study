최대공약수의 불변식으로 합동식과 역원을 풀기

−17을 5로 나눌 때 나머지를 0 이상으로 맞추고, 나머지를 반복해 공통으로 나누는 수를 찾습니다. 최대공약수가 합동식에서 약분이 가능한 조건으로 이어집니다.

이 장을 읽고 나면

  • 음의 정수에도 나눗셈의 나머지가 유일함을 보인다.
  • 유클리드 알고리즘의 공약수 보존과 종료를 증명한다.
  • 확장 계산으로 역원을 구하고 선형 합동식의 해를 검산한다.

몫과 나머지의 범위를 정한다

정수 a와 양의 정수 b에 대해 a=bq+r, 0≤r<b를 만족시키는 정수 q,r을 찾습니다. q를 a/b 이하의 가장 큰 정수로 두면 bq≤a<b(q+1)이므로 r=a−bq가 범위 안입니다. 두 쌍이 있다고 가정하면 b(q−q′)=r′−r인데 오른쪽은 절댓값이 b 미만입니다. b의 배수 중 이 범위에는 0만 들어가므로 두 쌍은 같습니다. 예를 들어 −17=5(−4)+3입니다.

공통으로 나누는 수의 집합은 바뀌지 않는다

d가 a,b를 나누면 a−bq=r도 나눕니다. 반대로 d가 b,r을 나누면 bq+r=a도 나눕니다. 공약수 전체가 같으므로 gcd(a,b)=gcd(b,r)입니다. 양의 나머지가 엄격하게 내려가면 결국 0이 됩니다. 마지막 양의 수를 gcd로 읽습니다. b=0으로 시작하면 a≠0인 경우 gcd(a,0)=|a|입니다.

마지막 식을 거꾸로 대입해 18=54−36=4·252−5·198을 얻습니다. 일반 계산에서도 각 새 나머지를 이전 둘의 정수 선형결합으로 유지하므로 각 나머지는 초기 두 수의 정수 선형결합입니다. 이것이 이 알고리즘이 주는 Bézout 항등식입니다.

같은 나머지끼리 계산할 수 있다

m≥2에서 a≡b (mod m)는 m이 a−b를 나눈다는 뜻입니다. 차이가 0인 경우, 부호를 바꾼 경우, 두 차이를 더한 경우 모두 m의 배수여서 동치관계입니다. 대표값이 각각 m의 배수만큼 바뀌면 덧셈과 곱셈의 변화도 m의 배수라 같은 합동류에서 계산할 수 있습니다.

a의 역원 x는 ax≡1 (mod m)을 만족합니다. 역원이 있으면 ax−my=1인 정수 y가 있으므로 공약수는 1을 나누어야 합니다. 반대로 gcd(a,m)=1이면 Bézout의 ax+my=1에서 x가 역원입니다. 예를 들어 1=2·43−5·17이라 17의 mod 43 역원은 −5≡38입니다.

합동식에서 약분할 때는 모듈러스도 본다

6x≡8 (mod 14)는 14|(6x−8)이라는 뜻입니다. 각 정수 항을 2로 나누면 7|(3x−4)와 동치입니다. 3의 mod 7 역원은 5라서 x≡20≡6 (mod 7), 따라서 mod 14의 대표로는 6,13입니다. 우변이 9이면 6x−9는 홀수라 14의 배수가 될 수 없습니다. 반대로 모듈러스와 약분하는 값이 서로소라면 역원을 곱하는 방식으로 모듈러스를 유지하며 지울 수 있습니다.

from math import gcd

a,b = 252,198
remainders=[]
while b:
    a,b=b,a%b
    remainders.append(b)
print(divmod(-17,5))
print(remainders,a,4*252-5*198)
print(pow(17,-1,43), (17*38)%43)
print([[x for x in range(14) if (6*x-y)%14==0] for y in (8,9)])
assert a == gcd(252,198)
