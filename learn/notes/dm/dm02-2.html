DM02·2

반례와 증명: 예시에서 일반 주장으로

코드를 열 번 실행해 모두 맞았어도 모든 입력에서 맞는다는 결론은 아직 남아 있습니다. 반례로 틀린 주장을 가려내고, 직접증명·대우·귀류법이 각각 어떤 논리로 작동하는지 비교합니다.

이 장을 읽고 나면

  • 예와 반례의 역할을 구별한다.
  • 정의로부터 직접증명과 대우 증명을 구성한다.
  • 귀류법에서 어떤 가정을 모순으로 이끄는지 표시한다.

반례에는 조건과 실패를 둘 다 보여야 한다

“두 홀수의 합은 홀수다”라는 주장을 봅시다. 3과 5를 택하면 둘 다 홀수이고 합 8은 짝수입니다. 범위와 조건을 만족하지만 결론이 거짓이므로 반례입니다. 2 + 5 = 7은 첫 수가 홀수가 아니어서 이 주장에 대한 반례가 될 수 없습니다.

반대로 “두 홀수의 합은 짝수다”를 3 + 5, 1 + 7, 9 + 11로 확인하면 사례는 쌓입니다. 그런데 정수 전체를 보려면 모두에 공통으로 적용되는 이유를 찾아야 합니다.

정의를 풀어 써서 직접증명하기

직접증명

홀수인 정수 a, b를 아무거나 택합니다. 홀수의 정의로 a = 2m + 1, b = 2n + 1인 정수 m, n이 있습니다.

a + b = (2m + 1) + (2n + 1)
= 2(m + n + 1)

괄호 안은 정수이므로 합은 2의 배수, 곧 짝수입니다. 처음에 a, b를 특정 숫자로 고정하지 않았으므로 홀수 두 개 모두에 적용됩니다.

대우로 방향을 돌리기

“n²이 짝수이면 n은 짝수”를 증명합니다. 제곱에서 n으로 거슬러 올라가기보다 대우 “n이 짝수가 아니면 n²도 짝수가 아니다”를 봅니다. 정수 n이 홀수라면 n = 2k + 1이므로

n² = 4k² + 4k + 1 = 2(2k² + 2k) + 1

입니다. 제곱도 홀수입니다. 대우가 원래 명제와 같은 진리값을 가지므로 증명이 끝납니다. “n이 짝수이면 n²이 짝수” 역시 참이지만 이것은 원래 명제의 역이며, 이를 보인 것만으로 원래 명제를 얻을 수 없습니다.

반대편을 가정하고 모순으로 가기

정수 전체에 가장 큰 정수가 없음을 보입니다. 반대로 가장 큰 정수 M이 있다고 가정합니다. M + 1도 정수이며 M + 1 > M입니다. 가장 큰 정수라는 가정과 이를 넘어서는 정수를 얻은 사실이 서로 맞지 않습니다. 따라서 가장 큰 정수가 있다는 가정을 버립니다.

범위를 “1 이상 10 이하인 정수”로 바꾸면 최대가 10입니다. 이때 M + 1은 여전히 정수이지만 지정한 범위 밖입니다. 논리 자체가 아닌 주장 범위가 달라진 것입니다.

코드로 오류 찾기와 증명 구별하기

def claim(n):
    return n ** 2 > n

failures = [n for n in range(-3, 4) if not claim(n)]
print(failures)
print(all(claim(n) for n in range(2, 8)))

실행 결과

[0, 1]
True

정수 0과 1에서 부등식이 실패하므로 “모든 정수 n에서 n² > n”은 거짓입니다. 2부터 7까지 성공했다는 두 번째 출력은 그 범위의 검사입니다. “모든 n ≥ 2”를 보이려면 n(n − 1) > 0을 이용하면 됩니다. n ≥ 2이면 n도, n − 1도 양수이기 때문입니다.

쓴 증명을 검토하는 질문

첫째 범위와 조건을 적었는가. 둘째 각 등호와 논리 방향을 설명할 수 있는가. 셋째 결론 자체를 중간에 슬쩍 가정하지 않았는가. 마지막으로 반례를 찾을 때는 범위 밖 값을 고르지 않았는가. 다른 사람이 한 줄씩 따라갈 수 있도록 적으면 빠진 전제를 찾기 쉽습니다.
