순서를 빼고 세기: 조합과 이항계수

발표 순서를 정하는 대신 4명에서 3명의 팀을 뽑습니다. 같은 팀에서 순서를 바꿔 쓴 목록을 한 번으로 세는 법을 배우고, 두 결과가 있는 반복 시행의 경우의 수로 연결합니다.

이 장을 읽고 나면

  • 조합 공식을 순열의 중복을 제거하는 방식으로 설명한다.
  • 이항계수를 같은 수의 선택 위치를 세는 데 사용한다.
  • 중복 허용과 순서 포함 여부를 나누어 모델을 고른다.

순열 안에 같은 팀이 여러 번 있다

4명 중 3명의 발표 순서를 정하면 24가지였습니다. 순서를 무시하고 팀만 정할 때는 (A, B, C)와 (B, C, A)가 같은 결과입니다. 사람 A, B, C로 만들 수 있는 순서는 여섯 가지입니다.

같은 24가지 순서 안에서 모든 팀은 똑같이 3!번 등장합니다. 따라서 팀의 수는 24 ÷ 6 = 4입니다. n개에서 r개를 중복 없이 고르고 순서를 무시하는 수를 조합이라고 합니다.

C(n, r) = P(n, r) ÷ r! = n! ÷ (r! (n−r)!)

0 ≤ r ≤ n을 가정합니다. C(n, r)를 “n개 중 r개”라고 읽고 이항계수라고도 부릅니다. 고르는 것과 남겨 두는 것은 일대일 대응이므로 C(n, r) = C(n, n−r)입니다.

두 종류 결과가 나오는 자리 정하기

세 번 검사해서 각 검사 결과를 성공 S 또는 실패 F로 적습니다. 정확히 한 번 성공하는 기록은 SFF, FSF, FFS입니다. 성공 자리를 3개 중 1개 고르면 남은 자리는 실패로 확정됩니다. C(3, 1) = 3입니다.

풀이 예제

5번 검사 중 정확히 2번 성공인 기록의 수를 구합니다.

① 5개 자리에서 성공할 위치 두 개를 고른다.
② 어떤 위치를 먼저 골랐는지는 기록에 남지 않는다.
③ C(5, 2) = 5×4 ÷ (2×1) = 10.

이 계산은 기록의 개수입니다. 각 기록이 나올 확률을 계산하려면 성공 확률과 시행 사이의 관계를 더 알아야 합니다.

from itertools import combinations, product
from math import comb

teams = ["".join(team) for team in combinations("ABCD", 3)]
records = [row for row in product("SF", repeat=5) if row.count("S") == 2]
print(teams)
print(len(records), comb(5, 2))

실행 결과

['ABC', 'ABD', 'ACD', 'BCD']
10 10

한 대상을 포함하는지 나누면 파스칼 관계

5명에서 두 사람을 고르는 팀을 A가 들어간 팀과 A가 빠진 팀으로 나눕니다. A가 들어가면 4명 중 1명만 더 고릅니다. A가 빠지면 나머지 4명에서 2명을 고릅니다. 두 갈래는 겹치지 않습니다.

이를 일반화하면 1 ≤ r < n에서 C(n, r) = C(n−1, r−1) + C(n−1, r)입니다. 같은 수가 (a + b)n을 전개할 때도 나옵니다. 각 괄호에서 b를 고르는 위치를 r개 정하면 an−rbr 항이 생깁니다.

중복이 허용되면 한 팀의 순서 수가 같지 않다

맛 A, B, C 중 아이스크림 두 스쿱을 사되 맛이 같아도 되고 순서는 무시한다고 합시다. AA, AB, AC, BB, BC, CC 여섯 선택입니다. 순서 있는 (A,B)와 (B,A)는 같은 선택이지만 AA는 순서를 바꾸어도 새로운 배열이 나오지 않습니다. 3²를 무조건 2!로 나누면 틀립니다.

두 자리를 고르는 조건A·B·C일 때 개수
중복 불가, 순서 중요3 × 2 = 6
중복 불가, 순서 무시C(3, 2) = 3
중복 가능, 순서 중요3 × 3 = 9
중복 가능, 순서 무시AA, AB, AC, BB, BC, CC → 6
from itertools import combinations_with_replacement

choices = ["".join(row) for row in combinations_with_replacement("ABC", 2)]
print(choices)
print(len(choices))

실행 결과

['AA', 'AB', 'AC', 'BB', 'BC', 'CC']
6

같은 종류를 여러 번 골라도 되는 순서 없는 경우는 종류별 개수를 정하는 문제로 바꿀 수 있습니다. 두 스쿱이라면 각 맛의 개수는 0 이상이고 세 개의 합이 2입니다. 다음에는 가능한 기록을 셀 뿐 아니라 그 기록이 나올 확률도 계산합니다.
