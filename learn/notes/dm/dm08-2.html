DM08·2

일차 점화식의 닫힌꼴과 상·하계를 계산하기

지난 값의 세 배를 복사하고 매번 새 수를 더하는 수열을 계산합니다. 반복식과 닫힌꼴이 언제 같은지 증명하고, 추가항의 성장률이 같을 때 왜 n이 붙는지 확인합니다.

이 장을 읽고 나면

  • 일차 비동차 점화식의 일반식을 반복 대입으로 만들고 귀납 검증한다.
  • 서로 다른 성장률과 같은 성장률을 구분한다.
  • 같은 식에서 닫힌꼴과 상·하계가 각각 무엇을 알려주는지 설명한다.

초깃값과 각 시점에 추가한 항을 따로 추적한다

aₙ=c aₙ₋₁+dₙ에서 n=1이면 c a₀+d₁입니다. n=2이면 c²a₀+c d₁+d₂입니다. 시점 j에서 추가한 dⱼ는 이후 n−j번 c를 곱한 상태로 남습니다.

aₙ = cⁿa₀ + ∑j=1n cⁿ⁻ʲ dⱼ

지수가 0인 곱은 항이 하나도 없어 1로 둡니다. 이 식은 n=0에서 합이 비어 a₀입니다. n−1에서 식이 성립한다고 가정하고 c를 곱한 뒤 dₙ을 새 항으로 붙이면 n 식이 됩니다. 처음 값을 지정하고 각 뒤 값을 앞 값으로 하나씩 정하므로 이 해는 유일합니다.

서로 다른 밑에서 기하합을 정리한다

a₀=2, c=3, dₙ=2ⁿ이라 둡니다. 일반식 뒤 항은 3ⁿ∑j=1n(2/3)ʲ입니다. 유한 기하합에서 ∑j=1nrʲ=r(1−rⁿ)/(1−r)이므로 2·3ⁿ−2·2ⁿ으로 줄어듭니다. 앞에 2·3ⁿ가 있어 정답은 4·3ⁿ−2·2ⁿ입니다.

닫힌꼴로부터 n≥0에서 2·3ⁿ≤aₙ≤4·3ⁿ을 얻습니다. 0≤2·2ⁿ≤2·3ⁿ이기 때문입니다. 이는 값의 양쪽을 제한하며, aₙ의 지배적인 성장률이 3ⁿ임을 설명합니다. 상계 4·3ⁿ을 aₙ의 정확한 정의로 대체하지는 않습니다.

밑이 같으면 매번 같은 크기의 값을 보탠다

c=2이고 dⱼ=2ʲ이면 cⁿ⁻ʲdⱼ=2ⁿ가 모든 j에서 같습니다. n개의 항을 더하므로 aₙ=(a₀+n)2ⁿ입니다. a₀=2이면 처음 네 항은 2,6,16,40입니다. 이 차이는 반복으로 만든 알고리즘의 비용을 점화식으로 적을 때도 중요합니다.

def build(c):
    a=[2]
    for n in range(1,7):
        a.append(c*a[-1]+2**n)
    return a

a,b=build(3),build(2)
assert a == [4*3**n-2*2**n for n in range(7)]
assert b == [(2+n)*2**n for n in range(7)]
print(a[:4])
print(b[:4])
print(2*3**4,a[4],4*3**4)
