두 색으로 칠할 수 있는 그래프와 홀수 순환의 증명

인접한 정점에는 서로 다른 색을 써야 합니다. 여섯 점의 고리에는 두 색이 잘 맞지만, 선 하나를 추가하면 불가능할 수 있습니다. 가능한 경우에는 색을, 불가능한 경우에는 홀수 고리를 찾아냅니다.

이 장을 읽고 나면

  • 이분 그래프와 올바른 2색칠을 대응시킨다.
  • 홀수 순환이 존재하지 않을 때 BFS로 색을 붙이는 증명을 이해한다.
  • 충돌에서 실제 홀수 순환을 복원한다.

색 두 개가 연결의 두 편을 정한다

유한 무방향 단순 그래프에서 각 정점에 색 0 또는 1을 붙여 모든 간선 양끝의 색을 다르게 하는 일을 2색칠이라고 합니다. 색별 두 부분 안에는 간선이 없습니다. 반대로 간선이 항상 서로 다른 두 부분 사이에 있는 이분 그래프라면 두 부분에 서로 다른 색을 주면 됩니다.

일반적으로 k개의 색으로 인접한 정점의 색이 모두 다르게 칠하는 것을 k색칠이라 하고, 가능한 가장 작은 k를 채색수 χ(G)라고 합니다. 위 대응은 "이분 그래프 ⇔ χ(G)≤2"라는 뜻입니다. 이 장의 목표는 다음 정리를 두 방향 모두 증명하는 것입니다.

정리 (이분 그래프의 판정)

그래프 G가 이분 그래프(2색칠 가능)일 필요충분조건은 G에 홀수 길이의 순환이 없는 것이다.

색이 다르도록 고리를 따라가면 간선을 지나갈 때마다 색이 뒤집힙니다. 홀수 개 간선을 지나 제자리로 나오면 색이 반대가 되어 모순입니다. 그래서 두 색으로 칠한 그래프에는 홀수 길이의 단순 순환이 없습니다. 이것이 정리의 "⇒" 방향입니다.

홀수 순환이 없으면 깊이의 홀짝을 쓴다

각 연결 성분에서 시작점을 정해 너비 우선 탐색을 합니다. 처음 발견한 가장 가까운 트리 경로의 길이가 깊이입니다. 각 정점에는 깊이를 2로 나눈 나머지를 줍니다. 어떤 간선 (u,v)의 양끝이 같은 홀짝이라고 가정합시다. 두 트리 경로가 만나는 마지막 공통 조상을 w라고 하면, w에서 u와 v까지의 경로는 w를 제외하고 만나지 않습니다. 그 두 경로와 간선을 합친 길이는 d(u)+d(v)−2d(w)+1입니다. 같던 깊이의 홀짝 두 개에 1을 더하므로 홀수입니다.

해당 간선이 트리 간선이라면 두 끝의 깊이는 바로 한 단계 차이 나므로 이런 충돌이 날 수 없습니다. 따라서 두 트리 경로와 충돌 간선으로 실제 홀수 순환이 생깁니다. 홀수 순환이 없다는 가정과 모순이므로 모든 간선 양끝의 색이 다릅니다. 이것이 "⇐" 방향입니다. 정점 하나뿐인 연결 성분은 어느 색을 주어도 조건을 만족합니다.

성공하면 색표, 실패하면 순환을 보여 준다

아래는 정점이 0~5인 고리에서 0부터 너비 우선 탐색으로 깊이의 홀짝을 붙이고 실제 간선들의 양끝 색을 확인합니다. 그다음 0–2를 추가합니다. 실제 탐색 순서에 따라 충돌을 찾는 간선이 다를 수 있습니다. 찾아낸 순환은 첫·마지막 정점이 같고, 중간의 정점이 중복되지 않으며, 모든 연속 쌍이 실제 간선인지 검증하면 됩니다.

from collections import deque

def color_or_cycle(n, edges):
    adj = [[] for _ in range(n)]
    for u,v in edges:
        adj[u].append(v)
        adj[v].append(u)
    depth = {}
    parent = {}
    for start in range(n):
        if start in depth:
            continue
        depth[start], parent[start] = 0, None
        queue = deque([start])
        while queue:
            u = queue.popleft()
            for v in adj[u]:
                if v not in depth:
                    depth[v], parent[v] = depth[u]+1, u
                    queue.append(v)
                elif depth[u]%2 == depth[v]%2:
                    anc = []
                    node = u
                    while node is not None:
                        anc.append(node)
                        node = parent[node]
                    trail = []
                    node = v
                    while node not in anc:
                        trail.append(node)
                        node = parent[node]
                    return None, anc[:anc.index(node)+1]+trail[::-1]+[u]
    return [depth[v]%2 for v in range(n)], None

edges = [(i,(i+1)%6) for i in range(6)]
colors,_ = color_or_cycle(6,edges)
chord = edges+[(0,2)]
_,cycle = color_or_cycle(6,chord)
print(colors)
print(cycle)
assert all(colors[u]!=colors[v] for u,v in edges)
assert (len(cycle)-1)%2 == 1
assert all((u,v) in chord or (v,u) in chord for u,v in zip(cycle,cycle[1:]))
