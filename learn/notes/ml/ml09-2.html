밀도로 군집을 만들고 이상치를 따로 본다

한 구간에 촘촘히 모인 점과 혼자 멀리 떨어진 점이 있습니다. 중심까지의 거리 대신 각 점 주변에 이웃이 충분한지 확인합니다. 그림을 만드는 과정에서 중요한 차이가 사라지는 경우도 비교합니다.

이 장을 읽고 나면

  • DBSCAN의 이웃 반경과 핵심·경계·잡음점을 계산한다.
  • 밀도 군집의 잡음과 업무에서 찾아야 할 이상치를 구분한다.
  • 축을 줄여 그린 결과에서 원래 차이가 사라지는 사례를 설명한다.

반경 안에 점이 충분히 많은지 센다

DBSCAN은 반경 ε 안에서 주변 점이 충분한 곳을 찾아 서로 연결합니다. 합성 점의 위치가 0,0.2,0.4,0.6,0.8,1,3,3.2,3.4,5입니다. ε=0.25, 최소 점 수를 3으로 둡니다. 바로 그 점을 포함해서 세므로 0.4의 이웃은 0.2, 0.4, 0.6 세 개입니다.

점 분류규칙
핵심점ε 이내에 자신을 포함해 최소 점 수 이상이 있음
경계점자신은 핵심점이 아니지만 어떤 핵심점의 반경에 들어 있음
잡음점핵심점도 경계점도 아님

0.2~0.8의 핵심점들이 가까운 핵심점과 연속해 연결됩니다. 0과 1은 양끝의 경계점으로 붙습니다. 3.2는 별개의 핵심점으로 3과 3.4를 붙입니다. 점 5는 핵심점의 반경에도 들어가지 않습니다. 연속한 핵심점이 연결되는 첫 묶음의 길이는 1로, 반경 0.25보다 큽니다. 붙어 있는 경계점만으로는 두 핵심점 묶음을 합치지 않습니다.

정리하면 DBSCAN은 k-means와 달리 군집 수를 미리 주지 않고, 핵심점이 이어지는 한 휘어진 모양의 군집도 찾으며, 어느 군집에도 속하지 않는 점을 잡음(라벨 −1)으로 따로 남깁니다. scikit-learn 1.9의 DBSCAN 기본값은 eps=0.5, min_samples=5이고, min_samples는 이 장처럼 자기 자신을 포함해 세며 거리는 eps 이하를 이웃으로 봅니다. 이 예에 DBSCAN(eps=0.25, min_samples=3)을 적용하면 0~1이 군집 0, 3~3.4가 군집 1, 5가 −1로 나옵니다.

잡음 표시를 다시 점검할 후보로 쓴다

실행 예제

x = [0, .2, .4, .6, .8, 1, 3, 3.2, 3.4, 5]
eps, minimum = .25, 3
neighbors = [[j for j, b in enumerate(x) if abs(a - b) <= eps] for a in x]
core = {i for i, near in enumerate(neighbors) if len(near) >= minimum}
border = {i for i, near in enumerate(neighbors) if i not in core and core.intersection(near)}
noise = set(range(len(x))) - core - border
for name, selected in [("core", core), ("border", border), ("noise", noise)]:
    print(name, [x[i] for i in sorted(selected)])

실행 결과

core [0.2, 0.4, 0.6, 0.8, 3.2]
border [0, 1, 3, 3.4]
noise [5]

코드는 이웃 조건의 세 점 종류를 확인합니다. 전체 군집 ID를 얻으려면 이웃인 핵심점의 연결 묶음을 만들고 각 경계점을 그 묶음에 배정합니다. 한 경계점이 둘 이상의 핵심점 묶음에 인접하면 구현 규칙에 따라 어느 쪽에 붙는지 달라질 수 있습니다.

반경과 최소 점 수, 거리 척도에 따라 결과가 달라집니다. 단일 반경으로 밀도가 크게 다른 두 군집을 모두 잘 찾기는 어려울 수 있습니다. 업무에서 이상 탐지는 평소와 다른 사례를 확인할 검토 목록을 만드는 데 씁니다. 잡음점은 규칙의 밀도 기준에서 어긋난 점입니다. 실제 센서 고장인지, 드문 정상 주문인지, 측정 오류인지는 근거를 추가 확인합니다. 반대로 흔한 값과 비슷하거나 비정상끼리 무리를 이루면 이 규칙에서 잡음으로 안 잡힐 수 있습니다.

밀도 군집의 잡음 외에도 이상 탐지 방법은 여럿이며, 모두 "무엇을 평소로 볼지"를 다르게 정의합니다.

방법이상하다고 보는 기준
통계 규칙 (z점수, IQR)한 변수에서 평균·사분위수로부터 멀리 떨어진 값. 변수 하나씩 본다
DBSCAN 잡음반경 안 이웃이 적고 핵심점에도 닿지 않는 점
LOF (국소 이상 계수)자기 주변 밀도가 이웃들의 주변 밀도보다 훨씬 낮은 점
Isolation Forest무작위 분할을 반복할 때 적은 횟수 만에 홀로 떨어지는 점

훈련 자료 안의 이상한 점을 찾는 일(이상치 탐지)과, 깨끗한 정상 자료로 배운 뒤 새로 들어온 관측이 다른지 보는 일(새로움 탐지)은 평가 방법이 다릅니다. 어느 쪽이든 점수의 기준선(몇 %를 이상으로 볼지)은 업무 비용으로 정하고 검토 결과로 확인합니다.

좌표를 줄인 그림에 어떤 정보가 남았는지 확인한다

두 데이터를 그림에 놓을 때 변수를 두 개로 줄이는 일이 흔합니다. 원자료 (1,2,0)과 (1,2,9)는 세 번째 축에서 9만큼 다르지만 처음 두 축의 그림에서는 겹칩니다.

좌표를 어떻게 만들었는지와 원자료에서 무엇이 다른지 봅니다. 데이터가 입력 오류인지 드물지만 유효한 관측인지 확인해야 합니다. 원자료를 불러올 수 있도록 행 식별자도 남깁니다.

그림의 거리와 무리 수가 원래 공간을 그대로 재현하는지 따로 확인합니다. 다음 장의 PCA처럼 선형으로 사영한 그림은 버린 축의 차이가 사라지고, t-SNE·UMAP 같은 비선형 시각화는 가까운 이웃 관계를 살리는 대신 무리 사이의 거리와 무리의 크기가 원래 공간과 다를 수 있으며 설정값에 따라 모양이 바뀝니다. 그림에서 보이는 무리는 가설로 두고 원래 특성에서 다시 확인합니다. 이상치를 찾을 때 어떤 질문에서 무엇이 드문지, 시험할 새 자료를 어떻게 구분했는지를 먼저 정합니다.
