ML08·1

빈 값과 이름을 모델이 쓸 수 있는 입력으로 바꾸기

거리 기록이 비어 있는 주문과 배송 유형이 ‘방문’인 주문을 생각합니다. 숫자가 필요한 모델에 넣으려면 비어 있는 이유와 수집 시점을 확인하고, 채울 기준과 범주별 열의 뜻을 정해야 합니다.

이 장을 읽고 나면

  • 숫자 결측을 채우고 결측 여부를 별도 열로 남긴다.
  • 범주 원-핫 인코딩의 열을 만들고 새 범주를 처리한다.
  • 기준 범주를 뺄 때 0으로만 된 행의 의미를 확인한다.

비어 있는 이유를 보고 채울 값을 정한다

연습용 배송 표의 거리 열에 [4, 비어 있음, 8, 비어 있음]이 있습니다. 결측값은 필요한 값이 관측되지 않았다는 뜻입니다. 비어 있거나 기록되지 않은 거리와 실제 거리 0은 다른 상태입니다. 수집 실패인지, 아직 기록할 시간이 아닌지, 항목 자체가 맞지 않는지 확인합니다. 학습에 필요한 목표 라벨이 빠진 상황은 입력 특성의 빈칸과 따로 처리합니다.

통계에서는 비어 있게 된 원리를 세 가지로 나눕니다. 어떤 대치가 편향을 덜 만드는지가 이것에 달려 있습니다.

구분뜻배송 예
MCAR (완전 무작위 결측)결측 여부가 어떤 값과도 무관기록 장비가 무작위로 가끔 꺼짐
MAR (무작위 결측)결측 여부가 관측된 다른 변수로 설명됨특정 지점의 단말기에서만 거리가 자주 빠짐
MNAR (비무작위 결측)결측 여부가 빠진 값 자체에 달림아주 먼 거리일수록 측정이 실패해 빠짐

MCAR이면 결측 행을 빼도 남은 자료의 분포가 치우치지 않지만(표본 수만 줄어듦), MAR·MNAR에서는 빼거나 단순 대치하면 치우칠 수 있습니다. MNAR은 관측된 자료만으로는 확인할 수 없어 수집 과정을 조사해야 합니다.

모델이 수치 결측을 직접 다룰 수 없다면 훈련에서 관측한 값으로 채울 기준을 구할 수 있습니다. 값을 대신 채우는 일을 결측값 대치라고 합니다. 수치 열은 평균이나 중앙값(이상값에 덜 흔들림), 범주 열은 최빈값으로 채우는 것이 가장 단순한 방법입니다. 값 4와 8의 중앙값으로 채우면 6입니다. 데이터가 없는 행을 통째로 제외할 수도 있지만 특정 집단에서 결측이 많다면 남는 자료의 범위가 바뀝니다.

거리가 비었는지를 별도 열 distance_missing에 두면, 보충한 6과 원래부터 거리 6인 주문을 구별할 수 있습니다. 결측 여부도 접수 시점에 알 수 있을 때 특성으로 쓸 수 있습니다. scikit-learn의 SimpleImputer는 기본값이 strategy="mean", add_indicator=False이므로, 이 예처럼 하려면 strategy="median", add_indicator=True로 지정합니다. 훈련에서 관측을 하나도 못 한 열에는 중앙값이 없으므로 수집을 보완하거나 빼거나, 업무상 의미 있는 미리 지정한 값으로 처리합니다.

범주마다 자리 하나를 정해 0 또는 1을 쓴다

배송 유형이 보관함·방문이라면 서로 다른 이름일 뿐입니다. 명목 범주에 아무 번호나 주어 거리 계산에 쓰면 번호 사이의 순서와 간격이 입력에 들어갑니다. 원-핫 인코딩은 범주마다 한 열을 두고 이번 행에 해당하는 범주의 열에만 1을 씁니다.

이번에는 유형의 결측을 별도의 결측 범주로 기록합니다. 훈련에서 보관함·결측·방문이 나왔으므로 새 행에도 그 세 열만 같은 순서로 만듭니다. 운영에서 처음 등장한 점포는 기존 열 가운데 해당되는 것이 없습니다. 새 범주를 만나면 오류로 알려 주거나, 미리 정한 기타 범주에 보내거나, 예시처럼 해당 범주 쪽 열을 모두 0으로 만들 수 있습니다. 마지막 방식은 scikit-learn의 handle_unknown="ignore"와 같은 원리입니다. OneHotEncoder의 기본값은 handle_unknown="error"(새 범주에서 오류)와 drop=None(모든 범주의 열을 남김)입니다.

범주에 실제 순서가 있으면 이야기가 다릅니다. 배송 등급 일반 < 빠름 < 당일처럼 순서가 의미 있는 순서형 범주는 0, 1, 2 같은 정수 하나로 바꾸는 순서 인코딩(scikit-learn OrdinalEncoder, 순서는 categories로 직접 지정)을 쓸 수 있습니다. 이때도 0→1과 1→2의 간격이 같다는 가정이 선형 모델에 들어가므로, 간격이 의미 없으면 원-핫이 안전합니다. 나무 모델은 크기 비교만 하므로 이 간격 가정의 영향을 덜 받습니다.

훈련에서 나타난 범주와 빈칸을 구별하는 규칙을 먼저 저장합니다. 학습·검증·테스트를 각각 독립적으로 원-핫 변환하면 각 표에 생기는 열과 순서가 다를 수 있습니다. 예를 들어 검증에 방문이 없으면 방문 열이 사라질 수 있습니다.

기준 범주와 새 범주를 어떻게 표현했는지 확인한다

모든 범주의 열을 쓰면 기존 범주의 한 행에서 세 열의 합은 1입니다. 기존 범주로만 이루어진 훈련 자료에서는 이 열의 합이 절편을 나타내는 1의 열과 똑같습니다. 그러면 열들이 완전한 다중공선성(한 열이 다른 열들의 선형결합)에 놓여, 절편이 있고 규제가 없는 선형 회귀에서 계수가 하나로 정해지지 않습니다. 이를 더미 변수 함정이라 부르고, 피하려고 기준 범주의 열 하나를 빼는 방식(k개 범주 → k−1열, drop="first")이 있습니다. 예를 들어 보관함을 빼면 남은 (결측,방문)이 (0,0)인 기존 행은 보관함을 가리킵니다.

여기에 새 범주를 모두 0으로 처리하는 방식까지 쓰면 점포와 보관함이 다 같은 벡터가 됩니다. 구별이 업무에 중요하다면 새 범주 정책을 처음부터 별도로 정해야 합니다. 모든 모델에서 기준 범주를 빼야 하는 것은 아니며, 나무처럼 절편과 선형 독립을 요구하지 않는 모델은 세 열을 그대로 쓸 수 있습니다.

실행 예제

from statistics import median

train_distances = [4, None, 8, None]
train_types = ["visit", "locker", None, "visit"]
fill = median(value for value in train_distances if value is not None)

def category(value):
    return "missing" if value is None else value

columns = sorted({category(value) for value in train_types})

def transform(distance, kind):
    observed = fill if distance is None else distance
    indicator = int(distance is None)
    one_hot = [int(category(kind) == label) for label in columns]
    return [float(observed), indicator, *one_hot]

print("columns:", ["distance", "distance_missing", *columns])
print("train blank:", transform(None, None))
print("new known type:", transform(10, "visit"))
print("new unknown type:", transform(None, "store"))

실행 결과

columns: ['distance', 'distance_missing', 'locker', 'missing', 'visit']
train blank: [6.0, 1, 0, 1, 0]
new known type: [10.0, 0, 0, 0, 1]
new unknown type: [6.0, 1, 0, 0, 0]

왜 그럴까?

결측을 평균이나 중앙값으로 채우면 빠진 값이 실제로 복구됐다고 말할 수 있을까요?

모범 답 보기

채운 값은 훈련에서 정해 둔 대표값입니다. 관측되지 않은 값이나 결측 원인이 확인된 것은 아니므로, 실제 관측과 구별하고 평가에서 영향을 살펴야 합니다.
