최소제곱 해를 푸는 방법과 해가 여럿인 경우

후보 직선을 몇 개 그려 보는 대신 가장 작은 오차를 주는 계수를 계산할 수 있습니다. 행렬을 분해해 직접 구하는 방법과, 손실이 줄어드는 방향으로 조금씩 움직이는 방법을 같은 자료로 비교합니다.

이 장을 읽고 나면

  • 정규방정식의 뜻과 최소제곱 해의 잔차 조건을 읽는다.
  • QR 분해와 lstsq, 경사하강이 해를 얻는 방식을 구별한다.
  • 열이 중복되면 여러 계수가 같은 예측을 낼 수 있음을 계산한다.

최소에서 잔차가 설계행렬의 모든 열과 직교한다

대기 건수 x=[0,1,2]인 주문의 실제 처리 시간이 y=[2,2,5]분입니다. 설계행렬의 열은 1과 대기 건수입니다. r=y−Xβ, J(β)=Σrᵢ²/(2n)으로 두면 한 계수의 기울기는 ∂J/∂βⱼ=−ΣXᵢⱼrᵢ/n입니다. 제곱을 미분해 나온 2가 식의 2와 지워집니다. 벡터로 묶으면 ∇J=−Xᵀr/n입니다.

최소에서 Xᵀr=0이므로 잔차와 X의 각 열을 내적한 값이 0입니다. 예제의 β=[1.5,1.5]는 잔차 [0.5,−1,0.5]를 냅니다. 잔차를 더하면 0이며, 대기 건수를 곱해 더해도 0·0.5+1·(−1)+2·0.5=0입니다. 이 조건에서 계수를 δ만큼 바꿀 때 SSE 증가량은 ‖Xδ‖²입니다. 두 벡터가 직교해 교차항이 0이기 때문입니다. 그래서 이 조건을 만족한 계수는 최소제곱 해입니다.

Xᵀ(y−Xβ)=0을 정리한 (XᵀX)β=Xᵀy를 정규방정식이라고 합니다. 이 이름은 정규분포 가정을 뜻하지 않습니다. 이 예에서는 왼쪽 행렬이 [[3,3],[3,5]], 오른쪽이 [9,12]입니다. 3b+3w=9를 3b+5w=12에서 빼면 2w=3이고 b=w=1.5입니다.

직접 풀거나, 손실을 줄이는 방향으로 이동한다

직접 계산하는 한 방법은 X의 열들이 독립일 때 X=QR로 QR 분해하는 것입니다. Q의 열은 서로 직교하고 길이가 1이며 R은 아래쪽이 0인 삼각행렬입니다. 목표 벡터 y를 X의 열공간에 투영한 성분에 대해 Rβ=Qᵀy를 풀면 최소제곱 해를 얻습니다. 여기서 투영하는 대상은 목표 벡터 y입니다. 열이 거의 중복된다면 XᵀX를 만든 뒤 역행렬을 계산하면 수치 오차가 커질 수 있습니다. NumPy의 lstsq는 최소제곱과 유효 랭크를 함께 구할 수 있습니다.

경사하강에서는 β ← β−η∇J를 반복합니다. 양수 η가 한 번의 이동 크기를 조절하는 학습률입니다. 시작을 [0,0]으로 두면 잔차는 y와 같고 기울기는 −[9,12]/3=[−3,−4]입니다. η가 0.1일 때 첫 갱신 결과는 [0.3,0.4]입니다.

작고 조밀한 행렬은 직접 최소제곱을 푸는 방법이 편리합니다. 경사하강은 기울기 계산과 갱신을 반복하며, 모든 행을 한 번에 처리하기 어렵다면 일부 행으로 기울기를 어림하는 방법도 있습니다. 학습률이 지나치게 크면 오히려 손실이 커질 수 있고, 너무 작으면 가까운 해까지 오래 걸립니다.

설계행렬의 열이 중복되면 계수 해가 하나로 정해지지 않는다

원래 열 x에 2x를 새 특성으로 추가합니다. 세 열 가운데 2x는 기존 열의 배수이므로 독립인 열은 2개입니다. 열 수 3보다 랭크가 작아진 상태를 랭크 부족이라고 합니다.

예측은 b+w₁x+w₂(2x)=b+(w₁+2w₂)x입니다. b=1.5와 w₁+2w₂=1.5를 지키면 같은 적합값을 냅니다. 예를 들어 (w₁,w₂)=(1.5,0),(0,0.75),(0.3,0.6) 모두 가능합니다. lstsq는 그중 계수 벡터의 길이가 최소인 해를 반환합니다.

실행 예제

import numpy as np

x = np.arange(3, dtype=float)
X = np.column_stack((np.ones(x.size), x))
y = np.array([2.0, 2.0, 5.0])

least_squares, _, rank, _ = np.linalg.lstsq(X, y, rcond=None)
Q, R = np.linalg.qr(X)
direct = np.linalg.solve(R, Q.T @ y)
beta = np.zeros(2)
beta += 0.1 * (X.T @ (y - X @ beta)) / y.size
print(f"first GD: {beta.round(6).tolist()}")
for _ in range(499):
    beta += 0.1 * (X.T @ (y - X @ beta)) / y.size
print(f"rank={rank}, lstsq={least_squares.round(6).tolist()}")
print(f"QR={direct.round(6).tolist()}, GD={beta.round(6).tolist()}")

wide = np.column_stack((X, 2 * x))
alternative, _, rank, _ = np.linalg.lstsq(wide, y, rcond=None)
print(f"dependent rank={rank}, beta={alternative.round(6).tolist()}")
print(f"same fitted values: {np.allclose(wide @ alternative, X @ least_squares)}")

실행 결과

first GD: [0.3, 0.4]
rank=2, lstsq=[1.5, 1.5]
QR=[1.5, 1.5], GD=[1.5, 1.5]
dependent rank=2, beta=[1.5, 0.3, 0.6]
same fitted values: True

왜 그럴까?

같은 적합값을 낸다면 중복 특성의 계수를 해석해도 될까요?

모범 답 보기

자료가 구별하는 것은 w₁+2w₂의 합입니다. 여러 계수 쌍이 같은 예측을 내므로 각 계수의 기여를 유일하게 정할 수 없습니다. 변수 구성이 왜 겹쳤는지부터 확인합니다.
