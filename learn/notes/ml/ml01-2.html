정답 열 없이 군집과 자기지도 과제 만들기

여러 거점에서 기록한 배송 요청 수는 있지만 거점 유형은 정리돼 있지 않습니다. 요청 수만으로 비슷한 거점을 묶을 수 있습니다. 글에서는 원문의 일부를 가려 입력과 정답을 직접 만들 수 있습니다.

이 장을 읽고 나면

  • 비지도 군집화에서 사용하는 입력과 출력이 무엇인지 설명한다.
  • 같은 기록에서 입력과 목표를 만드는 자기지도 학습을 설명한다.
  • 지도·비지도·자기지도 학습의 차이를 자료와 목표로 판별한다.

정답 유형 없이 비슷한 거점을 묶는다

아래 합성 자료에서 행 하나는 거점 하나입니다. 하루 배송 요청 수가 1, 2, 7, 8인 거점 네 곳이 있습니다. 어떤 거점이 어떤 유형에 속하는지 알려 주는 목표 y는 없습니다. 가진 관측값에서 묶음이나 구조를 찾는 방법을 비지도 학습이라고 합니다. 여기서 비슷한 값을 여러 묶음으로 나누는 작업은 군집화입니다.

연습으로 요청 수를 작은 값부터 놓고 이웃 사이 간격을 봅니다. 간격은 2−1=1, 7−2=5, 8−7=1입니다. 가장 큰 간격에서 두 묶음으로 나눈다면 [1,2]와 [7,8]입니다. 같은 숫자들이어도 몇 묶음을 찾을지, 거리를 어떤 기준으로 정할지에 따라 답이 바뀔 수 있습니다.

군집 A에 들어간 두 거점의 요청 수가 비슷하다고 말할 수 있습니다. 실제 운영 원인이 같다는 주장에는 다른 근거가 필요합니다. 두 특성을 같이 사용할 때 한 특성의 값 범위가 월등히 크면 거리 계산을 주도할 수 있습니다. 변동의 단위와 비교하고 싶은 기준을 함께 정합니다.

원래 기록에서 맞힐 것을 만든다

짧은 텍스트 기록을 [포장, 완료, 확인]이라는 세 토큰으로 표현합니다. 토큰은 모델에 넣기 위해 잘라 놓은 텍스트 조각입니다. 교육용 예에서는 단어 하나를 토큰 하나로 씁니다. 두 번째 토큰을 가려 [포장, [가림], 확인]을 입력으로, 원래 있던 완료를 목표로 둡니다.

가려진 값을 예측하는 모델은 자기 출력과 원문에서 얻은 정답을 비교하며 배울 수 있습니다. 사람이 각 문장에 정답 열을 붙이지 않아도, 자료의 일부를 변형해 입력을 만들고 원래 값을 정답으로 활용하는 방식을 자기지도 학습이라고 합니다. 앞부분 [포장, 완료]를 줘 다음 토큰 확인을 예측하는 과제도 같은 원리입니다.

실행 예제

requests = [8, 1, 7, 2]
ordered = sorted(requests)
cut = max(range(1, len(ordered)), key=lambda i: ordered[i] - ordered[i - 1])
print(f"clusters: {ordered[:cut]} and {ordered[cut:]}")

tokens = ["포장", "완료", "확인"]
position = 1
masked = tokens.copy()
target = masked[position]
masked[position] = "[가림]"
print("input:", " ".join(masked))
print("target:", target)

실행 결과

clusters: [1, 2] and [7, 8]
input: 포장 [가림] 확인
target: 완료

위 코드는 두 군집을 찾고 자기지도 학습에 줄 한 쌍을 준비합니다. 그 한 쌍을 많이 만드는 것과, 모델이 답을 더 잘 예측하도록 모델 안의 값을 조정하는 일은 별도의 과정입니다.

지도 신호의 출처를 확인한다

배송 문의를 유형별로 분류하는 사례로 비교해 봅니다. 상담사가 붙인 주소 수정·지연 문의·기타 유형을 맞히는 것은 지도학습입니다. 유형 없이 비슷한 문의 문장을 묶으면 비지도 군집화입니다. 문의 문장의 토큰을 가리고 원래 토큰을 맞히게 하면 자기지도 학습입니다.

자기지도에서 모델을 미리 훈련한 다음, 적은 수의 사람 답안을 써 특정 문제에 맞춰 다시 학습하는 것도 가능합니다. BERT의 가린 토큰 예측은 이처럼 다른 작업에 앞서 텍스트 표현을 배우는 사전학습 과제의 예입니다. 사람의 정답을 붙이지 않는다는 관점에서 자기지도를 넓은 비지도 범주에 포함시키기도 합니다. 여기서는 내부에서 만든 목표가 있는지에 따라 구별합니다.

왜 그럴까?

상담 문의의 한 토큰을 입력에 그대로 두고 그 토큰을 정답으로 정하면 어떤 문제가 생길까요?
