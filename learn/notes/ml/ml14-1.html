보이지 않는 집단의 소속을 확률표로 계산하기

기록마다 두 번 시험해 성공 횟수만 적었습니다. 어떤 방식으로 시험했는지는 보이지 않습니다. 하나의 기록이 여러 집단에 얼마나 속할지 계산하고, 그 확률을 사용해 각 집단의 성공률을 다시 추정합니다.

이 장을 읽고 나면

  • 혼합 가중치와 조건부 관측분포가 결합·주변 확률을 만드는 과정을 쓸 수 있다.
  • 잠재 소속의 사후확률인 책임도를 손으로 계산할 수 있다.
  • 책임도의 합을 사용해 두 이항 성분의 매개변수를 한 번 갱신할 수 있다.

시험 방식은 기록 사이에 바뀔 수 있다

부품 검사 기록마다 한 번 A 또는 B라는 방식을 고른 뒤, 같은 방식으로 독립 시험을 두 번 한다고 합시다. 기록에는 성공 횟수 k∈{0,1,2}만 남습니다. 어느 방식을 골랐는지 z∈{A,B}는 직접 기록되지 않았습니다. 이 변수를 잠재 변수라고 합니다. 모형에는 방식 B를 고를 확률 π와 각 방식의 한 시험 성공 확률 pA,pB가 있습니다. 기록들은 서로 독립이라는 가정을 둡니다.

조건부 확률 P(K=k|Z=B)는 C(2,k)pBk(1−pB)2−k입니다. C(2,k)는 두 번 중 성공한 k개의 위치를 고르는 수입니다. 성공 횟수만 보이므로, 관측 확률은 방식별 결합확률을 더한 값입니다.

P(K=k) = (1−π)·P(K=k|A) + π·P(K=k|B)

가중치 π가 클수록 기록이 방식 B에서 왔을 가능성이 사전에 큽니다. 하지만 실제로 k가 어떤 값으로 나왔는지를 보고 나면 그 기록에 대한 B의 사후확률은 달라집니다.

성공 횟수를 본 뒤의 사후 소속

시작 값을 π=1/2, pA=1/4, pB=3/4로 둡니다. k=0일 때 A라면 (3/4)²=9/16, B라면 (1/4)²=1/16입니다. 둘의 사전 확률이 같아, B에서 이 기록이 나올 결합확률 1/32를 관측 확률 10/32로 나누면 P(B|K=0)=1/10입니다.

각 기록 i의 이 사후확률을 책임도 rᵢ라고 합니다. 기록 하나가 어느 성분에 얼마나 기여하는지 계산하는 무게로 씁니다. k=1이면 두 방식에서 그 횟수가 나타날 확률이 같으므로 사전 확률 1/2이 그대로 유지됩니다.

정수 개수 대신 기대 개수로 매개변수를 갱신한다

네 기록의 성공 횟수가 (0,0,1,2)라고 합시다. B에 대한 책임도는 (1/10,1/10,1/2,9/10)이며 합은 8/5입니다. 이 합을 방식 B로 분류된 기대 기록 수로 해석합니다. 전체가 네 기록이므로 새 가중치 π는 (8/5)/4=2/5입니다.

B에서는 기록마다 두 시험을 했으므로 기대 시험 수는 2Σrᵢ=16/5입니다. 기대 성공 수는 Σrᵢkᵢ=1/2+2×(9/10)=23/10입니다. 기대 성공 수를 기대 시험 수로 나누면 새 pB는 (23/10)/(16/5)=23/32입니다. A에서는 책임도가 1−rᵢ입니다. 기대 기록 수 12/5, 기대 성공 수 7/10에서 새 pA=7/48입니다.

이 갱신이 어디서 나오는지 확인합시다. 만약 모든 기록의 z를 알았다면, z까지 포함한 완전 자료 로그우도에서 π에 관한 항은 nBlog π+nAlog(1−π)입니다. 최댓값을 주는 π는 nB/(nA+nB)입니다. z를 모르는 경우에는 앞 책임도를 조건부 평균에 사용해 nB를 Σrᵢ로 바꿉니다. 각 성공률의 로그우도도 성분별 기대 성공과 실패 수를 써서 미분하면 기대 비율이 나옵니다. 둘 다 양수인 내부 해를 다뤘으며, 기대 기록이 0인 성분은 분모가 0이어서 같은 갱신을 바로 적용할 수 없습니다.

분수 그대로 한 번 실행하기

from fractions import Fraction as F
from math import comb

def prob(k, p):
    return comb(2, k) * p**k * (1-p)**(2-k)

records = (0,0,1,2)
pi, p_a, p_b = F(1,2), F(1,4), F(3,4)
responsibility = []
for k in records:
    a = (1-pi) * prob(k,p_a)
    b = pi * prob(k,p_b)
    responsibility.append(b/(a+b))
mass_b = sum(responsibility)
mass_a = len(records)-mass_b
success_b = sum(r*k for r,k in zip(responsibility,records))
success_a = sum(records)-success_b
updated = (mass_b/len(records), success_a/(2*mass_a), success_b/(2*mass_b))
assert updated == (F(2,5),F(7,48),F(23,32))
print("책임도:", *responsibility)
print("성분별 기대 기록 A,B:", mass_a, mass_b)
print("π, p_A, p_B:", *updated)

실행 결과

책임도: 1/10 1/10 1/2 9/10
성분별 기대 기록 A,B: 12/5 8/5
π, p_A, p_B: 2/5 7/48 23/32

처음의 확률로 각 기록이 얼마나 속하는지 계산하는 단계가 E, 그 결과를 고정해 매개변수를 갱신하는 단계가 M입니다. 실제 방식의 소속을 알아냈다고 볼 수는 없습니다. 축적된 횟수에 맞는 하나의 혼합모형을 업데이트한 것입니다. 다음 장에서는 왜 이 두 단계가 관측 로그우도를 낮추지 않는지 증명하고, 높은 우도가 잠재 구조의 유일성을 보장하지 않는 예를 봅니다.
