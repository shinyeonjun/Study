확률 보정과 개별 예측의 불확실성

모델이 지연 확률을 0.8이라고 답할 때, 비슷한 답을 받은 주문을 모으면 실제로 얼마나 지연됐는지 확인할 수 있습니다. 확률에 대한 평균적 약속과 해당 주문에서 무슨 일이 생길지를 따로 봅니다.

이 장을 읽고 나면

  • 예측 확률의 구간 평균과 양성 비율을 대조한다.
  • 이진 Brier 점수를 손으로 계산한다.
  • 확률 보정과 개별 예측의 불확실성을 구별한다.

같은 확률을 받은 사례의 실제 빈도를 확인한다

이진 모델이 지연 확률 p를 냅니다. 확률 보정이 잘 됐다는 것은 같은 확률을 낸 사례를 많이 모으면 실제 양성 비율이 그 확률에 가깝다는 뜻입니다. 연속된 점수는 서로 가까운 확률을 구간으로 묶어, 각 구간의 평균 예측 확률과 실제 양성 비율을 비교합니다.

합성 평가에서 p=0.2인 다섯 건 중 지연 1건, p=0.8인 다섯 건 중 지연 3건이었습니다. 첫 점은 (0.2, 0.2)이고 두 번째는 (0.8, 0.6)입니다. 두 번째 구간의 예측은 이 자료의 관측 비율보다 0.2 높습니다. 이렇게 점이 대각선 아래에 있으면 실제보다 확신이 큰 과신(overconfident), 대각선 위에 있으면 과소 확신이라고 합니다. 이처럼 구간별 (평균 예측, 관측 비율)을 찍은 그림을 신뢰도 그림(보정 곡선, reliability diagram)이라고 합니다. 모집단에서 얼마나 어긋나는지는 이 다섯 건만으로 단정하기 어렵습니다.

원래 점수를 새로운 확률로 바꾸는 대표적인 방법은 두 가지입니다. 플랫 보정(Platt scaling)은 점수 s에 시그모이드 1/(1+exp(−(as+b)))를 맞추고, 등위 회귀(isotonic regression)는 점수가 커질 때 확률이 줄지 않는 계단 모양 함수를 맞춥니다. 등위 회귀는 모양 제약이 약해 자료가 적으면 과적합하기 쉽습니다. scikit-learn 1.9의 CalibratedClassifierCV는 기본이 method='sigmoid'이고, 보정 곡선을 구하는 calibration_curve는 기본으로 [0,1]을 같은 폭 5개 구간(n_bins=5)으로 나눕니다. 원래 모델이 훈련했던 자료와 별도로 보정용 검증 예측을 얻고 보정 규칙을 학습합니다. 최종 테스트는 모델과 보정 규칙을 고를 때 따로 남겨 둡니다. 구간을 크게 묶으면 서로 다른 부분의 차이가 상쇄될 수 있으므로 구간 정의와 건수를 같이 봅니다.

예측한 확률과 실제 0 또는 1 사이의 제곱을 평균 낸다

양성 확률 p와 실제 라벨 y∈{0,1}이 주어질 때 이진 Brier 점수는 mean((p−y)²)입니다. 값이 작을수록 이 평가 기준에서 좋습니다. 예를 들어 p=0.8에서 지연이면 0.04, 정상이라면 0.64입니다.

실행 예제

from statistics import mean

bins = [(0.2, [1,0,0,0,0]), (0.8, [1,1,1,0,0])]
pairs = []
for probability, observed in bins:
    pairs += [(probability, y) for y in observed]
    print(f"p={probability:.1f}, n={len(observed)}, observed={mean(observed):.1f}")
print(f"Brier={mean((p-y)**2 for p,y in pairs):.2f}")
print(f"constant p=0.4 Brier={mean((0.4-y)**2 for _,y in pairs):.2f}")

실행 결과

p=0.2, n=5, observed=0.2
p=0.8, n=5, observed=0.6
Brier=0.22
constant p=0.4 Brier=0.24

모든 주문에 평가 비율 0.4를 답하면 이 표에서 예측 빈도와 실제 빈도가 맞지만 주문 사이의 차이는 표현하지 못합니다. 이 상수는 비교 원리를 보이기 위해 정했습니다. 실제 기준 모형이라면 0.4 같은 예측값을 훈련에서 구한 뒤 고정합니다. Brier 하나는 보정뿐 아니라 좋은 주문과 나쁜 주문을 확률로 구별하는 정도 등에도 영향을 받습니다. 이 점수와 보정 그림을 함께 읽습니다.

높은 확률이 개별 사례의 결과를 결정하는가

정확히 보정된 확률 0.8이라도 비슷한 사례의 일부는 반대 결과를 냅니다. 실제 환경의 우연한 차이에서 오는 관측 불확실성(우연적 불확실성, aleatoric)과 자료 부족이나 모형 선택에 따른 모델 불확실성(인식적 불확실성, epistemic)을 나누어 볼 수 있습니다. 앞의 것은 자료를 더 모아도 줄지 않고, 뒤의 것은 비슷한 자료가 늘면 줄어듭니다. 모델 불확실성은 다른 훈련 표본으로 여러 모형을 학습해(앙상블·부트스트랩) 예측이 얼마나 갈라지는지로 어림하기도 합니다. 한 주문의 확률 숫자만 보고 두 성분을 분해할 수는 없습니다.

훈련에 없던 거점에서 p=0.99가 나왔다면, 비슷한 훈련 분포에서 성립한 보정이 새 거점에서도 유지되는지 알 수 없습니다. 자료의 범위를 확인하고 작은 구간의 관측 비율에는 표본이 적다는 불확실성을 함께 표시합니다. 위험한 경우에는 사람 검토로 넘길 조건이나 예측을 보류할 기준을 운영 목적에 맞춘 별도 자료로 평가합니다.

왜 그럴까?

예측값이 0.8에 가까운 사례 중 80%가 지연됐다는 사실만으로, 특정 주문의 지연을 확정할 수 있나요?
