결정나무의 질문과 Gini 불순도

대기 주문이 몇 건일 때부터 지연이 많아질까요? 결정나무는 한 특성에 관한 질문으로 자료를 두 묶음으로 나눕니다. 정상이 많은 쪽과 지연이 많은 쪽으로 얼마나 잘 나뉘었는지 건수를 세어 비교합니다.

이 장을 읽고 나면

  • 결정나무의 뿌리·가지·잎과 예측 규칙을 설명한다.
  • Gini 불순도를 계산해 여러 분할을 가중 비교한다.
  • 한 단계에서 좋은 질문을 고르는 방식과 전역 최적의 차이를 설명한다.

한 질문의 응답으로 다음 칸을 고른다

합성 자료에서 접수 직전 대기 건수는 1,2,3,4,5,6이고 대응하는 지연 라벨은 0,0,1,0,1,1입니다. 결정나무는 x ≤ 2.5? 같은 질문을 순서대로 묻습니다. 처음 질문은 뿌리 노드, 두 갈래는 가지, 더 묻지 않고 예측하는 칸은 잎 노드입니다. 이진 CART 방식은 내부 노드에서 자료를 두 자식으로 나눕니다.

숫자가 서로 다른 이웃 관측값 사이의 중간값은, 훈련 행의 소속이 달라질 수 있는 후보를 한 번씩 나타냅니다. 같은 관측값을 가진 두 행은 이 한 특성만으로 서로 다른 쪽에 놓을 수 없습니다. 여러 특성이 있으면 각 특성의 후보를 검토합니다.

같은 쪽에 라벨을 더 모았는지 계산한다

Gini 불순도는 노드에 여러 라벨이 얼마나 섞여 있는지 나타냅니다. 클래스별 비율이 p₁,…,pₖ이면 G=1−Σpⱼ²입니다. 표본을 복원해 두 번 뽑을 때 라벨이 다를 확률로 해석할 수 있습니다. 지연과 정상이 3건씩이면 G는 1−(3/6)²−(3/6)²=0.50입니다. 한 라벨만 있는 노드는 G가 0입니다.

임계값 2.5가 왼쪽의 정상 2건과 오른쪽의 정상 1건·지연 3건을 나눕니다. 오른쪽의 G는 1−(1/4)²−(3/4)²=0.375입니다. 자식 두 개의 G는 행 수 비율을 곱해 더합니다. 자식 가중 불순도는 (2/6)×0+(4/6)×0.375=0.25, 부모의 불순도에서 이를 뺀 감소량은 0.50−0.25=0.25입니다.

임계값 3.5에서는 좌우가 각각 세 건이고 지연이 한 건과 두 건입니다. 두 자식의 G가 모두 4/9이므로 가중한 값도 4/9≈0.444입니다. 후보 2.5가 3.5보다 덜 섞인 두 묶음을 만듭니다.

왜 그럴까?

자식 노드 두 개의 Gini를 단순히 반반 평균하면 어떤 정보가 빠질까요?

모범 답 보기

두 자식 크기가 다르면 큰 쪽에 든 표본이 더 많습니다. 이 예에서 오른쪽의 Gini는 4/6만큼 반영되므로, 자식의 크기를 쓰지 않으면 분할을 다른 기준으로 비교하게 됩니다.

가장 좋은 후보를 고르고 같은 일을 반복한다

이 노드에서 후보마다 자식 가중 불순도를 비교합니다. 2.5와 4.5가 모두 0.25로 최소입니다. 예제 구현에서는 동률일 때 더 작은 임계값을 선택합니다. 나눈 자식 노드에서 다시 후보를 평가합니다. 매번 현재 노드에서 감소량이 큰 쪽을 고르는 탐욕적 선택을 하므로 전체 나무의 모든 조합을 비교한 결과와 다를 수 있습니다.

실행 예제

from fractions import Fraction as F
from collections import Counter

values = [1, 2, 3, 4, 5, 6]
labels = [0, 0, 1, 0, 1, 1]

def gini(targets):
    return 1 - sum(F(n, len(targets))**2 for n in Counter(targets).values())

def weighted(left, right):
    total = len(left) + len(right)
    return F(len(left), total) * gini(left) + F(len(right), total) * gini(right)

scores = []
for i in range(1, len(values)):
    threshold = (values[i - 1] + values[i]) / 2
    loss = weighted(labels[:i], labels[i:])
    scores.append((loss, threshold))
    print(f"threshold={threshold:.1f}: weighted Gini={float(loss):.3f}")

score, threshold = min(scores)
print(f"chosen={threshold:.1f}, decrease={float(gini(labels) - score):.3f}")

실행 결과

threshold=1.5: weighted Gini=0.400
threshold=2.5: weighted Gini=0.250
threshold=3.5: weighted Gini=0.444
threshold=4.5: weighted Gini=0.250
threshold=5.5: weighted Gini=0.400
chosen=2.5, decrease=0.250

이 코드는 정렬돼 있고 값이 모두 다른 특성 하나를 예로 듭니다. 두 자식이 비어 있지 않은 분할만 봅니다. 새 주문의 대기 건수가 5라면 2.5를 초과하므로 오른쪽 잎에 가서 지연을 예측합니다. 분류 잎에는 라벨별 비율을 저장할 수도 있습니다. 회귀용 나무는 수치 목표로부터 제곱오차처럼 그 문제에 맞는 분할 기준을 사용하고, 제곱오차 기준의 잎은 목표 평균을 예측합니다.
