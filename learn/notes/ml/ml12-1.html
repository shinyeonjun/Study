생성 모형과 판별 모형, 나이브 베이즈 계산

문의에 ‘대기’나 ‘문자’가 들어 있는지를 보고 지연 문의인지 구별합니다. 각 유형에서 어떤 말이 얼마나 자주 쓰였는지 먼저 계산하고, 새 글이 어느 쪽에서 더 잘 나올지 비교합니다.

이 장을 읽고 나면

  • 생성 분류의 P(Y)P(X|Y)와 판별 분류를 구별한다.
  • 조건부 독립과 평활화를 써 후보별 점수를 계산한다.
  • 로그 합과 정규화로 계산하고 확률의 한계를 설명한다.

클래스를 주고 입력을 설명하는 모형을 만든다

로지스틱 회귀는 입력 x를 주고 P(Y|X=x)를 직접 표현하는 판별 모형입니다. 생성 방식의 분류는 클래스의 확률 P(Y)과 그 클래스가 주어질 때 입력이 나올 가능성 P(X|Y)를 각각 학습합니다. 이 두 항의 곱이 결합확률이며, 베이즈 규칙 P(Y=c|X=x)=P(Y=c)P(X=x|Y=c)/Σₖ P(Y=k)P(X=x|Y=k)로 반대 조건인 P(Y|X)를 구할 수 있습니다. 분모는 모든 클래스에 공통이므로 어느 클래스가 가장 큰지만 알면 될 때는 분자만 비교합니다.

생성 모형은 입력의 분포까지 모형화하므로 새 입력을 만들어 내거나 일부 특성이 빠진 입력을 다루기 쉽고, 가정이 맞으면 적은 자료로도 빨리 안정됩니다. 판별 모형은 경계에 필요한 것만 배우므로 입력 분포에 대한 가정이 틀렸을 때 덜 흔들리고, 자료가 많으면 보통 분류 오차가 더 낮습니다. 이 경향은 나이브 베이즈와 로지스틱 회귀를 비교한 연구(Ng·Jordan 2002)로 잘 알려져 있으나, 모든 자료에서 성립하는 법칙은 아닙니다.

합성 메일에서 지연 3건, 정상 3건이 있어 사전확률은 각각 0.5입니다. 특성은 ‘대기’가 있는지와 ‘문자’가 있는지입니다. 나이브 베이즈는 같은 클래스 안에서 특성들이 서로 조건부 독립이라고 가정해 P(X|Y)를 특성별 조건부 확률의 곱으로 계산합니다. 여기서는 각 특성이 0 또는 1인 베르누이 사례입니다.

관측 빈도가 0인 곳에 평활화를 적용한다

훈련에서 ‘대기’가 들어간 정상 문의는 한 건도 없었습니다. 이 확률을 원시 빈도 0으로 쓰면 다른 특성이 어떻든 새 글이 정상일 점수가 곱에서 0이 됩니다. 단순한 add-one 평활화는 각 특성에서 0과 1의 빈도에 각각 1을 더합니다. 정상에서 ‘대기’ 있음의 확률은 (0+1)/(3+2)=1/5이고 없음의 확률은 4/5입니다.

새 글의 ‘대기’는 있고 ‘문자’는 없다는 입력이 옵니다. 지연의 ‘문자 없음’ 확률은 1−3/5=2/5입니다. 정상의 ‘문자 없음’은 1−2/5=3/5입니다. 특성의 종류에 따라 P(xⱼ|Y)의 모양을 다르게 둡니다.

종류 (scikit-learn)특성P(xⱼ|Y)
베르누이 (BernoulliNB)단어가 있음/없음 같은 0·1클래스별 있음 확률 p, 없음 1−p. 이 장의 예
다항 (MultinomialNB)단어 등장 횟수클래스별 단어 비율 (그 단어 횟수+α)/(전체 단어 수+α×어휘 수)
가우시안 (GaussianNB)연속값클래스별 평균·분산을 갖는 정규밀도

scikit-learn의 BernoulliNB와 MultinomialNB는 평활 강도 alpha의 기본값이 1.0이라 add-one(라플라스) 평활과 같습니다. 이 장의 여섯 건에 BernoulliNB()를 그대로 적용하면 아래 계산과 같은 지연 확률 8/11≈0.7273이 나옵니다.

작은 확률을 많이 곱하는 대신 로그를 더한다

여러 작은 확률을 직접 곱하면 컴퓨터가 0으로 반올림할 수 있습니다. 로그는 곱을 합으로 바꾸고 순서를 보존합니다. 먼저 로그 점수를 비교하고, 확률이 필요하면 공통 최댓값을 빼고 지수를 적용해 합으로 나눕니다.

실행 예제

from math import exp, log

training = {
    "late": [(1,1),(1,1),(1,0)],
    "normal": [(0,0),(0,0),(0,1)],
}
query = [1,0]
total = sum(len(rows) for rows in training.values())
scores = {}
for label, rows in training.items():
    value = log(len(rows) / total)
    for j, event in enumerate(query):
        probability = (sum(row[j] == event for row in rows) + 1) / (len(rows) + 2)
        value += log(probability)
    scores[label] = value
    print(f"{label}: unnormalized={exp(value):.2f}")

shift = max(scores.values())
mass = {label: exp(score - shift) for label,score in scores.items()}
print(f"late posterior={mass['late']/sum(mass.values()):.4f}")
print("prediction:", max(scores, key=scores.get))

실행 결과

late: unnormalized=0.16
normal: unnormalized=0.06
late posterior=0.7273
prediction: late

모범 답 보기

두 열이 같은 증거인데 조건부 독립으로 곱하면 같은 단서가 두 번 들어갑니다. 예측 확률이 실제 빈도보다 과도하게 한쪽에 쏠릴 수 있습니다.

조건부 독립은 클래스 안의 가정입니다. 전체 자료에서 상관이 없어 보이는지와 별개의 확인입니다. 모델이 분류를 잘해도 출력 확률이 잘 보정됐는지는 다른 자료에서 확인합니다.
