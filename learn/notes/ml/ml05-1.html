ML05·1

로짓과 시그모이드, 이진 분류의 안정적인 손실

도서관 방문 전에 긴 대기가 생길 확률을 내고 싶습니다. 선형식으로 얻은 값을 0과 1 사이로 바꾼 뒤, 어느 확률에서 경보를 낼지 정하고 관측된 정답의 손실을 계산합니다.

이 장을 읽고 나면

  • 오즈와 로그오즈를 시그모이드 확률로 바꾼다.
  • 임계값을 정하고 이진 분류 경계를 계산한다.
  • 로짓에서 이진 교차엔트로피를 안정적으로 평가한다.

확률의 비율을 로그로 바꾸어 선형식과 연결한다

이진 목표에서 긴 대기를 양성 1이라고 합시다. 양성 확률 p가 0.8이면 음성 확률은 0.2이고 양성과 음성의 확률 비인 오즈는 p/(1−p)=4입니다. 양의 값인 오즈에 자연로그를 쓴 로짓은 ln[p/(1−p)]입니다. 확률 p가 0과 1 사이를 움직이면 로짓은 모든 실수 값을 가질 수 있습니다.

로지스틱 회귀는 z=b+wᵀx로 로짓을 표현합니다. 이를 확률로 돌려 놓는 시그모이드는 p=1/(1+exp(−z))입니다. z=0이면 p=0.5이며 z가 커질 때 p가 커집니다. 이 장의 합성 모형은 z=2x−4입니다. x=1,2,3일 때 로짓은 −2,0,2이고 확률은 약 0.119,0.500,0.881입니다.

계수는 로그오즈의 기울기로 읽습니다. 다른 입력을 고정하고 xj가 1 늘면 로짓이 wj만큼 늘고, 오즈는 exp(w_j)배가 됩니다. 이 배수를 오즈비라고 합니다. z=2x−4에서 x가 2에서 3이 되면 오즈는 1에서 e²≈7.389로 늘어납니다(0.881/0.119≈7.39). 확률 p 자체는 x에 대해 S자로 변하므로 "x가 1 늘면 확률이 몇 %p 는다"처럼 일정한 값으로 읽을 수 없습니다.

예측 확률과 경보 결정은 서로 다른 단계다

확률이 기준 이상이면 경보를 보낸다고 정합니다. 임계값 0.5는 로짓 0을 뜻하므로 이 예에서는 x≥2에서 경보합니다. 임계값이 0.8이면 2x−4≥ln 4이므로 x≥(4+ln 4)/2≈2.693입니다. x가 벡터일 때는 일정한 로짓을 내는 b+wᵀx=상수가 경계입니다.

경보 기준을 바꾸는 데 모형을 다시 학습할 필요는 없습니다. 임계값은 지연 누락과 거짓 경보의 비용에 맞춰 검증 자료에서 고릅니다. 모형이 0.8이라고 말한 사례들 가운데 실제로 약 80%가 양성인지, 즉 확률이 실제 빈도와 맞는지(보정, calibration)는 평가에서 따로 확인합니다.

실제 라벨에 준 확률에 손실을 매긴다

관측 라벨 y가 1이면 손실은 −ln p, y가 0이면 −ln(1−p)입니다. 이를 합친 이진 교차엔트로피(BCE)는 −[y ln p+(1−y)ln(1−p)]입니다. 여러 관측의 BCE를 줄이도록 회귀 계수를 정합니다. 자연로그를 쓰므로 손실 단위는 나트입니다.

BCE와 최대가능도

관측이 서로 독립이라고 보면, 계수가 주어졌을 때 관측된 라벨 전체가 나올 확률(가능도)은 각 관측에서 실제 라벨에 준 확률의 곱입니다. 곱에 로그를 씌우고 부호를 바꾸면 BCE의 합이 됩니다. 그래서 BCE 최소화 = 최대가능도 추정입니다. 선형 회귀와 달리 닫힌 해가 없어 경사하강 계열의 반복 최적화로 계수를 찾습니다. 한 관측의 BCE를 로짓 z로 미분하면 p−y라는 간단한 꼴이 나와, 예측 확률이 정답보다 클수록 z를 낮추는 방향으로 고칩니다. scikit-learn의 LogisticRegression은 기본으로 L2 규제(C=1.0, C가 작을수록 규제가 강함)를 더한 손실을 lbfgs로 최소화합니다.

로짓 z가 큰 양수이면 유한한 컴퓨터 정밀도에서 시그모이드가 1로 반올림될 수 있습니다. 그 뒤 ln(1−p)를 구하면 문제가 생깁니다. 유한한 z에 대한 같은 BCE를 max(z,0)−y·z+log1p(exp(−|z|))로 계산할 수 있습니다. 지수의 입력이 0 이하라 큰 양수의 지수를 계산하지 않습니다. log1p(u)는 u가 아주 작을 때도 ln(1+u)를 안정적으로 구합니다.

실행 예제

from math import exp, log1p
from statistics import mean

def sigmoid(z):
    scale = exp(-abs(z))
    return 1 / (1 + scale) if z >= 0 else scale / (1 + scale)

def loss(z, y):
    return max(z, 0) - y*z + log1p(exp(-abs(z)))

labels = [0,1,1]
z_values = [-2,0,2]
for z, y in zip(z_values, labels, strict=True):
    print(f"z={z:2d}, p={sigmoid(z):.3f}, y={y}, BCE={loss(z,y):.3f}")
print(f"mean BCE={mean(loss(z,y) for z,y in zip(z_values,labels,strict=True)):.4f}")
print(f"z=1000: y=1 loss={loss(1000,1):.1f}, y=0 loss={loss(1000,0):.1f}")

실행 결과

z=-2, p=0.119, y=0, BCE=0.127
z= 0, p=0.500, y=1, BCE=0.693
z= 2, p=0.881, y=1, BCE=0.127
mean BCE=0.3157
z=1000: y=1 loss=0.0, y=0 loss=1000.0
