집단별 오류와 특성 중요도를 조사해 읽기

두 지점에서 혼잡의 75%를 똑같이 잡았더라도, 어떤 지점에서는 경보를 확인할 일이 더 많을 수 있습니다. 어떤 영향을 받는지 나누어 보고, 특성이 왜 중요해 보이는지도 모형과 자료의 범위 안에서 확인합니다.

이 장을 읽고 나면

  • 집단별 재현율·거짓양성률·정밀도를 건수로 비교한다.
  • 순열 특성 중요도를 실제 점수 차이로 계산한다.
  • 집단별 차이와 특성 중요도를 원인으로 바로 해석할 수 없는 이유를 설명한다.

같은 재현율이라도 경보의 품질은 다를 수 있다

합성 도서관 자료에서 A와 B를 각각 100건 평가합니다. A에는 실제 혼잡 40건과 정상 60건, B에는 혼잡 20건과 정상 80건이 있습니다. A는 실제 혼잡 30건, B는 실제 혼잡 15건을 잡아 둘 다 재현율 75%입니다. A의 정상 6건, B의 정상 8건에도 경보가 나와 두 집단의 거짓양성률도 각각 10%입니다.

정밀도의 분모는 실제 혼잡 수가 아니라 경보 전체입니다. A에서 30/(30+6)=0.833…, B에서 15/(15+8)=0.652…입니다. 두 집단의 실제 혼잡 비율이 달라 경보의 구성도 다릅니다. 지표를 하나 골라 같게 만든다고 다른 기준까지 같아지지는 않습니다.

공정성을 살필 때는 경보를 놓쳤을 때의 불이익과 헛경보를 확인하는 부담이 누구에게 돌아가는지 먼저 적습니다. 라벨을 붙이는 조건, 집단별 평가 건수, 수집 누락과 적용 목적도 확인합니다. 작은 집단은 분모가 작아 수치가 크게 흔들리거나 실제 양성이 없어 재현율이 정의되지 않을 수 있습니다. 공개할 때에는 개인이 드러나는지에도 주의합니다. 연구 윤리와 데이터에서 집단 지표와 권리를 다시 볼 수 있습니다.

모델을 고정하고 한 특성만 다른 행에 돌려본다

순열 중요도는 고정한 모형에서 평가용 특성 하나의 값만 행 사이에 섞은 다음 점수가 얼마나 나빠졌는지 보는 방법입니다. 정답과 다른 열을 유지합니다. 같은 종류의 관측과 같은 지표로 원래 점수를 먼저 계산합니다. 점수가 높을수록 좋은 정확도라면 원래 정확도−섞은 뒤 정확도가 한 번의 중요도 계산입니다.

네 행에서 정답과 x 모두 [0,0,1,1], 규칙은 x를 그대로 반환한다고 둡니다. x를 [1,0,1,0]로 섞으면 행 2와 3만 맞습니다. 점수는 1.0에서 0.5로 내려가고 이 한 순열의 차이는 0.5입니다.

실행 예제

from statistics import mean

def accuracy(pred, y):
    return mean(a == b for a,b in zip(pred,y,strict=True))

for site, tp, actual_pos, fp, actual_neg in [("A",30,40,6,60),("B",15,20,8,80)]:
    print(f"{site}: TPR={tp/actual_pos:.3f}, FPR={fp/actual_neg:.3f}, precision={tp/(tp+fp):.3f}")

truth = [0,0,1,1]
features = {"x": [0,0,1,1], "z": [0,0,1,1]}
permutation = [2,0,3,1]

def predict(columns):
    return columns["x"]

baseline = accuracy(predict(features), truth)
for key in features:
    shuffled = {**features, key: [features[key][i] for i in permutation]}
    print(f"{key}: accuracy drop={baseline - accuracy(predict(shuffled),truth):.2f}")

실행 결과

A: TPR=0.750, FPR=0.100, precision=0.833
B: TPR=0.750, FPR=0.100, precision=0.652
x: accuracy drop=0.50
z: accuracy drop=0.00

예제는 순열 한 개를 고정했습니다. 실제로는 섞기를 여러 번 반복해 평균과 변동을 볼 수 있습니다. 점수가 낮을수록 좋은 오차에서는 나빠졌다는 뜻이 되도록 차이의 방향을 바꿉니다.

어떤 모델이 무엇에 의존했는지로 해석한다

예제의 z는 원래 x와 같은 값입니다. 그래도 이 모델은 x를 직접 답하므로 z를 섞어도 점수가 같습니다. 중요도가 낮다는 것은 이 모형·자료·지표에서의 결과입니다. 같은 정보가 다른 열에 있어서 모델이 그 대체 열을 쓸 수도 있습니다. 서로 관련된 열에서 하나만 섞으면 현실에서 드문 조합이 섞일 수 있습니다.

어느 특성을 섞었을 때 점수가 많이 떨어져도 그 특성이 정답을 일으킨다고 말할 수는 없습니다. 예를 들어 어떤 거점 코드가 혼잡 예측에 중요하더라도, 이용 시간이나 주변 행사 같은 배경의 대리값일 수 있습니다. 원인에 대한 질문은 실제 개입과 비교할 방법을 따로 정해야 합니다.
