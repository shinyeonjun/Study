장비별로 분리해 중첩 검증하고 마지막 두 장비를 평가하기

같은 장비에서 나온 두 행이 훈련과 검증에 한 줄씩 들어가면, 새 장비에 얼마나 잘 맞을지 과대평가할 수 있습니다. 장비 묶음을 유지하면서 정규화 강도를 고르고, 따로 남긴 보류 자료로 마지막 차이를 확인합니다.

이 장을 읽고 나면

  • 개발 바깥 검증, 안쪽 선택, 최종 보류의 역할을 구별한다.
  • 대칭 입력에서 ridge 기울기를 도출하고 기준 모델과 비교한다.
  • 전체 평균과 보류 장비별 결과를 함께 보고한다.

합성 장비 표와 선택 규칙을 고정한다

장비 A~H에서 입력 x=0과 x=2의 연속값을 한 번씩 측정합니다. 손으로 답을 정해 두기 위해 y=10+sᵍ(x−1)로 합성합니다. sᵍ는 장비 g의 자료를 만드는 기울기입니다. 분석 코드의 입력 피처는 x뿐이고 장비 ID는 분할을 유지할 때만 사용합니다.

기준은 훈련 자료 y의 상수 평균입니다. 대안은 절편에 벌점을 주지 않는 ridge 회귀로, 후보 λ는 0과 4입니다. 기준과 대안은 같은 검증 장비에 대한 평균절대오차(MAE)로 비교합니다. 타당한 입력만 포함된 합성 자료입니다. 실제 실험에서는 실패한 장비와 빠진 관측의 처리 규칙도 포함해 평가표의 단위를 정합니다.

선택한 모형이 아니라 선택하는 절차를 평가한다

바깥 검증 짝은 AB, CD, EF를 차례로 씁니다. AB를 검증할 때는 C,D,E,F만 가지고 안쪽에서 장비 하나씩 빼어 λ를 비교합니다. 나머지 세 장비로 맞추고 안쪽에서 남긴 하나로 오차를 냅니다. 네 장비의 MAE 평균이 작은 λ를 고르고 동점이면 0을 택합니다. λ를 고른 다음 C,D,E,F 전체에서 다시 맞추어 A,B에 적용합니다. 이 과정을 나머지 바깥 짝에서 반복합니다. 같은 바깥 점수로 λ를 고르고 그 점수를 최종 성능으로 사용하면 선택 과정의 이득이 평가에 들어갑니다.

scikit-learn으로 옮기면 안쪽은 GridSearchCV(Ridge(), {"alpha":[0,4]}, cv=LeaveOneGroupOut(), scoring="neg_mean_absolute_error")에 fit(X, y, groups=장비), 바깥은 장비 짝을 그룹으로 둔 같은 분할기입니다. Ridge는 기본 fit_intercept=True에서 절편에 벌점을 주지 않으므로 아래 유도와 같은 목적함수입니다(scikit-learn 1.9.1에서 아래 표의 안쪽 MAE 세 줄과, A~F·alpha=4의 기울기 1.125=9/8을 실제로 확인했습니다). 동점이면 GridSearchCV는 후보 목록에서 앞에 있는 값을 고르므로, 목록을 [0,4] 순서로 두어야 위의 "동점이면 0" 규칙과 같아집니다.

대칭 자료에서 ridge의 정확한 기울기를 계산한다

u=x−1로 놓으면 각 장비의 u는 −1과 1입니다. 훈련 자료의 u 평균이 0이고 y 평균이 10이므로 예측 절편은 10입니다. m대의 장비를 맞출 때 각 장비가 제곱오차 2(sᵍ−b)²를 더합니다. 2∑(sᵍ−b)²+λb²를 b로 미분해 0으로 놓으면 b=2∑sᵍ/(2m+λ)입니다. 각 검증 장비에서 두 행의 절대오차는 모두 |sᵍ−b|입니다.

개발의 바깥 폴드마다 훈련 집합이 서로 겹칩니다. 여러 바깥 점수를 완전히 독립인 복제 표본처럼 세어 단순 신뢰구간을 만드는 근거가 부족합니다. 보류 장비 자체를 늘리거나 새로운 실험을 추가할 때에도 관측과 불확실성의 단위를 맞춥니다.

보류 장비의 평균은 같고 개별 차이는 크다

A~F 모두를 개발에 사용하면 안쪽 오차는 1과 20/21이어서 λ=4를 고릅니다. 개발 전체의 기울기는 9/8입니다. 보류 G의 기준·대안 MAE는 2와 7/8, H는 1과 17/8입니다. 두 장비에 동일한 비중을 두면 전체는 둘 다 3/2입니다. 기준에서 대안을 뺀 장비별 향상량은 9/8과 −9/8로 방향이 반대입니다. 장비 두 대에서 얻은 같은 평균은 전체 모집단에서 두 모형이 동등하다는 결론을 주지 않습니다.

from fractions import Fraction as F

truth = dict(zip("ABCDEFGH", [0,1,1,2,2,3,2,-1]))
rows = {g:[(u, 10+s*u) for u in (-1,1)] for g,s in truth.items()}

def fit(train, lam):
    pairs = [row for g in train for row in rows[g]]
    a = F(sum(y for _,y in pairs),len(pairs))
    b = F(sum(u*(y-a) for u,y in pairs),sum(u*u for u,_ in pairs)+lam)
    return a,b

def mae(test, model):
    a,b = model
    values = [abs(y-(a+b*u)) for g in test for u,y in rows[g]]
    return sum(values)/len(values)

def inner(dev, lam):
    values = [mae(g,fit([h for h in dev if h!=g],lam)) for g in dev]
    return sum(values)/len(values)

def choose(dev):
    return min((0,4),key=lambda l: (inner(dev,l),l))

for test in ("AB","CD","EF"):
    train = [g for g in "ABCDEF" if g not in test]
    lam = choose(train)
    a,b = fit(train,lam)
    print(test, inner(train,0), inner(train,4), lam, b,
          mae(test,(a,0)),mae(test,(a,b)))
dev = "ABCDEF"
lam = choose(dev)
a,b = fit(dev,lam)
print(lam, b, inner(dev,0), inner(dev,4))
for test in ("G","H","GH"):
    print(test, mae(test,(a,0)),mae(test,(a,b)))
