가우시안 혼합 모형과 EM의 책임도

도착 시간이 두 종류의 과정에서 섞여 나왔지만 어떤 과정인지 기록되지 않았습니다. 하나의 정규분포로 모두 설명하는 대신 두 정규분포를 섞고, 각 점이 어느 성분에서 왔을지 확률로 배정해 봅니다.

이 장을 읽고 나면

  • 가중치를 합해 혼합 밀도를 계산한다.
  • EM의 E 단계 책임도와 M 단계 평균 갱신을 손으로 구한다.
  • 우도 증가와 전역 최적·실제 군집 해석의 한계를 구별한다.

먼저 성분을 고른 뒤 그 성분에서 값이 나온다고 둔다

관측마다 보이지 않는 성분 Z를 먼저 고른 다음, 그 성분의 정규분포에서 수치를 뽑는 모형을 생각합니다. 가우시안 혼합 모형(GMM)의 밀도는 p(x)=Σ πₖ φ(x; μₖ,σₖ²)입니다. 여기서 φ는 평균 μ와 분산 σ²인 정규밀도, π는 성분의 가중치로 0 이상이며 합은 1입니다.

합성 예에서 두 성분의 평균은 0, 4, 공통 분산은 4, 가중치는 각각 1/2입니다. 관측값 0, 2, 4에서 두 가중 밀도 값을 더해 그 점의 전체 밀도를 얻습니다. 연속형 데이터의 밀도 높이는 단일 값이 나올 확률 대신 여러 값이 들어 있는 구간의 확률을 구하는 데 씁니다.

책임도를 구한 뒤 각 성분의 값을 다시 맞춘다

EM은 두 단계를 반복합니다. E 단계는 현재 모형에서 각 x가 성분 k에 속할 조건부 확률인 책임도 rₖ(x)=πₖφₖ(x)/Σⱼπⱼφⱼ(x)를 계산합니다. 평균 0인 성분의 x=0 지수 항은 1이고 평균 4 쪽은 exp(−4²/(2×4))=exp(−2)입니다. 두 가중치와 정규밀도의 공통 계수는 같으므로 왼쪽 책임도는 1/(1+exp(−2))≈0.8808입니다.

M 단계는 그 책임도를 관측 가중치로 삼아 모형을 갱신합니다. 왼쪽의 x가 0,2,4일 때 책임도는 약 0.8808,0.5,0.1192입니다. 합이 1.5이므로 Σ rᵢxᵢ/Σrᵢ≈0.9845가 새 평균입니다. 오른쪽 새 평균은 약 3.0155입니다.

이 예에서는 가중치와 분산을 고정하고 평균만 다시 구합니다. 일반적인 1차원 EM에서는 각 성분의 가중치를 책임도 합을 n으로 나눈 값으로, 분산을 새 평균에서의 편차 제곱을 책임도로 가중한 평균으로 갱신할 수 있습니다. 식으로 쓰면 Nₖ=Σᵢ rᵢₖ일 때 πₖ=Nₖ/n, μₖ=Σᵢ rᵢₖxᵢ/Nₖ, σₖ²=Σᵢ rᵢₖ(xᵢ−μₖ)²/Nₖ입니다.

k-means(ML09·1)와 비교하면 구조가 같습니다. k-means의 배정 단계는 각 점을 한 중심에 0 또는 1로 넣는 딱딱한 배정이고, EM의 E 단계는 0과 1 사이 책임도로 나누어 넣는 부드러운 배정입니다. 모든 성분의 분산을 같게 두고 0으로 줄여 가면 책임도가 가장 가까운 평균 쪽으로 0·1이 되어 k-means와 같아집니다. GMM은 성분마다 퍼짐과 비중이 달라도 되므로 크기와 모양이 다른 군집을 표현할 수 있습니다.

좋아진 훈련 우도가 말해 주는 범위를 확인한다

실행 예제

import numpy as np

x = np.array([0.0,2.0,4.0])
means = np.array([0.0,4.0])
variance = 4.0

def weighted_density(center):
    return 0.5 * np.exp(-0.5 * (x[:,None] - center)**2 / variance) / np.sqrt(2*np.pi*variance)

weights = weighted_density(means)
responsibility = weights / weights.sum(axis=1, keepdims=True)
updated = (responsibility.T @ x) / responsibility.sum(axis=0)
print("left responsibility:", responsibility[:,0].round(4).tolist())
print("updated means:", updated.round(4).tolist())
before = np.log(weights.sum(axis=1)).sum()
after = np.log(weighted_density(updated).sum(axis=1)).sum()
print(f"log-likelihood: {before:.4f} -> {after:.4f}")

실행 결과

left responsibility: [0.8808, 0.5, 0.1192]
updated means: [0.9845, 3.0155]
log-likelihood: -6.4687 -> -5.9755

정확한 E 단계와 M 단계는 같은 모형 아래 관측 자료의 우도를 낮추지 않습니다. 여기서는 관측을 독립으로 두고 밀도의 로그를 합합니다. 예의 로그우도는 약 −6.4687에서 −5.9755가 됐습니다. 여러 시작점이 서로 다른 결과로 이어질 수 있으므로 전역 최적이라는 보장은 없습니다. 분산도 제한 없이 추정하면 한 성분이 점 하나로 수축하며 밀도가 지나치게 높아질 수 있습니다. 분산 하한이나 정규화 등 적합 조건을 기록합니다.

성분 수를 늘리면 훈련 로그우도는 거의 항상 올라가므로, 로그우도만으로 성분 수를 고를 수 없습니다. 모수 개수에 벌점을 주는 BIC = −2·로그우도 + (모수 개수)·ln n이나 AIC = −2·로그우도 + 2·(모수 개수)를 성분 수마다 계산해 가장 작은 값을 고르거나, 검증 자료의 로그우도로 비교합니다. scikit-learn 1.9의 GaussianMixture는 기본값이 n_components=1, covariance_type='full', n_init=1, init_params='kmeans'(k-means 결과로 시작), 공분산 대각에 더하는 하한 reg_covar=1e-6이고, bic(X), aic(X), 책임도를 주는 predict_proba(X)를 제공합니다.

왜 그럴까?

책임도 0.88이 나오면 실제로 어떤 과정에서 나왔는지 확정할 수 있을까요?

모범 답 보기

현재 정규 혼합 모형이 주는 조건부 확률입니다. 성분의 수, 분포 형태, 초기값이 바뀌면 답도 달라질 수 있고 실제 과정 이름이 자동으로 확인되는 것은 아닙니다.
