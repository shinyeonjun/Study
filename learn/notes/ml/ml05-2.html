다항 softmax, 가장 큰 로짓과 교차엔트로피

문의 종류 하나를 배달, 결제, 계정 중에서 고르려 합니다. 세 점수를 각각 따로 시그모이드로 바꾸면 합이 1일 필요가 없습니다. 함께 정규화해 한 범주의 확률분포를 만드는 계산을 봅니다.

이 장을 읽고 나면

  • 로짓에서 softmax 확률 분포를 계산한다.
  • softmax의 argmax와 클래스 경계를 설명한다.
  • 최댓값을 뺀 로짓으로 다항 교차엔트로피를 안정적으로 구한다.

서로 배타적인 클래스의 확률 합을 1로 만든다

하나의 문의에 정확히 한 범주 A, B, C만 붙인다고 둡니다. 모형은 입력마다 로짓 z=(z_A,z_B,z_C)를 냅니다. softmax는 각 로짓에 지수를 적용한 뒤 pᵢ=exp(zᵢ)/Σⱼ exp(zⱼ)로 나눕니다. 확률은 양수이고 합은 1입니다. 로짓이 (ln 4, ln 2, 0)이면 다음과 같습니다.

로짓을 클래스마다 따로 선형식으로 두고 z_k=b_k+w_kᵀx에 softmax를 적용한 모형이 다항 로지스틱 회귀(softmax 회귀)입니다. 클래스가 둘이면 p₁=exp(z₁)/(exp(z₀)+exp(z₁))=1/(1+exp(−(z₁−z₀)))이므로, 로짓의 차이 z₁−z₀에 시그모이드를 쓴 앞 장의 이진 로지스틱 회귀와 같습니다. 모든 로짓에 같은 값을 더해도 확률이 같으므로(마지막 절에서 확인합니다) 한 클래스의 로짓을 0으로 고정해도 표현력은 줄지 않습니다. 그림의 C 로짓이 0인 것도 이런 기준 클래스로 읽을 수 있습니다.

서로 배타적이지 않은 여러 라벨을 붙이는 문제는 다릅니다. 예를 들어 한 글에 결제와 배달 문의가 동시에 있을 수 있다면, 각 라벨의 포함 여부를 별도 이진 문제처럼 다룰 수 있습니다.

가장 큰 로짓이 어느 클래스인지 확인한다

지수 함수는 증가하고 분모가 모든 클래스에서 같으므로 큰 로짓은 큰 확률을 냅니다. 가장 큰 값의 위치인 argmax는 로짓과 확률에서 같습니다. 어느 클래스를 예측할지만 필요하면 순위만 비교해도 됩니다.

입력 x에 대한 로짓이 (−x,1,x)라면 x<−1에서 A, −1<x<1에서 B, x>1에서 C가 가장 큽니다. x=±1에서는 동률입니다. 두 로짓이 같은 점도 두 값이 다른 모든 로짓보다 높거나 같아야 실제 예측 경계가 됩니다. 예를 들어 x=0에서는 A와 C가 동률이지만 둘 다 B보다 작습니다. 로짓이 x의 선형식이면 두 클래스의 경계 z_j=z_k는 (b_j−b_k)+(w_j−w_k)ᵀx=0이라는 직선(고차원에서는 초평면)이므로, 다항 로지스틱 회귀의 결정 경계는 선형입니다.

실제 클래스에 준 확률로 손실을 낸다

관측 라벨이 B이면 정답 분포를 (0,1,0)으로 둡니다. 다항 교차엔트로피는 −ln p_B이고 위 예에서 ln(7/2)≈1.2528 나트입니다. 클래스가 맞았는지만 보는 정확도와 달리, 교차엔트로피는 실제 클래스에 준 확률의 크기도 반영합니다.

모든 로짓에 같은 값을 더하면 지수의 공통 배수가 약분되므로 확률은 바뀌지 않습니다. 큰 양의 로짓의 지수를 계산하는 대신 최대 로짓을 먼저 뺍니다. 이동한 값을 uᵢ=zᵢ−max(z)라 하면 로그 손실은 ln(Σ exp(uᵢ))−u_y입니다. 가장 큰 u가 0이므로 분모에는 적어도 1이 있습니다. 실제 클래스의 확률이 계산에서 0으로 반올림되어도 로짓으로 손실을 구할 수 있습니다.

실행 예제

from math import exp, log

def softmax_and_loss(logits, target):
    peak = max(logits)
    shifted = [z - peak for z in logits]
    exponents = [exp(u) for u in shifted]
    total = sum(exponents)
    probability = [v / total for v in exponents]
    return probability, log(total) - shifted[target]

normal = [log(4), log(2), 0]
for name, logits in [("original", normal), ("shifted", [z+1000 for z in normal])]:
    p, loss = softmax_and_loss(logits, 1)
    print(f"{name}: p={[round(q,4) for q in p]}, B loss={loss:.4f}")
p, loss = softmax_and_loss([1000,0,-1000], 2)
print(f"extreme: C probability={p[2]:.1f}, C loss={loss:.1f}")

실행 결과

original: p=[0.5714, 0.2857, 0.1429], B loss=1.2528
shifted: p=[0.5714, 0.2857, 0.1429], B loss=1.2528
extreme: C probability=0.0, C loss=2000.0

왜 그럴까?

확률의 순위만 맞히는 모형을 교차엔트로피로 비교하면 무엇을 더 구별할 수 있을까요?

정답에 가장 높은 확률을 줘 맞힌 두 모형도 그 확률이 0.45와 0.95라면 손실이 다릅니다. 확률 자체를 비교할 때에는 보정도 따로 확인합니다.
