ML15·2

교환가능한 보정 자료로 분할 적합 예측구간 만들기

예측값이 10이라는 숫자만으로는 새 관측값이 얼마나 틀릴지 알기 어렵습니다. 연습에서 얻은 오차 크기를 줄 세워, 새 관측을 일정 비율 이상 포함하는 구간을 계산합니다.

이 장을 읽고 나면

  • 모형을 맞춘 표본과 오차를 보정할 표본을 분리한다.
  • 절대오차의 순위로 유한표본 포괄률을 증명한다.
  • 표본이 작아 경계가 무한해지는 경우와 분포 이동의 한계를 설명한다.

모형을 고정한 뒤 오차를 한 줄로 세운다

모형 f는 별도 훈련 자료에 맞춘 뒤 고정합니다. 그때 쓰지 않은 n개의 보정 관측 (Xᵢ,Yᵢ)에서 점수 Sᵢ=|Yᵢ−f(Xᵢ)|를 구합니다. 점수는 예측이 실제 값에서 떨어진 거리입니다. 새 입력 x에 대해 작은 오차와 큰 오차 중 어디까지 허용할지 이 보정 점수에서 정합니다. 이 방식은 표본을 나누는 분할 적합 예측(split conformal prediction)의 한 예입니다.

오류 목표를 0<α<1로 두고, 순위 k=⌈(n+1)(1−α)⌉를 계산합니다. 보정 점수 중 작은 쪽에서 k번째 값 q를 사용해 새 예측 구간을 [f(x)−q, f(x)+q]로 정합니다. k=n+1이면 보정 점수에 그런 순위가 없어 q=+∞로 둡니다. 표본 수가 너무 작으면 정해 둔 포괄률을 보장할 유한 너비를 이 규칙으로 고를 수 없다는 뜻입니다.

교환가능성이 있으면 새 관측의 순위가 균등하다

훈련 결과를 고정한 조건에서 보정 n개와 새 관측 하나가 교환가능하다고 가정합니다. 즉 순서를 섞어도 그 결합분포가 같습니다. 각 사례에 같은 함수로 점수를 매기면 점수열에서도 조건이 유지됩니다. 서로 같은 점수가 있을 때 각 점수와 독립인 같은 연속분포의 난수를 점수마다 독립적으로 붙여 동점을 가르면 n+1개의 순위 중 어느 자리에도 새 점수가 놓일 확률이 같습니다.

새 점수의 순위가 k 이하이면 관측 Y가 구간에 들어갑니다. k≤n일 때 대우로 보이면, 새 점수가 보정의 k번째 값 q보다 크다면 q 이하인 보정 점수가 적어도 k개 있으므로 새 점수의 순위는 k+1 이상입니다. 따라서 {순위 ≤ k} ⊂ {새 점수 ≤ q}이고, 무작위 동점 처리 아래 순위가 균등하므로

P(Y ∈ 구간) ≥ P(순위 ≤ k) = k/(n+1) ≥ 1−α

입니다. 마지막 부등식은 k=⌈(n+1)(1−α)⌉의 정의에서 나옵니다. 구간을 ≤로 닫았기 때문에 동점이 있어도 이 하한은 유지됩니다. 점수에 동점이 생길 확률이 0이면(연속분포) 포괄률은 정확히 k/(n+1)이고, 따라서 1−α+1/(n+1)보다 작습니다. k=n+1에서는 구간이 전체 실수선이라 포괄 확률이 1입니다.

여기서 일반적인 분위수 함수가 보간한 값이나 표본 최대값을 임의로 쓰면 유한표본 순위 계산이 바뀝니다. 보장이 유효하면 기대하는 것은 보정 표본과 새 표본을 반복할 때 전체 포괄률입니다. 관측 시기, 집단, 입력값마다 같은 포괄률을 약속하는 것은 아닙니다. 새 시점의 관측 과정이 크게 바뀌면 교환가능성을 주장할 근거가 약해집니다. 결과를 보고할 때 집단별 포괄과 구간 너비를 함께 살펴봅니다.

가능한 마지막 순위를 직접 대조한다

from fractions import Fraction as F
from math import ceil, inf

def cutoff(scores, alpha):
    k = ceil((len(scores)+1)*(1-alpha))
    return k, sorted(scores)[k-1] if k<=len(scores) else inf

for error in (F(1,5), F(1,10)):
    k, q = cutoff([1,2,2,4], error)
    print(k, q, (10-q,10+q))

# 서로 다른 점수 다섯 개에서 하나씩 새 관측 역할을 맡긴다.
scores = [1,2,3,4,5]
covered = 0
for i, new in enumerate(scores):
    cal = scores[:i]+scores[i+1:]
    covered += new <= cutoff(cal,F(1,5))[1]
print(covered, len(scores))
assert covered == 4
