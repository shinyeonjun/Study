Jensen 부등식으로 EM이 우도를 낮추지 않음을 보이기

값이 올라가는 것을 몇 번 봤다고 매번 상승한다는 증명이 되지는 않습니다. 로그 안의 합을 다룰 수 있는 하한을 만들고, E 단계와 M 단계가 각각 움직이는 대상을 구분합니다.

이 장을 읽고 나면

  • Jensen 하한과 로그우도 사이의 차를 KL 발산으로 표현할 수 있다.
  • EM의 한 번 갱신에서 관측 로그우도가 감소하지 않음을 증명할 수 있다.
  • 초기값과 식별 가능성이 우도 증가 보장과 별개인 이유를 설명할 수 있다.

합 안에 숨은 변수를 넣으면 로그가 붙는다

관측 한 건 x와 잠재 소속 z가 있는 모형을 pθ(x,z)라고 씁니다. 혼합모형의 관측 로그우도는 ℓ(θ)=log Σzpθ(x,z)입니다. 독립인 자료가 여러 건이면 관측마다 이 로그를 구해 더합니다. 합의 로그를 각 성분 로그의 합으로 바꿀 수는 없습니다.

여기서는 고려하는 모든 성분의 결합값이 양수이고, q(z)도 양수인 분포라고 둡니다. 합 안의 각 항에 q(z)/q(z)를 곱하면 log Σzq(z)[pθ(x,z)/q(z)]입니다. 이제 로그는 아래로 굽은 오목 함수이므로, Jensen 부등식은 가중 평균에 로그를 한 값이 가중 로그 평균 이상임을 말합니다.

log pθ(x) ≥ F(q,θ) = Σzq(z) log [pθ(x,z)/q(z)]

예를 들어 무게가 반씩인 1과 4의 평균은 2.5입니다. 평균에 로그를 취한 log 2.5는 (log 1+log 4)/2=log 2보다 큽니다. 같은 부등식을 p/q에 적용한 것입니다.

두 값의 차를 쓰면 등호가 보인다

pθ(x,z)=pθ(x)pθ(z|x)를 하한에 넣습니다. Σq=1이라 log pθ(x)는 그대로 남습니다. 나머지는 Σq log[pθ(z|x)/q(z)]입니다. 따라서

log pθ(x) − F(q,θ) = Σz q(z) log [q(z)/pθ(z|x)] = KL(q ‖ pθ(z|x)) ≥ 0

입니다. KL 발산은 두 확률표가 얼마나 다른지 재는 값이며, 양수인 분포에서 둘이 같은 경우에만 0입니다. 따라서 q를 현재 θ에서의 사후확률로 고르면 하한이 바로 참 로그우도에 닿습니다. 이 선택이 E 단계입니다.

하한을 올리면 새 로그우도도 내려가지 않는다

t번째 매개변수를 θᵗ, 그때 구한 사후분포를 qᵗ라 합시다. M 단계에서는 qᵗ를 그대로 둔 채 θ를 바꾸어 F(qᵗ,θ)를 최대화합니다. qᵗ를 고정하면 −Σqᵗ log qᵗ는 θ에 무관합니다. 결국 기대한 완전자료 로그우도 Σqᵗ log pθ(x,z)만 최대화하면 됩니다. 그래서 앞 장에서 정수 소속 개수 대신 기대 개수를 사용했습니다.

새 θ를 θᵗ⁺¹로 쓰면, 다음의 사슬이 성립합니다.

ℓ(θᵗ⁺¹) ≥ F(qᵗ,θᵗ⁺¹) ≥ F(qᵗ,θᵗ) = ℓ(θᵗ)

첫째는 어떤 q에서도 맞는 하한, 둘째는 M의 증가, 마지막은 이전 θ에서 E가 얻은 등호입니다. 독립 관측이 여러 건이면 각 관측의 하한을 더해 같은 결론을 얻습니다. 정확한 M 단계 대신 하한을 적어도 줄이지 않는 갱신을 사용해도 이 부등식은 남습니다.

모수 값이 달라도 관측 분포가 같을 수 있다

두 번 시행의 성공 횟수를 관측하는 혼합모형에서, 무작위 성분의 성공률을 p로 놓으면 각 횟수의 확률은 E[(1−p)²], 2E[p(1−p)], E[p²]입니다. 따라서 이 관측분포는 E[p]와 E[p²]로 정해집니다. (π,pA,pB)가 (1/2,1/4,3/4)인 경우와 (4/13,1/8,2/3)인 경우 모두 E[p]=1/2, E[p²]=5/16입니다. 예를 들어 두 번째의 제곱 평균은 (4/13)(1/64)+(9/13)(4/9)=5/16입니다. 그래서 두 모수의 관측 확률은 똑같이 (5/16,3/8,5/16)입니다. 성분 이름을 바꾼 관계가 아니므로, 이름을 고정해도 시행 두 번의 관측분포만으로 모수를 하나로 정할 수 없는 예입니다.

서로 다른 초기값에서 증명을 확인한다

앞 장의 기록 (0,0,1,2)을 다시 씁니다. 별개의 두 초기화를 사용합니다. 첫째는 pA, pB를 0.25와 0.75로 나누고, 둘째는 둘 다 0.5로 설정합니다. 둘째 경우 성분의 조건부 분포가 같아 책임도는 모든 기록에서 π=1/2입니다. 두 성공률이 동일하게 전체 성공률 3/8로 바뀐 뒤 둘 다 같은 값에 머뭅니다.

from math import comb, log

data = (0, 0, 1, 2)
def probability(k, p):
    return comb(2, k) * p**k * (1-p)**(2-k)

def terms(theta, k):
    pi, p_a, p_b = theta
    return (1-pi)*probability(k,p_a), pi*probability(k,p_b)

def observed(theta):
    return sum(log(sum(terms(theta,k))) for k in data)

def step(theta):
    resp = []
    for k in data:
        a,b = terms(theta,k)
        resp.append(b/(a+b))
    mass = sum(resp)
    success = sum(k*r for k,r in zip(data,resp))
    return (mass/len(data), (sum(data)-success)/(2*(len(data)-mass)), success/(2*mass))

for label,start in (("서로 다르게", (.5,.25,.75)), ("같게", (.5,.5,.5))):
    theta = start
    history = [observed(theta)]
    for _ in range(8):
        theta = step(theta)
        history.append(observed(theta))
    assert all(b >= a - 1e-12 for a,b in zip(history,history[1:]))
    print(label, "로그우도:", " / ".join(f"{history[k]:.4f}" for k in (0,1,8)))
    print("마지막 파라미터:", " / ".join(f"{x:.4f}" for x in theta))

실행 결과

서로 다르게 로그우도: -4.4703 / -4.1968 / -4.1589
마지막 파라미터: 0.3976 / 0.1064 / 0.7820
같게 로그우도: -4.8520 / -4.5994 / -4.5994
마지막 파라미터: 0.5000 / 0.3750 / 0.3750

두 경로 모두 로그우도는 줄지 않았지만 도달한 값이 다릅니다. 같은 모형의 두 성분을 바꾸고 π를 1−π로 바꿔도 관측분포는 같습니다. 더 단순하게, 기록마다 베르누이 시험을 한 번만 했다면 관측 성공 확률은 (1−π)pA+πpB 한 숫자뿐입니다. (π,pA,pB)=(0.5,0.25,0.75)과 (0.5,0.5,0.5)가 같은 관측분포를 줍니다. 관측 우도가 높은 것에서 실제 보이지 않는 성분의 값이 유일하다고 결론 내릴 수 없습니다.

한눈에 정리

조건 또는 단계역할
Jensen 하한ℓ−F는 q와 사후분포 사이 KL이다.
E현재 매개변수에서 하한을 우도에 맞춘다.
M고정한 q에서 하한을 올린다.
초기값과 식별 가능성우도 감소 방지의 증명으로 해결되지는 않는다.
