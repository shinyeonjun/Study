ML03·2

혼동행렬로 보고 정밀도·재현율 계산하기

지연을 찾는 모델이 경보를 다섯 번 냈습니다. 그중 실제 지연은 세 번이었습니다. 전체 지연도 세 번이었다면 모두 찾았지만, 실제 지연이 네 번이었다면 하나를 놓쳤습니다. 두 계산은 같은 세 건을 서로 다른 기준으로 나눕니다.

이 장을 읽고 나면

  • 양성 클래스를 정하고 혼동행렬의 TP·FP·FN·TN을 읽는다.
  • 정확도·정밀도·재현율·F1을 계산하고 정의가 불가능한 경우를 구별한다.
  • 임계값과 클래스 불균형이 점수에 주는 영향을 해석한다.

지연을 양성으로 정하고 네 종류를 센다

교육용 배송 지연 문제에서 찾으려는 경우를 양성(positive)이라 하고 지연을 1로 둡니다. 반대인 정상을 음성 0으로 둡니다. 평가는 실제 정답과 모델의 예측을 비교합니다.

기호무엇을 센 값인가실제 상황
TP · 참양성실제 양성, 예측 양성지연을 찾아 경보
FP · 거짓양성실제 음성, 예측 양성정상인데 경보
FN · 거짓음성실제 양성, 예측 음성지연을 놓침
TN · 참음성실제 음성, 예측 음성정상이며 경보 없음

예측과 정답을 조합해 네 건수를 한 표에 둔 것이 혼동행렬입니다. 여기서는 행을 실제, 열을 예측으로 둡니다. 다른 책이나 코드에서도 실제와 예측의 축 표시, 양성의 위치를 확인하세요. scikit-learn이 이진 라벨 [0,1] 순서로 기본 출력한 표의 윗줄은 음성이므로, 아래 그림과는 행과 열의 순서가 각각 반대입니다.

같은 TP에서 서로 다른 분모를 쓴다

그림에서 전체는 10건입니다. 예측을 맞힌 건수 TP+TN=3+4=7을 전체로 나눈 값 0.70이 정확도입니다.

경보를 검토하는 입장에서 경보 5건 중 실제 지연은 3건입니다. 양성 예측을 분모에 둔 정밀도는 TP/(TP+FP)=3/5=0.60입니다. 실제 지연들을 놓치지 않았는지 볼 때는 실제 지연 4건을 분모로 둡니다. 재현율은 TP/(TP+FN)=3/4=0.75이며, 참양성률이라고도 합니다.

두 지표를 함께 보려면 F1을 쓸 수 있습니다. 두 값이 양수일 때 정밀도와 재현율의 조화평균 2·정밀도·재현율/(정밀도+재현율)입니다. 건수로는 2TP/(2TP+FP+FN)=6/9≈0.667입니다. TP가 같을 때 거짓 경보나 누락이 늘면 분모가 커져 점수가 낮아집니다.

분모가 0일 때

  • TP+FP=0이면 경보를 한 번도 내지 않았으므로 정밀도를 분수로 계산할 수 없습니다.
  • TP+FN=0이면 실제 지연 사례가 없으므로 재현율을 계산할 수 없습니다.
  • 2TP+FP+FN=0이면 F1도 건수 식으로 정의되지 않습니다. 건수 식의 분모가 양수이고 TP가 0이면 건수 식으로 F1=0입니다(이때 조화평균 식은 정밀도나 재현율이 정의되지 않거나 0이라 쓸 수 없습니다).

라이브러리가 정의 불가인 결과를 경고와 함께 0으로 내기도 합니다. 예를 들어 scikit-learn 1.9.1의 precision_score는 기본값 zero_division="warn"이라, 양성 예측이 하나도 없으면 경고를 띄우고 0.0을 돌려줍니다. 보고서에는 사용한 규칙, 혼동행렬, 실제 지연 건수와 경보 건수를 함께 적습니다.

임계값을 바꾸면 들어오는 건수를 다시 센다

모델이 지연일수록 큰 점수를 내면 임계값 이상인 주문에 경보를 냅니다. 예제의 0.70에서는 TP=3, FP=2, FN=1, TN=4입니다. 0.50으로 낮추면 지연 하나(0.55)와 정상 하나(0.63)가 경보에 추가됩니다. 그래서 TP=4, FP=3, FN=0, TN=3으로 바뀝니다. 재현율이 0.75에서 1로 높아지는 동안, 정밀도는 0.60에서 4/7≈0.571로 낮아졌습니다.

한 평가 자료에서 임계값을 낮추면 양성 예측에 새 관측만 추가됩니다. 실제 양성이 있는 경우 재현율은 그대로이거나 높아집니다. 정밀도는 새로 추가된 주문 가운데 지연이 얼마나 많은지에 따라 달라집니다.

실행 예제

from collections import Counter

scores = [0.96, 0.91, 0.86, 0.80, 0.73, 0.63, 0.55, 0.44, 0.37, 0.21]
truth = [1, 0, 1, 0, 1, 0, 1, 0, 0, 0]

def ratio_text(num, den):
    return f"{num / den:.3f}" if den else "undefined"

for threshold in [0.70, 0.50, 1.00]:
    predicted = [int(score >= threshold) for score in scores]
    counts = Counter(zip(truth, predicted, strict=True))
    tp, fp = counts[1, 1], counts[0, 1]
    fn, tn = counts[1, 0], counts[0, 0]
    print(f"threshold={threshold:.2f}: TP={tp}, FP={fp}, FN={fn}, TN={tn}")
    precision = ratio_text(tp, tp + fp)
    recall = ratio_text(tp, tp + fn)
    f1 = ratio_text(2 * tp, 2 * tp + fp + fn)
    print(f"precision={precision}, recall={recall}, F1={f1}")

실행 결과

threshold=0.70: TP=3, FP=2, FN=1, TN=4
precision=0.600, recall=0.750, F1=0.667
threshold=0.50: TP=4, FP=3, FN=0, TN=3
precision=0.571, recall=1.000, F1=0.727
threshold=1.00: TP=0, FP=0, FN=4, TN=6
precision=undefined, recall=0.000, F1=0.000

드문 지연을 찾을 때 어떤 점수를 볼까

주문 1,000건 중 지연이 10건인 불균형 자료를 생각합니다. 항상 정상이라고 하면 정상 990건을 맞혀 정확도 99%가 됩니다. 지연은 한 번도 찾지 못해 재현율 0이고, 경보가 없어 정밀도가 정의되지 않습니다.

왜 그럴까?

같은 정확도 70%인 두 임계값 중 하나를 골라야 한다면 무엇을 더 확인할까요?

모범 답 보기

지연을 놓치면 어떤 문제가 생기는지, 정상 주문을 점검할 여력이 얼마나 있는지 봅니다. 예제의 0.50은 지연을 모두 찾지만 거짓 경보를 한 건 더 냅니다. 검증 자료에서 비용이나 감당 가능한 경보 수와 함께 선택합니다.

비용에 맞춘 임계값은 검증에서 고릅니다. 테스트에서 그 값을 고정해 실제 경보 수와 지연 누락 수를 보고합니다. F1은 TP·FP·FN을 같이 보지만 업무마다 서로 다른 비용을 직접 나타내는 지표는 아니므로, 따로 지정한 기준이 있다면 함께 확인합니다.
