ML01·1

한 행의 뜻과 예측할 값부터 정하기

주문이 들어올 때 배송에 몇 분이 걸릴지 알고 싶습니다. 접수 시점에 알 수 있는 정보와 배송이 끝나야 알 수 있는 정보가 한 표에 있다면, 학습에 들어가기 전에 두 정보를 구분해야 합니다.

이 장을 읽고 나면

  • 관측 단위와 예측 시점을 정해 X와 y를 구성한다.
  • 같은 주문 기록으로 회귀 문제와 분류 문제를 정의한다.
  • 과거 자료에서 규칙을 얻는 학습과 새 입력에 규칙을 적용하는 추론을 구별한다.

한 주문을 한 행으로 만들고 열의 역할을 정한다

이 장의 표는 계산을 위한 합성 자료입니다. 접수 시점에 주문 한 건의 배송 소요 시간을 예측합니다. 그래서 관측 단위는 주문 한 건입니다. 한 주문의 상자가 세 개여도 목표 시간을 한 번만 예측한다면 주문 한 행에 상자 수 3을 둡니다. 같은 기사나 같은 거점에서 주문 여러 건이 들어왔을 수 있으므로, 주문이 네 행이라는 사실만으로 행들이 독립이라고 할 수는 없습니다.

새 주문에도 접수 즉시 얻을 수 있는 거리와 상자 수를 특성(feature)으로 씁니다. 특성을 행과 열로 묶은 배열을 X라고 합니다. 맞히려는 답인 배송 소요 시간은 목표(target)이며, 이 예의 한 행에 답을 하나씩 모은 배열을 y라고 합니다. 완료된 자료에서는 X와 y를 주문 ID로 맞춥니다.

거리와 상자 수가 열 두 개라 X는 (4, 2) 모양입니다. 일반적으로 샘플이 n개, 특성이 d개면 X는 (n, d), y는 길이 n입니다. scikit-learn 문서는 이 모양을 (n_samples, n_features)라고 적습니다. X[2]는 세 번째 주문 A3의 거리와 상자 수, y[2]는 같은 주문의 완료까지 걸린 분입니다. ML 문맥에서 샘플 하나는 관측값 또는 행 하나를 가리킵니다. 통계 문맥의 표본은 여러 관측값을 모은 자료 전체를 가리킬 때가 있습니다.

숫자를 맞힐지 범주를 맞힐지 결정한다

과거 입력과 정답의 짝 (X, y)를 주고 새 입력의 정답을 예측하도록 규칙을 정하는 방식을 지도학습이라고 합니다. 숫자량을 예측하는 회귀와 범주를 예측하는 분류가 대표적입니다.

질문목표 예시학습 문제
배송에 몇 분이 걸리나?12, 16, 24, 28분회귀
20분을 초과하는가?정상, 정상, 지연, 지연이진 분류
어떤 배송 유형인가?방문, 보관함, 지정 장소다중 클래스 분류

20분을 초과하면 지연 1, 그 이하면 정상 0으로 표시할 수 있습니다. 0과 1은 두 범주를 구분하는 번호입니다. 분류인지 회귀인지를 정하려면 숫자로 저장했는지보다 그 숫자가 양을 뜻하는지 범주를 뜻하는지를 확인합니다. 15분과 19분은 회귀에서는 다른 정답이지만 이 분류 기준에서는 둘 다 정상입니다.

왜 그럴까?

같은 주문을 회귀로 풀 때와 지연 여부 분류로 풀 때 왜 틀렸다는 뜻이 달라질까요?

모범 답 보기

회귀에서는 18분을 20분으로 예측하면 2분 오차입니다. 지연 여부의 기준이 20분 초과라면 두 값은 모두 정상입니다. 선택한 목표가 평가에서 보려는 차이를 정합니다.

학습에서 규칙을 얻고 추론에서 적용한다

가장 단순한 예부터 봅니다. 거리가 3 km 이하면 가까운 주문, 3 km를 초과하면 먼 주문으로 나누는 규칙을 먼저 정합니다. 이전 자료에 가까운 주문이 12, 16분, 먼 주문이 24, 28분 걸렸습니다. 가까운 그룹의 평균은 14분, 먼 그룹의 평균은 26분입니다. 거리를 구간으로 나누는 기준은 이 예에서 사람이 정했고, 각 구간에서 쓸 예상 시간은 자료에서 얻었습니다.

학습(fit)
과거 주문의 거리와 정답 소요 시간으로 그룹별 평균을 계산해 저장합니다.
추론(predict)
거리 5 km인 새 주문을 먼 그룹에 넣고 저장한 26분을 출력합니다. 실제 소요 시간은 완료 후 평가할 때 얻습니다.

실행 예제

from statistics import mean

features = [(1, 1), (2, 2), (4, 1), (6, 3)]
targets = [12, 16, 24, 28]

def route(distance):
    return "near" if distance <= 3 else "far"

groups = {"near": [], "far": []}
for (distance, box_count), target in zip(features, targets):
    groups[route(distance)].append(target)
fitted = {name: mean(values) for name, values in groups.items()}

new_distance = 5
print(f"training shape: ({len(features)}, {len(features[0])})")
print(f"near={fitted['near']:.1f} min, far={fitted['far']:.1f} min")
print(f"new order: {fitted[route(new_distance)]:.1f} min")

실행 결과

training shape: (4, 2)
near=14.0 min, far=26.0 min
new order: 26.0 min

표에는 후보 특성이 두 열 있지만 이 규칙은 거리만 씁니다. 이 계산이 잘 작동했는지 알기 위해서는 학습할 때 못 본 주문을 예측하고 처음 정한 목표로 평가합니다. 실제 문제를 정할 때는 입력 열의 확보 시각과 예측을 사용할 대상도 함께 적어야 합니다.
