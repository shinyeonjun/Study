ML10·2

튜닝을 분리하고 학습곡선으로 다음 실험 읽기

어떤 모델이 지금의 검증에서 가장 점수가 낮았다고 해서 그 점수를 최종 성능으로 쓰면 선택 과정의 영향을 놓칩니다. 평가를 남겨 둔 뒤, 훈련 데이터를 어느 정도 모으면 격차가 줄어들지 그래프로 봅니다.

이 장을 읽고 나면

  • 교차검증에서 하이퍼파라미터를 고르고 최종 평가를 분리한다.
  • 중첩 교차검증의 안쪽과 바깥쪽 역할을 설명한다.
  • 학습곡선과 검증곡선의 가로축을 읽고 결론의 한계를 확인한다.

같은 분할과 같은 지표로 후보를 비교한다

나무의 최대 깊이, 정규화 강도, 이웃 수처럼 학습 방식의 설정을 하이퍼파라미터라고 합니다. 개발 자료를 가른 뒤 같은 기준으로 각 후보를 여러 번 검증해 선택합니다. 합성 예에서 세 회차의 검증 오차가 A는 [2,5,4], B는 [3,3,3]입니다. 오차를 낮추는 목표와 세 회차 동등 가중을 먼저 정하면 평균 3인 B를 고릅니다.

현재 회차의 변환과 모형은 현재 훈련 부분에서만 배웁니다. 새 거점과 시간 순서를 구분하는 등 실제 목적에 맞는 분할을 사용합니다. 후보가 많을수록 검증의 우연한 특징에 맞는 후보를 골랐을 가능성도 커집니다. 선택이 끝난 다음 따로 남긴 테스트에서 한 번 점검합니다.

안쪽 검증을 써도 바깥 평가는 손대지 않는다

중첩 교차검증에서는 바깥 분할의 훈련 자료 안에서만 다시 안쪽 훈련과 검증을 나눕니다. 안쪽에서 설정을 고르고, 그 절차에 참가하지 않은 바깥 쪽 자료에서 시험합니다. 여러 바깥 구간에 대해 반복하면 현재 자료와 분할에서 설정을 골라 재학습하는 절차의 성능을 평가할 수 있습니다.

바깥 결과를 다시 보고 최종 후보 목록을 바꾸면 바깥의 독립적 역할도 약해집니다. 각 회차 결과는 훈련 부분을 공유할 수 있으므로 회차 수를 독립 실험 수인 것처럼 보고 단순히 신뢰구간을 만드는 것은 주의가 필요합니다. 결과에는 회차의 원자료 단위, 사용한 지표, 어떤 기준으로 선택했는지 같이 남깁니다.

훈련 행 수가 늘 때 오차의 간격을 읽는다

학습곡선은 모형과 적합 절차를 정해 두고 훈련 크기를 바꾸면서 훈련·검증 오차를 봅니다. 그림에서 훈련을 10개에서 80개로 늘리자 검증 오차가 8에서 3으로 줄고, 두 오차의 격차는 7에서 0.5가 됐습니다. 이러한 모습은 같은 방식으로 모은 자료를 더 쓸 때 성능을 확인해 볼 근거가 됩니다.

두 오차가 모두 높은 수준에서 나란히 멈추는 경우에는 단순한 모형이나 부족한 특성, 큰 관측 잡음 등 여러 가능성을 살핍니다. 자료 크기를 고정하고 최대 깊이 같은 설정값을 가로축에 놓으면 검증곡선이라고 합니다. 훈련 크기와 설정을 하나의 곡선에서 동시에 바꾸면 어떤 변화가 오차를 움직였는지 읽기 어렵습니다.

실행 예제

from statistics import mean

scores = {"A": [2, 5, 4], "B": [3, 3, 3]}
print("CV", {name: round(mean(losses), 3) for name, losses in scores.items()})
print("chosen:", min(scores, key=lambda name: mean(scores[name])))
sizes = [10, 20, 40, 80]
train = [1, 1.5, 2, 2.5]
validation = [8, 6, 4, 3]
for n, train_loss, val_loss in zip(sizes, train, validation, strict=True):
    print(f"size={n}: validation-training={val_loss - train_loss:.1f}")

실행 결과

chosen: B
size=10: validation-training=7.0
size=20: validation-training=4.5
size=40: validation-training=2.0
size=80: validation-training=0.5

왜 그럴까?

검증 성능을 보는 중에 나무 수나 학습을 멈추는 시점을 고릅니다. 그 검증 점수를 최종 점수로 봐도 될까요?
