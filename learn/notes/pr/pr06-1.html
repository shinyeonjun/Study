확률 · PR06 연속분포

PR06·1

확률밀도·누적확률·분위수

같은 응답 시간도 재는 단위에 따라 다른 숫자로 기록됩니다. 시간을 연속적인 양으로 놓고, 한 구간에 확률이 얼마나 모이는지 면적으로 계산해 봅니다.

이 장을 읽고 나면

  • 연속분포에서는 한 점의 밀도와 구간의 확률을 구분한다.
  • 밀도를 적분해 누적분포함수를 만들고, 누적값의 차이로 구간 확률을 구한다.
  • 균등분포의 확률을 길이의 비율로 계산하고, 누적확률에서 분위수를 찾는다.

측정값이 한 구간에 들어갈 확률을 구한다

서비스 응답을 기다리는 시간이 0.31초인지 0.312초인지는 측정 정밀도에 따라 달라집니다. 대기 시간을 실수로 모형화하면, 한 값에 확률을 배정하는 이산형 문제와 접근이 달라집니다. 예를 들어 0.30초에서 0.32초 사이에 들어올 확률을 묻고, 그 구간 위에서 확률이 얼마나 쌓이는지 계산합니다.

이 장은 확률밀도함수 f를 갖는 연속분포를 다룹니다. f(x)는 음이 아니고, 실수 전체에 걸쳐 적분한 값이 1입니다. 밀도가 0이 아닌 범위를 적고 그 밖에서는 f(x)=0으로 둡니다. 구간 확률은 구간 위의 넓이입니다.

P(a < X ≤ b) = ∫ab f(x) dx.

밀도의 높이가 구간 안에서 거의 일정하면, 확률은 그 높이에 구간 폭을 곱한 값에 가깝습니다. X가 초 단위라면 f(x)의 단위는 1/초이고, f(x) dx의 단위는 서로 상쇄됩니다. 점 하나의 폭은 0이므로 이 모형에서는 P(X=a)=0입니다. 구간 끝점을 포함해도 확률은 같습니다. 기기가 0.31초라는 반올림 값을 기록할 확률은 0.31초로 표시되는 구간을 적분해 구합니다.

밀도 f(x)=2x의 넓이를 직접 구한다

0 ≤ x ≤ 1에서 f(x)=2x, 그 밖에서는 f(x)=0인 모형을 써 봅시다. x축 위의 직각삼각형은 밑변 1, 높이 2여서 전체 넓이가 1입니다. x=0.75의 밀도는 1.5이지만 어떤 사건의 확률도 1.5가 되지 않습니다.

∫0.250.75 2x dx = [x²]0.250.75 = 0.5625 − 0.0625 = 0.5.

확률변수가 범위를 벗어날 수 없다고 설정했다면, 끝 바깥쪽까지 적분해도 f=0인 부분은 누적을 늘리지 않습니다. 가령 P(X ≤ 1.2)=1입니다.

왼쪽부터 면적을 누적해 F(x)를 만든다

누적분포함수 F(x) = P(X ≤ x)는 왼쪽 전체에서 x까지의 확률입니다. 앞에서 이산확률을 더했던 자리에 면적 적분이 들어갑니다. 밀도는 위아래로 움직일 수 있지만, F는 음이 아닌 면적을 누적하므로 줄어들지 않습니다.

F(x) = ∫−∞x f(t) dt.
P(a < X ≤ b) = F(b) − F(a).

세 구간에서 정의하기

위 밀도에서 x < 0에는 아직 면적이 없습니다. 0 ≤ x ≤ 1에서는 ∫0x 2t dt = x²입니다. x > 1이면 전체 면적 1을 이미 지나왔습니다. 그래서 F(x)는 왼쪽에서 0, 가운데에서 x², 오른쪽에서 1입니다. 밀도 f가 연속인 내부에서는 미적분의 기본정리로 F′(x)=f(x)입니다.

분위수는 누적확률에서 x를 찾는다

누적분포는 x를 주고 왼쪽 확률을 구합니다. 분위수 qp는 반대로 누적확률 p를 주고 이에 대응하는 위치를 구합니다. 0 < p < 1이고 F가 그 위치에서 한 번만 p를 지난다면 F(qp)=p를 풉니다. F가 p인 구간이 있어 답이 여러 개라면, 여기서는 F(x) ≥ p를 처음 만족하는 위치를 사용합니다. 일반식으로는 qp = inf{x | F(x) ≥ p}입니다. inf는 이 집합의 가장 큰 하한입니다.

같은 분포의 중앙값은 p=0.5에 대응하는 √0.5 ≈ 0.7071입니다. 밀도가 오른쪽으로 갈수록 높아서, 구간의 가운데 x=0.5에서 왼쪽 면적은 1/4밖에 쌓이지 않습니다. 분위수는 가능 범위에서 차지한 길이의 비율보다 누적확률로 결정합니다.

밀도가 일정하면 길이가 두 배일 때 확률도 두 배다

신호가 오는 시각을 2초부터 8초 사이의 연속 균등분포로 모형화합시다. 전체 폭이 6초이므로 넓이를 1로 만드는 높이는 1/6입니다. 3초부터 5초까지의 폭은 2초이므로 확률은 2/6 = 1/3입니다. 반대로 0.25 분위수까지는 전체 폭의 1/4인 1.5초가 필요합니다. 시작점 2초를 더해 3.5초입니다.

U(a,b)에서 a ≤ x ≤ b일 때 f(x) = 1/(b−a), F(x) = (x−a)/(b−a).
qp = a + p(b−a).

이 식에서 a < b이며, 확률을 구할 구간이 [a,b]의 밖으로 걸치면 겹치는 길이만 셉니다. 실제 응답이나 도착 시간이 균등하게 분포한다는 결론은 관측이나 현상에 대한 근거로 따로 판단합니다.

누적값과 분위수를 계산하여 되돌려 본다

코드에서 두 함수는 각각 밀도 2x인 예와 균등분포 예의 누적면적을 계산합니다. 분위수를 해당 F에 돌려 넣으면 목표 누적확률이 나옵니다.

from math import isclose, sqrt

def triangular_cdf(x):
    return min(max(x, 0.0), 1.0)**2

def uniform_cdf(x, left, right):
    fraction = (x - left) / (right - left)
    return min(max(fraction, 0.0), 1.0)

p = 0.25
q = sqrt(p)
uniform_q = 2 + p * (8 - 2)
assert isclose(triangular_cdf(q), p)
assert isclose(uniform_cdf(uniform_q, 2, 8), p)
print(f"삼각형 밀도의 구간 확률: {triangular_cdf(0.75) - triangular_cdf(0.25):.4f}")
print(f"삼각형 밀도의 25% 분위수: {q:.4f}")
print(f"균등 모형에서 3~5초 확률: {uniform_cdf(5, 2, 8) - uniform_cdf(3, 2, 8):.4f}")
print(f"균등 모형의 25% 분위수: {uniform_q:.4f}초")
삼각형 밀도의 구간 확률: 0.5000
삼각형 밀도의 25% 분위수: 0.5000
균등 모형에서 3~5초 확률: 0.3333
균등 모형의 25% 분위수: 3.5000초
