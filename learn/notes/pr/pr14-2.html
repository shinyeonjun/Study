Hoeffding을 유도하고 유한한 여러 후보의 일반화 오차를 제한하기

12개 모델을 같은 시험 자료에 평가하면 어느 하나는 우연히 좋은 점수를 받을 수 있습니다. 한 모델에서 얻은 확률 상계를 후보 전체로 옮기고, 선택한 모델의 위험에 무엇이 보장되는지 계산합니다.

이 장을 읽고 나면

  • 범위가 있는 변수의 log-MGF 상계에서 Hoeffding을 도출한다.
  • 유한한 고정 후보의 동시 오차 확률과 필요한 표본 수를 계산한다.
  • 같은 자료에서 고른 최선 모델의 초과 위험을 상계한다.

지수로 다시 가중해도 범위와 분산의 상계는 유지된다

X∈[a,b]라 두고 중심화 로그 MGF를 φ(t)=log E exp[t(X−E[X])]로 잡습니다. φ(0)=φ′(0)=0입니다. 두 번 미분하면 φ″(t)는 원래 분포에 exp(tX)에 비례하는 가중치를 준 분포에서의 분산입니다. X가 유계라 이 미분에서 적분과 순서를 바꿀 수 있습니다.

가중한 뒤에도 X는 [a,b] 안에 있습니다. 분산은 상수 c 주위 제곱거리 E[(X−c)²]를 가장 작게 한 값입니다. c=(a+b)/2를 선택하면 각 거리는 (b−a)/2 이하라 φ″(t)≤(b−a)²/4입니다. t≥0에서 0부터 두 번 적분해 φ(t)≤t²(b−a)²/8을 얻습니다.

독립 변수들의 로그 MGF를 더한다

독립인 Xᵢ가 각기 [aᵢ,bᵢ]에 놓이면 중심화 합 S의 지수 Markov 상계는 exp(−ts+t²B/8)입니다. 여기서 B=∑(bᵢ−aᵢ)²입니다. B>0, s>0에서 최솟값을 주는 t=4s/B를 넣어 exp(−2s²/B)를 얻습니다. B=0이면 모든 값이 상수라 양수 꼬리의 확률은 0입니다. 아래 꼬리는 −Xᵢ에 동일하게 적용합니다. [0,1] 범위 n개의 평균에서 양측 ε 편차는 ≤2 exp(−2nε²)입니다.

후보를 같은 자료에 평가한다

평가 전에 고정된 M개 가설에서 각 손실은 [0,1]에 있습니다. 동일한 IID 관측 n개로 각 모델의 평균 손실 R̂(h)를 계산합니다. 참 위험 R(h)는 그 모델의 모집단 평균 손실입니다. 한 모델의 큰 편차 확률을 위처럼 묶고, 어떤 후보라도 큰 편차가 나오는 사건은 그 사건들의 합집합이므로 확률을 모두 더할 수 있습니다.

P(maxₕ|R̂(h)−R(h)|≥ε) ≤ 2M exp(−2nε²)

서로 다른 모델이 같은 자료를 봐서 오차가 의존하더라도 합집합 상계는 성립합니다. M=12, ε=.1, 허용 실패확률 δ=.05이면 n≥⌈log(2M/δ)/(2ε²)⌉=309면 이 상계로 충분합니다. 실제 필요한 수는 손실 분포와 후보에 따라 더 작을 수 있습니다.

실제로 선택한 후보의 참 위험도 비교한다

참 위험 최소 모델을 h*, 경험 위험 최소 모델을 ĥ라 둡니다. 전 후보의 편차가 ε 이내인 사건에서 R(ĥ)≤R̂(ĥ)+ε≤R̂(h*)+ε≤R(h*)+2ε입니다. 같은 표본으로 후보군 자체를 늘리거나 피처를 바꿨다면, 이 고정 후보 개수의 상계를 그대로 적용할 수 없습니다. 후보를 정하는 자료와 평가 자료를 나누는 방법을 고려합니다.

같은 관측으로 비교하는 네 모델을 모의실험한다

입력 X와 표지 Y는 각각 공평한 독립 이진값입니다. 예측 규칙 0, 1, X, 1−X 네 가지는 모두 참 오분류 위험 1/2입니다. n=60에서 편차 .2 이상을 봅니다. 상수 0과 1의 오류는 서로 보수이고, X와 1−X의 오류도 서로 보수입니다. 대표 두 오류는 Y와 X XOR Y이며 이 모형에서는 독립입니다. 그래서 한 규칙의 양쪽 꼬리 p=2P(Binomial(60,1/2)≤18)에서, 네 후보 최대 편차의 정확확률은 1−(1−p)²입니다.

구분확률 또는 빈도
합집합 상계0.06583798
이 모형의 정확 확률0.00533374
시드 33, 10,000회 모의실험47/10,000 = 0.004700
from fractions import Fraction as F
from math import ceil, comb, exp, log
from random import Random

n = ceil(log(2*12/.05)/.02)
single = F(2*sum(comb(60,k) for k in range(19)),2**60)
joint = 1-(1-single)**2
rng = Random(33)
runs = 10000
observed = 0
for _ in range(runs):
    losses = [0]*4
    for _ in range(60):
        x,y = rng.getrandbits(1),rng.getrandbits(1)
        for i,prediction in enumerate((0,1,x,1-x)):
            losses[i] += prediction != y
    observed += max(abs(count-30) for count in losses) >= 12
print(n,f"{float(joint):.8f} {8*exp(-4.8):.8f}")
print(observed,f"{observed/runs:.6f}")
