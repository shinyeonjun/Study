확률변수 · 한 값의 확률과 누적확률

동전 두 번의 결과 HT와 TH는 순서가 다르지만 앞면 개수는 같습니다. 원래 결과를 수로 바꾸는 규칙을 세운 다음, 정확히 한 값일 확률과 그 값까지 모은 확률을 나란히 읽습니다.

이 장을 읽고 나면

  • 원래 결과·확률변수 값·사건을 구별한다.
  • 이산 확률변수의 확률질량함수와 누적분포함수를 만든다.
  • 경계가 포함되는지 확인하며 구간의 확률을 계산한다.

결과를 수로 바꾸는 규칙

동전을 두 번 던지고 앞면을 H, 뒷면을 T로 적습니다. 순서를 기록할 때 표본공간은 {HH, HT, TH, TT}입니다. 앞면과 뒷면의 확률이 각각 1/2이고 한 번의 결과가 다음 결과의 확률을 바꾸지 않는다고 가정합니다. 이 모형에서는 네 결과의 확률이 각각 1/4입니다.

정의

확률변수는 표본공간의 각 결과에 실수 하나를 붙이는 함수입니다. X를 앞면 개수라고 정하면 X(HT) = 1입니다. 함수 X의 규칙은 정해져 있지만 실제로 어느 결과가 나오느냐에 따라 얻게 될 값이 달라집니다. {X = 1}은 앞면이 하나 나오는 사건이며, HT와 TH를 함께 가리킵니다.

이렇게 가능한 값을 유한 개 또는 셀 수 있게 나열할 수 있는 변수를 이산 확률변수라고 합니다. 앞면 개수는 {0, 1, 2}, 작업을 마칠 때까지 시도한 횟수는 {1, 2, 3, …}으로 나열할 수 있습니다. 값이 꼭 정수일 필요는 없습니다. 결과가 0.5점 또는 1.5점 중 하나뿐이면 이산입니다.

정확히 그 값일 확률

가능한 값마다 확률을 쓰면 확률질량함수(probability mass function, PMF)가 됩니다. 기호를 p(x) = P(X = x)로 씁니다. 대문자 X는 결과를 수로 바꾸는 함수이고, 소문자 x는 지금 묻는 수를 뜻합니다.

물어보는 값 x사건 {X = x}확률 p(x)
0{TT}1/4
1{HT, TH}1/4 + 1/4 = 1/2
2{HH}1/4

어느 값의 확률도 음수가 될 수 없고 전체를 합하면 1입니다. 앞면 1.5개는 가능하지 않아 p(1.5) = 0입니다. 값 0, 1, 2에 똑같이 1/3을 줄 수는 없습니다. 값 1에 대응하는 원래 결과가 둘이기 때문입니다. 원래 결과들의 확률이 다르면 경우의 수를 세는 대신 해당 결과들의 확률을 하나씩 더합니다.

그 값까지 모은 확률

누적분포함수(cumulative distribution function, CDF)는 F(x) = P(X ≤ x)입니다. x보다 작거나 같은 값의 확률을 모두 더합니다. F(1)은 p(0) + p(1) = 1/4 + 1/2 = 3/4입니다.

F(1.5)에도 값 0과 1이 포함되므로 역시 3/4입니다. x를 키워도 전에 더한 값을 빼지 않으므로 누적확률은 줄어들지 않습니다. 이 예에서는 2에 도달하면 가능한 값을 전부 포함해 1이 됩니다. 점마다 뛰어오르는 높이는 그 점의 PMF와 같습니다. 그래프에서 1의 바로 왼쪽은 1/4이고, 1에서 3/4가 되므로 점프 높이 1/2가 바로 P(X = 1)입니다.

이어지는 구간의 확률

P(0 < X ≤ 2) = F(2) − F(0) = 1 − 1/4 = 3/4입니다. F(0)을 빼면 값 0도 빠집니다. 일반적으로 P(a < X ≤ b) = F(b) − F(a)이고, 양 끝을 어느 쪽에서 포함하는지 먼저 읽습니다.

from collections import Counter
from fractions import Fraction
from itertools import product

outcomes = list(product("HT", repeat=2))
counts = Counter(outcome.count("H") for outcome in outcomes)
pmf = {x: Fraction(n, len(outcomes)) for x, n in sorted(counts.items())}
assert sum(pmf.values()) == 1

for x in (0, 1, 1.5, 2):
    exact = pmf.get(x, 0)
    cumulative = sum(p for value, p in pmf.items() if value <= x)
    print(f"x={x}: p(x)={exact}, F(x)={cumulative}")

실행 결과

x=0: p(x)=1/4, F(x)=1/4
x=1: p(x)=1/2, F(x)=3/4
x=1.5: p(x)=0, F(x)=3/4
x=2: p(x)=1/4, F(x)=1

product는 두 자리의 가능한 순서쌍을 모두 만듭니다. Fraction으로 분수를 정확하게 계산합니다. 이 코드는 공정하다는 가정 아래의 확률을 계산한 것입니다. 실제 동전을 던져 얻은 횟수나 비율은 실험마다 달라질 수 있습니다.

왜 그럴까?

p(1.5) = 0과 F(1.5) = 3/4가 동시에 맞는 이유를 설명해 보세요.

모범 답 보기

앞면이 1.5개 나오는 결과는 없지만, 앞면이 1.5개 이하인 경우는 세 결과 TT, HT, TH입니다. 질문 하나는 정확히 같은 값, 다른 하나는 그 값까지 얻는 사건을 묻습니다.
