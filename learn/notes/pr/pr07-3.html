공분산과 상관: 함께 움직이는 방향을 수로 읽기

두 변수의 관련성을 한 숫자로 표현할 때 두 값이 각각 평균보다 얼마나 큰지부터 봅니다. 공분산은 이 두 차이의 곱을 평균하고, 상관은 측정 단위가 달라져도 선형 관련성을 비교하게 합니다.

이 장을 읽고 나면

  • 확률이 주어진 점들로부터 공분산, 피어슨 상관, 공분산 행렬을 계산한다.
  • 공분산과 상관의 단위, 0인 분산이라는 예외를 설명한다.
  • 독립과 무상관의 관계를 반례로 판정한다.

평균을 기준으로 함께 높고 낮은지 본다

한 관측에서 두 수 X,Y가 짝지어 옵니다. 설명용 모형에서 X는 처리에 들인 시간(h), Y는 추가 대기 시간(min)이고, 가능한 짝 (0,1), (1,0), (1,2), (2,3)은 확률이 각 1/4입니다. 평균은 각각 μX=1시간, μY=1.5분입니다. X는 X의 평균을, Y는 Y의 평균을 빼서 각각 중심화합니다.

(X,Y)X−1 (h)Y−1.5 (min)편차의 곱 (h·min)
(0,1)−1−0.50.5
(1,0)0−1.50
(1,2)0+0.50
(2,3)+1+1.51.5

공분산은 편차의 곱을 확률로 평균한 값입니다. Cov(X,Y)=E[(X−μ_X)(Y−μ_Y)]이며, 전개하면 Cov(X,Y)=E[XY]−E[X]E[Y]입니다. 이 장에서는 두 변수의 제곱 기댓값이 유한하다고 가정합니다. 여기서는 네 곱의 평균 0.5 h·min을 얻습니다. 양수는 같은 방향 편차의 곱이, 음수는 반대 방향 편차의 곱이 더 크게 기여했다는 뜻입니다.

단위를 지우려면 표준편차 두 개로 나눈다

X를 시간에서 분으로 바꾸면 새 변수는 60X입니다. 공분산은 60배가 되어 수치가 30으로 바뀝니다. 피어슨 상관계수 ρ는 Cov(X,Y)/(σ_X σ_Y)로 계산합니다. 양의 단위 변환에서는 분자와 분모가 같이 늘어나므로 상관은 그대로입니다. 측정 방향을 반대로 뒤집으면 상관의 부호도 바뀝니다.

이 예에서 Var(X)=0.5 h², Var(Y)=1.25 min²입니다. 그러므로 ρ = 0.5 / √(0.5×1.25) ≈ 0.632456입니다. 상관의 범위는 −1부터 1이고 단위가 없습니다. 정확히 +1이나 −1이면 분산이 양수인 두 값이 확률 1로 증가·감소하는 직선 위에 놓입니다. 둘 중 하나가 항상 일정해 표준편차가 0이면 공분산은 0이어도 이 상관계수는 정의되지 않습니다.

벡터로 읽는 분모

이 예에서 중심화한 X,Y를 길이 4인 벡터로 놓으면 분자 4·Cov는 두 벡터의 내적입니다. 분모 4σXσY는 두 길이의 곱입니다. 즉 같은 확률의 점에서는 상관을 중심화 벡터 사이 각도의 코사인으로 볼 수 있습니다. 각도가 직각이면 선형 방향에서 편차 곱의 합이 0입니다.

여러 변수의 공분산을 행렬로 정리한다

변수 순서를 (X,Y)로 정하면 공분산 행렬 Σ의 (i,j) 칸은 i번째와 j번째 변수의 공분산입니다. 대각에는 자기 자신과의 공분산 곧 분산이 들어갑니다. 편차 곱의 두 인수를 바꿔도 값이 같아서 좌우의 대응 칸은 대칭입니다.

ΣX (h)Y (min)
X (h)0.5 h²0.5 h·min
Y (min)0.5 h·min1.25 min²

가중합의 분산도 이 행렬에서 읽습니다. 두 변수의 단위를 맞춘 뒤 Var(aX+bY)=a²Var(X)+2ab Cov(X,Y)+b²Var(Y)입니다. 양쪽 비대각 칸이 합쳐져 2가 나옵니다. 벡터 a로 적으면 이 값은 aᵀΣa이고 항상 0 이상입니다. 예를 들어 X를 분으로 바꾼 60X와 Y를 더하면 분산은 3600×0.5 + 120×0.5 + 1.25 = 1861.25 min²입니다.

지금은 네 점이 확률 모형 전체여서 평균은 4로 나눴습니다. 이 네 점을 미지의 모집단에서 추출한 표본으로 쓰면 모집단 공분산을 추정하는 데 표본 공분산(보통 n−1로 나눔)을 사용할 수 있습니다. 정의하려는 대상과 분모를 먼저 확인합니다.

무상관이어도 규칙이 숨어 있을 수 있다

독립인 변수에서는 E[XY]=E[X]E[Y]가 되어 공분산이 0입니다. 두 분산이 양수라면 상관도 0입니다. 거꾸로 공분산이 0이라고 독립이 되지는 않습니다. X가 −1, 0, 1을 각각 1/3로 취하고 Y=X²인 경우를 살펴봅니다.

E[X]=0, E[Y]=2/3입니다. E[XY]=E[X³]=(−1+0+1)/3=0이라 공분산은 0입니다. 그러나 X=0을 알 때 Y=0의 확률은 1이고 전체에서 Y=0의 확률은 1/3입니다. 선형 관련성을 나타내는 곱은 서로 상쇄됐지만 가능한 조합에 관한 정보는 남아 있습니다. 산점도와 결합분포를 같이 보는 이유입니다.

from fractions import Fraction as F
from math import sqrt

def mean(values):
    return F(sum(values), len(values))

def covariance(xs, ys):
    x_mean, y_mean = mean(xs), mean(ys)
    return mean([(x - x_mean) * (y - y_mean) for x, y in zip(xs, ys)])

xs = [0, 1, 1, 2]
ys = [1, 0, 2, 3]
var_x = covariance(xs, xs)
var_y = covariance(ys, ys)
cov_xy = covariance(xs, ys)
rho = cov_xy / sqrt(var_x * var_y)
print("행렬 첫 행:", var_x, cov_xy)
print("행렬 둘째 행:", cov_xy, var_y)
print(f"상관: {rho:.6f}")
u = [-1, 0, 1]
v = [x**2 for x in u]
assert covariance(u, u) > 0 and covariance(v, v) > 0
print("Y=X² 공분산:", covariance(u, v))
행렬 첫 행: 1/2 1/2
행렬 둘째 행: 1/2 5/4
상관: 0.632456
Y=X² 공분산: 0

코드의 zip은 정해 둔 같은 길이의 두 리스트를 순서대로 붙입니다. 실제 짝 자료에서는 X와 Y의 순서를 각각 따로 정렬하면 원래의 짝이 깨집니다. 동일 관측의 두 값을 같은 위치에 두어야 합니다.
