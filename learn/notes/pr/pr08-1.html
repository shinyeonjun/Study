난수로 표본을 만들고 경험분포 읽기

주사위의 눈이 나올 확률을 정해 두었다면, 그 모형에서 뽑은 관측이 어떤 모습인지 컴퓨터로 살펴볼 수 있습니다. 한 번의 관측, 여러 관측을 담은 표본, 표본을 만드는 절차의 반복을 차례로 구분해 봅니다.

이 장을 읽고 나면

  • 시드와 난수 생성기의 상태가 각각 무엇인지 설명한다.
  • 관측값을 센 뒤 비율과 누적비율로 바꾼다.
  • 표본 크기 n과 모의실험 횟수 B를 배열에서 구분한다.

관측 여덟 개로 확률표 만들기

공정한 6면체 주사위를 연달아 던질 때 눈을 X로 적습니다. 모형에서는 어떤 눈이든 P(X=k)=1/6입니다. 실제로 기록한 여덟 개의 눈이 1, 4, 6, 4, 2, 4, 6, 3이라면 눈마다 등장 횟수를 세어 볼 수 있습니다.

눈 k123456
횟수111302
관측 비율1/81/81/83/802/8
이 눈 이하 누적비율1/82/83/86/86/88/8

각 결과의 관측 횟수를 전체 표본 크기로 나눈 표를 경험분포라고 합니다. 표본의 각 행은 같은 무게 1/8을 가집니다. 눈 4의 관측 비율은 3/8입니다. 공정한 모형의 1/6과 차이가 나는 것은 가능한 일입니다.

눈이 3 이하일 때의 경험 누적비율은 세 칸을 더한 3/8입니다. 일반적으로 관측값을 x₁, ..., xₙ이라 쓰면 경험 누적분포함수 Fₙ(t)는 xᵢ ≤ t를 만족하는 관측의 비율입니다. 문턱값 t 사이에 관측이 하나도 없으면 새로 더해지는 행이 없어서 그래프 높이가 그대로입니다. 같은 값이 반복 등장하면 그 지점에서 반복 횟수만큼 한 번에 뜁니다.

컴퓨터에서 같은 확률 모형을 반복하기

이 장의 의사난수 생성기는 상태를 바꾸는 정해진 규칙으로 값을 만듭니다. 시드는 시작할 때 내부 상태를 만드는 입력입니다. 같은 알고리즘·환경에서 같은 시드로 다시 시작하고 호출의 순서와 인수를 같게 하면 이전 실행을 재현할 수 있습니다. 같은 생성기에 두 번째 요청을 하면 그동안 상태가 진행되었으므로 앞에서 쓴 시드로 자동 초기화되지 않습니다. 연구 노트에 시드, NumPy 버전, 코드뿐 아니라 모형과 가정도 적어 둡니다.

모의실험을 쓰는 순서

  1. 한 번의 표본에 어떤 관측이 몇 개 들어가는지 정합니다.
  2. 관측을 내는 모형을 코드로 표현합니다.
  3. 표본마다 평균이나 조건을 만족한 횟수처럼 요약값 하나를 계산합니다.
  4. 여러 번 반복한 요약값으로 분포나 사건의 비율을 추정합니다.

아래에서는 공정한 주사위를 3번 던지는 실험을 4회 흉내 냅니다. integers(1, 7, ...)는 1부터 6까지 뽑습니다. 배열의 한 행이 표본 하나이고 열 셋은 그 표본의 관측입니다. axis=1은 열 방향으로 접어 한 행마다 평균 하나를 만든다는 뜻입니다.

import numpy as np

rng = np.random.default_rng(42)
rolls = rng.integers(1, 7, size=(4, 3))
print(rolls.tolist())
print(rolls.mean(axis=1).round(3).tolist())

repeated = np.random.default_rng(42).integers(1, 7, size=(4, 3))
print(np.array_equal(rolls, repeated))

실행 결과

[[1, 5, 4], [3, 3, 6], [1, 5, 2], [1, 4, 6]]
[3.333, 4.0, 2.667, 3.667]
True

반복으로 무엇을 추정하는지 확인한다

예를 들어 세 눈의 평균이 3을 넘을 확률을 구한다면, 각 행의 평균을 3과 비교하여 참의 개수를 B로 나눕니다. 위 출력에서는 세 행이 참이라 추정값이 3/4입니다. 정확한 모형 확률은 가능한 세 눈의 조합을 모두 세어서 별도로 확인할 수 있습니다. B=4는 절차 설명용이라, 결과를 정밀한 확률로 해석하기에는 반복이 적습니다.

from itertools import product

triples = list(product(range(1, 7), repeat=3))
successes = sum(sum(rolls) > 9 for rolls in triples)
print(len(triples), successes, f"{successes / len(triples):.4f}")

실행 결과

216 135 0.6250

이 예제의 216개 순서 있는 결과는 각 던지기가 독립이고 눈마다 확률 1/6일 때 같은 확률을 가집니다. 서로 의존하는 관측이나 편향된 주사위라면 이 가정을 먼저 고쳐야 합니다. 모형의 불일치는 B를 늘려도 자동으로 해결되지 않습니다.

한눈에 정리

  • 경험분포는 실제로 얻은 관측값이나 모의실험 출력을 세어 전체 개수로 나눈 것이다.
  • 생성 상태를 재현하려면 시드와 함께 알고리즘·환경·호출을 기록한다.
  • n은 표본 하나 안의 크기다. B는 그 표본을 반복해 만드는 횟수다.
