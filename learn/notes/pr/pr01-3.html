확률 · PR01 확률의 언어

PR01·3

확률을 정하는 방법과 해석

원 안에 현을 ‘무작위로’ 하나 그을 때 그 현이 내접 정삼각형의 한 변보다 길 확률은 얼마일까요? 정답이 1/3, 1/2, 1/4 세 개로 갈립니다. 계산이 틀린 것이 아니라 ‘무작위’가 무엇인지 정하지 않았기 때문입니다. 공리는 확률들이 어떻게 맞물려야 하는지만 정하고 값 자체는 정하지 않습니다. 이 장은 값을 정하는 방법(대칭, 기하, 빈도, 믿음)과 각 방법이 언제 정당한지, 그리고 확률이라는 수가 무엇을 뜻하는지를 다룹니다.

이 장을 읽고 나면

  • 등가능 모형을 쓸 근거가 있는 경우와 없는 경우를 구별하고, 무차별 원리가 왜 모순을 낳는지 설명할 수 있다.
  • 기하학적 확률을 넓이 비로 계산하고, ‘균등’이 매개변수의 선택에 따라 달라진다는 것을 예로 보일 수 있다.
  • 베르트랑의 역설의 세 답을 유도하고, 시뮬레이션으로 확인하며, 세 답이 다른 확률측도에서 나온다는 것을 설명할 수 있다.
  • 빈도 해석과 주관적(베이즈) 해석의 주장과 한계를 비교할 수 있다.
  • 대수의 법칙이 보장하는 것과 보장하지 않는 것을 구별할 수 있다.

등가능 모형과 그 근거 이해하기

Ω가 유한하고 모든 근원사건의 확률이 같다고 가정하면, 공리만으로 확률이 완전히 정해집니다. 모든 ω에서 P({ω}) = c라 하면 유한 가법성과 정규화로 |Ω| × c = 1이므로 c = 1/|Ω|이고, 다시 유한 가법성으로

P(A) = Σω∈A P({ω}) = |A| / |Ω|   (|A|는 A의 원소 수)

입니다. 이것이 등가능 모형(고전적 확률, naive definition)입니다. 계산은 세기로 바뀌고, 세는 기술은 DM03의 순열·조합입니다. 하지만 이 공식의 무게는 계산이 아니라 ‘모든 결과가 같은 확률’이라는 가정에 실려 있고, 그 가정은 공리에서 나오지 않습니다. 근거가 따로 필요합니다.

정당한 근거는 대체로 둘입니다. 첫째, 물리적 대칭. 잘 만든 주사위는 면을 서로 바꾸는 대칭이 있어 어느 면을 특별히 대할 이유가 물리적으로 없습니다. 잘 섞은 카드도 마찬가지입니다. 이때도 근거는 ‘이름이 여섯 개’가 아니라 ‘물체와 던지는 방식의 대칭’입니다. 둘째, 설계에 의한 무작위화. 명단에서 난수로 한 명을 뽑으면 각 사람이 뽑힐 확률은 우리가 그렇게 만들었기 때문에 같습니다. 통계학에서 무작위 표본 추출과 무작위 배정이 중요한 이유가 이것입니다. 등가능성을 가정하는 대신 직접 만들어 냅니다.

흔한 실수 · 무차별 원리

‘내일 비가 오거나 안 오거나 둘 중 하나이니 비 올 확률은 1/2’. 이 추론은 ‘달리 알 수 없으면 모든 경우를 같게 본다’는 무차별 원리를 쓴 것인데, 근거가 없을 뿐 아니라 자기모순을 낳습니다. 같은 날씨를 {비, 눈, 맑음}으로 나누면 같은 원리가 ‘비 1/3’을 줍니다. 경우를 어떻게 나누느냐(표본공간을 어떻게 잡느냐)에 따라 답이 바뀌는 원리는 확률을 정해 주지 못합니다. 날씨 확률은 대칭이 아니라 기상 자료와 모형에서 와야 합니다.

역사적인 예가 있습니다. 18세기 수학자 달랑베르는 동전을 두 번까지 던져 앞면이 한 번이라도 나오면 이기는 내기에서, 결과를 ‘앞’(첫 번째에 앞면, 더 던질 필요 없음), ‘뒤앞’, ‘뒤뒤’ 세 경우로 보고 이길 확률을 2/3라고 썼습니다. 세 경우가 같은 확률이라는 근거가 없었던 것입니다.

해결책은 앞 장들에서 본 것과 같습니다. 대칭으로 같은 확률을 정당화할 수 있는 섬세한 공간(두 번 다 던진 순서쌍 4개)으로 가서 세고, 필요하면 거친 사건으로 묶습니다. 이 방식으로 세기의 고전 문제 두 개를 계산합니다.

실행 예제

from math import comb, perm

# 생일 문제: 1년 365일이 등가능하고 서로 독립이라는 모형
for k in (10, 23, 50):
    distinct = perm(365, k) / 365 ** k         # 365P_k / 365^k
    print(k, round(1 - distinct, 4))

# 조합 세기: 52장에서 5장을 뽑을 때 다섯 장이 모두 같은 무늬(스트레이트 플러시 포함)
print(comb(52, 5), 4 * comb(13, 5), round(4 * comb(13, 5) / comb(52, 5), 6))
10 0.1169
23 0.5073
50 0.9704
2598960 5148 0.001981

생일 문제의 표본공간은 k명의 생일 순서쌍 365k개이고, 모두 다른 경우는 365 × 364 × … × (365 − k + 1)개입니다(순열). 23명이면 생일이 겹칠 확률이 절반을 넘습니다. 이 수는 모형의 가정, 곧 365일이 같은 확률이고(2월 29일 무시) 사람들의 생일이 서로 무관하다는 가정에서 나온 것입니다. 실제 출생일은 날짜마다 조금씩 다릅니다. 다행히 날짜별 확률이 고르지 않으면 겹칠 확률은 오히려 커진다는 것이 알려져 있어, 독립 가정만 맞으면 0.5073은 하한으로 읽을 수 있습니다. 모형의 가정을 적고, 가정이 틀리면 답이 어느 방향으로 움직이는지 아는 것까지가 계산입니다.

기하학적 확률 이해하기

결과가 연속적이면 결과를 셀 수 없습니다. 대신 Ω가 넓이(또는 길이, 부피)가 유한한 평면 영역이고 ‘점을 균등하게 고른다’고 하면

P(A) = (A의 넓이) / (Ω의 넓이)

로 정합니다. 이것이 기하학적 확률입니다. 넓이는 배반인 영역에서 더해지고(가산 가법성은 측도론에서 보장됩니다) 전체를 1로 나누었으므로 공리를 만족합니다. 등가능 모형의 ‘개수’를 ‘넓이’로 바꾼 것이며, ‘같은 넓이의 영역은 같은 확률’이 균등의 정확한 뜻입니다. 점 하나는 넓이가 0이므로 확률도 0입니다(PR01·1의 비가산 공간).

고전 예제인 만남 문제를 풉니다. 두 사람이 정오에서 1시 사이에 서로 무관하게, 각자 균등한 시각에 도착하고 먼저 온 사람은 15분만 기다립니다. 만날 확률은? 도착 시각을 (x, y) ∈ [0, 60]²(분)로 두면 Ω는 넓이 3600인 정사각형이고, 만나는 사건은 |x − y| ≤ 15인 띠입니다. 띠 밖은 직각을 낀 두 변이 45인 직각이등변삼각형 두 개이므로

P(만남) = 1 − 2 × (½ × 45 × 45) / 3600 = 1 − 2025/3600 = 1575/3600 = 7/16 = 0.4375

실행 예제

import numpy as np

rng = np.random.default_rng(2026)
n = 1_000_000
x = rng.uniform(0, 60, n)                      # A가 도착하는 시각(분)
y = rng.uniform(0, 60, n)                      # B가 도착하는 시각(분)
meet = np.abs(x - y) <= 15                     # 먼저 온 사람이 15분 기다림
print(f"{meet.mean():.4f}", 7 / 16)
0.4370 0.4375

점 100만 개 중 띠에 떨어진 비율이 넓이 비와 소수 셋째 자리까지 맞습니다. 이 시뮬레이션은 Monte Carlo 적분의 가장 단순한 형태이기도 합니다. 넓이를 직접 구하기 어려운 영역도 균등한 점을 뿌리고 비율을 세면 넓이를 추정할 수 있습니다.

‘균등’은 무엇에 대해 균등한가

기하학적 확률에는 함정이 하나 있습니다. 한 변의 길이가 [0, 1]에서 무작위인 정사각형을 생각합니다. ‘변의 길이 s가 균등’이라고 하면 P(s < 1/2) = 1/2입니다. 같은 상황을 ‘넓이 a = s²이 [0, 1]에서 균등’이라고 하면 같은 사건 s < 1/2 ⇔ a < 1/4의 확률이 1/4입니다. 두 모형은 같은 정사각형들의 집합 위에 서로 다른 확률을 놓습니다. s가 균등하면 a = s²은 균등하지 않고, 그 반대도 마찬가지입니다(비선형 변환은 균등성을 보존하지 않습니다). ‘무작위 정사각형’이라는 말만으로는 어느 모형인지 정해지지 않습니다. 이 문제가 극적으로 드러나는 것이 다음 절의 역설입니다.

베르트랑의 역설 이해하기

J. 베르트랑이 1889년 책 Calcul des probabilités에서 제시한 문제입니다. 반지름 1인 원에 현을 무작위로 하나 긋습니다. 원에 내접하는 정삼각형의 한 변의 길이는 √3입니다. 현의 길이 L이 √3보다 길 확률은? 현을 ‘무작위로’ 고르는 그럴듯한 방법 세 가지가 서로 다른 답을 줍니다. 각 방법에서 현의 길이와 중심까지 거리 d의 관계 L = 2√(1 − d²)를 씁니다. L > √3 ⇔ d < 1/2입니다.

방법 1 (두 끝점을 원 위에서 균등하게). 회전 대칭으로 한 끝점 P를 고정해도 됩니다. 다른 끝점이 원 위에서 균등합니다. P를 꼭짓점으로 하는 내접 정삼각형을 그리면, 다른 끝점이 P의 맞은편 호(두 꼭짓점 사이, 중심각 120°)에 떨어질 때 현이 삼각형의 변보다 깁니다. 호의 비율이 120/360이므로 답은 1/3입니다.

방법 2 (반지름 위의 거리를 균등하게). 회전 대칭으로 반지름 하나를 고정하고, 중심에서 그 반지름 위로 거리 d ∈ [0, 1]를 균등하게 고른 뒤 그 점에서 반지름에 수직인 현을 긋습니다. d < 1/2일 확률이므로 답은 1/2입니다.

방법 3 (현의 중점을 원판에서 균등하게). 원판 안의 점 M을 넓이에 비례해 균등하게 고르고, M을 중점으로 하는 현을 긋습니다(중심이 아닌 점은 그런 현이 하나로 정해집니다). 중점이 중심에서 1/2 안에 있어야 하므로 반지름 1/2인 원의 넓이 비 (1/2)² = 1/4입니다. 이 반지름 1/2인 원은 내접 정삼각형의 내접원과 같습니다.

세 방법을 그대로 시뮬레이션합니다. 방법 3에서 원판 안의 균등한 점을 만들 때 중심 거리 r을 [0, 1]에서 균등하게 뽑으면 안 됩니다. 반지름 r 이하의 넓이 비율이 r²이므로 P(R ≤ r) = r²이고, 균등 난수 U의 제곱근 √U가 이 분포를 따릅니다. 바로 앞에서 본 ‘무엇에 대해 균등한가’의 문제가 코드 한 줄에 그대로 들어 있습니다.

실행 예제

import numpy as np

rng = np.random.default_rng(2026)
n = 1_000_000
side = np.sqrt(3)                              # 반지름 1 원에 내접한 정삼각형의 한 변

# 방법 1: 원 위의 두 점을 각각 균등하게
t1, t2 = rng.uniform(0, 2 * np.pi, (2, n))
L1 = 2 * np.abs(np.sin((t1 - t2) / 2))

# 방법 2: 반지름 하나 위에서 중심까지 거리 d를 균등하게
d = rng.uniform(0, 1, n)
L2 = 2 * np.sqrt(1 - d**2)

# 방법 3: 현의 중점을 원판 안에서 균등하게 (넓이에 비례)
r = np.sqrt(rng.uniform(0, 1, n))              # 중점이 중심에서 떨어진 거리
L3 = 2 * np.sqrt(1 - r**2)

for name, L in (("endpoints", L1), ("radius", L2), ("midpoint", L3)):
    print(name, f"{(L > side).mean():.4f}")
endpoints 0.3338
radius 0.5004
midpoint 0.2501

세 시뮬레이션이 각각 1/3, 1/2, 1/4에 맞습니다. 어느 계산도 틀리지 않았습니다. 차이를 한 장으로 보려면 현의 길이 L의 누적분포 F(ℓ) = P(L ≤ ℓ)를 세 방법에서 비교하면 됩니다. 위의 유도에서 방법 1은 F(ℓ) = (2/π) arcsin(ℓ/2), 방법 2는 F(ℓ) = 1 − √(1 − ℓ²/4), 방법 3은 F(ℓ) = ℓ²/4입니다.

무엇이 일어났는지 확률공간의 언어로 정리합니다. 세 방법 모두 표본공간은 같습니다. ‘원의 현 전체’(또는 그것을 매개하는 좌표)입니다. 사건도 같습니다. ‘L > √3’. 다른 것은 확률 P입니다. ‘무작위로’라는 말은 P를 하나로 정하지 못했고, 세 방법은 서로 다른 세 확률측도를 고른 것입니다. 그래서 이것은 확률론의 모순이 아니라 문제가 덜 정해진(ill-posed) 것입니다. 앞 절의 정사각형 예처럼, 현을 매개하는 변수(끝점의 각도, 중심 거리, 중점의 위치)마다 ‘균등’이 다른 측도를 뜻합니다.

그럼 ‘진짜’ 답은 없을까요? E. T. 제인스(1973)는 답이 원의 크기와 위치에 의존하지 않아야 한다는 불변성 요구를 세우면 방법 2가 골라진다고 주장했고, 원을 그린 바닥에 지푸라기를 멀리서 던지는 실험이 이 답과 맞는다고 보고했습니다. 이것은 설득력 있는 하나의 기준이지만 모든 상황에 맞는 유일한 답이라는 뜻은 아닙니다. 현을 실제로 만드는 물리적 절차가 정해지면 측도가 정해지고 답도 하나가 됩니다. 원 둘레에 무작위로 핀 두 개를 꽂는 절차라면 방법 1이 맞습니다.

데이터에서 같은 문제

‘무작위 사용자의 평균 세션 수’를 구할 때 사용자 명단에서 사용자를 뽑는 것과, 세션 기록에서 세션을 뽑아 그 사용자를 보는 것은 다른 측도입니다. 뒤의 방법은 세션이 많은 사용자를 세션 수에 비례해 더 자주 뽑으므로 평균이 커집니다(길이 편향 표집). ‘무작위 표본’이라고만 쓰지 말고, 무엇을 단위로 어떤 절차로 뽑았는지 적어야 확률이 정해집니다.

확률은 무엇을 뜻하는가 이해하기

지금까지 확률 값을 정하는 방법을 보았습니다. 그런데 P(A) = 0.3이라는 수는 세계에 대해 무엇을 말할까요? 대표적인 해석이 둘 있고, 둘 다 같은 공리를 따릅니다. 수학은 해석에 중립적입니다. 해석이 달라지는 곳은 ‘어떤 대상에 확률을 붙여도 되는가’와 ‘값을 어떻게 정당화하는가’입니다.

빈도 해석

빈도 해석(frequentist)에서 P(A)는 같은 조건에서 시행을 한없이 되풀이할 때 A가 일어나는 상대도수의 극한입니다. R. 폰 미제스가 체계화했습니다. 장점은 객관적이고 검증 가능하다는 것입니다. 주사위가 공정한지는 많이 던져 보면 됩니다. 하지만 한계도 분명합니다.

  • 한 번뿐인 사건: ‘이번 선거에서 A 후보가 이길 확률’, ‘이 환자가 이 수술에서 회복할 확률’은 되풀이할 수 없습니다. 빈도 해석은 이런 진술에 엄밀한 뜻을 주기 어렵습니다.
  • 참조 집단 문제: 이 환자를 ‘60대 환자’ 집단에 넣느냐 ‘60대 흡연 남성 당뇨 환자’ 집단에 넣느냐에 따라 상대도수가 다릅니다. ‘같은 조건’은 저절로 정해지지 않습니다.
  • 극한은 관측할 수 없다: 우리는 유한한 횟수만 관측합니다. 그리고 ‘상대도수가 확률로 간다’는 대수의 법칙 자체가 ‘확률 1로’라는 확률 진술이라, 확률을 빈도로 정의하는 데 쓰면 순환이 됩니다.

주관적(베이즈) 해석

주관적 해석(subjective, Bayesian)에서 P(A)는 정보를 가진 한 행위자가 A를 믿는 정도입니다. F. 램지와 B. 드 피네티가 발전시켰습니다. 한 번뿐인 사건에도 확률을 줄 수 있고, 증거가 들어오면 베이즈 규칙(PR03)으로 갱신합니다. 사람마다 사전 정보가 다르면 확률도 다를 수 있습니다.

‘믿음의 정도’라면 아무 수나 써도 되는 것 아니냐는 반문이 생기는데, 그렇지 않습니다. 믿음의 정도를 ‘사건이 일어나면 1을 받는 표를 기꺼이 사고팔 값’으로 정의하면, 공리를 어기는 믿음은 반드시 손해를 봅니다. 예를 들어 P(A) = 0.6, P(Aᶜ) = 0.6으로 믿는 사람은 A 표와 Aᶜ 표를 각각 0.6에 사는 것을 공정하다고 여깁니다. 둘을 모두 사면 1.2를 내고, 어떤 결과가 나와도 정확히 1을 받으므로 0.2를 확실히 잃습니다. 이런 확정 손실 내기를 더치북(Dutch book)이라 하고, 더치북을 당하지 않으려면 믿음이 (유한) 가법성을 포함한 공리를 만족해야 한다는 것이 더치북 논증입니다. 주관적 확률도 공리라는 같은 규칙을 따르는 이유입니다.

빈도 해석주관적(베이즈) 해석
P(A)의 뜻반복 시행에서 상대도수의 극한행위자의 믿음의 정도(내기 값)
한 번뿐인 사건정의하기 어렵다정의된다
공리의 근거상대도수가 0~1이고 배반 사건에서 더해진다더치북을 피하는 정합성
통계에서의 모습신뢰구간·가설검정: 절차의 장기적 성질사후분포: 모수에 대한 믿음의 갱신
약점참조 집단, 관측 불가능한 극한사전분포의 선택이 주관적

두 해석을 잇는 실무 개념이 보정(calibration)입니다. ‘비 올 확률 70%’라고 예보한 날들을 모았을 때 실제로 약 70%의 날에 비가 왔다면 그 예보는 잘 보정된 것입니다. 개별 예보는 주관적 확률이지만, 그 품질은 빈도로 검사합니다. 분류 모델이 출력하는 확률 점수가 실제 빈도와 맞는지 확인하는 보정 곡선(reliability diagram)이 같은 생각입니다.

대수의 법칙 미리 보기 이해하기

빈도 해석과 수학을 잇는 정리가 대수의 법칙입니다. 정확한 진술과 증명은 PR08과 PR12에서 하고, 여기서는 시뮬레이션으로 무엇을 말하고 무엇을 말하지 않는지 봅니다. 공정한 주사위를 10만 번 던지며 6의 상대도수와, 6이 나온 횟수가 기대 횟수 n/6에서 벗어난 양을 기록합니다.

실행 예제

import numpy as np

rng = np.random.default_rng(2026)
rolls = rng.integers(1, 7, size=100_000)       # 공정한 주사위 10만 번
six = np.cumsum(rolls == 6)                    # n번째까지 나온 6의 개수
for n in (10, 100, 1_000, 10_000, 100_000):
    k = six[n - 1]
    print(n, k, f"{k / n:.4f}", f"{k - n / 6:+.1f}")
10 1 0.1000 -0.7
100 14 0.1400 -2.7
1000 166 0.1660 -0.7
10000 1696 0.1696 +29.3
100000 16565 0.1656 -101.7

상대도수는 1/6 ≈ 0.1667로 다가갑니다. 그런데 표의 마지막 열을 보십시오. 6이 나온 횟수와 기대 횟수의 차이는 n = 1만에서 +29.3, 10만에서 −101.7로 커졌습니다. 상대도수가 다가가는 것은 차이가 n보다 느리게 커지기 때문입니다. 차이의 전형적인 크기는 표준편차 √(n × 1/6 × 5/6)로 n = 10만이면 약 118이고, 상대도수의 흔들림은 그것을 n으로 나눈 √(p(1 − p)/n) ≈ 0.0012입니다. 대수의 법칙은 ‘덜 나온 눈이 나중에 더 나와 보충된다’는 말이 아닙니다. 주사위는 과거를 기억하지 않습니다. 앞에서 6이 적게 나왔다고 다음에 6이 나올 확률이 커지지 않으며(도박사의 오류), 초기의 부족분은 보충되는 것이 아니라 뒤에 쌓이는 많은 시행 속에 희석됩니다.

이번에는 경로 하나가 아니라 같은 실험을 1만 번 되풀이하여, 상대도수가 1/6에서 0.02 넘게 벗어나는 실험의 비율을 n별로 셉니다.

실행 예제

import numpy as np

rng = np.random.default_rng(2026)
p, eps, reps = 1 / 6, 0.02, 10_000
for n in (100, 1_000, 10_000):
    freq = rng.binomial(n, p, size=reps) / n   # 같은 실험을 reps번 되풀이
    print(n, f"{np.mean(np.abs(freq - p) > eps):.4f}")
100 0.5905
1000 0.0916
10000 0.0000

벗어날 확률이 n과 함께 0으로 갑니다. 이것이 약한 대수의 법칙의 내용입니다. 서로 독립이고 같은 조건인 시행에서 사건 A의 확률이 p이고 n번 중 상대도수가 fₙ이면, 어떤 ε > 0에 대해서도 P(|fₙ − p| > ε) → 0 (n → ∞)입니다. 베르누이(1713년 Ars Conjectandi)가 처음 증명했습니다. 오늘날 표준적인 짧은 증명은 체비쇼프 부등식을 써서 P(|fₙ − p| ≥ ε) ≤ p(1 − p)/(nε²)라는 상계를 얻고 n → ∞로 보내는 것입니다. 여기에 p = 1/6, ε = 0.02를 넣으면 n = 100, 1000, 10000에서 각각 3.47, 0.347, 0.0347입니다. 실제 비율(0.59, 0.09, 0.00)보다 크므로 상계로서 옳지만 느슨하고, n = 100에서는 1보다 커서 아무 정보도 주지 않습니다.

대수의 법칙이 말하는 것말하지 않는 것
n이 커지면 상대도수가 p에서 ε 넘게 벗어날 확률이 0으로 간다(강한 법칙: 확률 1로 fₙ → p)정해진 n에서 상대도수가 p에 가깝다는 것. 어떤 유한한 n에서도 크게 벗어날 확률은 0이 아니다
(대수의 법칙 자체는 수렴 속도를 말하지 않는다. 흔들림이 대략 √(p(1 − p)/n), 곧 1/√n 크기로 줄어든다는 것은 체비쇼프 부등식과 PR08·3의 중심극한정리가 알려 준다)횟수의 차이 k − np가 줄어든다는 것. 차이는 대략 √n 크기로 커진다
시행이 독립이고 p가 고정되어 있을 때 성립조건이 바뀌는 자료(유행, 계절, 마모되는 주사위)에서도 성립한다는 것
확률 모형 안에서의 수학적 정리확률을 빈도로 순환 없이 정의해 준다는 것

한 줄 정리
