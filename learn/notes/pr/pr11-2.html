PR11·2

야코비안으로 넓이를 바꾸고 조건부 밀도를 구하기

정사각형 안의 점에서 두 좌표를 더하고 뺍니다. 새 점들은 마름모 안에 들어가고, 같은 확률 질량이 다른 넓이에 걸쳐 나타납니다. 그 넓이의 비율로 밀도를 구합니다.

이 장을 읽고 나면

  • 역변환의 야코비안 절댓값과 지지집합을 계산한다.
  • 결합밀도를 적분한 뒤 조건부 밀도를 얻는다.
  • 공분산이 0이어도 독립이 아닐 수 있음을 보인다.

역변환에서 원래 사각형으로 돌아간다

X,Y는 서로 독립인 Uniform(0,1)입니다. 그러므로 정사각형 0<x,y<1에서 결합밀도는 1입니다. U=X+Y, V=X−Y로 바꾸면 역함수는 x=(u+v)/2, y=(u−v)/2입니다. 한 쌍에서 원래 점을 하나로 되찾을 수 있습니다.

역함수의 야코비안은 x,y를 u,v로 미분한 행렬입니다. 두 행이 (1/2,1/2)와 (1/2,−1/2)이므로 행렬식은 −1/2입니다. 밀도 변환에는 방향이 아니라 작은 넓이의 크기가 필요해서 절댓값 1/2를 씁니다. 이 예에서 일대일, 미분 가능하며 역변환의 행렬식이 0이 아닙니다.

새 좌표의 한 단면을 직접 읽는다

0<u+v<2, 0<u−v<2의 두 조건을 합치면 0<u<2, |v|<ℓ(u)이고 ℓ(u)=min(u,2−u)입니다. 범위 내부 결합밀도는 1/2입니다. 마름모의 가로·세로 대각선이 각각 길이 2라 넓이는 2이고, 밀도 1/2를 곱하면 전체 확률이 1입니다.

u를 고정하고 v의 길이 2ℓ(u) 위로 fU,V를 적분하면 주변밀도 fU(u)=ℓ(u)입니다. 0<u<2에서 이 값이 양수이므로 fV|U=u=(1/2)/ℓ(u)=1/[2ℓ(u)]입니다. 지지집합을 따라 조건부로는 균등분포입니다. u=0 또는 2에서는 이 나눗셈으로 조건부 분포를 정의하지 않습니다.

공분산의 0과 독립을 분리한다

Cov(X+Y,X−Y)=Var(X)−Var(Y)=0입니다. Var(U)=Var(V)=1/6입니다. 그럼에도 가능한 V의 폭이 U에 따라 바뀝니다. 예를 들어 0<u<1/2에서는 |V|>1/2가 불가능하고, 1/2<u<3/2의 내부에서는 양의 조건부확률이 있습니다. 길이가 양수인 u 구간들에서 조건부 분포가 달라지므로, 독립이라면 조건부 분포가 동일해야 한다는 성질이 깨집니다.

벡터 Z에 일반 행렬 A를 적용하면, 평균을 뺀 벡터가 A(Z−E[Z])입니다. 이 벡터의 외적을 평균해 Cov(AZ)=A Cov(Z) Aᵀ를 얻습니다. 계산에 필요한 2차 모멘트는 유한해야 합니다. 공분산이 0인 항은 선형적인 동반 변동을 볼 뿐이며, 그림의 모양을 고정하지 않습니다.

from fractions import Fraction as F

def slice_at(u):
    ell = min(u, 2-u)
    if ell<=0:
        return None
    mass_inside_half = min(1, F(1,2)/ell)
    return ell, 1/(2*ell), mass_inside_half

for u in (F(1,4),F(1),F(5,4)):
    print(u,*slice_at(u))
xy_var = F(1,12)
print(2*xy_var,2*xy_var,xy_var-xy_var)

1 1 1/2 1/2
5/4 3/4 2/3 2/3
