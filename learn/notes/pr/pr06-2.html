PR06·2

정규분포와 첫 도착의 지수분포

평균 근처에 값이 몰리는 측정값과 사건이 처음 일어날 때까지의 대기 시간은 서로 다른 모양을 가집니다. 정규분포와 지수분포를 각각 써서 구간 확률, 분위수, 단위를 읽어 봅니다.

이 장을 읽고 나면

  • 정규분포의 평균·표준편차를 읽고, 원래 값을 z점수로 바꾸어 확률과 분위수를 구한다.
  • 일정한 도착률의 포아송 과정에서 건수와 첫 도착 대기 시간의 관계를 설명한다.
  • 대기 시간의 지수분포에서 꼬리 확률을 계산하고, 평균·분산의 단위를 점검한다.

정규분포에서 떨어진 거리를 표준편차로 잰다

반복 측정의 오차처럼 가운데에 값이 몰리고 양쪽으로 갈수록 드물어지는 양을 정규분포로 나타낼 수 있습니다. 평균 μ는 정규분포의 중심이고 표준편차 σ > 0은 퍼진 정도입니다. N(μ,σ²) 표기에서는 두 번째 자리가 분산입니다. 이 장에서는 평균이 50밀리초(ms), 표준편차가 10 ms인 정규 모형을 씁니다.

이 모형에서 60 ms는 평균보다 10 ms 크므로 오른쪽으로 표준편차 한 칸에 있습니다. 40 ms는 왼쪽으로 한 칸입니다. 항상 평균을 뺀 다음 표준편차로 나누면, 원래 수치를 다른 위치나 단위의 모형과 같은 척도에서 읽을 수 있습니다. 이 계산을 표준화라고 합니다.

정규분포 N(μ,σ²)의 밀도는 다음과 같습니다. exp(u)는 eu를 뜻합니다. 곡선은 x=μ에서 가장 높고 좌우 대칭이며, 꼭대기 높이 1/(σ√(2π))는 σ가 작을수록 커집니다. 예를 들어 σ=0.1이면 꼭대기 밀도가 약 3.99로 1을 넘지만, 전체 면적은 여전히 1입니다(PR06-1의 "밀도는 확률이 아니다").

f(x) = 1/(σ√(2π)) · exp(−(x−μ)²/(2σ²)),   −∞ < x < ∞.

정규변수 X ∼ N(μ,σ²)이면 Z = (X−μ)/σ ∼ N(0,1).
원래 값 x = μ + σz.

시간인 분자와 표준편차의 시간 단위가 나누어져 z는 단위가 없습니다. 표준화하면 밀도 그래프의 가로 폭과 높이 척도가 달라집니다. 40~60 ms와 z의 −1~1처럼 서로 대응하는 구간의 확률은 같습니다. 표준화는 원래 모양을 유지한 채 중심과 단위를 바꾸는 계산이므로, 정규분포에 적용하면 표준정규분포가 됩니다.

정규 누적확률과 분위수를 각각 읽는다

표준정규 누적분포함수를 Φ(z) = P(Z ≤ z)라고 씁니다. 정규 밀도의 누적값은 보통 표 또는 수치 계산으로 구합니다. 아래 상자처럼 구간의 양 끝을 각각 표준화한 뒤, 오른쪽 누적값에서 왼쪽 누적값을 뺍니다.

손으로 풀기 · 평균에서 한 칸 안쪽

P(40 ≤ X ≤ 60) = Φ((60−50)/10) − Φ((40−50)/10)
= Φ(1) − Φ(−1) ≈ 0.84134475 − 0.15865525 = 0.68268950.

밀도가 중심에 대해 대칭이므로 P(X > 60)과 P(X < 40)은 각각 약 0.15865525입니다. 두 꼬리를 합하면 약 0.31731050입니다.

반대로 누적확률 0.95를 주고 시간의 95번째 백분위수를 묻는다면, Φ(z)=0.95를 만족하는 z부터 찾습니다. z ≈ 1.64485이므로 시간은 50 + 10(1.64485) ≈ 66.45 ms입니다. 오른쪽 꼬리만 5%인 위치입니다. 가운데 95%를 원하면 양쪽 꼬리가 각각 2.5%여야 하므로 오른쪽 경계에 쓰는 분위수는 Φ의 0.975 분위수입니다.

첫 도착이 늦다는 것은 그때까지 도착이 없다는 뜻이다

앞으로 t시간 동안 기록 장치에 들어오는 사건 수를 N(t), 첫 사건까지 걸리는 시간을 T라고 하겠습니다. 사건의 평균 도착률이 시간당 λ로 일정하고, 겹치지 않는 구간의 도착 수가 독립인 동질 포아송 과정을 가정합니다. 이 과정에서 N(t)는 평균 λt인 포아송분포입니다. t가 커지면 관측하는 구간과 그 안의 평균 사건 수도 늘어납니다.

T > t라는 사건은 시각 t까지 도착 수가 0이라는 사건과 같습니다. 포아송 질량함수에 0건을 넣으면 다음 결과를 얻습니다. t ≥ 0이며 λ > 0입니다.

P(T > t) = P(N(t)=0) = e−λt.
FT(t) = 1 − e−λt,   fT(t) = λe−λt   (t ≥ 0).

이 지수분포에서 음수 시간의 누적확률과 밀도는 0입니다. 위 식에서 e−λt는 꼬리 확률이고, fT(t)는 시간 1단위당 확률이 얼마나 쌓이는지 나타내는 밀도입니다. 밀도에 λ가 붙는 이유는 FT를 미분할 때 e의 지수 −λt의 기울기가 −λ이기 때문입니다.

첫 사건이 30분에서 1시간 사이에 올 확률은 P(T > 0.5) − P(T > 1) = e−1 − e−2 ≈ 0.2325입니다. 이미 30분 동안 아무 일도 없었던 경우, 앞으로 30분도 사건이 없을 조건부 확률은 P(T > 1)/P(T > 0.5) = e−1입니다. 지수분포에서는 경과 시간에 관계없이 추가 대기 시간의 분포가 같으며 이를 무기억성이라고 부릅니다. 식으로 쓰면 모든 s, t ≥ 0에서 P(T > s+t | T > s) = e−λ(s+t)/e−λs = e−λt = P(T > t)입니다. 밀도가 있는 연속분포 가운데 이 성질을 갖는 것은 지수분포뿐입니다. 시간대에 따라 도착률이 오르내리거나 사건이 몰려 발생하는 기록에는 모형 가정을 다시 확인합니다.

평균·분산·표준편차에 단위를 붙인다

이산 확률변수의 기댓값은 값마다 확률 질량을 곱해 더했습니다. 밀도가 있는 X에서는 x에 작은 구간 확률 f(x)dx를 곱해 적분합니다. 기댓값과 분산이 유한할 때 각각 아래와 같이 계산합니다.

E[X] = ∫ x f(x) dx.
Var(X) = ∫ (x−E[X])² f(x) dx = E[X²] − E[X]².

적분 범위는 실수 전체로 두거나 밀도가 양수인 영역만 적습니다. 지수분포에는 부분적분을 쓸 수 있습니다. E[T] = ∫0∞ t λe−λt dt에서 u=t, v=−e−λt로 두면 경계항 [−te−λt]0∞가 0으로 갑니다. 남은 ∫0∞ e−λt dt는 1/λ입니다. 같은 방식으로 E[T²] = 2E[T]/λ = 2/λ²이고, 분산은 2/λ² − (1/λ)² = 1/λ²입니다.

양시간당 λ=2인 예단위
도착률 λ21/시간
평균 1/λ0.5시간
분산 1/λ²0.25시간²
표준편차 1/λ0.5시간

분 단위로 바꾸면 평균과 표준편차에는 60을 곱하지만 분산에는 60²을 곱합니다. 같은 분포의 도착률 λ는 분당 2/60이 됩니다. 일부 도구는 지수분포를 도착률 λ 대신 척도 1/λ로 입력받습니다. 모수 이름과 단위를 확인하면 시간당 2와 평균 0.5시간을 구분할 수 있습니다.

계산기로 정규의 면적과 지수의 꼬리를 확인한다

파이썬의 NormalDist는 누적확률을 계산하는 cdf와 확률을 위치로 바꾸는 inv_cdf를 제공합니다. sigma는 표준편차를 받으므로 10을 입력합니다. 지수 모형에서는 e−λt가 0건의 확률과 같은지 같은 t와 λ를 넣어 대조합니다.

from math import exp, isclose
from statistics import NormalDist

latency = NormalDist(mu=50, sigma=10)
standard = NormalDist()
central = latency.cdf(60) - latency.cdf(40)
assert isclose(central, standard.cdf(1) - standard.cdf(-1))

rate_per_hour = 2
wait_hours = 0.5
mean_count = rate_per_hour * wait_hours
no_arrival = exp(-mean_count) * mean_count**0
tail = exp(-rate_per_hour * wait_hours)
assert isclose(no_arrival, tail)

print(f"40~60 ms 확률: {central:.6f}")
print(f"정규 95번째 백분위수: {latency.inv_cdf(0.95):.2f} ms")
print(f"30분 0건 확률 / 30분 초과 대기: {no_arrival:.6f} / {tail:.6f}")
print(f"30분~1시간 내 첫 도착 확률: {tail - exp(-rate_per_hour):.6f}")
print(f"대기 시간 평균: {1 / rate_per_hour:.2f}시간")
print(f"대기 시간 분산: {1 / rate_per_hour**2:.2f}시간²")
40~60 ms 확률: 0.682689
정규 95번째 백분위수: 66.45 ms
30분 0건 확률 / 30분 초과 대기: 0.367879 / 0.367879
30분~1시간 내 첫 도착 확률: 0.232544
대기 시간 평균: 0.50시간
대기 시간 분산: 0.25시간²

대상계산 기준
정규분포z = (x−μ)/σ. 확률은 Φ로, 확률에서 위치를 찾을 때는 분위수로 계산한다.
고정 구간의 건수와 첫 대기 시간동질 포아송 과정에서 N(t)는 평균 λt인 포아송분포이고 T는 도착률 λ의 지수분포다.
