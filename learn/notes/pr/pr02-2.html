확률 · PR02 조건이 붙는 확률

PR02·2

확률나무에서 경로를 곱하고 더하기

기기를 먼저 구분하고 그 안에서 성공과 실패를 나누면, 같은 접속 기록을 나무처럼 그릴 수 있습니다. 한 경로는 ‘모바일이면서 실패’라는 교사건이고, 실패로 끝나는 경로들을 합치면 기기에 관계없는 실패 확률을 얻습니다.

이 장을 읽고 나면

  • 확률나무에서 가지 확률과 경로 확률을 구별한다.
  • 조건부확률의 곱셈법칙으로 교사건을 계산한다.
  • 서로 겹치지 않는 조건으로 나누어 전확률을 구한다.
  • 비율을 합칠 때 집단 크기를 가중치로 사용한다.

나무의 시작과 첫 갈림길

앞에서 사용한 가상 접속 기록은 모바일 40건, 데스크톱 60건이었습니다. 무작위로 한 요청을 고르면 P(M) = 0.40, P(D) = 0.60입니다. 이를 첫 가지에 적습니다. 다음 가지에서는 기기를 안다는 조건을 씁니다. 모바일에서 실패 12/40 = 3/10, 성공 28/40 = 7/10을 적고, 데스크톱에서 실패 8/60 = 2/15, 성공 52/60 = 13/15를 적습니다.

확률나무에서 같은 마디에서 뻗는 가지들은 그 마디의 조건 안에서 가능한 경우를 빠짐없이, 겹치지 않게 나눕니다. 따라서 같은 마디의 가지 확률을 더하면 1입니다. 모바일 가지 아래의 3/10은 모든 요청의 30%가 모바일 실패라는 뜻이 아닙니다. 이미 모바일인 요청만 놓고 세면 30%라는 뜻입니다.

한 경로에서는 곱한다

‘모바일이면서 실패’라고 말하려면 첫 갈림길에서 모바일에 속하고, 그 안에서 실패에 속해야 합니다. 전체 대상의 40%가 모바일이고, 그 40%의 30%가 실패이므로 전체에서 차지하는 비율은 0.40 × 0.30 = 0.12입니다. 이전 장의 12/100과 같습니다.

곱셈법칙

P(B) > 0일 때 P(B ∩ A) = P(B) × P(A | B)입니다. 조건부확률에서 분모를 옮긴 식입니다. 교사건에서는 A와 B의 순서를 바꿀 수 있어서, 두 조건 사건의 확률이 모두 양수라면 P(A) × P(B | A)로도 같은 값을 얻습니다.

풀이 예제

‘데스크톱이면서 성공’은 60/100 × 52/60 = 52/100입니다. 데스크톱 60건 중에서 계산한 비율을 전체의 60%에 적용한 셈입니다. 경로에 가지가 더 많아지면, 그 앞의 조건을 모두 적은 가지 확률을 차례로 곱합니다. 예를 들어 P(A ∩ B ∩ C) = P(A)P(B | A)P(C | A ∩ B)이고, 조건부확률에 등장한 분모는 각각 양수여야 합니다.

서로 겹치지 않는 경로는 더한다

실패로 끝나는 경로가 두 개 있습니다. ‘모바일 실패’ 12/100과 ‘데스크톱 실패’ 8/100입니다. 한 요청이 두 기기에 동시에 속하지 않으므로, 겹치는 건수가 없습니다. 따라서 P(F) = 12/100 + 8/100 = 20/100입니다.

전확률 법칙

표본공간을 겹치지 않는 사건 B₁, B₂, …로 빠짐없이 나누면, P(A) = Σᵢ P(A ∩ Bᵢ)입니다. 각 P(Bᵢ)가 양수인 가지에서 P(A ∩ Bᵢ) = P(Bᵢ)P(A | Bᵢ)를 씁니다. 확률이 0인 가지는 교사건의 확률도 0이라 건너뜁니다. 여기서는 모바일과 데스크톱이 전체를 나눈 두 사건입니다.

아래 코드는 Fraction을 F라는 이름으로 가져옵니다. 분수로 계산한 값을 보여 줄 때만 소수 둘째 자리까지 표시합니다.

실행 예제

from fractions import Fraction as F

mobile, desktop = F(40, 100), F(60, 100)
fail_if_mobile, fail_if_desktop = F(12, 40), F(8, 60)
paths = {
    "모바일 실패": mobile * fail_if_mobile,
    "모바일 성공": mobile * (1 - fail_if_mobile),
    "데스크톱 실패": desktop * fail_if_desktop,
    "데스크톱 성공": desktop * (1 - fail_if_desktop),
}
for name, p in paths.items():
    print(name, f"{float(p):.2f}")
print("전체 실패", paths["모바일 실패"] + paths["데스크톱 실패"])
print("전체 합", sum(paths.values()))
모바일 실패 0.12
모바일 성공 0.28
데스크톱 실패 0.08
데스크톱 성공 0.52
전체 실패 1/5
전체 합 1

모바일 안의 실패율과 데스크톱 안의 실패율만 단순 평균하면 전체 실패율이 아닙니다. 집단이 차지하는 비중이 40%와 60%로 다르기 때문입니다. 전체 실패율은 집단별 실패율을, 각 집단의 비중으로 가중한 평균입니다. 각 집단의 비중이 바뀌면 집단별 실패율이 같아도 전체 실패율이 달라질 수 있습니다.

기록을 먼저 무엇으로 나눌까

나무는 관측 시간을 뜻할 때도 있고, 단지 같은 자료를 읽는 순서를 뜻할 때도 있습니다. 이 예에서는 기기를 먼저 나눴지만 실패 여부를 먼저 나누어도 됩니다. 첫 가지에 실패 20/100, 다음에 실패 중 모바일 12/20을 두면 같은 모바일 실패 12/100에 도착합니다. 가지고 있는 정보가 어느 조건에 붙어 있는지 보고 먼저 나눌 항목을 정합니다.
