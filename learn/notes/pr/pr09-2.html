PR09·2

전분산: 집단 안의 차이와 집단 사이의 차이

같은 날의 대기시간 8개에는 요청 방식이 달라도 생기는 차이와, 같은 방식 안에서도 남는 차이가 함께 들어 있습니다. 전체 분산을 둘로 나누고 조건부 평균이 제곱오차를 얼마나 줄이는지 확인합니다.

이 장을 읽고 나면

  • 조건부 분산과 조건부 평균의 분산을 구분한다.
  • 집단 비율을 써서 전분산을 검산하고 평균만으로는 알 수 없는 값을 판단한다.
  • 제곱오차 기준에서 조건부 평균이 예측값이 되는 이유를 설명한다.

편차를 두 단계로 나눈다

앞 장과 같은 모형입니다. A 방식의 시간은 3, 3, 5, 5, 7, 7분, B 방식은 8, 10분입니다. 여덟 건 각각을 확률 1/8로 뽑습니다. 집단 변수 G는 A를 확률 3/4, B를 확률 1/4로 취합니다. 전체 평균은 6분, 조건부 평균은 A가 5분, B가 9분입니다.

10분을 관측하면 전체 평균과의 편차는 10−6=4분입니다. 자기 집단의 평균에서 벗어난 10−9=1분과 그 집단 평균이 전체 평균에서 벗어난 9−6=3분의 합입니다. 일반적으로 Y−μ = (Y−m(G)) + (m(G)−μ)입니다. 여기서 μ=E[Y], m(G)=E[Y|G]입니다.

제곱하기 전에 알아 둘 것

위 관측에서는 4²가 1²+3²와 같지 않습니다. 제곱하면 교차항 2×1×3도 생깁니다. 다만 같은 집단 안에서 (Y−m(G))를 평균하면 0이고, 나머지 인수 (m(G)−μ)는 그 집단에서 상수입니다. 교차항은 모든 집단에 대해 평균할 때 0이 됩니다.

조건부 분산과 조건부 평균의 분산은 다르다

A에서 대기시간은 평균 5분을 중심으로 −2, 0, +2만큼, 각각 확률 1/3로 벗어납니다. 따라서 Var(Y|G=A)=(4+0+4)/3=8/3분²입니다. B에서는 평균 9에서 −1과 +1만큼 차이 나므로 Var(Y|G=B)=1분²입니다. 이 여덟 건이 모형 전체여서 집단 내부에서 가능한 값의 확률이 곧 분산의 가중치입니다. 표본으로 모집단 분산을 추정할 때 쓰는 n−1을 이 계산에 적용하지 않습니다.

항계산결과
집단 내부 분산의 평균(3/4)×(8/3) + (1/4)×19/4 = 2.25분²
조건부 평균의 분산(3/4)×(5−6)² + (1/4)×(9−6)²3분²
전체 분산9/4 + 321/4 = 5.25분²

첫째 항은 각 집단에서 평균 주위로 흩어진 정도를 그 집단 비율로 평균한 값입니다. 둘째 항은 개인 대기시간 대신 각 집단의 평균값 5, 9의 분산을 구한 것입니다. 무작위 요청이 A일 때 5, B일 때 9라는 확률변수이므로 두 값에 3/4와 1/4를 그대로 씁니다.

전분산의 법칙

Y의 제곱 기댓값이 유한한 경우 Var(Y)=E[Var(Y|G)] + Var(E[Y|G])입니다. 집단 정보를 모르는 상태에서 직접 얻은 분산을, 조건부 정보를 써서 다시 계산하는 식입니다. 두 항 모두 단위가 Y 단위의 제곱입니다. 표준편차를 집단 비율로 평균하는 공식으로 바꿀 수 없습니다.

전체 자료에서 직접 확인하려면 6을 뺀 뒤 제곱합니다. 3, 5, 7, 8, 10분이 각각 두 번, 두 번, 두 번, 한 번, 한 번 있으므로 제곱합은 2×9+2×1+2×1+4+16=42입니다. 전체 여덟 건으로 나누면 42/8=5.25입니다. 집단 평균과 비율만 있다면 둘째 항까지는 구할 수 있지만, 집단 안의 분산을 모르면 전체 분산은 정할 수 없습니다.

회귀가 예측하려는 평균

집단 정보 없이 대기시간을 숫자 하나 c로 예측한다고 합시다. 제곱오차의 평균 E[(Y−c)²]는 전체 평균 6에서 가장 작고, 그 값은 5.25입니다. G가 알려지면 A에서는 5, B에서는 9를 각각 예측합니다. 이때 제곱오차의 평균은 첫째 항 2.25입니다. 그 차이 3은 집단 평균 사이의 분산입니다.

조건 G=g에서 임의의 예측값 c와 실제 조건부 평균 m을 놓고 Y−c=(Y−m)+(m−c)로 씁니다. 조건부평균을 취한 교차항이 0이므로 E[(Y−c)² | G=g] = Var(Y|G=g)+(m−c)²입니다. 조건별로 가장 작은 오차를 만들려면 c=m을 택합니다. 이것이 제곱오차 기준에서 회귀함수가 조건부 평균을 예측하는 이유입니다. 직선을 쓰는 모형이나 한정된 자료에서 학습한 모형은 그 함수를 근사합니다. 절대오차를 쓰면 적절한 목표가 달라질 수 있습니다.

집단 평균을 예측으로 쓰려면 새 요청이 들어올 때 G가 알려져 있어야 합니다. 여기의 오차 감소는 여덟 건을 모형 전체로 뒀을 때의 계산입니다. 실제 회귀의 새 데이터에서 얼마나 개선되는지는 학습에 쓰지 않은 자료로 확인합니다.

두 방식으로 얻은 분산을 분수로 대조한다

from fractions import Fraction as F

def average(values):
    return F(sum(values), len(values))

groups = ([3, 3, 5, 5, 7, 7], [8, 10])
all_waits = [wait for group in groups for wait in group]
overall = average(all_waits)
means = [average(group) for group in groups]
weights = [F(len(group), len(all_waits)) for group in groups]
group_vars = [
    average([(wait - mean)**2 for wait in group])
    for group, mean in zip(groups, means)
]
within = sum(w * var for w, var in zip(weights, group_vars))
between = sum(w * (mean - overall)**2 for w, mean in zip(weights, means))
direct = average([(wait - overall)**2 for wait in all_waits])
assert direct == within + between

print("A, B 조건부 분산:", *group_vars)
print("집단 내부 평균 분산:", within)
print("집단 평균의 분산:", between)
print("전체 분산:", direct)
A, B 조건부 분산: 8/3 1
집단 내부 평균 분산: 9/4
집단 평균의 분산: 3
전체 분산: 21/4
