확률 · PR02 조건이 붙는 확률

PR02·1

조건이 주어지면 분모가 달라진다

가상의 접속 로그 100건 중 실패는 20건입니다. 그런데 ‘모바일 요청 중 몇 건이 실패했나’라고 물으면 100건 전부를 나눌 수 없습니다. 이미 모바일이라는 것을 알았으니 모바일 40건만 남겨 다시 계산합니다.

이 장을 읽고 나면

  • 조건부확률의 분모와 교사건의 분모를 구별한다.
  • 분할표에서 같은 칸으로 양방향 조건부확률을 구한다.
  • 조건부확률을 계산할 수 없는 경우와 자료의 해석 한계를 설명한다.

표에서 먼저 질문의 집단을 찾기

짧은 기간의 가상 접속 기록입니다. 한 행에는 같은 기기로 분류한 요청의 실패·성공 건수가 있습니다. 이 장에서는 아래 100건 중 하나를 균일하게 고르는 실험을 생각합니다. 그래서 표에 있는 건수를 나눈 값이 이 실험의 확률입니다. 다른 기간의 실패 확률을 알아낼 때는 이 비율이 표본이 주는 정보라는 점을 구별합니다.

기기와 결과에 따라 나눈 접속 기록 (건)
기기실패성공합계
모바일122840
데스크톱85260
합계2080100

두 범주를 교차해 수를 셌으므로 분할표입니다. 행에는 기기, 열에는 결과가 옵니다. 표 내부 한 칸은 기기와 결과를 동시에 만족하는 건수입니다. 가장자리의 합계는 다른 변수를 구별하지 않고 합한 수입니다. 예를 들어 실패한 20건은 12건과 8건을 합한 열 합계입니다.

조건부확률의 분모

M을 ‘모바일’, F를 ‘실패’라고 씁니다. P(F | M)은 ‘모바일이라는 조건에서 실패할 확률’입니다. 세로선 오른쪽 M이 알려 준 조건이고, 왼쪽 F가 알고 싶은 사건입니다. 전체 100건에서 모바일 40건만 남기고, 그중 실패 12건을 세면 P(F | M) = 12/40 = 0.30입니다.

정의

P(B) > 0이면 조건부확률은 P(A | B) = P(A ∩ B) / P(B)입니다. 전체를 기준으로 측정한 P(A ∩ B)를, 조건 B가 차지하는 크기 P(B)로 나눠 B의 범위를 새로운 1로 환산합니다.

같은 자료로 네 질문 풀기

P(F) = 20/100 = 0.20은 기기를 모를 때의 실패 확률입니다. P(M ∩ F) = 12/100 = 0.12는 한 요청이 모바일이면서 실패할 확률입니다. 이제 모바일이라고 알려 주면 P(F | M) = (12/100)/(40/100) = 12/40 = 0.30입니다. 실패했다고 알려 주면 P(M | F) = (12/100)/(20/100) = 12/20 = 0.60입니다.

실행 예제

from fractions import Fraction

mobile_fail, mobile_ok = 12, 28
desktop_fail, desktop_ok = 8, 52
total = mobile_fail + mobile_ok + desktop_fail + desktop_ok
mobile_total = mobile_fail + mobile_ok
failed = mobile_fail + desktop_fail
print(Fraction(failed, total))
print(Fraction(mobile_fail, total))
print(Fraction(mobile_fail, mobile_total))
print(Fraction(mobile_fail, failed))

같은 조건의 경우들은 합해서 1

모바일이라는 조건에서 한 요청은 성공과 실패 중 하나입니다. P(성공 | M) = 28/40 = 0.70이므로 P(F | M) + P(성공 | M) = 1입니다. 같은 조건을 유지하며 두 결과가 겹치지 않고 전체를 채우기 때문입니다. 반대로 P(F | M)과 P(F | 데스크톱)은 분모가 다르므로 둘을 더해 1이 될 필요가 없습니다.

예를 들어 이 표에 태블릿 요청이 0건이라면, 100건 중 한 건을 고르는 실험에서 P(태블릿) = 0입니다. 이 정의로는 P(F | 태블릿)을 계산할 수 없습니다. 현실에서 태블릿 접속이 절대 없다는 뜻은 아닙니다. 지금 있는 표만으로 그 조건의 실패율을 구할 수 없다는 뜻입니다.

실행 예제

from fractions import Fraction

for failed, total in [(12, 40), (8, 60), (0, 0)]:
    if total == 0:
        print("조건에 맞는 행이 없습니다.")
    else:
        print(Fraction(failed, total))

조건에 맞는 행이 없습니다.

차이는 원인과 다르다

이 표에서 모바일의 실패율은 30%이고 데스크톱은 8/60 ≈ 13.33%입니다. 이 두 숫자만으로 기기 종류가 실패의 원인이라고 결론지을 수는 없습니다. 같은 기간이라도 이용한 서비스, 서버, 네트워크 환경이 유형에 따라 달랐을 수 있습니다. ‘모바일 중 실패 비율이 더 높았다’고 관측 범위를 붙여 보고하고, 원인을 알아보려면 비교할 조건을 더 모읍니다.
