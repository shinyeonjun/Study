PR03·1

독립과 배반을 구별하기

월요일에 실패한 요청은 같은 요청에서 성공할 수 없습니다. 반면 동전 앞면과 별도로 던진 주사위 짝수는 동시에 일어날 수 있습니다. 두 사건이 함께 일어날 수 있는지와, 한쪽 정보가 다른 쪽 확률을 바꾸는지는 서로 다른 질문입니다.

이 장을 읽고 나면

  • 곱식과 조건부확률로 두 사건의 독립 여부를 판단한다.
  • 배반의 정의를 교집합으로 표시하고 독립과 구별한다.
  • 복원과 비복원 추출에서 둘째 확률을 계산한다.
  • 관측 자료의 비율을 독립에 관한 확정 결론으로 해석하지 않는다.

한쪽 결과를 알아도 확률이 그대로일 때

공정한 동전과 주사위를 한 번씩 던지는 모형을 생각합니다. 여기서는 동전 2가지와 주사위 6가지의 조합 12개가 등가능하다고 명시합니다. H는 ‘동전 앞면’, E는 ‘주사위 짝수’입니다. 두 줄의 전체에서 짝수는 12개 중 6개이므로 P(E) = 1/2입니다. 앞면 줄만 남겨도 짝수 3개가 6개 중에 있으므로 P(E | H) = 1/2입니다.

정의

두 사건 A, B가 P(A ∩ B) = P(A)P(B)를 만족하면 독립이라고 합니다. P(B) > 0이면 이는 P(A | B) = P(A)와 같은 조건입니다. P(A) > 0이면 반대 방향에서도 P(B | A) = P(B)입니다. 한 사건을 알더라도 다른 사건의 확률이 달라지지 않습니다.

동전·주사위의 경우 P(H ∩ E) = 3/12 = 1/4이고 P(H)P(E) = (1/2)(1/2) = 1/4입니다. 기기의 종류가 모바일일 때 실패 확률이 30%이고 전체에서 실패 확률이 20%였던 PR02의 자료와는 다릅니다. 그 표의 요청 100건 중 한 건을 균일하게 고르는 실험에서는 P(F | M) = 0.30 ≠ 0.20 = P(F)이므로 모바일과 실패가 독립이 아닙니다.

실행 예제

from fractions import Fraction as F
from itertools import product

space = list(product(("앞", "뒤"), range(1, 7)))
heads = [(c, d) for c, d in space if c == "앞"]
even = [(c, d) for c, d in space if d % 2 == 0]
both = [(c, d) for c, d in heads if d % 2 == 0]
p_heads, p_even = F(len(heads), len(space)), F(len(even), len(space))
p_both = F(len(both), len(space))
print(p_heads, p_even, p_both)
print(p_both == p_heads * p_even)
print(F(len(both), len(heads)))

배반은 같은 결과에 두 이름을 붙일 수 없는 경우

주사위 한 번에서 A를 ‘홀수’, B를 ‘짝수’로 두면 A ∩ B = ∅입니다. 두 사건을 배반(서로 배타적)이라고 합니다. 공정한 주사위에서 각각 확률 1/2이지만, 홀수라고 알게 되면 짝수의 확률은 0입니다. 곱식으로도 0 ≠ (1/2)(1/2)라서 독립이 아닙니다.

확률이 양수인 두 배반 사건은 독립일 수 없습니다. 교사건 확률은 0인데 확률의 곱은 양수이기 때문입니다. 한 사건의 확률이 0이면 곱과 교사건 확률이 모두 0이어서 정의상 독립입니다. 예를 들어 여섯 면 주사위에서 ‘7’은 빈 사건으로 보면 어떤 사건과도 배반이며 곱식도 만족합니다. 다만 P(A | ∅)는 분모가 0이므로 조건부확률의 비율식으로 정의하지 않습니다.

교집합이 비어 있지 않다는 이유만으로 독립이라고 단정할 수 없습니다. ‘짝수’와 ‘4 이상’은 4·6이 겹칩니다. 확률은 각각 1/2, 1/2이지만 교사건 확률 2/6은 곱 1/4과 달라서 독립이 아닙니다.

같은 공을 뽑을 때 복원이 하는 일

빨간 공 3개와 파란 공 2개를 잘 섞어 하나를 균일하게 고릅니다. 첫 번째가 빨강일 확률은 3/5입니다. 공을 넣고 다시 같은 방식으로 섞어 고르면 둘째 빨강의 조건부확률도 3/5입니다. 첫 번째 결과가 무엇이든 구성과 선택 규칙이 같으므로 이 모형에서 두 ‘빨강을 뽑는다’ 사건은 독립입니다.

공을 빼놓으면 첫 번째가 빨강이라는 조건에서 빨간 공 2개와 파란 공 2개가 남습니다. 둘째 빨강의 확률은 그 조건에서 2/4입니다. 첫 결과를 모를 때 둘째가 빨강일 (주변)확률은 두 경로를 더해 3/5 × 2/4 + 2/5 × 3/4 = 3/10 + 3/10 = 3/5로, 복원할 때와 같습니다. 그래도 첫째가 빨강이라는 조건에서는 2/4, 파랑이라는 조건에서는 3/4로 둘째 확률이 달라지므로 독립이 아닙니다.

실행 예제

from fractions import Fraction as F

first_red = F(3, 5)
second_if_red = {"복원": F(3, 5), "비복원": F(2, 4)}
for name, prob in second_if_red.items():
    print(name, "둘째 조건부확률:", prob, "두 번 모두 빨강:", first_red * prob)
복원 둘째 조건부확률: 3/5 두 번 모두 빨강: 9/25
비복원 둘째 조건부확률: 1/2 두 번 모두 빨강: 3/10

레이블로 공을 구별하고 순서가 있는 선택을 생각하면, 비복원 추출의 전체 결과는 5 × 4개이고 빨강·빨강 결과는 3 × 2개입니다. 6/20 = 3/10으로 경로를 곱했을 때와 같습니다. 복원 추출이라도 둘째 공을 고르는 규칙을 첫 결과에 따라 바꾸면 독립이 깨질 수 있습니다.

자료에서 독립을 읽을 때

실제 로그에서 두 사건의 비율을 비교할 수 있습니다. 이론상 독립인 시행을 유한 번 반복해도 표의 비율들이 정확히 일치할 필요는 없습니다. 반대로 특정 표에서 우연히 같아도 데이터가 생성된 과정이 반드시 독립이라고 증명되지 않습니다. 실험 설계와 관측 수, 시간 순서 같은 정보를 함께 봅니다.
