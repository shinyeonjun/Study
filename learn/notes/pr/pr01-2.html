공부 교재

확률 · PR01 확률의 언어

PR01·2

공리에서 성질을 끌어내기

주사위의 대칭에서 얻은 1/6, 10만 번 관측에서 얻은 상대도수, 전문가가 말한 ‘내일 비 올 확률 70%’는 출처가 전혀 다르지만 모두 같은 규칙을 따라야 합니다. 그 규칙이 콜모고로프의 세 공리입니다. 이 장에서는 공리 각각이 왜 필요한지 반례로 확인하고, 여사건 규칙부터 포함배제, 합집합 상계, 확률의 연속성까지 모든 기본 성질을 세 공리만으로 증명합니다.

이 장을 읽고 나면

  • 확률공간 (Ω, 𝓕, P)의 세 요소와 σ-대수의 세 조건을 정확히 말할 수 있다.
  • 세 공리 중 하나를 빼면 무엇이 깨지는지 반례로 보일 수 있다.
  • P(∅) = 0, 여사건, 단조성, 덧셈 공식을 공리만으로 증명하고 각 단계에서 쓴 공리를 지목할 수 있다.
  • 포함배제 원리를 증명하고 교란순열 문제에 적용할 수 있다.
  • 합집합 상계와 확률의 연속성을 증명하고, 가산 가법성이 왜 필요한지 설명할 수 있다.

확률공간의 세 요소 외우기

앞 장에서 표본공간 Ω와 사건(Ω의 부분집합)을 정했습니다. 확률 모형을 완성하려면 두 가지가 더 필요합니다. 어떤 부분집합에 확률을 매길지 정한 모임 𝓕, 그리고 그 사건들에 수를 매기는 함수 P입니다. 이 셋을 묶은 (Ω, 𝓕, P)를 확률공간(probability space)이라 합니다. 확률을 이렇게 집합 위의 함수로 정의하고 아래 공리를 세운 사람은 A. N. 콜모고로프(1933년 저서 Grundbegriffe der Wahrscheinlichkeitsrechnung)입니다. 그 뒤 확률론은 측도론의 한 분야로 다루어집니다.

σ-대수 ‘시그마 대수’라고 읽습니다. σ는 ‘가산 개의 합집합’을 뜻하는 관례적 기호입니다. 유한 합집합에만 닫힌 모임은 그냥 ‘대수’라고 합니다.

정의 · σ-대수

Ω의 부분집합들의 모임 𝓕이 다음을 만족하면 σ-대수라 하고, 그 원소를 사건이라 합니다.
① Ω ∈ 𝓕
② A ∈ 𝓕이면 Aᶜ ∈ 𝓕 (여집합에 닫힘)
③ A₁, A₂, … ∈ 𝓕이면 A₁ ∪ A₂ ∪ … ∈ 𝓕 (가산 합집합에 닫힘)

조건에서 바로 따라 나오는 것이 있습니다. ①과 ②로 ∅ = Ωᶜ ∈ 𝓕이고, 드모르간 법칙 ⋂ Aᵢ = (⋃ Aᵢᶜ)ᶜ과 ②③으로 가산 교집합에도 닫힙니다. 즉 사건들을 ‘아님, 그리고, 또는’으로 가산 번 조합해도 여전히 사건입니다. 확률을 매길 대상이 이 연산들로 빠져나가지 않게 하는 것이 σ-대수의 역할입니다.

Ω가 유한하거나 가산이면 보통 모든 부분집합을 𝓕로 씁니다. 그러면 𝓕은 신경 쓸 필요가 없습니다. 그런데 작은 𝓕에도 뜻이 있습니다. 주사위 하나에서 𝓕 = {∅, {1, 3, 5}, {2, 4, 6}, Ω}도 σ-대수입니다(네 집합이 위 연산에 닫혀 있는지 확인해 보십시오). 이 𝓕은 ‘홀짝만 아는 관찰자’가 판정할 수 있는 사건의 모임입니다. 앞 장에서 본 ‘거친 표본공간’은 섬세한 Ω 위의 작은 σ-대수로도 표현되고, 정보가 쌓여 가는 과정을 커지는 σ-대수의 열로 나타내는 것이 확률과정론의 여과(filtration)입니다(PR13). Ω가 비가산일 때 𝓕이 꼭 필요한 이유는 이 장 끝의 ‘더 알아보기’에서 봅니다.

콜모고로프의 세 공리 외우기

정의 · 확률의 공리

함수 P : 𝓕 → ℝ가 다음 세 조건을 만족하면 확률(확률측도)이라 합니다.
(P1) 비음수성: 모든 사건 A에 대해 P(A) ≥ 0
(P2) 정규화: P(Ω) = 1
(P3) 가산 가법성: 쌍마다 배반인 사건 A₁, A₂, …에 대해 P(A₁ ∪ A₂ ∪ …) = P(A₁) + P(A₂) + …

(P3)의 우변은 음이 아닌 항의 무한급수이므로 항상 수렴하거나 +∞로 발산합니다. 좌변이 1 이하의 값이라는 것은 공리에서 따라 나오므로(아래 성질 ⑤) 실제로는 언제나 수렴합니다. 그리고 항의 순서를 바꿔도 합이 같으므로 사건에 번호를 매기는 방식은 결과에 영향을 주지 않습니다.

공리가 하는 일과 하지 않는 일을 구분해야 합니다. 공리는 확률이 서로 어떻게 맞물려야 하는지만 정하고, 주사위의 6이 1/6인지 0.2인지는 정하지 않습니다. 구체적인 값을 정하는 방법(대칭, 기하, 빈도, 믿음)은 다음 장의 주제입니다. 어떤 방법으로 얻은 값이든 이 공리를 어기면 그 값들로는 일관된 계산을 할 수 없습니다.

공리를 하나씩 빼 보기 이해하기

세 조건이 모두 필요한지 확인하는 방법은, 하나를 빼고 나머지 둘만 만족하는 함수를 만들어 무엇이 이상해지는지 보는 것입니다.

뺀 공리나머지를 만족하는 반례 Q무엇이 깨지는가
(P1) 비음수성Ω = {1, 2}, Q({1}) = −0.2, Q({2}) = 1.2, Q(∅) = 0, Q(Ω) = 1. 가법성과 정규화는 성립{2} ⊆ Ω인데 Q({2}) > Q(Ω). 부분이 전체보다 크다. 상대도수나 믿음의 정도로 읽을 수 없다
(P2) 정규화Q(A) = 2 × (A의 원소 수)/6 또는 Q ≡ 0‘반드시 일어남’의 값이 정해지지 않아 0.3이 큰지 작은지 비교할 기준이 없다. Q ≡ 0은 모든 사건을 같게 취급한다
(P3) 가법성주사위에서 Q(A) = (|A|/6)². 0 ≤ Q ≤ 1이고 Q(Ω) = 1Q({1, 2}) = 4/36인데 Q({1}) + Q({2}) = 2/36. 여사건 규칙도 깨진다: Q({1}) + Q({2, …, 6}) = 1/36 + 25/36 ≠ 1
(P3)을 유한 가법성으로 약화Ω = ℕ에서 ‘모든 자연수가 같은 확률’(P3) 아래서는 불가능: P({n}) = c이면 Σ c는 0(c = 0) 또는 ∞(c > 0)이지 1이 아니다. 유한 가법성만 요구하면 이런 함수를 허용하게 되고, 대신 아래의 연속성이 무너진다

세 번째 반례가 가르쳐 주는 것이 있습니다. 0과 1 사이의 값을 갖고 전체가 1이라는 것만으로는 ‘확률답다’고 할 수 없습니다. 확률을 확률답게 만드는 핵심은 배반인 사건의 확률을 더한다는 (P3)이고, 이 장의 거의 모든 증명이 (P3)을 씁니다.

공리에서 끌어내는 기본 성질 이해하기

아래 여섯 성질은 모두 세 공리와 앞 장의 집합 연산만으로 증명됩니다. 각 증명 끝에 쓴 공리를 표시합니다. 증명은 짧지만 ‘어디서 무엇을 썼는지’를 따라가는 연습이 핵심입니다.

① P(∅) = 0. A₁ = Ω, A₂ = A₃ = … = ∅으로 둡니다. ∅은 어떤 집합과도(자기 자신과도) 교집합이 비므로 이 열은 쌍마다 배반이고 합집합은 Ω입니다. (P3)에서 P(Ω) = P(Ω) + P(∅) + P(∅) + …입니다. P(Ω)는 유한한 실수이므로(P는 ℝ 값 함수이고, (P2)로 그 값은 1) 양변에서 빼면 P(∅) + P(∅) + … = 0입니다. 같은 수 c = P(∅)를 무한히 더한 급수는 c = 0일 때만 수렴하므로(c ≠ 0이면 부분합 nc가 ±∞로 감) P(∅) = 0입니다. 이 증명에는 비음수성 (P1)이 필요 없고, P(Ω)가 유한하다는 사실과 (P3)만 씁니다. [P3, P(Ω) 유한]

② 유한 가법성. 쌍마다 배반인 A₁, …, Aₙ에 대해 Aₙ₊₁ = Aₙ₊₂ = … = ∅을 덧붙이면 (P3)과 ①로 P(A₁ ∪ … ∪ Aₙ) = P(A₁) + … + P(Aₙ)입니다. 유한 가법성은 공리가 아니라 정리입니다. [P3, ①]

③ 여사건: P(Aᶜ) = 1 − P(A). A와 Aᶜ는 배반이고 합집합은 Ω이므로 ②와 (P2)로 P(A) + P(Aᶜ) = 1입니다. ‘적어도 하나’의 확률은 직접 세기보다 ‘하나도 없음’의 확률을 1에서 빼는 편이 쉬운 경우가 많습니다. [②, P2]

④ 단조성: A ⊆ B이면 P(A) ≤ P(B). B = A ∪ (B ∖ A)이고 두 조각은 배반이므로 P(B) = P(A) + P(B ∖ A) ≥ P(A)입니다. 같은 식에서 P(B ∖ A) = P(B) − P(A)도 나옵니다. 이 차 공식은 A ⊆ B일 때만 성립합니다. 일반적으로는 P(B ∖ A) = P(B) − P(A ∩ B)입니다. [②, P1]

⑤ 모든 사건에서 P(A) ≤ 1. A ⊆ Ω이므로 ④와 (P2)에서 바로 나옵니다. 공리에 ‘1 이하’가 없는 이유가 이것입니다. 증명할 수 있는 것은 공리로 두지 않습니다. [④, P2]

⑥ 덧셈 공식: P(A ∪ B) = P(A) + P(B) − P(A ∩ B). 겹치지 않는 조각으로 두 번 나눕니다. A ∪ B = A ∪ (B ∖ A)이고, B = (A ∩ B) ∪ (B ∖ A)입니다. 두 분해 모두 배반 조각이므로 ②에서 P(A ∪ B) = P(A) + P(B ∖ A), P(B) = P(A ∩ B) + P(B ∖ A)입니다. 둘째 식에서 P(B ∖ A)를 구해 첫째 식에 넣으면 됩니다. [②]

덧셈 공식에서 바로 두 가지 부등식이 나옵니다. P(A ∩ B) ≥ 0이므로 P(A ∪ B) ≤ P(A) + P(B)이고, P(A ∪ B) ≤ 1이므로 P(A ∩ B) ≥ P(A) + P(B) − 1입니다. 뒤의 것은 ‘두 사건이 모두 일어날 확률’의 하한입니다. P(A) = 0.9, P(B) = 0.8이면 두 사건의 관계를 전혀 몰라도 P(A ∩ B) ≥ 0.7입니다. 사건의 관계를 모를 때 이런 상·하한은 유용합니다.

흔한 실수

P(A ∪ B) = P(A) + P(B)는 배반일 때만 성립합니다. P(A) = 0.7, P(B) = 0.6일 때 그냥 더하면 1.3이 되어 ⑤에 어긋납니다. 합이 1을 넘는다는 사실 자체가 두 사건이 겹친다는 증거입니다(겹침이 적어도 0.3).

포함배제의 원리 이해하기

사건이 세 개면 덧셈 공식을 어떻게 일반화할까요? 세 확률을 더하면 두 사건에 걸친 영역은 두 번, 세 사건 모두에 걸친 영역은 세 번 세어집니다. 쌍마다 교집합을 빼면 두 번 센 영역은 맞춰지지만 세 번 센 영역은 3 − 3 = 0번이 되어 버리므로 다시 한 번 더합니다.

정리 · 포함배제의 원리

P(A ∪ B ∪ C) = P(A) + P(B) + P(C) − P(A∩B) − P(A∩C) − P(B∩C) + P(A∩B∩C).
일반적으로 Sk를 ‘사건 k개를 고른 교집합의 확률을 모든 고르는 방법에 대해 더한 값’이라 하면
P(A₁ ∪ … ∪ Aₙ) = S₁ − S₂ + S₃ − … + (−1)n+1 Sₙ.

증명 1 (세는 횟수). 그림의 논리를 일반화합니다. 이산 표본공간에서 P(E) = Σω∈E p(ω)이므로, 우변에서 각 결과 ω의 p(ω)가 몇 번 더해지는지 세면 됩니다. ω가 정확히 m개(m ≥ 1)의 사건에 속한다고 합시다. k개 사건의 교집합이 ω를 포함하려면 그 k개가 모두 ω를 포함하는 m개 중에서 골라져야 하므로, ω는 Sk에서 C(m, k)번 세어집니다. 따라서 우변에서 ω의 총 계수는

C(m, 1) − C(m, 2) + C(m, 3) − … + (−1)m+1 C(m, m) = 1 − Σk=0m (−1)k C(m, k) = 1 − (1 − 1)m = 1

입니다(둘째 등호는 이항정리, DM03·2). 어떤 사건에도 속하지 않는 ω는 우변에서 0번 세어집니다. 그러므로 우변은 합집합에 속한 결과의 확률을 정확히 한 번씩 더한 값, 곧 P(A₁ ∪ … ∪ Aₙ)입니다. 이 셈을 지시함수로 쓰면 모든 ω에서 성립하는 항등식 1⋃Aᵢ = Σk (−1)k+1 Σ|S|=k 1⋂i∈SAᵢ이 되고, 비가산 공간에서는 양변의 기댓값을 취해 같은 결론을 얻습니다(PR04에서 기댓값의 선형성을 배운 뒤).

증명 2 (귀납법, 모든 확률공간). n = 2는 덧셈 공식 ⑥입니다. n개에서 성립한다고 가정하고 Uₙ = A₁ ∪ … ∪ Aₙ이라 하면 ⑥으로 P(Uₙ ∪ Aₙ₊₁) = P(Uₙ) + P(Aₙ₊₁) − P(Uₙ ∩ Aₙ₊₁)입니다. 분배법칙으로 Uₙ ∩ Aₙ₊₁ = (A₁ ∩ Aₙ₊₁) ∪ … ∪ (Aₙ ∩ Aₙ₊₁)이고, 이것은 n개 사건의 합집합이므로 귀납 가정으로 전개할 수 있습니다. P(Uₙ)의 전개에는 Aₙ₊₁을 포함하지 않는 교집합이, 빼는 항의 전개에는 Aₙ₊₁을 포함하는 교집합이 부호가 하나 바뀌어 나타나고, 둘을 모으면 n + 1개의 공식이 됩니다. 이 증명은 공리에서 얻은 ⑥과 집합 연산만 쓰므로 Ω의 종류와 상관없이 성립합니다.

순서쌍 주사위 공간에서 A₁ = ‘첫째가 6’, A₂ = ‘둘째가 6’, A₃ = ‘합이 10 이상’으로 확인합니다. 결과 36개가 같은 확률이라고 둡니다.

실행 예제

from fractions import Fraction
from itertools import combinations, product

omega = set(product(range(1, 7), repeat=2))
def P(E):
    return Fraction(len(E), len(omega))

A1 = {w for w in omega if w[0] == 6}           # 첫째가 6
A2 = {w for w in omega if w[1] == 6}           # 둘째가 6
A3 = {w for w in omega if sum(w) >= 10}        # 합이 10 이상
events = [A1, A2, A3]

S = []                                         # S_k: k개씩 고른 교집합 확률의 합
for k in range(1, 4):
    S.append(sum(P(set.intersection(*c)) for c in combinations(events, k)))
print(*S)
print(P(A1 | A2 | A3), S[0] - S[1] + S[2])
print(S[0], S[0] - S[1])                       # 한 항에서 끊기, 두 항에서 끊기
1/2 7/36 1/36
1/3 1/3
1/2 11/36

S₁ = 18/36, S₂ = (1 + 3 + 3)/36, S₃ = 1/36((6, 6) 하나)이고, 18 − 7 + 1 = 12개, 곧 1/3이 직접 센 합집합 확률과 같습니다. 마지막 줄은 공식을 중간에서 끊은 값입니다. 첫 항에서 끊은 1/2은 참값 1/3보다 크고, 둘째 항에서 끊은 11/36은 작습니다. 이것은 우연이 아닙니다. 홀수 번째 항에서 끊으면 상한, 짝수 번째 항에서 끊으면 하한이 된다는 것이 본페로니 부등식(Bonferroni inequalities)이고, 첫 항에서 끊은 것이 다음 절의 합집합 상계입니다.

응용: 교란순열(맞추기 문제)

편지 n통을 봉투 n개에 무작위로 넣습니다(n!개의 배치가 같은 확률). 적어도 한 통이 제 봉투에 들어갈 확률은? Aᵢ = ‘i번 편지가 i번 봉투에’라 합시다. 특정한 k통이 모두 제자리에 있는 배치는 나머지 n − k통을 아무렇게나 놓는 (n − k)!개이므로 P(⋂i∈S Aᵢ) = (n − k)!/n!이고, k통을 고르는 방법이 C(n, k)가지이므로

Sk = C(n, k) × (n − k)!/n! = 1/k!   ⇒   P(적어도 하나 제자리) = 1 − 1/2! + 1/3! − … + (−1)n+1/n!

입니다. 이 합은 e−1의 급수 Σ (−1)k/k!와 비교하면 n → ∞에서 1 − 1/e ≈ 0.632로 갑니다. 각 Aᵢ의 확률 1/n은 n이 클수록 작아지지만 사건 수 n이 함께 커져, 답은 n에 거의 의존하지 않습니다.

실행 예제

import math
from fractions import Fraction
import numpy as np

def p_match(n):                                # 포함배제: 고정점이 하나 이상일 확률
    return sum(Fraction((-1) ** (k + 1), math.factorial(k)) for k in range(1, n + 1))

for n in (2, 3, 4, 10):
    print(n, p_match(n), round(float(p_match(n)), 6))
print(round(1 - math.exp(-1), 6))

rng = np.random.default_rng(2026)
n, trials = 10, 200_000
perm = rng.permuted(np.tile(np.arange(n), (trials, 1)), axis=1)
hit = (perm == np.arange(n)).any(axis=1)
print(f"{hit.mean():.4f}")

3 2/3 0.666667
4 5/8 0.625
10 28319/44800 0.632121
0.632121
0.6330

n = 10에서 이미 1 − 1/e와 소수 여섯째 자리까지 같습니다. 마지막 줄은 무작위 순열 20만 개를 실제로 만들어 센 상대도수 0.6330으로, 정확한 값 0.6321과 0.001 정도 다릅니다. 시행 20만 번에서 이 정도 흔들림은 자연스럽습니다(얼마가 자연스러운지는 PR08에서 다룹니다). 공식은 정확한 값을, 시뮬레이션은 공식을 잘못 세웠는지에 대한 독립적인 점검을 줍니다.

합집합 상계 이해하기

정리 · 불(Boole)의 부등식, 합집합 상계

임의의 사건 A₁, A₂, …(유한 또는 가산 개)에 대해 P(A₁ ∪ A₂ ∪ …) ≤ P(A₁) + P(A₂) + …. 사건 사이의 관계(독립, 배반 등)에 대한 가정이 전혀 필요 없습니다.

증명. 겹치는 사건들을 겹치지 않는 조각으로 바꿉니다. B₁ = A₁, B₂ = A₂ ∖ A₁, B₃ = A₃ ∖ (A₁ ∪ A₂), 일반적으로 Bₙ = Aₙ ∖ (A₁ ∪ … ∪ Aₙ₋₁)로 둡니다. Bₙ은 ‘Aₙ에서 처음으로 일어난 부분’입니다. 그러면 (i) Bᵢ들은 쌍마다 배반이고(i < j이면 Bⱼ는 Aᵢ를 뺐는데 Bᵢ ⊆ Aᵢ), (ii) ⋃ Bᵢ = ⋃ Aᵢ이며(⋃Aᵢ의 원소 ω는 자기가 속한 가장 작은 번호의 Bₙ에 들어감), (iii) Bᵢ ⊆ Aᵢ입니다. 따라서 P(⋃ Aᵢ) = P(⋃ Bᵢ) = Σ P(Bᵢ) ≤ Σ P(Aᵢ)입니다. 둘째 등호에 (P3), 부등호에 단조성 ④를 썼습니다. [P3, ④]

그림처럼 겹침이 클수록 상계는 느슨해집니다. 반대로 사건들이 거의 배반이면 상계는 거의 정확합니다. 이 부등식이 쓸모 있는 이유는 가정이 필요 없다는 데 있습니다. 대표적인 두 장면입니다.

다중 검정. 효과가 없는 가설 m개를 각각 유의수준 α로 검정하면, 각 검정이 거짓 양성을 낼 확률이 α이므로 ‘적어도 하나 거짓 양성’의 확률은 검정들이 어떻게 얽혀 있든 mα 이하입니다. 그래서 전체 오류를 α 이하로 묶으려면 각 검정을 α/m에서 하면 됩니다. 이것이 본페로니 보정입니다.

학습 이론. 가설(모델) h가 유한 개 있을 때 ‘어떤 가설이든 훈련 오차와 실제 오차가 ε 넘게 벌어진다’는 사건은 가설별 사건의 합집합입니다. 가설 하나에 대한 확률을 집중부등식으로 묶은 뒤 합집합 상계로 가설 수만큼 곱하면 모든 가설에 동시에 성립하는 보장이 나옵니다. 머신러닝의 일반화 이론에서 가장 기본적인 논증입니다.

실행 예제

alpha = 0.05
for m in (1, 5, 10, 20, 50):
    exact = 1 - (1 - alpha) ** m               # 독립일 때의 정확한 값
    bound = min(1.0, m * alpha)                # 합집합 상계(독립 가정 없음)
    print(m, round(exact, 4), round(bound, 4))
1 0.05 0.05
5 0.2262 0.25
10 0.4013 0.5
20 0.6415 1.0
50 0.9231 1.0

m이 작을 때 두 값이 가까운 것은 1 − (1 − α)m ≈ mα(α가 작을 때의 1차 근사)이기 때문입니다. m = 20부터 상계는 1이 되어 쓸모가 없습니다. 상계는 항상 옳지만 항상 쓸모 있지는 않습니다. 덧붙여, 같은 논리를 여사건에 쓰면 교집합의 하한 P(A₁ ∩ … ∩ Aₙ) ≥ 1 − Σ P(Aᵢᶜ)를 얻습니다(드모르간으로 (⋂Aᵢ)ᶜ = ⋃Aᵢᶜ). 신뢰구간 여러 개가 동시에 참값을 덮을 확률을 보장할 때 쓰는 식입니다.

확률의 연속성 이해하기

공정한 동전을 계속 던질 때 ‘언젠가는 앞면이 나온다’의 확률은 1일까요? 직관적으로는 분명하지만, 이 사건은 무한히 많은 던지기에 걸쳐 있어 유한한 계산으로는 직접 다룰 수 없습니다. 이런 극한 사건을 다루는 도구가 연속성입니다.

정리 · 확률의 연속성

(아래에서 올라감) A₁ ⊆ A₂ ⊆ …이고 A = ⋃ Aₙ이면 P(Aₙ) → P(A).
(위에서 내려옴) B₁ ⊇ B₂ ⊇ …이고 B = ⋂ Bₙ이면 P(Bₙ) → P(B).

증명. 커지는 열에서 C₁ = A₁, Cₙ = Aₙ ∖ Aₙ₋₁(n번째 단계에서 새로 더해진 부분)으로 두면 Cₙ들은 쌍마다 배반이고, C₁ ∪ … ∪ Cₙ = Aₙ, ⋃ Cₙ = A입니다. (P3)으로 P(A) = Σn=1∞ P(Cₙ)이고, 무한급수의 값은 부분합의 극한이므로 P(A) = lim Σk=1n P(Cₖ) = lim P(Aₙ)입니다(마지막에 유한 가법성). 줄어드는 열은 여사건으로 바꿉니다. Bₙᶜ는 커지고 ⋃ Bₙᶜ = Bᶜ(드모르간)이므로 P(Bₙ) = 1 − P(Bₙᶜ) → 1 − P(Bᶜ) = P(B)입니다. [P3, ②, ③]

동전에 적용합니다. Aₙ = ‘처음 n번 안에 앞면이 나온다’는 커지는 열이고 ⋃ Aₙ = ‘언젠가 앞면’입니다. 던지기가 서로 영향을 주지 않으면 P(Aₙ) = 1 − (1/2)ⁿ이므로 P(언젠가 앞면) = lim (1 − 2⁻ⁿ) = 1입니다. 같은 말을 줄어드는 열로 하면 Bₙ = ‘처음 n번이 모두 뒷면’은 줄어들고 ⋂ Bₙ = ‘영원히 뒷면’이므로 그 확률은 lim 2⁻ⁿ = 0입니다. 앞 장에서 미뤄 둔 ‘영원히 뒷면’ 결과의 확률이 이렇게 0으로 정해집니다. 확률 0이지만 불가능한 결과는 아닙니다.

가산 가법성이 왜 필요한가

증명에서 (P3)을 쓴 곳은 한 군데, P(⋃Cₙ) = Σ P(Cₙ)입니다. 사실 이 관계는 거꾸로도 성립합니다. 유한 가법성과 ‘아래에서 올라가는 연속성’을 가정하면 가산 가법성이 나옵니다. 쌍마다 배반인 A₁, A₂, …에 대해 Dₙ = A₁ ∪ … ∪ Aₙ은 커지는 열이고, 유한 가법성으로 P(Dₙ) = Σk≤n P(Aₖ), 연속성으로 P(Dₙ) → P(⋃Aₖ)이므로 P(⋃Aₖ) = Σ P(Aₖ)입니다. 즉 가산 가법성 = 유한 가법성 + 연속성입니다.

그러니 (P3)을 유한 가법성으로 약화하면 잃는 것은 정확히 ‘극한과 확률을 바꿀 권리’입니다. 앞의 표에 나온 ‘자연수 위의 균등’이 그 예입니다. 그런 함수 Q가 있다면 각 점의 값 c = Q({n})은 유한 가법성만으로도 0이어야 합니다(서로 다른 점 n개의 합집합에서 nc ≤ 1이 모든 n에서 성립해야 하므로). 그러면 Aₙ = {1, …, n}은 ℕ으로 커지지만 Q(Aₙ) = n × 0 = 0이 끝까지 0이고, Q(ℕ) = 1로 뛰어오릅니다. 강한 대수의 법칙, 마팅게일 수렴, 강화학습에서 ‘결국 목표에 도달한다’ 같은 정리는 모두 극한 사건의 확률을 다루므로, 연속성 없이는 증명할 수 없습니다. 콜모고로프가 유한 가법성이 아니라 가산 가법성을 공리로 고른 이유가 여기에 있습니다. (반면 de Finetti 같은 주관주의 확률론자는 유한 가법성만 요구해야 한다고 주장했습니다. 표준 교과서는 가산 가법성을 씁니다.)

흔한 실수

위에서 내려오는 연속성은 P(B₁)이 유한하다는 사실(확률은 1 이하)을 씁니다. 길이 같은 일반 측도에서는 깨질 수 있습니다. Bₙ = [n, ∞)는 줄어들어 ⋂ Bₙ = ∅이지만 각 Bₙ의 길이는 ∞입니다. 확률을 넘어 측도로 갈 때(RA04) 이 조건을 다시 만납니다.

더 알아보기 · 모든 부분집합에 확률을 줄 수는 없다

왜 𝓕을 ‘모든 부분집합’으로 두지 않고 σ-대수라는 번거로운 장치를 둘까요? [0, 1)에서 점을 균등하게 고르는 모형을 생각합니다. 균등하다면 확률은 평행이동해도 변하지 않아야 합니다(끝을 넘으면 0으로 감아 돌리는 평행이동, 곧 원 위의 회전). 그런데 다음 정리가 있습니다.

비탈리(Vitali)의 정리. [0, 1)의 모든 부분집합에 정의되고, 가산 가법적이며, 회전에 대해 불변이고, 전체가 1인 함수는 존재하지 않는다.

증명의 뼈대. x − y가 유리수일 때 x ~ y라 하면 [0, 1)이 동치류로 나뉩니다(DM07의 동치관계와 분할). 각 동치류에서 원소를 하나씩 골라 집합 V를 만듭니다(여기서 선택공리를 씁니다). [0, 1)의 유리수 q마다 V를 q만큼 회전한 Vq를 만들면, 이 집합들은 쌍마다 배반이고 합치면 [0, 1) 전체이며 유리수가 가산 개이므로 가산 개입니다. 회전 불변이면 모든 Vq의 확률이 P(V) = c로 같으므로 (P3)에서 1 = c + c + c + …입니다. c = 0이면 우변은 0, c > 0이면 ∞이므로 모순입니다.

결론은 확률을 매길 수 있는 집합을 제한해야 한다는 것입니다. 구간에서 출발해 여집합과 가산 합집합으로 만들 수 있는 집합들(보렐 σ-대수)에는 길이가 일관되게 정의되고, 실제 분석에서 만나는 집합은 모두 여기에 들어갑니다. 비탈리 집합 같은 집합은 선택공리 없이는 만들 수조차 없으므로 실무에서 마주칠 일은 없습니다. 이 구성은 RA04·1에서 측도의 언어로 다시 다룹니다.

한 줄 정리

확률의 모든 계산 규칙은 비음수성·정규화·가산 가법성 세 공리에서 ‘겹치지 않는 조각으로 나누어 더한다’는 한 가지 기술로 증명되며, 가산 가법성은 극한 사건의 확률을 다룰 수 있게 해 줍니다.
