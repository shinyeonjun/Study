PR04·2

기댓값·분산과 실제 보상

고정 선택은 항상 2점입니다. 다른 선택은 자주 0점, 가끔 8점인데 두 선택의 평균은 똑같이 2점입니다. 확률표에서 이 평균을 구하고 한 번에 받는 보상과 얼마나 다른지 계산합니다.

이 장을 읽고 나면

  • 확률을 가중치로 써서 기댓값을 계산한다.
  • 변동하는 보상의 분산과 표준편차를 검산한다.
  • 모형의 기댓값, 반복해서 얻은 평균, 한 번의 결과를 구별한다.

확률을 가중치로 평균 내기

연습 프로그램에서 과제 하나를 해결할 때 얻는 점수를 보상이라고 하겠습니다. 고정 선택의 보상 S는 항상 2점입니다. 변동 선택의 보상 V는 3/4의 확률로 0점, 1/4의 확률로 8점입니다. 이 숫자는 설명을 위해 정한 모형입니다.

정의

가능한 값이 유한 개일 때 확률변수 X의 기댓값 E[X]는 Σ x · p(x)입니다. 각 값에 그 값이 발생할 확률을 곱해 모두 더합니다. 가중치들의 합은 1이므로 다시 값의 종류 수로 나누지 않습니다.

계산 예제

E[S] = 2 × 1 = 2점입니다. E[V] = 0 × 3/4 + 8 × 1/4 = 2점입니다. 변동 선택 V에서 한 번의 보상은 0점이나 8점뿐이라 2점은 나올 수 없습니다. 확률로 평균을 낸 값과 실제 한 번의 결과를 구분합니다.

앞 장의 동전에서도 E[X] = 0 × 1/4 + 1 × 1/2 + 2 × 1/4 = 1입니다. 기댓값이 실제 가능한 값인지는 분포마다 다릅니다. 값이 셀 수 있게 무한히 많다면 합이 잘 정의되는 조건이 중요합니다. 여기서는 유한한 보상표로 계산합니다.

평균이 같을 때는 평균에서 벗어난 정도를 본다

V에서 보상 0의 편차는 −2점, 보상 8의 편차는 +6점입니다. 확률을 곱해 그냥 더하면 (−2) × 3/4 + 6 × 1/4 = 0입니다. 평균을 기준으로 위와 아래가 상쇄되어 변동을 보여 주지 못합니다. 편차를 제곱한 뒤 그 값을 확률로 평균 내면 퍼짐을 확인할 수 있습니다.

정의

분산 Var(X)는 E[(X − μ)²]입니다. 여기서 μ = E[X]입니다. 확률을 이미 아는 모형에서 사용하는 식입니다. 표본으로 모르는 모집단 분산을 추정할 때 배운 n − 1로 다시 나누지 않습니다. 표준편차는 분산의 제곱근이며 원래 변수가 가진 단위로 돌아옵니다.

V가 낸 보상확률평균과의 차이차이의 제곱 × 확률
0점3/4−2점4 × 3/4 = 3점²
8점1/46점36 × 1/4 = 9점²

분산은 3 + 9 = 12점², 표준편차는 √12 ≈ 3.46점입니다. S는 항상 평균과 같으므로 편차가 0이고 분산도 0입니다. 계산이 간단할 때는 Var(X) = E[X²] − (E[X])²를 써도 됩니다. (X − μ)² = X² − 2μX + μ²로 풀고 아래 절의 선형성을 쓰면 기댓값이 E[X²] − 2μ·E[X] + μ² = E[X²] − 2μ² + μ² = E[X²] − μ²이 되어 이 식을 얻습니다. 여기서 E[X²] = Σ x² · p(x)처럼, X의 함수 g(X)의 기댓값은 X의 확률을 그대로 쓰고 값만 g(x)로 바꿔 더합니다. V에 적용하면 E[V²] = 0² × 3/4 + 8² × 1/4 = 64/4 = 16, 16 − 2² = 12로 같은 답입니다.

from fractions import Fraction
from math import sqrt

pmf = {0: Fraction(3, 4), 8: Fraction(1, 4)}
mean = sum(x * p for x, p in pmf.items())
var = sum((x - mean) ** 2 * p for x, p in pmf.items())
second_moment = sum(x**2 * p for x, p in pmf.items())
assert var == second_moment - mean**2
print(f"기댓값: {mean}점")
print(f"분산: {var}점²")
print(f"표준편차: {sqrt(var):.2f}점")

실행 결과

기댓값: 2점
분산: 12점²
표준편차: 3.46점

단위를 바꾸거나 더할 때의 기댓값과 분산 외우기

보상 규칙을 바꿔, 변동 선택의 점수를 3배하고 참가 점수 1점을 얹는다고 합시다. 새 보상 Y = 3V + 1은 3/4 확률로 3 × 0 + 1 = 1점, 1/4 확률로 3 × 8 + 1 = 25점입니다. 정의대로 계산하면 E[Y] = 1 × 3/4 + 25 × 1/4 = 7점이고, 편차는 −6과 +18이므로 Var(Y) = 36 × 3/4 + 324 × 1/4 = 27 + 81 = 108점²입니다. 이 값은 아래 성질로 바로 얻을 수 있습니다.

기댓값과 분산의 성질 (a, b는 상수)

① E[aX + b] = aE[X] + b
② Var(aX + b) = a²Var(X), 표준편차는 |a| × SD(X)
③ E[X + Y] = E[X] + E[Y] — 독립이 아니어도 항상 성립
④ X와 Y가 독립이면 Var(X + Y) = Var(X) + Var(Y)

①은 Σ (ax + b)p(x) = aΣ x p(x) + bΣ p(x) = aE[X] + b에서 나옵니다(확률의 합이 1). ②에서 b가 사라지는 이유는 모든 값을 b만큼 옮기면 평균도 b만큼 옮겨 편차가 그대로이기 때문이고, a가 제곱되는 이유는 편차가 a배가 된 뒤 제곱되기 때문입니다. 예에서 E[Y] = 3 × 2 + 1 = 7, Var(Y) = 3² × 12 = 108, 표준편차는 3 × 3.46 ≈ 10.39점으로 정의대로 계산한 값과 같습니다.

③과 ④는 두 확률변수를 더할 때 씁니다. 변동 선택을 서로 영향 없이 두 번 하여 보상 V₁, V₂를 합치면 E[V₁ + V₂] = 2 + 2 = 4, Var(V₁ + V₂) = 12 + 12 = 24입니다. 직접 확인하면 합은 0(확률 3/4 × 3/4 = 9/16), 8(0과 8의 두 순서, 2 × 3/4 × 1/4 = 6/16), 16(1/16)이고, 기댓값은 8 × 6/16 + 16 × 1/16 = 4, 분산은 (0−4)² × 9/16 + (8−4)² × 6/16 + (16−4)² × 1/16 = 9 + 6 + 9 = 24입니다.

흔한 실수 · 2V와 V₁ + V₂

한 번의 보상을 두 배로 하는 2V는 0 또는 16점이라 Var(2V) = 2² × 12 = 48입니다. 독립인 두 번의 합 V₁ + V₂는 높고 낮은 결과가 서로 상쇄될 수 있어 분산이 24에 그칩니다. 평균은 둘 다 4입니다. 또 ④는 독립(뒤의 PR07에서는 더 약한 조건인 공분산 0)이 있어야 성립하며, ③은 그런 조건이 필요 없습니다.

평균 보상을 한 번의 결과와 구별한다

각 시행에서 이전 시행이 새 결과에 영향을 주지 않고, 변동 선택 V의 확률이 일정하다고 가정합니다. 그 모형을 코드로 여러 번 반복해 봅니다. rng.random() < 0.25가 참이면 8점, 나머지는 0점으로 기록합니다. 같은 기록에서 처음 1번, 10번, 100번, 10,000번의 평균을 차례로 구합니다.

from random import Random

rng = Random(14)
rewards = [8 if rng.random() < 0.25 else 0 for _ in range(10_000)]
for n in (1, 10, 100, 10_000):
    first_n = rewards[:n]
    print(f"{n}: {sum(first_n) / n:.3f}")

실행 결과

1: 8.000
10: 0.800
100: 2.320
10000: 1.970

이 실행에서 처음에는 8점이 나오고 몇 번씩 묶어 평균을 내면 수치가 달라집니다. 시행을 늘렸을 때 평균이 기댓값에 가까워지는 까닭은 PR08에서 다룰 대수의 법칙(큰수의 법칙)과 연결됩니다. 위 성질 ②·④로 미리 보면, 독립인 n번의 평균은 기댓값이 2로 그대로이고 분산은 n × 12 / n² = 12/n으로 줄어듭니다. 매번 시행을 하나 더 할 때 오차가 줄어드는 보장은 없습니다. 또한 이 결과는 설정한 확률 모형을 확인한 것으로, 현실의 보상 확률이 1/4임을 입증하지 않습니다.

평균 목표를 적기

목표가 한 번에 적어도 1점을 얻는 것이라면 고정 선택은 항상 성공하지만 변동 선택은 1/4만 성공합니다. 같은 모형을 반복할 때 평균 점수만 묻는다면 두 선택의 기댓값은 같습니다. 어느 선택이 나은지 말하기 전에 평균, 목표 달성 확률, 변동 중 무엇을 비교할지 정합니다. 강화학습에서도 주어진 상태에서 어떤 행동을 골랐을 때의 보상 분포와 기댓값을 생각합니다. 상태와 정책이 달라지며 결과가 이어지는 경우에는 이 단순 반복 모형과 다른 구조가 됩니다.

왜 그럴까?

100번째 시행 후의 평균보다 101번째 시행 후의 평균이 기댓값에 더 멀어질 수 있을까요?

모범 답 보기

그럴 수 있습니다. 새 보상 하나가 지금의 평균을 어느 방향으로 바꾸는지는 새 결과에 달려 있습니다. 반복 평균의 장기 성질이 각 단계 오차의 단조 감소를 뜻하지 않습니다.

한 줄 정리

기댓값은 값을 확률로 가중 평균한 수이고 분산은 편차 제곱의 기댓값이며, E[aX + b] = aE[X] + b, Var(aX + b) = a²Var(X)이고 합의 분산은 독립일 때만 그냥 더합니다.
