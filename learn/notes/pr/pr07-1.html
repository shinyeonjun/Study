결합분포표에서 주변분포와 조건부분포 읽기

임의의 주문 한 건을 뽑아 주문 유형과 지연 여부를 함께 기록합니다. 같은 표의 24건을 보더라도 ‘모든 주문에서’와 ‘배달 주문에서’는 분모가 달라집니다.

이 장을 읽고 나면

  • 결합확률표의 칸, 행·열 합계가 나타내는 확률을 구분한다.
  • 조건에 맞는 행이나 열을 골라 그 안에서 합이 1이 되도록 다시 나눈다.
  • 결합확률과 주변확률의 곱을 비교하여 두 변수가 독립인지 판단한다.

한 주문에 두 값을 붙인다

주문 유형 X는 매장이면 0, 배달이면 1로 기록합니다. 지연 여부 Y는 제때면 0, 지연이면 1입니다. 0과 1은 분류 이름을 대신하는 코드입니다. 아래 100건 중 한 건을 같은 확률로 고르는 작은 모형을 씁니다. 주문 모집단 전체의 확률을 추정하려면 이 100건의 수집 방식도 확인해야 합니다.

결합확률질량함수 p(x,y)는 X=x와 Y=y가 동시에 성립할 확률 P(X=x, Y=y)입니다. 쉼표는 두 조건을 함께 만족한다는 뜻입니다. 이 표에서 p(1,1)=24/100=0.24입니다. 모든 칸의 확률은 0 이상이고 합은 1입니다.

한쪽 정보만 남기려면 다른 쪽을 합한다

X가 무엇이든 지연될 확률은 지연 열의 합 0.12+0.24=0.36입니다. 이렇게 변수 하나만의 분포를 주변분포라고 합니다. pY(y)=Σxp(x,y)처럼 관심 있는 y를 고정하고 가능한 x에 대해 합합니다. X의 주변분포라면 x를 고정하고 모든 y에 대해 합합니다. 두 주변분포만 보아서는 주문 유형과 지연을 어느 칸에 어떻게 짝지었는지 대체로 복원할 수 없습니다.

조건을 알게 되면 무엇을 새로 1로 볼까

배달 주문인 것을 안다면 분모가 100에서 40으로 바뀝니다. 배달 40건 중 지연 24건이므로 P(Y=1 | X=1)=24/40=0.60입니다. 나머지 제때의 확률은 16/40=0.40입니다. 이렇게 조건 안에서 두 확률의 합이 다시 1이 되도록 만든 것이 Y의 조건부분포입니다.

조건의 방향 확인

p(y | x)=p(x,y)/pX(x)는 pX(x)>0인 행에서 계산합니다. 반대로 P(X=1 | Y=1)은 지연 열 합계를 분모로 쓰므로 24/36=2/3입니다. 분자는 같지만 질문과 분모가 바뀝니다.

표에 주문 유형 X=2가 한 건도 없어서 주변확률이 0이라면, 이 모형에서 X=2를 고정해 같은 나눗셈을 할 수 없습니다. 건수 0인 세부 칸과 분모 전체가 0인 조건은 구분합니다.

조건을 알 때 분포가 그대로라면

가능한 모든 (x,y)에서 p(x,y)=pX(x)pY(y)이면 X와 Y는 독립입니다. 확률이 양수인 X 조건을 골랐을 때 Y의 분포가 주변분포와 같다는 말로도 표현할 수 있습니다. 한 칸이라도 곱이 어긋나면 독립이 아닙니다. 일반적인 표에서는 한 칸의 일치만으로 모든 칸이 맞는다고 결론 내릴 수 없습니다.

결합 표와 독립일 때의 값 비교

배달이며 지연된 실제 결합확률은 0.24입니다. 독립이라면 0.40×0.36=0.144이어야 합니다. 또 주문 전체 지연 확률 0.36과 배달이라는 조건의 지연 확률 0.60도 다릅니다. 이 100건을 같은 확률로 뽑는 모형에서는 두 변수가 독립이 아닙니다.

이 비교는 두 값의 관련성을 보여 줍니다. 주문 유형이 지연의 원인이라는 결론을 얻으려면 거리, 시간대 등도 살펴야 합니다. 관측한 표에서의 계산과 더 큰 모집단에 대한 통계적 판단도 서로 다른 단계입니다.

분자와 분모를 코드에서 따로 확인한다

행 번호를 X, 열 번호를 Y의 코드와 맞춥니다. 분수의 연산에는 Fraction을 쓰고 소수는 마지막 출력에서 표시합니다. 독립 조건의 곱이 모든 칸에서 맞는지도 검사합니다.

from fractions import Fraction

counts = [[48, 12], [16, 24]]
row_totals = [sum(row) for row in counts]
column_totals = [sum(column) for column in zip(*counts)]
total = sum(row_totals)
joint = [[Fraction(cell, total) for cell in row] for row in counts]
px = [Fraction(count, total) for count in row_totals]
py = [Fraction(count, total) for count in column_totals]
delayed_given_delivery = joint[1][1] / px[1]
delivery_given_delayed = joint[1][1] / py[1]

assert sum(px) == sum(py) == 1
assert sum(p / px[1] for p in joint[1]) == 1
independent = all(
    joint[i][j] == x_prob * y_prob
    for i, x_prob in enumerate(px)
    for j, y_prob in enumerate(py)
)
print("배달과 지연:", joint[1][1])
print("지연 | 배달:", delayed_given_delivery)
print("배달 | 지연:", delivery_given_delayed)
print("독립:", independent)
배달과 지연: 6/25
지연 | 배달: 3/5
배달 | 지연: 2/3
독립: False

모든 칸의 합, 주변 합, 조건부 합을 점검한다

결합표 전체는 1입니다. 행의 합을 모은 X 주변분포도 1, 열의 합을 모은 Y 주변분포도 1입니다. 확률이 양수인 한 행이나 열을 조건으로 선택한 뒤, 작은 표 안에서 다시 계산한 확률들의 합도 1입니다. 다음 장에서는 값이 연속적으로 바뀔 때 칸을 합하는 대신 면적을 적분합니다.
