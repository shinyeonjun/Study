확률 · PR11 연속 확률의 변수변환

PR11·1

제곱처럼 되돌리는 길이 둘일 때 새 확률밀도 구하기

온도 차이 −1과 1을 제곱하면 같은 수가 됩니다. 변환 뒤 한 값이 원래 여러 곳에서 올 수 있으므로, 어느 길이로부터 확률이 들어오는지 먼저 셉니다.

이 장을 읽고 나면

  • 누적분포를 원래 표본공간에서 직접 계산한다.
  • 일대일이 아닌 변환을 여러 분기로 나눈다.
  • 밀도의 발산과 한 점에 놓인 확률을 구별한다.

변환된 사건을 원래 변수로 읽는다

X가 −1에서 2까지 길이 3의 균등분포라고 둡니다. W=X²의 누적확률은 FW(w)=P(X²≤w)입니다. w≥0이면 −√w≤X≤√w가 원래 사건입니다. 이 구간을 X가 들어 있는 [−1,2]와 교차해 길이를 3으로 나눕니다.

w의 범위X에 남는 구간누적확률
w<0공집합0
0≤w≤1[−√w,√w]2√w/3
1<w<4[−1,√w](1+√w)/3
w≥4[−1,2]1

내부의 분기를 미분해 밀도를 구한다

0<w<1에서는 두 쪽이 함께 움직여 fW(w)=1/(3√w)입니다. 1<w<4에서는 왼쪽 끝이 이미 −1로 고정되어 1/(6√w)입니다. 다른 열린 구간에서는 0입니다. 누적분포는 0,1,4에서 연속이므로 그 지점만을 정확히 관측할 확률은 0입니다. 0 근처에서 밀도가 커져도 폭이 0으로 줄 때 확률이 0으로 갑니다.

단조 구간마다 역함수를 써도 같습니다. 제곱의 역분기 x=±√w에서 |dx/dw|=1/(2√w)입니다. 원래 밀도 1/3을 곱하면 두 분기가 모두 유효할 때 두 항이 생기고, x<−1인 분기가 사라지면 하나가 남습니다. 역분기 공식은 해당 구간 내부에서 미분과 역미분이 가능한 곳에 사용합니다.

평균은 밀도를 먼저 만들지 않아도 구할 수 있다

W의 기댓값은 X²의 기댓값입니다. 균등밀도로 x²를 −1부터 2까지 적분하면 (2³−(−1)³)/9=1입니다. W²의 기댓값은 x⁴를 적분해 (2⁵−(−1)⁵)/15=11/5입니다. 따라서 Var(W)=11/5−1=6/5입니다. 변환 뒤 밀도를 적분해도, 처음 X를 통해 계산해도 같은 결과를 얻습니다.

from fractions import Fraction as F
from math import sqrt

def cdf(w):
    if w < 0:
        return 0
    r = sqrt(w)
    return max(0,min(2,r)-max(-1,-r))/3

for w in (.25,1,2.25,4):
    print(f"{cdf(w):.6f}")
mu = F(2**3-(-1)**3,9)
second = F(2**5-(-1)**5,15)
print(mu,second,second-mu**2)
