현재 상태와 여러 단계의 전이

현재 상태에 따라 다음 상태의 확률이 정해지는 모형을 만듭니다. 한 걸음의 화살표를 표로 옮기고, 가능한 경로를 합해 두 걸음 뒤의 확률을 계산합니다.

이 장을 읽고 나면

  • 상태를 정하고, 다음 상태의 확률을 정하는 데 현재 상태가 충분하다는 가정을 설명한다.
  • 전이행렬에서 행과 열의 역할을 읽고, 확률의 한 걸음 이동을 행벡터로 계산한다.
  • 지정한 경로의 확률을 곱하고, 시작과 끝 사이의 여러 경로를 합해 두 걸음 전이를 구한다.

다음 상태를 설명하는 데 필요한 정보를 정한다

서버의 부하를 1분마다 관찰하고 낮으면 L, 높으면 H로 기록한다고 합시다. t번째 관찰의 상태를 St라고 쓰겠습니다. 다음 분의 부하가 H일 확률을 구할 때 현재 부하 등급만으로 충분하다고 가정하면, 과거 기록의 나머지 부분을 조건에서 뺄 수 있습니다.

P(St+1=j | S0=i0, …, St=i) = P(St+1=j | St=i).

조건에 붙인 사건의 확률이 양수일 때 이 관계가 모든 시각과 가능한 이력에서 성립하면 마르코프 성질을 만족합니다. 과거의 영향이 현재 상태에 반영되어 있어도 됩니다. 예컨대 H가 오래 지속된 서버와 방금 H가 된 서버의 다음 상태 확률이 다르면, 현재 등급 하나만 담은 상태로는 가정이 성립하기 어렵습니다. 최근 부하나 H의 지속 시간을 상태에 추가하고, 그 표현이 충분한지 다시 살펴볼 수 있습니다.

이 장에서는 한 걸음의 확률이 어느 시각에서도 같은 시간 동질 모형을 씁니다. 점심과 자정의 전이확률이 다르면 시간에 따라 행렬을 달리할 수 있습니다. 시간 동질성과 마르코프 성질은 별개의 가정입니다.

한 행은 출발 상태를 고정한 확률분포다

가상의 부하 모형에서 낮은 부하는 다음 분도 낮을 확률이 3/4입니다. 높은 부하는 L과 H로 각각 1/2의 확률로 갑니다. 자기 자신으로 향하는 화살표는 한 분이 지났고 상태 등급이 같았음을 뜻합니다.

행을 출발, 열을 도착으로 정하면 전이행렬 P의 원소 Pij는 P(St+1=j | St=i)입니다. 행과 열 모두 (L,H) 순서로 놓습니다.

출발 ↓ / 도착 →LH행 합
L3/41/41
H1/21/21

각 행의 원소가 음이 아니고 합이 1입니다. 열은 서로 다른 출발 조건의 확률을 모은 것이니 합이 1일 필요가 없습니다. 이 예에서 첫 열의 합은 5/4입니다. 책이나 프로그램에서 상태를 열벡터로 놓고 다른 관례를 쓸 수 있습니다. 열을 출발로 두는 관례의 행렬은 이 장 P의 전치 Pᵀ이고, 그때는 열 합이 1이며 분포 열벡터 π에 왼쪽에서 곱해 πt+1 = Pᵀπt로 씁니다. 두 관례의 결과는 같으므로, 자료를 읽을 때 행 합과 열 합 중 어느 쪽이 1인지부터 확인합니다. 여기서는 행을 출발, 분포는 행벡터로 계속 사용합니다.

현재 상태가 L일 확률이 0.6이고 H일 확률이 0.4라면, 현재 분포는 p0 = (0.6, 0.4)입니다. 다음 분에 H일 확률은 L에서 온 0.6·(1/4)와 H에서 온 0.4·(1/2)를 더한 0.35입니다. L일 확률도 같은 방식으로 0.65입니다.

pt+1 = ptP.   (pt+1)j = Σi(pt)iPij.

지정한 경로는 곱하고 가능한 경로를 더한다

L에서 시작해 두 걸음 뒤가 H인 사건을 봅시다. 중간 상태가 L인 경로 L→L→H와 중간 상태가 H인 경로 L→H→H 두 가지가 있습니다. 시작이 L이라는 조건에서 각 경로의 확률을 따로 계산합니다.

첫 경로의 확률은 P(S1=L | S0=L) · P(S2=H | S1=L,S0=L)입니다. 마르코프 가정으로 두 번째 항에서는 S1만 남겨 PLH를 쓸 수 있습니다. 두 경로는 중간 상태가 달라 동시에 일어날 수 없으므로 확률을 더합니다.

P(S2=H | S0=L) = (3/4)(1/4) + (1/4)(1/2) = 5/16.

가능한 모든 중간 상태 k를 합하는 식은 행렬곱의 정의와 같습니다. (P²)ij = ΣkPikPkj입니다. P²의 모든 원소는 두 걸음 뒤 도착 확률이며, P²는 P의 원소를 각자 제곱한 배열과 다릅니다. 같은 전이행렬이 매번 쓰인다면 n걸음 뒤 분포는 p0Pn입니다.

경로의 합과 행렬곱을 계산해 대조한다

파이썬에서 @는 행렬곱입니다. p0는 길이 2인 1차원 배열이며, p0 @ P에서 왼쪽에 있으므로 행벡터의 계산으로 해석합니다. P[0, 1]은 (L 출발, H 도착)입니다.

import numpy as np

P = np.array([[0.75, 0.25], [0.50, 0.50]])
p0 = np.array([0.60, 0.40])
two_steps = P @ P
via_L = P[0, 0] * P[0, 1]
via_H = P[0, 1] * P[1, 1]
assert np.isclose(two_steps[0, 1], via_L + via_H)
assert np.allclose(two_steps.sum(axis=1), 1)

def row_text(row):
    return " ".join(f"{value:.4f}" for value in row)

for label, row in zip(("L", "H"), two_steps):
    print(f"{label} 출발, 두 걸음: {row_text(row)}")
print(f"한 걸음 뒤 분포: {row_text(p0 @ P)}")
print(f"두 걸음 뒤 분포: {row_text(p0 @ two_steps)}")
print(f"L에서 H로 두 걸음: {via_L:.4f} + {via_H:.4f}")
L 출발, 두 걸음: 0.6875 0.3125
H 출발, 두 걸음: 0.6250 0.3750
한 걸음 뒤 분포: 0.6500 0.3500
두 걸음 뒤 분포: 0.6625 0.3375
L에서 H로 두 걸음: 0.1875 + 0.1250

두 번째 행을 검산하면 H에서 H로 끝나는 경로는 H→L→H의 1/8과 H→H→H의 1/4입니다. 합은 3/8 = 0.375입니다. 다음 장에서는 같은 행렬을 여러 번 곱할 때 분포가 어디로 가는지 봅니다.

한 걸음 뒤 분포현재 행벡터 pt에 오른쪽으로 P를 곱한다.
여러 걸음 뒤 도착 확률경로 안에서는 전이확률을 곱하고, 서로 다른 경로를 더한다.
