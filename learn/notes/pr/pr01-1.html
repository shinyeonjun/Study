PR01·1

가능한 결과와 그중에 묻는 사건

주사위를 한 번 던질 때 ‘짝수가 나올까’와 ‘4가 나올까’는 같은 질문이 아닙니다. 던지는 일은 같아도 결과를 묶는 방식이 다릅니다. 먼저 가능한 결과를 정하고, 관심 있는 결과만 골라 사건으로 표시합니다.

이 장을 읽고 나면

  • 시행·결과·표본공간·사건을 구별한다.
  • 여사건과 교집합·합집합을 결과 목록으로 적는다.
  • 등가능성 가정이 있을 때만 결과 수의 비로 확률을 계산한다.
  • 모형으로 정한 확률과 실제 관측 빈도를 구별한다.

한 번 무엇을 하고, 무엇을 기록하나

주사위를 한 번 던져 위쪽 눈을 기록합니다. 던져서 결과 하나를 얻는 일을 시행, 이번에 얻은 눈 4를 결과, 기록할 수 있는 모든 눈의 집합 Ω = {1, 2, 3, 4, 5, 6}을 표본공간이라고 합니다. 기호 Ω는 ‘오메가’라고 읽습니다. 시행에 들어가기 전에 눈이 모서리에 서는 경우를 어떻게 처리할지도 정해야 한 번의 기록이 무엇인지 명확해집니다. 예제에서는 눈 하나가 잘 나오도록 던졌다고 가정합니다.

정의

사건은 표본공간에서 관심 있는 결과들을 모아 놓은 부분집합입니다. 사건 A가 {2, 4, 6}이라면 4가 나왔을 때 A가 일어났다고 합니다. 5가 나왔다면 일어나지 않은 것입니다. P(A)는 사건 A의 확률로, 0에서 1 사이의 값을 가집니다. 전체 사건 Ω의 확률은 1이고, 결과가 하나도 없는 빈 사건 ∅의 확률은 0입니다.

무엇을 결과로 삼는지는 질문에 따라 달라집니다. 동전을 두 번 던져 순서까지 기록하면 앞앞, 앞뒤, 뒤앞, 뒤뒤가 결과입니다. 앞면 개수만 기록하면 기록값은 0, 1, 2입니다. 기록을 덜 자세하게 바꿔도 세 기록값의 확률이 같아지지는 않습니다. 값 1에는 순서가 다른 두 결과가 함께 들어가기 때문입니다(아래 ‘결과를 세어도 되는 조건’).

여사건, 그리고, 또는

같은 주사위에서 A를 ‘짝수’, B를 ‘4 이상’으로 둡니다. A가 아닌 결과들이 여사건 Aᶜ = {1, 3, 5}에 속합니다. 한 결과는 A와 Aᶜ 중 정확히 하나에 속합니다. 따라서 P(Aᶜ) = 1 − P(A)입니다.

‘짝수이면서 4 이상’은 교사건 A ∩ B = {4, 6}입니다. ‘짝수이거나 4 이상’은 합사건 A ∪ B = {2, 4, 5, 6}입니다. 확률에서 ‘또는’은 둘 다 만족하는 경우도 포함합니다.

풀이 예제

모든 눈이 같은 확률이라고 가정합니다. A의 3개와 B의 3개를 그냥 더하면 4와 6을 두 번 셉니다. 한 번씩 빼면 3 + 3 − 2 = 4개입니다. 그래서 P(A ∪ B) = P(A) + P(B) − P(A ∩ B) = 4/6입니다. 이 덧셈 공식은 눈의 확률이 달라도 성립합니다. 다만 그때는 각 눈의 확률을 더해야 합니다.

아래 Python 예제에서는 Fraction(분자, 분모)으로 분수를 정확하게 계산합니다. sorted는 집합의 결과를 눈으로 비교하기 쉽도록 순서 있는 목록으로 보여 줍니다.

실행 예제

from fractions import Fraction

omega = set(range(1, 7))
a = {2, 4, 6}
b = {4, 5, 6}
print(sorted(omega - a))
print(sorted(a & b))
print(sorted(a | b))
print(Fraction(len(a | b), len(omega)))
[1, 3, 5]
[4, 6]
[2, 4, 5, 6]
2/3

확률이 지켜야 할 세 규칙 이해하기

확률을 어떻게 정하든(등가능 가정이든, 관측 자료든) 다음 세 규칙을 지켜야 합니다. 이를 확률의 공리(Kolmogorov의 공리)라고 합니다. 두 사건이 같은 결과를 하나도 공유하지 않을 때, 즉 A ∩ B = ∅일 때 두 사건을 배반(서로 배타적)이라고 부릅니다.

확률의 공리

① 모든 사건 A에서 P(A) ≥ 0.
② P(Ω) = 1.
③ A와 B가 배반이면 P(A ∪ B) = P(A) + P(B). 서로 배반인 사건이 셀 수 있게 무한히 많아도 확률을 모두 더한 것이 합사건의 확률입니다.

앞에서 쓴 성질은 모두 이 세 규칙에서 나옵니다. A와 Aᶜ는 배반이고 합치면 Ω이므로 ③과 ②에서 P(A) + P(Aᶜ) = 1입니다. 여기에 A = Ω를 넣으면 P(∅) = 0입니다. 덧셈 공식은 A ∪ B를 배반인 두 조각 A와 B ∩ Aᶜ로 나누고, B도 배반인 A ∩ B와 B ∩ Aᶜ로 나누어 ③을 두 번 쓰면 얻습니다. 겹침이 없는 배반 사건에서는 빼는 항 P(A ∩ B)가 0이라 그냥 더하면 됩니다.

결과를 세어도 되는 조건

가능한 n개 결과 각각의 확률이 같으면 하나당 1/n입니다. 이런 결과들을 등가능하다고 말합니다. 따라서 사건 E의 확률은 P(E) = E에 든 결과 수 / 전체 결과 수로 구합니다. 유한한 결과를 다룰 때 쓰는 계산이고, 단지 결과의 이름을 나열했다고 각 이름의 확률이 같아지는 것은 아닙니다.

공정한 동전을 같은 조건에서 서로 영향 없이 두 번 던진다고 가정합니다. 순서까지 구별한 네 결과 앞앞·앞뒤·뒤앞·뒤뒤는 각각 1/4입니다. 앞면 개수로 묶으면 0개에는 뒤뒤 하나, 1개에는 앞뒤와 뒤앞 둘, 2개에는 앞앞 하나가 들어갑니다. 그러므로 개수 0·1·2의 확률은 각각 1/4, 1/2, 1/4입니다.

코드에서 product는 두 번의 결과를 순서 있게 짝지으며, Counter는 앞면 개수별로 몇 조합인지 셉니다.

실행 예제

from collections import Counter
from itertools import product

outcomes = list(product(("앞", "뒤"), repeat=2))
counts = Counter(pair.count("앞") for pair in outcomes)
print([counts[k] for k in (0, 1, 2)])
[1, 2, 1]

흔한 실수

‘앞면 개수의 값은 0, 1, 2 세 종류이니 모두 1/3’이라고 판단하면, 두 순서가 한 값에 합쳐진다는 점을 놓칩니다. 쉽게 셀 수 있는 등가능 결과를 먼저 고릅니다.

관측 빈도와 모형의 확률

한 번씩 던져 기록한 눈이 1, 2, 1, 4, 1, 1, 2, 6이라면 1의 도수는 4, 상대도수는 4/8 = 0.5입니다. 공정한 주사위 모형에서의 확률 1/6과 같을 필요는 없습니다. 모형은 시행 전 가정에 따른 가능성을 말하고, 관측 빈도는 실제 자료에서 이루어진 횟수를 셉니다.

실행 예제

from fractions import Fraction

rolls = [1, 2, 1, 4, 1, 1, 2, 6]
print(rolls.count(1), len(rolls))
print(Fraction(rolls.count(1), len(rolls)))
print(Fraction(1, 6))
4 8
1/2
1/6

같은 조건에서 서로 영향을 주지 않는 시행을 많이 반복하면 상대도수가 모형 확률에 가까워지는 경향이 있습니다. 다만 시행을 하나 늘릴 때마다 오차가 반드시 줄어드는 것은 아니고, 몇 번 안 되는 관측에서 상대도수가 모형 확률과 다르다고 바로 모형이 틀렸다고 결론 내릴 수도 없습니다. 실험 전에 시행 조건과 집계 방법을 정하고, 횟수와 조건을 함께 기록합니다.
