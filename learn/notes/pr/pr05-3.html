PR05·3

포아송분포: 정해진 구간 안에서 몇 건인가

가상의 알림 서비스에 10분 동안 알림이 평균 2건 도착한다고 합시다. 다음 10분에 정확히 2건일 수도, 0건이거나 더 많을 수도 있습니다. 처음 알림까지 얼마나 걸리는지와 정해진 구간에 몇 건이 들어오는지부터 구분합니다.

이 장을 읽고 나면

  • 고정 구간의 건수와 첫 사건까지의 대기 시간을 구분한다.
  • 도착률에 구간 길이를 곱해 포아송 모수 λ를 구하고 확률을 계산한다.
  • 이항 근사가 맞을 만한 조건과 로그 데이터에서 가정이 어긋날 사례를 든다.

이번에는 시도 번호가 아니라 시간 구간을 고정한다

알림을 언제 보든 10분을 정해 두고 그동안 들어온 알림의 수 K를 기록합니다. 예를 들어 [09:00, 09:10)에서 끝인 09:10에 들어온 알림은 다음 구간에 넣습니다. 경계의 값을 두 번 세지 않게 정한 것입니다. K에는 0도 가능하고, 모형은 유한한 최대 횟수를 미리 정하지 않습니다. ‘첫 알림까지 몇 초인가’는 다른 확률변수이며 여기서는 세지 않습니다.

시간당 평균 도착률이 일정하게 12건이라고 하면 10분은 1/6시간이라 평균 건수는 2건입니다. 20분에서는 4건입니다. 서로 다른 길이의 구간을 비교할 때 먼저 관측 시간의 단위를 맞춥니다.

도착률과 모수

시간당 건수 같은 단위가 붙은 도착률 r에 구간 길이 t를 곱해 포아송 모수 λ(람다)를 얻습니다. λ = rt는 해당 구간의 평균 건수입니다. λ가 2.5가 되어도 문제없습니다. 2.5는 평균이고, 실제로 세는 K는 0, 1, 2, … 중 하나입니다.

λ를 알면 각 건수의 확률을 계산한다

포아송 확률질량함수

λ > 0일 때 포아송분포(Poisson distribution)의 정의는 아래와 같습니다. k는 0, 1, 2, …인 정수입니다.

P(K = k) = e−λ × λk ÷ k!

e는 약 2.71828인 상수이고, k!는 1부터 k까지의 곱인 팩토리얼입니다. 0!은 1로 둡니다. λ가 0이라면 모형에서 사건 수는 항상 0입니다.

풀이 예제

10분에 평균 2건이면 정확히 2건의 확률은 e−2 × 2² ÷ 2! = 2e−2 ≈ 0.2707입니다. 적어도 1건은 P(K ≥ 1) = 1 − P(K = 0) = 1 − e−2 ≈ 0.8647입니다. 2건과 적어도 2건도 서로 다른 사건입니다.

이 분포에서는 E[K] = λ, Var(K) = λ입니다. λ = 2에서 기댓값은 2건이고 분산의 수치는 2, 표준편차는 √2 ≈ 1.41건입니다. 두 숫자가 같은 것은 모형의 특징입니다(아래 이항 근사에서 보면, 이항의 분산 np(1 − p)는 p가 0에 가까울수록 평균 np = λ에 가까워집니다). 실제 로그의 구간별 평균과 분산이 표본에서 꼭 일치할 필요는 없습니다.

어떤 도착 과정을 이 모형으로 근사할 수 있나

예의 일정한 도착률 모형에서는 길이가 같은 구간에서 평균 건수가 같습니다. 서로 겹치지 않는 구간의 건수는 독립이라고 가정합니다. 또 아주 짧은 구간을 보면 사건 한 건의 확률은 길이에 대략 비례하고 두 건 이상일 가능성은 그보다 훨씬 빠르게 줄어듭니다. 이런 조건의 도착 과정에서 고정 구간의 건수가 포아송분포를 따릅니다. 모든 건수 자료가 이 과정을 따르지는 않습니다.

실제 서비스에서는 점심에 요청이 몰리거나 서버 오류가 연달아 터질 수 있습니다. 이때 10분이라는 길이를 맞춰도 시간대에 따라 평균이 다르거나, 한 구간에 문제가 생긴 것이 다음 구간에도 이어질 수 있습니다. 먼저 같은 시간대끼리 비교하고 구간별 건수의 분포와 평균·분산을 확인합니다. 평균과 분산이 비슷해도 독립이나 일정한 도착률이 자동으로 증명되지는 않습니다.

많은 독립 시도에서 드문 성공을 세는 경우

앞의 이항분포로도 성공 건수를 셌습니다. 독립 시도 n번이 많고 한 번의 성공확률 p가 작다면, λ = np인 포아송으로 이항 확률을 근사할 수 있습니다. 예를 들어 n = 100, p = 0.02라면 평균은 모두 2에 맞지만 각 확률이 완전히 같지는 않습니다. 실제로는 독립과 같은 p부터 확인하고, 필요한 건수나 꼬리 확률에서 오차가 허용 범위에 드는지도 비교합니다. n과 p의 한 숫자만으로 정확도가 정해지지 않습니다.

왜 λ가 np일까요? n을 늘리며 p를 λ/n으로 낮추면 평균은 계속 λ입니다. 이항의 성공 위치 수 C(n, k)와 성공확률 pk를 합치면, k가 고정일 때 n의 거듭제곱이 상쇄되어 λk/k!에 다가갑니다. 남은 실패 확률 (1 − λ/n)n − k는 e−λ에 다가갑니다. 두 항을 곱하면 포아송 식이 됩니다. 이것은 n을 아주 크게 보낸 결과라서 유한한 n에서는 근사입니다.

비교할 건수: 0~3건
정확값: 이항(100, 0.02)
근삿값: 포아송(2)
from math import comb, exp, factorial, isclose

n, p = 100, 0.02
lam = n * p
def poisson(k):
    return exp(-lam) * lam**k / factorial(k)

assert isclose(1 - poisson(0), 0.8646647167633873)
print("건수  이항 정확값  포아송 근삿값  절대차")
for k in range(4):
    exact = comb(n, k) * p**k * (1 - p)**(n - k)
    approx = poisson(k)
    print(f"{k}    {exact:.6f}      {approx:.6f}        {abs(exact - approx):.6f}")
건수  이항 정확값  포아송 근삿값  절대차
0    0.132620      0.135335        0.002716
1    0.270652      0.270671        0.000018
2    0.273414      0.270671        0.002743
3    0.182276      0.180447        0.001829

위의 절대차는 반올림 전 확률에서 계산했습니다. 출력된 여섯 자리 수만 빼면 마지막 자리가 다를 수 있습니다. 2건에서는 약 0.002743의 차이이고, 0.2743퍼센트포인트로 읽을 수 있습니다. 드문 꼬리 사건에서는 절대차가 작아도 정확한 확률에 견준 차이가 클 수 있으므로, 필요한 사건에서 직접 비교하는 편이 좋습니다.

한 줄 정리

일정한 도착률 r로 독립적으로 일어나는 사건을 길이 t 구간에서 세면 λ = rt인 포아송분포 P(K = k) = e−λλk/k!를 따르고, 평균과 분산이 모두 λ이며, n이 크고 p가 작은 이항(np = λ)의 근사로도 쓰입니다.
