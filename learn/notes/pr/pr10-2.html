정상분포가 있을 때 어디로 수렴하는가

같은 전이행렬을 계속 곱했을 때 분포가 다가가는 곳을 찾아봅니다. 한 걸음 뒤에도 같은 분포를 찾는 식과, 어느 초기 상태에서나 그 분포에 수렴하는 조건을 확인합니다.

이 장을 읽고 나면

  • 한 걸음 뒤에도 그대로인 분포를 πP=π와 합 1 조건으로 구한다.
  • 유한 연쇄에서 기약성과 비주기성이 각각 정상분포의 유일성과 수렴에 어떻게 관여하는지 설명한다.
  • 교대하는 연쇄와 흡수 상태가 있는 연쇄에서 분포의 여러 걸음 변화를 계산한다.

한 걸음 뒤에도 같은 분포를 찾는다

앞 장의 부하 모형에서 행렬 P의 L행은 (3/4, 1/4), H행은 (1/2, 1/2)였습니다. 현재 H일 확률이 h라면 L은 1−h입니다. 다음 분의 H 확률은 (1−h)/4 + h/2 = 1/4 + h/4가 됩니다.

어떤 분포 π에서 출발할 때, 한 걸음 뒤에도 전체 확률벡터가 π라면 이를 정상분포라고 부릅니다. 각 시점의 상태는 계속 움직일 수 있습니다. 분포가 보존된다는 말은 상태별로 들어오는 확률과 나가는 확률이 균형을 이룬다는 뜻입니다.

πP = π,   πi ≥ 0,   Σi πi = 1.

손으로 풀기 · 부하 모형의 정상분포

H의 확률이 그대로라면 h = 1/4 + h/4입니다. 3h/4 = 1/4에서 h = 1/3, L은 2/3입니다. 한 걸음 동안 L→H로 가는 확률의 양은 (2/3)(1/4) = 1/6입니다. H→L의 확률의 양도 (1/3)(1/2) = 1/6으로 같습니다.

초기 H 확률을 h0라고 하면 ht+1 − 1/3 = (ht − 1/3)/4입니다. 매 걸음 차이가 1/4로 줄어들어 ht = 1/3 + (h0 − 1/3)(1/4)t가 됩니다. 이 모형에서는 어느 상태나 초기분포에서 출발해도 해가 (2/3, 1/3)으로 다가갑니다.

유일한 정상분포와 초기분포로부터의 수렴을 나눈다

상태가 유한할 때 정상분포는 적어도 하나 존재합니다. 두 상태 i, j 사이에 확률이 양수인 전이들을 따라 서로 오갈 수 있다는 관계를 소통이라고 합니다. 모든 상태가 서로 소통하면 연쇄는 기약입니다. 유한 기약 연쇄에는 정상분포가 정확히 하나 있습니다.

한 상태에서 출발했다가 같은 상태로 돌아올 수 있는 양의 걸음 수를 모읍니다. 그 수들의 최대공약수를 그 상태의 주기라고 부릅니다. 기약 연쇄에서는 모든 상태의 주기가 같습니다. 주기가 1이면 비주기라고 합니다. Pii > 0이라 한 걸음 만에 돌아올 수 있다면 그 상태의 주기는 1입니다.

유한하고 기약이며 비주기이면, 어느 초기분포 p0에서든 p0Pt가 유일한 정상분포로 수렴합니다. 부하 모형에서는 L↔H가 가능해 기약이고, 자기 상태에 남는 전이도 있어 비주기입니다. 직접 계산한 수렴이 이 조건에 들어맞습니다.

교대와 흡수가 일어나는 두 모형을 비교한다

(가) L과 H가 번갈아 나오는 경우. P의 두 행은 (0,1), (1,0)입니다. 확률벡터에 P를 곱하면 두 좌표가 바뀝니다. 정상분포는 π=(1/2, 1/2) 하나입니다. 이 분포에서 시작하면 계속 같은 분포를 유지합니다. 하지만 L에서 시작하면 분포가 (1,0)과 (0,1)을 계속 오가므로 수렴하지 않습니다. 돌아올 수 있는 걸음 수가 2, 4, 6, …이라 주기가 2입니다. 한 번의 경로에서 L과 H가 차지하는 시간 비율은 각각 1/2에 가까워지지만, 특정 시각의 분포는 계속 교대합니다.

(나) A에 가면 머무르는 경우. A에서 출발하면 다음에도 A인 확률이 1입니다. 이런 A를 흡수 상태라고 합니다. P의 두 행은 (1,0), (1/2,1/2)입니다. B에 있을 확률은 걸음마다 절반이 됩니다. 초기 B 확률이 b0라면 t걸음 뒤에는 b0(1/2)t이고, 어느 초기분포에서나 (1,0)으로 수렴합니다. 정상분포 역시 (1,0) 하나입니다. 이처럼 기약은 위에서 소개한 수렴 보장의 충분조건 중 하나입니다. 기약이 아니어도 흡수 때문에 수렴할 수 있습니다.

A와 B가 둘 다 흡수 상태라면 P는 단위행렬입니다. 처음에 A와 B에 나누어 놓은 확률이 그대로 남기 때문에 모든 초기분포가 정상분포입니다. 하나로 수렴한다고 이야기할 수 있는지는 어느 전이가 가능한지에 달려 있습니다.

작은 두 상태에서 반복을 실행한다

부하 모형은 L과 H에서 각각 시작하고, 교대 모형은 L에서 시작합니다. A만 흡수 상태인 모형은 B에서 시작합니다. 두 상태 모두 흡수 상태인 경우 초기분포 (0.4,0.6)을 씁니다. 각 초기분포와 매 걸음 뒤 분포에서 두 번째 상태의 확률을 기록합니다.

import numpy as np

load = np.array([[0.75, 0.25], [0.50, 0.50]])
alternating = np.array([[0.0, 1.0], [1.0, 0.0]])
absorption = np.array([[1.0, 0.0], [0.5, 0.5]])
fixed = np.eye(2)
stationary = np.array([2 / 3, 1 / 3])
assert np.allclose(stationary @ load, stationary)

def second_state(P, initial, steps):
    p = np.array(initial)
    result = [p[1]]
    for _ in range(steps):
        p = p @ P
        result.append(p[1])
    return " ".join(f"{value:.4f}" for value in result)

print("부하 L 시작:", second_state(load, [1.0, 0.0], 6))
print("부하 H 시작:", second_state(load, [0.0, 1.0], 6))
print("교대 L 시작:", second_state(alternating, [1.0, 0.0], 4))
print("흡수 B 시작:", second_state(absorption, [0.0, 1.0], 4))
print("흡수 둘, 혼합 시작:", second_state(fixed, [0.4, 0.6], 4))
부하 L 시작: 0.0000 0.2500 0.3125 0.3281 0.3320 0.3330 0.3333
부하 H 시작: 1.0000 0.5000 0.3750 0.3438 0.3359 0.3340 0.3335
교대 L 시작: 0.0000 1.0000 0.0000 1.0000 0.0000
흡수 B 시작: 1.0000 0.5000 0.2500 0.1250 0.0625
흡수 둘, 혼합 시작: 0.6000 0.6000 0.6000 0.6000 0.6000

각 줄의 첫 수는 0걸음 확률이고 마지막까지 모두 분포의 둘째 좌표입니다. 6걸음의 0.3333은 출력 형식으로 반올림한 수입니다. 유한 번 반복해서 가까워지는 모습을 보는 것과, 모든 초기 상태에서의 극한을 증명하는 것은 별도의 일입니다.
