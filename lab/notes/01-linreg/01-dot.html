과제 1 · 선형회귀를 바닥부터

01

장바구니 총액이 내적이다

개념부터 읽지 않습니다. 코드를 먼저 돌리고, 숫자를 바꿔 보고, 무슨 일이 일어났는지는 그다음에 봅니다. 이 장에서 만든 함수 dot이 이 과제 끝의 선형회귀까지 그대로 쓰입니다.

이 장을 끝내면

  • 내적 함수 dot, 길이 함수 norm, 코사인 함수 cosine을 numpy 없이 직접 짠다.
  • 내적이 "곱해서 더하기"이면서 동시에 "두 벡터가 얼마나 같은 방향인가"라는 것을 숫자로 확인한다.
  • 선형회귀의 예측 ŷ = w·x + b가 결국 내적 한 번이라는 것을 본다.

먼저 돌려 보기

공책 2권(1,200원), 펜 3자루(800원), 가방 1개(3,000원)를 샀습니다. 아래 세 줄을 파일이나 파이썬 창에 그대로 넣고 실행하기 전에, 나올 숫자를 먼저 머릿속으로 계산해 보세요.

qty = [2, 3, 1]
price = [1200, 800, 3000]
print(qty[0]*price[0] + qty[1]*price[1] + qty[2]*price[2])

실행 결과

7800

같은 자리끼리 곱하고, 그 곱을 모두 더했습니다. 개수 목록과 가격 목록을 "짝지어 곱한 뒤 더하는" 이 계산에 이름이 있는데, 그게 내적입니다. 이름은 나중에 다시 보고, 먼저 손으로 함수를 만듭니다.

함수로 만들기

위 코드는 항목이 3개일 때만 돌아갑니다. 항목이 몇 개든 되도록 함수로 바꿉니다.

직접 짜기

dot(a, b)를 만드세요. 조건은 두 가지입니다.

  1. 길이가 같으면 같은 자리끼리 곱해 모두 더한 값을 돌려준다.
  2. 길이가 다르면 ValueError를 낸다.

다 짰으면 print(dot(qty, price))가 7800을 내는지 확인합니다. for와 zip을 쓰면 짧아집니다.

짠 뒤에 비교하기

먼저 직접 짜 보고 열어 보세요.

한 가지 답 보기 
def dot(a, b):
    if len(a) != len(b):
        raise ValueError("길이가 다릅니다: %d와 %d" % (len(a), len(b)))
    total = 0
    for x, y in zip(a, b):
        total += x * y
    return total

길이 검사를 왜 굳이 넣을까요? 직접 확인해 봅니다.

print(list(zip([1, 2], [3, 4, 5])))

실행 결과

[(1, 3), (2, 4)]

zip은 짧은 쪽이 끝나면 아무 말 없이 멈춥니다. 검사가 없으면 dot([1, 2], [3, 4, 5])가 오류 없이 1·3 + 2·4 = 11을 돌려줍니다. 가격표에서 한 줄이 빠진 실수가 그대로 "총액"이 되어 나오는 셈입니다. 검사를 넣은 함수는 이렇게 멈춥니다.

ValueError: 길이가 다릅니다: 2와 3

바꿔 보기

숫자를 하나씩 바꾸면서 결과를 먼저 예측하고 돌려 봅니다.

바꾼 것코드결과
공책을 4권으로dot([4, 3, 1], price)10200
가격을 모두 2배로dot(qty, [2400, 1600, 6000])15600

공책을 2권 늘리면 총액이 1,200 × 2 = 2,400원 늘어납니다. 가격을 모두 2배로 하면 총액도 정확히 2배가 됩니다. 한쪽을 바꾼 만큼만 결과가 바뀌는 이 성질을 선형성이라고 합니다. 선형회귀의 "선형"이 바로 이 뜻입니다.

무슨 일이 일어난 건가

내적

길이가 같은 두 벡터 a = (a₁, …, aₙ), b = (b₁, …, bₙ)의 내적은

a·b = a₁b₁ + a₂b₂ + … + aₙbₙ

결과는 벡터가 아니라 숫자 하나입니다.

방금 확인한 두 가지가 내적의 핵심 성질입니다.

  • 한쪽을 c배 하면 결과도 c배: (ca)·b = c(a·b). 가격 2배 → 총액 2배.
  • 더한 것의 내적은 내적의 합: (a + a′)·b = a·b + a′·b. 장바구니 두 개를 합쳐 계산하든 따로 계산해 더하든 같습니다.

더 정확한 정의와 증명은 개념 사전의 LA02 내적과 노름에 있습니다.

길이와 방향

내적에는 얼굴이 하나 더 있습니다. 자기 자신과 내적하면 길이의 제곱이 나옵니다.

직접 짜기

norm(a) = √(a·a)를 만드세요. 앞에서 만든 dot과 math.sqrt를 씁니다. norm([3, 4])를 먼저 예측해 보고 돌려 봅니다.

두 벡터의 내적을 각자의 길이로 나누면 −1부터 1 사이의 값이 나옵니다. 이것이 두 벡터 사이 각의 코사인입니다.

def cosine(a, b):
    return dot(a, b) / (norm(a) * norm(b))

for v in ([1, 0], [1, 1], [0, 1], [-1, 0]):
    print(v, round(cosine([1, 0], v), 3))

실행 결과

[1, 0] 1.0
[1, 1] 0.707
[0, 1] 0.0
[-1, 0] -1.0

같은 방향이면 1, 직각이면 0, 반대 방향이면 −1입니다. 내적이 0이면 두 벡터는 직교합니다. 방향이 전혀 겹치지 않는다는 뜻입니다.

이게 왜 선형회귀의 시작인가

집값을 면적과 방 개수로 예측한다고 합시다. 가중치 w = (w₁, w₂)와 절편 b를 정하면 예측은

ŷ = w₁ × 면적 + w₂ × 방 개수 + b = w·x + b

입니다. 장바구니에서 "개수 × 가격"을 더한 것과 똑같은 계산입니다. 선형회귀는 이 w와 b를 자료에 가장 잘 맞게 고르는 일이고, 다음 장들에서 그것을 손으로 만듭니다.

한눈에 정리

한 줄 정리

내적은 "짝지어 곱해 더하기"이고, 그 숫자가 크기와 방향을 함께 담고 있으며, 선형회귀의 예측이 바로 그 계산이다.
