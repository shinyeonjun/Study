덱 6

틀린 만큼 고친다: 손실과 경사하강

오차 → 손실 = 점수 하나 → 손실 곡선 → 기울기 = 고칠 방향 → 한 발씩 → 발 크기

덱 2의 집 2(면적 1, 방 3, 가격 9). 면적 레시피 w를 모른다고 치고 찾아간다.

틀린 양 = 예측 − 정답 = 오차

부호 = 어느 쪽으로 틀렸나(−: 낮게), 크기 = 얼마나. 실제 − 예측으로 적는 책도 있다: 부호만 반대.

오차를 그냥 평균하면 서로 지워진다

둘 다 5만큼 틀렸는데 평균 0. 그래서 부호를 없애고(크기나 제곱) 평균 = 손실: 틀린 정도를 점수 하나로.

절댓값 평균 = MAE, 제곱 평균 = MSE

MAE로는 A가, MSE로는 B가 낫다. 제곱은 넓이라서 큰 실수 하나(8 → 64)가 점수를 끌고 간다.

MAE: 보통의 틀림MSE: 큰 실수를 무겁게MSE 단위 = 가격²RMSE = √MSE: A 4, B 3

잠깐, 직접

w마다 손실 하나 = 손실 곡선

손실(w) = (w + 6 − 9)² = (w − 3)²

학습 = 이 곡선의 바닥 찾기. 곡선 전체는 모른다: 서 있는 자리의 높이와 기울기만 잴 수 있다.

최솟값 = 바닥의 높이 0argmin = 바닥의 자리 w = 3

기울기 = 2 × 오차: 틀린 만큼 크다

기울기 = 2 × (w − 3) = 2 × 오차

기울기 = w를 조금 늘릴 때 손실이 변하는 비율. w = 0에서 0.1 늘리면 손실 ≈ −6 × 0.1 = −0.6.

잠깐, 직접

한 발 = 기울기 반대쪽으로, 학습률만큼

새 w = w − η × 기울기

η(에타) = 학습률: 기울기를 몇 배 해서 움직일지. 빼기라서 기울기가 −면 w가 커진다.

새 자리에서 다시 재면 발이 저절로 작아진다

바닥에 가까울수록 오차가 작다 → 기울기가 작다 → 발이 작다. 틀린 만큼만 고치니 브레이크가 따로 없다.

잠깐, 직접

발이 너무 크면 바닥을 넘어 튕겨 나간다

새 오차 = (1 − 2η) × 오차

배율 0.5 · −0.5 · −1.2. 크기가 1보다 작아야 오차가 준다 → 이 곡선은 η < 1. 음수면 바닥을 넘나든다.

잠깐, 직접

기울기 ≈ 0이면 멈춘다: 평평하다는 뜻일 뿐

이 곡선에선 기울기 = 2 × 오차라 '기울기 작음 = 거의 맞음'. 골짜기가 여럿이면 멈춘 곳이 가장 낮다는 보장은 없다.

잠깐, 직접

경사하강과 MAE·MSE를 코드로

import numpy as np
w, eta = 0.0, 0.25
for k in range(4):
    g = 2 * (w - 3)          # 기울기 = 2 × 오차
    w = w - eta * g          # 한 발
    print(k + 1, w, (w - 3) ** 2)
eA, eB = np.array([0, 0, 0, 8]), np.array([3, 3, 3, 3])
print(np.abs(eA).mean(), (eA ** 2).mean())
print(np.abs(eB).mean(), (eB ** 2).mean())
