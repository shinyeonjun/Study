틀린 만큼 고친다

잔차 → 손실 → 경사하강 → 학습률

모델은 정답과 어긋난 크기를 보고 다음 가중치를 고른다.

틀린 크기를 하나의 점수로

제곱하면 큰 오차 하나가 훨씬 크게 반영된다.

MAE는 원래 단위, MSE는 제곱 단위

예측을 훈련할 때 줄이는 손실과 성능 보고용 지표는 따로 선택할 수 있다.

최솟값과 최소를 만드는 값

L = (w − 3)²

우리가 바꾸는 변수는 w. 기울기는 2(w−3).

잠깐, 직접

경사가 음수면 오른쪽으로 한 발

새 w = w − 학습률·기울기

학습률 .25, 현재 미분 −4: 1 − .25×(−4) = 2.

같은 규칙을 다시 쓴다

한 발 갈 때마다 새 가중치에서 기울기를 다시 잰다.

잠깐, 직접

너무 큰 발걸음은 최소를 건너뛴다

손실이 잘 줄어드는지 확인한 뒤 학습률·종료를 정한다.

언제 멈출까?

목표 손실을 .1 이하로 정하면 세 번째 갱신에서 멈춘다.

잠깐, 직접

경사하강 세 번과 MAE·MSE

import numpy as np
w = 1.
for _ in range(3):
    w -= .25 * 2*(w-3)
    print(f"{w:g} {(w-3)**2:g}")
r = np.array([0, 1, -4])
print(f"{np.abs(r).mean():.3f} {(r*r).mean():.3f}")
