덱 15

확률로 분류하다

점수 z → 시그모이드 = 0~1로 → 로짓 = 오즈의 로그 → 판정 기준 → 손실 = 정답 확률의 −ln → softmax

메일 속 링크 수로 '스팸일 확률'을 낸다. 맞히는 것보다 정답에 얼마나 확신했는지를 잰다.

곱해서 더한 점수 z = 아무 실수, 확률이 아니다

선형회귀(덱 8)처럼 곱해서 더하면 점수가 나온다. '스팸일 확률 −2'는 말이 안 된다: 점수를 0~1로 바꾸는 장치가 필요.

분류 = 이름표 고르기 (덱 7)점수 z: 클수록 스팸 쪽

시그모이드 = 점수를 0~1로 누르는 함수

p = 1 / (1 + e^(−z))

e^(−z) = e(≈ 2.718)의 −z제곱(덱 3). 순서는 그대로: 점수가 크면 확률도 크다. 링크 3개 메일 = 스팸 확률 0.88.

로짓 = 오즈의 로그: 확률을 실수 전체로 편다

오즈 = 스팸 쪽 무게 ÷ 정상 쪽 무게. p = 0.8이면 4 : 1. 로그를 씌우면 −∞~∞, 곧 점수 z가 사는 곳. 그래서 z = 로짓이고 이 모델이 로지스틱 회귀.

오즈 1 = 반반 = z 00.2와 0.8 → −1.39와 1.39

잠깐, 직접

w = 링크 1개당 오즈 ×e², 확률 증가는 자리마다 다르다

z가 2 오르면 오즈는 e²배(로그 한 칸 = 같은 배수, 덱 3). 확률은 이미 1에 가까우면 더 못 오른다. 이 배수를 오즈비라 부른다.

확률과 판정은 따로: 기준 0.5 = z가 0인 곳

모델이 내는 것은 확률. '스팸으로 거른다'는 사람이 정한 기준을 넘었는지로 따로 정한다. 시그모이드(0) = 0.5라서 기준 0.5 = 점수 0.

잠깐, 직접

손실 = 정답에 준 확률의 −ln

손실 = −ln(정답에 준 확률)

같은 0.88이라도 정답이 무엇이냐에 따라 쓰는 확률이 다르다: 정상이면 1 − 0.88 = 0.12. 맞혔나만 보는 정확도와 달리 '얼마나 확신했나'까지 잰다.

메일 여러 통 = 확률의 곱 → ln으로 놀람의 합

곱이 클수록 = 놀람의 합이 작을수록 좋은 모델. 로그가 곱을 합으로(덱 3). 이 평균을 줄이도록 w, b를 고친다(덱 6).

BCE = −[y ln p + (1 − y) ln(1 − p)]y: 정답 1(스팸) 또는 0z로 미분 = p − y: 틀린 만큼 고친다

잠깐, 직접

교차엔트로피 = 엔트로피 + KL

엔트로피 = 실제가 원래 가진 뜻밖임, 어떤 모델도 못 줄인다. KL = 모델이 틀려서 더 놀란 양, Q = P일 때만 0. 정답 한 통이면 P = (1, 0)이라 교차엔트로피 = 앞의 −ln(정답 확률).

교차엔트로피를 줄이기 = KL 줄이기ln으로 재면 단위 nat, 순서는 같다

잠깐, 직접

범주가 여럿 = softmax: e^z로 양수, 합으로 나누기

p = e^z ÷ (모든 e^z의 합)

범주마다 점수 하나(선형식 하나, 덱 2의 칸 하나). 가장 큰 점수 = 가장 큰 확률: 순서는 그대로. 손실은 똑같이 정답 범주 확률의 −ln.

softmax는 점수 차이만 본다 → 범주 둘이면 시그모이드

그래서 한 범주 점수를 0으로 묶어 둬도 잃는 것이 없다. 로지스틱 회귀 = 범주 둘짜리 softmax. 코드에서는 큰 점수를 먼저 빼고 계산해 넘침을 막는다.

잠깐, 직접

시그모이드, 손실, softmax를 코드로

import numpy as np
x, y = np.array([1, 2, 3]), np.array([0, 1, 1])   # 링크 수, 정답(1 = 스팸)
z = 2 * x - 4
p = 1 / (1 + np.exp(-z))
q = np.where(y == 1, p, 1 - p)                     # 정답에 준 확률
print(z.tolist(), p.round(3).tolist())
print(q.round(3).tolist(), round(np.prod(q), 3), round(-np.log(q).mean(), 4))
s = np.array([np.log(4), np.log(2), 0])            # 업무, 광고, 스팸
e = np.exp(s - s.max())                            # 큰 점수를 먼저 빼도 같다
print((e / e.sum()).round(3).tolist(), round(-np.log(e[1] / e.sum()), 4))
[-2, 0, 2] [0.119, 0.5, 0.881]
[0.881, 0.5, 0.881] 0.388 0.3157
[0.571, 0.286, 0.143] 1.2528

np.where = 정답이 1이면 p, 아니면 1 − p. 평균 놀람 0.3157이 이진 교차 엔트로피.
