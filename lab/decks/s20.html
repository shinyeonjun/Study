덱 20

무엇을 볼지 고르다: attention

토큰 = 벡터 → 내적 = 맞는 정도 → softmax = 비율 → 값을 섞기 → Q · K · V → √d → 미래 가리기

단어 하나의 표현을 만들 때, 문장의 다른 단어를 어느 비율로 가져올지 스스로 고른다.

단어의 뜻은 주변이 정한다 → 어디를 볼지 고르기

attention = 단어마다 다른 단어들을 얼마씩 가져와 섞을지 정하는 계산. 비율은 고정이 아니라 문장마다 새로 계산한다.

토큰 = 모델이 다루는 글 조각

토큰 번호 = 표의 줄 번호, 임베딩 = 그 줄의 벡터

번호는 크기가 아니라 주소. 읽어 온 벡터가 그 토큰의 표현이고, 표 E의 숫자는 학습으로 바뀐다.

임베딩 = 번호를 벡터로패딩 = 길이를 맞추려 채운 빈 토큰줄 읽기 = 원-핫 × E (편향 없는 선형층)

내적 = 질문이 찾는 특성을 얼마나 가졌나

자리끼리 곱해 더하기(덱 1). q가 켜 둔 자리에 큰 값을 가진 토큰일수록 점수가 크다. 이 점수가 '얼마나 볼지'의 출발점.

점수 = 질문 · 키

내적은 방향과 길이를 함께 잰다

q의 길이가 1이면 내적 = q 방향 그림자의 길이. 방향이 덜 맞아도 길면 이긴다. 코사인 = 길이로 나눈 내적 = 방향만.

attention 점수는 내적 쪽길이도 학습으로 조절된다

잠깐, 직접

점수 → 비율 = softmax

softmax = eˣ ÷ (eˣ의 합)

eˣ는 늘 양수, 점수가 클수록 크다 → 합 1인 비율. 점수 차 0.69 = 비율 2배. 질문마다 따로(줄마다) 합이 1.

0.69 ≈ ln 2

가져오기 = 비율대로 값 V를 섞는다

출력 = 값들의 가중 평균이라 늘 값들 '사이'에 있다. 비율이 큰 V₁ 쪽으로 끌려간다.

고르기 = 점수(질문·키)가져오기 = 값 V

잠깐, 직접

찾는 것 Q, 내세우는 것 K, 건네는 것 V

W_Q, W_K, W_V = 덱 2의 레시피 표 W 세 개, 학습으로 정해진다. 점수 = 내 q · 남의 k, 가져오는 건 남의 v.

셋 다 x 그대로면: 길이가 같을 때 자기 점수가 늘 최대따로 배우면 찾는 것 ≠ 가진 것

√d로 나누기 = 특성이 많아도 점수가 부풀지 않게

점수 = q · k ÷ √d

d = q, k의 칸 수. 칸마다 곱을 더하니 d가 크면 점수 퍼짐이 √d배(d = 64면 8배) → 한 칸 몰림 → 학습 신호가 거의 0. 이 예는 d = 2: 내적 0.98 ÷ √2 = 0.69.

가정: q, k 칸이 평균 0·분산 1·독립

한 번에 = softmax(QKᵀ ÷ √d) V

Attention(Q, K, V) = softmax(QKᵀ ÷ √d) V

QKᵀ = 질문 줄 × 키 칸의 점수 표. 키 하나가 값 하나를 들고 있어 키 수 = V의 줄 수(덱 2의 가운데 숫자). 출력 줄 수 = 질문 수.

Kᵀ = K를 전치(줄 ↔ 칸)값의 칸 수는 d와 달라도 된다

잠깐, 직접

앞을 미리 보면 안 된다 = 미래 가리기

다음 단어를 맞히는 학습에서 뒤를 보면 정답을 베낀다. 가릴 칸의 점수를 softmax 전에 −∞로: e^(−∞) = 0이라 비율 0.

인과 마스크 = 자기와 앞만패딩 키도 같은 방법으로 가린다

잠깐, 직접

attention 한 번과 미래 가리기를 코드로

import numpy as np
def softmax(S):                                   # 줄마다 합 1
    E = np.exp(S - S.max(axis=1, keepdims=True))
    return E / E.sum(axis=1, keepdims=True)
a = np.sqrt(2) * np.log(2)
Q = np.array([[a, 0], [0, a]])                    # 질문 2개
K = np.array([[1., 0], [0, 1], [0, 0]])           # 키 3개
V = np.array([[2., 0], [0, 4], [2, 4]])           # 값 3개
A = softmax(Q @ K.T / np.sqrt(2))                 # √d로 나눈 점수 → 비율
print(A); print(A @ V)
S = np.where(np.tri(3, dtype=bool), 0.0, -np.inf) # 미래 = −∞
print(softmax(S) @ np.array([2., 4., 8.]))
[[0.5  0.25 0.25]
 [0.25 0.5  0.25]]
[[1.5 2. ]
 [1.  3. ]]
[2.         3.         4.66666667]

비율 표, 출력 (1.5, 2)·(1, 3), 가린 뒤 출력 2, 3, 4.67. S.max를 빼는 건 e^큰 수가 넘치지 않게(비율은 같다).
