무엇을 볼지 고르다

임베딩 → Q·K·V → 점수 → 가중합

한 단어의 표현을 만들 때 다른 단어의 정보를 얼마나 가져올까?

토큰 ID는 사전 번호, 표현은 벡터

ID의 크기는 뜻의 크기가 아니다. 표현의 좌표는 학습된다.

비교용과 가져올 값을 따로 만든다

같은 입력 표현에 서로 다른 가중치 행렬을 곱해 만든다.

질문과 후보를 내적해 점수

Q=(1, 0), Kₐ=(√2·ln 2, 0), Kᵦ=(0, 1). 키 차원 dₖ=2이므로 내적을 √2로 나눈다.

잠깐, 직접

점수는 소프트맥스로 비율이 된다

행마다 더했을 때 1. 값은 그 비율대로 섞는다.

점수가 큰 쪽의 내용을 더 가져온다

가중치의 크기만으로 모델 내부에서 어느 정보가 결정을 만들었는지는 확정할 수 없다.

잠깐, 직접

미래 토큰을 보면 정답이 새어 나간다

소프트맥스 전에 허용하지 않는 점수를 −∞로 둔다.

모양을 보며 원하는 축에서 합친다

Q와 K의 특징 수는 맞아야 하며 출력 특징 수는 V를 따른다.

잠깐, 직접

attention 한 행을 손계산과 비교

import numpy as np
q = np.array([1., 0.])
K = np.array([[np.sqrt(2)*np.log(2), 0.], [0., 1.]])
V = np.array([[3., 0.], [0., 6.]])
score = q @ K.T / np.sqrt(2)
weight = np.exp(score-score.max())
weight /= weight.sum()
print(weight.round(4).tolist(), (weight @ V).round(8).tolist())
[0.6667, 0.3333] [2.0, 2.0]

정확히 계산하면 2/3, 1/3이고 출력은 (2,2).
