덱 2

행렬로 한꺼번에

행·열 → 행렬곱 → 전치 → 연립식

집 세 채의 점수 두 개씩, 행렬곱 한 번.

집 한 채 = 한 행

X · 3 × 2

열 하나 = 특성 하나.

가중치의 열마다 다른 출력

W · 2 × 2

특성 두 개를 출력 두 개에 연결.

행과 열을 내적한다

(XW)ᵢⱼ는 X의 i번째 행과 W의 j번째 열의 내적.

잠깐, 직접

안쪽 차원을 따라 더해진다

WX는 안쪽 2와 3이 달라 이 예에서는 계산할 수 없다.

전치 = 행과 열 교환

Xᵀ · 2 × 3

선형회귀의 XᵀX에 이 전치가 쓰인다.

잠깐, 직접

가격을 두 개 알면 가중치를 거꾸로

b=2를 식 1에 넣으면 a=3.

같은 식을 복제해도 정보는 그대로

랭크 = 서로 독립인 행의 최대 개수. 여기선 계수 행렬의 랭크가 두 경우 모두 1이며 우변이 해의 유무를 가른다.

잠깐, 직접

세 채를 계산하고 두 식을 푼다

import numpy as np
X = np.array([[2, 1], [1, 3], [4, 0]])
W = np.array([[3, 1], [2, 4]])
pred = X @ W
print(pred.tolist())
print(np.linalg.solve(X[:2], pred[:2, 0]).round(3).tolist())
[[8, 6], [9, 13], [12, 4]]
[3.0, 2.0]

유일한 답을 구할 때는 역행렬을 따로 만들지 않고 solve를 쓸 수 있다.
