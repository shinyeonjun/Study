슬라이드 교재 덱 2

덱 2

행렬 = 숫자를 바꾸는 기계

레시피 → 표 W → 1당 화살표 → 쌓기 X, XW → 거꾸로 = 학습

면적·방 → 가격·편의. 행렬곱은 이 바꾸기를 집마다 한 번에.

집 하나 → 점수 두 개

점수마다 레시피 하나. AI의 층 하나도 이렇게 입력 하나에서 점수 여러 개를 만든다.

레시피를 표로 적으면 = 행렬 W

칸(세로) 하나 = 레시피 하나. 줄(가로) 하나 = 재료 하나.

행렬 = 바꾸는 규칙을 적은 표W: 면적·방 → 가격·편의

W의 줄 = 재료 1이 미는 화살표

면적 1 → 점수 (3, 1)만큼, 방 1 → (2, 4)만큼 이동. 집 1은 이 화살표들을 이어 붙인 것.

잠깐, 직접

화살표 두 개만 알면 모든 집 = 선형

입력 (면적, 방)섞는 법결과 (가격, 편의)
면적 1 · (1, 0)W의 줄 1(3, 1)
방 1 · (0, 1)W의 줄 2(2, 4)
집 1 · (2, 1)2×(3, 1) + 1×(2, 4)(8, 6)
집 2 · (1, 3)1×(3, 1) + 3×(2, 4)(9, 13)
집 3 · (4, 0)4×(3, 1) + 0×(2, 4)(12, 4)

재료를 섞은 비율 그대로 결과도 섞인다. 이 성질이 선형, 그래서 '선형'대수.

잠깐, 직접

집을 쌓으면 X, 결과를 쌓으면 XW

XW = 집마다 W에 넣은 결과

결과의 줄 1은 집 1만의 결과. 줄끼리는 섞이지 않는다.

가운데 숫자가 같아야 하는 이유

외울 규칙이 아니라 플러그 모양: 집이 주는 재료 수 = W가 받는 재료 수.

잠깐, 직접

전치 = 같은 표를 재료별로 보기

Xᵀ · 2 × 3

집별로 보던 줄을 재료별 줄로. 면적끼리 한 줄에 모인다. 선형회귀의 XᵀX에서 쓴다.

잠깐, 직접

결과를 보고 레시피를 거꾸로 = 학습

예측: 레시피 → 점수. 학습: 정답 점수 → 레시피. 가격 레시피 (a, b)를 모르고 집 1·2의 가격 8, 9만 안다 → b = 2, a = 3.

식이 새 정보를 줘야 레시피가 정해진다

두 배 한 식은 새 정보가 아니다: 답이 여러 개. 우변까지 어긋나면 답이 없다. 새 정보를 주는 식의 수 = 랭크.

잠깐, 직접

섞기, 쌓기, 거꾸로를 코드로

import numpy as np
X = np.array([[2, 1], [1, 3], [4, 0]])
W = np.array([[3, 1], [2, 4]])
print(2 * W[0] + 1 * W[1])       # 집 1 = 화살표 섞기
print((X @ W).tolist())          # 세 채 한 번에
print(np.linalg.solve(X[:2], [8, 9]))  # 가격 8, 9 → 레시피
[8 6]
[[8, 6], [9, 13], [12, 4]]
[3. 2.]

W[0] = W의 줄 1 = 면적 화살표.
