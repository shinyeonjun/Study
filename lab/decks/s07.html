덱 7

학습 문제를 세우는 법

무엇을 내나 → 규칙 vs 학습 → X와 y → 정답은 어디서 → 기준선 → 나눠서 시험 → 누출

'집값을 맞혀 줘'를 학습할 수 있고 채점할 수 있는 질문으로 바꾼다.

AI가 내는 것이 문제를 정한다

방법보다 먼저: 무엇을 받아 무엇을 내고, 맞았는지 무엇으로 볼까. 출력이 다르면 채점법도 다르다.

규칙을 사람이 쓰면 프로그램, 자료로 찾으면 학습

식의 모양은 같다. 다른 건 숫자 3, 2를 어디서 얻었나. 학습 = 경험(자료)이 쌓일수록 성적이 나아지게 숫자를 고르는 것.

AI ⊃ 머신러닝 ⊃ 딥러닝, 강화학습은 겹친다

딥러닝은 모델의 모양, 강화학습은 문제의 모양. 기준이 달라 포함이 아니라 겹친다. 넓이는 크기와 무관.

잠깐, 직접

한 줄 = 집 한 채, 앞에서 아는 것 X · 맞힐 것 y

한 줄이 무엇 하나인지(집? 거래? 동네?)부터 정한다. X의 열 = 특성, y = 목표(정답).

숫자가 양을 뜻하면 회귀, 이름표면 분류

저장이 숫자인지가 아니라, 숫자 사이의 거리가 뜻이 있는지. 무엇을 틀렸다고 볼지도 여기서 정해진다.

잠깐, 직접

정답이 어디서 오나 = 지도 · 비지도 · 자기지도

사람이 붙였나 / 없나 / 자료를 가려서 만들었나. 다음 낱말 맞히기로 배우는 언어 모델이 (다).

먼저 '아무 생각 없는' 답 = 기준선

특성을 하나도 안 쓰고 훈련 평균만 답해도 MAE 2. 모델이 이보다 나아야 특성이 정보를 보탠 것.

정확도 0.9인데 하나도 못 찾는다

한쪽이 드물면 다수만 답해도 정확도가 높다. 그래서 기준선의 점수를 먼저 재고, 찾고 싶은 쪽을 따로 센다.

잠깐, 직접

훈련으로 배우고, 검증으로 고르고, 시험은 한 번

고르는 데 쓴 점수는 그 자료에 맞춰진 점수. 처음 보는 집에서의 실력은 고르는 데 안 쓴 시험이 말해 준다.

시험은 실제로 쓸 상황을 흉내 낸다

쓸 곳이 '처음 보는 단지의 다음 달'이면 시험도 그래야 한다. 같은 단지가 양쪽에 있으면 단지를 외워서 맞힌다.

예측하는 순간에 없는 열 = 누출

과거 표에는 다 채워져 있어 섞이기 쉽다. 기준은 '같은 파일에 있나'가 아니라 '그 순간에 있나'.

평균 같은 전처리 값도 훈련에서만누출 = 시험 점수만 좋아짐

잠깐, 직접

기준선 두 개를 코드로

import numpy as np
train, val = np.array([8, 9, 12, 11]), np.array([8, 12])
base = train.mean()                       # 기준선 = 훈련 평균
print(base, np.abs(val - base).mean(), np.abs(val - [7, 13]).mean())
sold = np.array([1] * 10 + [0] * 90)       # 1 = 1주 안에 팔림
pred = np.zeros(100, dtype=int)            # 모두 '안 팔림'
print((pred == sold).mean(), (pred[sold == 1] == 1).sum())
10.0 2.0 1.0
0.9 0

첫 줄: 기준선, 기준선의 검증 MAE, 레시피의 검증 MAE. 둘째 줄: 정확도, 찾아낸 '팔림' 수.
