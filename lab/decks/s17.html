덱 17

작은 신경망

직선 하나로 못 가르는 XOR → 층 = 레시피 + 편향 → ReLU = 문턱 → 은닉층이 점을 옮긴다 → 꺾인 경계 → 배치

덱 15의 분류 경계는 직선 하나. 직선이 모자랄 때 층을 하나 끼운다.

직선 하나로는 못 가르는 문제 = XOR

XOR = 두 입력이 다르면 1, 같으면 0. 직선 경계는 평면을 두 쪽으로 자를 뿐: 같은 쪽 두 점을 이은 선분도 그 쪽에 남는데, 두 선분이 만나 버린다.

덱 15 경계 z = 0 = 직선 하나선형 분류의 한계

층 하나 = 레시피 표 W + 편향 b

s = xW₁ + b₁

W₁의 칸 하나 = 유닛 하나의 레시피(덱 2). 편향 = 입력과 상관없이 더하는 수: s₂는 처음부터 1을 깎고 시작한다.

유닛 = 점수 하나를 내는 칸층 = 유닛 여럿을 한 번에

ReLU = 문턱 아래는 끄고, 넘으면 그대로

편향이 문턱을 정한다: h₂ = ReLU(x₁ + x₂ − 1)은 입력 합이 1을 넘어야 켜진다. 점수 칸마다 따로 꺾는다.

활성함수 = 층 뒤에 붙는 꺾기ReLU = 가장 흔한 활성함수

잠깐, 직접

은닉층 = 점을 새 자리로 옮긴다

(0, 1)과 (1, 0)은 같은 점 (1, 0)으로 모였다. 같은 답끼리 이은 선분이 더는 만나지 않는다: 이제 직선 하나로 갈린다.

은닉층 = 입력과 출력 사이의 층은닉값 h = 새로 만든 특징

출력층 = 옮긴 자리에서 직선 하나

h₂가 켜진 (1, 1)만 2배로 깎인다. z ≥ 0이면 1. 시그모이드(덱 15)를 씌우면 확률 0.62와 0.38.

출력층 = 마지막 층z = 로짓: 확률로 바꾸기 전 점수

잠깐, 직접

입력 쪽에서 보면 = 꺾인 경계

z는 0.5 < s < 1.5에서만 양수. 직선 조각 두 개를 이어 붙인 경계: 꺾이는 곳 하나 = 은닉 유닛 하나가 켜지는 곳.

유닛이 많을수록 꺾을 곳이 많다

꺾기를 빼면 층을 쌓아도 직선 하나

(xW₁ + b₁)W₂ + b₂ = x(W₁W₂) + (b₁W₂ + b₂)

W₂ = 둘째 층의 표, 여기선 (1, −2). 레시피를 이어 붙인 것도 레시피 하나(덱 2). 꺾기가 있어야 층을 쌓는 뜻이 생긴다.

잠깐, 직접

배치 = 입력을 줄로 쌓아 한 번에

첫 축 = 사례(배치), 둘째 축 = 특징. 층은 둘째 축만 바꾸고 줄 순서는 그대로. b₁은 모든 줄에 같이 더한다.

배치 = 한 번에 넣는 사례 묶음PyTorch Linear는 W를 (출력, 입력)으로 저장: xWᵀ

잠깐, 직접

XOR 망을 코드로

import numpy as np
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])
W1, b1 = np.array([[1, 1], [1, 1]]), np.array([0, -1])
W2, b2 = np.array([1, -2]), -0.5
H = np.maximum(X @ W1 + b1, 0)        # 층 1: 레시피 + ReLU
z = H @ W2 + b2                       # 층 2: 직선 하나
print(H.tolist())
print(z.tolist(), (z >= 0).astype(int).tolist())
print(((X @ W1 + b1) @ W2 + b2).tolist())   # ReLU를 빼면
[[0, 0], [1, 0], [1, 0], [2, 1]]
[-0.5, 0.5, 0.5, -0.5] [0, 1, 1, 0]
[1.5, 0.5, 0.5, -0.5]

셋째 줄: ReLU를 빼면 (0, 0)이 1.5로 1 쪽에 간다.
