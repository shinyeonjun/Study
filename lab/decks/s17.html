덱 17

작은 신경망

행렬 → 활성함수 → 은닉층 → 비선형

선형층 하나에 할 수 없던 분류를 층 두 개로 풀어 본다.

행렬이 두 개의 중간 점수를 만든다

가중치 행렬은 입력 특징 두 개와 은닉 유닛 두 개를 연결한다.

가중치와 편향을 직접 읽는다

첫 점수는 2·1−1·2+1=1. 둘째는 2·(−1)−1·1=−3.

ReLU = 음수는 0으로

ReLU(z) = max(0,z)

은닉 점수 (1,−3)은 활성화 뒤 (1,0).

잠깐, 직접

다음 층은 그 표현을 다시 읽는다

층 사이에 남은 것은 새 특징 두 개.

활성화가 없다면 층 둘도 선형

편향까지 있다면 아핀 변환 하나로 합쳐진다.

잠깐, 직접

XOR · 켜진 입력이 하나일 때만 1

활성화는 입력 공간에서 다른 규칙이 켜지게 한다.

텐서의 축은 수의 역할

자료의 모양과 dtype을 확인한 뒤 배치로 처리.

잠깐, 직접

두 사례를 신경망에 동시에

import numpy as np
X = np.array([[2,-1],[0,2]])
W = np.array([[1,-1],[2,1]])
H = np.maximum(X @ W + [1,0], 0)
print(H.tolist())
print((H @ np.array([[3], [4]]) + .5).tolist())
[[1, 0], [5, 2]]
[[3.5], [23.5]]

행마다 같은 층을 통과한 두 예측.
