Q러닝 · 한 번의 경험으로 표 고치기

벨만 최적식 → 한 번의 전이 → 목표값과 학습률 → 탐험과 실습

로봇이 직행 성공률을 모른 채 출발한다. 경험 한 줄씩으로 어느 길이 나은지 배워 보자.

벨만 최적식은 다음 상태의 최고 값을 쓴다

Q*(s,a) = E[r + γ maxb Q*(s′,b) | s,a]

E는 전이 확률로 평균 낸다는 뜻이다. 처음 행동 a를 고정하고, 다음 상태에서는 가능한 행동 b의 최고 Q를 쓴다.

한 번 실행하면 결과 하나를 관측한다

한 번의 경험으로 상태·행동·보상·다음 상태를 기록한다. 종료 여부도 함께 기록한다.

에피소드 = 출발부터 종료까지 한 번

종료에 도착하면 목표는 이번 보상

직행의 기대 반환은 0.75×4 + 0.25×0 = 3이다. 한 번의 목표에는 그때 실제로 받은 보상이 들어간다.

잠깐, 직접

목표 쪽으로 정한 비율만큼 움직인다

새 Q = 기존 Q + α × (목표 − 기존 Q)

모든 Q가 0에서 시작한다. 첫 우회 뒤 C에서 배송하면 α(알파)=0.5로 목표 6까지 절반을 움직인다.

통로에서 배운 값이 출발로 전달된다

첫 우회는 C의 Q가 0이라 우회 Q를 −0.5로 바꿨다. 다음 에피소드의 우회는 C에서 배운 값을 써서 −0.5에서 1.4 쪽으로 절반 움직여 0.45가 된다.

부트스트랩 = 현재 추정치를 목표 계산에 사용

잠깐, 직접

새 표본마다 Q표를 한 칸씩 고친다

같은 상태·행동을 반복하면 직행의 표본 목표 평균은 3에 가까워진다. 현재 Q를 고정해 생각하면, 표본 목표를 확률로 평균 낸 것이 벨만 목표다.

가끔 다른 행동도 해 본다

ε(엡실론)=0.2인 ε-greedy의 예. 행동이 둘이고 최고 Q가 하나일 때 무작위 선택은 그 최고 행동도 포함한다.

잠깐, 직접

탐험 중의 행동과 학습 목표는 따로 정한다

탐험 때문에 실제로 중단을 골라도, 우회의 목표에는 배송 쪽 Q가 더 크면 그 값이 들어간다.

오프폴리시 · 경험을 모으는 규칙과 목표의 규칙이 다름

잠깐, 직접

환경을 5,000번 돌며 Q표를 배운다

from random import Random

rng = Random(24)
Q = [[0.0, 0.0], [0.0, 0.0]]
visits = [[0, 0], [0, 0]]

def step(s, a):
    # S=0은 직행·우회, C=1은 배송·중단 순서다.
    if s == 0 and a == 0:
        return (4 if rng.random() < 0.75 else 0), None
    if s == 0:
        return -1, 1
    return (6 if a == 0 else 0), None

for _ in range(5000):
    s = 0
    while s is not None:
        best = int(Q[s][1] > Q[s][0])
        a = rng.randrange(2) if rng.random() < 0.2 else best
        reward, next_state = step(s, a)
        future = max(Q[next_state]) if next_state is not None else 0
        target = reward + 0.8 * future
        visits[s][a] += 1
        alpha = 1 / visits[s][a]
        Q[s][a] += alpha * (target - Q[s][a])
        s = next_state

print("S · 직행 / 우회:", *(f"{value:.2f}" for value in Q[0]))
print("C · 배송 / 중단:", *(f"{value:.2f}" for value in Q[1]))
assert Q[0][1] > Q[0][0] and Q[1][0] > Q[1][1]
S · 직행 / 우회: 2.96 3.80
C · 배송 / 중단: 6.00 0.00

step()이 길의 확률로 결과를 뽑고, 학습은 돌려받은 보상과 다음 상태를 쓴다. α는 상태·행동별 방문 횟수의 역수다.

배운 표를 벨만식의 정답과 대조한다

이번 실행은 출발에서 우회를 선택하고 통로에서 배송을 선택한다. 경험으로 구한 값은 시드와 방문 횟수에 따라 달라진다.
