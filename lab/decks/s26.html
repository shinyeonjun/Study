덱 26

Q러닝 · 한 번의 경험으로 표 고치기

전이표를 모른다 → 경험 한 줄 → 평균을 조금씩 → 목표 = r + γ max Q → 값이 거꾸로 번진다 → 가끔은 탐험 → 5000판

덱 25는 0.75를 알고 풀었다. 진짜 로봇은 모른다: 해 보고 표를 고친다.

확률표를 모르면 = 해 보고 고치는 Q표

Q(s, a) = q(s, a)를 경험으로 어림한 값. 찾아갈 답은 덱 25의 q*: 직행 3, 우회 3.8, 배송 6, 중단 0.

경험 한 줄 = (s, a, r, s′)

상태 s에서 a를 했더니 r을 받고 s′에 왔다. 끝났는지도 함께 적는다. 학습 재료는 이것뿐.

평균은 한 번에 조금씩 고쳐도 된다

새 Q = Q + α × (목표 − Q)

틀린 만큼(목표 − Q)의 α배만 움직인다. α = 1/n이면 정확한 평균, 고정 α = 0.5면 최근 경험이 더 무겁다. 덱 6의 경사하강과 같은 꼴.

목표 = 받은 보상 + γ × 다음 자리의 최고 Q

max Q(s′, b) = 다음 자리 s′에서 고를 수 있는 행동 b 중 가장 큰 Q. 한 번의 결과는 운이 섞이지만, 여러 번 고치면 평균(Σ p) 쪽으로 간다.

끝에 닿으면 목표 = 받은 보상만

D·F 뒤에는 받을 보상이 없다(덱 25의 v(D) = 0). 그래서 끝난 경험은 받은 보상이 곧 목표.

잠깐, 직접

판 1: 목표 쪽으로 반만 간다

우회를 고칠 때 C는 아직 0이었다: 우회가 손해처럼 보인다. 순서 = 경험한 순서.

판 2: C에서 배운 값이 S로 넘어온다

부트스트랩 = 아직 덜 배운 Q로 목표를 만든다. 판이 거듭되면 배송 → 6, 우회 → −1 + 0.8 × 6 = 3.8.

잠깐, 직접

늘 최고만 고르면 못 배운다

고르지 않은 칸은 경험이 없어 고쳐지지 않는다. 지금 아는 최선 = 활용, 덜 해 본 것 시도 = 탐험.

ε-greedy = 가끔은 주사위로 고른다

ε(엡실론) = 무작위로 고를 확률. 무작위 안에는 최고 행동도 들어 있어 우회는 0.8 + 0.2 ÷ 2 = 0.9.

ε = 0: 활용만ε = 1: 늘 무작위

잠깐, 직접

실제로 한 행동 ≠ 목표에 쓰는 행동 = 오프폴리시

Q러닝: 모으는 규칙(ε-greedy)과 배우는 대상(최선 정책)이 다르다 = 오프폴리시. 탐험해도 최선의 값을 배운다.

잠깐, 직접

5000판 돌려 Q표 배우기

import numpy as np
rng = np.random.default_rng(0)
Q = np.zeros((2, 2))   # 줄 S, C · 칸 S: 직행·우회, C: 배송·중단
N = np.zeros((2, 2))   # 칸마다 경험한 횟수

def step(s, a):        # 환경. 0.75는 여기에만 있다
    if s == 0 and a == 0:
        return (4 if rng.random() < 0.75 else 0), None
    if s == 0:
        return -1, 1
    return (6 if a == 0 else 0), None

for _ in range(5000):
    s = 0
    while s is not None:
        a = rng.integers(2) if rng.random() < 0.2 else Q[s].argmax()
        r, s2 = step(s, a)
        target = r if s2 is None else r + 0.8 * Q[s2].max()
        N[s, a] += 1
        Q[s, a] += (target - Q[s, a]) / N[s, a]   # α = 1/N
        s = s2
print(Q.round(2))
[[3.04 3.8 ]
 [6.   0.  ]]

step만 0.75를 안다. 학습은 돌려받은 r, s′만 쓴다. 칸마다 α = 1/(경험 횟수), ε = 0.2.

배운 Q표 ≈ 벨만식의 답

0.75를 한 번도 보지 않고 거의 같은 답. 각 칸에서 가장 큰 Q를 고르면 S 우회, C 배송: 덱 25의 최적 정책.

직행 3.04 ≠ 3: 표본의 운 · 시드마다 조금씩 다르다
