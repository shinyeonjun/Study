덱 21

Transformer = 블록을 쌓아 다음 토큰 맞히기

위치 붙이기 → 섞기·바꾸기 → 잔차 → 정규화 → 블록 쌓기 → 한 칸 뒤 맞히기 → 이어 쓰기

덱 20의 attention 하나로는 문장을 못 쓴다. 무엇을 더하면 '다음 말'을 맞히는 모델이 될까.

위치가 없으면 = 단어 주머니

누가 누구를 물었는지 모른다. 순서를 숫자로 넣어 줘야 한다.

attention 출력 = 값들의 가중 평균 (덱 20)평균은 순서를 모른다

위치 벡터 = 빨리 도는 바늘과 천천히 도는 바늘

입력 = 토큰 벡터 + 위치 벡터

빠른 바늘로 가까운 자리를, 느린 바늘로 먼 자리를 가른다. 바늘 여러 개를 함께 보면 자리마다 다른 무늬. 같은 '비'도 자리마다 다른 벡터가 된다.

p = 0부터 센 자리

잠깐, 직접

블록의 두 일: 토큰끼리 섞기, 토큰 안에서 바꾸기

attention = 문맥 모으기. FFN = 모은 것을 토큰마다 가공하기. 둘 다 입력과 같은 모양 (토큰 수 × d)을 낸다. d = 토큰 벡터의 칸 수.

FFN = 층 2개짜리 신경망헤드 여러 개 = attention을 여러 벌 따로

잔차 = 입력은 그대로 두고 고칠 양만 더하기

y = x + F(x)

F가 0이면 블록은 x를 그대로 넘긴다. 블록마다 '얼마나 고칠까'만 배우면 된다. 더하려면 F(x)도 x와 같은 모양.

잔차 = 기울기가 내려가는 지름길

dy/dx = 1 + dF/dx

F의 기울기가 작아도 1이 남는다. 그래서 블록을 수십 개 쌓아도 앞쪽 층까지 기울기가 닿는다(덱 18 역전파). 모든 폭주·소실을 막아 주지는 않는다.

곱해지며 줄어듦 = 기울기 소실

잠깐, 직접

LayerNorm = 토큰 하나의 숫자를 평균 0, 폭 1로

더하기를 블록마다 거듭해도 숫자 크기가 불어나지 않게. 그 뒤 학습되는 배율 γ·이동 β로 필요한 만큼 다시 늘리고 옮긴다.

문장 길이·배치 크기와 무관

블록 하나 = 섞기와 바꾸기, 둘 다 잔차로

원 논문은 더한 뒤 정규화(Post-LN). 지금은 먼저 정규화(Pre-LN)가 많다: 지름길에 아무것도 끼지 않아 깊게 쌓아도 안정적.

원 논문: d = 512, 헤드 8, 블록 6LN = LayerNorm

잠깐, 직접

학습 = 한 칸 뒤를 맞히기, 미래 칸은 가린다

'시작' 자리가 '비'를 미리 보면 정답을 베낀다. 가려 두면 문장 하나로 세 자리를 한 번에 학습한다.

인과 마스크 = 가린 칸 점수를 −∞로 (덱 20)교사 강요 = 입력에 진짜 앞부분

잠깐, 직접

손실 = 정답에 준 확률의 −ln 평균

덱 15의 교차엔트로피를 자리마다 한 번씩. 세 확률의 곱 0.1 → 손실 = −ln 0.1 ÷ 3. 모든 정답에 확률 1을 주면 손실 0, 퍼플렉서티 1.

퍼플렉서티 = e^평균 손실같은 토큰 방식·같은 자료에서만 비교

생성 = 고른 토큰을 붙여 다시 넣기

확률이 가장 큰 토큰을 고르거나, 확률대로 뽑는다. 자기 출력을 다음 입력으로 쓴다 = 자기회귀.

P(문장) = P(비|시작)·P(온다|시작, 비)·…

잠깐, 직접

위치, 잔차, 정규화, 마스크, 손실을 코드로

import numpy as np
p = np.arange(3)                                  # 자리 0, 1, 2
pe = np.stack([np.sin(p), np.cos(p), np.sin(p/100), np.cos(p/100)], 1)
print(pe.round(2))
x = np.array([1., 3.]) + [0.5, -0.5]              # 잔차: x + F(x)
print(x, (x - x.mean()) / x.std())                # LayerNorm (γ=1, β=0)
print(np.tril(np.ones((3, 3), int)).tolist())     # 1 = 보임
pg = np.array([0.5, 0.25, 0.8])                   # 정답에 준 확률
loss = -np.log(pg).mean()
print(round(loss, 4), round(np.exp(loss), 4))
