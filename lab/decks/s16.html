잘 맞는다는 것

훈련 점수 ≠ 실력 → 과소·과대적합 → 편향² + 분산 + 잡음 → 규제 → 교차검증 → 전처리도 훈련에서만

집 다섯 채에 딱 맞는 곡선이 새 집에서는 더 틀린다. 왜 그런지, 어떻게 고르는지.

잠깐, 직접

검증 오차 = 편향² + 분산 + 잡음

편향 = 평균적으로 빗나간 방향. 분산 = 훈련 자료가 바뀔 때 예측이 흔들리는 양. 잡음 = 정답 자체의 흔들림, 어떤 모델도 못 줄인다.

복잡한 모델 = 자료가 바뀌면 크게 흔들린다

4차는 점마다 꼭 맞추느라 점이 조금만 달라져도 곡선이 크게 바뀐다 = 분산이 크다. 직선은 덜 흔들리지만 휘는 규칙은 못 담는다 = 편향.

단순 → 편향↑ 분산↓복잡 → 편향↓ 분산↑그 사이 = 검증으로 고른다

잠깐, 직접

규제 = 큰 w에 값을 매긴다

손실 = SSE + λ·w²

λ(람다) = w가 클 때 매기는 값의 세기. 오차를 조금 더 내더라도 w를 작게 = 덜 출렁이는 모델. 이 L2 벌점이 리지.

L2는 0 쪽으로 줄이고, L1은 0에 세운다

|w|는 0에서 뾰족하게 꺾인다: 거기서는 오차를 줄이는 힘이 벌점을 못 이기면 멈춘다. w²는 0 근처에서 평평해 벌점이 거의 안 걸린다.

k겹 교차검증 = 돌아가며 한 번씩 검증

λ나 차수 같은 설정(하이퍼파라미터)을 검증 한 번의 운으로 고르지 않으려고. 고른 뒤 시험은 한 번만: 시험을 보며 고치면 시험도 검증이 된다.

잠깐, 직접

전처리도 배운다 = 훈련에서 fit, 나머지는 transform

빈칸 채우기, 표준화도 자료에서 숫자를 배운다 = 모델의 일부. 그래서 배우는 것은 훈련에서만. 빈칸과 거리 0은 다르다: 0으로 채우지 않는다.

빈칸 = 결측값표준화 = 평균 0, 표준편차 1 눈금으로

이름은 크기가 아니다 = 원-핫

숫자로 바꾸는 것도 뜻을 지켜야 한다. 순서가 진짜 있는 범주(작음 < 중간 < 큼)만 번호 하나로 쓸 수 있다. 원-핫 칸 목록도 훈련에서 정한다.

회차마다 다시 fit해야 누출이 없다

검증 = 처음 보는 자료를 흉내 내는 자리. 중앙값 하나라도 검증 행을 보고 정하면 이미 본 자료다(누출, 덱 7). 전처리와 모델을 한 줄(파이프라인)로 묶어 회차마다 통째로 다시 fit.

잠깐, 직접

과대적합, 리지, fit·transform을 코드로

import numpy as np
x, y = np.array([1, 2, 3, 4, 5]), np.array([3, 3, 6, 6, 9])            # 훈련 집
xv, yv = np.array([1.5, 2.5, 3.5, 4.5]), np.array([3.5, 5, 5.5, 7.5])   # 검증 집
for d in (0, 1, 4):                                     # 다항식 차수
    c = np.polyfit(x, y, d)
    tr, va = [np.mean((np.polyval(c, a) - b) ** 2) for a, b in ((x, y), (xv, yv))]
    print(d, round(tr, 2), round(va, 2))
X = np.array([-1., 1.]); Y = 2 * X
print([float(X @ Y / (X @ X + lam)) for lam in (0, 2, 6)])  # 리지 w
A, B = np.array([2, np.nan, 6]), np.array([np.nan, 8, 10])
m = np.nanmedian(A); a = np.where(np.isnan(A), m, A)    # fit: 훈련 A에서만
b = (np.where(np.isnan(B), m, B) - a.mean()) / a.std()  # transform: 검증 B
print(m, a.mean(), round(a.std(), 2), b.round(2).tolist())

a.std() = n으로 나눈 표준편차(√(8/3)). 검증 B는 훈련 A의 숫자로만 바꾼다.
