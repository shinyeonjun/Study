덱 1

AI는 숫자를
곱해서 더한다

벡터 → 내적 → 길이·방향 → 예측 → 행렬

세상을 숫자 목록으로

AI가 보는 집 = 숫자 3개짜리 목록. 이 목록이 벡터.

벡터성분차원 = 3

벡터 = 화살표

좌표방향크기

그냥 목록과 벡터의 차이 = 더할 수 있다

벡터 = 자리마다 같은 종류의 양이 들어 있어 더하고 몇 배 할 수 있는 숫자 목록. 그래서 화살표로 그릴 수 있다.

덧셈 = 이어 붙이기2배 = 같은 방향으로 두 배 길이

곱해서 더하기 = 내적

a·b = a₁b₁ + a₂b₂ + a₃b₃

내적결과는 숫자 하나

잠깐, 직접

길이 = 자기 자신과의 내적

‖a‖ = √(a·a)

노름(길이)피타고라스

코사인 = 방향이 얼마나 비슷한가

cos = a·b ÷ (‖a‖ × ‖b‖)

내적은 화살표가 길어지면 같이 커진다. 두 화살표의 길이로 나눠 크기를 빼면 방향만 남는다: −1 ~ 1.

코사인 유사도0이면 직교음수면 반대쪽

잠깐, 직접

AI의 예측 = 내적 + b

w = 각 숫자가 얼마나 중요한가. 부호 + 는 올리고, − 는 내린다(역에서 멀수록 싸진다).

선형 모델가중치 w절편 b

학습 = 좋은 w, b 찾기

ŷ = w·x + b

x는 자료가 준다. w와 b는 처음엔 모른다. 실제 집값과 가장 가깝게 맞추는 w, b를 찾는 것이 학습.

파라미터학습예측 ŷ

여러 집을 한 번에 = 행렬

집 1: 0.05×84 + 0.3×3 − 0.1×5 + 1 = 4.2 + 0.9 − 0.5 + 1 = 5.6. 줄마다 이 계산을 한 번씩.

행렬행렬곱 = 내적 여러 번Xw + b

잠깐, 직접

코드로는 한 줄

import numpy as np
X = np.array([[84, 3, 5], [59, 2, 10], [120, 4, 2]])
w = np.array([0.05, 0.3, -0.1])
b = 1
print(X @ w + b)
[5.6  3.55 8.  ]

@ = 행렬곱. 집이 3채든 3백만 채든 같은 한 줄.
