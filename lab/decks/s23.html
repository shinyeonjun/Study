덱 23

모델 안을 들여다보다

활성 벡터 → 읽기(탐침) → 읽힌다 ≠ 쓴다 → 바꿔 보기(개입) → 섞인 뉴런 → 특징과 회로

덱 21의 블록 사이를 흐르는 숫자. 거기에 무엇이 담겼고, 모델은 그걸 정말 쓰고 있을까.

모델 안 = 층마다 나오는 숫자 벡터, 활성

활성 = 그 층이 계산한 값들 = 그 입력의 내부 표현. 이 덱은 숫자 두 개짜리 작은 모델로 본다.

뉴런 = 활성의 한 칸

탐침 = 활성에서 라벨을 읽는 작은 모델

모델은 그대로 두고 탐침만 맞춘다. (가)에서는 두 축이 우연히 같이 움직여 누가 진짜인지 모른다. 관계를 바꾼 자료로 가려낸다.

지름길 특징 = 우연히 라벨과 같이 움직인 것

읽힌다 ≠ 쓴다

h₀에는 라벨 정보가 '들어 있다'. 그래도 모델은 h₀를 '쓰지 않는다'. 쓰는지는 바꿔 봐야 안다.

읽기 = 관찰, 바꾸기 = 개입 (덱 22)

잠깐, 직접

ablation = 하나를 지우고 점수가 얼마나 떨어지나

묻는 것: 이 칸이 점수에 필요한가. u가 더 크게 필요하다. 0이 드문 값이면 평균 같은 다른 값으로도 바꿔 본다.

ablation = 덱 22의 '하나만 빼기'를 모델 안에서

patching = 다른 실행의 값을 옮겨 심기

복원율 = (옮긴 뒤 − 비교) ÷ (정상 − 비교)

비교 실행 = 단서 하나를 바꾼 입력으로 돌린 것. 묻는 것: 이 칸 하나로 정상 점수가 되돌아오나.

activation patching

잠깐, 직접

복원율 0 ≠ 안 쓰인다

두 실험은 다른 질문. 결론은 고른 입력 쌍·바꾼 값·잰 점수까지만 말한다.

개입 기록 = 층·위치·방향·대체값·지표

잠깐, 직접

뉴런 하나 = 여러 뜻이 섞인 칸

h₀ = 2만 보고는 a인지 b인지 모른다. 특징은 칸 하나가 아니라 여러 칸에 걸친 방향. 이런 뉴런 = 다의적 뉴런.

특징 = 활성 공간의 방향

중첩 = 칸보다 많은 특징을 겹쳐 담기

한 입력에서 켜지는 특징이 적으면(희소) 겹쳐 담아도 거의 읽힌다. 실제 모델도 그렇다는 것이 중첩 가설.

cos 120° = −0.5

잠깐, 직접

희소 오토인코더 = 넓고 대부분 0인 특징으로 다시 쓰기

뉴런 칸 대신 특징 칸으로 읽기. z 칸 수를 h보다 크게 잡고, 입력마다 몇 개만 켜지게 학습한다. 특징 이름은 켜지는 예를 보고 붙인 가설.

SAE = sparse autoencoderλ = 희소함의 무게

회로 = 특징이 출력까지 가는 길이라는 가설

'b가 이 길로 점수를 만든다'를 끊어 보고(제거), 그것만 남겨 보고 확인한다. 한 입력의 결과를 모델 전체로 넓히려면 다른 입력·층에서 다시.

복원 성능 ≠ 출력에 쓰임

탐침, 옮겨 심기, 특징 읽기를 코드로

import numpy as np
held = np.array([[-2, 2], [-1, 1], [1, -1], [2, -2]]); y = np.array([0, 0, 1, 1])
print("탐침 h0:", ((held[:, 0] > 0) == y).mean(), "h1:", ((held[:, 1] > 0) == y).mean())
s = lambda h: 2 * h[0] + h[1]                      # 점수 = 2u + v
clean, bad = np.array([3, 1]), np.array([-1, 1])
for i in (0, 1):
    p = bad.copy(); p[i] = clean[i]                # 정상 값 옮겨 심기
    print("patch", i, s(p), (s(p) - s(bad)) / (s(clean) - s(bad)))
z = np.maximum(0, np.array([[0.5, 0.5], [0.5, -0.5]]) @ [5, -1])   # 특징 a, b
print(z, z @ [[1, 1], [1, -1]], z @ [1, 2])        # 복원, 점수 a + 2b
탐침 h0: 1.0 h1: 0.0
patch 0 7 1.0
patch 1 -1 0.0
[2. 3.] [ 5. -1.] 8.0

h₁ 탐침은 새 자료에서 0. u 복원율 1, v 0. z = (2, 3), 복원 (5, −1), 점수 8.
