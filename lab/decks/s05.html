덱 5

여러 변수와 기울기 벡터

손실 지형 → 하나씩 흔들기 = 편미분 → 모으면 화살표 = 기울기 → 방향 고르기 → 출력도 여럿 = 야코비

가중치가 둘이면 '어느 쪽으로'가 방향이 된다. 기울기 벡터가 그 방향을 알려 준다.

가중치가 둘이면 손실은 지형

w₁, w₂를 바꿀 때마다 손실이 바뀐다. 지도처럼 위에서 보면 같은 높이 = 같은 손실이 원으로 이어진다.

등고선 = 손실이 같은 점바닥 = 손실 최소

편미분 = 손잡이 하나만 돌려 본 기울기

∂L/∂w₁ = −4, ∂L/∂w₂ = +4

∂L/∂w₁ = 다른 가중치는 그대로 두고 w₁만 조금 움직일 때의 기울기. 덱 4의 미분을 한 축씩.

편미분을 모으면 = 기울기 벡터 ∇L

∇L(나블라 L) = 오르막을 가리키는 화살표. 반대 −∇L은 내리막이고, 이 그릇에서는 바닥을 곧장 향한다.

잠깐, 직접

방향 하나를 고르면 = 기울기와 내적

방향미분 = 그 방향으로 1만큼 갈 때 손실 변화율. 길이를 1로 맞춰야 '1만큼'이 된다. 덱 1의 내적.

가장 빠른 내리막 = 기울기의 정반대

내적 = 길이 × 길이 × cos(덱 1). u의 길이는 1이라 cos만 남는다. cos이 −1인 정반대가 가장 빠른 내리막.

∇L: 오르막등고선 방향: 변화 0−∇L: 가장 빠른 내리막

잠깐, 직접

−∇L 쪽으로 한 걸음 = 경사하강

한 걸음 갈 때마다 그 자리에서 ∇L을 다시 잰다. 0.25 = 학습률, 한 번에 얼마나 갈지(덱 6).

출력이 여럿이면 편미분 표 = 야코비 행렬 J

층 하나 = 덱 2의 레시피. 선형 층의 J는 레시피 숫자 그대로(덱 2의 W를 전치한 모양: W는 줄이 재료).

행 = 출력열 = 입력크기 = 출력 수 × 입력 수

잠깐, 직접

손실 기울기를 입력까지 = 길마다 곱하고 더한다

(∂L/∂면적, ∂L/∂방) = JT × (1, 3) = (6, 14)

면적은 가격과 편의 두 길로 손실을 바꾼다. 길마다 곱하고(덱 4 연쇄법칙) 모두 더한다. JT = J의 전치(덱 2). 역전파가 층마다 하는 일.

잠깐, 직접

기울기, 한 걸음, 되돌리기를 코드로

import numpy as np
w = np.array([0, 1])
grad = 2 * (w - np.array([2, -1]))      # (∂L/∂w₁, ∂L/∂w₂)
print(grad, round(float(grad @ [0.6, 0.8]), 2))  # 기울기, 방향미분
print(w - 0.25 * grad)                   # 한 걸음
J = np.array([[3, 2], [1, 4]])           # 행 = 가격, 편의
print(J.T @ np.array([1, 3]))            # 길마다 곱해 더하기
[-4  4] 0.8
[1. 0.]
[ 6 14]

grad @ u = 방향미분, J.T @ g = 입력별 손실 기울기.
