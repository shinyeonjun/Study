덱 5

여러 변수와 기울기 벡터

편미분 → 기울기 벡터 → 방향미분 → 야코비안

모델의 가중치 두 개 중 어느 쪽을 얼마나 움직일까?

가중치가 두 개면 손실에 방향이 생긴다

L=(w₁−2)²+(w₂+1)²

두 오차 제곱을 더해 하나의 손실로 감싼다.

한 변수만 움직인다 = 편미분

한 축에서 미분하는 동안 다른 축의 값은 그대로 둔다.

모든 편미분을 벡터 하나로

−∇L = (4, −4)

기울기 벡터가 0이 아니면, 반대 방향이 가장 빠른 국소 감소.

잠깐, 직접

가고 싶은 방향과 내적한다

DᵤL = ∇L · u

한 방향으로 잰 순간 손실 변화율.

등고선의 중심으로 가면 손실이 준다

이 모형의 등고선은 (2,−1)을 중심으로 한 원. 중심으로 향하면 손실이 작아진다.

잠깐, 직접

출력도 여러 개면 편미분을 표로

J의 크기 = 출력 수 × 입력 수

행 하나 = 한 출력의 입력별 편미분.

출력의 기울기를 입력까지 되돌린다

한 입력이 여러 출력에 영향을 주면 그 경로를 합한다.

잠깐, 직접

배열로 방향미분과 경사 확인

import numpy as np
grad = 2*(np.array([0, 1]) - [2, -1])
J = np.array([[1, 2], [1, -1]])
print(grad.tolist(), round(float(grad @ [.6, .8]), 1))
print((J.T @ [1, 3]).tolist())
[-4, 4] 0.8
[4, -1]

경사와 방향의 내적은 숫자 하나, Jᵀg는 입력별 숫자 목록.
