자료를 표와 배열로

행의 의미 → 자료형 → 결측 → NumPy 배열

집값 모델에서 집 한 채가 어디서 한 행이 되는지 확인한다.

집 한 채의 기록을 열로 펼친다

한 행 = 집 한 채. 같은 집의 다른 시점 관측은 다른 키가 필요할 수 있다.

파일의 모양마다 읽는 단위가 다르다

텍스트를 읽을 때 열 이름과 단위부터 확인.

숫자, 범주, 시각을 나눈다

범주를 1,2,3으로 바꿔도 크기 관계가 생기는 건 아니다.

잠깐, 직접

결측은 실제 0과 다르다

빈 값을 0으로 바꾸면 역이 바로 앞인 집이 가짜로 늘어난다.

위치 대신 집 ID로 결합한다

붙이기 전 키의 중복과 의도한 한 행의 의미를 점검.

잠깐, 직접

시험을 열기 전에 전처리 값 고정

평균이나 중앙값도 학습으로 정한 값. 전체 자료에서 먼저 구하면 시험 정보가 섞인다.

검증한 수치 열을 배열로

열 순서를 훈련과 예측에서 같게 유지.

짧은 CSV를 읽어 특성만 뽑는다

from io import StringIO
import pandas as pd

csv = "id,area,rooms,minutes\nA,84,3,0\nB,59,2,10\nC,120,4,2"
rows = pd.read_csv(StringIO(csv)).set_index("id")
X = rows[["area", "rooms", "minutes"]].to_numpy()
print(rows.index.is_unique, X.shape)
print((X @ [.05, .3, -.1] + 1).round(2).tolist())
