덱 9

자료를 표와 배열로

기록 → 표: 행 = 집 → 글자 파일 → 열의 종류 → 빈칸 → 키로 붙이기 → 배열 X

덱 1의 X @ w에서 X는 어디서 오나. 집 기록이 숫자 격자가 되기까지.

기록을 세로로 모으면 = 표 (행 = 집, 열 = 변수)

dict = 이름(키)으로 값을 찾는 짝들. 같은 이름을 같은 열에 모아야 집끼리 비교하고 계산한다.

관측 = 행 하나 (집)변수 = 열 하나 (면적)id = 행의 이름표

한 행이 무엇인지 먼저 = 거래 표 ≠ 집 표

행 수 4를 집 수로 읽으면 틀린다. 집값 모델의 한 행 = 예측할 대상 하나 = 집 한 채.

잠깐, 직접

CSV = 표를 글자로 적은 것 → 읽으면 전부 글자

계산 전에 숫자로 바꾸고, 열 이름·단위·빈칸부터 확인한다. 목록 속 목록처럼 겹친 자료는 JSON으로 주고받는다.

CSV = 평평한 표JSON = 겹친 dict·listencoding = 글자 ↔ 바이트 규칙

열의 종류 = 어떤 계산이 뜻 있나

숫자로 적혔는지가 아니라 더하기·순서·빼기가 뜻 있는지로 가른다. 범주 코드를 그대로 X에 넣으면 모델은 '동네 3 = 동네 1의 세 배'로 계산한다.

잠깐, 직접

빈칸 = 모름 ≠ 0

0 = 알고 있고 0, 빈칸 = 모른다. 섞으면 합과 나누는 수가 바뀌고, 모델은 가짜 '역 앞 집'을 배운다.

잠깐, 직접

키(id)로 붙인다, 줄 순서로 붙이지 않는다

키 = 행 하나를 가리키는 이름표. 붙이기 전에 id가 겹치지 않는지, 붙인 뒤 행 수가 그대로인지 본다.

잠깐, 직접

숫자 칸만 남기면 = 배열 X, shape (4, 3)

배열 = 이름표 없이 자리 번호만, 한 종류 숫자만(dtype). id는 빠지고 순서로만 집을 가리킨다. axis=0으로 모으면 집이 사라지고 '평균 집' 하나가 남는다.

열 순서 = w의 순서

w의 첫 자리는 '면적 1당' 값. 훈련 때와 예측 때 열 이름·순서·단위를 똑같이 맞춘다.

잠깐, 직접

CSV 글자에서 X까지 코드로

import numpy as np
from io import StringIO
csv = "면적,방,역\n84,3,5\n59,2,10\n120,4,2\n77,3,"
X = np.genfromtxt(StringIO(csv), delimiter=",", skip_header=1)
print(X.shape, np.isnan(X).sum(axis=0).tolist())   # 빈칸 = nan
X[np.isnan(X)] = np.nanmedian(X[:, 2])             # 아는 역 값의 중앙값
print(X.mean(axis=0).tolist())
print((X @ [0.05, 0.3, -0.1] + 1).round(2).tolist())
(4, 3) [0, 0, 1]
[85.0, 3.0, 5.5]
[5.6, 3.55, 8.0, 5.25]

nan = 숫자 자리의 '모름' 표시. 빈칸은 역 열에 1개, 중앙값 5로 채운 뒤 집 4채 예측.
