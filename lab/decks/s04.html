슬라이드 교재 덱 4

덱 4

변화를 재다

손실 곡선 → 차분몫 → 극한 → 미분

가중치 하나가 예측값인 모델에서 손실이 어느 쪽으로 갈까?

정답 3, 예측 w

L(w) = (w − 3)²

예측 1을 2로 바꾸면 오차 제곱은 4에서 1.

두 점을 이은 직선의 기울기

w가 한 단위 늘 때 손실이 평균 3 준다.

변화 폭을 줄여 본다

limₕ→₀ [L(1+h) − L(1)] / h = −4

h≠0에서 차분몫은 −4+h. h를 0에 가깝게 하면 −4로 다가간다.

잠깐, 직접

접선은 순간의 기울기

L′(1) = −4

w=1에서 아주 조금 오른쪽으로 가면 손실이 줄어든다.

이어져 있어도 뾰족할 수 있다

연속은 극한값과 함숫값이 같음. 미분하려면 양쪽 차분몫의 극한도 같아야 한다.

잠깐, 직접

새 예제에서도 변화율을 곱한다

중간 값이 어떤 단계에서 얼마나 움직이는지 나눠 계산한다.

기본 함수마다 도함수

합은 항별로 미분. 곱은 한 인수만 미분하고 다른 인수는 남긴 두 곱을 더한다.

잠깐, 직접

양쪽에서 순간 기울기 검산

import numpy as np
h = np.array([1., .5, .1, -.1])
loss = lambda w: (w - 3)**2
print(np.round((loss(1+h)-loss(1))/h, 2).tolist())
print(2*(1-3))
[-3.0, -3.5, -3.9, -4.1]
-4

w를 앞뒤로 흔들어 접선 기울기와 대조한다.
