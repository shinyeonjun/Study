슬라이드 교재 덱 4

덱 4

변화를 재다: 극한과 미분

손실 곡선 → 평균 변화율 → 간격 줄이기 = 극한 → 순간 기울기 = 미분 → 이어 곱하기 = 연쇄법칙

모델은 손실 곡선 전체를 못 본다. 지금 자리의 기울기만 재서 w를 어느 쪽으로 옮길지 정한다.

모델이 아는 것 = 지금 자리의 손실뿐

w = 모델이 고칠 숫자(가중치) 하나. 손실 = 틀린 정도. 곡선은 미리 보이지 않는다.

가중치 w손실 L(w)목표: 손실이 작은 w

두 점 사이 기울기 = 평균 변화율

Δ(델타) = 변한 양. w를 1에서 2로 옮겼더니 손실 4 → 1.

간격을 0에 다가가게 = 극한

limh→0 [L(1 + h) − L(1)] ÷ h = −4

h = 0을 바로 넣으면 0 ÷ 0. 그래서 h를 0에 다가가게 할 때 모이는 값을 쓴다 = 극한(lim).

잠깐, 직접

미분계수 = 그 자리의 순간 기울기

L′(1) = −4

L′(1) = w = 1에서의 순간 기울기. w를 조금 움직이면 손실은 그 −4배만큼 움직인다.

도함수 = 자리마다 기울기, 부호 = 내리막 방향

L′(w) = 2(w − 3)

경사하강은 기울기의 반대쪽으로 w를 옮긴다(덱 6). 기울기 0인 곳 = 바닥 후보.

잠깐, 직접

이어져 있어도 뾰족하면 기울기가 없다

연속 = 끊김 없이 이어짐. 미분 가능 = 가까이 보면 직선 하나. AI의 ReLU = max(0, w)도 0에서 뾰족하다.

잠깐, 직접

규칙은 '조금 늘리면'에서 나온다: (w²)′ = 2w

넓이 w²는 변이 h 늘 때 약 2w·h 는다. 그래서 기울기 2w. 손실 (w − 3)²의 2(w − 3)도 같은 이유.

자주 쓰는 도함수 = 각자 '자라는 방식'

함수도함수뜻
wⁿn·wⁿ⁻¹정사각형 그림을 n차원으로 (w² → 2w)
eʷeʷ지금 크기만큼 자란다 (e ≈ 2.718)
ln w1/ww가 클수록 천천히 자란다 (덱 3의 ln)
f + gf′ + g′따로 자란 만큼을 더한다
f · gf′g + fg′직사각형의 두 띠

f′ = f의 도함수. 외울 표가 아니라 '조금 늘리면 얼마나 느나'의 답 모음.

연쇄법칙 = 변화율을 이어서 곱한다

dL/dw = dL/dŷ × dŷ/dw = −8 × 2 = −16

입력 2, 정답 6인 자료 하나: ŷ = 2w, 손실 (ŷ − 6)². 톱니처럼 w → ŷ(2배) → 손실(−8배). 신경망 학습(역전파)이 이 곱.

잠깐, 직접

간격 줄이기와 연쇄법칙을 코드로

L = lambda w: (w - 3)**2
for h in [1, 0.5, 0.1, 0.01, -0.01]:
    print(h, round((L(1 + h) - L(1)) / h, 4))
print(2 * (1 - 3))                  # 도함수 2(w − 3), w = 1
L2 = lambda w: (2*w - 6)**2         # 입력 2, 정답 6
print(round((L2(1.001) - L2(1)) / 0.001, 2))
1 -3.0
0.5 -3.5
0.1 -3.9
0.01 -3.99
-0.01 -4.01
-4
-16.0

h를 줄이면 −4로, 연쇄법칙 −16은 작은 간격으로 잰 값 −16.0과 맞는다.
