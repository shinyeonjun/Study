덱 25

벨만식 · 오늘의 보상과 다음 상태의 가치

정책의 가치 → 기댓값을 한 단계씩 → 벨만 기대식 → 벨만 최적식

통로 C의 가치를 먼저 구하면, 출발에서의 선택도 숫자로 비교할 수 있다.

한 걸음 뒤의 반환은 통째로 할인한다

다음 시점부터의 보상을 이미 Gₜ₊₁에 모아 두었다. 지금 시점으로 한 칸 당겨 γ를 곱한다.

상태의 가치는 정책을 따라 얻는 평균

Vπ(C) = 0.5 × 6 + 0.5 × 0 = 3

Vπ(C)는 C에서 출발해 이 정책을 따를 때의 기대 반환이다. 종료 뒤에는 더 받을 보상이 없다.

행동 가치는 첫 행동부터 고정한다

Qπ(S, 우회) = −1 + 0.8 × 3 = 1.4

Qπ(S, 우회)는 출발에서 우회를 먼저 한 뒤 C에서는 정책 π를 따를 때의 기대 반환이다.

잠깐, 직접

여러 전이가 있으면 결과마다 따로 계산한다

종료에 들어가는 순간의 보상은 그대로 더한다. 종료 상태 D와 F의 미래 가치는 0이다.

두 갈래 평균을 한 줄로 쓰면 벨만식

Qπ(s,a) = Σ p(s′,r | s,a) × [r + γVπ(s′)]

Σ는 가능한 다음 상태 s′와 보상 r을 모두 더한다는 뜻이고, p는 각 전이의 확률이다.

잠깐, 직접

정책으로 행동을 고르면 한 번 더 평균

Vπ(S) = 0.5 × 3 + 0.5 × 1.4 = 2.2

먼저 행동별로 결과를 평균 낸다. 그 뒤 π가 각 행동을 고르는 확률로 그 행동 값들을 평균 낸다.

잠깐, 직접

두 평균을 합친 식이 벨만 기대식

Vπ(s) = Σa π(a | s) × Σs′,r p(s′, r | s,a) × [r + γVπ(s′)]

안쪽 Σ는 한 행동의 전이 결과를 더한다. 바깥쪽 Σ는 정책이 고를 수 있는 첫 행동을 더한다.

앞으로 최선이라면 통로의 가치는 6

V*(C) = max(6, 0) = 6

V*(C)는 여기부터 가능한 가장 높은 기대 반환이다. 이 예의 C에서는 배송을 고른다.

행동마다 평균을 낸 뒤 가장 큰 것을 고른다

V*(s) = maxa Σs′,r p(s′, r | s,a) × [r + γV*(s′)]

행동은 로봇이 고르고, 전이 결과는 환경이 정한다. 각 행동을 비교할 때는 다음 상태의 최적 가치 V*를 쓴다.

잠깐, 직접

전이표에서 정책의 가치와 최적 가치를 구한다

gamma = 0.8
# 한 항목은 (확률, 즉시 보상, 다음 상태)다.
transitions = {
    "직행": [(0.75, 4, "D"), (0.25, 0, "F")],
    "우회": [(1.0, -1, "C")],
    "배송": [(1.0, 6, "D")],
    "중단": [(1.0, 0, "F")],
}

def q(action, values):
    return sum(p * (r + gamma * values[next_state])
               for p, r, next_state in transitions[action])

terminal = {"D": 0, "F": 0}
deliver = q("배송", terminal)
stop = q("중단", terminal)
fixed = {**terminal, "C": (deliver + stop) / 2}
optimal = {**terminal, "C": max(deliver, stop)}
print(f"정책 π의 출발 가치 {(q('직행', fixed) + q('우회', fixed))/2:.1f}")
print(f"출발의 최적 가치 {max(q('직행', optimal), q('우회', optimal)):.1f}")
정책 π의 출발 가치 2.2
출발의 최적 가치 3.8

행동 이름이 모두 달라 이름만으로 전이표를 찾는다. D와 F부터 C, S 순서로 값을 채운다.

한눈에 정리

Vπ(s)상태 s부터 정책 π를 따를 때의 기대 반환
Qπ(s,a)상태 s에서 첫 행동 a를 고정하고 이후는 π를 따를 때의 기대 반환
벨만 기대식전이 결과는 환경의 확률로, 첫 행동은 정책의 확률로 평균
벨만 최적식다음에 최선으로 행동한다고 두고 행동별 기대 반환 중 최댓값을 고름
종료 상태진입 보상은 전이에 기록. 종료 상태부터의 미래 가치는 0
