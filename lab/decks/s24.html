덱 24

강화학습 첫걸음 · 확률에서 MDP까지

정답 없이 점수만 → 고르고 받는 고리 → 결과는 확률 → 평균 = 기댓값 → 나중 점수 = 할인 → 표 하나 = MDP

배달 로봇: 바로 갈까(직행), 돌아갈까(우회)? 덱 26까지 이 길 하나로 간다.

정답 대신 점수만 = 강화학습

직행해서 +4. 그런데 우회했으면 더 받았을까? 해 봐야 안다 → 해 보고 받은 점수로 고르는 법을 배운다.

고르고 받는 고리 = 에이전트와 환경

행동 뒤에 보상이 온다: A₀ 다음 R₁. 결정 규칙이 못 바꾸는 것(바퀴, 날씨)은 모두 환경.

상태 s = 지금 상황행동 a = 고를 수 있는 것보상 r = 한 번의 점수정책 π = 상태마다 행동 고르는 규칙

배달 로봇의 길: 고르는 곳과 운이 정하는 곳

네모 = 로봇이 고른다. 점 = 환경이 주사위를 굴린다. D·F에 닿으면 한 판 끝.

직행: 빠르지만 25%는 실패우회: 한 걸음 손해(−1), 대신 확실

0.75 = 직행을 골랐을 때 D에 갈 확률

조건부확률 = 조건에 맞는 경우만 세고 그 안에서 비율. 우회한 판은 분모에 넣지 않는다.

20번 중 15번꼴 = 0.75결과 확률의 합 0.75 + 0.25 = 1

기댓값 = 확률을 무게로 단 평균

E[보상] = 0.75 × 4 + 0.25 × 0 = 3

한 번엔 4 아니면 0. 3은 한 번도 안 나온다: 여러 번 반복한 평균이 다가가는 값. 좋은 행동 = 기댓값이 큰 행동.

잠깐, 직접

나중 점수는 덜 친다 = 할인율 γ

γ(감마) = 한 걸음 늦을 때마다 곱하는 비율(0~1). 첫 보상의 무게는 1. 같은 6점도 늦게 받으면 4.8.

γ = 0: 당장 보상만γ = 1: 모두 같은 무게매번 1점 끝없이, γ = 0.8 → 합 5로 유한

한 판의 할인 합 = 반환 G

G₀ = R₁ + γ × G₁ = −1 + 0.8 × 6 = 3.8

반환 = 그 시점부터 끝까지 받은 보상의 할인 합. 뒤의 반환을 통째로 한 번 할인하면 된다(덱 25의 씨앗).

보상 r: 한 칸의 점수반환 G: 한 판의 할인 합기대 반환: 여러 판 반환의 평균

잠깐, 직접

γ가 바뀌면 고르는 길이 바뀐다

γ = 로봇이 얼마나 멀리 보나. 작으면 당장(직행), 2/3를 넘으면 돌아가도 큰 점수(우회). 이 덱부터 γ = 0.8.

환경의 규칙 전부 = 전이표 p(s′, r | s, a)

p(s′, r | s, a) = s에서 a를 했을 때 다음 상태 s′와 보상 r이 나올 확률. | 뒤가 이미 정한 것.

MDP = 상태 · 행동 · 전이표 · 할인율 γ이 표만 있으면 모든 평균을 계산(덱 25)

지금 상태만 보면 충분 = 마르코프 성질

마르코프 = 지금 상태와 행동을 알면, 지나온 길을 더 알아도 다음 확률이 그대로. 깨지면 상태에 빠진 정보를 넣는다.

MDP = 마르코프 결정 과정성립 여부는 상태를 어떻게 정했나에 달림

잠깐, 직접

π = 로봇이 고르는 확률, p = 세상이 정하는 확률

π × p = 0.5 × 0.75 = 0.375

정책 π(a | s) = 로봇의 다이얼: 학습이 바꾼다. 전이 p = 세상의 주사위: π를 바꿔도 직행하면 여전히 0.75.

잠깐, 직접

한 번은 4 또는 0, 평균은 3

import numpy as np
rng = np.random.default_rng(0)
r = rng.choice([4, 0], size=10000, p=[0.75, 0.25])
print(r[:8])                     # 직행 8번의 보상
print(r.mean())                  # 1만 번의 평균
print(np.dot([0.75, 0.25], [4, 0]))   # 기댓값
gamma = 0.8
print(round(-1 + gamma * 6, 2))  # 우회 → 배송의 반환 G
[4 4 4 4 0 0 4 4]
2.998
3.0
3.8

한 번 한 번은 4 또는 0. 1만 번 평균은 기댓값 3 근처. 우회 → 배송은 운이 없는 길이라 반환이 늘 3.8.
