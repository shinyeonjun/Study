강화학습 첫걸음 · 확률에서 MDP까지

로봇의 선택 → 결과의 확률 → 보상의 기댓값 → MDP

배달 로봇이 직행할까, 한 번 더 돌아갈까? 선택 뒤에 생기는 일부터 그려 보자.

로봇이 고르고, 길이 결과를 돌려준다

로봇이 행동을 고른다. 한 번 움직이면 새 상태와 보상 점수를 받는다.

에이전트 = 선택하는 로봇환경 = 로봇이 움직이는 세계

같은 직행도 결과가 두 갈래

0.75는 ‘출발에서 직행을 골랐을 때’ 배송될 확률이다.

조건부확률 · 무엇을 이미 골랐나

기댓값은 확률로 무게를 준 평균

0.75 × 4 + 0.25 × 0 = 3

한 번 직행하면 보상은 4 또는 0이다. 같은 조건에서 반복할 때 평균이 가까워지는 값이 3이다.

잠깐, 직접

우회하면 다음 선택이 생긴다

그림은 ‘우회한 뒤 배송’을 고른 한 경로다. 통로 C에서는 중단도 고를 수 있다.

나중 보상에 곱할 비율이 할인율

할인율 γ(감마)를 작게 두면, 같은 보상이라도 나중에 받는 쪽의 비중이 줄어든다.

한 번의 길에서 받은 점수를 모두 더한다

G = −1 + 0.8 × 6 = 3.8

반환 G는 한 경로에서 받은 보상의 할인 합이다. 이 반환에 확률을 붙여 평균 내면 기대 반환이다.

잠깐, 직접

전이표에 가능한 결과를 모두 적는다

전이란 한 번 움직인 결과다. 같은 상태·행동에서 나올 모든 (다음 상태, 보상)의 확률을 합하면 1이다.

S 출발 · C 통로D 배송 완료 · F 배송 미완료D와 F는 종료

현재 상태에 다음을 예측할 정보가 있어야 한다

마르코프 조건에서는 현재 상태와 행동을 알면 과거 경로를 더 알아도 다음 상태·보상의 확률이 그대로다.

MDP · 마르코프 결정 과정

잠깐, 직접

정책은 선택의 확률, 전이는 결과의 확률

정책을 바꾸면 어떤 길을 더 자주 시도할지 달라진다. 이 예에서 길의 전이 확률은 그대로다.

잠깐, 직접

직행의 평균과 우회의 반환을 계산한다

import numpy as np

probability = [0.75, 0.25]
direct = np.dot(probability, [4, 0])
gamma = 0.8
detour_then_deliver = -1 + gamma * 6

assert np.isclose(sum(probability), 1.0)
print(f"직행 기대 반환 {direct:.1f}")
print(f"우회 후 배송 반환 {detour_then_deliver:.1f}")
직행 기대 반환 3.0
우회 후 배송 반환 3.8

직행은 결과 두 개를 평균 낸다. 우회 후 배송은 확률 1인 경로라 그 반환이 곧 기대 반환이다.
