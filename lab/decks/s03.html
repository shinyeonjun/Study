덱 3

곱을 합으로

지수 → 로그 → Σ·Π → 문장 점수

긴 문장의 확률을 모델은 어떻게 계산할까?

문장 확률은 토큰마다 곱한다

0.8 · 0.25 · 0.5 = 0.1

마지막의 ‘끝’은 문장 끝 표지. 다음 토큰은 앞 토큰들로 조건을 건다.

같은 수를 반복해서 곱한다

10⁻³ × 10⁻³ = 10⁻⁶. 분수 지수 1/2는 제곱근.

로그는 그 수를 만든 지수

log₁₀(0.001) = −3

로그의 입력은 양수. 로그 밑은 양수이며 1을 제외.

잠깐, 직접

곱을 로그합으로

ln(p₁p₂p₃) = ln p₁ + ln p₂ + ln p₃

ln의 밑은 e. 0.1을 400번 곱하면 부동소수점에서는 0으로 반올림되지만 로그합은 약 −921.03이다.

Σ는 다 더하고 Π는 다 곱한다

같은 항 목록을 서로 다른 방식으로 묶는다.

잠깐, 직접

같은 차이와 같은 비율은 다르다

등차는 차이 고정, 등비는 비율 고정. 등비수열에 로그를 취하면 등차가 된다.

로그 축 한 칸 = 원래 값 열 배

0.001→0.01도 0.1→1도 로그 축에서는 한 칸.

잠깐, 직접

확률과 로그확률을 같이 확인

import numpy as np
p = np.array([.8, .25, .5])
print(f"{p.prod():.1f}")
print(f"{np.log(p).sum():.4f}")
0.1
-2.3026

확률 0의 로그는 유한한 값으로 표현할 수 없다.
