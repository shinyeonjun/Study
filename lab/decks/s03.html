슬라이드 교재 덱 3

덱 3

곱을 합으로: 지수·로그·Σ

문장 확률 = 곱 → 지수 = 곱한 횟수 → 로그 = 횟수 거꾸로 → 곱이 합으로 → Σ·Π

언어 모델은 문장 확률을 토큰마다 곱해서 만든다. 길면 곱이 사라진다. 로그가 곱을 합으로 바꾼다.

문장 확률 = 토큰 확률을 차례로 곱한 것

다음 토큰 확률 = 앞 토큰들을 보고 고른 몫. 몫의 몫의 몫이라 곱한다: 0.8 × 0.25 × 0.5 = 0.1.

토큰 = 모델이 읽는 낱말 조각확률은 0~1

지수 = 같은 수를 몇 번 곱했나

10³ = 10을 3번 곱한 것. 10⁻³ = 1을 10으로 3번 나눈 것 = 0.001. 위에 작게 쓴 수가 지수.

곱하면 횟수가 더해진다 = 지수법칙

10a × 10b = 10a+b

외울 규칙이 아니라 횟수 세기. 나누기는 음수 횟수라 같은 식이 그대로 맞는다.

로그 = 몇 번 곱했나를 거꾸로 묻기

log₁₀(x) = 10을 몇 번 곱해야 x가 되나. 10을 몇 번 곱하고 나눠도 0·음수는 안 나온다 → 로그는 양수만 받는다.

잠깐, 직접

곱의 로그 = 로그의 합

log(a × b) = log a + log b

곱하기 = 지수 눈금 위에서 칸 수를 이어 걷기. 그래서 로그를 씌우면 곱이 덧셈이 된다.

문장 확률에 ln = 토큰 점수를 더한다

ln = 밑이 e(≈ 2.718)인 로그, AI에서 쓰는 기본 로그. 확률 1 → 0, 작을수록 더 큰 음수.

로그확률 = ln p문장 점수 = 로그확률의 합

잠깐, 직접

길면 곱은 0으로 사라지고, 로그합은 남는다

컴퓨터 실수(float64)는 약 10⁻³²⁴보다 작으면 0이 된다. ln은 큰 확률에 큰 값을 줘서 순서도 그대로다.

잠깐, 직접

같은 배 곱하기 → 로그로는 같은 양 더하기

토큰 하나 늘 때마다 확률 ×0.5 = 로그확률 −0.69. 로그 눈금 한 칸이 일정한 배수인 이유.

Π = 다 곱하라, Σ = 다 더하라

ln Π pₜ = Σ ln pₜ

곱의 로그 = 로그의 합을 토큰 수만큼. 언어 모델의 학습 점수가 이 식이다.

잠깐, 직접

곱, 로그합, 사라지는 곱을 코드로

import numpy as np
p = np.array([0.8, 0.25, 0.5])
print(round(p.prod(), 4), round(np.log(p).sum(), 4))
print(round(np.exp(np.log(p).sum()), 4))   # 로그합 → 다시 확률
q = np.full(400, 0.1)                       # 토큰 400개
print(q.prod(), round(np.log(q).sum(), 2))
0.1 -2.3026
0.1
0.0 -921.03

np.log = ln. 곱은 0.0이 되지만 로그합은 −921.03으로 남는다.
