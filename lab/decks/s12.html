덱 12

독립과 베이즈

알아도 그대로 = 독립 → 독립이면 곱 → 배반 ≠ 독립 → 조건 뒤집기 = 베이즈 → 기저율 → 증거가 쌓이면

덱 11의 요청 100건과 나무를 이어서. 마지막은 이상 탐지 모델의 경고 하나.

특성이 쓸모 있다 = 알면 확률이 바뀐다

짝수 번호는 실패에 대해 아무것도 말해 주지 않는다. 이런 관계 = 독립. 독립인 특성은 예측에 보탬이 없다.

짝수 번호 50건 · 실패 10건은 예로 정한 숫자

독립 = 한쪽을 알아도 다른 쪽 확률이 그대로

H = 동전 앞면, E = 주사위 짝수. 앞면이라는 조건으로 분모를 줄여도 짝수의 비율이 같다 = 동전은 주사위에 대해 아무것도 말해 주지 않는다.

P(E | H) = P(E)

잠깐, 직접

독립이면 '둘 다' = 확률의 곱

독립 ⇔ P(A ∩ B) = P(A) × P(B)

덱 11의 길 곱하기 P(A ∩ B) = P(B) × P(A | B)에서 P(A | B)가 P(A)와 같으면 곱만 남는다. 곱이 맞는지가 독립의 시험.

잠깐, 직접

배반 ≠ 독립: 겹치지 않는 건 오히려 가장 얽힌 것

배반 = 칸이 겹치는가(그림만 보고 안다). 독립 = 알면 확률이 바뀌는가(숫자를 대 봐야 안다). 확률이 0보다 큰 두 사건이 배반이면 독립일 수 없다.

잠깐, 직접

빼 두고 뽑으면 = 첫 결과가 둘째를 바꾼다

독립은 공의 성질이 아니라 뽑는 방법의 성질. 같은 상자라도 규칙이 바뀌면 답이 바뀐다.

한 바퀴(epoch) 안에서 자료를 겹치지 않게 뽑기 = 비복원

이상 탐지 모델이 경고했다: 이상일 확률은?

모델 성능은 'A일 때 E'로 잰다. 쓰는 사람은 'E를 봤을 때 A'가 궁금하다. 조건을 뒤집는 계산 = 베이즈.

기저율 = 아무것도 보기 전 이상 비율Aᶜ = 정상

1000대로 펼치면: 경고 107대 중 이상은 8대

경고가 떴으니 분모 = 경고 107대. 이상은 드물어(10대) 정상 990대에서 나온 오경고 99가 경고 대부분을 차지한다.

1% → 약 7.5%: 올랐지만 80%와는 멀다1000대는 계산용 가상 대수

베이즈 규칙 = 펼쳐 센 것을 식으로

분자 = '이상이면서 경고' 길(8대), 분모 = 경고로 가는 모든 길(107대). 덱 11의 나무에서 곱하고 더한 뒤 나눈 것뿐.

사전 → 증거 → 사후분모에 정상의 오경고가 꼭 들어간다

잠깐, 직접

기저율이 바뀌면 = 같은 경고도 다른 뜻

모델은 그대로인데 장소만 바뀌어도 경고의 뜻이 0.075에서 0.47로. 기저율을 빼고 0.8을 답으로 읽는 것 = 기저율 무시.

다른 곳에 옮기면 0.8, 0.1도 바뀔 수 있다

잠깐, 직접

증거가 또 오면 = 사후가 다음 사전이 된다

가정: 장치 상태를 알면 두 센서의 경고는 서로 독립(조건부 독립). 같은 잡음에 함께 흔들리면 이 곱셈은 증거를 부풀린다.

베이즈 갱신 = 증거마다 확률을 고쳐 가기나이브 베이즈 분류기 = 특성들에 이 가정을 둔다

기저율만 바꿔서 계산

from fractions import Fraction as F
hit, false_alarm = F(8, 10), F(1, 10)          # P(E | A), P(E | Aᶜ)
for prior in (F(1, 100), F(1, 10)):            # P(A)
    warn = prior * hit + (1 - prior) * false_alarm
    post = prior * hit / warn
    print(prior, warn, post, round(float(post), 4))
p1 = F(8, 107)                                 # 경고 1번 뒤 = 다음 사전
print(p1 * hit / (p1 * hit + (1 - p1) * false_alarm))
1/100 107/1000 8/107 0.0748
1/10 17/100 8/17 0.4706
64/163

Fraction = 분수 그대로 계산. 사전 1/100 → 사후 8/107, 사전 1/10 → 8/17(= 80/170). 마지막 줄 = 경고 두 번.

한눈에 정리

독립알아도 확률 그대로 · P(A | B) = P(A) · 예측에 보탬 없음
독립의 시험P(A ∩ B) = P(A) × P(B) · 동전·주사위 1/4 ✓, 모바일·실패 0.12 ≠ 0.08
배반겹치지 않음 · 확률이 양수면 독립일 수 없다
비복원첫 결과가 둘째를 바꾼다 · 3/5 → 2/4
베이즈P(A | E) = P(A) × P(E | A) ÷ P(E) · 1% → 8/107 ≈ 0.075
기저율같은 경고도 기저율 10%면 0.47 · 0.8을 답으로 읽지 않는다
갱신사후 → 다음 사전 · 경고 2번 64/163 ≈ 0.39 (조건부 독립 가정)
