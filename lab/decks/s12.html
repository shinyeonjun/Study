독립과 베이즈

기저율 → 조건의 방향 → 베이즈 → 독립

감지율 90%인 모델도 경고의 절반만 맞을 수 있다.

감지율 90%를 어디에 적용할까?

스팸일 때 경고가 울릴 확률과, 경고일 때 스팸일 확률은 다르다.

전체 경고는 90이 아니라 180

P(스팸 | 경고) = 90/180 = 0.5

경고를 받았다면 이 열의 180개 가운데 실제 스팸 90개.

베이즈는 조건을 반대쪽에서 계산

A는 실제 스팸, B는 경고. 분모는 스팸·정상에서 경고가 나올 확률을 더한 값.

잠깐, 직접

스팸이 드물어지면 결과가 바뀐다

10,000건 중 스팸 100건이면 90건 정탐, 정상 9,900건이면 990건 오탐.

독립인 신호는 확률을 바꾸지 않는다

P(B)>0일 때 P(A | B)=P(A)인 경우 독립.

잠깐, 직접

서로 동시에 못 일어남 ≠ 독립

독립이면 교집합 확률과 개별 확률의 곱이 같아야 한다.

같은 경고라도 적용 대상 확인

모델이 옮겨 갈 곳에서 기저율과 성능을 다시 확인.

잠깐, 직접

기저율만 바꿔서 계산

import numpy as np
prior = np.array([.10,.01])
tp = .9*prior
fp = .1*(1-prior)
print((tp/(tp+fp)).round(4).tolist())
[0.5, 0.0833]

감지율과 오탐률은 두 조건에서 동일하다.

한눈에 정리

기저율새 신호 전에 실제 스팸이 얼마나 흔한가
베이즈P(A | B) = P(B | A)·P(A) / P(B)
독립P(A∩B) = P(A)·P(B)
배반두 사건이 동시에 일어나지 않음
