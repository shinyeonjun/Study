덱 14

많이 반복하면: 추정과 불확실성

모르는 μ, 손에 든 x̄ → 가장 그럴듯한 값 → 모으면 μ로 → 평균도 흔들린다 → σ/√n → 종 모양 → 구간 → 다시 뽑기 → 편향

테스트 요청 36개로 잰 평균 응답 2.6초. 이 숫자를 얼마나 믿을까?

모르는 참값 μ, 손에 든 x̄ = 추정

μ = 모수(모집단의 값). x̄ = 통계량(표본으로 계산한 값). 추정 = x̄로 μ를 맞히기.

테스트 정확도도 x̄모집단 = 모델이 실제로 받을 요청 전체

이 자료가 가장 잘 나올 값 = 최대우도

L(p) = p(1 − p)³ → 가장 높은 곳 p = 0.25

자료는 고정, 후보 p를 바꿔 가며 '이 자료가 나올 확률'(우도)을 잰다. 가장 높은 p가 추정값.

학습 = 우도 최대 = −log 우도(손실) 최소 (덱 15)

많이 모으면 x̄ → μ = 대수의 법칙

하나는 1이나 5로 크게 튀지만, 쌓일수록 큰 값과 작은 값이 서로 상쇄되어 2.5 곁에 붙는다.

기댓값 = 긴 반복의 평균 (덱 13)미니배치 평균 손실도 같은 원리

x̄도 확률변수: 두 요청의 평균은 가운데로 몰린다

가능한 9쌍을 다 따진 분포. 큰 값과 작은 값이 만나 가운데가 된다. 분산 2.25 → 1.125 (반).

평균 = 표본마다 달라지는 확률변수그 분포 = 표집분포

평균의 흔들림 = σ/√n = 표준오차

SE = σ / √n

독립 n개의 합은 분산 n·σ² (위에서 둘 → 4.5). n으로 나누면 분산 ÷ n² → σ²/n, √ 하면 σ/√n.

잠깐, 직접

모아도 그대로인 SD, 줄어드는 SE

SD = 요청 하나가 얼마나 다른가. SE = 평균이 다시 잴 때 얼마나 다른가. 다음 요청이 1~5초인 건 n이 커도 그대로.

평균의 분포는 종 모양으로 = 중심극한정리

원래 분포는 치우쳤는데, 평균의 분포는 n이 클수록 종(정규) 모양. 원자료가 정규로 바뀌는 게 아니다.

그래서 '± 1.96 SE'가 통한다조건: 독립 · 같은 분포 · 분산이 유한

잠깐, 직접

x̄ ± 1.96·SE를 던지면 = 95% 신뢰구간

2.6 ± 1.96 × 0.25 = [2.11, 3.09]

μ는 고정, 움직이는 건 구간. 95% = 이 방법이 μ를 덮는 비율. 1.96은 정규의 ± 1.96σ 넓이 0.95 (덱 13).

σ를 모르면 s와 t값으로 (ST03)

잠깐, 직접

가진 표본에서 다시 뽑기 = 부트스트랩

모집단을 다시 못 뽑으니 표본을 모집단 대신 쓴다. 평균들의 퍼짐 0.75 = SE 추정 (여기선 σ/√4 = 0.75와 같다).

식이 없는 값(중앙값, F1)에도 쓴다뽑는 단위 = 서로 독립인 단위

잠깐, 직접

모아도 안 줄어드는 오차 = 편향

E[x̄] − μ = 2.0 − 2.5 = −0.5

편향 = 평균적으로 참값에서 벗어난 양. n을 늘리면 SE만 줄어 2.0에 정확히 모인다, 틀린 곳에.

못 돌아온 느린 요청이 빠진 기록같은 사용자 반복 = 독립 아님

잠깐, 직접

표집분포, 구간, 부트스트랩을 코드로

import numpy as np
x, p = np.array([1, 2, 5]), np.array([0.25, 0.5, 0.25])
rng = np.random.default_rng(0)
means = rng.choice(x, size=(10_000, 36), p=p).mean(axis=1)  # 36개 평균을 1만 번
print(means.mean().round(3), means.std().round(3))          # μ = 2.5, SE = 0.25 근처
lo, hi = means - 1.96 * 0.25, means + 1.96 * 0.25
print(((lo <= 2.5) & (2.5 <= hi)).mean())                   # μ를 덮은 비율
s = np.array([1, 2, 2, 5])
boot = rng.choice(s, size=(10_000, 4)).mean(axis=1)         # 부트스트랩
print(boot.std().round(3))

1만 번 다시 잰 평균의 퍼짐 = SE. 구간이 μ를 덮은 비율이 0.95 근처.
