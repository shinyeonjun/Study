덱 8

선형회귀 완성

가장 가까운 직선? → 잔차 → 제곱합 → 바닥 = 남은 무늬 없음 → b, w 풀기 → 새 집

방 수로 가격 맞히기. 세 집을 다 지나는 직선이 없을 때, 어느 직선을 고를까.

방 수로 가격을 맞히는 직선 = 선형회귀

세 점을 다 지나는 직선은 없다. 먼저 '가깝다'를 숫자로 정해야 고를 수 있다.

학습 = 좋은 b, w 찾기 (덱 1)특성 하나 → 예측 하나

잔차 = 모델이 놓친 만큼

r = y − ŷ

y = 실제 가격, ŷ = 예측. 방 수를 주고 가격을 맞히니까, 같은 방 수에서 세로로 잰다. +는 낮게 예측, −는 높게 예측.

잔차 합은 속는다 → 제곱해서 더한다 = SSE

SSE = Σ r²

두 직선 다 잔차 합 0: +와 −가 지워진다. 제곱(넓이)은 지워지지 않고, 크게 틀린 집을 더 크게 센다. SSE가 작을수록 가까운 직선.

잠깐, 직접

직선마다 SSE 하나 → 가장 낮은 곳 = 최소제곱

SSE는 b, w의 함수: 손실(덱 6). 바닥은 더 줄일 방향이 없는 곳, 곧 기울기 0인 곳.

최소제곱 = SSE가 가장 작은 b, w바닥 = 기울기 0

집을 쌓고 1 열을 붙이면 = 설계행렬 X

β = (b, w): 찾을 계수 두 개. 1 열이 있어야 b도 '곱해서 더하기' 안에 들어간다.

바닥 = 잔차에 남은 무늬가 없다

Xᵀr = 0

Xᵀr = X의 열(1 열, 방 수 열)마다 r과 내적: (Σr, Σx·r). SSE를 b로 미분 = −2Σr, w로 미분 = −2Σx·r. 바닥에서 둘 다 0.

잠깐, 직접

두 조건을 풀면 b = 1, w = 1.5

XᵀX β = Xᵀy

이 두 식을 행렬로 쓴 것이 정규방정식('정규'는 정규분포와 상관없다). 식 두 개, 모르는 수 두 개: 덱 2처럼 거꾸로 풀기.

평균점에서 보면 기울기 = 같이 움직인 양 ÷ x의 퍼짐

첫 조건 ÷ 3: b + 2w = 4 → 직선은 평균점 (2, 4)를 지난다. 방이 평균보다 많은 집이 가격도 평균보다 높을수록(넓이 +) 기울기가 커진다.

잠깐, 직접

열이 겹치면 답이 하나가 아니다

자료가 가르는 것은 w₁ + 2w₂ 하나뿐: 새 정보를 주는 열 수(랭크, 덱 2) < 열 수. 예측은 같아도 계수 하나하나를 '효과'로 읽을 수 없다.

잠깐, 직접

새 집 = 식에 넣기, 믿는 범위는 자료가 있는 곳까지

예측은 곱해서 더하기 한 번. 학습에 쓴 세 집의 SSE로는 새 집 성능을 모른다: 따로 둔 검증 자료로 잰다(덱 7).

잠깐, 직접

X 쌓기, 최소제곱, 경사하강을 코드로

import numpy as np
x, y = np.array([1, 2, 3]), np.array([3, 3, 6])
X = np.column_stack((np.ones(3), x))      # 1 열 + 방 수 열
beta = np.linalg.lstsq(X, y, rcond=None)[0]
r = y - X @ beta
print(beta.round(6).tolist(), r.round(6).tolist(), round(r @ r, 6))
print(np.allclose(X.T @ r, 0))            # 남은 무늬 없음
b = np.zeros(2)
for _ in range(1000):                     # 경사하강으로도 같은 바닥
    b += 0.3 * X.T @ (y - X @ b) / 3
print(b.round(6).tolist(), round(np.array([1, 4]) @ beta, 6))
[1.0, 1.5] [0.5, -1.0, 0.5] 1.5

lstsq = 한 번에 풀기, 반복문 = 그릇을 조금씩 내려가기(덱 6). 같은 b = 1, w = 1.5.
