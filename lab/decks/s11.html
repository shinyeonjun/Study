확률의 언어

결과 전체 Ω → 사건 = 칸 묶음 → 그리고·또는·아님 → 세기 → P의 규칙 → 조건 = 분모 바꾸기

분류 모델이 내놓는 '0.30'을 읽기 위한 낱말들. 서버 요청 100건 기록 하나로 끝까지.

분류 모델의 출력 = 조건이 붙은 확률

0.30 = '모바일이라는 조건에서' 실패하는 비율. 이 문장을 정확히 쓰려면 낱말 세 개: 결과 전체, 사건, 조건.

모델 출력 = 입력을 안 뒤의 확률기록 100건으로 끝까지

표본공간 Ω = 한 번 해서 나올 수 있는 결과 전체

한 번 = 기록에서 요청 하나를 무작위로 뽑기. Ω(오메가)는 무엇을 적어 둘지 정하는 일: 잘게 적으면 나중에 묶을 수 있지만, 거칠게 적으면 되돌릴 수 없다.

사건 = Ω의 칸 묶음 = 예/아니오 질문 하나

뽑힌 칸이 M 안에 있으면 'M이 일어났다'. 질문 하나 = 칸 묶음 하나 = 부분집합.

Ω 전체 = 반드시 일어남∅ (빈 묶음) = 절대 안 일어남

그리고 = 겹친 칸, 또는 = 어느 쪽이든, 아님 = 나머지

∩ = 둘 다, ∪ = 적어도 하나, ᶜ = 그 사건이 아닌 칸 전부. 원 크기는 칸 수와 비례하지 않게 그렸다.

|M| = M의 칸 수(M ∪ F)ᶜ = Mᶜ ∩ Fᶜ = 52

잠깐, 직접

순서가 있으면 곱하고, 순서를 지우면 겹친 만큼 나눈다

모든 결과가 같은 가능성이면 확률 = 그 사건의 칸 수 ÷ 전체 칸 수. 그래서 센다. 단계마다 갈래 수를 곱하고, 같은 것을 여러 번 셌으면 나눈다.

문장 생성 = 순서 있음 (순열)단어 묶음 = 순서 없음 (조합)

잠깐, 직접

확률 P = 칸 묶음에 0~1 무게를 다는 규칙

규칙 셋: 무게는 0 이상, Ω 전체는 1, 겹치지 않는 조각은 더한다. 나머지는 모두 '조각으로 나눠 더하기'에서 나온다.

아님 = 1 − 그 사건또는 = 더하고 겹침 빼기어떤 사건도 1을 넘지 않는다

잠깐, 직접

조건 = 분모를 그 집단으로 바꾸기

P(F | M) = P(F ∩ M) ÷ P(M) = 0.12 ÷ 0.40 = 0.30

| 뒤 = 이미 안 사실. 조건 M이 새 '전체 1'이 된다. 모델이 입력을 보고 내놓는 확률이 바로 이것.

잠깐, 직접

| 양쪽을 바꾸면 다른 숫자: P(F | M) ≠ P(M | F)

분자 12(둘 다)는 같다. 분모가 '모바일 40'이냐 '실패 20'이냐가 다르다. 두 질문을 섞는 것이 가장 흔한 실수.

P(F | M): 모바일이면 얼마나 실패하나P(M | F): 실패한 것 중 모바일은 얼마나

잠깐, 직접

나무의 길 = 조건부 확률을 곱해 '둘 다'로 되돌리기

P(M ∩ F) = P(M) × P(F | M)

조건부의 식에서 분모를 넘긴 것. 한 길에서는 곱하고, 겹치지 않는 길끼리는 더한다. 다음 덱에서 이 나무를 거꾸로 읽는다(베이즈).

칸 묶음을 참·거짓 배열로

import numpy as np
mobile = np.array([1]*40 + [0]*60, dtype=bool)          # 요청 100건
fail = np.array([1]*12 + [0]*28 + [1]*8 + [0]*52, dtype=bool)
print((mobile & fail).sum(), (mobile | fail).sum(), (~mobile).sum())
print(fail.mean(), fail[mobile].mean(), mobile[fail].mean())
12 48 60
0.2 0.3 0.6

참·거짓 배열 = 사건. mean = 참의 비율 = 확률. fail[mobile] = 모바일 칸만 남기기 = 조건.

한눈에 정리

표본공간 Ω나올 수 있는 결과 전체 · 빠짐없이, 겹치지 않게 (요청 100건)
사건Ω의 칸 묶음 = 예/아니오 질문 (M 40칸, F 20칸)
∩ ∪ ᶜ그리고 12 · 또는 40 + 20 − 12 = 48 · 아님 60
세기순서 있음 = 곱하기 (6) · 순서 없음 = 겹친 만큼 나누기 (3)
P의 규칙0 이상 · 전체 1 · 안 겹치면 더한다
조건부 P(F | M)분모를 M으로: 12 ÷ 40 = 0.30 ≠ P(M | F) = 0.60
곱셈P(M ∩ F) = P(M) × P(F | M) · 나무의 길
