확률의 언어

표본공간 → 사건 → 교집합 → 조건부확률

스팸 경고를 봤을 때 실제 스팸일 가능성을 사건으로 표현한다.

표본공간 = 가능한 결과 전체

한 메일이 두 사건에 동시에 속할 수 있다.

겹치는 결과는 한 칸으로

P(A∩B) = 15 / 100

A∩B에는 실제 스팸이고 경고도 받은 15개만 있다.

또는은 겹친 개수를 한 번 뺀다

둘 중 어느 것도 아닌 메일은 나머지 65개.

잠깐, 직접

조건을 알면 분모가 줄어든다

‘경고인 것 중 스팸’은 15/30. ‘스팸 중 경고’는 15/20.

∪ 밖에는 두 조건이 모두 없다

(A∪B)ᶜ = Aᶜ∩Bᶜ

‘A 또는 B가 아님’은 표현이 모호하므로 ‘A도 B도 아님’으로 써 본다.

잠깐, 직접

순서를 기억하면 세는 답이 바뀐다

경우의 수로 확률을 내려면 각 결과가 같은 확률인지 확인.

모형은 조건을 붙여 다음을 맞힌다

경고 전의 스팸 확률은 0.2, 경고를 본 뒤에는 0.5다.

잠깐, 직접

교차표의 분모 두 가지

import numpy as np
counts = np.array([[15,5],[15,65]])
print(int(counts.sum()))
print(float(counts[0,0]/counts[:,0].sum()))
print(float(counts[0,0]/counts[0,:].sum()))
