덱 18

역전파

손잡이마다 책임 → 살짝 돌리면 배율이 곱해진다 → 끝에서 거꾸로 한 번에 → 갈래는 더한다 → 꺼진 ReLU → 미니배치

가중치가 수천 개여도, 끝에서 한 번 거꾸로 훑으면 모두의 기울기가 나온다.

순전파 = 입력에서 손실까지, 중간값을 적어 두며

ŷ = 예측, L = 손실(덱 6). 계산 칸을 화살표로 이은 것 = 계산 그래프. 중간값 z, h, ŷ은 거꾸로 갈 때 다시 쓴다.

w, b, v, c = 고칠 손잡이(매개변수)x, y = 주어진 자료

w를 살짝 돌리면 = 칸마다 배율이 곱해진다

∂L/∂w = 24

∂L/∂w = w만 살짝 바꿀 때 손실이 변하는 배율(덱 5). 실제로 w = 3.01이면 L = 18.2408. 배율 이어 곱하기 = 연쇄법칙(덱 4).

끝에서 거꾸로 = 모든 손잡이를 한 번에 = 역전파

뒤쪽 공통 부분(6, 12)을 한 번 구해 모두가 나눠 쓴다. 손잡이마다 따로 돌려 보면 손잡이 수만큼 다시 계산해야 한다.

순전파 한 번 + 역전파 한 번 = 모든 기울기

잠깐, 직접

곱하는 배율 = 칸마다 '조금 늘리면'의 답

곱셈 칸에서 w 쪽 배율은 x, x 쪽 배율은 w. 그래서 ∂L/∂w = 12 × 2인데 ∂L/∂x = 12 × 3 = 36.

국소 기울기 = 칸 하나의 배율역전파 = 국소 기울기를 이어 곱하기

같은 값이 두 길로 쓰이면 = 길마다 기여를 더한다

한 길 안에서는 곱하고, 길이 모이면 더한다: 두 길이 동시에 손실을 움직이니까. 덱 17의 x₁도 s₁, s₂ 두 유닛으로 간다.

갈래 = 같은 값이 여러 칸에 쓰임

잠깐, 직접

ReLU가 꺼진 길로는 책임이 0

b = −7이면 z = −1. w를 살짝 돌려도 z는 음수 그대로 → h = 0 그대로 → 손실도 그대로. 이 예에서는 c만 배운다. z = 0에서는 기울기가 없어 PyTorch는 0을 쓴다.

기울기를 받으면 한 걸음 = 모든 손잡이를 반대로

새 w = w − η × ∂L/∂w

η = 학습률(덱 6), 여기선 0.01. 학습 = 순전파 → 역전파 → 한 걸음을 되풀이.

자료가 여럿이면 기울기도 표본마다, 쓰는 건 평균

가장 단순한 모델: 예측 = w. 전체 손실 = 한 건 손실의 평균 → 기울기도 평균. 표본마다 '고칠 방향'이 다르다.

몇 개만 뽑아 평균 = 미니배치: 싸지만 흔들린다

흔들림(분산) = 한 건 분산 ÷ 배치 크기

미니배치 = 일부만 뽑아 평균한 기울기, 이걸로 걷기 = SGD. 가운데는 그대로 −4: 방향은 맞고 흔들림만 준다. 분산 = 평균에서 벗어난 정도(덱 10).

잠깐, 직접

바닥에서도 한 건 기울기는 0이 아니다

그래서 학습률을 점점 줄인다(학습률 스케줄). 미니배치를 키워도 흔들림이 준다.

SGD = 미니배치 기울기로 걷기바닥 근처 흔들림은 학습률에 비례

잠깐, 직접

순전파, 역전파, 검산, 미니배치를 코드로

import numpy as np
x, y = 2.0, 4.0
w, b, v, c = 3.0, -1.0, 2.0, 0.0
z = w*x + b; h = max(z, 0); yh = v*h + c   # 순전파
L = (yh - y)**2 / 2
d_yh = yh - y; d_h = d_yh * v; d_z = d_h * (z > 0)   # 역전파
print(L, d_yh, d_h, d_z)
print(d_z * x, d_z, d_yh * h, d_yh)    # w, b, v, c
f = lambda w: (v*max(w*x + b, 0) + c - y)**2 / 2
print(round((f(w + 1e-3) - f(w - 1e-3)) / 2e-3, 6))   # 살짝 돌려 검산
g = 0 - np.array([1, 3, 5, 7])          # w = 0의 표본 기울기
print(g.mean(), g.var(), g.reshape(2, 2).mean(axis=1))
