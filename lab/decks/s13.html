덱 13

확률변수·기댓값·분포

결과 → 숫자 X → 막대 = 분포 → 무게중심 = 기댓값 → 흔들림 = 분산 → 세는 방식 = 분포 이름 → 넓이 = 밀도

같은 챗봇에 물어도 응답 시간은 매번 다르다. 그 '매번 다름'을 숫자로 다루는 법.

결과마다 숫자를 붙이는 규칙 = 확률변수 X

규칙은 정해져 있고, 어느 결과가 올지만 모른다. 그래서 값 X도 미리 모른다.

확률변수 = 결과 → 숫자{X = 2} = X가 2가 되는 결과들

값마다 확률을 모으면 = 분포

p(x) = P(X = x): X가 정확히 x일 확률. 결과 하나하나 대신 '값마다 얼마나 자주'만 남긴다.

언어모델의 출력 = 다음 낱말마다 확률 막대분포 ≠ 한 번 나온 값

기댓값 = 아주 많이 했을 때의 평균 = 무게중심

E[X] = 1×0.25 + 2×0.5 + 5×0.25 = 2.5

확률 = 긴 반복에서의 비율 → 확률로 가중한 합 = 긴 반복의 평균. 2.5초 응답은 한 번도 없다.

학습이 줄이는 손실 = 손실의 기댓값강화학습: 보상의 기댓값을 키운다

잠깐, 직접

평균이 같아도 다르다 → 분산 = 평균에서 거리²의 평균

Var(X) = E[(X − 2.5)²] = 2.25

거리를 그냥 평균 내면 −와 +가 지워져 늘 0 (덱 8의 잔차 합). 그래서 제곱. √로 단위를 초로 되돌리면 표준편차 SD = 1.5초.

다 같이 밀면 그대로, 늘리면 제곱으로

E[aX + b] = a·E[X] + b · Var(aX + b) = a²·Var(X)

0.5초 고정 지연: 모두 같이 밀려 평균에서의 거리는 그대로. 두 배 느린 서버: 거리가 2배 → 거리²은 4배 (2.25 → 9).

잠깐, 직접

4번 중 느린 횟수 K = 이항분포

P(K = k) = (순서 수) × 0.25ᵏ × 0.75⁴⁻ᵏ

한 번 = 느림 1 / 아님 0 (베르누이, 평균 0.25). K는 그 넷을 더한 값이라 평균도 0.25 × 4 = 1.

무엇을 세느냐 = 어떤 분포냐

같은 '느림 0.25'라도 묻는 것이 다르면 막대 모양이 다르다. 분포 이름 = 세는 방식.

베르누이 = 한 번의 0·1기하: '평균 4번'이어도 4번 안에 안 올 수 있다

잠깐, 직접

소수점까지 재면 막대 대신 넓이 = 밀도

P(a ≤ T ≤ b) = 곡선 아래 넓이 = ∫ f(t) dt

f(t) = 밀도(높이), ∫ = 잘게 나눈 막대 넓이의 합(적분). 한 점은 폭이 0이라 P(T = 0.5) = 0.

잠깐, 직접

왼쪽부터 모은 확률 = 누적분포 F

F(x) = P(X ≤ x)

뛰는 높이 = 그 값의 확률. 곡선의 기울기 = 밀도 (t²을 미분하면 2t).

P(X > 2) = 1 − F(2) = 0.25F는 0에서 1로 오르기만 한다

잠깐, 직접

평균 근처에 몰린 종 = 정규분포

같은 요청을 여러 번 잰 지연처럼 작은 흔들림이 더해진 값. μ에서 'σ 몇 개'만큼 떨어졌는지만 알면 넓이가 정해진다.

신경망 가중치 초기값을 정규에서 뽑는다평균들의 분포가 이 모양 (덱 14)지수분포 = 첫 도착까지 기다린 시간

기댓값, 분산, 누적을 코드로

import numpy as np
x = np.array([1, 2, 5]); p = np.array([0.25, 0.5, 0.25])
mu = x @ p                                   # 확률로 가중한 합
print(mu, (x - mu)**2 @ p, np.cumsum(p))     # E[X], Var(X), F
rng = np.random.default_rng(0)
s = rng.choice(x, size=100_000, p=p)         # 요청 10만 번 흉내
print(s.mean().round(3), s.var().round(3))
print((2*x - 2*mu)**2 @ p)                   # 2X의 분산
2.5 2.25 [0.25 0.75 1.  ]
2.497 2.245
9.0

x @ p = 곱해서 더하기(덱 1). 10만 번 흉내 낸 평균·분산이 2.5, 2.25 근처.
