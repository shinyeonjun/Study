확률변수·기댓값·분포

질량 → 평균 → 분산 → 연속 밀도

AI 응답 시간 하나를 여러 번 관측한다면 어떤 값이 얼마나 나올까?

결과를 숫자로 바꾸면 확률변수

같은 조건에서 단일 응답 시간을 X로 표시. 막대는 확률질량.

평균을 낼 때 더 자주 나오는 값에 비중

E[X] = 2.5초

한 번에 2.5초가 실제로 나올 필요는 없다.

흔들림은 평균에서의 거리로

평균과의 거리를 제곱해 확률로 가중한다. 표준편차는 √2.25=1.5초.

잠깐, 직접

횟수와 기다림은 서로 다른 질문

독립이고 성공 확률이 같다. 시간 구간의 드문 도착 횟수에는 포아송도 쓴다.

누적은 그 값까지 전부 더한다

F(x) = P(X ≤ x)

2초 이하가 0.75이면, 2초보다 오래는 1−0.75=0.25.

잠깐, 직접

연속에서는 막대 높이 대신 넓이

밀도는 높이이고 확률은 넓이. 정확히 한 점에 놓일 확률은 0.

무엇을 재는지 보고 분포를 고른다

정규나 지수도 모형. 실제 자료의 모양과 가정을 확인.

잠깐, 직접

질량을 더해 평균과 분산

import numpy as np
x = np.array([1., 2., 5.])
p = np.array([.25, .5, .25])
print((p.cumsum()).tolist())
print(float(x @ p), float((x*x) @ p - (x @ p)**2))
[0.25, 0.75, 1.0]
2.5 2.25

누적합과 확률로 가중한 평균을 출력한다.
