기초 없이 시작해서 필기부터 차근차근. 개념 하나를 확실히 이해하고 다음으로 넘어갑니다.

오늘 복습할 것

노트를 읽고 '공부 끝'을 누르면, 복습할 날에 여기에 나타납니다.

과목과 노트

과목 구성은 지금 알려진 필기 기준으로 잡은 틀입니다. 시험 과목·출제 기준·일정은 바뀔 수 있으니 데이터자격검정 공식 공지에서 꼭 확인하세요.

이렇게 공부합니다

  1. 읽기. 노트는 비유 → 정의 → 예제 → 확인 문제 순서입니다. 외우기는 그대로 외울 것, 이해하기는 왜 그런지 설명할 수 있어야 하는 것입니다.
  2. 가리고 떠올리기. 다 읽었으면 위쪽 핵심어 가리기를 켜고, 빈칸을 머릿속으로 채운 뒤 눌러서 확인합니다. 다시 읽기보다 떠올려 보는 쪽이 훨씬 오래 남습니다.
  3. 확인 문제. 답을 먼저 생각하고 나서 엽니다. 맞았는지 틀렸는지 표시해 두면 홈에서 틀린 문제 수가 보입니다.
  4. 공부 끝 누르기. 그러면 1일, 3일, 7일, 14일, 30일 간격으로 복습할 날에 이 페이지 맨 위에 다시 나타납니다. 한 번에 몰아 보는 것보다 간격을 두고 여러 번 보는 쪽이 기억에 남습니다.
공부 기록은 이 기기의 브라우저에만 저장됩니다. 다른 기기와는 따로 기록됩니다.
