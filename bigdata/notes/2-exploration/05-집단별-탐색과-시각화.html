집단 구성까지 살피는 탐색적 데이터 분석

전체 비율을 보고 잘 운영되는 지점을 골랐는데, 한산한 때와 혼잡한 때를 따로 보면 결론이 달라질 수 있습니다. 탐색에서는 변수형과 분모, 그래프에 보이지 않는 조건을 확인합니다.

이 장을 읽고 나면

  • 질문과 변수의 종류에 맞는 그림을 고른다.
  • 집단 안의 비율과 전체 비율을 계산해 비교한다.
  • 상관과 시각적 패턴을 원인 주장과 구별한다.

표의 유형에서 어떤 그림을 그릴지 고른다

탐색적 데이터 분석(EDA)에서는 숫자를 계산하고 그림을 그려 자료의 모양과 의심할 점을 찾습니다. 지점별 건수와 요일 같은 범주에는 막대그래프를 사용할 수 있습니다. 날짜 순서에 따른 급변은 선그래프, 대기 인원과 대기시간처럼 짝을 이룬 수치는 산점도로 살필 수 있습니다.

처리량이 증가한 것처럼 보이면 세로축 범위와 시간 간격을 먼저 확인합니다. 두 팀이 1시간마다 집계한 수와 하루 전체 집계를 한 눈금에 넣으면 비교가 어렵습니다. 범주별 건수를 수치 범위의 히스토그램과 혼동하지 말고, 비율을 보고할 때는 분모를 표시합니다.

전체 수치가 집단별 비교와 다른 경우

방문 조건A의 정시 처리B의 정시 처리
한산9건 / 10건 = 90%80건 / 100건 = 80%
혼잡20건 / 100건 = 20%1건 / 10건 = 10%
전체29건 / 110건 ≈ 26.4%81건 / 110건 ≈ 73.6%

두 조건 모두 A의 비율이 높지만, A는 어려운 혼잡 기록의 비중이 큽니다. B는 한산한 기록의 비중이 큽니다. 합쳐서 보면 B의 비율이 훨씬 높습니다. 조건별 비교와 전체 비교의 방향이 뒤집히는 경우를 심프슨 역설이라고 합니다. 서로 다른 질문에 답한 값이므로 어느 쪽의 분모를 사용했는지 분명히 적습니다.

a = [(9, 10), (20, 100)]
b = [(80, 100), (1, 10)]

def pooled(rows):
    return sum(done for done, total in rows) / sum(total for done, total in rows)

for name, rows in (("A", a), ("B", b)):
    group_rates = [f"{done/total:.1%}" for done, total in rows]
    print(name, *group_rates, f"{pooled(rows):.1%}")

실행 결과

A 90.0% 20.0% 26.4%
B 80.0% 10.0% 73.6%

값이 함께 움직여도 이유는 더 확인한다

정시 처리 비율이 낮은 지점이 더 큰 업무를 처리했을 수 있습니다. 행사, 당일 인력, 고객 유형 등 다른 조건이 두 수치 모두와 관계될 수도 있습니다. 산점도가 함께 증가하는 모양을 보여도 그것만으로 한 값이 다른 값을 변화시켰다고 말할 수는 없습니다. 공분산과 상관에서 곡선 관계와 이상값의 예를 다룹니다.

두 수치가 직선적으로 함께 움직이는 정도는 피어슨 상관계수 r로 요약합니다. r은 공분산을 두 표준편차의 곱으로 나눈 값으로 −1에서 1 사이이며, 1에 가까우면 양의 직선 관계, −1에 가까우면 음의 직선 관계, 0 근처면 직선 관계가 약하다는 뜻입니다. r=0이어도 곡선 관계는 있을 수 있고, 이상값 하나가 r을 크게 바꿀 수 있으므로 반드시 산점도와 함께 봅니다. 순서만 의미 있는 자료나 단조 관계를 볼 때는 값을 순위로 바꿔 계산하는 스피어만 순위상관계수를 씁니다.

탐색에서 뒤늦게 발견한 흥미로운 패턴은 다음 분석 질문으로 기록합니다. 여러 조합을 본 뒤 가장 눈에 띈 하나만 보고한다면 우연히 큰 차이를 골랐을 수 있습니다. 새 자료에서 같은 정의로 검증하거나, 적어도 언제 발견한 결과인지 구분합니다.
