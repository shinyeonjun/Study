계산 결과, 예측 파일, 검정 답안을 한 번씩 완성한다

하루 작업의 기록 세 묶음을 받았습니다. 어느 유형인지 알아보는 데서 멈추지 않고, 서로 다른 세 가지 종류의 답을 끝까지 만들어 봅니다.

이 장을 읽고 나면

  • 주어진 조건으로 남긴 값의 개수와 평균을 계산한다.
  • 평가 표 순서에 맞춰 예측 파일을 생성하고 다시 읽는다.
  • 분할표의 독립성 검정과 보고할 차이를 구별한다.

아래 세 지시를 먼저 답안 메모에 옮긴다

이 장의 데이터와 요구 조건은 연습용입니다. 한 번은 전체 흐름을 읽고, 다음에는 스스로 정한 연습 시간 안에 문제만 보고 다시 풉니다. 공식 체험에서는 유형마다 실제 화면에 명시된 제출 위치와 형식을 따릅니다. 아래에서는 세 가지가 섞이지 않도록 계산값, 파일, 검정 결과를 각각 확인합니다.

구분연습 문제제출할 것
제1유형시간 기록 [8,14,빈칸,26,10,18,31,22]분에서 빈칸과 범위 [0,20] 밖을 제외. 남은 값의 개수와 평균을 계산개수는 정수, 평균은 소수 첫째 자리
제2유형이미 적합한 예측 규칙 ŷ=3+3x를 평가 행 (31,3),(12,4),(28,2)에 적용. 각 쌍은 (주문 ID, 작업량)원본 순서로 result.csv에 pred 한 열
제3유형지점 A의 지연·정시 [10,10], B의 지연·정시 [4,16]. Pearson χ² 독립성 검정 실시. 이 연습에서는 연속성 보정 미적용χ² 통계량과 p값을 소수 셋째 자리까지

가공과 예측에서 입력과 출력의 짝을 확인한다

시간 숫자 중 0~20 안에 있는 것은 8,14,10,18입니다. 모두 4개이고 합은 50, 평균은 12.5입니다. 빈칸은 0분이라는 기록이 없으므로 분모에 넣지 않았습니다. 자료가 정해 준 범위 안 값을 남겼고, 다른 문제라면 범위 검사나 결측 대체 규칙이 달라질 수 있습니다.

평가 데이터는 ID 31, 12, 28의 순서입니다. 작업량 3,4,2를 정해진 식에 넣으면 예측은 12,15,9입니다. 제출 파일에는 ID가 빠지지만 파일 속 행의 위치가 원본 평가 대상과의 짝을 나타냅니다. 출력의 처음 두 행을 손계산한 순서와 비교합니다.

도수가 다른 원인을 말하기 전에 관측과 기대를 비교한다

지점별 한 행의 합은 20입니다. 지연 열 합계는 14, 정시 열 합계는 26입니다. 독립을 가정한 A의 기대 지연은 20×14÷40=7이고 기대 정시는 13입니다. B에서도 각각 7, 13입니다. 각 셀의 관측−기대 크기는 3이라 χ²=2×(9/7+9/13)=360/91≈3.956입니다. 자유도는 (2−1)(2−1)=1이고 p값은 약 0.046703입니다.

연습에서는 각 방문이 한 셀에만 들어가며 서로 독립이라고 둡니다. 표본이 희소하거나 같은 사람이 시점마다 반복해서 들어가면 이 근사와 독립 가정을 다시 확인해야 합니다. 계산값은 0.05보다 작습니다. 지연 비율 차이로 보면 A 50% 대 B 20%, 30퍼센트포인트입니다. 관측된 연관을 확인해도 지점의 업무량 차이 같은 다른 조건을 확인하기 전에는 원인까지 판단하기 어렵습니다.

세 답을 코드에서 만들고 파일은 다시 읽는다

from pathlib import Path
from tempfile import TemporaryDirectory

import pandas as pd
from scipy.stats import chi2_contingency

time = pd.Series([8, 14, None, 26, 10, 18, 31, 22])
eligible = time[time.between(0, 20)]
print("type 1:", len(eligible), f"{eligible.mean():.1f}")

evaluation = pd.DataFrame({"id": [31, 12, 28], "volume": [3, 4, 2]})
predicted = 3 + 3 * evaluation["volume"]
submission = pd.DataFrame({"pred": predicted})

def export(frame, path="result.csv"):
    frame.to_csv(path, index=False)
    return pd.read_csv(path)

with TemporaryDirectory() as folder:
    saved = export(submission, Path(folder) / "result.csv")
    assert list(saved.columns) == ["pred"] and len(saved) == len(evaluation)
    assert saved["pred"].tolist() == predicted.tolist()
    print("type 2:", saved.columns.tolist(), saved["pred"].tolist())

counts = [[10, 10], [4, 16]]
outcome = chi2_contingency(counts, correction=False)
assert outcome.expected_freq.tolist() == [[7.0, 13.0], [7.0, 13.0]]
print("type 3:", f"{outcome.statistic:.3f}", f"{outcome.pvalue:.3f}")
type 1: 4 12.5
type 2: ['pred'] [12, 15, 9]
type 3: 3.956 0.047

위 출력은 검산용입니다. 연습용 임시 경로는 실제로 파일을 만들어 다시 읽되 작업이 끝나면 정리합니다. 실제 제2유형 제출에서는 지시한 파일명으로 예측 파일을 생성하도록 export(submission)처럼 명시해야 합니다. 제1·3유형에서는 계산기에 나온 말이나 목록 전체를 붙이지 않고 각 소문항 값만 적습니다.
