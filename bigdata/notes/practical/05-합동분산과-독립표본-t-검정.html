5-05

분산비, 합동분산, 양측 p값을 차례로 구한다

두 장비의 평균 처리시간이 다른지 확인합니다. 같은 두 표본이라도 분산을 비교하는 질문과 평균을 비교하는 질문에서 필요한 통계량이 다릅니다.

이 장을 읽고 나면

  • 분산비를 계산할 때 분자로 둘 집단과 자유도를 정한다.
  • 합동분산과 독립표본 t 통계량을 원래 정밀도로 계산한다.
  • 양측 p값과 효과의 크기를 따로 해석한다.

먼저 비교 단위와 가설을 읽는다

공식 제3유형 체험에는 두 집단의 분산비, 합동분산, 합동분산을 이용한 독립표본 t 검정의 p값을 구해 각각 제출하는 예가 있습니다. 이 장은 장비 A와 B의 합성 처리시간으로 같은 계산 순서를 연습합니다. A의 관측은 [8,9,10,11,12]분이고 B는 [6,7,8]분입니다. 각 그룹은 서로 다른 작업에서 관측했습니다. 계산에서는 관측은 그룹 안팎에서 서로 독립이고, 각 그룹의 모집단은 정규분포를 따른다고 가정합니다. 합동 t 단계에서는 추가로 두 모집단 분산이 같다고 가정합니다.

이 장의 ①은 두 모집단 분산이 같다는 귀무가설 아래 F 검정에 쓰는 통계량을 구합니다. 분자에 자유도가 더 큰 집단의 분산을 넣으라고 정했습니다. ②는 합동분산을, ③은 ‘두 모집단의 평균이 서로 다르다’가 대립가설인 양측 t 검정의 p값을 묻습니다. 계산은 충분한 정밀도로 진행하고 각 답은 소수 셋째 자리까지 적습니다.

항목AB
관측 수53
평균10분7분
평균으로부터의 제곱편차 합10분²2분²
표본분산10÷4=2.5분²2÷2=1분²
표본분산의 자유도42

분산비의 순서를 놓치지 않고 합동분산을 만든다

표본분산을 구할 때에는 평균을 이미 표본에서 추정했으므로 각각 n−1로 나눕니다. 이번 지시에서는 자유도가 더 큰 A가 분자입니다. F=2.5÷1=2.5이고 자유도는 (4,2)입니다. 분산이 큰 그룹을 분자로 두라는 지시였다면 문제의 조건에 맞춰 다시 결정해야 합니다. 분자가 어떤 그룹인지에 따라 F 기준 분포의 자유도 쌍도 따라갑니다. 이 소문항은 분산비만 묻습니다.

합동분산은 그룹별 분산을 단순 평균하지 않습니다. 각 그룹의 제곱편차 합을 합쳐 자유도의 합으로 나눕니다. 이 경우 sₚ²=(4×2.5+2×1)/(4+2)=2분²입니다. 표본분산 2.5와 1이 같지 않다는 사실만으로 두 모집단 분산이 반드시 다르다고 볼 수 없습니다. 이 연습에서 합동 t를 쓰는 이유는 소문항이 그 계산을 지시했기 때문입니다.

평균 차이를 표준오차로 나눈 뒤 양쪽 꼬리를 센다

A−B의 관측 평균 차이는 3분입니다. 합동분산을 써 평균 차이의 표준오차를 √[2(1/5+1/3)]≈1.0328분으로 구합니다. 통계량은 t=3/√[2(1/5+1/3)]≈2.9047이고 자유도는 5+3−2=6입니다. 이 양측 p값은 평균이 같다는 가정 아래 지금 관측한 절댓값 이상의 t를 얻을 확률입니다. 약 0.027166이므로, 소수 셋째 자리까지 쓰는 답은 0.027입니다.

유의수준을 0.05로 정했다면 합동 t 가정에서 평균이 같다는 귀무가설을 기각합니다. p값은 실제로 몇 분 차이인지 말해 주지 않습니다. 해석에서 관측 평균 차이 3분, 장비에 배정한 방식과 독립성, 표본이 아주 작다는 제약을 함께 살핍니다. 짝지은 작업이라면 작업별 차이를 분석해야 하고, 두 독립 그룹에서 등분산을 가정하지 않는다면 Welch t를 고려할 수 있습니다.

분산과 통계량을 직접 계산하고 SciPy 결과와 맞춘다

from math import sqrt
from statistics import mean, variance
from scipy.stats import ttest_ind

a = [8, 9, 10, 11, 12]
b = [6, 7, 8]
df_a, df_b = len(a) - 1, len(b) - 1
var_a, var_b = variance(a), variance(b)
f_value = var_a / var_b
pooled = (df_a * var_a + df_b * var_b) / (df_a + df_b)
se = sqrt(pooled * (1 / len(a) + 1 / len(b)))
t_value = (mean(a) - mean(b)) / se
result = ttest_ind(a, b, equal_var=True, alternative="two-sided")
assert abs(t_value - result.statistic) < 1e-12

print(f"1. F = {f_value:.3f}")
print(f"2. pooled = {pooled:.3f}")
print(f"3. p = {result.pvalue:.3f}")
print(f"check: t={t_value:.4f}, df={df_a + df_b}")
1. F = 2.500
2. pooled = 2.000
3. p = 0.027
check: t=2.9047, df=6

마지막 확인 줄은 계산을 검산하는 값입니다. 별도 답안에는 각 소문항이 요구하는 값만 넣습니다. 예를 들어 ③이 p값을 묻는다면 확인 줄의 t가 아니라 0.027을 적습니다.
