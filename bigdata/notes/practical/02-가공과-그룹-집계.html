5-02

필터와 결측 대체를 순서대로 적용한다

지점별 처리시간의 평균을 구하려면, 어떤 주문을 남기고 어느 값으로 빈칸을 채웠는지부터 설명할 수 있어야 합니다. 행 수가 바뀌는 지점마다 손계산과 코드를 대조합니다.

이 장을 읽고 나면

  • 읽은 표에서 빈칸과 범위 밖 수치를 구분한다.
  • 필터를 적용하고 그룹별 중앙값으로 결측을 채운다.
  • 그룹 집계의 분모와 정렬 동률 기준을 확인한다.

문제의 연산 순서를 표에 옮긴다

공식 제1유형 체험처럼, 여러 가공 결과를 관리한 뒤 각 답을 별도 화면에 입력하는 연습입니다. 출고 준비 한 건을 한 행으로 만든 여덟 건의 합성 자료를 사용합니다. order_id는 주문, site는 지점, minutes는 처리시간(분)입니다. 지시 순서는 다음과 같습니다.

  1. 기록된 처리시간이 0분 미만 또는 30분 초과라면 그 행을 제외합니다. 빈칸인 행은 따로 남깁니다.
  2. 남은 행에서 지점별 중앙값을 계산해 같은 지점의 빈칸을 채웁니다.
  3. 지점별로 채운 뒤의 행 수와 처리시간 합·평균을 구합니다. 전체 평균의 분모는 대체까지 마친 전체 주문 수입니다.
  4. 채운 뒤 처리시간이 가장 긴 주문을 찾습니다. 시간이 같은 경우 주문 번호가 작은 것이 앞섭니다.
지점원래 주문과 처리시간제외 이후의 중앙값빈칸을 채운 값
A101: 8, 102: 12, 103: 빈칸, 104: 60(8+12)÷2=108, 12, 10
B105: 12, 106: 20, 107: 16, 108: 빈칸12, 16, 20의 중앙인 1612, 20, 16, 16

30분은 남기는 범위의 끝이고, 60분은 제외합니다. 빈칸은 아직 값이 없는 상태입니다. 조건이 between(0,30) 하나라면 빈칸에도 거짓이 나와 빈칸 행이 사라질 수 있습니다. isna()로 만든 조건을 |로 합치면 빈칸을 그대로 남길 수 있습니다.

지점별 중앙값과 행별 대체 값을 계산한다

groupby("site")["minutes"].median()은 지점 수만큼 줄어든 결과를 만듭니다. 반면 transform("median")은 각 주문이 속한 지점의 중앙값을 그 주문 위치에 돌려주므로 원래 행과 길이·인덱스가 맞습니다. 이를 fillna에 넣으면 결측만 바꿉니다. 지점에 남은 관측이 모두 결측이면 중앙값도 결측이므로, 문제에서 지시한 대체나 제외 규칙이 있는지 확인합니다. 연습 데이터에서는 두 지점 모두 관측값이 남았습니다.

A는 합 8+12+10=30, 평균 10분, 행 수 3입니다. B는 합 12+20+16+16=64, 평균 16분, 행 수 4입니다. 전체 평균은 94÷7≈13.429분입니다. (10+16)÷2=13은 지점마다 같은 가중치를 준 수이므로 질문의 전체 주문 평균과 다릅니다.

결과에 들어가는 행과 분모를 코드로 점검한다

from io import StringIO
import pandas as pd

raw = StringIO("""order_id,site,minutes
101,A,8
102,A,12
103,A,
104,A,60
105,B,12
106,B,20
107,B,16
108,B,
""")
orders = pd.read_csv(raw)
time = orders["minutes"]
clean = orders.loc[time.isna() | time.between(0, 30)].copy()
by_site = clean.groupby("site")["minutes"]
clean["minutes"] = clean["minutes"].fillna(by_site.transform("median"))
assert clean["minutes"].notna().all()

summary = clean.groupby("site")["minutes"].agg(["size", "sum", "mean"])
for site, row in summary.iterrows():
    print(site, int(row["size"]), int(row["sum"]), f'{row["mean"]:.1f}')
first = clean.sort_values(["minutes", "order_id"], ascending=[False, True]).iloc[0]
print(f"overall: {clean['minutes'].mean():.3f}")
print("first order:", int(first["order_id"]))
A 3 30 10.0
B 4 64 16.0
overall: 13.429
first order: 106

지점별로 다 모여 있어도 전체를 다시 정렬할 때는 정렬 열의 우선순위를 분명히 둡니다. 가장 긴 시간은 내림차순이고 동률 주문 번호는 오름차순입니다. 열 선택과 집계 문법은 pandas 기초에서 이어서 볼 수 있습니다.
