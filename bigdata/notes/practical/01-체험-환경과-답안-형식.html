5-01

문제를 풀기 전에 제출할 답을 확인한다

계산이 맞아도 다른 칸에 쓰거나, 파일이 요구한 모양과 다르면 답을 전달하지 못합니다. 공식 체험을 열면 무엇을 어디에 적는지부터 구별합니다.

이 장을 읽고 나면

  • 공식 체험에서 풀이 화면과 제출 화면의 역할을 찾는다.
  • 유형별로 제출하는 것이 숫자 답인지 CSV 생성 코드인지 구별한다.
  • 계산값을 마지막에 제출 형식으로 바꾸고 자릿수를 확인한다.

공식 체험은 절차를 한 번 직접 실행하는 곳이다

한국데이터산업진흥원의 실기 체험에는 문제를 읽는 곳, 코드를 쓰는 곳, 실행한 결과를 확인하는 곳이 있습니다. 처음 열면 문제에서 제공한 데이터 이름과 열 설명, 언어 선택, 실행과 제출 위치를 차례로 찾습니다. 체험의 예시는 코드 작성과 실행, 제출을 연습하기 위한 자료라 본시험의 출제 경향을 보장하지 않습니다. 체험 안내에 따르면 본시험과 달리 체험에는 저장 기능이 제공되지 않으므로 여러 화면을 오갈 때 작성한 코드를 잃을 수 있습니다.

이 장의 체험 화면 설명은 2026년 11월에 공식 체험 페이지에서 확인한 내용입니다. 문항 수·배점·시험 시간·제출 방식·답안 형식은 회차마다 바뀔 수 있으므로, 응시하는 해의 데이터자격검정 공식 공지로 다시 확인합니다.

사용할 수 있는 패키지는 회차별로 달라질 수 있습니다. 공식 체험의 언어별 기본 코드로 설치 목록을 확인해 보고, 실제 응시 전에 데이터자격검정 공지의 이용 안내를 확인합니다. 이 책은 Python으로 풉니다. 이 장 아래의 연습은 모두 새로 만든 합성 값이라 체험 화면에 보이는 원문 문제와 별도로 풀 수 있습니다.

답이 들어갈 칸과 파일을 먼저 적어 둔다

유형공식 체험에서 확인할 점이 책에서 해 볼 일
제1유형데이터를 가공해 각 계산 결과를 지시한 형식으로 별도 화면에 입력결측 처리 → 그룹 집계 → 정수·소수 답
제2유형학습용 자료로 적합하고 평가용 데이터의 결과를 CSV로 만드는 코드를 제출분류 확률과 회귀 예측을 각각 만들고 열·순서·행 수 검사
제3유형검정통계량이나 p값 등의 소문항 답을 지시 순서대로 별도 화면에 입력독립표본 t·χ² 검정과 회귀 해석

공식 제2유형 체험은 특정 평가 지표와 제출 파일명, 예측 열 이름, 예측 행 수를 문제 문장에 제시합니다. 확인 시점의 체험 지시는 파일명 result.csv, 예측 열 pred 하나였고, 파일명에 폴더 경로를 붙이지 말라고 했습니다. 본문에서 실습할 때에는 그 장이 정한 이름을 사용하고 실제 문제에 들어가면 해당 지시로 바꿉니다. 평가용 자료에 있는 식별자는 원본 순서를 확인하는 데 쓸 수 있지만, 지시가 예측 열 하나라면 그 식별자를 제출 파일에 추가하지 않습니다.

버릴 위치와 반올림할 위치를 구별한다

계산기에서 4.761095를 얻었다고 합시다. 소수 셋째 자리까지 반올림해 적으라면 4.761입니다. 답이 0.1이어도 같은 서식으로 쓰면 0.100입니다. 수학적으로 같은 크기여도 답안 칸이 자릿수를 검사할 수 있습니다. 문제 문장에 정수나 소수 자리 조건이 있으면 화면에 넣기 직전에 적용합니다.

예를 들어 이 장의 연습에서 ‘소수부를 버려 정수로 적는다’는 것은 0 방향으로 버린다는 뜻으로 정했습니다. −3.9는 −3입니다. ‘바닥값을 취한다’면 원래 수보다 작거나 같은 가장 큰 정수인 −4입니다. 양수에서는 둘이 같아 보이므로 음수 자료에서 특히 구분해야 합니다. 여기서는 반올림의 정확한 중간값은 절댓값이 큰 쪽으로 보내는 규칙도 따로 명시합니다. Python의 round는 정확한 중간값에서 짝수 쪽을 택할 수 있고, 일반 float는 모든 소수를 정확히 표현하지 않습니다.

계산값과 답안 문자열을 각각 출력한다

from decimal import Decimal, ROUND_HALF_UP
from math import floor, trunc

number = Decimal("4.761095")
exact_half = Decimal("2.345")
print("numeric form:", number.quantize(Decimal("0.001"), rounding=ROUND_HALF_UP))
print("pad zeros:", Decimal("0.1").quantize(Decimal("0.001"), rounding=ROUND_HALF_UP))
print("tie practice:", exact_half.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP))
print("negative:", trunc(-3.9), floor(-3.9))
numeric form: 4.761
pad zeros: 0.100
tie practice: 2.35
negative: -3 -4

데이터와 검정을 계산하는 동안에는 충분한 자릿수를 유지합니다. 예를 들어 첫 소문항이 분산, 둘째가 분산으로 만든 검정통계량을 묻는다면, 둘째 계산에 넣는 값에는 원래 분산을 사용하고 제출할 때 각각 반올림합니다. 소문항에서 이미 반올림한 값을 쓰라고 명시했으면 그 지시를 따릅니다.
