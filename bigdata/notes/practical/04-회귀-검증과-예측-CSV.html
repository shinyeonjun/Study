5-04

시간을 지켜 회귀 검증을 하고 예측 CSV를 만든다

어제까지 학습한 모형으로 내일의 작업시간을 맞힙니다. 같은 시점의 평균을 쓰는 기준선과 선형회귀를 비교하고, 나중 날짜의 정답 없이도 제출용 예측을 만드는 순서를 봅니다.

이 장을 읽고 나면

  • 과거 학습, 이후 검증, 정답 없는 평가 자료를 분리한다.
  • 같은 검증 행에서 기준선과 선형회귀의 RMSE를 비교한다.
  • 선택한 모형을 다시 적합해 지정 순서의 실수 예측을 저장한다.

비교가 일어나는 시점과 행을 맞춘다

2026년 11월에 확인한 공식 제2유형 체험은 총구매액 예측을 요구하며, RMSE로 평가하는 예시와 한 열짜리 예측 CSV 지시를 제공합니다. 이번에는 새 합성 데이터에서 주문의 작업량 volume으로 작업시간 hours를 예측합니다. 작업일 1~4의 작업량 [1,2,3,4]와 시간 [3,5,7,9]로 적합하고, 작업일 5~7의 작업량 [5,6,7], 시간 [12,12,16]으로 비교합니다. 이후의 평가 행에는 시간 정답이 없습니다. 이 분할에서는 오늘의 작업량이 작업을 시작할 때 이미 확정된 값이라고 가정합니다.

원본 평가 표에는 같은 날의 여러 행이 있거나 순서가 의미상 정렬되어 있지 않을 수 있습니다. 이 연습에서는 미래 작업일을 발생 순서로 제시하고, 날마다 작업량이 [8,10,9]처럼 오르내립니다. 제출 서식의 순서는 평가 원본 행 기준입니다. 작업량 값으로 정렬한 순서가 아닙니다.

동일한 검증 데이터에서 오차를 계산한다

첫 기준선은 학습 시간 네 개의 평균 6시간을 모든 행에 예측합니다. 두 번째는 학습 데이터에 적합한 선형식 hours = 1+2×volume입니다. 선형식은 학습 자료에서 잔차 제곱의 합을 최소화한 절편과 기울기를 씁니다. 검증의 선형 예측은 [11,13,15]입니다.

RMSE는 오차 제곱의 평균에 제곱근을 씌워, 답을 원래 단위인 시간으로 돌려놓습니다. 선형식은 √[(1+1+1)/3]=1시간입니다. 기준선은 √[(36+36+100)/3]≈7.572시간입니다. 평균절대오차(MAE)도 원래 단위지만 RMSE보다 큰 오차의 영향을 덜 받습니다. 문제에서 RMSE로 비교하라고 했으면 그 값으로 후보를 고릅니다. 검증 예가 세 행뿐이라 우연에 민감하고 미래의 성능을 보장하지는 않습니다.

방식을 고른 다음 사용 가능한 라벨을 모아 다시 적합한다

검증에서 선형 회귀를 골랐습니다. 조건을 고정한 뒤 학습·검증 라벨을 합쳐 다시 최소제곱으로 적합하면, 처음과는 다른 절편과 기울기를 얻습니다. 이 단계 뒤 검증 데이터의 적합 오차를 앞서 구한 검증 지표 대신 쓰지 않습니다. 서로 같은 검증 행에서 비교한 지표가 후보 선택의 근거입니다. 평가용 정답은 계속 사용할 수 없습니다.

선택, 재적합, 저장을 한 번에 실행한다

from pathlib import Path
from tempfile import TemporaryDirectory

import numpy as np
import pandas as pd

x = np.array([1, 2, 3, 4, 5, 6, 7], dtype=float)
y = np.array([3, 5, 7, 9, 12, 12, 16], dtype=float)

def design(values):
    return np.column_stack([np.ones(len(values)), values])

def fit(values, hours):
    coefficients, *_ = np.linalg.lstsq(design(values), hours, rcond=None)
    return coefficients

def rmse(actual, predicted):
    return np.sqrt(np.mean((actual - predicted) ** 2))

baseline = np.full(3, y[:4].mean())
validation = design(x[4:]) @ fit(x[:4], y[:4])
print(f"RMSE baseline={rmse(y[4:], baseline):.3f}")
print(f"RMSE linear={rmse(y[4:], validation):.3f}")

test = pd.DataFrame({"day": [8, 9, 10], "volume": [8, 10, 9]})
final = fit(x, y)
print(f"refit intercept={final[0]:.3f}, slope={final[1]:.3f}")
pred = design(test["volume"].to_numpy()) @ final
submission = pd.DataFrame({"pred": pred})

def write_checked(frame, path="result.csv"):
    frame.to_csv(path, index=False)
    saved = pd.read_csv(path)
    assert list(saved.columns) == ["pred"] and len(saved) == len(test)
    assert np.isfinite(saved["pred"]).all()
    assert np.allclose(saved["pred"], pred)
    return saved

with TemporaryDirectory() as folder:
    saved = write_checked(submission, Path(folder) / "result.csv")
    for day, value in zip(test["day"], saved["pred"], strict=True):
        print(f"day {day}: {value:.3f}")

예제에서는 다른 파일에 영향을 주지 않도록 임시 경로를 사용합니다. 시험에서 지시한 이름이 result.csv이면 주어진 작업 폴더에 그 이름 그대로 생성하는 코드를 냅니다. 이 연습에서는 출력 줄만 읽기 쉽게 반올림하고 CSV 값은 그대로 저장합니다. 실제 문제에서 자릿수나 열 이름을 달리 지정하면 그 지시를 따릅니다.

scikit-learn을 쓰면 LinearRegression().fit(X, y)가 같은 절편·기울기를 줍니다. RMSE는 np.sqrt(mean_squared_error(y_true, y_pred))로 구하면 버전과 상관없이 동작합니다. 1.4 이상에는 root_mean_squared_error가 있고, 예전의 mean_squared_error(..., squared=False)는 1.4에서 사용 중단 예고 후 1.6에서 제거되었으므로 시험 환경의 버전을 먼저 확인합니다.
