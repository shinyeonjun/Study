5-06

기울기와 결정계수, p값이 답하는 질문을 나눈다

작업 강도가 커질 때 작업 시간이 얼마나 달라지는지 묻습니다. 같은 회귀 결과에서도 기울기, 결정계수, p값을 지시한 자리와 단위에 맞춰 따로 읽습니다.

이 장을 읽고 나면

  • 절편을 포함한 단순 선형회귀의 절편과 기울기를 구한다.
  • 잔차 제곱합과 결정계수의 뜻을 설명한다.
  • 기울기의 양측 p값을 효과의 크기와 구별해 제출한다.

문제의 출력이 예측 파일인지 회귀 숫자인지 확인한다

이 장은 공식 제3유형 체험의 숫자 답안 절차를 회귀에 적용한 자체 연습입니다. 공식 체험에 이 회귀 예제가 출제되었다는 뜻은 아닙니다. 작업 강도 x가 [1,2,3,4,5]일 때 걸린 시간 y가 [2,4,4,5,5]분인 합성 표본을 씁니다. 절편이 있는 최소제곱 회귀에서 ① 기울기, ② 결정계수, ③ 기울기가 0이라는 가설의 양측 p값을 구해 각 숫자를 소수 셋째 자리까지 작성합니다.

최소제곱식은 y의 관측치와 같은 x에서의 예측치 차이를 제곱해 더한 값을 가장 작게 만듭니다. x와 y의 평균은 3과 4입니다. 중심을 뺀 x의 제곱합은 10, x와 y 중심 편차의 곱은 합쳐 7입니다. 기울기는 7÷10=0.7, 절편은 4−0.7×3=1.9입니다. 강도가 한 단위 커질 때 이 모형의 예측 시간은 평균 관계로 0.7분 늘어납니다.

잔차 제곱합과 전체 변동에서 결정계수를 구한다

예측은 [2.6,3.3,4.0,4.7,5.4]이고 관측−예측 잔차는 [−0.6,+0.7,0,+0.3,−0.4]입니다. 잔차 제곱합 SSE=0.36+0.49+0+0.09+0.16=1.10입니다. 전체 변동은 평균 4를 모두의 예측값으로 썼을 때의 제곱합 SST=4+0+0+1+1=6입니다. 이 절편 포함 모형에서 결정계수 R²는 1−SSE/SST = 1−1.1/6 = 49/60≈0.8167입니다.

R²는 이 표본에서 평균으로 늘 같은 값을 내는 모형에 비해, 선형식이 제곱편차를 줄인 비율을 나타냅니다. 이 값을 관측 다섯 건 중 얼마나 많이 맞았는지의 비율로 읽으면 안 됩니다. 같은 식을 나중 자료에 넣었을 때의 오차도 별도로 확인해야 합니다.

표본에서 얻은 기울기의 불확실성을 계산한다

설명변수 값이 주어졌을 때 오차가 독립이고, 평균이 0이며 분산이 일정한 정규 오차를 가정합니다. 여기서 잔차 제곱합의 자유도는 표본 5개에서 절편·기울기 두 개를 뺀 3입니다. 기울기의 표준오차는 √[(1.1/3)/10]≈0.1915입니다. 기울기 0이 귀무가설이면 t=0.7/0.1915…≈3.656이고, t분포 양쪽 꼬리 p값은 약 0.03535입니다. 제출값은 0.035입니다.

0.05에서 기각하더라도 자료에서 연관을 관측했다는 정도로 해석합니다. 작업 강도가 높은 경우 장비나 담당자가 다르게 배정됐다면 단순회귀 하나로 강도의 효과를 분리하기 어렵습니다. 과제에서 기울기를 묻는 칸에 p값을 넣으면 뜻이 바뀝니다. 범위를 벗어난 강도의 예측에는 선형 관계가 계속된다는 가정도 추가됩니다.

SciPy 기울기와 수동 잔차 계산을 대조한다

from scipy.stats import linregress

x = [1, 2, 3, 4, 5]
y = [2, 4, 4, 5, 5]
fit = linregress(x, y, alternative="two-sided")
y_mean = sum(y) / len(y)
prediction = [fit.intercept + fit.slope * xi for xi in x]
sse = sum((o - p) ** 2 for o, p in zip(y, prediction, strict=True))
sst = sum((o - y_mean) ** 2 for o in y)
r_squared = 1 - sse / sst
assert abs(r_squared - fit.rvalue**2) < 1e-12

print(f"1. slope = {fit.slope:.3f}")
print(f"2. R2 = {r_squared:.3f}")
print(f"3. p = {fit.pvalue:.3f}")
print(f"check: intercept={fit.intercept:.3f}, SSE={sse:.3f}, SE={fit.stderr:.4f}")
1. slope = 0.700
2. R2 = 0.817
3. p = 0.035
check: intercept=1.900, SSE=1.100, SE=0.1915

linregress가 제공하는 rvalue의 제곱은 이 절편 있는 단순회귀에서 R²와 같습니다. 다중회귀에서는 각 특징과 정답의 상관계수를 제곱한 값 하나로 전체 모형의 R²를 대체할 수 없습니다.

핵심어기억할 기준
기울기x가 한 단위 변할 때 예측 y가 달라지는 양이다.
결정계수 R²이 절편 포함 회귀에서 평균 기준 대비 감소한 제곱합의 비율이다.
기울기의 p값귀무모형과 오차 가정에서 관측한 기울기의 표준화된 극단성을 평가한다.
