모형의 예측 근거와 특징 중요도 해석하기

어떤 입력을 바꾸면 모형의 점수가 변하는지 확인한다. 한 주문의 예측 근거와 여러 주문에서의 중요도, 실제 업무를 바꿨을 때의 효과를 따로 읽는다.

이 장을 읽고 나면

  • 개별 예측의 항별 기여를 계산한다.
  • 특징 순열 전후의 예측 오차 차이를 구한다.
  • 상관된 특징과 인과 효과에 관한 해석 한계를 설명한다.

한 주문의 예측을 항별로 읽기

모형이 예상 소요 시간을 ŷ=10+3x+2z로 계산한다고 하자. x는 묶음 수, z는 별도 확인이 필요하면 1, 아니면 0이다. 주문의 x=2, z=1이면 기본 10분에 6분과 2분을 더해 18분이다. ‘3분/묶음’은 이 모형에서 z를 고정했을 때의 예측 변화다. 실제 작업 방식을 변경했을 때의 효과를 추정하려면 개입과 비교 방법이 추가로 필요하다.

한 특징을 섞었을 때 오차 증가를 본다

검증 표의 x는 [0, 1, 2, 3], z는 [0, 1, 0, 1]이고 실제값은 [10, 15, 16, 21]이다. 설명용으로 이 모형이 네 원본 행을 정확히 맞춘다. 순열 중요도에서는 한 열의 순서를 바꾸어 그 값과 원래 행의 관계를 섞은 뒤 같은 모형을 평가한다. 원본 오차를 빼서 증가분이 얼마인지 본다.

평가 입력예측실제와의 절대오차MAE
원본10, 15, 16, 210, 0, 0, 00
x 순서를 반대로19, 18, 13, 129, 3, 3, 96
z 순서를 반대로12, 13, 18, 192, 2, 2, 22

이 특정 순열에선 묶음 수를 섞었을 때 오차가 6분, 확인 여부를 섞었을 때 2분 커졌다. 실제 순열 중요도는 여러 번 섞고 증가의 평균과 변동을 기록한다. 평가 지표나 기간을 바꾸면 어떤 특징이 중요한지도 바뀔 수 있다.

from statistics import mean

x, z = [0, 1, 2, 3], [0, 1, 0, 1]
actual = [10, 15, 16, 21]

def mae(groups, checks):
    predictions = [10 + 3*a + 2*b for a, b in zip(groups, checks)]
    return mean(abs(y - p) for y, p in zip(actual, predictions))

baseline = mae(x, z)
print("원본 MAE:", baseline)
print("x를 섞은 증가분:", mae(x[::-1], z) - baseline)
print("z를 섞은 증가분:", mae(x, z[::-1]) - baseline)

실행 결과

원본 MAE: 0
x를 섞은 증가분: 6
z를 섞은 증가분: 2

함께 움직이는 특징에 주의한다

입력에 묶음 수와 묶음에서 계산한 부피가 함께 들어가면 두 열이 같은 정보를 공유할 수 있다. 중요도가 어느 열에 높게 나타나는지는 모형이 이 정보를 어디에서 이용하는지에 따라 달라진다. 한 열씩만 섞으면 실제로 거의 없는 묶음 수와 부피의 조합이 생길 수도 있다. 같이 움직이는 열을 묶으면 질문은 ‘이 입력 묶음에 얼마나 의존하는가’로 바뀐다.

업무 보고에서는 입력 시점, 집계한 표본, 성능 지표와 설명 방법을 적는다. 중요도가 높은 특징이 우연히 결과를 겪은 뒤 추가된 열이라면 설명의 의미를 넓히기 전에 누출부터 점검한다.

한 줄 정리

특징을 섞어서 잰 값은 선택한 모형이 그 특징에 의존하는 정도를 보여 준다. 개입 효과에는 별도 근거가 필요하다.
