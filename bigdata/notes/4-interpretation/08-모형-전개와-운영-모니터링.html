모형 배포 뒤에 자료와 성능을 감시하기

교재에서 검증한 주문 알림을 실제 업무에 붙였다고 가정한다. 오늘 바로 볼 수 있는 입력 문제와 기간이 지난 뒤에 판단할 모형 성능을 구분해 대응한다.

이 장을 읽고 나면

  • 입력·예측·실제 결과의 확인 시점을 정한다.
  • 입력 분포 변화와 예측 성능 저하를 구분한다.
  • 조사·대체·재학습·재평가 순서를 운영 예로 설명한다.

모형은 어떤 시점에 어떤 결정을 돕는가

접수 시점에 지연 가능성이 높다고 판정하면 담당자에게 확인 목록을 준다. 알림이 누락되거나 서비스가 멈추면 시간 순으로 모든 주문을 보는 기본 운영 방식이 있다. 실제 지연 라벨은 다음 날 출고 기한이 지난 뒤에야 확정된다. 어느 버전으로 어떤 주문을 언제 평가했는지 예측과 함께 기록하면 나중에 같은 주문의 실제 라벨을 연결할 수 있다.

두 기간의 경보 표

지표기준 기간최근 기간확인 가능한 시점
결측 주문 / 전체 주문2 / 10012 / 100접수 시점
찾은 지연 / 실제 지연16 / 2012 / 20기간의 라벨 확정 뒤
결측률0.020.12접수 시점
재현율0.800.60기간의 라벨 확정 뒤

이 시설의 연습 규칙은 결측률이 0.08 이상이면 입력 경보, 확정 라벨의 재현율이 0.70 이하이면 성능 경보다. 최근 기간에는 두 경보 모두 조건에 해당한다. 표본 수가 적으면 우연한 변동도 있으므로, 기간별 건수와 집계 조건을 같이 표시한다. 아직 답이 없는 주문을 정상으로 계산하면 둘을 공정하게 비교하기 어렵다.

from fractions import Fraction as F

for label, missing, found in (("기준", 2, 16), ("최근", 12, 12)):
    missing_rate = F(missing, 100)
    recall = F(found, 20)
    print(label, f"결측 {float(missing_rate):.2f}",
          f"재현율 {float(recall):.2f}",
          "입력 경보", missing_rate >= F(8, 100),
          "성능 경보", recall <= F(7, 10))

최근 결측 0.12 재현율 0.60 입력 경보 True 성능 경보 True

무엇이 바뀌었는지 확인한 뒤 대응한다

입력 분포가 바뀌는 현상은 데이터 드리프트로 부를 수 있다. 입력과 결과의 조건부 관계가 바뀌는 현상은 개념 드리프트라고 한다. 결과의 기본 비율(예: 지연 비율) 자체가 바뀌는 것은 따로 라벨(사전 확률) 드리프트라고 부르기도 하며, 용어 구분은 문헌마다 조금씩 다르다. 입력 결측률이 늘었다고 조건부 관계의 변화를 바로 알 수는 없다.

입력 분포 변화를 숫자 하나로 보는 지표로 PSI(모집단 안정성 지수)가 쓰인다. 기준 기간의 구간별 비율 e와 최근 비율 a로 Σ(a−e)×ln(a/e)를 더한다. 예로 세 구간이 기준 0.5, 0.3, 0.2에서 최근 0.4, 0.3, 0.3이 되면 (−0.1)ln(0.8)+0+(0.1)ln(1.5)≈0.0223+0.0405≈0.063이다. 흔히 0.1 미만은 안정, 0.25 이상은 큰 변화로 보는 경험 규칙이 있으나 공식 기준은 아니다. 최근 상품군 구성, 접수 경로, 로그 전환 시점, 누락이 특정 열과 업체에 모여 있는지부터 살핀다.

열의 수집이 멈췄다면 연결을 복구하고 안정될 때까지 기본 운영 절차를 쓸 수 있다. 실제 업무 환경이 바뀌었다면 모형 입력·설정·학습 기간을 다시 검토한다. 고친 후보와 현재 모형은 같은 추후 기간에 비교하고, 담당자가 보는 알림 건수와 처리 가능량도 확인한다. 새 버전으로 넘기기 전에 이전 상태로 돌아갈 절차와 다시 평가할 날짜를 정한다.

후보를 운영에서 비교하는 방식으로, 현재 모형(챔피언)과 새 후보(챌린저)를 함께 돌리며 성능을 비교하거나, 후보의 예측을 기록만 하고 업무에는 쓰지 않는 그림자 운영, 주문의 일부만 무작위로 후보에 배정하는 A/B 테스트가 있다. 성능이 떨어진 모형을 다시 학습·조정하는 일을 리모델링이라고도 부르며, 주기적으로 할지 경보가 울릴 때 할지 미리 정한다.

한 줄 정리

입력은 지금 관측하고, 예측 성능은 라벨이 확정된 뒤 같은 주문 기준으로 비교한다. 조치는 조사 결과에 맞춘다.
