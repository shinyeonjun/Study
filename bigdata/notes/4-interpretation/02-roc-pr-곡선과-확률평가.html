ROC·PR 곡선과 확률의 오차 읽기

판정 임계값을 여러 곳에 두면 하나의 혼동행렬에서 곡선으로 넘어갈 수 있다. 점수를 순위로 보는 평가와 숫자를 확률로 보는 평가를 구분한다.

이 장을 읽고 나면

  • 임계값을 바꾸며 ROC와 PR 좌표를 계산한다.
  • 동점이 있는 점수의 ROC-AUC를 손으로 구한다.
  • 확률 예측의 보정과 제곱오차를 설명한다.

점수 하나에서 좌표 하나 만들기

여섯 주문의 모형 점수와 실제 지연 상태를 확인했다. 값이 클수록 지연이 의심된다고 하자. 점수가 임계값 이상이면 알린다. 0.8에서는 점수 0.9와 두 개의 0.8이 모두 알림 대상이다. 점수가 같은 두 주문을 임의 순서로 잘라 한 건만 넣는 기준은 이 임계값 규칙에 없다.

주문123456
점수0.90.80.80.40.30.1
실제 지연101010

0.8에서 실제 지연 세 건 중 두 건에 알리므로 참양성률(TPR)은 2/3이다. 실제 정상 세 건 중 하나에 잘못 알리므로 거짓양성률(FPR)은 1/3이다. ROC의 가로가 FPR, 세로가 TPR이므로 이 점은 (1/3, 2/3)이다. PR은 가로가 재현율, 세로가 정밀도다. 알림 세 건 중 실제 지연이 두 건이므로 PR 좌표는 (2/3, 2/3)이다.

두 주문씩 비교하는 ROC-AUC

양성 한 건과 음성 한 건을 뽑는 조합은 3×3=9개다. 양성 점수가 높으면 1점, 같으면 0.5점, 낮으면 0점이다. 양성 점수 0.9, 0.8, 0.3은 각각 3점, 2.5점, 1점을 얻는다. ROC-AUC는 6.5/9=13/18≈0.7222다. 이는 위 ROC 선분 아래의 사다리꼴 면적(1/6+2/9+1/3=13/18)과 같다. 즉 ROC-AUC는 "양성 하나와 음성 하나를 무작위로 뽑았을 때 양성 점수가 더 높을 확률(동점은 절반)"이다. 0.5는 무작위 순위(대각선), 1은 모든 양성이 모든 음성보다 위에 있는 완전한 순위다. FPR=1−특이도이므로 ROC는 재현율과 특이도의 맞바꿈을 그린 것이기도 하다.

PR을 그리면 목표인 재현율에 도달하는 데 알림이 얼마나 정확해야 하는지 보기 쉽다. 이 자료에서 무작위 순위의 정밀도 기준은 양성 비율 3/6=0.5다. 다른 자료의 양성 비율이 더 낮으면 같은 TPR·FPR에서도 정밀도가 더 낮아진다. 그래서 양성이 드문 문제에서는 ROC-AUC가 높아도 PR 곡선이 낮게 깔릴 수 있다. PR 곡선 아래 면적(PR-AUC)은 재현율 전 구간의 정밀도를 한 숫자로 요약하며, 무작위 기준은 0.5가 아니라 양성 비율이다. 점 사이를 직선으로 이어 면적을 구한 값과 평균정밀도(AP, 재현율이 늘어난 폭마다 그 지점의 정밀도를 곱해 더한 값)는 서로 다를 수 있으니 어떤 계산인지 적는다.

순위와 별도로 확률에 점수를 매긴다

이제 같은 0~1 점수가 실제 발생 확률로 제시됐다고 가정한다. 이진 브라이어 점수는 (예측 확률−관측값)²의 평균이고 낮을수록 좋다. 곧바로 틀린 경보를 세는 점수가 아니라 확률 하나하나에 제곱오차를 매긴다. 점수를 순서를 보존하도록 바꿔도 ROC-AUC는 같으나 확률의 브라이어 점수는 달라질 수 있다. 비슷한 확률을 낸 묶음의 실제 양성률을 보는 보정 그래프도 도움이 된다.

로그 손실(log loss, 교차 엔트로피)도 확률을 평가한다. 관측이 1이면 −ln(p), 0이면 −ln(1−p)를 매기고 평균한다. 낮을수록 좋다. 확신을 갖고 틀릴수록(예: 실제 1인데 p=0.01이면 −ln 0.01≈4.61) 벌점이 급격히 커진다는 점이 브라이어 점수와 다르다. 위 여섯 주문에서는 −[ln 0.9+ln 0.2+ln 0.8+ln 0.6+ln 0.3+ln 0.9]/6≈0.6264다.

from fractions import Fraction as F

scores = [F(x, 10) for x in (9, 8, 8, 4, 3, 1)]
labels = [1, 0, 1, 0, 1, 0]
pos = [s for s, y in zip(scores, labels) if y == 1]
neg = [s for s, y in zip(scores, labels) if y == 0]
auc = sum(F(int(p > n)) + F(int(p == n), 2) for p in pos for n in neg)
auc /= len(pos)*len(neg)
brier = sum((s-y)**2 for s, y in zip(scores, labels))/len(labels)
print("ROC-AUC:", auc, f"{float(auc):.4f}")
print("브라이어:", brier, f"{float(brier):.4f}")

실행 결과

ROC-AUC: 13/18 0.7222
브라이어: 9/40 0.2250

한 줄 정리

ROC·PR로 임계값에 따른 판정을 보고, 실제 발생 확률로 쓸 점수에는 확률 오차와 보정도 확인한다.
