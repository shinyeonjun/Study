베이지안 갱신과 다변량 분석 기법 고르기

오류를 잘 찾는 경보라도 오류 자체가 드물면 경보 뒤의 실제 오류 확률은 낮을 수 있다. 갱신 계산을 해 보고, 변수가 여러 개일 때 목적별로 다른 분석을 고른다.

이 장을 읽고 나면

  • 사전확률·우도·사후확률을 구분한다.
  • 자연빈도와 베이즈 공식으로 사후확률을 계산한다.
  • PCA, 요인분석, 다변량 분산분석의 질문을 구분한다.

경보가 울렸을 때 실제 오류일 확률

설명용으로 주문 1,000건에 오류가 20건 있다고 하자. 검사기는 오류 20건 중 16건에 경보하고 정상 980건 중 98건에도 경보한다. 오류를 E, 경보를 A라고 쓴다. 오류의 사전확률은 0.02다. 오류라고 둘 때 경보를 볼 확률, 즉 P(A | E)는 0.8이다. 정상이면 경보를 볼 확률 P(A | 정상)는 0.1이다.

상태경보경보 없음합계
오류16420
정상98882980
합계1148861,000

경보를 관측한 뒤에는 경보 114건만 분모에 넣는다. 16건이 실제 오류이므로 P(E | A)=16/114 ≈ 0.1404다. 베이즈 공식으로도 같은 값을 얻는다.

P(E | A)=P(A | E)P(E) / [P(A | E)P(E) + P(A | 정상)P(정상)]=(0.8 × 0.02) / (0.8 × 0.02 + 0.1 × 0.98).

from fractions import Fraction as F

prior = F(20, 1000)
hit = F(16, 20)
false_alarm = F(98, 980)
evidence = hit*prior + false_alarm*(1-prior)
posterior = hit*prior / evidence
assert posterior == F(16, 114)
print("경보율:", f"{float(evidence):.3f}")
print("사후확률:", f"{float(posterior):.4f}")

실행 결과

경보율: 0.114
사후확률: 0.1404

모수를 직접 관측하지 못할 때도 같은 원리를 확률분포에 적용한다. 모수의 사전분포와 관측 자료의 우도를 곱한 뒤 전체 확률이 1이 되도록 나누면 사후분포가 된다. 어떤 사전분포를 골랐는지 기록하고, 작은 표본에서는 사전을 바꿨을 때 결론이 어떻게 움직이는지도 살핀다.
