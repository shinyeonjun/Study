문장을 특징으로, 관계를 그래프로 표현하기

문장과 관계 기록을 모형에 넣으려면 분석 단위와 표현을 먼저 정한다. 세 문서의 TF–IDF와 작은 그래프의 연결 수를 계산한다.

이 장을 읽고 나면

  • 문서-단어 행렬의 행과 열을 세운다.
  • 한 가지 TF–IDF 정의에 따라 값을 계산한다.
  • 방향 그래프에서 진입·진출 차수를 구한다.

문장마다 어떤 단어가 얼마나 나오나

문의 D1은 ‘배송 배송 지연’, D2는 ‘배송 확인’, D3은 ‘주소 확인’이라고 하자. 이 예에서는 공백 단위로 토큰을 만들고 행은 문서, 열은 어휘로 둔다. ‘단어 주머니’(bag of words)는 각 어휘의 등장 수를 기록한다. 단어 순서는 사라지므로 ‘주소 확인’과 ‘확인 주소’의 빈도 벡터는 같다. 두 단어가 붙는 표현이 중요하면 순서가 있는 두 토큰 묶음(바이그램)을 특징으로 검토한다.

문서 안에서는 자주, 전체 문서에서는 드물게

이 장에서는 TF를 문서 안의 원시 등장 수, IDF를 ln (N/df)로 둔다. N은 학습 문서 수이고 df는 해당 단어가 등장한 문서 수다. 예를 들어 D1의 ‘배송’은 2ln (3/2) ≈ 0.8109이고 ‘지연’은 ln 3 ≈ 1.0986이다. 더 적게 등장한 ‘지연’이 전체에서는 희귀해 더 큰 값이 된다. 평활화, 정규화, TF 가중치 등 구현마다 변형이 있으므로 식을 확인한다. 이 장의 식에서 모든 학습 문서에 등장하는 단어의 IDF는 0이다.

from collections import Counter
from math import log

docs = [s.split() for s in ("배송 배송 지연", "배송 확인", "주소 확인")]
terms = ("배송", "지연", "확인", "주소")
df = Counter(term for doc in docs for term in set(doc))
counts = Counter(docs[0])
print("문서 빈도:", *(df[term] for term in terms))
for term in ("배송", "지연"):
    weighted = counts[term] * log(len(docs) / df[term])
    print(term, f"{weighted:.4f}")

실행 결과

문의 분류에서 새 문서가 들어오면 기존의 어휘 열과 학습 IDF를 적용한다. 테스트 문서까지 넣어 어휘나 IDF를 다시 추정하면 평가 문서의 내용이 학습 과정에 반영된다. 훈련 어휘에 없는 단어는 이 표현에 대응하는 열이 없다.

누가 누구에게 전달했는가

같은 고객 문의의 팀 간 전달을 그래프로 표현한다. 정점은 팀, 방향 간선은 ‘보낸 팀 → 받은 팀’이다. 간선이 A→B, A→C, C→B라면 B의 진입 차수는 2, 진출 차수는 0이다. A의 진출 차수는 2다. 집계 기간 내 같은 전달을 여러 번 기록했다면 방향 간선 하나의 가중치로 셀지, 기록마다 별도 간선으로 둘지 먼저 정한다.

한 줄 정리

문장에는 문서와 어휘의 관계를, 그래프에는 정점과 간선의 의미를 명시한 뒤 특징을 계산한다.
