거래에서 연관 규칙과 향상도 구하기

함께 장바구니에 들어온 품목을 찾는다. 많이 함께 등장했는지, 한 품목을 고른 사람에게서 다른 품목이 평소보다 자주 등장했는지를 서로 다른 수로 답한다.

이 장을 읽고 나면

  • 지지도·신뢰도·향상도를 계산한다.
  • 규칙의 방향을 바꾸고 각 지표를 비교한다.
  • Apriori의 후보 제거 원리를 설명한다.

거래 수와 함께 산 수를 구분하기

한 장바구니를 한 건으로 센다. 품목 A가 든 거래는 5건, 품목 B가 든 거래는 6건이며, 둘 다 든 거래는 4건이다. 전체는 10건이다. A만 담긴 거래가 1건, B만 담긴 거래가 2건, 둘 다 없는 거래가 3건이다. 품목의 수량을 여러 번 세지 않고 거래마다 등장 여부를 먼저 정한다.

서로 다른 분모 세 개

지표묻는 내용A→ B
지지도전체 거래 중 A와 B가 동시에 등장한 비율4/10=0.4
신뢰도A를 산 거래에서 B를 산 비율4/5=0.8
향상도A 거래의 B 비율을 전체 B 비율과 비교0.8/(6/10)=4/3

화살표를 바꾸면 신뢰도는 4/6=2/3이다. 향상도는 (2/3)/(5/10)=4/3으로 같다. 식을 P(A∩ B)/(P(A)P(B))로 정리하면 왜 대칭인지 볼 수 있다. 양쪽 품목이 관측되어 분모가 양수일 때, 향상도 1은 독립일 때 기대되는 동시 등장과 같은 비율, 1 초과는 그보다 자주 등장함을 뜻한다. 작은 표본의 1 초과만으로 안정적인 관계나 원인 관계를 결론 내리기 어렵다.

from fractions import Fraction as F

baskets = [set("AB")]*4 + [set("A")] + [set("B")]*2 + [set("C")]*3
joint = sum({"A", "B"} <= basket for basket in baskets)
a = sum("A" in basket for basket in baskets)
b = sum("B" in basket for basket in baskets)
size = len(baskets)
print("지지도:", F(joint, size))
print("신뢰도 A → B:", F(joint, a))
print("신뢰도 B → A:", F(joint, b))
print("향상도:", F(joint, a) / F(b, size))

실행 결과

지지도: 2/5
신뢰도 A → B: 4/5
신뢰도 B → A: 2/3
향상도: 4/3

후보를 미리 버리는 조건

Apriori는 일정 지지도 이상인 품목 집합부터 찾는다. A가 등장하지 않는 거래에서는 A와 B도 함께 등장할 수 없다. 따라서 품목이 추가될수록 집합의 지지도는 커질 수 없다. {A,B}의 지지도가 0.4이고 최소 지지도가 0.5라면 {A,B,C}의 지지도도 최대 0.4다. 세 품목 후보를 직접 세지 않고 제거할 수 있다.

한 줄 정리

지지도는 전체, 신뢰도는 왼쪽 품목의 거래, 향상도는 오른쪽 품목의 전체 등장률을 기준에 넣는다.
