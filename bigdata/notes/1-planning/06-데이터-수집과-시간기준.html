데이터를 수집하고 시간·중복 기준 정하기

센서에서 기록을 받았다는 말에는 언제 발생한 것인지, 누가 만든 것인지, 몇 번째 전달인지가 빠져 있습니다. 실제로 집계를 다시 계산할 수 있도록 수집 방법과 기록의 뜻을 먼저 정합니다.

이 장을 읽고 나면

  • 수집 원천과 전달 방식을 목적에 맞춰 선택한다.
  • 발생 시각과 수집 시각을 구별하고 늦은 기록을 다룬다.
  • 재전송 중복과 잘못된 자료를 따로 세어 검증한다.

어떤 기록을 어느 곳에서 얻는가

혼잡을 파악하려면 출입 센서 기록, 좌석 예약 표, 창구 대기 기록 등 서로 다른 원천을 모을 수 있습니다. 센서는 입장을 세고, 예약 표는 방문을 계획한 사람의 수를 보여 줍니다. 둘은 같은 사람 수를 측정하는 값이 아닐 수 있습니다. 기록마다 생성 원천과 자료 한 행의 뜻, 측정 단위, 갱신 주기를 먼저 확인합니다.

수집 방식쓰는 경우정할 기준
파일 일괄 제공매일 정리한 예약 파일을 한 번에 받는다파일 생성일, 날짜 범위, 형식과 받아야 할 시각
데이터베이스 조회허가된 업무 시스템에서 새 주문이나 변경 건을 가져온다키, 변경 시각, 조회 범위와 접근 권한
API문서화된 요청으로 필요한 항목을 가져온다요청 입력과 응답 형태, 이용 조건과 갱신 주기
이벤트·스트림기록이 계속 들어올 때 도착하는 대로 처리한다어느 시간이 기준인지, 늦은 도착과 중복 처리

배치 처리에서는 묶음을 만들어 정해진 시각에 처리합니다. 스트림 처리에서는 새 이벤트가 계속 들어오는 상황을 다룹니다. 스트림이라고 지연이 0이 되는 것은 아닙니다. 15분 이내에 안내가 필요한지, 하루 뒤 다시 계산해도 되는지에 따라 수집과 제공의 시간 목표를 정합니다.

발생한 시간과 시스템에 도착한 시간을 따로 남긴다

입장 센서가 10:12에 기록한 이벤트 e2는 통신을 거쳐 10:19에 서버에 도착했습니다. 구간의 실제 입장을 알고 싶은 분석에서는 발생 시각을 기준으로 10:00 이상 10:15 미만 구간에 넣습니다. 수집 처리율을 살피는 보고서라면 수집 시각을 볼 수 있습니다. 시간대 정보도 남겨 다른 지역의 기록과 비교할 때 같은 기준으로 바꿀 수 있게 합니다.

10:15 직후에 첫 화면을 보여 주면 e2가 아직 없으므로 10:00 구간의 합은 잠정치입니다. 뒤늦게 도착한 자료를 허용 범위 안에서 반영할지, 나중에 정정해 게시할지 계획합니다. 집계의 갱신 상태를 사용자가 알아야 수치가 바뀐 이유를 설명할 수 있습니다.

재전송을 통합하고 품질 오류를 남긴다

센서는 응답을 받지 못하면 같은 이벤트를 다시 보낼 수 있습니다. 아래 예는 센서 한 대에서 온 기록입니다. 같은 이벤트 ID를 다시 보낸 경우는 정확한 재전송이라고 가정합니다. 사람 수가 같다는 이유로 다른 이벤트를 하나로 합치면 손실이 됩니다. 같은 ID라도 정정 기록이 있는 원천이라면 버전이나 수정 규칙도 고려합니다.

from collections import Counter
from datetime import datetime

rows = [
    ("e1", "10:04", 7),
    ("e1", "10:04", 7),
    ("e2", "10:12", 9),
    ("e3", "10:18", 4),
    ("e4", "10:20", -1),
]
seen = set()
totals = Counter()
duplicate = invalid = 0
for event_id, time, visitors in rows:
    if visitors < 0:
        invalid += 1
        continue
    if event_id in seen:
        duplicate += 1
        continue
    seen.add(event_id)
    hour = datetime.strptime(time, "%H:%M")
    start = hour.replace(minute=(hour.minute // 15) * 15)
    totals[start.strftime("%H:%M")] += visitors

for start, total in sorted(totals.items()):
    print(start, total)
print("duplicate", duplicate, "invalid", invalid)

실행 결과

10:00 16
10:15 4
duplicate 1 invalid 1

날짜와 시간대가 같은 작은 예라 코드에서 시와 분만 사용했습니다. 원래는 들어온 다섯 줄을 그대로 보관하고, 중복 한 줄과 음수 한 줄이 제외됐다고 기록합니다. 외부 수집은 필요한 항목으로 범위를 좁히고 제공자, 이용 조건, 인가받은 방식, 갱신일을 함께 남깁니다.
