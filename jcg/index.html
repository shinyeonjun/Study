정처기 실기 코드 노트

기출 23회차의 C, Java, Python, SQL 문제를 개념별로 묶고, 기출에 덜 나왔지만 꼭 알아야 하는 개념까지 보탰습니다. 문법을 외우기 전에 코드가 메모리에서 어떻게 움직이는지부터 눈으로 확인하면서 공부할 수 있게 만들었습니다.

이렇게 쓰세요

  1. 장마다 원리 → 한 줄씩 따라가기 → 함정 → 기출 표시 순서입니다. 위에서부터 읽으면 앞 내용이 다음 내용의 바탕이 됩니다.
  2. 파란 기출 빈출은 실제로 여러 번 나온 개념, 노란 필수 보강은 기출에 적게 나왔지만 모르면 바로 틀리는 개념입니다.
  3. 한 줄씩 상자는 다음 ▶을 누르며 변수와 메모리가 바뀌는 걸 보는 곳입니다. 키보드 ← → 로도 움직입니다.
  4. 눌러 보기·직접 입력 상자는 값을 바꿔 가며 규칙을 확인하는 곳입니다.
  5. 연습 문제는 답을 입력하면 채점되고, 맞힌 문제는 이 컴퓨터 브라우저에 기록됩니다.

시험장 체크리스트

  • 출력 형식: 공백, 줄바꿈, 대괄호, 따옴표, 대소문자, 소수점 자리까지 코드대로인가
  • 정수 나눗셈과 나머지: C·Java는 0쪽으로 버림, Python //는 아래로 내림
  • C 포인터: 괄호 위치(*p+2와 *(p+2)), 기준점이 움직였는지, 매크로는 괄호 없이 글자 그대로 바뀌는지
  • C 구조체·연결리스트: 초기화 값으로 직접 그렸는가, head 삽입이면 순서가 뒤집혔는가
  • Java 상속: 메서드는 실제 객체, 필드·static·오버로딩 선택은 선언 타입
  • Java 생성자: 부모 먼저, 자식 필드는 부모 생성자가 끝난 뒤 초기화
  • Java 비교: 문자열·Integer(128 이상)·배열의 ==는 주소 비교
  • Python: 얕은 복사로 공유되는 안쪽 리스트, 슬라이싱 끝 미포함, 음수 간격의 시작점, 기본값 리스트 공유
  • SQL: 실행 순서, NULL은 집계와 비교에서 빠짐, AND가 OR보다 먼저, 행 수인지 값인지
  • 재귀: 종료 조건에 음수가 걸리는지, 작은 값부터 표로 채웠는지
