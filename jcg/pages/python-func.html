P-9출력 형식이 점수를 가른다기출 빈출

Python 문제는 코드가 짧은 대신 출력 형식에서 틀리게 만듭니다. 계산을 맞혀 놓고 공백 하나로 틀리지 않게 규칙을 정확히 알아 두세요.

print(1, 2, 3, sep='-', end='!\n')
print([1, 'a', True], (1,), {'k': 1})
print("%5.2f|%-4d|%s" % (3.14159, 7, 'ok'))
print(f"{7/2:.1f} {7//2:3d}|{'ab':>4}|")
print("a=", 20, "b=", 2)
출력
1-2-3!
[1, 'a', True] (1,) {'k': 1}
 3.14|7   |ok
3.5   3|  ab|
a= 20 b= 2
  • print(a, b)는 사이에 공백 한 칸, 끝에 줄바꿈. sep과 end로 바꿀 수 있음. end는 마지막 값 뒤에도 붙습니다.
  • 리스트를 그대로 찍으면 쉼표 뒤 공백, 문자열 작은따옴표까지 나옵니다.
  • True, False, None은 첫 글자가 대문자입니다.
  • %5.2f는 전체 폭 5칸에 소수 둘째 자리, 오른쪽 정렬. %-4d는 왼쪽 정렬. f-string은 {값:형식}

기출2020-4 9번, 2021-3 14번 (False), 2022-1 6번 ("a=", 20), 2022-3 9번 (리스트 출력), 2024-2 6번 (f-string), 2026-1 13번 (end='A'), 2022-2 13번 (% 포맷)

P-10연산자와 and·or필수 보강

print(2 ** 10, 7 // 2, -7 // 2, 7 % 3, -7 % 3)
print(1 < 2 < 3, 3 > 2 > 2, True + True)
print(0 or 5, 3 and 0, not 0, [] or "x", 2 and 5)
print(100 >> 2, 5 & 3, 5 | 3, 5 ^ 3, ~5)
출력
1024 3 -4 1 2
True False 2
5 0 True x 5
25 1 7 6 -6
  • **는 거듭제곱, //는 아래로 내림 나눗셈, %의 부호는 오른쪽 수를 따름
  • a < b < c는 a < b and b < c
  • or는 처음으로 참인 값, and는 처음으로 거짓인 값을 그대로 돌려줍니다. 끝까지 가면 마지막 값
  • True는 1, False는 0으로 계산됩니다
  • Python에는 ++, --가 없습니다. i += 1

기출2021-2 7번 (a >> i), 2021-3 14번 (비교 결과 False)

P-11함수기출 빈출

def f(a, b=10, *args):
    return a + b + sum(args)
print(f(1), f(1, 2), f(1, 2, 3, 4), f(b=5, a=1))

x = 10
def g(): x = 20          # 지역 변수 x를 새로 만듦
def h():
    global x
    x = 30               # 전역 x를 바꿈
g(); print(x); h(); print(x)
출력
11 3 10 6
10
30

기본값 리스트는 한 번만 만들어진다

  • 기본 인자는 안 넘기면 기본값, *args는 남은 위치 인자를 튜플로, **kw는 이름 붙은 인자를 딕셔너리로
  • 함수 안에서 대입하면 지역 변수가 됩니다. 전역을 바꾸려면 global
  • return이 없으면 None을 돌려줍니다
  • 기본값은 def 할 때 한 번 만들어져 계속 재사용됩니다. 리스트·딕셔너리를 기본값으로 쓰면 호출끼리 공유됩니다

기출2022-1 6번 (기본 인자). 가변 기본 인자는 기출에 아직 없지만 Python 출력 문제의 대표 함정입니다.

P-12컴프리헨션, lambda, map, filter기출 빈출

print(list(map(lambda x: x * 2, [1, 2, 3])))
print(list(filter(lambda x: x % 2, range(6))))
print([x ** 2 for x in range(1, 6) if x % 2])
print({k: len(k) for k in ['ab', 'c']}, {x % 3 for x in range(6)})
for i, (k, v) in enumerate(zip('ab', [1, 2]), 1):
    print(i, k, v)
print(any(x > 4 for x in [1, 5]), all(x > 4 for x in [1, 5]), sum(x for x in range(4)))
출력
[2, 4, 6]
[1, 3, 5]
[1, 9, 25]
{'ab': 2, 'c': 1} {0, 1, 2}
1 a 1
2 b 2
True False 6
  • lambda 매개변수: 식은 이름 없는 한 줄 함수
  • map(함수, 리스트)는 각 원소에 함수를 적용, filter(함수, 리스트)는 함수가 참인 것만. 그대로 찍으면 객체 주소가 나오니 list()로 감쌉니다
  • [식 for x in 반복 if 조건]: 조건을 통과한 x만 식으로 바꿔 모음. 중괄호면 셋이나 딕셔너리
  • enumerate(xs, 1)은 번호를 1부터, zip은 짧은 쪽 길이에 맞춰 짝을 지음

P-13정렬과 key필수 보강

words = ["banana", "kiwi", "apple", "fig"]
print(sorted(words))
print(sorted(words, key=len))
print(sorted(words, key=lambda w: w[-1]))
print(sorted(words, key=lambda w: (-len(w), w)))
print(max(words, key=len), min([3, -5, 2], key=abs))
출력
['apple', 'banana', 'fig', 'kiwi']
['fig', 'kiwi', 'apple', 'banana']
['banana', 'apple', 'fig', 'kiwi']
['banana', 'apple', 'kiwi', 'fig']
banana 2

key는 "이 값으로 비교하라"는 함수입니다. 튜플을 돌려주면 첫 값으로 먼저, 같으면 다음 값으로 비교합니다. 음수를 붙이면 그 기준만 내림차순이 됩니다.

P-14클래스기출 빈출

class Animal:
    count = 0                          # 클래스 변수 (Java의 static)
    def __init__(self, name):
        self.name = name               # 인스턴스 변수
        Animal.count += 1
    def speak(self): return "..."
    def intro(self): return self.name + ":" + self.speak()
    def __str__(self): return "Animal(" + self.name + ")"

class Dog(Animal):
    def __init__(self, name, age):
        super().__init__(name)
        self.age = age
    def speak(self): return "멍"

d = Dog("바둑", 3)
print(d.intro(), d.age, d, Animal.count)
출력
바둑:멍 3 Animal(바둑) 1
  • self는 Java의 this. 메서드의 첫 매개변수로 직접 적어야 합니다
  • 부모 메서드 안의 self.speak()도 실제 객체(Dog)의 것이 불립니다. Java의 동적 바인딩과 같습니다
  • 자식이 __init__을 만들면 부모 것은 자동으로 안 불립니다. super().__init__()을 직접 불러야 합니다
  • print(객체)는 __str__이 돌려준 문자열을 찍습니다

클래스 변수를 객체로 바꾸면

class K:
    cnt = 0
a = K(); b = K()
a.cnt = 5        # a에만 인스턴스 변수가 새로 생김
K.cnt += 1
print(a.cnt, b.cnt, K.cnt)
출력
5 1 1
