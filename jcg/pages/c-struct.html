C-9구조체와 화살표 연산자기출 빈출

구조체는 여러 상자를 묶은 큰 상자입니다. 구조체 변수로는 ., 구조체 포인터로는 ->로 멤버에 접근합니다. p->score는 (*p).score의 줄임말입니다. 구조체 포인터에 p++를 하면 구조체 하나 크기만큼 이동해서 다음 원소를 가리킵니다.

struct Stu { char name[10]; int score; };

struct Stu s[3] = { {"Kim", 70}, {"Lee", 85}, {"Park", 90} };
struct Stu *p = s;
printf("%s\n", p->name);
p++;
printf("%s %d\n", p->name, p->score);
printf("%d\n", (p + 1)->score - s[0].score);
출력
Kim
Lee 85
20

p++ 뒤에 p는 s[1]을 가리키니 p + 1은 s[2]입니다. 90 - 70 = 20. typedef struct {...} Stu;로 이름을 붙이면 struct를 빼고 Stu만 써도 됩니다.

함정

  • 기준점이 계속 움직입니다. p++를 할 때마다 화살표를 다시 그리세요.
  • *d->num은 *(d->num)입니다. ->가 *보다 먼저 붙습니다.
  • 중괄호 없이 나열한 초기값 {"Kim", 28, "Lee", 38}도 구조체 단위로 차례대로 채워집니다.
  • 구조체끼리 a = b로 대입하면 멤버 전체가 복사됩니다 (2025-2 14번).

C-10동적 할당 malloc필수 보강

연결리스트 문제마다 malloc이 나옵니다. "원하는 크기만큼 새 상자를 만들고 그 주소를 돌려준다"까지만 알면 충분합니다.

int *p = (int *)malloc(sizeof(int) * 3);   /* int 3칸짜리 공간 */
for (int i = 0; i < 3; i++) p[i] = (i + 1) * 10;
printf("%d", p[0] + p[2]);
free(p);                                    /* 다 쓰면 돌려줌 */
출력
40
  • malloc이 돌려주는 것은 주소라서 포인터에 담습니다.
  • sizeof(Node)는 구조체 하나의 크기. malloc(sizeof(Node))는 노드 하나를 새로 만드는 관용구입니다.
  • 함수 안에서 malloc으로 만든 공간은 함수가 끝나도 사라지지 않습니다 (지역 변수와 다른 점).

C-11연결리스트기출 빈출

연결리스트는 "다음 노드의 주소"를 품은 구조체를 줄줄이 이은 것입니다. 최근 기출에서 가장 자주 나온 모양은 맨 앞에 끼워 넣는 head 삽입인데, 이렇게 만들면 입력 순서가 뒤집힙니다.

for (Node *cur = head; cur != NULL; cur = cur->next)
    printf("%c", cur->ch);
출력
EDOC

노드를 떼어 옮기는 문제

2025년부터는 만든 리스트에서 노드를 빼거나 옮기는 문제가 나옵니다. 포인터 대입 한 줄마다 화살표 하나를 지우고 새로 그리세요.

작업코드그림으로
맨 앞에 삽입n->next = head; head = n;새 노드가 지금 맨 앞을 가리키고, head가 새 노드로
cur 뒤에 삽입n->next = cur->next; cur->next = n;순서를 바꾸면 뒤쪽을 잃어버림
cur 다음 노드 삭제cur->next = cur->next->next;건너뛰도록 연결
맨 앞 노드를 맨 뒤로first = head; head = head->next; first->next = NULL; tail->next = first;2 → 3 → 1

함정

  • 변수 이름(n1, n2...)이 순서를 알려주지 않습니다. next 대입을 따라가 최종 그림을 그리세요.
  • 같은 포인터에 여러 번 대입하면 마지막 대입만 남습니다 (2025-2 16번).

C-12스택과 큐기출 빈출

스택은 나중에 넣은 것이 먼저 나오고(LIFO), 큐는 먼저 넣은 것이 먼저 나옵니다(FIFO). 배열로 만든 스택은 top 하나, 큐는 front와 rear 두 개로 관리합니다.

int st[5], top = -1;
st[++top] = 1; st[++top] = 2; st[++top] = 3;   /* push 1, 2, 3 */
printf("%d ", st[top--]);                      /* pop → 3 */
st[++top] = 4;                                 /* push 4 */
printf("%d ", st[top--]);                      /* pop → 4 */
printf("%d", st[top--]);                       /* pop → 2 */
출력
3 4 2

배열 큐는 rear가 끝에 닿으면 앞자리가 비어 있어도 못 씁니다. 그래서 % 크기로 한 바퀴 돌게 만든 것이 원형 큐입니다.

  • st[++top] = x는 top을 먼저 올리고 넣기, st[top--]는 꺼내고 나서 내리기
  • 원형 큐: rear = (rear + 1) % N. 빈 상태는 front == rear, 가득 찬 상태는 (rear + 1) % N == front

C-13트리 순회기출 빈출

구조체 안에 포인터가 두 개(왼쪽, 오른쪽) 있으면 이진 트리입니다. 재귀 함수에서 "자기 처리" 줄이 재귀 호출 앞에 있는지, 사이에 있는지, 뒤에 있는지가 순회 방식을 정합니다. 아래에서 순회 방식을 바꿔 재생해 보세요.

typedef struct N { int v; struct N *a; struct N *b; } N;
int c = 0, rst = 0;

void fts(N *n) {
    if (n == NULL) return;
    fts(n->a);              /* 왼쪽 */
    fts(n->b);              /* 오른쪽 */
    if (++c == 3) rst = n->v;   /* 나: 재귀 뒤에 있으니 후위 */
}

함정

  • 변수 이름(an, bn, cn...)이 트리 모양을 알려주지 않습니다. {값, 왼쪽, 오른쪽} 초기값을 보고 직접 그리세요.
  • ++c == 3은 먼저 1을 더하고 비교합니다. 첫 방문 때 c는 1입니다. c++ == 3이면 네 번째 노드가 답이 됩니다.

기출2026-2 7번 (후위 순회 세 번째 노드). 2025-1 17번은 같은 원리를 Python 클래스로 냈습니다.

C-142차원 배열과 이중 포인터기출 빈출

int a[3][4]는 길이 4짜리 배열 세 개가 메모리에 한 줄로 붙어 있는 것입니다. a[i]는 i행의 시작 주소이고 *(a + i)도 같은 것이라서, a[i][j]는 *(*(a + i) + j)와 같습니다.

포인터 배열 int *pa[2]는 주소를 담는 칸 두 개입니다. 각 칸이 어느 행을 가리키는지 먼저 표로 적어 두세요.

int a[2][3] = { {1, 2, 3}, {4, 5, 6} };
int *pa[2] = { a[1], a[0] };     /* 순서가 바뀌어 있음 */
printf("%d\n", **(a + 1));
printf("%d\n", *(*a + 2));
printf("%d\n", pa[0][2]);
printf("%d\n", **pa + *(pa[1] + 1));
출력
4
3
6
6
식풀어 쓰면값
**(a + 1)a[1][0]4
*(*a + 2)a[0][2]3
pa[0][2]pa[0]은 a[1] → a[1][2]6
**pa + *(pa[1] + 1)a[1][0] + a[0][1]4 + 2 = 6
  • **x = x[0][0]
  • *(x[i] + j) = x[i][j]
  • 이중 포인터 int **pp = &p 는 '포인터의 주소'. *pp는 p, **pp는 p가 가리키는 값
  • C·Java 2차원 배열 초기화에서 빠진 칸은 0

C-15변수의 수명: 지역, 전역, static기출 빈출

같은 이름이라도 선언된 위치에 따라 다른 상자입니다. 안쪽에서 같은 이름을 선언하면 바깥 것을 가립니다.

int gx = 1;                          /* 전역: 어디서나 같은 상자 */
void f(void) { int gx = 2; gx++; }   /* 지역 gx가 전역을 가림 */
void g(void) { gx += 10; }           /* 전역 gx를 바꿈 */
int counter(void) { static int c = 0; c += 2; return c; }

int main(void) {
    int x = 3;
    { int x = 4; x++; }              /* 블록 안의 다른 x */
    f(); g();
    int sum = 0;
    for (int i = 0; i < 3; i++) sum += counter();
    printf("%d %d %d", x, gx, sum);
}
출력
3 11 12
종류만들어지는 때사라지는 때초기값
지역 변수블록에 들어올 때마다블록을 나갈 때쓰레기값 (직접 넣어야 함)
static 지역 변수처음 한 번프로그램 끝0, 초기화 줄은 한 번만 실행
전역 변수프로그램 시작프로그램 끝0

C-16재귀기출 빈출

재귀 호출은 호출할 때마다 새 상자 묶음(스택 프레임)이 위에 쌓이고, 끝나면 거꾸로 하나씩 풀립니다.

값을 묻는 문제는 큰 값부터 내려가며 따라가지 말고, 작은 값부터 표를 채워 올라가는 게 빠르고 안전합니다.

int f(int n) { if (n <= 1) return n; return f(n - 1) + f(n - 3); }
printf("%d %d", f(2), f(6));
n-10123456
f(n)-1011 + (-1) = 00 + 0 = 00 + 1 = 11 + 0 = 11 + 0 = 1
출력
0 1

함정

  • 종료 조건 n <= 1에는 음수도 걸립니다. f(-1)은 0이 아니라 -1입니다. 같은 함정이 C와 Java로 세 번 나왔습니다.

기출2026-2 18번·2020-4 19번·2023-3 11번 (f(n-1) + f(n-3)), 2022-1 14번·2023-3 8번 (팩토리얼), 2025-1 16번 (분할 재귀)

C-17비트 연산기출 빈출

2진수로 바꿔서 자리별로 계산합니다. 16진수 한 자리는 2진수 네 자리입니다(0xB6 = 1011 0110). 아래 계산기에 기출 숫자를 넣어 보세요.

int z = 6;
z = z & z >> 1;   /* 시프트가 먼저: 6 & 3 */
printf("%d", z);
출력
2
  • x << n은 ×2ⁿ, x >> n은 ÷2ⁿ (나머지 버림)
  • x & 1은 홀짝 판별 (x % 2와 같음)
  • x ^ x = 0, x ^ 0 = x. XOR을 두 번 하면 원래 값
  • ~x = -x - 1 (~13 = -14)

기출2025-1 19번 (& 0xA5), 2025-3 7번 (^ 42), 2025-3 15번 (z & z >> 1), 2024-1 2번 (<< 2), 2021-2 7번 (Python >>)

C-18switch와 함수 포인터기출 빈출

switch는 맞는 case에서 시작해서 break를 만날 때까지 아래로 계속 내려갑니다.

int score = 87, k = 0;
switch (score / 10) {          /* 87 / 10 = 8 */
    case 10:
    case 9: k += 1;
    case 8: k += 10;
    case 7: k += 100; break;
    default: k += 1000;
}
printf("%d", k);
출력
110

함수 포인터는 함수의 주소를 담는 변수입니다. 2026년 1회에 처음 나왔습니다. 선언이 낯설 뿐, 쓰는 법은 함수 이름과 같습니다.

int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }

int (*fp)(int, int) = add;         /* 반환형 (*이름)(매개변수형) */
printf("%d ", fp(3, 4));
fp = sub;
printf("%d ", fp(3, 4));
int (*ops[2])(int, int) = { add, sub };
printf("%d", ops[1](9, 4));
출력
7 -1 5
