S-1실행 순서 하나로 문법이 설명된다기출 빈출

SQL은 위에서 아래로 한 줄씩 실행되지 않습니다. 표 전체를 단계별로 걸러 내는 파이프라인입니다. 쓰는 순서는 SELECT가 맨 앞이지만, 실행은 FROM부터입니다. 단계 버튼을 차례로 눌러 보세요.

  • WHERE는 묶기 전에 실행되니 집계 함수(COUNT, AVG...)를 못 씁니다. 그룹 조건은 HAVING.
  • SELECT에서 붙인 별칭은 그 뒤인 ORDER BY에서만 쓸 수 있습니다. WHERE, GROUP BY, HAVING에서는 못 씀.
  • GROUP BY를 쓰면 SELECT에는 묶은 열과 집계 함수만 올 수 있습니다.

이 장의 나머지 예제와 연습 문제는 모두 아래 두 표로 실행했습니다.

S-2결과 행 수 계산기출 빈출

최근 기출은 SQL을 직접 쓰게 하기보다 "결과가 몇 행인지, 값이 얼마인지"를 많이 묻습니다. 아래 규칙만 정확하면 됩니다.

  • 집계 함수만 있고 GROUP BY가 없으면 결과는 항상 1행.
  • COUNT(*)는 행 수, COUNT(컬럼)은 NULL 제외, COUNT(DISTINCT 컬럼)은 중복도 제외.
  • DISTINCT는 결과 행에서 중복을 지웁니다.
  • AND가 OR보다 먼저 묶입니다.
  • 조건 없는 조인(CROSS JOIN, FROM A, B)은 행 수를 곱합니다.
SELECT COUNT(*), COUNT(점수), COUNT(DISTINCT 학과) FROM 학생;
-- 6 | 5 | 3

SELECT COUNT(*) FROM 학생 WHERE 학년 = 4 OR 학과 = '전자' AND 점수 >= 80;
-- 3   ← 학년 = 4 OR (학과 = '전자' AND 점수 >= 80)

SELECT COUNT(*) FROM 학생 WHERE (학년 = 4 OR 학과 = '전자') AND 점수 >= 80;
-- 1   ← 괄호를 쳐야 이렇게 됨

두 번째 쿼리는 학년 4인 이영희·최지훈 두 명에, 전자과면서 80점 이상인 이수진을 더해 3입니다. 왼쪽부터 차례로 읽으면 1이 나와서 틀립니다.

함정

  • "결과 행 수"를 묻는지 "결과 값"을 묻는지 확인하세요. SELECT COUNT(DISTINCT 학과) FROM 학생 WHERE 학과='컴퓨터'는 행 수 1, 값 1입니다. 3으로 쓰면 틀립니다.

기출2020-1 6번·2022-3 12번·2026-1 9번 (DISTINCT 행 수, 같은 유형 세 번), 2021-1 6번·2024-1 18번 (AND와 OR), 2021-3 13번 (CROSS JOIN), 2022-2 4번·2025-3 20번 (COUNT(col2)와 OR)

S-3NULL의 세 가지 규칙필수 보강

NULL은 "값이 없음"이라 0도 빈 문자열도 아닙니다. 비교, 집계, 조건에서 각각 다르게 동작합니다.

SELECT COUNT(*) FROM 학생 WHERE 점수 = NULL;          -- 0
SELECT COUNT(*) FROM 학생 WHERE 점수 IS NULL;         -- 1
SELECT COUNT(*) FROM 학생 WHERE 점수 >= 70;           -- 4
SELECT COUNT(*) FROM 학생 WHERE NOT (점수 >= 70);     -- 1   (4 + 1 ≠ 6)
SELECT AVG(점수), SUM(점수) FROM 학생;                 -- 81.6 | 408
규칙결과
NULL과의 비교 (= < > 등)참도 거짓도 아닌 '알 수 없음'이라 WHERE에서 걸러짐. NULL 찾기는 IS NULL, IS NOT NULL
집계 함수NULL을 빼고 계산. AVG는 408 / 5 = 81.6 (6으로 나누지 않음). COUNT(*)만 NULL 행도 셈
NOT, 반대 조건NULL 행은 조건에서도, 그 반대 조건에서도 빠짐. 이영희는 70 이상도 아니고 미만도 아님

S-4WHERE 조건기출 빈출

SELECT 이름 FROM 학생 WHERE 이름 LIKE '이%' ORDER BY 학번 DESC;
-- 이도윤, 이수진, 이영희

SELECT 이름 FROM 학생 WHERE 점수 BETWEEN 75 AND 90;
-- 김철수, 박민수, 이수진   (75와 90 포함)

SELECT 이름 FROM 학생 ORDER BY 학년 DESC, 이름 ASC;

S-5서브쿼리기출 빈출

서브쿼리는 안쪽부터 풀어서 값이나 목록으로 바꿔 놓고 바깥을 읽으세요.

SELECT 이름 FROM 학생 WHERE 점수 > (SELECT AVG(점수) FROM 학생);
-- 김철수, 이수진, 이도윤   (안쪽 = 81.6)

SELECT COUNT(*) FROM 학생
WHERE 학과 IN (SELECT 학과 FROM 학생 GROUP BY 학과 HAVING AVG(점수) >= 80);
-- 5   (안쪽 = 컴퓨터, 전자)

SELECT 학과명 FROM 학과 d
WHERE EXISTS (SELECT * FROM 학생 s WHERE s.학과 = d.학과명 AND s.학년 = 4);
-- 컴퓨터   (4학년이 있는 학과)
쓰는 법뜻
= (서브쿼리)서브쿼리 결과가 한 값일 때
IN (서브쿼리)결과 목록 중 하나와 같으면
> ALL (서브쿼리)결과 전부보다 큼 = 최댓값보다 큼
> ANY (서브쿼리)하나라도보다 큼 = 최솟값보다 큼
EXISTS (서브쿼리)결과가 한 행이라도 있으면 참. 바깥 행마다 다시 실행됨

기출2022-2 3번 (ALL), 2024-1 13번 (IN 서브쿼리), 2026-1 18번 (AVG 서브쿼리), 2024-3 3번 (중첩 서브쿼리)

S-6JOIN기출 빈출

두 표를 조건으로 이어 붙입니다. 종류마다 "짝이 없는 행을 남기느냐"만 다릅니다. 버튼을 눌러 결과를 비교해 보세요.

-- 같은 INNER JOIN을 WHERE로 쓰는 방식 (기출에 자주 나옴)
SELECT s.이름, d.건물
FROM 학생 s, 학과 d
WHERE s.학과 = d.학과명 AND s.학년 >= 3;
-- 김철수 공학관 / 이영희 공학관 / 박민수 IT관
  • 별칭 학생 s를 붙이면 s.이름처럼 줄여 씁니다.
  • LEFT JOIN은 왼쪽 표 행이 전부 남고, 짝이 없으면 오른쪽 열이 NULL.
  • 조인 결과 위에 GROUP BY나 COUNT를 하면, 조인으로 늘어난 행 수 기준으로 셉니다.

기출2021-2 6번 (JOIN ON 빈칸), 2025-1 7번 (WHERE 조인), 2026-1 18번, 2024-3 3번

S-7집합 연산기출 빈출

-- T1(A): 1, 2, 3, 3    T2(A): 3, 4
SELECT A FROM T1 UNION SELECT A FROM T2;       -- 1, 2, 3, 4
SELECT A FROM T1 UNION ALL SELECT A FROM T2;   -- 1, 2, 3, 3, 3, 4
SELECT A FROM T1 INTERSECT SELECT A FROM T2;   -- 3
SELECT A FROM T1 EXCEPT SELECT A FROM T2;      -- 1, 2   (오라클은 MINUS)
  • UNION은 합치고 중복 제거, UNION ALL은 그대로
  • INTERSECT는 양쪽에 다 있는 것, EXCEPT/MINUS는 왼쪽에만 있는 것
  • 두 SELECT의 열 개수와 타입이 같아야 합니다
  • UNION은 T1 안의 중복(3, 3)도 지웁니다
