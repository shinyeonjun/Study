SQL② 정의·관리·이론

S-8명령어 분류필수 보강

분류뜻명령어
DDL (정의어)구조를 만들고 바꾸고 없앰CREATE ALTER DROP TRUNCATE RENAME
DML (조작어)행을 다룸SELECT INSERT UPDATE DELETE
DCL (제어어)권한을 줌·뺏음GRANT REVOKE
TCL (트랜잭션 제어)작업 묶음을 확정·취소COMMIT ROLLBACK SAVEPOINT

필기에서도 나오는 분류지만, 실기에서는 "다음 중 DDL에 해당하는 것을 고르시오"나 빈칸형으로 나옵니다. TCL은 DCL에 포함해서 설명하는 교재도 있습니다.

S-10제약조건기출 빈출

제약뜻쓰는 법
PRIMARY KEY기본키. 중복 불가 + NULL 불가PRIMARY KEY (학번)
FOREIGN KEY외래키. 다른 표의 기본키 값만 허용FOREIGN KEY (학번) REFERENCES 학생(학번)
UNIQUE중복 불가 (NULL은 허용)이메일 VARCHAR(50) UNIQUE

CHECK허용 값 조건CHECK (계절 IN ('봄', '여름', '가을', '겨울'))

CONSTRAINT 이름제약에 이름 붙이기CONSTRAINT FK_TEAM FOREIGN KEY (...) REFERENCES ...

함정

  • REFERENCES의 S를 빼먹는 실수가 잦습니다.
  • 외래키 빈칸은 '참조하는 쪽 열'과 '참조되는 쪽 표(열)' 자리를 바꿔 쓰기 쉽습니다. FOREIGN KEY 뒤가 내 열, REFERENCES 뒤가 남의 표.

기출2026-1 10번 (CONSTRAINT ... FOREIGN KEY ... REFERENCES 빈칸 다섯 개), 2026-2 19번 (CHECK)

S-11DML: 행 넣고 고치고 지우기기출 빈출

INSERT INTO 학생 (학번, 이름, 학과) VALUES (7, '정하늘', '전자');
INSERT INTO 학생 VALUES (8, '한별', '기계', 1, 70);      -- 열 생략 시 모든 열을 순서대로
UPDATE 학생 SET 점수 = 점수 + 5, 학년 = 학년 WHERE 학과 = '전자';
DELETE FROM 학생 WHERE 이름 = '최지훈';

함정

  • DELETE FROM입니다. DELETE * FROM은 틀립니다.
  • UPDATE에는 반드시 SET. 여러 열은 쉼표로. 구조를 바꾸는 ALTER와 헷갈리지 마세요.
  • 문자열과 날짜는 작은따옴표. 전화번호 '010-1234-5678'도 문자열입니다.
  • WHERE를 빼먹으면 모든 행이 바뀌거나 지워집니다.
  • 문제 조건("IN을 사용", "WHERE 금지", "별칭은 AS로")을 반드시 그대로 지키세요. 결과가 같아도 감점됩니다.

기출2020-3 9번·2023-1 13번 (DELETE, 같은 문제 두 번), 2023-2 4번 (INSERT), 2021-2 5번·2024-2 3번 (UPDATE SET)

S-12DCL과 TCL필수 보강

GRANT SELECT, INSERT ON 학생 TO user1;
GRANT SELECT ON 학생 TO user2 WITH GRANT OPTION;   -- user2가 남에게도 줄 수 있음
REVOKE SELECT ON 학생 FROM user2 CASCADE;          -- user2가 나눠 준 권한까지 회수

UPDATE 학생 SET 점수 = 0 WHERE 학번 = 1;
SAVEPOINT A;
DELETE FROM 학생 WHERE 학번 = 2;
ROLLBACK TO A;      -- DELETE만 취소, UPDATE는 살아 있음
COMMIT;             -- 지금까지의 변경을 확정
  • GRANT는 TO, REVOKE는 FROM
  • COMMIT 후에는 ROLLBACK으로 되돌릴 수 없음
  • 트랜잭션 성질 ACID: 원자성(전부 아니면 전무), 일관성, 격리성, 지속성

S-13키와 무결성필수 보강

키조건예 (학번, 주민번호, 이름이 있는 학생 표)
슈퍼키유일성 (행을 구별할 수 있음){학번}, {학번, 이름}, {주민번호, 이름} ...
후보키유일성 + 최소성 (하나라도 빼면 구별 못 함){학번}, {주민번호}
기본키후보키 중 대표로 고른 것. NULL 불가{학번}
대체키기본키가 되지 못한 후보키{주민번호}
외래키다른 표의 기본키를 참조하는 열수강.학번 → 학생.학번
무결성규칙
개체 무결성기본키는 NULL이나 중복 값을 가질 수 없음
참조 무결성외래키 값은 참조하는 표의 기본키에 있는 값이거나 NULL
도메인 무결성열의 값은 정해진 범위(타입, CHECK) 안에 있어야 함

시험 팁키 종류는 서술형·단답형으로도 나옵니다. 외래키 문법은 2026-1 10번.
