P-1변수는 이름표, 복사는 세 종류기출 빈출

Python의 변수는 전부 이름표입니다. a = [1, 2]는 리스트 객체를 만들고 a라는 이름표를 붙이는 것입니다. Java 객체 변수와 같은 구조인데, 숫자와 문자열까지 모두 그렇습니다. 그래서 객체가 바뀔 수 있는지(list, dict, set) 없는지(int, str, tuple)가 결과를 가릅니다.

바깥 리스트안쪽 리스트
대입 b = a공유공유
얕은 복사 a[:], a.copy(), list(a), copy.copy(a)새로공유
깊은 복사 copy.deepcopy(a)새로새로
arr = [[0] * 3] * 3
arr[0][0] = 1
print(arr)
x = [1, 2]; y = x; y += [3]; print(x)
t = (1, 2); u = t; u += (3,); print(t, u)
p = [1]; q = [1]; r = p
print(p == q, p is q, r is p)
출력
[[1, 0, 0], [1, 0, 0], [1, 0, 0]]
[1, 2, 3]
(1, 2) (1, 2, 3)
True False True

함정

  • [[0] * 3] * 3은 같은 안쪽 리스트를 세 번 가리킵니다. 따로 만들려면 [[0] * 3 for _ in range(3)].
  • 리스트의 +=는 제자리에서 늘립니다(같은 객체). 튜플과 문자열은 바꿀 수 없어서 +=가 새 객체를 만듭니다.
  • ==는 내용 비교, is는 같은 객체인지 비교. Java의 equals와 ==가 반대 이름으로 붙어 있다고 생각하면 됩니다.

기출2026-1 14번 (m[:] 뒤 b[i+1] += b[i])

P-2인덱싱과 슬라이싱기출 빈출

규칙은 s[시작:끝:간격], 그리고 끝은 포함하지 않는다. 이 두 가지가 전부입니다. 음수 인덱스는 뒤에서부터 셉니다. 아래 시뮬레이터에 값을 넣어 보세요. 빨간 숫자가 뽑히는 순서입니다.

코드결과포인트
s[2:5]FOR2, 3, 4 (5는 미포함)
s[:3]INF시작 생략은 처음부터
s[-3:]ION뒤에서 세 개
s[::2]IFRAIN0, 2, 4, 6, 8, 10
s[::-1]NOITAMROFNI뒤집기
s[5:1:-1]MROF5, 4, 3, 2 (역방향도 끝 미포함)
s[1:5:-1]'' (빈 문자열)방향과 범위가 반대

함정

  • lst[::-2]처럼 시작을 생략하고 간격이 음수면 마지막 원소부터 시작합니다.
  • 공백과 밑줄도 한 칸입니다. 긴 문자열은 번호를 직접 적어 두고 자르세요.
  • 슬라이싱은 범위를 넘어가도 오류 없이 있는 데까지만 잘라 줍니다. 인덱싱 s[20]은 IndexError.

P-3문자열 메서드필수 보강

s = "  Hello, Python  "
print(repr(s.strip()), s.split(), "a,b,,c".split(","))
print("hello world".capitalize(), "hello world".title(), "Hello".upper(), "Hello".lower())
print("banana".count("a"), "banana".find("n"), "banana".find("z"), "banana".replace("a", "o", 2))
print("-".join(["a", "b", "c"]), "ab" * 3, "py" in "python", ord('A'), chr(97))
출력
'Hello, Python' ['Hello,', 'Python'] ['a', 'b', '', 'c']
Hello world Hello World HELLO hello
3 2 -1 bonona
a-b-c ababab True 65 a
메서드하는 일주의
split()공백 기준으로 나눠 리스트로인자 없으면 연속 공백도 하나로 취급
split(',')쉼표 기준구분자가 연달아 있으면 빈 문자열 ''이 생김
'구분자'.join(리스트)리스트를 이어 붙여 문자열로원소가 전부 문자열이어야 함
strip()양 끝 공백 제거가운데 공백은 그대로
find(x) / index(x)처음 나오는 위치없으면 find는 -1, index는 ValueError
replace(a, b, n)a를 b로 (n개까지)새 문자열을 돌려줌. 원본은 그대로
capitalize() / title()첫 글자만 대문자 / 단어마다 대문자capitalize는 나머지를 소문자로
count(x)x가 몇 번 나오는지대소문자 구분

P-4리스트기출 빈출

lst = [3, 1, 2]; lst.append([4, 5]); print(lst, len(lst))
l2 = [3, 1, 2]; l2.extend([4, 5]); print(l2)
print(l2.pop(), l2.pop(0), l2)
l2.insert(1, 9); l2.remove(9); print(l2, l2.index(4), l2.count(1))
r = l2.sort(); print(r, l2, sorted([3, 1, 2], reverse=True))
print([1, 2] + [3], [0] * 3, 2 in [1, 2])
출력
[3, 1, 2, [4, 5]] 4
[3, 1, 2, 4, 5]
5 3 [1, 2, 4]
[1, 2, 4] 2 1
None [1, 2, 4] [3, 2, 1]
[1, 2, 3] [0, 0, 0] True
메서드하는 일
append(x)x를 통째로 하나 추가 (리스트를 넣으면 리스트 하나가 원소로)
extend(xs)xs를 펼쳐서 여러 개 추가
insert(i, x)i번 자리에 끼움
pop() / pop(i)맨 끝 / i번을 꺼내서 반환
remove(x)값 x를 처음 하나 삭제, 반환 없음
lst.sort()원본을 정렬하고 None을 반환
sorted(lst)정렬된 새 리스트를 반환, 원본 그대로
reverse()원본을 뒤집음

P-5튜플과 언패킹필수 보강

a, b = 1, 2
a, b = b, a                 # 맞바꾸기
x, *rest = [1, 2, 3, 4]
t = (1,)                    # 원소 하나짜리 튜플은 쉼표 필수
print(a, b, x, rest, type(t).__name__, type((1)).__name__)
출력
2 1 1 [2, 3, 4] tuple int

튜플은 고칠 수 없는 리스트입니다. t[0] = 5는 TypeError. 함수가 return a, b로 여러 값을 돌려주면 사실 튜플 하나를 돌려주는 것입니다.

P-6딕셔너리기출 빈출

d = {'a': 1, 'b': 2}
d['c'] = 3
d['a'] = 10
print(d, d.get('z', 0), list(d.keys()), list(d.values()))
for k, v in d.items():
    print(k + str(v), end=' ')
출력
{'a': 10, 'b': 2, 'c': 3} 0 ['a', 'b', 'c'] [10, 2, 3]
a10 b2 c3
  • 넣은 순서를 유지합니다 (3.7부터).
  • 같은 키에 대입하면 덮어쓰기. 키는 중복될 수 없습니다.
  • d['z']처럼 없는 키를 읽으면 KeyError, d.get('z', 기본값)은 기본값.
  • for k in d는 키만, .items()는 (키, 값) 쌍.

기출2026-2 5번 (key[-1] + value[0]), 2025-3 9번 (값으로 튜플 저장), 2025-2 17번 (딕셔너리 컴프리헨션과 set)

P-7셋기출 빈출

st = {1, 2, 3}
st.add(2)                # 이미 있음, 무시
st.update([3, 4, 5])     # 여러 개 추가
st.remove(1)
print(st, st & {4, 5, 6}, st | {9}, st - {2}, st ^ {2, 7})
출력
{2, 3, 4, 5} {4, 5} {2, 3, 4, 5, 9} {3, 4, 5} {3, 4, 5, 7}
  • 중복 무시, 순서 없음. 출력 순서는 신경 쓰지 않아도 되고 원소만 맞으면 됩니다.
  • add는 하나, update는 여러 개를 펼쳐서 추가
  • & 교집합, | 합집합, - 차집합, ^ 대칭차(한쪽에만 있는 것)
  • 빈 셋은 set(). {}는 빈 딕셔너리

기출2020-2 2번·2023-1 15번 (add와 update, 같은 문제 두 번), 2025-2 17번 (교집합 크기)

P-8range와 자료형 변환필수 보강

print(list(range(5)), list(range(2, 10, 3)), list(range(5, 0, -2)))
print(type(3), type(3.0), type("3"), type([3]), type((3,)), type({3}), type({}))
print(int("12") + 1, str(12) + "1", float("1.5") * 2, int(3.99), int(-3.99))
print(bool(""), bool("0"), bool([]), bool(0.0))
출력
[0, 1, 2, 3, 4] [2, 5, 8] [5, 3, 1]
<class 'int'> <class 'float'> <class 'str'> <class 'list'> <class 'tuple'> <class 'set'> <class 'dict'>
13 121 3.0 3 -3
False True False False
  • range(시작, 끝, 간격)도 끝은 포함하지 않습니다. 슬라이싱과 같은 규칙
  • int()는 소수점 아래를 버립니다(0 쪽으로). //는 아래로 내림이라 음수에서 다름
  • 빈 것("", [], {}, 0, None)은 거짓, 나머지는 참. 문자열 "0"은 비어 있지 않아서 참
  • 문자열 + 숫자는 TypeError. str()로 바꿔서 이어 붙입니다.
