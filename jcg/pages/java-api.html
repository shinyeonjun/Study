J-9==는 주소, equals는 내용기출 빈출

String a = "java", b = "java", c = new String("java");
System.out.println(a == b);
System.out.println(a == c);
System.out.println(a.equals(c));
System.out.println(1 + 2 + "3" + 4 + 5);
System.out.println("x" + 1 + 2);
출력
true
false
true
3345
x12
  • 따옴표로 쓴 같은 문자열은 상수 풀에 하나만 만들어 공유합니다. 그래서 a == b가 true.
  • new String은 새 객체라 ==가 false. equals는 글자를 비교해서 true.
  • 배열도 ==는 주소 비교입니다. 내용이 같아도 false. 내용 비교는 Arrays.equals
  • +는 왼쪽부터 계산합니다. 문자열을 만나기 전까지는 숫자 덧셈(1 + 2 = 3), 그다음부터 전부 이어 붙이기.

Integer도 128부터는 다른 객체

Integer i1 = 127, i2 = 127, i3 = 128, i4 = 128;
int i5 = 128;
System.out.print((i1 == i2) + " " + (i3 == i4) + " " + i3.equals(i4) + " " + (i3 == i5));
출력
true false true true

Integer는 -128~127을 미리 만들어 두고 재사용합니다(캐시). 그 밖의 값은 매번 새 객체라 ==가 false입니다. 한쪽이 기본형 int면 Integer가 숫자로 풀려서(언박싱) 값 비교가 됩니다.

J-10String 메서드와 StringBuilder필수 보강

String s = "Hello,Java,World";
System.out.println(s.length() + " " + s.charAt(6) + " " + s.indexOf("Java") + " "
    + s.substring(6, 10) + " " + s.substring(11) + " " + s.split(",").length);
System.out.println(s.replace("l", "L") + " " + s.contains("Java") + " " + s.indexOf("z"));
s.toUpperCase();
System.out.println(s);
StringBuilder sb = new StringBuilder("abc");
sb.append("de").reverse();
System.out.println(sb);
출력
16 J 6 Java World 3
HeLLo,Java,WorLd true -1
Hello,Java,World
edcba
메서드결과주의
charAt(i)i번째 글자 (char)0부터
indexOf(x)처음 나오는 위치없으면 -1
substring(a, b)a부터 b-1까지끝 미포함 (Python 슬라이싱과 같음)
substring(a)a부터 끝까지
split(",")나눈 문자열 배열구분자는 결과에서 사라짐
replace(a, b)전부 바꾼 새 문자열원본은 그대로
toUpperCase()대문자로 바꾼 새 문자열결과를 대입하지 않으면 아무 일도 없음
StringBuilder고칠 수 있는 문자열append insert reverse가 자기 자신을 바꿈

함정

  • String은 불변입니다. s.toUpperCase();만 쓰고 s = 로 받지 않으면 s는 그대로입니다.
  • "ITISTESTSTRING".split("T")는 [I, IS, ES, S, RING]. T가 연달아 있으면 빈 문자열이 생깁니다 (2024-2 20번).

J-12예외 처리기출 빈출

try {
    int[] arr = new int[3];
    arr[3] = 1;
    System.out.print("A");
} catch (ArithmeticException e) { System.out.print("B");
} catch (ArrayIndexOutOfBoundsException e) { System.out.print("C");
} catch (Exception e) { System.out.print("D");
} finally { System.out.print("E"); }
System.out.print("F");
출력
CEF
  • try에서 예외가 난 줄 이후는 건너뜁니다 (A 안 찍힘).
  • 위에서부터 처음 맞는 catch 하나만 실행합니다 (D는 안 찍힘).
  • finally는 예외가 있든 없든, return이 있든 실행합니다.
  • 예외를 처리했으면 그 뒤 코드는 정상으로 이어집니다.

finally와 return

static int f() {
    int r = 1;
    try { return r; }
    finally { r = 100; System.out.print("F"); }
}
System.out.print(f());
출력
F1

return을 만나면 돌려줄 값 1이 먼저 정해지고, 나가기 직전에 finally가 실행됩니다. finally에서 r을 바꿔도 이미 정해진 반환값은 그대로입니다.

예외언제
ArithmeticException정수를 0으로 나눔
ArrayIndexOutOfBoundsException배열 범위 밖
NullPointerExceptionnull인 변수로 메서드·필드 접근
ClassCastException잘못된 다운캐스팅
NumberFormatExceptionInteger.parseInt("abc")

throw new 예외()는 직접 예외를 던지는 것, 메서드 선언 끝의 throws 예외는 "이 메서드는 예외를 밖으로 넘길 수 있다"는 표시입니다.

J-13컬렉션: ArrayList, HashSet, HashMap필수 보강

ArrayList<Integer> list = new ArrayList<>();
list.add(3); list.add(1); list.add(0, 9);     // [9, 3, 1]
list.remove(1);                                // 1번 자리 → [9, 1]
list.remove(Integer.valueOf(9));               // 값 9 → [1]
System.out.println(list + " " + list.size());

HashSet<Integer> set = new HashSet<>();
set.add(3); set.add(1); set.add(3);
System.out.println(set.size() + " " + set.contains(1));

HashMap<String, Integer> m = new HashMap<>();
m.put("a", 1); m.put("b", 2); m.put("a", 3);
System.out.println(m.get("a") + " " + m.getOrDefault("z", 0) + " " + m.size());
출력
[1] 1
2 true
3 0 2

함정

  • remove(1)은 1번 자리를 지웁니다. 값 1을 지우려면 remove(Integer.valueOf(1)).
  • 리스트를 그대로 찍으면 [9, 1]처럼 쉼표 뒤 공백이 붙습니다.
  • Set은 중복을 무시하고, Map은 같은 키에 넣으면 덮어씁니다.

시험 팁HashSet 크기 문제가 언어별 모음 문제에 있습니다. Python의 set, dict와 같은 개념이라 함께 보세요.

J-14람다와 함수형 인터페이스기출 빈출

메서드가 하나뿐인 인터페이스는 (매개변수) -> 식 모양의 람다로 바로 구현할 수 있습니다. 2025년 2회에 처음 나왔습니다.

interface Calc { int run(int a, int b); }

Calc add = (a, b) -> a + b;
Calc mul = (a, b) -> a * b;
System.out.print(add.run(2, 3) + mul.run(2, 3));
출력
11

(a, b) -> a + b는 "a와 b를 받아 a + b를 돌려주는 run 메서드"를 짧게 쓴 것입니다. 결과가 int 두 개라서 5 + 6 = 11이지 "56"이 아닙니다.

J-15enum, 제네릭, 배열기출 빈출

enum Color { RED, GREEN, BLUE }
enum Tri { A("x"), B("y"); final String c; Tri(String c) { this.c = c; } }

System.out.println(Color.GREEN.ordinal() + " " + Color.GREEN.name() + " " + Color.values().length
    + " " + Color.valueOf("BLUE") + " " + Tri.values()[1].c);

int[][] jag = new int[3][];
jag[0] = new int[2]; jag[1] = new int[4];
System.out.println(jag.length + " " + jag[1].length + " " + jag[0][1] + " " + jag[2]);
boolean[] bb = new boolean[2]; String[] ss = new String[2]; double[] dd = new double[1];
System.out.println(bb[0] + " " + ss[0] + " " + dd[0]);
출력
1 GREEN 3 BLUE y
3 4 0 null
false null 0.0
  • ordinal()은 선언 순서(0부터), name()은 상수 이름 문자열, values()는 전체 배열
  • Java 배열은 행마다 길이가 다를 수 있습니다. arr.length는 행 수, arr[i].length는 그 행의 길이
  • 배열 기본값: 숫자 0, boolean false, 객체 null
  • 제네릭 class Box<T>의 T는 쓸 때 정하는 타입. Box<String>이면 T가 String
