C① 메모리와 포인터

C는 메모리를 숨기지 않는 언어라서, 여기서 '변수는 상자, 포인터는 주소'를 잡아 두면 Java와 Python이 훨씬 쉬워집니다. 상자와 주소에서 출발해 배열, 문자열, 함수 인자, 서식, 반복 로직까지 이어집니다.

C-1변수는 상자, 포인터는 주소기출 빈출

변수를 선언하면 메모리에 상자가 하나 생기고, 상자마다 번지수(주소)가 붙습니다. &x는 x 상자의 주소이고, *p는 "p에 적힌 주소로 가서 그 상자를 열어라"라는 뜻입니다. 포인터 p도 상자 하나일 뿐인데, 안에 든 것이 값이 아니라 다른 상자의 주소입니다.

이것만 확실하면 C 포인터의 절반이 끝납니다

  • &x : x의 주소
  • *p : p가 가리키는 상자 (읽으면 값, 대입하면 그 상자를 바꿈)
  • int *p의 *는 선언에서 '포인터 변수'라는 표시, 식 안의 *p는 '따라가기'. 같은 기호가 두 역할을 합니다.
  • p + 1 : 다음 원소의 주소. int면 4바이트 뒤, 구조체면 구조체 하나 크기만큼 뒤

C-2배열과 포인터, 그리고 ++기출 빈출

배열 이름 a는 첫 칸의 주소입니다. 그래서 a[i]는 *(a + i)와 완전히 같은 말이고, 포인터 p에 a를 넣으면 p[i]로도 쓸 수 있습니다.

시험에서 제일 많이 틀리는 건 *와 ++, +가 한 줄에 섞일 때입니다. 괄호가 어디에 붙었는지만 보면 됩니다. 아래를 한 줄씩 넘겨 보세요.

  • *p++ : 값을 쓰고 포인터가 다음 칸으로 (후위 ++가 p에 붙음)
  • (*p)++ : 값을 쓰고 그 값이 1 증가
  • *++p : 포인터가 먼저 이동하고 값을 읽음
  • *p + 2 : 값에 2를 더함 / *(p + 2) : 두 칸 뒤의 값
  • 포인터끼리 빼면 바이트가 아니라 칸 수: &a[3] - &a[0] = 3

C-3문자열은 \0으로 끝나는 char 배열기출 빈출

"PROGRAM"은 메모리에 여덟 칸으로 들어갑니다. %s는 받은 주소부터 \0을 만날 때까지 전부 찍고, %c는 한 글자만 찍습니다. 그리고 C에서 문자는 사실 정수(아스키 코드)라서 'P' + 3은 'S'가 됩니다.

char *s = "PROGRAM";
printf("%s\n", s + 3);
printf("%c\n", *(s + 3));
printf("%c\n", *s + 3);
int len = 0;
while (s[len] != '\0') len++;
printf("%d %c\n", len, s[len - 2]);
출력
GRAM
G
S
7 A

길이를 세는 루프가 끝나면 len은 \0이 있는 7번 칸을 가리키고 있으니, s[len - 2]는 5번 칸 A입니다.

문자아스키쓰임
'A'65대문자 시작
'a'97소문자 = 대문자 + 32
'0'48문자 숫자를 정수로: ch - '0'
' '32공백
'\0'0문자열 끝

함정

  • %s에 주소를 넘기면 한 글자가 아니라 그 위치부터 끝까지 출력됩니다.
  • 문자끼리 빼면 정수가 나옵니다. 'E' - 'A'는 4.
  • char s[] = "abc"는 고칠 수 있는 배열이지만, char *s = "abc"는 읽기 전용 문자열을 가리킵니다. 후자를 s[0] = 'x'로 고치면 실행 오류.

C-4문자열 함수필수 보강

#include <string.h>의 네 함수는 기출 코드에 설명 없이 등장합니다. 모두 \0을 기준으로 움직인다는 점만 기억하세요.

char s1[20] = "Hello";
char s2[] = "World";
printf("%d %d %d\n", (int)strlen(s1), (int)sizeof(s1), (int)sizeof(s2));
strcat(s1, s2);
printf("%s %d\n", s1, (int)strlen(s1));
strcpy(s1, "Hi");
printf("%s %c\n", s1, s1[3]);
printf("%d %d %d\n", strcmp("abc", "abd") < 0, strcmp("b", "a") > 0, strcmp("ab", "ab"));
출력
5 20 6
HelloWorld 10
Hi l
1 1 0
함수하는 일주의
strlen(s)\0 앞까지 글자 수sizeof는 배열 전체 바이트 수 (\0 포함, 남는 칸 포함)

strcat(dst, src)dst의 \0 자리부터 src를 이어 붙임dst 배열이 충분히 커야 함

C-5함수에 넘기기: 값 복사와 주소 전달기출 빈출

C 함수는 인자를 항상 복사해서 받습니다. int n으로 받으면 원본과 상관없는 복사본을 고치는 것이고, 원본을 바꾸려면 주소를 넘겨서 *n으로 직접 고쳐야 합니다. 배열은 이름 자체가 주소라서 넘기면 원본이 바뀝니다.

void byValue(int n)   { n = 100; }
void byAddr(int *n)   { *n = 100; }
void swap(int *x, int *y) { int t = *x; *x = *y; *y = t; }
void inc(int arr[], int n) { for (int i = 0; i < n; i++) arr[i]++; }

int a = 1, b = 2, arr[3] = {1, 2, 3};
byValue(a);   printf("%d\n", a);
byAddr(&a);   printf("%d\n", a);
swap(&a, &b); printf("%d %d\n", a, b);
inc(arr, 3);  printf("%d %d %d\n", arr[0], arr[1], arr[2]);
출력
1
100
2 100
2 3 4

이 감각을 기억해 두세요. Java 장의 "참조 전달"과 Python 장의 "이름표"가 같은 이야기를 다른 문법으로 하는 것입니다.

함정

  • 구조체를 Acc a처럼 값으로 받으면 통째로 복사됩니다. 원본은 안 바뀝니다.
  • 매개변수 이름이 main의 변수 이름과 같아도 서로 다른 상자입니다.

C-7매크로는 글자 바꿔치기필수 보강

#define은 컴파일 전에 글자를 그대로 바꿔 끼웁니다. 함수처럼 계산해서 넘기는 것이 아니라서 괄호가 없으면 우선순위가 깨집니다.

#define SQ(x) x*x
#define SQ2(x) ((x)*(x))
#define MUL(a, b) a*b

printf("%d %d %d", SQ(2+3), SQ2(2+3), MUL(2+1, 3+1));
출력
11 25 6
코드바뀐 모습값
SQ(2+3)2+3*2+311
SQ2(2+3)((2+3)*(2+3))25
MUL(2+1, 3+1)2+1*3+16

시험 팁매크로는 기출 23회차에서 거의 나오지 않았지만 C 출력 문제의 대표 함정이라 짧게 정리해 둡니다.

C-8반복 로직과 정렬기출 빈출

C 기출의 4분의 1은 포인터 없이 반복문 하나로 숫자를 다루는 문제입니다. 자주 나오는 모양 몇 개만 손에 익혀 두면 읽는 속도가 크게 빨라집니다.

int n = 1234, rev = 0, sum = 0;
while (n > 0) {
    sum += n % 10;
    rev = rev * 10 + n % 10;
    n /= 10;
}
printf("%d %d", sum, rev);
출력
10 4321

정렬은 이웃한 두 칸을 비교해 바꾸는 버블 정렬이 가장 자주 나옵니다. 부등호 방향이 오름차순·내림차순을 정합니다.

  • 오름차순: 앞이 더 크면(a[j] > a[j+1]) 교환
  • 버블 정렬은 한 바퀴마다 가장 큰 값이 맨 뒤로, 선택 정렬은 한 바퀴마다 가장 작은 값을 찾아 맨 앞과 교환
  • 안쪽 반복 범위가 j < n - 1 - i처럼 줄어드는 이유는 뒤쪽이 이미 확정됐기 때문
